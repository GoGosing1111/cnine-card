숲켓몬 v1310 하이퍼 버닝 누적 패치

1. CMS에 기존 버닝과 분리된 하이퍼 버닝 패널/저장 API 추가
2. 하이퍼 버닝 기본값
   - PVE 최대 30회
   - PVP 최대 30회
   - 1분마다 1회 충전
   - PVE/PVP 코인 보상 2.5배
   - 중복 카드 조각 2배
   - 카드팩 30% 할인
   - 장비 보급상자 20% 할인
3. 기존 버닝은 붉은색 테마 유지
4. 하이퍼 버닝은 검은색 + 보라색 투톤 전용 테마/발동 연출/진행 배너 적용
5. 기존 버닝과 하이퍼 버닝은 설정을 각각 보존하되 동시에 ON 불가
   - 마지막으로 ON 저장한 이벤트가 활성화
   - 다른 이벤트는 같은 DB batch에서 자동 OFF
6. 캐시 및 저장 롤백 방지
   - CMS GET/PATCH no-store
   - 저장 응답 후 DB fresh 재조회 검증
   - 오래된 CMS 조회 응답 폐기
   - 이벤트 updatedAt 비교로 오래된 게임 상태 응답 폐기
   - 서버 메모리 캐시 1초 제한
   - 장비상자 구매 시 프로모션 설정 fresh 조회
7. DB 변경
   - 신규 테이블 없음
   - app_meta 키 hyper_burning_event_settings_v1310 1행만 사용
8. 프로젝트 노출 문구는 숲켓몬 기준으로 정리
