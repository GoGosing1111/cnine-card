숲켓몬 v1316 · PVE 전투 시작 버튼 무반응 핫픽스

배포
- v1315 이하 누적 패치 대신 v1316 누적 패치 하나만 적용합니다.
- PVP V2 작업은 이 핫픽스에서 포함하지 않았습니다.

원인
1. 몬스터 토벌 화면은 저장된 selectedMonster가 현재 몬스터 목록에 없으면 화면 표시만 현재 탭 첫 몬스터로 대체했습니다.
2. 그러나 battleState.selectedMonster는 이전 ID를 그대로 보존해 전투 버튼은 활성화될 수 있었습니다.
3. 버튼 클릭 후 startBattle이 실제 목록에서 이전 ID를 찾지 못하면 monster가 undefined가 됐고, 기존 try/catch 진입 전 monster.name을 읽으면서 예외가 발생했습니다.
4. 예외가 화면 표시 전에 발생해 사용자에게는 버튼을 눌러도 아무 반응이 없는 것처럼 보였습니다.
5. 전투 시작 버튼이 매 렌더링마다 생성되는 노드의 직접 onclick에만 의존해, DOM 재구성 시 클릭 복구 경로도 없었습니다.

수정
- 화면에 선택해 표시한 몬스터와 battleState.selectedMonster를 즉시 동기화합니다.
- 버튼에 type=button과 전용 data 속성을 부여합니다.
- document capture 단계의 단일 위임 클릭 핸들러로 DOM 재렌더 후에도 클릭을 보장합니다.
- 비활성 버튼, 전투 횟수 부족, 덱 5장 미편성은 서버 요청 전에 명확히 차단합니다.
- 몬스터 정보 불일치 시 첫 유효 몬스터로 복구하고 안내합니다.
- 모달 생성 전후 전체 전투 시작 구간을 try/catch/finally로 보호합니다.
- 시작 중 중복 클릭을 차단하고 성공·실패 모두 fightStarting 잠금을 해제합니다.
- V2 배지와 전투 시작 버튼의 pointer-events/z-index를 명시해 클릭 가로채기를 방지합니다.
- app.js와 battle-v2-live.css 캐시 버전을 v1316으로 변경했습니다.
