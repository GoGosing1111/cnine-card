숲켓몬 v1317 · 일반 PVP 전투엔진 V2 실전 적용

배포
- v1316 이하 누적 패치 대신 v1317 누적 패치 하나만 적용합니다.
- v1316 PVE 전투 시작 버튼 핫픽스와 기존 누적 기능을 모두 포함합니다.

적용 범위
- 일반 비동기 PVP의 서버 승패 판정을 전투엔진 V2와 연결했습니다.
- 기본 엔진 설정 V2_OWNER에서는 OWNER가 직접 도전한 일반 PVP에만 V2가 적용됩니다.
- 일반 유저는 기존 엔진을 유지합니다.
- CMS에서 V2_PUBLIC으로 변경하면 일반 PVE와 일반 PVP 모두 V2가 적용됩니다.
- 대장전, 레이드, 봉인전, 무한의탑은 이번 버전에서 변경하지 않았습니다.

PVP V2 판정
- 공격자와 수비자의 실제 저장 PVP 덱 5장을 사용합니다.
- 각 카드의 돌파 반영 전투력과 실제 고유효과를 사용합니다.
- 장비 총전투력의 PVP 배분값 10%를 양 진영에 각각 반영합니다.
- 카드 전투력을 HP, 공격, 방어, 속도로 분배합니다.
- 전열 2장과 후열 3장, 속도 행동 게이지, 보호막, 반격, 회복, 생존, 회피, 치명타, 처형을 적용합니다.
- 최대 100행동 후에도 양쪽이 생존하면 남은 HP와 보호막 비율로 판정합니다.
- 완전 동률은 기존 PVP 원칙대로 공격자 승리로 처리합니다.
- 서버 시드 기반 결정론으로 같은 요청 ID는 같은 전투 결과를 계산합니다.

화면
- 기존 카드 프레임, 등급 프레임, 돌파 표시와 고유효과 CSS를 유지합니다.
- 양 팀 5장의 실제 HP, 보호막, 행동 게이지를 표시합니다.
- 타격, 치명타, 회피, 회복, 반격, K.O., 전열 붕괴를 V2 타임라인 순서대로 재생합니다.
- 모든 V2 연출 속도는 1.6배로 고정합니다.
- PC, 와고 iframe, 모바일의 기존 PVP 전투 모달에서 재생합니다.

기존 기능 유지
- PVP 전투 횟수 차감과 충전
- 시즌 점수 증감, 승패 누적, 랭킹
- 승패 코인, 버닝 보상 배율
- 큐브, 마법 결정, 장비 드롭
- 같은 상대 연속 3회 제한
- FUR 및 PRESTIGE 덱 편성 제한
- CMS에서 기존 엔진으로 즉시 복귀하는 기능

추가 오류 예방
- PVP 전투 횟수가 부족할 때 존재하지 않는 cfg 변수를 참조하던 기존 오류를 수정했습니다.
- 부족 안내는 현재 서버 에너지 상태의 충전 시간을 사용합니다.
- PVP 설정 캐시는 1초로 제한해 CMS 엔진 전환의 오래된 상태가 오래 남지 않게 했습니다.

DB 및 용량
- 신규 테이블, 컬럼, 인덱스, 영수증을 추가하지 않았습니다.
- V2 타격 타임라인과 카드별 HP 변화는 응답으로만 전달하고 D1에 저장하지 않습니다.
- pvp_match_history에는 기존처럼 전투당 1행만 저장합니다.
- 신규 전투부터 attacker_deck과 defender_deck에 전체 카드 객체 대신 카드 ID 5개만 저장합니다.
- PVP 기록 조회에서도 사용하지 않는 덱 JSON 컬럼을 읽거나 전송하지 않습니다.
- 기존 저장 정리의 PVP 전투 기록 14일 보존 정책을 그대로 사용할 수 있습니다.
