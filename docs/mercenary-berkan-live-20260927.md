# 베르칸 SSS 운영 연결 — 2026-09-27

사용자 이름 베르칸, SSS, 크라이베른과 같은 희귀도. 후속 “현재 모션·오라로 확정” 답변으로 기술 검수본의 운영 등록·전투 연결을 승인했다. 원본 카드는 무가공 보존하며 SD, 제자리 사격, 피격/쓰러짐, 전용 스킬과 금빛 윤곽·흑금 오라를 사용한다. 달리기는 제외한다.

## 범위

- V-055 / MS-055 흑금 낙성. V-051~V-054는 별도 승인된 간호사 용병이 사용하므로 보존한다. 전체 운영 원화/SD 55종, 스킬 목록 35종.
- 기존 SSS 전투력 180,000, 후열 SNIPER. 초기 피해 배율 5.88 / 비용 35 / 재사용 5턴, PVP 상한 보정 1.3은 크라이베른 기준이다. 기존 단일 저격 서버 기믹을 사용하며 새로운 피해 판정이나 행동을 생성하지 않는다.
- 현재 CMS의 크라이베른 유효 가중치와 같은 베르칸 가중치를 사용한다. 예: 기존 8991:999:10에 10을 추가하면 8991:999:10:10이며, 두 희귀 용병 모두 SSS 안에서 10/10010이다. SSS 전체 확률은 변경하지 않는다. 이후 명시적으로 저장한 베르칸 가중치는 우선한다. 하이퍼팩과 합성은 기존 공통 선택 함수를 사용한다.
- CMS의 기존 등급·수치·배정·설정을 보존하는 정확한 이전 목록 확장만 허용한다. 신규 용병의 기본 배정은 MS-055이며 이후 CMS 수정/해제는 재배포로 복원하지 않는다.
- 56 모션 + 60 FX = 116 독립 프레임. PixiJS 8.20.0 / GSAP 3.13.0. 기존 전장, 진형, 카드 도크와 효과 계층을 사용한다. 새 renderer/ticker/DB 조회/폴링은 없다.
- 아틀라스 11개, RGBA 총 116 MiB. 텍스처 원본은 캐시를 공유하며 Sprite 풀을 재사용한다. 계정 보유 데이터 전체 재조회나 전투 중 쿼리는 추가하지 않았다. 일반적인 무부하를 주장하지 않는다.
- 신규 음원은 추가하지 않았다. 승인된 기존 소리는 그대로 유지한다.

## 검증과 배포 선택

직전 실제 운영 배포: `c5e53d85-47d7-49a3-8de9-0e2f1a93f69a`, 소스 `49d6d86d7df1331e863a33548538ca3204251871`.

기존 용병 시스템에 승인 캐릭터 하나를 연결하는 한정된 변경이다. 인증·공통 DB/트랜잭션 기반·마이그레이션·의존성·인프라 변경은 없다. `npm run deploy:production -- --scoped`를 사용한다. 원화/SD/116 프레임, CMS 보존과 동시 저장, 확률 경계, SQLite/PostgreSQL 획득·재시도·롤백, 편성 및 PVE/PVP 서버 전투, 전용 재생 취소, 공용 그리드 번들, 실제 메인 로더 검사를 선정한다. 정확한 목록은 배포 로그의 SCOPED RELEASE에 기록한다.

PC 격리 계정으로 실제 메인 토벌 버튼 → 전투 → 성공 결과 → 복귀를 확인했다. 모바일 390×844에서 실제 랭크전 매칭 → 전투 → 승리 결과 → 복귀를 확인했다. 공용 카드 5장 + 별도 베르칸 편성 및 주변 광원을 확인했다. 이 과정에서 기존 일반 카드 이펙트의 GSAP 콜백이 취소된 AnimatedSprite에 접근하는 오류를 발견해 해제 여부를 검사하도록 수정했다. 실제 Pixi/GSAP으로 충돌 프레임, 해제 후 앞뒤 이동, 공유 텍스처 보존을 네 가지 이펙트 모두 검증한다. 운영 계정에 시험 개봉·재화 차감·용병 지급을 하지 않는다.

리소스/프롬프트/해시: `preview/mercenary-berkan-sss-v1/README.md`. PC 및 모바일 화면은 같은 폴더 `qa/`에 보존한다.

사용자 후속 제보의 스킬 종료 후 사각 잔상을 재현했다. Pixi 8.20.0의 WebGL 최적화 다중 블러가 중간 재사용 텍스처를 지우지 않는 경로 때문에 크기가 바뀐 포즈에 이전 버퍼 경계가 남았다. 베르칸의 두 BlurFilter만 중간 버퍼를 지우는 `legacy:true` 재생 경로로 변경했다. 화려한 금빛 윤곽·오라·불티, 원화와 애니메이션은 유지한다. 실제 Pixi 블러의 첫 패스 clear 여부를 회귀검사하며, 스킬 완료 후 화면은 `qa/desktop-after-skill-clean.png`에 보존한다.
