# [업데이트] 무한의탑·폐차장·카우방 개편 안내

**적용 완료: 2026년 10월 8일 01:35 (한국 시간)**

성장에 맞춰 더 높은 난도에 도전하고 더 많은 보상을 얻을 수 있도록 무한의탑, 폐차장, 카우방을 개편했습니다.

## 1. 무한의탑 — 100층 확장 및 보상 상향

- 최고층이 **70층에서 100층으로 확장**됩니다.
- 기존 **1~70층 최초 클리어 코인 보상이 10배**로 증가합니다.
- 적 전투력이 상향되며, 71~100층에 새로운 성장 목표가 추가됩니다.

| 구간 | 최초 클리어 기본 코인 |
| --- | ---: |
| 70층 | **50억** |
| 71~79층 | 각 **10억** |
| 80층 | **100억** |
| 81~89층 | 각 **15억** |
| 90층 | **150억** |
| 91~99층 | 각 **20억** |
| 100층 | **200억** |

기존 진행도와 클리어 기록은 유지됩니다. 이미 클리어한 층의 보상은 다시 지급되지 않으며, 개편 전 보상에 대한 차액 소급 지급은 없습니다. 70층을 완료한 유저는 71층부터 이어서 도전할 수 있습니다.

## 2. 폐차장 — 난도 상향 및 상위·초월 구간 추가

| 난도 | 완주 기본 코인 |
| --- | ---: |
| 외곽 폐차장 | **5,000만** |
| 압축 설비 구역 | **1억** |
| 용광로 심부 | **2억** |
| 용광로 심부 · 상위 | **3억** |
| 용광로 심부 · 초월 | **8억** |

기존 난도의 적 전투력이 상향되고, 상위 장비를 갖춘 유저가 도전할 수 있는 두 구간이 추가됩니다. 전체 난도를 합해 **하루 최대 30회**, 입장 시 **출입 허가증 1장**을 사용합니다. 완주 코인과 별도로 차량 부품은 기존 통합 드랍 정책에 따라 판정됩니다. 상위·초월 구간은 용광로 부품 드랍 설정을 공유합니다.

## 3. 카우방 — 3단계 난도와 보상 확대

| 난도 | 카우 킹 전투력 | 클리어 기본 코인 |
| --- | ---: | ---: |
| 목초지 · 입문 | 260만 | **5억** |
| 붉은 목초지 | 1,300만 | **15억** |
| 심연의 목초지 | 1억 5,600만 | **30억** |

- 난도를 선택해서 입장할 수 있습니다. 일반·정예 적도 선택한 난도에 맞춰 강해집니다.
- 모든 난도의 입장 횟수는 **하루 최대 6회로 공유**됩니다.
- 입장 비용은 **포탈 1개 + 25만 코인**입니다.
- 카우방 일일 클리어 코인 상한은 **180억**입니다.

### 카우방 입장권 리셋 및 드랍률 변경

**이번 개편 적용 시점에 보유 중이던 미사용 카우방 입장권(포탈)은 전체 초기화되었습니다.** 개편 후 전투에서 새로 획득한 포탈로 입장할 수 있습니다.

포탈 드랍률은 일반 토벌·일반 소탕·아포칼립스 수동 토벌 모두 **완료 전투당 0.5%**로 적용됩니다. 소탕은 완료된 전투마다 각각 판정하며, 0.5%는 확률이므로 일정 횟수마다 획득이 보장되는 것은 아닙니다.

이미 입장한 전투의 확정 결과와 보상 기록은 유지됩니다. 결과를 다시 확인하거나 복구할 때 입장권을 추가로 사용하지 않습니다. 개편 당일 이미 사용한 일일 입장 횟수도 유지됩니다.

표의 코인은 기본 클리어 보상입니다. 계급 혜택 등 기존 추가 보상 정책과 콘텐츠별 일일 한도는 함께 적용됩니다. 업데이트 후 새로고침하여 변경된 난도와 보상을 확인해 주세요.
