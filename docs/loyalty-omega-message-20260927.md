## 구현 및 검수 범위

- 기존 메시지에는 용병 보상 유형이 없어서 `MERCENARY_OMEGA_X` 전용 수령 경로를 추가했다. 쿠폰에는 사용할 수 없다.
- 메시지 도착 시에는 용병을 즉시 지급하지 않는다. 보상 받기 또는 일괄 수령 시 기존 용병 취득 함수를 사용해 영구 소유 1장을 지급하며 기존 보유자는 중복 수량이 1 증가한다. 성장·편성은 바꾸지 않는다.
- 계정 소유권, DB 원본 보상 종류·수량, 사용자/보상 행 잠금, 메시지 수령 영수증, 고유 취득 ID를 검증한다. 취득·수령 영수증·메시지 상태는 같은 원자적 batch에서 기록한다. 재시도 및 응답 유실은 중복 지급하지 않는다.
- 발송 스크립트는 승인된 다섯 계정 외 대상을 거부한다. 단일 트랜잭션에서 메시지·첨부 보상·감사·완료 영수증을 기록하고 고유 캠페인으로 중복 발송을 막는다.
- 실제 메시지 마크업/CSS로 데스크톱 1440×900, 모바일 390×844의 보상 표시, 가로 넘침 없음, 44/46px 수령 버튼, 단일 수령 요청을 확인했다. 수령 UI 검사는 격리된 fixture이며 운영 유저 보상을 대신 받지 않았다.

작은 수정: 기존 메시지 보상에 정해진 용병 1종을 연결하며 DB 스키마·권한·공통 트랜잭션 기반은 변경하지 않는다. `npm run deploy:production -- --scoped` 사용.
