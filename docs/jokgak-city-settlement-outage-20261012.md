# 족각도시 정산 조회로 인한 API 장애 — 2026-10-12

## 운영 증거

- 사용자 신고: 족각도시 CMS 서버 응답 오류, 게임 전체 이용 불가.
- CMS 저장 세션 확인 요청이 시간 초과됐다. 정적 HTML은 200이지만 인증 후 게임 API는 Hyperdrive의 `Timed out while waiting for an open slot in the pool` 오류를 냈다.
- PostgreSQL 활동 조회에서 활성 연결 298개가 같은 회차 정산 후보 SELECT를 실행하고 있었다. 확인한 장기 조회는 233초 이상, 잠금 차단 PID는 없었다. 이후에도 같은 조회 296개가 다시 쌓였다.
- 원인: 이용자별 상관 서브쿼리가 도시 행동의 JSON 모드를 반복 조회하고, 회차 경계의 상태/알림 요청마다 최종 거래 이전에 같은 정산 계획을 동시에 계산했다.
- 긴급 조치로 정확히 해당 SELECT 형태와 테이블, 활성 상태, 실행 시간 10초 초과를 모두 만족하는 조회 278개에 `pg_cancel_backend`를 실행했다. DB 연결 종료, 계정 변경, 보상 커서 강제 이동은 하지 않았다. 읽기 조회 취소만으로는 재발해 코드 수정이 필요했다.

## 수정 범위

- 닫힌 회차 기간의 행동을 한 번 집계해 이용자/회차별 참여 여부와 공격 횟수를 구한 뒤 도시 플레이어에 조인한다. PVP 영수증의 `cityMode` 및 구형 `reward.mode`, 일반 ON 영수증을 동일하게 처리한다.
- 정산 계획 작성 전에 DB의 공통 임대 잠금을 획득한다. 실행 중인 정산이 있으면 다른 도시 요청은 짧은 `CITY_ROUND_SETTLING` 응답을 받고 무거운 조회를 시작하지 않는다. 프로세스 중단 시 90초 후 회복할 수 있고 정상 완료/실패 시 자기 토큰만 해제한다.
- 완료된 회차는 작은 커서 조회로 즉시 반환한다. 보상·영수증·TOP 커서·이전 행동 정리는 기존 단일 거래로 유지한다. 참여 공격 횟수, 현금 순위, 동률, 정책 동결, 지급액은 변경하지 않는다.
- 공통 DB 어댑터, 인증, DB 스키마, 인프라 설정은 변경하지 않는다.
