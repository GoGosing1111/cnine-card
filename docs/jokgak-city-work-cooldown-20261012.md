# 족각도시 재근무 대기시간 표시 — 2026-10-12

요청: 근무 목록의 ‘재근무 대기’에서 남은 재사용 대기시간을 확인할 수 있도록 표시한다.

- 버튼 아래에 `58초`, `1분 05초`처럼 실제 남은 시간을 표시한다. 서버가 내려준 `career.nextWorkAt`과 기존 서버 시각 보정을 사용하며 매초 갱신한다.
- 대기가 끝나면 새로고침 없이 현재 위치의 ‘근무 시작’, 다른 위치의 ‘장소 찾기’로 갱신한다. 기존 진행 중 근무·취직·기능 중지·사망·구금 등 이용 제한은 기존 패널 계산을 그대로 따른다.
- 창을 닫았다 열어도 서버의 종료 시각을 유지한다. 근무 설명의 설정 시간도 분·초로 표기하여 분 미만 또는 분수 단위 설정이 긴 소수로 노출되지 않게 한다.
- 카운트다운은 비활성 버튼에서도 읽을 수 있도록 두 줄로 표시한다. 실제 대기시간, 급여, CMS 설정, 서버 지급/차감 로직은 변경하지 않는다.

## 검수 및 배포 범위

Chrome 1440×1000 / 390×844에서 실제 도시 API 처리기를 연결한 격리 계정으로 병동 근무 → 급여 수령 → 65초 대기 → 59/58초 갱신 → 창 재개방 → 1초/0초 경계 → 재근무 시작을 확인했다. 다른 장소 버튼의 자동 복구와 근무 중 중복 시작 차단도 확인했으며 JS 오류·가로 넘침은 없었다. 초기 QA 서버의 Windows 경로 구분자 불일치를 수정한 뒤 최종 화면과 동작을 검수했다.

화면 증거는 `docs/qa/jokgak-city-work-cooldown-20261012/`에 보존한다. 국소 UI 변경이므로 별도 새 테스트를 늘리지 않고 기존 직업/일거리 회귀와 연결된 UI/캐시 검사만 선택한다. 현상수배 UI 연결 검사 1개는 이미 통과했다. 서버 파일은 변경하지 않았다.
