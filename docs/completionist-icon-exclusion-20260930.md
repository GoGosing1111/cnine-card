# 폐인 칭호 ICON 제외 — 2026-09-30

사용자 지시: 폐인 칭호의 카드 도감 100% 조건에 ICON 등급을 반영하지 않는다.

- `readCollectionMastery`의 카드 집계에서 `rarity='ICON'`을 제외한다. 전체 수와 보유 수에 같은 필터를 적용하므로 미보유·신규 ICON이 달성률을 낮추거나 보유 ICON이 빠진 일반 카드를 대신 채우지 않는다.
- ICON 이외의 활성·공개 카드 100%와 활성·공개 차량 90% 조건, 기존 칭호 보유·중복 지급 방지는 유지한다. ICON만 있는 빈 대상 도감은 달성으로 인정하지 않는다.
- 카드 도감 공개 목록, ICON 합성 잠금, 다른 칭호·CMS·계정 데이터는 변경하지 않는다. 스키마·의존성·공통 인증 변경은 없다.
