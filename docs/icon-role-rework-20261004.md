# ICON 역할 개편 · 2026-10-04

## 적용 범위

사용자 요청: ICON 고유효과를 RPG 역할로 전면 개편하고, 전투·CMS·UI·연출·운영 반영 및 유저 공지까지 완료한다.

디임 암살 / 하이희야 공격 / 나무늘봉순 마법 / 오조은 지원 / 오리꿍 저주 / 강구열 방어 / 아윤 돌격.
단일 설정은 shared/icon-roles-v1.mjs, 운영 저장 키는 icon_role_settings_v1이다. 미등록 상태의 출시 기본값을 읽으며 런타임 조회로 DB를 생성하거나 기존 icon_cms_v1 초안을 덮어쓰지 않는다.

- 일반 카드 5장 편성 계약 유지. 기존 ICON 7종의 원화·프레임·SD 원본과 표시 크기를 변경하지 않는다.
- ICON은 기존 스탯 고유효과·고유진화와 중복 적용하지 않는다. 서버에서 정규화한 기본 전투력에 역할을 부여한다.
- PVE/PVP/족장전 공통 덱 판정에 적용. 모든 판정은 서버의 전투 스냅샷이며 연출 속도로 발동 횟수가 달라지지 않는다.
- 전투당 스킬 6회, 피해 상한, 회복·보호 총량, 중첩·지속·행동 게이지 상한. 반격·추가타로 새 행동을 재귀 생성하지 않는다.
- 보스의 행동 지연은 피해 약화로 대체한다. 봉인·저주·정화·부활·전투 연장과 연동한다.
- 기존 16프레임 hit/skill 자산에 역할 문양, 표식, 방벽, 시전, 총구 좌표를 연결한다. 신규 SD 원화나 몸체 모션을 제작한 것으로 기록하지 않는다.
- 승인 SD를 직접 참조한 하이희야 총구/총몸 축을 전체 스프라이트 변환에 적용한다. 좌우 진영 반전도 같은 좌표로 처리한다.
- 카드 상세/합성 화면/CMS의 역할 설명은 공통 계약을 사용한다. CMS OWNER 권한, 버전 충돌, 요청 재시도, 감사 기록을 포함한다.
- 설정은 새 전투에 적용하며 기존 저장 전투 결과는 다시 계산하지 않는다.
- 합성 enabled=false 잠금, 5,000억 코인·마스터의 별 500만 개·SS/FUR +13 재료·성공률 10%는 변경하지 않는다.

## 검증 및 배포

규모: 공통 전투 판정 + 서버 CMS + 공통 V3 소비자 + 실제 카드 UI의 큰 개편.
배포: npm run deploy:production. 직접 Wrangler Pages 호출 및 scoped 검사 생략을 사용하지 않는다.

관련 단위/서버 검증: tests/icon-roles-v1.test.mjs (고정 7종, 잘못된 설정, 피해·보호·회복 상한, 봉인·정화, PVE/PVP, 비 ICON 호환, PostgreSQL CAS/동시성·재시도).

시각 검증: tests/icon-roles-v1.browser.mjs — PC 1440 / 모바일 390, CMS 저장·재조회, 메인 합성·상세, 7종 × PVE/PVP 전투 재생과 복귀.
마지막 연속 피해 숫자 정리와 지원·돌격 수치 보정 뒤에는 tests/icon-roles-main-entry.browser.mjs로 실제 메인 로더, 공통 번들, PVE/PVP 래퍼, 결과 화면, 원래 화면 복귀를 확인했다.
공통 번들 10개는 build:v3, ICON UI는 build-icon-fusion.mjs로 빌드한다.

preview/icon-roles-v1/balance-report.json: 동일 전투력 중립 카드와 비교한 1,120회 진영 교대 실험. 실제 랭크전의 승률 예측이 아니다. 지원은 조합·생존 구간 의존, 돌격은 초반 우위로 해석하며 실운영 세부 수치는 CMS에서 조정할 수 있다.

브라우저 증적: preview/icon-roles-v1/qa. 프리뷰 전투는 서버 시뮬레이터에서 생성한 고정 기록이며 계정·재화·전적을 변경하지 않는다.
운영 반영 결과는 별도 live-verification.json에 기록한다.

전체 게이트의 오래된 정적 기준은 실제 소스와 최신 승인 기록에 맞춰 최소 정정했다. V3 소스 목록 76개 및 ICON/기존 리미티드 배너 호출, ICON의 이전 스탯 고유진화 제외, 기존 승인 리미티드 8종에 따른 도감 63종 및 20261004 캐시 접두어다. 도감 런타임·자산·승인 상태는 바꾸지 않았다. 통과한 단계의 원본 로그와 SHA-256을 보존하고 저장소의 엄격한 전체 게이트 이어 실행을 사용한다. 실패 단계는 모두 다시 실행하며 부분 배포나 검사 생략으로 전환하지 않는다.

## 복구

역할 정책 이상은 OWNER CMS에서 전체/모드/개별 역할 OFF로 새 전투 적용을 중단할 수 있다. 기존 승인 자산과 legacy 초안은 보존한다.
런타임 문제는 이 개편 직전의 운영 커밋으로 정상 배포 절차를 거쳐 되돌린다. DB 마이그레이션·획득 지급·재화 변경은 없다.
