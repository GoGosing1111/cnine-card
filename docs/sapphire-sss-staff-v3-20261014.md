# 이름 미정 SSS 지팡이 가독성 수정 — 2026-10-14

사용자 “근데 왜 지팡이 빠져있음?”에 따라 전투 검수판의 무기 파지·가독성을 수정했다. V2는 승인 지팡이를 합성했지만 파지가 낮아 크리스털 머리와 긴 자루가 날개·다리와 겹쳤으며 손과 어긋난 자세도 있었다. 파일 존재와 해시 확인을 통과한 것이 시각 완성을 의미하지 않았음을 기록한다.

## 수정 범위

- built-in image_gen으로 대기·시전·궁극기의 파지 팔을 바깥쪽 가슴 높이로 보정했다. 몸 전용 원본 3장과 프롬프트는 해당 프리뷰 `assets/sources/*-staff-v3.png`, `prompts-staff-v3.json`에 보존한다.
- 승인 원화와 분리한 지팡이 PNG는 동일 바이트를 유지한다. `pack-v3.mjs`는 396px / 몸 360px의 고정 비율로 무기 전체를 합성한다. 이동·회전·균일 배율만 사용하고 재생성·비균일 변형을 하지 않는다.
- 지팡이 광원은 몸 뒤에 놓아 장식을 덮지 않는다. 대기 몸·발 고정, 독립 오라, 대쉬 제거, 6연사·강화 궁극기는 유지한다. 모든 수정은 독립 검수 프리뷰에 한정한다.
- 기존 V1/V2 몸 시트·프레임·영상은 보존한다. `manifest-v2.json`으로 이전 구성을 복원할 수 있다. 운영 로스터·스킬 성능·획득·편성·이름을 추가 확정하지 않았다.

## 관련 검수

- `qa/v3/staff-contact-sheet.png`: 활성 자세 11개 전체의 지팡이 머리·파지·자루를 직접 확인했다. 합성 결과의 투명 여백과 잘림은 빌더에서 확인한다.
- `qa/v3/report.json`: PC 1440×1080 / 모바일 390×844 PASS, 콘솔/HTTP 오류 0. 각각 7초 동안 몸 상태 1개·오라 상태 40개로 대기 고정 확인. 활성 무기 크기는 모든 시각에서 동일하다.
- 각 모드 지면 오차·효과 경계 이탈 0, 12개 적중 접점 오차 0. 효과 OFF에서도 몸·손·지팡이를 확인했고 배속·정지·탐색·중단·이탈 정리를 통과했다.
- 실제 1배속 영상을 `qa/v3/*-showcase.webm`에 기록하고 다시 디코딩 재생했다. 대기·포격·최종 폭쇄 캡처와 재생 시각은 `video-inspection.json`에 남긴다.
- 배포에서 `qa.test.mjs`의 기존 4개 관련 회귀와 무기 크기·파지/머리 위치 회귀 1개를 실행한다. 이미 통과한 동일 번들의 브라우저 검수를 반복하지 않는다. 사용자 최종 시각 승인은 대기다.
