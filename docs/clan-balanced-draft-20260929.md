## 자동 배분

- 기존에는 140명을 정원 22명으로 나눈 올림값인 7개 클랜만 생성해 DC가 제외됐다. 이제 신청 마감 시 최대 8개 공식 클랜을 모두 사용한다. 8명 미만은 신청자 수만큼 열고, 2명 미만은 기존처럼 시작을 대기한다.
- 클랜장을 포함해 인원 차이를 최대 1명으로 배분한다. 140명은 18명 4개·17명 4개, 176명은 22명 8개다. 추가 자리의 시작 클랜은 시즌 ID에 따라 순환한다.
- 정원은 기존 `clan_redraft_v20260916:<seasonId>` 계약을 재사용하고 `BALANCED_EIGHT_CLANS_V1`으로 식별한다. 마스터 편성·정원·DRAFT 전환을 같은 배치로 저장한다. 기존 재드래프트·시즌 중 수동 증원 기록은 그대로 유지한다.
- 수동 지명, 30초 패스, 마감 자동 편성, 활성화 검사 및 신규 균등 시즌의 편입 한도에서 동일 정원을 사용한다. 기존 UI의 클랜별 정원 표시가 이 계약을 이미 사용하므로 UI·자산은 변경하지 않는다.
- 전체 1시간, 미지명 시 30초 패스, 블라인드/스네이크, 기존 마스터 평가식과 정규전 화·목·토·일 21:00–22:00은 유지한다.
