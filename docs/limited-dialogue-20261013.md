## 연결과 표시 규칙

- 발테르의 `종결 집행`, 헬리오스의 `천양붕락` 시전마다 전용 3종을 차례로 순환한다. 진무의 기존 5종과 표시 조건은 보존한다.
- 진무와 같은 PVE·협동 격전지에서 표시하고 PVP·실제 레이드는 생성/공간 예약을 하지 않는다. 내부 RAID 렌더러를 공유하는 협동 격전지는 기존 판별 조건으로 허용한다.
- 혼합 3개 부대에서는 엔진당 대사창 하나를 공유한다. 시전자의 얼굴·프레임·문구를 바꾸되 각 캐릭터의 순번을 따로 보존한다. 다른 캐릭터의 이전 연출 종료가 현재 대사를 해제하지 않는다.
- 등록된 모든 문구의 높이를 미리 측정해 모바일에서 문구/화자 전환 시 전장 높이가 바뀌지 않게 했다. 마지막 캐릭터 해제 시 대사창·관찰자·전장 여백을 정리한다.
- 얼굴은 불투명하게 표시하고 화면 전체 흐림, 백색 플래시, 전체 원화 덮개는 추가하지 않는다. 기존 전투 속도·명중 시점·서버 피해 적용·성능·획득/편성 정책은 바꾸지 않는다.
- 공용 소스를 사용하는 전투 소비자 10개를 공식 빌드로 갱신했다. 런타임 태그는 `limited-dialogue-20261013-v1`, 셸 캐시는 `20261013-limited-dialogue1`이다.
