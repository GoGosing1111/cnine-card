# 발테르·헬리오스 문구 컷신 — 2026-10-13

사용자 요청: “발테르랑 헬리오스 문구 컷신도 3개정도씩 해서 만들자 이쁘게 꾸며서”, “진무꺼 참고해서 만들어라”.

## 구성과 문구

진무의 작은 얼굴 초상·장식 프레임·이름/스킬·SSS 표식을 기준으로 두 캐릭터의 전용 문구를 각각 3종 추가했다. 발테르는 붉은색과 은색, 검 문장과 붉은 보석을 사용한다. 헬리오스는 금빛과 백금색, 태양 문장과 별 장식을 사용한다. 승인된 원화에서 CSS로 얼굴 부분만 표시하며 원본 이미지는 수정하지 않았다.

| 캐릭터 | 순서 | 문구 |
| --- | --- | --- |
| 발테르 | 1 | 무릎 꿇어라. 판결은 이미 내려졌다. |
| 발테르 | 2 | 내 검이 닿는 곳, 저항은 끝난다. |
| 발테르 | 3 | 붉은 맹세 아래, 마지막 적까지 집행한다. |
| 헬리오스 | 1 | 눈을 떠라. 너희의 마지막 태양이다. |
| 헬리오스 | 2 | 어둠의 끝에서, 나의 검이 떠오른다. |
| 헬리오스 | 3 | 천 개의 태양이여, 이 전장에 강림하라. |

## 연결과 표시 규칙

- 발테르의 `종결 집행`, 헬리오스의 `천양붕락` 시전마다 전용 3종을 차례로 순환한다. 진무의 기존 5종과 표시 조건은 보존한다.
- 진무와 같은 PVE·협동 격전지에서 표시하고 PVP·실제 레이드는 생성/공간 예약을 하지 않는다. 내부 RAID 렌더러를 공유하는 협동 격전지는 기존 판별 조건으로 허용한다.
- 혼합 3개 부대에서는 엔진당 대사창 하나를 공유한다. 시전자의 얼굴·프레임·문구를 바꾸되 각 캐릭터의 순번을 따로 보존한다. 다른 캐릭터의 이전 연출 종료가 현재 대사를 해제하지 않는다.
- 등록된 모든 문구의 높이를 미리 측정해 모바일에서 문구/화자 전환 시 전장 높이가 바뀌지 않게 했다. 마지막 캐릭터 해제 시 대사창·관찰자·전장 여백을 정리한다.
- 얼굴은 불투명하게 표시하고 화면 전체 흐림, 백색 플래시, 전체 원화 덮개는 추가하지 않는다. 기존 전투 속도·명중 시점·서버 피해 적용·성능·획득/편성 정책은 바꾸지 않는다.
- 공용 소스를 사용하는 전투 소비자 10개를 공식 빌드로 갱신했다. 런타임 태그는 `limited-dialogue-20261013-v1`, 셸 캐시는 `20261013-limited-dialogue1`이다.

## 배포 범위

문구·장식과 기존 전투 재생 연결에 한정된 변경이다. 서버 거래·인증·공통 DB·의존성 변경이 없어 `npm run deploy:production -- --scoped`를 사용한다. 위 14개 관련 회귀와 기존 출시/캐시/Hyperdrive 가드를 적용하며 전체 게임 검사를 추가하지 않는다. 배포 직전 실제 Pages 운영 커밋을 조회해 기준으로 사용하고, 최신 원격 변경도 보존한다. 운영 적용 결과는 완료 후 아래에 기록한다.
