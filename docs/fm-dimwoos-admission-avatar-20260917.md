# FM 딤우스 · 진짜디임 편입 및 11일 지급

## 승인 범위

2026-09-17 사용자 요청: “FM클랜에 진짜디임 편입시키고 해당 아바타 조은 T1하고 동급으로 맞추고 FM클랜에 11일짜리 배포”.

- 승인 장비창 V1 원본과 새 로비 V3 원본을 유지한다.
- FM 딤우스: A-21 / `FM_DIMWOOS`.
- 운영 `T1_JOEUN`과 동일한 코인 획득량 +75%, 레이드 입장 +10회.
- 사용·공개 ON, 판매 OFF, 이벤트 지급.
- 현재 시즌 5, FM 클랜 7에 미소속 진짜디임 계정 4773을 편입한다.
- FM의 현재 21명을 유지하면서 진짜디임을 추가하기 위해 해당 시즌 FM의 명시적 정원을 21→22로 조정한다.
- 진짜디임을 포함한 실제 지급 시점의 검증된 FM 22명에게 정확히 11일의 보유권을 지급한다.

## 원본 및 운영 자산

`preview/avatar-fm-dimwoos-v1/build-assets.mjs`는 승인된 원본 해시를 확인한 뒤 비율을 유지하는 크기 조정·투명 여백·WebP 압축만 수행한다. 원본을 재생성하거나 알파를 다시 추출하지 않는다.

- 로비: 1024×1536, 640×960 WebP.
- 장비창: 기존 공용 장비창 계약의 640×1088 RGBA WebP.
- 원본/운영 파일 해시: `runtime-manifest.json`.
- 공용 `SoopketmonCharacterLoadoutV2`로 PC 1440px·모바일 390px에서 장비창 표시, 탭 전환, 이미지 로딩 및 가로 넘침을 확인했다. 밝은 배경에서도 투명 가장자리를 확인했다.

## 운영 트랜잭션

`scripts/ops/avatar-fm-dimwoos-release.mjs`는 일반 API에 연결하지 않는 명시적 일회성 작업이다.

- 작업 키: `avatar_fm_dimwoos_clan_grant_20260917_v1`.
- 정원 기록 키: `ops:fm-dimwoos-admission-avatar:20260917:v1`.
- 계정 닉네임·활성 상태·PLAYDK 인증·5장 랭크 덱·미소속·전투/예약 부재를 확인한다.
- 현재 시즌·FM 전체 명단·정원 기록·T1 조은 실제 효과·신규 코드/시리얼 충돌을 잠금 아래 재검증한다.
- FM 활성 정원 22, 진짜디임 편입, 드래프트 소속, 신규 아바타·효과, 22명 기간제 보유권, 감사 로그 3건과 완료 영수증을 하나의 트랜잭션으로 반영한다.
- 원래 균등 드래프트 정원과 참여자 수, 다른 클랜 정원, 시즌 공통 정원, 기존 회원 기록, 지갑, 장착 상태를 보존한다.
- 같은 완료 영수증의 재실행은 만료 연장이나 중복 지급 없이 원래 결과를 반환한다.
- 미리 실행한 검토는 전체 롤백한다. 운영 지급은 이미지 배포 확인 후에만 호출한다.
- 만료한 보유권의 장착과 효과는 기존 아바타 API가 차단한다.

## 검증

`tests/avatar-fm-dimwoos-clan-11days.test.mjs`에서 22명 지급·정원·소속·11일 만료, 기존 계정/타 클랜 보존, 중복 실행, API 장착/효과/만료, 지급 실패 전체 롤백, T1 효과 변경·명단 변경·시리얼 충돌·편입 자격 및 정원 변경 거부를 검증한다. 이 검사는 `test:avatar`와 `release:gate`에 포함한다.

운영 후보는 깨끗한 커밋에서 `npm run deploy:production`을 실행한다. 이 명령이 선행하는 `npm run release:gate`를 통과해야 업로드된다. 운영 지급 명단과 실제 지급/만료 시각은 DB 영수증 및 비공개 로컬 운영 기록에 저장한다.
