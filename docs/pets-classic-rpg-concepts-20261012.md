# 레트로 RPG 펫 3종 시안 — 2026-10-12

사용자 요청은 첨부 3장의 느낌을 참고한 펫 리소스 제작이다. 흰 정령, 금방울 불독, 붉은 날개 마신을 각각 배경 없는 정지 전신 시안으로 제작했다. 이름은 시안 구분용 가칭이며 사용자 최종 시각 승인·정식 명명·동작 제작·펫 등록은 별도다.

## 리소스

- 미리보기: `preview/pets-classic-rpg-20261012-v1/index.html`
- 원본: 같은 폴더의 `assets/pet-white-spirit-v1.png`, `assets/pet-bell-bulldog-v1.png`, `assets/pet-crimson-wing-demon-v1.png`
- 생성 방식: 기본 제공 `image_gen.imagegen`, 각 첨부에서 캐릭터를 참고한 독립 생성 1회씩. CLI 미사용.
- 전체 프롬프트와 첨부 식별자: 같은 폴더의 `generation.json`
- 규격·용량·SHA-256·알파 정보: 같은 폴더의 `manifest.json`

3장 모두 1254×1254 RGBA PNG다. 생성 원본을 바이트 단위로 그대로 복사했고 원본과 해시가 일치한다. 캐릭터 외부에 투명 영역이 있으며 얼굴·귀·발·날개가 잘리지 않는다. 캔버스 외곽의 일부 생성 잔여 픽셀은 알파 1/255이고 육안으로 보이는 캐릭터 실루엣은 외곽에 닿지 않는다. 원본에 알파 가공이나 재압축은 하지 않았다.

흰 정령은 졸린 눈과 흰색/연보라 귀, 불독은 갈색/흰색의 낮고 묵직한 체형과 금방울을 살렸다. 마신은 회색 피부·긴 검은 머리·붉은 날개와 천을 전신으로 재구성하고 자연스러운 성인 비율을 유지했다. 머릿결은 연속되는 부드러운 흐름으로 확인했다.

## 관련 확인

- 생성 이미지 전신과 투명 경계를 직접 확인했다.
- 독립 미리보기 PC 1440px, 모바일 390px에서 원본 3장·축소 보기 3장의 정상 로딩, 가로 넘침 없음, 저장 링크 3개 및 페이지 오류 없음을 확인했다.
- 두 화면의 실제 스크린샷을 확인했다. 128px 높이 영역의 축소 비교도 함께 제공한다.
- 자산 및 독립 미리보기만 추가한다. 게임 실행 코드·펫 카탈로그·설정·기존 승인 리소스를 변경하지 않는다.
- 자산 전용 배포 명령은 `npm run deploy:production -- --assets-only`다. 직전 운영 배포 커밋 `786b47a`(Pages `271add53`)에서 게임 실행 파일 변경은 없으며, 전체 게임 테스트를 실행하지 않는다.
