# 전투 바닥 문양과 펫 크기 — 2026-10-17

사용자는 제안 이미지의 원형 룬을 모든 전투의 아군·상대 진영에 적용하고 전투 펫을 20% 축소하도록 요청했다. 황금 발판 대상은 후속 답변 **“ICON 용병 SSS급이상”**으로 확정했으며 일반 SSS와 SSS 리미티드 용병은 서로 다른 문양을 사용한다.

## 표시 기준

| 대상 | 문양 |
| --- | --- |
| 일반 아군 | 은색·청색 룬 |
| 일반 상대 | 어두운 청동·적색 룬 |
| ICON 카드 | 황금 태양 문양 |
| SSS 이상 일반 용병 | 황금 검·매듭 문양 |
| SSS 이상 리미티드 용병 | 백금·황금 왕관/깃 장식 문양 |

황금 문양 바깥에는 각 진영의 청색·적색 이미지 링이 남는다. SS 리미티드와 FUR·ZENITH·SUPERSTAR는 일반 진영 문양을 사용한다. 서버의 등급·편성·전투력·보상·출시 상태를 수정하지 않는다.

## 리소스와 구현

- ImageGen으로 만든 전용 투명 PNG 5종을 `assets/ui/project-v/battle-ground-runes-v1/originals/`에 바이트 그대로 보존했다. 승인된 구상 이미지, 생성 프롬프트, SHA-256, 512px WebP 변환 설정은 같은 폴더의 `manifest.json`에 기록했다. 생성 원본과 결과의 가운데·바깥 알파를 확인했다.
- `BattleGroundStyle.mjs`는 실제 카드·용병 스냅샷으로 문양을 선택한다. 디펜스의 기존 `kind/rank` 형식도 지원하며, edition이 없는 이전 디펜스 스냅샷의 리미티드는 정확한 공식 카탈로그 코드로만 구분한다.
- `BattleGroundSigil.js`의 공유 이미지 텍스처를 Pixi Sprite로 표시한다. 공통 전투의 네모 타일·빈 격자·이중 발밑 테두리를 제거했다. 기본 그림자는 남기며 몬스터 디펜스에서는 문양을 덮지 않도록 접촉 그림자 크기를 조정한다.
- 편성 위치는 유지한다. 공격 중 이동과 무관하게 발판이 제자리에 있고, 사망·부활·같은 슬롯의 다른 등급 교체 때 갱신한다. 반복 레이아웃은 공유 텍스처를 파괴하지 않는다. 몬스터 디펜스의 이동형 캐릭터에는 같은 이미지 문양이 따라간다.
- 펫은 PC·모바일의 최소 표시 크기와 주변 캐릭터 간격 보정을 모두 계산한 뒤 `× 0.8`로 표시한다. 아군·상대·협동 소유자별 펫에 동일하게 적용하며 이름·버프 수치 크기는 유지한다.
- 공통 V3 소비자 10종과 몬스터 디펜스/로그라이크 번들을 재빌드했다. 로비 로더·런타임 버전·캐시 쿼리를 함께 갱신했다.
