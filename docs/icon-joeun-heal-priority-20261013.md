# ICON 조은 회복 우선순위 — 2026-10-13

사용자 요청: `아이콘 조은 힐 기준을 피 낮은 카드,용병부터 채우게 패치해`. 후속 확인: `남은 체력 비율(%)이 낮은 순`.

## 확인과 반영

- 직전 운영 API Worker도 HP/최대 HP 오름차순으로 회복 대상을 선택하고 있었다. 카드만 대상으로 삼거나 HP 절대 수치로 비교하는 운영 오류는 확인되지 않았다.
- 요청한 기준을 `selectIconSupportTarget`으로 분리해 고정했다. 매 회복 시 살아 있는 아군 카드·용병·시전자 전체에서 체력 비율이 가장 낮은 부상자 1명을 고른다. 이전 대상은 캐시하지 않는다.
- 부상자가 없는 경우에만 기존 만피 아군 정화를 선택한다. 사망자·비대상 유닛·배틀슈트는 제외한다. 비율 동률은 기존 슬롯·ID 순서다.
- 후보 전체 정렬 대신 한 번 순회해 선택한다. DB 조회·저장이나 난수 호출을 추가하지 않는다. 회복량·공명·회복 총량·재사용·최대 발동·정화·연장전 차단·CMS 설정은 유지한다.
- 서버 회복 사건에 `healPriority: LOWEST_HP_PERCENT`, `targetHpBefore`, `targetMaxHpBefore`를 기록해 실제 선정 기준과 회복 직전 비율을 확인할 수 있게 했다. 기존 대상 ID·회복량·회복 후 HP 전달 형식은 유지한다.

## 검수

- 신규 회귀 7개 통과: 절대 HP와 비율의 순서가 다른 카드/용병 혼합 편성, 시전자 포함, 제외 대상, 부상자 우선/만피 정화, 동률·원본 편성 순서 보존, PVE/PVP 반복 회복 재선정·재사용·총량·연장전, 실제 공통 전투 엔진의 용병 회복 및 결정적 재생.
- 예: 카드 500/1,000(50%)와 용병 2,000/10,000(20%)이면 용병 우선. 다음 회복 전 카드 비율이 더 낮아지면 카드로 대상을 바꾼다.
- 같은 실행 코드의 신규 7개 검사는 배포에서 반복하지 않는다. 배포 과정에서는 기존 `icon-roles-v1.test.mjs`, `icon-apocalypse-actions-20261006.test.mjs`, 실제 번들/메인 로더 연결 `pve-battlefield-entry-v2117.test.mjs`, `check:worker`를 실행한다.
- 서버 선정·사건 메타데이터만 수정하며 UI·전투 연출·클라이언트 번들은 변경하지 않는다. PVE/PVP 핵심 경로는 실제 공통 엔진 회귀로 검증한다.
