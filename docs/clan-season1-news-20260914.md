# 클랜전 시즌 1 뉴스 특집 · 2026-09-14

사용자 요청에 따라 시즌 결산을 실제 스포츠 신문 형태의 6면과 전용 삽화 4장으로 제작했다. 게시 경로는 `/news/clan-season-1-20260914/`다. 독립 읽기 전용 특집이며 게임 메뉴·전투·재화·수상 기록을 바꾸지 않는다.

운영 DB를 읽기 전용 반복 가능 스냅샷으로 조회했다. 시즌 1은 정규시즌과 챔스 모두 완료이고 FM이 두 우승을 차지했다. 정규시즌은 FM·삼성 승점 18 동률에서 누적점수 7,913 대 7,874로 순위가 갈렸다. 챔스 결승 FM–롯데는 1,970 대 1,915로 종료됐다. 완료 전투 34,104회, 정규 28경기·챔스 2경기와 개인 공수 기록을 교차 검증했다.

신문은 종합, 챔스 결승 리포트, 정규 순위·동률 분석, 개인 TOP 10·MVP, 8개 클랜 결산, 데이터 분석의 6면이다. 정규시즌 최다승 음순이 320승과 결승 최다승 Moo날두 70승을 각각 조명했다. MVP·다크호스는 편집부 선정으로 명시했다. 경기 수·규칙이 다른 정규시즌과 챔스를 분리했다.

내장 image_gen으로 2관왕 트로피, FM–롯데 결승, 8색 깃발, T1 선수 분석 삽화를 생성했다. 공식 문장·트로피 참고 원본은 수정하지 않았다. 한글과 통계는 HTML/CSS/SVG로 조판한 뒤 1800×3270 PNG 6장으로 출력했다. 원본 4장과 지면 6장, 출처·프롬프트를 ZIP으로 제공한다. 개별·전체 다운로드와 모바일 읽기를 지원한다.

검수 증거는 배포 루트 밖 `../qa/clan-news-20260914/`에 보존한다. 공개 데이터에서 내부 계정 ID·인증·재화·운영 로그를 제외했다. 출처·집계법·프롬프트·해시는 특집의 `sources.md`, `facts.json`, `prompts.json`, `manifest.json`에 기록했다. Black Han Sans와 IBM Plex Mono는 기존 OFL 자산을 재사용하며 시스템 글꼴 파일을 배포하지 않는다.
