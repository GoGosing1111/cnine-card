# 리미티드 용병 도감 선공개 — 2026-10-02

사용자 요청에 따라 용병 도감 `전체 도감` 옆에 `리미티드` 탭을 추가하고 승인된 리미티드를 조회 전용으로 공개한다. 획득·습득·편성·실전 전투는 활성화하지 않는다.

- 도감 코드는 일반 용병 CMS 및 팩·합성·보상 획득 카탈로그에 포함하지 않는다. 공통 획득 허용 함수도 이 여섯 코드를 항상 차단한다. 원화·프레임·SD의 원본 해시를 유지하고 원화와 프레임을 별도 계층으로 표시한다. 발테르는 사용자 지정 슬림 V3 광원 프레임, 나머지는 승인 V2 프레임을 사용한다.
- 봉순·조은의 예상 SS를 확정 등급으로 승계하지 않는다. SSS 이네스의 원화와 SSS 발테르의 준비된 전투 리소스를 모두 공개하며 미준비 SD·능력치·스킬은 만들어 넣지 않는다.
- OWNER CMS에 `리미티드 확률`을 추가한다. 기존 `app_meta`의 `mercenary_limited_draw_policy_v1`에 SS·SSS 확률 및 카드별 가중치 초안을 별도로 저장하며, 일반 하이퍼팩/용병 합성 정책은 그대로 유지한다. 확률 초기값은 **미정**, `acquisitionEnabled=false`이고 실효 획득 확률은 항상 0%다. CMS 저장으로 ON을 요청하면 서버가 거부한다.
- 신규 테이블·DB 마이그레이션·공통 인증·거래 기반 변경은 없다. 기존 원자 배치로 설정·감사·재시도 영수증을 함께 저장하고 버전 충돌·동일 요청 중복을 보호한다.
- 발테르 제작 후보는 원래 `valter-release-ready` 작업 트리에 보존한다. 이번 공개 범위 파일 205개를 해시 확인해 가져왔으며 승인 모션 27프레임·효과 96프레임은 그대로다. 기존 프리뷰 번들의 엔진 버전이 운영 로더와 달라 초기화가 실패했으므로 현재 `20261002-arke-v2` 공용 엔진 기준으로 **프리뷰 번들만 재빌드**했다. 공용 V3 엔진·실전 전투 코드는 변경하지 않았다.
- 관련 서버·도감 검사 8개 통과. PC 1440×1000·모바일 390×844에서 리미티드 6종 탭/재조회, 등급·잠금, SD·원화, 기존 전체·보유 목록, SSS 전투 프리뷰 초기화·타격, CMS 독립 저장·잠금 및 잘림을 확인했다. 브라우저 검수는 35항목 통과, JS 오류·자산 오류 0건이며 후속 CMS 저장 바 겹침을 수정했다.
- 신규 원화/모션 생성이나 재작화는 없으며 승인 원본·무기·머릿결·얼굴·비율을 수정하지 않았다.
