# S-BODY 제작 결제 오류 수정 — 2026-09-30

## 원인과 변경

- 운영 제작 CMS의 `배틀슈트 05 제작`(S-BODY, recipe 521)은 `COIN_OR_MASTER_STAR`이며 코인 100,000,000,000 또는 마스터의 별 1,000,000 중 하나를 선택한다. 성공 확률은 10%이고 슈트 코어 5를 10개 사용한다. 이 값은 읽기 전용으로 확인했으며 수정하지 않았다.
- 기존 배틀슈트 화면은 모든 레시피의 코인과 별을 동시에 표시·검사하고 `paymentType: BOTH`를 보내, 서버가 S-BODY 요청에 `코인 또는 마스터의 별 결제 방식을 선택하세요.`를 반환했다.
- 제작 화면과 요청값이 CMS의 결제 모드를 따르도록 변경했다. 선택 결제 레시피는 선택한 재화만 비용·부족 여부·확인창·요청에 반영한다. `BOTH` 레시피는 기존 두 재화 결제를 유지한다. 처리 중 재시도는 같은 요청번호와 처음 선택한 결제 방식을 유지한다.
- 제작소 JS/CSS와 진입 로더의 캐시 키를 `sBodyPayment=20260930`으로 갱신했다. 서버 지급·차감·확률·레시피는 변경하지 않았다.
