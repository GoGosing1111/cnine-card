# SS·SSS 용병 획득 영상

사용자가 전달한 SS / SSS 영상을 실제 하이퍼팩의 서버 확정 영수증에 연결한다. 확률·비용·보상·등급·편성·전투 코드는 변경하지 않는다. 중복 용병도 확정된 등급의 영상을 재생하며, 저장된 영수증 복구는 기존처럼 재결제 없이 결과만 표시한다.

## 자산

| 등급 | 원본 | 배포본 | 보존 규격 |
|---|---:|---:|---|
| SS | 5,507,719 B | 3,137,541 B | 1280×720 · 24fps · 192프레임 · 8초 |
| SSS | 7,771,216 B | 4,462,564 B | 1280×720 · 24fps · 240프레임 · 약 10초 |

합계 42.77% 절감. 원본 파일은 변경하지 않았다. H.264 High 3.1 / yuv420p / MP4 fast-start로 인코딩하고 원본 AAC 48kHz 스테레오는 재인코딩 없이 복사했다. 모든 프레임과 오디오를 끝까지 디코딩해 오류가 없음을 확인했다. 원본 대비 SSIM은 SS 0.989767, SSS 0.986607이다. 손실 압축이므로 무손실이라고 표현하지 않는다.

경로: `assets/ui/project-v/mercenary-acquisition/`. 출처 파일명, 원본·결과 SHA-256, 크기, 프레임 수는 `manifest-v1.json`에 기록한다.

재생성 명령(FFmpeg 7.1):

```text
ffmpeg -i INPUT -map 0:v:0 -map 0:a:0? -map_metadata -1 -c:v libx264 -preset slow -crf 23 -profile:v high -level:v 3.1 -pix_fmt yuv420p -tag:v avc1 -c:a copy -movflags +faststart OUTPUT
```

## 연결·복구

- `mercenary-pack-live.mjs` → 기존 `hyper-pack-fx-v2076` → `MercenaryAcquisitionVideo` 순서로만 사용한다. SS·SSS가 없는 영수증은 영상 요청을 하지 않는다. 별도 렌더러·라이브러리를 추가하지 않았다.
- 해당 영수증에 필요한 등급만 병렬로 준비하고 등급당 한 파일만 받는다. 최대 2개, 합계 7.6MB의 압축 Blob을 보관한다. 전체 바이트 수를 검증한 뒤 Blob URL로 재생하므로 재생 중 네트워크 스트리밍에 의존하지 않는다.
- 16:9 / `object-fit:contain` / `playsinline`으로 원본 전체를 표시한다. 영상 중에는 Pixi ticker를 멈추고 종료 후 공용 Pixi/GSAP 카드 공개를 이어간다. 영상 완료는 `ended` 이벤트로 판정한다.
- 최초 무음 재생, 사용자 `소리 켜기`로 원음을 재생한다. 브라우저 자동 재생 차단 시 `계속 재생`으로 시작할 수 있다.
- 수동 일시정지·백그라운드 대기는 재생 기한에서 제외한다. 다운로드는 20초, 실제 재생 진전 없음은 15초로 제한한다. 불완전·404·HTML 대체 응답·디코딩 실패 때는 기존 카드 연출로 복귀한다.
- `결과 바로 보기`·닫기·페이지 이탈 시 요청 중단, 비디오 정지, Blob URL 해제, 이벤트·타이머 정리를 수행한다. 영상 오류가 결제나 지급 API를 재실행하지 않는다.
- SS·SSS가 포함되면 영상/카드 공개가 끝나기 전 결과 목록을 숨겨 중복 표시·스포일러를 방지한다. 오류·건너뛰기 시 확정 결과 목록과 연속 개봉은 계속 접근 가능하다.
- 메인 HTML·상점 동적 import·CSS·FX 참조 캐시를 2145로 갱신한다. 전투 버전과 V3 그리드 번들은 변경하지 않는다. FX 번들은 `npm run build:hyper-pack`으로 재생성한다.

## 검증

- `test:hyper-pack`에 새 회귀 12개를 포함했다. 등급 분리, 게으른 다운로드/중복 제거, 전체 수신, 종료 이벤트, 자동재생 차단, 긴 정지, 손상/오류/지연, 취소, 사운드, 기한, MP4 구조·해시·규격·프레임 수를 검사한다.
- 기존 개봉 UI 회귀 9개 유지: 중복 결제 방지, 저장 영수증 복구, 1회/10회 전환, 연속 개봉, 계정 캐시와 불일치 검증.
- 실제 게임 상점 버튼에서 PC 1440px / 모바일 390px로 검수했다. 로컬 API만 모의 응답하여 운영 재화는 사용하지 않는다. SS·SSS 완주, 정지/이어 재생, 소리, 연속 개봉, 10회 혼합, 손상 파일, 다운로드 중 건너뛰기, 재생 중 닫기와 화면 잘림을 검사한다.
- QA 로그·스크린샷: 작업 머신 `C:/Users/User/AppData/Local/Temp/cnine-acquisition-video-20260922/`. 배포 후 같은 검증을 운영 정적 자산 + 로컬 모의 API로 재실행한다.
- 배포는 전체 `release:gate`를 포함하는 `npm run deploy:production`만 사용한다. 자산 전용 단축 배포나 DB 변경을 사용하지 않는다.
