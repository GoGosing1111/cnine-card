사용자 지시: “일일퀘스트 1000억으로 올리고 주간퀘스트 1조로 올려 이번주 주간퀘스트 소급적용해 일일퀘스트는 오늘기준”.

- 주간 POST: 2,500억 → 1조 코인. 2026-10-12~18 KST 주간부터 적용한다. 목표 300개 유지.
- 다른 주간 퀘스트, 사용 상태, 게시판과 계정 인증 조건은 보존한다.
- 기존 수령자는 일일 900억, 주간 7,500억 차액을 보상 메시지로 받는다. 이미 발급됐지만 아직 수령하지 않은 주간 보상도 포함한다. 원래 보상과 원래 영수증은 그대로 보존한다.

## 구현 및 운영 순서

일일 서버·CMS 상한을 1,000억으로 올렸다. 일일 수령의 설정 검증·수령 기록·잔액·코인 로그를 같은 트랜잭션으로 처리하여, 인상 전 설정을 읽은 요청이 인상 후 낮은 금액을 지급하지 못하게 한다. 기존 주간 수령은 동일한 설정 검증 보호를 이미 제공한다.

운영 스크립트 `scripts/ops/dk-quest-reward-increase-20261017.mjs`의 설정 단계는 두 설정 행을 잠그고 이전 수령이 완료된 뒤 오늘/이번 주의 차액 대상 목록을 확정한다. 설정과 대상 목록·감사 기록을 함께 저장한 뒤 잠금을 해제한다. 별도 지급 단계에서 메시지·첨부 보상·완료 영수증·감사 기록을 함께 저장한다. 사용자 행과 설정 행의 잠금 순서 역전을 피한다.

운영 키: `ops:dk-quest-reward-increase:20261017:v1`. 캠페인별 사용자당 1개 메시지만 허용한다. 지급 실패는 전체 지급 단계를 되돌리며, 재실행과 응답 유실은 완료 영수증을 재사용한다. 직접 잔액 조정 없이 기존 원자적 메시지 보상 수령 API로 지급된다. 실제 운영 설정 저장 전에 관련 코드 배포가 필요하다.
