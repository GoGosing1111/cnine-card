## 운영 반영 순서

1. 깨끗한 커밋을 origin/main에 반영하고 `npm run deploy:production`으로 전체 출시 게이트 및 배포를 실행한다.
2. 신규 코드 배포 확인 후 `app_meta.loot_shop_policy_v1`의 `fur_choice.accountLimit`만 3→10으로 변경하고 revision을 증가시킨다. 구형 서버는 10을 거부하므로 설정을 먼저 바꾸지 않는다.
3. 직렬화 거래, 기존 원문 비교, OWNER 감사 기록, 일회성 영수증 `ops:loot-fur-limit-10:20260922:v1`으로 보호한다. 구매·팩·재화 테이블은 변경하지 않는다.
4. 운영 정책, 배포 JS/CMS, 실제 이미지 응답을 다시 확인한다. 롤백은 구매 이력을 보존한 채 CMS 한도를 먼저 3으로 돌린 후 구형 코드를 배포한다.
