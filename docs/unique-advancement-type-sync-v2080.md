# 고유효과 변경 시 완료 전직 계열 자동 동기화

2026-09-10 사용자 요청: 하이희야 ZENITH를 공격형에서 방어형으로 변경했으므로 기존 완료 전직도 자동으로 따라가야 한다.

## 적용 계약

- 완료 전직의 존재와 소유권은 `card_unique_advancements_v1937`의 기존 행으로 확인한다. 전직하지 않은 카드에는 자동으로 전직을 부여하지 않는다.
- 현재 활성 `card_unique_effects`의 가장 높은 양수 스탯으로 실제 전직 계열을 해석한다. 신규 전직과 같은 판정 함수를 사용하며 동률 우선순위는 ATTACK → DEFENSE → SPEED → HP다.
- 카드 상세 상태, 실제 전투 준비, 완료 요청의 재시도 응답 모두 같은 해석을 사용한다. 공격/방어/속도/HP 계열을 다시 바꾸면 다음 조회·전투 준비부터 자동으로 따라간다.
- 고유효과가 삭제·비활성화되거나 모든 스탯이 0 이하인 경우 기존 완료 계열을 유지한다.
- 기존 완료 행과 당시 영수증은 감사 원본으로 보존한다. 강화, 보유 수량, 전직 시각, 비용과 재료 잔액을 변경하지 않으며 추가 재전직이나 재료 소모가 없다.
- 완료 영수증 재시도는 당시 성공 여부·비용·잔액을 유지하고 현재 전직 계열만 응답에 반영한다. 기능 OFF 상태에서 허용하던 완료 요청 재조회에도 같은 규칙을 적용한다.
- 이미 생성된 전투 결과·진행 스냅샷을 소급 변경하지 않는다. 서버 수정이므로 클라이언트 자산·캐시·다른 콘텐츠의 공개 설정은 변경하지 않는다.
