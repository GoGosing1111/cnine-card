# 영입전 사은품 — 2026-09-29

사용자 요청: `영입전 사은품 (2000억, 300만 마별, 리페어권 1개, 미스틱에너지 1000개) 리소스 만들고 해당 내용물 추가해`.

`RECRUITMENT_GIFT_BOX`(영입전 사은품) 1개를 개봉하면 다음 네 보상을 모두 확정 지급한다.

| 내용물 | 상자 1개당 수량 |
|---|---:|
| 코인 | 200,000,000,000 (2,000억) |
| 마스터의 별 `MASTER_STAR` | 3,000,000 |
| 핑두 리페어 쿠폰 `PINGDU_REPAIR_COUPON` | 1 |
| 미스틱 에너지 `STARLIGHT_ARMOR_CORE` | 1,000 |

## 등록 및 사용

- CMS → 유저관리 → 대상 계정 관리 → 인벤토리 아이템 지급 → **영입전 사은품**. 기존 권한과 대상 보호를 유지하며 수량은 1~9,999개다. 확인창에서 대상·상자 수량·네 보상을 확인한다.
- CMS의 인증자 보상 메시지에도 영입전 사은품을 선택할 수 있다. 현재 작업에는 수신자 지정이나 실제 계정 지급·메시지 발송이 없다.
- 인벤토리 → 팩·상자 → 영입전 사은품 → **1개 개봉 · 보상 받기**. 남청색·금색 전용 화면에 네 보상과 완료 결과를 표시한다.
- 기존 펀딩·대회 사은품의 구성은 변경하지 않는다. 리페어권의 복구 비용·기능 정책도 기존 그대로다.

## 자산 및 거래

- 전용 이미지 `assets/ui/packs/recruitment-gift-box-v1.png`: 내장 imagegen으로 생성한 원본을 그대로 복사했다. 코인·별·리페어권 한 장·미스틱 에너지 코어를 담은 남청색 선물 상자다. 글자와 수량은 게임에서 조판한다.
- 도구·최종 프롬프트·생성 원본·SHA-256은 `docs/recruitment-gift-art-20260929.json`에 보존한다.
- 독립 카탈로그 마커 `recruitment_gift_catalog_20260929_v1`을 사용한다. 초기화는 아이템을 등록하며 운영자의 이름·이미지·OFF 편집을 덮어쓰거나 상자를 자동 지급하지 않는다.
- 기존 계정 변경 잠금과 공동 거래 영수증을 재사용한다. 상자 차감, 별·리페어권·에너지 증가, 코인 증가, 각 원장과 완료 영수증은 한 DB batch로 확정한다. 중간 실패는 전체 롤백하며 재시도는 기존 결과를 반환한다.
- 지급·개봉 요청은 계정·종류·입력에 결합한다. 인벤토리 수량과 큰 정수의 상한, 아이템 활성 여부를 검사한다. 브라우저는 응답 유실 때 같은 요청 번호로 복구하며 프로필 재조회 실패로 보상을 재요청하지 않는다.
- 신규 공통 인증·DB 구조·의존성 변경은 없다.
