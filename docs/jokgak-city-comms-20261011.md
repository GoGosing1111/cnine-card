# 족각도시 알림·교대·확성기 — 2026-10-11

사용자 요청: 팝업 전체 스킵, 도시에서 팝업 안 보기 체크, 별도 로그함, 6시간 교대마다 전원 퇴장 후 직접 재입장, 시장 확성기 구매 후 지도 메시지 연출. 가격은 **도시 현금 500원**으로 확정했다. 후속 지시는 **교대가 끝난 팝업 소멸 및 DB 로그 누적 금지**다.

## 동작

- 피격·행동 팝업과 로그함의 전체 스킵은 마지막 확인 시각까지의 모든 미확인 알림을 읽음 처리한다. 페이지에 보이는 10개만 처리하지 않으며 이후에 새로 도착한 알림은 보존한다.
- 팝업 안 보기 설정은 계정별 서버 저장이다. 피격 알림과 도시 밖 사망 안내를 숨기며 새로고침·다른 기기에도 적용된다. 숨기거나 스킵한 알림은 이번 교대 로그함에서 확인한다.
- 로그함에는 본인의 행동 및 받은 알림을 최신순으로 표시한다. 같은 시각의 기록도 고유 ID로 페이지를 넘겨 중복·누락을 방지한다. 다른 사람의 지갑·인벤토리와 전투 전체 스냅샷은 로그 응답에 포함하지 않는다.
- KST 00·06·12·18시 경계에 도시 전원 퇴장. 서버의 현재 epoch 조건으로 명단·행동을 즉시 제한하고 열린 도시 화면도 입장 대기로 전환한다. 사용자가 입장 버튼을 다시 눌러야 한다. 강제 퇴장에 추가 퇴장 쿨다운은 없다. 기존 사망 대기와 교대별 재산/직업 초기화는 유지한다.
- 지난 교대의 `jokgak_city_notifications_v1` 및 `jokgak_city_actions_v1` 행을 실제 삭제한다. API와 기존 매분 스케줄러 양쪽에서 처리하여 접속자가 없어도 정리한다. 보이는 팝업·지도 방송·활동 로그는 교대 만료 즉시 제거하며, 예약 정리 주기는 최대 약 1분이다. 다른 콘텐츠와 별도 경제 감사 원장은 유지한다.
- 현재 회차의 확정 영수증은 기존 재시도에 재사용한다. 교대가 지난 요청은 epoch 검증에서 거부하므로 만료된 영수증을 장기 보관할 필요가 없다. 정리 마커는 과거 교대 요청으로 되돌아가지 않는다. 매분 재정리는 교대 직전 진행 중이던 작업이 늦게 남긴 기록도 제거한다.
- 시장에서 500원에 확성기 1개를 구매한다. 메시지 전송에 1개를 사용하고 보낸 사람·문구를 지도 위 방송 배너로 공개한다. 최근 방송을 계정 간 전달하고 중복 표시를 막는다. 100자, 사용 간격 15초, 최대 99개, 화면 표시 10초는 구현 기본값이다. 확성기 소지품과 방송 기록은 교대에 소멸한다.
- 확성기 구매/사용은 기존 플레이어·생활 상태·영수증 거래에 포함한다. 실패 시 함께 롤백하고 성공 응답 유실 후 같은 요청 재시도에도 중복 차감하지 않는다. TEST/ON 소지품과 방송은 분리한다. 메시지는 서버 길이/문자 검증 및 출력 이스케이프를 적용한다.
