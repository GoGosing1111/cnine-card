# 디펜스 게임 대기실 V4 — 2026-10-17

사용자가 설정 패널 형태의 V3 초안을 반려하고 게임 대기실을 요청했다. V3는 운영에 배포하지 않았으며 이 V4가 현재 구현이다. 새 구성을 사용자의 최종 시각 승인으로 기록하지 않는다.

## 화면

- 내장 ImageGen으로 수호석·세 갈래 성벽 길목·넓은 집결 단상이 있는 새 성채 배경을 제작했다. 배경을 어둡게 덮어 없애지 않고 캐릭터와 함께 화면의 주 요소로 사용한다.
- 준비 화면은 원화 카드 박스 대신 실제 전투 SD 3기를 크게 세운다. 캐릭터 아래 선택판, 왼쪽 상단 난이도, 하단 대장/인원/초대/연습/대기실 생성 조작부를 배치한다. 보스와 규칙은 버튼으로 여는 정보창이며 동시에 하나만 열린다.
- 대기실은 2~3개 분대의 전신 캐릭터와 방장/내 분대/준비 상태가 같은 집결지에 나타난다. 빈 분대 자리·초대 코드·공동 목표·준비 인원과 출전 가능 여부를 실제 방 상태로 표시한다.
- 모바일은 내 분대를 먼저 보여주고 분대 버튼 또는 가로 이동으로 다른 분대를 본다. 보고 있는 분대 버튼의 선택 상태도 함께 갱신한다. 하단 준비/출전 버튼을 고정하고 320×720에서는 장면 높이를 줄여 세 캐릭터의 이름까지 가리지 않는다. 가로 화면은 전체 스크롤한다.
- SUIT와 디펜스 전용 기계식 버튼을 사용한다. 다른 콘텐츠 버튼·밀어서 잠금 해제는 추가하지 않는다. 동작 줄이기에서는 캐릭터 호흡 효과와 분대 전환 애니메이션을 멈춘다.
