## 함께 수정한 재생 문제

모바일 재료 선택·합성 버튼이 화면 아래에 있어, 성공 영상이 화면 위의 합성 무대에서 재생되자 공통 `IntersectionObserver`가 화면 밖 영상으로 판단해 즉시 정지했다. 최초 `play()`가 `AbortError`로 거절되면 기존 처리가 바로 결과 화면으로 넘어갔다. 첨부 영상을 실제 합성 결과에 연결한 로컬 검수에서 재현했다.

합성 결과 연출 시작 시 무대를 화면 중앙으로 스크롤한다. 동작 줄이기 설정에서는 즉시 이동한다. 공통 런타임의 화면 밖 일시정지 표시가 있는 `AbortError`만 영상 실패로 처리하지 않고, 기존 화면 복귀 재생을 허용한다. 영상 오류·종료·건너뛰기·안전 제한 시간의 정리는 유지한다. 공통 성능 관찰자나 다른 콘텐츠는 바꾸지 않았다.

메인 로더의 ICON 번들 캐시 키는 `20261006-success-video-v1`이다. 성공 영수증에만 영상이 연결되며, 선택한 ICON 획득 결과는 영상 종료 후 표시한다.
