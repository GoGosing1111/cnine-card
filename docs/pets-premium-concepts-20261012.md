## 원본과 생성 이력

- 경로: `preview/pets-premium-20261012-v1/assets/`
- 6장 모두 1254×1254 RGBA PNG, 배경 투명, 정지 전신 시안이다. 최종 생성 원본을 무가공 복사했다.
- 기본 제공 `image_gen.imagegen`으로 각 1회 생성했다. CLI/API 우회는 사용하지 않았다.
- 흑금 영룡만 최초 뿔 끝과 꼬리의 여백을 보완하는 편집 1회를 추가했다. 최종 V2의 전체 뿔과 꼬리를 확인했다. 최초 생성 경로와 편집 프롬프트를 함께 기록했다.
- 전체 프롬프트는 `generation.json`, 파일 규격·SHA-256·알파 정보는 `manifest.json`이다. 이름·등급·버프·계정 보유권·라이브 카탈로그를 확정하는 작업이 아니다.
- `pets-premium-six-v1.zip`에 PNG 6장과 위 JSON 2개를 묶었다. ZIP 내부 PNG 6개의 해시가 각각 원본과 일치한다.

## 최소 관련 확인

- 6장 모두 실제 알파 채널과 투명 영역을 확인했다. 알파 8 초과의 캐릭터 경계는 캔버스 외곽에 닿지 않으며 원본과 복사본이 일치한다. 일부 생성 잔여 외곽 픽셀의 최대 알파는 1/255다.
- 독립 미리보기 PC 1440px·모바일 390px에서 이미지 12개(원본 6개·축소 비교 6개) 정상 로딩, 가로 넘침 없음, 페이지 오류 없음, 개별 저장 링크 6개를 확인했다. 실제 PC 전체 화면과 모바일 첫 화면을 직접 확인했다.
- PC 브라우저의 일괄 다운로드 버튼을 눌러 내려받은 ZIP이 로컬 원본과 일치했다. ZIP SHA-256: `dc9981f5b5775417e8cb19bded982c1de171895ab13a2abb1e214adc0a736092`.
- 새 미리보기에서 기존 3종으로 돌아가는 링크를 확인하고 기존 미리보기 하단에 신규 6종 진입 링크를 추가했다. 기존 PNG를 변경하지 않았다.
- 자산·독립 미리보기·기록만 변경하므로 `npm run deploy:production -- --assets-only`를 사용한다. 직전 운영 배포는 `0bb0ffcca3e9da5af2d1ed8a9de44f6edb023de5` / Pages `3798ccaa`다. 전체 게임 테스트와 변경 없는 워커 재배포는 하지 않는다.
