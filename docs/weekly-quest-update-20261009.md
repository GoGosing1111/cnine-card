# 주간퀘스트 표시·DK 목표 변경 — 2026-10-09

- 사용자 요청에 따라 주간 PLAY DK 게시글 작성 목표를 200개에서 **300개**로 변경한다. 상태 API, 게임 진행도, CMS 목표 표시, 서버 수령 조건과 새 보상 메시지가 같은 정의를 사용한다.
- 주간 코인 보상을 `100억`, `1.2조`처럼 만·억·조 단위로 표시한다. 소수는 최대 두 자리까지 내림하고 정확한 수량은 툴팁에 제공한다. 1만 미만과 아이템 수량은 기존 숫자 표기를 유지한다.
- 일일 15개, 다른 주간 목표, 실제 지급액·CMS 지급 설정과 기존 수령 영수증은 유지한다. 300개 변경을 이유로 수령 내역을 초기화하거나 보상을 재지급하지 않는다.
