# 할로윈 용병 성장 목록 누락 수정 · 2026-10-17

사용자 요청: **할로윈 용병 레벨 올릴 수 없나 확인해 가능하게 하고**.

원인은 성장 API와 경험치 분류가 기존 `LIMITED_MERCENARIES`만 사용하여 할로윈 SS 7종(V-980~V-986)을 제외한 것이다. 보유·편성은 이미 전체 목록을 사용하므로 카드가 있어도 성장 화면에는 나오지 않았다.

- 두 경로를 `ALL_LIMITED_MERCENARIES`로 연결했다. 보유한 할로윈 7종은 기존 성장실에서 선택·경험치 전수·돌파가 가능하다.
- 기존 리미티드 성장 정책을 그대로 따른다. 최대 Lv.20, Lv.5/10/15/20 돌파, 일반 대비 필요 경험치 5배다. 현재 운영 정책 revision 1은 ON이며 Lv.1 필요 경험치 3,750, Lv.20 18,000이다.
- 같은 SS 등급 중복 용병 카드를 사용한다. 다른 용병은 100 EXP, 동일 용병은 300 EXP이며 각 용병의 기본 1장은 보호한다. 코인·마스터의 별 추가 비용은 없다. 기존 돌파 10%·실패 시 현재 경험치 초기화·이전 성장 유지 규칙을 변경하지 않는다.
- 족게이다(4111)의 V-980 보유 1장을 읽기 전용으로 확인했다. 검수로 운영 카드를 소비하거나 레벨을 올리지 않았다. 성장 CMS·할로윈 발행 수량·확률·재고·원화·기본 전투 성능도 변경하지 않는다.
- 성장 모듈과 화면 버전을 갱신하고 공유 성장 모듈을 서비스워커의 최신 계정 스크립트 대상으로 추가했다.
