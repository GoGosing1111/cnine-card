# 군단토벌 중간 정지·Z-BODY 광역기·진입 UI 수정

## 재현과 수정

- 연속 전투의 `sequential` 재생은 효과 시작을 첫 충돌까지 미룬다. Z-BODY 고유 광역기는 생성과 동시에 슈트 몸을 예약하므로, 예고 중 일반 공격이 큐에 들어오고 첫 광역 타격이 치명타가 되면 일반 공격은 몸의 해제를, 광역 타격은 일반 공격 큐 소진을 기다리는 순환 대기가 생겼다.
- 실제 `BattleSuitSkillChipPlayback`과 `ZBodyThunderFX`를 사용한 재현 검사에서 기존 코드의 몸 잠금이 해제되지 않음을 확인했다. 고유 스킬만 시전 즉시 기존 GSAP 시계로 시작하게 수정했다. 로켓·헬기의 연속 전투 발사 지연, 서버 피해 순서·대상·15초 주기와 헬기폭격 동등 피해 정책은 유지한다.
- 일시정지와 탭 이탈은 중앙의 재개 화면으로 표시한다. 시작/재생 실패는 진행 상태를 끝내고 예약 연출을 취소하며 다시 출전/입장 복귀를 표시한다. 오류를 승리·보상으로 처리하지 않는다.
- Z-BODY 광역기 안내 및 서버의 실제 타격이 확인된 시전 횟수를 표시한다.

## 진입 화면

- 섬 전경 위에 최종 수호자를 크게 배치하고, 4구간의 몬스터·중간 보스·최종 보스를 시각적인 경로로 표시한다.
- 실제 카드 5장과 별도 용병을 원화로 구성하며, 난이도 위협 표시·제한 시간·직접 획득 안내·입장 버튼을 우측 패널에 배치한다. 모바일은 세로 구성과 하단 고정 입장 버튼을 사용한다.
- 승인된 포스터는 원본 그대로 콘텐츠 소개 확대 보기에 사용한다. 새 이미지 생성이나 승인 원본 변경 없음.
- 제목 폰트는 저장소의 Black Han Sans를 재사용한다. 라이선스: `assets/fonts/clan-camp/BlackHanSans-OFL.txt` (SIL OFL 1.1).
- OWNER 한정, 일반 공개 OFF, 실계정 보상 OFF와 실제 저장 덱/용병 계약을 유지한다.

## 검증 범위

- 개발 중 신규 2개 회귀 통과: 순환 대기/해제·정확히 한 번의 피해·효과 정리, 스킬칩 없는 저장 Z-BODY의 12마리 전장 광역 판정.
- 기존 스킬칩 런타임·Z-BODY 실제 프레임/GSAP 검사 30개 통과. 일반 로켓 발사 지연·헬기 타격, 정지/취소, 구세대 대상 보호, PVP의 스킬칩 시계 제외를 포함한다.
- PC 1440×960 진입/4난이도·카드/용병·전투 완료 확인. 모바일 390×844의 화면 구성·편성 스크롤·일시정지 중앙 화면·재개 확인. 모바일 어려움 전투에서 실제 뇌검 집행 2회 타격 후 37/37 및 보스 3/3, 36초 클리어와 콘솔 오류 0건을 확인했다.
- 로컬 시작 API 503 주입 시 오류 중앙 화면과 다시 출전/입장 복귀 버튼이 나타나며, 입장 화면 복귀 후 저장 편성과 입장 버튼이 정상 복원됨을 확인했다. 최종 모바일 배치와 기존 승인 포스터 열기/닫기도 확인했다.
- 실제 라이브 PixiJS 8.20.0·GSAP 3.13.0과 승인 Z-BODY 아틀라스를 재사용한다. 수정 파일: `preview/project-v-v3/source/battle/BattleSuitSkillChipPlayback.js`. 효과의 프레임·피벗·사운드·데미지 계산 변경 없음.

## 범위 배포

- 직전 실제 운영 배포는 Wrangler 목록의 Pages `97bda19f-0338-4e77-9322-1a0a0ae18bd0`, 소스 `6debe12eae001f2f471bdbea3040deeb9dcd9bb3`이다.
- 이번 범위는 고유 스킬의 연속 재생 대기 버그와 군단토벌 진입 UI다. 공통 DB/인증/경제/스키마/의존성 변경 없음. 이미 배포된 다른 작업을 보존하도록 origin/main을 통합했다.
- 공용 재생 원본의 소비 번들을 기존 `build-v3-grid-consumers.mjs`로 다시 만들고 군단토벌 번들도 갱신했다. 런타임·메인 앱·전용 페이지 캐시 키를 함께 갱신한다.
- `npm run deploy:production -- --scoped`를 사용한다. 최종 선택 검사: 군단토벌 계정 입장, 지속 전투, 실제 공용 번들/메인 PVE·PVP 로더, Z-BODY 운영 자산/연결. 이미 통과한 동일 스킬 재생 검사 32개를 배포 전에 별도로 반복하지 않는다.
- 선택 파일: `tests/legion-hunt-entry-account-20260926.test.mjs`, `tests/sustained-hunt-v2.test.mjs`, `tests/pve-battlefield-entry-v2117.test.mjs`, `tests/z-body-release-v3.test.mjs`. 서버/DB 변경이 없어 추가 CHECKS는 빈 목록이며, 배포 도구의 필수 캐시·출시 플래그·Hyperdrive 확인을 유지한다.
