# 운영 PVE 화면 복구와 하이퍼팩 개봉 준비

사용자 지시: 카우방은 기존 게임 안에 맞는 운영 UI로 연결한다. 폐차장은 원래 쓰던 화면으로 복구한다. 포탈은 PVE·아포칼립스에서만 나오며 PVP·영토전·랭크전에는 표시하지 않는다. 하이퍼팩은 CMS에서 ON을 누르면 실제 개봉이 시작되도록 준비하되 현재 OFF를 유지한다.

## 운영 동선

- 카우방: `/?screen=battle&pve=cow-room`. 기존 계정·재화 헤더와 PVE 메뉴 안에서 포탈 수, 25만 코인 입장비, 오늘 입장/보상, 저장된 PVE 편성을 확인한다. 입장 후 공용 V3 전체 전투 모달과 서버 확정 결과를 표시한다.
- 폐차장: `/?screen=scrapyard`. 원래 `scrapyardView`, `bindScrapyardView`, `scrapyard/run`, 전투·결과·재시도 흐름을 사용한다. 독립 원정 화면으로 보내던 두 가로채기를 제거했다.
- 과거 `/pve-v3/?content=cow-room|scrapyard` 링크도 기존 게임의 해당 콘텐츠로 돌려보낸다. 운영 메뉴와 CMS 연결 주소를 함께 갱신했다.
- 카우방 연출은 공용 `ProjectVBattleV3Live`, PixiJS·GSAP, 아트 어댑터, FormationLayout/ViewportLayout, 하단 카드 도크를 사용한다. 승인된 연속 몬스터 확장을 같은 Pixi 엔진 팩토리에 연결했다. iframe·정지 편성 데모를 운영 입구로 쓰지 않는다. 기본 PVE/PVP와 연속 전투를 전환할 때 엔진 종류를 확인해 이전 인스턴스를 정리한다.
- 카우방 5억 클리어·30억 일일 상한·6회 입장, 폐차장 기존 경제, 탑 기존 70층/최초 보상 정책은 변경하지 않는다.

## 포탈 범위

서버 호출에 `battleMode: PVE|APOCALYPSE`를 명시하고 토벌/HUNT와 소탕/SWEEP만 허용한다. 일반 2%·아포칼립스 3%, 아포칼립스 소탕 금지를 유지한다. 프런트도 명시된 결과 모드와 포탈 출처를 검사하며 PVP/SIEGE 화면에서는 차단한다. 로그인 시 보관 포탈을 자동으로 표시하던 코드를 제거했다. 보관 포탈은 카우방 메뉴에서 사용할 수 있다.

## 하이퍼팩 CMS

`admin/mercenaries/opening` GET/PATCH를 카드팩 관리와 용병 개봉 확률 화면에서 사용한다. `app_meta.hyper_pack_opening_v2093`가 없으면 OFF다. OWNER만 현재 revision과 요청 ID를 보내 ON/OFF를 저장할 수 있다. 감사 로그와 상태 변경은 같은 거래이며 중복 요청, 다른 창 변경, 외부 Origin을 검증한다.

ON 전 확률 합계, 등급별 후보, 활성 지급 재료, 계정 지급 테이블, 1회 5억·최대 10회 비용을 확인한다. 기존 CMS 등급·확률·지급 수량을 바꾸지 않는다. 같은 등급은 보유 여부와 무관하게 균등하며 중복 카드는 수량으로 집계한다. 스위치와 지급을 같은 거래의 잠금·조건으로 검사하므로 OFF 변경과 차감이 경합해도 무단 지급/차감을 하지 않는다.

상점의 1회·10회 개봉, 카드 원화/연출, 지급 영수증, 컬렉션이 실제 API로 연결된다. 열려 있던 상점도 포커스 복귀·설정 변경·상태 갱신으로 ON을 반영한다. OFF 후에도 이미 완료된 영수증을 조회할 수 있으며, 새로고침은 미확인 영수증을 지우지 않는다. 용병 전투 편성·업그레이드와 장비 강화의 개방 상태를 변경하지 않는다.

## 검증

- SQLite와 PostgreSQL: 포탈 2%/3% 경계·제외 모드·재추첨 방지·입장 원자성·결과 복구·6회 상한, OWNER CMS 권한·revision·감사 롤백·개봉 차감·별칭 재시도·OFF 경합·영수증 보존을 검증한다.
- 실제 메인 index/shell과 로컬 계정 API에서 PC 1440/970px 및 모바일 390/320px 입장 화면, 공용 Pixi 전투, 하단 카드 5장, 결과·새로고침 복구를 확인한다. 운영 계정에 시험 전투/개봉을 실행하지 않는다.
- 로컬 검수 결과는 릴리스 작업 디렉터리의 `qa/native-2093/`에 보존한다. 운영 배포는 범위 커밋 후 `npm run deploy:production`의 전체 release gate를 통과해야 한다.

## 배포·복구

이번 배포는 UI·API 코드 갱신이며 운영 확률·재화·보상 데이터 변경은 없다. Cow/Scrapyard/Tower는 현재 ON, Hyper 개봉은 OFF다. 장애 시 CMS 개봉 OFF로 신규 차감을 즉시 중지할 수 있고 완료 영수증은 유지한다. 롤백 코드는 직전 main `775682cbfd3d290897ca30106bc4d771ac04e78a`이며, 이를 재배포하면 폐차장·카우방 독립 화면 문제가 돌아오므로 화면 수정 유지 여부를 먼저 확인한다.
