# 용병 PVE·PVP 별도 편성 · 2026-10-09

사용자 요청: “용병 PVE,PVP 별도로 편성 가능하게 추가해, 중복으로도 가능하게 하고”.

용병도감에 PVE·PVP 편성 선택과 두 모드의 현재 용병을 함께 표시한다. 보유한 용병 한 장으로 양쪽에 동일 용병을 편성할 수 있다. 저장·해제·수정 버전은 각각 독립적이며 일반 카드 5장과 용병 1장 구성은 유지한다. PVE/PVP 덱의 용병 표시·전투력·도감 진입 링크도 해당 모드를 사용한다. 리미티드 덱 슬롯은 해당 원화를 표시한다.

기존 `user_mercenary_loadout_v1` 편성은 PVE로 유지하고, PVP는 기존 계정별 설정 패턴에 따라 `app_meta`의 `mercenary_pvp_loadout_v1:<userId>`에 저장한다. 별도 PVP 기록이 없는 기존 계정은 기존 편성을 양쪽에 적용한다. 첫 변경 때 이전 PVP 선택을 같은 거래 안에서 확정하여 한쪽 변경이 다른 쪽에 전파되지 않는다. DB 스키마·공통 거래 기반 변경이나 일괄 데이터 수정은 없다.

기존 계정 잠금, 원자적 소유권/수정 버전 검사, 요청 영수증을 유지한다. 모드를 생략한 이전 클라이언트와 기존 미완료 요청은 PVE로 처리한다. 클라이언트는 요청의 모드를 보관하므로 화면 모드가 바뀌어도 유실 응답을 원래 모드로 복구한다. 듀오전 캐시에는 새 편성 버전을 반영하고 PVP 저장 시 기존 편성 행을 갱신하여 계정 전력 캐시가 즉시 무효화된다.

PVE 사냥·폐기장·탑·군단·호위·공성은 PVE 선택, 일반 PVP·클랜전·영토전·쿠데타·듀오는 PVP 선택을 읽는다. 진행 중인 전투/원정의 확정 스냅샷은 해당 전투의 기존 유지 정책을 따른다. 원화·성장·밸런스·획득 및 미출시 용병 잠금은 변경하지 않는다.

## 검증

- SQLite·PostgreSQL: 다른 용병/동일 용병 편성, 독립 해제·수정 버전, 기존 공통 편성 승계, 소유권/잘못된 모드 차단, 메타데이터 저장 실패의 전체 롤백과 영수증 재시도, 단일/일괄 전투 스냅샷을 확인했다.
- PVE/PVP 실제 전투 생성기에서 선택한 용병과 일반 카드 5장 + 용병 1장 구조를 검증한다. 듀오전은 PVP 변경의 캐시 무효화 및 PVE 변경 시 PVP 유지 회귀를 확인했다.
- PC 1440×1000·모바일 390×844: 모드 전환, 별도 저장, 같은 용병 재사용, 독립 해제, 새로고침, 다른 모드 화면에서 유실 응답 복구, 덱별 전투력·링크·원화, 가로 넘침 및 JS 오류를 확인했다. 증빙: `preview/mercenary-loadout-modes-20261009/`.
- 기존 계정 편성/리미티드 편성 회귀 통과. 최종 scoped 배포는 `mercenary-loadout-modes`, `mercenary-public-deployment-v2097`, `mercenary-codex-owned-roster-v2133`, `ranked-duo-batch` 테스트와 Worker 문법 검사를 선택한다.
