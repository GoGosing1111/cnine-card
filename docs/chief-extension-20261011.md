# 진짜디임 장군 임기 연장 및 특별 담화

사용자 요청: 진짜디임의 장군(족장) 임기에 7일을 추가하고, 전용 일러스트와 독재정권 연장 특별 담화를 접속 유저에게 한 번 표시한다.

- CMS 실조회: 제10대 진짜디임, 기존 종료 2026-10-13 00:09:51 KST. 연장 목표는 기존 종료 + 604800000ms, 2026-10-20 00:09:51 KST다. 실제 저장은 원래 타임스탬프의 밀리초도 보존한다.
- OWNER CMS의 전용 1회 실행으로 현재 진짜디임 ID 4773의 임기만 수정한다. 현재 임명 ID·시작일·대수·즉위식 버전·권한 사용량은 유지한다. 현재 임기 및 직무 가드, 원본 비교, 행사 영수증, 연장, 감사 기록을 같은 기존 DB 배치에서 처리한다. 재시도는 동일 영수증을 반환한다.
- 공지는 연장 성공 영수증이 있어야 공개된다. 계정별 서버 수신 영수증으로 다른 탭/기기의 재표시를 차단한다. 이미지 준비 후 표시 권한을 요청하며 응답 유실은 같은 요청 ID로 복구한다. 로그인/탭 복귀/최대 60초 확인으로 접속자를 안내하고, 전투 및 다른 모달 중에는 표시를 대기한다. 기존 코드를 이미 열어 놓은 세션은 일반 새로고침으로 새 클라이언트를 받으며 강제 새로고침하지 않는다.
- 다음 임명으로 교체되거나 임기가 끝나면 아직 확인하지 않은 계정에 대한 자동 노출도 종료한다. 감옥에서도 이 공지 조회·확인 경로만 허용하며 게임 기능 제한은 유지한다.
- 그림은 built-in image_gen으로 새로 제작했다. 진짜디임 승인 얼굴과 장군 군복/배경의 참조 역할을 분리했다. PNG 원본과 전송용 WebP, 입력 역할·최종 프롬프트·해시를 `preview/chief-extension-20261011/art-manifest.json`에 보존한다.
