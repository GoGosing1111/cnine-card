# 몬스터 디펜스 PVE · 운영 TEST 준비 — 2026-10-16

사용자 요청에 따라 기존 협동 디펜스 검수판을 **PVE → 디펜스** 메뉴와 실제 로그인/영속 방 서버에 연결했다. 운영 모드는 TEST이며 OWNER와 CMS에서 지정한 계정만 이용한다. 미지정 계정은 테스트 안내가 표시되고 서버 입장도 차단한다. 새 계정 지급·보상·참가 비용은 없다.

## 플레이와 난이도

각자 제공된 용병 2명 + 카드 1장을 골라 2인 6기 또는 3인 9기로 출전한다. 자동 공격, 직접 전술, 전선 지원 이동, 정비 자원 강화, 연습용 자동 대원을 지원한다. TEST 전투 수치와 제공 편성은 실제 계정의 카드/용병 고유 능력·성장·보유권과 분리한다.

위 값은 TEST 초기값이며 **OWNER CMS → 디펜스 · TEST**에서 난이도별 사용·HP·공격·속도·등장 수·수호석 HP를 바꾼다. 생성된 방은 당시 설정을 보존한다. OFF와 지정 계정 해제는 새 입장/티켓 갱신을 막고 기존 접속은 최대 2분의 티켓 유효기간 안에 종료된다. 서버 자동 전투는 방의 종료 조건까지 진행한다. 공개 ON 전환은 제공하지 않는다.

적 원본 13종은 `shared/monster-defense-v1.mjs`가 단일 구성표다. 일반/돌파/원거리/중갑 정예와 난이도별 중간·최종 보스를 섞어 등장시킨다. 물개왕은 지원병 소환, 크리그는 전선 포격, 성기사는 중갑과 충격파, 핏빛 군주는 실제 피해량 흡혈, 아르케는 전선 순차 공격이다. 2.5초 예고·위험 전선 표시·HP 40% 미만 격노를 제공한다. 원본 PNG는 수정하지 않았으며 길목·수호석도 기존 생성 원본을 사용한다. 전체 사용 자산 30개의 SHA-256은 `preview/coop-defense-v1/build-report.json`에 있다.

전장 2880×1280과 긴 2~3개 길목을 유지한다. PC 전체 보기, 모바일 내 전선 확대/드래그/좌우 팬/축소 지도를 제공한다. 분대 3기가 모두 쓰러질 때만 전멸 1회를 기록하며 15→30→45→60초 후 체력 50%로 복귀한다. 정비·강화·재접속으로 부활 대기나 쿨다운을 초기화하지 않는다.

## 서버와 운영 경계

- `/api/defense/{feature,create,join,session,leave}`는 기존 계정 인증과 사용자 단위 잠금을 사용한다. TEST 설정은 1행을 읽는다.
- `/api/defense/live/{state,command}`는 방 한정 단기 티켓으로 기존 Durable Object의 `defense:<roomId>`를 사용한다. 전투 중 PostgreSQL 조회/계정 재화 쓰기는 없다. 기존 격전지의 방·계정 포인터와 키가 분리돼 있다.
- 서버 100ms 고정 틱, 1초 알람, 한 번에 최대 5초 따라잡기. 클라이언트 폴링 300ms, 동시 1개·실패 시 2초까지 간격 증가. 사용자별 상태/명령 각 15회/초, 적42·이벤트240·명령 영수증4,096개 상한을 둔다. 명령 해시는 고정 64자다.
- 명령 바디를 최대4KiB까지 먼저 읽고 상태 읽기→변경→영수증 저장 사이에 비동기 작업을 넣지 않는다. 동시 명령 유실·다른 소유자 조작·재시도 이중 적용을 차단한다. 클라이언트는 피해·승패를 확정하지 않는다.
- 방 최대1시간·전투 최대30분. 서버 상태와 전멸 이력을 저장하며 동일 계정으로 재접속한다. 룸 티켓은120초, 갱신 중 중복 요청을 합치고 같은 계정의 유효 티켓은 최대3개다.
- CMS는 OWNER 전용, 설정 revision/CAS·같은 요청 재시도·최근50개 변경 메타데이터를 설정과 함께 저장한다. 일회 운영 등록은 설정/감사 로그/영수증을 한 거래로 처리하고 재배포 훅에서 실행하지 않는다.
