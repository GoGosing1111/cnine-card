사용자 `승인 라이브올려 레오넬 동급으로`, `획득 불가 도감에는 출력`에 따라 V-976 제로를 등록한다. 마지막 `백금 검익으로 승인`이 거신 검영 선택을 대체한다. 최종 승인 기록은 `preview/mercenary-cyan-knight-battle-20261020-v1/live-approval-20261020.json`이다.

## 적용

- SSS 리미티드, 기본 전투력 **2,300,000**. 레오넬과 실제 공격·체력·방어·자연 속도·추가 행동·연계·기본 피해 상한·80% 피해 경감·상태이상/반격 보호가 같다. 장비 전투력 변환도 같다. 단일 정책은 `shared/mercenary-zero-v1.mjs`다.
- 일반 공격은 청광 횡단 → 섬광 연참 → 용궤 검격으로 순환한다. 각 동작의 여러 검격은 서버 일반 공격 한 번을 표현한다.
- PVE 천검 포위(MS-976)와 창천 종단(MS-975)은 교대로 발동하며 **공통 재사용 5행동**, 에너지 35를 사용한다. 두 개의 독립 쿨다운으로 화력이 배증하지 않는다. 매 시전 총 1,512%를 살아 있는 적에게 나누어 대상당 한 번 적용한다. PVP 광역기는 레오넬과 같이 사용하지 않는다.
- 백금 검익, 승인 흰 망토·흰 네온 윤곽, 전신 비율과 파지를 보존한다. 서로 다른 소환검의 엇박자 경로·관통 후 소멸/재등장·큰 타격 효과를 유지한다. **자동 확대 OFF**. 거신 검영은 비교 프리뷰에 보존하며 실전 어댑터는 백금 검익만 선택한다.
- 공개 도감의 전체/리미티드 목록, 원화·전투 SD·전투력·기술별 설명에 표시한다. **획득·팩 획득 OFF**이며 일반/리미티드/할로윈 팩·합성 풀에 추가하지 않는다. CMS 가중치가 양수여도 서버 획득 검사를 통과하지 못한다. 계정 지급·자동 편성·운영 경제 변경은 없다.
- 보유권이 생기는 향후 승인 상황을 위해 PVE/PVP 계정 편성, 공통 V3·12인 사냥·협동/디펜스의 기존 연결을 준비한다. 현재 미보유 편성은 서버에서 차단한다.
