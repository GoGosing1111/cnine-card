## 결과와 범위

- 제안 이름은 **사현 / 지워진 미래의 관측자**. 쿠온이 기억을 보존하는 인물이라면 사현은 멸망 직전의 미래를 지우다가 사람들의 이름까지 잃은 관측자로 설정했다. 관측소의 명부를 사이에 둔 쿠온과의 대화도 작성했다.
- 현문안은 불규칙한 깨진 렌즈 고리와 세로 동공이다. 기존 만화의 눈 문양·복장·인물을 사용하지 않는다. 공허법상은 얼굴 없는 상아색 유리 수호체와 빈 흉부·길게 열린 손으로 설계했다.
- 전용 원화, SD V3, 수호체, 렌즈, 눈 컷인 5종을 built-in ImageGen으로 생성해 화면에 연결했다. 원본 바이트·SHA-256·치수·알파 검사는 `preview/apocalypse-sahyeon-20261019-v1/manifest.json`, 전체 프롬프트는 같은 폴더 `prompts.json`에 있다. SD V1/V2는 선택하지 않았다.
- 경로: `/preview/apocalypse-sahyeon-20261019-v1/`. 정지선·공백회랑·천경붕괴·전체 전투·일시정지·중단·동작 줄이기를 제공한다.

## 실제 기준과 기술

2026-10-19 05:13:40 KST, PostgreSQL 반복 읽기 전용 거래에서 조회한 아즈마(id 78)의 CMS 적용 전투력은 **110,000,000**이다. 과거 정적 자료의 180,000,000을 기준으로 삼지 않았다. 원본 조회는 `azuma-reference.json`에 보존했다.

사현은 **220,000,000**이다. 동일 설정으로 실제 서버 시뮬레이터를 실행해 보스와 6개 쫄몹의 HP·공격·방어가 모두 정확히 2배이고 보스 보호막도 2배임을 확인했다. 속도·연타 2회·강제 행동 간격 4는 유지한다. 승률이나 클리어 시간의 2배를 보장한다는 뜻은 아니다.

| 기술 | 실제 서버 규칙 | 연출 적용 |
|---|---|---|
| 현문안 · 정지선 | 공격력이 높은 4명 스킬 봉인, 대상별 4행동, 정화 가능 | 눈 컷인 → 대상 렌즈, 1.12초 적용 |
| 현문안 · 공백회랑 | 전체 회복·재생·흡혈 차단, 대상별 4행동, 정화 가능 | 눈 컷인 → 회랑 렌즈, 1.12초 적용 |
| 공허법상 · 천경붕괴 | 전체 공격력 30%, 보호막 관통 65% | 눈 → 거대 수호체 → 압축·파열, 2.85초에 1회 적용, 4.6초 종료 |

슈트 스킬 피해 방어는 아즈마와 같은 50%다. 이를 두 배로 올려 면역으로 만들지 않았다. `balance.json`은 같은 5개 시드·4개 분대 전투력의 60회 비교 결과를 보존한다. 카드당 1,500만에서 아즈마 5/5승, 사현 0/5승, 플레이어 전투력도 두 배로 올린 사현 5/5승이었다. 이것은 지정된 검수 편성의 결과이며 모든 운영 편성의 승률을 대표하지 않는다.

## 격리와 승인 상태

`build-plugin.mjs`는 이 프리뷰 빌드에만 보스 카탈로그와 전용 FX를 주입한다. 기존 서버의 `createPveBattleV2` / 난이도 계산과 V3 Pixi 엔진을 사용한다. 화면은 고정된 서버 계산 `payload.json`을 재생하며 클라이언트가 피해를 새로 판정하지 않는다. 긴 궁극기는 프리뷰의 직접 `playEvents` 경로로 재생한다. 실제 일반 PVE 진입 래퍼에 신규 보스를 등록한 상태는 아니다.

운영 공유 카탈로그·전투 API·DB는 변경하지 않았다. 제안 ID 80은 예약된 ID가 아니므로 운영 연결 시 재확인해야 한다. `registration-draft.json`은 `registered:false`, `enabled:false`, `visualApproval:false`, `rewardsConfirmed:false`다. 검수 시뮬레이션의 보상은 0이며 운영 보상 정책을 확정한 것이 아니다. 신규 리소스의 `projectVMonsterArt.approved`도 false로 보존한다.

루트 `AGENTS.md` 706행: **“신규 이펙트 운영 연결에는 기존 시각 승인 규칙을 유지한다.”** 따라서 원화와 전투 연출의 사용자 시각 승인을 기다리는 검수본이다. 기술 검수 결과를 시각 승인으로 기록하지 않는다.
