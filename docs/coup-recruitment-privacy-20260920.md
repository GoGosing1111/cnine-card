# 쿠데타 모집 인원 비공개 · 2026-09-20

- 사용자 지시: 모집 중에는 족장팀·반란군 인원을 숨기고 개전 후 공개한다.
- 모집 화면은 양 진영 인원수와 참가자 명단을 숨긴다. 본인 진영·참가 확정 상태는 유지한다.
- 일반 status/join 응답도 RECRUITING의 members를 빈 배열로 반환한다. 본인 mine은 유지하며, 권한 검사를 거친 CMS 응답만 명단을 유지한다.
- ACTIVE 전환 시 기존 인원수와 명단이 다음 전황 갱신부터 다시 표시된다. 전투·보상·모집 상태를 변경하지 않는다.
- SQLite/Postgres 회귀 검증: 46개 통과. PC 1440px 및 모바일 390/320px: 25개 브라우저 확인 통과. 기존 명단이 남아 있는 응답도 모집 UI에서 숨기는지 확인했다.
- 운영 배포는 release:gate를 포함한 deploy:production으로 수행한다.
