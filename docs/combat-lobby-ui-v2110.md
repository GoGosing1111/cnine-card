# PVE·PVP 로비 스타일 통일 — 2026-09-14

## 요청과 반영 범위

- PVE 콘텐츠 탐색, 덱 편성, 토벌 대상 선택과 PVP 매칭·덱·기록·랭킹·보상에 로비의 남색 바탕, 회청색 구분선, 연두색 선택·주요 버튼을 적용한다.
- PVE 콘텐츠 탭의 용병 지휘소 링크를 제거한다. 성장 메뉴의 지휘소와 PVE/PVP의 별도 용병 편성 슬롯은 유지한다.
- 콘텐츠 탭은 개별 아이콘과 짧은 한글 이름으로 표시한다. 모바일에서도 가로로 잘리지 않으며 운영에서 열린 콘텐츠만 노출한다. 카우방의 실제 포탈 개수는 계속 표시한다.
- PVE의 서버 준비 장식과 CMS 구현 설명을 없애고 편성·전투력·남은 횟수·보상 정보를 정돈한다. 배틀슈트 전투력은 PVE 전용임을 명시한다.
- PVP 시즌 종료 시각, 티어, 피로도와 편성 제한은 유지한다. 모바일 피로도 숫자, 필터, 저장 버튼, 긴 시즌 이름의 줄바꿈을 보완한다.

## 구현

- 스타일은 `css/combat-lobby-v2110.css`에서 `.pvev2-live-root`, `.ranked-live-v2`에만 적용한다. 화면 너비가 아닌 콘텐츠 영역을 기준으로 컨테이너 쿼리를 사용한다.
- `js/pve-command-v2-live.js`는 표시 문구와 탭 이름만 정리한다.
- `js/pve-v3-navigation.mjs`에서 지휘소 링크 주입을 삭제하고 카우방 포탈 개수를 스타일이 구분하도록 속성을 추가한다.
- 두 변경 스크립트와 새 CSS는 `2110-combat-lobby` 캐시 키를 사용한다. 기존 고정 버전 회귀 검증 3개도 같은 키와 한글 문구로 갱신한다.
- 일반 카드 5장, 선택 용병 1장, 저장 API, 전투 판정, 경제, 운영 플래그, V3 전장·카드 프레임·원화/SD는 변경하지 않는다. 무한의탑·폐차장은 기존 전용 진입 화면을 유지한다.

## 검증

- Chrome 실제 index/app/공유 셸 검수: 1440×1000, 1024×768, 768×1024, 390×844, 320×740, 740×420.
- 계정·API는 로컬에서 모두 가로채며 운영 계정이나 재화를 변경하지 않는다.
- 198개 브라우저 검증 통과: 콘텐츠 탭·상태·필터 잘림, 용병 탭 제거 및 재진입, 용병 슬롯 보존, 별도 아포칼립스 행동력과 소탕 제외, 정확한 5장 저장, 프리셋 적용/복원, 검색, 피로도·불완전 덱 차단, PVP 5개 탭과 포탈 개수.
- 네비게이션 검증 및 전투 관련 회귀 검증 31개 통과. 카드 목록과 전체 컨트롤의 데스크톱·모바일 스크린샷을 직접 확인했다.
- 재현 스크립트와 화면은 배포 디렉터리 밖 `../qa/combat-lobby-v2110/`에 보관한다.
- 운영 반영은 깨끗한 후보에서 `npm run deploy:production`이 실행하는 전체 `release:gate` 통과 후에만 진행한다.
