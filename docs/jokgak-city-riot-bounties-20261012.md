# 족각도시 폭동지역·현상수배 — 2026-10-12

사용자는 교전이 많은 지역의 폭동 연출, 다수 처치 유저에 대한 서버 무작위 현상수배(3천·5천·1만원), 수배범 사망 시 지나가는 안내와 실제 도시 현금 지급을 요청했다. 최종 정정 **“체포말고 처치만”**을 우선 적용했다.

## 실제 동작

- 폭동: 최근 5분 교전 5회 이상. 정상 완료된 공격·체포만 1회씩 집계하며 무승부를 포함한다. 지역 경계, 파동, 불티, ‘폭동지역’ 표식과 최근 교전 횟수를 표시한다. 시간 창에서 교전이 빠져 기준 미만이면 해제된다.
- 수배: 회차 3번째 처치부터, 기존 수배가 없는 유저에게 처치마다 25% 확률로 발령한다. 3,000/5,000/10,000원은 각각 동일한 확률로 정한다. 클라이언트가 선정·금액을 지정할 수 없다. 수배 완료 후 재선정 대기 10분이다.
- 지급: 일반 공격 전투에서 도시 HP를 0으로 만든 처치자에게 해당 현상금을 더한다. 방어자의 역처치도 포함한다. 단순 승리·무승부·체포는 지급 대상이 아니며, 체포로 HP가 0이 되어도 수배를 완료하거나 처치 실적을 늘리지 않는다.
- 공개: 지도 아래 수배 게시판은 닉네임·금액·이번 회차 처치 수·현재 위치를 표시한다. 체류자/선택 대상에도 현상금이 보인다. 지급 영수증과 7초간 지나가는 ‘현상수배범 사망 / 수배 완료’ 배너에 실제 수령자·금액을 표시한다. 확성기와 함께 나타나도 서로 가리지 않는다.
- 운영: OWNER CMS → 족각도시 → 폭동·현상수배. 기준·확률·재선정 대기·금액 3종·기능 스위치를 저장한다. 상세 기준은 구현 기본값이며 운영자가 변경할 수 있다. 도시 자체의 기존 운영 모드·역할/회차 보상·전투 균형은 유지한다.
- OFF: 새 선정·표시·지급을 중단한다. OFF 중 처치된 기존 수배는 무지급 해제한다. 이미 발령한 수배 금액은 설정 변경으로 바뀌지 않는다. 구버전 CMS에서 누락된 새 설정은 보존한다.
- 범위: TEST/ON과 6시간 회차별로 실적·현금·수배·전황을 분리한다. 자발적 퇴장/재입장으로 수배를 초기화하지 않는다. 과거 공격 로그에서 처치를 추정하거나 소급 보상을 주지 않는다. 글로벌 코인·일반 PVP/PVE는 변경하지 않는다.

## 저장·재시도

신규 테이블/마이그레이션 없이 기존 도시 life의 모드별 `conflict`와 `app_meta`의 현재 회차 사건/수배 레지스트리를 사용한다. 플레이어 상태·현금·처치 실적·수배 발령/해제·개인 알림·공개 사건·공격 영수증을 기존 CAS 배치 안에서 함께 확정한다. 같은 영수증 재시도, 응답 유실, 동시 사냥, 저장 실패에서 중복 지급/부분 저장을 막는다. 도시 현금 한도 초과는 기존 정책처럼 전체 행동을 거절한다.

교전 수는 시간/회차/모드로 좁힌 작은 사건 레코드에서 계산하고 2초만 서버 캐시한다. 수배 인물은 현재 활성/접근 가능 계정·실제 life 수배를 확인한다. 이전 회차 사건/레지스트리는 기존 회차 정산 배치에서 삭제한다. 계정별 최근 배너 ID를 저장하여 새로고침 시 재생을 반복하지 않는다. 기존 팝업 숨김·동작 줄이기·활동 로그를 따른다.
