# 장비 연마 CMS · 공개 OFF 배포 — 2026-10-05

사용자 요청: 장비 강화 화면에서 진입하고 유저 공개는 OFF인 상태로 설정과 재화 CMS를 추가해 배포한다.

## 적용 범위

- 장비 강화 센터에 장비 연마 진입 링크. 공개 OFF일 때 일반 유저에게 숨기고 OWNER에게 검수 링크를 제공한다. 선택된 장비 인스턴스를 넘긴다.
- OWNER CMS: 유저 공개, 안내문, 대상 장비 부위, 전체 연마 횟수, 5개 옵션 사용 여부·상승량·추첨 가중치·개별 상한.
- 회차별 코인·마스터의 별·연마석 비용, 비용 일괄 편집 및 횟수 변경에 따른 행 조정.
- 연마석 코드 EQUIPMENT_POLISH_STONE, 이름·설명·카탈로그 활성 설정과 전용 원화. 정책과 재화 메타데이터를 한 트랜잭션으로 저장한다.
- 최초 상태 조회에서 누락된 고정 정책/재화 카탈로그만 생성한다. ON CONFLICT DO NOTHING으로 기존 CMS 설정을 보존하며 보유 수량·지급·상점·드랍은 변경하지 않는다.
- 실제 보유 장비(강화 단계 포함)와 세 종류 재화 잔액을 조회한다. 인스턴스 소유권과 페이지 커서는 기존 강화 인벤토리 조회를 사용한다.
- OWNER는 저장한 확률과 상한으로 무차감 연출을 검수한다. 결과는 연출 시작 전에 서버가 결정하고, 다시보기는 같은 결과를 재생한다. 검수 수치는 브라우저 메모리에만 존재한다.

## 현재 잠금

공개 기본값 false, executionMode OFF, executionReady false.
일반 유저는 OFF 상태에서 state/preview/execute 경로로 들어갈 수 없다. OWNER를 포함해 실제 quote/execute/receipt는 423으로 잠근다.
CMS의 공개 ON은 화면 공개만 뜻한다. 실제 연마 차감·장비별 영구 성장·전투 반영 엔진은 이번 설정/진입 배포 범위에 포함하지 않는다.
기존 장비 강화·복구 공개와 실행 설정은 변경하지 않는다.

## 저장 보호

정책 버전과 직전 JSON을 모두 검사한다. 중복/오래된 창의 저장은 409다.
옵션의 유효 상한 합이 전체 횟수보다 작거나, 활성 옵션 가중치가 0이거나, 비용이 음수/범위 밖이면 저장하지 않는다.
CMS 정책·재화·감사 로그의 부분 저장을 막고 실패하면 함께 취소한다. 잘못된 정책은 공개 OFF로 닫는다.
