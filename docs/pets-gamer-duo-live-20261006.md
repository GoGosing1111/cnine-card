## CMS 변경

- 메뉴 이름은 `펫 관리`. 목록의 작은 원화·이름·버프 요약과 선택한 펫의 큰 원화를 제공한다.
- 기본 화면은 버프 종류 한 개, 효과, 적용 대상·사용 모드, 저장 버튼이다. 여러 버프를 추가하는 반복 편집기를 제거하고 새 등록 기본값을 10%로 설정했다.
- 이름·경로·메모·검수 사용·삭제는 상세 설정, 용병 편성·SD·서버 전투 검수·백업은 별도 접힌 도구로 정리했다.
- 최초 조회는 `/api/admin/pets`로 펫 설정만 읽는다. 용병 목록을 포함한 무거운 검수 API는 도구를 펼칠 때 불러온다.
- 기존 서버 유효성 검사·리비전 충돌·동일 요청 재시도·OWNER 제한은 유지한다. UI에서 버프를 편집하면 해당 펫의 버프 배열을 하나로 저장한다.
