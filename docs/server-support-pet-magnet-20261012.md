사용자 요청: 서버 안내의 후원 문구를 일시적으로 숨기고, 시즌패스 적용자가 펫 도감에서 바로 펫 자석을 적용할 수 있게 한다.

- `js/server-support-v1.mjs`의 `SERVER_SUPPORT_ENTRY_VISIBLE=false`로 메뉴 하단 서버 안내 링크와 시즌패스에서 안내 페이지로 돌아가는 진입을 숨긴다. 기존 안내 원문·신청 기능·서버 설정은 보존하며 해당 상수를 복원하면 다시 표시할 수 있다.
- 시즌패스 메뉴와 일일 보상은 유지한다. 펫 도감의 선택한 펫 상세에 시즌패스 자석 적용 버튼, 현재 대상, 한국시간 종료일을 표시한다. 활성 기간의 보유 펫 한 마리에 적용하며, 다른 펫을 선택하면 대상을 변경한다. 영구 자석 보유 펫과 미보유 펫에는 신규 적용 버튼을 잠근다.
- 기존 `server-support/info`, `server-support/pet` API와 서버의 계정 자격·기간·보유·revision 검사를 재사용한다. DB·가격·혜택 기간·CMS·영구 잠재력·물약 정책은 변경하지 않는다. 실제 지원 펫을 장착하고 새 군단토벌에 입장하면 기존 서버 전투 스냅샷에 자석이 반영된다.
- 기존 계정별 요청 저장 키를 공유한다. 통신 중단·새로고침 후 같은 영수증으로 재확인하고, 계정 변경과 기간 만료 시 잘못된 적용을 차단한다. 로비 원본에서 번들을 재생성하고 도감·로비·앱/PWA 캐시 태그를 갱신한다.
