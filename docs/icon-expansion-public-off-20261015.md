# 신규 ICON 2종 라이브 준비 공개 · 실행 OFF

사용자 최종 지시는 “3장편성 일단 하지말고 라이브 반영만하고 OFF로 해놔”다. 기존 ICON 덱 한도 2장을 유지한다. 남수댕(왕관 찬탈)·디임 빨간 모자(자율 병기)의 사진·SD·스킬 프리뷰와 제작 조건을 라이브 제작 화면 및 OWNER CMS에 공개하되 제작·획득·편성·실전 활성화는 OFF다. 기존 디임과 다른 ICON 9종, 기존 제작 가능한 8종의 운영 상태를 변경하지 않는다.

## 제작 계약

- 신규 2종: **1조 코인 / 마스터의 별 500만 개 / 성공률 10%**.
- SUPERSTAR +13·FUR +13 각 1장, 실패 시 재료와 재화 소모·천장 없음은 기존 정책을 그대로 참조한다.
- 기존 아이콘의 5천억 코인 가격은 유지한다. 새 2종을 기존 제작 대상 배열에 넣지 않으며 서버는 해당 코드 요청을 DB·영수증·난수·재화 접근 전에 423으로 거부한다.
- 단일 준비 계약은 `shared/icon-expansion-v1.mjs`다. 신규 cardId는 null이며 운영 카드 원장에 행을 만들거나 계정에 지급하지 않는다. 도감의 기존 보유 카드 목록에 가짜 보유분을 만들지 않는다.
- 전용 원본 및 실행 가능한 SD/스킬 검수판은 기존 두 `preview/icon-*-battle-20261015-v1/` 폴더에 그대로 보존한다. 제작 화면은 해당 두 프리뷰로 연결한다.

## 기존 ICON보다 상위 성능 준비

사용자 “기존 아이콘보다 더 상위로 출시”에 따라 다음 준비안을 적용했다. 실제 전투에는 아직 연결하지 않는다.

- 같은 전투력에서 기존 ICON 기준 체력·공격·방어·속도를 1.25배로 준비한다. 격리 비교는 기존 9종의 각 능력 최고값을 기준으로 하며 기존 역할 패시브/스킬을 중복 상속하지 않는다.
- 왕관 찬탈: 첫 행동부터 조건 확인, 재사용 2행동, 최대 8회. 탈취할 강화가 없으면 발동 횟수를 소모하지 않는다.
- 자율 병기: 첫 행동 소환, 재사용 4행동, 최대 3회. 주인 HP 50%·공격 80%·속도 110%; 동시에 1기, 별도 피격, 주인 사망 시 소멸.
- OWNER 기술 준비실에 두 대상·제작 조건·상위 준비안·수치를 표시한다. 기존 저장 수치는 보존하고 완전히 미입력된 두 기술에만 준비 기본값을 읽어 온다. 나머지 6종은 카드 미지정·수치 null이다. 초안 저장으로 개방하지 않는다.

## 검수

- 관련 검사 100개 통과: 신규 OFF/재화 보호, 기존 합성 성공·실패·재시도·원자성, 기술 CMS 저장/충돌, 기존 기술 경계, 최신 운영 PVP 준비 코드와의 병합 회귀.
- 현재 origin/main 기준 기존 전투 125쌍(250전)의 전체 결과·타임라인 차이 0건: `docs/qa/icon-expansion-public-off-20261015/unchanged-controls.json`.
- 신규 상위안 1대1 격리 비교 1,152전: 남수댕 PVE 280승/8패, PVP 288승/0패; 디임 PVE/PVP 각각 288승/0패. 장비·용병 없는 동일 18만 전투력/기존 기본 역할 기준이며 모든 팀 구성이나 운영 승률을 보장하는 수치가 아니다. 근거 `balance.json`, 재현 `scripts/benchmark-icon-expansion-20261015.mjs`.
- PC 1440px·모바일 390px 제작 준비 표시/CMS는 같은 QA 폴더의 `browser.json` 및 캡처를 따른다.
- 변경은 공개 준비와 잠금에 한정한다. DB 스키마·운영 경제 설정·계정 재화 변경 없이 지정 scoped 배포를 사용한다. 운영 배포 식별자와 읽기 검증은 완료 후 별도로 기록한다.
