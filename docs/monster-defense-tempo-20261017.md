# 몬스터 디펜스 진행 속도·전략·지원 연출 — 2026-10-17

사용자 피드백: 20분 이상 걸리는 원정을 단축하고, 몬스터 출현 속도를 개선한다. 지원에 텔레포트 연출을 추가한다. 플레이어의 선택과 전략으로 클리어가 달라지도록 난이도를 높인다. 버튼의 글자 정렬·크기를 고치고 PVE 복귀를 로비 복귀로 바꾼다.

## 적용 범위

새로 만든 규칙 3 방에 `tempoRevision:1`을 기록한다. 이미 저장된 방에는 이 필드를 소급 추가하지 않으므로 기존 진행 속도·전술 범위·피해를 유지한다. 전용 디펜스 모델과 화면만 변경한다. 일반 PVE/PVP, 계정 전투력, 보유 카드, 재화와 계정 보상은 변경하지 않는다.

배포 전 운영 설정은 **OFF / revision 7 / 지정 계정 5 / 계정 보상 false**다. 30웨이브, 특성 정비 15초, 포인트 추첨 50/65/80%, 강화 60/35/15/5%, 비용·특성·부활 정책을 그대로 유지한다. 운영 설정에 쓰기 작업을 하지 않는다.

## 진행과 전략

- 30웨이브 및 29회의 개인 보급 추첨 기회를 유지한다. 첫 등장 대기 800→300ms, 순차 등장 간격 기준 1,450→850ms를 참가 인원으로 나눈다. 서버 100ms 틱으로 실제 등장 시각을 처리한다.
- 진입 지점을 기존보다 400만큼 전방으로 옮기고 이동 속도를 2배로 한다. 몬스터 HP를 올려 시간을 늘리는 방식은 사용하지 않는다. 기본 공격 1.7배와 기존 난이도별 CMS 배율로 진입 압박을 높인다.
- 첫 정비·일반 정비 8초. 5웨이브마다 특성 정비는 기존 CMS 시간(현재 15초)을 쓴다. 모든 대원이 준비하면 기존 최소 3초 후 출발한다. 사용하지 않은 포인트와 특성 선택은 계속 이월되고 자동 차감되지 않는다. CMS에는 두 정비 시간의 의미를 명시한다.
- 3의 배수 공세는 추격병 집중 돌파, 5의 배수는 장갑병·공성 병단, 10의 배수와 마지막은 보스 공세다. 우선순위는 보스→공성→돌파다. 집중 전선은 종류별로 순환하며 2·3인 모두 특정 전선에만 몰리지 않는다. 다음 공세의 종류·전선을 전투 HUD와 정비실에서 알린다.
- 사격 전술은 기본 사거리+300, 돌격 전술은 +240 이내의 적을 타격한다. 사거리 밖에서 명령하면 쿨다운을 소모하지 않는다. 멀리 있는 적을 즉시 제거하던 전술을 실제 접근 시점에 맞춰 사용한다.
- 포격은 2.5초 경고 후 해당 전선을 타격한다. 난이도별 최대 체력 기준 피해 하한은 입문 28%, 보통 40%, 어려움 50%, 악몽 60%, 재앙 70%이며 기존 공격 기반 피해와 비교해 큰 값을 사용한다. 방어 태세는 포격 피해를 40%로 줄이고, 1.8초 지원 전송을 경고에 맞추면 전선을 벗어날 수 있다. 공성포 경고도 보스가 없을 때 표시한다.
- 적의 원거리 정체 방지 판정, 정상 처치 및 웨이브 정산, 중복 명령 영수증과 성장 거래는 유지한다.

## 연출과 화면

ImageGen 전용 텔레포트 원본·프롬프트·해시는 `preview/coop-defense-v1/assets/teleport-v1/manifest.json`에 보존한다. 원본 8칸 중 상단 광원이 잘린 2칸을 제외하고 완전한 6칸만 잘라 WebP 아틀라스로 연결했다. 새로 도형을 그려 대체하지 않았다. 출발·도착 발밑 좌표는 서버의 이동 목적지를 그대로 사용한다. 출발지 소멸→도착지 등장으로 표시하며 전투 피해 판정은 서버가 유지한다. 재접속은 현재 이동 상태에서 복원하며 과거 이동 이펙트를 다시 쌓지 않는다. 화면 숨김·종료·전송 완료 시 스프라이트를 정리한다. 동작 줄이기는 정지 포털 표식을 사용한다.

기존 디펜스 전용 버튼 이미지를 유지하고 과도한 가로 확장을 줄였다. PC 주 버튼은 높이 64px, 글자 18~22px. 모바일은 높이 56px, 글자 16~18px다. 주 버튼의 불필요한 영문 소제목과 한쪽 화살표를 제거하고 중앙 정렬한다. 상단 `로비로 돌아가기`는 별도 이미지 버튼이며 `/?screen=home`으로 이동한다. 전투 조작 글자와 공세 예고를 확대하고 모바일에서도 정비실 예고가 보이게 했다.
