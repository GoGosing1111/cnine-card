`FUNDING_GIFT_BOX`(펀딩 사은품) 1개 개봉 시 **250,000,000,000 코인(2,500억), MASTER_STAR 3,000,000개, PINGDU_REPAIR_COUPON 2개**를 모두 확정 지급한다. 기존 대회 사은품 `TOURNAMENT_GIFT_BOX`의 별 200만·코인 2,500억 구성은 유지한다. 수신자 지정이 없는 아이템 준비 작업이며 실제 계정 지급·메시지 발송은 수행하지 않는다.

## 지급·사용

- CMS → 유저관리 → 대상 계정 관리 → 인벤토리 아이템 지급 → **펀딩 사은품**. 1~9,999개, 대상·수량·세 보상 확인 후 지급.
- CMS → PLAY DK 인증·메시지 → 2단계 인증자 보상 메시지의 **펀딩 사은품** 선택. 실제 메시지 전송은 운영자가 대상 범위·수량·내용을 확인하고 실행한다.
- 유저 인벤토리 → 팩·상자 → 펀딩 사은품 → **1개 개봉 · 보상 받기**. 완료 화면에서 세 보상을 함께 확인한다.
- 리페어권은 기존 핑두 리페어 쿠폰이며 장비 강화 센터 → 파괴 기록에서 사용한다. 복구·강화 정책과 출시 플래그는 변경하지 않는다.
