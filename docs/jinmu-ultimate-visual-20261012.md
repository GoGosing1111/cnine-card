# 천룡검황 진무 · 궁극기 가독성 보정

사용자 요청: 궁극기 광역 범위 확인, 흐릿한 효과 보강, 빠르게 사라지는 연출 완화. 후속 최종 지시는 **큰 일러스트를 없애고 작은 얼굴 초상·대사 5종·SSS 리미티드 테두리를 적용하되, 레이드에서는 표시하지 않고 다른 PVE에서만 표시**하는 것이다.

## 최종 대사창

- 마다라 레이드의 기존 얼굴 초상·별도 대사 영역을 직접 확인했다. 진무는 불투명한 얼굴 초상(PC 62px, 모바일 48px), 금속성 금색 이중 테두리·절삭 모서리·초상 링·SSS LIMITED 인장으로 구성했다. 기존 승인 원화의 얼굴 부분만 CSS로 표시하며 원화·SD·아틀라스 파일은 보존한다.
- 전투 헤더 아래, 캔버스 위에 실제 높이를 측정한 전용 행을 둔다. 군단토벌의 실제 상단 조작·진행 정보·보스 체력창과 겹치지 않는다. 별도 재생 타이머 없이 기존 궁극기 시작 시 대사가 한 줄씩 순환한다.
- `battleData`의 원래 콘텐츠 모드와 실제 전장 모드를 함께 검사한다. 레이드·마다라·협동 레이드·PVP에서는 대사창을 생성하거나 공간을 예약하지 않는다. 기존 마다라 대사창은 변경하지 않는다. 확인할 수 없는 콘텐츠도 표시하지 않는다.
- 전체 일러스트를 Pixi 전장에 로드·표시하던 코드는 제거했다. 전투 종료·리셋에서는 대사창과 높이 보정을 해제한다.
- 대사 5종: “고개를 들어라. 마지막으로 볼 하늘이다.” / “천룡의 이름으로, 이 전장을 평정한다.” / “내 검 앞에서 운명을 논하지 마라.” / “용이 눈을 떴다. 이제 물러설 곳은 없다.” / “천룡이여, 내려와 오만한 자들을 심판하라.”

## 원인과 수정

- 서버 `MERCENARY_JINMU_AREA`는 유효한 적 전체를 한 번씩 처리한다. 기존 클라이언트만 피격 연출을 5곳으로 제한했다. 영수증에 있는 실제 대상마다 표시하며 군단 12칸을 확인했다. 피해·행동력·발동 조건은 유지한다.
- 광역 폭발 크기를 고정된 캐릭터 배율 대신 적 진형의 실제 가로·세로 범위로 결정한다. 실제 알파 외곽을 기준으로 화면 밖 잘림을 제한한다.
- 용·폭발·피격 텍스처는 승인된 원본 프레임을 통째로 표시한다. 반투명 프레임 두 장을 겹치던 교차 페이드로 본체가 흐려지지 않도록 변경했다. 궁극기 소환·피격 강도는 최대 알파 1이며 끝부분만 점진적으로 사라진다. 이미지·아틀라스는 변경하지 않았다.
- 궁극기만 1.25배로 재생하여 4.7초 원본을 **3.76초**에 보여준다. 기존 2.6배 모션과 전투 가속의 중첩을 제거하고, 첫 접촉 직후 다음 행동을 미리 허용하던 처리를 해제했다. 전체 시퀀스가 끝난 뒤 다음 행동으로 넘어간다. 기본 검격 속도는 유지한다.
- 최초 가독성 수정에서 기존 원화 컷신을 1.08초로 늘렸으나, 후속 사용자 지시로 이 컷신은 제거했다. 현재는 위의 얼굴 대사창만 일반 PVE에 표시한다. 동작 줄이기에서는 기존 전투 모션 단축을 유지한다.
