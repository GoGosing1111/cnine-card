# 천룡검황 진무 · 궁극기 가독성 보정

사용자 요청: 궁극기 광역 범위 확인, 흐릿한 효과 보강, 빠르게 사라지는 연출 완화, 기존 일러스트 컷신 확인.

## 원인과 수정

- 서버 `MERCENARY_JINMU_AREA`는 유효한 적 전체를 한 번씩 처리한다. 기존 클라이언트만 피격 연출을 5곳으로 제한했다. 영수증에 있는 실제 대상마다 표시하며 군단 12칸을 확인했다. 피해·행동력·발동 조건은 유지한다.
- 광역 폭발 크기를 고정된 캐릭터 배율 대신 적 진형의 실제 가로·세로 범위로 결정한다. 실제 알파 외곽을 기준으로 화면 밖 잘림을 제한한다.
- 용·폭발·피격 텍스처는 승인된 원본 프레임을 통째로 표시한다. 반투명 프레임 두 장을 겹치던 교차 페이드로 본체가 흐려지지 않도록 변경했다. 궁극기 소환·피격 강도는 최대 알파 1이며 끝부분만 점진적으로 사라진다. 이미지·아틀라스는 변경하지 않았다.
- 궁극기만 1.25배로 재생하여 4.7초 원본을 **3.76초**에 보여준다. 기존 2.6배 모션과 전투 가속의 중첩을 제거하고, 첫 접촉 직후 다음 행동을 미리 허용하던 처리를 해제했다. 전체 시퀀스가 끝난 뒤 다음 행동으로 넘어간다. 기본 검격 속도는 유지한다.
- 기존 원화 컷신은 연결돼 있었지만 원본 0.98초가 2.6배 및 전투 가속으로 축약됐다. 새 컷신은 원본 1.35초/1.25배 = **1.08초**, 최대 알파 1이며 충돌 전에 퇴장한다. 아군·적군 측에 맞춰 화면 안쪽에 배치한다. 동작 줄이기에서는 기존대로 숨기고 재생 시간을 단축한다.

## 관련 검수

- `tests/jinmu-live-20261012.browser.mjs --visual`: PC 1440×1000, 모바일 390×844. 실제 서버 12대상 영수증을 실제 배포 번들에서 재생했다. PVP 아군/적군 검격, PVE 광역, 컷신, 후속 행동 대기를 포함해 **10개 확인, 브라우저 오류 0**.
- 모든 대상의 HP 영수증 적용 및 피해 표시 1회, 12개 피격 효과의 대상 ID 일치, 최대 불투명도, 화면 내 효과·컷신, 3.76초 재생 및 2.56초 시점에도 다음 행동을 허용하지 않는 것을 확인했다. 종료 후 잔여 효과 제거·기존 자리 복귀·상시 용 알파 1 유지.

- 메인 로더/번들 버전 `jinmu-visual-v2`, 앱·서비스워커 캐시 `20261012-jinmu-visual2`.
- 직전 운영 배포: Pages `ea53e299-2978-4782-8bd1-1aa7ae31dbcd`, 소스 `41c767f4` (Wrangler 운영 목록으로 확인). 해당 커밋의 협동전 인벤토리 복구를 유지한다.
