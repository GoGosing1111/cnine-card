# 숲켓몬 Windows 설치형 클라이언트 — 2026-10-15

사용자 `클라이언트도 만들자 설치형 런쳐까지`, `Windows PC 런처부터 제작` 및 `런처 대충만들지 말고 좀 이쁘게 만들지?` 지시에 따라 Windows x64 런처와 설치 파일을 제작했다. 안드로이드·iOS는 추후 지원으로 표시한다. 기존 PWA 점검, 이용 중단, 강제 새로고침은 필요하지 않으며 이 작업에서 점검 설정을 변경하지 않는다.

## 실제 동작

- 전용 네이비·라임 성채 배경, 기존 승인 로고·원화, 게임 시작 버튼, 다운로드 진행, 리소스 관리, 이용 안내를 제공한다. 작은 창 950×680에서도 주요 버튼과 안내가 잘리지 않는 것을 실제 Electron에서 확인했다.
- Electron 44.7.2와 electron-builder 26.15.3은 `packaging/windows-client`의 별도 패키지다. 게임 루트 의존성·인증·DB·전투 판정은 변경하지 않는다. 설치는 사용자 단위이며 바탕화면·시작 메뉴 바로가기와 제거 프로그램을 생성한다.
- 첫 실행에 필수 코드·폰트 약 84MiB를 내려받는다. 미디어는 이용할 때 받아 PC에 보관하고 재실행 시 같은 해시 파일을 재사용한다. 게임 콘텐츠 전체 6GB 이상을 최초 설치 때 강제로 받지 않는다.
- 다운로드 중단·손상·실패는 부분 파일만 제거하고 완료 파일과 이전 활성 버전을 보존한다. 검사·복구 기능을 제공한다. 4GiB를 정리 기준으로 사용하되 필수 파일을 보호하고 게임 중에는 정리하지 않는다. 따라서 실사용량은 일시적으로 기준을 넘을 수 있다.
- 모든 필수 리소스 준비를 마친 뒤 활성 목록을 교체하고 게임 실행 중에는 그 목록을 고정한다. 게임 종료 후에 업데이트를 다시 확인한다. `/index.html` 등 Pages 정규 URL 전환은 동일 원점 리다이렉트만 허용하며 최종 응답 해시를 검증한다.
- 기존 `https://cnine-card.pages.dev` 원점을 유지해 로그인·API·서버 판정은 온라인으로 처리한다. 원격 게임 창은 sandbox/contextIsolation을 사용하고 Node 및 런처 브리지를 노출하지 않는다. 런처 명령은 로컬 창의 메인 프레임만 허용한다.
- Electron 전용 프로필의 서비스워커만 차단한다. 사용자 Chrome/PWA 저장소·설정에 접근하지 않는다. 게임 중 F5/Ctrl+R은 확인 후 실행하고 F11 전체 화면을 지원한다.

## 범위와 한계

인터넷과 기존 계정 로그인이 필요하다. 최초 이용 이미지의 다운로드·디코딩·GPU 업로드·서버 응답 시간은 남아 있으므로 무로딩 또는 완전 오프라인으로 안내하지 않는다. 실행 중 배포로 아직 받지 않은 이전 미디어가 교체되면 해시 불일치로 거부하고 전투 후 업데이트 안내를 표시한다. 최초 로그인 계정 인증은 사용자가 진행한다.

게임 리소스는 업데이트되지만 런처 실행 파일의 자동 교체는 미구현이다. 최소 런처 버전 요구 시 최신 설치 파일을 안내한다. 이번 0.1.0 설치 파일은 코드 서명 인증서가 없는 빌드이며 Windows 보안 안내가 나타날 수 있다. 공개 다운로드 채널·서명 배포는 이 파일 제작과 별도다.

## 배포

운영에는 정적 클라이언트 파일 목록과 그 캐시 헤더만 추가한다. `packaging/windows-client/`와 설치 파일·개발 의존성은 Pages 공개 대상에서 제외한다. 런처를 수정해도 게임의 서비스워커 버전을 올리지 않는다. 기존 배포 명령이 목록을 자동 생성하므로 후속 정상 배포도 클라이언트 업데이트를 제공한다. 계급 프리뷰의 실제 공개 미들웨어를 공유해 비공개 검수 파일을 제외하고, `_redirects`의 이전 페이지도 목록에 넣지 않는다.

최신 배포 `19861d8283e572ce53da2f1c79e5b06ef6394482`의 장비 보호 안내 변경과 후속 기록은 그대로 통합했다. 공통 서버나 게임 의존성을 바꾸지 않는 별도 클라이언트·정적 목록 추가이므로 관련 회귀와 기존 출시/캐시/Hyperdrive 보호를 포함한 scoped 배포를 사용한다. 배포 결과와 설치 파일 SHA-256은 완료 후 이 문서에 추가한다.

최초 연결 배포는 `152bbdd1e7298923237b885efda69e5a38479d33` / Pages `591808ad`다. 패키징 앱 운영 검사에서 비공개 검수 HTML의 404를 발견해 목록 생성기에 위 공개 경계를 적용했다. 수정 목록의 필수 고유 파일 **1,486개 / 87,504,913바이트 전부**를 운영 서버에서 다운로드·해시 검증했다. 리소스 버전 `d82872cbd31de09230009157fd8a3cf49bcd0841956d40d91bb84ba57443d1eb`, 전체 공개 목록 12,931개다. 설치 파일 자체는 변경하지 않는다.
