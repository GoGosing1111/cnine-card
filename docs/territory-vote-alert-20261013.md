# 영토전 스킬 투표 표시·알림 — 2026-10-13

사용자 요청: 영토전 투표가 진행 중이면 스킬 버튼에 테두리 효과와 투표 진행 알림을 제공한다.

## 동작

- 현재 선택 거점에서 아군의 준비된 스킬에 1표 이상 모이면 전술 작전 진입 버튼과 해당 스킬 카드에 금빛 테두리·은은한 맥동·투표 중 배지를 표시한다. 카드에는 서버 표 수와 필요 인원을 표시한다.
- 진행 중인 투표를 처음 확인하면 스킬명·표 수·`보기` 버튼을 높이 약 50px의 한 줄 알림으로 4초간 표시한다. 버튼은 실제 전술 작전 패널을 열며 닫기 버튼도 제공한다.
- 사용자 후속 요청에 따라 큰 안내 카드를 없애고 스킬 패널 상단에 `투표 알림 ON/OFF` 체크박스를 제공한다. 기본 ON이며 같은 브라우저의 계정별 로컬 저장소에 선택을 보존한다. OFF는 새 알림을 차단하고 표시 중 알림도 닫지만 투표 중 테두리·배지는 유지한다. 저장소가 차단돼도 현재 페이지에서 선택할 수 있다.
- 계정·회차·거점·진영·스킬·쿨타임 세대별로 같은 탭에서 한 번 알린다. 세션 저장소를 사용하며 저장소가 차단돼도 메모리에서 중복을 막는다. 여러 투표가 동시에 시작되면 한 알림으로 묶는다.
- 본인이 이미 투표한 경우 기존 완료 안내를 유지하며 추가 알림은 생략한다. 진행 중인 테두리는 계속 표시한다. 표 수가 증가하거나 상태가 다시 렌더링돼도 알림 타이머를 다시 시작하지 않는다.
- 전투·처리 중·숨겨진 탭·열린 패널에서는 새 알림을 미룬다. 투표 초기화, 스킬 발동/쿨타임, 거점 이동, 회차 종료, 휴전, 참가 불가 상태에서는 해당 표시를 해제한다. 화면을 닫으면 알림 타이머와 요소도 정리한다.
- 기존 상태 폴링을 사용하며 추가 API 요청을 만들지 않는다. 서버 투표 기준·권한·스킬 성능·경제·DB는 변경하지 않는다. 다른 거점 투표를 새로 조회하는 기능은 포함하지 않는다.
- 동작 줄이기 설정에서는 정적인 금빛 테두리를 유지하고 애니메이션은 끈다. 알림은 접근성 상태 영역으로 제공한다.

## 구현

`js/territory-vote-alert-v1.js`, `css/territory-vote-alert-v1.css`를 영토전 메인 진입에 연결했다. 기존 `tickSkills`와 닫기 경로만 연결하고 앱·서비스워커 버전을 `20261013-territory-vote-alert-compact`로 맞췄다.

## 검수

실제 메인 HTML·영토전 UI·스킬 목록을 로컬 API fixture에 연결하고 외부 요청을 차단했다. 운영 계정이나 투표는 변경하지 않았다.

- Chrome 1440×1000 / 390×844: 적군 투표만 있을 때 표시 없음, 아군 첫 표 알림, 7→9표 실시간 갱신, 같은 알림 요소 유지, 투표 보기→패널 이동, 실제 투표 버튼 클릭 1회/요청 1회 확인.
- 본인 투표 후 버튼 잠금·진행 테두리 유지, 쿨타임 해제, 다음 투표 알림, 닫은 알림 재표시 없음, 다른 거점 이동·복귀와 화면 재입장, 동작 줄이기 확인.
- 작은 알림의 높이 56px 이하, OFF 상태의 새 투표 알림 차단·테두리 유지, 페이지 새로고침 후 OFF 유지, ON 복구·패널을 닫은 후 안내, 4초 자동 닫힘과 자동 닫힘 후 중복 없음 확인.
- 가로 넘침 및 브라우저 실행 오류 없음. 알림·스킬 카드 화면을 PC와 모바일에서 직접 확인했다.
- 화면·결과: `docs/qa/territory-vote-alert-20261013/`. 실행 스크립트: `tests/territory-vote-alert-20261013.browser.mjs`.
- 배포에서 선택하는 관련 회귀는 `tests/territory-vote-alert-20261013.test.mjs` 7건이다. 진영/거점/참가 상태, 표 수·기준 읽기, 알림 중복과 계정/쿨타임 분리, 저장소 실패, ON/OFF의 계정별 저장과 복구를 확인한다.

## 배포 범위

현재 영토전 UI에 한정된 작은 변경으로 `npm run deploy:production -- --scoped`를 사용한다. 기존 구수댕 변경과 운영 보상 기록은 보존한다. 초기 반영은 커밋 `697dd513` / Pages `86aa6558`로 완료됐고, 배포 중 도착한 사용자 후속 요청의 작은 알림·ON/OFF를 다음 scoped 배포로 반영한다. 배포 기준은 실제 직전 운영 커밋을 재조회해 사용한다.
