# 군단토벌 백그라운드 사냥

사용자 요청: PC 창 최소화·다른 탭, 모바일 앱 전환 중에도 군단토벌을 스킵하거나 자동 일시정지하지 않고 계속 진행한다.

- 군단토벌 전용 렌더러의 화면 가시성과 전투 진행을 분리했다. 숨겨진 동안 화면·소리는 멈추고 실제 경과 시간까지 도달한 서버 타임라인만 순서대로 처리한다. 브라우저가 JavaScript를 동결하면 복귀 후 그 간격을 복원한다. 결과 시각에 도달하기 전 결과로 건너뛰지 않는다.
- 화면을 숨길 때 기존 공격·탄착·등장 애니메이션의 세대를 무효화한다. 서버가 기록한 체력·보호막, 정확한 몬스터 인스턴스와 용병 상태로 현재 전장을 복원하고 이후 전투를 1배속으로 이어 보여준다. 최종 보스 체크포인트와 확정 결과를 그대로 사용한다.
- 사용자가 직접 누른 일시정지는 유지한다. 일시정지 시간은 백그라운드 진행 시간에서 제외한다. BFCache의 일시적인 pagehide, freeze/resume는 종료로 처리하지 않는다. 재생 취소를 정상 전투 완료로 오인하던 경로도 막았다.
- 처치 영수증은 기존 reveal/claim/finish 경로로 한 번씩 전달한다. 자석 펫은 기존 서버 자동 수집을 유지하고, 일반 드랍은 직접 주워야 한다. 화면이 멈춰도 드랍 만료 시간은 흐르며 자동 획득 애니메이션 때문에 정산을 기다리지 않는다. 보상·입장 횟수·900초 제한·CMS 출시 상태를 변경하지 않는다.
- 브라우저/앱을 완전히 종료하거나 운영체제가 페이지를 폐기한 경우까지 실행을 보장하지 않는다. 이 경우 기존 중단 복구·보상 정산 정책을 유지한다. 화면을 숨기는 동작은 완전 종료와 구분한다.

## 검증과 배포

- 새 회귀: 중간 공격 중 화면 숨김, 경과 시간까지만 순차 진행, 동결된 시간 복원, 직접 일시정지, 복귀 후 미래 전투 재개, 정확한 몬스터 세대·용병 상태, 보스/결과 경계, 처치 누락·중복 방지, 정산 재시도, 렌더러 없이 드랍 만료·자석 영수증 처리.
- 기존 관련 회귀: 군단토벌 제한 시간·입장/실제 번들 로더, 중단 복구, 자석 펫 원정 가방·원자적 정산. 오래된 제한 시간 검사의 VM에는 현재 원본이 사용하는 애니메이션 클래스와 root 목만 보충했다.
