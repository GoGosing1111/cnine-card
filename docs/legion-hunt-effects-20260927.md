# 군단토벌 광역기·드랍 표시 수정 — 2026-09-27

사용자 요청: Z슈트가 타격 직전 이미지에서 멈춘 뒤 갑자기 피해를 주는 문제와 중간 소멸을 수정한다. V3 필드 드랍 아이콘을 표시하고, 장착 헬기폭격은 Z바디와 별개 광역기로 발동한다.

## 원인과 수정

- Z바디는 CAST 직후 시각 시간을 진행하면서, 앞선 카드 동작·KO 처리를 기다리는 HIT 앞에서 아틀라스를 충돌 직전 프레임에 고정했다. 이제 이전 동작이 정리된 후 같은 GSAP 시계에서 접근을 시작한다. 후속 타격도 준비 프레임 시간을 확보하고 서버 HIT와 접촉 프레임을 함께 재생한다.
- 먼저 죽은 대상의 후속 HIT가 없는 경우에도 이미 발동한 다섯 검의 연속 프레임·잔향을 끝낸다. 헬기폭격이 먼저 적을 처치해 Z 피해 기록이 없는 경우도 시각 효과만 완료한다. 이 경로는 피해·신규 대상·드랍 기록을 생성하지 않는다. 마지막 프레임의 알파를 서서히 줄이고 마지막 잔향 이후 레이어를 정리한다.
- 헬기폭격은 서버에서 단일 대상이었다. `ALL_LIVING_ENEMIES`로 고치고 적별 기존 5배 피해를 4회 접촉에 나눈다. Z바디의 고유 스킬 스케줄과 장착 헬기 스케줄은 독립이며 둘 다 기존 15초 간격을 유지한다. 로켓·유도탄·일반 슈트 공격과 PVP 규칙은 변경하지 않는다.
- 헬기는 적 진형 범위로 네 폭발을 분산하며, 주 표적이 먼저 죽어도 다른 확정 피해와 효과가 유지된다. 대상마다 헬기·폭발 객체를 복제하지 않고 1대/4개 폭발을 재사용한다. 동일 접촉의 여러 피해 기록이 폭발 시간을 다시 시작하지 않는다. 사망·슬롯 교체 이후 잔향 위치도 고정한다.
- 드랍은 Pixi 아이콘 앞의 클릭 버튼에 일반 버튼용 불투명 네이비 배경이 적용되어 가려졌다. `.ground-drop`을 일반 버튼·호버 스타일에서 제외했다. 모바일 축소 전장에서도 아이콘은 화면 기준 최소 32px를 확보하고 기존 필드 좌표·클릭 토큰·서버 수령 계약을 유지한다.

## 검수·기술 기록

- PixiJS 8.20.0 / GSAP 3.13.0. 기존 V3 효과 레이어와 `BattleSuitSkillChipPlayback`의 단일 시계를 사용한다. 새 렌더러·별도 타이머·자산·음원 없음. 승인된 Z 아틀라스의 픽셀·해시는 그대로다.
- 관련 구현: `ZBodyThunderFX.js`, `BattleSuitSkillChipPlayback.js`, `SkillChipFX.js`, 군단토벌 `GroundDrops.js`, 공통 서버 `_battle_v2_preview.js`.
- 충돌 기준은 Z 검 300ms/지면 340ms 아틀라스 프레임이다. 첫 타격은 슈트 준비 동작 1,080ms 전체를, 후속 타격은 검 접근 300ms를 확보한다. 헬기가 먼저 시작해도 Z바디의 준비 프레임을 건너뛰지 않는다. 그 뒤 서버 확정 HP를 적용한다. 대상 수로 피해를 나누지 않으며 과잉 피해·사망 이후 피해 생략은 기존 서버가 결정한다.
- 지연된 KO, 12명 동시 사망, 슬롯 재사용, 다섯 검의 마지막 프레임, 피해 중복 없음, 일시정지/배속/취소/레이어 정리, 장착 칩 전달 및 별개 광역 스케줄 회귀를 확인했다.
- 실제 공용 렌더러 검수에서 25/25회·5,322,300 피해가 서버와 일치하고 완료 뒤 FX/대기 그룹 0, 슈트 ready 복귀를 확인했다. PC 1280×720·모바일 390×844 군단토벌 진입→전투→아이템 클릭→철수 결과를 로컬 실제 핸들러/분리 테스트 DB에서 검수했다. PC 100마리·별 2개, 모바일 70마리·별 1개가 정산되었다. 최종 빌드에서 모바일 32px 아이콘·터치 획득·콘솔 오류 없음도 확인했다.
- QA 서버의 Z/헬기/마스터의 별 100% 드랍은 명시적 환경변수에서만 설정된다. 운영 CMS·덱·재화·입장 횟수를 검수에 사용하거나 수정하지 않는다.
- OWNER 공개/일반 유저 OFF/실계정 보상 OFF/1배속/15분+최종 보스/일일 2회 유지.
