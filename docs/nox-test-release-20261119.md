# 종언의 주파수 — 운영 TEST

2026-11-19 사용자 지시에 따라 신규 녹스 레이드를 라이브 TEST로 연결한다. 운영 전환은 관리자 → 레이드 → **종언의 주파수 · 녹스**의 OFF / TEST / ON 선택과 저장으로 적용된다.

- TEST: OWNER 및 지정 참가자만 입장하며 무료다. PlayDK 글 1547590의 `ㅌㅅ` 및 명시적인 `탑승합니다` 신청을 게시판 UUID와 게임 2차 인증으로 대조한다. 닉네임 변경을 이유로 다른 계정에 권한을 부여하지 않는다.
- ON: 전체 공개. 1인당 **50,000,000,000,000 코인(50조)**을 전원 준비 후 전투를 시작할 때 차감한다. 대기실 생성·참가·해산은 무료다. 각 공대원은 준비 버튼으로 표시된 비용을 확인한다.
- 전원의 잔액, 원장, 공대 시작, 입장 영수증을 단일 PostgreSQL 거래로 처리한다. 중복 요청은 기존 영수증을 반환한다. 한 명이라도 잔액이 부족하거나 일부 처리가 실패하면 전원 차감을 취소한다.
- 운영 모드가 바뀐 대기실은 나간 뒤 다시 만든다. 기존 TEST 공대에 ON 비용을 소급 청구하거나 공개 이용자가 TEST 공대를 무료로 이용할 수 없다. OFF에서도 나가기는 가능하다.
- 기존 보상 잠금은 유지한다. 공대는 저장된 PVE 덱, 장비, 슈트, 용병 및 펫 능력을 사용한다. 3인 보스 HP 1,800만 / 6인 1,200만, 세 번의 필수 기믹, 27개 지뢰 + 3개 안전 발판, 210초 광폭화다.

서버는 카드·피해·점수·클리어를 클라이언트로부터 받지 않는다. 리듬 판정은 ±35/90 ms를 유지하고 입력 수신만 최대 1.5초 허용한다. 서버 처리 시간을 제외한 왕복 시각으로 음원과 입력 시계를 맞춘다. 공대원 입력은 각자의 상태만 원자적으로 병합해 여섯 명의 리듬 입력이 하나의 전역 재시도 줄에 서지 않게 한다. 발판의 350 ms 순서 표시는 예정 시각으로 재생하며 판정은 서버가 유지한다.

운영 테이블과 TEST 명단의 적용은 별도 감사 영수증 `ops:nox-test-release:1547590:20261119:v1`에 기록한다. 계정 코인 변경이나 메시지 발송은 이 배포 작업에 포함되지 않는다.

검수: `npm run test:nox-raid`. 화면 검수는 Windows Chrome, Android 터치 에뮬레이션, Windows 진입 URL, H5 iframe에서 첫 진입·재입장·입력·발판·퇴장 잔여 작업을 확인한다. 실제 휴대폰/설치형 앱 측정이 아니다. Windows Playwright WebKit은 AudioContext를 제공하지 않아 정밀 음원 준비를 차단한다. 이를 실제 Safari 통과 결과로 취급하지 않는다.
