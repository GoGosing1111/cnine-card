# 쿠데타 공중폭격 지원 · 즉시 족장 교체

사용자 요청 `야포단하고 똑같은 효과로 공중폭격 지원 만들어` 및 `족장 패배하면 투표없이 바로 반란군 지휘관으로 교체`를 현재 운영 쿠데타에 연결한다. 최신 일러스트 지시 `포스터 참고하지말고 근엄하고 공포스러운 쿠데타 일러스트 만들어 아바타 활용할 필요 없음 여자 지휘관만 만들어`에 따라 기존 포스터·아바타를 입력하지 않고 새 여성 지휘관을 제작했다.

## 공중폭격 지원

- `AIR_SUPPORT`: 현재 전선 적 최대 HP 30% 피해. 남은 HP를 초과하지 않으며 야포단과 같은 전선 이동·최종 승리 정산을 사용한다.
- 족장·반란군 지휘관 모두 사용. 족장 30분, 이번 지원 회차 반란군 25분. 다음 회차는 양쪽 30분이다.
- 야포단과 쿨타임·요청 영수증이 별개다. 행동력을 차감·충전하지 않는다. 일반 참가자와 미참가 지휘관은 발동 불가, 원자폭탄 OFF를 유지한다.
- 새 일러스트·스킬 설명·PC/모바일 카드·발동 팝업·CMS 지원 안내를 연결했다. 현재 회차 지원 재적용 시 이미 사용한 AIR_SUPPORT 쿨타임도 한 번만 보정한다.

## 족장 패배 정산

반란군 승리 시 기존 족장 임기를 REMOVED로 종료하고, 해당 회차의 활성 USER/OWNER·반란군 참가 지휘관에게 즉시 새 족장 임기 7일과 기존 족장 권한을 부여한다. 유효한 기존 대수가 있으면 다음 대수를 사용한다. 현재 지휘관은 진짜디임(ID 4773), 기존 족장은 하이희야♡(ID 4977)이다. 아직 승리하지 않은 진행 중 회차를 수동으로 정산하거나 실제 족장을 미리 바꾸지 않는다.

라운드 FINISHED·족장팀 8시간 수감·기존 족장 직무 종료·새 임명·승계 영수증을 기존 DB 배치로 원자 처리한다. 새 trial·유권자·투표는 생성하지 않는다. `coup_succession_v2123:<roundId>` 및 회차/임명 metadata에 이전·새 족장을 보존한다. 중간 실패는 전체 롤백, 재시도는 임기·형기를 연장하지 않는다. 정산 전 CMS가 새 족장을 임명한 오래된 회차는 그 임명을 덮어쓰지 않는다. 이전에 열린 재판만 기존 규칙으로 마감한다.

`chief/status`의 COUP 출처와 승계 정보를 실제 임명에서 읽는다. 로비는 실제 반란군 승리 후 새 임명의 `쿠데타 성공 / 족장 교체 / 이전 이름 → 새 이름` 팝업을 자동 표시한다. 여왕 즉위식의 24시간 표시·오늘 하루 숨김·세션 숨김·다시 보기·초점 복구를 공유하며 기존 즉위식은 유지한다. 그림에는 이름을 굽지 않고 live 한글을 겹쳐 표시한다.

## 이미지·검수

원본 PNG를 그대로 복사했다. 생성 원본·SHA-256·새 여성 지휘관 전체 프롬프트는 `assets/ui/coup/coup-art-v2123-20261002.json`에 기록했다. 기존 쿠데타 포스터와 아바타는 참조하지 않았다.

실제 JS/CSS/이미지를 루프백 fixture에서 PC 1280×900·모바일 390×844로 확인했다. 승계 팝업의 인물·한글 이름·버튼·가로 넘침, 공중폭격 상세의 적 대상·25/30분·독립 쿨타임을 확인했다. fixture는 운영 데이터 쓰기를 막으며 실제 스킬은 발동하지 않았다. 화면 증거는 `C:/Users/User/.codex/tmp/pet-gusudaeng-settings-20261002/coup-succession-desktop.png`, `coup-succession-mobile.png`, `coup-air-support-desktop.png`, `coup-air-support-mobile.png`에 보존했다.

## 범위 배포

공통 인증·DB 기반·마이그레이션·의존성을 바꾸지 않는 쿠데타 국소 변경이다. `tests/coup-palace-v2115.test.mjs`의 SQLite/PostgreSQL 피해·권한·쿨타임·재시도/동시 요청·롤백·직무 교체·과거 재판 회귀와 `tests/queen-coronation-v1.test.mjs`의 팝업 분기/숨김을 선정한다. Worker 컴파일·출시 플래그·캐시·Hyperdrive 확인 후 `npm run deploy:production -- --scoped`로 한 번 배포한다. 실제 전선·명단·체력·진행 중 쿨타임을 초기화하지 않는다.

첫 scoped 사전 실행은 72개 중 69개 통과로 운영 업로드 전에 중단됐다. 핵심 공중폭격·즉시 교체/롤백은 양 DB에서 통과했다. fixture에 반란군 지휘관을 기본 배정하면서 기존 차단 검사가 지휘관(ID 2)을 일반 참가자로 보던 두 실패는 일반 참가자(ID 3)를 검사하도록 수정했다. 별도 `chief-burning-v1918`는 과거 서비스워커 캐시 문자열 v1941을 요구하는 기존 오류였으며 현재 운영 v2108과 관련이 없다. 이 무관한 검사·서비스워커는 정비하지 않았다. 동일 팝업 실행 코드에서 5/5 통과한 queen 회귀는 반복하지 않고, fixture 검사 수정의 직접 영향 범위인 coup 파일만 최종 scoped 게이트에서 다시 실행한다.
