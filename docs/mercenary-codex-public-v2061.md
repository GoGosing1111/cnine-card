## 정보와 화면

기존 검수 프리뷰의 CSS·클라이언트·모델과 준비 로스터를 그대로 공유한다. `npm run build:mercenary-codex`로 공개 HTML만 생성하며, 테스트가 템플릿과 빌드 결과의 일치를 검사한다. 후속 디자인 수정도 공통 소스 한 곳에 반영한다.

공개 화면에는 “도감 공개 중 · 정보 열람 전용”을 표시한다. 21종 모두 등급·능력치·스킬·획득 경로는 확정 대기다. 로스터의 시스템 미연결 상태와 원화/SD의 개별 승인 상태를 변경하지 않았다. 원화 원본과 승인 프레임도 덮어쓰지 않았다.

검색·초성 검색·위치/역할 필터·정렬·즐겨찾기·상세·원본 확대·키보드 탐색을 유지한다. 공개 즐겨찾기는 `cnine.mercenaryCodex.public.v1`로 분리하며 계정 보유 카드가 아니다. 같은 탭에서 이동하고 상단 로고로 게임 로비에 돌아갈 수 있다. 모바일 검색 입력·지우기 영역은 최소 44px다.

## 캐시 안전

- 앱과 서비스 워커 버전: `2061-mercenary-codex`.
- 공개 도감 HTML은 항상 재검증한다. 변경한 JS/CSS 참조의 캐시 버전도 갱신했다.
- 서비스 워커가 모든 문서 이동 응답을 `/index.html`에 저장하던 경로를 수정했다. 루트 게임 문서만 게임 캐시를 사용하고, 도감은 자기 경로에 저장한다. 도감 방문 후 오프라인으로 돌아와도 게임 인덱스가 도감으로 바뀌지 않는다.
- 문서 캐시 쓰기 용량 부족이 정상 네트워크 응답을 가리지 않는다. 관리자/API 요청 제외는 유지한다.

## 검증

- `npm run test:mercenary-codex`: 30개 통과. 읽기 전용 경계, 메뉴 중복 방지, 고정 동일 탭 경로, 공개 HTML 일치, 즐겨찾기 분리, 캐시 격리, 원본·SD 해시 보존 포함.
- PC 1440×1200, 모바일 390×844에서 브라우저 시나리오 각 19개 통과. 초성 검색, 필터, 상세 원화/SD, 확대, 포커스 복귀, 뒤로가기, 즐겨찾기, 메뉴 이동, 계정 API 미호출, JS 오류 없음 확인.
- 320px에서 가로 넘침 없음, 검색 및 필터 최소 높이 44px 확인.
- 전체 출시 회귀 테스트 691개와 별도 추가 검사 59개 통과(두 집합에 중복 검사 포함). 기존 테스트에 고정된 앱/셸 캐시 기대값은 새 배포 버전으로만 갱신했다. 전투 스프라이트의 `2060-nonblocking-fx` 버전은 유지했다.
- 최종 배포는 작업 범위만 커밋한 깨끗한 릴리스 작업 트리에서 `npm run release:gate` 및 `npm run deploy:production`으로 진행한다. 검수 대기 이미지·문서 등 미추적 작업물은 포함하지 않는다.
