# ICON 구수댕 성능 점검·소폭 보강 — 2026-10-13

사용자 `구수댕 성능체크해서 어느정도 좋게 만들어라`에 따라 현재 서버 엔진과 운영 FUR +15 기준 능력치·ICON CMS 설정으로 비교했다. 기존 구수댕은 고정 편성 비교에서 이미 상위권이다. PVE 고유효과 배율만 **100→105%**로 올려 보강한다.

## 변경

- 비법 배합 타격, 깊은 감칠맛 전이/단일 집중 피해와 시전당 전이 총량에 적용하는 PVE 배율을 5% 높인다. 기본 공격·능력치를 통째로 5% 올리는 변경이 아니다.
- PVE 환산: 스킬 170→178.5%, 전이 30→31.5%, 단일 집중 45→47.25%, 시전당 전이 총량 공격력 600→630%. 방어·실제 피해·대상 HP 상한·반올림에 따라 실제 피해 상승폭은 달라진다.
- PVP 배율 90%, 첫 2행동/재사용 4행동/최대 6회, 표식 3행동, 최대 3명, 대상당 HP 6% 전이 상한과 46% 스킬 상한은 유지한다. 정화·봉인·사망·추가타 재귀 방지도 그대로다.
- 운영 저장 문서는 과거 7종 명단이다. 기존 명단 읽기 어댑터가 새 구수댕 기본값을 반영한다. DB 쓰기·리비전 조작·기존 7종 사용자 수치 덮어쓰기는 없다. 명시적으로 저장된 9종 문서와 과거 영수증의 100% 스냅샷은 그대로 인정한다.
- 카드 획득·합성·이전 ZENITH 정산·리소스·UI 배치 변경은 없다.

## 비교 방법과 결과

`scripts/benchmark-icon-gusudaeng-20261013.mjs`와 `docs/qa/icon-gusudaeng-balance-20261013/`의 운영 입력·전후 보고서를 함께 보존한다. 계정 정보는 포함하지 않는다.

- PVP: 공통 아군 4명에서 ICON 한 자리 교체, 조은을 공통 파트너로 둔 ICON 2장 조합도 비교. 장비 전투력 0/500만, 전열/후열, 공격/방어 양쪽, 조건별 시드 24개. 총 **2,880전**.
- PVE: ICON 9종, 동일 아군 4명, 장비 0/500만, 기준 전투력의 4/10/25/50/100배 단일 보스, 조건별 시드 24개. 총 **2,160전**. 승리 표시만 집계하지 않고 보스 HP 0과 타임라인 피해 합계를 확인한다.
- 전후 각 **5,040전**, 합계 **10,080전**. 용병·펫·마법·배틀슈트는 제외한 역할 비교다. 실제 랭크전 승률이나 모든 편성의 우열을 의미하지 않는다.
- 기존 구수댕의 해당 PVP 비교 승률은 **76.49%**(2,203/2,880). 디임과는 단독 ICON 53.13%, 조은 공통 파트너일 때 42.71%로 상성이 남는다. 이를 근거로 PVP 전체 화력이나 발동 빈도를 더 높이지 않았다.
- 단일 보스 시나리오는 전후 모두 클리어했으며 기존 구수댕도 9종 중 평균 소요 행동이 가장 적었다. 상향 후 각 조건의 평균 소요 행동은 **1.36~2.49% 감소**했다. 실제 시간 단축률이나 실계정 클리어 확률로 표현하지 않는다.
- PVP 2,880전의 승패·시전·전이 집계는 전후 일치한다. 별도 회귀에서는 다른 ICON 8종 상대 양쪽 진영의 전체 서버 타임라인과 최종 HP도 대조한다.
