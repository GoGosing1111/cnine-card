# 아포칼립스 군단 보스 V2127

사용자 승인: 2026-09-18 `전부 승인하고 아카드부터는 쫄몹 나오게 설정해 6마리 정도`.

## 등록과 판정

- 75 아카드 기본 전투력 7,500,000 / 76 카네키 켄 10,000,000. 9/18 운영 하시라마 5,500,000 재확인.
- 보스당 쫄몹 6마리: 승인 SD 뱀파이어·타락한 성기사·달빛 악령 각 2마리. 각각 보스 기본 전투력의 8%, 별도 체력·행동·처치 판정. 총 7마리 전멸 시 승리.
- 보스의 1·2·3번째 행동에 봉인·힐불가·궁극기 각 1회. CMS 전용 스킬 OFF는 3종 모두 차단한다. 기존 개막 궁극기를 중복 발동하지 않는다.
- 봉인 중 일반 공격은 유지하며 액티브·회복 스킬은 막는다. 회복 불가 중 재생·회복은 0, 정화로 해제 가능. 상태 지속은 피격 대상의 자기 행동 수 기준.
- 기존 하시라마 보상(기본 600,000 × 1,000% = 6,000,000)을 승리당 한 번 승계. 기존 드롭·행동력·아바타 보상 정책을 재사용한다.
- 등록 스크립트는 SERIALIZABLE + advisory lock + ID 충돌 검사 + 자산 확인 + 관리자 로그 + 멱등 receipt. 기존 CMS 프로필·계정 데이터는 수정하지 않는다.

## 화면과 자산

- 승인 원본은 preview에 보존. 운영 자산은 `assets/ui/project-v/monsters/apocalypse-legion-v1/`, 해시 동일한 사본.
- 원화와 SD 경로 분리. 전투 카드 도크/프레임 재사용. 공용 FormationLayout의 기존 7개 격자 셀에서 보스 중앙·쫄몹 6마리 배치.
- PixiJS 8.20.0 / GSAP 3.13.0. 스킬당 실제 12프레임, 충돌 6프레임. 엔진 GSAP 시간축·재생 속도·취소/정리 공용. 컷신·팝업·히트스톱·신규 합성음 없음.
- 로딩 실패 시 서버 HP/상태를 적용하는 폴백, 이전 세션 비동기 응답 무시, 보스 변경 시 사용하지 않는 FX 텍스처 해제.
- 엔진/래퍼 버전 `2127-apocalypse-legion-20260918`. 앱은 래퍼의 ready/ensureRuntime 계약을 사용. V3 번들 9개 동시 빌드.

- 운영 자산이 배포된 뒤 자산 HTTP/해시를 검증하고 DB 등록한다. 운영 배포 명령은 `npm run release:gate` 후 `npm run deploy:production`.
