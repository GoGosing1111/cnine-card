# 펫 도감·메뉴·전투 위치·별도 지급 — 2026-10-09

사용자 요청에 따라 공용 메뉴를 **카드·용병·펫**으로 바꾸고 **펫 도감**을 추가했다. `/pet-codex/`에서 모든 등록 원화, 보유 여부와 수량, 시작 버프, 수집 진행률을 조회한다. 이름·동물·버프 검색과 전체/보유/미보유 필터를 제공한다. 기존 보유권·편성 버전 검증으로 보유 펫 한 마리만 장착하며 미보유 원화도 둘러볼 수 있다.

CMS에는 독립 **펫 지급** 메뉴를 추가했다. OWNER가 등록된 펫과 정확한 닉네임 또는 계정 ID를 선택하고 수량 1~9,999마리·사유를 입력한다. 서버에서 계정 ID·현재/지급 후 보유량을 조회한 뒤 화면의 확인 버튼으로 지급한다. 최신 20건의 지급 대상·펫·수량·사유를 표시한다.

지급 API는 기존 USER_MANAGE 인증 결과 중 OWNER만 허용한다. 닉네임은 SQL 동등 비교로 확인하며 `%`·`_`를 검색 패턴으로 처리하지 않는다. 대상 계정 변경 잠금, 보유 기록/CMS 버전 비교와 기존 DB 원자성 가드를 사용한다. 보유량·관리자 로그·지급 영수증을 같은 배치에 저장한다. 동일 요청 번호는 저장된 영수증을 재사용하고 내용이 달라지면 거부한다. 클라이언트도 전송 전 요청을 보관해 응답 소실·새로고침 후 같은 번호로 확인한다. 장착·잠재력·다른 펫 보유량·재화는 변경하지 않는다.

전투 펫은 전투 슬롯을 차지하지 않는 기존 지원 레이어에 둔다. PVE는 슈트의 정지 위치 왼쪽이며 같은 줄에 다른 카드가 있으면 카드와 슈트 사이의 공간에 맞춘다. PVP는 각 진영의 정지 편성 중앙 아래다. 움직이는 공격자의 위치를 따라 흔들리지 않고 리사이즈에 맞춰 다시 배치한다. 슈트가 없는 PVE는 아군 편성 왼쪽, 협동 편성은 소유자별 위치를 사용한다. 기존 시작 버프·보상·전투 판정은 유지한다.
