# 여봉상 방 후원 2회분

사용자 “방 후원 1당 2조+ 슈트코어6 10개 지급 여봉상 지급”, 후속 “2개”를 합쳐 여봉상(ID 5598)에 **4조 코인(4,000,000,000,000)과 슈트 코어 6 20개**를 직접 지급한다. 정확한 게임 닉네임과 ACTIVE 계정, 아이템 코드 SUIT_CORE_6을 읽기 전용으로 확인했다.

작업 키는 `ops:yeobongsang-room-sponsor:20261018:two:v1`이다. 기존 38명 후원 지급과 별도 요청이며 기존 작업을 재실행하지 않는다. 계정 USER_LOCK·DB 보조 임대와 행 잠금 아래 코인·인벤토리·두 원장·감사·완료 영수증을 한 거래로 저장한다. 재시도는 영수증만 반환한다. 실제 지급 전 롤백 예행과 지급 후 독립 연결에서 원장을 검증한다.

일회 운영 작업이며 게임 실행 코드·UI·설정·스키마를 변경하거나 사이트를 재배포하지 않는다. 완료 내역은 실행 후 기록한다.

관련 격리 PostgreSQL 검사 3개 통과: 정확한 2회분 지급·기존 보유/타 계정 보존·롤백 예행·무쓰기 재실행, 각 쓰기 실패 시 전체 원복, 계정/잠금/잔액 범위 검증 및 COMMIT 응답 유실 복구.
