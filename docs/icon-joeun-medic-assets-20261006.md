# ICON 조은 의료 슈트 원화·SD 적용

사용자 승인: “첫번째 아이콘 조은 SD 리소스 , 두번째 아이콘 일러스트로 적용”. 대상은 기존 ICON 오조은 `CN-1C000004`다.

첫 번째 첨부는 1024×1536 투명 SD 원본, 두 번째는 1080×1456 카드 일러스트다. 두 PNG를 바이트 그대로 보존하고 기존 사진·SD도 이력으로 남긴다. 얼굴·목·의상·신체 비율은 추가 수정하지 않는다. 승인 경로·SHA-256은 [단일 승인 기록](../preview/icon-battle-assets-v1/joeun-medic-approval-20261006.json)에 고정한다.

전투 표시용 파일은 기존 ICON 방식(672px 비율 유지 contain, 사방 48px 투명 여백, 768×768 무손실 WebP)으로 내보낸다. 원본 발 위치를 같은 좌표 변환으로 기록한다. 로스터 → CMS 카탈로그/합성 번들 → 전투 manifest와 메인 로더 캐시를 갱신한다. 카드·덱·컷인에는 일러스트, 전장에는 SD를 사용한다.

운영 DB는 `scripts/operations/replace-icon-joeun-art-20261006.mjs`로 해당 카드의 `image_url`만 교체한다. 트랜잭션·기존 경로 비교·재실행 영수증을 사용한다. 보유 수량·경제·스킬·전투 수치·합성 ON 상태와 다른 카드·용병 자산은 유지한다.

작은 자산 연결 변경으로 분류한다. 관련 ICON 자산/전투 연결 회귀, 실제 메인 화면의 PC·모바일 카드와 PVE/PVP 전장 표시를 확인하고 `npm run deploy:production -- --scoped`로 배포한다. 운영 이미지 경로는 파일 배포 확인 후 전환한다.

검수 결과: 승인 원본 두 파일 SHA-256 일치, SD 투명 여백·768×768 내보내기 통과. 실제 메인 index.html과 V3 렌더러에 로컬 검수 데이터를 연결해 390px/1440px 랭크전 카드, PC PVP·모바일 PVE의 새 SD·원화 로드(HTTP 200), 전투 종료와 복귀를 확인했다. 브라우저 오류 0건이며 승인 원화와 SD를 별도로 사용한다. [화면·검수 기록](../preview/icon-joeun-medic-20261006/qa-report.json)을 보존한다.

운영 DB dry-run은 통과 후 롤백했다. 해당 카드의 image_url 외 컬럼은 그대로 유지됨을 비교했다. 배포 게이트는 `tests/icon-fusion-live-20260930.test.mjs`, `tests/icon-cms-v1.test.mjs`를 선택한다. 직전 운영 기준은 `fdc06e87a2eeb82b771a749d7e689c037582492a`이며 이후 문서 기록과 이번 자산 연결 변경만 포함한다. 자산 첫 회귀·브라우저 확인을 배포 전에 반복하지 않는다.
