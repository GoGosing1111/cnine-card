# 족각도시 보급상자 — 2026-10-18

## 확정 범위

- 사용자 지정: 6시간 회차에 무작위 2~3회 낙하, 지도 표식과 확성기 형식의 위치 속보, 10분 동안 빼앗기, 종료 시 보유자 획득.
- 최종 후속 **‘둘다 70만으로 올려’**에 따라 그로자와 황금 AKS는 모두 도시 전투력 **700,000**이다. 이전 500,000은 폐기한다. 두 무기의 확률은 각각 50%, 회차 전용 장비다.
- 낙하 지점에서 먼저 확보하고 현재 보유자에게 쟁탈 교전을 걸어 이기면 상자를 빼앗는다. 패배·무승부는 소유권을 바꾸지 않는다. 빼앗아도 최초 10분 마감은 연장하지 않는다.
- 이동·퇴장·사망·구금·병원 강제 이송으로 지점을 떠나면 상자를 내려놓는다. 최종 보유자가 없으면 소멸한다. 시장·탐색 풀에는 추가하지 않는다. 같은 무기를 다시 얻으면 추가 보유나 재추첨 없이 중복으로 기록한다.

## 서버와 거래

- `shared/jokgak-city-supply-v1.mjs`가 무기·시간·낙하 규칙의 단일 기준이다. 무기 실제 장착과 화면 표시 모두 같은 전투력을 사용한다.
- 서버가 회차·ON/TEST별 2~3개의 무작위 일정/지점/보상 추첨을 최초 1회 저장한다. 병원·모텔을 제외한 9개 장소에서 낙하한다. 10분 쟁탈전은 겹치지 않는다. 미래 지점·시간과 미확정 무기 추첨 결과를 공개 응답에 넣지 않는다.
- 중간에 처음 켜진 회차는 남은 시간에 배치하여 과거 낙하를 만들지 않는다. 40분 미만 남은 첫 활성화는 다음 회차부터 시작한다. 시작 전후 각 5분 여유를 둔 최소 두 쟁탈 구간을 확보한다.
- 새 테이블·공통 DB 어댑터 변경 없이 `app_meta`의 `jokgak_city_supply_v1:` 키와 기존 도시 플레이어·행동 영수증·알림을 쓴다. 최초 계획 저장, 소유권 교체, 최종 장비 지급은 각각 원자 거래이며 플레이어 리비전·생존 기록·상자 상태 CAS를 확인한다.
- 최종 보상 영수증은 `city-supply-award:<dropId>`로 고정한다. 이중 접속·재시도·동시 정산·응답 유실에서 중복 지급하지 않는다. 마감을 넘겨 계산된 전투는 소유권·피해를 함께 취소한다.
- 기존 1분 스케줄러와 상태/행동 조회가 오프라인 보유자도 정산한다. 판정 시간은 실제 10분 마감이고 결과 노출은 다음 조회 또는 스케줄러 실행 시점이다. 회차 종료에서 도시 장비와 관련 보급 기록을 정리한다.
- ON/TEST, 계정 접근, 도시 OFF와 예약 OFF, 기존 역할별 공격 가능 여부·행동 대기·교전 보호를 유지한다. PVP 덱 5장의 외형과 정규화된 도시 전투를 사용하며 공통 전투 엔진을 변경하지 않는다.
- 쟁탈 교전은 도시 체력 피해를 적용하되 일반 공격의 현금 강탈·처치/공격 실적·현상금·회차 공격 보상을 중복 발생시키지 않는다. 기존 일반 공격·체포는 그대로다.
