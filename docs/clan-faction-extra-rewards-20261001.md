# 세력전 회차 추가 보상 — 2026-10-01

사용자 지시: 세력전 보상에 마스터의 별 300,000개와 미스틱 에너지 300개를 추가한다.

- 기존 대상인 회차 종료 시 영토 4개 이상을 점령한 클랜의 해당 회차 참여자에게 1인당 1회 지급한다. 기존 300억 코인, 하루 2회·회차 3시간, 참여/소속 검증, 영토전 중 일시중단과 순연 기준은 유지한다.
- 배포 이후 새로 정산되는 회차의 기존 코인 보상에 두 아이템을 추가한다. 진행 중인 회차도 이후 종료 정산 시 적용하며 이미 정산된 과거 회차에는 소급 생성하지 않는다.
- `shared/clan-faction-sessions-v1.mjs`에 별/에너지 수량을 기록하고 종료 스냅샷에 수량·보상 버전을 확정한다. 미스틱 에너지의 실제 인벤토리 코드는 `STARLIGHT_ARMOR_CORE`다.
- 회차 정산의 기존 상태 revision·작업 토큰·트랜잭션으로 코인/별/에너지 메시지를 함께 생성한다. 기존 코인 캠페인 키는 유지하고 두 아이템에 별도 접미사를 사용해 각각의 메시지와 기존 수령 영수증을 재사용한다. 메시지 수량은 1인당 3개다.
- 기존 정산 테이블의 `reward_count=recipient_count` CHECK를 활용해 세 보상의 생성 건수·총 수량을 확인한다. 어느 보상이라도 INSERT 0행/오류가 발생하면 정산 상태·모든 메시지·종료 스냅샷을 함께 롤백한다. 신규 운영 테이블·마이그레이션이나 공통 지급 함수 변경은 없다.
- 메시지 발송은 즉시 지갑/인벤토리를 적립하지 않는다. 사용자가 메시지함에서 수령하면 실제 공용 수령 함수가 별 300,000개·에너지 300개와 수령 영수증/로그를 원자적으로 저장한다. 재수령은 중복 적립하지 않는다.
- 종료 보상 화면과 개인의 최근 회차 결과에 두 수량을 표시한다. 과거 스냅샷에 없는 아이템을 현재 기본값으로 표시하지 않는다. 관련 CSS·클랜/세력전 import·메인 캐시는 `20261001-session-rewards`로 갱신한다.
