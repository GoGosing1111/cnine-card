# 할로윈 봉순 · 오리꿍/아윤 대진 조정 · 2026-10-19

사용자 후속 `오리꿍 아윤 상대로 동률로 만들어 그럼`에 따라 할로윈 SS 나무늘봉순 V-980을 조정한다. 앞선 점검의 추가 상향 없음 판단을 이 요청으로 대체한다. 일반 SS 봉순 V-990과 ICON 봉순은 대상이 아니다.

## 변경

**봉순의 PVP 받는 피해를 15% 줄인다.** 방벽 흡수와 HP 손실로 나누기 전에 한 번 적용하며, 상대 용병의 기존 성장에 따른 피해 감소 관통은 유지한다. 특정 상대 코드·계정·현재 승률·난수를 읽어 보정하지 않는다. 일반 랭크전과 동일 엔진을 사용하는 PVP/듀오에 같은 고유 규칙을 사용한다.

공통 정책은 V4다. 기본 전투력 237,600, 자체/연계 배율 5.28, 자연 속도 2.5배, 아군 카드당 추가 행동 3회, 카니발 브레이크 840%·비용 20·재사용 2, 스킬/기본 피해 상한 2.4/1.35배는 유지한다. PVE, 다른 용병, 일반 카드, 이미지·연출·획득·재고·성장 비용·강윤 정책은 변경하지 않는다. 도감 설명에 PVP 피해 감소와 PVE 제외를 함께 표시한다.
