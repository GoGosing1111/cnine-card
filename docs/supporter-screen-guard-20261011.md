# 시즌패스·후원 화면 캡처 억제

사용자 “일단 가능한 선에서만 막아 우회는 어쩔수없고”에 따라 2026-10-11 적용한다. 앞선 [기술 검토](supporter-season-pass-menu-20261011.md)의 웹/PWA 한계를 유지하는 최선 노력 방식이다. OS 스크린샷·OBS·모바일 버튼 캡처·외부 카메라를 전부 차단하거나 감지한다고 주장하지 않는다.

공개 서버 안내·서버 후원·시즌패스 모달에만 `js/supporter-screen-guard-v1.mjs`를 연결했다. 모달이 닫히면 이벤트 제한과 보호 상태를 해제한다. CMS, 다른 게임 화면, 클립보드 기존 내용, 서버 인증·보상·후원 거래는 변경하지 않는다.

- 브라우저에 전달된 PrintScreen/Windows·Mac 캡처 조합키와 저장·인쇄 단축키를 가로채고 내용을 가린다. OS가 웹페이지로 전달하지 않는 단축키나 이미 촬영한 화면은 막을 수 없다.
- 창 포커스 이탈·탭 숨김·페이지 숨김·인쇄 시작 시 내용을 가린다. 다시 돌아오면 **계속 보기**를 눌러 복귀한다. 캡처로 단정하는 경고·계정 제재·캡처 신고 로그는 만들지 않는다.
- 모달 열람 중 복사·잘라내기·선택·우클릭·이미지 드래그를 제한하고 모바일 이미지 길게 누르기를 억제한다. 클립보드를 지우거나 읽지 않는다.
- 인쇄용 CSS는 실제 시즌패스·후원 내용을 제거하고 보호 안내만 표시한다.
- 화면에는 계정 번호와 서버 시각 기준 KST 열람 시각을 반복 워터마크로 표시한다. 로그인 토큰·실명·연락처는 사용하지 않는다. 워터마크는 공유 억제용이며 제거·편집이 가능하다.
- 생성 원화와 기존 화면 구도를 유지하고 워터마크는 클릭을 통과시킨다. 달력 선택·수령·펫 변경·키보드 Tab/Enter/Escape 및 화면 확대를 유지한다. 재렌더링 중 가림 상태와 복귀 조작도 보존한다.

Chrome 실제 공용 번들/메뉴/후원 API + 로컬 SQLite 계정으로 데스크톱 1440×1000·모바일 크기 390×844를 확인했다. 실제 로컬 보상은 1회만 지급됐고 펫 변경도 정상이다. 이벤트 취소, 단축키 가림/복귀, 공개 안내/후원/달력 전환, 인쇄 미디어, 재렌더링/닫기/재입장, 다른 메뉴의 제한 해제, 스크롤 하단에서의 모바일 가림을 통과했다. 브라우저 오류·가로 넘침이 없으며 PC·모바일 이미지를 직접 확인했다. Headless Chrome은 OS 포커스/스크린샷 동작을 재현하지 않으므로 blur·visibilitychange는 이벤트 주입으로 검증했으며 실제 OS 캡처 차단 검증으로 취급하지 않는다.
