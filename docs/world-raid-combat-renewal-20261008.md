# 월드레이드 V3 전투·공대 현황·난이도 개편

사용자 요청: 월드레이드 입장 후 전투 UI·스킬 연출·공대 현황판 전면 개선, 난이도 증가, 실제 화면 사진. 후속 정정은 “V3 전투화면에서 연출이 나와야 하는 것 아니냐”다. 최종 구현은 실제 V3 전장 안에서 재생하며, 초기 외부 현황판 중심 연출은 최종안에서 제외했다.

## 실제 전장

- 참가 중인 BATTLE 방에 진입하면 V3 전투가 자동으로 열린다. 전황판으로 닫은 뒤에는 같은 방의 폴링이 강제로 다시 열지 않는다.
- 기존 Pixi Application·EffectLayer·5인 진형·아트 어댑터·원본 카드 도크를 사용한다. 별도 전투 캔버스나 복제 진형을 만들지 않았다. 보스에는 승인 SD를 명시하여 일반 몬스터 ID 충돌로 다른 외형이 표시되지 않게 했다.
- 보스 HP, 방벽, 호위병, 광폭화, 다음 공격과 궁극기 예고를 표시한다. 서버가 해당 방에 저장한 불변 설정을 읽으므로 과거 방의 30초 공격 주기가 신규 CMS 값 25초로 잘못 표시되지 않는다.
- PC에는 우측 공대 현황을, 모바일에는 여닫는 하단창을 배치했다. 생존·체력·기여 피해·순위·출전 덱을 보여 주며 갱신 시 펼침 상태와 필터를 유지한다.
- 기존 7초 상태 조회를 공유한다. 별도 전투 폴링을 추가하지 않는다. 서버 상태가 22초 이상 새로 도착하지 않으면 동기화 대기 상태를 표시한다.
- 서버는 계정별 덱 HP와 누적 피해를 제공한다. 새로 확인된 누적 피해 차이만 V3 타격으로 나누어 표현한다. 개별 카드 공격 분배는 시각 표현이며 서버에 없는 개별 카드 판정으로 주장하지 않는다. 승패·보상은 서버 종료와 기존 청구 영수증만 사용한다.
- 닫기·화면 이동·숨김·종료 시 타임라인/표시 객체를 해제한다. 숨김 복귀는 최신 HP를 복구하고 지난 궁극기를 몰아서 재생하지 않는다. 기존 유한 연결 시간·WebGL 복구 화면을 유지했다.

## 스킬 연출

나가토 중력 붕괴, 요리이치 태양 검격, 이치고 월아의 기존 개별 12프레임 원본을 그대로 사용한다. GSAP이 준비·방출·충돌·잔향과 피해 표시를 같은 타임라인에서 제어하며 7번 프레임에 HP를 갱신한다. 보스 위치에서 시전하고 아군 진영에 적중한다. 기존 V3 사운드와 사용자 ON/OFF를 따르며 신규 합성음을 만들지 않았다.

|---|---:|---:|
| 나가토 | 0.96초 | 1.89초 |
| 요리이치 | 0.62초 | 1.48초 |

PixiJS 8.20.0 / GSAP 3.13.0. 구현·원본 해시·좌표·캡처·재현 기록은 `preview/world-raid-combat-v2-20261008/`에 보존한다. 기존 원화와 SD 및 아틀라스 바이트는 변경하지 않는다.

호위병 HP도 기존 7%/8% 비율에 맞춰 증가한다. 보상·입장 횟수·오픈 시간·최대 20명·제한 시간·방벽 비율·궁극기 배율/빈도는 유지한다. 기존 생성 방의 저장 설정은 그대로이며 변경은 새로 생성하는 방에 적용한다. 코어 프로토콜·리치·아포칼립스는 범위 밖이다.

최근 7일 400개 방/5,833개 참여 행에서 비관리자 167명과 유효 과거 파티 317개를 추출했다. 닉네임은 보관하지 않고 ID는 서버 분산값만 보존해 익명화했다. 동일한 서버 피해 투영식/전투 모델에서 보스별·전후별 5/10/15/20명 각 1,000표본과 과거 파티, 최강 솔로/듀오를 측정했다. 총 25,914회, seed 871943. 아래는 시뮬레이션이며 운영 실측 승률이 아니다.

## 검증·배포 범위

- 로컬 브라우저: 실제 메인과 V3에서 3종 보스, PC/모바일, 프레임 12장·충돌 7번, 캔버스 1개, 종료 후 잔여 효과 0, 중복 발동 억제, 원본 HP 일치, 필터/펼침 유지, 단일 청구, 닫기/복귀/숨김/동작 줄이기 통과. 캡처는 검수용 계정/방이며 운영 계정을 소비하지 않았다.
- 신규 상태/불변 방/결과 검사 4건과 PostgreSQL 호환 DB 운영 변경 검사 2건 통과. CMS 변경은 SERIALIZABLE 거래·동일 작업 키·비교 후 갱신·감사 로그·실패 롤백·재시도 무중복을 검증했다. 운영 dry-run은 롤백했고 당시 저장 방 5,000개의 설정 지문이 같았다.
- 월드레이드 한 경로의 UI·표시 어댑터·CMS 수치 변경이다. 공용 인증/DB 기반/마이그레이션/의존성/전투 엔진 원본을 변경하지 않으므로 해당 범위 배포는 scoped로 한다. 동시 작업의 대규모 변경은 해당 전체 게이트와 운영 배포가 완료된 기준을 사용한다.
- 배포 과정에서만 관련 기존 진입/복구/요일 보스/CMS/실제 V3 번들·로더/페이로드 회귀 및 Worker 컴파일을 실행한다. 통과한 무관한 전체 검사를 반복하지 않는다.
- 운영 변경 스크립트 `scripts/ops/world-raid-renewal-20261008.mjs`는 배포 소스 SHA와 측정 해시를 확인한다. 읽은 CMS가 바뀌었으면 중단한다. 세 보스 행과 주간 설정만 갱신하며 공통 설정 및 기존 방 설정 지문을 보존한다. 재화 지급은 수행하지 않는다.

배포 SHA·직전 운영 SHA·실행한 scoped 검사·실제 CMS 영수증은 운영 완료 후 이 문서와 후속 JSON에 기록한다.
