# 할로윈팩 족로 3장 출시

사용자 지시: “헬리오스 완판 족로 3개 한정으로 진무랑 똑같은 확률로 올려”, 대상 “할로윈팩”.

## 운영 범위

- 족로 `V-979`를 할로윈팩의 네 번째 SSS 리미티드로 추가한다.
- 서버 전체 **팩 발행 3장**이다. 기존 지정 계정의 직접 지급 1장은 그대로 보존하고 팩 발행 수량에 포함하지 않는다.
- 진무의 현재 설정과 같은 SSS 내부 100 PPM(0.01%), 1단계 SSS 500 PPM(0.05%)로 **1회 실효 확률 0.000005%**다.
- 신규 100 PPM은 일반 SSS 잔여 비중에서 가져온다. 일반 SSS 설정 924500 → 924400 PPM. 다른 개별 확률·1단계 분포·가격·ON 상태를 유지한다.
- 헬리오스는 공용 발행 8/8 소진 상태와 기존 200 PPM 구간을 유지한다. 소진된 구간은 기존 정책대로 일반 SSS로 지급한다. 족로도 3장 소진 후 같은 정책을 따른다.
- 팩의 완료 영수증·획득 기록·한정 시리얼이 모두 일치하는 족로 당첨자에게 보유 목록, PVE/PVP 편성, 랭크전 목록, 전투, 성장 접근을 제공한다. 기존 지정 계정 및 만료된 대여 정책은 유지한다.
- 기존 승인 원화·전투 리소스·스킬·전투 수치는 변경하지 않는다. 원화 SHA-256: `82297D41E879DAB7DF179345875EBF329A3E825BB20BD76C68BFBE91667DFBDB`.

## 구현·적용 순서

`shared/mercenary-halloween-pool-v3.mjs`에 팩 전용 발행 정책을 추가하고, 이전 설정을 읽으면 신규 족로 확률을 0으로 보완한다. 코드 배포만으로 개방하지 않는다. 새 코드가 배포된 후 운영 작업으로 발행 카운터와 확률을 함께 저장한다.

운영 스크립트:

```text
node scripts/ops/run-halloween-jokro-launch-20261021.mjs read
node scripts/ops/run-halloween-jokro-launch-20261021.mjs dry-run <검토한 설정 SHA256>
node scripts/ops/run-halloween-jokro-launch-20261021.mjs apply <검토한 설정 SHA256>
node scripts/ops/run-halloween-jokro-launch-20261021.mjs verify
```

설정 원문 해시 비교, 기존 카운터 부재 및 발행 이력 부재 확인, 활성 OWNER 확인 후 실행한다. 카운터 생성·설정 리비전·감사 로그·운영 영수증을 같은 트랜잭션으로 저장한다. 재실행은 쓰기 없이 영수증을 검증하며 발행 수량을 초기화하지 않는다. 카드 직접 지급은 0장이다.

운영 키: `ops:halloween-jokro-launch:20261021:v1`. 설정 키: `mercenary_halloween_ss_pack_v1`.
