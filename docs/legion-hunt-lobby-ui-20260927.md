# 군단토벌 · 라이브 로비 디자인 통일

사용자 요청: 군단토벌 UI를 기존 게임 로비와 맞춘다. 2026-09-26 요청, 2026-09-27 반영.

## 디자인 기준과 변경

- 기준 화면: `preview/lobby-clarity-v1/`, 실제 로비 소스 `ui/adventure-lobby/component.js`.
- 로비의 남색 배경 `#080c17`, 패널 `#111828`, 회청색 구분선 `#29344c`, 연두색 선택·주요 동작 `#c8ff6b`, Noto Sans KR, 동일한 브랜드 마크를 사용한다.
- 입장은 섬·최종 보스 장면, 15분 진행 경로, 저장된 출전 편성, 난이도 선택으로 구성한다. PC는 장면과 편성을 왼쪽, 선택·입장을 오른쪽에 배치한다. 모바일은 난이도 두 열과 하단 고정 입장 버튼을 사용한다.
- 전투 중에는 입장용 헤더와 중복 V3 제목을 숨긴다. 전투 전용 상단 바에 난이도, 보스 출현까지 남은 시간, 조작 버튼을 놓고 그 아래 전황·처치·획득을 표시한다. 기존 250ms 표시 갱신에 진행 막대를 연결하며 별도 타이머나 요청을 추가하지 않는다.
- 일시정지·결과창도 같은 색, 서체, 구분선, 주요 버튼을 사용한다. 결과는 처치·시간·획득·놓친 드랍을 두 열로 배치한다.
- V3 엔진·번들·진형·카드 도크·등급 프레임·원화와 SD 경로는 변경하지 않는다. 서버 전투·보상·입장 차감 코드는 변경하지 않는다. OWNER 한정, 일반 공개 OFF, 실계정 보상 OFF를 유지한다.
- 새 스타일은 `css/legion-hunt-entry-v2.css`, `css/legion-hunt-battle-v2.css`에 둔다. 이전 CSS는 보존한다. 메인 HTML, 입장 모듈, 전투 페이지, 화면 표시 스크립트의 연결 쿼리는 `20260927-lobby-ui`다.
