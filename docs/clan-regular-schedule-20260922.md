# 재경기 이후 정규 클랜전 일정 복구

2026-09-22 사용자 지시: 정규 클랜전은 화·목·토·일이며, 9월 21일 월요일 재경기와 무관하게 22일 화요일에도 진행한다.

## 원인과 코드 수정

`functions/_clan_rematch_20260920.js`가 20일 경기를 21일 21시로 옮기면서 이후 모든 정규 라운드에도 24시간을 더했다. CMS의 `openDays: [0,2,4,6]`는 그대로였지만 저장된 경기 날짜가 정규 요일을 벗어났다.

- 재경기 대상만 이동하고 이후 정규 대진·시작·종료 시간을 보존한다.
- 재경기와 정규경기가 겹치면 일정을 임의 순연하지 않고 충돌 상태로 차단한다.
- 이미 완료된 재경기 영수증은 그대로 유지하여 결과를 다시 초기화하지 않는다.

- 완료된 1~3라운드 12경기(어제 재경기 포함), 대진, 승점, 멤버 전적, CMS 설정, 기존 재경기 영수증을 보존했다.
- 대상 시즌·경기 행을 잠그고 기존 날짜·대진·SCHEDULED 상태·점수 0·전투 기록 0을 검증했다. 한 항목이라도 달라지면 전체 롤백한다.
- dry run에서 같은 요청 재실행의 멱등성을 검사하고 롤백했다. 별도 연결에서 28경기 전체가 원본과 같음을 확인한 후 적용했다.
- 적용 후 별도 연결에서 복구 날짜와 완료 경기 12개 전체 행의 불변을 확인했다.
- 복구 영수증: `ops_clan_regular_schedule_20260922_v1`; 관리자 감사 기록: `34520`.

- 실행 전후 스냅샷과 한시적 운영 도구는 원래 작업 폴더의 `tmp/clan-schedule-20260922/`에 보관하며 배포에 포함하지 않는다.
