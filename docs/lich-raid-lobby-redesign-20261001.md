# 리치왕 공대 대기실 UI 전면 개편 — 2026-10-01

사용자가 기존 대기실의 폰트·버튼·디자인을 반려하고 전면 개편을 요청했다. 기존 게임 메뉴 안에 대기실을 두면서, 운영 UI 기준 `docs/ui-fixed-reference-20260915.md`의 네이비·라임과 한글/숫자 서체 조합을 계승했다.

## 화면과 조작

- 리치왕 탭에 들어가면 모집·창설 화면을 바로 표시한다. 소개 페이지를 먼저 통과하지 않는다. 기존 승인 리치왕 원화를 짧은 전장 배너에 사용하고 실제 조작 공간을 확보했다.
- 모집 중인 공대는 역할별 인원·현재 정원·참가 버튼을 표시한다. 공대 창설 영역은 실제 입장권 수량, 1장 사용과 해산 시 반환 없음, 창설 버튼을 묶는다.
- 공대원 목록과 내 작전/출정 조건을 나눴다. 공대장은 기본 select 대신 정벌·봉인·구출 버튼으로 역할을 배분한다. 선택·준비·비활성 상태에 별도 색·테두리를 사용하고 이전의 붉은 기본 버튼 스타일을 제거했다.
- 준비·출정 조작을 상단에 두고 스크롤 시 유지한다. 부족한 인원·미배정 작전·준비 대기 인원을 구체적으로 표시한다. 같은 역할을 다시 눌러 준비를 불필요하게 초기화하지 않는다.
- 자신의 일반 카드 5장·용병·배틀슈트를 입장 전 미리 본다. 서버 편성 스냅샷과 실제 원화/아이템 이미지를 사용하며 전투 SD나 가짜 프레임을 카드 사진으로 사용하지 않는다.
- 한글은 자체 호스팅 Noto Sans KR 100–900, 숫자는 Barlow Condensed 600이다. 외부 서체 서버 없이 표시하며 라이선스·원본/가공 해시는 `assets/fonts/lich-raid/README.md`와 OFL 파일에 기록했다.
- 대기실 CSS는 `raid/lich-king/lobby.css`, 기존 라이브 오버레이는 `live.css`로 정리하고 `build-inline.mjs`로 게임 내 범위 CSS를 생성한다. UI 캐시는 `20261001-lobby-v2`다. 기존 V3 전투 번들·계산·카드 도크·진형과 보스 1.5배 표시는 유지한다.
- 대기실 명령 처리 중 다른 레이드 탭으로 이동하면 늦게 도착한 응답이 제거된 DOM이나 새 전장에 접근하지 않게 했다.

## 필요한 검수와 배포 범위

- `tests/lich-raid-lobby-20261001.browser.mjs`: 로컬 SQLite·검수 계정 3개·실제 도감 원화/V3 자산으로 통과했다. PC 1440×1000, 모바일 390×844 / 360×800 및 공대장 모바일 화면을 확인했다. 시작 전 사운드를 OFF로 두고 외부 요청은 차단했다. 운영 API·실계정 재화는 사용하지 않았다.
