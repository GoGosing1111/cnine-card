# 플레이어 명함 · v2053

## 출시 범위

닉네임으로 열리는 공개 명함. 로비 상단 본인 이름, 내 정보, 랭크전 랭킹·전투 기록, 클랜 로스터·클랜장, 영토전 랭킹, 월드 레이드 참가자에 연결한다. 로비의 기존 **내 계정** 버튼은 그대로 별도로 유지한다. 비공개 클랜 드래프트 후보의 신원은 공개하지 않는다.

현재 티어·순위·점수·전적, 역대 최고 최종 순위, 최장/현재 연속 챌린저, 트로피 진열장, 최근 랭크 시즌 정산 및 클랜 우승 기록을 보여준다. 초상화는 소유·공개·활성·기간 조건을 만족하는 **현재 장착 아바타의 로비 원화**만 사용한다. 미장착이면 모노그램으로 표시한다.

## 최초 트로피

| 코드 | 이름 | 획득 조건 |
| --- | --- | --- |
| CLAN_CHAMPION | 클랜의 영광 | 공식 클랜 시즌 정산의 우승 클랜에 정산 당시 소속 |
| CHALLENGER_STREAK_3 | 푸른 왕조 | 연속된 완료 랭크 시즌 3회에서 모두 최종 챌린저(1~10위) |
| RANKED_CHAMPION | 정점의 증명 | 랭크 시즌 최종 1위 |

클랜·랭크 1위는 횟수를 표시한다. 푸른 왕조는 영구 달성형 배지이며 최장 연속 기록과 현재 연속 기록을 분리한다. 미참가·챌린저 미달인 완료 시즌은 연속 기록을 끊는다. 진행 중 시즌이나 정산 진행 중 시즌은 아직 확정 기록이 아니므로 집계하지 않는다. 챌린저 도입 전 그랜드마스터 기록을 소급해 챌린저로 바꾸지 않는다.

클랜은 `clan_season_settlements` 완료 + 같은 시즌 `clan_members`의 우승 당시 소속을 사용한다. `DISABLED_TEST` 정산은 제외한다. 운영 시즌의 보상 OFF(`DISABLED_CONFIG`)는 경제 보상 유무일 뿐이므로 우승 기록 자체는 인정한다. 조직 전체의 누적 `trophies` 숫자를 개인 소유로 복사하지 않는다. 새 클랜에 가입했다고 그 클랜의 과거 트로피를 받지 않는다. 이후 시즌 이적으로 과거 시즌 우승이 없어지지 않는다.

랭크는 `pvp_season_settlements`/`pvp_season_settlement_ranks` 완료 기록을 읽는다. 전체 완료 시즌의 순서에 미참가 시즌까지 포함하여 SQL에서 연속 구간을 계산한다. 화면 목록은 각각 최근 12개이지만 최고 기록·보유 트로피는 전체 완료 기록 기준이다.

## 효과와 테두리: 준비만

- `effects.enabled=false`, `modifiers=[]`: 전투력, 코인, 드랍률, 재화, 보상에 **아무 효과 없음**.
- 각 트로피 `effect.enabled=false`: 구체적인 효과와 수치는 사용자 결정 후 별도 작업.
- 기본 테두리 `OBSIDIAN`, `level=0`, `enhancement.enabled=false`. 강화 버튼은 비활성.
- 강화 재료·비용·성공률·최대 단계는 아직 정하지 않았다. 이를 위한 차감·강화 API도 열지 않았다.
- 향후 추가할 수 있는 트로피 후보: 클랜 3회 우승, 영토전 기여, 레이드 최초 정복. 현재는 조건·보상 미확정이므로 지급하지 않는다.
- 향후 실물 소유/강화 기능을 열 때에는 별도 개인 명함·트로피 원장을 추가하고 `(user_id,trophy_code,source_type,source_id)` 중복 방지 및 원자적 차감을 구현한다. 현재는 공식 정산 기록의 읽기 전용 투영이므로 기존 정산 기록을 삭제하거나 다시 쓰면 명함에도 반영된다. 기록을 정리할 때는 먼저 불변 수상 원장으로 보존해야 한다.

## 기술/안전 계약

`GET /api/player-card?userId=...` (ID 없는 기존 화면은 정확한 닉네임 조회). 로그인 필요, ACTIVE·이용정지 조건 검증. 공개 필드 화이트리스트만 반환하며 지갑, 개인키, 덱, 계정 인증 정보는 포함하지 않는다. 명함 조회는 시즌 자동 진행/정산/보상 지급/스키마 변경을 호출하지 않는다. 이전 수상 데이터를 읽지 못하면 503 + 다시 확인, 임의의 0개를 표시하지 않는다.

네이티브 dialog의 상위 레이어·포커스 격리·ESC·닫기 복원. 12초 요청 제한, AbortSignal, 빠른 유저 전환 시 이전 응답 무시. WebGL 실패/로딩 지연은 명함 표시를 막지 않는다. PixiJS+GSAP은 지연 로드한 공용 엔진으로 금속 테두리 광택과 트로피 등장·호버만 그린다. 배경 탭·동작 줄이기 설정에서 중지, 닫을 때 renderer/tween/observer/이벤트 정리. 효과음은 사용하지 않는다.
