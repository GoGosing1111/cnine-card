# 황궁 쿠데타 · 국민 재판

2026-09-14 사용자 요청으로 추가. 행정부 메뉴의 `쿠데타` 및 CMS의 `쿠데타 · 재판`에서 이용한다.

## 확정 정책

- 참가자가 족장팀 / 반란군을 선택한다. 현 족장은 족장팀으로만 참가한다. 참가 확정 화면에서 패배 불이익에 동의해야 하며 진영 변경은 허용하지 않는다.
- PVP 일반 카드 정확히 5장과 기존 선택 용병 전용 슬롯을 사용한다. 기존 영토전의 덱 스냅샷·고유효과·장비·마법·시너지·15% 전투력 보정과 서버 PVP V2 계산, V3 PixiJS/GSAP 재생을 공유한다.
- 족장팀 패배: 참가자와 해당 회차 족장을 기존 포로수용소에 8시간 수감한다. 족장은 직무정지 및 국민 재판에 회부한다. 수용소 배경, 채팅, 형기와 OWNER 조기 석방 기능은 공용이다.
- 반란군 패배: 정산 시 양수 코인 20% 차감(1코인 미만 버림). 정확히 0이면 -3,000,000,000. **이미 음수여도 3,000,000,000 추가 차감**한다. 마지막 항목은 후속 사용자 답변으로 확정됐다.
- 판결은 **유저 투표로 복직·파면**을 결정한다. 운영자가 판결을 선택하는 API나 버튼은 없다.

## 전황과 운영

외문 → 근위대 뜰 → 황궁 광장 → 내궁 관문 → 정전의 5개 거점. 반란군은 외문 쪽, 족장팀은 정전 쪽에서 시작하며 최초 전선은 중앙 광장이다.

교전 승리 진영이 상대 진영 체력에 피해를 준다. 패배한 출격도 상대 진영의 반격 피해로 반영된다. 진영 체력을 소진시키면 다음 거점으로 이동하고 양측 체력을 회복한다. 반란군이 정전을 함락하거나 족장팀이 외문을 함락하면 즉시 종료한다. 시간 초과 시 중앙보다 전진한 진영, 중앙이면 남은 진영 체력이 많은 쪽이 승리한다. 동률은 무승부이며 불이익을 적용하지 않는다.

CMS에서 `모집 개설 → 양 진영 참가 → 전투 시작`. 모집 중에만 취소할 수 있다. 모집 개설과 전투 시작은 별도 조작이며 배포만으로 실계정 전투가 시작되지 않는다. 한 번에 한 쿠데타만 진행하며 열린 재판이 있으면 새 회차를 개설하지 못한다.

운영자가 변경할 수 있는 초기값:

| 항목 | 기본값 | 허용 범위 |
| --- | --- | --- |
| 쿠데타 전투 시간 | 180분 | 1~10,080분 |
| 국민 재판 투표 시간 | 1,440분 | 1~10,080분 |
| 출격 대기 | 30초 | 5~300초 |
| 거점별 진영 체력 | 500,000 | 1,000~100,000,000 |

이는 기존 영토전과 별도 설정이며 다음 모집부터 적용한다. 현재 회차 설정은 개설 시 스냅샷으로 고정한다. 보상·참가비·자동 후임 족장 임명은 추가하지 않았다.

재판은 개시 당시 활성 USER·OWNER 계정을 유권자로 고정한다. 계정당 한 표이며 수정 불가. 마감 시 파면 표가 더 많으면 파면, 동률·무투표는 복직한다. 복직해도 원래 임기나 수감 형기를 연장·단축하지 않는다. 판결은 해당 임기 ID에만 적용해 이후 선출된 족장에게 영향을 주지 않는다. 만료 정산은 상태 조회와 공통 수감 확인 경로에서 재조정한다(공통 경로는 최대 1초 캐시). 접속이 없으면 다음 요청에서 확정한다.

## 원자성 및 복구

- 회차·투표 행의 조건부 갱신과 CHECK 가드를 실제 DB 트랜잭션 안에서 실행한다.
- 반란군 잔액 행을 잠근 뒤 정산 원장을 기록하고 코인을 갱신한다. 회차 종료, 코인, 수감, 재판, 유권자 명부가 함께 커밋되므로 실패 시 전부 롤백된다.
- 회차별 정산 원장과 수감 이벤트 ID, 재판 ID로 재시도를 중복 적용하지 않는다. 석방 후 재시도로 다시 수감하거나 형기를 늘리지 않는다.
- 족장 버닝·하이퍼·탑 초기화는 선고와 동일한 임기 메타 행을 잠그고 실제 변경 트랜잭션 안에서 직무정지를 확인한다.
- 공격 요청 ID별 서버 V3 결과를 보존한다. 클라이언트는 응답 유실 시 본인 `coup/attack-result`를 조회하며 새 공격으로 중복 처리하지 않는다. 수감 예외는 현황·본인 전투 결과·투표뿐이고 새 출격은 허용하지 않는다.

## 검증

`npm run test:coup`: SQLite 및 PGlite를 통한 실제 PostgreSQL 호환 SQL 검증. 음수 잔액, 20% 정산, 실패 롤백, 중복 정산, 동시 실제 V3 공격·쿨다운·영수증, 동시 투표·중복 투표, 신규 계정 배제, 마감·동률, 임기 분리, 권한 가드, 8시간 수감·채팅·석방을 확인한다.

브라우저 검수는 외부 QA 디렉터리 `../qa/coup-v2115/`에서 실계정 변경 없이 API fixture로 수행한다. 전황 화면 1440/390/320px, 참가 동의, 거점 선택, 투표, 음수 지갑, 실제 공통 V3 전투·황궁 배경·결과 복귀, CMS 및 수용소 투표·이벤트 석방을 검수한다. 생성 원본을 제외한 임시 스크립트·화면 캡처·로그는 배포 디렉터리에 넣지 않는다.

운영 배포는 깨끗한 커밋에서 `npm run release:gate`를 통과하는 `npm run deploy:production`만 사용한다. FUR 14강·15강 OFF와 다른 콘텐츠의 운영 정책은 유지한다.
