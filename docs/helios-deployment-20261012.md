# 헬리오스 편성 출시 — 2026-10-12

사용자 후속 지시 `헬리오스 편성 되게 설정해`로 이전 편성 잠금을 해제한다.
헬리오스(V-999)를 보유한 계정은 PVE·PVP에 각각 저장하고 한 장으로 두 모드에 함께 편성할 수 있다.
음순이에게 이미 지급된 카드도 같은 보유 검증을 통과한다. 자동 편성이나 추가 지급은 하지 않는다.

## 변경

- `limitedDeploymentSnapshot`에 확정된 헬리오스 정책 V1을 연결한다. 기본 전투력 1,123,200,
  전열·근접, PVE 천양붕락, 기존 발테르 대비 4% 속도·추가 행동·체력·방벽을 사용한다.
- 실제 계정 조회·편성 저장·PVE/PVP 단건 및 일괄 전투 스냅샷을 기존 경로로 제공한다.
  코인, 장비, 모드별 편성 버전, 소유 검증과 재시도 보호는 그대로다.
- 전장에 빠져 있던 헬리오스 SD 등록과 SolarFX 재생 어댑터를 추가한다. 승인 원화·SD·시트·검 픽셀은 변경하지 않는다.
  기본 베기와 PVE 광역기를 원본 2.6배속으로 재생하며 적군 편성은 동일한 동작을 좌우 반전한다.
- 광역기 연출은 서버의 `MERCENARY_HELIOS_AREA` 대상별 HP·방벽 영수증을 1회씩 표시한다.
  소환검·충격파가 별도 피해를 만들지 않는다. 기본 공격도 적중 지점에서 한 번만 표시한다.
- 프리뷰의 카메라·피격 흔들기 제어는 운영 전투에 가져오지 않고 기존 공통 전장의 제어를 따른다.
  자산은 등장한 용병당 재사용하며 상시 별도 GSAP 반복 루프를 추가하지 않는다. 전투 취소·제거 시 정리한다.
- 10개 전투 소비 번들과 캐시·메인 로더를 `20261012-helios-deploy-v1`로 갱신한다.
  공개 도감의 준비 중 안내를 PVE/PVP 편성 가능 안내로 바꾼다. 기존 팩 설정·확률·발행 한도는 변경하지 않는다.
