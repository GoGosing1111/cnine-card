# 군단토벌 몬스터 HP HUD 수정 — 2026-10-19

사용자 보고: “군단토벌 신맵 몬스터 HP 바 HUD 이상하더라”. 기존 승인 B형 HUD 이미지를 유지하고 표시 오류를 수정했다. 새 이미지나 UI를 제작하지 않았다.

## 원인과 수정

- 구형 `namePlate.visible=false`가 B형 HUD 전체 이미지 프레임을 숨겼다. 일반 몬스터는 공용 `setNameVisible(false)`로 이름 탭만 제외하고 HP 프레임을 유지한다. 정예·보스는 이름을 표시한다.
- 기존 재등장 바인딩은 텍스트 노드만 바꿔 HUD 내부 이름이 초기 슬라임/몬스터로 남았다. 실제 인스턴스 이름을 `setDisplayName`으로 갱신하고 반복되는 긴 이름도 공통 말줄임 처리를 유지한다.
- 최초 5칸만 모바일 크기를 적용하던 경로를 12칸 전체에 적용했다. 몬스터 열 간격에 맞춰 이미지 비율을 유지한 채 폭을 제한한다. 깊이 정렬이 매 프레임 크기를 원복하지 않도록 군단토벌에서 해당 비율을 유지한다.
- 바 높이는 현재 스프라이트 높이와 표시 HUD 높이를 기준으로 정하고 `formationHudY`도 함께 갱신한다. 보스→일반 재등장, 화면 크기 변경 때 이전 높이가 남지 않는다. 임시 공용 보스 표식 대신 실제 서버 인스턴스의 보스/정예 구분을 사용한다.

아군 HUD·몬스터 배치·원화·직립 모션·피해·실제 HP·보호막·드롭·코인·운영 개방 상태는 변경하지 않았다. 부모 연속전투 렌더러의 이름 바인딩 한 줄과 군단토벌 확장 소스만 수정하고, 군단토벌 번들 및 운영/프리뷰 캐시 주소를 갱신했다.
