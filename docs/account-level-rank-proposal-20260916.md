# 계정 레벨·군대식 계급 도입안

작성: 2026-09-16 · 내부 기획 문서(유저 노출 금지) · 상태: **기획·디자인 검수판**

## 사용자 확정 방향

- 최고 250레벨. 모든 레벨에 계급이 대응하고 계급별 혜택·버프가 존재한다.
- PLAY DK 참고 이미지의 원형 테두리, 색 구분, 읽기 쉬운 중앙 마스코트를 디자인 기준으로 사용한다.
- 숲켓몬 전용 군인 마스코트 + 계급장. PLAY DK 캐릭터를 그대로 사용하지 않는다.
- 편의·PVE 중심. PVP 전투력에 영향을 주지 않는다.
- **기존·신규 계정 모두 Lv.1 / 누적 XP 0에서 시작. 과거 활동 환산 없음.**
- 명함과 게임 내 닉네임 주변에서 자기 계급을 잘 알아볼 수 있어야 한다.
- 후속 확정: **경험치 획득 제한 없이 전체 PVE 활용. 약 50일 만렙을 초기 성장 목표로 설정.**
- 최신 지급량 지시: **봉인전 160 XP·몬스터 공성전 120 XP 유지, 다른 8개 PVE 지급량은 직전 안의 1/10.** 필요 누적 XP·기본 플레이 예시 횟수는 유지하여 예상 기간을 재계산한다.

- 최신 화면 지시: **유저에게 성장 방식·EXP 지급량·필요 EXP·예상 기간을 표시하지 않는다.** 성장 정책은 내부 전용 모듈에 보관하고 공개 클라이언트에서 분리한다.
- 빠진 18계급 전용 원화를 모두 제작해 기존 3종과 함께 21종을 채운다.

이 문서의 레벨 경계·수치·경험치 속도·백호 외형은 구체적인 **제안**이다. 사용자 확정사항과 혼동하지 않는다. 아직 경험치 지급, 계정 DB 변경, 전투 버프, 운영 UI 연결을 구현하거나 배포하지 않았다.

## 계급 구성

## 혜택 제안

효과는 **현재 계급의 총효과**다. 이전 계급을 누적 합산하지 않는다. 계급 변경으로 일반 덱 5장·선택 용병 1장 규칙을 바꾸지 않는다.

| 도달점 | 개인 PVE 공격력 | 개인 PVE 체력 | 대상 PVE 코인 | 덱 프리셋 슬롯 |
|---|---:|---:|---:|---:|
| 훈련병 Lv.1 | +0% | +0% | +0% | 1 |
| 이병 Lv.5 | +0.5% | +0.75% | +0.25% | 1 |
| 하사 Lv.50 | +2.5% | +3.75% | +1.25% | 2 |
| 소위 Lv.125 | +5% | +7.5% | +2.5% | 3 |
| 소령 Lv.170 | +6.5% | +9.75% | +3.25% | 3 |
| 준장 Lv.215 | +8% | +12% | +4% | 4 |
| 원수 Lv.250 | +10% | +15% | +5% | 5 |

- 21계급의 총효과를 균등 단계로 제안했다. UI에서는 모든 계급의 정확한 값을 확인할 수 있다.
- 편의: 덱 프리셋 저장 슬롯. 저장한 **편성**을 꺼내는 기능이며 실제 동시 전투 덱/추가 카드 슬롯이 아니다.
- 외형: 계급 아이콘, 명함 표식, 진급 기록. 승급비·확률 없는 자동 진급과 영구 유지 제안.
- 코인 보너스는 허용된 개인 PVE 정산의 기본 코인에만 적용하는 안. 뽑기 확률, 장비 강화 확률, 거래·환급·선물·세금·쿠폰·유료 구매·클랜 보상에는 적용하지 않는다.
- PVP, 클랜전, 영토전 효과는 **0**. 매칭 전투력·방어덱·랭킹 점수에도 계급 전투 버프를 섞지 않는다.
- 월드 레이드와 기록 경쟁형 PVE는 우선 미적용. 공유 보스 점수·순위에 영향을 줄 수 있어 별도 경제·경쟁 검토가 필요하다.
- 효과 적용은 명시적인 콘텐츠 허용 목록으로 처리한다. 알 수 없는 모드에 자동 적용하지 않는다.
- 퍼센트는 정수 basis point(100bp=1%)로 보관하고, 보상 정수화/상한 순서는 서버 정산에서 고정할 계획이다. 아직 운영 로직은 없음.

## 전체 PVE 경험치 · 지급량 조정

사용자 후속 지시로 기존 하루 400 XP / 첫 10회 제한안을 폐기했다. **새 레벨 시스템 자체의 일일 XP 상한, 콘텐츠별 획득 횟수 상한, 첫 N회 제한을 두지 않는다.** 전 콘텐츠의 정상 플레이 정산에 XP를 붙인다.

| PVE 콘텐츠 | 정산 단위 | XP 제안 |
|---|---|---:|
| 몬스터 토벌 | 클리어 1회 · 일반/상위 난이도 및 소탕 포함 | 8 |
| 아포칼립스 | 클리어 1회 | 24 |
| 월드 레이드 | 유효 전투 참여 정산 1회 · 보스 처치 전 포함 | 20 |
| 호송작전 | 작전 정산 1회 | 30 |
| 몬스터 공성전 | 유효 전투 정산 1회 | 120 |
| 봉인전 | 유효 전투 정산 1회 | 160 |
| 방치형 원정 | 실제 정산 1시간 · 분 단위 비례 | 6 |
| 무한의탑 | 층 클리어 1회 · 재등반 포함 | 10 |
| 폐차장 | 전체 구역 원정 완료 정산 1회 | 20 |
| 카우방 | 클리어 1회 | 30 |

- 소탕은 실제 정산된 N회에 XP × N. 일반 전투와 소탕의 이중 지급은 금지한다.
- 재등반·반복 전투 횟수에 따른 계정 XP 감쇠를 두지 않는다. 저레벨 콘텐츠도 정상 정산되면 XP를 지급한다.
- 레이드·공성전·봉인전은 콘텐츠 자체의 유효 전투 정산을 사용한다. 공동 보스 최종 처치가 있어야만 XP를 주는 방식으로 제한하지 않는다.
- 방치형 원정은 서버가 인정한 미정산 시간만 한 번 지급한다. 계정 레벨 시스템 때문에 원정 시간을 추가로 자르지 않는다.
- 모든 현재/신규 PVE가 경험치 지급 대상이다. 신규 레이드(예: 코어 프로토콜)는 해당 콘텐츠 출시 시 XP 정산 연결을 함께 구현한다. 여기서 콘텐츠 출시 게이트를 해제하지 않는다.
- **XP 지급 범위와 전투 버프 범위는 별개**다. 공유 레이드·경쟁형 PVE도 XP를 지급하지만 위의 미확정 전투 버프를 자동 적용하지 않는다. PVP 전투력 영향 없음은 그대로 유지한다.
- 기존 각 콘텐츠의 입장·행동력·소탕 가능 여부는 콘텐츠 계약을 따른다. 경험치 전용 제한을 추가하지 않는 설계이며 기존 시스템의 입장 제한을 임의 제거하지 않는다.

### 조정 후 예상 성장 기간

다음 레벨 필요 XP = `60 + 4 × 현재 레벨`. Lv.1→2는 64 XP, Lv.249→250은 1,056 XP. 누적 **139,440 XP**에 Lv.250. 지급량 인하를 상쇄하는 필요 XP 변경은 하지 않았다.

기존 기본 예시의 플레이 횟수를 유지하면 토벌 10회(80) + 레이드 3회(60) + 호송 1회(30) + 탑 5층(50) + 폐차장 3회(60) = **하루 280 XP**, `ceil(139440 / 280) = 498일`이다. 같은 구성을 두 배 플레이하면 560 XP/일, 약 249일.

봉인전·몬스터공성은 인하 예외다. 기본 예시 + 봉인전 9회(1,440) + 몬스터공성 9회(1,080)라면 총 **2,800 XP/일 → 약 50일**이다. 이 조합은 계산 예시이며 해당 횟수의 실제 플레이 가능 여부는 운영 입장·회복량과 함께 검증해야 한다. 특정 콘텐츠를 매일 의무적으로 할 필요는 없다.

| 플레이 예시 | 평균 XP/일 | 250레벨 도달 |
|---|---:|---:|
| 기본 예시 · 봉인전/공성 제외 | 280 | 498일 |
| 기본 예시 2배 | 560 | 249일 |
| 기본 예시 + 봉인전 9회 + 몬스터공성 9회 | 2,800 | 50일 |

- 최초 50일 목표는 지급량 인하 후 모든 플레이 구성에서 성립하지 않는다. 50일 달성에 필요한 평균은 약 2,789 XP/일이며 내부 모델에서만 입력량으로 예상일을 계산한다. 유저 화면에는 지급량·계산기·예상 기간을 표시하지 않는다.
- 날짜로 진급을 잠그거나 XP 일일/콘텐츠별 상한을 만들지 않는다.
- 방치형 원정은 6 XP/시간이므로 운영 구현 시 정산마다 소수 XP를 버리지 않고 누적 잔여분을 보관해야 한다. 내부 계산 모델은 입력한 일일 합계를 정수화한다.
- 최고 레벨은 250. 초과분으로 추가 레벨을 만들지 않는다. 유저 화면에는 레벨과 최고 계급만 표시한다.
- 출시 시점 이전 로그는 지급 대상에서 제외한다. 기존 계정도 과거 XP를 만들지 않는다.

## 아이콘과 명함·게임 표시

대표 시안은 숲잎 표식의 **백호 군인**이다. 푸른 눈·짙은 줄무늬·밝은 얼굴을 공통으로 유지한다. PLAY DK의 얼굴·불꽃·삼각형 표식을 복제하지 않는다.

- 준비한 원화: 훈련병부터 원수까지 **21종**. 각각 별도 생성한 원본 RGBA PNG이며 실제 크기·알파·해시는 자산 매니페스트에 기록한다.
- 기존 이병·소령·원수 원본은 보존했다. 계급 목록 썸네일, 상세, 명함·인게임 예시 모두 계급별 전용 파일을 사용한다.
- 생성 프롬프트는 `assets/prompts.json` 및 `assets/prompts-expansion.json`. 원사 갈매기 방향은 개별 수정본을 사용한다.
- 색만 바꾸지 않고 군복·모자·자세·계급장·테두리의 구조를 바꾼다. 완전한 월계수는 최상위에 집중한다.
- 명함의 기존 아바타, PVP 티어, 트로피를 유지하고 이름 아래에 계급 64px + 계급명 + Lv.를 추가하는 안. 모바일은 40~46px.
- 요약 명함: 계급 96px(모바일 70px), 아바타와 분리. 로비 48px, 클랜원 목록 32px, 채팅 24px, 결과 36px.
- 24px에서 별 개수까지 정확히 읽기는 어렵다. **계급명·Lv.를 함께 노출**하고 닉네임/계급을 터치하면 명함이 열린다.
- 반짝임 상시 반복은 사용하지 않으며 색 이외에 계급장과 텍스트로 구분한다.
- 공통 메뉴 이름은 `SoopketmonV21NavigationContract`를 읽고, 기존 네이비 패널·라임 강조색·선택/상세 구조를 따른다. 실제 명함 검수에는 `PlayerCallingCard.render`를 재사용한다.

## 후속 운영 구현 설계

1. `account_progression` 단일 사용자 행에 총 XP, 버전, 시작일을 보관. 모든 계정 기본 0 XP/Lv.1.
2. 경험치 정산 영수증에 `(user_id, source_type, source_id)` 유일성. 같은 출석/전투 재시도·새로고침·복구에 중복 XP 금지.
3. 원래 콘텐츠 정산과 XP 영수증·총 XP 변경을 한 서버 트랜잭션으로 묶기. 실패·롤백에는 XP 지급 없음.
4. XP 일일/원천별 상한을 만들지 않는다. 사용자 단위 원자적 증가와 유일 영수증으로 동시 정산의 누락·중복만 막는다. 콘텐츠의 기존 입장·정산 계약은 유지한다.
5. API가 `level, rankCode, rankName, iconUrl, effectsVersion`만 반환. 성장 지급량·누적 XP·필요 XP·계산식을 공개 응답에 포함하지 않는다. 클라이언트가 레벨·버프를 결정하지 않음.
6. 명함 API와 공통 닉네임 컴포넌트로 계급을 전달. PVE 효과는 승인된 모드의 스냅샷에만 넣고 PVP 스냅샷과 분리.
7. 인플레이션·랭킹 영향 검토 후 최종 경험치·혜택·프리셋 정책과 21종 원화 검수를 완료하고 회귀·실계정 UI 연결 검수.
8. 그 운영 구현을 출시할 때는 깨끗한 후보에서 `npm run release:gate` 후 `npm run deploy:production`만 사용.
