## 변경

- `functions/_battle_v2_preview.js`의 `buildPvePlayerTeam`이 새 `distributePveEquipment`를 사용한다. PvE 카드 지원 보너스는 편성 카드 수로 균등 분배하며 정수 잔여분은 마지막 카드에 배정한다. 합계는 기존 지원 총량과 같다.
- 분배는 강화 전투력·고유효과와 독립이다. 같은 편성의 한 카드를 강화해도 다른 카드의 장비 몫·HP·공격·방어·보호막이 변하지 않는다. 강화한 카드의 전투력과 고유효과는 정상 증가한다.
- 배틀슈트는 기존 독립 전투원으로 유지하며 카드 지원 몫에 중복 합산하지 않는다. 계정 저장값·강화 설정·보스 CMS·재화/보상 처리·DB 계약은 변경하지 않는다.
- 기존 `distributeEquipment`와 PvP/듀오/별도 협동 전장 호출은 유지한다. 일반 PvE 팀을 사용하는 아포칼립스·사냥·탑·폐차장·소굴·리치왕 참가 편성은 동일한 안정된 분배를 사용한다.
