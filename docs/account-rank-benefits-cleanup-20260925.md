# 계급 혜택의 보관함 목록 제거 · 2026-09-25

- 사용자 스크린샷의 `내 편성 보관함 5/5` 목록과 보관/덮어쓰기·적용 버튼을 일반 `계급과 혜택` 진입에서 제거한다. 이 진입에서 `account-rank/presets` 조회도 생략한다.
- 전투 편성의 전용 보관함 진입(`AccountRank.open(true)`)과 저장 데이터·서버 API는 유지한다. 계급 혜택 수치와 경험치 정책은 변경하지 않는다.
- 계급 모듈의 직접/동적 import URL을 맞추고 생성 로비 번들 및 이를 사용하는 페이지의 캐시 참조를 갱신한다.
- 실제 기존 메인 화면에서 5개 보관함 행이 노출되는 현상을 재현했다. 수정 후 Chrome PC 1440×1000 / 모바일 390×844에서 계급 열기·다른 계급 선택·닫기 및 전용 보관함 재진입을 확인했다. 일반 계급 창의 보관함 행/목록 조회는 모두 0건, 전용 진입은 저장된 5행과 적용 버튼을 유지한다. 페이지 오류·가로 넘침 없음. 운영 계정에 시험 저장하지 않았다.
- 검수 화면과 보고서: 배포 루트 밖 `../qa-account-rank-benefits/`. 모듈 문법과 생성 로비 소스 일치 검사 통과.
- 직전 실제 운영 배포는 Wrangler에서 확인한 `5c9642d6-f33b-457a-816e-18bb44ea8ede`, 소스 `7d0ec46837d6ee86143f8f641c5285fdef12c5c7`이다.
- 작은 UI 수정이므로 `npm run deploy:production -- --scoped`. 최종 PC/모바일 검수를 반복하지 않고 게이트는 `tests/adventure-lobby-menu-separation.test.mjs`로 공용 로비 연결을 확인한다. 서버/DB/인증/의존성 변경이 없어 전체 게임 검사와 별도 서버 거래 검사를 추가하지 않는다. 기존 clean/main·출시·캐시·Hyperdrive 검사 유지.
