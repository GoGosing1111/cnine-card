# 후원 패스 미수령 보상 누적 · 2026-10-17

사용자 확정: **앞으로도 후원 기간 내 놓친 보상을 계속 누적해서 일괄 수령**. 첫 기준은 후원 혜택의 적용 시각(`startsAt`)이며, 이전의 당일 보상만 수령 정책을 대체한다.

- 후원 적용 KST 날짜부터 오늘까지 열린 날짜의 미수령 보상을 모두 받을 수 있다. 이미 받은 날짜는 기존 영수증으로 제외한다.
- 연속 후원 연장 시 이전 30일 달력의 미수령분도 남는다. 미래 날짜와 유료 기간을 넘는 보상은 열리지 않으며, 만료·중지 상태에서는 새 지급을 하지 않는다. 중지/만료 후 새로 등록된 기간이 과거 기간을 복원하지 않는다.
- 시즌패스의 **미수령 보상 모두 받기** 버튼에서 누적분을 받는다. 현재 달력의 지난 날짜를 개별 수령하는 것도 가능하다. 누적 일수·날짜 범위·진행 상황을 표시한다.
- 일괄 요청은 날짜별 영수증, 기존 KST 날짜 중복 방지, 보상·지급 로그를 같은 거래에 저장한다. 한 거래는 최대 30일/장비 50개/보상 항목 60개로 제한하고, 버튼 한 번으로 남은 거래를 이어 처리한다. 창을 닫거나 숨기면 새 거래를 시작하지 않는다.
- 응답이 끊기면 보관한 요청 번호로 확정 결과를 복구한다. 새로고침만으로 새 지급을 시작하지 않는다. 이미 처리한 거래는 후속 실패가 발생해도 유지된다.
- 기존 후원 상태·보상표 revision·품목 활성·지갑/보유 수량 검증과 계정 잠금을 유지한다. 공통 인증/DB 기반과 테이블은 변경하지 않는다. 운영 CMS revision 10·보상 구성·ON 상태를 수정하지 않고, 사용자가 수령할 때 지급한다.
