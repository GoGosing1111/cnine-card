# 조직 메뉴 · 입단 심사 OFF · 자동 갱신 깜빡임 수정

사용자 “사이드메뉴에도 조직으로 바꾸고 입단심사 불가하게 OFF”, “왜 자꾸 깜빡거려 다시 불러오는 거마냥” 지시를 반영한다.

- PC 사이드메뉴, 모바일 전체 메뉴의 분류와 진입명, 기존 주요 메뉴를 **조직**으로 통일한다. 기존 clan 경로와 마지막 대회 기록은 유지한다. 로비 원본에서 수정한 뒤 생성 번들을 다시 빌드한다.
- 공개 입단 심사는 `admissionEnabled:false`로 잠근다. 시작·이어하기·질문·추천·희망 조직 선택을 열지 않으며 이전 기기 초안을 읽거나 덮어쓰지 않는다. 버튼의 disabled 속성을 제거해도 입단 이벤트를 연결하지 않는다. 직접 URL·새로고침·기존 대회 기록에서 돌아오는 진입도 동일하다.
- 기존 imagegen 배경·황동 버튼·인장을 사용한 준비 화면을 표시한다. 아지트 콘셉트는 계속 열람 가능하다. 실제 모집·신규 운영 DB·점수·해금은 OFF를 유지한다.
- 깜빡임 원인은 ClanV1의 20초 갱신이 요청 시작과 종료마다 상위 HTML을 교체하면서 조직 iframe을 제거·재생성한 것이다. 같은 조직 화면을 보고 있으면 iframe을 보존하여 현재 탭·아지트 단계·포커스·스크롤을 유지한다. 기존 클랜 데이터 갱신과 사용자가 선택한 대회 기록 전환은 유지한다.

검수는 공개 기능의 관련 회귀와 PC 1440 / 모바일 390에 한정한다. `tests/organization-public-20261015.test.mjs`에서 기존 7개 응답 초안·조작된 버튼·직접 URL·재접속 차단, 20초 타이머 3회(실패 요청 포함)의 iframe 탐색 0회·화면 상태 유지, 이미지 버튼·화면 넘침·브라우저 오류·조직 API 요청 없음을 확인했다. 로비 원본/생성 번들 일치와 실제 로비 컴포넌트의 조직 메뉴 진입도 확인한다.

운영 반영 결과는 배포 완료 후 이 문서와 `organization-admission-off-live-20261015.json`에 기록한다.
