# 제작소 UI 및 합성 확장 준비 — 2026-09-22

## 요청 및 공개 범위

- 대메뉴 장비·제작과 기존 장비 합성 진입 명칭을 `제작소`로 통일한다. 기존 딥링크, 차량 바로가기, 합성 API는 유지한다.
- 로비·용병도감·장비강화의 네이비/라임, 한글 타이포그래피, 공통 메뉴를 재사용한다.
- 슈트코어·기타 합성은 **확장 준비**다. 신규 운영 레시피 저장, 재화 변경, 확률 확정, 활성화는 하지 않았다.
- 사용자 예시는 `슈트 코어 1 × 10 + 코인 + 마스터의 별 → 슈트 코어 2 (확률)`이다. 코인·별 수량과 확률은 미정이다.

## 화면

- 차량 / 장비 합성 / 재료 / 배틀슈트 / 슈트코어 / 기타 합성의 6개 분류.
- 이름·결과물·재료 검색, 제작 가능 필터, 초기화·새로고침.
- 목록과 상세를 분리하고 목록 내부 스크롤을 유지한다. 선택 시 목록이 맨 위로 튀지 않는다.
- 투입 수량, 보유량, 부족량, 성공 확률과 실패 소모를 한 화면에서 확인한다.
- 중복 장비는 동일 아이콘을 반복하지 않고 `× 수량`으로 표시한다. 기존 단일·일괄 합성 및 장착·강화 장비 제외 규칙은 보존한다.
- 모바일은 목록 높이를 제한하고 상세를 아래에 배치하며, 분류 탭은 가로 스크롤한다. 공통 하단 메뉴가 제작 버튼을 가리지 않는다.
- 기존 결과 연출과 영수증을 보존한다. 서버 응답 불명확 시 동일 요청번호로 재확인하며 처리 중 선택 변경·중복 클릭을 잠근다.

## CMS / 서버

- `SUIT_CORE_SYNTHESIS`, `ITEM_SYNTHESIS`는 기존 다중 재료 제작 엔진을 재사용한다. DB 스키마·운영 seed 변경 없음.
- CMS의 `+ 슈트코어 합성`, `+ 기타 합성`은 브라우저의 미저장 초안만 만든다. 기본 운영 OFF / 공개 OFF / OWNER 테스트.
- 코인·마스터의 별·성공 확률을 공란으로 두며 입력 전 저장을 막는다. 서버도 미정·음수·범위 밖 값을 거부한다.
- 슈트코어 초안만 사용자 예시의 입력 코어 10개/출력 코어 1개를 미리 채운다. 코인과 별은 BOTH 결제로 같은 영수증에서 함께 차감한다.
- 재료는 기존 CMS에서 여러 종류를 선택하고 개별 수량을 지정한다. 기타 합성은 인벤토리 아이템을 결과로 사용한다.
- 새 분류에 공개 레시피가 없으면 준비 중 안내만 표시한다. 예시는 실제 제작 버튼이나 재화 소모를 만들지 않는다.
- 마스터의 별을 재료 행과 비용 양쪽에 중복 등록하는 것은 거부한다. 원자적 차감/지급과 재시도 중복 방지는 기존 서버 트랜잭션을 사용한다.
- 기존 미스틱 에너지 고정 정책, 차량·슈트 비용, 장비 합성 확률은 변경하지 않았다.
