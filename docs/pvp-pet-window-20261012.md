# 랭크전 펫 효과창 축소·ON/OFF — 2026-10-12

사용자 모바일 건의: 랭크전 펫 효과 발동창이 지나치게 커 전투 화면을 가리므로 크기를 줄이고 ON/OFF를 추가한다.

## 적용

- PVP 전투의 펫 발동창을 작은 초상·펫 이름·아군/상대·실제 버프 수치·완료 체크로 압축했다. 긴 설명과 상태 문구 반복은 줄이고 여러 버프는 빠짐없이 표시한다.
- 창 옆 `펫 효과창 ON/OFF` 버튼으로 발동 안내와 기록창을 즉시 숨기거나 다시 표시한다. 숨겼을 때도 버튼은 남는다. 기본값은 ON, 선택은 해당 브라우저의 `cnine_pvp_pet_effect_window`에 저장해 새로고침과 다음 PVP에도 유지한다. 저장소가 차단돼도 현재 창의 전환은 동작한다.
- 터치 버튼 높이는 최소 44px, 키보드 Space/Enter와 포커스·눌림 상태를 지원한다. 다른 탭에서 바꾼 설정도 동기화하고 전투 종료 시 리스너를 해제한다.
- 표시 설정만 변경한다. 서버 버프 계산·수치·지속 효과·펫 캐릭터와 기존 전투 연출은 유지한다. PVE와 격전지의 기존 발동창에는 이 PVP 설정을 적용하지 않는다.

## 검수·배포 범위

- 격리된 서버 표본과 실제 V3 번들/전투 래퍼로 PC 1440×900, 태블릿 835×754, 모바일 390×844를 확인했다. 단일 버프 기준 창 높이는 PC/태블릿 약 42px, 모바일 49px다. 가로 넘침·수치 잘림·브라우저 오류가 없다.
- ON/OFF 즉시 반영, OFF 상태의 새로고침/재입장/버프 발동, 키보드로 다시 표시, 다음 전투 ON 유지, 중복 버튼 없음, 모바일 복합 버프 5개 표시, PVE 표시 유지·닫기를 확인했다. 버프 적용 진단값은 토글 전후 동일했다.
