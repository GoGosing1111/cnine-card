# 계급 경험치 물약 — 2026-10-20

사용자 요청: 계급 레벨업 경험치 2배·3배 물약, 각각 60분. 미라클버닝이 표시되는 콘텐츠 현황에 적용 중인 효과를 표시한다.
추가 사용 정책은 사용자 확정 답변 **같은 배율은 시간 연장, 다른 배율은 교체**다.

## 동작

- `RANK_EXP_POTION_2X_60M`: 계급 경험치 2배 물약.
- `RANK_EXP_POTION_3X_60M`: 계급 경험치 3배 물약.
- 첫 사용 및 만료 후 사용은 서버 기준 60분. 같은 배율은 기존 만료 시각에 60분을 추가한다.
- 다른 배율은 남은 시간을 폐기하고 새 배율로 60분을 시작한다. 2배→3배와 3배→2배 모두 같은 규칙이다. 사용 전에 교체 안내를 표시한다.
- 실제 서버 계급 경험치 계산에 개인 배율을 적용한다. 펫·트로피의 기존 경험치 보너스를 포함한 획득량을 곱하고 기존 최대 계급·경험치 상한과 지급 영수증을 유지한다. 코인·아이템 수량·전투 수치는 바꾸지 않는다.
- 로그아웃 중에도 시간이 흐른다. 콘텐츠 현황에 전용 물약 이미지, 현재 배율, ‘적용 중’, 남은 시간을 표시하며 만료되면 행과 건수를 갱신한다. 미라클버닝과 함께 표시한다.
- 인벤토리에서 1개씩 사용한다. 활성 인벤토리 아이템을 사용하는 기존 시즌패스 CMS 카탈로그에도 두 물약이 표시된다. 기존 패스 보상표·가격·판매·드롭 설정을 바꾸거나 계정에 지급하지 않는다.

## 거래 및 표시

`shared/rank-exp-potion-v1.mjs`가 아이템·60분·연장/교체 정책의 단일 정의다.
개인 효과는 `app_meta/account_rank_potion_v1:<userId>`에 저장한다. 기존 사용자 잠금·joint 영수증·원자 거래를 사용하며 새 DB 스키마나 인증 체계는 추가하지 않는다.

물약 차감·효과 저장·로그·완료 영수증은 같은 거래다. 예상 버전이 달라진 확인창은 차감하지 않는다.
실패한 요청은 같은 요청 번호로 복구하고, 실제 쓰기가 성공하는 시점부터 60분을 계산한다.
사용 전에 계정별 요청 번호를 저장하고 수량이 0이 되어도 인벤토리 ‘이전 아이템 사용 결과’에서 복구한다.
완료 영수증 재조회/재시도는 시간 연장이나 추가 소모를 하지 않는다.

개인 효과는 인증된 `/api/rank-exp-potion/status`에서 별도로 읽고 `private, no-store`로 응답한다.
기존 공개 캐시 `/api/live-operations`에 개인정보를 섞지 않는다.
현재 계정이 다른 응답이나 최신 사용보다 이전 버전인 응답은 표시를 덮어쓰지 못한다.
