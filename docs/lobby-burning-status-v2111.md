# 콘텐츠 현황 버닝 표시 — 2026-09-14

## 반영

- 로비 하단의 얇은 콘텐츠 현황 행 맨 앞에 진행 중인 버닝 또는 하이퍼버닝을 표시한다. 일반 버닝은 주황색 불꽃, 하이퍼버닝은 보라색 불꽃·번개로 구분한다.
- 이름, 남은 시간 `HH:MM:SS`, 현재 운영 설정의 전투 코인 배수와 행동력 충전 주기를 표시한다. 운영에서 선택된 활성 이벤트 하나만 표시하며, 이벤트가 없으면 기존 콘텐츠 현황을 그대로 보여준다.
- 기존 `burning-event/status` 상태, 서버 시간 보정, 매초 카운트다운과 종료 후 갱신을 재사용한다. 추가 폴링이나 운영 설정 변경은 없다.
- 전환·OFF·자연 종료 시 현재 운영 콘텐츠 목록을 유지하며 이벤트 항목과 진행 건수를 갱신한다. 이벤트 갱신만으로 다른 콘텐츠의 서버 시간 보정을 다시 계산하지 않는다.
- 콘텐츠 현황 API의 일시적인 실패에도 독립적으로 확인한 버닝 정보는 표시한다. 기존 경매·전투 콘텐츠 진입과 가로 스크롤을 유지한다.
- 이벤트 행은 안내 정보이며 구매·전투·이벤트 활성화 버튼으로 동작하지 않는다. 원래 카드 상점의 버닝 안내와 팝업 정책은 유지한다.

## 파일과 캐시

- `js/app.js`: 기존 버닝 상태와 콘텐츠 현황 렌더링 연결, 간결한 타이머 표시.
- `css/lobby-burning-status-v2111.css`: 기존 60px 콘텐츠 행에 맞는 이벤트 색상·배치, 320px 모바일 대응.
- `index.html`: 새 CSS와 앱 스크립트의 `operations=2111-burning` 캐시 키. 기존 핵심 릴리스 태그와 서비스 워커 계약은 유지한다.
