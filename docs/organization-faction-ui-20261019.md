# 조직 세력전 전용 창·지도·격돌 개선 — 2026-10-19

사용자 요청: 격돌 연출 복구, 조직 문장의 투명 배경 처리, 영토전처럼 넓은 전용 창, 단색 구역 칠하기를 벗어난 지도 표현.

## 변경

- 조직 본부의 세력전 탭과 전황 지도 버튼은 최상위 게임 화면에 전체 크기 전용 창을 연다. 중첩 iframe의 좁은 본부 폭에 갇히지 않으며 본부로 복귀하면 기존 화면과 스크롤을 유지한다. 네이티브 dialog로 초점 이동을 제한하고 Escape와 복귀 버튼을 제공한다.
- 지도에 화면 높이를 우선 배분하고 일정·보상은 펼침 안내로, PC 교전 목록과 내 전투 입장은 작전 패널로 이동했다. PC 1920×1080에서 지도 1456×885, 1366×900에서 942×705. 모바일은 지도 확대·지역 선택·작전 정보 바로가기를 제공한다.
- 실제 KOSTAT 2013 행정 경계와 46개 지역, 좌표·선택·드래그·카메라 유지 정책은 보존했다. ImageGen 도시 지형 질감, 경계 깊이, 조직별 투명 문장, 선택 강조를 사용한다. 생성된 도로·건물은 게임용 시각 질감이며 실제 GIS 도로 데이터가 아니다.
- 사용하지 않던 격돌 함수와 정적 소형 핀을 정리하고 ACTIVE 전투에 전용 교차검·불꽃 이미지와 완만한 애니메이션을 연결했다. 지역명·격돌 중 문구는 SVG 텍스트다. 전투 목록 클릭/키보드로 상세 위치를 확인하고 종료 상태는 다음 갱신에서 제거한다. 동작 줄이기에서는 애니메이션을 멈춘다. 무방어 지역의 즉시 점령을 가짜 전투로 만들지 않는다.
- 포스터 사각 좌표를 그대로 보여주던 문장을 15개 개별 투명 이미지로 추출했다. 문장·방패 내부는 유지하고 포스터 배경·문구는 제거했다. 완전한 문장들을 투명 atlas로 묶어 요청 수와 Pages 파일 수를 줄였다. 지도, 점령 조직, 전투실에서 동일한 완전한 실루엣을 표시한다.
- 전용 창에서 V3 전투는 창 내부의 기존 독립 진입 경로를 사용해 부모 dialog 뒤로 가려지지 않는다. 전투 종료 후 전투실과 지도 복귀를 확인했다.

## 자산·검수

- 생성 방식: 내장 `image_gen`; 로고 15개 background-extraction, 지도 질감과 격돌 아이콘 각 1개. 원본 포스터는 수정하지 않았다.
- 프롬프트·출처·SHA-256·배포 atlas 좌표: `assets/ui/organization/faction-v3-20261019/manifest.json`.
- 원본 PNG와 개별 WebP: `docs/qa/organization-faction-ui-20261019/sources/`, `extracted/`. 운영에는 terrain/clash/emblems WebP와 manifest만 사용한다.
- 관련 브라우저 검사: `tests/organization-faction-ui-20261019.browser.mjs`. 분리된 PGlite TEST 회차와 로컬 API만 사용하고 음소거했다. 1920/1366/390/320px의 전체 창, 재입장·복귀, 지도 이동·확대, 46개 지역, 두 교전 핀, 키보드 선택, 동작 줄이기, 종료 시 제거, 가로 넘침 없음, 리소스/스크립트 오류 없음 확인. PC 전용 창 안에서 실제 V3 로딩→재생→종료→지도 복귀도 통과했다.
- 원화 해시·alpha·불투명 내부·잘리지 않은 가장자리와 atlas 검사: `tests/organization-faction-art-20261019.test.mjs`. 실제 경계 검사는 기존 `tests/organization-faction-map-20261015.test.mjs`를 사용한다.
- 화면과 보고서는 같은 `docs/qa/organization-faction-ui-20261019/`에 보존한다. 기술 검수이며 사용자 시각 승인으로 기록하지 않는다.
- 서버 전투·조직 편성 정원·원로 권한·개방 시간·비용·보상·점령 판정은 변경하지 않았다.
