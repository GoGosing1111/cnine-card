# 슈퍼스타팩 일반 공개 및 10회 개봉

- 일반 유저 개봉을 ON으로 전환한다. 기존 CMS 가격·확률·이미지 설정은 보존한다.
- `superstar_pack_public_release_v2047=1`을 한 번만 기록하므로 이후 운영자가 수동 OFF로 바꾸면 다시 열리지 않는다.
- 1회와 10회만 지원한다. 현재 1회 3억, 10회 총 30억 코인이다. 매회 기존 10% 독립 판정이며 10회 당첨 보장은 없다.
- 10회도 기존 스와이프 결제 → 봉인 해제 → 팩 분리 → 당첨/꽝 연출을 각각 재생한다. 다음 팩 버튼으로 진행하고 마지막에 전체 결과를 표시한다.
- 최초 스와이프에서 10회 결제·카드·중복 조각·로그·기존 1% 세금·영수증을 하나의 트랜잭션으로 확정한다. 지급이나 영수증 저장이 0행이면 전액 롤백한다.
- 같은 배치 내 중복도 순서대로 판정해 기존 중복 조각 600개 규칙을 적용한다. 모든 팩은 서버 난수로 판정한다.
- 통신 중단/새로고침은 계정별 동일 요청번호와 마지막 확인 위치로 복구한다. 결제 완료 영수증은 개봉 OFF나 잔액 부족 상태에서도 재조회하며 재결제하지 않는다.
- 운영 점검, 블랙미라클, 레이드와 다른 콘텐츠 설정은 변경하지 않는다. 실계정 코인을 사용하는 검증 개봉은 하지 않는다.

## 검증

- `npm run test:superstar-pack`: 서버 배치·롤백·영수증 재조회·CMS 설정 보존·PostgreSQL SQL 변환·클라이언트 복구 및 기존 연출 계약.
- 기존 로컬 테스트 탭에서 10개 연출과 혼합 결과(당첨 3/꽝 7) 완료, 모바일 390px 가로 넘침/누락 이미지 없음 확인.
- 운영 배포 전 깨끗한 릴리스 작업 트리에서 `npm run release:gate`, 배포는 `npm run deploy:production`만 사용.
