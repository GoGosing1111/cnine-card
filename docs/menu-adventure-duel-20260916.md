# 공통 메뉴: 인벤토리 · 모험 · 대전

사용자 확정: 인벤토리를 독립 진입으로 분리하고 PVE/PVP를 별도 메뉴로 연다. 영토전은 PVP에 둔다. 혼동을 줄이는 이름은 `모험 · PVE / 대전 · PVP`다.

- PC: 로비, 인벤토리, 모험, 대전, 성장·수집, 상점·교환, 보상, 클랜·생활, 행정부. 전체 메뉴는 하단에 고정한다.
- 모바일: 로비, 인벤토리, 모험 PVE, 대전 PVP, 전체. 나머지 분류는 전체 메뉴에서 연다.
- 인벤토리는 하위 분류창을 거치지 않고 기존 인벤토리로 이동하며 상점·교환 목록에서 제거한다.
- 모험은 몬스터 아이콘과 PVE 표지, 대전은 교차한 검과 PVP 표지를 쓴다. 분류창에도 상대가 몬스터인지 다른 유저인지 설명한다.
- 영토전·랭크전·시즌 랭킹은 대전에서만 표시한다. 클랜 가입·관리 화면은 클랜·생활에 둔다.
- 기존 목적지 ID, 영토전 창, 전투·덱·입장 정책은 유지한다. 공통 컴포넌트가 연결된 게임 화면과 별도 운영 페이지에 함께 적용한다.
- 별도 페이지의 링크로 진입할 때 캐시된 초기 화면이 메뉴 어댑터보다 먼저 준비되어도 요청한 목적지 본문으로 이동한다. 상점 본문에 목적지 이름만 붙는 시작 순서 문제를 회귀 검사한다.
- 메뉴 계약 검사, PC·모바일 분류 격리·검색·인벤토리 직접 진입·영토전 진입·작은 PC 전체 메뉴 접근을 검수한다. 범위 커밋 후 `npm run deploy:production`의 전체 출시 검사를 통과해 배포한다.
