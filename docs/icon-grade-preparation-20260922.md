## 고유효과 8종 설계 초안 — 신규 종류 확정 아님

사용자가 `기존 4종 + 신규 4종 = 총 8종`으로 구성을 확정했다. 신규 4종의 구체적인 종류는 아래 제안 상태이며, 아직 별도 승인된 운영 효과나 수치가 아니다.

| 구분 | 효과 | 설정 키 | 단위 |
|---|---|---|---|
| 기존 | 공격 | attackPercent | % |
| 기존 | 방어 | defensePercent | % |
| 기존 | 체력 | hpPercent | % |
| 기존 | 속도 | speedPercent | % |
| 신규 제안 | 치명타 확률 | criticalChancePoints | %p |
| 신규 제안 | 치명타 피해 | criticalDamagePercent | % |
| 신규 제안 | 방어 관통 | penetrationPoints | %p |
| 신규 제안 | 흡혈 | lifestealPercent | % |

모든 카드별 초기 수치는 `null`(미정)이다. 0이나 임의 밸런스를 확정값처럼 저장하지 않는다. 초안 입력 범위는 비정상 데이터 차단용이며 확정 운영 상한이 아니다. 값을 입력해도 프레임 검수·설정 초안까지만 가능하고 실제 전투 보정을 만들지 않는다.
