# [업데이트 안내] 숲켓몬 대규모 UI 리뉴얼 및 편의성 개선

안녕하세요, 숲켓몬 운영팀입니다.

2026년 8월 19일 점검을 통해 숲켓몬의 주요 화면을 새로운 프리미엄 게임 UI로 전면 개편하고, 카드·장비·차량 구매 편의성과 모바일 대응을 강화했습니다.

## 1. 대규모 UI 리뉴얼

- 메인 로비를 미래형 최고지휘관 콘셉트의 풀스크린 게임 로비로 개편했습니다.
- 기존 웹사이트형 화면을 폐기하고 차콜 블랙·시안 포인트 기반의 통합 게임 UI를 적용했습니다.
- PC와 모바일에서 각각 화면 밀도, 글자 크기, 조작 영역, 콘텐츠 간격이 자동 조절됩니다.
- 카드 상점, 도감, 전투, 장비·제작, 보상, 랭킹, 승부·경매를 새로운 지휘 메뉴에서 바로 이용할 수 있습니다.
- 콘텐츠마다 서로 다른 전용 SVG 아이콘을 적용해 메뉴 구분과 시인성을 높였습니다.
- 구형 UI는 로딩·오프라인·오류 상황에서도 더 이상 표시되지 않습니다.

## 2. 로그인 및 계정 화면 개편

- 기존 계정은 `PLAY DK 개인키`로 로그인할 수 있습니다.
- 신규 이용자는 `와이고수 닉네임`으로 계정을 생성할 수 있습니다.
- 모바일 키보드가 열린 상태에서도 입력창과 접속 버튼이 가려지지 않도록 개선했습니다.
- 로그인·계정 생성·오류 안내를 하나의 통합 보안 콘솔 UI로 개편했습니다.

## 3. 카드팩을 카드 상점으로 개편

- 메뉴 명칭을 `카드팩`에서 `카드 상점`으로 변경했습니다.
- 카드팩 원본 비율을 유지하면서 PC·태블릿·모바일별 표시 해상도와 최대 크기를 자동 조절합니다.
- 구매 선택을 `20장 → 100장 → 1000장 → 자동 구매` 순서로 정리했습니다.
- 1장 구매 버튼은 제거했습니다.
- 1000장 구매는 서버에 한 번에 요청하지 않고 100장씩 10회 안전하게 처리합니다.
- 대량 구매 결과는 전체 카드 이미지를 한꺼번에 렌더링하지 않고 등급·획득량 중심으로 간결하게 표시합니다.

## 4. 장비·차량 대량 구매 및 자동 진행

- 장비 보급상자와 차량 뽑기에 구매 수량 직접 입력 기능을 추가했습니다.
- 최대 10,000개까지 입력할 수 있으며 서버에는 회차당 최대 100개씩 나누어 요청합니다.
- 구매 후 자동 개봉을 연속 진행할 수 있습니다.
- 진행 수량, 실제 사용 코인, 획득 결과, 중단 상태를 실시간으로 확인할 수 있습니다.
- 새로고침이나 화면 전환이 발생해도 처리 중인 요청 번호와 진행 상태를 복구합니다.
- 여러 브라우저 탭에서 동시에 구매하는 경우 중복 진행을 차단합니다.
- 구매 도중 가격이 변경되면 추가 결제 전에 작업을 중단하고 새 가격 확인을 요청합니다.

## 5. 메시지·출석·쿠폰 화면 개편

- 메시지함의 읽음 처리, 보상 수령, 삭제, 와고 2단계 인증 화면을 모바일 친화적으로 개편했습니다.
- 연속 출석 보상은 7일 진행 상태를 한눈에 확인할 수 있도록 변경했습니다.
- 쿠폰 입력창과 상태 안내를 긴 닉네임·긴 코드에서도 깨지지 않도록 개선했습니다.
- 모바일의 모든 주요 입력창과 버튼은 터치하기 쉬운 크기로 조정했습니다.

## 6. 장비·칭호·차고지·제작소 개편

- 장비, 칭호, 차고지 탭을 새로운 성장 메뉴와 연결했습니다.
- 장비 슬롯과 기존 카드 프레임 좌표는 유지하면서 필터, 선택 상태, 능력치 패널을 정돈했습니다.
- 제작소의 폐차장 원정, 차량 제작, 장비 합성을 새로운 패널 구조로 개편했습니다.
- PC에서는 정보와 제작 목록을 동시에 확인하고, 모바일에서는 한 열로 자연스럽게 전환됩니다.

## 7. 전투 메뉴 고급 연출

- 전투 관련 메뉴에만 라임·시안 포인트와 전용 강조선을 적용했습니다.
- PVE 전투, 몬스터 토벌, 월드 레이드, 몬스터 공성전, 봉인전, 방치형 원정, 무한의탑, 랭크전, 영토전에 각각 다른 아이콘을 적용했습니다.
- 일반 메뉴는 무채색을 유지하고, 선택·진입 시에만 강조 효과가 나타나도록 조정해 화면 피로도를 낮췄습니다.
- 화면이 보이지 않거나 움직임 감소 옵션이 켜진 경우 불필요한 애니메이션을 자동으로 멈춥니다.

## 8. 성능 및 안정성 최적화

- 대량 구매 중 불필요한 카드 이미지 사전 로딩과 디코딩을 제거했습니다.
- 대량 결과 화면의 생성 요소 수를 제한해 긴 작업에서도 화면이 무거워지지 않도록 개선했습니다.
- 진행률 표시는 브라우저 프레임 단위로 묶어 갱신하고, 사용자 데이터 저장은 일정 간격으로 제한했습니다.
- 정상 처리 구간의 인위적인 대기 시간을 제거했습니다. 서버 혼잡이 감지된 경우에만 안전한 재시도 간격을 적용합니다.
- 숨겨진 탭에서는 다음 구매 회차를 잠시 멈추고, 화면 복귀 후 안전하게 이어서 진행합니다.
- 구매·개봉 요청에는 고유 영수증 번호를 사용하며, 응답이 끊겨도 같은 요청 번호로 결과를 확인합니다.
- 코인 차감, 아이템 지급, 영수증 완료 처리를 하나의 원자적 서버 작업으로 묶어 중복 차감과 미지급 가능성을 줄였습니다.
- 반복되는 블러·광원·무한 파티클을 줄이고 필요한 전환 효과만 유지했습니다.
- 최고지휘관 일러스트는 AVIF·WebP 반응형 자산을 우선 사용합니다.

## 9. V3 전투엔진 공개 예고

`PROJECT V V3 전투엔진`은 현재 최종 최적화와 실전 검증을 진행하고 있으며 곧 별도 업데이트로 공개할 예정입니다.

V3 전투엔진은 이번 UI 패치에는 포함되지 않았습니다. 공개 일정과 세부 전투 시스템은 별도 공지를 통해 안내해 드리겠습니다.

앞으로도 안정적이고 완성도 높은 숲켓몬을 제공할 수 있도록 계속 개선하겠습니다.
