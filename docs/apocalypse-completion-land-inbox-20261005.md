# 아포칼립스 기믹 실패·이탈 패배 / 숲켓랜드 쿠폰 메시지 중단

2026-10-05 사용자 후속 지시: F5·다른 화면 이동으로 클리어하지 못하게 하고, 기믹을 깨지 않으면 전멸 처리한다. 숲켓랜드 쿠폰번호를 스트리머 메시지함으로 보내지 않는다.

이 문서가 `player-suggestions-20261005.md`의 초기 연습 기믹·선지급·추가 보상 복구 정책을 대체한다.

## 적용 동작

- 아포칼립스 시작은 행동력만 사용하고 결과는 PENDING이다. 코인, 계정 경험치, 카드와 중복 보상, 장비 보급상자, 기존 드랍, 마법 결정, 통합 드랍 및 보스별 추가 보상은 이 단계에서 지급하지 않는다.
- 초록색 안전 구역을 6초 안에 선택해야 한다. 잘못 선택하거나 입력하지 않으면 서버가 전원 HP 0과 패배를 확정한다. 카드·용병 전멸 타임라인과 보상 0을 표시한다.
- 기믹 성공 후 실제 전투를 끝까지 재생해야 완료를 요청한다. 서버는 같은 페이지의 전투 토큰, 회피 성공, 살아 있는 연결, 최소 진행 시간을 확인한다. 승리일 때만 클리어와 보상을 확정한다.
- 새로고침, 페이지 이탈, 다른 게임 화면 이동, 연결 만료는 미완료 전투의 패배다. 페이지 메모리에만 보관하는 토큰은 새 페이지에서 복구할 수 없다. pagehide 취소 요청이 유실돼도 새 페이지가 이전 요청을 취소하며, 서버 연결 만료가 남은 요청을 차단한다.
- 초기 로딩에서도 요청 번호를 먼저 기록해 새로고침에 대응한다. 기존 요청 번호 재사용으로 행동력을 다시 차감하지 않는다. 미완료 전투를 자동으로 열거나 정답 제출·보상 청구하는 복구는 제거했다. 이미 정상 완료된 영수증은 조회할 수 있다.
- 클리어 영수증, 기본·추가 보상, 중복 카드 보상, 경험치, 처치 진척도, 전투 로그를 기존 DB batch 트랜잭션에서 함께 확정한다. 이탈과 완료 경쟁, 지급 오류, 응답 유실 재요청은 중복 지급하지 않는다. 보상 난수는 시작 시 고정하고 일일 제한은 완료 시 다시 적용한다. 저장 영수증에는 큰 전투 타임라인을 보관하지 않는다.
- 보스별 코인 증가율·마스터의 별·미스틱 에너지 설정은 유지한다. 사용자가 수량을 별도 지정하므로 이번 변경으로 미설정 수량을 임의 활성화하지 않는다.
- 숲켓랜드 스핀은 당첨 결과·쿠폰·보관함 기록을 그대로 저장하지만 쿠폰번호 메시지를 만들지 않는다. 기존 메시지는 삭제하지 않으며 OWNER 이용권 지급 알림은 유지한다. 같은 화면의 쿠폰 입력과 기존 발급 쿠폰 사용도 유지한다.

## 관련 검증과 배포 범위

- SQLite 및 실제 PostgreSQL 호환 어댑터/PGlite: 오입력, 무입력, 시간 초과, 페이지 토큰 교체, 이탈, 연결 만료, 조기 완료, 다른 계정, 요청 번호 재사용, 지급 중 오류의 전체 롤백, 완료/이탈 경쟁, 완료 동시 재시도, 재조회 중복 지급 방지, 마법 결정 일일 상한.
- 숲켓랜드: 메시지 저장 장애가 있어도 쿠폰 발급 성공, 쿠폰번호 메시지 0건, 이용권 알림 유지, 보관함 조회, 쿠폰 사용·상한·중복·동시 요청.
- 관련 아포칼립스·소탕 회귀 및 공용 전장 로더/배포 번들 연결 검증.
- 실제 앱과 배포용 Pixi 번들, 합성 계정만 사용해 1440×1000 PC / 390×844 모바일의 기믹·전멸·정상 완료·숲켓랜드 화면을 확인했다. 입력 전 F5, 입력 성공 후 전투 중 F5, 다른 화면 이동이 모두 FAILED이며 WIN 기록이 늘지 않았다. 일반 PVE·PVP 재생도 각각 정상 종료했다.
- 화면 기록: `%TEMP%/cnine-apocalypse-completion-20261005/`, 일반 전투 기록: `%TEMP%/cnine-apocalypse-core-20261005/`. 운영 계정의 재화를 사용하지 않았다.
- 직전 배포 기준: `981257cc9c3e3c5088b53a0dd6902909b4ac41fb` / Pages `f16b737e`. 범위는 아포칼립스 완료 처리와 숲켓랜드 알림이며 공통 인증·DB 어댑터·스키마·의존성을 변경하지 않는다. `npm run deploy:production -- --scoped`를 사용한다.

## 유저 공지 반영 문안

아포칼립스 토벌에 충격파 회피 기믹이 적용됩니다. 제한 시간 안에 표시된 안전 구역을 선택해야 하며, 잘못된 구역을 선택하거나 시간 안에 입력하지 않으면 출전한 파티가 전멸하고 토벌에 실패합니다. 회피에 성공한 뒤에도 보스를 처치하고 전투를 끝까지 완료해야 클리어 보상을 받을 수 있습니다.

전투 도중 새로고침하거나 다른 화면으로 이동하면 해당 전투는 클리어로 인정되지 않으며 보상도 지급되지 않습니다. 이미 사용한 아포칼립스 행동력은 반환되지 않습니다. 보스별 추가 보상의 구체적인 수량은 별도 안내합니다.

숲켓랜드 당첨 쿠폰번호는 앞으로 스트리머 메시지함으로 자동 발송되지 않습니다. 숲켓랜드의 당첨 결과와 당첨 보관함에서 쿠폰번호를 확인하고 복사할 수 있습니다. 숲켓랜드 화면 안의 쿠폰 입력 공간에서 바로 쿠폰을 사용할 수 있으며, 기존에 발급된 쿠폰도 유효한 조건에 따라 계속 사용할 수 있습니다.
