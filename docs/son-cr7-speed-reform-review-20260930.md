이 문서는 구현 전 설계 검토 기록이다. 이후 사용자의 `속도형 고유효과 개편 작업 시작하고 배포해 유저 공지용까지 작성`, `방어형 2장의 적폐도 하향시켜라` 지시로 준비 전용 제한이 해제됐다. 최신 구현·검증·운영 상태는 [개편 반영 기록](speed-guard-reform-release-20260930.md)을 따른다. 아래 50% 억제 제안은 최종 30%로 조정됐다.

1. **먼저 만든 코드 준비본**: 살아 있는 용병·힐러 중 HP 비율이 가장 낮은 대상 우선 공격, 방어형 2장이 고유 속도 증가분의 30%만 억제, 시작 게이지 유지, 방어형 1장 이하가 되면 속도 복구. 별도 브랜치 `codex/speed-type-balance-20260928`, 커밋 `6e30da98`에만 보관됐다.
2. **그 뒤 제안한 최신 구상**: 사용자의 `속도가 확실히 예전 포스를 뿜는다 하는 새 방안`, `용병 먼저 타격 안해도 됨`에 따라 선공·확정 연타·처치 추격을 중심으로 바꾼 안이다. 이 구상의 억제 후보는 **50%**다. 앞선 코드 준비본의 **30%**와 혼동하지 않는다.

앞선 준비본의 최대 97.7~100% 승률은 특정 합성 덱·용병·전직 조건의 결과다. 손흥민과 CR7의 실카드 비교나 전체 유저 승률이 아니다. 이번 안의 성능 근거로 전용하지 않는다.

## 현재 구조의 불리한 지점

- `functions/_battle_v2_preview.js`의 `suppressSpeedUnique`는 방어형 2장 상대에서 **SPEED 계열만** 고유 속도 증가분을 제거하고 시작 게이지를 0으로 만든다. 전투 도중 방어형이 줄어도 복구하지 않는다.
- 손흥민의 속도 +50%는 이 조건에 걸리지만, ATTACK 계열인 CR7의 속도 +30%는 그대로 남는다. 속도형을 대표하는 카드의 주력 장점이 지워지는 비대칭이다.
- 계열 능력치 배분도 공격 계수 ATTACK 0.350 / SPEED 0.195로 다르다. 단순히 고유효과 50 대 30만 바꾸거나 비교해서 실제 성능을 단정할 수 없다. 공격형에는 관통·첫 행동 피해·방벽 상대 피해·마무리 보정도 있다.
- 속도형에는 이미 힐러 우선 공격, 힐러 대상 피해 +50% 또는 기타 대상 +15%, 방벽 추가 피해, 게이지 감소, 회피, 처치 추격이 있다. 신규 효과는 이 기존 효과와 합쳐서 평가한다.
- 용병은 아군 일반 카드 행동과 연계해 추가 행동한다. 속도형의 행동 증가가 용병의 기여까지 바꾸므로 총 피해량과 승률을 분리해서 확인해야 한다.

## 이번 검토의 제안

**손흥민을 PVP에서 우선 채용할 만한 대표 속도형으로 만들고, 동일 투자 조건의 종합 기여에서 CR7보다 우세하도록 조정한다.** CR7은 강한 단발 피해·관통·마무리라는 공격형 역할을 유지한다.

수치 출발점은 이전 최신 구상을 이어간다. 아래는 제안값이며 승인된 운영 수치나 실측 결과가 아니다.

| 항목 | 제안 |
|---|---|
| 선공 | 속도형 시작 행동 게이지 30 → 60 |
| 방어형 2장 억제 | 양수인 고유 속도 증가분의 50%만 억제; 시작 게이지 유지; 방어형 1장 이하 시 복구 |
| 기본 연타 | 본타 적중 후 같은 대상에 본타의 50% 잔영 타격: 100% + 50% |
| 주기적 강화 | 자신의 1·4·7…번째 기본 공격은 100% + 50% + 50% |
| 처치 추격 | 게이지 +70, 최대 3회 유지; 잔영 처치도 인정 |
| 기존 확률 가속 | 28% 확률 게이지 +35는 확정 연타로 교체 |
| 표적 | 기존 힐러 우선 유지; 별도의 용병 우선 저격은 이번 최신 구상에 포함하지 않음 |

연타는 같은 기본 행동 안의 타격이다. 용병 행동·게이지 감소·처치 보상을 타수마다 중복 발동시키지 않는다. 처치 또는 본타 회피 시 남은 타격을 종료하고, 연격 전체에 한 행동의 피해 상한을 적용한다. 반격·방벽 소모·보호 효과와의 발동 계약도 구현 전에 명확히 해야 한다.

두 카드의 기본 전투력과 CMS 고유 수치를 먼저 임의로 바꾸기보다, 이 공통 속도형 개편에서 **손흥민의 실전 우위**가 나오는지를 첫 검수 기준으로 둔다. 부족하면 손흥민의 기본 타격 기여나 연격 수치를 별도로 조정한다. 모든 속도형이 모든 공격형보다 강해져야 한다는 뜻은 아니다.

## 성능 판정 기준

- 같은 나머지 4장·강화 단계·장비·마법·용병에서 SUPERSTAR 슬롯만 손흥민/CR7으로 교체한다. 카드별 실제 고유효과와 계열 중복 보정은 유지한다.
- 양쪽 위치를 교환하고 같은 난수 시드를 사용한다. 힐방방공공, 방어 1장, 회복형 없는 조합 등 상대 편성을 나눠 비교한다.
- 용병 없음, SS, 동일 SSS 조건을 각각 비교하고, 용병 밸런스 개편 이후에도 다시 맞춰 본다.
- 출발 목표: 동일 조건의 두 덱 직접 대결에서 손흥민 쪽 **55~60% 승률**. 이것은 추천 검수 목표이며 측정 결과가 아니다. 다양한 상대 덱 상대 평균 성적과 초반 기여도 함께 우세해야 한다.
- 첫 행동 시점·힐러 처치 시간·본인 피해·용병 피해·생존·팀 승률을 함께 본다. 자기 피해만 늘고 실제 채용 가치가 낮으면 목표 미달이다.

이번 확인에서는 비교 설계와 운영 값 조회까지만 수행했다. 최신 연타 구상을 구현하거나 새 승률 실험을 실행하지 않았으며 기존 준비본을 main에 병합하거나 운영 배포하지 않았다.
