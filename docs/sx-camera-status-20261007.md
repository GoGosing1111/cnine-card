# SX 궁극기 전장 밀림 · 전투 메시지 가림 수정

2026-10-07 사용자 첨부의 두 문제를 함께 수정한다.

- SX 실전 어댑터가 승인 프리뷰의 카메라 확대·피벗 및 배경 역보정을 실행했다. 최초 리소스 구성 중에도 카메라가 바뀌고, 궁극기/QTE 정지 중에는 변경된 구도가 유지됐다. 실전 SX는 본체·효과만 움직이고 공용 카메라·배경 및 다른 스킬의 카메라를 변경하거나 초기화하지 않도록 분리했다.
- 카드 뒤 노란 메시지는 캔버스의 기존 상태창이었다. 라이브 DOM 상태창이 있는 전투에서는 중복 캔버스 창을 숨기고, DOM 메시지를 카드 도크의 실제 높이보다 10px 위에 배치한다. 긴 메시지는 줄바꿈한다. DOM 상태창 없는 독립 프리뷰의 기존 창은 유지한다.
- 모바일 편성 계산은 이동한 메시지를 아래 여백으로 예약한다. 상단 여백으로 잘못 계산해 전투 캐릭터가 축소되는 회귀를 브라우저에서 발견하고 수정했다.

승인된 SX 이미지·모션 원본 및 프리뷰 구현은 변경하지 않았다. 2배 일반 공격속도, 궁극기 5.7초, 타격 5회/대상, 20초 주기, 서버 피해·보상도 유지한다.
