## 스킬과 잠금

기존 서버 `SKILL_ADVANCE` 판정을 사용한다. 아군의 남은 대기 3행동을 앞당기면 다음 정규 행동에 스킬을 시전하고 다음 재사용 대기에 3행동을 합산한다. 추가 턴·피해를 만들지 않으며 대출이 남은 같은 대상에게 다시 빌려주지 않는다. 봉인·충전형 시전·전투당 최대 시전 횟수를 보존한다. 대상은 정규 행동으로 발동하는 기존/신규 ICON이며 용병·장착 마법·일반 패시브·보스 스킬은 제외한다.

남수댕·디임과 같은 1조 코인·마스터의 별 500만·10%, SUPERSTAR +13/FUR +13 각 1장 조건이다. 실패 소모·천장 정책도 같다. 준비 성능은 기존 ICON 기준 스탯 ×1.25, 첫 1행동·기본 재사용 3행동·최대 6회다. 대상이 없거나 대출 중이면 시전 횟수를 소모하지 않는다. 운영자 저장값이 있으면 그대로 보존한다.

새 카드의 `cardId:null`, 제작·획득·실전 OFF와 덱 최대 2장은 유지한다. 공개 조회에는 신규 3종, 제작 가능한 기존 목록에는 8종, 운영 역할에는 9종이 남는다. 위조 신규 제작 요청도 DB·난수·재화·영수증 접근 전에 423으로 거절한다. 신규 원장 등록·지급·DB 저장은 이 배포에 없다. CMS에서는 선불 출격과 오조은 자료·준비 수치를 연결하고 3/8종 준비를 표시하며 저장 후에도 전체 OFF다.

## 재생·검수

기존 V3/PixiJS 8.20.0/GSAP 3.13.0을 전용 시연 번들에서 사용한다. `source/preview.js`가 실제 서버의 ADVANCE/REPAY 이벤트를 재생하고 생성 아틀라스로 시각화한다. 전투 판정은 `functions/_icon_technique_combat.js`, 격리 입력은 non-JSON Symbol 권한이다. 일반 계정 요청은 이 권한을 만들 수 없다. 공용 실전 엔진·버전은 변경하지 않는다.

## 배포 범위

새 카탈로그·선택 목록·CMS·전용 시연과 캐시 버전을 갱신한다. Pages 20,000개 제한에 맞추기 위해 기존 staging의 실행용 테스트 제외 대상을 `tests/` 외 `preview/`의 `.test.*js` 및 `.browser.mjs`로 확대했다. 모든 실행용 검사는 Git/로컬 QA에 남기며 원화·페이지·fixture·모듈을 제거하지 않는다. staging의 파일 보존/제외 회귀를 통과했다.

작은 범위의 준비 공개이므로 지정된 scoped 배포를 사용한다. 공통 DB/인증/의존성/실전 전투 계산은 수정하지 않는다.
