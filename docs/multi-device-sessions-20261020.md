# PC·모바일 동시 접속

같은 계정으로 PC와 모바일을 함께 사용할 수 있도록 로그인 세션의 교체 범위를 변경했다. 이전에는 일반 계정에 새 토큰을 발급하면 해당 계정의 다른 토큰을 모두 삭제했다. 이제는 동일한 `client_id`로 재로그인한 경우에만 그 브라우저의 이전 토큰을 교체하며, 다른 기기와 식별자가 없는 기존 세션은 유지한다.

다중접속 오류로 응답을 바꾸던 서버 처리와 경고창·강제 로그아웃 클라이언트 처리를 제거했다. 실제 만료된 소탕 요청은 세션 만료로 안내한다. 로그아웃은 현재 토큰만 삭제하며, 계정 이용 제한·개인키 초기화의 전체 세션 취소와 서버의 계정 단위 거래 잠금은 유지한다. 이미 이전 정책으로 삭제된 토큰을 부활시키지 않으며, 해당 기기는 기존 자동 복구 또는 재로그인을 사용한다.

전용 이미지나 신규 UI를 추가하지 않는 세션 정책 변경이다. 메인 앱과 서비스 워커 캐시 태그를 함께 갱신했다. 사용자 요청은 동시 사용 개방까지 포함하며, 기존 미승인 콘텐츠·보상·경제 정책의 공개 상태를 바꾸지 않는다.

## 검증

- `tests/multi-device-sessions-20261020.test.mjs`: 실제 세션 발급·인증 코드와 운영 PostgreSQL 호환 계층을 PGlite에서 실행했다.
- PC/모바일 두 토큰의 GET·POST 인증, 한쪽 재로그인, 다른 클라이언트 동시 로그인, 기존 식별자 없는 세션, 운영자 세션 보존을 확인했다.
- 로그아웃·만료·이용 제한·개인키 초기화 이후 토큰의 차단과 다른 계정 격리를 확인했다.
- 과거 다중접속 오류가 반복되어도 경고창·로그인 삭제·리디렉션이 발생하지 않으며 계정 단위 액션 잠금이 유지되는지 확인했다.
- 전용 검사 4개 및 API·앱 구문 검사 통과. 공통 세션 변경이므로 전체 출시 검사를 실행한다. 배포 결과는 후속 기록으로 추가한다.
