# SSS 발테르 행동력 상향 — 2026-10-11

사용자 `SSS 발테르 행동력 더 빠르게 해라`에 따라 V-996 전용 정책을 V2로 변경한다.

| 항목 | 기존 | 적용 |
| --- | --- | --- |
| PVE/PVP 자연 속도 | 기본 속도의 2배 | 기본 속도의 3배, 직전 대비 50% 증가 |
| 아군 일반 카드 1행동당 추가 행동 | 1.5회 | 3회 |
| 발테르가 있는 진영의 용병 행동 안전 상한 | 일반 행동 한도의 2배 | 3배 |

용병·배틀슈트·적 행동으로 추가 행동을 재귀 생성하지 않는다. 듀오는 해당 소유자 카드에만 반응하고 동료 용병의 행동 횟수는 그대로다. 카드가 모두 쓰러진 PVP의 마지막 대응도 같은 주기를 사용한다. 오래된 편성 스냅샷으로 새 전투를 시작해도 서버가 정책 V2와 최신 속도를 부여한다.

전투의 기존 진영별 안전 상한이 추가 행동을 중간에 차단하던 경로도 함께 조정했다. 일반 카드 20행동의 긴 통제 전투에서 마지막 일반 행동으로 종료되기 전 발테르 57행동(19×3)을 확인했다. 기존 상한대로라면 40행동에 멈춘다. 발테르 없는 진영은 기존 2배 상한을 유지한다.

기본 전투력·공격/체력/방어·면역·경감·피해 배율은 그대로다. PVE 광역기 종결 집행의 에너지 35·재사용 5행동과 PVP 기본 공격 전용 정책, 기존 칼 모션 2.5배를 유지한다. 승인 원화·SD, 등급·획득·소유·편성·팩 확률/가격/한도와 기능 공개 설정을 변경하지 않는다.

## 배포 범위

작업 중 origin/main에 있던 미배포 영토전 개편은 별도 작업에서 전체 게이트를 통과해 배포됐고, 이어 족각도시 TOP 이벤트도 배포됐다. 최종 배포 전 Cloudflare 목록에서 확인한 직전 운영 소스는 `9a2b4bc8`이다. 이 기준의 이후 실행 변경은 발테르 정책/해당 진영의 행동 상한과 파생 번들로 한정한다.
