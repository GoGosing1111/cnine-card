# 군단토벌 용병 단독 생존 시 몬스터 행동 정지 수정

사용자 제보: 재앙에서 일반 카드가 모두 쓰러지고 용병·바디만 남으면 몬스터가 공격하지 않는다. 이후 군단토벌의 용병 단독 생존 문제로 재확인했다.

## 원인과 변경

몬스터의 보장 행동은 일반 카드 행동만 집계하고 용병·슈트 행동은 제외했다. 일반 카드가 모두 사망하면 빠른 용병의 자연 행동이 게이지를 선점하고, 몬스터의 보장 행동도 더 이상 발생하지 않았다. 실제 공격 대상 선택에는 살아 있는 용병이 정상 포함돼 있었다.

`functions/_battle_v2_preview.js`의 군단토벌 연속 전투에서 일반 카드가 하나도 남지 않았을 때만 용병 행동을 기존 몬스터 보장 주기에 포함한다. 일반 카드 생존 중 용병 추가 행동, 다른 PVE/PVP, 슈트의 독립 사격·비피격 정책은 유지한다. 용병 피해·방벽·사망은 기존 처리 경로를 사용하며 슈트만 남으면 패배한다.

운영 지역 정책 r7/ON과 재앙의 몬스터 전투력 1,400만·보스 9억 5천만·공격 185%·보장 주기 3을 읽기 전용으로 확인했다. CMS 난이도·장비·드롭·코인·입장 횟수와 계정 보유량은 변경하지 않는다. 이미 시작한 원정의 확정 타임라인은 재계산하지 않으며 신규 원정부터 수정이 적용된다.

## 검증

- 수정 전 회귀 2건 실패: 용병 단독 생존, 마지막 일반 카드 사망 직후 몬스터 행동 누락.
- 실제 발테르와 H/SX 정의를 사용하는 격리 전투 12개(기존 섬+신규 5지역 × 슈트 2종): 수정 전 모두 30초간 몬스터 공격 0회, 수정 후 첫 공격 0.57초·10~11회 공격 후 실제 용병 사망/패배 처리. 보상·계정 변경 없이 검수용 몬스터 HP만 높여 행동 순서를 분리했다.
- 일반 카드 5명 생존 전투와 군단토벌 이외 PVE 대조군은 기존 엔진 결과와 완전히 동일했다.
- 신규 회귀는 생존 용병 대상 피해, 일반 카드 사망 전후 전환, 일반 카드 생존 중 기존 행동 주기, 슈트만 남은 패배를 확인한다.
- 기존 지역 보스 패턴 검사의 `attack:1`은 엔진 최솟값 100에 묶여 압력을 낮추지 못했고, 단독 용병 버그 덕분에 보스까지 생존하고 있었다. 검수용 일반 몬스터 전투력만 100만으로 낮춰 보스 등장·고유 패턴·슈트 사격 간격을 검증한다. 보스 전투력과 별도의 실제 난이도 생존 검사는 유지한다.
- 관련 범위: 신규 단독 생존, 지역 전투, 용병 행동, 군단토벌 세션/보상 회귀. 운영 배포는 지정 scoped 검사와 Worker 컴파일·기존 출시/캐시 검사를 사용한다.

수정 전후 재현 수치는 `docs/qa/legion-hunt-last-mercenary-20261018/regression.json`에 보존한다.

## 배포 준비

첫 scoped 실행에서 관련 28개 검사·Worker 문법·출시/Hyperdrive 검사가 통과했으나 Pages 파일 한도(20,000개)에 20,005개로 걸려 업로드 전에 중단됐다. 브라우저·서버·프리뷰에서 가져오지 않는 `scripts/ops/`의 일회 운영 도구와 영수증을 Git에 보존하고 Pages 전송 목록에서 제외한다. 게임 이미지·화면·기능은 제외하지 않는다. 기존 스테이징 검사에 운영 스크립트/JSON/SQL 제외와 원본 보존을 추가했다.
