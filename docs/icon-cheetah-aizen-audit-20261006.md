## PVP 비교

운영에서 읽은 카드·고유효과·역할 설정을 메모리 DB에 넣고 실제 `cardUniqueDeckStates`로 준비했다. FUR은 +15와 해당 전직을 모두 적용했다. 실제 랭크전 어댑터와 같이 원래 카드 전투력에 서버 고유효과·전직·ICON 역할 스냅샷을 연결하고 `createPvpBattleV2`로 판정했다.

- 고정 시드 32개, 공격/방어 양방향, 양쪽 총 장비 전투력 0 또는 500만.

- 5장 비교: 공통 나머지 4장, 비교 카드 전열/후열 배치 각 1회. 공통 카드는 동일한 중립 비교용 카드이며 특정 이용자 덱을 복제한 것은 아니다.

## PVE 확인 및 판정 한계

같은 공통 4장에 비교 카드만 교체하고, 일반 보스 전투력 100만·400만·1,000만, 총 장비 0·500만, 시드 32개로 1,728판을 실행했다. ICON 7종과 두 FUR 모두 각 192/192승이었다. 이 구간의 클리어 승률만으로 PVE 전체의 절대 우위를 판정할 수 없다.

장비 없는 100만 보스에서는 ICON 편성이 평균 15.06–26.16행동에 처치했고, 치타구 68.81행동·아이젠 60.50행동보다 적었다. 그러나 1,000만 보스에서는 나무늘봉순 77.50행동·오조은 77.47행동·강구열 75.00행동이 치타구 72.75행동·아이젠 72.91행동보다 많았다. 고체력 몬스터의 HP 비례 최소 피해, 역할별 지원·충전 행동 등으로 생기는 차이다. 이는 전투 행동 수 비교이며 실제 재생 시간 측정은 아니다. 아포칼립스·레이드·다수 웨이브를 이 일반 보스 시험으로 대체하지 않는다.

따라서 **PVP 성능 우위와 기본 스탯 우위는 확인됐으나, 모든 콘텐츠·모든 편성에서 반드시 승리하거나 더 빨리 처치한다는 보장은 없다.** 이번 점검으로 추가 상향이 필요한 PVP 열세는 발견되지 않았다. 운영 밸런스 수치는 변경하지 않았다.
