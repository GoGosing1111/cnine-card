# 시라누이 SSS 리미티드 · 지정 계정 전용

사용자는 V7 망령 군기를 승인하고 라이브 배포, 일반 획득 차단, 핑크빛유두 지급·편성을 요청했다. 분류 확인 답변은 **카이론과 같은 SSS 리미티드**다.

- 운영 코드 **V-987**, 이름 **시라누이(不知火)**. 핑크빛유두 **ID 1**만 보유 정보·PVE/PVP 편성을 사용할 수 있다. 다른 OWNER도 허용하지 않는다. 일반/리미티드 팩, 합성, 제작 및 일반 CMS 카드 풀에 넣지 않는다.
- 카이론의 전투 상수 객체를 공유한다. 기본 전투력 1,347,840, 링크·장비 환산·공격속도·추가 행동·피해 경감·상태이상 보호·베르칸 피해 면역이 동일하다. PVE 망령 포대는 총 560%를 살아 있는 적 전체에 분산, 에너지 35, 재사용 5행동이다. PVP에는 광역기를 배정하지 않는다.
- 승인 원화, 고정 총기, AR 4프레임, 머리 뒤 광륜, 군기 V7를 그대로 사용한다. 기본 공격 9발, 세 번째 기본 공격의 30발 스킬 변주, 광역기 25발 엄호·5회 포격·해골 표식은 시각 표현이다. 기본 공격 영수증 1회 및 광역기 대상별 1회만 적용하고 추가 피해·상태이상을 생성하지 않는다.
- 실제 V3 타임라인에 연결하며 원본 프리뷰의 독립 시계·카메라 초기화·적 위치/색 초기화를 차단한다. 적 진영은 캐릭터와 총구 축을 함께 반전한다. 군기·광륜은 별도 후면 레이어로 유지하고 취소·숨김·재개·배우 제거 시 정리한다.
- 승인 색인: `preview/mercenary-monochrome-artillery-battle-v1/live-approval-20261015.json`. 원화/대기 이미지와 기계적 WebP 파생 기록: `assets/ui/project-v/mercenaries/shiranui-20261015/`. 기존 승인 원본의 바이트는 보존한다.

## 검수

- 서버: 지정 계정의 PVE/PVP 저장·재시도·배치 조회, 다른 계정의 보유 행을 조작한 경우도 차단, 공개 풀 제외, 카이론 능력치/장비/링크/공격 주기 일치, 광역기 대상 중복 제거와 PVP 제외.
- 지급: 실 DB와 독립된 PostgreSQL fixture에서 전체 쓰기 단계 실패 롤백, dry-run, 영수증 재시도, 잘못된 계정·임대 잠금 누락 차단, 기존 보유 및 다른 재화·편성 보존.
- 실제 생산 번들: PC 1440×1000·모바일 390×844, 기본 연발·30발 스킬·적 진영·12대상 광역기, 전체 광역기 꼬리 연출, 취소·재개·정리, 도감 편성·새로고침 유지. 결과는 `docs/qa/shiranui-20261015/`.
- 배포는 마지막 운영 소스 기준 scoped 검사와 공식 `npm run deploy:production -- --scoped` 경로로 수행한다. 지급 후 운영 영수증 및 배포 검증 결과는 아래에 기록한다.

## 지급 방식

`scripts/ops/pingdu-shiranui-grant-20261015.mjs`, 영수증 `ops:pingdu-shiranui-grant:20261015:v1`. 운영 USER_LOCK 임대와 사용자 행 잠금 아래 영구 1장을 보유·획득 원장·감사 로그·영수증과 같은 거래에 저장한다. 비용·리미티드 수량 차감은 없고 기존 편성을 자동 교체하지 않는다. 실행기는 비밀 토큰과 짧은 유효기간을 사용하고 종료한다.
