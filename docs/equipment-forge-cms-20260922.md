# 장비 강화 상세 CMS 보완 · 2026-09-22

요청: 장비 강화의 미비 사항을 처리하고 CMS에서 강화 재료·확률·기타 정책을 상세하게 설정한다.

## 운영 점검과 적용 범위

- 운영 조회 시 `equipment_forge_runtime_policy_v1`은 r0/OFF이며 10단계 비용·수량·확률이 모두 null이다. 공개 설정은 r1/공개 ON/실행 OFF다. 공동 승인본은 등록되지 않았다.
- 강화 기본 재료는 2026-09-13 확정 규칙인 **코인 + 마스터의 별**을 유지한다. 신규 경제 수치, 신규 보호권·복구권 지급, 상자·상점 보상풀 편입은 하지 않는다.
- 현재 운영 카탈로그에는 마스터의 별만 있으며 전용 보호권·복구권은 미등록이다. CMS는 등록된 아이템의 이름·코드·활성 여부를 제공한다. 없는 아이템이나 비활성 재료를 지정해 정책을 저장하면 거절한다.
- 공동 출시 게이트, 정책 승인, 유저 강화·복구 실행 OFF를 유지한다. CMS 저장은 미승인 초안 저장이며 TEST도 공동 게이트를 우회하지 않는다. 정책 완성 이후의 실제 출시 승인은 별도다.
- 운영 테이블 변경/DDL/마이그레이션은 없다. 기존 정책 키·CAS·원자적 관리자 로그를 그대로 사용한다. 운영 값도 수정하지 않는다.

## CMS 위치와 설정

`/admin/#equipment-forge`의 **장비 강화** 메뉴에 통합했다. 기존 공동 출시 정책 메뉴의 장비 탭은 이 화면으로 안내한다.

1. 강화 단계: +0→+10 각 단계의 성공/유지/파괴 확률, 코인, 마스터의 별 수량, 보호권 소모 수량. 합계 100%, 성공 하한 10%, 확률 정밀도 0.0001%를 검증한다.
2. 보호권·획득처: 등록 아이템 선택, 시도마다/파괴 판정 때만 소모, 무한의탑·폐차장·카우방별 획득 여부·확률·수량. 상자·뽑기 편입은 불가하다.
3. 파괴 복구: 정책 사용 여부, 코인, 복구 재료와 수량, 파괴 당시 단계/+0 반환, 복구 가능 시간. 비용 0/시간 0은 각각 무료/무기한이며 빈칸과 구별한다.
4. 검증·저장 정보: 미설정 항목 목록, 재료 등록 검사, 정책 버전, 견적 유효 시간 15~900초, OFF/TEST 초안 모드.
5. 유저 공개·안내문, 확정 전투력표·출시 조건은 별도 접이식 영역이다. 공개 설정 저장으로 편집 중인 강화 정책을 지우지 않는다.

모든 정책 탭의 수정은 한 번에 저장한다. 동시 수정 충돌·통신 실패 시 입력을 보존하고, 재불러오기/페이지 이탈 시 미저장 변경을 보호한다. 권한이 사라지면 편집 상태를 제거한다.

## 서버 보완

- 보호권을 마스터의 별과 같은 코드로 설정해 강화 비용과 섞는 오류를 차단한다.
- 보호권 비활성·미등록 상태에서는 견적을 만들지 않는다.
- 잘못된 단계/획득처 행을 5xx가 아닌 명시적인 400 정책 오류로 반환한다.
- 복구 견적 만료 시점을 `견적 유효 시간`과 `실제 복구 마감` 중 더 빠른 시점으로 제한한다. 마감 직전 견적으로 복구 기한을 연장할 수 없다.
- CMS 조회는 보유량·잔액 없이 1회의 제한된 카탈로그 조회를 추가한다. 아이템별 네트워크 요청·주기적 폴링·새 라이브러리는 추가하지 않는다.

운영 배포는 범위 커밋과 origin/main 일치 확인 뒤 `npm run deploy:production`으로만 진행하며, 내부 `release:gate`를 우회하지 않는다.
