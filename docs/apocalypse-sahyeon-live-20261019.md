# 사현 아포칼립스 운영 반영

사용자 `라이브 반영해`로 승인 원화·SD·눈 기술·거대 수호체 궁극기의 운영 연결을 진행한다. 보상은 후속 답변 `아즈마 보상의 2배로 적용`을 따른다. 이전 프리뷰 문서와 `registration-draft.json`은 제작 당시 이력으로 보존한다.

## 적용 정책

- 사현 / 지워진 미래의 관측자, `APOCALYPSE_SAHYEON`, 몬스터 ID 80. 아즈마 다음 아포칼립스 토벌 목표로 추가하며 탑에는 편입하지 않는다.
- 현재 아즈마 CMS 전투력 110,000,000 → 사현 220,000,000. 보스와 6명 잔영의 전투력·HP·공격·방어 예산과 보스 보호막은 2배다. 속도·연타·행동 간격·슈트 스킬 피해 방어 50%는 유지한다.
- 기본 보상 500,000,000 코인, MASTER_STAR 450,000개, STARLIGHT_ARMOR_CORE 300개(신비에너지). 아즈마 코인 기본값 25,000,000을 50,000,000으로 올리고 기존 rewardPercent 1000은 유지한다. 고정 아이템 수량은 2배, 추가 코인 비율은 같은 값을 사용한다. 글로벌 드롭·이벤트·계정 보너스는 변경하지 않는다.
- 현문안 · 정지선: 공격력 상위 4명, 스킬 봉인 각자 4행동. 현문안 · 공백회랑: 전체 회복·재생·흡혈 차단 각자 4행동. 정화 가능.
- 공허법상 · 천경붕괴: 전체 공격력 30%, 보호막 관통 65%. 2.85초에 서버 확정 피해를 한 번 표시하고 4.6초까지 연출한다. 눈 기술은 1.12초 적용, 2.2초 종료다. 사현 기술에만 웹 재생 제한 9초를 부여해 기존 2초 복구가 타격/연출을 자르지 않게 한다.
- 이전 승인 원본 5종을 바이트 그대로 사용한다. `live-approval-20261019.json`에 실제 사용자 채택과 보상 답변을 기록했다. 새 원화를 생성하거나 그림을 변형하지 않았다.

## 구현과 등록 보호

공유 카탈로그에서 ID 80을 인식하고 기존 서버 군단 전투 생성기에 연결한다. 기존 일반 보스의 규칙·그림은 보존한다. 공통 V3 엔진과 모든 기존 소비 번들을 같은 소스로 재빌드하고 메인 로더·서비스 워커 캐시를 함께 갱신한다. 프리뷰의 연출 코드를 공통 V3에서도 사용하며 세션 변경/정리 후 늦은 콜백을 무시한다.

등록 스크립트는 사전 확인된 아즈마 설정과 실제 CMS 값이 같은지 확인하고, 테이블 잠금·프로필 행 잠금 안에서 새 보스·설정·감사 로그·완료 영수증을 함께 저장한다. ID/이름/설정 충돌, CMS OFF, 공개 자산 해시 누락 시 저장하지 않는다. 기존 다른 설정은 바이트 구조 비교로 보존하며 재시도는 영수증을 반환한다. 다음 자동 ID가 80과 충돌하지 않게 시퀀스를 앞으로만 진행한다.

운영 DB 저장 없이 롤백하는 리허설에서 ID 80, 표시 순서 43, 전투력 220,000,000, 기본 코인 500,000,000과 아이템 수량을 확인했다. `docs/qa/apocalypse-sahyeon-live-20261019/registration-dry-run.json`에 결과를 보존한다.

## 검사와 배포 범위

새 보스 등록·전용 FX 분기·해당 기술 제한 시간만 추가한다. 공통 인증·DB 구조·기존 전투 공식·마이그레이션은 바꾸지 않는다. 지정된 scoped 배포를 사용하며 기존 출시 플래그·캐시·Hyperdrive 보호를 유지한다.

선정 검사: 사현 실제 서버 능력치/피해/자산, 사현 운영 등록·보상 원자성·재시도, 기존 아포칼립스 군단 상태/피해, 인접 족로 웹 재생 제한, 실제 번들/메인 진입 버전 연결. `check:worker`로 API 문법도 확인한다. 실제 index.html의 PC/모바일 토벌 버튼 → 사현 전투 → 결과 → 복귀와 이어지는 PVP 매칭 → 전투 → 결과 → 복귀는 격리 API/DB로 검사한다.

직전 실제 운영 소스: `d5d8a37d1a3857118614732ca6942030f30be351`, Pages `ca0bbda8-b847-4a9f-8880-8876f7a8f019`. 새 배포 후 승인 자산과 공용 런타임의 공개 해시를 확인하고 그 증빙으로 일회 운영 등록을 실행한다. 실제 등록/배포 완료 결과는 아래에 별도로 기록한다.

### 배포 전 검수 결과

- 실제 공유 카탈로그의 7명 전투 및 능력치 2배, 5억 코인/45만 별/300 에너지, PostgreSQL 등록 롤백·감사 실패·아즈마 변경 차단·기존 설정 보존·재시도·다음 ID 81, 클리어 지급 원자성/중복 방지, 사현 4.6초 연출 제한 검사를 통과했다.
- Chrome 1440×1000 / 터치 390×844에서 메인 토벌 시작 → 회피 선택 → 사현 전투 → 결과 → 복귀, PVP 매칭 → 전투 → 결과 → 복귀가 통과했다. 첫 테스트의 잘못된 FUR 5장 편성을 실제 제한에 맞는 FUR 2장 + ZENITH 3장으로 수정했으며 운영 코드를 우회하지 않았다.
- 두 화면 모두 봉인 4명, 회복 차단 5명, 궁극기 5명에 각 1회 반영했다. 궁극기 총 HP 피해 23,074,573이 서버 타임라인과 같다. 이 검수 편성은 전투에서 패배했고 정상 패배 정산(보상 0)으로 종료했다. 클리어 보상은 별도 격리 거래 검사에서 검증했다.
- 페이지 오류·가로 넘침·전투 후 잔류 FX 0. `browser.json`과 PC/모바일 이미지에 보존했다. 최초 비동기 화면 조건이 너무 일찍 캡처된 문제는 동기 FX 시간 조건으로 고쳐 실제 수호체가 나타난 시점을 다시 촬영했다.
