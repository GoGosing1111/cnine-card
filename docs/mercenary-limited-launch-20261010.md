# 용병 리미티드팩 ON/OFF · 헬리오스 이미지 · 한도 0 제외

사용자 요청은 헬리오스 엑박 수정, 용병 리미티드팩 ON/OFF 추가와 운영 ON, 발행 한도 0장인 용병의 추첨 제외다. 이전 준비/OFF 정책은 이번 명시적 출시 승인으로 대체한다.

- 헬리오스 원화는 정상이며 CMS/계약실/결과 연출이 공통으로 참조하는 `v-999-640.webp`만 누락됐다. 승인 원화 SHA-256 `BE6BF7819C24C53A7CDB0C2C86D85802AFA1E39FDF62D8F4306B8013CCE62492`를 검증하고 기존 빌더의 width 640 / WebP quality 86 규격으로 파생 파일(640×960, 197,994바이트)을 추가했다. 원본·SD·프레임과 다른 파생 자산은 변경하지 않았다.
- CMS 리미티드팩 상단에 ON/OFF 버튼을 두고 현재 저장 상태, 저장 전 선택, 적용 후 실제 개봉 여부를 분리 표시한다. 저장 사유와 기존 원자적 저장/재시도/버전 충돌 보호를 사용한다.
- 코드 출시 게이트를 열되 새 설치 초안은 OFF다. 개봉은 저장된 mode=ON과 가격/확률/가용 풀 준비 상태를 모두 검사한다. 불완전한 ON 저장은 쓰기 전에 거부하며 OFF 상태에서는 불완전한 초안을 저장할 수 있다.
- 발행 한도 0장은 가중치가 커도 준비/추첨 풀에서 제외한다. 누적 발행 0장과 구분한다. 공개 명부에 `한도 0장 · 제외`로 표시한다. 한 등급의 리미티드가 전부 소진되면 기존과 같이 개봉을 중단하며 확률을 임의 재분배하지 않는다.
