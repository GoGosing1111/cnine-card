# 영토전 시설·전장 개편 — 2026-10-03

## 구현 범위

기존 9거점 영토전 지도와 양 진영 로스터를 유지한다. 현재 거점 선택 → 전장 진입 → 같은 화면의 전체 전장 → 전선으로 돌아가기 → 기존 지도의 흐름이다. 숫자 전선 리본과 기존 SKILL COMMAND 지도 배너는 제거했다. 전황 LIVE와 지휘관 컷인은 제목 아래의 같은 전용 영역을 교대로 사용한다.

`shared/territory-battlefield-v5.mjs`가 기본 수치·CMS 범위·스킬 정의의 기준이다. CMS의 26개 숫자 설정과 사용 여부를 `settings.battlefield`에 저장한다. 모집 마감 후 진영 편성 시 회차 정책을 고정한다. 기존 ACTIVE 회차를 자동 변환하지 않는다. 설정 저장 시 모집 시간을 바꾸지 않았으면 기존 모집 마감 시각을 유지한다.

| 시설 | 확보 조건 | 실제 이득 |
| --- | --- | --- |
| 중계탑 | 양 진영 줄다리기 ±20점, 확보 교전 승리 +4/패배 +1 | 점령 즉시 전력 +20, 유지 중 공성 +15%, 교전 전력 +2, EMP 해금 |
| 보급열차 | 15분 간격 5분, 먼저 20점, 호위 승리 +5/패배 +1 | 전력 +25, 180초 공성 +15%, 해당 열차의 성공 진영 참여자 행동력 +3 |
| 공성포 | 전력 100, 지휘관 권한, 독립 스킬 대기 | 30초 예고 후 적 최대 HP 10%, 대포병 반격 시 50% 감소, 적 시설 60초 정지 |

중계탑·보급 피해 강화는 곱으로 적용하며 서버 트랜잭션이 현재 소유·마비 상태를 다시 읽는다. 양 강화가 활성화되면 +32.25%다. 소유권을 잃으면 중계탑 강화와 EMP 권한을 잃는다. EMP·착탄 마비 중에는 강화·추가 충전과 새 공성포 준비가 중단된다. 이미 예약한 포격은 유지한다. 공병은 시설 마비를 즉시 해제한다. 성벽 파쇄탄은 철벽의 감소율을 절반으로 낮춘다. 기존 지속 작전은 별개로 유지된다.

시설 교전도 실제 개인 PvP 시뮬레이션을 사용한다. 공성 피해만 0으로 바꾸며 기존 에너지·승리 코인·공격 횟수 계약을 유지한다. 열차 보급은 최대 행동력 안에서 한 번 수령한다. 최대치일 때 수령 권한을 없애지 않는다. 전선이 이동한 뒤에도 같은 ACTIVE 회차의 과거 열차 보급을 수령할 수 있다.

## 저장·경합

추가 테이블 6개: `territory_battlefield_policies`, `territory_battlefield_fronts`, `territory_battlefield_trains`, `territory_battlefield_contributions`, `territory_battlefield_supply_claims`, `territory_battlefield_events`.

정책·시설 상태는 기존 영토전 테이블과 분리하며 PG의 ID·밀리초는 BIGINT다. 개인 교전은 기존 APPLIED 영수증과 같은 배치 안에서 기여·전력을 기록한다. 점령·열차 성공 보너스는 1회 적용한다. 보급은 에너지 변경과 열차별 수령 영수증을 원자 처리한다. 공통 회차 → 전선 잠금 순서를 사용하고 stale front·휴전·종료·변경된 지휘권을 CHECK 가드로 확인한다. 공성포는 HP 1을 남기고 개인 점령을 대신하지 않는다. 예약은 전선 ID에 고정하므로 다음 전선을 공격하지 않는다.

운영 DB 스키마는 기존 neondb_owner 소유권을 유지한 채 추가 테이블·인덱스·런타임 DML 권한·독립 마커만 적용한다. 현재 회차·시간·로스터·기존 경제 설정은 갱신하지 않는다. 별도 실전 공격이나 보급 수령으로 운영 검증하지 않는다.

검사에서 발견한 기존 정산 INSERT의 17개 열/18개 자리표시자 오류도 열 목록에서 자리표시자를 만들도록 수정했다. 정산 실패 후 재시도, 이미 수령한 보상 보존, 승리 클랜 승점 1회 반영 회귀가 통과했다.

## 자산·화면

전장 원본 1장과 시설 원본 3장을 `assets/ui/territory-war/battlefield-v5/`에 보존한다. SHA·프롬프트·파생 WebP는 같은 위치의 manifest/prompts에 기록한다. 중계탑과 열차는 실제 전용 이미지이며, 공성포는 포신·포미·포구까지 단일 직선 강체로 검수했다.

시설 UI와 개별 카드 교전의 SIEGE 배경을 연결했다. 전용 sceneAssetKey에만 새 배경을 적용하고 다른 전투는 기존 배경을 사용한다. 공용 렌더러·브리지의 런타임 식별자를 맞추고 기존 소비자 번들을 다시 빌드했다. 연출 ON/OFF, reduced-motion, 숨김·휴전·지도 상태에서의 연출 중단을 제공한다.

## 검증·배포

신규 SQLite/PG 회귀 21개: 고정 정책·레거시·점령/탈환·실시간 피해 강화·EMP 권한·열차 성공·보급 최대치/중복/실패 롤백·전선 이동 후 수령·지휘권/버전 경합·포격 예고/반격/휴전/HP1·실제 공격 경로의 HP/코인/에너지 중복 방지.

관련 기존 영토전·승점·정산·개인 승리·HP 동기화 검사를 수행했다. 브라우저는 실제 index/JS/CSS를 로컬 fixture API로 열어 PC 1600×1000, 모바일 390×844에서 지도·진입·복귀·겹침·목표 선택·실제 Pixi 카드 전투·결과를 검사했다. CMS는 실제 관리자 페이지에서 26개 설정의 조회와 저장을 확인했다. 검수 계정은 가상이며 운영 지급/공격을 하지 않았다.

이번 변경은 시설 서버 동작, 원자 보상, 추가 스키마, 공용 렌더러 배경 연결을 포함하므로 전체 게이트가 포함된 `npm run deploy:production`을 사용한다. 운영 반영 후에는 변경 자산/모듈 반영과 현재 모집 회차의 보존만 짧게 확인한다. 공지 초안은 `notice-territory-battlefield-20261003.md`다.
