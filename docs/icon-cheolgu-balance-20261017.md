# 아이콘 제우스 철구 성능 보강 — 2026-10-17

## 요청과 원인

사용자 요청: “아이콘 … 성능 체크해보고 상향 필요하면 상향시켜 너무 사기는 말고 최상위느낌으로”, 대상 정정 “아이콘 철구”. 대상은 ICON-ZEUS-CHEOLGU / CN-1C000008이다.

운영 revision 3에서 철구는 첫 충전 2행동·첫 시전 3행동, 피해 배율 180%, 집중 20%, 방어 무시 25%였다. 나무늘봉순과 핵심 공격 수치가 같고 충전에 행동을 소비했다. 단순 피해 배율 증가는 대상별 46% 피해 상한에 막혀 PVP 개선이 작았다.

## 적용 내용

| 항목 | 이전 | 이후 |
| --- | --- | --- |
| 충전 행동 | 기본 공격 없이 충전만 | 같은 행동에서 기존 기본 공격을 이어가며 충전 |
| 첫 충전 / 첫 시전 | 본인 2 / 3번째 행동 | 본인 1 / 2번째 행동 |
| 뇌격 공격 배율 | 180% | 220% |
| 빈 대상당 번개 집중 | 20% | 25% |
| 뇌격 방어 무시 | 25% | 30% |

재사용 대기 4행동, 최대 6회 시전, 최대 3명 타격, 대상별 전체 시전 피해 상한 46%, PVE 100% / PVP 90% 적용률을 유지한다. 대기 후 충전하고 다음 행동에 시전하므로 연속 시전 간격은 기본 5행동이다. 추가 턴·게이지를 만들지 않는다. 공격력·HP·속도 등 기본 능력치, 다른 8개 ICON 설정, 획득 정책, 용병 성장 및 확장 기법 OFF 상태는 변경하지 않는다.

봉인 중에는 충전을 취소하고 다시 충전해야 한다. 충전 알림에는 continuesBasic=true를 기록하며 서버 전투 시간과 클라이언트 가속 행동 수에 중복 산입하지 않는다. 기존 배너만 기본 공격과 함께 표시한다. 이전 영수증은 새 플래그가 없으므로 기존 충전 연출 시간을 유지한다.

## 비교 결과와 해석

운영 FUR 카탈로그·고급 강화·전투·아이콘 설정을 읽기 전용으로 확보하고 실제 서버 전투 함수로 비교했다. 같은 동료, 장비 0/500만, 전열/후열, 양 진영, ICON 1장/조은 동반 2장 조건이다. 각 버전당 PVP 2,880전 + 단일 보스 PVE 2,160전, 합계 5,040전이다.

| 표본 | 이전 비교 승률 | 상향 후 비교 승률 |
| --- | --- | --- |
| 선정용 24개 난수 | 33.40% | 63.33% |
| 별도 24개 난수 검증 | 33.37% | 63.33% |

이 수치는 통제한 표본의 비교 승률이며 실제 랭크전 승률 또는 모든 조합에서의 순위가 아니다. 구수댕 상대의 열세가 남고, 별도 표본에서 단독 디임 상대는 약 49%다. 선정 표본의 단일 보스 평균 처치 행동은 약 51.0 → 41.6으로 줄었으며 9종 중 두 번째였다. 모든 카드가 해당 보스를 처치하므로 승리 여부 대신 행동 수로 효율을 비교했다.

같은 발테르/카이론을 양쪽에 편성한 추가 768전씩에서는 V-996 33.07% → 35.42%, V-988 30.99% → 34.11%였다. 기존 2026-10-08 용병 전투 fixture와 현재 정적 편성 프로필을 사용한 회귀 표본이다. 강한 용병이 빠르게 승부를 결정하는 조건의 개선폭은 작다. 이를 최상위 용병까지 항상 이기는 카드로 해석하지 않는다.
