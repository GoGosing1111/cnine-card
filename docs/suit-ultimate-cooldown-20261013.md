Z의 기존 첫 15초 대기를 X와 같은 즉시 발동으로 바꿨다. 서버 전투 시계의 0·40·80초 경계에서 시전하며 별도의 브라우저 타이머를 추가하지 않는다. 이미 확정된 전투 영수증을 다시 판정하지 않고 신규 전투 생성부터 적용한다.

오버로드의 신규 장비 설명은 실제 주기로 생성한다. 기존 DB 설명의 옛 “이후 18초마다” 문구는 장비 목록/상세 응답을 만들 때만 40초로 바꿔 표시한다. 운영 DB·CMS 설정·재화·소유권·승인 원화와 모션을 수정하지 않는다.

공식 빌드로 공용 전투 소비자 10개를 갱신했다. 런타임 표식은 `suit-ult-40s-20261013-v1`, 셸 캐시는 `20261013-suit-ult40s1`이다. 기존 발테르/헬리오스 대사 검사는 후속 캐시 버전도 허용하도록 현재 앱·서비스워커 버전의 일치를 검증한다.
