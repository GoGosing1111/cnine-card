# 시라누이 백은 탄환·단일 연사 강화·SSS 대사 — 2026-10-18

사용자 요청: 시라누이 사격 투사체를 화려하게 강화하고 단일 스킬 효과와 일러스트 분위기에 맞는 SSS 리미티드 멘트를 추가한다.

## 반영 범위

- 승인 원화의 흑백·백은 탄환·군기·광륜을 기준으로 built-in ImageGen에서 전용 탄도 12프레임, 백은 파열 12프레임, 은색 군기 대사 프레임을 새로 제작했다. 생성 PNG 바이트·최종 프롬프트·참조·SHA-256은 `assets/ui/project-v/mercenaries/shiranui-fx-20261018/`에 보존한다. 원화·SD·총기·반동 모션과 군기 아우라는 그대로다.
- 기본 9발과 단일 30발 사격에 더 큰 은탄·백색 번개 꼬리·검은 잔연·총구 섬광·은색 파편을 사용한다. 실제 총구의 변환된 축에서 출발해 실제 대상 가슴으로 이동하며 반대편 사격도 같은 좌표 계약을 따른다.
- 30발 단일 변주는 기존 해골 낙인 아래 백은 균열을 쌓고, 6발마다 파열을 더한 뒤 마지막 탄환에 12단계 파열·해체·잔광을 재생한다. 기존 광역기의 25발 엄호와 포탄 비행도 동일 새 탄도 이미지를 사용한다. 화면 전체 백색 플래시나 추가 카메라 흔들기는 넣지 않는다.
- 동작 줄이기는 총구/적중 빈도와 불투명도를 낮추고 연사 중 추가 파열을 생략한다. 마지막 파열도 작게 줄이며 피해 접점은 동일하다.
- 전용 은색 군기 이미지 프레임과 기존 원화 초상을 기존 SSS 공용 대사 레일에 연결했다. 기본 등장 대사와 단일/광역 스킬 발동 대사 5종을 순환한다. PVE와 허용된 협동 격전지의 기존 표시 정책을 따르고 PVP·실제 레이드는 표시하지 않는다. 문구·이름·기술명·SSS LIMITED는 DOM이다. 320px에서는 기술명 보조 문구를 숨겨 대사 공간을 확보한다.
- 시라누이와 다른 SSS 화자가 섞여도 레일의 최대 높이를 먼저 확보한다. 중단·재개·퇴장 시 효과와 대사 멤버를 함께 정리한다.
- 수치·공격 횟수·접점·PVE 광역 피해·PVP 정책·지정 계정 조건·획득 잠금·보유분을 변경하지 않는다. 새 이미지의 기술 검수와 사용자 최종 시각 승인은 구분한다.

대사:
1. 망령의 군기가 올랐다. 사격 개시.
2. 침묵해라. 다음은 백은의 탄환이다.
3. 탄도는 정해졌다. 빗나갈 일은 없다.
4. 광륜이 꺼지기 전에, 전장을 끝낸다.
5. 마지막 탄피가 떨어지면, 고요만 남는다.
