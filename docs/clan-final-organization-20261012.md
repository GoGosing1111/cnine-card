# 마지막 챔피언스리그와 조직 개편 준비 · 2026-10-12

사용자 지정: 12일 21시부터 마지막 챔피언스리그를 진행한 뒤 클랜 시스템을 종료한다. 이전 클랜을 승계하지 않고 새 조직으로 출발하며, 이번에는 준비 화면부터 공개하고 모집은 추후 시작한다.

## 확정 범위

- 시즌 3 / id 6, 삼성–LG 2·3위전은 2026-10-12 21:00~23:00 KST. T1 결승은 같은 날 23:00~2026-10-13 01:00. 2026-10-05 승인된 각 120분 규칙을 그대로 사용한다.
- 개막 전 대회 318의 일정과 시즌 종료만 이동한다. 시드 T1·삼성·LG, 고정 명단 50명, 정규 경기·점수·기존 보상 정책은 보존한다.
- 기존 매분 Durable Alarm이 챔스 경계에서 자동 진행한다. 결승이 실제 종료되고 우승 보상 SENT, 기존 세력전 정산까지 완료해야 종료 영수증과 클랜 OFF·scheduleEnabled false를 한 거래로 저장한다. 진행 중 전투는 기존 120초 회수 규칙을 유지한다. 오류는 닫지 않고 재시도한다.
- 다음 클랜 시즌·등록·드래프트·초기화는 차단한다. 종료된 클랜의 변경 요청은 OWNER 바로가기·구버전 화면도 차단하고, 늦게 도착한 설정 저장이 OFF를 덮어쓰지 못하도록 저장 조건도 검사한다.
- 기존 멤버·전적·우승·지급 기록은 역사 데이터로 보존한다. 명함의 현재 클랜 소속 표시는 종료 영수증 뒤 숨기고 수상 이력은 유지한다. 새 조직에는 멤버·점수·공동 자산을 복사하지 않는다.
- 새 조직은 PREPARATION, 15개·각 10명, registrationOpen false. 별도 가입 테이블·점수 지급·해금 조건·경제 정책은 만들지 않는다. 모집 및 실제 조직 콘텐츠 출시 일정은 미정이다.

## 화면과 자산

- 실제 클랜 화면에 조직 개편 탭과 마지막 대회 안내를 연결한다. 종료 후에는 조직 준비와 마지막 대회 기록만 제공한다.
- 새 도시 야경 원본은 내장 image_gen으로 생성하여 `assets/ui/organization/city-night-v1.png`에 보존했다. 최종 프롬프트·도구 모드는 같은 경로의 generation JSON에 있다.
- 사용자 제공 구상도·문양 PNG는 바이트 변경 없이 보존했다. 문양과 건물은 원본을 SVG viewBox로 표시하는 UI이며, 승인 원본을 재생성하거나 덮어쓰지 않는다.
- PC는 15개 문양 선택과 상세 패널, 모바일은 문양 선택 시 확대 대화상자를 제공한다. 실제 가입 동작은 없다. 아지트 5단계 장면과 조직 전용 콘텐츠 구상을 연결하고 원본 포스터는 펼쳐보기로 보존한다.
- 독립 공개 안내: `/preview/organization-renewal-20261012-v1/`.
