# 카이론 사격 후 축소·카이론/헬리오스 광역 폭발 수정

사용자 제보: 카이론이 사격 스킬 사용 후 사라져 보이고, 카이론·헬리오스의 광역 폭발이 보이지 않거나 너무 빨리 끝난다.

## 원인과 수정

- 카이론은 사격 정리 시 362×543 모션 프레임을 남겨 둔 채 공통 IDLE이 원래 1024×1536 SD의 배율을 적용했다. 실제 전투 번들에서 전체 스프라이트 높이가 110.22px로 줄어드는 현상을 재현했다. 정리할 때 원래 텍스처·발 기준점·크기를 함께 복구해 정상 311.79px로 돌아온다. 반복 사격과 다음 행동에 의한 조기 정리에도 동일하게 적용한다.
- 두 광역기는 첫 피해 직후 호출자에게 완료를 알렸고, 다음 행동이 공유 대상의 남은 효과를 취소했다. 자동 전투 배속까지 겹치면 폭발이 몇 프레임만 표시됐다. 광역기 전체 시퀀스가 끝난 뒤 다음 행동을 진행하며 자동 배속의 추가 가속을 적용하지 않는다.
- 승인된 모션 자체의 2.6배 재생은 유지한다. 일반 설정에서 카이론은 전체 3.00초(첫 타격 1.25초), 헬리오스는 전체 약 2.23초(첫 타격 약 0.95초)다. 동작 줄이기는 기존 진무 방식과 같은 별도 8배 단축을 따른다.
- 원화·직선 탄도·수직 미사일·폭발 위치·흰 테두리·고정 스코프를 보존한다. 서버 피해·대상·재사용·스탯·제작·획득 정책은 변경하지 않는다.
- 공통 V3 소비 번들 10개를 정식 빌더로 갱신하고, 메인 로더·래퍼·런타임 버전과 캐시 키 `mercenaryFx=20261015-lifecycle`을 일치시킨다.

## 검증

`tests/mercenary-visual-lifecycle-20261015.browser.mjs`는 실제 배포 번들과 라이브 래퍼를 사용하는 로컬 브라우저 검사다. 운영 계정을 변경하지 않는다.

- PC 1440×1000 / 모바일 390×844 각각 카이론 아군 사격, 적군 사격, 카이론 광역, 헬리오스 광역: 8개 통과.
- 자동 배속을 4배로 설정해도 두 광역기 타임라인은 1배로 진행하고, 폭발 정점에서 호출자가 아직 완료되지 않았음을 확인했다.
- 서버 사냥 세션이 생성한 12대상 광역 영수증을 재생해 체력 동기화·피해 표시가 대상마다 1번만 적용되는지 확인했다. 일반 사격도 1회만 적용한다.
- 카이론은 사격 중·종료·반복 사격·다음 행동에 의한 정리·전투 취소에서 크기와 양 진영 방향을 확인했다. 전투 취소 후 모션·잔여 효과가 정리된다.
- PC·모바일 스크린샷에서 카이론 본체와 두 광역 폭발을 직접 확인했다. 브라우저 오류 0건.
- 전후 수치와 8개 결과는 `docs/qa/mercenary-visual-lifecycle-20261015/report.json`에 보존한다. 이미지와 원시 결과는 작업 호스트의 `C:/Users/User/.codex/tmp/mercenary-visual-lifecycle-20261015/{before,after}/`에 있다.
