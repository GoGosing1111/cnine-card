- 기존 `아윤방 핀볼 이벤트` 사은품 상자 발송과 별개인 이번 지급이다. 메시지 발송은 계정 잔액·재고를 직접 변경하지 않으며 사용자가 메시지함에서 수령한다.

## 실행과 검증

- 도구: `scripts/ops/ayoon-pinball-verified-rewards-20260928.mjs`.
- 작업 키: `ops:ayoon-pinball:verified-rewards:20260928:v1`.
- 캠페인: `ayoon-pinball-verified-coin-20260928-v1`, `ayoon-pinball-verified-star-20260928-v1`.
- 기존 두 보상 캠페인의 트랜잭션 구조를 재사용한다. 인증 대상 해시와 기존 지급 유무를 확인한 뒤 두 보상·메시지·감사 로그·완료 영수증을 함께 COMMIT한다. 실패하면 모두 ROLLBACK하며 같은 키 재시도는 원래 영수증을 검증한다.
