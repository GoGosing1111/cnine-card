# 펫 꽝 확률 · 결과 팝업

사용자 후속 요청으로 꽝(펫 지급 없음)을 개봉 확률에 추가하고, 모든 개봉 결과를 전용 모달 팝업에서 확인하도록 변경했다.

관리자 → 펫 개봉·아이템 → 획득 풀·꽝 확률에서 펫별 가중치와 꽝 가중치를 조정한다. 꽝 확률 = 꽝 가중치 / (선택한 펫 가중치 합 + 꽝 가중치). 펫 합계 50·꽝 50이면 꽝 50%다. 0은 꽝 제외이며 이전 저장 설정의 누락 필드는 0으로 읽어 기존 확률을 유지한다. 실제 꽝 비율은 아직 사용자 지정이 없으므로 임의 운영 비율을 넣지 않는다. 획득 풀이 없는 실제 개봉 OFF 상태도 유지한다.

봉인구·정수는 추첨 횟수 전체에 대해 차감하고 꽝은 펫 보유 목록에 넣지 않는다. 꽝·성공 순서와 수량을 기존 거래 영수증에 함께 저장한다. 같은 요청 재시도로 꽝을 재추첨하지 않으며 거래 오류 때 차감과 결과 저장을 모두 되돌린다.

팝업은 성소 배경과 봉인구 원화를 재사용한 상단, 개봉·펫·꽝 요약, 실제 펫 원화와 합산 수량, 꽝 카드, 사용 아이템 및 확인/계속 개봉 버튼으로 구성했다. 전부 꽝인 경우도 별도 제목과 표시를 제공한다. native dialog의 키보드 포커스와 배경 조작 차단을 사용하고 모바일 긴 결과는 팝업 내부에서 스크롤한다.

검증은 펫 개봉 관련 기존 회귀, 새 꽝 가중치·확률·동시 차감·전부 꽝·혼합·영수증 재사용·오류 rollback(SQLite/PostgreSQL)에 한정한다. 실제 Chrome PC 1440px·모바일 390px에서 CMS 확률 변경과 결과 모달/전부 꽝 모달, 닫기·계속 개봉, 응답 단절 재시도, 넘침 및 JS 오류를 검수했다. 관련 검사와 운영 반영은 기존 scoped 정책을 따른다.
