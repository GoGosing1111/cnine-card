# 용병 성장과 PVP 전투력 보너스 공동 적용

2026-10-16 사용자 공동 적용 지시와 필요 경험치 3배·돌파 10% 후속 정정을 반영한다. 공지문 작성까지 요청됐으며 게시하지 않는다. 기존 2026-10-15 준비 문서의 OFF와 작은 전투력 보너스보다 이번 지시가 우선한다.

## 적용 수치

PVP 편성 전투력 비율 `R`에서 `G=max(0,log2(R))`를 사용한다. 피해 보너스는 `min(0.6,0.3*G)`, 게이지 충전 보너스는 `min(0.2,0.1*G)`다. 2배에서 +30%/+10%, 4배 이상에서 +60%/+20%다. 서버가 확정한 시작 편성 카드 5장·기존 장비·용병 기본/개인 장비만 합산한다. 성장·연계 파생 스탯을 중복 환산하지 않는다. 듀오는 소유자별 상대 평균, 영토전은 기존 보정 후 편성, 예전 저장 전투는 기존 판정을 유지한다. 5장 미만 기존 전투는 이 보너스를 적용하지 않고 정상 실행한다.

모든 등급 재료 기본 100 EXP, 동일 용병 300 EXP. 일반 용병의 현재 레벨 필요 경험치는 `3*(200+50*level)`: 750부터 3,600까지 레벨마다 150 증가. 리미티드는 정확히 5배다. 5/10/15/20 돌파 성공률은 각각 100,000ppm(10%). 재료 경험치를 3배 더 늘리거나 성공률을 단계별로 낮추지 않는다. 코인·마스터의 별 비용 0, 기본 1장 보호, 일반 레벨 잔여 XP 이월, 돌파 초과 XP 사전 동의, 실패 시 현재 XP 0·기존 레벨/효과 보존을 유지한다.

V2 성장표는 레벨당 체력/공격 25%, 방어 6%, 속도 1%; 돌파마다 체력 100%, 공격 125%, 방어 15%, 속도 2%, 배정 스킬 5%다. 최종 누적 체력 875%, 공격 975%, 방어 174%, 속도 27%, 스킬 20%. 기존 성장 후 PVP 전투력 보너스를 별도로 한 번 적용한다. 표시용 용병 속도도 실제 보너스 적용 속도와 일치시킨다.

기본 스탯/스킬 성장은 해당 용병의 일반 PVE/PVP에 반영한다. 경감 관통·행동 대응·추가행동 숙련은 PVP 전용이다. 관통/대응은 상대보다 높은 레벨에서만 `min(1,레벨차/10)`을 곱한다. 고유 효과와 기존 리미티드 성능을 일괄 하향하지 않는다. 족각도시는 계정 성장을 제외하는 전용 규칙을 유지한다.

## 설정과 운영

- 승인된 독립 프로필: `shared/mercenary-growth-launch-20261016.mjs`. 미입력 CMS 기본값은 여전히null/OFF이며 조회 중 자동 채택하지 않는다.
- 일회 적용: `scripts/ops/mercenary-growth-launch-20261016.mjs`, 영수증키 `ops:mercenary-growth-launch:20261016:v1`. 정책 이전값의 SHA-256 충돌 검사, 전용 빈 테이블 설치·정책·감사 기록·영수증 단일 거래, 재시도 중복 방지, 후속 CMS 편집 보호를 제공한다. 기존 보유·레벨·과거 QA 기록을 이관하거나 지급하지 않는다.
- CMS는 서버의 releaseEnabled와 policy.mode를 표시하고 ON/OFF 저장을 지원한다. 미완성 ON은 클라이언트/서버 모두 차단한다. OFF 상태조회는 새 성장 테이블 없이도 동작한다.
- PC 1440px·모바일 390px에서 750/3,750 EXP와 10% 표시·Lv.5 1,350 EXP·공개 성장 버튼·검수 조작 미노출·CMS 입력값과 ON/OFF 저장을 로컬 API 대역으로 확인했다. 실제 계정 카드 소모 없음. `qa/pvp-growth-launch-20261016/ui/report.json`.
- 유저 공지문: `pvp-growth-launch-notice-20261016.txt`. 적용된 수치·20레벨 필요량·돌파/실패·누적 성장·PVP 숙련을 포함한다.

## 전투 비교

`scripts/measure-pvp-growth-launch-20261016.mjs`로 고정 합성 편성 12,800전을 실행했다. 일반 SSS 4종 대 리미티드 SSS 5종, 카드당 2천만, 4타입 덱, 8시드/양진영, 8레벨 조합을 확인했다. 균형 덱의 Lv.1/Lv.20 대 Lv.1에는 카드 전투력비 1/1.25/1.5/2/4도 비교했다. 카드비와 용병까지 포함한 실제 편성비는 보고서에서 별도로 기록한다.

같은 카드 전투력 조건의 일반 Lv.20 대 리미티드 Lv.1은 464/1,280(36.25%), Lv.20 대 Lv.6은 117/1,280(9.14%), Lv.20 대 Lv.11은 29/1,280(2.27%)였다. 같은 레벨 1/1 및 20/20은 각 0/1,280이었다. 이 수치는 지정한 합성 편성의 결과이며 운영 평균 승률이 아니다. 서로 다른 시드·카드 전력 범위를 쓴 이전 46,080전 결과와 단순 전후증감으로 비교하지 않는다.

## 검증과 배포 기록
