# 미라클 버닝 — 2026-09-29

사용자 요청에 따라 기존 버닝에 MIRACLE 모드를 추가한다. 기본 OFF이며 운영 발동은 인증된 OWNER이면서 닉네임이 정확히 `핑크빛유두`인 계정만 가능하다. 일반·하이퍼 버닝의 기존 전체 OWNER 권한은 유지한다.

## 운영 규칙

| 항목 | 미라클 버닝 진행 중 |
| --- | --- |
| 아포칼립스 | 최대 10회, 5분마다 1회 충전 |
| PVP / 일반 PVE | 각각 최대 30회, 1분마다 1회 충전 |
| 전투 코인 | 관리자가 1~100배 설정, 기본 100배 |
| 드랍 | 기존 확률 ×1.3, 최대 100% |
| 시간 | 기존 버닝의 30/60/120분 선택, 기본 60분 |

드랍률은 사용자 답변 `10% → 13%`를 따른다. 아바타 드랍 보정 뒤 미라클을 곱하며, 고정 수량·희귀도별 상대 가중치·일일 한도·개봉 확률은 바꾸지 않는다. 공통 카드·장비·마법 결정·주간 큐브·팩/티켓 드랍과 통합 드랍풀에 적용한다. 군단토벌은 기존 원정 생성 시점의 정책 스냅샷에 적용하며, 이미 확정된 원정·보상 영수증을 재판정하지 않는다.

미라클 ON은 기존 일반/하이퍼를 같은 DB batch에서 OFF로 저장한다. 진행 중 다른 OWNER의 일반/하이퍼 활성화, 족장 버닝과 숲켓랜드 하이퍼 발동권 사용은 거부한다. 전용 OWNER는 기존 모드로 전환할 수 있다. 종료·OFF 이후 서버는 기존 설정을 다시 사용하며, 아포칼립스는 5회/30분으로 복귀한다. 발동 시각은 행동력 저장과 같은 초 단위로 맞춰 첫 초의 반복 충전을 방지한다.

## 구현과 검수 범위

새 app_meta 키 `miracle_burning_event_settings_v1`과 전용 `admin/miracle-burning-event` GET/PATCH를 사용한다. 새 테이블·마이그레이션·의존성·인증 체계 변경은 없다. 기존 PVE/PVP 보상 계산과 원자적 차감/지급·재시도 처리를 그대로 사용한다.

하늘색 전용 ImageGen 이미지·팝업·CMS를 연결했다. 프리뷰와 이미지 기록은 `preview/miracle-burning-v1/`에 있다. PC·모바일 검수는 해당 README에 기록한다.

관련 검사:

- `tests/miracle-burning-20260929.test.mjs`: 전용 권한, 우회 경로 차단, 고정 혜택/100배 저장, 버닝 전환 batch 롤백, 1.3배 확률/상한/요청 캐시, 드랍 상대 가중치·수량, 군단토벌 스냅샷, 실제 아포칼립스·PVE·PVP 차감/충전/기본 복귀, 클라이언트 만료 처리. 최종 scoped 배포에서 실행.
- `tests/avatar-drop-rate.test.mjs`: 공통 드랍과 PostgreSQL 실지급·재시도·한도 검사 통과. 아바타 +100%인 10% 드랍은 미라클 중 26%, 종료 후 새 요청 10%; 기존 영수증 유지.
- `tests/burning-owner-access-20260927.test.mjs`, `tests/burning-owner-timer-v1902.test.mjs`: 기존 OWNER 권한과 시간 선택 검사 통과.
- `tests/pve-apocalypse-v1952.test.mjs`: 독립 행동력·클라이언트·화면 연결 검사 통과.
