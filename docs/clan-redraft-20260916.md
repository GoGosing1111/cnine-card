## 운영 반영 계약

- 시즌 ID 5 / 시즌 2, 기존 156명 + 박세라-ㅂ-(ID 45) = 157명.

- 박세라-ㅂ-의 기존 선호 역할·활동 시간을 이어받고 현재 랭크 덱을 등록한다. 참가 취소된 이용자를 재등록하지 않는다.
- `REDRAFT_WAIT` 단계는 신청 기간이 아니다. 참가·지명 API가 닫히고, 화면은 자동 참가 유지와 정확한 재시작·마감 시각을 표시한다.
- 2026-09-16 19:00 KST 시작, 20:00 마감. `clan_draft_scheduler_v1`의 기존 영속 알람이 접속 없이 시작하며 일반 조회도 동일한 잠금·멱등 처리를 사용한다.
- 참가 풀의 후보 키를 재발급해 이전 지명 키를 재사용하지 않는다. 시작 시 기존 활동·랭크·기여 평가식을 다시 계산한다.

- 수동 지명, 시간 초과 순번 전환, 마감 자동 편성 모두 동일한 클랜별 정원을 사용한다. 30초 미지명 패스와 1시간 종료 정책은 유지한다.
- 시즌 활성화 전에 모든 클랜이 자기 정원을 채웠고 AVAILABLE 참가자가 없는지 검증한다. 이 재지명 기록이 없는 다른 시즌은 기존 정책을 유지한다.
- 기존 첫 전투 2026-09-17 21:00 KST 및 대진 28개는 보존한다. 편성 초기화 전 전투·보상·정산 기록이 0건인지 검사하고 원본 스냅샷과 운영 감사 기록을 같은 트랜잭션에 보관한다.
