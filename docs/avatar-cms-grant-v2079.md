# OWNER 아바타 직접 지급

## 운영 경로

CMS → 아바타 관리 → **아바타 직접 지급** (`/admin/avatar-grant`).
선택한 아바타 1종을 정확한 닉네임 최대 30명에게 영구 지급한다.
닉네임은 줄바꿈으로 구분하며 이름 내부의 공백·특수문자는 유지한다.

1. 사용·공개 ON 아바타 선택, 닉네임 및 사유 입력
2. 서버가 정확한 계정 ID와 보유 상태 확인
3. 확인 체크 후 지급: 신규 / 기간제→영구 전환 / 영구 보유 건너뛰기
4. 다음 지급은 **다른 계정에 새로 지급**에서 시작

OFF/TEST/ON 공개 설정, 장착/장착 쿨타임, 코인 및 기타 아이템은 변경하지 않는다.
이 기능은 메시지 지급이 아니라 아바타 보유 목록에 직접 지급하는 기능이다.

## 안전 계약

- `POST /api/admin/avatars/grant`: `preview`, `apply`, `status`, `cancel`.
- 기존 SETTINGS 인증에 더해 활성 OWNER를 트랜잭션 내 재검증한다.
- `preview`는 정확한 이름 조회만 허용하며 누락·중복·비활성 계정은 전체 거절한다.
- 대상과 아바타 이름/코드/버전을 고정하고 적용 시 재검증한다. 확인 유효기간 15분.
- 모든 보유 변경, `AVATAR_ADMIN_GRANT` 관리자 감사로그, `app_meta` 영수증을 같은 PostgreSQL 트랜잭션으로 커밋한다.
- `apply`는 클라이언트가 전송 전에 저장한 같은 `previewId`만 사용한다. 새로고침/통신 실패 시 재확인 가능하며 완료 요청은 재실행하지 않는다.
- `cancel`은 영수증 행 잠금으로 적용과 직렬화한다. 미처리 요청만 취소하며 이미 완료한 지급은 회수하지 않는다.
- 영구 소유는 출처와 취득 시각까지 그대로 유지한다. 기간제는 영구로 전환한다. 미공개 아바타를 자동 공개하지 않는다.
- 일회성 운영 스크립트, 토큰 및 운영 조회 결과는 공개 배포 폴더에 포함하지 않는다.

## 검증

- PGlite에서 실제 PostgreSQL SQL 실행: 배치 지급, 영구 보유 유지, 기간제 전환, 원자적 롤백, 동일 요청 재전송, 이중 클릭, 취소/지연 적용 경합.
- 권한, 정확한 이름, 계정 상태·이름 변경, 아바타 버전·공개 변경, 만료 및 타 OWNER 영수증 차단.
- UI 세션 복구/대상 불일치 차단, CMS 링크 및 캐시 태그 검사.
- 로컬 UI fixture에서 아바타 이미지, 다중 대상 확인, 체크박스·지급 버튼, 완료 및 새 지급 초기화 검수. 1280px 화면 가로 넘침 없음. fixture는 운영 계정/재화를 사용하지 않는다.
- `npm run test:avatar`에 신규 테스트를 추가하여 `release:gate`에 포함.
