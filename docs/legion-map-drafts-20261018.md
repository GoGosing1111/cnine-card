# 군단토벌 나머지 5개 맵 필드 드랍 초안

사용자 지시: “군단토벌 잊혀진섬에 있는 방식으로 나머지 맵들도 다 똑같이 채워봐 나머진 내가 추가수정함 off로 유지”.

## 적용 범위

- 검은 돛의 해안·유리 사막·끝나지 않는 대극장·거수의 뱃속·역천 제도 5개 맵에 잊혀진 섬의 필드 드랍 후보·사용 여부·가중치·최소/최대 수량·난이도별 일반/보스 확률·소멸 시간을 독립 복사한다.
- 운영 조회 시 기준은 잊혀진 섬 r29, 후보 12종이었다. 실제 적용은 트랜잭션 안에서 다시 읽은 현재 원본을 사용한다. 보통/어려움/악몽/지옥을 그대로 복사하고 추가 난이도 재앙만 지옥 값을 초안으로 사용한다.
- 기존 지역 전투 능력치·몬스터·보스·세트/고유 장비·연마석 설정은 보존한다. 일반 필드 드랍은 지역 전용 전리품과 독립 추첨하며 같은 처치에서 겹치면 기존 묶음 수집·종료 정산으로 지급한다. 필드에 놓인 묶음의 소멸 시간은 해당 맵 필드 드랍 설정을 따른다.
- 5개 지역 전체 운영은 **OFF**다. 이전 TEST/OWNER 검수 정책을 대체한다. 잊혀진 섬의 운영 모드와 설정, 지역 장비의 활성·공개·보급, 연마 정책은 변경하지 않는다. 아이템 지급이나 입장 횟수 변경은 없다.

## 수정 위치

OWNER CMS → 군단토벌 → 지역 확장 · 전투와 전리품 → 맵별 필드 드랍.

맵 탭을 선택해 후보 추가·제외, 드랍 사용, 가중치, 수량, 난이도별 확률을 수정한 뒤 **지역 설정 저장**으로 저장한다. 탭 이동 중 입력값은 유지한다. 각 맵은 독립 저장본이므로 이후 잊혀진 섬 수정이 자동으로 덮어쓰지 않는다. 지역 공통 전투·전용 장비 드랍 편집은 기존 위치에 유지한다.

`regions[].fieldDrops`는 선택 필드로 확장해 기존 세션·정책과 호환한다. 저장 시 기존 잊혀진 섬과 같은 현재 카탈로그 검증을 사용하며 최대 맵당 100종이다. 필드 수량은 서버 추첨하고 새 원정에 정책을 고정한다. TEST 보상 미지급·OFF 입장 차단·종료 영수증 중복 지급 방지를 유지한다.

## 적용 및 검수

- 일회 작업: `scripts/ops/legion-map-drafts-20261018.mjs`. 작업 키 `ops:legion-map-drafts:20261018:v1`. PostgreSQL 트랜잭션·설정 행 잠금·감사 로그·완료 영수증을 함께 저장한다. 재실행은 영수증을 반환하며 사용자 후속 편집을 덮어쓰지 않는다.
- 운영 dry-run은 5개 맵 × 후보 12종 × 난이도 5개, OFF r1을 확인한 뒤 롤백했다. 실제 적용은 새 런타임 배포 이후 진행한다.
- 자동 검사 범위: 신규 초안 복사/멱등성/롤백/맵별 독립 편집/정책 검증/OFF 차단/TEST 미지급/ON 정산, 기존 지역 묶음/장비 정산, 기존 잊혀진 섬 CMS. SQLite와 PostgreSQL 격리 DB를 사용한다. 전체 게임 검사는 실행하지 않는다.
- 실제 로컬 CMS: 1440px 및 390px, 5개 탭 후보 12종, 가중치 수정 후 다른 맵 보존, 저장·재조회, 후보 추가·제외, OFF 유지, 가로 넘침·이미지 누락·JS 오류 없음. 화면은 `docs/qa/legion-map-drafts-20261018/`.
- 전용 프레임은 ImageGen 원본 및 무손실 WebP를 사용한다. `assets/ui/legion-regions-v1/cms/manifest-20261018.json`에 프롬프트·해시를 보존했다. 기능·화면 검수는 사용자 시각 승인으로 기록하지 않는다.
