# 용병 행동·피해·체력 긴급 상향 · 2026-09-14

사용자는 용병의 실전 체감이 여전히 부족하다고 지적하며 행동 횟수·데미지·체력을 늘리고, 별도 체감 검수 대기 없이 운영에 반영하도록 지시했다.

아군 일반 카드 1회 행동마다 용병 추가 행동 1회를 부여한다. 기존 3회당 1회보다 예약 행동 기회가 3배 늘어난다. 일반 카드 턴·게이지·난수·행동 제한을 소모하지 않고, 자기 행동으로 추가 행동을 재생산하지 않는다. 사망·기절·스킬 준비·재사용·대상 소실 규칙은 유지한다.

자기 편 일반 카드 5명의 전투 시작 평균 공격력·최대 체력을 기준으로 다음 최소 능력치를 적용한다. 기존 능력치가 더 높으면 보존하며 배틀슈트·적·다른 용병은 산정에서 제외한다.

| 등급 | 최소 공격력 | 최소 최대 체력 | 전용 방벽 |
| --- | ---: | ---: | ---: |
| C | 60% | 80% | 60% |
| B | 75% | 100% | 70% |
| A | 90% | 120% | 80% |
| S | 120% | 150% | 90% |
| SS | 160% | 200% | 120% |
| SSS | 220% | 280% | 150% |

SS 최소 공격력은 기존 평균 85%에서 160%로 상승한다. 체력은 실제 서버 maxHp/hp에 반영하며, 기존 방벽만 늘리는 방식이 아니다. 시작 시 체력 비율을 보존하고 초기화를 반복해도 회복·방벽을 재지급하지 않는다. 피해·회복·보호 스킬은 같은 연계 공격력을 사용한다. CMS의 스킬별 개별 수치와 등급별 기본 전투력, 보유·개봉·1회 보장 정책은 유지한다.

PVE·PVP가 내보내는 용병 시작 스냅샷에도 서버가 적용한 실제 최대 체력·현재 체력·방벽을 기록해 V3 HP 표시와 판정을 일치시킨다. 도감과 CMS의 연계 설명은 동일 정책을 표시한다. 기존 승인 스킬 프레임·사운드·렌더러를 재사용한다.

별도 대규모 성능 실험이나 사용자 시각 검수 대기는 추가하지 않는다. 변경 회귀와 필수 release:gate는 deploy:production 안에서 수행하고 운영 API의 정책 버전 2105를 확인한다. 배포 증거는 `../qa/mercenary-action-hp-2105/`에 보존한다.
