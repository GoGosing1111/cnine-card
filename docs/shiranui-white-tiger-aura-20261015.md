# 시라누이 · 진무 기준 백호 아우라 교체

사용자 최신 정정은 **주변의 탄환 아우라를 진무처럼 백호 형상으로 바꾸는 것**이다. 앞서 제안하고 생성한 백호 공격·포효·발톱 타격은 범위를 잘못 확대한 결과여서 사용하지 않는다. 백호를 별도 전투 동물로 배치하지 않고, 머리 형상과 백색 기운이 시라누이를 감싸는 상시 아우라로 제작했다.

## 구현 범위

- 프리뷰: `preview/mercenary-monochrome-artillery-battle-v1/`.
- 승인 캐릭터·머리 광륜·AR 평타 9발·스킬 30발/해골·중앙 자주포 5회/엄호 25발, 카이론 동급 성능 준비값을 유지한다.
- 진무 참조: `preview/mercenary-golden-dragon-battle-v1/qa/desktop-aura.png`, `assets/sources/aura.png`, `assets/sources/dragon.png`, `source/GoldenDragonFX.js`; 실제 운영 연결은 `preview/project-v-v3/source/battle/JinmuCombatPlayback.js`에서 확인했다.
- 원본 `assets/sources/white-tiger-wrap-v5-padded.png`는 built-in image_gen으로 만든 2×2, 실제 4프레임이다. 최초 원본은 여백 보정 전 이력으로 보존한다. 생성 프롬프트는 `prompts/white-tiger-wrap-v5.json`과 `white-tiger-wrap-v5-padded.json`이다.
- 백호 코 기준으로 원본 프레임을 등록하고 12초의 느린 진행/복귀를 사용한다. 몸·코 위치와 전체 크기를 고정하고 대기 재시작/스킬 전환에서 시간 위상을 이어간다. 백호는 공격에 반응해 포효하거나 타격하지 않는다.
- `pack-tiger-aura-v5.mjs`는 원본 RGB를 재색칠하지 않고 알파를 뒤/낮은 앞 계층으로 상보 분할한다. 파생 레이어를 추가 작화로 세지 않는다. 같은 GSAP 시계, PixiJS 필터 안에서 프레임을 혼합하고 본체/총기 위의 가림을 제한한다.
- 이전 탄환 아우라는 비활성화한다. 잘못 만든 `white-tiger-idle/aim/roar/claw-v5`는 출처 이력만 남기며 로드하거나 공격 함수에서 참조하지 않는다.
- 새 용병 운영 등록·배포·획득 개방은 포함하지 않는다. 이름 시라누이와 카이론 동급 성능 준비 상태를 유지한다.

## 제작 공정 대응

| 04 무기 | 기존 승인 총기 픽셀·배율·파지·발사점을 유지. `qa-ar-v3.test.mjs` 관련 검사. |
| 05 효과 작화 | `white-tiger-wrap-v5-padded.png`, 실제 기운 변화 4프레임. 입력 진무 원본/생성 프롬프트 보존. |
| 06 패킹 | `pack-tiger-aura-v5.mjs`, `qa/aura-v5/source-registration.json`; 코 정합·투명 여백·앞뒤 알파 합 검사. |
| 07 위치/접점 | 아우라 코와 크기 고정. 기존 총구/사격/포격 메서드는 이전 기준 해시 그대로. |
| 08 공용 V3 | 기존 `BallisticArtilleryFX.js`의 아우라 메서드만 수정. 같은 V3/GSAP, 뒤/앞 효과 계층. |

| 10 증빙 | `qa/aura-v5/`의 보고서·캡처·실제 캔버스 녹화와 디코딩 검수. |
| 11 시각 승인 | 진무 기준 백호 아우라 제작 지시와 최종 시각 승인을 구분. 현재 새 아우라 사용자 검수 대상. |

## 관련 검사

`qa-tiger-aura-v5.test.mjs`는 기존 평타·스킬·포격 메서드 및 세 동작의 시각 타이밍을 이전 커밋 `cdd55ca38`과 비교한다. 전투 성능·기존 효과·몸/무기·머리 광륜 보존, 새 백호 공격 효과 0개, 아우라 4개 원본과 앞뒤 알파 합을 확인한다. 게임 전체 검사를 반복하지 않고 이 아우라가 표시되는 경로만 검수한다.

기존 동작 영상과 V4 아우라는 제작 이력이다. 현재 아우라 녹화/보고서는 `qa/aura-v5/`에 별도 보존한다.

검사 결과: 자산/공격 보존 검사와 아우라 범위 검사가 통과했다. PC 1440×1080 및 모바일 390×844에서 120개 시간 표본의 아우라 위치·크기·몸 위치가 각각 1개, 동작 전환 시 위상 오차 0이다. 표시/비표시·동작 줄이기·중단·대상 소실·dispose가 통과했고 콘솔/HTTP 오류는 0개다. 두 화면의 18.65초 실제 전장 영상을 녹화하고 다시 디코딩 재생했다. 런타임 증빙은 `qa/aura-v5/runtime-report.json`, 공격 보존은 `scope-report.json`이다. 사용자 최종 시각 승인은 대기한다.
