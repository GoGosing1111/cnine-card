## 원자성과 성능

- 경기 입력에 승리 보상을 고정한다. 승패·두 팀 점수·공격자 코인·장부·완료 영수증을 같은 짧은 거래로 기록한다. 장애/재시도/결과 재조회는 추가 지급하지 않는다. 전투 계산은 거래 바깥에서 실행한다.
- 새 경제 테이블은 독립 `ranked_duo_weekly_schema_v3` 마커로 준비한다. 기존 V2 마커가 있어도 누락되지 않으며 기존 테이블 트리거 소유권을 다시 변경하지 않는다. 유저 요청에서 DDL을 하지 않는다.
- 시즌 보상은 회당 **20팀/40명**으로 제한한다. 최종 순위 인덱스에서 `cursor < final_rank <= cursor+20` 범위만 읽는다. 받는 계정만 ID 순서로 잠그며 보상 영수증·잔액·장부·지급 위치를 같은 거래로 처리한다.
- 받는 계정이 없거나 안전한 잔액 범위를 넘으면 해당 지급 거래 전체가 실패한다. 지급하지 않은 상태에서 정산 완료나 다음 시즌으로 넘어가지 않는다.
- 전투 요청은 스케줄러 임대나 전 서버 집계 행을 갱신하지 않는다. 로비는 전체 참가자를 재집계하지 않는다. 기존 변경 계정별 덱 요약·프로필 무효화 구조와 Hyperdrive 쿼리 캐시 OFF를 유지한다.
