## 확인한 원인과 수정

1. **게이지 포화와 진영/슬롯 차례 독점.** 기존 최소 시간 증가 0.001은 개별 속도가 100,000 이상일 때만 해제됐다. 여러 ICON의 속도 합이 큰 중간 구간에서는 모두 게이지 130 상한에 걸려, 같은 진영과 슬롯이 반복해서 먼저 행동하고 다른 카드가 100행동 동안 한 번도 못 움직였다. ICON이 있는 일반 전투는 정확한 게이지 도달 시간으로 처리한다. 기존 협동전의 버전별 판정은 유지한다.
2. **횟수형 봉인의 영구 스킬 차단.** `magicSealCharges`를 ICON 스킬 차단 조건으로만 읽고 차단 횟수는 소모하지 않았다. 장착 마법이나 정화가 없으면 전투 내내 스킬을 못 썼다. 사용 조건을 만족한 스킬 시도에서 1회 소모하고 그 차례는 평타를 한다. 막힌 시도는 스킬 횟수와 재사용 대기를 소비하지 않는다. 지속 행동형 아포칼립스 봉인, 기존 패시브 봉인과 역할별 예산은 유지한다.
3. **ICON 재생 시간 누락.** 서버 전투 시간표에서 ICON 스킬·집중의 시간이 0으로 계산돼 스킬칩 전투에서 다른 행동과 겹칠 수 있었다. 실제 타격·복귀의 재생 해제 시점을 서버와 공통 V3가 공유한다. 과거 저장 기록의 0시간 ICON 행동도 재생 시 순서를 지킨다. 긴 전투의 연출 가속에는 실제 ICON 스킬/집중 행동만 포함하고 패시브 알림은 제외한다.
