# 월령 준비 중 표적 소실 수정 (2026-09-17)

## 문의와 원인

월령이 적의 체력이 낮아질 때까지 공격하지 않고 원거리 공격에 쓰러진다는 문의를 조사했다. 기준 코드는 `6fe830f2`, 운영 CMS revision 55, 월령 V-010 / SS / 적월 낙형 MS-010이다.

적월 낙형은 적의 낮은 HP를 발동 조건으로 사용하지 않는다. 생존 적 중 HP 비율이 가장 낮은 표적을 지정해 한 행동 동안 준비하고, 다음 행동에 검격을 가한다. 잃은 HP 비율은 추가 피해에만 사용한다.

실제 문제는 준비 중 아군이 표적을 처치하면 다음 타격 행동이 `TARGET_LOST`로 취소되고 재정비 지연까지 남는 것이었다. 비교 표본에서 시전의 약 13~16%가 이 원인으로 공격을 잃었다. 동일 조건의 A급 원거리보다 보편적으로 약하다는 부분은 재현되지 않았지만, 공격을 낭비하는 결함은 실제 서버 전투에서 재현했다.

## 변경

- 타격 시 기존 표적이 사망하거나 대상 지정 불가이면 생존 적 중 HP 비율이 가장 낮은 표적을 다시 지정해 **같은 타격 행동에서** 검격을 가한다.
- 표적 변경 때문에 준비 행동, 자원 소모, 재사용 대기 또는 추가 타격을 생성하지 않는다. 기존 표적이 유효하면 다른 적의 HP가 더 낮아져도 표적을 유지한다.
- 새 표적의 HP가 가득 차 있어도 공격한다. 추가 피해는 실제 타격 순간의 잃은 HP 비율로 계산한다.
- 시전자 사망·기절·침묵, 회피·방벽·피해 경감은 기존대로 적용한다. 생존 표적이 없으면 공격을 취소한다.
- 피해 배율 2.8, 비용 25, 재사용 대기 4, 준비 1행동, 재정비 게이지 20, 잃은 HP 추가 피해 상한 50%를 유지한다. 등급·능력치·스킬 배정 및 앞서 적용한 SS 원거리 보정은 변경하지 않는다.
- 도감·보유 용병·CMS의 읽기 전용 적용 설명을 일치시킨다. CMS 편집 원문이나 운영 DB에는 쓰지 않는다.

서버는 용병 코드가 아닌 `WOUNDED_MOON_DRAW` 기믹을 판별한다. 운영자가 직접 설정한 배정만 사용하며 다른 용병에 스킬을 자동 배정하지 않는다.

## 비교 결과

양쪽 일반 카드 전력과 구성을 동일하게 맞춘 5장 + 별도 용병 1장의 실제 서버 PVP다. 카드당 10만·100만·2,000만·1억, 혼합·공격·방어·속도 덱, 공격/방어 양쪽, 각 128개 난수(`seed=n×7919`, n=1..128)를 비교했다. 상대별 각 버전 4,096전, 전후 총 106,496전이다. 정량 원본 요약은 같은 이름의 JSON에 기록한다.

위 값은 동일 덱 합성 비교이며 실사용자 승률이 아니다. A급 5종은 현재 CMS에 공격 스킬이 배정되지 않아 같은 능력치와 기본 공격을 사용한다. 실제 계정의 덱·장비·상성·배정 차이까지 동일하다는 뜻이 아니며 모든 SS 상대에 50%를 맞춘 것도 아니다.

## 검증과 배포

- 다른 43종의 PVP 22,016전과 월령을 포함한 44종의 일반/아포칼립스 단일 보스 PVE 8,448전은 변경 전후 전체 전투 반환값이 일치했다.
- 신규 회귀 9개: 같은 행동 재지정, HP가 가득 찬 적, 사망·지정 불가·슈트 제외, 기존 표적 유지, 몬스터 교체·보스, 시전자 제어/사망, 회피/방벽, 비용·재정비·재사용 대기, 실제 5+1 PVP 재현, 도감/보유 설명과 CMS 원문 보존.
- 실제 `index.html`의 PVE 토벌·PVP 랭크전 시작 → V3 전투 → 결과 → 복귀를 PC 1440×1000 / 모바일 390×844에서 확인한다. 재입장·구버전 엔진 갱신·입장 오류 복구, 도감·CMS 설명도 확인한다.
- 브라우저 전투/계정 API는 격리 검수 데이터를 사용한다. 운영 재화를 소비하지 않는다. 배포 후 운영 정적 파일로 같은 진입 검사를 반복한다.
- 기존 V3·PixiJS·GSAP·스킬 연속 프레임을 재사용한다. 클라이언트 엔진 버전·로더·원화·SD·사운드는 변경하지 않는다.
- 깨끗한 범위 커밋을 main에 통합하고 `npm run deploy:production`으로 전체 `release:gate`를 통과시킨 뒤 배포한다. 롤백은 이 범위 커밋을 되돌려 같은 절차로 재배포하며 별도 DB 역변경은 없다.
- 운영 CMS 원문 검증 기준: revision 55, SHA-256 `56a2d12dc3e5dd4aa7f3e35afed3c8e8f5ed40668f02d37a01024534416edf89`.

## 유저 안내 문안

월령의 「적월 낙형」이 준비 중 표적이 처치되면 공격을 소모하던 현상을 수정했습니다. 이제 다른 생존 적을 다시 지정해 예정된 타격을 이어갑니다. 적의 HP가 가득 차 있어도 공격하며, 낮은 HP는 추가 피해에만 영향을 줍니다. 스킬 피해 배율·자원 소모·재사용 대기는 기존과 같습니다.
