## 최신 사용자 지시와 시각 기준

사용자는 용병 레벨 UI, 돌파 성공·실패 연출, 능력치 부여 방식을 다시 구현하고 고레벨 일반 용병이 리미티드와 싸우는 구조를 상세히 만들도록 지시했다. 이어 CSS/SVG 봉인 화면을 반려하고 **모든 버튼을 이미지 생성 스킬로 제작**하도록 정정했다.

- CSS/SVG 도형 봉인과 평면 버튼 시안은 반려 이력이다. 기능 검사 통과를 시각 승인으로 취급하지 않는다.
- 내장 `image_gen`으로 흑금속 성물의 닫힘·성공 개방·실패 파손을 각각 제작했다. 버튼도 같은 계열의 생성 이미지 표면을 사용한다. 원본 PNG 8장(기존 보조 버튼 반려 이력 1장 포함)은 바이트 그대로 보존한다. 봉인 파생 WebP는 균일 축소·인코딩, 버튼은 거의 투명한 바깥 여백만 정리하고 패딩을 남겨 축소·인코딩한다. 그림 내부를 다시 그리거나 변형하지 않는다.
- 후속 V3 검수에서도 사용자가 긴 금장 버튼과 작은 글씨를 반려했다. V4는 새로 생성한 간결한 흑금속 프레임의 모서리 크기를 고정해 사용한다. 주요 버튼 16px 이상, 규칙·검수 제목 18px, 충분한 조작 크기와 좁은 화면 재배치가 기준이다. 이전 V3 레이아웃을 시각 승인으로 인용하지 않는다.
- 최신 추가 지시 **“도형 CSS지워라”**에 따라 슬라이더 손잡이의 흰 마름모, 상단 마름모, 성장실 장식 SVG·궤도·링·장식 코너를 제거했다. 구 봉인·링·균열·파편 CSS와 관련 미사용 애니메이션도 삭제했다. 생성 이미지의 분리·이동, 조작 문자와 키보드 초점 표시만 유지한다.
- 한글 이름·결과·수량·확률은 HTML로 정확하게 표시한다. 생성 이미지에 한글을 구워 넣지 않는다. 코드는 배치·조작·접근성·시간 제어를 담당한다.
- 대상은 이번 성장실의 선택·훈련·돌파·수량·로드맵·바로 결과·다시보기·복귀·닫기·음향 등 로컬 조작부다. 운영 공통 메뉴 컴포넌트를 다른 디자인으로 전역 교체하지 않는다.
- 생성 원본과 프롬프트의 단일 색인은 `../assets/ui/mercenary-growth-20261015-v3/manifest.json`이며 각 생성 이미지의 SHA-256을 확인했다. 새 시각 최종 승인은 사용자 검수 후 별도이며 이번 요청을 라이브 승인으로 해석하지 않는다.

## 화면과 결과 흐름

공통 메뉴를 유지한 성장실에서 보유 용병을 선택하고, 원화·현재 레벨·재료·예상 경험치와 능력치 변화를 함께 확인한다. Lv.1~20을 눌러 성장 계획만 조회할 수 있으며 실제 카드가 소모되지 않는다. 덱·장비가 반영된 실제 전투 수치가 없는 상태 화면에서는 임의 HP 숫자를 만들지 않고 정확한 누적 성장률을 표시한다.

돌파 흐름은 **서버 판정·영수증 확정 → 성물 충전 → 직접 밀어 개방 → 성공/실패 전용 원화 → 능력치 전후 공개**다. 실제 결과를 먼저 확정하고 연출은 그 결과만 보여준다. 성공은 열린 성물과 빛, 실패는 깨진 결정과 소진된 빛으로 구분한다.

- 성공: Lv.5/10/15 돌파는 다음 레벨로 진행하고 해당 돌파 능력을 추가한다. Lv.20 최종 돌파는 레벨 20을 유지한다.
- 실패: 현재 레벨 경험치만 0. 레벨, 보유 원본 용병, 이미 성공한 돌파와 능력치는 유지한다. 실패 연출에서 용병 소멸로 오해하지 않게 표시한다.
- 초과 경험치: 일반 레벨은 이월하며 돌파 구간에서 넘는 분량만 명시적 동의 후 소멸한다. 미동의 시 카드 차감 전에 차단한다.
- 재료: 같은 등급 중복 카드만 사용, 기본 1장 보호. 동일 용병 3배·다른 동급 1배. 리미티드는 필요 경험치 5배다.
- 연출을 닫기·건너뛰기·다시보기·재접속해도 재판정하거나 추가 차감하지 않는다. 확정 영수증의 전후 성장 내역과 정책 버전을 재사용한다.
- 마우스·터치·키보드·동작 줄이기와 좁은 화면의 결과 스크롤을 지원하며 검수 음향은 OFF다.

## 능력치 부여 방식

이전의 돌파 한 번당 모든 능력치 +500% 방식은 경로 증명용 테스트였다. 새 검수안은 일반 레벨과 돌파를 분리하고 속도·숙련에 각각 상한을 둔다. 아래 수치는 검수 프로필이며 CMS 운영값은 여전히 미정이다.

| 항목 | 일반 레벨 1 상승 | 돌파 1회 성공 |
|---|---:|---:|
| 체력 | +25% | +100% |
| 공격력 | +25% | +125% |
| 방어력 | +6% | +15% |
| 기본 행동 속도 | +1% | +2% |
| 배정 스킬 계수 | — | +5% |
| PVP 경감 관통 | — | +12.5% |
| PVP 행동 대응 | — | 단계별 +10/15/20/25% |
| PVP 추가 행동 숙련 | — | 단계별 +0.10/0.15/0.20/0.30회 |

각 증가분을 **가산 합산**한다. Lv.1은 성장 0이며 최종 Lv.20 돌파까지 체력 +875%, 공격 +975%, 방어 +174%, 기본 속도 +27%, 배정 스킬 계수 +20%가 된다. 체력은 성장 전의 9.75배, 공격은 10.75배다. 속도를 같은 배율로 늘리지 않는다.

| 단계 | 체력 | 공격 | 방어 | 기본 속도 |
|---|---:|---:|---:|---:|
| Lv.1 | 0% | 0% | 0% | 0% |
| 첫 돌파 후 Lv.6 | +225% | +250% | +45% | +7% |
| 두 번째 돌파 후 Lv.11 | +450% | +500% | +90% | +14% |
| 세 번째 돌파 후 Lv.16 | +675% | +750% | +135% | +21% |
| Lv.20 최종 돌파 전 | +775% | +850% | +159% | +25% |
| Lv.20 최종 돌파 후 | +875% | +975% | +174% | +27% |

기존 덱 연계·개인 장비 반영 후 한 번만 성장 배율을 적용한다. 공격 본체와 연계 하한은 더하지 않고 기존처럼 큰 값을 택한다. 현재 HP 비율을 유지하고 시작 방벽은 별도로 증폭하지 않는다. 스킬 비용·재사용·대상 수를 변경하지 않는다. 성장 파생 능력치를 편성 전투력에 다시 더하지 않아 PVP 보너스로 중복 증폭되지 않는다.

## 일반 SSS가 리미티드를 상대하는 세 가지 수단

기존 리미티드의 태생 전투력·연계·경감·추가 행동을 전역 하향하지 않는다. 성장이 완료된 용병에 새로운 PVP 대응 능력을 더한다.

1. **경감 관통**: 상대보다 높은 레벨일 때만, 적 고유 경감·지정 용병 면역으로 사라질 피해의 일부를 복구한다. 유효 숙련은 `누적 관통 × min(1, 레벨 차이 / 10)`이다. 최종 관통 50%와 10레벨 이상 차이면 75% 경감은 37.5% 경감으로 남고, 기존 완전 면역 공격은 원래 피해의 50%만 유효해진다. 같은 레벨은 0이며 일반 카드·PVE 기믹에는 적용하지 않는다.
2. **행동 대응**: 리미티드의 고유 연속 행동까지 합친 행동 기회를 비교해, 부족분의 최대 70%를 보충한다. 상대 기준은 `성장 전 자연 속도 + 해당 덱 카드 속도 합 × 고유 추가 행동량`이며 내 기준은 `현재 자연 속도 + 해당 덱 카드 속도 합 × (고유 + 성장 추가 행동량)`이다. `max(0, 상대 기준 − 내 기준) × 배운 대응 숙련 × min(1, 레벨 차이 / 10)`을 내 자연 속도에 더한다. 이미 받은 성장 추가 행동은 내 기준에 포함하므로 다시 지급하지 않는다. 예를 들어 상대 행동 기회가 100, 내가 40이고 10레벨 이상 높으며 최종 숙련 70%면 부족분 60의 70%인 42만 보충해 82가 된다. 같은 레벨에는 0이고 내가 이미 빠르면 추가하지 않는다. 전투 시작 시 살아 있는 소유 카드·고유 수치를 고정하며 보조 유닛과 상대 성장·다른 대응 보정·전투력 보너스를 재참조하지 않는다. 듀오도 각 소유자 덱을 분리하고 상대별 보충 후보를 합산하지 않고 가장 큰 값 하나만 선택한다. 이 값은 잠재 행동 기회 비교용이며 실제 예약 행동도 자연 게이지를 소비하므로 실제 행동 횟수의 70%를 보장하지 않는다.
3. **추가 행동 숙련**: 해당 덱 카드가 행동할 때 쌓이는 용병 행동량에 최대 +0.75회를 가산한다. 일반 1회는 1.75회, 고유 3회는 3.75회이며 곱하지 않는다. 소수 누적을 보존하고 듀오도 소유자별로 분리한다. PVE 추가 행동 정책은 유지한다.

리미티드도 성장 시 같은 성장표를 사용하되 경험치 요구량은 5배다. 같은 레벨에서는 관통·행동 대응이 꺼지므로 리미티드의 태생 우위가 남는다. 별도 편성 전투력 보너스는 기존 준비안의 피해 최대 +20%·게이지 최대 +8%를 유지한다.

## 실제 전투 검증과 한계

자연 속도만 비교하던 초기 후보에서는 일반 Lv.20 대 리미티드 Lv.1 평균 승률이 3.61%였다. 대표 로그에서 체력·공격은 충분해도 전열을 정리하는 동안 상대의 연속 행동에 쓰러지는 원인을 확인했다. 능력치 배율을 더 키우지 않고, 카드가 만드는 고유 추가 행동까지 비교해 부족한 잠재 행동 기회를 보충하도록 수정했다.

최종 공용 전투 엔진에서 일반 SSS 4종 × 리미티드 5종, 8개 레벨 관계, 카드 전력 3구간, 덱 타입 4종, 공수 교대·12개 시드로 **46,080전**을 비교했다. 대표 튜닝에 사용하지 않은 시작 시드 730001을 사용했고 레벨·PVP 보너스를 함께 켠 격리 검수다. 실제 유저 승률은 아니다.

- 일반 Lv.20 대 리미티드 Lv.1 전체: **1,636/5,760승, 28.40%**. 20개 용병 상대 조합 모두 역전 사례가 있다.
- 크라이베른 Lv.20 대 발테르 Lv.1: 전체 편성 조건 평균 **55.56%**, 카이론 Lv.1 상대로 **41.32%**.
- 라그니엘 Lv.20 대 발테르 Lv.1: 평균 **40.97%**.
- 베르칸 Lv.20 대 발테르 Lv.1: 전체 평균 **26.39%**, 카드 1장 전력 2,000만·공격 덱에서는 17/24승(**70.83%**).
- 오메가-X Lv.20 대 발테르 Lv.1: 전체 평균 **15.28%**, 같은 고전력 공격 덱에서는 11/24승(**45.83%**). 일반 용병 간 편차는 남는다.
- 일반 Lv.20 대 리미티드 Lv.6·11 평균은 각각 **3.84%·0.52%**다. 리미티드의 성장도 유효하다.
- 동일 레벨 1/1·20/20의 11,520전에서는 일반 SSS 승리가 없었다. 고레벨·덱 조합으로 돌파구를 만들되 동레벨 리미티드의 강점은 남는 구조다.

구현한 것은 **성장과 덱 조합에 따른 실제 경쟁·역전 경로**다. 모든 일반 SSS가 평균 동급이 되거나 높은 레벨만으로 자동 승리한다는 의미는 아니다. 실제 출시 전 운영 덱·장비 분포와 미정 경험치·돌파 확률을 함께 확인해야 한다. 최종 결과·추천 조합·제약은 `qa/mercenary-level-v2-20261015/growth-combat-report.md`와 `comparison.json`, 수정 원인과 같은 입력의 전투 로그는 `action-opportunity-correction.json`에 보존한다. 초기 3.61% 자료는 `comparison-superseded-natural-speed-only.json`으로 분리했으며 최신 결과로 인용하지 않는다.

## CMS·영수증·운영 잠금

CMS는 레벨별 XP, 등급별 재료 XP, 돌파 확률, 레벨마다 얻는 네 능력치와 돌파별 능력·숙련을 따로 입력한다. Lv.1~20 및 최종 돌파 누적표를 같은 공통 함수로 계산한다. 부분 입력 초안은 저장할 수 있지만 미정값을 0이나 검수 프로필로 채우지 않는다. 전체 설정과 출시 스위치가 열리기 전에는 실행할 수 없다.

V2 영수증은 성장표 버전·정책 revision·전후 성장 요약을 고정한다. 카드 차감·성장·영수증의 기존 원자적 거래를 유지한다. 성공 응답 유실이나 정책 변경 후 다시 조회해도 같은 결과를 보여준다. 과거 V1 성장 스냅샷은 기존 계산으로 재현한다. 이전 OFF 정책은 메모리에서만 새 구조로 읽고 DB를 자동 수정하지 않는다.
