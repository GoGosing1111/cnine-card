# 로비 가독성 개편 · V2107

## 사용자 기준

- 장비 강화·용병도감의 짙은 남색, 밝은 본문, 절제된 라임 강조를 로비에 적용한다.
- 행정부를 독립된 메뉴 분류로 제공한다. 기존 콘텐츠 경로와 공개 여부를 유지한다.
- 메인은 이전 로비처럼 아바타 일러스트로 화면을 채우고 족장 이름을 작게 표시한다. 콘텐츠 현황은 하단 가로 한 줄이다. 족장 이름은 기존 상세 창에 연결한다.
- 메인에 바로가기·장비·용병·검색 목록을 중복 배치하지 않는다. 왼쪽 분류를 누르면 해당 분류의 항목만 별도 창에 표시하고, 검색도 그 분류 안에서만 작동한다. 예를 들어 상점·교환에는 5개 항목만 표시한다.
- 하단 전체 메뉴 버튼은 그대로 유지한다. 전체 메뉴에서만 모든 분류를 함께 표시하고 전체 검색을 제공한다. 분류 창의 반복 분류 탭과 각 항목의 중복 분류 배지를 제거한다.
- 39개 세부 목적지에 각각 다른 SVG 선화 아이콘을 제공한다. 콘텐츠 현황은 글자·카운트다운을 유지하면서 본문 높이를 60px로 줄인다.
- 로비에 “어떤 모험”, 추천 시작점, 첫 모험 순서 등 입문 문구를 상시 표시하지 않는다.
- “처음 오셨나요?”를 누르면 맨처음 시안을 별도 창으로 연다. 그 시안의 첫 모험 길잡이와 5단계 화면 안내를 튜토리얼로 사용한다. 자동 시작하지 않으며 중단 위치를 계정별 로컬 저장소에 보존한다. 별도 창은 필요할 때만 로드한다.
- 용병 지휘소에서 용병카드 개봉 패널을 제거한다.

## 구현

로비는 `soop-adventure-lobby`의 Shadow DOM으로 구성해 기존 콘텐츠별 CSS와 분리한다. 메뉴 이동은 기존 `SoopketmonV21ExactShell`과 런타임 라우터를 사용한다. 서버 공개 조건을 만족하는 메뉴만 디렉터리에 표시한다.

현황판은 기존 `liveOperationsHtml`, `loadLiveOperations`, `renderLiveOperations`, `openLiveOperation`을 그대로 사용한다. 기존 DOM 선택자와 타이머가 작동하도록 light DOM 슬롯에 유지하며 `lobby-clarity` 표시에만 하단 가로 한 줄 스타일을 적용한다. 경매 입찰, 전투 입장, 서버 상태와 카운트다운의 처리 로직은 변경하지 않는다.

계정 이름·재화는 기존 계정 저장 갱신을 구독한다. 족장 및 아바타는 기존 족장 조회의 `viewerAvatar`/`avatar`를 사용한다. 아바타 원본은 수정하지 않는다. 서버 정보 갱신 중 검색과 안내 창을 유지한다.

용병 선택·편성·해제 및 이전 요청 결과 복구를 유지한다. 제거 범위는 선택 화면의 신규 개봉 조작과 관련 표시다. 하이퍼팩 개봉 기능·확률·코인 차감 정책은 변경하지 않는다.

## 소스와 검증

- 검수 화면: `preview/lobby-clarity-v1/`
- 첫 시안 튜토리얼: `preview/lobby-clarity-v1/tutorial/`
- 계정 연결: `ui/adventure-lobby/component.js`
- 개별 메뉴 아이콘: `ui/adventure-lobby/icons.js` — 외부 아이콘 패키지 없이 직접 그린 24px 벡터, 생성 번들에 포함
- 기존 현황판 스타일: `css/adventure-lobby-v2107.css`
- 생성 번들: `js/adventure-lobby-v2107.js`
- 생성: `npm run build:lobby`
- 소스 일치 검사: `npm run test:lobby` — 운영 출시 게이트에 포함
- 브라우저 검사: `tests/lobby-clarity-v1.browser.mjs`, `tests/adventure-lobby-v2107.browser.mjs`

브라우저 검수는 실제 운영 index/app/메뉴/현황판 코드를 실행하고 API만 격리된 검수 데이터로 대체한다. 1440×1000, 390×844, 320×740, 768×1024, 1440×560을 확인한다. 첫 시안 창과 튜토리얼의 수동 시작·복귀·저장·중단, 분류별 검색 격리, 전체 메뉴 보존, 아이콘 구분, 현황 바 높이, 행정부, 숨긴 기능, 계정 갱신 중 상태 유지, 실제 경매 화면과 PVE 진입, 기존 카운트다운, 용병 선택과 분실 응답 재처리를 검증한다. 운영 로비 브라우저 검사는 301개, 첫 시안·용병 선택 검사는 212개 항목을 통과했다.

브라우저 캡처·로그는 배포 디렉터리 밖의 `../qa/`에 저장한다. 실제 계정 쓰기·입찰·전투 실행·재화 소모는 검수에 사용하지 않는다.

배포는 깨끗한 origin/main 후보에서 `npm run deploy:production`으로 수행한다. 기능 플래그·DB·CMS의 운영 설정은 이 변경에서 수정하지 않는다.
