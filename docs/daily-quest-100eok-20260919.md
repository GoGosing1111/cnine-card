# 일일퀘스트 100억 설정 및 당일 차액 소급

사용자 요청: “일일퀘스트 코인 한도 100억으로 변경 금일 수령자 소급적용”.

CMS 게시글 일일퀘스트 보상 입력 상한을 10억에서 100억(10,000,000,000 코인)으로 변경한다. API에서도 OWNER 권한과 0~100억 정수 범위를 검사한다. 운영 설정의 `postRewardCoin`과 `rewardCoin`을 100억으로 맞추고 게시글 수·대기시간·인증 조건·이용 가능 상태는 보존한다.

소급 범위는 한국 시간 2026-09-19 일일퀘스트 수령 기록이다. 기존 보상과 100억의 차액만 지갑에 직접 적립하고, 수령 기록의 총 보상을 갱신한다. 기존 코인 지급 원장은 수정하지 않고 추가 코인 원장 및 수령 건별 소급 영수증에 원래 금액·차액·잔액을 기록한다. 같은 수령 건은 재실행해도 다시 지급하지 않는다. 설정 변경과 경합한 이전 금액의 늦은 수령도 배포 후 추가 조회한다.

운영의 `users.coin`, `coin_logs.change_amount/balance_after`, `wago_daily_quest_claims.reward_coin`은 이미 BIGINT여서 별도 형식 변경이 필요 없다. 운영 지급 작업과 감사 기록은 별도 일회성 실행 기록으로 보존한다.

검사는 실제 CMS 저장 함수의 100억 요청·상한 초과 차단, PostgreSQL 호환 API의 저장·수령·재수령 차단·OWNER 권한을 포함한다. 운영 배포는 일반 `npm run deploy:production` 출시 게이트를 사용한다.
