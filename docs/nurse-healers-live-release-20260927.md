- MS-051 `백의의 맹세` 하나를 네 명에게 동일 배정. 공격력 3.2배의 단일 총 회복 예산을 자신을 포함한 생존 일반 카드·용병에게 균등 분배한다. 초과 회복·정수 나머지는 버리고 회복 억제·아포칼립스 저주를 적용한다. 배틀슈트·몬스터·호송 목표물·사망자는 제외한다. 모두 최대 HP이거나 제압·자원 부족·PVP 연장전 회복 금지 상태면 비용을 쓰지 않는다.
- 서버가 한 GROUP_HEAL 이벤트로 모든 대상의 확정 HP를 내보내며, 기존 V3의 PixiJS 8.20.0·GSAP 3.13.0 재생기가 0.88초 충돌 프레임에서 반영한다. 16개 실제 연속 프레임·2.6초 효과를 공유한다. 신규 음원은 없다.
- 원화 4장은 사용자 첨부와 바이트 단위 동일하며 카드·도감은 원화, 전장은 투명 SD를 사용한다. 원본 해시는 승인 JSON과 기존 리소스 manifest에 기록한다.
- 하이퍼팩 SS 등급 확률 500ppm(0.05%)와 모든 기존 용병 가중치를 보존한다. 신규 간호사만 각각 가중치 3을 추가한다. CMS 58·추첨 정책 18 스냅샷 기준 총 SS 가중치 4112, 간호사 한 종의 SS 내 확률 약 0.0729572%, 전체 약 0.0000364786%. 사용자가 지정한 3은 확률 3%가 아니라 CMS 가중치다.
- CMS와 추첨 정책은 한 PostgreSQL 트랜잭션으로 저장하고 감사 두 건과 중복 방지 영수증을 남긴다. 운영 계정 보유 카드·재화·기존 배정은 수정하지 않는다.
