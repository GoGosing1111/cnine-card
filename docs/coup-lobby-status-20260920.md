# 쿠데타 콘텐츠 현황

로비·상점의 기존 콘텐츠 현황 API에 쿠데타 공개 요약을 추가한다.

- 운영 ON + RECRUITING: `쿠데타 / 참가 모집 / 개전 대기`.
- 운영 ON + ACTIVE + 종료 시각 전: `쿠데타 / 전투 진행 / 종료까지`와 실시간 남은 시간.
- OFF, 종료, 취소, 정산 중, 시간이 지난 ACTIVE는 제외한다.
- 현황 카드를 누르면 기존 `coup` 화면으로 바로 이동한다.

모집 마감 시각은 현재 쿠데타 모델에 없으므로 임의의 카운트다운을 만들지
않는다. 회차 UUID는 문자열로 유지하며 참가자·덱 정보는 노출하지 않는다.
현황 조회는 읽기 전용이고 개전·전투·정산을 실행하지 않는다. 쿠데타 조회
실패가 기존 경매·영토전 등 현황 조회를 실패시키지 않도록 분리했다.

기존 15초 서버 캐시와 30초 화면 갱신, 한 줄 현황판을 유지한다.
앱 스크립트 캐시를 갱신하며 현재 쿠데타 운영 ON/OFF는 바꾸지 않는다.

검증: SQLite·PostgreSQL 모집/진행/종료/OFF/마감 경계, 읽기 전용 동작,
쿠데타 조회 실패 격리 및 화면 문구·타이머·이동 경로 회귀 검사를
`test:coup`에 포함한다. 실제 index의 PC·모바일 화면은 합성 API로 검수해
운영 참가/전투나 계정 재화를 사용하지 않는다.
