# X-BODY 천광 연섬 누락 수정 — 2026-09-28

사용자가 처음에는 Z바디 스킬 하나가 보이지 않는다고 했으나, 이어 제공한 X-BODY 연출 검수 화면과 `TEST.gif`로 천광 연섬을 특정했다. GIF의 교차 베기·올려베기·도약 내려베기는 기존 승인된 X-BODY V2 모션이다.

## 원인과 수정

- 기존 동작 선택은 세 동작 주기 중 연섬 차례여도 같은 적의 서버 타격 영수증이 6개 이상 한꺼번에 대기 중이어야 `skill`을 선택했다. 실전에서 한 개씩 도착하는 공격은 계속 일섬으로 바뀌었다.
- 바로 앞 공격과 같은 액터·같은 적 ID이면 짧은 묶음에도 기존 연섬 차례를 적용한다. 적이 자주 바뀌는 짧은 묶음은 일섬을 유지해 몬스터 교체가 긴 동작에 밀리는 기존 문제를 다시 만들지 않는다. 같은 슬롯 객체라도 적 ID가 바뀌면 이전 대상의 연섬 조건을 승계하지 않는다.
- 공용 단발 경로는 슈트의 전용 `takeBatch`가 있으면 사용한다. X-BODY가 이 경로에서 Z-BODY의 선택기로 처리되던 누락도 수정했다. Z-BODY의 기존 경로는 유지한다.
- 기존 PixiJS 8.20.0 / GSAP 3.13.0, 승인 모션·검·아틀라스·접촉 시각·같은 대상 묶기·대기열 따라잡기 배속을 그대로 사용한다. 여섯 번의 시각 접점 때문에 서버 타격 영수증을 복제하거나 새 피해·대상을 만들지 않는다.
- 줌인 OFF와 천룡 강림 20초는 유지한다. 서버·DB·경제·기능 플래그는 변경하지 않는다.
- 메인 로더 `xBody=20260928-flurry`, 공용/군단토벌 런타임 `20260928-x-body-flurry`로 갱신하고 12슬롯 군단토벌을 포함한 10개 소비자 번들을 재빌드한다.
