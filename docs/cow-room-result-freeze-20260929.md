## 원인과 수정

- 카우방 건너뛰기는 공용 V3 렌더러의 `destroy()`를 먼저 호출한 뒤 같은 렌더러의 `showResult()`로 숨겨진 결과 레이어를 열려고 했다. 공용 렌더러는 이미 종료된 경우 `showResult()`를 무시하므로 전투가 멈추고 결과는 보이지 않는다.
- 실제 공용 렌더러의 종료·결과 표시 메서드를 사용하는 회귀에서 일반 재생·일시정지 상태 모두 결과 비노출을 재현했다.
- `js/cow-room-live.mjs`에서 종료된 렌더러 참조를 분리하고 기존 독립 결과창으로 서버에 저장된 결과를 표시한다. 늦게 돌아온 재생 취소가 결과창을 다시 덮어쓰거나 일시정지 사격을 재개하지 않도록 차단한다.
- 렌더러 준비 전에는 일시정지·결과보기 버튼을 비활성화한다. 정상 재생 완료는 기존 V3 결과 레이어를 유지한다.
- 결과 확인 전까지 같은 원정 복구 ID를 보존한다. 보상 계산·정산·입장 API와 공용 전투 엔진은 변경하지 않는다.
- `js/pve-v3-navigation.mjs`의 카우방 동적 import와 `index.html`의 내비게이션 로더 캐시 키를 갱신한다.
