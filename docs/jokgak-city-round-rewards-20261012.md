# 족각도시 회차 보상 CMS — 2026-10-12

사용자 요청: “족각도시 참여 보상 최소 기준점, top5 보상 cms에 추가해.” 최종 정정: **“참여보상은 공격기준 top5는 현금기준.”**

## 설정과 정산

- OWNER CMS → 족각도시 → **회차 보상**. 기존 행동별 보상과 별도 탭이다.
- 참여 보상: 그 회차에 정상 완료한 일반 선제공격 횟수 ≥ 최소 횟수. 승·패·무승부 포함. 방어·체포·TEST·실패 요청·재전송은 제외한다. 기존 행동별 일일 보상 한도와 독립이다.
- TOP 5: 회차 종료 직전 ON 지갑 현금에 해당 회차의 확정된 자동 수입을 더해 순위를 계산한다. 공격 최소 횟수는 TOP 5 조건이 아니다. 자발적 퇴장·오프라인도 포함하고 정지 계정은 제외한다.
- 동률은 공동 순위(1·1·3위), 공동 5위 전원 포함. 참여와 순위 조건을 모두 충족하면 합산하여 한 번 지급한다.
- 참여 및 순위별 게임 코인(0~5조)과 활성 인벤토리 아이템 최대 5종(종별 1~100만)을 설정한다. 도시 현금은 정산 직후 초기화되므로 회차 지급 재화로 추가하지 않았다. 0코인·아이템 없음인 순위는 지급하지 않는다.
- 신규 설정은 OFF·최소 공격 0(미입력)·보상 0이다. 참여 활성화는 최소 1회 이상과 지급할 보상이 필요하며 TOP 5 활성화는 보상이 있는 순위가 최소 하나 필요하다. 기존 운영 모드·경제·역할 보상은 재설정하지 않는다.
- 기준·금액·활성화 변경은 다음 KST 00/06/12/18시 회차부터 적용한다. 해당 보상 OFF 또는 운영 OFF/TEST는 아직 정산하지 않은 회차 보상을 즉시 중지한다. 정책 스냅샷이 없는 과거 회차는 지급하지 않는다.
- 게임 코인·인벤토리에 자동 지급하고 기존 코인/아이템 원장과 `jokgak_city_round_reward_receipt_v1:<epoch>`에 근거를 기록한다. 실제 계정에 검수 보상을 넣지 않는다.

## 연결과 보호

- `shared/jokgak-city-round-rewards-v1.mjs`: 기본값·검증·공동 순위.
- `shared/jokgak-city-settings-v1.mjs`: 기존 `jokgak_city_settings_v1`의 `roundRewards` 필드. 구버전 CMS가 필드를 생략해도 저장 시 기존 값을 보존한다.
- `functions/_jokgak_city_round_rewards.js`: 회차별 고정 정책과 보상 준비. 기존 통합 지급 함수를 사용하고 장비보호권 지급 제한을 유지한다.
- `functions/_jokgak_city_top.js`: 현금 및 완료 공격 집계, 기존 회차 원자적 거래에 보상 추가. 전투 영수증의 `mode=PVP`와 도시 운영 모드를 구분하며 신규 `cityMode`, 과거 `reward.mode`를 사용한다. 전투 재생용 mode는 유지한다.
- 설정 CAS, 플레이어/지갑 스냅샷, 유효 아이템, 지급 결과 검증 후 보상·영수증·TOP 커서·이전 로그 삭제가 모두 한 거래로 커밋된다. 중복 호출, 응답 유실, 중간 실패 시 재지급하거나 부분 지급하지 않는다.
- 기존 TOP 1 누적 트로피 및 2026-10-11 18시 TOP10 일회 메시지 캠페인은 유지한다. DB 스키마·공통 거래/인증 기반 변경은 없다.
