# 군단토벌 입장 화면·실계정 편성 수정

## 문제와 수정

운영 PVE 버튼이 검수 프리뷰를 바로 열고 고정 원정대를 생성했다. 실제 저장 덱과 용병을 누락한 잘못된 연결이다. 사용자 후속 요청은 정상 입장 절차, 내 덱·용병, 완성된 진입/콘텐츠 UI다.

- 섬 배경과 승인된 포스터, 카드 원화 5장, 별도 용병 패널, 난이도 선택과 고정 입장 버튼으로 전용 입장 화면을 구성했다.
- 메뉴 열기·난이도 변경·결과에서 복귀는 대기 상태다. 명시적 입장 후에만 전투 페이지/렌더러/서버 원정을 생성한다. 중복 클릭과 닫힌 화면의 지연 응답은 출전하지 않는다.
- 서버의 기존 `loadScrapyardV3Snapshot` 및 `releasedMercenarySnapshot`을 연결한다. 출전 때 다시 읽은 저장 카드, 강화·고유특성·타입·장비·마법·궁극기와 용병/CMS 스킬을 사용한다. 일반 카드 5장과 용병 1장은 분리한다.
- 공용 PVE의 플레이어 팀 구성 함수를 그대로 재사용한다. 군단토벌 제한 시계는 슈트/스킬칩이 없는 계정에서도 작동한다. 나머지 PVE/PVP 결과는 이전 운영 기준과 바이트 단위 비교한다.
- 운영 전투 페이지는 검수 party 선택 UI가 없다. 전투 HUD, 중간 보스, 클릭 드랍, 결과/재도전/입장 화면 복귀를 사용한다. 기존 V3 진형·카드 도크·등급 프레임은 유지한다.
- OWNER 한정, 일반 공개 OFF, 실계정 보상 지급 OFF, 기존 CMS 후보와 드랍 정책을 유지한다.
