## 원인과 수정

편성 스냅샷의 발테르는 `skills: []`였고 정규 서버 전투 생성에서도 스킬을 부여하지 않았다. V17의 광역 ultimate 자산은 있었지만 PVE 서버 이벤트가 없어 실전에서 재생될 수 없었다.

- 단일 정책 `shared/mercenary-valter-v1.mjs`에 **종결 집행 / MS-996 / PVE 전용**을 연결했다. 기존 SSS 광역 기준과 같은 총 배율 560%, 에너지 35, 재사용 5행동이다. 살아 있는 서로 다른 적 전체에 예산을 나눠 회피·방어·방벽·경감을 각각 판정한다. 적이 한 명이면 전체 예산으로 한 번 때린다.
- 오래된 빈 편성 스냅샷도 새 PVE 전투 생성 시 서버의 정규 스킬을 받는다. PVP는 기존 기본 공격 전용 정책이다. 다른 용병이나 일반 카드에 이름·스킬 복사로 발테르 광역이 적용되지 않는다.
- `MERCENARY_VALTER_AREA`의 `hits`는 각 대상의 최종 HP/방벽을 담는다. 상위 `damage`/`absorbed`는 합계이므로 기존 PVE 피해 집계도 누락되지 않는다. 동시 타격을 마친 뒤 KO/부활을 처리한다.
- V3는 서버 영수증 한 개를 승인 V17 `ultimate` 한 번으로 재생한다. 이미지·모션·이펙트 원본은 변경하지 않았다. 12명 동시 피해 숫자는 대상 높이와 폭에 맞춰 표시한다.
- 기본 공격·단일 스킬은 **4.05 → 1.62초**, 광역 ultimate는 **5.55 → 2.22초**, 칼 적중은 **약 1.7344 → 0.6938초**다. 전역 재생 배속은 별도로 유지한다. 대기 오라·서버 행동 주기·피해량을 모션 배속으로 늘리지 않는다.
- 메인 로더와 10개 V3 소비 번들을 함께 갱신했다. 캐시 식별자는 `valter-pve-area-2_5x` / `20261009-valter-area-2_5x`다.

발테르의 기존 능력치·베르칸 HP/방벽 피해 0·개인 면역, 다른 리미티드 성능, 팩 OFF/가격/확률/개봉 한도는 유지했다. 저장된 전투 영수증을 소급 재계산하거나 실계정 전투·보상을 생성하지 않았다.
