# 베르칸 속도 및 군단토벌 광역기 처리 — 2026-09-27

사용자 요청은 베르칸 공격속도·행동력 상향/추가 광역기 제작, 군단토벌의 여전히 어색한 광역 처리 재확인이다.

## 변경

- V-055 베르칸의 운영 `RANK_FIXED` 속도를 1.25배로 계산한다. 일반 카드 4회 행동당 용병 5회 추가 행동이 가능하도록 0.25 행동 진척을 보존한다. 다른 용병, 레거시 스냅샷, 다섯 일반 카드 편성은 유지한다. 듀오에서는 해당 소유자의 카드만 진척을 만든다.
- 실제 베르칸 일반 사격/흑금 낙성 GSAP 속도도 1.25배로 맞춘다. 기존 1.3배 재생 기준 1.625가 된다. 피해 접촉은 로컬 1.12/2.08초 그대로이며 전체 타임라인을 함께 가속한다. 서버가 확정한 피해·회피·보호막은 각 대상에 한 번만 반영한다.
- HP/공격력/방어력, 기존 스킬 총 배율 5.6·비용 35·재사용 5행동은 변경하지 않는다. 8,192건 양 진영·네 전투력·네 덱의 동일 엔진 비교에서 베르칸의 대 크라이번 승률은 두 시드 묶음 62.40%/59.89%, 보스 스킬 누적 피해는 비교 대상의 1.011~1.020배였다. 운영 승률 예측이 아닌 고정 로컬 회귀 표본이다. 과거 동급 승률 요구는 사용자의 이번 속도 상향 요청에 맞게 갱신했다.
- 추가 광역기 **흑금 천우**는 독립 프리뷰 `preview/mercenary-berkan-area-v1/`에 준비했다. 16개 새 RGBA 연속 프레임을 기존 PixiJS/GSAP/V3와 결합하며 운영 연결·CMS 배정·피해 정책 추가는 하지 않는다. 신규 이펙트는 검수 후 연결한다는 고정 기준을 따른다.

## 군단토벌 재현과 수정

첫 광역 타격 예정 시각 1.08초에 준비 동작을 다시 시작하여 실제 타격이 2.16초가 되고, 뒤의 검마다 0.30초가 다시 추가되는 문제를 회귀로 재현했다. 별도로 광역 피해가 이미 적용된 12마리의 퇴장이 앞선 카드 복귀 Promise를 기다리는 경로도 재현했다.

군단토벌의 `continuousAreaPlayback`에서 CAST 시점에 광역기 전체 접촉을 한 번 예약한다. Z의 다섯 타격은 1.08/1.21/1.34/1.43/1.54초로 이어지고, 헬기 역시 기존 접촉 간격을 유지한다. 명중 시 몬스터 퇴장은 병렬로 시작하되, 새 몬스터 슬롯 교체에는 앞선 동작이 모두 완료되어야 한다는 기존 경계를 유지한다. 이벤트 완료 통지는 서버 순서를 유지하고 피해를 다시 계산하거나 복제하지 않는다. 일반 PVE/PVP의 기존 스킬 재생 경로는 이 토벌 전용 옵션을 켜지 않는다.

15분 보스 시계/1배속, OWNER 무제한·일반 하루 2회, 현재 OWNER 공개/실계정 보상 OFF는 변경하지 않는다. 새 자산이나 음원으로 승인된 Z/헬기를 바꾸지 않는다.

## 추가 재현: 광역 타격 앞의 다른 퇴장 대기

마지막 확인에서 `CAST → 일반 공격(복귀 대기) → 다른 몬스터 KO → 다음 일반 공격 → 광역 HIT` 순서로 큐를 구성하면, 재생 커서가 광역 HIT에 도달하기 전에 멈추는 별도 경로를 발견했다. 12마리 × 5타격이 4초 동안 모두 0회로 남는 실패를 먼저 재현했다.

이미 시전한 토벌 광역기만 독립적으로 예정된 접촉을 처리한다. 외부/QTE 경계, 남은 슈트 탄착, 실제 몬스터 인스턴스 ID를 확인하고 원래 큐가 따라잡을 때 재처리하지 않는다. 완료 통지는 기존 서버 순서를 지키고, 슬롯 교체는 앞선 공격과 퇴장의 완료를 계속 기다린다. 대기 중에도 동일한 GSAP 시계로 FX 소멸을 샘플링한다. 일시정지·취소와 새 몬스터를 오래된 슬롯으로 조회하는 경우는 이 조기 처리에서 제외한다.

후속 배포 기준은 실제 직전 운영 `1929039c8b84e4e2bd6926db72bf59bf9067a2b2`이다. 새 실패로 확인된 토벌 클라이언트 처리와 로더·생성 번들만 변경하므로 범위 배포를 유지한다. 선택 회귀는 `legion-hunt-area-cadence-20260927`, `legion-hunt-z-body-playback-20260926`, `z-body-thunder-fx-v3`, `battle-suit-skill-chip-runtime-v2046`, `sustained-hunt-v2`, `pve-battlefield-entry-v2117`, `v3-common-grid-v1`이다. 변경 없는 베르칸·서버 재화 검사는 첫 배포 결과를 재사용한다.
