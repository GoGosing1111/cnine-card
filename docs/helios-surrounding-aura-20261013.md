# 헬리오스 주변 아우라 — 2026-10-13

사용자 지시: `헬리오스는 왜 발테르처럼 아우라 없냐 투명화 말고 발테르 참고해서 주변 아우라 만들어`.

## 원인과 변경

- 운영 HeliosCombatPlayback은 공격 종료·초기 설정 시 SolarFX를 취소하고 모든 효과를 숨겼다. 발테르와 달리 대기 아우라 갱신 경로가 없었다.
- 발테르 KnightFX의 실루엣 18장·외곽 광원 구조를 참고해 별도 HeliosSurroundingAura를 연결했다. 기존 헬리오스 황금 맨틀·태양 광륜 시트와 발밑 고리, 상승 불티 24개를 본체 뒤에 배치한다.
- 원본 몸체는 alpha 1을 유지한다. 주변 아우라의 프레임 전환과 광원만 변화하며 본체의 색·이미지·무기·배율·좌표를 덮어쓰지 않는다. 외곽은 현재 모션을 그대로 따라가며 적군의 좌우 반전도 부모 좌표를 따른다.
- 대기 시 V3 소유 GSAP 시계로 주변 효과만 갱신한다. 공격은 기존 서버 영수증·2.6배속을 유지하고 종료 후 아우라를 복구한다. 화면 숨김·취소·사망·제거·재입장과 동작 줄이기를 지원한다. 기존 배포 문서의 ‘상시 루프 없음’ 설명은 이번 사용자 지시로 대체된다.
- 새 이미지 생성·원본 가공·전투 수치·획득·계정 데이터 변경은 없다. 발테르 구현은 수정하지 않았다.
- 운영 10개 전투 번들과 메인 로더·앱·서비스워커의 캐시 키를 갱신했다.

## 검수와 배포 범위

- `tests/helios-surrounding-aura-20261013.test.mjs` 5건 통과: 본체/피격 위치 보존, 반전, 사망·부활, 동작 줄이기, 중복 루프 방지, 취소·제거, PVP 단일/PVE 광역 피해 1회 표시와 2.6배속 보존.
- 실제 운영 번들을 사용하는 로컬 전장에서 PC 1440×1000 PVP 아군·PVE 12마리 광역기와 모바일 390×844 PVP 적군·PVE 광역기를 직접 확인했다. 네 화면 모두 대기·공격 후 복구·사망/부활·피격 위치 보존·취소/재개·동작 줄이기·제거/재입장 7개 흐름, 가로 넘침 없음, 본체 alpha 1을 통과했다. 기본 공격 피해 표시 1회·광역기 대상별 12회이며 브라우저 오류는 없었다. 증거는 `docs/qa/helios-surrounding-aura-20261013/`에 보존한다. 승인 원화와 전투 수치에 변화가 없는 표시 경로 수정이므로 전체 검사를 실행하지 않는다.
