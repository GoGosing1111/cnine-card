## 사용 방법

1. `/preview/project-v-mercenary-system-v1/skills`에서 스킬 이름·효과·약점과 16프레임 연출을 검토한다.
2. 시연용 용병을 자유롭게 바꿔 본다. 시연 선택은 배정에 저장되지 않는다.
3. `/preview/project-v-mercenary-system-v1/skill-assignments`에서 용병을 고르고 적용할 스킬만 직접 체크한다. 모두 미배정으로 시작하며 체크를 해제해 배정을 없앨 수 있다.
4. 배정 초안 저장·재로드·JSON 내보내기/가져오기를 사용한다. 이름·검토 의견과 용병·스킬 연결은 각각 보관한다.

## 데이터와 검증

- 목록: `shared/mercenary-skills-v1.mjs`. ID·효과 분류·표적·메커니즘·연출·검토 의견을 관리한다. code·rank·exclusivity가 없다.
- 검토본: version=3 / catalogVersion=1. 로스터 버전에서 독립했다. 구형 V1/로스터10 및 V2/로스터11의 이름·의견·수정 번호는 보존하고 당시 제안 code만 제거한다. 임의·누락·중복·ON 필드를 자동 수리하지 않는다.
- 배정: `shared/mercenary-skill-assignments-v1.mjs`, 형식 `PROJECT_V_MERCENARY_SKILL_ASSIGNMENTS_V1`, authority=USER, status=DRAFT, runtimeEnabled=false. 43개 `{code, skillIds: []}`가 기본값이다.
- 여러 스킬이나 동일 스킬의 여러 용병 선택을 초안에서 허용한다. 실제 장착 슬롯 수·무기 적합성·밸런스 정책은 아직 확정하지 않는다.
- 알려진 용병/스킬 ID, 누락·중복, 길이·버전·OFF·수정 충돌을 검증한다. 스킬 검토 의견이나 제작 참조 code는 배정으로 가져오지 않는다.
- 원화·SD·17개 연속 시트·272프레임·충돌 타임라인은 보존한다. 매니페스트의 creationReferenceCode는 과거 제작 출처만 표시한다.

브라우저 검토 초안이며 운영 CMS DB, 용병 획득·편성 저장·실제 전투는 활성화하지 않는다.
