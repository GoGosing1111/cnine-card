# 반란군 패배 정산 변경 — 2026-10-02

사용자 추가 지시: 반란군 패배 시 코인 삭감을 없애고 참가자 전원을 8시간 수감한다. 이 지시가 과거 코인 차감 및 회차별 시범 운영 1시간 30분·3시간 규칙보다 우선한다.

- 현재 모집 중인 회차와 이후 정산에 적용한다. 반란군 패배 시 보유 코인의 양수·0·음수 여부와 무관하게 잔액을 변경하지 않는다.
- 반란군 참가자 전원을 정산 시점부터 8시간 수감한다. 기존 포로수용소의 자동 만료·OWNER 석방 동작을 사용한다.
- 정산 완료·수감 대상 등록을 기존 원자적 처리에 포함한다. 실패 시 전체 롤백하고, 완료 후 재시도는 형기를 늘리거나 석방자를 다시 수감하지 않는다.
- 이미 끝난 정산·기존 코인 차감 기록은 재계산하지 않는다. 족장팀 패배의 8시간 수감·국민 재판과 무승부 무불이익은 유지한다.
- 전쟁 규정, 참가 확인창, 전황의 패배 규칙·종료 안내, 관리자 규칙·개전 확인창을 같은 내용으로 수정한다. 사용자·관리자 JS 로더 캐시 버전을 함께 올린다.
