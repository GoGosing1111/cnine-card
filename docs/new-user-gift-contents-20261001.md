## 기존 박스와 거래

- 신규 명세는 version 2이며 카드별 강화값을 저장하고 실제 `user_cards` INSERT/UPDATE에 전달한다. 기존보다 낮은 강화로 덮어쓰지 않으며 수량 0인 옛 행은 새 지급 강화로 초기화한다.
- 최초 운영 확인에서 미개봉 V1 4건, 개봉 완료 V1 19건이 있었다. 사용자 요청의 전체 적용에 따라 미개봉 V1만 해시·원래 구성 검증 후 최신 전체 구성으로 한 번 전환한다. 원장 행 잠금과 조건부 갱신을 사용하며 기존 발급자·발급일·1회 수령 기록은 유지한다. 이전 명세 해시는 새 명세에 보존하고 원래 내용은 최초 발급 감사 로그에서 추적할 수 있다.
- 전환 후 신규 카드 추가는 그 박스에 다시 소급하지 않는다. 이미 개봉한 원장과 결과는 유지하며 소급 추가 지급하지 않는다. 운영 전환 도구는 `scripts/ops/new-user-gift-contents-20261001.mjs`이며 박스 신규 발급·개봉·계정 보상 지급을 하지 않는다.
- 기존 원자적 개봉·한정 재고 잠금·지급 행수 검증·실패 전체 롤백·완료 재응답을 유지한다. 상품 설명만 upsert하며 운영 OFF 설정은 덮어쓰지 않는다.

## 최소 검수·배포 범위

- 변경 범위는 한 상품의 보상 구성·전용 원장 전환·안내·포스터다. 공통 인증/DB 기반/스키마/의존성/기능 플래그 변경은 없다.
- 실제 직전 운영 Pages는 `9fa05b85-8dec-4dfb-a455-3e792e67440c`, 소스 `ecab6a11617ab1a83f7876591a2c59d39711fbed`로 Wrangler 운영 목록과 완료 기록을 대조했다. 이후 완료 문서와 클랜 운영 도구 커밋도 포함하되 게임 실행 파일 변경이 없음을 확인했다. 이 소스를 배포 기준으로 사용한다.
- `tests/new-user-gift-v2075.test.mjs`만 선택한다. 세 등급 강화, 새 장비 5개, 더 높은 강화 보존, 원자성/재시도, 미개봉 V1 전환/롤백/재실행, 완료 V1 보존, 설명 OFF 유지 및 공용 화면 표시를 확인한다. 배포 과정에서 한 번 실행하며 무관한 전체 검사는 반복하지 않는다.
- 지정 명령 `npm run deploy:production -- --scoped`. Worker 문법, 깨끗한 커밋·origin/main, 출시/캐시/Hyperdrive 필수 검사는 기존 도구를 따른다.
- 플레이어 개봉 모달을 PC 1280×1050·모바일 390×844에서 실제 공용 렌더러와 모의 API로 확인했다. 전체 구성 6행, 카드 상세 목록, 개봉 완료·인벤토리 복귀, 가로 넘침 없음, 브라우저 오류 없음이 통과했다. 운영 검수는 변경 파일·포스터 반영과 새 상품 명세만 짧게 확인한다.
