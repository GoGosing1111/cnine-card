# 몬스터 디펜스 전체 이미지 UI V5 — 2026-10-17

사용자 `준비취소 다시만들어라`에 이어 분대와 나머지 박스·배지 모두를 스킬로 제작한 이미지로 교체하도록 지시했다. 단순 CSS 네모 박스는 최종 화면 기준에서 제외한다. 기능 검사 통과와 사용자 시각 승인은 구분한다.

## 이미지와 연결

- 내장 ImageGen으로 준비/취소용 흑철 버튼, 날개형 분대 명패, 수호석 문장, 전술 금속 패널 총 4종을 제작했다. 신규 PNG의 원본 바이트와 알파를 보존했다. 버튼은 `preview/coop-defense-v1/assets/lobby-v4/ready-command-button.png`와 `prompt-ready-button.json`, 나머지 3종은 `preview/coop-defense-v1/assets/ui-v5/manifest.json`과 `prompts.json`에 원본·해시·전체 프롬프트를 기록한다.
- 준비/취소, 혼자 연습·참가·초대 복사, 난이도·인원 선택, 분대 탭·준비 상태·역할·이름판, 초대 코드판·정보창·하단 조작부에 연결했다. 난이도/웨이브는 수호석 문장 형태다.
- 전투 HUD·방어선 탭·유닛/지원 이동·전술 버튼·카메라 조작·미니맵·공세/보스 안내·전멸 대기·이탈 확인·결과·토스트에 연결했다. 캐릭터 머리 위 이름판은 디펜스 서브클래스에서 생성 이미지 Sprite로 교체한다. 체력·보호막·전장 범위 등 실제 데이터 도형은 유지하며 공통 BattleCharacter 파일은 바꾸지 않는다.
- 정비창·포인트/강화/특성 탭·강화 능력 선택·능력 증감판·특성 카드·보유 특성·참여자 상태·정비 완료 버튼에 연결했다. 정비 미리보기도 같은 이미지 세트를 소비한다.
- `image-skin.css`는 그림의 9-slice 배치, 화면 크기별 여백, 텍스트·접근성과 상태를 담당한다. 숫자·문구는 DOM/Pixi 텍스트로 남기고 확률·포인트·준비 판정은 서버 값을 따른다.

## 검수

- 실제 로컬 Durable Object fixture에서 2인 합류, 방장/참여자 준비·취소, 마우스·터치·Enter·Space, 시작 가능/차단을 확인했다. PC/모바일에서 준비와 출전 버튼 높이가 일치하고 최소 44px 터치 영역이 유지된다.
- 3인 연습의 9기 분대 전환, 정보창 개폐, 모든 캐릭터 이름의 하단 버튼 위 표시를 1440×1000, 390×844, 320×720, 844×390에서 확인했다. 2인 PC의 큰 캐릭터가 화면 밖으로 나가던 크기, 320px의 명패/하단 겹침, 정보창 위치와 모바일 정비 프레임의 텍스트 여백을 보정했다.
- 전투 카메라·유닛 선택·이탈 확인·부활·결과 화면과 실제 서버 포인트 공개·강화 선택/영수증·특성 선택을 확인했다. 7종 적과 9기 아군의 이미지 HUD·단일 renderer, 모바일·가로·재접속에서도 앞서 수정한 전진 방향을 확인했다.
