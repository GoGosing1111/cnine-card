아윤은 운영 제니스 카드의 파란 고양이 모자, 흰 티셔츠, 회색 반바지와 크림색 신발을 유지한다. 족스케는 운영 카드의 철구 얼굴, 올린 머리, 흰 아이젠 코트와 검은 내피를 유지한다. 동일 멤버의 다른 카드에는 적용하지 않는다.

기본 이미지 생성 도구로 각 캐릭터를 개별 제작했다. 최초 출력의 체크무늬가 RGB 배경에 포함되어 사용하지 않았다. 같은 도구로 배경만 크로마키로 수정하고 기존 `scripts/process-project-v-chroma-sd-v1.mjs`로 실제 알파 PNG와 안전 여백을 출력했다. 1350×1350 PNG, 384/768 AVIF·WebP를 제공한다. 최종 프롬프트는 `docs/ayoon-joksuke-sd-v2115-prompts.json`에 보존한다.

기존 ZENITH/FUR 전투 아트 어댑터와 반응형 전투 자산 맵에 카드 ID로 연결한다. 카드 원화와 전투 SD를 분리하며 도감·덱·카드 상세는 기존 원화를 사용한다. 어댑터와 매니페스트, 메인 스크립트의 캐시 키를 함께 갱신한다. 신규 공격·스킬 효과나 게임 수치를 추가하지 않는다.

사용자의 제작·연결 요청이 운영 연결 근거다. 기존 제니스 29종의 과거 시각 승인 기록은 보존하고, 신규 아윤에는 `USER_CREATE_AND_CONNECT_20260914`를 별도로 기록한다. 출력 후 사용자 시각 승인을 받았다고 기록하지 않는다.

투명 알파·여백·해시·반응형 크기와 기존 전투 어댑터 검사를 통과했다. 실제 V3 렌더러에서 PVP/PVE 표시, PVP 기본 공격 3회, 모바일 390px 폭을 확인했고 해당 검사에서 브라우저 오류는 없었다. 운영 배포는 `npm run deploy:production`의 `release:gate`를 통과한 동일 커밋으로 진행한다.
