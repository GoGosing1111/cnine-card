# 시즌 3 모집·드래프트 자동 일정

사용자 승인: 이번 챔피언스리그 종료 즉시 신규 클랜 참가 모집, 실제 종료일의 다음 날 21시(KST) 드래프트. 운영 자동 일정에도 반영한다. 정규 클랜전은 **화·목·토·일 21:00–22:00** 그대로 유지한다.

## 일정

- 시즌 2(id 5) 2·3위전: 2026-09-28 21:00–22:00 KST, 결승: 22:00–23:00 KST.
- 결승의 기존 전투·정산 완료 처리 직후 시즌 3 신규 모집을 연다.
- 위 일정대로 종료 시 2026-09-29 21:00 KST에 신청을 닫고 기존 1시간·지명 30초 드래프트를 시작한다.
- 첫 정규 클랜전은 10월 1일 목요일 21:00. 다음 라운드도 기존 CMS 화·목·토·일 21시 설정으로 생성한다.
- 종료일이 바뀌면 실제 `completed_at`의 한국 날짜 다음 날 21시를 계산한다. 24시간을 단순 가산하지 않는다.

## 범위와 보호

- 기존 ClanDraftAlarm을 재사용한다. 시즌 2 전용 계획 `clan_champions_followup_20260928:5`가 켜진 경우에만 챔스 경계에서 진행·종료를 자동 처리한다. 플레이어 접속이 필요 없다.
- 경계 이전에는 시즌·설정·계획·현재 경기의 인덱스 조회만 수행한다. 전투나 유저 명단을 반복 스캔하지 않는다.
- 종료 후 기존 우승 보상 처리 재시도를 거친다. 새 시즌과 개설 영수증을 한 트랜잭션으로 저장하고 중복 실행 시 재사용한다. 기존 시즌·순위·멤버·전적·CMS 설정을 보존한다.
- 과거 참가자는 자동 복사하지 않는다. 시즌 3은 신규 신청 풀을 사용한다. 기존 최소 2명 조건과 드래프트 안전장치는 유지한다.
- 공통 DB·인증·스키마·인프라 변경 없음. 공개 플래그와 다른 콘텐츠를 건드리지 않는다.

## 검증 및 배포 범위

- 새 전환 회귀 8개: SQLite/PostgreSQL 종료→모집, 중복 실행, 원자적 롤백·재시도, 우승 보상 오류, 21시 드래프트, 정규 요일·시간 보존, 한국 날짜 경계와 비활성 게이트.
- 관련 기존 회귀: `tests/clan-champions-v2071.test.mjs`, `tests/clan-draft-timeouts-20260915.test.mjs` 및 Worker 컴파일.
- 직전 운영 배포: `6783f1d1-0822-4723-8c95-8fc259d09944`, 소스 `d819fb672a208b2376ce1d716bdcaf33c23efb34`.
- 클랜 후속 일정에 한정된 작은 변경이므로 `npm run deploy:production -- --scoped` 사용. 게임 전체 검사는 실행하지 않는다.
- 운영 계획은 배포 후 단일 트랜잭션으로 등록한다. 실행 전 dry-run 롤백, 등록 후 독립 조회 및 Durable Alarm의 다음 경계 확인으로 마무리한다.
