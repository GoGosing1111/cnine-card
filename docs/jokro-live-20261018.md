# 족로 SSS 리미티드 · 지정 계정 라이브

사용자 `기존 리미티드 프레임 쓰고 라이브 반영, 획득 막아놓고 핑크빛유두에만 지급, 청룡단천 광역기 데미지 강하게` 지시로 승인된 프리뷰를 기존 V3 운영 전투에 연결한다. 다음 용병 프리뷰의 버튼 장식에 ImageGen을 쓰지 말라는 지시는 향후 기준이며, 이번 버튼은 유지한다.

- **V-979 족로 / SSS LIMITED**. 프리뷰 임시 코드 V-992는 이네스와 충돌하므로 사용하지 않는다. 일반 팩·리미티드 팩·합성·재뽑기·제작 풀에 추가하지 않는다. ID 1 핑크빛유두만 보유 조회·PVE/PVP 편성·단건/배치 전투 조회가 가능하며 다른 계정의 비정상 보유 행도 거절한다.
- 기본 전투력 **1,617,408**. 동일 편성·장비·성장 조건에서 진무보다 기본·연계 공격·체력·전체 방벽 20% 상승, 기본 피해 상한 20% 상승. 공통 전열 방벽 60%를 포함해서 상승 비율을 계산한다. 행동 속도와 추가 행동은 진무와 같고 개인 피해 경감은 **80%**다. 상태이상·반격 보호와 베르칸 피해 면역을 유지한다.
- PVE **청룡단천**은 총 **1,260%**를 살아 있고 공격 가능한 적 전체에 나눠 적용한다. 에너지 35, 재사용 5행동. 시전당 WINDUP → 대상별 피해 1회 → END를 보장하며 화면 절단·후속 파열은 추가 판정이 아니다. PVP는 전용 기본 공격 정책을 따른다.
- 승인 원화와 전투 master·24동작/108효과 프레임은 보존한다. 일러스트는 공통 승인 `frame-valter-slim-v3.png`(SHA-256 F5F636CAC672A485F19CE4ED484ECB2798217D365A4D31B2C6C7FABB878189EA)를 사용한다. 새로 원화·무기·칼집을 생성하지 않는다.
- 기존 V3/PixiJS/GSAP 시계가 재생·피해 접점·중단·정리를 소유한다. 몸 동작 2배, 효과 1배, 캐릭터 네온 윤곽, 실제 전장 두 조각과 검흔·파열을 유지한다. 전체 일러스트 컷신은 없다. 기존 SSS 공용 대사 레일에 족로 프로필을 추가해 PVE/협동 허용 범위에서 상시 표시하고 스킬 때 문구를 순환한다.
- 디펜스도 동일한 V3 족로 자산 로더와 정리/재개 함수를 포함한다. 해당 콘텐츠의 역할 정규화·출시 설정은 유지한다.
