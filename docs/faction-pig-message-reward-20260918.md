## 수령 지원

`PIG_COIN` 메시지 보상은 `pig_coin_wallets_v1`에 적립하고 `pig_coin_ledger_v1`에 `MESSAGE_REWARD`로 기록한다. 수령 영수증, 지갑, 원장, 메시지 수령·숨김 처리는 하나의 트랜잭션으로 커밋한다. 계정 소유권과 정수 수량을 검증하며 동일 메시지의 재시도는 한 번만 적립한다. 실패 시 메시지가 수령 가능한 상태로 남는다.

일반 코인·인벤토리와 구분하며 쿠폰 보상 목록에는 추가하지 않는다. 수령 후 피그코인 상점 잔액 및 상태 캐시를 함께 비운다. `app.js`에만 캐시 키를 추가하며 전투 엔진과 V3 리소스 버전은 변경하지 않는다.
