## 원인과 변경

앞선 변경은 기존 보스 차례에 5회 연속 공격만 추가했다. 첫 공격과 다음 묶음 사이에는 여전히 카드 7회의 행동을 기다렸다. 새 방식은 같은 카드 7회 행동 구간에 5회 공격을 고르게 배분한다. 첫 공격은 카드 2회 후, 이후 간격은 1~2회다. 반복 공격 수는 1로 복원하고 `actionFrequency: 5`의 서버 행동 예산으로 처리한다. 살아 있는 대상 재선택·보스 처치 후 중단·실제 피해와 판정은 기존 권위 서버 전투 경로를 사용한다. 일반 카드, 용병과 독립 슈트의 기존 행동 경로는 보존한다.

공격·방어는 CMS 보스별 1,000% 제한, 전투 유닛 변환 시 1,200% 제한을 아카자에 한해 해제한다. 표시 전투력 계산도 같은 상한 초과 값을 반영한다. 유한 숫자 정규화와 최소값은 유지한다. 아카자의 일반 공격에 적용되던 대상 최대 HP 46% 피해 상한과, 아카자가 받는 타격의 65% 방어 감소율 상한을 해제한다. 고정 최소 피해 1.6%가 높은 방어력을 무시하지 않도록 아카자 대상에게만 이 하한을 제외한다. 피해는 기존 관통·방어 공식과 보호 효과로 계산한다. 고정 피해 스킬/궁극기 정책은 변경하지 않는다.

CMS는 아카자 행의 공격·방어 입력 `max`만 제거하고 두 항목에 “상한 해제”를 표시한다. 다른 나이트메어 보스와 기본 설정, 아포칼립스/PVP에는 적용하지 않는다. 승인 SD·원화와 공통 궁극기 15%·1회는 유지한다.
