# 배틀슈트 이름표 정리 · 2026-09-18

사용자가 지적한 배틀슈트 위 닉네임 표시를 공용 `AccountBattleUnit`에서 변경한다.

- 높은 검정 박스·청록색 외곽선·이중 밑줄·두꺼운 글자 테두리를 제거한다.
- 높이 24, 최대 폭 192의 반투명 네이비 바탕에 작은 라임 식별선과 14px/600 흰색 글자를 사용한다. 기존 높이는 36, 글자는 18px/900이었다.
- 20자 입력 제한과 긴 이름 말줄임을 유지한다. 모바일 전장 축소 뒤에도 글자는 최소 10 CSS px를 유지하며, 추가 크기는 기존 이름표 하단을 기준으로 위로 확장해 머리를 가리지 않는다.
- 슈트·무기 원본, 공격 애니메이션·효과·서버 판정·전투력·재화·진형 좌표는 변경하지 않는다. Z-BODY와 기존 총기 슈트 모두 같은 이름표를 사용한다.

공용 소스와 운영 번들 9개를 함께 빌드한다. 실제 엔진과 래퍼는 `2126-fluid-combat-suit-nameplate-20260918`을 사용하며, 메인 앱은 기존 `ready()`/`ensureRuntime()` 판정을 그대로 사용한다. 앱과 전투 파일에는 `suitName=20260918` 캐시 키를 추가한다.

검수는 운영 재화를 쓰지 않는 로컬 계정 API와 실제 메인 `index.html`의 토벌 시작·랭크전 매칭 버튼으로 진행한다. 배틀슈트 103개, 공통 그리드 25개, 운영 연결 77개 기존 검사를 통과했다. PC 1440×1000·1280×720와 모바일 390×844에서 입장·전투·결과·복귀·재입장과 이름표를 확인했다.

구버전 엔진을 제공한 격리 서버에서도 메인 시작 버튼으로 새 `battleRuntime` 번들이 자동 요청되고 토벌 결과·복귀까지 완료됐다. 모바일 PVE/PVP에 각각 503을 주입했을 때 오류 안내와 복귀 버튼이 실제 표시되고 대기 화면으로 복귀했다. 검수용 제어 서버·DB·로그는 배포 경로 밖 `../qa/`에만 둔다. 전체 출시 게이트 통과 뒤 `npm run deploy:production`으로 배포한다.
