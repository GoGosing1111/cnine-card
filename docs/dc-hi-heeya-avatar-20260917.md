## 운영 절차

`scripts/ops/avatar-dc-hi-heeya-release.mjs`는 API에 자동 연결되지 않는 명시적 일회성 작업이다. 작업 키 `avatar_dc_hi_heeya_clan_grant_20260917_v1`를 잠가 중복 실행 시 원래 영수증만 반환한다.

현재 시즌·DC 신원·전체 명단·활성 계정·실제 T1 옵션·코드와 시리얼 충돌을 재검증한 후 아바타, 두 효과, 전원 보유권, 감사 로그와 완료 영수증을 하나의 PostgreSQL 트랜잭션으로 저장한다. 검증이나 지급 실패는 전체 롤백된다. dryRun은 모든 쓰기를 롤백한다.

공식 `npm run deploy:production`의 `release:gate`를 통과한 자산이 운영 URL에서 해시까지 일치하는지 확인한 후 지급한다. 운영 명단·실제 지급/만료 시각·감사 ID는 DB 영수증과 비공개 로컬 운영 결과에 보관한다.
