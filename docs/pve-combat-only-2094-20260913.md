# 무한의탑·폐차장 전투 연결 — 2094

2026-09-13 최종 사용자 지시: “UI는 유지하고 전투화면을 개편안으로 하라고”.

## 범위

- 무한의탑과 폐차장의 기존 게임 메뉴, 입장 화면, 덱 표시, 버튼, 결과 화면을 보존한다.
- 도전/출발 버튼으로 시작하는 전투만 실제 서버 V3 연속 전투와 공용 PixiJS/GSAP 재생기로 교체한다. 독립 프리뷰 페이지나 별도 원정 지휘소를 연결하지 않는다.
- 카우방의 PVE·아포칼립스 포탈 범위와 기존 운영 연결, 하이퍼팩 개봉 OFF는 변경하지 않는다.

## 전투 및 운영 정책

- 탑은 `tower/fight`에서 현재 CMS의 층별 수호자·전투력으로 서버 연속 전투를 생성한다. 준비된 일반 24체 → 정예 3체 → 수호자 1체, 동시 적 3체, 180초 규칙을 사용한다.
- 탑의 코인·추가 보상 지급 경로는 기존 경로를 유지한다. 승리하면 정확히 한 층만 진행하며 기존 최고층에서 완료한다. 재등반, 160층 확장, 반복 보상, 층 건너뛰기를 도입하지 않는다.
- 제출한 도전층과 현재 서버 층이 다르면 전투 전에 409로 차단한다. 수신한 전투 결과는 계정별 세션 저장소에 보관하여 화면 새로고침 후 같은 결과를 재생한다. 서버 응답을 받지 못한 경우의 완전한 전투 기록 복구는 기존 탑 API의 지원 범위 밖이며, 층 검증으로 다음 층을 중복 요청하지 않게 한다.
- 폐차장은 기존 `scrapyard/status` 입장 UI에서 `scrapyard/v3/run`을 사용한다. 서버에 저장된 동일 요청 결과를 재조회하고 결과를 확인한 뒤 클라이언트 요청 기록을 해제한다. 출입증, 일일 제한, 구역별 보상은 기존 CMS 정책을 따른다.
- 전투 전용 공용 모듈은 `js/pve-continuous-battle-live.mjs`, 스타일은 `css/pve-continuous-battle-live.css`다. 기존 `ProjectVBattleV3Live`와 공통 진형·SD·카드 원화 도크를 재사용한다. 서버 피해·승패를 화면에서 다시 계산하지 않는다.
- 일시정지, 백그라운드 정지, 결과 보기, 화면 이탈 시 재생 취소를 연결한다. 결과 화면은 각 콘텐츠의 기존 화면으로 돌아간다.
