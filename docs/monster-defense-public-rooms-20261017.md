# 몬스터 디펜스 · 공개 대기방

사용자 `격전지처럼 방 방식으로해 초대코드 쓰지말고`에 따라 초대코드 입력·표시·클립보드 링크·URL 초대 처리를 제거했다. 출전 준비의 **방 찾아 참가**에서 공개 목록을 열고 **참가하기**로 합류한다. 기존 **대기실 만들기**와 목록의 **방 만들기**는 현재 선택한 난이도/2~3인 설정으로 방을 만든다.

## 사용 흐름

- 실제 보유 용병2+카드1을 편성하고 방을 만들거나 목록에서 선택한다. 편성 전에도 목록은 확인할 수 있으며 **내 분대 편성**으로 이동한다.
- 방장 이름, 난이도, 웨이브, 현재/최대 인원, 준비 상태를 표시한다. 난이도 및 참가 가능한 방 필터, 수동 새로고침과 10초 자동 갱신을 제공한다. 목록은 최근 50개이며 추가 방 존재 시 안내한다.
- 목록을 닫거나 숨겨진 탭에서는 자동 요청을 멈춘다. 인원이 찬 방의 참가를 비활성화하고, 참가 직전 정원/출발 상태가 바뀌면 서버 거절 내용을 목록 안에 표시한 뒤 최신 목록을 제공한다.
- 대기실은 **공개 대기방 / 방장 이름의 방어대**를 표시한다. 빈 분대에는 방 목록에서 모집 중이라고 안내한다. 준비·출발·편성 교체·방장 승계·재접속은 기존 동작을 유지한다.

## 목록 저장 및 안전성

`shared/monster-defense-room-list-v1.mjs`가 공개 요약만 생성하고 `MonsterDefenseDirectory`는 기존 COOP_PLAYERS의 별도 `defense:public-lobbies-v1` 인스턴스에 저장한다. 격전지 목록과 분리되며 바인딩/마이그레이션은 추가하지 않는다. 계정 ID·편성 원본·전투 티켓은 목록에 노출하지 않는다.

방 상태가 바뀌면 갱신하고 같은 상태는 20초 간격으로 임대를 연장한다. 목록 임대는 45초, 실제 방의 2시간 만료를 넘지 않는다. 연습방·전투 중·해산·만료·사람 접속이 45초 이상 없는 방은 숨기며 대기방 재접속 시 다시 등록한다. 시작/해산의 삭제 표식과 단조 증가 revision이 늦게 도착한 과거 목록의 복원을 차단한다. 마지막 한 자리의 동시 참가와 실제 출발은 원래 방 Durable Object가 판정한다. 목록 갱신 장애는 알람에서 재시도한다.

기존 TEST 및 보유 편성·역할 능력치·성장·부활·보상 OFF 설정을 유지한다. 일반 격전지의 방/보상 경로는 변경하지 않는다. 로컬 검수 서버에도 같은 방 목록 UI를 연결했다.

## 이미지 및 검수

디펜스 안에서 이미 제작한 전용 `ui-v5/guardian-panel.png`, `guardian-crest.png`, `squad-nameplate.png` 및 `lobby-v4/ready-command-button.png`, `defense-roguelike-v2/assets/ui-v3/command-button.png`를 사용한다. 목록 카드/창/상태/버튼의 재질과 윤곽은 실제 ImageGen 이미지다. 새 이미지 생성이나 승인 원본 변경은 하지 않았다.

- 관련 서버 검사 10개 통과: 목록 권한/필터/노출 범위·격전지 목록 분리·연습방 제외·준비/정원·방장 승계·출발/해산/만료 제거·오래된 갱신 차단·재접속·동시 참가, 기존 보유 편성과 실제 방 API, 기존 격전지 목록 회귀.
- 로컬 검수 서버/모델 관련 기존 검사 13개 추가 통과. 관련 서버/모델 검사는 합계 23개다.
- `tests/monster-defense-rooms.browser.mjs`: PC 1440×1000 및 390/320px 목록, 검색 조건, 자동 갱신, 가득 찬 방, 참가 오류 안내/복구, 방장 승계, 목록에서 만들기/참가, 실제 3명 준비/출발, Escape와 초점 복구를 검수했다. 브라우저 예외/실패 자산 0건이며, 모바일 방장 명패가 좁은 열로 줄바꿈되던 배치를 수정해 전체 폭으로 표시했다.
- `tests/monster-defense-loadout.browser.mjs`의 참가 경로를 방 목록으로 바꿔 보유 선택/교체/준비 해제/실제 6기 전투를 회귀 확인했다. 운영 계정에 방을 만들거나 참가하는 검수는 하지 않는다.

증빙은 `docs/qa/monster-defense-public-rooms-20261017/`에 보존한다. 관련 검사와 Worker 컴파일을 지정한 scoped 배포로 반영한다.
