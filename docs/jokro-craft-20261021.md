## 구현

기존 용병 제작 정책을 카이론/족로 두 고정 정의로 분리했다. 제작 정책과 레시피 고정 신원 검증, OWN­ER 저장 권한, revision 낙관 잠금, 기존 PostgreSQL 행 잠금과 단일 제작 거래를 유지한다. 족로의 마스터의 별 1,000만 비용은 서버·CMS에서 잘리지 않는다.

각 용병 정책 행을 잠그고 성공 원장을 재집계한 뒤 비용 차감·보유·획득·제작 로그·완료 영수증을 같은 거래로 저장한다. 마지막 수량을 다른 계정이 먼저 제작하면 패배한 요청은 무차감 취소한다. 완료된 요청의 재조회는 운영 OFF·소진 후에도 같은 영수증으로 복구된다.

족로 제작 획득 자격은 WORKSHOP_JOKRO의 실제 성공 로그, COMPLETED 제작 영수증, JOKRO:user:request 획득 기록이 모두 일치해야 인정한다. 기존 지정 OWNER·대여 만료·팩/큐브 3장 검증을 유지하며 보유 행만 추가해 편성 제한을 우회하지 못한다.
