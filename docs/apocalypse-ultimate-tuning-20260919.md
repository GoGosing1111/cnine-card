# 아카드·카네키 켄 궁극기 조절

2026-09-19 사용자 요청: 과도하게 강한 두 궁극기를 CMS에서 조절할 수 있게 한다.
후속 선택: 피해 배율을 절반으로 완화한다. 아카드 190% → **95%**, 카네키 켄 225% → **112.5%**.

## 설정과 전투

- CMS → 전투 관리 → 아포칼립스 상세 설정 → 각 보스 아래 `ULTIMATE`에서 궁극기 사용, 공격력 대비 피해 배율(0~1,000%), 보호막 관통률(0~100%)을 저장한다. 소수점 1자리 입력을 지원한다.
- `battle_apocalypse_settings_v1.monsterProfiles[75|76].legionUltimate`에 저장한다. 기존 개막 스킬의 `skillDamagePercent`와 분리한다.
- 서버가 설정을 정규화해 전투 생성 시 복사한다. 시작한 전투의 값은 유지하고 이후 전투에 새 설정을 사용한다. 일반·자동 PVE는 공통 `pveDifficultyRuntime`과 군단 생성/피해 판정을 사용한다.
- 궁극기 OFF는 세 번째 행동을 일반 공격으로 대체한다. 기존 전용 스킬 OFF는 봉인·힐불가·궁극기를 모두 막는다. 0% 피해는 실제 피해 0이다.
- 봉인·힐불가, 쫄몹 6마리, 보스 기본 능력치, 보상과 원화/SD/연출은 변경하지 않는다. 보호막 관통률은 아카드 40%, 카네키 켄 60%를 유지한다.
- 예전 CMS 창의 저장에 새 필드가 빠져 있어도 기존 궁극기 설정을 보존한다. 기존 설정이 없는 과거 스냅샷은 종전 기본값을 사용하며 운영 완화는 별도 DB 설정으로 적용한다.
- 공용 V3 엔진 번들·로딩 경로·버전은 변경하지 않는다. CMS JS/CSS/설정 모듈의 캐시 키만 갱신한다.

## 운영 변경

작업 키: `ops:apocalypse-ultimate-half:20260919:v1`.
기존 운영 설정을 잠그고 두 보스의 `legionUltimate`만 추가/수정한다. 다른 설정이 동일함을 검사하고 관리자 로그 및 멱등 영수증을 같은 트랜잭션에 기록한다. 명시된 95%/112.5% 외의 수치와 계정 재화는 수정하지 않는다.

운영 도우미·설정 전후 기록은 배포 디렉터리 밖 `cnine-apocalypse-bosses-20260918/ops/apocalypse-ultimate-half-20260919*`에 보관한다. 운영 배포는 전체 `release:gate`를 실행하는 `npm run deploy:production`만 사용한다.

## 검증

- `npm run test:apocalypse`: 30개 검사 통과. 신규 네 검사는 실제 서버 전투 피해 감소, 0% 피해, 궁극기 OFF와 두 상태 스킬 유지, 관통률, 전투 스냅샷, 실제 CMS PATCH의 PostgreSQL 저장·재조회 및 구버전 CMS 저장 보존을 검증한다.
- 실제 CMS 패널 JS/CSS로 95%, 112.5%, 관통률, ON/OFF를 입력하고 저장·새로고침·상한 검증. 1,440px/390px 가로 넘침 없음. 스크린샷은 배포 밖 `qa/apocalypse-ultimate-cms-*`에 저장한다.
- 실제 `index.html`에서 토벌 시작 및 PVP 매칭 → V3 전투 → 결과 → 복귀를 로컬 격리 계정으로 확인한다. 로그와 스크린샷은 `qa/apocalypse-ultimate-entry-qa.json`, `qa/apocalypse-tuned-*`에 남긴다.
