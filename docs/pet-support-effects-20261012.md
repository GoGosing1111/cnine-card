## 변경 범위

- 기존 승인 펫 원화·버프 아틀라스를 재사용한다. 공격은 검기, 방어는 장갑 문양, 체력은 심장과 생명 파동, 속도는 날개·번개, 시작 보호막은 다중 결계로 구분한다.
- 펫 발동 문장 → 해당 펫에서 실제 적용 대상으로 이어지는 빛줄기 → 대상 문양·입자·수치 표시를 2.6초 동안 재생한다. 복합 버프는 모든 효과의 문양과 수치를 표시한다. 전투 진행을 기다리게 하지 않는다.
- 전투 카드 도크에 펫 초상·이름·진영/분대·실제 CMS 수치·대기/스킬 발동/발동 완료 기록을 표시한다. 일반 공유 전투 알림과 별도로 유지한다.
- 모바일 일반 PVE/PVP에서는 마지막 카드 아래에 펫과 이름이 들어갈 공간을 확보한다. 미사용 전투 슬롯을 펫 위치 계산에서 제외하고 긴 펫 이름이 화면 가장자리에서 잘리지 않도록 한다.
- 격전지 지연 입장·시간 보정으로 0초 이벤트를 건너뛴 경우 발동 기록만 복원한다. 시작 체력·보호막을 다시 적용하거나 스킬 연출을 반복하지 않는다.
- 전투 종료·화면 숨김·세션 교체 시 표시와 이펙트를 정리한다. 동작 줄이기는 이동 궤적과 회전을 생략하고 짧은 문양 표시를 사용한다.

서버 전투 계산, CMS 버프 수치, 장착/보유, 드롭, 자석, 재화와 출시 플래그는 변경하지 않는다. 펫은 기존대로 **전투 시작 시 1회 버프**이며 새로운 반복 공격 스킬을 부여하는 변경이 아니다.
