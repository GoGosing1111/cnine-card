# 포트리스 참가상 메시지 지급 — 2026-10-03

- 사용자 승인: `위 인원 마별 150만개 포트리스 참가상 메세지로 지급`.
- 명단: 36팀, 중복 표시를 제거한 참가 닉네임 72명.
- 보상: 1인당 `MASTER_STAR` 1,500,000개, 메시지 제목 `포트리스 참가상`.
- 운영 PostgreSQL `cnine`의 `production` 브랜치에 메시지 70건과 보상 70건을 하나의 트랜잭션으로 저장하고, 커밋 후 실제 저장 인원·종류·수량·중복 여부를 확인했다. 총 105,000,000개.
- 유저가 메시지에서 수령하는 방식이다. 이번 운영 작업에서는 인벤토리 수량을 직접 변경하지 않았다.
- 참가 닉네임은 PLAY DK 인증 연결을 우선해 식별했다. `난종신`, `처음와봄`, `애장`은 인증 연결 계정을 사용하고, 동일 이름의 미인증 게임 계정에 중복 지급하지 않았다. 관리자 역할의 참가자도 명단에 따라 포함했다.
- `박세라-ㅂ-`은 유일하게 일치하는 게임 계정 닉네임으로 확인했다.
- **사용자 지시로 제외한 2명:** `콧송이`, `공명`. 게임 닉네임, 현재 인증 닉네임 및 과거 인증 스냅샷에서 연결을 찾지 못해 계정 정보를 요청했고, 사용자가 `패스`라고 답했다. 70명 지급으로 완료 처리했다. `꽃송이`처럼 유사한 이름에 임의 지급하지 않았다.
- 캠페인: `fortress-participation-20261003-master-star-1500000`.
- 감사 영수증: `app_meta`의 `ops:fortress-participation-20261003-master-star-1500000`. 실제 수신 계정 ID, 참가 닉네임 대응, 메시지·보상 ID, 미해결 명단을 보존한다.
- 재실행 시 동일 영수증과 캠페인으로 기존 지급을 검증한다. 누락 계정 추가는 기존 70명을 그대로 유지하고 신규 계정만 추가한다.
- 작업 범위는 일회성 운영 데이터와 지급 도구·기록이다. 게임 실행 코드 및 운영 배포 변경은 없다. 검증 범위는 스크립트 구문 확인과 실제 저장 결과 확인으로 한정했다.
