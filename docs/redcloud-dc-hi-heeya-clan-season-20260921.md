# 레드클라우드 DC 하이희야 시즌 기간제 지급

2026-09-21 사용자 지시: `레드클라우드` 계정에 `DC_HI_HEEYA` 아바타를 현재 활성 클랜 시즌의 남은 기간 동안 지급한다.

- 고정 일수를 사용하지 않고 지급 트랜잭션 직전에 유일한 `ACTIVE` 클랜 시즌의 `ends_at`을 읽는다.
- 보유권 `expires_at`은 해당 시즌의 `ends_at`과 정확히 같다.
- 활성 계정·활성 공개 아바타·활성 OWNER·유일한 활성 시즌을 모두 재검증한다.
- 기존 영구 보유권은 기간제로 낮추지 않고, 더 긴 기존 기간제도 줄이지 않는다.
- 지급·감사 로그·완료 영수증은 한 트랜잭션으로 처리하며 동일 작업은 재실행하지 않는다.
- 계정 재화, 클랜 소속, 아바타 장착 상태는 변경하지 않는다.
