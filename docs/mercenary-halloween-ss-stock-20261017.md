# 할로윈 SS 발행 한도 5장 추가

사용자 요청: `할로윈 리미티드 SS 등급들 5장씩 한도 더 늘려`.

- V-980 나무늘봉순, V-981 조은, V-982 하이희야, V-983 오리꿍, V-984 디임, V-985 아윤, V-986 남수댕: 각각 5장 → 10장, 총 35장 추가.
- 기존 발행 수량과 일련번호, 보유분을 보존한다. 이 작업은 카드 지급이 아니다.
- 진무 팩 한도 3장과 헬리오스 공용 한도, 모든 가격·확률·판매 상태를 보존한다.
- 새 기본값과 저장 검증은 SS 10장이다. 전환 중 기존 V3 5장 문서는 읽기만 허용하며, 실제 카운터는 해당 저장 문서와 일치해야 한다. 이전 화면의 저장은 설정 버전 검사로 보호된다.
- 상점·계약실·CMS의 한도와 잔여 수량은 서버 데이터로 표시한다. 원화와 전투 리소스는 변경하지 않는다.

운영 절차는 호환 코드 배포 후 `scripts/ops/halloween-ss-stock-plus5-20261017.mjs`의 `increaseHalloweenSsStock`을 dry run, 실제 적용 순으로 호출한다. 설정과 7개 발행 카운터를 잠그고 하나의 거래로 변경하며 감사 기록과 `ops:halloween-ss-stock:20261017:plus5-v1` 영수증을 함께 저장한다. 재호출은 추가 증가 없이 기존 영수증을 반환한다.

관련 검사는 SS 한도 전환·6~10번 발행·초과 차단·감사 실패 롤백·중복 적용 방지, 기존 할로윈 개봉 회귀, PC 1440 / 모바일 390의 상점·계약실·CMS 표시로 제한한다. `QA_STOCK_ONLY=1`을 사용하고 실제 구매·지급은 발생시키지 않는다. 운영 적용 결과는 후속 기록에 남긴다.
