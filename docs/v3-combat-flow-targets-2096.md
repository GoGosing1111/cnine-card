# V2096 전투 흐름·실제 타격 대상 수정

2026-09-13 사용자 요청: 전투 정지감, 남아 있는 스킬 잔상, 몬스터가 없는 위치로 나가는 스킬을 수정한다.

## 확인한 원인과 수정

- V2095의 연속 전투는 카드 동작·KO·증원을 기다릴 때 스킬 시간축도 정지했다. 실제 무한의탑 녹화에서 폭발이 약 1.6초 동안 같은 상태로 멈췄다. 대기 중에는 다음 서버 이벤트의 실행만 보류하고, 이미 발생한 폭발과 연기는 공통 GSAP 시간에 따라 계속 소멸한다. 사용자 일시정지와 QTE는 별도로 같은 시간축을 정지한다.
- 시전 이후 몬스터가 먼저 죽으면 서버는 해당 칩의 타격 이벤트를 만들지 않는다. 이제 실제 `castId`별 `SKILL_CHIP_HIT`가 있는 시전만 표현한다. 헬기폭격도 서버가 취소한 후속 폭발을 그리지 않는다.
- 타격이 끝난 효과가 재사용되는 몬스터 액터를 따라가던 문제를 수정했다. 투사체는 정확한 서버 인스턴스를 사용하고, 폭발은 명중 순간의 월드 좌표를 보존한다. 교체된 몬스터나 빈 슬롯으로 대상을 바꾸지 않는다. 일반 공격·전술 스킬·용병 스킬·배틀슈트 탄환의 대상 확인도 함께 보강했다.
- 사격 대기열에 마지막 탄환을 넣는 순간 그 탄환의 HP 0을 미리 기록하던 문제를 수정했다. 배틀슈트 HP 스냅샷은 실제 탄착 때 반영한다. 처치 공격 전에 이전 탄환을 처리해, 죽은 몬스터에 남은 탄환이 계속 날아가는 상황을 막는다.
- 연속 전투의 실제 충돌이 준비된 뒤 투사체를 발사한다. 지연된 타격을 기다리는 동안 미사일이 먼저 사라지는 공백을 없애고 준비·비행·충돌을 연속 재생한다. 동시에 시전된 두 칩은 같은 발사 시점을 사용한다.
- KO 전의 불필요한 정지 구간을 제거했다. 증원은 등장한 뒤 전투에 참여하고, 남은 먼지·등장 동작은 소유한 타임라인에서 정리한다. 일반 몬스터 교체가 보스 배너의 표시 완료까지 기다리지 않는다.
- 처음 진입할 때 자산 로딩이 늦어 초기화가 재시도되면, 이전 초기화의 뒤늦은 실패가 새 렌더러까지 파괴하는 경합도 확인했다. 비동기 마운트에 인스턴스 확인을 추가하고 실패한 인스턴스만 정리한다. 선택적 음원 디코드는 첫 화면 준비를 막지 않는다.

## 구현과 자산

- PixiJS **8.20.0**, GSAP **3.13.0** 유지. 새 렌더러·라이브러리·이미지·사운드는 추가하지 않았다.
- 시간축: `preview/project-v-v3/source/battle/BattleSuitSkillChipPlayback.js`.
- 일반/배틀슈트 대상과 탄착: 같은 디렉터리의 `BattleEngine.js`; 용병 대상은 `MercenaryCombatPlayback.js`.
- 연속 몬스터 교체: `preview/scrapyard-v3-v1/source/ScrapyardBattleEngine.js`. 폐차장·무한의탑·카우방이 동일한 공용 계열을 사용한다.
- 실제 Pixi 프레임: `preview/battle-suit-skill-chip-v1/source/SkillChipFX.js`. 기존 6×4 폭발 아틀라스의 24프레임, 로켓·헬기·파편·연기 자산과 지면 앵커를 보존했다.
- 음원: 같은 디렉터리의 `SkillChipAudio.js`. 기존 CC0 원음을 사용하며 출력 지연을 고려해 충돌을 예약한다. 재개·배속 변경 때 남은 음원을 동기화하고 취소·완료 때 정리한다.
- 런타임 연결: `js/battle-v3-live.js`, `js/pve-continuous-battle-live.mjs`, `js/cow-room-live.mjs`.
- 공통 빌드: `npm run build:v3-grid`의 기존 9개 소비자. 캐시 `2096-combat-flow`, 번들 `106-combat-flow`, 브리지 `3.36.0-combat-flow`.

## 검증 범위

- 서버가 실제 생성한 폐차장 134개·무한의탑 330개 이벤트를 기존 운영 UI에서 재생한다. 프리뷰 페이지를 운영 진입 화면으로 사용하지 않는다.
- 전투 중 프레임, 효과 수명, 타격 순간의 인스턴스 ID·HP·가시성·좌표, 전체 이벤트 순서를 수집한다. 단순히 결과 창이 열리는 것으로 잔상 검증을 대체하지 않는다.
- 회귀 테스트에 시전 취소, 헬기 후속 타격 취소, 대기 중 효과 소멸, 재사용된 액터와 충돌 좌표 분리, 미래 탄환의 HP 조기 적용 방지, 지연 후 미사일 비행과 충돌, 일시정지·취소를 추가했다.
- 실제 브라우저 검수는 데스크톱 1440×1080, 모바일 390×844에서 수행한다. 사운드 ON 상태의 일시정지 중 결과 보기·재입장, 무장 없는 편성, 저격총 편성도 확인한다.
- 로컬 원본 보고서·녹화: 작업 후보 상위 `qa/combat-2095/`의 `candidate-2096-*`, `lifecycle-2096-*`, `2096-nosuit-debug-*`, `2096-sniper-*`. 실제 음향 장치의 물리적 지연을 측정한 결과로 확대 해석하지 않는다.

기존 입장·결과 UI, 카드 원화·SD, 서버 피해·승패·보상, CMS 수치와 공개 설정은 이 수정의 변경 대상이 아니다. 운영은 깨끗한 커밋 후보에서 `npm run deploy:production` 내부의 전체 `release:gate`를 통과한 뒤 반영한다.
