# 용병 성장 규칙 준비 — 2026-10-14

사용자 지시: 리미티드는 일반 용병보다 경험치를 5배 더 요구하고, 높은 레벨의 일반 SSS는 리미티드 SSS도 이길 수 있어야 한다. 후속으로 **준비만**, 동일 용병 재료 **3배**, 같은 등급의 다른 용병 재료 **기본 경험치**를 확정했다.

## 확정한 계산

| 항목 | 준비 규칙 |
|---|---|
| 일반 용병의 레벨/돌파 요구량 | CMS의 레벨별 기본 요구 경험치 |
| 리미티드의 레벨/돌파 요구량 | 같은 레벨의 기본 요구 경험치 × 5 |
| 크라이베른 → 크라이베른 재료 | SSS 기본 재료 경험치 × 3 |
| 다른 SSS → 크라이베른 재료 | SSS 기본 재료 경험치 × 1 |
| 발테르 → 발테르 재료 | SSS 기본 재료 경험치 × 3, 요구량은 여전히 일반의 5배 |
| 다른 SSS → 발테르 재료 | SSS 기본 재료 경험치 × 1, 요구량은 일반의 5배 |

5배는 대상의 요구량이며 획득 경험치를 줄이는 방식이 아니다. 동일 카드 3배와 별도로 계산한다. 같은 등급만 재료로 사용하고 중복분만 소모하며 기본 1장 보호를 유지한다. 일반 레벨의 이월, 5/10/15/20 돌파, 실패 시 현재 레벨 경험치 0, 돌파 초과분 명시 동의도 그대로다.

`MERCENARY_LEVEL_RULES`에 두 배수를 고정했다. 동일 카드 배수를 임의 변경하는 CMS 입력은 제거했다. 레벨별 CMS는 일반 용병 요구량을 관리하고 리미티드 값을 서버와 UI가 공통 함수로 계산한다. 실제 요구량 5배가 기존 1조 XP 저장 범위를 넘지 않도록 기본 입력 상한은 2천억이다. 새 테이블·스키마 변경은 없다.

## 준비 경로 보완

- 리미티드 판정은 서버의 정식 용병 코드 목록을 사용한다. 클라이언트가 `edition`을 바꿔 요구량을 회피하거나 다른 계정의 전용 용병을 성장시킬 수 없다.
- 기존 준비 경로는 일반 CMS 목록만 읽어 발테르 등 리미티드를 성장 대상으로 인식하지 못했다. 정식 출시된 리미티드의 등급·이름·원화·계정 제한을 연결하고 성장실 표시, 재료 검증, 서버 계획과 계정 성장 표시를 준비했다.
- 20261005 버전의 **OFF 초안**은 읽을 때만 새 버전과 동일 카드 3배로 해석한다. 미정값과 수정 버전, 원래 저장 문자열을 보존한다. 읽기로 CMS·유저 데이터를 변경하지 않으며 OFF가 아닌 구버전을 임의 전환하지 않는다.
- 미정 설정은 기존 35개에서 동일 카드 배수 1개가 확정되어 **34개**다. XP 기본값·확률·성장 효과는 null이다.
- 성장실 검수에 크라이베른·베르칸·발테르를 추가했다. 3배 재료 표시, 리미티드 5배 요구량, 예상 경험치·진척·돌파 준비 수치를 함께 확인할 수 있다. 나머지 예시 숫자는 운영과 분리한다.

## 높은 레벨 일반 SSS의 역전 준비

기존 단일 체력/공격 증가만으로는 리미티드의 행동 속도·연속 공격과 피해 제한을 넘기 어려웠다. 준비용 돌파 효과에 **행동 속도**, **체력·공격·방어·속도 동시 증가**를 추가했다. 실제 스탯과 카드 전력 연계 후의 공격/체력에도 적용하며 부상 비율을 유지하고 한 번만 반영한다. 과거 성장 정보 없는 스냅샷, 기존 돌파 효과, 일반 카드, 용병 기본 등급 전력과 리미티드 스킬/행동 규칙은 변경하지 않는다.

실제 전투 엔진으로 아래 검수용 프로필을 비교했다. **운영에 채택한 성장 수치나 실제 유저 승률이 아니다.** 수치 확정과 전체 용병 조합의 출시 밸런스 검수는 별도로 남는다.

- 검수용 돌파 효과: 네 구간 각각 `COMBAT_STATS_PERCENT=500`. 기본 재료 XP 100 / 단계 XP 1,000 / 돌파 확률 50%도 독립 검수값이다. 실제 기본 정책은 null/OFF로 유지한다.
- 같은 카드 5장과 장비 조건, 공격/방어 진영 교대, 난수 12개, 카드 전력 두 구간·균형/방어 편성으로 각 비교 96전.
- 크라이베른 Lv.1 vs 발테르/헬리오스 Lv.1: 각각 0/96승. Lv.11 vs Lv.1: 발테르 19/96승, 헬리오스 8/96승. Lv.20 vs Lv.1: 각각 **95/96승**. 양쪽 모두 Lv.20: 각각 0/96승.
- 이는 레벨 격차로 역전이 가능한 계산 경로를 확인한 것이다. 동레벨 우위, 특정 승률, 모든 SSS/상성의 승리 또는 출시 수치를 확정하지 않는다. 승자를 강제로 바꾸는 코드는 없다.
- 재현: `node scripts/measure-mercenary-level-catchup-20261014.mjs <출력 파일>`. 기록: `mercenary-level-rules-20261014-measurements.json`.
