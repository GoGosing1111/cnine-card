# 진무·족로 상향 및 시라누이 전투력 동기화 — 2026-10-18

사용자 요청: 천룡검황 진무를 카이론보다 상위로 올리고 족로도 상향한다. 후속 요청으로 시라누이 전투력도 상향된 진무와 동일하게 맞춘다.

진무·시라누이의 기본/연계 공격력·체력·전체 시작 방벽·기본 피해 상한을 카이론보다 20% 높인다. 족로도 기존보다 20% 높여 상향된 진무보다 20% 우위를 유지한다. 족로 표기 전투력은 정수 반올림이며 실제 능력치는 1.728 배율을 사용한다. 전열 공통 시작 방벽 60%를 포함한 전체 방벽을 비교한다.

기존 카이론은 진무 수치표를 공유했으므로 기존 값으로 독립 고정한다. 시라누이는 사용자 후속 요청에 따라 상향된 진무 수치표를 공유하고 고유 사격 방식과 560% 광역 피해 예산을 유지한다. 서버 전투 생성에서 저장 스냅샷보다 현재 정책을 우선하므로 기존 보유자도 다음 전투부터 적용된다.

공격속도·행동 크레딧 3.12, 진무/시라누이 모션 2.6배 및 족로 발도 2배·FX 1배는 유지한다. 개인 피해 경감은 진무/시라누이/카이론 75%, 족로 80% 그대로다. 스킬 비용 35·재사용 5행동·PVP 광역 제외, 면역과 성장·원화·획득·현재 발행량은 변경하지 않는다.

## 검증

- 진무·족로·카이론 관련 3개 기존 테스트 파일 16개 통과. PVE/PVP, 장비 0/1억, 일반 카드 연계, 전체 방벽, 행동 횟수와 단일 적용 피해 예산을 확인했다. 카이론 수치 전체를 기존 값으로 고정하는 회귀를 포함한다.
- 실제 서버 계산 고정 조건 비교: [measure.mjs](qa/jinmu-jokro-buff-20261018/measure.mjs), [comparison.json](qa/jinmu-jokro-buff-20261018/comparison.json). 동일 카드·16종 시드·양쪽 진영·두 전투력 구간 128회에서 진무 대 카이론 60/64승, 족로 대 진무 64/64승. 운영 이용자의 승률이나 모든 조합의 승리를 보장하는 수치가 아니다.
- 같은 PVE 표본의 첫 광역 피해: 카이론 467,380,403, 진무 673,027,781, 족로 1,817,175,006. 공격력과 스킬 배율이 각각 증가하므로 실제 스킬 피해 증가폭은 단순 20%와 다르다.
- 시라누이는 진무와 PVE/PVP 능력치·연계·장비·방벽·피해 경감·행동 속도 동등성을 검사한다. PVP 전체 피해/행동 타임라인 및 PVE 기존 560% 예산도 비교한다.
- 공통 V3 및 디펜스 소비 번들을 재생성하고 메인 앱·래퍼·번들 캐시 키를 갱신한다. UI 구성과 원화는 변경하지 않는다.
