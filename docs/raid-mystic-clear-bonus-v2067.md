# 기존 월드 레이드 격파 추가 보상 — V2067

2026-09-08 사용자 지시: **기존 보상을 대체하지 않고 미스틱 에너지 3개를 추가 지급**한다. 신규 코어 프로토콜 레이드는 변경하지 않는다.

- 기존 월드 레이드 격파 보상 대상자에게 인당 미스틱 에너지 3개를 추가한다. 참여·피해량·순위·희귀 드롭·장비 등 기존 보상과 확률은 유지한다. 격파 실패 시 추가 에너지는 없다.
- 실제 아이템 코드는 `STARLIGHT_ARMOR_CORE`이며, 기존 재료 인벤토리에 합산한다. 새 재화나 다른 이름의 아이템을 만들지 않는다.
- 설정 키는 `raid_settings_v1`의 `clearMysticEnergy`다. 저장값이 없으면 기본 3개, CMS에서 0~1,000,000개의 정수로 변경할 수 있다. 0은 추가 지급 중지다.
- CMS 경로: **레이드 → 다중 레이드 보상 풀 → 보스 처치 보상 → 미스틱 에너지 추가 지급 → 추가 수량 → 레이드 전체 설정 저장**.
- 기존 CMS 보상 배열을 덮어쓰지 않는다. 별도 입력칸으로 기존 코인·아이템 보상에 더할 수량만 저장한다.
- 배포 이후 새로 생성하는 기존 레이드 방부터 설정을 스냅샷으로 고정한다. 이미 생성된 방의 구형 스냅샷에 이 필드가 없으면 0으로 보존하며, 기존 보상 계획·완료 영수증을 소급 변경하거나 재지급하지 않는다.
- 추가 재료는 기존 개인별 보상 계획, 중복 수령 방지 영수증, 보상 트랜잭션과 `RAID_V1293_REWARD` 인벤토리 감사 로그를 사용한다. 결과 화면과 수령 안내는 서버가 반환한 품목명·수량을 표시한다.
- 검증: `node --test tests/raid-mystic-clear-bonus-v2067.test.mjs`, `npm run test:raid-entry`, 운영 배포 전 `npm run release:gate`.
