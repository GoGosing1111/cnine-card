# 영토전 순위 균형 편성 / 58회차 재시작

사용자 후속 지시: 현재 클랜 순위를 보고 1·2위를 갈라 균형을 맞추고, 휴전한 이번 회차를 재편성하여 다시 시작한다.

- 현재 클랜 순위표의 단일 SQL 계약을 재사용한다. 1위 DK / 2위 FM 분리, 공식 8개 클랜 4대4 유지. 클랜원 개별 분할과 클랜 가입 정보 수정은 하지 않는다.
- 서양: DK·DC·롯데·LG / 동양: FM·T1·한화·삼성. 승점 합 24:24, 순위 합 18:18.
- 58회 개막 고정 로스터 156명과 무소속 18명을 그대로 유지하며 기존 개인 전력·5회 참여 이력 기준으로 87:87 편성한다.
- 2026-09-23 23:37 KST 운영 트랜잭션 모의 적용 후 롤백 확인. 전력 133,602,709:132,572,223, 차이는 평균 대비 약 0.77%. 새 중앙 전선은 작업 중 CMS에서 변경된 현재 기본 HP **5,000,000**을 사용한다. CMS 자체를 덮어쓰지 않는다.
- 현재 58회를 유지하고 이전 중앙 전선 466은 CANCELLED 이력으로 보존한다. 취소 전선은 이후 재방문 피로에 포함하지 않는다. 새 중앙 전선 양측 HP 회복, 행동력 15, 작전 상태 초기화, 현재 CMS 준비 3분 / 전투 1,200분을 적용한다.
- 개인 공격·방어·기여 기록, 기존 교전 1,366건, 지급 코인·아이템은 보존한다. 승패 정산 또는 보상 재지급을 호출하지 않는다.
- 전투 진행 중/휴전 종료/다른 회차/순위·정책 변경/부분 반영을 차단한다. 짧은 단일 트랜잭션 및 회차 행 잠금, 재시도 영수증, 원본 스냅샷과 관리자 감사 로그를 사용한다.
