- 군단토벌도 3시간마다 1회 충전. 추가 답변 `현재 군단토벌 입장 한도만큼 저장`에 따라 최대 10회, 후원 적용 중 13회.

## 정책·저장

- 두 콘텐츠는 별도 잔액이다. 각 콘텐츠 내 지역·난이도는 잔액을 공유한다. 자정 초기화가 없고 오프라인 경과 시간도 충전한다. 최대치에서는 충전 시간을 적립하지 않는다.
- 첫 조회/출전 시 기존 당일 사용량을 제외한 잔액으로 한 번만 전환하고 충전을 시작한다. 초기화나 전체 계정 일괄 지급을 하지 않는다.
- 격전지: 대기방 생성·참가·개별 준비는 무료. 3명 모두 준비하여 전장 로딩을 시작할 때 각 1회 사용한다. 패배·이탈도 소모하며 TEST는 소모하지 않는다. 참가자 한 명이라도 부족하면 세 명 모두 차감하지 않고 준비를 해제한다. 승리 보상·선택 보상에는 별도 하루 3회 제한이 없다.
- 격전지의 방 출전 의도를 DO에 먼저 저장하고 PostgreSQL에서 세 잔액과 출전 영수증을 함께 커밋한다. 응답 유실/재시작 시 영수증을 다시 사용한다. 잔액 CAS에는 매 거래 고유 토큰을 사용한다. 이전에 이미 출전한 구버전 방은 보상을 한 번 정산하며 소급 차감하지 않는다.
- 군단토벌: 실제 begin에서 1회 사용하며 방 준비/잘못된 덱/같은 begin 재시도는 추가 사용하지 않는다. 원정 기록과 행동력을 같은 CAS로 저장한다. 코인 미수급 중단은 기존처럼 한 번 복구하며 이미 지급한 코인이나 종료 영수증은 취소하지 않는다.
- OWNER의 기존 군단토벌 입장 무제한은 유지한다. 코인을 받는 원정은 같은 최대 10/13회·3시간 충전 잔액을 사용하고 잔액이 없으면 코인이 지급되지 않는다.
- 기존 OFF/TEST/ON·전투 성능·판당 코인 상한·지역 드랍률·전리품 정산·후원 기간은 유지한다. 신규 DB 스키마/전역 권한 변경 없음.
- 격전지 `coop_energy_v1:<user>`와 `coop_entry_energy_v1:<room>`, 군단토벌 기존 `legion_hunt_owner_session_v1:<user>`의 `energy`를 사용한다. 구 일일 기록은 전환 근거로 보존한다. CMS 문서의 구 dailyLimit 필드는 호환 목적으로만 남으며 신규 일일 제한을 적용하지 않는다.
