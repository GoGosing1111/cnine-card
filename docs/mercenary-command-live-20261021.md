# 용병도감 · 편성 UI 운영 반영

사용자 `구성자체는 괜찮은거같아`에 이어 폰트·남색 패널을 수정한 `mercenary-command-typography` 시안을 `라이브에 반영해`로 승인했다. 초록 버튼은 사용자 첨부 원본 그대로 보존한다.

## 화면과 조작

- Pretendard Variable 1.3.9와 승인된 무광 남색/은색 코너 패널을 실제 도감에 적용한다. 원본·WebP·프롬프트·해시는 `assets/ui/mercenary-codex/command-20261021/manifest.json`에 보존한다. 패널 48/16px, 초록 버튼 38/9px의 9-slice로 모서리 비율을 유지하며 모든 문구·수치는 DOM이다.
- 상단에서 PVE/PVP 출전 용병과 미편성 상태를 동시에 확인한다. 선택 상세에는 PVE/PVP 두 개의 직접 편성 버튼과 변경 전후 이름을 표시한다. 기존 소유권·등급·편성 제한과 서버 모드별 revision을 따른다.
- 양쪽에 같은 용병을 지정할 수 있다. 편성 완료와 목록 선택 상태를 구분하고 해제도 모드별로 제공한다. 기존 영수증 requestId와 계정별 pending 저장 계약을 유지해 유실 응답을 동일 요청으로 복구한다. 다른 화면에서 편성이 변경된 409 충돌은 최신 상태를 다시 읽는다.
- PC는 이미지 목록/상세를 나란히, 모바일은 선택 상세를 native dialog로 연다. 닫기·Escape·초점 복귀·키보드·동작 줄이기를 지원한다. 소유 상태·검색·등급은 기본 화면, 포지션·정렬·즐겨찾기는 펼치기로 유지한다.
- 원화/전투 SD/원본 확대와 전체 스킬 상세, 성장·장비·합성·SSS 재뽑기 링크를 보존한다. 승인 원화와 전투 수치, 발행 수량, 확률, 출시 상태는 수정하지 않는다.
- 사용자 후속 `사이드메뉴에서 빼 이미 카드 용병 펫에 있음`에 따라 독립 `용병 · 편성` 사이드 항목은 제거한다. 기존 `카드·용병·펫` 안의 용병 진입, 모바일 전체 메뉴, 전투 준비 화면의 모드별 용병 링크를 유지한다.

- 기존 `mercenary-codex-owned-roster-v2133`, `mercenary-codex-public-v2061`, `mercenary-codex-jokro-20261021` 회귀를 함께 선택한다. 기존 테스트의 UI 문구·CSS 링크와 직접 모드 인자를 새 계약에 맞췄다.

- 실제 브라우저에서 폰트 로딩, PC/모바일 이미지 패널·버튼·문구·원화 비율을 확인한다. 검수 보고서와 화면은 `docs/qa/mercenary-command-20261021/`에 보존한다.

## 배포 범위

용병도감 클라이언트와 공통 메뉴의 용병 직접 진입만 변경하는 scoped 배포다. 서버/DB/경제 변경 없음. 배포 직전 실제 Pages 운영 SHA를 조회하고 그 기준으로 `npm run deploy:production -- --scoped`를 실행한다. 배포 후 운영 HTML/CSS/JS/이미지 해시와 공개 도감 GET을 확인한다.

- `prompts.json`의 색인 해시는 생성 당시 UTF-8/LF 원본 기준이다. Windows 체크아웃의 CRLF는 LF로 정규화해 검증하며, PNG/WebP는 정규화 없는 바이트 해시다.
