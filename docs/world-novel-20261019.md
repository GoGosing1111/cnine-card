# 세계관 소설화와 읽기 UI 정리 · 2026-10-19

사용자 요청: 세계관을 실제 소설처럼 다듬고 용병 사이의 사건·대화·관계를 쌓을 것. 후속 요청: 과하고 어울리지 않는 UI 버튼을 깔끔하게 정리할 것.

## 이야기

- 현재 공개본 33장면을 바탕으로 1부 6장·30장면, 2부 5장·23장면, 용병 이야기 7편·21장면으로 다시 집필했다. 합계 18장·74장면, 실제 카탈로그의 용병 23명이 등장한다. 원래 33개 장면 ID는 모두 유지한다.
- 1부는 의뢰인 한서하·한서진 남매의 구출과 귀환을 한 사건으로 마무리한다. 리시아·아우렌·베스페라·라비에나는 과거 서부 회랑 철수 판단을 서로 다른 위치에서 겪었다. 다나의 현재 행방은 미확인으로 남으며 후속 원정의 동기가 된다. 누나와 동생의 이름, 다나·이도윤과 과거 사건은 이번에 집필한 허구의 설정이다.
- 2부는 기존 월드 레이드(오르제·렌조·제노) → 이스겐의 왕좌 → 바르센의 전장 → 세드릭의 코어 연결을 보존한다. 남매 사건 이후 다나와 남은 승객을 찾는 연속 원정으로 인과를 정리했다. 베르칸·아잔트의 조사 속도와 귀환 안전의 충돌, 크라이베른의 구출 판단, 강윤과의 사격 순서, 발테르·헬리오스의 역할 분담을 대화와 행동으로 보여 준다.
- 외전 7편은 리시아/아우렌, 베스페라/라비에나, 사요/서윤, 레니아/케일, 미레시아/아스텔, 에이라/루카스, 경찰 조은/동탄 디임이다. 각 편은 세 장면에 걸쳐 마찰 → 선택 → 달라진 다음 행동으로 이어진다. 호감 수치나 일회성 명언으로 관계의 해결을 대신하지 않는다.
- 서사 등장과 실제 용병 소유·스킬 배정·편성·획득·전투·레이드 보상은 별개다. 게임 데이터/API/경제 설정을 변경하지 않았다. 승인 원화를 재생성하거나 덮어쓰지 않았다.

## 읽기 화면

두꺼운 금속 프레임·배지·장 카드 박스를 제거했다. 본편 1부/2부/용병 이야기를 작은 텍스트 선택으로 구분하고 목록은 간격과 선으로 정리했다. 이전/다음과 읽기 버튼은 얇고 낮은 대비의 전용 이미지 소재를 사용한다. 본문은 조용한 종이 소재, 여백, 한글 명조로 읽고 화자는 대사 옆 DOM 텍스트로 명확하게 표시한다. 여러 인물의 기존 원화도 함께 표시한다.

ImageGen 내장 도구로 숙소·보관소 배경과 절제된 버튼·본문 소재 4개를 생성했다. 원본·실제 프롬프트·해시·런타임 경로는 `assets/ui/reverse-call/world-story-v3/manifest.json` 및 `docs/qa/world-novel-20261019/art/`에 보존했다. 기존 v1/v2 승인 원본과 자산은 보존한다. 기술·직접 화면 검수는 사용자 시각 승인과 구분한다.

기존 저장 키와 장면 주소를 유지한다. 이전 완독자는 새로 생긴 `empty-chair`부터 읽을 수 있고, 부분 저장은 같은 장면 ID로 복구한다. 완독은 본편 각 부와 외전 각각 독립적으로 저장하며 외전 끝에서 다른 편으로 자동 넘어가지 않는다. 저장소가 차단돼도 읽기는 계속된다.

## 구현과 검수

저작 원본은 `docs/qa/world-novel-20261019/source/`, 빌드는 같은 폴더 상위의 `build.mjs`다. 운영에는 CSS를 포함한 `world/index.html`, 데이터와 읽기 코드를 묶은 `world/world.js`를 제공한다. 이전 `world/expansion.js`는 이전 공개본의 참조·원본 자산 검수 호환용으로 보존하며 새 화면은 번들 데이터만 소비한다. 공통 사이드 메뉴의 모습은 유지하고 소개 문구만 새 편수로 갱신한다. 독립 페이지는 새로운 모듈 URL을 사용하고 기존 서비스워커의 문서/메뉴 네트워크 우선 경로를 유지한다.

- PC 1440×960, 모바일 390×844·320×740: 표지, 대화/인물, 장 목록, 외전 끝, 레이드 장면을 캡처해 직접 확인했다. 글자·장식·버튼의 가로 넘침이 없다.
- 시작/이전/다음/방향키, 장 선택, 외전 종료 경계, 해시 이동, 새로고침·이어 읽기, 터치 스와이프, 동작 줄이기, 저장소 차단을 검사했다. 최종 페이지 오류 0개다.
- 관련 데이터·기존 확장 호환 검사 7개 통과. 새로운 원본·파생 해시, 모든 장 연결, 화자·원화 경로, 이전 읽기 기록 호환과 독립 완독을 확인했다.
- 로컬 서버의 `.mjs` MIME 누락으로 관측된 공통 메뉴 모듈 로딩 오류는 검수 서버 설정을 고친 뒤 해소됐다. 운영 코드를 우회하거나 관련 없는 도시 기능을 변경하지 않았다.
- 증거: `docs/qa/world-novel-20261019/screens/`. 최종 운영 배포는 아래에 별도 기록한다.

작은 정적 콘텐츠·UI 수정으로 scoped 배포한다. 관련 이야기 검사, 기존 세계관 진입 회귀와 로비 소스 일치만 선택하며 공통 게임 전체 검사는 반복하지 않는다.
