# S 청아의 상위 등급 PVP 체급 보정 · 2026-09-18

사용자 후속 지시: “SS는 못이기게 해야지 체급은 넘어가면 안돼.” 이전 70% 스킬 하향으로 SS 경찰 조은과 대등해진 결과를 추가 조정한다. 이 문서가 `mercenary-cheonga-pvp-nerf-20260918.md`의 후속 적용 기준이다.

## 적용 규칙

- 대상은 PVP의 S 청아(V-005), 실제 원거리 공격, 탄착 교정(MS-005 / SAME_TARGET_CALIBRATION) 장착이다.
- 전투 시작 시 상대 편성에 생존한 SS 또는 SSS 용병이 있으면, 청아의 기본 공격과 탄착 교정 피해량·타격별 피해 상한에 **추가 50%**를 적용한다. 이 조건은 전투 시작에 고정하며 상대 용병의 사망·표적 변경으로 해제하지 않는다.
- 상위 용병 편성 상대 최종 계수는 **기본 공격 50%, 탄착 교정 35%**다. 탄착 교정은 앞서 적용한 70%에 50%를 한 번 더 곱한다. 현재 CMS 배율 4.2 기준 각 탄은 `0.98 / 0.98 / 1.372 → 0.49 / 0.49 / 0.686`이다.
- 일반적인 PVP 타격 상한은 기본 공격에서 대상 기준 체력의 60% → 30%, 탄착 교정에서 42% → 21%가 된다. 용병 대상 상한의 기준 체력에는 기존 규칙대로 개시 방벽이 포함된다. 방어·회피·보호·현재 잔여 체력도 적용된다.
- 상대 용병이 없거나 C/B/A/S이면 기존 전투와 동일하다. PVE, 다른 용병, 청아의 다른 등급·무기·배정은 이 체급 보정 대상이 아니다.
- 3행동에 걸친 연사, 즉시 초탄, 빗나감 후 후속탄, 표적 재지정, 마지막 탄 보너스, 비용 25, 재사용 대기 5행동, 고정 전투력·HP·방벽·공격 간격은 유지한다.
- CMS revision 55의 원본 수치·등급·배정 및 사용자 계정에는 쓰기를 하지 않는다. 운영 도감·보유 용병·CMS의 스킬 설명은 같은 정책 모듈에서 위 규칙을 표시한다.

## 선택 근거

피해를 상대 등급과 무관하게 낮추는 후보도 비교했다. 탄착 교정을 45%로 낮춘 경우 청아는 A 카르시아와 약 50%가 되었지만, 일부 고전력 공격 덱에서는 SS 경찰 조은과 여전히 비슷했다. 기본 공격까지 일괄 하향해도 A와의 격차가 먼저 소진됐다. 스킬만 계속 줄이면 기본 공격만 사용하는 것보다 나빠지는 문제도 있었다.

따라서 이번 사용자의 체급 지시를 명시적인 상위 용병 편성 규칙으로 적용했다. S·A 상대의 이미 검증한 성능은 유지하면서 SS·SSS 상대의 기본 공격과 스킬 예산을 함께 줄인다. 승자·난수·팀 전투력을 직접 바꾸는 처리는 없다.

## 실전 엔진 비교

기준 커밋 `5e191b6a391558b5cd9cfea70960e6c141f6a523`, CMS revision 55. 양측 일반 카드 5장과 별도 용병 1장으로 서버 PVP 함수를 실행했다. 일반 카드당 전력 10만·100만·2,000만, 혼합·공격·방어·속도 덱, 공격/방어 양쪽을 비교했다. 표의 수치는 **청아 팀의 시뮬레이션 승률**이며 실제 유저 전적이 아니다.

## 검증·출시

- 대상 외 용병 PVP 8,256개, 전체 용병 일반/아포칼립스 PVE 8,448개, 별도 하위·동급 상대 표본 6,528개는 이전 버전과 전체 반환값이 일치했다.
- `tests/mercenary-ranged-balance.test.mjs`의 기존 출시 게이트 연결을 유지한다. SS별 팀 성능 상한을 55% → 25%로 강화하고 모든 전력·덱 그룹은 45% 미만으로 검사한다. 단독 대결은 SS의 승리를 검사한다.
- 회귀 검사에는 양쪽 진영, SS/SSS, 3연사와 기본 공격의 실제 피해 상한, 명중 실패, 상대 사망 후 고정 보정, 다른 스킬·등급·무기·PVE 제외, 버프/약화와의 한 번만 곱셈, 비용·재사용 대기 보존을 포함한다.
- PC 1440×1000 / 모바일 390×844에서 실제 메인 앱의 PVE/PVP 입장 → MS-005 재생 → 결과 → 복귀를 격리 계정 API로 확인했다. 도감과 CMS에서 최종 50%/35% 규칙, 가로 넘침과 브라우저 오류도 확인했다. 운영 계정 재화는 사용하지 않았다.
- 서버 계산과 조회 설명만 변경한다. Pixi 연출·GSAP 타임라인·메인 전투 로더·번들은 변경하지 않는다. CMS 모듈 캐시 키와 정책 버전은 `20260918-cheonga-tier-v2`로 갱신한다.
- 범위 커밋 후 `npm run deploy:production`으로 전체 `release:gate`를 통과하고 배포한다. 배포 후 운영 정적 파일·도감 응답·격리 계정의 운영 자산 전투 경로를 확인한다.
- 롤백은 이 범위 커밋을 되돌려 같은 게이트와 배포 명령을 사용한다. DB 롤백은 없다.

## 유저 공지 문안

S등급 청아가 상위 용병의 체급을 넘지 않도록 PVP 보정을 추가했습니다. 탄착 교정 장착 상태에서 SS·SSS 용병이 편성된 상대와 싸우면 기본 공격과 탄착 교정의 피해량·피해 상한이 추가로 50% 감소합니다. 최종 적용치는 기본 공격 50%, 탄착 교정 35%이며 전투 시작 편성을 기준으로 종료까지 유지됩니다. 동급 이하 상대와 PVE 성능, 연사 방식, 소모 자원과 재사용 대기는 유지됩니다.
