## 지역별 특성과 전리품

| 지역 | 보스 패턴 | 세트 / 고유 장비 |
|---|---|---|
| 검은 돛의 해안 | 호위와 본체 협공, 호위 처치 시 취약 | 난파왕 / 흑조의 작살총 |
| 유리 사막 | 갑각 폐쇄·개방, 개방 중 피해 증가 | 유리 사냥꾼 / 태양송곳 |
| 끝나지 않는 대극장 | 막 전환에 따라 다중 공격 강화 | 마리오네트 / 단장의 가면 |
| 거수의 뱃속 | 기생체가 보스 회복, 주기적 광역 공격 | 포식자 / 여왕의 생체갑 |
| 역천 제도 | 폭격·급강하·착지 취약 구간 | 천공 추격자 / 낙뢰의 깃 |

세트는 무기·상의·하의·신발·장신구 5부위이며 2/4부위 효과를 제공한다. 고유 장비는 세트 개수에 포함하지 않아 4세트+고유, 2세트+2세트 조합을 선택할 수 있다. 세트·고유 효과와 연마 옵션은 PVE 전용이다. 일반 장비 기본 전투력은 기존 90% PVE / 10% PVP 분배를 따른다.
