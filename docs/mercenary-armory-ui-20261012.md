# 용병 무장고 UI와 독립 진입 · 2026-10-12

사용자 요청: 용병·5부위 슬롯과 보관함의 좌우 구조는 유지하되, 독립 진입점을 제공하고 내부 UI를 정돈한다. 후속 요청에 따라 로비 복귀와 뒤로가기를 항상 찾을 수 있게 제공한다.

## 반영

- PC 로비 사이드메뉴에 **용병 장비**를 별도 추가한다. 모바일 전체 메뉴 검색과 장비 - 제작 분류에도 별도 항목으로 표시하며 `/mercenary-codex/equipment/`로 직접 이동한다. 도감과 덱 편성의 기존 바로가기도 유지한다.
- 고정 상단에 **뒤로가기 / 숲켓몬 / 로비로**를 둔다. 같은 출처의 이전 게임 화면이 있으면 뒤로 돌아가고, 직접 주소 또는 PWA 실행처럼 이전 화면이 확인되지 않으면 `/?screen=home`으로 복귀한다. 모바일 보관함 바로 이동은 불필요한 브라우저 이력을 만들지 않는다.
- 차콜·금색 재질, 기존 승인 격납고 배경, 원화 중심 무장대, 다섯 부위의 선 아이콘과 장착 테두리, PVE/PVP 선택, 전투력·효과 위계를 정돈한다. 원화·장비 파일은 재생성·변형하지 않는다.
- 보관함에 지역별 개수와 선택한 모드의 실제 장비 전투력을 표시한다. 빈 보관함은 서버 공개 카탈로그에 있는 고유 장비 최대 3개만 도감 미리보기로 보여준다. 보유로 표시하거나 장착 버튼을 제공하지 않는다. 필터 결과 없음과 실제 미보유를 구분하고 필터 초기화를 제공한다.
- 상세창에 원화·두 모드 전투력·효과·장착 버튼을 정돈한다. 오류/비로그인 상태는 무한 로딩 대신 안내와 재시도를 제공한다.
- 저장 API, 모드별 장비 구성, 소유권·영수증·장비 수치·강화·연마·출시/공급 설정은 변경하지 않는다.

## 검수

- 실제 서버 핸들러와 격리 메모리 계정으로 PC 1440×1050, 모바일 390×844 검수. 운영 계정과 재화 변경 없음.
- 브라우저 35항목 통과: PC 사이드메뉴/모바일 검색 진입, PVP 실제 장착·새로고침 보존·해제, PVE 독립 유지, 30종 카탈로그·지역 필터, 도감 장착 금지, 스크롤 후 고정 상단, 모바일 보관함 이동 시 이력 불변, 로비 복귀, 이전 화면 복귀, 직접 진입 fallback, 빈 보관함 미리보기·필터 초기화, 서버 오류 재시도. 브라우저 오류 0건, 가로 넘침 없음.
- PC 보유/빈 상태, 모바일 무장대/보관함/상세창 화면을 직접 확인했다. 증빙은 `docs/qa/mercenary-armory-ui-20261012/`에 보존한다.
- 작은 UI·진입 변경이므로 지정 scoped 배포를 사용한다. 장비 저장 회귀 `tests/mercenary-equipment-20261011.test.mjs`와 로비 빌드 일치/메뉴 회귀 `test:lobby`만 선택한다. 서버·공통 인증·DB 구조 변경 없음.

운영 배포 기준과 결과는 검증 후 추가한다.
