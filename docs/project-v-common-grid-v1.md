## 표시 규칙

- 실제 배치된 유닛 아래에만 타일을 표시한다. 6시 방향의 빈 행, 전체 직사각형 격자, 외곽선을 만들지 않는다. KO·철수 때 제거하고 부활·증원 때 해당 자리에 다시 표시한다. 공격 중 움직이는 발끝을 따라 타일이 이동하지 않는다.
- 일반 카드 저장·검증은 정확히 5장이다. 용병은 진영당 별도 최대 1장이고 등록하지 않으면 자리도 없다. 그리드 등록은 표시 전용이며 일반 전투 배열·카드 도크·API에 용병을 추가하지 않는다. 용병 등급·획득·운영 편성은 기존 별도 게이트를 따른다.
- 슈트는 기존 PVE 판정을 통과한 경우에만 아군 진영 가운데에 배치한다. PVP·랭크·공성·영토·클랜전 차단은 유지한다. 봉인전 `SEAL`과 공성전 `SIEGE`를 혼동하지 않는다.
- 모든 자리는 공통 정수 행·열로 계산한다. PVP/PVE와 콘텐츠별 임의 좌표를 만들지 않는다. 좌우 진영은 대칭이며 빈 자리·KO가 있어도 다른 자리를 당겨서 재배치하지 않는다.
- PC는 열 210·행 176, 모바일은 열 216·행 300의 일정한 간격을 사용한다. 타일은 모두 190×64다. 값은 확대 전 공통 좌표계 기준이며 화면에는 단일 균일 배율로 맞춘다.
- 일반 카드·용병·슈트의 기본 배율은 PC 0.5, 모바일 0.65로 같다. 카드 인덱스나 진영에 따른 추가 확대·축소를 금지한다. 개별 자산의 신체/보스 크기와 공격 연출 변형은 유지한다. 이름표는 실제 신체 높이에 고정하며 이동 때 다시 옛 높이로 돌아가지 않는다.
- 모바일은 전투 폭 760px 이하에서 1080×1240 배치 영역을 헤더·상태·카드 도크 사이에 균일 배율로 맞춘다. 프리뷰 높이는 화면 폭과 콘텐츠 비율로 정한다. 호송 체력 표시는 별도 상단 영역을 확보한다.

공용 V3를 쓰는 토벌·탑·월드 레이드·봉인전·호송·아포칼립스·랭크·공성·영토·클랜전, 코어 레이드와 기존 연출 프리뷰가 기본 배치를 상속한다. 무한의탑은 공동 출시 준비 범위이며 별도 활성화하지 않는다. 원정은 공용 번들을 직접 쓰고 폐차장·카우방은 기존 연속 몬스터 교체 확장만 유지한다. 용병·슈트 스킬칩·보스 검수 번들과 신규 계정 PVE 진입 화면도 공통 소스를 사용한다.

`preview/v3-wide-grid-v1/`에는 기존/개편 비교 조작과 용병 표본만 남긴다. 두 좌표 모듈은 공통 소스를 재수출한다. `grid=original`은 이 비교 화면에서만 선택할 수 있다.

PC 일반 5자리: `(170,240) (590,240) (170,416) (590,416) (380,592)`. 용병 `(380,240)`, 슈트 `(380,416)`, 단일 보스 `(1010,416)`, 호송 차량 `(800,592)`. 일반 상대는 X=1600 기준 반전한다. 모바일은 가독성을 위해 진영당 2열로 재배치하고, 단일 보스·호송도 같은 정수 셀을 쓴다. 실제 구현은 `FormationLayout.mjs`의 셀/피치만 수정한다.

PixiJS **8.20.0**·GSAP **3.13.0**, 승인 카드 원화·전투 SD·총기·아틀라스·사운드는 유지한다. 스킬 이동/복귀·충돌은 기존 공통 좌표와 시계를 사용한다. 서버 피해·승패를 배치 코드가 다시 계산하지 않는다.

## 빌드·검증·보류

```text
npm run build:v3
npm run test:v3-grid
node scripts/qa-v3-common-grid.mjs
node scripts/qa-v3-wide-grid-preview.mjs
```

`build:v3` → `build:v3-grid`는 공용·폐차장·카우방·탑·계정 PVE·그리드 비교·보스·슈트 스킬칩·용병 스킬의 9개 전투 코드 번들과 비교 화면의 높이 계산 번들을 함께 빌드한다. 승인 아트·아틀라스·사운드를 재생성하지 않는다. `grid-build-report.json`에 공통 소스와 각 번들의 UTF-8/LF SHA-256을 기록한다. 릴리스 게이트의 `test:v3-grid`가 옛 번들 혼입을 검사한다.
