# V3 공통 점유 그리드 V1

2026-09-11 · **LOCAL_INTEGRATED / LIVE_DEPLOYMENT_HELD_BY_USER**

사용자의 `모든 v3 개편 및 모든 컨텐츠에서 해당 그리드 개편안을 사용하도록 해`를 공통 렌더러에 반영한다. 후속 `라이브는 아직`에 따라 로컬 구현·검수·범위 커밋까지만 진행한다. 운영 배포·푸시·DB·메뉴·기능 플래그 변경은 포함하지 않는다.

## 표시 규칙

- 실제 배치된 유닛 아래에만 타일을 표시한다. 6시 방향의 빈 행, 전체 직사각형 격자, 외곽선을 만들지 않는다. KO·철수 때 제거하고 부활·증원 때 해당 자리에 다시 표시한다. 공격 중 움직이는 발끝을 따라 타일이 이동하지 않는다.
- 일반 카드 저장·검증은 정확히 5장이다. 용병은 진영당 별도 최대 1장이고 등록하지 않으면 자리도 없다. 그리드 등록은 표시 전용이며 일반 전투 배열·카드 도크·API에 용병을 추가하지 않는다. 용병 등급·획득·운영 편성은 기존 별도 게이트를 따른다.
- 슈트는 기존 PVE 판정을 통과한 경우에만 아군 진영 가운데에 배치한다. PVP·랭크·공성·영토·클랜전 차단은 유지한다. 봉인전 `SEAL`과 공성전 `SIEGE`를 혼동하지 않는다.
- PC 승인 좌표·배율은 유지한다. 단일 보스와 호송 차량은 별도 실제 자리를 사용한다. 모바일은 전투 폭 760px 이하에서 1020×1060 배치 영역을 헤더·상태·카드 도크 사이에 균일 배율로 맞춘다. 프리뷰 높이는 화면 폭과 콘텐츠 비율로 정한다. 호송 체력 표시는 별도 상단 영역을 확보한다.

공용 V3를 쓰는 토벌·탑·월드 레이드·봉인전·호송·아포칼립스·랭크·공성·영토·클랜전, 코어 레이드와 기존 연출 프리뷰가 기본 배치를 상속한다. 탑의 표시 통합은 탑 재기획 또는 PVE 통합 출시 편입이 아니다. 원정은 공용 번들을 직접 쓰고 폐차장·카우방은 기존 연속 몬스터 교체 확장만 유지한다. 용병·슈트 스킬칩·보스 검수 번들도 공통 소스를 사용한다.

`preview/v3-wide-grid-v1/`에는 기존/개편 비교 조작과 용병 표본만 남긴다. 두 좌표 모듈은 공통 소스를 재수출한다. `grid=original`은 이 비교 화면에서만 선택할 수 있다.

PC 일반 5자리: `(280,260) (695,280) (125,425) (655,520) (300,575)`. 용병 `(495,250)`, 슈트 `(410,425)`, 단일 보스 `(1210,425)`, 호송 차량 `(890,540)`. 일반 상대는 X=1600 기준 반전한다. 모바일의 단일 보스 `(805,650)`, 호송 차량 `(790,970)`에 가용 영역 오프셋을 더하며 나머지는 `ViewportLayout.mjs`가 기준이다.

PixiJS **8.20.0**·GSAP **3.13.0**, 승인 카드 원화·전투 SD·총기·아틀라스·사운드는 유지한다. 스킬 이동/복귀·충돌은 기존 공통 좌표와 시계를 사용한다. 서버 피해·승패를 배치 코드가 다시 계산하지 않는다.

## 빌드·검증·보류

```text
npm run build:v3
npm run test:v3-grid
node scripts/qa-v3-common-grid.mjs
node scripts/qa-v3-wide-grid-preview.mjs
```

`build:v3` → `build:v3-grid`는 공용·폐차장·카우방·그리드 비교·보스·슈트 스킬칩·용병 스킬의 7개 코드 번들을 함께 빌드한다. 승인 아트·아틀라스·사운드를 재생성하지 않는다. `grid-build-report.json`에 공통 소스와 각 번들의 UTF-8/LF SHA-256을 기록한다. 릴리스 게이트의 `test:v3-grid`가 옛 번들 혼입을 검사한다.

- 공통 점유·KO·부활·증원·타일 고정·용병 슬롯·PC/모바일 비교·빌드 일치 검사 **21개 통과**.
- 원정·폐차장·카우방·연속 세션·슈트/스킬칩·용병 스킬·호송·코어/모바일 레이드·비차단 전투 연출 관련 기존 회귀 검사 통과.
- 콘텐츠별 브라우저 검사 **33개 통과**: 10종 × 모바일/PC, 개편 3화면, 스킬 검수 3화면의 모바일↔PC 전환, 코어 레이드 프리뷰 입장. 원화 도크·PVE 제한·단일 캔버스·헤더/도크 경계·편집 섹션 높이를 확인했다.
- 별도 비교 검수: 폭 320·390·576·760·988·1366·1600의 PVP/PVE, 창 높이 변경, 용병 미배치, PC 좌표·배율과 전투 스냅샷 보존. 390px 연속 전투는 10/10 격파, 일시정지·초기화·전체화면 복원, 종료 후 실제 4칸을 확인했다.
- 결과: `output/v3-common-grid-20260911/final/` 및 `wide-regression/`. 브라우저 JavaScript·HTTP 오류 없음. 기존 선택적 아포칼립스 자산 캐시/GPU 경고는 별도로 남겼다. 실제 휴대폰 하드웨어 검수와 구분한다.

브라우저 검사는 외부 Playwright를 사용한다. 필요하면 `PLAYWRIGHT_MODULE_URL`, `QA_CHROMIUM`, `QA_BASE_URL`, `QA_OUTPUT_DIR`을 지정한다.

이번 작업은 로컬 공통 그리드 통합이다. 남은 PVE 전체 작업과 블랙미라클·코어 공동 출시 게이트를 완료 처리하지 않는다. 운영 캐시·메뉴/API는 갱신하지 않았다. 이후 별도 배포 지시가 있을 때 대상·캐시·출시 조건을 재검토하고 `release:gate` 및 `deploy:production` 절차를 따른다.
