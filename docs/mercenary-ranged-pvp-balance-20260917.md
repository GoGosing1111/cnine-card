# 저격·다단 사격 용병 PVP 점검 · 2026-09-17

사용자 지시: 전체 용병을 근거리와 제대로 비교하되, S등급 이상 저격총·행동이 느린 원거리의 손실을 개별 보정한다. 모든 원거리의 공격력·속도를 일괄 올리지 않는다.

## 실제 원인과 적용 범위

운영 CMS r55의 **44종 전체**를 조사했다. 무기 원본 분류, 운영 역할·스킬 배정, 준비·후속탄·재장전 행동과 동일 등급 근거리 상대 승패를 비교했다. 서버의 기본 행동 주기는 무기 연출 시간과 별개다. 예를 들어 저격 기본 연출은 0.90초, 일반 사격은 0.69초이지만 서버 추가 행동 주기는 같다. 문제는 스킬 준비·후속탄이 각각 실제 용병 행동을 소비하는 데 있었다.

| 대상 | 기존 소모 | 변경 |
|---|---|---|
| 베스페라 · MS-004 | 준비 + 한 발 = 2행동 | 현재 행동에서 한 발. 후열 핵심 위협 우선 유지 |
| 아스텔 · MS-008 | 준비 + 한 발 = 2행동 | 현재 행동에서 한 발. 보호막이 없어도 파쇄 20% 적용 |
| 네레이아 · MS-032 | 준비 + 한 발 + 다음 행동 게이지 지연 | 현재 행동에서 한 발. 적 HP 30% 조건 없이 마무리 50%, 재장전 지연 제거 |
| 네레이아 · MS-036 | 준비 + 초탄 + 후속탄 = 3행동 | 두 발을 1행동에서 처리. 초탄 명중·보호막 흡수 조건 없이 추적 40% 적용 |
| 청아 · MS-005 | 준비 + 3연사 = 4행동 | 3행동, 행동마다 한 발. 초탄 실패로 연사 취소하지 않고 마지막 교정탄 유지 |
| 련화 · MS-009 | 준비 + 표적 전환 3연사 = 4행동 | 3행동, 행동마다 한 발. 약화된 적 사이 표적 전환 유지 |
| 아델린 · MS-037 | 준비 + 3연사 = 4행동 | 3행동, 행동마다 한 발. 전탄 명중 조건을 제거하고 명중한 표적의 다음 공격 스킬 약화 |
| 마리엘 · MS-040 | 준비 + 최대 3발 = 최대 4행동 | 최대 3행동, 행동마다 한 발. 대상별 분산 피해 유지, 단일 대상은 1행동 |
| 동탄 디임 · MS-043 | 준비 + 2연사 + 재장전 게이지 지연 | 2행동, 행동마다 한 발. 초탄 실패 후에도 후속탄 발사, 재장전 지연 제거 |

**총 8종, 9개 배정 스킬**이다. 저격 3종과 실제로 여러 행동에 걸쳐 사격하던 5종에 서로 다른 규칙을 쓴다. 엘로디의 단발 석궁, 경찰 조은의 단발 제압, 하이희야의 9발 연출/1회 피해 판정은 기존 처리와 동일하다. C~A등급·근거리·마법·지원형도 원래대로다. 스킬 MS-025·MS-027 등 미배정 목록을 미리 버프하거나 새로 배정하지 않는다.

## 피해·자원·방어 계약

- 등급별 전투력, 기본 능력치, CMS 피해 배율·비용·쿨타임, 스킬 배정, 획득 확률을 유지한다. 서버 공통 프로필과 공개 설명이 동일한 적용 조건을 사용한다.
- 저격수의 같은 행동 안 두 발은 PVP의 기존 1회 피해 상한을 피해 비중으로 나눈다. 다단 사격은 실제로 별도 행동을 소비하므로 각 행동의 기존 상한을 사용한다.
- 각 탄의 회피는 독립 판정한다. 빗나간 탄은 보충하지 않는다. 남은 탄은 살아 있는 적에게 다시 조준하며 죽은 표적에 피해를 기록하지 않는다.
- 비용·쿨타임은 발동마다 한 번만 적용한다. 스킬 타격·후속탄으로 자원이나 추가 행동을 만들지 않는다. 다단 사격 도중 사망·기절·침묵은 여전히 연사를 취소한다.
- 선택된 스킬은 PVE 기본 공격의 최소 피해에 실제 타격별 배율을 적용한다. 보스전에서 배율 높은 스킬만 최소 피해가 0이던 역전을 교정하며, 호송 최소 피해 OFF·아포칼립스 축소·피해 상한을 유지한다.

## PVP 비교 결과

전체 점검: **전후 각각 119,040판**. 동일 등급의 모든 근거리 상대와 3개 카드 전투력 구간(장당 10만·100만·2,000만), 혼합·공격·방어·속도 덱 4종, A/B 진영 교환, 시드 32개를 사용했다. PVE는 전후 각각 6,336판으로 스킬 편성과 평타 전용 편성을 비교했다.

상향 8종은 시드를 128개로 늘려 **전후 각각 36,864판**을 다시 비교했다. 아래 표는 공격형 근거리와의 결과다. S등급은 아우렌, SS등급은 월령과 용병마다 3,072판씩 비교했다. 수호형 상대 결과까지 섞어 공격 성능을 높게 표현하지 않는다.

미조정 36종은 비교 가능한 PVP 109,824판과 PVE 5,184판의 전후 집계가 정확히 같다. 경찰 조은·하이희야처럼 이번 지연 보정에 해당하지 않는 용병의 근거리 상대 열세까지 해결했다고 주장하지 않는다.

## 화면·회귀·출시

- 도감·보유 용병은 실제 적용되는 스킬 설명을 표시하고 CMS에는 해당 배정에만 읽기 전용 전투 보정 항목을 표시한다. 운영자가 저장한 원본 문서는 수정하지 않는다.
- 테스트는 저격 즉시 사격과 다단 사격의 행동 수를 별도로 검증한다. 표적 사망·초탄 회피·조건부 보너스·기절/침묵 취소·자원/쿨타임·PVP 상한·PVE/아포칼립스 최소 피해·동등 근거리·A등급 비교를 포함한다.
- 기존 PixiJS 8.20.0 / GSAP 3.13.0과 MercenaryCombatPlayback의 승인 연속 프레임·충돌·원음을 사용한다. 서버의 skillPhaseIndex와 대상별 WINDUP/HIT를 재생하며 원화·SD·프레임·엔진 번들·컷신을 새로 만들지 않는다.
- 실제 index.html의 토벌 시작·PVP 매칭 → 전투 → 결과 → 복귀, 재입장·모드 전환·구버전 번들 자동 갱신·오류 복귀를 PC 1440×1000 / 모바일 390×844와 격리 계정/API로 확인한다.
- 깨끗한 범위 커밋을 최신 main에 반영하고 npm run deploy:production에서 전체 release:gate를 통과한 뒤 배포한다. 배포 후 운영 정적 파일로 같은 입장을 재검수하고 공개 도감·운영 CMS 불변을 확인한다.
