# 족로 일반 PVE·레이드 연출 중단 수정 — 2026-10-19

## 재현과 원인

실제 일반 PVE 서버 시뮬레이터의 청룡단천 영수증을 실제 웹 `createRenderer().play()` 경로에 전달했다. 기존 웹 래퍼의 개별 이벤트 제한은 2초인데 족로 광역기의 첫 타격은 2.12초, 전체 연출은 5.6초다. 브라우저에서 **2.012초에 시간 초과 경고가 발생하고 타격·화면 절단 0회**로 취소되는 것을 재현했다. 이전 족로 검수는 엔진의 `playMercenaryEvent()`를 직접 호출하여 이 웹 래퍼 제한을 통과하지 않았다.

## 수정

- `MERCENARY_JOKRO_AREA`의 웹 대기 한도를 9초로 늘려 5.6초 원래 연출과 기기 지연 여유를 보장한다. 족로의 매 세 번째 기본 공격은 3.4초짜리 용령발도이므로 해당 용병의 `TURN` 영수증은 6초까지 기다린다.
- 기다리는 최대 시간만 바꾸며 실제 연출을 9초/6초로 늘리거나 효과 속도를 바꾸지 않는다. 다른 행동의 기존 2초·6초·9초 제한은 보존한다. 실제로 멈춘 연출은 기존 취소·복구 경로를 그대로 따른다.
- 웹 래퍼 버전은 `3.37.2-jokro-authored-timeout`, 메인 로더 쿼리는 `jokroPlayback=20261019-v1`이다. 기존 서비스워커의 전투 스크립트 네트워크 우선 경로를 사용한다. Pixi/GSAP 공용 엔진과 생성 번들은 변경하지 않았다.
