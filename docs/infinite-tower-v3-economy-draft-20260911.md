# 무한의탑 V3 입장·보상 수량 시안

2026-09-11 사용자 요청: “기존 탑 보상과 재료를 기준으로 수량·일일 한도 시안까지 작성”. **수치 제안이며 운영 승인값이 아니다.** 운영 DB는 읽기 전용으로 확인했다.

## 운영 기준 확인

- 현재 설정은 70층까지다. 층 범위 설정을 개별 층 설정보다 우선한다. 최고층은 `tower_user_progress`에 있으며, 조사 시점 집계 567건의 최고 도달층은 59층이었다. 이 집계만으로 60층의 오류나 적정 난도를 단정하지 않는다.
- `magic_card_settings_v1.acquisition.tower`는 `enabled:false`, `floorRewards:[]`다. 기존 탑 최초 보상 마력석은 현재 0개다.
- 기존 차량 제작 재료 `VEHICLE_PART_TIRE`(고성능 타이어), `VEHICLE_PART_FRAME`, `VEHICLE_PART_ENGINE`은 활성 항목이다. 마스터의 별·미스틱 에너지·슈트 코어를 무료 반복 보상에 자동 추가하지 않는다.
- 과거 최초 보상 기록과 최고층을 보존한다. 전체 시즌의 최고층 이하를 이미 보상받은 구간으로 이전하고, 신규 V3 최초 영수증은 계정·층별로 한 번만 만든다. 보상 버전 변경이나 재등반으로 다시 지급하지 않는다.

## 제안 수량과 한도

| 항목 | 시안 |
| --- | --- |
| 입장 | 무료, 입장권 없음 |
| 일일 반복 보상 | 성공한 원정 10회, 실패는 보상 횟수 미소모 |
| 한도 이후 | 기록·해금 도전 가능, 반복 보상 0 |
| 반복 코인 | 해당 10층 구간 일반층 최초 코인의 2%, 1회 최대 50만 |
| 반복 제작 재료 | 20층 이상에서 보상 가능한 성공 5회마다 고성능 타이어 1개, 하루 최대 2개 |
| 자동 재등반 | 직접 선택, 최대 10회. 패배·보상 소진·화면 이탈·설정 변경·사용자 중지 시 다음 입장 중단 |
| 날짜 경계 | 한국 시간 00시. 입장 시 확정한 날짜·보상 예산을 정산까지 유지 |
| 71층 이후 최초 보상 | 미편성, 자동 생성 0. 별도 승인 전 신규 고액 최초 보상 추가 없음 |

| --- | --- | --- | --- |

마일스톤 5억을 반복 계산의 기준으로 쓰지 않는다. 예를 들어 이미 70층을 깬 계정이 100번 재등반해도 그날 반복 코인은 최대 500만, 타이어는 최대 2개다. 새 60층 최초 돌파는 기존 3억과 그날 남은 반복 보상 20만을 각각 한 번 받는다. 일일 예산 0은 지급 없음이며 무제한이 아니다.

## 추가 드롭 정책 제안

| 기존 부가 지급 | 새 반복 원정 시안 | 최초 돌파 전환 시 확인 항목 |
| --- | --- | --- |
| 마력석 | 0 | 현재 OFF/빈 보상표 그대로 반영 |
| 장비 확률 드롭 | 0 | 기존 확률을 새 최초 돌파에 유지할지 최종 결정 필요 |
| 블랙미라클 확률 드롭 | 0 | 공동 출시·사용 플래그와 별개로 획득 정책 확인 필요 |
| 주간 프리미엄 큐브 누적 | 0 | 기존 전투 시도마다 누적되는 구조를 무제한 재등반에 복사하지 않음 |
| 고급 리롤권 드롭 | 0 | 신규 첫 돌파 한정 유지 여부 최종 결정 필요 |
| 미스틱 에너지·슈트 코어 | 0 | 고가 제작 재료의 상시 무료 공급 추가 없음 |

현재 구현의 고정 보상 지급기는 코인·마력석·기존 인벤토리 재료를 지원한다. 부가 확률 드롭의 자동 승계는 활성화하지 않았다. 이 항목은 운영 전환 전 승인해야 하는 정책이며 기존 운영 보상은 현재 경로에서 계속 동작한다.

## 구현과 검수

- 계산: `functions/_tower_v3_economy.js`. 기록 이전: `_tower_v3_legacy.js`. 예약·지급·영수증: `_tower_v3_runs.js`.
- CMS: 검수 화면에서 일일 횟수·코인 비율/상한·재료 간격/한도를 조정한다. 운영 설정 저장 준비 모듈 `_tower_v3_settings.js`도 별도다. 초안 저장이 승인 또는 ON 전환으로 이어지지 않는다.
- SQLite와 PostgreSQL 각각 100회 반복, 최초 보상 중복, 응답 유실, 동시 탭, 자정, CMS/덱 변경 후 복구, 지급 실패 롤백을 검증했다.
- 경제 검수 결과와 실제 운영 연결 승인은 분리한다. 보상 수량·추가 드롭 적용 범위를 확정한 뒤 최종 출시 게이트를 다시 통과해야 한다.
