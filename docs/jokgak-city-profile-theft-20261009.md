# 족각도시 현금 강탈 및 내 프로필 — 2026-10-09

사용자 요청: PVP 승리 시 상대 소지금을 빼앗고 직업·배고픔·현재 상태 프로필을 추가한다. 후속 선택으로 **소지 현금 10%, 1회 최대 2,000원**을 확정했다.

## 동작

- 도시 공격/방어/체포 전투의 승자에게 패자 현금을 옮긴다. `min(floor(패자 현금 × 비율 / 100), 1회 한도, 승자의 보유 여유)`를 계산한다. 무승부/0원은 이동 없음. 강탈 후 기존 역할별 추가 보상을 별도로 처리한다.
- 기존 일반 PVP, 일반 코인·아이템, 카드/용병 전투 성능은 유지한다. 신규 지급이 아니므로 역할 보상 OFF와 독립적으로 동작한다. CMS 생활·상점에서 사용 여부·정수 비율 0~100·1회 한도 0~10억 원을 조절한다.
- 기존 정책에 `cash.theft`가 없으면 승인값 `{enabled:true,percent:10,maxCash:2000}`으로 읽는다. 시작 현금과 기존 저장 정책을 덮어쓰지 않는다. TEST/ON 각 지갑만 이동하며 모드 변경 후 기존 영수증을 재실행해도 다른 지갑에 적용하지 않는다.
- 양쪽 생활 JSON과 플레이어 revision, 정책 스냅샷, 전투 영수증, 상대 알림을 기존 CAS/batch 하나에 저장한다. 실패는 전체 취소, 응답 유실은 같은 영수증 회수, 경합은 최신 상태 재확인으로 처리한다. DB 스키마/마이그레이션/공통 인증·거래 기반 변경은 없다.
- 강탈 영수증은 이동 금액/방향/조건만 공개한다. 상대 전체 지갑·소지품은 체류자/전투 상대 목록에 노출하지 않으며 방어자가 조회하는 기록에서도 공격자의 개인 현금과 보상 잔액을 제외한다.

## 화면

- 지도 위 도시 프로필: 닉네임·직업·현재 위치·수배·행동 대기, 현금, 전투 체력/포만감/건강을 함께 배치한다. 포만감은 높을수록 배부른 기존 의미를 유지하고 ‘낮을수록 배고픔’으로 안내한다.
- 사망·구금·응급 진료·교전 보호·배고픔·행동 대기를 우선순위에 따라 표시한다. 카운트다운은 서버 시각 오프셋을 사용한다. 식당/병원 바로 찾기도 유지한다.
- 공격 결과, 재생 오류 시 확정 결과 안내, 다른 콘텐츠의 비모달 피격 알림과 기록에 현금 획득/손실을 표시한다. 기존 네이비/라임 스타일과 지도 원본을 유지한다.
- 공지 초안에 강탈 규칙과 프로필을 추가했다. 외부 게시/발송은 하지 않는다.
