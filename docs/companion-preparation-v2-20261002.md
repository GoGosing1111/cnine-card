# 용병 2슬롯 · 펫 시작 버프 준비 — 2026-10-02

사용자 요청은 용병 최대 2명, 등급별 최대 1명, 같은 등급 중복 금지다. 펫은 우선 1마리를 편성하며 전투 시작에 SD로 등장해 버프를 적용한다. 후속 답변에 따라 버프 종류·수치는 **CMS에서 펫마다 설정**한다.

## 준비 범위와 공개 상태

- 일반 카드 `cardIds`는 서로 다른 정확히 5장이다. 용병은 별도 `mercenaryCodes` 최대 2개, 펫은 `petCode` 1개로 분리한다. 최대 전투 인원은 7명이며 펫은 타격 대상·행동 슬롯·승패 인원에 포함하지 않는다.
- 용병 코드·등급은 서버 용병 CMS에서 조회한다. 같은 코드나 같은 등급을 두 슬롯에 배치하면 서버에서 거부한다. 검수 UI에서도 같은 등급 선택지를 막는다. 보유권 검증이 포함된 공용 계약을 준비했으며 OWNER 검수만 보유권을 우회한다.
- 기존 라이브 `mercenaryCode` 1슬롯 저장·편성·전투 계약은 그대로다. 2슬롯/펫 공용 계약과 별도 실제 엔진 검수 경로를 준비했으며, 실계정 저장 마이그레이션·라이브 편성 UI·실전 활성화는 이후 출시 연결 범위다. 기존 계정을 자동 변환하지 않는다.
- `COMPANION_RELEASE`의 `dualMercenaries`, `pets`, `petAcquisition`은 모두 `false`다. CMS 저장/검수는 공개나 획득 활성화가 아니다. 운영용 초기 펫 목록은 비어 있으며 임의 캐릭터·버프 수치를 등록하지 않는다.

## 펫 CMS

OWNER 관리자 메뉴 **펫·동료 준비**에서 추가·삭제·이름·SD 경로·검수 사용·대상·PvE/PvP·버프 목록·운영 메모를 설정한다. SD는 프로젝트 `assets/` 아래 PNG/WebP를 사용한다. 원화 대신 SD를 전투에 연결하며 이미지 제작·승인은 이번 작업에 포함하지 않는다.

| 설정 | 선택지 |
|---|---|
| 적용 대상 | 일반 카드 / 용병 / 카드 + 용병 |
| 버프 종류 | 공격력, 방어력, 최대 HP, 속도 증가 / 시작 보호막 |
| 수치 | 종류별 %; 초기값 `null`(미정), 입력 한계 0~1000% |
| 적용 시점 | 전투 시작 1회 |
| 유지 | 능력치 증가는 해당 전투 동안 유지; 보호막은 피해로 소모 |

입력 한계는 출시 권장 수치가 아니다. 서로 다른 버프 1~5개, 펫 최대 100개다. 미정 수치·미등록 SD·모드 불일치·검수 사용 OFF인 펫은 검수 실행을 거부한다. 획득 방식·등급·확률·비용·확정 출시 수치는 정하지 않았다.

## 서버·저장

- `GET/PATCH /api/admin/pets`: 기존 `BATTLE_MANAGE` 인증 결과에 OWNER 제한을 추가한다. 공개 응답 캐시는 `private, no-store`다.
- `GET /api/admin/companions/preparation`: 규칙·저장된 펫·확정 등급의 서버 용병·검수 카드 조회.
- `POST /api/admin/companions/preparation/preview`: CMS 버전이 일치하는 편성을 재검증하고 PvE/PvP 엔진을 실행한다. 클라이언트가 등급·버프·능력치를 덮어쓸 수 없다. 계정 재화·보상·편성을 변경하지 않는다.
- 기존 `app_meta`의 `pet_cms_preparation_v1` 한 행에 설정·버전·최근 50개 저장 영수증을 함께 저장한다. GET은 초기화/DDL/쓰기하지 않는다. 첫 저장은 충돌 방지 INSERT, 이후 저장은 이전 JSON 일치 조건의 원자적 UPDATE다.
- `expectedRevision`과 `requestId`로 동시 편집 충돌과 동일 요청 재시도를 처리한다. 동일 ID에 다른 내용/작성자는 409다. 실패·충돌 시 UI는 편집본을 보존하며 내려받기와 결과 재확인을 지원한다.

## 전투 검수

공용 저수준 전투 엔진에 내부 검수 키를 명시한 경우에만 2명용 독립 행동 누적과 펫 시작 버프가 동작한다. 기존 라이브 PvE/PvP 래퍼는 이 키를 전달하지 않는다.

버프는 일반 카드 시작 효과와 용병 연계 능력치가 준비된 뒤, 행동 게이지·첫 행동·보스 시작 공격 전에 적용한다. HP 증가 후 보호막을 계산하므로 CMS 항목 순서에 따라 결과가 바뀌지 않는다. 시작 HP 비율을 유지하고, 용병 공격력은 연계 최소 공격력도 포함한 유효 공격력에서 증가시킨다. 슈트·몬스터는 펫 적용 대상에서 제외한다.

`PET_OPENING_BUFF` 1개 이벤트에 펫 SD와 대상별 적용 전후 능력치를 기록한다. 검수 화면은 SD 등장, 대상 버프 표시, 능력치 전후표, 용병별 실제 행동 횟수를 보여준다. 펫은 전투 배우 배열에 추가하지 않는다.
