# 용병 무장고 전체 UI 재설계 · 2026-10-12

사용자 후속 지시: 기존 변경은 범위가 작다. 용병·5부위 슬롯 / 보관함의 큰 구조만 남기고 **모든 버튼과 모든 영역을 다시 설계**한다. 이 문서는 앞선 `mercenary-armory-ui-20261012.md`의 시각 결과를 대체하며 독립 메뉴와 로비·뒤로가기 동작은 이어받는다.

## 바뀐 화면과 조작

- 페이지 전체를 새 HTML/CSS로 구성했다. 짙은 올리브·아이보리·황동 색, 한글 세리프 제목, 문장형 안내, 전용 선 아이콘과 버튼 재질을 적용했다. 로비 복귀, 뒤로가기, 새로고침, PVE/PVP, 용병 변경, 강화소 이동까지 형태·크기·선택/호버/포커스/비활성 상태를 재설계했다.
- 무장대는 원화의 얼굴과 실루엣을 중심으로 배치했다. 5부위 슬롯, 빈 슬롯 아이콘, 강화 수치, 모드별 전투력, 세트별 5칸 진행도와 2/4세트 ON/OFF, 고유·연마 효과 표시를 새로 구성했다. 승인 원화와 장비 이미지를 변경하지 않았다.
- 보관함에는 내 장비/도감 선택, 지역별 수량, 6개 부위 아이콘 버튼, 이름 검색, 기본/전투력/강화 정렬을 제공한다. 각 장비를 전시형 카드로 만들고 장착 중/고유 장비/강화 수치와 현재 모드의 전투력을 구분한다. 지역 필터는 모바일 가로 스크롤 후 초기화해도 선택된 전체 버튼이 보인다.
- 상세창은 PC에서 장비 전시대와 정보를 나란히, 모바일에서는 세로로 구성한다. 보유 장비는 **현재 부위 장비와 실제 강화 포함 전투력 차이**를 표시한다. 도감은 기본 수치임을 안내하고 장착을 제공하지 않는다. 하단 장착·해제·닫기는 스크롤 중에도 노출된다. 닫은 뒤 선택한 카드/슬롯으로 키보드 포커스를 돌려준다.
- 미보유 화면, 도감 미리보기, 검색 결과 없음·초기화, 로딩, 로그인/요청 오류·재시도도 같은 디자인으로 교체했다. 미리보기 닫기는 실제 출발점인 보관함으로 돌아간다.
- 화면의 소유권·저장 API, 영수증/재시도 ID, PVE/PVP 분리, 장비 수치·확률·획득/강화 정책은 기존 구현을 사용한다. 서버·DB·인증·출시 플래그 변경은 없다.

## 검수와 배포 범위

- 이전 운영 기준: 실제 Pages Production `cbf5ca7f-2d12-4296-8ec2-213b01e5dc98`, 소스 `918ec71692c6264d463468beaaaad84ad0289288`. 배포 목록으로 재확인했다.
- 이 변경은 하나의 독립 UI 화면에 한정된다. `npm run deploy:production -- --scoped`에서 `tests/mercenary-equipment-20261011.test.mjs`를 실행하며 공통 전체 검사는 반복하지 않는다. 독립 로비 메뉴 코드는 이번에 변경하지 않았다.
- 격리 메모리 DB와 실제 API 핸들러로 브라우저 35항목 통과: PC/모바일 메뉴 진입, 모드 전환, 장착·해제·재로딩 보존, 모드별 독립 저장, 도감 30종과 지역 필터, 미보유 장착 금지, 로비/뒤로가기/직접 진입 복귀, 오류 복구 등. 운영 계정·재화 변경 없음.

- PC 보유/미보유/상세, 모바일 무장대/보관함/상세의 실제 렌더링을 직접 확인했다. 검수 이미지와 결과는 `docs/qa/mercenary-armory-overhaul-20261012/`에 기록한다.
