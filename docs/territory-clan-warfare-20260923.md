# 영토전 클랜 4 vs 4 / 지휘관 스킬 개편

사용자 지시: 클랜 4개 대 4개 무작위 배치, 개막 클랜 로스터 전원 자동 참가, 남은 모집 시간 동안 클랜 미가입자 기존 편성, 클랜 마크 표시, 피해 중심 스킬 개편. 후속 확정: **스킬마다 각각 45분 쿨타임**. 기존 지휘관 권한을 유지한다.

## 개막과 참가

- 현재 클랜 시즌의 공식 8개 클랜을 Fisher–Yates로 섞어 A/B에 각각 4개 배치한다. 전투력으로 클랜을 재배치하지 않는다.
- 8개가 준비되지 않으면 개막 편성을 기다린다. 다른 시즌의 명단이나 가짜 클랜으로 채우지 않는다.
- 클랜명·마크·진영·개막 로스터를 같은 DB 거래에서 저장한다. 새로고침·재시도·후속 클랜 이탈로 명단이 달라지지 않는다.
- 개막 명단의 모든 계정을 참가자로 등록한다. 덱 미완성도 명단에서 제외하지 않는다. 실제 전투에는 소유 카드로 유효한 공격덱 5장이 필요하며 방어덱을 대신 사용하지 않는다.
- 자동 참가자는 취소할 수 없고 CMS의 개인 진영 변경으로 다른 클랜 진영에 옮길 수 없다. 모집 중에는 저장된 PVP 공격덱을 최신화할 수 있다. 미완성 덱은 전투 중에도 최초 완성을 허용한다.
- 클랜 미가입자는 남은 모집 시간에 기존 신청/취소를 사용한다. 모집 종료 시 클랜 진영을 고정한 상태에서 인원·전투력·직전 5회 승패/참여 지표를 이용해 편성한다.
- 개막 이후 클랜 합류자는 다음 영토전부터 자동 참가한다. 이미 개막 당시 무소속으로 신청한 명단은 해당 회차 기준을 유지한다.
- 기존 진행/정산 회차는 이전 규칙을 유지한다. 새 모집 또는 아직 편성 전인 모집에서 새 규칙을 확정한다. OFF 중 만료된 미개막 모집은 개막 시 정상 모집 시간을 다시 부여해 무소속 신청 시간을 확보한다.

## 스킬

새 회차는 회차당 1회/작전 게이지 제한 대신 **진영별·스킬별 45분**을 사용한다. 첫 사용은 지휘관 선출 후 가능하다. 지휘관 교체, 전선 변경, 새로고침은 쿨타임을 초기화하지 않는다. 휴전·전투 종료·운영 OFF에서는 신규 발동이 불가능하다.

| 스킬 | 직접 피해 | 추가 효과 |
| --- | --- | --- |
| 총공세 | 기존 공성 기본 피해 ×8 | 기존 총공세 피해 증폭 |
| 기습 침투 | 기존 적 최대 HP 비율 | 대공망 우회 |
| 융단폭격 | 기존 적 최대 HP 비율 | 기존 대공망 요격 적용 |
| 자주포 포격 | 기본 피해 ×12 | 기존 포격 증폭, 대포병 억제 적용 |
| 철벽 방어 | 없음 | 기존 HP 복구·피해 감소 |
| 통합 대공망 | 없음 | 기존 피해 감소·폭격 요격 |
| 대포병 반격 | 기본 피해 ×10 | 적 자주포 활성 시 기존 억제율만큼 추가 피해, 포격 억제 |
| 재집결 돌파 | 기본 피해 ×6 | 기존 진영 행동력 보충 |

기본 피해는 기존 `territorySiegeDamage`의 전투력 제곱근·배율·최소/최대·요청번호 기반 편차를 재사용한다. 비율, 효과 시간, 증폭/회복/요격 수치는 기존 CMS 값을 읽는다. 새 지속 효과는 이전 작전을 교체한다. 직접 피해는 기존 작전과 동일하게 적 HP 1까지 적용하며 거점 점령은 개인 교전에서 확정한다.

스킬 피해는 진영 누적 피해에 기록한다. 개인 공격 횟수·기여 피해·개인전 승리 코인·참여 보상 횟수는 추가하지 않는다. 기존 개인 전투, 용병 별도 슬롯, 보상 정책과 관리자 인해전술은 보존한다.

## 저장과 동시성

- `_territory_clan_warfare.js`의 독립 버전 게이트는 기존 영토전 foundation fast gate가 있어도 실행된다. 기존 열을 삭제/재해석하지 않는 추가 스키마다.
- `territory_war_clans`: 회차별 8개 클랜의 진영 및 표시 스냅샷.
- `territory_war_skill_cooldowns`: 회차/진영/스킬별 다음 사용 가능 시각.
- `territory_war_skill_receipts`: 요청번호, 사용자, 스킬, 확정 결과. 클라이언트는 실패한 요청번호를 유지한다.
- 전선 revision, 현재 회차/전선/지휘관/휴전/종료/쿨타임을 원자 배치에서 검증한다. CHECK guard 실패 시 피해·회복·행동력·쿨타임·알림을 모두 롤백한다. 경합 시 동일 요청번호로 최대 3회 최신 전선을 확인한다.
- 지휘관 권한이 변경된 뒤에도 이전 확정 영수증은 본인 요청에 한해 재조회할 수 있다. 다른 사용자/스킬의 요청번호는 거부한다.
- 자동 참가자의 장비·차량·칭호·용병·마법은 기존 계정 제공자와 편성 공식을 재사용한다. 네트워크 조회 동시 수를 8로 제한한다.

## 검증과 출시

- 운영 읽기 전용 확인: 영토전 OFF, 58회 모집 상태, 현재 클랜 시즌 2, 공식 8개 클랜/로스터 156명. 조회 중 계정 데이터나 스위치를 변경하지 않았다.
- 관련 검사 55개 통과: 신규 SQLite/PostgreSQL 실제 호환 어댑터 거래, 45분 경계, 스킬 간 독립, 반대 진영 독립, 재시도 영수증, 지휘관 변경/휴전/전선 경합 롤백, 기존 편성/개인전/보상/성능 회귀.
- 실제 `index.html` 및 공통 로비 메뉴에서 PC 1440×1000 / 모바일 390×844 확인. 검수 계정과 API 응답은 로컬 합성 데이터이며 운영 계정 공격/재화 소비는 수행하지 않았다.
- 8개 클랜 마크 로딩, 자동 참가/취소 차단, 무소속 신청/취소, 덱 최신화, 전황 지도, 8종 스킬, 개별 쿨타임/나머지 스킬 활성, 요청번호 정리 및 가로 잘림을 검수했다. 브라우저 오류 0건.
- 재현: `scripts/qa-territory-clan-warfare-20260923.mjs`. `PLAYWRIGHT_MODULE`, `CHROMIUM_PATH`, `TERRITORY_QA_DIR`를 지정한다. 산출물은 배포 트리 밖에 저장한다.
- 큰 변경이므로 최종 `npm run deploy:production`에서 전체 `release:gate`를 한 번 실행한다. 새 DB 회귀를 `test:territory-reward`에 포함했다.
- 배포는 현재 OFF 설정을 자동 ON으로 전환하지 않는다. 운영자가 다음 모집을 개막하면 적용된다. 진행 중인 구형 회차가 있다면 종료까지 구형 스킬 계약을 유지한다.
- 롤백은 먼저 운영을 OFF로 두고 직전 검증된 코드로 배포한다. 새 회차를 구형 코드로 진행하지 않는다. 추가 스키마와 확정 영수증은 삭제하지 않는다.
