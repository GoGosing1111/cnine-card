# 보스 샌드백 문제 (V1813)

V1812 배포는 확인했습니다 (`app.js` 가 `?v=56-v1812-pace` 로 서빙 중).
그 상태에서 "여전히 보스가 샌드백" 이라는 제보는 **정확합니다.** V1812 는 길이만
줄였고 보스 행동 횟수는 손대지 않았습니다.

---

## 왜 보스가 안 때리나

```js
// 플레이어 — 전투력에 비례해 계속 자란다
speed = 70 + power * profile.speed * 0.10
// 몬스터 — 고정
speed = isBoss ? 104 : 92
```

카드 1장 10만 기준 플레이어 속도는 약 **1,470**, 몬스터는 **92** 입니다.
5장이면 팀 합계가 7,350 이라 몬스터 몫은 **1.2%** 입니다.

실측(V1812 적용 후, 덱 50만 · 나이트메어):

```
실전형   127턴 중 보스 행동  0회
공격특화  87턴 중 보스 행동  1회
```

**전투력을 올릴수록 보스는 더 안 움직입니다.** 강해질수록 보스가 허수아비가 되는
구조였습니다.

---

## 고친 방법 — 게이지와 무관한 보장 행동

말씀하신 방향 그대로입니다. 속도를 손대면 구간마다 다시 어긋나서,
**"플레이어가 15번 움직이면 보스가 한 번"** 을 게이지와 무관하게 보장했습니다.

```js
// simulateBattleV2Preview 의 ATB 루프
let actor = ready[0];
if (forcedMonsterEvery > 0) {
  if (actor.side === 'A') {
    playerStreak += 1;
    if (playerStreak >= forcedMonsterEvery) {
      const waiting = alive(b).filter(card => card.isMonster);
      if (waiting.length) { actor = waiting.sort(...)[0]; actor.gauge = 100; }
    }
  }
  if (actor.isMonster) playerStreak = 0;
}
```

`createPveBattleV2` 에서만 `forcedMonsterEvery: 15` 로 켭니다.
**기본값이 0 이라 PVP 는 건드리지 않습니다.**

### 같이 낮춘 것 — 몬스터 1회 피해

행동 횟수가 0~5회에서 10~15회로 늘었습니다. 공격력을 그대로 두면 전멸합니다.
**실측: 그대로 두면 4개 덱 구성 전부 승률 0% · 전원 사망이었습니다.**

```js
power * (isBoss ? 0.205 : 0.175)   →   power * (isBoss ? 0.0513 : 0.0438)
```

지금은 **1대에 카드 최대HP의 약 36%** — 세 대 맞으면 카드 하나가 죽습니다.
맞는 게 확실히 보이되 전멸하지는 않는 지점으로 맞췄습니다.

### PVP 는 그대로

미러전 300판, 선공 승률. 강제 행동이 PVP 로 새지 않았습니다.

```
공격특화 48% → 48%    실전형 46% → 46%    균형 51% → 49%    방어형 48% → 50%
```

## 난이도 — 저번에 남겨둔 숙제가 같이 풀렸습니다

V1812 로 난이도가 내려간 걸 몬스터 전투력 +75% 로 상쇄하자고 드렸는데,
**보스가 실제로 때리기 시작하니 대부분 자동으로 상쇄됩니다.**

"내 덱 전투력의 몇 %짜리 몬스터까지 잡히나" (실전형 · 나이트메어):

| 덱 전투력 | 원본 | V1812 | **V1813** | 원본 대비 |
|---:|---:|---:|---:|---:|
| 50,000 | 10% | 30% | **30%** | +200% |
| 150,000 | 40% | 80% | **60%** | +50% |
| 300,000 | 80% | 140% | **100%** | +25% |
| 500,000 | 120% | 220% | **120%** | **±0%** |
| 1,000,000 | 260% | 400% | **140%** | −46% |

- **50만 구간은 원본과 정확히 같습니다.**
- 저전투력은 여전히 쉬워집니다 — 4초 시뮬 클럭에 막혀 있던 게 풀린 것이라
  의도된 방향으로 봅니다 (원래 자기 전투력의 10%짜리만 잡히던 구간입니다).
- **100만 이상은 46% 어려워집니다.** 보스가 이제 실제로 때리기 때문입니다.
  원본에서 자기 전투력 260%짜리를 잡던 게 140% 로 내려옵니다.

> 그래서 **몬스터 전투력 +75% 상향은 이제 필요 없습니다.** 하시려면 저전투력
> 구간만 보시면 됩니다.

## 알아두실 것

**① 방어형(공격형 카드 0장) 극단 구성은 나이트메어를 못 깹니다.**
40판 전부 `MONSTER_SURVIVED` — 화력이 없어 4초 클럭 안에 못 잡습니다.
원본에서도 0% 였고, V1812 에서 93% 로 잠깐 올라갔다가 다시 0% 가 됐습니다.
공격형 없는 5장 구성은 실사용에서 드물어 그대로 뒀습니다.

**② 몬스터 공성전(`_siege.js`)도 `createPveBattleV2` 를 씁니다.**
같은 변경이 적용됩니다. 공성전 밸런스는 따로 확인해 주세요.

**③ 자동사냥은 영향 없습니다.** `resolveAutoBattle` 은 V2 엔진을 안 쓰고
전투력 비교로 승패를 정합니다.
