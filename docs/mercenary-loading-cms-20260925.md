## 변경

- 화면을 닫으면 대기를 즉시 종료한다. 엔진·모듈·렌더러·카드 장면은 12초, 개별 이미지·오디오는 8초, CMS 응답 전체는 20초로 제한한다. 이 시간은 각각의 로딩 단계 기준이다.
- 엔진·이미지 실패 재시도는 새 URL로 다시 요청한다. 브라우저가 정체된 같은 URL 요청을 재사용하는 상황도 검수했다. 오류 안내와 `다시 불러오기` 버튼을 제공하며 닫기·재입장이 가능하다.
- 합성 전용 이미지 로더가 중복 요청을 합치고 실패한 이미지 요청을 취소·제거한다. 재료 320px, 결과 640px WebP를 동시에 로드하고 파생본이 없으면 원본으로 제한적으로 복구한다. 공식 원본은 수정하지 않았다.
- 기존 UI PixiJS·GSAP 번들을 재사용한다. 공유 텍스처를 건드리지 않으며 합성 화면이 만든 텍스처·렌더러·타임라인은 닫을 때 정리한다. 기존 연출의 형태·시간·사운드 원음은 유지한다.
- CMS는 저장된 설정을 먼저 읽고, 해당 CMS 테이블이나 문서가 실제로 없을 때만 기존 초기화를 실행한다. 연결 오류나 잘못된 저장값은 초기화로 숨기지 않는다. 정상 용병 설정 GET은 2개, 확률 GET은 3개 SELECT만 실행한다(공통 인증 및 별도 개봉 ON/OFF API 제외).
- 빈 응답·잘린 JSON·응답 본문 정체는 복구 가능한 오류로 표시한다. 저장 결과가 불명확하면 기존 요청 ID를 보존하고 명시적 재확인으로 복구한다. 역할 변경 뒤 늦게 끝난 CMS 요청은 화면 상태를 덮어쓰지 않는다.
- CMS 상단의 고정 43종 표시는 실제 문서 수로 바꿨다. 현재 운영 로스터는 49종이다.

## 검증 및 배포 선택

- 변경은 용병 합성 준비 화면과 용병 CMS에 제한된다. 공통 DB 어댑터, 인증·권한 규칙, 공통 트랜잭션, 마이그레이션, 의존성, Wrangler 설정 변경은 없다. `npm run deploy:production -- --scoped`를 사용한다.

- 최종 범위 게이트: `tests/mercenary-loading-20260925.test.mjs`, `tests/mercenary-fusion-eight.test.mjs`, `tests/mercenary-fusion-transactions.test.mjs`, `tests/mercenary-codex-public-v2061.test.mjs`, `tests/mercenary-codex-owned-roster-v2133.test.mjs`, `check:worker`. 기존 출시 플래그·깨끗한 소스·origin/main·캐시·운영 Hyperdrive 검사도 유지한다.
