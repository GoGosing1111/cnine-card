# 조직 배정 후 현황 화면 · 지도 크기 안정화

## 사용자 요청과 변경

- 배정이 끝난 회차의 기본 화면을 모집 마감 안내에서 **조직 현황**으로 변경한다. 소속이 없는 로그인 계정도 15개 조직 목록을 먼저 본다. 기존 입단 설문·추가 모집과 OWNER 관리 기능은 해당 단계에서 유지한다.
- 조직별 문장, 소속 인원, 점령 거점 수와 지역 이름, 공동 자금, 아지트 단계를 표시한다. 점령 거점 수 순서로 정렬하고 내 조직을 별도 이미지 선택 상태로 구분한다. 현황 새로고침과 세력전 바로가기를 제공한다.
- 기존 `organization/overview`와 `organization/faction/overview`의 공개 읽기 응답을 사용한다. 다른 조직의 개인 명부·설문·평가 자료는 요청하거나 공개하지 않는다. 전황 응답 실패·회차 불일치는 미확인으로 표시하며 자금이나 점령지를 0으로 꾸미지 않는다.
- 지역 클릭·모바일 선택은 선택 정보만 변경한다. 현재 지도의 위치와 배율은 보존한다. `+`, `−`, 선택 지역 확대, 전체 보기와 마우스 드래그는 유지한다.
- 게임 → 조직 → 세력전의 중첩 iframe에서 콘텐츠 루트의 실제 높이를 올림해 전달한다. 내부 세로 스크롤바가 지도 폭에 영향을 주지 않도록 하고, 스크롤은 게임 화면이 담당한다. standalone 및 다른 출처의 임베드는 자체 스크롤을 유지한다. 관찰자와 resize 이벤트는 pagehide 시 해제한다.
- 기존 조직 배정, 시즌 ON, 운영 일정, 6거점·3천억 코인 보상, 공동 자금·승급 비용은 변경하지 않는다.
