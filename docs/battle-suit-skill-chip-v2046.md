# 배틀슈트 스킬칩 V2046

2026-09-06 사용자 승인 기준: 로켓런처 3초 / 헬기폭격 15초, 배틀슈트 일반 사격 1발 기준 별도 피해 2.5배 / 총 5배. 구현 완료. 실제 게시 커밋은 Cloudflare Pages 운영 배포 기록을 기준으로 한다.

## 장착과 피해

- 장비 화면의 아바타 바로 오른쪽에 스킬칩 탭. 계정별 최대 3슬롯, 같은 칩 중복 장착 불가.
- 512×512 투명 PNG·무손실 WebP 2종. 원본, 프롬프트, 해시를 `assets/ui/project-v/skill-chips/`에 보존한다.
- 실제 인벤토리 보유량과 활성 상태를 장착 및 전투 스냅샷에서 다시 검사한다. 장착·해제·발동으로 칩을 소모하지 않는다.
- 일반 덱은 정확히 5장, 배틀슈트는 기존 별도 지원 액터다. 장비 전투력·일반 사격·카드 행동 게이지를 바꾸지 않는다.
- 배틀슈트가 연결된 서버 PVE 전투에 적용한다. 별도 합성 전투 모드의 피해 계산은 임의 확대하지 않는다. PVP와 몬스터공성의 기존 배틀슈트 제외 규칙은 유지한다.
- 기존 배틀슈트 1발 공식을 독립 난수 스트림으로 계산한 뒤 배율을 한 번 적용한다. 기존 방어·회피·치명타·아포칼립스 관통 규칙을 유지한다.
- 로켓은 발사 360ms 뒤 1회. 헬기는 610/830/1050/1270ms 뒤 4회로 **합계 5배**를 나눠 적용한다. 정수 나머지는 앞 타격부터 분배한다. 사망·전투 종료 후 추가 피해는 없다.
- `damageBreakdown.battleSuit`는 기존 일반 사격, `damageBreakdown.skillChips`는 실제 칩 피해다. 지원 액터 기여도와 전체 피해에는 둘의 합계를 반영한다.
- 신규 자동 지급·상점·획득 확률은 추가하지 않는다. 인벤토리에서는 소모형 사용 버튼 대신 장비 탭 장착 안내를 표시한다.

## 전투 시간 계약

`V3_COMBAT_MS_V1`은 기존 V3 기본 재생 속도에서의 전투 밀리초다. 기존 서버 `at`/게이지 시계는 초 단위가 아니므로 3/15를 직접 넣지 않는다. 카드 행동은 기존 서버의 원자적 행동 단위로 계산하며, V3 애니메이션 길이만큼 다음 행동 시작 시각을 배정한다. 일반 사격은 기존 독립 게이지 간격을 유지한다.

서버가 `combatAtMs`, `combatGroup`, `combatGroupDurationMs`, `SKILL_CHIP_CAST`, `SKILL_CHIP_HIT`를 확정한다. 클라이언트는 피해나 발동 횟수를 계산하지 않는다. 배속은 하나의 전투 시계를 배율 재생할 뿐 결과를 바꾸지 않는다. 느린 애니메이션·입력 기믹·궁극기 영상 대기에서는 시계와 칩 소리를 함께 정지한다. Core 레이드가 삽입하는 QTE와 성공/실패 분기는 원래 이벤트 순서에서 처리한다.

새 전투마다 스케줄과 재생 컨트롤러를 새로 만든다. 첫 로켓은 3초, 첫 헬기는 15초다. 초기화되는 것은 발동 대기시간뿐이며 보유량·장착 상태는 유지한다. 종료·창 닫기·세션 교체는 시계·음원·이펙트를 정리하고 늦게 끝난 자산 로딩도 재생하지 않는다. 발동이 없는 짧은 전투는 칩 자산을 로드하지 않는다.

## 렌더링과 사운드

기존 V3 엔진·진형·하단 카드 도크·프레임·아트 어댑터를 재사용한다. 승인된 `SkillChipFX`와 실제 녹음 기반 `SkillChipAudio`를 함께 번들링하며 Pixi/GSAP을 이중 로드하지 않는다. 로켓 투사체는 기존 대상 Y−62 궤적, 폭발과 지면광은 대상 발끝 `SOLE_CENTER`를 유지한다.

칩당 한 이펙트 풀만 유지한다. 로켓과 헬기 동시 발동 시 다른 칩 음원을 중단하지 않는다. 녹음 원음 충돌 피크와 출력 지연 보정은 승인 프리뷰와 동일하다. 장치의 실제 물리적 출력 오차는 청음/루프백 검수 대상이다. 절차적 합성음은 사용하지 않는다.

서버 이벤트 순번별 최신 HP/실드를 기억해 늦게 도착한 일반 사격·카드 충돌이 과거 체력으로 되돌리지 못하게 한다. 더 나중에 발생한 회복은 정상 반영한다.

## 데이터와 확장

단일 카탈로그는 `shared/battle-suit-skill-chips.mjs`다. 신규 스킬은 코드·주기·배율·충돌 오프셋·이펙트 키, 시각/음원 구현과 회귀 테스트를 추가한다. 이미 설치된 카탈로그에 추가할 때는 마이그레이션 키도 갱신한다.

장착 테이블 `user_skill_chip_loadout_v2046`: `(user_id,slot_no)` 기본 키, `(user_id,item_code)` 유일성, 1~3 슬롯 CHECK. 장착은 같은 INSERT에서 소유권을 확인한다. 해제는 사용자·슬롯·기존 코드가 일치해야 적용된다. PostgreSQL 고정 DDL은 `execSchema`를 사용한다. 기존 CMS 설정·보유량은 덮어쓰지 않는다.

API: `GET character/skill-chips`, `POST character/skill-chips/equip`, `POST character/skill-chips/unequip`. 변경 본문은 `{slot:1,code:'SKILL_CHIP_ROCKET_LAUNCHER'}`. 클라이언트는 성공 응답의 최종 상태를 사용한다.
