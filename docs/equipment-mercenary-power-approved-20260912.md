## 장비 강화

원래 장비의 총 전투력에 아래 누적 증가율을 적용한다. 무기·상의·하의·신발·장신구 공통이며 최초 최대 단계는 +10이다. 배틀슈트는 기존 별도 PVE 전력으로 유지한다.

| 단계 | 기본 대비 누적 증가 | 최종 배율 | 해당 단계 상승분 / 기본 전투력 |
|---|---:|---:|---:|
| +0 | 0% | 1.00배 | — |
| +1 | +6% | 1.06배 | +6% |
| +2 | +12% | 1.12배 | +6% |
| +3 | +18% | 1.18배 | +6% |
| +4 | +24% | 1.24배 | +6% |
| +5 | +30% | 1.30배 | +6% |
| +6 | +36% | 1.36배 | +6% |
| +7 | +42% | 1.42배 | +6% |
| +8 | +48% | 1.48배 | +6% |
| **+9** | **+80%** | **1.80배** | **+32%** |
| **+10** | **+120%** | **2.20배** | **+40%** |

`최종 총 전투력 = floor(기본 총 전투력 × (100 + 누적 증가율) / 100)`.
`PVE = floor(최종 총 전투력 × 0.9)`, `PVP = 최종 총 전투력 - PVE`.
각 단계의 증가율은 기본 전투력에 적용한다. 카탈로그 기본값을 덮어쓰거나 직전 단계의 최종 전투력에 다시 누적 곱하지 않는다.

기본 100,000인 엠퍼러 장비 1개는 +8 148,000 → +9 180,000 → +10 220,000이다. +10의 PVE는 198,000, PVP는 22,000이다. 동방무기상 무기 1개(180,000)는 +10에 총 396,000, PVE 356,400, PVP 39,600이다.

2026-09-12 장비 목록의 최고 기본 조합인 동방무기상 무기 1개 + 엠퍼러 상의·하의·신발·장신구 4개를 전부 +10으로 강화하면 총 1,276,000 / PVE 1,148,400 / PVP 127,600이다. 이는 장비 합계이며 덱에 한 번만 반영한다.

프리뷰 V2의 UI·연출 승인 원본과 시연 모델은 보존한다. 승인된 실제 전투력 기준은 출시 초안 `policy.powerScaling`에 기록하고 CMS와 공개 상태 API에 제공한다. 이 기록으로 실제 장비 단계·계정 전투력·재료가 변경되지는 않는다.

## 용병

획득 직후, **레벨 성장·장비·스킬·시너지·일시 버프 적용 전 용병 자체 전투력**이다. HP·공격력 입력값으로 그대로 사용하는 수치가 아니다.

| 등급 | 기본 전투력 |
|---|---:|
| C | 10,000 |
| B | 20,000 |
| A | 40,000 |
| S | 70,000 |
| SS | 120,000 |
| SSS | 180,000 |

오메가-X(V-021)는 기존 사용자 지정 SSS를 유지한다. 다른 용병의 저장된 등급·스킬 배정은 재배정하거나 초기화하지 않는다. CMS에서 선택된 등급을 위 표에 대응해 기준 전투력을 표시한다. 이 표는 서버의 승인 기준으로 제공하며 개별 편집 문서의 능력치·성장 필드를 임의로 채우지 않는다.

비교 기준은 2026-09-12 19:25 KST 운영 전투 설정과 배포 코드 `11e80768`로 확인했다. 슈퍼스타 자체 전투력은 +10 40,250 / +11 58,000 / +12 74,000 / +13 93,200이다. 슈퍼스타는 같은 단계의 일반 FUR·ZENITH 중 높은 전투력에 10,000을 더하며, 운영 DB의 고급 강화 표가 비어 있어 서버 기본 고급 강화 표를 사용한다. SS 120,000은 슈퍼스타 +13보다 약 28.8% 높다. SSS 180,000은 SS보다 50% 높다. 이후 슈퍼스타 설정이 바뀌면 비교를 다시 검수하며 용병 수치를 자동 연동하지 않는다.

일반 카드 5장 + 선택적 용병 1슬롯을 유지한다. 용병 전투력은 별도 항목으로 최종 전력에 한 번 합산하며 장비 보너스를 용병에 중복 복제하지 않는다. 역할별 능력치 환산·성장 상한·성장량·스킬 계수는 이 기준을 출발점으로 설계하고 검수한다.

## 남은 출시 조건

전투력 기준 승인은 전체 경제 정책이나 실제 실행 승인과 구분한다. 장비 성공·유지·파괴 확률, 비용, 보호권 획득량·소모, 복구 정책과 원자적 서버 처리는 준비 중이다. 성공률 10% 하한·보호권 게임 내 극희귀 획득·상자 제외는 유지한다. 용병 성장·획득·능력치 환산과 실전 검수도 별도로 진행한다.

CMS에는 승인 기준을 공개하되 기존 운영 편집 문서와 사용자 재화·장비·덱은 보존한다. V3 공동 출시 조건과 `FORGE_EXECUTION_IMPLEMENTED=false`, 용병 `runtimeEnabled=false`를 유지한다. 전체 경제 정책이 미정이므로 장비 출시 초안의 `policyApproved=false`도 그대로 둔다.

CMS 표시 배포는 기존 선공개 승인 범위다. 운영 반영은 범위 커밋 후 `npm run deploy:production`의 필수 `release:gate`를 거치며, CMS PC·모바일에서 등급별 기준·상승표·OFF 상태·저장 호환성을 검수한다.
