# 세력전 점령 보호·재공격 대기 단축

## 사용자 확정

- 점령 보호: 2시간 → **20분**.
- 같은 클랜의 같은 지역 재공격 대기: 30분 → **15분**.
- 공격대별 재출정 10분, 개인 재교전 1분, 교전 제한 30분은 그대로 유지한다.
- 전투 종료/무방비 점령 시점부터 계산하며, 대기 종료 시각과 같아지면 서버가 허용한다.

## 기존 시즌 적용

- 상태의 `cooldownVersion: 2`로 기존 마감 시각을 한 번만 단축한다. 보호는 100분, 같은 지역 재공격은 15분을 기존 마감 시각에서 뺀다.
- 새 기준상 이미 지난 대기는 즉시 해제되며, 점령지·소유 클랜·편성·지휘관·전황·보상·계정 재화는 초기화하지 않는다.
- 회차 동기화에서 ACTIVE/PAUSED 상태 모두 기존 revision 비교 및 거래 안에서 저장한다. 실패하면 이전 상태를 유지하며, 재시도·동시 호출로 중복 단축하지 않는다.
- 신규 상태와 신규 교전 종료는 처음부터 새 시간으로 저장한다. 신규 마감 시각에는 과거 시간의 차이를 다시 빼지 않는다.
- 영토전 중단 전에 남았던 시간을 기준으로 재개 시 중단 시간을 보전한다. 이미 보전된 중단 시간도 유지하며, 종료된 대기를 재개 때 되살리지 않는다.
- 정규 클랜전·영토전, 하루 2회/회차 3시간, KEEP/PARTICIPANTS/PAUSE/DEFER 정책과 300억 메시지 보상은 변경하지 않는다.

## 화면·캐시

- 상세 안내와 무방비 점령 성공 알림은 서버 `rules`의 시간을 표시한다.
- 메인 앱·클랜 진입의 모듈 주소와 공유 규칙 캐시 키를 `20260922-cooldowns`로 갱신한다.
- 주소 및 PWA 설치는 유지한다. 오래 열어 둔 화면은 새로고침하면 새 안내가 표시된다.

## 검증·배포

- SQLite/PostgreSQL 61개 관련 테스트 통과: 20분/15분 경계, 신규 점령·패배·시간 초과, 기존 상태 전환, 멱등성, 실패 롤백, 중단/재개, 편성 및 보상 보존.
- 브라우저 검증 76개 통과(1600×1080, 1440×560, 768×1024, 390×844, 320×740). 20분/10분/15분 안내, 편성, 지도, 전투실과 화면 넘침을 확인했다.
- 실제 메인 메뉴 → 세력전 → 공용 V3 전투 → 결과 → 복귀를 PC 1440px·모바일 390px에서 확인했다. 브라우저 오류 0건, 안내 포함 8개 검사 통과. 모든 교전은 합성 로컬 DB에서 실행했다.
- 운영 반영은 깨끗한 범위 커밋 및 최신 main 통합 후 `npm run release:gate`, `npm run deploy:production` 경로만 사용한다. Pages와 회차 워커가 동일한 규칙을 사용하도록 함께 배포한다.
- Hyperdrive 쿼리 캐시 OFF, 기존 Neon 연결 계정과 DB를 유지한다.
- 되돌림이 필요하면 새 운영 변경으로 처리한다. 이전 `state_json` 전체를 덮어써 점령·전투·보상을 되돌리거나 `cooldownVersion`을 제거하지 않는다.

## 유저 안내 문구

세력전의 점령 보호 시간이 20분, 같은 지역 재공격 대기시간이 15분으로 단축됩니다. 기존에 적용 중이던 대기시간도 새 기준에 맞춰 단축되며, 이미 새 대기시간을 넘긴 경우 해제됩니다. 공격대 재출정 대기 10분과 개인 재교전 대기 1분은 유지됩니다. 점령지와 부대 편성은 초기화되지 않습니다.
