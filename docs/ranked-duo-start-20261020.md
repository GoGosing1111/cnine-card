# 랭크 듀오 시작 버튼 · 2026-10-20

사용자 첨부 화면에는 상시 매칭 전환 뒤에도 ‘시즌 참가하기’가 표시됐다. 전환 전 배포 `974382226`의 실제 화면 모듈과 첫 경기 전 `joined:false` 응답을 조합해 같은 증상을 재현했다. 최신 모듈만 검수했던 이전 검증은 이미 열린 탭의 구버전 화면을 다루지 못했다.

상시 매칭 상태는 구버전 화면에서도 모집 없이 출전하도록 `joined:true`를 반환한다. 실제 개인 기록 유무는 `hasSeasonRecord`로 구분한다. 조회만으로 참가 행·점수·재화를 만들지 않고, 첫 매칭 때 요청자의 개인 기록만 생성하는 기존 처리를 유지한다. 과거 모집 시즌은 실제 참가 여부를 계속 반환한다.

최신 화면의 버튼명을 ‘랭크 듀오 시작’으로 바꾸고 앱·모듈·서비스 워커의 캐시 버전을 갱신했다. 구버전 화면은 화면 안 새로고침으로 ‘랜덤 매칭 · 바로 출전’을 표시하며, 일반 새로고침 후에는 최신 이름을 표시한다. 기존 전용 ImageGen 버튼·프레임은 유지한다.

첨부 계정 핑크빛유두는 OWNER다. 기존 OWNER 참가 제외 정책은 이번 버튼 수정으로 변경하지 않는다. 운영 계정으로 실제 교전하거나 보상을 지급하지 않았다.
