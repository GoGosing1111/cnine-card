# 헬리오스 성능 · 행동 · 모션 조정 — 2026-10-12

사용자 요청: 발테르와 동급을 기준으로 3~5% 위의 최상위 성능. 중앙값 4%를 적용했다. 전투 수치 미정이었던 헬리오스(V-999)를 정규 서버 전투 빌더와 피해 처리에 연결하되, 기존 획득·편성 잠금과 모션 시각 승인 대기는 유지한다.

| 기본 전투력 | 1,080,000 | 1,123,200 (+4%) |
| 무장 없는 자연 행동 속도 | 84,450 | 87,828 (+4%) |

공격력 연계까지 중복 4% 증가시키지 않고 추가 행동으로 공격 우위를 준다. 동일 장비가 강해져도 자연 속도 4% 차이가 희석되지 않도록 발테르의 기본 전투력과 같은 장비로 속도 기준을 계산한다. 실제 승률은 덱·전투력·난수에 따라 달라지며 53~55%로 고정하는 구현이 아니다.

발테르와 같은 약화·독·제압·방어력 감소·근접 패링 대응과 베르칸 피해 면역을 헬리오스 개인에게 적용한다. 다른 아군과 일반 용병의 정책은 그대로다.

## 스킬과 모션

- PVE **천양붕락**: 총 560% 예산을 살아 있는 적 전체에 나누어 대상별 1회 판정. 에너지 35, 시전자 5행동 재사용. 중복 대상·사망 대상·슈트는 제외하며 연출의 소환검/충격파가 서버 피해를 추가하지 않는다.
- PVP는 발테르와 같은 기본 공격 정책. 별도의 광역기 발동이나 승자 덮어쓰기가 없다.
- 추가 행동의 소수점 잔량을 보존한다. 기존 정수 상한 4에 4.08을 잘라 누적 행동을 잃지 않도록 헬리오스만 상한과 소수점 정밀도를 보완했다. 1,000회 카드 행동에 정확히 3,120회, 듀오는 해당 소유자만 적립한다. 헬리오스가 있는 진영의 장기전 안전 상한도 확장한다.
- SolarFX의 기존 단일 GSAP 시간축에 2.6배를 적용한다. 자세·적중·귀환·이펙트 전체를 함께 재생하고 대기 오라는 1배 유지한다. 원본 이미지와 무기 픽셀, 시트는 수정하지 않았다. 기존 서로 다른 원본 연출의 총 길이를 발테르와 같게 만들지는 않는다.
- 기본 베기 0.654초, 검진 1.654초, 궁극기 2.231초. 원본 시간 탐색 기능을 보존하고 화면 시간 표시는 실제 재생 시간으로 변경했다.

## 검증

- 신규 서버 정책/주기/듀오/장기전/면역/광역 예산/에너지·쿨다운/실제 페이로드 9건 통과.
- 기존 발테르 행동력 5건, 헬리오스 등록·원화 해시·경제 설정 보존·계정 편성 차단 4건 통과.
- 등록 검사 파일의 마지막 전체 HTML 비교 1건은 기존 체크인 HTML과 생성 함수의 캐시 태그 및 Windows 줄바꿈 차이로 실패한다. 해당 HTML과 생성 함수는 이번 작업에서 변경하지 않았고 HEAD와 동일함을 확인했다. 도감 실제 PC/모바일 화면과 신규 성능 문구는 별도로 검수했다.
- 운영 공개 도감 HTTP 200, CMS revision 61, 일반 55종과 리미티드 9종을 확인했다. 비교 fixture도 revision 61이다. 기존 출시 63종(일반 55 + 리미티드 8), 4개 덱, 3개 전투력 구간, 양 진영을 정규 서버로 **6,720회** 비교했다. 모든 상대에 종합 우세, 발테르 상대 **477승 291패 / 768회 (62.109375%)**. 2천만·10억 전투력 구간의 발테르전은 덱별 51.5625~57.8125%다. 과거 통제 전투 기록이며 운영 계정 승률을 측정하지 않았다.
- 동일 조건 PVE도 두 용병 각각 96회, 총 192회 확인했다. 원본 결과는 `docs/qa/helios-supremacy-20261012/comparison.json`.
- 실제 SolarFX 번들 및 도감 화면을 PC 1440×1050·모바일 390×844로 확인했다. 4개 모드 모두 실제 재생 속도·시간, 기본 검 적중, 광역 5대상, 재생 종료/중단 정리, 2배속 조절, 원본 몸 비율, 획득·편성 잠금, 가로 넘침 없음, 브라우저 오류 0. `browser.json` 및 PNG 6장에 보존했다.
- 공용 빌더로 파생 번들을 동기화했다. 실제로 전투 정책을 포함하는 idle/전장 확장 프리뷰와 SolarFX 검수 번들이 변경됐고 메인 V3 전투 표시 번들은 동일하다. 바뀐 프리뷰 참조 URL에 `20261012-helios-performance1`을 추가했다.

## 공개 상태 및 배포 범위

성능 정책·공개 도감 안내·빨라진 모션 검수본을 배포한다. 헬리오스는 `AGENTS.md`의 2026-10-09 등록 지시에 따라 현재 선공개 상태로서 획득/편성 및 모션 최종 시각 승인은 별도다. `heliosPreparedSnapshot`은 비교용이며 계정 편성 서비스에서 가져오지 않는다. 공개 도감의 `deploymentEnabled=false`, 저장 확률·가중치·발행 한도, 기존 8종 편성 및 출시 상태를 유지한다.

한 용병 정책 변경으로 인증·DB·거래·의존성 구조를 변경하지 않았다. `npm run deploy:production -- --scoped`를 사용한다. 최종 배포에서는 공통 전투/행동 주기, Valter PVE 광역, 파생 번들 일치 및 Worker 컴파일만 추가 확인하며 이미 통과한 비교·브라우저 검수는 반복하지 않는다.

배포 준비 시 확인한 직전 운영: Pages `8073e96f-618e-4b83-b676-4356d3799dd5`, 소스 `17970563` (다른 작업의 장비 UI 배포). 최신 main을 통합한 뒤 정확한 40자리 배포 기준을 지정한다.
