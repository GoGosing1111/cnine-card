# 군단토벌 공개 · 코인 시간 분산 · 공통 전투 안내

사용자 2026-10-18 지시: 장비 확률을 절반 더 올리고 ON, 전투를 가리는 큰 펫 효과창을 작은 사이드 버프 아이콘으로 변경, 멘트 바깥 검은 줄 제거. 후속 요청은 코인 낙하 연출과 너무 빠른 상한 도달 개선이다.

## 동작

- 신규 5지역과 용병장비 30종의 지역 획득을 공개한다. 기존 양수 0.001%는 0.0015%로, 기존 0%는 유지한다. 보스 세트/고유는 독립 추첨, 세트는 5부위 중 1개다. CMS는 장비 확률만 0.0001% 단위까지 저장한다. 연마석 확률·장비 능력치·일반 공급 풀은 유지한다.
- ON 작업은 `scripts/ops/legion-equipment-enable-20261018.mjs`의 별도 1회 영수증으로 기록한다. 지역 정책과 30종 공개 플래그를 같은 거래로 적용하며 재실행은 추가 상향하지 않는다. 일반 뽑기 공급은 OFF, 개인 지급은 0건이다. 실제 운영 데이터로 dry-run/rollback 확인 완료.
- 코인 상한은 그대로다. 새 원정의 누적 지급액은 기존 처치 가중치/보너스 계산과 `상한 × 마지막 확인 처치 시간 / 일반 몬스터 토벌 시간` 중 작은 값이다. 최종 보스가 나오는 구간까지 나누어 수급한다. 보너스도 시간별 예산을 초과하지 못하고, 처치 없이 기다리거나 클리어만 해서는 추가 지급하지 않는다. 진행 중인 revision 1 원정은 기존 계약을 유지하며 다음 원정부터 revision 2를 사용한다.
- 서버 지급 확인 후 처치 위치에서 기존 통화 이미지 `assets/ui/icon-fusion-20261004/coin.webp`가 튀어 떨어졌다가 아군/펫으로 흡수된다. 전투 속도·일시정지·동작 줄이기를 따르며 백그라운드 추격 재생, 중복 응답, 상한 이후에는 새 코인 연출을 만들지 않는다. 최대 동시 4묶음, 묶음당 3개로 제한한다.
- 공통 V3 펫 안내는 28px 버프 아이콘만 표시한다. PC 36px / 터치 44px 조작 영역, hover/focus/tap 상세, Escape·바깥 터치 닫기를 제공한다. 복합 효과는 하나의 대표 아이콘에서 전체 효과를 확인한다. 실제 펫 능력과 서버 적용 대상·횟수는 유지한다.
- 리미티드 승인 프레임과 원화는 보존한다. 프레임 바깥 배경과 전장 밀림을 제거해 전투 배경이 이어지며 캐릭터 배치는 대사 아래 안전 영역을 사용한다. 공통 작은 스킬 알림의 검은 바탕도 제거한다.
