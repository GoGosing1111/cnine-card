## 표시 오류와 수정

실제 V3 페이로드의 최초 카드 최대 HP는 시작 버프 이전 +14 154,294, +15 236,405다. 서버의 편성 다양성·생명 연결 적용 후에는 187,375와 287,090이 되지만 기존 클라이언트 `serverMaxHp`는 최초 값에 고정됐다. +15가 실제 HP 10%를 잃어 258,381이 되어도 258,381 / 236,405가 100%를 넘어 HP바가 여전히 가득 차게 된다. 버프 전후 차이 때문에 실제 최대 HP의 약 17.65%가 줄기 전까지 피해를 작게 보일 수 있었다.

- `eventHpPercent`가 서버 이벤트의 `targetMaxHp`/`maxHp`를 받아 기준을 갱신한다. 시작 오라, 피해·회복, 광역 대상별 이벤트와 최종 상태에 적용한다.
- 별도 스킬칩 재생의 HP 스냅샷도 같은 최대 HP를 사용하며 오래된 순번으로 최대 HP를 되돌리지 않는다.
- 서버 전투력·피해·체력·보호막·승패와 기존 FUR 조정 설정은 바꾸지 않는다. 변경은 표시 비율 계산에 한정한다.
- 런타임 `20261002-hp-sync-v1`로 공통 번들, 메인 로더와 라이브 브리지를 맞추고 셸 캐시를 갱신한다. 공통 엔진을 사용하는 10개 번들과 빌드 기록을 재생성한다.
