# 마법카드 시즌 2 설계 기록

- 기록일: 2026-09-06
- 상태: `DESIGN_RECORDED_IMPLEMENTATION_PENDING`
- 사용자 지시: 기존 마법카드와 능력은 유지하고, 나중에 별도 지시가 오면 S2 신규 마법카드 제작을 바로 시작한다.
- 현재 범위: 설계 기록만 저장한다. 기능 코드, 운영 DB, CMS 설정, 뽑기 풀과 라이브 배포는 변경하지 않는다.

## 목표

1. 현재 S1 마법카드와 보유·강화·장착 상태를 그대로 보존한다.
2. S2는 기존 효과의 단순 수치 상위호환이 아니라 새로운 발동 규칙과 전투 상호작용을 사용한다.
3. S2는 체감상 S1보다 좋게 만들되 S1 전체를 무의미하게 만들 정도의 급격한 파워 인플레이션은 막는다.
4. S1과 S2를 혼합 편성할 수 있게 하되 생존 효과와 피해 증폭 효과의 무한 연쇄를 차단한다.
5. 아포칼립스에서는 기존 배틀슈트 필수 게이트와 마법 추가 피해 상한을 유지한다.

## 현재 S1 기준

현재 서버가 허용하는 마법 효과는 다음 14종이다.

| 분류 | 효과 코드 | 현재 의미 |
| --- | --- | --- |
| 전투 시작 | `OPENING_ATTACK` | 장착 캐릭터 공격력 증가 |

| 피격 후 | `ARCANE_COUNTER` | 공격력 비례 반격 피해 |
| 공격 후 | `FOLLOWUP_HASTE` | 행동 게이지 충전 |
| 공격 후 | `ARCANE_SEAL` | 상대의 다음 마법 발동 봉인 |

현재 강화는 효과 수치가 아니라 발동률을 올린다. 기본 운영 곡선은 `+0~+9 = 0, 5, 10, 15, 20, 25, 30, 35, 40, 50%`다. 따라서 S2까지 이 방식을 그대로 쓰면 +0 신규 카드가 전투에서 전혀 작동하지 않고, 기존 효과와 다른 시즌 체감도 만들기 어렵다.

## S2 권장 방향

S1은 현재 확률 발동 구조를 그대로 유지한다. S2는 조건을 충족하면 확정 발동하는 `조건·규칙형`으로 분리한다.

- S2 카드는 +0부터 기본 효과가 작동한다.
- 강화는 발동 확률보다 효과 수치, 대상 수, 저장량, 지속 타수 또는 복제 효율을 올린다.
- 카드별 10단계 성장표를 사용하며 +9의 최종 효과는 +0 대비 약 25~30% 높은 수준을 1차 기준으로 삼는다.
- 단일 카드가 무조건 승패를 결정하지 않도록 발동 횟수와 팀 단위 누적량을 제한한다.

## 반드시 피할 S2 효과

다음은 새 시즌 효과로 만들지 않는다. S1의 단순 상위 수치가 되어 기존 카드를 사실상 폐기하기 때문이다.

- 전투 시작 공격력 증가량만 높인 카드
- 시작 보호막 또는 최대 HP 비율만 높인 카드
- 위기 회복량만 높인 카드
- 더 높은 비율의 즉시 반격 또는 즉시 추가타
- 행동 게이지 증가·감소량만 높인 카드
- 더 많은 HP로 부활하는 카드
- 보호막 강탈 비율만 높인 카드

## 시즌과 뽑기 구조

현재는 모든 활성 마법카드를 하나의 공용 풀에서 `draw_weight`로 추첨한다. S2를 그대로 추가하면 S1과 S2가 한 풀에 섞이고 기존 카드 획득률만 희석되므로 다음 구조로 분리한다.

1. 기존 모든 카드에 `season_code = 'S1'`을 무손실로 지정한다.
2. 신규 카드에는 `season_code = 'S2'`를 지정한다.
3. `is_active`는 보유 카드의 전투 사용 가능 여부로 유지한다.
4. 뽑기 노출과 가중치는 별도 풀·엔트리 테이블에서 관리한다.
5. S1 상시 풀과 S2 시즌 픽업 풀을 분리하며, S1 카드의 보유·강화·장착 데이터는 이전하지 않는다.
6. 같은 카드가 한 덱에 한 장만 장착되는 현재 규칙은 유지한다.

권장 데이터 항목:

- `season_code`
- `effect_family`
- `activation_model`
- `effect_params_json`
- 카드별 `level_curve_json`
- 별도 마법카드 뽑기 풀과 풀 엔트리

## 전투 판정 규칙

### 생존 효과 우선순위

치명 피해 관련 효과가 중첩될 때 무한 생존이 발생하지 않도록 공용 생존 예산을 둔다.

1. 보호막과 일반 피해 감소
2. `운명의 대리` 피해 이전
3. 카드 전직 생존·불멸 판정
4. `불사조의 계약` 부활

같은 피해에서 여러 단계가 동시에 반복되지 않게 하고, 서버 타임라인에 소비된 생존 효과와 차단 사유를 기록한다.

### 회복과 보호막

`생명 연성진`은 기존 팀 회복 총량을 우회하지 않는다. 먼저 회복 풀을 소비한 실제 요청 회복량과 실제 적용 회복량의 차이만 초과 회복으로 인정한다.

### 아포칼립스

- 월식 추가 피해와 붕괴 장부 폭발은 기존 `apocalypseMagicCap`을 적용한다.
- 인과 절단의 보호막 관통은 배틀슈트 전용 아포칼립스 관통을 대체하지 못하게 별도 상한을 둔다.
- 마법카드만으로 아포칼립스 배틀슈트 필수 조건을 우회할 수 없어야 한다.

### 복제 방지

`만상 거울`은 다음 효과를 복제하지 않는다.

- `PHOENIX_REVIVE`
- `S2_FATE_INTERCEPT`
- `S2_ARCANE_MIRROR`
- 모든 전투 시작 효과
- 이미 복제된 효과

복제 이벤트에는 원본 카드 ID와 원본 소유자를 기록하고 재귀 발동을 차단한다.

## 클라이언트와 연출 요구사항

S2는 기존 네 가지 범용 색상 효과만 재사용하지 않고 대표 카드별 식별 가능한 연출을 만든다.

- 월식의 예언서: 적 위에 월식 표식과 남은 타수 표시
- 인과 절단: 세 번째 공격 예고, 수평 절단선과 보호막 관통 표현
- 운명의 대리: 치명 피해 연결선과 피해 이전 방향 표시
- 생명 연성진: 초과 회복이 보호막으로 굳어지는 변환 표현
- 성좌 전환: V3 전열·후열 실제 위치 교대 애니메이션
- 붕괴 장부: 보호막 피해 축적 게이지와 파괴 폭발
- 별의 유언: 사망 캐릭터에서 생존 아군으로 퍼지는 성광
- 만상 거울: 원본 카드 색상을 반전시킨 복제 연출

모든 판정은 서버 타임라인이 권위이며, 클라이언트는 결과를 재계산하지 않고 재생만 한다.

## 밸런스 승인 기준

- 동일 전투력·동일 강화 수준에서 S2 5장 덱 대 S1 5장 덱 목표 승률: 55~60%
- 단일 S2 카드 교체로 중립 PVP 매치업 승률 변동: 최대 약 8%p
- 적합한 PVE 매치업의 클리어 시간 또는 생존 기대치 개선: 약 8~15%
- 특정 효과 1장으로 아포칼립스 배틀슈트 게이트 우회: 0건
- 부활·전직·대리 중첩으로 동일 피해에서 생존 효과 2회 이상 소비: 0건
- 거울 복제 재귀 및 무한 발동: 0건

최종 수치는 최소 다중 시드 PVE·PVP 시뮬레이션 후 확정한다.

## 구현 시작 시 작업 순서

1. S1 운영 데이터와 카드별 수치의 읽기 전용 스냅샷을 생성한다.
2. 시즌·효과 파라미터·뽑기 풀 스키마를 무손실 마이그레이션으로 추가한다.
3. 서버의 마법카드 허용 목록과 정규화 계약을 S2까지 확장한다.
4. S2 조건형 발동 관리자와 공용 생존 예산·복제 방지 규칙을 전투 엔진에 구현한다.
5. CMS에 시즌 풀 및 카드별 성장표 편집기를 추가한다.
6. 라이브 V2와 PROJECT V V3 렌더러에 S2 이벤트를 연결한다.
7. S1 회귀 테스트를 먼저 고정한 뒤 S2 카드별 단위 테스트와 조합 테스트를 추가한다.
8. 독립 프리뷰에서 카드별 판정·수치·연출을 검수한다.
9. 사용자 승인 전에는 S2 카드와 S2 뽑기 풀을 라이브 활성화하지 않는다.
