# 챔피언스리그 트로피·명함 디자인 · v2109

2026-09-14 사용자 요청: 챔피언스리그 트로피를 새로 제작하고 명함의 트로피 디자인에도 반영한다.

## 디자인과 연결

- 챔피언스리그 전용 백금 컵, 상승하는 양쪽 손잡이, 금빛 테두리, 푸른 크리스털, 흑요석 받침을 내장 `image_gen`으로 제작했다. 외부 이미지나 실존 대회 로고를 사용하지 않았다.
- 원본은 `assets/ui/player-card/champions-league-v2109.png`의 1254×1254 RGBA PNG다. 생성 원본을 수정 없이 보존하고, 운영용 512×512 투명 WebP만 별도로 내보냈다. WebP는 68,600바이트다.
- 전체 생성 프롬프트는 `assets/ui/player-card/prompts-v2109.json`, 파일 해시·규격·사용 위치는 `assets/ui/player-card/manifest-v2109.json`에 보관한다.
- 클랜 본부의 챔스 배너와 챔피언스리그 대진표 상단이 새 트로피를 사용한다. 기존 평면 컵 아이콘을 교체하고, 대회 화면에는 원화를 크게 보여준다.
- 명함은 챔스 트로피와 우승 횟수·달성일을 하나의 전용 진열 영역에 표시한다. PC에서는 챔스 트로피 옆에 기존 3종을 진열하고 모바일에서는 챔스 가로 진열 아래에 기존 3종을 둔다.
- 미획득은 회색 실루엣·미획득 문구로 구별한다. 시각 순서를 바꾸더라도 서버 배열의 원래 인덱스를 유지하므로 각 버튼은 해당 트로피의 획득 조건을 연다.

## 기록·범위 보존

- `CLAN_CHAMPIONS_TROPHY` 카탈로그의 `art`·`tone`만 바꾼다. 일반 시즌 `CLAN_CHAMPION`은 기존 황금 트로피를 계속 사용한다.
- 공식 수상 조건, 우승 횟수, 수상 영수증, 재화·아바타 지급, 대진·경기 일정은 변경하지 않는다. 운영 DB 수정은 없다.
- 트로피 효과와 명함 강화의 비활성 상태, 아바타 조회 조건, 개인정보 제한, 모달 취소·오류 복구·키보드 동작을 유지한다. 기존 PixiJS·GSAP 장식 런타임을 그대로 사용한다.
- 수정한 JS/CSS의 실제 게임 및 독립 프리뷰 URL을 `2109-champions-trophy`로 갱신했다. 변경하지 않은 공통 로비 번들의 캐시는 유지한다. 문서 탐색은 기존 서비스워커에서 네트워크를 우선한다.
