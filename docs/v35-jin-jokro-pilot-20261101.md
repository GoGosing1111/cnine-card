## 첫 제작 범위

첫 묶음은 **대기 + 기본 베기 + 대표 스킬 1개**다. 완성 용병 전체를 양산하기 전에 얼굴·체형·파지·몸의 연결과 강한 기술의 품질을 검증한다.

| 동작 | 설계 | 먼저 확인할 부분 |
| --- | --- | --- |
| idle | 오른쪽을 향한 측면 자세. 몸을 바르게 세우고 팔을 내려 칼끝이 아래로 향한다. 호흡·천 움직임은 절제한다 | 발 접지, 손 위치, 검신의 정상 곡률, 루프 경계 |
| attack_basic | 디딤과 골반 회전 → 몸통·어깨 선행 → 빠른 베기 → 무게가 이어지는 회수 → 대기 | 손 이탈·팔 비틀림·칼끝의 지면 관통 없이 이펙트 OFF에서도 읽히는 검술 |
| skill_signature_01 | 시험용 큰 사선베기: 준비 자세 → 체중을 실은 베기 → 접촉 파열과 검압 → 지면 반응·잔향 → 회수 | 교체 공격 자세/스미어 필요성, 타격 정지·반동, 몸·검광·접촉·지면의 동기 |

동작 ID와 대표 스킬 구성은 시험용이다. 정식 스킬명·피해·타수·쿨타임·등급을 확정하는 값이 아니다. 초안 타이밍은 준비·접촉·회수의 실제 재생을 보고 조정하고, 실제 전투 연동 시 서버 이벤트 계약에 맞춘다.

## 제작 순서

1. V7 원본·무기 해시와 승인 범위를 고정하고 얼굴·갑주·검·망토 정체성을 비교한다. 기존 측면 작화를 유지하며 V4 쿼터뷰로 바꾸지 않는다.
2. 기존 부품 시안의 사용 가능 영역을 확인하고, 숨겨진 관절·몸통·손과 필요한 극단 자세를 보완한다. 반려 시안의 잘못된 손·발·칼 형태를 그대로 계승하지 않는다.
3. 몸통·골반·팔/다리·양손 파지·무기·망토의 실제 Spine 리그를 구성한다. 파일/CLI로 .spine 저장·재열기·내보내기를 수행하고 정지 조립과 극단 포즈를 확인한다.
4. idle과 attack_basic을 제작해 이펙트 OFF 정상 속도로 본다. 손이 높던 대기, 발 접지 불량, 회수 중 칼끝이 바닥 아래로 내려가던 문제를 전 구간에서 확인·수정한다.
5. 대표 스킬의 고유 공격 자세와 속도 대비를 먼저 완성한다. 필요한 교체 작화·스미어, 검광·접촉 파열·지면 반응·잔향을 추가한다. 기본 베기에 효과만 키운 결과로 대체하지 않는다.
6. V3 공용 렌더러·시계에서 OFF/ON, 정상 속도/느린 재생, 동작 전환·중단·복귀를 확인한다. PC·모바일의 실제 표시 크기에서 전신·칼끝·효과 범위가 읽히는지 본다.
7. 정상 속도 영상, 문제 구간 비교, 편집 가능한 .spine·이미지·런타임과 PROJECT.md를 제공한다. 던전앤파이터급 목표에 미달한 점은 수정 대상으로 남기고 사용자 피드백을 반영한다.

## 완료와 다음 확장

세 동작의 실제 재생과 V3.5 몸·무기·이펙트·제어 검사를 마치면 기술 산출물을 제공할 수 있다. **최종 품질 완료는 던전앤파이터급 기준을 실제 재생으로 검수하고 사용자 시각 피드백을 반영한 상태**로 구분한다. 미달한 시안은 중간 결과이며 파일·테스트 통과만으로 목표를 달성했다고 적지 않는다.

첫 묶음의 품질을 확인한 뒤 이동·피격·사망/퇴장과 나머지 기술·전환으로 확대한다. 실제 전투 액터/이벤트 연동과 성능 검증을 수행한 범위만 완료로 기록한다. 이 시험 제작 명세는 운영 CMS 등록·능력치·획득·출시를 확정하지 않는다.
