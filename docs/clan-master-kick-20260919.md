# 클랜장 클랜원 추방

- 클랜 본부 → 클랜원에서 클랜장에게만 일반 클랜원의 추방 버튼을 표시한다. 이름과 클랜을 표시하는 확인창을 거쳐 실행한다.
- `POST clan/member/kick`: 로그인 계정과 실제 시즌 클랜장·MASTER 소속을 재검증한다. OWNER도 클랜장 소속 없이 이 API를 우회할 수 없다.
- 현재 정규 시즌 ACTIVE만 허용한다. 클랜전 ACTIVE/CLOSING, 대상의 미완료 전투/예약, 세력전 교전 중에는 거절한다. 챔피언스리그 확정 명단은 변경하지 않는다.
- 사용자 ID·시즌 ID·가입 시각으로 오래된 명단을 차단한다. 요청 키별 영수증을 남기며, 재시도는 처음 성공 결과만 반환한다. 추방 후 재가입한 유저를 과거 요청으로 다시 추방하지 않는다.
- PostgreSQL 트랜잭션에서 클랜 소속 삭제, 드래프트 WITHDRAWN 처리, 세력전 편성·행동대장 해제, revision 갱신, 감사 로그와 영수증을 함께 커밋한다. 실패 시 전부 롤백한다.
- 재화·이미 보낸 보상 메시지·개인 전투 기록·클랜 점수·정원·수감 상태는 변경하지 않는다. 추방은 별도 영입이나 보상 지급을 실행하지 않는다.
- DB 검증: 실제 PGlite/PostgreSQL 어댑터로 권한, 다른 클랜, 자신, 시즌·가입 변경, 경기·예약·세력전 차단, 원자적 롤백, 중복 요청 및 재가입 보호 확인.
- UI 검증: 실제 클랜 스크립트/CSS를 브라우저에서 1440px·390px로 표시. 취소, 오류 문구, 같은 요청으로 재시도, 명단 제거, 일반 클랜원 버튼 숨김 및 가로 넘침 확인. 테스트 계정/응답으로 운영 명단은 변경하지 않았다.
- V3 전투 코드·번들·버전 변경 없음. CSS/JS 캐시 키: `20260919-master-kick`.
