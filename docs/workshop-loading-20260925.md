## 수정

- 제작소에만 CSS·순서 보장 스크립트·첫 상태 GET 동시 로딩 적용. 두 자산 그룹이 준비되기 전에는 화면을 마운트하지 않는다. 다른 기능은 기존 CSS 우선 로딩을 유지한다.
- 최초 상태는 한 번만 소비하고, 1초 만료·계정 토큰·재화 변경 epoch를 확인한다. 이전 계정/재화의 응답과 이탈한 화면의 응답을 사용하지 않는다.
- 새로고침·재진입은 브라우저 마이크로캐시와 이전 inflight 응답을 건너뛰고 현재 서버 상태를 요청한다. 미리 받은 GET 실패도 처리하여 미처리 rejection 없이 기존 오류·재시도 UI를 사용한다.
- 자산 실패 재시도 시 아직 로딩 중인 CSS도 기다린다. 무거운 Pixi/GSAP 제작 연출은 기존처럼 실제 제작 응답 뒤에만 로드한다.
- 제작·합성 POST, 확률·비용·보상·차감, DB 및 출시 플래그는 변경하지 않았다. 기존 디자인과 6개 분류도 유지한다.
- `index.html` 앱 URL 및 제작소/폐차장 공용 스크립트 URL에 `workshopLoading=20260925` 적용. 기존 서비스워커의 앱·제작소 network-first 경로 유지.
