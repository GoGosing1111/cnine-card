# 공통 메뉴 · 모바일 가독성 보완 V2108

2026-09-14 사용자는 메시지함·카드상점 등 로비 밖에서 예전 왼쪽 메뉴가 나타나는 문제를 지적하고, 모든 메뉴와 페이지를 전수 확인해 새 UI로 통일하도록 요청했다. BGM은 메시지함·튜토리얼 버튼과 겹치지 않게 아래로 내리고 모바일 잘림도 함께 수정한다.

## 반영

- 새 메뉴 컴포넌트를 게임 페이지의 공통 영역에 유지한다. 메시지함·상점·수집·성장·전투·보상·행정부 화면을 이동하거나 계정 정보가 갱신되어도 옛 사이드 메뉴로 돌아가지 않는다.
- 왼쪽 분류는 해당 항목과 검색만 연다. 하단 전체 메뉴는 전체 목록과 검색을 제공한다. 짧은 PC 창에서는 전체 메뉴를 고정하고 분류 목록을 스크롤한다.
- 콘텐츠 제목 줄과 전체 메뉴 진입도 새 공통 UI에 연결한다. 원래 콘텐츠 DOM, 버튼 바인딩, 전투 화면, 고유 배경과 서버 처리는 유지한다.
- 별도 주소의 장비 강화, 용병도감, 용병 지휘소, 소원램프에도 같은 사이드 메뉴와 모바일 하단 메뉴를 제공한다. 이 페이지들의 기존 전용 헤더·작업 화면은 유지한다.
- 로비 BGM 토글을 족장 이름 아래에 배치한다. 원래 음소거 저장, 재생 목록, 화면 이탈 시 정지 동작을 재사용한다.
- 실제 공통 헤더·사이드바·모바일 하단 메뉴 크기를 관찰해 콘텐츠 영역의 폭과 높이를 맞춘다. 모바일 상단 높이를 줄이고 메시지함과 튜토리얼 버튼을 각각 표시한다. 별도 페이지는 하단 메뉴만큼 스크롤 여백을 확보한다. 자체 제목을 쓰는 장비·수용소에서는 숨겨진 제목 높이를 빼지 않으며, 좁은 PC·태블릿의 장비·클랜·아바타 열을 재배치해 오른쪽 버튼 잘림을 없앤다.

## 검수 범위

메뉴 계약의 모든 39개 목적지를 확인한다. 숨김 설정의 연금술·소원램프는 API 공개 여부를 유지한다. PVE 하위 진입, 제작 분류, 영토전·공성전 등 기존 팝업은 원래 경로를 사용한다. 운영 메뉴에서 연결하지 않는 독립 전투 프리뷰, CMS, 로그인·수감 잠금 화면에는 게임 메뉴를 덧씌우지 않는다.

- `tests/adventure-lobby-v2107.browser.mjs`: 실제 index/app/라우터로 로비, 메뉴, 튜토리얼, 계정 갱신, 경매/PVE 복귀, BGM 위치·토글·정지를 검사한다.
- `tests/shared-navigation-v2108.browser.mjs`: 메시지함·상점·수집·전투·장비·수용소·클랜·아바타의 공통 메뉴, 본문 전체 높이, 가로 잘림, 작은 PC 창의 전체 메뉴 고정과 직접 링크를 검사한다.
- `tests/standalone-navigation-v2108.browser.mjs`: 별도 운영 페이지 4곳을 1440·1024·390·320px에서 확인한다. 분류 격리, 전체 메뉴, 팝업 크기, 도감 선택, 강화/복구 탭과 가로 잘림을 검사한다.
- `tests/lobby-clarity-v1.browser.mjs`: 첫 시안 튜토리얼 및 용병 편성·해제·이전 처리 복구를 검사한다.
- 전체 목적지 브라우저 캡처와 페이지별 결과는 배포 폴더 밖 `../qa/fresh-pages/`에 저장한다. 각 목적지는 페이지를 다시 불러온 뒤 독립적으로 확인해 다른 콘텐츠 팝업이 검사를 가리지 않도록 한다.

브라우저 검수의 API는 격리된 데이터로 대체하며 실제 계정 쓰기·입찰·전투·재화 소모는 하지 않는다. DB, 기능 플래그, 확률, 보상과 운영 CMS 값은 변경하지 않는다. 앱·서비스 워커·공통 UI 캐시는 `2108-shared-navigation`으로 함께 갱신한다. 깨끗한 후보에서 `npm run deploy:production`의 전체 출시 게이트를 통과한 뒤 배포한다.
