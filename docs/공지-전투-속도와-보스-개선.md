# 전투 개선 안내 — 전투 시간 단축 · 보스 행동 정상화

"전투가 너무 늘어진다", "보스가 샌드백 같다"는 제보를 확인했습니다.
**두 가지 다 사실이었고, 원인도 서로 달랐습니다.** 각각 고쳤습니다.

---

## 1. 전투가 왜 그렇게 길었나

실제로 재봤습니다. 덱 전투력 50만, 나이트메어 기준입니다.

```
한 판에 231턴   ·   재생 시간 2분 10초
```

두 가지가 겹쳐 있었습니다.

**체력이 너무 높았습니다.** 몬스터 체력이 전투력의 4배, 나이트메어는 여기에 2배가
더 붙어 **8.4배**였습니다. 아무리 세게 때려도 깎는 데 200턴 넘게 걸립니다.

**연출에 길이 조절이 없었습니다.** 예전 전투 화면에는 턴이 쌓이면 재생을 조금씩
빠르게 하는 장치가 있었는데, 새 전투 화면으로 넘어오면서 빠져 있었습니다.
그래서 200턴이든 50턴이든 턴당 재생 속도가 똑같았습니다.

### 바뀐 것

양쪽 체력을 같은 비율로 낮췄습니다. **한쪽만 낮추면 승패가 바뀌기 때문에**
플레이어와 몬스터를 함께 조정했습니다. 여기에 옛 전투 화면에 있던 재생 압축을
새 화면에도 다시 넣었습니다.

| 덱 구성 (나이트메어) | 이전 | 이후 |
|---|---:|---:|
| 공격 특화 | 1분 27초 | **44초** |
| 공격2·방어1·속도1·생명1 | 2분 10초 | **1분 2초** |
| 균형형 | 2분 32초 | **1분 6초** |

일반 몬스터는 **54초 → 30초** 입니다.

## 2. 보스가 왜 샌드백이었나

이쪽이 더 근본적인 문제였습니다.

```
플레이어 행동 속도  =  기본값 + 전투력에 비례한 값   ← 강해질수록 계속 빨라짐
몬스터 행동 속도    =  고정값                        ← 그대로
```

카드 한 장 전투력 10만이면 플레이어 속도는 약 1,470, 몬스터는 92입니다.
5장이면 팀 합계가 7,350이라 **몬스터 몫이 1.2%** 밖에 안 됩니다.

실제로 측정하니 이랬습니다.

```
127턴짜리 전투에서 보스가 공격한 횟수 —  0회
```

**전투력을 올릴수록 보스가 더 안 움직이는 구조였습니다.** 강해질수록 보스가
허수아비가 되니, 전투가 "싸움"이 아니라 일방적으로 두들기는 시간이 됐습니다.

### 바뀐 것

행동 속도와 **무관하게**, 플레이어가 일정 횟수 움직이면 보스가 반드시 한 번
공격하도록 바꿨습니다. 속도를 손보는 방식은 전투력 구간마다 다시 어긋나기 때문에
"보장 행동" 방식을 택했습니다.

| 나이트메어 · 실전형 덱 | 이전 | 이후 |
|---|---:|---:|
| 보스 공격 횟수 | 0회 | **10회** |
| 보스 한 대의 위력 | — | **카드 체력의 약 36%** |

**세 대 맞으면 카드 한 장이 쓰러집니다.** 보스가 때리는 만큼 전투가 조금 길어져서
1분 2초가 됐지만, 이전 2분 10초와 비교하면 여전히 절반 이하입니다.

### 전투 중에 카드가 쓰러지는 게 정상입니다

이제 나이트메어에서는 **이겨도 카드 1~2장이 쓰러지는 게 보통입니다.**
지금까지 한 장도 안 쓰러졌던 건 보스가 공격을 못 하고 있었기 때문입니다.

**전투가 끝나면 체력은 그대로 회복됩니다.** 다음 전투에 아무 영향이 없으니
안심하셔도 됩니다. 원정(균열)의 체력 관리와는 별개입니다.

## 3. 정직하게 말씀드릴 것 — 난이도가 구간별로 달라집니다

이번 변경으로 **모두가 같은 방향으로 바뀌지 않습니다.** 미리 알려드립니다.

"내 덱 전투력의 몇 %짜리 몬스터까지 잡히나" 로 재봤습니다. (나이트메어 기준)

| 내 덱 전투력 | 이전 | 이후 | |
|---:|---:|---:|---|
| 5만 | 10% | **30%** | 쉬워집니다 |
| 15만 | 40% | **60%** | 쉬워집니다 |
| 30만 | 80% | **100%** | 조금 쉬워집니다 |
| 50만 | 120% | **120%** | 그대로입니다 |
| 100만 이상 | 260% | **140%** | **어려워집니다** |

**저·중 전투력 구간은 쉬워집니다.** 사실 이 구간은 몬스터가 강해서 못 이긴 게
아니라, **전투 제한 시간 안에 못 잡아서 지고 있었습니다.** 전투력 5만이면 자기
전투력의 10%짜리 몬스터까지만 잡혔습니다. 이건 원래 의도한 설계가 아니었습니다.

**고전투력 구간은 어려워집니다.** 보스가 이제 실제로 공격하기 때문입니다. 지금까지
자기 전투력의 260%짜리 몬스터까지 잡히던 것이 140% 선으로 내려옵니다.
**투자를 많이 하신 분들께는 체감이 큰 변화입니다.** 숨기지 않고 먼저 말씀드립니다.

당분간 지켜보고, 특정 구간이 지나치게 빡빡해지면 몬스터 설정을 조정하겠습니다.
어느 콘텐츠에서 막히는지 알려주시면 그 구간부터 보겠습니다.

## 4. 같이 고쳐진 것 — 시간 초과로 지던 문제

방어형·균형형 위주로 덱을 짜신 분들 중에 **"분명 이기고 있었는데 졌다"** 는 경험이
있으셨을 겁니다. 진 게 아니라 **제한 시간이 끝난 것**이었습니다.

몬스터를 다 못 잡은 채로 전투 시간이 끝나면 패배 처리됩니다. 화력이 낮은 덱은
아무리 강화해도 시간 안에 못 잡아서 계속 실패했습니다.

전투가 짧아지면서 이 구간이 크게 줄었습니다. 다만 **공격형 카드가 한 장도 없는
구성**은 여전히 나이트메어에서 시간 안에 잡기 어렵습니다.

## 랭크전·영토전(PVP)은 그대로입니다

이번 변경은 **몬스터 전투에만** 적용됩니다.

작업 중에 PVP 에도 영향이 가는 걸 발견해서 되돌렸습니다. PVP 는 일정 행동 수를
넘기면 연장전이 걸리는 구조인데, 전투가 짧아지면 연장전에 도달하지 못해 **일부
덱 상성이 뒤집혔습니다.** 랭크전과 영토전은 경쟁 콘텐츠라 예고 없이 상성이 바뀌면
안 된다고 판단했습니다.

덱 조합 6종의 모든 맞대결(36쌍)을 각 150판씩 돌려 **승률·턴 수·연장전 발생률이
이전과 완전히 같은 것**을 확인했습니다.

다만 **재생 속도 개선은 PVP 에도 적용됩니다.** 승패 판정과 무관한 부분이라
랭크전도 조금 더 빠르게 끝납니다.
