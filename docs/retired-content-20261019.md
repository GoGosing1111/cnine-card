# 사용하지 않는 콘텐츠 제거 — 2026-10-19

사용자 요청: “몬스터공성 API,로그 아예 삭제하고 설정에서도 치킨집,금도끼은도끼 이벤트 아예 삭제해 그리고DB정리 하는 설정도 안쓰니까 삭제”.

## 제거 범위

- 몬스터공성 서버 실행 모듈, 전황 집계, 공성 클라이언트·스타일·CMS·전용 프리뷰를 삭제했다. 모든 `siege/*`, `admin/siege/*` 요청은 인증·DB 접근·지역 API 전달 전 410으로 종료한다.
- 설정의 치킨집·금도끼 은도끼·DB 정리 패널과 로딩 스크립트를 삭제했다. 이벤트 메뉴·공개 여부 폴링·쿠폰 발행 UI 선택지를 없애고, 이벤트 URL은 홈으로 돌린다. 이벤트 참여·설정 API와 수동 DB 정리 API도 410으로 종료한다.
- 모바일 설정 탐색 메뉴 높이 보정은 삭제한 치킨집 CSS에서 공통 CMS CSS로 옮겼다. 기존 화면 구성과 스타일을 유지한다.
- 이미 획득한 슈퍼스타 +13 강화권과 차량부품 150개 선택권은 기존 인벤토리 상세창에서 사용한다. 해당 보상 API의 인증·원장·재시도 정책은 유지한다. 이벤트 참가권·보상 원장·공용 지급 이력·계정과 재화는 삭제하지 않는다.
- 기존 PostgreSQL 자동 유지보수 비활성 정책과 레거시 D1 자동 유지보수는 보존한다. 수동 계정/로그 정리 API는 제거하며 공성 전용 자동 정리 태스크도 제거한다.

## 공성 로그 정리

사전 운영 조회에서 진행 중인 공성 회차가 없고, 삭제 대상 로그에 외부 키·사용자 트리거가 없음을 확인했다. 치킨집과 도끼 이벤트 기간도 종료됐다.

`scripts/ops/remove-retired-content-20261019.mjs`는 라이브 410 응답을 먼저 확인한 뒤 한 거래에서 다음 대상만 처리한다.

- `monster_siege_actions`: 사전 조회 58,428건 / 904,192,000 bytes.
- `monster_siege_ai_actions`: 사전 조회 3,531건 / 3,514,368 bytes.
- `app_meta`의 `monster_siege_settings_v1`, `pingdu_chicken_event_v1`, `pingdu_golden_axe_v1` 세 키.

`TRUNCATE ONLY ... RESTRICT`와 테이블 잠금, 진행 회차 확인, 외부 의존성 차단을 사용한다. 회차·참가자·보상·참여 보너스·AI 상태는 전후 행 수와 정렬된 행 해시를 대조한다. 운영 감사와 `ops:retired-content-cleanup:20261019:v1` 완료 영수증을 같은 거래에 저장하고 재실행은 중복 차감 없이 끝난다. DB 스키마나 공용 거래 로그는 변경하지 않는다.

## 검수와 배포

- 실제 API 진입점에서 24개 경로 × 5개 HTTP 메서드가 DB/인증/전달 없이 410을 반환하고, 유지할 보상·다른 콘텐츠 경로는 차단하지 않는 회귀 검사.
- PGlite에서 감사 저장 실패·dry-run의 전체 롤백, 실제 삭제 범위, 계정·재화·공용 거래 보존, 재실행, 진행 회차·외부 참조 차단 검사.
- 기존 전황·저장소 유지보수 및 이벤트/쿠폰의 영향받은 검사 수정. 역사적 순수 함수 테스트와 지급 원장은 보존한다.
- 실제 CMS HTML·CSS·컨트롤러에 격리된 mock API를 연결해 PC 1440×960 / 모바일 390×844 설정·쿠폰·운영 로그 화면, 제거 패널/호출 부재, 화면 넘침과 콘솔 오류를 확인했다. 인벤토리 보상 선택·1회 사용·갱신 후 완료 화면도 확인했다. 운영 쓰기는 0회이며 이미지와 결과는 `docs/qa/retired-content-20261019/`에 보존한다. 기술 검수를 사용자 시각 승인으로 기록하지 않는다.
- 직전 운영 소스 `f5c6f6070ca9065ea67a5c416951b3bf012071a7`을 기준으로 관련 회귀·출시 정책·컴파일 검사 후 `npm run deploy:production -- --scoped`를 사용한다. 라이브 API 폐기와 자산 해시를 확인한 다음 로그 정리 및 별도 연결 재검증을 진행한다.
