# SX슈트 궁극기 줌아웃·검신 오라 — 2026-10-08

사용자 요청: 궁극기 때 다시 줌아웃하여 검 전체를 표시하고 화면 뒤틀림 없이 복구한다. 검신의 파란 오라는 첨부 이미지처럼 상시 유지한다.

## 구현

- `SXSuitCamera.js`: 창천멸진 시작 0.38초 안에 거대 검의 전체 높이와 아군 편성이 들어오는 배율로 부드럽게 줌아웃한다. PC·모바일의 실제 캔버스와 안내·카드 영역을 기준으로 계산하며 검이 사라진 뒤 원래 배율로 돌아온다.
- 배경 3개 밴드를 하나의 임시 컨테이너로 묶고 카메라 변환의 역변환을 적용한다. 밴드별 배율·피벗을 남기지 않으며 회전·기울기를 사용하지 않는다. 완료·취소·전투 전환 시 임시 부모와 카메라를 해제한다.
- 궁극기 카메라는 같은 전투 시계를 사용한다. 일시정지 중에도 같은 화면을 유지하고, 일반 공격이나 SX가 카메라를 사용하지 않는 정리 동작은 다른 액터의 카메라를 초기화하지 않는다.
- 승인된 파란 검신 오라를 캐릭터 외형에 직접 붙여 대기·이동·공격의 첫/마지막 프레임과 연출 정리 후에도 유지한다. 손잡이부터 검 끝까지 자세를 따라가며 본체 그림 위에 표시한다. SX 인스턴스 제거 시 함께 정리한다.
- 승인 이미지·모션·효과 텍스처를 변경하지 않는다. 공격속도 2배, 궁극기 시간표·피해·서버 판정도 유지한다.
- 공용 V3의 10개 소비 번들과 메인 로더·PVE 진입·서비스 워커 캐시를 갱신한다. `sxCamera=20261008-v3`, 런타임 접미사 `ultimate-frame-aura-v3`.
