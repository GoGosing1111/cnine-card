# 오픈 2달 기프트 메시지 보상

- 메시지 보상에 `UNIQUE_ADVANCEMENT_PASS`(전직 패스권)와 `STARLIGHT_ARMOR_CORE`(미스틱 에너지)를 추가한다.
- 기존 인벤토리 보상 수령 트랜잭션을 재사용한다. 메시지 발송만으로 보유량이 늘어나지 않으며, 수령 시 영수증과 인벤토리 로그를 남긴다.
- 두 보상 모두 개별 수령과 순차 일괄 수령을 지원한다. 패스권의 전직 시 자동 소모 조건은 변경하지 않는다.
- 앱과 서비스워커 캐시 버전은 `2044-gift-message-rewards`다.

## 요청된 운영 발송

- 대상: 발송 시점의 2차 인증 완료 ACTIVE 계정 전원, 인증된 ADMIN·OWNER 포함.
- 계정당 별도 메시지 2통: 전직 패스권 1개, 미스틱 에너지 30개.
- 제목과 내용: `숲켓몬 오픈 2달 기프트`.
- 운영 도구는 배포 트리 밖에 둔다. 대상 ID 스냅샷 및 두 캠페인 키를 영수증 `ops:two-month-gift:2026-09-06`에 함께 기록하며, 두 발송을 단일 트랜잭션으로 검증·확정한다.
- 동일 영수증 재시도는 신규 발송 없이 기존 결과만 확인한다. 캠페인·유저 고유 인덱스도 중복을 차단한다.

## 검증

- `npm run test:message-rewards`: 두 아이템의 정상 수령·재시도·동시 요청·실패 롤백·클라이언트 일괄 수령.
- 운영 PostgreSQL 연결의 임시 테이블에서 실제 수령 SQL 호환성, 지급 수량, 재시도, 로그 실패 롤백을 확인한다. 테스트는 ROLLBACK으로 끝내며 운영 유저 재산을 변경하지 않는다.
- 운영 배포 전에 `npm run release:gate`, 배포는 `npm run deploy:production`만 사용한다.
