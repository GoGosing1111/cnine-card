# 디펜스 로그라이크 성장 V2 · 2026-10-17

## 사용자 지시
새 디펜스 전용 7종으로 교체하고 긴 웨이브 및 성장 선택을 구현한다. 포인트 획득도 확률이며 강화 성공률을 낮춘다. “반영해 그리고 포인트추첨 획득,강화 관련 선택도 대충만들지 도구사용해서 최상급으로 만들것”에 따라 TEST에 배포한다. 기존 2~3인, 각자 용병 2명 + 카드 1장, 누적 전멸 부활 정책은 유지한다.

## 실행 정책
- 기본 30웨이브. 5·15·25 정예, 10·20·30 노크스 보스. 보스는 포격 → 지원 병력 → 전선 순차 공격으로 변한다.
- 일반 50%/100P, 정예 65%/150P, 중간 보스 80%/250P. 참가자마다 독립 추첨하며 미당첨 0P. 최종 공세 후에는 전투가 끝나므로 추첨/정비가 없다.
- 공격·생존·전술 3계열, 최대 각 +10. 1성공마다 분대 공격 +8%, 최대 HP +10%, 전술 대기 -3%. 전술 강화 최대 -30%, 고속 동기화 포함 최대 -40%.
- 목표 +1~3 60%/100P, +4~6 35%/150P, +7~9 15%/200P, +10 5%/300P.
- 실패도 포인트를 소모하며 기존 단계는 유지한다. 확정 강화·실패 누적 보정은 없다.
- 최종 공세 제외 5공세마다 무료 특성 3개 중 1개. 총 8개 특성. 원거리 관통, 방벽 지속, 수호석 회복, 지원 협약, 추가 대기 감소, 정예/보스 피해, 종료 회복, 수호석 진입 감속이 실제 전투에 연결됐다.
- 정비 기본 15초, 전원 준비 시 최소 3초 이후 출발. 미사용 포인트와 미선택 특성은 다음 정비로 이월한다. 자동 소비는 없다.
- 전멸 15→30→45→60초 / HP50%. 강화·포인트·전술 마감 시각은 부활/재접속으로 초기화되지 않는다.
- OWNER CMS에서 웨이브 10~60(10단위), 정비 15~60초, 추첨 종류별 확률·수량, 강화 구간별 확률·비용, 단계별 효과를 조절한다. 저장한 정책은 새 방에만 복사한다.
- 콘텐츠 수명 상한은 방 2시간 / 전투 90분. 기존 30분 상한이 늘어난 웨이브와 정비 시간을 잘라버리지 않도록 확장했다.
- 계정 보상 비활성, 기존 TEST/지정 계정 접근 및 CMS 난이도 조절값을 유지한다. 기존 version2 방은 이전 전투 규칙을 이어간다.

## 서버·재시도
서버가 웨이브 종료 때 플레이어별 draw를 한 번 저장한다. 강화는 wave·attemptSeq·cost·단계·단계별 확률을 검사하고, 영수증/차감/성공 변화와 방 저장을 같은 동기 명령에 반영한다. 기존 Durable Object 요청 ID 및 fingerprint 재시도 보호를 사용한다. 클라이언트는 저장된 결과만 개봉하며 결과와 관계없는 시각 애니메이션 때문에 재추첨하지 않는다. 원정 RNG는 공개 snapshot에 포함하지 않는다.

전멸 중 성장을 선택해도 죽은 유닛을 부활시키지 않는다. 체력 강화는 현재 비율을 유지하며 실제 부활은 기존 마감 시각을 따른다. 과거 특성을 나중에 선택할 때 새로운 미선택 제안에 같은 특성이 남지 않게 조정한다. 서버 이력은 유지하고 모바일 snapshot은 최근 추첨 6개/강화 4개로 제한한다.

## 설정 등록과 배포
`scripts/ops/monster-defense-growth-20261017.mjs`는 기존 설정을 잠그고 revision CAS로 신규 growth만 한 번 추가한다. 운영 상태·테스트 계정·기존 난이도·후속 OWNER 성장값은 보존한다. 설정·감사·완료 영수증을 한 거래로 기록하며 dry-run은 전부 rollback한다. 재시도는 기존 영수증을 반환한다.
