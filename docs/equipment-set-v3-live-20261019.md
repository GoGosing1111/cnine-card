# 엠퍼러·아르덴 +10 유저 장비 전투 연출

사용자 `아르덴도 작업해서 라이브 반영해`에 따라 기존 엠퍼러 시연과 새 아르덴 효과를 공통 V3 전투에 연결한다. 유저 장비 상의·하의·신발·장신구 네 부위를 같은 세트로 실제 장착하고 각각 +10 이상일 때만 표시한다. 무기는 조건에 포함하지 않는다. 보유만 한 +15 장비, 혼합 세트, +9 부위, 다른 유저의 장착 정보는 조건을 충족하지 않는다.

엠퍼러는 기존 금빛 황제 문장·금장 지면 문양을 유지한다. 아르덴은 실제 장비 원화의 백금·금세공·청록 보석에 맞춰 별도 문장, 지면 문양, 12프레임 결정 타격 애니메이션을 built-in ImageGen으로 생성했다. 원본 PNG, 변환 WebP, 전체 프롬프트·SHA-256은 `assets/effects/equipment-sets-20261019/manifest.json` 및 `prompts.json`에 보존한다. 아르덴 참고 원화는 `preview/mythic-emperor-successor-v1/assets/mythic-armor-fantasy-v5.png`, `mythic-dual-disk-fantasy-v5.png`다. ImageGen에는 해당 재질·색·장식 특징을 텍스트로 지정했다.

V3에 유저 아바타를 추가하지 않는다. 전투 중 해당 유저의 카드 진영을 기준으로 문장·지면·광입자를 표시하며 실제 일반 공격 적중 콜백에서 추가 타격 효과를 재생한다. 격전지·랭크듀오는 ownerId별로 나누고 모바일/다인 전투는 해당 카드 자리별 작은 지면 문양을 사용한다. 기존 카메라 배율·배치·카드 도크를 유지한다. 동작 줄이기에서는 고정 문양만 표시한다.

`equipmentGrowthRuntime`의 기존 최대 5개 장착행 조회에 강화 상태 조인을 추가한다. 전투 시작 시의 시각 정보만 스냅샷에 기록하며 스탯·피해·속도·승패·보상·경제·확률은 변경하지 않는다. 랭크듀오는 기존 장비 집계 결과에서 실제 equipped_count가 있는 행만 사용하며 캐시 형식 버전을 갱신한다. PVE/PVP/조직/영토전/쿠데타·격전지·듀오 및 별도 레이드 저장 장착정보를 지원한다. 유저 장비를 적용하지 않는 족각도시는 제외한다. 기존 저장 전투에 없는 장착 정보를 현재 장비로 소급 추정하지 않는다.

공통 Pixi 객체와 `BattleEngine.timeline` 시계를 사용한다. 조건 미충족 시 자산을 요청하지 않으며 효과 로딩 실패가 전투를 막지 않는다. 세션 교체·닫기·종료에서 타격 객체와 타임라인을 정리한다. 기존 10개 V3 소비 번들을 빌드하고 메인 로더·서비스워커 버전을 갱신했다.

검수 범위는 세트·강화 판정, SQLite/Postgres 장착 조회, 듀오 집계/캐시 회귀, 효과 유무에 따른 전투 결과 동일성, V3 라이브 로더 계약이다. 실제 공통 번들의 PVP PC, PVE 모바일, 격전지 PC/모바일에서 소유자 분리·넘침 없음·터치 44px·재시작·효과 ON/OFF·일시정지·동작 줄이기·해제를 확인했다. 기존 보스 아틀라스 캐시 해제 경고 한 종류 외 신규 콘솔 오류는 없었다. 캡처는 `docs/qa/equipment-set-v3-20261019/`에 보존한다. 기술 검수를 별도 사용자 시각 승인으로 기록하지 않는다.

통합 시연은 `/preview/equipment-sets-v3-20261019/`, PVE는 `?mode=pve`, 3인 격전지는 `?mode=coop`이다. 이 시연은 저장된 검수 편성만 사용하며 운영 계정 읽기·쓰기·보상 지급을 하지 않는다. 기존 엠퍼러 단독 시연과 이미지 생성 원본은 Git에 보존하고 운영에는 WebP와 통합 시연을 배포하여 기존 Pages 파일 한도를 지킨다.
