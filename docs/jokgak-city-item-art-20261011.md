## 원본과 표시 파일

- 제작 도구: 내장 `image_gen.imagegen`, 자산별 1회씩 총 8회. 외부 API/CLI는 사용하지 않았다.
- [자산·전체 제작 프롬프트·SHA-256](../assets/ui/jokgak-city/items-v1/manifest.json)
- 원본: `assets/ui/jokgak-city/items-v1/*-source.png`, 1254 × 1254 RGBA. 생성 PNG를 그대로 복사해 보존했다.
- 표시 파일: 동일 디렉터리의 `*-768.webp`, `*-256.webp`. 비율과 알파를 유지하고 크기/포맷만 변환했다. 내용 편집·배경 대체·크롭은 하지 않았다.
- 소지품과 작은 장착칸에는 256px, 큰 진열과 고밀도 화면에는 768px를 `srcset`으로 제공한다.
- 원본 도시 지도·전투 배경은 보존했다. 무기 전체 축과 연결부를 원본 크기에서 확인했다.

## 적용

공용 매핑은 `js/jokgak-city-item-art-v1.mjs`, 화면별 배치는 `css/jokgak-city-items-v1.css`다. 상점·무기상·식당·병원, 무기 인벤토리·도시 소지품·프로필 장착칸, 결제 확인·보급품 사용 완료창에 연결했다.

PC는 3열 진열, 모바일은 그림과 정보를 나란히 배치하고 결제 버튼을 전체 너비로 제공한다. 정식·진료는 큰 단일 상품 화면을 사용한다. 아이템 전체가 보이도록 이미지 박스 안에 비율을 유지하고, 실제 화면에서 발견한 하단 잘림을 수정했다.

가격·회복량·보유 수량·구매/사용 가능 여부는 기존 서버 상태를 그대로 사용한다. 서버 거래, 기존 현금 정책, TEST/ON 분리 및 CMS 모드는 변경하지 않았다. 정상 아이템과 구분되는 맨손·탐색·상태 표시는 기존 기능 아이콘을 유지한다.

## 배포 범위

도시 아이템 표시만 변경하므로 scoped 배포를 사용한다. 인증·DB·서버 전투·의존성 변경이 없고, 거래 동작은 위 브라우저 검수로 확인했다. 무관한 콘텐츠 전체 검사는 실행하지 않는다.

- 명령: `npm run deploy:production -- --scoped`.
