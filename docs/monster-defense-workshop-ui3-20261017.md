# 디펜스 분대 정비 UI V3 — 2026-10-17

## 사용자 요청과 적용

사용자가 기존 버튼 재사용, 밀어서 잠금 해제, 서체와 색감을 거부했다. 이 문서는 해당 정비실의 표시와 조작 수정만 기록한다. 기존 성장 규칙은 `monster-defense-growth-20261017.md`를 따른다.

- 포인트 추첨은 **포인트 확인** 한 번으로 공개한다. range 입력·드래그 이벤트·봉인 해제 문구를 제거했다.
- 용병 성장 금장 버튼 참조를 없애고 내장 ImageGen으로 디펜스 전용 기계식 버튼과 정비실 배경을 새로 제작했다.
- 흑철·아이보리·청록 팔레트, 실패는 코랄, 큰 한글 제목과 확률/비용 숫자로 다시 구성했다. 과도한 영문 장식 문구를 줄였다.
- SUIT Variable을 공식 저장소 커밋 `55118d981336d8fce005eb62888c12c0568ef7b0`에서 받아 로컬 제공한다. 원본 폰트와 OFL 라이선스를 함께 보존했다. 출처: https://github.com/sun-typeface/SUIT
- 헤더는 보유 포인트/다음 공세, 탭은 추첨/강화/특성, 본문은 현재 선택, 하단은 준비 상태와 정비 완료로 구성한다.
- 모바일은 글자 크기를 줄이는 대신 본문 스크롤을 사용한다. 390×844에서 강화 선택 직후 주 버튼 전체가 하단 위에 표시된다. 반응로는 강화 연출/결과 때 나타나며 결과 위치로 스크롤한다. 가로 화면은 정비실 전체 스크롤로 좁은 높이를 활용한다.
- 같은 컴포넌트를 `/defense/` TEST와 `/preview/defense-roguelike-v2/`에 연결했다. 실제 서버 확정 영수증만 공개하며 미리보기는 지정 결과/시간 정지/실제 지급 없음 표시를 유지한다.

## 검수

정비 UI에 한정해 Chrome/Playwright로 확인했다. 단위검사는 scoped 배포에서 기존 성장 회귀 8개를 사용한다. 공통 인증/DB/서버 정책을 수정하지 않았다.

- 1440×1000 PC: 포인트 당첨/미당첨, 강화 선택/성공/실패, 특성 3개 선택.
- 390×844 터치·동작 줄이기: 추첨, 생존 강화, 결과, 특성. 320×720과 844×390 가로 화면에서 가로 넘침 및 하단 접근성 확인.
- Enter 연속 입력으로 추첨 결과/보유 포인트가 중복 증가하지 않음.
- 로컬 실제 TEST 경로: 서버 추첨 100P → 강화 1회 → 잔액0P/공격+1/attemptSeq1 → 새로고침 후 동일 영수증 유지.
