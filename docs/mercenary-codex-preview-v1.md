## 성능과 원본 보존

원화 전체는 약 50.71MiB다. 초기 목록에 이 원본 전체를 내려받지 않는다.

- 원화 320/640px WebP, SD 640px WebP를 별도 디렉터리에 생성: 총 63개, 6,961,632바이트.
- 전체 21종의 320px 목록 원화 합계: **940,880바이트** (약 0.94MB). 원화 원본 합계 대비 약 98.2% 감소.
- `srcset`과 `sizes`로 해상도에 맞는 목록 이미지를 선택하고, 목록 아래쪽은 lazy loading을 사용한다. 고해상도 디스플레이에서는 640px 이미지가 선택될 수 있으므로 0.94MB를 총 네트워크 전송량으로 해석하지 않는다.
- 원본은 확대 요청 시에만 불러온다. 프레임은 원래 승인 자산을 별도 계층으로 재사용한다.
- 모든 원본·SD·앵커의 기존 SHA-256이 일치하며 원본을 덮어쓰거나 재압축하지 않았다.
- 생성 명령: `node scripts/build-mercenary-codex-media-v1.mjs`.
- 파생 파일별 입력/출력 해시·규격·용량: `assets/ui/project-v/mercenaries/codex-v1/manifest.json`.

## 공개 범위

**최초 프리뷰 작업에서는 운영 공개/활성화하지 않았다.** 이 작업은 메뉴 배치와 정보 화면을 검토할 수 있는 독립 프리뷰였다. 서버, DB, 운영 메뉴, 서비스 워커와 공개 기능 플래그를 변경하지 않았다. 이후 사용자의 명시적 공개 지시에 따라 읽기 전용 도감만 별도로 운영에 연결하며, 뽑기·강화·편성·전투의 등급 확정 게이트는 유지한다.
