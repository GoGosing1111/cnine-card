## 사용자 정정 반영

- 기존 캐릭터의 직업적 콘셉트와 그림의 인상은 이어가되 독립적인 새 캐릭터로 제작한다.
- `빅물개는 그대로 써도 됨`: 모루 초안은 적용 후보에서 제외하고 `unused/`에 이력만 보존했다.
- `동양 백인 도 좀 넣어라`: 동양인·백인 얼굴을 충분히 포함했다. 초기 네르반·카르도·바레온 원화는 V2로 교정하고 나머지 제작 명세도 갱신했다.
- 태온 V1에서 칼날을 잡는 오류가 보여 손잡이 파지를 고친 V2로 교체했다. 기존 얼굴·복식·불꽃·배경은 유지했다.

## 생성 및 보존

내장 `image_gen` 사용. 기존 로컬 원화를 직접 확인한 뒤 해당 이미지를 구도·작화 참고로 전달했다. 서로 다른 원화는 개별 요청으로 생성했다. 새 PNG는 생성 원본 그대로 복사했고 재압축·코드 기반 색상/얼굴 보정은 하지 않았다. `manifest.json`에 선택 버전, 원본·참조 해시와 크기, 실제 요청 JSON을 연결한다. V1~V2 이력은 덮어쓰지 않는다.

기술 확인과 사용자 승인 여부는 분리한다. 현재 모든 원화는 `REVIEW_READY`, 사용자 시각/이름 승인은 false다. 예전 몬스터 자산의 `productionBindingBeforeApproval:false` 규칙을 유지한다. `AGENTS.md`의 신규 효과·사운드 시각 승인 전 런타임 연결 금지 역시 유지한다.

## 게임 보존 및 남은 작업

이번 변경에는 게임 실행 파일·DB 변경이 없다. 피해량, 타격 수, 대상, 쿨타임, 상태이상, 패턴, 보상, 난이도는 변경하지 않았다. 읽기 전용 토벌·레이드 조회와 보호 대상 해시를 `baseline-gameplay.json`에 기록했다. 이 시점의 원화 준비를 실제 게임의 IP 교체 완료로 표현하지 않는다.

후속 적용에는 확정 원화 기준 전투 SD·모션, 식별 가능한 소환체/효과/고유 기술명, UI·CMS·기록 표시 이름 연결이 남아 있다. NORMAL 원화를 쓰는 레이드 부속 유닛은 노말 원본을 바꾸지 않고 레이드 전용 자산으로 분리해야 한다. 일반 레이드의 이름 기반 초기화/조회, 과거 전투 영수증, 동일 캐릭터 난이도 별칭도 유지해야 한다.

## 검수·배포

자산과 독립 비교 페이지만 변경하므로 게임 전체 검사는 실행하지 않는다. 원본/참조 해시·선택 버전·범위 제외, 페이지 문법 및 PC·모바일 핵심 조작만 확인한다. 실제 결과는 같은 프리뷰의 `qa/`에 기록한다.

공개는 `npm run deploy:production -- --assets-only` 경로로 수행한다. 배포 직전에 Cloudflare production 목록의 실제 Source를 40자리 SHA로 확인해 `ASSET_DEPLOY_BASE`로 지정한다. 원화 검수판의 공개이며 게임 전투 자산을 활성화하는 배포가 아니다.
