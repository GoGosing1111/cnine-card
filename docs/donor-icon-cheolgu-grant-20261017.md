# 10월 13일 후원 집계 아이콘 철구 지급

사용자 요청에 따라 10월 13일 집계 명단의 보상을 지급하고, 이후 기준을 달성한 사람은 댓글로 별도 신청하도록 공지 초안을 작성했다.

## 완료 결과

- 집계 기준: 총합(임시 제외) 1,000개 이상. 미션·영상풍선 등을 포함하고 임시 도전미션은 제외한다.
- 대상 117명 중 인증된 게임 계정을 확인한 116명에게 ICON 제우스 철구(CN-1C000008)를 각 1장 직접 지급했다.
- 나머지 1명은 사용자 지시대로 계정 확인 필요 명단에 분리했다. 확인되지 않은 계정에 임의로 지급하지 않았다.
- 닉네임 변경은 인증된 계정 연결로 구분했으며, 동일하거나 비슷한 이름만으로 지급 대상을 결정하지 않았다.
- 코인·마스터의 별 등 기존 재화와 재료, 다른 카드 및 기존 카드 강화 수치를 보존했다.
- 공개용 공지 초안과 전체 명단은 사용자에게 로컬 파일로 제공했다. 외부 게시판에 공지를 게시하지 않았다.

## 날짜 구분

- 사용자 지정 공지 집계 기준일: 2026-10-13.
- 실제 원본 확인 및 지급·검증일: 2026-10-17 한국 시간.
- 원본은 누적 집계표로, 후원별 일자가 없다. 10월 13일의 개별 후원 기록을 별도로 재구성했다고 주장하거나 실제 지급일을 소급하지 않는다.

## 관련 검증

- 운영 계정 잠금과 DB 트랜잭션을 사용하여 20명 이하 단위로 처리했다.
- 지급 전 116명 전원에 대해 실패 롤백, 재실행 중복 방지, 기존 자산 보존을 확인했다.
- 검증 중 발생한 동시 거래 잠금 충돌은 거래를 취소하고 잠금을 해제한 뒤 제한된 횟수 안에서 재시도하여 해결했다.
- 지급 후 별도 DB 연결에서 카드 보유분 116건, 영수증 116건, 감사 로그 116건을 확인했다.
- 계정 확인 대기 대상에게는 이번 지급 영수증이 없음을 확인했다.
- 게임 실행 코드 변경이나 운영 재배포는 하지 않았다.

계정별 식별자, 후원 내역, 지급 계획 및 영수증 원문은 운영 DB와 로컬 작업 기록에 보존한다. 이 원격 기록에는 해당 개인 식별 데이터를 포함하지 않는다.

## 2026-10-17 후속 추가 지급

- 사용자 후속 요청으로 명시된 게임 계정 2명에게 같은 ICON 카드를 각 1장 추가 지급했다. 이번 추가 대상은 기존 116명과 중복되지 않는다.
- 추가 대상은 명시적인 사용자 지급 지시로 확정했으며, 원본 후원 표에 없는 후원액이나 기존 확인 대기 대상과의 동일인 관계를 추정하지 않았다.
- 추가 2명의 실패 롤백·중복 방지·기존 자산 보존을 검증하고 실제 지급 후 카드 보유분·영수증·감사 로그 각 2건을 재확인했다.
- 최초 116명에 추가 2명을 합쳐 누적 118명 지급 완료. 기존 계정 확인 대기 1명은 유지한다.
- 로컬 공지 명단에 추가 2명을 별도 항목으로 반영했다. 추가 대상의 식별자와 영수증 원문은 원격 저장소에 포함하지 않는다.
