# UI 고정 기준 — 2026-09-15

사용자 지시: “UI 현 로비에 맞게 똑바로 다시만들어”, “UI도 앞으로 고정이다 기준점은 용병도감,로비,장비강화”.

## 기준 화면

- 현재 로비: `js/adventure-lobby-v2107.js`. 공통 왼쪽 분류 메뉴, 해당 분류만 여는 창, 모바일 하단 전체 메뉴를 재사용한다. 로비 메인 아바타 구도를 보존한다.
- 용병도감: `mercenary-codex/index.html`, `style.css`. 목록 → 선택 원화 → 상세 정보의 위계, 압축된 제목·상태 표시, 어두운 패널과 라임 선택 상태를 계승한다.
- 장비강화: `equipment-forge/index.html`, `live.css`, `preview/equipment-forge-v1/style.css`. 중앙 자산 무대와 실제 조작 패널의 구분, 재질·테두리·버튼 상태를 계승한다.

## 적용 원칙

- 공통 색: 배경 `#080c17`, 패널 `#111828`, 경계 `#28324a`, 본문 `#f3f5ff`, 보조문 `#8b97b0`, 라임 `#c8ff6b`.
- 기존 Noto Sans KR 한글과 Barlow Condensed 숫자·영문 조합을 사용한다. 의미 없는 영문 장식과 거대한 홍보 제목으로 실제 조작을 밀어내지 않는다.
- 신규 독립 화면도 `adventure-navigation-standalone.js`의 운영 공통 메뉴를 연결한다. 개별 화면별로 메뉴를 복제하지 않는다.
- 실제 제품·캐릭터·장비 자산을 중심으로 선택과 교환 내용을 명확히 보여준다. 과장된 임의 가격·수량·등급은 쓰지 않는다.
- 데스크톱과 모바일에서 선택, 상세 확인, 확인창, 오류, 미설정 상태, 스크롤과 메뉴 접근을 직접 검수한다. 기능 테스트와 시각 검수 결과는 별도로 기록한다.

## 고급 전리품 상점

위 기준을 최초 적용한다. 경제 정책은 별도 사용자 답변 “미정 — CMS 설정 후 활성화”를 따르며, 정책 저장·활성화 전 판매와 콘텐츠별 피그 코인 지급을 OFF로 유지한다.
