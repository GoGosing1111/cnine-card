# 세금·방치형 원정 종료와 군단토벌 메뉴 연결 — 2026-10-01

사용자 지시: 세금 시스템과 방치형 원정을 삭제하고 API를 중단한다. 군단토벌을 모험 메뉴에 연결한다.

- 세금·방치형 원정의 PC/모바일 공통 메뉴, 구형 메뉴, 자동 로더 및 방치형 원정 CMS 진입을 제거했다. 군단토벌은 모험 메뉴에서 기존 입장 화면으로 연결한다. 서버의 기존 콘텐츠 접근 조건은 유지한다.
- `administration/treasury`와 `idle-dungeon`, `admin/idle-dungeon`의 전체 하위 경로는 HTTP 410을 반환한다. 공개 API 최상단에서 서비스 바인딩 전달·인증·DB 연결 전에 차단하며, 구형·V3·관리자·직접 내부 호출도 차단한다. 설정을 ON으로 저장해도 다시 열리지 않는다.
- 일반 카드팩·슈퍼스타팩·프라임 상품·아바타 구매의 세금 적립과 스키마 초기화 연결을 제거했다. 구매 가격·차감·지급·영수증·재시도 보호는 유지한다.
- 원정의 시간 정산, 세션 갱신, 코인 수령과 계급 경험치 지급을 제거했다. 별도 원정 cron은 없으며, 기존 DB 진행 기록이 남아 있어도 이를 진행·지급하는 운영 경로가 없다. 과거 순수 계산 시뮬레이션은 오프라인 회귀용으로만 남긴다.
- 기존 잔액·감사 원장·이미 지급된 보상은 삭제하거나 환수하지 않는다. 종료 전에 확정된 승부예측 지원금은 기존 경기의 정산·무효 환입만 보존하며 신규 지원금·예산 승인은 중단한다.

## 검증과 배포 범위

인증·DB 기반·공용 전투·의존성을 바꾸지 않는 콘텐츠 종료와 메뉴 연결이다. 전체 출시 검사 대신 지정 `--scoped` 배포를 사용한다. 기존 출시 플래그와 Hyperdrive cache OFF 검사는 유지한다.

- 종료 API 회귀: 실제 `onRequest`에서 구형/V3/관리자 경로와 GET·POST·PATCH·OPTIONS를 검증. DB나 바인딩 접근 시 실패하는 환경에서도 410을 반환한다. 직접 지급/경험치 호출도 차단한다.
- 관련 회귀: 세금 종료/기존 지원금 중복 환입, SQLite·PostgreSQL 슈퍼스타팩 거래, 프라임·아바타 구매 연결, 승부예측 환불, 원정 잔액 보존, 계급 경험치 중단, 공통 메뉴 계약. 초기 관련 검사 98건 중 캐시 접두사·새 테스트의 초기 스키마·보존된 순수 시뮬레이션 import 문제를 수정하고 실패 범위만 재검증했다.
- 실제 index.html의 PC 1440×1000·모바일 390×844에서 모험 → 군단토벌 입장 화면을 확인했다. 두 메뉴 제거, 구형 API 호출 0건, 열기만으로 전투 시작 요청 0건, 가로 잘림 없음, 브라우저 오류 0건이다.
- UI 증빙: 작업 트리 밖 `../retired-content-qa-20261001/`. 관련 검사 로그: `../retired-content-tests-20261001.log`.
- 배포 단계에서는 최종 종료 API 회귀와 Worker 구문 검사 및 지정 운영 보호만 실행한다. 이미 통과한 구매·계급·메뉴 검사를 반복하지 않는다.

직전 운영 기준은 Cloudflare Pages 배포 `da6aab90-619d-46f1-8a47-441a93ea261c`의 소스 `6b24fc2f0e7bf433590af99ef69d953977231613`이다. 선행 랭크전 전체 게이트와 운영 배포가 끝난 뒤 이 기준으로 통합했다. 그 이후 원격의 선물 안내 수정 기록은 문서만 변경한다.

배포 선택: `SCOPED_DEPLOY_TESTS=["tests/retired-content-20261001.test.mjs"]`, `SCOPED_DEPLOY_CHECKS=["check:worker"]`. 관련 거래·정산·메뉴 검사는 위 결과를 유지하며 최종 병합 소스의 API 차단과 Worker 컴파일만 확인했다.
