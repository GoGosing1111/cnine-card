# 랭크 듀오 랜덤 비동기 개편

사용자 요청: 시즌 고정 팀을 없애고 매칭마다 무작위로 팀을 구성해 비동기 교전. 점수는 **매칭을 시작한 사람만 반영**한다.

## 동작

- 새 시즌 모드 `RANDOM_ASYNC`: 요청자 + 무작위 파트너 1명 대 무작위 상대 2명. 네 명은 서로 다르며 온라인 여부와 무관하다. 우리 팀의 공격 덱과 상대의 방어 덱을 전투 직전에 다시 읽는다. 같은 동료·상대가 재선정될 수 있다.
- 개인 점수·승패·행동력·승리 보상은 요청자만 변한다. 네 사람의 전투 기록과 다시보기 권한은 영수증에 보존하고, 다른 사람의 매칭에는 점수 미반영을 표시한다.
- 대전 기간에도 참가 가능, 홀수 참가자 편성 대기 없음. 매칭은 유효한 네 명이 있어야 시작한다. 시작 후 참가 취소는 개인 기록 초기화를 막기 위해 금지한다.
- 개인 기록이 있는 사람만 시즌 순위·보상·트로피 대상이다. 상위 10명 챌린저이며 기존 티어 수치·보상액·24시간 모집/7일 전투 정책은 유지한다.
- 현재 운영 OFF·자동 모집 OFF 유지. 닫힌 시즌 4의 참가 73건과 모든 기존 고정 팀 기록을 보존한다. 새 일정·개시·참가 이관·보상 지급을 실행하지 않는다.

## 구현과 보호

`functions/_ranked_duo_random.js`의 전용 v4 테이블에 개인 점수, 일시적인 매칭 표, 네 명의 영구 전투 참가 기록, 최종 개인 순위를 저장한다. 새 랜덤 시즌을 만들 때만 스키마를 준비한다. 과거 모드 미지정 시즌은 `FIXED`로 읽어 기존 전투·순위·보상 경로를 유지한다.

전원 무작위 정렬이나 전체 인벤토리 조회 대신 무작위 피벗으로 두 인덱스 범위를 최대 12건씩 읽고, 최신 프로필은 요청자를 포함해 최대 12명만 읽는다. 90초 매칭 표를 재사용해 동시/반복 매칭의 새 추첨을 막는다. 출전 시 시즌·정책·네 명의 계정/덱 버전·참가/제한 상태·요청자 행동력·매칭 표를 한 거래에서 검사한다.

기존 전투 영수증·서버 시뮬레이션·리스 복구를 사용한다. 접수는 행동력·사용한 매칭 표·전투 입력·네 명의 기록을 함께 저장하고, 정산은 요청자 점수·승패·승리 코인·결과를 함께 저장한다. 동일 요청과 장애 복구는 같은 영수증으로 처리하며 복구 불가 시 행동력을 한 번 환불한다. 시즌 종료는 미완료 전투를 먼저 복구한 뒤 개인 순위를 고정한다.

`js/ranked-duo-random-v4.mjs`와 전용 CSS를 기존 진입·V3 전투 재생에 연결했다. 로비·매칭·개인 순위·전투 기록·티어·결과·오류 복귀·OWNER CMS에 전용 이미지 패널/버튼을 사용한다. ImageGen 원본 2종, 파생 WebP, 실제 프롬프트·해시는 `assets/ui/ranked-duo/random-20261020/`에 보존한다. 숫자·문구는 DOM이다. 기존 듀오 문장/트로피는 같은 콘텐츠 안에서 유지한다.
