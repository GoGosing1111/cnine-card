# 솔바인 호위 수정 · SS 원거리 PVP 재조정 (2026-09-17)

## 범위와 운영 데이터

사용자 지시: 솔바인 개선, 지난번 상향한 SS 원거리를 동급 근거리와 비슷한 승률로 재조정.
기준 전투 코드는 2161b288, 운영 CMS revision 55다. 신규 스킬 배정이나 CMS 원본 수치 변경 없이 이미 배정된 스킬의 서버 동작을 수정했다.
등급·전투력·능력치·카드 5장 + 별도 용병 1장·개봉 확률·보유 자산은 유지한다.

## 솔바인 / 황금 구명선

- 자기 자신을 대상에서 제외하고, 최저 HP 비율의 생존 아군에게 즉시 설치한다. 혼자 남으면 비용 없이 정상 기본 공격한다.
- 설치 행동에 50% 위력 기본 공격을 함께 수행한다. 별도 행동을 생성하지 않으며 이 공격은 에너지를 회복하지 않는다. 이후 일반 기본 공격은 정상 위력·자원 회복을 사용한다.
- 준비에 두 행동을 소모하던 구조를 제거했다. 유효한 호위가 남아 있으면 중복 시전·재차 과금을 하지 않는다.
- 유지 시간을 빠르게 돌아오는 솔바인 행동 대신 보호 대상 행동으로 계산한다. 현재 정책에서는 대상의 두 번째 행동 전까지다.
- 기본 공격뿐 아니라 단일 용병 공격 스킬도 첫 명중 한 번을 보호한다. 현재 40% 이전, 비용 15, 재사용 대기 3은 유지한다.
- 광역·지속 피해·반격·고정 피해·보스 기믹은 제외한다. 사망·기절·침묵 중에는 보호하지 않는다.
- 보호자가 실제로 받은 HP/방벽 피해만 원래 공격에서 차감한다. 보호자가 죽을 때 남은 이전량을 공짜로 무효화하거나 호위를 연쇄 발동하지 않는다. 피해 원 소유자는 공격자다.

## 지난번 상향한 SS 원거리 6종

SS + 해당 원거리 기믹 + PVP인 경우에만 스킬 배율과 타격 상한에 아래 계수를 곱한다.
기본 공격·PVE·S등급·비용·재사용 대기·즉시 사격·연사 보정은 유지한다. 경찰 조은·하이희야 등 이전 상향 범위 밖의 SS 원거리는 변경하지 않는다.

| 용병 | PVP 스킬 계수 | 기존 승률 | 수정 후 | 별도 난수 검증 |
|---|---:|---:|---:|---:|
| 베스페라 | 86% | 59.5% | 51.7% | 52.1% |
| 련화 | 81% | 68.8% | 49.8% | 51.1% |
| 네레이아 | 82% | 66.7% | 51.2% | 50.9% |
| 아델린 | 84% | 64.6% | 53.7% | 53.2% |
| 마리엘 | 84% | 66.4% | 53.3% | 53.7% |

네레이아는 MS-032·MS-036 두 배정 스킬에 82%를 적용한다. 한 행동의 두 발은 보정된 공통 피해 상한을 분할한다. CMS 원본 피해 배율에 이 계수를 적용하므로 향후 운영자 수치 변경도 계속 반영된다.

## 비교 조건과 검증 한계

- 양쪽 일반 카드 전력·구성을 동일하게 맞춘 5+1 PVP다. 카드당 10만·100만·2,000만, 혼합·공격·방어·속도 덱, A/B 양쪽으로 비교했다.
- 현재 SS 근거리 로스터는 월령(V-010) 한 종이므로 SS 표는 월령 대비 결과다. 모든 등급/직업 또는 실사용자 랭크전 승률을 의미하지 않는다.
- 수치 조정 표본 n=1~128, 별도 검증 표본 n=1001~1128, seed=n×7919. 각 SS당 각각 3,072전/버전이다. 솔바인과 최종 SS 비교는 총 116,736전이다.
- 덱별 상성은 남으며 표의 평균 승률을 개별 조합의 승률로 해석하지 않는다. 스킬 조건/선택/캡에 승패나 난수 강제 보정은 넣지 않았다.
- 대상 외 37종 PVP 14,208개와 솔바인 외 43종 일반/아포칼립스 PVE 6,192개는 수정 전후 전체 전투 반환값이 일치했다.
- 솔바인 PVE는 각 전력당 128전씩 추가 비교했다. 직접 피해가 약 두 배로 늘어난 것은 준비 행동 손실 감소에 따른 결과이며 공격력 수치를 올리지 않았다.

## 구현과 출시 검증

- 서버: functions/_mercenary_combat.js. SS 계수: shared/mercenary-ranged-balance-v1.mjs. 호위 정책/표시: shared/mercenary-guard-balance-v1.mjs.
- 도감·보유 용병·CMS 읽기 전용 적용 규칙을 같은 정책 함수로 표시한다. CMS 원본·배정·금액·확률에는 쓰기 작업이 없다.
- 회귀: 자기 대상, 빈 아군, 즉시 설치, 보호 대상 시간, 단일 스킬/연타/광역/DOT/반격, 치명적 이전량, 중복 설치, 제어 상태, 자원/행동 수, PVP 한정 계수/캡/등급, 실제 서버 PVP 승률 범위.
- 실제 게임 index.html의 토벌·PVP 시작 → 전투 → 결과 → 복귀, PC 1440×1000 / 모바일 390×844, 도감·CMS 설명을 검수한다. 재입장·구버전 갱신·입장 오류 복구도 동일 경로로 확인한다. 계정/전투 API는 격리 검수 데이터를 사용하며 운영 재화를 소비하지 않는다.
- 기존 PixiJS·GSAP·연속 프레임·메인 로더·엔진 버전은 재사용한다. 새 원화·SD·이펙트는 추가하지 않았다.
- 최종 깨끗한 범위 커밋을 main에 통합한 뒤 npm run deploy:production으로 전체 release:gate를 통과시키고 배포한다. 배포 후 실제 운영 정적 파일로 입장 경로를 다시 확인한다.
- 롤백은 이 범위 커밋을 되돌리고 동일 출시 검사를 통과시켜 배포한다. 별도 DB 마이그레이션/역변경은 없다.
