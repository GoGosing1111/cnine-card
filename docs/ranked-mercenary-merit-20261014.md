## 변경

- **상대 선정 전력 = 카드 5장 + 기존 캐릭터 장비·강화·차량·칭호 보너스.** 용병 본체와 용병 전용 장비의 기여 전력은 상대 선정 계산에서 제외한다. 모든 용병에 동일하게 적용하며 발테르 전용 예외나 다른 용병 강제 매칭은 없다.
- 실제 전투에 전달하는 용병 능력치·장비·스킬은 그대로다. 경기 결과, 시즌 점수, 에너지와 보상 계산을 변경하지 않는다.
- 발급 티켓에는 기존대로 **용병을 포함한 전체 편성 전력**을 저장한다. 전투 직전 전체 전력 대조를 유지해 용병 전력 교체도 기존 변경 검증에서 걸러진다.
- 티켓 재조회는 두 계정의 현재 PVP 용병을 한 번에 읽어 같은 매칭 기준을 재확인한다. 전체 후보·덱을 다시 조회하지 않고, 유효한 상대·토큰은 유지한다. 기존 티켓도 같은 열을 사용하므로 마이그레이션이 없다.
- 시즌 점수 제한·카드/장비 전력 제한, 최근 상대 회피, 3연속 상대의 대체 후보 우선, 96명 단위·최대 768명 조회를 유지한다.

## 유저 공지 원고

**랭크전 매칭 개선 안내**

강력한 용병을 편성했을 때 비슷한 용병을 사용하는 소수 상대에게 매칭이 몰리던 현상을 개선했습니다.
