# 숲켓랜드 v2039 · 보상 개편 v2088 · 랜덤카드 상품 삭제 v2089

## 사용자 확정 조건

- 행정부의 스트리머 전용 방송 이벤트. 빠찡코식 구슬 충돌 → 릴 순차 정지 → 당첨 공개.
- 대상: 진짜디임 / 조은 / 오리꿍 / 강구열 / 하이희야♡ 및 OWNER.
- 자동 일일 횟수 없음. OWNER가 발급한 이용권으로만 플레이.
- 당첨 보상은 시청자 공유용 쿠폰 코드로 스트리머 메시지함에 보관.
- 2026-09-13 하이퍼버닝 발동권을 신규 추첨 보상에서 제거했다. 이전에 지급된 발동권의 ×15·60분 사용 계약은 유지한다.
- 같은 날 후속 지시로 제니스 랜덤카드와 FUR 랜덤카드를 상품 정의·추첨 후보·OWNER 확률 입력에서 삭제했다. 기존 0% 항목이므로 남은 상품의 가중치는 바꾸지 않는다.

## 운영 방법

1. OWNER가 전체 메뉴 → 행정부 → 숲켓랜드 진입.
2. 최초 OWNER 조회에서 위 5개 닉네임을 정확히 찾아 안정적인 계정 ID에 일회 연결. 중복/미등록/비활성 계정은 자동 연결하지 않고 OWNER에게 표시. 이후 닉네임 변경으로 다른 계정에 권한이 넘어가지 않음.
3. 하단 OWNER CONTROL에서 대상, 이용권 수량, **쿠폰당 사용 인원**을 입력하고 확인 후 지급. 기본 입력은 1개·1명. 확인창의 코인 최대 지급액은 서버 보상 상한(50억) × 쿠폰 사용 인원으로 계산한다. 대상은 위 등록 ID 또는 OWNER뿐.
4. 스트리머는 인벤토리 이용권 버튼 또는 행정부 → 숲켓랜드에서 실행.
5. 코인/슈퍼스타팩 확정권/마스터의 별/블랙미라클/미스틱 에너지 쿠폰을 메시지함에서 복사해 공유. 시청자는 기존 쿠폰 사용 화면에서 입력. 한 계정은 같은 코드 1회만 사용.
6. 과거 지급된 하이퍼버닝 발동권은 스트리머 인벤토리에서 사용 확인. 진행 중인 버닝이 있으면 차감 없이 거부하며, 기존 행정부/OWNER 버닝 설정 권한은 변경하지 않음.

쿠폰 사용 인원은 OWNER의 발급 시 선택으로 제공한다. **이용권은 자동 지급하지 않는다.**

## 보상과 확률

- 코인 1~50억 (1억 단위)
- 슈퍼스타팩 확정권 1개 (5%). 시청자 쿠폰 수령 → 인벤토리 보관 → 100% 슈퍼스타 1장 개봉. 중복도 카드로 지급하며 기존 강화·전직 상태 보존.
- 마스터의 별 1,000~30,000 (1,000개 단위)
- 블랙미라클 카드 (`BLACK_MIRACLE_PACK`) 10~20개 랜덤 (1개 단위). 기존 개봉 플래그는 변경하지 않음.
- 미스틱 에너지 1~50개 (10%, 각 수량 동일 확률)
- ZENITH/FUR 랜덤카드·하이퍼버닝 발동권·고등급 재뽑기권·이예준 지정 카드는 신규 추첨에서 제외. 과거 발급 쿠폰은 원래 보상을 유지.

2026-09-08 보상 개편: 슈퍼스타팩 확정권 가중치 500(5%), 미스틱 에너지 1000(10%), 남은 6종 합계 8500(85%). 기존 설정은 잔여 보상 간 비율을 보존해 10000 총합으로 변환한다. OWNER는 이후 개별 가중치를 변경할 수 있다. 0은 제외. 수량 구간은 동일 확률이며 서버 Web Crypto 난수로 결정한다.

2026-09-13 사용자 지시로 하이퍼버닝 확률을 코인·마스터의 별·블랙미라클에 균등 재분배한다. 반올림 손실 없이 처리하기 위해 기존 가중치를 모두 3배하고 세 대상에 각각 기존 하이퍼버닝 가중치를 더한다. 이 변환은 한 번만 수행한다. 후속 랜덤카드 삭제에서는 7종 설정의 ZENITH/FUR 키만 제거하며, 저장된 5종 설정은 조회·재배포에서 그대로 유지한다. 가중치는 상대 비율이며 편집 범위는 0~40,000으로 이전 가중치의 최대 변환 결과까지 수용한다.

운영 변경 전 실제 유효 확률은 코인 28.33%, 마스터의 별 28.33%, 블랙미라클 14.17%, 하이퍼버닝 14.17%, 슈퍼스타팩 5%, 미스틱 10%, ZENITH/FUR 0%였다. 현재 5종 가중치는 코인 9,916 / 마스터의 별 9,916 / 블랙미라클 5,668 / 슈퍼스타팩 1,500 / 미스틱 3,000, 합계 30,000이다. 코인·별은 각각 33.053333…%, 블랙미라클은 18.893333…%다. 수량·하이퍼버닝 변경은 운영 작업 `soopketland-rewards-20260913-v1`, 랜덤카드 키 삭제는 `soopketland-rewards-20260913-v2`로 변경 전후 스냅샷을 보존한다.

쿠폰은 발급 당시 당첨 수량을 그대로 지급한다. 이전 블랙미라클 1~20개 쿠폰도 유효하며 신규 추첨만 10개 하한을 적용한다. 코인 50억 및 재화 상한 지급은 SQLite와 PostgreSQL의 실제 지급·감사·중복 방지 경로로 검수한다. 운영 코인 잔액·감사 컬럼은 BIGINT다.

과거 발급된 랜덤카드 쿠폰은 활성·공개 카드/활성 멤버, 무제한 발행 카드만 대상으로 하고 기존 전역 랜덤 드랍 제외 규칙을 적용한다. 전역 카드팩 정책은 변경하지 않는다. 숲켓랜드 안에서만 이예준 ID `CN-346F8DB0DEB84D41`를 과거 FUR 쿠폰의 후보에서도 계속 제외한다. 과거 지정 쿠폰만 호환 지급한다. 지정 카드도 활성·공개·무제한 발행·활성 멤버 검증을 통과해야 한다. 지급 가능한 후보가 없으면 쿠폰 사용과 보상 지급 모두 취소. 장마다 독립 추첨(중복 가능)하고 중복 카드는 당첨 장수만큼 합산 지급하며 강화/전직 상태는 보존한다. 한 번의 쿠폰 사용에서 모든 카드와 사용 영수증을 원자적으로 반영한다. 기존 발급 쿠폰의 당첨 수량과 사용 인원은 바꾸지 않는다.

## 무결성 / 보안

- 티켓 발급 lot + 인벤토리 수량을 함께 검증. 인벤토리 수량만 임의 추가해도 회전 불가.
- 발급, 회전, 쿠폰 지급, 버닝 활성화 각각 영속 요청 ID 및 재시도 영수증.
- 신규 회전 트랜잭션에 티켓 차감, lot 차감, 당첨 기록, 쿠폰, 메시지 저장을 포함.
- 쿠폰 트랜잭션에 인원 한도, 1계정1회, 지급, 감사로그, 수령 영수증을 포함.
- PostgreSQL 사용자/쿠폰/lot/버닝 메타 row lock과 SQLite 트랜잭션 적용. CHECK 제약 가드 실패/메시지·로그 실패는 전체 롤백.
- OWNER의 발급/설정 요청도 브라우저 새로고침 후 같은 요청 ID로 재확인.
- 접속/실행 권한은 서버에서 확인. 공개 라운지 데이터에 게임 계정 ID를 추가하지 않음.
- 새 룰렛/버닝 API는 기존 거대 런타임 마이그레이션 게이트를 기다리지 않는 전용 소형 스키마 경로.
