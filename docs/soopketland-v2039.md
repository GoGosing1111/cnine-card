# 숲켓랜드 v2039

## 사용자 확정 조건

- 행정부의 스트리머 전용 방송 이벤트. 빠찡코식 구슬 충돌 → 릴 순차 정지 → 당첨 공개.
- 대상: 진짜디임 / 조은 / 오리꿍 / 강구열 / 하이희야♡ 및 OWNER.
- 자동 일일 횟수 없음. OWNER가 발급한 이용권으로만 플레이.
- 당첨 보상은 시청자 공유용 쿠폰 코드로 스트리머 메시지함에 보관.
- 하이퍼버닝: 서버 전체 ×15, 60분. 원 요청의 ‘스트리머가 인벤토리에서 사용’ 조건을 따라 발동권만 스트리머에게 직접 지급.

## 운영 방법

1. OWNER가 전체 메뉴 → 행정부 → 숲켓랜드 진입.
2. 최초 OWNER 조회에서 위 5개 닉네임을 정확히 찾아 안정적인 계정 ID에 일회 연결. 중복/미등록/비활성 계정은 자동 연결하지 않고 OWNER에게 표시. 이후 닉네임 변경으로 다른 계정에 권한이 넘어가지 않음.
3. 하단 OWNER CONTROL에서 대상, 이용권 수량, **쿠폰당 사용 인원**을 입력하고 확인 후 지급. 기본 입력은 1개·1명. 대상은 위 등록 ID 또는 OWNER뿐.
4. 스트리머는 인벤토리 이용권 버튼 또는 행정부 → 숲켓랜드에서 실행.
5. 코인/재뽑기권/마스터의 별/블랙미라클/ZENITH/FUR 쿠폰을 메시지함에서 복사해 공유. 시청자는 기존 쿠폰 사용 화면에서 입력. 한 계정은 같은 코드 1회만 사용.
6. 발동권은 스트리머 인벤토리에서 사용 확인. 진행 중인 버닝이 있으면 차감 없이 거부하며, 기존 행정부/OWNER 버닝 설정 권한은 변경하지 않음.

쿠폰 사용 인원은 아직 별도 확정 답변이 없으므로 OWNER의 발급 시 선택으로 제공한다. 하이퍼버닝 발동권의 시청자 쿠폰화 여부도 추가 확인 질문을 했으며, 현재는 원 요청의 스트리머 직접 사용 기준이다. **이용권은 자동 지급하지 않는다.**

## 보상과 확률

- 코인 1~5억 (1억 단위)
- 고등급 재뽑기권 1개
- 마스터의 별 1,000~5,000 (1,000개 단위)
- 블랙미라클 카드 (`BLACK_MIRACLE_PACK`) 1~3개. 기존 개봉 플래그는 변경하지 않음.
- 하이퍼버닝 발동권 ×15·60분 1개
- ZENITH 랜덤카드 1장
- FUR 랜덤카드 1장

기본 7종 동일 가중치 10. OWNER가 항목별 0~10,000으로 조절하며 0은 제외. 최소 1종은 활성화해야 함. 수량 구간 안에서는 동일 확률. 서버 Web Crypto 난수로만 선택하며 기계 물리/릴 연출은 지급 결과에 영향을 주지 않음. 가중치는 기존 드랍풀과 분리.

랜덤카드는 활성·공개 카드/활성 멤버, 무제한 발행 카드만 대상으로 하고 기존 전역 랜덤 드랍 제외 규칙을 적용. 새 FUR 예외 등 현재 전역 정책을 재정의하지 않음. 지급 가능한 후보가 없으면 쿠폰 사용과 보상 지급 모두 취소. 기존 보유 카드 중복은 수량만 +1, 강화/전직 상태 보존.

## 무결성 / 보안

- 티켓 발급 lot + 인벤토리 수량을 함께 검증. 인벤토리 수량만 임의 추가해도 회전 불가.
- 발급, 회전, 쿠폰 지급, 버닝 활성화 각각 영속 요청 ID 및 재시도 영수증.
- 회전 트랜잭션에 티켓 차감, lot 차감, 당첨 기록, 쿠폰 또는 발동권, 메시지 저장을 포함.
- 쿠폰 트랜잭션에 인원 한도, 1계정1회, 지급, 감사로그, 수령 영수증을 포함.
- PostgreSQL 사용자/쿠폰/lot/버닝 메타 row lock과 SQLite 트랜잭션 적용. CHECK 제약 가드 실패/메시지·로그 실패는 전체 롤백.
- OWNER의 발급/설정 요청도 브라우저 새로고침 후 같은 요청 ID로 재확인.
- 접속/실행 권한은 서버에서 확인. 공개 라운지 데이터에 게임 계정 ID를 추가하지 않음.
- 새 룰렛/버닝 API는 기존 거대 런타임 마이그레이션 게이트를 기다리지 않는 전용 소형 스키마 경로.

## 렌더링 / 복구

- `js/soopketland-v2039.src.js` → `npm run build:soopketland` → 운영/프리뷰 공용 번들.
- PixiJS WebGL, GSAP 타임라인, 물리 구슬·핀 충돌, 3단 릴 정지, 별도 JACKPOT 공개와 입자.
- 모바일 실행 시 기계 위치, 완료 후 결과로 이동. 기본 음소거, 켜도 최대 10%.
- 연출 건너뛰기, 동작 줄이기, 숨김 탭, 12초 시계 기반 종료.
- 자산 로드가 느리거나 WebGL 실패해도 2.5초 뒤 확정된 결과를 HTML로 표시. 연출 실패가 보상 재추첨을 유발하지 않음.
- 독립 프리뷰: `/preview/soopketland-v2039/`. 프리뷰는 실제 티켓/보상/쿠폰을 절대로 사용하지 않음.
- 자산 생성 프롬프트, built-in 모드, 파일 해시 및 기존 녹음 SFX 출처: `assets/ui/soopketland/PROVENANCE.md`.

## 검증

- `npm run test:soopketland`: 권한, 일회 ID 바인딩, 소유권 변경, 무티켓, 동시 실행/동시 수령, 영수증 재시도, 원자성, 카드 제외, 버닝 정책, 프리뷰/라이브 연결.

- 기존 출시 테스트 전체 재검증. 기존 테스트 중 변경된 부분은 앱/SW 캐시 태그와 행정부 메뉴 신규 항목뿐.
- 라이브 배포 전 `npm run release:gate`, 배포는 `npm run deploy:production`만 사용.
- QA 중 실제 이용권/쿠폰을 발급하거나 서버 버닝을 활성화하지 않는다.
