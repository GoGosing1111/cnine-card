# SSS 궁사 화살 중심 V2 — 2026-10-18

사용자 요청: “주작 관련 리소스 다 폐기하고 화살 위주의 강력한 캐릭터로 다시 만들어”.

승인 원화·원본 활·몸 동작 24장을 보존하고, 주작과 관련한 이전 효과·원본·파생 파일·영상을 180개 폐기했다. 폐기 색인과 해시는 `preview/mercenary-imperial-archer-sss-v1/retired-phoenix-20261018.json`에 남겼다. 옛 10월 14일 아우라/강림 기록은 제작 이력이다.

새 효과는 강궁 충전, 실체가 보이는 관통 화살, 갑주 파열, 일곱 화살 집중 사격, 광역 화살비, 거대 화살의 지면 파열이다. 6개 독립 시트 × 12프레임을 built-in image_gen으로 생성했고 원본·프롬프트·해시를 실제 프리뷰 소비 파일에 연결했다.

일반 공격은 .85초 발사 / 1.18초 관통, 단일기는 5회 고속 사격 후 일곱 화살의 집중 사격, 광역기는 천공 화살 → 15회 지면 접점 → 4.05초 대형 화살 마무리다. 수치와 타수는 시각 시연용이며 운영 전투 수치와 연결하지 않았다.

사용자 후속 “불필요한 UI 리소스는 왜만드는데”를 반영했다. 불필요하게 생성한 패널·버튼 2개는 프로젝트에서 제거했고 사용하지 않는다. 기존 프리뷰 CSS·배치·공용 전장·카드 도크를 유지한다. 필요한 명칭·설명·효과 토글만 바꿨다. 공통 UI 이미지 규정에도 실제 요청 범위를 넓히지 않도록 보충했다.
