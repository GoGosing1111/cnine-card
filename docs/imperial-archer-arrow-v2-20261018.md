# SSS 궁사 화살 중심 V2 — 2026-10-18

사용자 요청: “주작 관련 리소스 다 폐기하고 화살 위주의 강력한 캐릭터로 다시 만들어”.

승인 원화·원본 활·몸 동작 24장을 보존하고, 주작과 관련한 이전 효과·원본·파생 파일·영상을 180개 폐기했다. 폐기 색인과 해시는 `preview/mercenary-imperial-archer-sss-v1/retired-phoenix-20261018.json`에 남겼다. 옛 10월 14일 아우라/강림 기록은 제작 이력이다.

새 효과는 강궁 충전, 실체가 보이는 관통 화살, 갑주 파열, 일곱 화살 집중 사격, 광역 화살비, 거대 화살의 지면 파열이다. 6개 독립 시트 × 12프레임을 built-in image_gen으로 생성했고 원본·프롬프트·해시를 실제 프리뷰 소비 파일에 연결했다.

일반 공격은 .85초 발사 / 1.18초 관통, 단일기는 5회 고속 사격 후 일곱 화살의 집중 사격, 광역기는 천공 화살 → 15회 지면 접점 → 4.05초 대형 화살 마무리다. 시각 타수는 아래의 한 시전 피해 예산을 공유한다. 운영 등록 전 준비 정책이며 실제 계정 전투는 아직 활성화하지 않았다.

사용자 후속 “불필요한 UI 리소스는 왜만드는데”를 반영했다. 불필요하게 생성한 패널·버튼 2개는 프로젝트에서 제거했고 사용하지 않는다. 기존 프리뷰 CSS·배치·공용 전장·카드 도크를 유지한다. 필요한 명칭·설명·효과 토글만 바꿨다. 공통 UI 이미지 규정에도 실제 요청 범위를 넓히지 않도록 보충했다.

사용자 후속 “성능은 베르칸 ,아잔트 상위로 밸런스 반영해라”에 따라 `balance.mjs`에 실제 실행 가능한 준비 정책을 반영했다. 비교 대상은 2026-10-15 동일 성능 정책인 V-055/V-056이다.

방어·회피·보호막·억제·기절·침묵·단일 공격 가로막기를 기존 전투 계산에 적용한다. 관통은 연출 콘셉트이며 방어를 무조건 무시하지 않는다. 화살비는 PVE 전용이고 대상 수로 총 예산을 나눈다. 6회 시각 접점이나 마지막 거대 화살은 추가 피해·행동·자원 회복을 만들지 않는다. 특정 상대 코드에 대한 피해 면역·강제 승리·전용 상성 보정은 없다.

검증은 `balance-engine.mjs`가 현재 공용 전투 엔진의 메모리 모듈에만 준비 정책을 연결한다. 별도 전투 계산식을 복제하지 않으며 삽입 지점이 달라지면 실패한다. V-000은 프리뷰 별칭이다. 운영 코드·이름·팩·CMS·계정 보유분을 등록하지 않는다. 재현 명령은 `node preview/mercenary-imperial-archer-sss-v1/measure-balance.mjs`, 결과는 `qa/arrow-v2/balance-report.json`이다.

동일 덱·장비·마법·난수와 양 진영으로 **1,056전** 비교했다. PVP는 베르칸 상대 384전 중 377승, 아잔트 상대도 384전 중 377승(각 98.18%)이다. 이는 해당 동일 조건 모의 대전 결과이며 운영 승률을 의미하지 않는다. 12개 보스/장비 조건 × 8개 난수 × 3용병의 PVE 288전에서 모두 클리어했고, 새 궁사는 평균 클리어 행동이 15.36~35.66% 감소했다. 용병이 담당한 누적 피해는 7.34~13.68% 증가했다. 짧아진 전투의 누적 피해이므로 이를 DPS 상승률로 표시하지 않는다.

`balance.test.mjs`는 실제 상위 능력치, 1회 자원/재사용·피해 예산, 억제·회피·보호막·대상 부재, PVP 광역 제외, 1/5/12대상 광역, 추가 행동·듀오 소유자 격리, 현재 보고서 해시와 미선택 운영 전투 6개의 전체 결과 동일성을 검사한다. 운영 전투 모듈 원본과 공통 번들은 변경하지 않았다.

- 수치 안내 연결 뒤에는 변경된 설명과 정책 연결만 `qa-balance-ui.mjs`로 PC·모바일 확인했다. 설명 잘림·가로 넘침·페이지 오류 없이 통과했고 `balance-ui-report.json`에 최종 번들 해시를 기록했다. 기존 효과 실행 코드와 타임라인은 같아 전체 영상 검사를 반복하지 않았다.

## 공개 범위

현재 원화/SSS 등급은 기존 확정, 새 효과는 사용자 시각 검수 대기다. 이름·코드·리미티드 지정·획득·운영 전투 연결은 미정이다. 기존 정적 프리뷰 주소를 화살 V2로 교체하며 운영 용병·계정·CMS·재화는 변경하지 않는다.

배포 기준은 직전 운영 소스 c3b7e2b47170b639d6e863cb2e74e636acc9ae77이며, preview/mercenary-imperial-archer-sss-v1/qa.test.mjs와 balance.test.mjs를 지정한 scoped 배포를 사용한다. 최종 배포 식별자와 운영 확인 결과는 완료 후 추가한다.

- 최종 PC·모바일 runtime-report PASS, 페이지 오류 0, 모든 일반/단일/광역 접점 오차 0, 지상 원점 오차 0, 효과 경계 잘림 0. 정상 배속 전체 재생 영상은 각각 약 24.5초이며 7.85/11.96/16.4/17.75초를 실제 디코딩해 관통·연사·화살비·대형 화살을 확인했다. 기술 시각 검수 상태와 사용자 시각 승인 대기를 분리했다.
