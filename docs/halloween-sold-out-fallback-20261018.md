# 할로윈 리미티드 소진 확률 → 일반 SSS

사용자 요청: “아예 이 멘트 안뜨고 나머지 확률 다 일반 sss로 돌려”.

기존에는 소진된 리미티드 구간이 당첨되면 개봉 전체를 취소했고 코인도 차감하지 않았다. 이제 할로윈 SS 7종·SSS 리미티드 3종 중 소진된 카드의 조건부 확률 전부를 일반 SSS로 돌린다. 다른 리미티드 확률이나 1단계 등급·꽝 확률을 재분배하지 않는다. 일반 SSS 내 카드 선택은 현재 CMS의 일반 카드별 가중치를 따른다.

10회 개봉 중 마지막 한정 수량을 먼저 사용한 뒤 같은 카드를 다시 뽑는 경우도 일반 SSS를 지급한다. 모든 리미티드가 소진돼도 판매 ON과 준비된 일반 풀이 있으면 계속 개봉한다. 일반 SSS 풀이 없거나 수량 원장이 미준비인 경우에는 결제 전에 차단한다.

동시 구매로 마지막 장을 놓친 요청은 같은 요청 번호를 유지한다. 미완료 계획 중 부족한 리미티드 슬롯만 일반 SSS로 바꾸고 대체 카드와 변경 근거를 먼저 영구 저장한다. 이후 지급 실패·응답 유실·복구에도 그 결과를 재추첨하지 않는다. 카드 지급·한정 발행·결제·완료 영수증은 기존 단일 거래로 처리하고 완료된 결과는 수정하지 않는다. 별도 SS 1회 확정권은 실제 해당 SS를 받았을 때만 소비하며, 받을 대상이 없으면 일반 팩 확률로 진행하고 확정권을 남긴다.

공개 API는 저장된 설정을 보존하고 현재 재고에 따른 `currentRates`, `effectiveNormalSssPercent`, `soldOutPolicy: STANDARD_SSS`를 제공한다. 계약실의 기존 전용 이미지와 수량 표시는 유지하고 추첨 안내만 수정했다. 가격·CMS 설정·발행 한도·보유량을 운영 작업으로 덮어쓰지 않는다.

검증: 관련 단위·격리 PostgreSQL 52개 통과. SS/SSS 10종의 소진 확률 경계, 일반 SSS 가중치, 부분/전체 소진, 묶음 개봉, 마지막 장 경합, 이전 미완료 계획 복구, 실패 롤백·응답 유실, 중복 결제 방지, 판매 OFF·설정 변경·풀 누락·확정권 보존을 확인했다. 1440px·390px 실제 계약실에서 전체 소진 상태의 10연속 SSS 지급, 단일 자동뽑기 2회 계속 진행, SSS 연출·건너뛰기, 수량·안내·모바일 가로 넘침 없음도 확인했다. 두 화면 모두 오류·누락 자산 0건이며 운영 계정 구매는 실행하지 않았다. 결과와 화면은 docs/qa/halloween-sold-out-fallback-20261018/에 보존한다. 운영 배포 결과는 완료 후 기록한다.
