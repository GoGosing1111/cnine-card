# 영토전 9거점·개인 편성 개편 (2026-10-11)

사용자 요청: “개편하고 클랜 팀분배가 아니라 개인분류로 다시 나누어”. 새 회차는 `warfare_version=6`을 사용한다.

## 변경한 동작

- 일직선에서 북부·중부·남부가 서로 연결된 9거점으로 변경한다. 여러 거점에서 동시에 공성·시설 교전을 진행한다.
- 본진과 연결된 아군 점령지에 인접한 거점을 공략한다. 적이 진입할 수 있는 아군 거점에는 방어 지원이 가능하다. 고립된 점령지에서는 추가 진격할 수 없다.
- 적 본진 점령 시 즉시 승리한다. 제한 시간 종료 시 점령 거점 수, 동률이면 누적 공성 피해로 판정하고 모두 같으면 무승부다.
- 개인별 인원·전투력·최근 5회 참여 이력으로 균형 편성한다. 같은 클랜도 다른 진영으로 배분하며 클랜 강제 로스터와 클랜 묶음 배분을 사용하지 않는다.
- 중지된 미개막 회차의 WAITING 명단을 다음 모집으로 한 번 승계한다. 진영과 클랜 강제 참가 표시는 초기화하고 새 모집 마감 시 개인 편성한다. 종료 회차 참가자는 자동 재신청하지 않는다.
- 개인 행동력·공격 횟수·교전 보상·회차 보상 정책을 유지한다. 개인 편성 회차에는 클랜 시즌 승점을 지급하지 않으며, 과거 회차 승점·보상은 보존한다.
- 25명 투표, 스킬별 45분 쿨타임은 유지한다. 직접 피해·회복·시설은 선택 거점에 적용하며 진영 작전 버프와 스킬 쿨타임은 회차 내 공유한다. 거점을 바꿔 쿨타임을 초기화할 수 없다.
- 직선 전진 단계에 의존하던 반격·최후 방어·피로 보정은 신규 지도에 적용하지 않는다. 기존 회차의 선형 전선 규칙은 그대로 처리한다.
- CMS 인해전술은 지원 거점을 선택한다. 해당 진영의 진입 경로와 현재 전장 ID를 검사하며 진영별 회차 1회 제한을 유지한다.

## 일관성과 저장

신규 `territory_network_rounds`, `territory_network_nodes`는 기존 회차·전장·시설·보상 테이블과 연결하는 추가 테이블이다. 스키마 정의와 마커는 `functions/_territory_network_v6.js`에 있다. 운영 소유자는 `neondb_owner`, 기존 실행 역할 `cnine_migrator`에는 해당 두 테이블의 DML만 부여한다. 적용 영수증은 `territory-network-v6-schema-20261011.json`에 기록한다.

편성·진입·점령·정산은 동일 회차 잠금과 트랜잭션 안의 상태 검증을 사용한다. 종료된 전장, 변경된 경로, 휴전·종료 중 요청은 행동력·코인·기여와 함께 롤백한다. 점령 후 해당 거점의 전장만 교체한다. 정산은 승자를 먼저 고정하여 보상 생성 재시도 중 추가 공격을 막는다.

클라이언트는 선택 거점 번호로 상태를 읽고 전장 ID를 공격·스킬 요청에 포함한다. 요청 순서가 뒤집힌 응답은 무시한다. 미완료 공격 영수증이 남아 있으면 먼저 기존 교전 결과를 확인한다. 순위·팀 인원 등 공통 요약 캐시는 거점을 바꿔도 공유하고, 거점 HP·접근 가능 여부는 새로 읽는다.
