## CMS 설정과 서버 판정

- 기존 용병 개봉 확률/합성 가중치 편집기에 `획득 허용` 체크박스를 추가했다. 가중치 0이 OFF, 양수가 ON이다. 설정 후 기존 저장 버튼으로 저장한다.
- 기존 CMS revision 검사, 요청 재시도, 변경 이력을 사용한다. 새로운 DB 테이블·마이그레이션·권한은 없다.
- OFF 카드는 하이퍼팩·합성 후보에서 제외한다. 지정 확정 지급도 OFF를 우회할 수 없다. 등급별 확률은 자동 변경하지 않으며, 해당 등급이 모두 OFF이면 개봉 준비 검사에서 차단한다.
- 공통 용병 지급의 기존 원자성 가드가 최신 CMS 설정을 같은 트랜잭션에서 확인한다. 과거 PENDING 추첨 계획·직접 보상도 OFF이면 지급과 차감을 함께 롤백한다. 이미 완료된 동일 획득의 재시도는 중복 지급하지 않고 허용한다.
- PostgreSQL은 기존 설정 한 행에 FOR SHARE를 잡아 OFF 저장과 지급의 선후를 정한다. 별도 카드별 네트워크 조회는 추가하지 않는다.
- 기존 보유 카드·편성·전투 사용에는 영향을 주지 않는다. 코드에 베르칸 영구 차단을 하드코딩하지 않는다.
- 운영 베르칸 OFF는 새 런타임 배포 후 `disableBerkanAcquisition`으로 현재 정책에서 V-055 가중치만 0으로 저장했다. 다른 운영자 수정은 보존했다.
