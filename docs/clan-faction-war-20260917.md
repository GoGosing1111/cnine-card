# 클랜 본부 개편 · 서울 세력전

## 사용자 확정

- 현재 로비의 공통 메뉴, 네이비 패널, 라임 강조색을 기준으로 클랜 본부와 클랜전 UI 개편.
- 서울 25개 자치구의 상권을 점령하는 별도 세력전. 정규 클랜 시즌 중 운영하며 정규 순위와 분리.
- 클랜장이 공격대·방어대를 편성. 침공 시 방어대원에게 공격 클랜·출정자 닉네임 팝업.
- 상대 부대의 공유 HP를 먼저 0으로 만드는 쪽이 승리.
- 점령 보호 2시간, 공격대 재출정 10분, 같은 지역 재공격 30분.
- 지역당 시간당 100만 **징수코인**. 정산 시 소속 클랜원에게 균등 분배.
- 몰이사냥 V3는 대기 상태를 유지하며 이 변경에 포함하지 않는다.

## 구현된 게임 규칙

| 항목 | 동작 |
|---|---|
| 입장 | 클랜·생활 → 클랜 → 세력전 |
| 시즌 | 드래프트 완료로 ACTIVE가 된 즉시 참여. 첫 정규전 starts_at 및 21시 대진 창과 분리하며 시즌 ends_at에 종료 |
| 최초 지도 | 25개 무주지. 기존 클랜 소속·정규 점수·승패는 그대로 유지 |
| 편성 | 공격대 2개, 방어대 2개. 부대당 최대 5명, 중복 배치 불가. 미편성 대기 인원 허용 |
| 출정 | 해당 공격대원 또는 클랜장이 실행. 인접 지역 제한 없음. 공격대당 진행 중 전투 1개 |
| 주둔 | 클랜장이 소유 지역마다 방어대 지정. 한 방어대가 여러 상권 방어 가능 |
| 무방비 지역 | 무주지 또는 방어대가 비어 있는 지역은 출정 즉시 점령. 버튼 위에 이 규칙 표시 |
| 공유 HP | 양측 각 1,000,000. 개인은 서버가 선택한 상대 부대원과 기존 V3 PVP로 교전 |
| 피해 반영 | 서버 전투의 상대 시작/종료 HP 감소 비율 × 공유 HP의 15%. 용병 HP 포함, 치유를 반영한 순감소, 과잉 피해 제외 |
| 재교전 | 개인 전체 전선 공통 60초. 일반 V3 승패 자체가 정규 클랜전 점수나 재화를 지급하지 않음 |
| 승부 | 공유 HP 0의 최초 확정으로 종료. 동시 막타는 시즌 상태 revision으로 직렬화 |
| 교전 기한 | 최대 30분. HP 승부 미확정이면 방어 유지. 시즌 종료도 방어 유지 |
| 재출정·재공격 | 전투 종료 또는 무방비 점령 시점부터 10분 / 30분 계산 |
| 징수세 | 소유 시간만큼 적립. 탈환 전까지의 수익은 이전 점령 클랜에 남음. 서버 시즌 종료시각 이후 적립 없음 |
| 분배 | 클랜원 누구나 공동 정산 실행. 현재 시즌의 소속 명단 전원에게 지급. 정수 나머지는 user_id 순으로 1개씩 배분 |
| 지갑 | 일반 코인과 별도의 영구 징수코인 잔액. 소비·교환 상품은 이 범위에 없음 |
| 지난 시즌 | 최근 24개 과거 시즌의 미정산 pool을 징수세 탭에서 정산 가능. 그 시즌 소속 명단 기준 |
| 침공 알림 | 로그인한 게임 화면에서 8초 간격으로 현재 침공 확인. 해당 방어대원만 수신. 숨긴 탭·다른 모달 재생 중에는 팝업 보류 |

브라우저를 닫은 상태의 OS 푸시 알림은 포함하지 않는다. 클랜장 최초 편성과 각 점령지의 방어대 배치는 운영자가 임의로 대행하지 않는다.

## 서버 경계와 저장

- `functions/_clan.js`의 인증·공개 모드·시즌 처리를 통과한 `clan/faction/*`만 새 모듈에 위임한다.
- `buildClanBattle`를 그대로 전달하여 최신 랭크전 5장, 전용 용병, 기존 장비·마법·고유효과와 V3 서버 판정을 재사용한다.
- `clan_faction_state`: 시즌별 25개 구역, 부대, 진행 전투, 쿨다운, 공동 수익. 최근 종료 전투 40개 / 이벤트 80개만 상태에 보관.
- `clan_faction_receipts`: 사용자+요청 키 유일성. HP·분배 결과의 작은 영수증을 보존하며 대형 전투 타임라인은 최초 응답으로만 전달.
- `clan_faction_wallets`: BIGINT 전용 재화 지갑. 기존 `users.coin`, 정규 대진·참여도·순위 테이블은 갱신하지 않는다.
- 상태 revision 교환, 처리 영수증, 전체 분배 지갑 갱신은 하나의 DB batch/transaction. 경쟁에서 진 요청은 모든 부수 효과가 0행이다.
- 저장 시 현재 소속, 클랜장 권한, 클랜원 명단, 시즌 상태, 실제 상대의 소속을 다시 조건으로 검사한다. 클라이언트 피해량은 사용하지 않는다.
- SQLite와 운영 PostgreSQL 호환 스키마를 `ensureFactionSchema`가 멱등 생성한다. 별도 계정 마이그레이션·기존 점수 재산정 없음.
- TEST 공개 모드에서는 징수코인 지급 차단. 세력전은 정규 클랜전과 동일한 공개 모드를 따른다.

## UI 및 재생

- `js/clan-v1.js`, `css/clan-command-v1.css`: 본부·정규전·세력전·클랜원·정규 순위·챔피언스리그 진입. 기존 정규 대진/드래프트/챔피언스리그 기능 유지.
- `js/clan-faction-v1.mjs`, `css/clan-faction-v1.css`: 실제 지도, 선택 지역 상세, 부대 편성, 수익 장부, 침공 팝업.
- `js/app.js` 공통 로그인 화면 연결로 클랜 화면 밖에서도 침공 알림 수신.
- 공용 `ensureFeatureResources('battleV2')`, `ProjectVBattleV3Live.ready()`, `prepareBattleV2LiveLoading`, `playPvpBattleV2Live`를 이용한다. 엔진·카드 프레임·SD·사운드를 새로 복제하지 않는다.
- 모바일은 지도 아래 지역 상세, 빠른 구역 선택, 지도 확대/축소, 가로 탭 스크롤을 제공한다.

## 출처

- 경계 원본: [southkorea/seoul-maps](https://github.com/southkorea/seoul-maps), KOSTAT 2013, Apache 2.0. 원본·라이선스·변환 내역은 `assets/ui/clan/seoul/NOTICE.md`.
- 지도는 게임용 도식이다. 상권명은 게임 표시용이며 지역 수익은 실제 경제 통계가 아니다.
- Workers 설계 참고: [Cloudflare best practices](https://developers.cloudflare.com/workers/best-practices/workers-best-practices/).

## 검증과 출시

- `npm run test:clan`: 기존 클랜·시즌·CMS와 신규 SQLite/PostgreSQL 검증 포함.
- `tests/clan-faction-v1.browser.mjs`: 1600×1080, 1440×560, 768×1024, 390×844, 320×740에서 71개 검사.
- `tests/clan-faction-live-entry.browser.mjs`: 실제 index → 공통 메뉴 → 세력전 → 공용 V3 캔버스 → 결과 → 복귀를 PC·모바일에서 검증. API만 합성 계정 DB로 대체.
- 운영 절차: 범위 커밋 → origin/main 일치 → `npm run release:gate` → `npm run deploy:production` → 배포된 자산과 실제 메뉴 경로 재검증.
- 롤백 시 이 변경을 되돌리는 커밋을 같은 출시 게이트로 배포한다. 세력전 테이블과 이미 분배된 징수코인은 보존한다.
