# 하이희야 SS · SD와 해일 탄막 운영 연결

2026-09-15 사용자 요청: “하이희야 용병 SD이미지 스킬 다 승인하니까 라이브 배포 적용해”. 앞선 원화 공개 전용 상태를 이번 승인으로 변경한다.

- V-044 하이희야, SS, 중열 사격. 기존 SS 공통 기본 전투력 120,000을 사용한다. 일반 카드 5장과 별도 용병 슬롯 1장 규칙을 유지한다.
- 원화는 사용자 첨부 PNG 그대로 보존한다. SHA-256 `1A5ADF3D106AE2FE455C2075E81CF19A09A8AAEF1558F6767EF3027E744D27EC`.
- SD는 승인된 실제 RGBA PNG 그대로 사용한다. SHA-256 `8BD6865E1972D60C9A48BF819DDCC6987A124D829C0A378DADC9170EC114AF91`. 발끝 `(0.5,1485/1536)`, 총구 `(993/1024,277/1536)`.
- 승인한 해일 탄막을 `MS-044`로 등록하고 하이희야에 배정한다. 고정 전열 단일 표적이며 기존 SS 사격 MS-005와 같은 총 피해 배율 4.2, 재사용 5턴, 에너지 25를 적용한다. 기절·최대 HP 비례 피해·방어 무시를 추가하지 않는다.
- 9발의 연사 연출은 하나의 서버 확정 피해 예산이다. 서버는 1회 명중 판정 및 재화/쿨다운 처리를 수행하고 마지막 충돌 시점에 HP를 반영한다. 연출에서 9배 피해를 계산하지 않는다.
- 하이퍼팩 SS 후보에 포함한다. 기존 등급 확률·계정별 개봉 정책은 변경하지 않으며 같은 SS 등급 내 균등 선택을 유지한다.

## 자산과 재생

`mercenary-hi-heeya-live-approval-20260915.json`에 원화·SD·프레임·사용자 승인·밸런스 근거를 기록했다. 승인된 해일 탄막 아틀라스와 개별 16프레임을 공용 `skill-assets-v2/tidal-barrage/`에 복사했다. 원본 파일은 재생성하거나 덮어쓰지 않았다. 도감의 WebP는 기존 빌더로 V-044만 추가한 표시용 파생물이다.

실제 사용 파일은 `MercenaryCombatPlayback.js`, `MercenarySkillFX.js`, `RenderAuthoredSkill.js`, `MercenarySpriteSequence.js`다. PixiJS 8.20.0, GSAP 3.13.0과 공용 V3 전장·진형·효과 레이어를 사용한다. 재생 시간은 3.4초, 충돌 시점은 0.66초부터 0.17초 간격 9개다. PVE·PVP가 같은 타임라인을 사용하며 취소 시 효과와 타임라인을 해제한다.

새 합성음을 만들지 않았다. 기존 승인된 `MS-027` 녹음 음원 프로필의 예고·명중·잔향을 재사용하며, 9개 충돌의 명중 게인은 0.16으로 제한한다. 출처·라이선스·음원 해시는 기존 `skill-audio-v1.json`의 assets 기록을 그대로 사용한다.

## 운영 등록과 검증

이전 완전한 CMS 43종·26스킬만 44종·27스킬로 확장한다. 기존 이름·등급·수치·스킬 배정·공통 설정을 보존하고, 이미 확장된 문서에는 다시 기본값을 덮어쓰지 않는다. 불완전한 문서는 거부한다.

운영 반영은 CMS revision 54와 설정 해시를 선행 확인한 뒤 `ops-hi-heeya-live-v2118-20260915` 감사 기록을 한 번 저장하는 범위 작업이다. 동일 요청은 재실행해도 다시 변경하지 않는다. 뽑기 설정·계정 지갑·보유 카드의 직접 변경은 포함하지 않는다.

회귀 검사는 이전 CMS 보존·멱등성·원화/SD 해시·SS 획득/중복/재요청·별도 슬롯·서버 명중/회피/표적 소실·PVE/PVP 이벤트를 확인한다. 브라우저 검수는 로컬 계정으로 1440/390/320px 편성 화면 및 양 모드 전장에서 SD·9개 탄막·공용 타임라인 일시정지·2배속·취소·HP 동기화를 확인했다.

운영 배포는 깨끗한 후보 커밋에서 전체 `release:gate`를 통과한 `npm run deploy:production`만 사용한다. 공개하지 않기로 한 클랜 뉴스는 이 변경에 포함하지 않는다.
