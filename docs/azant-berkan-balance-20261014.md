# 아잔트 · 베르칸 동급 성능 조정 — 2026-10-14

사용자 `아잔트 베르칸하고 비등하게 만들어라` 지시로 일반 SSS 아잔트 V-056을 상향한다. 두 용병의 기본 전투력과 스킬 CMS 원수치는 같았지만 아잔트는 행동 빈도와 PVP 피해 상한이 낮아 실제 비교에서 밀렸다.

## 변경

- PVE·PVP 기본 속도 **1 → 1.25배**, 아군 일반 카드 행동당 예약 행동량 **1 → 1.25**. 아군 카드 4회당 용병 추가 행동 5회를 얻는다. 자연 행동·사망·듀오 소유자 분리·추가 행동 상한은 기존 공용 규칙을 따른다.
- PVP **결정창 포격 MS-057**의 피해 상한 계수 **1 → 1.6**. 베르칸과 같이 해당 타격에서 이미 생성한 95~105% 편차를 상한에도 적용하며 난수를 다시 뽑지 않는다. 등급 차이/공격 억제 계수도 공용 산식으로 한 번 적용한다.
- 일반 SSS 기본 전투력 180,000과 체력·공격·방어·평타 피해, 스킬 원배율 5.6·비용 35·재사용 5행동을 유지한다. PVP는 전열 최대 2명, PVE 청옥 강림은 생존 적 전체에 예산을 나눠 대상당 한 번 판정한다. PVE의 스킬 배율과 타격 상한은 변경하지 않는다.
- `AZANT_COMBAT`에 아잔트 전용 정책을 명시했다. 상대 용병·계정·연패·목표 승률을 런타임 분기로 사용하지 않는다. 베르칸 및 다른 용병의 수치와 기존 전투 영수증을 수정하지 않는다.
- 공개 도감의 전력 연계 설명에 25% 행동 보강과 PVP 상한 1.6배를 표시한다. 승인 원화·SD·고정 대기·지팡이 파지·오라·스킬 연출과 피해 적용 횟수는 그대로다.
- 성장 기능 OFF, 획득 확률·가중치·보유 카드·편성·CMS 저장값을 유지한다. 운영 DB 쓰기는 없다.
