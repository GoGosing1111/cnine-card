# 용병 성장 UI 전면 개편 · 2026-10-06

요청: “UI 싹다 갈아엎어라 현 우리 UI 지향대로 다시 만들고 돌파때는 연출도 신경써”. 이전 `20261005` 성장 화면은 이력으로 보존하고 플레이어 UI 전체를 교체한다.

## 화면

- `docs/ui-fixed-reference-20260915.md`의 네이비 `#080c17`, 패널 `#111828`, 경계 `#28324a`, 라임 `#c8ff6b`, Noto Sans KR·Barlow Condensed를 사용한다.
- 운영 공통 `adventure-navigation-standalone.js` 메뉴를 연결했다. PC는 보유 용병 → 중앙 원화·성장 무대 → 재료·돌파 조작, 모바일은 가로 목록 → 무대 → 조작 순서다.
- 긴 홍보 제목·일반 정보 박스를 제거했다. 전용 성장실 배경, 원화를 보존한 카드 무대, 경험치 예상량, 네 단계 돌파 경로, 재료 수량 증감, 기본 1장 보호, 초과 경험치 동의를 연결했다.
- 검수 페이지의 **돌파 연출 보기**로 바로 체험할 수 있다. 성공·실패·5/10/15/20 구간은 하단 검수 도구에서 선택한다. 예시 수치는 실제 정책과 분리된다.

## 돌파 연출

`breakthrough.mjs` / `breakthrough.css`: 전용 공간 → 에너지 충전 → 입체 봉인 → 마우스·터치 밀기 → 봉인 개방 → 결과 공개.

- 성공은 봉인이 좌우로 열리며 광원·입자가 확장되고, 원화·상승 레벨·해금 효과를 공개한다.
- 실패는 봉인이 흔들리며 에너지 고리가 수축하고 광원이 사그라든다. 현재 레벨 유지, 경험치 0%, 기존 효과 보존을 명시한다.
- 미완료 밀기는 원점 복귀한다. Enter/Space/방향키/End, 바로 결과 보기, Escape, 동작 줄이기를 지원한다. 사운드는 기본 OFF이며 사용자의 ON/OFF 선택을 저장한다.
- 네이티브 modal dialog로 배경 조작과 초점을 차단한다. 타이머·입자·오디오·이벤트·스크롤 잠금은 닫기/이탈 시 해제한다.
- 연출 모듈은 API·재료·판정 코드가 없다. 완료된 서버 영수증만 표시한다. 새 계정 상태 조회와 결과 확인이 모두 끝나야 기존 요청을 확인 완료 처리한다. 페이지 이탈·연출 오류·상태 조회 실패에는 영수증이 남으며 복구로 재소모/재판정하지 않는다.

## 자산

- 내장 image_gen으로 빈 성장실 배경 1종을 생성했다. 기존 용병 원화는 생성 입력에 넣지 않았으며 수정하지 않았다.
- 원본·WebP·최종 프롬프트·해시: `assets/ui/mercenary-growth-20261006/manifest.json`.
- 봉인은 코드로 작성한 SVG, 입체 회전·고리·개방은 CSS, 입자는 제한된 canvas로 구현했다. 추가 라이브러리나 의존성 변경은 없다.

## 검증

`scripts/qa-mercenary-level-ui-20261006.mjs`의 실제 Chrome 검수:

- 1440×1000 PC, 390×844·320×700 모바일에서 화면·재료·돌파 성공/실패를 확인했다. 1024×768에서도 가로 넘침이 없다.
- 공통 메뉴, 이름 검색, 같은 등급만 노출, 음수/소수/보유량 초과 차단, 초과 경험치 동의, 네 돌파와 최종 Lv.20을 확인했다.
- 실제 마우스 및 CDP 터치 입력으로 미완료 복귀·끝까지 밀기, 키보드·Escape·건너뛰기, 초점 제한·스크롤 복구·사운드 토글을 확인했다.
- 동작 줄이기, 이동 중 정리, 운영 OFF/미설정·빈 목록·읽기 오류를 확인했다. 검수 시뮬레이션에서 서버 쓰기 요청은 0건이다.
- 결과와 화면은 `preview/mercenary-level-ui-20261006/qa/`에 보존한다. 외부 임시 QA 폴더는 배포 대상에 넣지 않는다.
- 최종 20레벨 결과는 `Lv.20 MAX`로 표시한다. 모바일 최종 돌파 화면도 별도 확인했다.
- `tests/mercenary-level-ui-20261006.test.mjs`: 결과 확인 전 pending 유지, 유실된 POST 응답 후 같은 영수증 복구, 화면 이탈/조회·연출 오류, 연출 중 계정 교체, 마지막 Lv.20과 실행 OFF 회귀. 지정 배포 과정에서 실행한다.

## 반영 범위

플레이어 성장 화면과 전용 연출만 변경했다. 공유 정책·서버 거래·DB·전투·CMS는 변경하지 않는다. `MERCENARY_LEVEL_RELEASE_ENABLED=false`, 운영 정책 OFF 및 미확정 수치 null을 유지한다.

한 화면에 한정된 수정이므로 관련 브라우저 검수와 영수증 회귀 후 `npm run deploy:production -- --scoped`를 사용한다. 배포 직전 Cloudflare 실제 운영 SHA를 확인하며, 다른 작업의 미배포 서버 변경이 끼어 있으면 해당 배포가 완료된 뒤 적용한다. 같은 코드의 무관한 전체 검사는 반복하지 않는다.

선행 감옥 배포 완료를 확인한 기준: `83886e94beeaeeca04a954d07a3ef726112fded7`, Pages `73c53856-0779-4744-9d6f-ea0bd0bf6c33`. 이 기준 이후 용병 UI만 scoped 반영한다. 선택 검사는 `tests/mercenary-level-ui-20261006.test.mjs`이며 광범위한 게임 검사나 DB 설치를 추가하지 않는다.
