# 군단토벌 · 잊혀진 섬 OWNER 공개 / CMS — 2026-09-26

## 사용자 범위

- `OWNER 공개로 추가해 PVE에 일반유저는 OFF`
- `드랍아이템도 CMS에서 설정,추가 가능하게 해두고`
- 콘텐츠 이름 **군단토벌**, 맵 이름 **잊혀진 섬**.
- 일반 유저 공개와 실계정 보상 지급은 OFF. 검수 원정대 3종을 사용하는 OWNER 플레이 검수이며, 실제 계정 덱·보상 경제 출시는 이번 범위에 포함하지 않는다.
- 후속 요청으로 간단한 소개 포스터를 제작했다. 상단 ‘숲’ 오류를 실제 한글 폰트 참조로 교정한 [최종 V3](../preview/sustained-hunt-v2/assets/posters/legion-hunt-forgotten-island-v3.png)만 저장한다.

## 운영 연결

- PVE의 기존 메뉴에 OWNER 전용 군단토벌 버튼 추가. 공용 전장·원화 도크·V3 아트 어댑터를 사용하는 기존 V2 프리뷰를 전체 화면으로 연다.
- `/api/legion-hunt/bootstrap|start|begin|reveal|claim|finish|cancel` 및 `/api/admin/legion-hunt`는 서버 인증 후 정확한 OWNER 역할만 허용한다. USER·ADMIN·미로그인 모두 차단하며 공개 ON을 요청 본문으로 전달할 수 없다.
- 기존 인증·사용자 잠금을 사용하고, 현재 원정의 축약 상태를 기존 app_meta의 계정별 키 하나에 저장한다. Worker 메모리에 세션을 보관하지 않는다. 전투 시뮬레이션은 출전 때 한 번만 수행한다.
- 현재 원정 키는 계정당 하나이며 새 출전으로 교체된다. 30분 만료. 새로고침 시 기존 재생 복구 대신 새 검수 원정을 준비한다.
- 처치에는 보상을 지급하지 않는다. 서버가 발급한 드랍의 토큰·좌표·소멸 시간과 계정별 원정을 검증한 클릭만 검수 획득 기록에 반영한다.
- app_meta compare-and-swap으로 클릭·재시도·정산을 저장한다. 원정 스냅샷에는 카탈로그 전체·렌더링 페이로드 대신 전투 이벤트의 최소 필드와 드랍 상태만 보관한다.
- OWNER 화면의 드랍 생성·클릭·정산 요청은 순서대로 보내 같은 계정 잠금과 경쟁하지 않는다. 잠금 사용 중 응답만 같은 본문으로 최대 두 번 재시도한다.

## CMS 사용

**CMS → 군단토벌 → 필드 드랍 설정**

1. 현재 활성·공개 카탈로그의 아이템·장비·이동수단·SUPERSTAR/ZENITH/FUR 카드를 검색하고 후보로 추가한다.
2. 신규 후보의 기본값은 사용 OFF. 사용 여부, 선택 가중치, 최소·최대 수량을 지정한다. 후보 최대 100종.
3. 보통·어려움·악몽·지옥 각각 일반 몬스터 확률, 보스 확률, 필드 소멸 시간(3~30초)을 설정한다.
4. 저장하면 다음 원정부터 적용된다. 진행 중인 원정은 시작 당시 설정을 유지한다.
5. 드랍 성공 시 활성 후보 중 가중치 비율로 1종을 선택하고 수량 범위에서 추첨한다. 화면에 후보별 조건부 선택 확률을 표시한다.

최초 후보는 빈 상태다. 검수용 프리뷰의 임시 세 종류를 실제 아이템 정책으로 자동 승계하지 않는다. 후보를 선택·활성화·저장해야 OWNER 필드 드랍이 생성된다. 로컬 단독 프리뷰(8958)는 종전 검수용 세 종류를 그대로 사용한다.

설정 저장은 리비전 검사 + CAS + 관리자 감사 로그를 같은 DB batch에서 처리한다. 오래된 탭의 덮어쓰기, 감사 기록 실패 후 부분 저장을 차단한다. 카탈로그 조회는 유형당 1회, 최대 1,001행이며 한도 초과 시 잘라 저장하지 않고 오류를 반환한다. 기존 통합 드랍풀·블랙미라클·다른 콘텐츠 정책은 변경하지 않는다.
