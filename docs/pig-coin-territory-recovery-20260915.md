# 영토전 피그 코인 소급 지급 회수 · 2026-09-15

## 문제와 적용 기준

피그 코인 도입 전에 끝난 V3 영토전의 미수령 보상을 지금 누르면 현재 CMS 지급 정책으로 피그 코인이 추가됐다. 지급 구현이 V3 여부만 검사하고 출시 대상 회차를 검사하지 않은 것이 원인이다.

현재 모집 중인 49회차부터 지급한다. 별도 운영 기준 `app_meta.pig_coin_territory_release_v1.firstRoundId=49`를 저장했고 CMS 지급량·상품 편집으로 이 기준을 바꾸지 않는다. 기준이 없거나 잘못된 경우 지급·예상 지급량을 0으로 처리한다. 트랜잭션에서도 회차 경계와 읽은 기준값을 검사한다. 48회차까지의 일반 코인·기존 영토전 보상 수령은 유지한다.

## 운영 회수

- 추가 지급·소비 차단을 위해 영토전 피그 코인 지급과 상점 판매를 잠시 OFF했다. 클랜·코어 지급 정책과 상품 설정은 보존했다.
- 39·41·44·47회차에서 7명에게 지급된 총 950개를 회수했다.
- 불법사행산업신고센터 150, 슬랜더조아 150, 대저동토마토 50, 흐린눈깔 50, 블랙캐슬 150, 나야 300, 하이희야♡ 100.
- 슬랜더조아의 해당 코인 15개로 구매한 미개봉 슈퍼스타 선택팩 1개를 취소했다. 팩·구매 기록의 사본을 감사 영수증에 보관하고 구매 한도를 복원했으며, 기존 구매 요청과 대기 개봉 요청을 취소해 재실행을 막았다. 환불 15개를 기록한 뒤 지급분 150개를 전액 회수했다.
- 회수 완료 시 7명 피그 코인 잔액 합계 0, 취소 대상 팩·구매 잔존 0. 정상 보유 카드·일반 재화는 변경하지 않았다.
- 원래 지급 원장은 보존하고 별도 음수 회수 원장 및 구매 취소 환불 원장을 추가했다. 운영 감사 ID `30342`, 멱등 키 `ops_pig_coin_territory_recovery_20260915_v1`.

`scripts/ops/pig-coin-territory-recovery-20260915.mjs`는 명시적 일회성 운영 도구다. 런타임 마이그레이션에서 실행하지 않는다. 구매·계정·지갑 잠금, 미개봉 확인, 잔액 부족 시 전체 롤백, 영수증 재시도 검사를 포함한다. 수정 배포 검증 후 `restoreAfterTerritoryFix`로 이전 판매·지급 상태를 복구하며, 도중 CMS 값이 바뀌면 덮어쓰지 않는다.

## 검증

SQLite와 PostgreSQL에서 과거 39·47·48회차 보상 수령 시 피그 코인 0, 경계 49·미래 50회차 정상 지급 및 재시도 중복 방지, 출시 기준 누락·손상·변경 시 차단을 확인한다. 운영 회수는 dry-run 롤백 후 실행하고 별도 조회로 지갑·원장·구매를 검증했다. 운영 코드는 깨끗한 커밋에서 `npm run deploy:production`의 전체 `release:gate`를 통과한 뒤 배포한다.
