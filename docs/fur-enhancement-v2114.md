# FUR +14 / +15 강화 설정 — 2026-09-14

사용자 승인:

| 전환 | 소모 중복 카드 | 마스터의 별 | 성공 확률 | 연속 실패 천장 |
| --- | ---: | ---: | ---: | ---: |
| +13 → +14 | 5장 | 20,000개 | 15% | 10회 |
| +14 → +15 | 8장 | 30,000개 | 10% | 20회 |

기존 고급 강화와 동일하게, 실패해도 재료는 소모되며 카드 단계는 유지된다. 강화 대상 1장을 남겨야 하므로 최소 보유 수량은 각각 6장과 9장이다. 천장은 연속 10회/20회 실패 후 다음 시도가 확정 성공하는 기존 규칙을 따른다. 성공하면 실패 횟수를 0으로 초기화한다.

## 강화 성능과 운영 상태

- 현재 +13 기본 전투력 증가율은 +2,500%(일반 FUR 83,200), 고유효과 증가율은 +100%, 해당 단계 퇴사 환급량은 카드 조각 10,000개다.
- 후속 답변의 `13보다 더 좋게` 정정을 반영해 +14 전투력은 +13의 1.5배, +15는 +14의 2배로 적용한다. 사용자가 설계를 맡긴 고유효과 배율과 단계별 환급량도 같은 비율로 증가시킨다.

| 단계 | 기본 전투력 대비 증가 | 일반 FUR 전투력 | 고유효과 증가 | 고유효과 배율 | 단계별 퇴사 조각 환급 |
| --- | ---: | ---: | ---: | ---: | ---: |
| +13 (유지) | +2,500% | 83,200 | +100% | 2배 | 10,000개 |
| +14 | +3,800% | 124,800 | +200% | 3배 | 15,000개 |
| +15 | +7,700% | 249,600 | +500% | 6배 | 30,000개 |

- 전투력은 일반 FUR 기본 3,200 기준이다. 카드별 기본 전투력과 Faker 전용 고정 가산은 기존 규칙을 따른다. 고유효과의 기존 최종 상한(공격·방어·체력 등 500%, 속도 300%)도 유지한다.
- 환급량은 각 강화 단계에 추가되는 금액이며 실제 퇴사에서는 기존 단계의 환급을 누적한다.
- 기존 FUR +11~+13 `enabled:true`와 세 단계의 운영 수치는 유지한다. 위 수치를 운영 CMS에 저장하고 검증 후 `extendedEnabled:true`로 연결한다.
- 설정이 누락된 환경에서는 미정 값을 `null` / CMS 빈칸으로 보존하며 확장을 자동으로 열지 않는다. 신규 두 단계의 수치가 모두 입력되고 `extendedEnabled:true`가 된 경우에만 실제 +14/+15 강화와 CMS 수동 지급이 열린다. API에서도 재료 차감 전에 확인한다.
- 새 PNG 프레임 두 종은 원화 시안 상태이며 실제 alpha 추출 방식에 대한 사용자 답변 대기다. 운영 카드는 검수된 기존 +13 프레임을 계속 사용한다. 체크무늬가 구워진 생성 원본을 투명 PNG로 취급하거나 운영 자산으로 넣지 않는다.

- `functions/_fur_enhancement_v2114.js`: 승인된 비용·확률·중복·천장 기본값, 미정 값 보존, 확장 단계 운영 검증.
- `functions/api/[[path]].js`: FUR 전용 최대 +15, 설정 조회/저장·과거 CMS 저장 호환, 전투력 표 연결, 자원 동시 차감, 수동 지급 상한. 다른 등급은 기존 상한 유지.
- `functions/_magic.js`: FUR 고유효과 표 +14/+15 확장과 설정 변경 시 캐시 갱신.
- `js/app.js`, 공용 V2/V3 카드: 강화 안내·재료 검사·단계 표시·전투력 계산.
