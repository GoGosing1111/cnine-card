# V2089 V3 코드·CMS 운영 반영

사용자 지시: `개편된 V3 개편안 전체 다 라이브로 반영해라 ,CMS포함 해서`.
후속: `용병은 등급별로 고정값 산정해놨고 장비강화 비용은 수정이 필요 코인+마별 , 용병은 차후에 중복 카드로 업그레이드할 예정 중복카드+마별`.

## 코드·CMS 범위

- 공통 V3 그리드·간격, 연속 다중 적 전투, 실제 계정 스냅샷, 진행·결과 복구, 용병·배틀슈트의 독립 슬롯을 같은 배포 후보에 포함한다.
- 무한의탑·폐차장·카우방·기존 서버 자동 원정 어댑터, 용병 지휘소, 장비 강화·보호·파괴 기록·복구의 서버 거래와 CMS를 포함한다.
- 일반 PVE 2%·아포칼립스 3% 카우방 포탈 발견·입장 연결과 CMS를 포함한다. 승인된 클리어 5억·일일 최대 30억·6회 및 CMS 입력 한도 100억을 등록한다.
- 기존 용병 등급·배정·개봉 확률은 보존한다. 개봉 OFF, 동일 등급 균등 추첨·중복 집계를 유지한다.
- 강화는 단계별 코인과 마스터의 별 수량이 모두 필요하다. 미설정 비용·다른 강화 재료·구형 단일 재료 견적을 실행할 수 없다. 두 재료·장비 상태·영수증을 원자적으로 정산한다.
- 용병 전투력은 C 10,000 / B 20,000 / A 40,000 / S 70,000 / SS 120,000 / SSS 180,000으로 고정한다. 공통 전투의 기본 프로필로 PVE/PVP 능력치를 환산한다. 개별 스탯·성장 초안과 과거 검수 레벨을 가산하지 않는다.
- 용병 업그레이드는 차후 동일 용병 중복 카드 + 마스터의 별로 제공한다. 이번에는 훈련·EXP·코인 레벨업을 닫고 중복을 계속 집계한다. 기존 초안 기록은 삭제하지 않는다.
