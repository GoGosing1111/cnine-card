# 몬스터·레이드 오리지널 원화/SD 라이브 연결

## 확정 범위

- 사용자 `이제 일러스트랑 sd이미지 라이브 반영해`, 최종 정정 `동영상은 빼고 기존 V3 궁극기 이펙트로 교체`를 적용한다.
- 승인 원화 36장과 투명 기본 SD 36장, 최신 34개 고유 이름을 사용한다. 토벌 29개 외형(난이도별 동일 인물 ID 포함)과 레이드 7개 외형이다. 원본을 가공·재생성하지 않았다.
- NORMAL 18개와 빅물개 ID 8, 비활성 레이드, 스킬 판정·피해·조건·재사용·경제·보상·기존 영수증은 유지한다. 새 모션 시트를 제작한 것은 아니다.
- 승인 원본/해시는 `preview/monster-original-ip-sd-20261013-v1/live-approval-20261013.json`에 고정했다.

## 연결 방식

- `shared/monster-original-ip-data-v1.mjs`는 승인 manifest에서 생성한 ID/코드 → 이름/원화/SD 대응표다. `scripts/build-monster-original-ip-v1.mjs`로 재생성한다.
- `shared/monster-original-ip-presentation-v1.mjs`를 토벌·탑·균열·레이드 및 해당 CMS의 JSON 표시 경계에 연결했다. 저장된 이름과 기존 전투 코드를 건드리지 않고, 이전에 만들어진 방과 영수증에도 새 외형을 표시한다. 사용자 닉네임·카드·판정/거래 필드는 교체하지 않는다.
- 토벌 SD manifest에 새 원본과 발 위치를 연결했다. 독립 리소스였던 ID 77/78도 포함했다. 제외 19개 항목의 전체 manifest 객체가 이전 커밋과 동일함을 확인했다.
- 바르센/이스겐 입장 UI·CMS·원화와 세드릭 표시를 연결했다. 바르센의 예전 캐릭터 cast 프레임을 로드하지 않으며 현재 승인 SD를 본체와 분신으로 재사용한다. 레이드 전용 소환체/코어에는 승인된 교체 자산을 재사용하고 공유 NORMAL 원본은 보존한다.
- 교체 대상 궁극기의 동영상/별도 음성 URL을 표시 응답에서 제거했다. V3 고유 스킬 효과는 그대로 사용하고, 일반 보스 궁극기도 기존 V3 보스 궁극기 아틀라스로 재생한다. 서버의 같은 타격 영수증을 표시하며 피해를 재계산하지 않는다.
- 주간 레이드 CMS는 새 표시 이름을 동일한 내부 보스 코드로 인식한다. 저장 시 기존 내부 이름을 보존한다.
- V3 공통 소비 번들과 PWA shell/entry/cache 버전을 갱신했다.

## 검수

- 승인 원화/SD 72개 파일 SHA-256 일치, 36개 대응표와 난이도 별칭, NORMAL/빅물개 제외, 기존 방/영수증의 이름·이미지 교체와 전투/사용자 정보 보존을 검사했다.
- 신규 연결 회귀와 Apocalypse, weekly boss/CMS, Madara/Lich/Core, 실운영 전장 로더 회귀 **64개 통과**.
- 실제 V3 로더를 사용하는 로컬 고정 편성에서 PC 1440×1000, 모바일 390×844를 확인했다. 하르트 궁극기 재생 완료, 야즈·오르제·제노·바르센·이스겐·세드릭 SD 연결, 모바일 전장/효과와 가로 넘침 없음, video 요소 0개를 확인했다.
- 스크린샷: `preview/monster-original-ip-sd-20261013-v1/qa/live-pc-ultimate.png`, `live-mobile-raid.png`, `live-mobile-ultimate.png`.
- 페이지 오류는 없었다. 연속 캐릭터 전환 시 기존 Pixi의 이미 해제한 아틀라스 unload 경고는 있었으나 실제 아틀라스 로드와 재생은 성공했다.
- 로컬 재현: `node scripts/serve-monster-original-ip-qa.mjs` → 출력된 localhost 주소. 운영 계정/입장권을 사용하지 않는다.

## 배포 정책

- `npm run deploy:production -- --scoped`를 사용한다. 콘텐츠 표시/자산 연결과 기존 이펙트 재사용이며 공통 인증·DB·트랜잭션·스키마·의존성은 변경하지 않았다.
- 배포 직전 운영 기준: `81850d4d7812c288a702b8021888e9257dd945d7` (군단토벌 7분/기본 10회). 그 변경을 포함한 최신 origin/main 위에 작업을 통합한다.
- scoped 선택: 새 original-IP 연결 회귀, 주간 보스 CMS/이름 호환 회귀, 필수 V3 로더 회귀와 `check:worker`. 이미 통과한 다른 레이드 거래 검사를 다시 전수 실행하지 않는다.
- 실제 배포 식별자와 운영 확인 결과는 배포 후 추가한다.
