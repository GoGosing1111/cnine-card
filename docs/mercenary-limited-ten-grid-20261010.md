# 리미티드팩 10회 결과 이미지 동시 공개

- 사용자 요청: `10장 결과값 한번에 사진으로 보여주라했잖아 빠르게`.
- 원인: 10회 영수증도 단일 카드용 순차 연출에 전달해 마지막 결과 외에는 이미지를 함께 확인할 수 없었다.
- 10회는 서버가 확정한 결과 10개를 5열×2행 이미지로 즉시 표시한다. 수동 개봉·자동 10회 묶음·이전 결과 확인 모두 같은 화면을 사용한다. 일반/리미티드 원화, 재료 아이콘, 꽝과 수량·등급·발행 번호를 원래 순서대로 표시한다.
- 자동 개봉은 1.5초 결과 확인 후 다음 묶음으로 진행한다. 중지/닫기/탭 숨김은 대기를 정리하고 다음 구매를 막는다. 1회 연출과 서버·DB·가격·확률·발행 한도·운영 ON은 변경하지 않는다.
- 메인 로더와 모듈/CSS 캐시를 `20261010-grid`로 올렸다. 승인 자산은 그대로 재사용한다.
