# SS 리미티드 · 일반 SSS 성능과 행동 주기 — 2026-10-09

사용자 요청: `SS리미티드 SSS (리미티드제외) 성능 비슷하게 맞춰라 행동력도 마찬가지고`.

SS 리미티드 7종의 행동 주기를 일반 SSS 4종 평균으로 올리고, 증가한 행동량을 반영해 일부 능력치를 조정했다. 일반 SSS 및 SSS 리미티드(발테르 V-996·헬리오스 V-999)는 변경하지 않았다.

## 적용 정책

- 단일 정책: `shared/mercenary-ss-limited-v1.mjs`, 버전 2.
- 표시/성장 등급 SS, 전투 등급 보정 SSS, 기본 전투력 180,000.
- 일반 SSS 자연 속도/행동 누적 배수는 오메가-X·라그니엘·크라이베른 1, 베르칸 1.25. SS 리미티드는 평균 **1.0625**를 PVE·PVP 모두 적용한다.
- 아군 일반 카드 64회 행동의 추가 행동 수: 일반 SSS 64/64/64/80회, SS 리미티드 각 68회. 즉 **16회당 17회**다. 자연 행동은 기존 속도 게이지를 따르므로 실제 전투 총 행동 수는 생존·제어·진형에 따라 다르다.
- 듀오에서는 해당 소유자의 카드만 추가 행동을 적립한다. 슈트·몬스터·용병 자신의 행동과 시각 효과는 적립하지 않는다.
- 스킬의 기존 개성과 분할 타격, 560% 피해 예산, 에너지 비용 35, 재사용 5행동을 유지한다. 운영 기준 최대 에너지 100·일반 공격 적중 회복 10과 연속타 중복 회복 방지도 확인했다.

도감의 SS 리미티드 상세에 전투 등급·행동 주기·스킬 비용 안내를 추가했다. 원화/SD/프레임 파일, 보유량, 팩 출시 및 편성 정책은 유지한다.

## 비교 방법과 한계

현재 공개 운영 CMS는 revision 61이며 일반 SSS 4종의 스킬 수치가 기존 운영 스냅샷과 일치함을 읽기 조회로 확인했다. 서버 정식 엔진 `createPvpBattleV2`로 동일 카드·장비·전직·마법·성장 조건, 3개 전투력 구간을 포함한 일반 덱 12개와 장비 편성 23개를 비교했다. 양 진영 각각 64난수, 용병당 17,920판, 최종 합계 **125,440판**이다.

초기 행동 주기 변경안 검증 후 목표 48~50%를 넘은 용병만 수치를 조정하고 새 난수로 다시 검증했다. 최종 난수 시작은 나무늘봉순·이네스·아윤 130001, 조은·디임 150001, 오리꿍·하이희야 160001이다. 상대는 항상 동일 일반 SSS 4종이므로 변경하지 않은 용병의 검증 결과는 보존했다. 모든 검증 단계와 상대·진영·편성별 분모 및 Wilson 구간을 JSON에 기록했다. 결과나 승자를 덮어쓰는 보정은 없다.

이 결과는 통제된 서버 시뮬레이션이며 실유저 승률 또는 개별 상성 50% 보장이 아니다. 일반 PVE 12시나리오 × 16난수 × 11용병의 2,112판은 실행·피해·행동 기록 확인용이다. 모두 클리어되는 조건이므로 전체 PVE 콘텐츠의 난이도별 동급 성능 증명으로 해석하지 않는다.

최종 검증 재현:

```text
node scripts/measure-ss-limited-tempo-20261009.mjs --final --pve --out <별도 결과 파일>
```
