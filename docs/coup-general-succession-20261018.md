# 쿠데타 성공 · 장군 교체 연출 준비 — 2026-10-18

사용자 `쿠데타 성공 일러스트,연출 추가준비해` 및 정정 `쿠데타 장군 교체`에 따라 전용 일러스트와 승계 연출을 준비했다. **준비 브랜치·로컬 미리보기 상태이며 운영 배포나 실제 장군 승계 처리는 하지 않았다.** 기술 검수는 사용자 시각 승인이 아니다.

## 최신 V4 수정

- 닫기 X를 대칭 SVG로 표시하고 44×44px 버튼의 중앙에 고정했다.
- `무능한 장군을 내렸다` 선언 → 움직이는 스포트라이트 아래 전임 장군 감옥 이송 → 새 장군 공개로 확장했다.
- 사용자 정정에 따라 **전임 장군은 여성, 새 장군은 남성**이다. 여성 전임 장군은 기존 V2 얼굴·검은 머리·군복을 참조하여 두 호위병에게 팔을 잡힌 채 감옥으로 이송된다.
- 새 남성 장군은 기존 여성 원화의 자세를 복제한 V3를 폐기하고 지휘실에서 작전대를 짚은 구도로 다시 제작했다. 두꺼운 더블 브레스티드 군용 코트와 여유 있는 실루엣을 사용한다.

## 원본과 프롬프트

내장 `image_gen`으로 제작했다. 원본은 생성 결과와 바이트가 같으며 프롬프트·참조 원본·SHA-256·크기·반려 이력은 `preview/coup-general-succession-20261018/art-manifest-v4.json`에 보존한다.

기존 V2 여성 장군 원본과 `art-manifest.json`은 과거 제작 이력 및 여성 전임자 참조로 보존한다. 반려된 타이트한 남성 V3와 남성 전임자 호송 V3는 생성 원본 경로·해시·프롬프트만 이력에 남기고 현재 화면에서 사용하지 않는다.

## 연결과 동작

**활성 임기 + GENERAL + COUP + 승계 APPOINTED**에서만 `general-coup-succession` 화면을 선택한다. 선거로 뽑힌 장군·미확정 또는 SUPERSEDED 승계·기존 여왕/족장 연출은 이전 분기를 따른다.

1. 원화 디코딩 후 파면 문구가 나타난다. 탐조등이 전임 여성 장군과 호위병을 가로지른다.
2. 약 2.7초부터 감옥 이송 문구를 표시한다.
3. 약 5.5초부터 새 남성 장군으로 전환하고 이전 이름 → 새 이름·대수·임기를 순서대로 공개한다. 약 7.7초에 확인 동작까지 표시된다.

이미지 확대는 전용 영역 안에서 잘라 전환 중 스크롤바가 생기지 않게 했다. 건너뛰기는 즉시 결과를 표시하고 확인 버튼으로 초점을 옮긴다. 기존 24시간 자동 노출·세션 숨김·하루 숨김·다시 보기·Escape 닫기·초점 복구를 유지한다. 동작 줄이기에서는 연출을 생략한다. 새 사운드는 자동 재생하지 않는다.

서버 쿠데타 결과·참가자·지휘관·임명·임기·보상·권한 코드는 수정하지 않았다. 운영 코드에 박세라 이름을 하드코딩하지 않고 확정된 서버 응답을 표시한다.
