# 족각도시 탐색 리소스·UI 개선

2026-10-12 사용자 요청: 새로 추가한 지역 탐색 화면을 다듬고 아이템별 리소스 이미지를 제작하여 실제 게임에 연결한다.

## 화면과 리소스

- 신규 탐색 무기 7종(쇠지렛대·알루미늄 배트·전술 단검·사냥 석궁·산탄총·기관단총·정밀 저격총), 방어구 6종(가죽 재킷·작업 조끼·보강 방호복·방탄 조끼·진압 방어구·중장갑 플레이트)을 내장 image_gen으로 개별 생성했다. 기존 시장 무기 3종 등 기존 8개 아이템 원본은 보존한다.
- 투명 PNG 원본 13개와 투명 WebP 768px·256px 파생본 26개를 `assets/ui/jokgak-city/exploration-v2/`에 보관한다. `manifest.json`에 치수·용량·SHA-256을, `generation.json`에 개별 프롬프트와 원본 출처를 기록한다.
- 총몸·총열·스코프 축의 연속성과 장비별 형태·재질·투명 경계를 직접 확인했다. 보라색 발광과 이미지에 박힌 글자·프레임 없이 장비가 크게 읽히도록 제작했다.
- 탐색 화면은 지역 지도 질감과 탐색 표식, 지역별 설명, 장비 이미지·발견 확률·전투력·보유 여부를 함께 보여준다. 아이템을 누르면 큰 이미지와 실제 발견 지역을 확인한다.
- 인벤토리는 장착 무기·방어구와 합산 도시 전투력을 먼저 표시한다. 개별 장비에는 상세 보기와 장착 버튼을 분리하고, 모바일에서는 두 열로 배치한다.
- 신규 획득·이미 보유·발견 없음 결과를 구분하고 서버 영수증의 장비·전투력을 큰 이미지와 함께 공개한다. 이미지 등장 효과는 동작 줄이기 설정을 따른다.
- OWNER CMS의 탐색 장비 설정에도 같은 이미지를 표시한다. PWA·게임 진입점·CMS의 관련 캐시 버전을 `20261012-explore-art2`로 맞춘다.

## 유지하는 정책

서버·공유 전투·경제 설정·DB 코드는 수정하지 않았다. 기존 무료 탐색, 현재 위치 제한, 대기·근무·사망·구금 검사, 발견 비중, 장비 전투력, 회차 초기화, TEST/ON 분리와 거래 영수증을 그대로 사용한다. 기존 시장 구매 가격과 OWNER 저장 방식도 유지한다.
