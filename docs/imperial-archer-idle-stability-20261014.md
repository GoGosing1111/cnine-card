# SSS 주작 궁사 대기 위치·반복 수정 — 2026-10-14

사용자 제보는 대기 주작의 빠른 움직임, 캐릭터와 어긋나는 위치와 흔들림이다. 이전 구현은 부리 위치가 서로 다른 그림에 같은 중앙 피벗을 썼고 프레임을 즉시 교체했다. 아우라 2.4초와 대기 모드 4초가 달라 반복 시작에서 중간 자세가 첫 자세로 돌아갔다. 몸도 0.5초마다 자세를 교체했다. 기존 정적 경계·접점 검수에서 실제 반복 경계의 연속성을 놓쳤다.

## 수정

- 원본 RGB·전체 아우라·승인 원화·활과 몸 프레임은 보존했다. 앞뒤 아우라 파생 아틀라스만 V2로 추가한다.
- 연속된 4개 날갯짓의 실제 부리를 등록해 같은 세계 좌표에 놓는다. 캐릭터 발을 기준으로 부리를 고정하고 한 반복의 공통 범위로 크기와 확대 카메라를 정한다.
- 0→1→2→3→2→1의 8초 왕복과 부드러운 보간으로 시작·종료 자세를 연결한다. 대기 몸 0번 프레임을 유지한다. 다른 사격·대시·궁극기 자세 시간표는 유지한다.
- 서로 다른 그림 사이의 보간은 투명 중간 계층에서 premultiplied 값을 가중 합산한 뒤 전장에 정상 합성한다. 원본 진한 빨강이 전장 배경과 직접 가산되거나 정상 합성 두 번으로 불필요하게 어두워지지 않게 한다.
- 앞뒤 꼬리는 기준점에 상대적인 곡선 경계에서 알파를 상보적으로 나눈다. 직선으로 몸을 가르던 앞 계층 경계를 완화한다.
- 같은 프리뷰의 재생 코드·manifest·V2 파생 효과만 수정했으며 공용 V3·서버·DB·경제·성능·운영 용병 등록을 바꾸지 않았다.
