# 계급 성장·혜택 개편 — 2026-10-08

사용자 최종 승인: 필요 경험치 8배, 보유 경험치는 기존 원수 상한까지 유지, 소령 코인 보상량 +5%부터 계급마다 +0.25%p, 준장 아이템 드랍 증가율 +1%부터 계급마다 +1%p. 기존 원수 공격력·체력 효과는 상사부터 유지한다. 후속 요청에 따라 레벨이 오를수록 다음 레벨 요구량도 계속 증가한다.

## 적용 정책

- 최고 계급은 원수 Lv.250 그대로다. 서버의 기존 이차 성장 곡선에 8배를 적용한다. EXP 지급량은 바꾸지 않는다.
- 다음 레벨 요구량: Lv.1 512 / Lv.80 3,040 / Lv.170 5,920 / Lv.215 7,360 / Lv.249 8,448 EXP. 전 구간에서 직전 레벨보다 증가한다.
- 기존 원수 상한 139,440 EXP는 상사 Lv.80, 현재 400 / 필요 3,040 EXP(13.15%)다. 초과 활동 영수증을 역산하거나 경험치를 재작성하지 않는다.
- 상사 이상 공격력 10%, HP 15%, 편성 보관함 5칸. 이후 계급에 전투 배율을 추가하지 않는다.
- 코인: 소령 5%, 중령 5.25%, 대령 5.5%, 준장 5.75%, 소장 6%, 중장 6.25%, 대장 6.5%, 원수 6.75%. 소령 미만 0%.
- 아이템 드랍: 준장 1%, 소장 2%, 중장 3%, 대장 4%, 원수 5%. 기본 확률에 대한 상대 증가다. 원수 기준 기본 10% → 10.5%.
- 기존 개인 PVE 혜택 범위를 유지한다. 경쟁·공동 콘텐츠에는 적용하지 않는다. 포탈 발견·확정 보상·상자 개봉·뽑기·제작 확률과 보상 수량·일일 한도는 변경하지 않는다.
- 통합 가중치 풀에서는 미획득 구간에서만 아이템 확률을 늘리고 코인 확률은 유지한다. 요청 내 계급 조회를 재사용하고, 확정된 영수증 재시도는 다시 판정하지 않는다.
