# Z-BODY 대검 외형 운영 교체

## 승인과 리소스

2026-09-18 사용자: “Z바디 리소스 교체해라 외형 공격모션 스킬모션 광역기 다 잘 발동하게 적용하고”. 후속 크기 지시: “H바디랑 S바디 정도로 맞춰 크기”.

대검 V2 공격·대시 16프레임, 검 꽂기 V5 시전 12프레임, 이전 V3 뇌검·지면 17프레임을 사용한다. 반려 V4는 제외한다. 원본 기록은 `codex/z-body-sword-preview-20260918`의 `f250df66`, `preview/battle-suit-z-sword-v1/`에 보존한다. 운영 `assets/ui/project-v/account-battle-suits/z-sword-v1/manifest.json`은 승인 파일 해시·피벗·타격 시각을 포함한다. PNG는 승인 원본 바이트 그대로다.

## 동작과 크기

Z만 `ZBodySwordAnimation.js`를 사용한다. 기존 지원 슬롯에서 돌진하여 검 끝을 대상에 맞추고 복귀한다. 검격 접촉 810ms, 검 꽂기 740ms, 뇌검 충돌 1080/1210/1340/1430/1540ms다. 중단·전투 종료·대상 교체 때 잔여 타격을 취소하고 슬롯으로 돌아간다.

기존 PixiJS 8.20.0 레이어, GSAP 3.13.0 등록 타임라인을 재사용한다. 몸체·검·지면·충돌은 같은 시계에서 일시정지·배속을 따른다. 별도 렌더러·가짜 적·새 사운드는 없다.

H/S 헬멧~발바닥 높이는 `278×1.4×(479−40)/512 = 333.70859375` 전장 단위다. Z 원본 헬멧~발바닥은 `736−144 = 592` 픽셀이므로 전 모션에 **0.563696948902027** 균일 배율을 적용한다. 검 길이는 몸체 크기에 포함하지 않는다. 기존 지원 슬롯의 화면 배율은 공통으로 적용하고 광역기 V3 배율은 유지한다.

## 피해와 운영 데이터

서버 공식·전투력·승패·공격 주기·스킬칩 배수·획득 정책은 변경하지 않는다. 기존 지원 타격 영수증을 순서대로 최대 48개씩 묶어 돌진→뇌검→돌진 순환으로 표시한다. 검격은 같은 대상끼리, 뇌검은 서버가 확정한 여러 대상의 타격을 묶을 수 있다. 각 영수증은 한 번만 적용하고 같은 시각·대상 숫자는 합쳐 표시한다. 서버 대상 외의 적에게 피해를 추가하지 않는다. 단일 보스에서는 넓은 연출과 함께 그 보스의 확정 피해만 표시한다. 로켓런처·헬기폭격 스킬칩은 기존 발동과 연출을 유지한다.

무기 미장착·다른 무기를 장착한 Z도 대검 외형을 사용한다. 장착 무기 서버 능력치, H/S 총기 외형과 원본은 보존한다. `safe_runtime_upgrade_z_sword_20260918`은 Z 이미지·설명만 원자적으로 갱신한다. 소유·강화·CMS 능력치·공급·공개·활성·코어·레시피는 보존한다. Z가 없는 DB에는 완료 표식을 남기지 않는다.
