# 몬스터 디펜스 · 원거리 적과 회복 분대의 웨이브 정체 수정

제보: [실험쥐 · 디펜스 오류제보합니다](https://www.playdk.kr/board/skm/1336055). 혼자 연습 중 진행되지 않는다는 본문과 첨부 영상에서 A 전선의 마지막 베일 스나이퍼가 먼 거리에서 남아 있는 상황을 확인했다. 운영 이용자의 저장 방을 조회하거나 변경하지 않고 같은 역할 조합을 격리 환경에서 재현했다.

## 원인과 변경

기존 판정은 적의 사거리 안에 아군이 들어오면 무조건 이동을 멈췄다. 베일 스나이퍼의 사거리 530은 전방 돌격 역할의 240보다 길고, 중앙 회복/후방 카드도 실제 거리가 각자의 사거리보다 멀다. 회복이 적의 피해를 상쇄하면 적과 아군 모두 쓰러지지 않아 서버 시간이 10분 진행돼도 같은 웨이브에 남았다. 수정 전 재현 수치는 `qa/monster-defense-range-20261017/before-model.json`에 보존한다.

`preview/coop-defense-v1/source/defense-model.mjs`에서 적은 기존 주기로 계속 공격하면서, **같은 전선의 살아 있고 이동 중이 아닌 공격 역할이 정상 사거리로 반격할 수 있는 위치까지 전진**한다. 회복 역할만으로 이동을 막지 않는다. 이미 상호 공격 가능한 교전은 기존 위치와 공격 주기를 유지한다. 처치는 원래 공격·피해·KO 판정으로 이뤄지며 강제 클리어나 새 타임아웃을 넣지 않았다.

공통 서버 모델만 변경했다. 아군 고정 배치·사거리·공격/회복 수치·난이도·성장 확률·포인트·준비/부활·TEST 및 보상 OFF를 유지한다. 새 저장 필드나 마이그레이션이 없어 아직 종료되지 않은 기존 방도 다음 서버 틱부터 수정된 이동 판정을 사용한다. 만료/패배/완료된 방을 부활시키지는 않는다. 클라이언트 번들을 다시 빌드해 내용이 동일함을 확인했으므로 프런트 캐시 버전은 변경하지 않았다.
