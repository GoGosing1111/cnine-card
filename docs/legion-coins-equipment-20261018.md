# 군단토벌 판당 코인 설계 · 용병 장비 극희귀 설정

사용자 요청: OFF인 신맵까지 판당 코인을 수급할 수 있도록 설계하고, 용병 장비 드랍 확률은 전부 극악으로 설정한다.

## 작업 구분

- 최신 사용자 승인에 따라 몬스터 처치 즉시 코인을 지급하는 API·화면을 구현했다. 보너스를 포함해 아래 표의 금액을 넘지 않는다. 배포 기록은 문서 마지막 절에 추가한다.
- 용병 장비는 기존 운영 CMS에 저장된 확률을 직접 낮춘다. 신규 맵 5개 OFF, 장비 30개 활성/공개/공급 OFF, 기존 계정 보유분과 연마 정책을 보존한다.
- 운영 조회 기준: 잊혀진 섬 ON/r29, 지역 OFF/r4. 사용자가 앞서 수정한 보통~악몽의 정예 세트 0%와 지옥/재앙의 세트 0.001%를 다시 높이지 않는다.

## 코인 수급 정책

2026-10-18 후속 사용자 지시: **기존 기본 금액은 전부 10배로 올리고, 재앙은 조정된 지옥의 2배**로 한다. 이후 **클리어 보상이 아니라 플레이 시간 동안 몬스터를 잡으며 자연스럽게 습득**하는 방식으로 정정했다. 아래 표는 처치 수급 기준의 최신안이다. 후속 `저 금액을 초과하지않게 하고 라이브 반영`으로 구현·배포를 승인했다.

현재 공통 제한인 한 판 최대 7분, 모든 맵 합산 하루 10회, 후원 시 13회를 기준으로 한다. 신규 지역의 보통 몬스터 전투력은 65만/보스 1,200만이며, 잊혀진 섬 지옥의 90만/900만과 비슷한 성장 구간이다. 따라서 신맵 보통 보상은 잊혀진 섬 지옥과 같은 금액으로 시작한다.

아래는 **한 판 동안의 보너스 포함 최종 수급 상한**이다. 클리어 시 지급하는 확정 보상이 아니며, 실제 수급은 처치한 몬스터만 누적한다. 코인 보너스가 있어도 아래 상한을 넘지 않는다. 신규 지역 5곳은 같은 난이도별 전투 능력치 표를 쓰므로 목표액도 같게 둔다. 세트/고유 장비 선택이 맵 선택의 이유가 되게 한다.

- 일반 몬스터를 처치할 때마다 **100% 코인 발생 → 자동 습득 → 계정 지갑과 전투 누적액에 반영**한다. 코인 획득을 장비의 극희귀 추첨이나 클릭 줍기에 묶지 않는다. 자석 펫이 없어도 코인은 자동 회수한다.
- 1마리의 기본 가치는 일반 **1배**, 정예 **3배**, 보스 **5배**를 설계 기준으로 둔다. 코인의 대부분을 일반·정예 사냥에 나눠 주고, 보스도 한 마리의 처치 보상으로 계산한다. 별도 클리어 보너스나 미달분 채워주기는 없다.
- 화면에서 몬스터가 쓰러질 때 기존 HUD에 맞춘 작은 `+획득액`, 전투 HUD에 `이번 토벌 획득 코인` 누적액을 보여준다. 광역 처치의 겹치는 숫자는 짧게 묶고, 계정 지급은 서버가 확인한 실제 처치별 금액을 합산한다.
- 전멸·시간 초과·자발적 철수·연결 끊김에도 **이미 지급된 코인을 회수하거나 감액하지 않는다**. 첫 처치부터 획득하며, 이전 설계의 90초/10마리 조건·실패 30%·철수 시 코인 0 규칙은 폐기한다. 처치하지 않은 몬스터, 보스 등장 시 강제 퇴장한 잔여 몬스터, 단순 대기 시간에는 코인이 없다.
- 기본 10회 모두 충분히 사냥했을 때 목표 총액은 잊혀진 섬 하루 100/200/300/500억, 신맵 500/700/1,000/1,500/3,000억이다. 후원 13회는 각각 130/260/390/650억, 650/910/1,300/1,950/3,900억이다. 실제 처치가 적으면 그만큼 낮아지며, 맵을 옮겨도 횟수는 공유한다.
- 펫·트로피 코인 증가 효과는 기존 합산 규칙을 한 번만 적용하되, **최종 누적액은 표의 금액 그대로 상한**이다. 기존 2배 상한 제안은 폐기한다. 출전 시 계엄령이 진행 중이면 독립 ×0.9를 고정한다. 드랍률 증가와 팩/뽑기 이벤트 배수는 코인에 연결하지 않는다.
- OFF/TEST는 실제 코인을 지급하지 않는다. OWNER 무제한 검수 입장은 유지하되 신규 코인 수급 원정은 일반 계정과 같은 하루 10/13회 한도를 적용한다. 지급 가능한 원정 여부는 begin 시 고정하며 몬스터마다 입장 횟수를 차감하지 않는다.

### 처치당 금액 산정

출전 시 같은 맵·난이도에 고정된 처치 단가를 사용한다. 계정별 시뮬레이션의 실제 처치 수로 목표액을 나누면 몇 마리만 잡는 약한 편성에도 전체 금액을 주는 문제가 생기므로, **정책에 고정한 출현 가능 수**를 분모로 쓴다.

- 현재 12슬롯·5초 간격 증원과 보스 등장 시각 270/285/300초를 기준으로 일반·정예 합산 출현 가능 수는 648/684/720마리다. 정예가 있는 신맵은 그중 최대 4마리를 정예로 대체한다. 해안·거수의 보스 호위 2마리는 일반 가치로 포함한다.
- `기준 가중 처치량 = 일반 수 × 1 + 정예 수 × 3 + 보스 수 × 5`. 잊혀진 섬은 653/653/689/725, 해안·거수는 663/663/699/735/735, 사막·대극장·역천은 661/661/697/733/733이다. 순서는 보통/어려움/악몽/지옥/재앙이며 섬에는 재앙이 없다.
- 처치마다 `새 누적액 = floor(목표액 × 보너스 배율 × 누적 가중 처치량 / 기준 가중 처치량)`, `이번 지급액 = 새 누적액 - 이전 지급액 합계`로 계산한다. 정수 연산으로 소수점 잔액을 다음 처치에 넘기고, 판당 보너스 반영 상한을 넘지 않는다. 클리어 순간 잔액을 별도로 더하지 않는다.
- 예를 들어 신맵 지옥 150억은 일반 한 마리당 약 2,041만~2,046만, 정예는 그 3배, 보스는 그 5배씩 사냥 중 나뉘어 들어온다. 재앙은 같은 처치 구조에서 목표액이 300억이므로 처치 단가도 정확히 2배를 기준으로 한다(정수 반올림 차이 제외).
- 7분은 보스전을 포함한 최대 시간이다. 보스가 나오기 전 사냥 구간에 수급이 집중되며, 처치 없이 시간을 보낸다고 코인이 자동 발생하지 않는다. 증원 규칙 변경 시 기준 처치량도 새 정책 revision에서 갱신하고 진행 중인 원정에는 기존 단가를 유지한다.

### 구현된 지급 계약

1. 승인된 판당 상한·기준 가중 처치량은 `shared/legion-hunt-coins-v1.mjs`의 버전 정책으로 고정하고 CMS에 읽기 전용 표로 표시한다. 운영 모드는 기존 CMS 설정을 따른다. 이번 출시로 신맵 OFF를 바꾸지 않는다. `clearCoins`·실패 감액·2배 상한은 사용하지 않는다.
2. 새 원정 출전 시 코인 정책 revision·목표액·기준 처치량·계정 코인 보너스를 스냅샷에 고정한다. begin에서 실제 코인 수급 가능 여부와 일일 횟수를 한 번 확정한다. 정책 필드가 없는 과거 원정은 코인 0으로 호환하고 소급 지급하지 않는다.
3. 기존 `reveal`/`revealMany` 요청에서 서버 타임라인의 실제 `huntKill` KO와 도달 시각을 검증해 코인을 지급한다. 아이템 드랍이 실패하거나 필드 공간이 가득 차도 코인은 별도로 지급한다. 클라이언트 금액·몬스터 등급·처치 수는 신뢰하지 않는다. `ENEMY_DESPAWN`, 피해만 준 공격, 아직 도달하지 않은 KO는 제외한다.
4. 코인은 **플레이 중 소규모 묶음 거래**로 지갑에 반영한다. 이미 묶어 보내는 처치 확인 요청을 재사용해 몬스터마다 별도 API/계정 전체 조회를 추가하지 않는다. 서버는 새 처치분의 `coinDelta`·`earnedCoins`를 반환하고, 성공 응답을 받은 획득액을 화면에 반영한다.
5. 기존 계정 잠금·세션 CAS·현재 ON 모드 확인을 재사용한다. 지급한 처치 시퀀스/누적 가중치·지갑 가산·코인 로그·원정별 누적 영수증을 같은 거래로 저장하며 실패 시 전부 롤백한다. 동일 KO 재확인, 겹치는 배치, 지연 응답, 동시 요청에서도 증가분은 한 번만 지급한다.
6. 원정 세션의 `coins` 영수증에 누적하고, 코인 로그에는 원정 ID와 검증한 마지막 처치 시퀀스를 남긴다. 복구는 저장된 확인 시퀀스 이하의 미지급 처치만 이어 처리한다. 응답 유실 뒤 재시도는 저장된 지급 결과를 반환한다.
7. `finish`는 새 클리어 코인을 만들지 않고, 도달·확인된 KO의 누락된 마지막 묶음만 같은 중복 방지 경로로 처리한 뒤 **이미 받은 합계**를 표시한다. 기존 장비/아이템 FINISH 정산에 코인을 다시 넣지 않는다. 철수/cancel/복구 시 이미 지급된 지갑 잔액은 유지한다.
8. 입장 화면에는 `판당 최대 코인`, 전투 중에는 `이번 토벌 획득 코인`, 결과에는 `총 획득 코인`을 표시한다. 숫자는 DOM으로 표시한다. 사용자가 새 금장 이미지 표시판을 기존 디자인에 어울리지 않는다고 반려해, 생성 원본은 QA 이력에만 보존하고 기존 HUD·정보 행의 글꼴·색·배치에 맞췄다.

## 용병 장비 설정

대상은 5지역 × (세트 5부위 + 고유 1개) = **30종**, 보통~재앙 5난이도 전부다. 일반 필드 후보 12종에는 현재 용병 장비가 없으며, 지역 세트/고유 판정이 전용 획득 경로다.

| 판정 | 변경 후 기본 확률 | 해석 |
|---|---:|---|
| 보통/어려움/악몽 정예 세트 | 0% 유지 | 기존 제외 상태 유지 |
| 지옥/재앙 정예 세트 | 0.001% 유지 | 정예 처치당 세트 중 하나, 평균 10만 회당 1번 |
| 모든 난이도 보스 세트 | 0.001% | 보스 처치당 세트 중 하나, 평균 10만 회당 1번 |
| 모든 난이도 보스 고유 | 0.001% | 보스 처치당 고유 장비, 평균 10만 회당 1번 |

- `%` 입력값은 가중치가 아니라 해당 처치의 실제 기본 확률이다. **0.001% = 0.00001 = 1/100,000**이며, 0.001이라는 소수 확률(0.1%)과 다르다.
- 세트 성공 후 5부위 중 균등하게 하나를 선택하므로 특정 부위는 **0.0002% = 1/500,000**이다. 세트 확률을 각 부위에 따로 5번 적용하지 않는다.
- 보스 세트와 고유는 독립 추첨이다. 보스당 둘 중 하나 이상은 기본 **0.00199999%**, 약 5만 회당 1번이다. 지옥/재앙은 정예 처치 수도 추가되므로 판당 전체 확률과 보스 1회의 확률은 다르다.
- 미라클 드랍 +30%는 기본값에 1.3배, 펫·트로피 합산 드랍 +B%는 추가로 `(1+B/100)`배다. 기존 혜택은 유지한다. 예: +30% 미라클과 +50% 수집 보너스이면 각 기본 0.001%가 **0.00195%**가 된다. 이벤트/계정별 최종값을 기본값과 혼동하지 않는다.
- 10만 회·50만 회는 평균 간격의 설명이며 확정 횟수·천장·연속 실패 보정이 아니다. 기존 드랍 획득/소멸과 단일 종료 정산은 그대로다.
- 일반 필드 아이템·연마석 확률/수량·전투력·몬스터·원본 이미지·장비 잠금·계정 재화는 변경하지 않는다. 새 원정부터 변경된 저장 정책을 사용한다.

## 적용 도구와 검사

- `scripts/ops/legion-equipment-extreme-rare-20261018.mjs`: 기존 양수 확률의 상한만 0.001%로 낮춘다. 기존 0%는 유지한다. 지역 정책 행 잠금/CAS, 카탈로그 잠금 확인, 다른 필드 풀 우회 여부 확인, 감사 로그·완료 영수증을 하나의 PostgreSQL 거래로 저장한다.
- 작업 키 `ops:legion-equipment-extreme-rare:20261018:v1`. 재실행은 영수증만 반환하며 이후 운영자의 수정값을 덮어쓰지 않는다. dry-run은 롤백한다.
