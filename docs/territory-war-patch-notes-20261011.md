# 영토전 개편 패치노트 — 개인 진영 편성 · 9거점 전장 · 아군 지휘 통신

작성일: 2026년 10월 11일

영토전을 **개인 단위로 진영을 나누고, 북부·중부·남부의 연결된 거점을 함께 공략하는 전장**으로 개편했습니다. 전용 지도와 수호·정화 성채 이미지를 적용했으며, 지휘관 메시지는 같은 진영 참가자에게만 전달됩니다.

이 문서는 10월 11일 진행한 전장·편성 개편과 후속 지도·지휘 통신 개선을 합친 변경 기록입니다. **운영 코드 반영은 완료됐으며, 새 지도와 개인 편성은 다음에 개장하는 신규 회차부터 적용됩니다.** 마지막 운영 확인인 10월 11일 21:16 기준 영토전은 OFF, 기존 69회차는 중지 상태였습니다. 이번 업데이트로 영토전을 자동 개장하거나 기존 참가자의 진영을 즉시 바꾸지는 않았습니다.

## 2. 클랜 묶음 편성에서 개인 균형 편성으로 변경

새 회차는 클랜을 하나의 팀 묶음으로 취급하지 않습니다. 모집 마감 시 신청한 유저를 개인별로 비교해 두 진영으로 배분합니다.

- 양 진영의 **인원수와 전투력**을 함께 고려합니다.
- **최근 완료된 5개 회차**의 참여 여부·공격 활동·승패 이력도 편성에 반영합니다. 신규 참가자는 신규 참가자로 구분합니다.
- 같은 클랜 소속이라는 이유로 같은 진영에 고정되지 않습니다.
- 클랜 로스터 전체를 새 회차에 강제로 등록하거나, 클랜 배치 때문에 개인 진영을 고정하던 방식을 신규 회차에서 제거했습니다.
- 클랜 가입 여부와 관계없이 모집 중 개인 신청·취소가 가능합니다. 모집이 끝난 뒤에는 해당 회차의 확정된 진영으로 참여합니다.

공격에는 기존과 같이 **일반 카드 5장으로 구성한 유효한 PVP 덱**이 필요합니다. 참가 명단이 보존됐더라도 덱이 미완성이라면 덱을 준비하고 편성 정보를 갱신해야 합니다.

### 중지된 회차의 대기 신청 보존

전쟁이 시작되기 전에 중지된 회차의 대기 명단은 다음 모집으로 승계합니다. 이전 진영 배정과 클랜 강제 참가 표시를 초기화하고, 새 모집 마감 때 개인 기준으로 다시 편성합니다.

- 마지막 운영 확인 당시 **69회차 대기자 146명**은 그대로 보존됐습니다.
- 이 146명을 배포 시점에 새 진영으로 나눈 것은 아닙니다. 최종 인원과 진영은 다음 모집의 신청·취소 결과를 반영해 결정됩니다.
- 이미 시작했거나 종료된 회차의 참가자를 다음 회차에 자동 재등록하는 기능은 아닙니다.

## 3. 일직선 전장을 북·중·남 9거점으로 재구성

이전에도 지도에는 9개 지점이 있었습니다. 이번 변경의 핵심은 거점 수 증가가 아니라, **한 곳씩 밀고 당기던 진행 방식을 여러 경로의 점령전으로 바꾼 것**입니다.

새 전장은 다음과 같이 구성됩니다. 표의 소속은 회차 시작 시점 기준이며, 교전 결과에 따라 바뀝니다.

| 구역 | 수호 측 서부 거점 | 중립 거점 | 정화 측 동부 거점 |
|---|---|---|---|
| 본진 | 서부 본진 | — | 동부 본진 |
| 북부 | 북서 고지 | — | 북동 요새 |
| 중부 | 서부 관문 | 중앙 교차지 | 동부 관문 |
| 남부 | 남서 보급로 | — | 남동 보급로 |

시작 시 각 진영이 본진을 포함해 4개 거점을 점령하고, 중앙 교차지 1개는 중립입니다. 북부·중부·남부는 서로 연결되어 있어 중앙만 계속 공격할 필요가 없습니다. 다른 경로로 진격하거나, 상대의 연결 거점을 빼앗아 진격 경로를 끊을 수 있습니다.

### 공격과 방어가 가능한 조건

1. **공격:** 우리 본진에서 아군 점령지만 따라 연결되는 거점에 인접한 적·중립 거점을 공략할 수 있습니다.
2. **방어:** 상대 진영이 진입할 수 있는 아군 점령 거점에는 방어 지원이 가능합니다.
3. **고립:** 본진과의 연결이 끊긴 점령지는 추가 진격의 출발점으로 사용할 수 없습니다. 소유권 자체가 사라지는 것은 아니며, 점령 거점 수에는 포함됩니다.
4. **상태 갱신:** 점령 결과에 따라 공격·방어 가능한 경로를 다시 계산합니다. 지도에서 보이는 진입 가능 여부를 확인한 뒤 전장에 들어가세요.

### 거점별로 독립적인 교전

- 여러 거점에서 공성·시설 교전을 동시에 진행할 수 있습니다.
- 거점에서 승리하면 해당 거점을 점령하거나 기존 점령지를 방어합니다.
- 전쟁이 끝나지 않았다면 해당 거점만 다음 교전으로 전환합니다. 해당 거점의 공성 HP와 시설 전장을 새로 준비하고, 다른 거점의 공성 HP·시설 진행 상태는 유지합니다.
- 적 본진 점령은 다음 교전으로 넘어가지 않고 전쟁 승리로 이어집니다.

## 4. 승패 판정 변경

**적 본진을 점령하면 즉시 승리**합니다. 본진 점령 없이 제한 시간이 끝났다면 다음 순서로 승패를 결정합니다.

1. **점령 거점 수**가 많은 진영 승리
2. 거점 수가 같으면 **해당 회차 누적 공성 피해량**이 많은 진영 승리
3. 두 수치가 모두 같으면 **무승부**

이전에는 전선이 중앙에서 어느 쪽으로 밀렸는지를 먼저 보고, 전선이 중앙이면 양 진영의 남은 공성 HP 비율을 비교했습니다. 새 지도에서는 특정 거점 한 곳의 남은 HP 비율로 시간 종료 승패를 판정하지 않습니다.

따라서 본진으로 진격하는 것과 함께, 종료 시점까지 점령 거점을 확보하고 방어하는 것이 중요해집니다.

## 5. 전선 보정과 작전·시설 적용 범위 정리

직선 전선의 전진·후퇴 단계에 맞춰 적용하던 **열세 진영 자동 반격 보정, 최후 방어, 연속 진격 피로**는 신규 다중 거점 회차에 적용하지 않습니다. 이전 회차의 기록과 판정은 당시 규칙을 유지합니다.

이 변경은 투표로 사용하는 작전을 없애는 것이 아닙니다. **대포병 반격을 포함한 기존 작전 8종과 시설 스킬 4종은 유지**합니다.

| 구분 | 신규 전장에서의 적용 |
|---|---|
| 직접 공성 피해·공성 HP 회복 | 선택한 거점의 전장에 적용 |
| 중계탑·보급열차·공성포 등 시설 진행 | 각 거점의 전장별로 진행 |
| 진영 단위 작전 강화 효과 | 해당 회차의 같은 진영에서 공유 |
| 스킬 재사용 대기시간 | 진영·스킬별로 회차 내 공유. 거점을 바꿔도 초기화되지 않음 |

- 같은 진영 **25명 투표로 자동 발동**하는 규칙을 유지합니다.
- 스킬별 **45분 재사용 대기시간**을 유지합니다.
- EMP의 중계탑 확보 조건, 공성포의 진영 전력 조건 등 기존 시설 조건을 유지합니다.
- 여러 거점의 대기 중인 투표와 예약 공성포가 각 대상 거점에서 처리되도록 연결했습니다.
- 거점 점령이나 경로 변경으로 더 이상 유효하지 않은 전장에 공격·스킬이 적용되지 않도록 확인합니다.

## 6. 개인 보상 유지, 클랜 시즌 승점 연동 종료

개인 편성 회차는 클랜 대항 결과로 취급하지 않으므로 **클랜 시즌 승점을 새로 지급하지 않습니다.** 과거 영토전에서 이미 반영한 클랜 시즌 승점은 보존합니다.

아래 정책은 이번 개편으로 변경하지 않았습니다.

- 개인 행동력의 기본 최대치·회복·공격 비용과 공격 횟수 집계
- 개인 교전 승리 보상과 기여도 집계
- 회차 승리·패배·무승부 및 참여 보상의 기존 지급 조건
- 기존 회차의 보상 기록과 미수령 보상
- 전선 공성·중계탑 확보·열차 호위라는 교전 목표와 기존 카드 전투

직선 전선 전용 보정의 미적용과 개인 보상 정책 유지는 별개입니다. 새로운 보상 배율이나 추가 지급액을 이번 패치로 신설하지 않았습니다.

## 7. 전용 지도와 수호·정화 진영 이미지 적용

전장을 한눈에 구분할 수 있도록 새 지도와 진영 이미지를 적용했습니다.

- **북부:** 설산과 능선이 보이는 지형
- **중부:** 거점들이 만나는 석조 교차로
- **남부:** 강과 숲이 이어지는 지형
- **수호 진영:** 은백색·청색 성채
- **정화 진영:** 진홍색·금색 성채
- **중립 거점:** 금빛 성소

상단 진영 배너, 지도 거점, 아군 지휘관 영역에 같은 진영 이미지를 사용합니다. 본진은 일반 거점보다 크게 표시하고, 선택한 거점은 바닥 광원과 이름표로 구분합니다.

화면에서 확인하고 조작할 수 있는 항목도 정리했습니다.

- 상단 진영별 참가 인원·점령 거점 수·내 진영 표시
- 양 진영의 점령 현황 표시
- 거점별 소유 진영·공성 HP·진입 가능 여부
- **상단 진영 이미지를 눌러 해당 본진 선택**
- 지도 거점 선택 → 전장 진입 → 공성·시설 교전 → 지도 복귀
- PC 키보드 포커스 표시와 동작 줄이기 설정 대응

기존 공통 UI 색상과 카드 전투 화면은 이어서 사용합니다. PC와 모바일 모두 9개 거점을 확인하고 선택할 수 있도록 배치를 조정했습니다.

## 8. 지휘관 메시지를 아군 전용으로 변경

지휘관 메시지는 **해당 회차에 활성 참가 중인 같은 진영 유저에게만** 전달됩니다. 이전에는 양 진영 메시지가 공통 상태 응답에 함께 포함됐으나, 이제는 응답을 보내기 전에 현재 참가 상태와 진영을 확인합니다.

| 조회하는 유저 | 받을 수 있는 지휘관 메시지 |
|---|---|
| 수호 진영 활성 참가자 | 수호 진영 메시지 |
| 정화 진영 활성 참가자 | 정화 진영 메시지 |
| 관전자·진영 미배정·비활성 참가자 | 없음 |
| CMS 관리자 | 관리자라는 이유로 전체 열람하지 않음. 실제 활성 참가 진영 기준 적용 |

- 전체 상태 조회, 신규 지도 자동 갱신, 메시지 전송 직후 조회, CMS 상태 조회에 같은 기준을 적용합니다.
- 진영이나 참가 상태가 변경되면 새 조회 시 현재 소속을 기준으로 확인합니다.
- 지휘 패널에는 아군 지휘관과 아군 메시지만 표시합니다.
- **‘아군 지휘 통신’, ‘아군 전용’, ‘같은 진영에만 표시’** 안내를 추가했습니다.
- 전송 완료 안내를 **‘지휘 메시지를 아군에게 전송했습니다.’**로 변경했습니다.
- 모바일 지휘 메뉴의 메시지 개수도 아군 메시지만 집계합니다.
- 모바일 지휘 패널 위로 공성 HP 영역이 겹치던 문제와 닫기 버튼 주변 표시를 정리했습니다.

지휘관의 메시지 작성 권한, 최대 100자, 10초 전송 간격은 기존 규칙을 유지합니다.

## 9. 거점 전환과 전투·정산 안정성 개선

여러 거점에서 동시에 교전해도 선택한 전장과 실제 결과가 일치하도록 처리했습니다.

- 다른 거점으로 이동한 뒤 이전 조회 응답이 늦게 도착해도 현재 선택을 덮어쓰지 않습니다.
- 교전 결과 확인, 상태 갱신, 보상 수령 등의 응답에서도 선택한 거점을 이어서 표시하도록 연결했습니다.
- 아직 확인하지 못한 공격 결과가 남아 있으면 해당 결과를 먼저 복구한 뒤 다음 전장으로 이동합니다.
- 이미 종료된 전장, 진입할 수 없는 거점, 휴전 중이거나 승패가 확정된 회차에 대한 공격은 차단합니다.
- 상태가 바뀌어 요청을 처리할 수 없을 때 행동력·코인·기여도만 일부 반영되지 않도록 함께 취소합니다.
- 같은 공격 요청을 재시도해도 교전 결과와 보상이 중복 반영되지 않도록 확인합니다.
- 보상 정산을 재시도하는 동안 추가 공격으로 승패가 뒤집히지 않도록 결과를 먼저 확정합니다.

## 10. CMS 관리 화면 변경

- 개편 안내를 클랜 4 대 4 기준에서 **개인 균형 편성·다중 거점** 기준으로 변경했습니다.
- 인해전술에 **지원 거점 선택**을 추가했습니다.
- 선택 거점의 실제 전장과 공성 HP를 기준으로 예상 피해를 표시합니다.
- 해당 진영이 공략하거나 방어할 수 있는 거점에만 발동할 수 있습니다.
- 점령 등으로 대상 전장이 변경됐다면 이전 전장에 잘못 발동하지 않도록 차단합니다.
- **진영별 회차당 1회 사용 제한**과 기존 피해율 설정은 유지합니다.
- 관리자 상태 조회에서도 지휘 메시지의 아군 전용 제한을 동일하게 적용합니다.

## 11. 적용 범위와 기존 기록 보존

새 지도·개인 편성·새 승패 기준은 **다음 신규 회차**부터 적용됩니다. 지휘 메시지의 같은 진영 제한은 기존·신규 회차의 공통 상태 조회에 적용됩니다.

기존 회차의 전선·참가·정산·보상 기록은 새 규칙으로 다시 계산하지 않습니다. 배포 당시 중지된 69회차와 대기 명단을 보존했으며, 기존 회차를 새 전장으로 강제로 변환하지 않았습니다.
