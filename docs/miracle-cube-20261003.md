# 미라클 큐브 준비 — 2026-10-03

사용자 요청: 프리미엄 큐브를 대체할 최상위 용병 큐브, 전체 등급 랜덤, 등급별 및 등급 안의 용병별 확률 CMS, 전용 리소스·UI·개봉 연출을 준비한다.

## 구현과 운영 상태

- 신규 아이템 `MIRACLE_CUBE`: 큐브 1개당 용병 1장, 1개 또는 10개 개봉. C/B/A/S/SS/SSS 등급을 추첨한 뒤 그 등급의 용병을 다시 추첨한다. 두 확률은 소수점 6자리까지 각각 정확히 100%로 검증하며 최종 당첨 확률도 표시한다.
- OWNER CMS `/admin/miracle-cube.html`: 등급 확률·개별 용병 확률·등급 내 균등 배분·검색·실시간 합계·OFF/ON·운영 메모·연출 미리보기. 기존 CMS의 별도 메뉴와 대시보드 바로가기를 추가했다. OWNER 외 저장을 금지하고 운영 메모는 일반 계정에 제공하지 않는다.
- 실제 화면 `/miracle-cube/`, 관리자 미리보기 `/miracle-cube/?admin=1`. 기존 공통 메뉴와 연결하며 인벤토리 사용 버튼으로 진입한다. 승인 용병 원화와 전체 결과·중복 보유 수량을 표시한다.
- 기본값 **개봉 OFF, 등급 확률 0%, 용병 확률 미설정**. 설정이 유효하기 전 ON 저장과 개봉을 차단한다. 임의 운영 확률·판매가·드랍률을 정하거나 실제 큐브를 지급하지 않는다. 리미티드 및 전역 획득 OFF 용병을 제외하며 하이퍼팩 확률은 변경하지 않는다.
- 최신 원격 `bef61e09`와 직전 운영 `24fd5f71`에 프리미엄 큐브 전량 삭제가 반영됐다. 초기 작업 중 준비한 기존 보유분 전환 선택지는 폐기했다. **신규 미라클만 등록**하며 삭제된 프리미엄 코드·보유분·보장·보정·드랍을 복구하지 않는다. 관련 최신 AGENTS 지시를 유지한다.
