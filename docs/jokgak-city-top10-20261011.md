# 족각도시 18시 회차 TOP10 메시지 보상 — 2026-10-11

사용자 요청과 후속 답변: 이번 18시 로테이션을 자정에 정산하여 현금 보유 TOP10에게 **1인당 5천억 코인**, **공동 10위까지 모두** 메시지로 지급한다.

- 대상: KST 2026-10-11 18:00 ~ 2026-10-12 00:00, epoch `82951` 한 회차.
- 기준: 기존 도시 업적 정산과 같은 ON 참여자의 종료 직전 현금. 해당 회차의 고정 직업 수입표에 따른 미반영 자동 수입을 포함한다. 퇴장자·오프라인 참여자 포함, TEST·비참여·이용 정지 계정 제외. 수령하지 않은 근무 완료 보상은 기존 기준대로 가산하지 않는다.
- 현금 내림차순의 10번째 금액 이상을 모두 선정한다. 동률은 공동 순위로 표시하며, 공동 10위가 있으면 지급 인원과 총액이 10명·5조 코인보다 늘어날 수 있다. 참여자가 10명 미만이면 실제 대상자만 지급한다.
- 수령 가능한 `COIN_REWARD` 메시지에 `500000000000` 코인을 첨부한다. 메시지 발송 시 게임 코인 잔액을 즉시 올리지 않고, 기존 보상 수령 버튼과 수령 영수증을 사용한다.
- 정산과 메시지·보상·감사 기록·완료 영수증·이전 회차 로그 삭제는 기존 도시 잠금과 **하나의 원자적 DB 배치**에서 커밋한다. 후발 참여·현금 변경 시 기존 스냅샷 가드가 재계산하며, 실패는 전체 롤백한다. 캠페인/유저 고유 인덱스와 회차 커서로 중복 발송을 막는다.
- 코드를 배포하는 것만으로 활성화되지 않는다. 운영 스크립트가 해당 회차에 예약 영수증을 등록한 경우에만 실행한다. 이후 회차에는 반복하지 않는다. 도시 ON/OFF·CMS revision·직업별 일반 보상 설정을 변경하지 않는다.

- `functions/_jokgak_city_top10_event.js`: 고정 이벤트·공동 순위·개인별 메시지·정산 완료 영수증.
