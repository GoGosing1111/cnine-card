# 핑두 리페어 쿠폰 — 2차 인증자 메시지 지급

## 요청 범위

- 사용자 지시: 2차 인증 전체 유저에게 핑두 리페어 쿠폰 1개씩 메시지로 지급.
- 발송 시점의 실제 2차 인증 연결 계정 중 ACTIVE 상태를 대상으로 한다. 인증된 USER·ADMIN·OWNER를 포함하며 미인증·이용 정지 계정은 기존 안전 필터로 제외한다.
- 인벤토리 직접 지급이 아니라 개인 메시지에 수령 가능한 쿠폰 1개를 첨부한다.

## 변경 및 안전 기준

- 기존 인증자 메시지 발송 API, 개인별 캠페인 중복 방지 인덱스, 원자적 메시지/보상 저장 및 수령 영수증을 그대로 사용한다.
- 서버 보상 종류, CMS 선택 항목, 메시지함 단일/일괄 수령 표시를 연결했다. 일반 입력형 쿠폰 발급은 확장하지 않는다.
- 발송·수령 경로에서 독립 카탈로그 게이트를 확인한다. 등록은 보유량·복구 비용·운영 정책을 바꾸지 않는다.
- 장비 강화·복구 정책, 상점·뽑기·드랍풀은 변경하지 않는다.
- 발송 결과가 불명확하면 새 요청으로 재발송하지 않고 관리자 로그의 캠페인 키·인원·수량을 먼저 확인한다.

## 검증 및 실행 상태

- PostgreSQL에서 인증/상태/역할 필터, 1인 1개 메시지, 캠페인 재시도, 1회 수령, 기존 보유량·미확인 수량 증가, 발송/수령 실패 롤백을 검사한다.
- 운영 발송은 코드 배포 후 CMS에서 한 번 실행하고 결과 인원·수량·캠페인을 기록한다. 현재는 발송 전이다.
