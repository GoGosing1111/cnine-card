# 랭크 듀오 시즌 로비 UI — 2026-09-25

사용자 요청: 듀오 UI를 게임 콘텐츠에 맞는 완성도로 개편한다.

## 적용 범위

- `docs/ui-fixed-reference-20260915.md`의 네이비·라임, Noto Sans KR / Barlow Condensed, 공통 메뉴를 계승한다.
- 큰 홍보 제목과 설명 패널을 경기장·두 사람의 팀 배너·출전 조작으로 교체한다. 본인 배너를 구분하고 팀 점수와 전적을 같은 무대에 표시한다.
- 개인 행동력의 현재/최대 값, 충전 시각, 공격 비용과 실제 출전 버튼을 묶는다. 모바일에서는 행동력 게이지를 압축하고 설명보다 출전 버튼을 먼저 보여준다.
- 상대 확인 화면에 우리 팀 두 사람과 상대 팀 두 사람을 모두 표시한다. 모바일은 두 팀을 위아래로 배치하고 매칭 후 상대 확인 시작 위치로 스크롤한다.
- 팀 랭킹은 상위 3팀과 우리 팀 강조 행, 전투 기록은 승패별 색과 재생 버튼으로 구성한다. 미완료·취소된 경기는 재생 버튼을 비활성화한다.
- V3 결과창에는 승패 표식, 경기 종료 시 팀 점수와 로비 복귀 버튼을 표시한다. 공통 결과 글꼴이 듀오 결과창 크기를 덮어쓰지 않도록 이 컴포넌트에 한정해 보정한다.
- 모집 전·신청 대기·빈 랭킹·빈 기록을 구별하고 시즌 가이드는 접을 수 있게 한다.

## 자산·성능·기존 계약

- 기존 `assets/ui/ranked/ranked-arena-v1825.webp`(69,090 bytes), `ranked-match-scanner-v1826.webp`(223,372 bytes)를 재사용한다. 스캐너는 상대 확인 화면에서만 사용한다. 외부 UI 라이브러리·신규 의존성은 추가하지 않는다.
- 팀 배너는 닉네임 첫 글자를 사용한 SVG 휘장이다. 실제 보유·편성 캐릭터처럼 보이는 임의 원화를 넣지 않는다. 카드 5장·선택 용병 1장은 편성 규칙으로 표시한다.
- 화면 개편으로 API 호출·폴링·DB 조회를 추가하지 않는다. 기존 요청 복구, 행동력 차감, 팀 평가·매칭과 서버 전투 계산은 유지한다. 신규 성능 벤치마크 대상인 서버 변경은 없다.
- `acceptFight`, `recoverFight` 본문과 기존 PC·모바일 네 사람의 V3 전장/로스터 CSS가 그대로인지 비교했다. 공통 엔진·프레임·전투 아트 어댑터는 변경하지 않는다.
- 진입 모듈과 CSS 캐시 버전을 `20260925-2`로 올리고 메인 앱 캐시를 함께 갱신한다.
- 시즌 생성·공개·모집/대전 개시, 행동력 정책·보상 설정 등 운영 데이터는 이 UI 배포 범위에 포함되지 않는다.

## 시각·동작 검수

`node scripts/serve-ranked-duo-qa.mjs`의 메모리 DB에서 실제 듀오 API와 운영 프런트 모듈을 사용했다. 기본 스타일·운영 공통 메뉴·글꼴을 함께 로드한다. `?scenario=active`, `recruit`, `empty`는 각각 독립된 로컬 DB이며 운영 계정에 연결하지 않는다.

- PC 1280/1440px, 모바일 390×844px: 팀 배너·출전 패널·상대 확인·랭킹·기록의 글자/여백/스크롤 확인. 모바일 문서 가로 폭 375px(스크롤바 제외), 문서 가로 넘침 없음.
- 두 팀 네 명의 이름을 표시하고 긴 닉네임을 좁은 배너·랭킹에서도 확인했다.
- 상대 찾기 → 전투 시작 → 서버 결과 → 팀 점수/개인 행동력 갱신 → 복귀를 PC·모바일에서 확인했다. 기록 재생도 확인했다.
- 모집 신청 → 참가 완료/참가자 수 갱신 → 취소, 모집 중 빈 랭킹, 시즌 미설정 탭 비활성화, 덱 이동 콜백과 가이드 펼침을 확인했다.
- JS 구문 검사, esbuild CSS 구문 검사(경고 없음), `git diff --check`를 확인했다.
