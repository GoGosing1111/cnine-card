# 명함 진열장과 누적 업적 트로피 — 2026-10-11

사용자 요청으로 명함에서 트로피를 4개씩 다음·이전 페이지로 넘겨 볼 수 있다. 기존 6종에 **도시의 무법자**, **서리한**을 추가하여 총 8종을 표시한다. 신규 트로피에는 누적 횟수, 목표와 최초 달성일을 표시한다. 미획득 상태에서도 진행도를 확인한다.

## 확정 조건과 기록

- **도시의 무법자:** 사용자가 확정한 “매 6시간 교대 종료 시 보유 현금 1위”를 누적 25회 달성한다. KST 00·06·12·18시 종료 직전 해당 회차 ON 참가자의 도시 현금과 기존 정책에 따른 미반영 자동 수입을 비교한다. 온라인·오프라인 및 자발적 퇴장 참가자를 포함하고 동률은 공동 1위다. 지급 버튼을 누르지 않은 근무 보상은 가산하지 않는다. TEST와 참여하지 않은 회차는 제외한다.
- TOP 집계 시작점은 기능 배포 후 초기화된 현재 교대다. 삭제된 이전 회차 로그로 과거 우승을 추정하지 않는다. 도시 팝업·행동 영수증은 이전 요청대로 회차 종료에 삭제한다. 영구 자료는 사용자별 누적 수, 최초 달성일, 마지막 정산 회차/금액과 공통 처리 위치뿐이며 회차별 전체 DB 로그를 새로 쌓지 않는다.
- **서리한:** 공식 ON 리치왕 정벌 성공 정산 당시 참가자의 클리어 누적 1,000회다. 주간 보상을 모두 받았거나 재화 지급이 꺼진 성공도 인정한다. TEST·실패·해산은 제외한다. 기존 공식 CLEAR 방의 확정 주간 보상 참가 명단, 과거 정수 지급 참가 명단 또는 남아 있는 실제 참가 명단으로 검증 가능한 기록을 합산한다. 증거가 없는 과거 참여는 임의 복구하지 않는다.
- 두 트로피 모두 최초 달성에 1개를 보유하고 이후에도 누적 횟수는 증가한다. 최초 달성일은 유지한다. 명함 조회와 기존 트로피 수집 칭호가 같은 자료를 읽으며 명함 GET에서 DB를 수정하지 않는다.

## 구현

- `functions/_milestone_trophies.js`: 영구 집계 조회, 과거 리치왕 참여 조회, 기존 클리어 트랜잭션에 추가하는 조건부 집계. 기존 주간 보상 카운터 충돌 재시도 경로를 재사용한다.
- `functions/_jokgak_city_top.js`: 회차당 한 번 우승자 집계. 기존 역할 할당을 `_jokgak_city_roles.js`로 분리하여 종료 회차의 동일 직업과 임금표를 사용한다.
- 정산은 기존 도시 조건부 원자적 배치 안에서 TOP 계산, 전체 퇴장, 만료 기록 삭제와 처리 위치 갱신을 함께 커밋한다. PostgreSQL에서는 회차 마커를 도시 행동과 공유 잠금하고, 정산은 독점 갱신한다. 계획 이후 참가자가 추가되거나 잔액/플레이어가 바뀌면 새 스냅샷으로 재시도한다. 종료된 회차의 늦은 행동과 자동 동기화는 쓰기를 거부한다.
- 별도 DB 테이블·스키마 마이그레이션 없이 기존 `app_meta`, 도시/합동 정산 가드와 배치를 사용한다. 전투 규칙, 재화 보상, 운영 ON/OFF와 공통 인증은 변경하지 않는다.
- `js/player-card-v2052.js`, `css/player-card-milestones-20261011.css`: 4개 단위 진열장, 페이지 버튼/키보드 조작, 원래 트로피 인덱스를 보존하는 상세 선택, 모바일 레이아웃. 메인 로더와 서비스 워커의 캐시 버전을 갱신한다.

## 디자인

내장 ImageGen으로 각 트로피를 별도 제작했다. 도시의 무법자는 왕관을 쓴 금속 주먹, 도시 건물, 끊어진 사슬과 흑요석 받침대를 사용한다. 서리한은 해골과 뿔 모양 가드, 청색 룬 검신을 가진 검을 얼음 받침대에 세운 디자인이다. 투명 배경의 1254×1254 PNG 원본을 보존하고 512×512 WebP를 실화면에 연결한다. 두 프롬프트, 원본 위치, 크기와 SHA-256은 [자산 명세](../assets/ui/player-card/milestones-20261011/manifest.json)에 있다.
