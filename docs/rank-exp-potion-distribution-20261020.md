# 경험치 2배 물약 쿠폰·유저관리 지급

사용자 요청: “경험치물약 2배짜리 쿠폰 발행 만들고 유저관리에서도 지급할수있게 처리해”.

## 적용

- 기존 `RANK_EXP_POTION_2X_60M`(계급 경험치 2배·60분)을 CMS 쿠폰 보상과 유저관리 → 인벤토리 아이템 지급 목록에 추가한다. 기존 전용 물약 이미지를 안내에 사용한다.
- 쿠폰당 지급 수량과 유저관리 1회 지급 수량은 1~9,999개다. 쿠폰 전체 사용 한도는 기존 1~1,000,000회이며 계정당 1회 수령한다. 코드와 수량은 운영자가 입력한다.
- 쿠폰 발급은 기존 `COUPON_MANAGE`/`COUPON_ISSUE`, 유저관리는 기존 `USER_MANAGE` 권한을 따른다. 비 OWNER의 OWNER 계정 수정 제한도 유지한다.
- 수령 시 물약만 인벤토리에 들어간다. 60분 효과는 기존 인벤토리 사용 버튼으로 시작한다. 기존 효과의 시작·연장·교체 정책은 변경하지 않는다.
- 물약 카탈로그가 비활성화되면 발급·신규 지급·신규 수령을 차단한다. 지급 경로에서 카탈로그를 재등록하거나 강제로 활성화하지 않는다.
- 쿠폰 수령은 계정·쿠폰 잠금 아래 인벤토리, 사용 횟수, 로그, 수령 기록을 같은 거래로 저장한다. 유저관리 지급은 기존 공동 거래 영수증과 계정 잠금을 사용한다. 응답 유실 후 재시도에도 1회만 지급한다.
- 새 쿠폰 코드 발급이나 운영 계정 지급은 실행하지 않았다. 3배 물약을 쿠폰에 추가하지 않았다.

## 검수

- `tests/rank-exp-potion-distribution-20261020.test.mjs`: 실제 PostgreSQL 호환 경로로 발급 3개 경로·권한·수량·카탈로그 중지, 쿠폰 마지막 사용 경쟁·중복·응답 유실·원자 취소, 유저관리 영수증·감사 원자성을 검사한다.
- 기존 코인 쿠폰 한도와 장비권 유저관리 지급은 배포 시 관련 회귀에 포함한다. 공통 거래 기반·인증·DB 스키마 변경은 없다.
- `tests/rank-exp-potion-distribution-20261020.browser.mjs`: 실제 CMS HTML·CSS·기본/대체 쿠폰 컨트롤러를 격리 API로 실행한다. PC 1440×1000, 모바일 390×844에서 쿠폰 발급·목록, 물약 이미지, 지급 수량·확인·완료를 확인한다. PC에서는 지급 실패 안내와 동일 요청 ID 재사용도 확인한다.
- 기존 모바일 CMS 사이드바가 유저 목록의 상세 버튼을 가리는 문제가 있어 모바일 계정 상세 진입은 키보드로 확인했다. 열린 지급창의 선택·수량·지급 버튼은 실제 조작했다. 이번 변경에 전체 CMS 배치 개편은 포함하지 않는다.
- 결과와 화면: `docs/qa/rank-exp-potion-distribution-20261020/`. 기술 검수는 새 시각 승인으로 기록하지 않는다.
