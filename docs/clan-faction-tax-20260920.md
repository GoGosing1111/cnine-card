# 세력전 상권 징수세 10억

사용자 요청에 따라 점령지 1곳당 시간당 징수세를 5천만에서
**1,000,000,000 징수코인(10억)**으로 변경한다. 클랜 공동 수익이며
기존 클랜원 균등 분배 및 일반 코인과 분리된 징수코인 지갑을 유지한다.

요청 확인 시각인 **2026-09-20 00:06:32 KST**를 새 요율 경계로 기록한다.
기존 확정 pool/지갑을 재작성하거나 이미 수령한 수익을 소급 지급하지 않는다.
미정산 시간 구간은 9월 17일 이전 100만 → 기존 5천만 → 변경 후 10억의
각 요율을 나눠 계산한다. 종료된 시즌은 종료 시각까지만 적립한다.
밀리초 단위 분자는 BigInt로 계산하며 잔여 소수 코인은 다음 정산으로 넘긴다.

지도 지역 상세, 시간당 총 수입과 징수세 화면은 공용 규칙의 같은 금액을
사용한다. 공용 규칙·세력전 모듈·앱 진입 스크립트 캐시를 함께 갱신한다.

검증: 역사적 요율, 새 요율 경계, 복수 점령지, 재호출 중복 방지,
나눠 정산한 결과와 일괄 정산의 일치, SQLite/PostgreSQL 지급 원자성 및
기존 시즌 분배 회귀. 운영 배포는 전체 출시 게이트를 통과해야 한다.
