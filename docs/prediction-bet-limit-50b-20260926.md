# 승부예측 유저 한도 50억 — 2026-09-26

사용자 지시: 승부예측 유저 베팅 한도를 50억 코인으로 올린다.

## 적용 범위

- 경기별 유저 누적 한도: 2,000,000,000 → 5,000,000,000 코인. 기존 20억 참여자는 같은 선택 항목에 30억을 추가할 수 있다.
- 기존 설정 동기화 경로가 저장된 운영 설정과 DRAFT/OPEN 경기의 `max_bet`를 갱신한다. 별도 DB 구조나 거래 처리 변경은 없다.
- CLOSED/SETTLED/VOID 기록, 기존 베팅·지갑·정산은 보존한다. 최소 10만, 수수료 10%, OWNER 보유액 내 제한 없음 정책은 유지한다.
- 유저 화면·레거시 화면·CMS 고정 안내와 이용 규정(2026-09-26)을 갱신하고, 메인/CMS 로더 캐시 키를 변경한다.
