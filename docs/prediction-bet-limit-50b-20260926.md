# 승부예측 유저 한도 50억 — 2026-09-26

사용자 지시: 승부예측 유저 베팅 한도를 50억 코인으로 올린다.

## 적용 범위

- 경기별 유저 누적 한도: 2,000,000,000 → 5,000,000,000 코인. 기존 20억 참여자는 같은 선택 항목에 30억을 추가할 수 있다.
- 기존 설정 동기화 경로가 저장된 운영 설정과 DRAFT/OPEN 경기의 `max_bet`를 갱신한다. 별도 DB 구조나 거래 처리 변경은 없다.
- CLOSED/SETTLED/VOID 기록, 기존 베팅·지갑·정산은 보존한다. 최소 10만, 수수료 10%, OWNER 보유액 내 제한 없음 정책은 유지한다.
- 유저 화면·레거시 화면·CMS 고정 안내와 이용 규정(2026-09-26)을 갱신하고, 메인/CMS 로더 캐시 키를 변경한다.

## 검수와 배포 범위

- 작은 정책 변경으로 분류한다. 한도 상수·안내·기존 설정 동기화 경로에 한정되며 인증/DB 기반/스키마/의존성을 변경하지 않는다.
- 직전 운영 배포: `e4770786-8758-40d5-a4b0-be3dbfefb8c6`, 커밋 `9d9d58e258e0d537eee10cd7ded743dd1c584dd1` (Wrangler 운영 배포 목록으로 확인).
- 지정 명령: `npm run deploy:production -- --scoped`.
- 선택 검사: `tests/coin-prediction-matchday-v2033.test.mjs`, `tests/coin-prediction-history-v1813.mjs`, `tests/coin-prediction-refund-bigint-v2042.test.mjs`. 서버 변경에 따른 `check:worker`는 배포 도구가 추가한다.
- 새 경계 재현 2건 통과: 20억+30억 누적 허용/초과 거부/동일 요청 재조회, 1회 50억 거래의 실패 롤백/재시도 1회 차감.
- PC 1440px·모바일 390px에서 신규 최대 50억, 기존 20억 참여 시 추가 가능 30억, 1코인 초과 입력 비활성화, 이용 규정과 CMS 50억 표시를 확인했다. 실제 라이브 스타일과 화면 컨테이너를 적용했으며 가로 넘침이 없다.
- 브라우저 검수는 로컬 fixture에서만 수행했다. 운영 베팅은 하지 않았다. 증빙: `%TEMP%/cnine-prediction-50b-20260926/`의 검수 스크립트, 이미지와 `report.json`.
