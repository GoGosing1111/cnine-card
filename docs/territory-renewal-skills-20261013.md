# 영토전 리뉴얼 포스터 · 신규 전술 3종 — 2026-10-13

사용자가 새 영토전 리소스를 활용한 간결한 고급 포스터와 이미지 생성 스킬로 만든 추가 공격/기타 효과 2~3종을 요청했다. 기존 지도·성채를 참조한 포스터와 V6 전술 3종을 추가했다.

## 구현

`preview/territory-renewal-20261013-v1/`에 포스터 원본, 정확한 생성 프롬프트, 검수 페이지와 제작 색인을 보존한다. 효과 원본·투명 아틀라스·프레임별 해시는 `assets/ui/territory-war/renewal-skills-v1/manifest.json`에 연결한다. built-in image_gen으로 각각 생성했다.

- 천뢰 관통포: 선택 거점의 적 최대 HP 6% 피해, 아군 전력 40 소비. 시설 정지 중 차단하고 적 HP 1을 남겨 개인 교전으로 최종 점령한다.
- 동력 교란파: 선택 거점 적 전력 최대 35 감소. 시설 정지 중 차단하며 발사 예약은 취소하지 않는다.
- 성채 재건: 선택 거점 아군 최대 HP 8% 및 전력 20을 실제 부족량 안에서 회복한다. EMP·타 거점·개인 행동력을 변경하지 않는다.

수치는 CMS 조정 가능한 구현 기본값이다. 기존 25명 투표, 스킬별 45분 진영 공통 쿨타임, 지휘관·거점 접근 권한, 회차별 동결 정책을 그대로 사용한다. 구 회차에는 신규 스킬을 표시하거나 적용하지 않는다.

피해/회복·전력·라운드/전선 버전·투표·영수증·쿨타임·이벤트를 기존 검증 거래로 함께 저장한다. 경쟁 요청이나 오래된 거점 상태는 전부 롤백하며 재시도는 기존 영수증을 반환한다. 공격 횟수·개인 기여·보상·계정 재화·대기 명단은 변경하지 않는다. DB 스키마·공통 인증·거래 기반·의존성 변경은 없다.

## 연출

16프레임씩 총 48프레임의 실제 형상 변화를 기존 V3 PixiJS 8.20.0/GSAP 3.13.0에 연결한다. 동일 전장 렌더러·등록된 시계·취소 경로를 사용하고 최초 필요 시에만 자산을 읽는다. 투명 알파를 보존하고 화면 전체 블러·백색 덮개를 추가하지 않는다. 독립 합성 사운드도 추가하지 않는다. 제작 요청과 기술 검수를 사용자 최종 시각 승인 이력으로 기록하지 않는다.

## 검증과 배포 범위

PC 1440×1000, 모바일 390×844의 실제 게임 UI와 CMS를 합성 계정으로 검수했다. 효과 3종·진영별 목표·효과 경계·일시정지/재생/배속/이동/취소·동작 줄이기·지도 복귀·하나의 렌더러와 정리를 확인했다. 브라우저 오류 0건. 검수 경로는 프리뷰 README에 기록한다.

국소적인 영토전 전술 확장으로 scoped 배포를 사용한다. 관련 회귀는 신규 스킬/이펙트, 기존 전장·다중 거점·25명 투표·공성포 이펙트이며 Worker 컴파일과 기존 운영 보호 검사를 포함한다. 운영 영토전 OFF와 미개막 대기 명단은 보존한다. 코드 배포로 새 모집·회차·보상 지급을 실행하지 않는다.

운영 배포 후 실제 커밋·검사 수·파일 해시·OFF 확인 결과를 같은 이름의 배포 JSON에 기록한다.
