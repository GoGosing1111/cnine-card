# 흑백 총기 캐릭터 · AR 연발·중앙 중포대 V3

후속 사용자가 현재 연출에 긍정적 피드백을 주고 주변 아우라를 요청하여 V4를 추가했다. AR/포격 동작·총기·몸 이미지는 유지하고 백은 탄환/탄도 궤적/은빛 지면 파동 12개 원본 프레임을 추가했다. 기존 머리 광륜 아래의 후면 레이어, 고정 발 기준점·크기, 12초의 느린 흐름과 동작 전환 시 연속 시간을 사용한다. 원본/프롬프트는 `assets/sources/ballistic-aura-v4.png`, `prompts/ballistic-aura-v4.json`, 추가 검수/현재 영상은 `qa/aura-v4/`다. 이 추가 아우라의 최종 사용자 시각 승인·운영 연결은 대기다.

2026-10-15 최신 후속 지시: 평타와 스킬 모두 자연스러운 AR 연발, 자주포 중앙 배치, 폭발 범위 확대, 스킬·광역기 재제작. 이전 단발/3발 및 진형 하단 포대 배치는 이전 이력이다.

현재 `preview/mercenary-monochrome-artillery-battle-v1/manifest.json`과 `README.md`를 따른다. 큰 단일 자세의 선명한 얼굴·머리와 필수 백색 광륜을 유지하고, 새로 작화한 팔/어깨 4프레임만 미세 반동으로 사용한다. 승인 총기를 동일 0.68 배율의 단일 강체로 합성하며 전신 포즈 전환과 소총 사격 카메라 흔들림을 제거했다.

평타 9발·스킬 30발, 초당 9발의 지속 사격이다. 해골 낙인은 연사 동안 유지한 뒤 파쇄한다. 광역기는 전장 중앙의 대형 자주포 5회 연속 포격에 AR 엄호 25발을 더한다. 큰 충격파와 적 5명 발 위치의 폭발을 연결하고, 모바일은 큰 폭발을 세 위치로 나눠 세로 늘어짐을 없앴다.

실제 새 몸 작화 4개·고유 효과 작화 56개를 사용한다. 잘린 자주포 원본 프레임은 제외하고 모든 생성 원본·프롬프트·이전 V2 매니페스트/문서를 보존한다. 신규 대시·피격·쓰러짐 제작은 포함하지 않는다.

관련 자산 검사와 PC 1440×1080·모바일 390×844 재생 검수 통과. 몸/광륜 이동·총구 축·타격점 오차 0, 중단·대상 소실·정리·재생 속도 확인, 브라우저 오류 0. 실제 18.65초 시연 두 개를 녹화·디코딩·시각 확인했다. 증빙은 `qa/ar-v3/runtime-report.json`과 `video-inspection.json`이다.
