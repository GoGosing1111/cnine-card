# 금도끼 은도끼 이벤트 · 2026-09-18

소원램프를 종료하고 낡은도끼로 참가하는 기간 한정 이벤트로 교체한다. 금도끼는 당첨 연출이며, 상품 1종을 즉시 지급한다. 금도끼 교환 재화는 만들지 않는다. 꽝에도 설정된 낡은도끼 수량을 소모한다.

## 운영 기준

CMS **설정 → 핑두의 금도끼 은도끼**에서 시작/종료(KST), 참가당 낡은도끼 수량, 계정당 일일 횟수(0=무제한), 상품별 최종 확률과 꽝 확률을 입력한다. 모든 수치·기간의 초기값은 미설정, 공개와 실제 참가 모두 OFF다. H-BODY 3%를 강제하거나 다른 임의 확률을 넣지 않는다. 확률 합계 100%, 하나 이상의 당첨 상품, 유효한 지급 카탈로그가 있어야 ON 저장이 가능하다.

상품은 F-BODY, G-BODY, H-BODY, 500억/1500억/3000억 코인, S용병 랜덤 1장, 슈퍼스타 +13 강화권, 차량부품 150개 선택권, 전직패스권 및 꽝이다. S용병은 현재 운영 CMS의 S등급을 균등 추첨하며 중복도 정식 카드 누적으로 지급한다. 슈퍼스타 강화권은 보유 +0~+12 카드 한 종류를 +13으로 만들며 카드 수량·코인·별을 추가 차감하지 않는다. 부품 선택권은 타이어·프레임·엔진 중 하나를 150개 지급한다. 두 선택 상품은 이벤트가 OFF/종료되어도 인벤토리에서 사용할 수 있다.

낡은도끼는 쿠폰관리의 전용 보상 또는 유저관리 아이템 지급으로 발급한다. 쿠폰 발급은 이벤트를 자동 ON으로 바꾸지 않는다. 보상 버튼을 다시 눌러 수령하는 단계는 없다.

## 처리와 복구

차감·상품·원장·영수증은 동일 PostgreSQL 트랜잭션이다. 사용자 행 및 요청 ID 잠금, 현재 설정/카탈로그 확인, KST 일일 상한, 만료 재검증, 지급 행수 검증을 수행한다. 실패는 전부 롤백한다. 재시도는 동일 요청 영수증을 반환하며 이벤트 OFF 후에도 이미 확정된 결과를 복구할 수 있다. 화면 이탈 전 미완료 요청을 저장하고, 결과 화면을 확인한 뒤 제거한다.

일반 용병 카드와 강화권의 기존 회계/원화 계약을 재사용한다. V3 전투 코드·번들·SD·버전은 이 이벤트에서 변경하지 않았다. 공용 네비게이션만 새 이벤트로 교체하고 관련 URL·셸 캐시를 갱신한다.
