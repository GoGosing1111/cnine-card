# 핑두의 배민권 쿠폰 — 2026-10-09

사용자 `핑두의 배민권 왜 쿠폰발급없음`에 따라 유저관리 직접 지급만 제공하던 배민권에 쿠폰 발급·등록 수령을 연결했다.

- CMS **쿠폰관리 → 보상 종류 → 핑두의 배민권 · 철구네 치킨**에서 코드·지급 수량·전체 사용 한도를 설정한다. 선택 시 수량 1개로 시작하며 기존 참가권 쿠폰과 동일하게 1~100,000개, 전체 사용 1~1,000,000회, 계정당 1회를 적용한다.
- **설정 → 철구네 치킨 → 배민권 쿠폰 만들기**가 발급 화면을 열고 배민권을 선택한다. 기본 목록과 다중 선택 목록 모두 배민권 이름·수량을 표시한다. 모바일 설정 화면에서는 메뉴가 버튼을 가리지 않도록 메뉴 높이를 제한했다.
- 기존 `COUPON_MANAGE`/`COUPON_ISSUE` 권한을 사용한다. 미라클 큐브의 OWNER 핑크빛유두 전용 권한과 코인 한도는 유지한다. `SLD-` 접두어는 숲켓랜드 예약 상태를 유지한다.
- 유저 등록은 실제 치킨 주문에서 소모하는 `PINGDU_BAEMIN_TICKET` 인벤토리와 미확인 수량을 적립한다. 활성 계정·쿠폰·아이템을 확인하고 계정 및 쿠폰 행을 잠근 뒤 인벤토리·전체 사용량·로그·영수증을 한 거래로 처리한다. 같은 요청 재시도는 영수증을 재사용하며 다른 요청의 중복 수령은 거부한다.
- 이미 준비된 배민권 카탈로그만 조회한다. HTTP 호출로 이벤트 테이블·카탈로그·보상·기간·ON 설정을 초기화하거나 재생성하지 않는다. 쿠폰 발급 자체는 유저 지급이나 치킨 주문을 실행하지 않는다.
