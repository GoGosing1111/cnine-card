# PVP 속도형·중복 방어형 개편 — 2026-09-30

사용자의 `속도형 고유효과 개편 작업 시작하고 배포해 유저 공지용까지 작성`, 후속 `방어형 2장의 적폐도 하향시켜라` 지시에 따른 운영 반영이다. 이전 준비 전용 지시를 이 범위에서 대체한다. 새 카드·용병·스킬 자산 출시나 마법 시즌 2 활성화는 포함하지 않는다.

## 구현

- `shared/pvp-speed-reform-v1.mjs`: PVP 일반 SPEED 카드 시작 게이지 60, 고유 속도 증가분 억제 30%, 기본 2타·1/4/7 기본 공격 3타, 추가타 계수 0.5. PVE와 용병·몬스터·슈트는 제외한다.
- `functions/_battle_v2_preview.js`: 기존 PVP +50%/+15% 직접 배율과 확률 게이지 +35를 연타로 교체한다. 본타 회피는 주기를 소비하되 추가타를 만들지 않는다. 전체 연타를 한 행동으로 계산하며 보호·방벽·마법·용병 행동·게이지 감소·처치 추격을 타수마다 호출하지 않는다. 기존 추격 +70/3회와 힐러 우선은 보존한다.
- 전체 연타의 기본 피해 상한은 기존 기본 공격 상한의 80%다. 일반 대상·전직 없는 경우 최대 HP의 48%이며, 기존 방벽 추가 피해·용병 방벽을 포함한 상한 풀·전직 보정은 기존 경로를 따른다. 연장전의 기존 강제 피해는 증폭하지 않는다. 이는 모든 방벽·용병 효과까지 포함한 최종 피해가 무조건 HP 48%라는 뜻은 아니다.
- PVP 방어형 팀 방벽 기여 곡선 `1/.6/.35/.2/.12` → `1/.25/.15/.10/.05`. 두 번째 카드 기여는 약 58.3% 감소한다. 동일 HP 2장 팀 방벽 총량은 21.875% 감소한다. 개인 방벽·반격·방어 능력 및 방어형 1장 자체 효과는 보존한다.
- 살아 있는 일반 방어형 2장 이상일 때만 속도 증가분을 억제한다. 시작 게이지를 보존하고 사망·부활 후 억제 여부를 갱신한다. 음수 고유 속도나 용병은 억제 계산에서 제외한다.
- 실제 서버 HP·방벽 손실을 타격별 스냅샷으로 분배한다. 렌더러는 이를 재생하며 피해를 재계산하지 않는다. 1HP 처치 때도 이미 계산된 방벽 손실을 보존한다.

## 연출과 연결

기존 `BattleEngine.js`의 PixiJS 효과 계층과 GSAP 타임라인, 승인 SPEED 아틀라스를 재사용한다. 새 정지 그림이나 스킬 원화를 만들지 않았다. 잠금 버전은 PixiJS 8.20.0 / GSAP 3.13.0이다. 충돌 시각은 기본 250/370/490ms이며 기존 배속 시계를 따른다. 타격별 HP·방벽·실제 피해 숫자와 누적 합계를 표시한다. 연타 숫자는 전장 안으로 보정하고 종료·취소 시 추가 효과를 회수한다.

라이브 엔진 버전은 `20260930-speed-combo`다. 공용 소스의 소비 번들 10종, 메인 로더, 래퍼와 셸 캐시를 함께 갱신한다. 공용 번들 재생성은 해당 소비자의 신규 기능 활성화를 뜻하지 않는다.

## 비교 결과와 한계

`tools/balance-harness-v1903/speed-reform-20260930.mjs`와 `reports/speed-reform-son-cr7-20260930.json`에 재현 조건과 결과를 보관한다. 개편 전 기준은 `aef4d6ab`다.

운영에서 읽은 손흥민·CR7 고유효과를 사용하고, 같은 나머지 4장·장비·용병에서 양쪽 진영을 교환했다. SUPERSTAR 전투력은 CMS 기본 7,000을 그대로 쓰지 않고 실제 `max(FUR,ZENITH)+10,000` 규칙을 적용했다. +13 고유효과 배율은 FUR 2.0, ZENITH/SUPERSTAR 1.6이다. SUPERSTAR 전직은 가정하지 않았다. 용병은 2026-09-21 읽기 전용 fixture 기준이다.

3개 투자 조건 × 용병 없음/SS 베스페라/SSS 오메가-X/SSS 라그니엘 = 12개 통제 시나리오. 각 시나리오 512판, 개편 전후 각각 6,144판을 비교했다. 손흥민 쪽 승률의 동일 가중 평균은 약 **23.7% → 64.1%**다. 시나리오별 개편 후 승률은 **1.0~96.7%**로 차이가 크다. 기본 카드+베스페라 조건과 일부 라그니엘·고강화 조건에서는 CR7이 우세하다.

이는 통제 덱 실험이며 실제 전체 계정 승률·채용률·용병 미보유 진입 장벽 자료가 아니다. 이전 검토의 55~60% 목표를 모든 조합에서 달성했다고 주장하지 않는다. 유저 공지에 승률 보장이나 손흥민의 무조건 우위 표현을 넣지 않는다.
