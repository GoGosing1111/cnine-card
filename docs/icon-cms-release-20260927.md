## 저장·성능

- `/api/admin/icons` GET/PATCH에 기존 BATTLE_MANAGE 권한 검증과 OWNER 역할 검증을 적용한다. 비권한·잘못된 요청은 문서 조회 전에 거부한다. 응답은 private/no-store.
- 기존 app_meta의 단일 키 `icon_cms_v1`에만 저장한다. 새 테이블·DDL·공통 DB·인증 기반 변경 없음. 최초 미등록 시 INSERT ON CONFLICT DO NOTHING, 이후 설정과 사용자 메모를 보존한다.
- 정상 GET: 인덱스 조회 1회. 최초 등록 GET: 조회/조건부 삽입/조회 3회. 정상 PATCH: 조회 1회 + 원자적 CAS 갱신 1회. 경합 때만 최신 읽기 1회 추가한다. 자동 재시도·폴링·전체 사용자 스캔 없음.
- 요청 본문 32KiB, 카드 7개, 메모 카드당 1,200자, 최근 영수증 50개로 제한한다. 문서·수정자·시간·영수증을 같은 갱신으로 확정한다. 이전 버전은 409, 같은 요청/같은 내용 재시도는 기존 저장 결과, 같은 ID/다른 내용은 409다. 영수증 보존 범위 밖 재시도도 이전 버전 검사로 재저장하지 않는다.
- 격리 PostgreSQL에서 준비된 GET 20회 = 20개 SQL, 합계 15.6ms. 운영 인증·네트워크를 제외한 로컬 측정값이며 운영 지연으로 일반화하지 않는다.
- CMS 메뉴를 열기 전 API/이미지 조회 없음. 캐릭터 선택은 추가 DB 조회 없음. 효과는 검수판을 열 때만 로드하며 재생 중 전용 아틀라스 1개, 캔버스 1개를 유지한다. 검수판 닫기·메뉴 이탈·권한 해제 때 iframe을 제거한다.
