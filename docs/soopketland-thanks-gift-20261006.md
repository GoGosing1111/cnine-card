# 숲켓랜드 마별 100만 · 핑두의 감사 선물 1% — 2026-10-06

사용자 요청: `숲켓랜드 마별 100만까지 늘리고 1%확률로 핑두의 감사선물 넣어`.

| 보상 | 수량 | 반영 확률 |
| --- | --- | --- |
| 코인 | 1억~500억 | 42% |
| 엠퍼러 에너지 | 1~5개 | 5% |
| 마스터의 별 | 1,000~1,000,000개, 1,000개 단위 | 42% |
| 미스틱 에너지 | 1~1,000개 | 10% |
| 핑두의 감사 선물 | 미개봉 상자 1개 | 1% |

기존 코인·마별 42.5%에서 각각 0.5%p를 배분했다. 수량은 기존 방식대로 구간 내 균등 추첨한다. 이용권 추첨은 공유용 쿠폰을 발급하고, 쿠폰을 수령하면 감사선물 상자 1개가 인벤토리로 지급된다. 상자를 자동 개봉하거나 기존 구성품 수량을 변경하지 않는다.
