# 군단토벌 용병 장비 — 2026-10-11

사용자 요청은 군단토벌 장비의 화려한 원화 개편과 용병 장착 전환이다. 후속 확정에 따라 용병 개별 장비가 아니라 계정의 PVE/PVP 두 구성을 저장한다. 용병 교체로 장비가 풀리지 않으며 같은 보유 인스턴스를 두 모드에 선택할 수 있다.

## 구현

- 신규 5지역 세트 25종, 고유 5종의 원화를 개별 제작했다. 해안의 흑금·청록, 사막의 백금·호박, 대극장의 벨벳·도자기, 거수의 녹색 갑각, 천공의 은백·푸른 번개를 사용한다. 30개 원본 PNG를 보존하고 512px 투명 WebP로 적용했다. 런타임 합계 2,406,258바이트다. 거수 도끼 최초 이미지의 잘린 끝부분은 별도 편집 후 전체 실루엣으로 교체했다. 작살총은 총몸부터 총구까지 일직선 축을 확인했다.
- `mercenary-codex/equipment/`의 용병 무장고에 원화와 5부위 슬롯, PVE/PVP 전환, 지역별 보관함, 도감, 장착 상세와 효과를 배치했다. 메인 용병 편성과 용병도감에서 이동한다.
- `mercenary_equipment_v1:<계정>:<모드>`에 revision과 실물 인스턴스 ID를 저장한다. 기존 계정 잠금/원자적 영수증/CAS를 사용하며 소유자·부위·출시 상태를 거래 안에서도 검증한다. 재시도는 같은 영수증으로 복구하며 다른 창의 변경을 덮어쓰지 않는다.
- 강화·연마 상태는 실제 장비에 유지한다. 같은 장비의 PVE/PVP 사용은 허용하고 강화창에서도 장착 중으로 인식한다. 파괴·소유권 상실·비활성 장비는 전투에서 제외한다.
- 장비 전투력은 해당 모드 용병에게만 가산한다. 세트·고유·연마 효과는 PVE 전용이며 일반 카드와 일반 장비 집계에 이중 가산하지 않는다. 아군 평균 능력치에 연계되는 강한 덱에서도 장비 능력치가 사라지지 않도록 추가분을 반영한다. 기존 용병 행동력/스킬/상대별 정책은 유지한다.
- 장비 목록은 30개 카탈로그별 최신 인스턴스와 성장 인스턴스만 조회한다. 운영의 대량 인벤토리를 전체 스캔하지 않는다. 스키마 마이그레이션은 없다.

## 보존한 운영 조건

운영 사전 확인: 카탈로그 30종, 활성/공개/공급 0종, 보유자·일반 장착 0건. 지역 정책 TEST/지정 참여자 없음, 연마 OFF다. 이번 작업은 이 조건이나 장비 수치·공급 확률을 변경하지 않는다. 기존 소유 장비 이관과 실제 계정 지급은 필요하지 않았다.

`scripts/ops/legion-mercenary-art-20261011.mjs`는 이미지 URL·설명만 갱신하고 이름·부위·수치·출시/공급·지역·연마 설정이 동일한지 거래 안에서 확인한다. 30건 dry-run은 통과했으며 운영 적용 영수증은 배포 후 같은 이름 JSON에 기록한다.
