# 조직 세력전 자율참여 공격대 — 2026-10-22

사용자 요청: 공격대 약 2개를 원로 편성 없이 조직원이 직접 가입해 공격하는 자율참여 공격대로 분리하고 완료 후 유저 공지를 작성한다.

- 기존 공격대 5개 중 제4·제5 공격대가 자율참여 대상이다. 제1~제3 일반 공격대와 방어대 5개, 각 3명 정원은 유지한다. 기존 편성 인원·행동대장·원로는 초기화하지 않는다.
- 현재 소속 조직의 활성 계정은 본인만 가입·이동·탈퇴한다. 다른 부대에서 가입하면 본인만 이동하며 마지막 방어대원이 나가면 해당 주둔은 해제한다. 행동대장 임명은 가입·공격의 전제조건이 아니며 기존 직책 권한은 유지한다.
- 자율 공격대는 가입한 조직원만 출정한다. 1명으로도 가능하며 나머지 대원은 기존 입장 알림/전투실을 이용한다. 본인 또는 출발/도착 부대가 교전 중이면 편성을 변경하지 않는다. 다른 부대의 교전 때문에 비전투 중인 자율 공격대까지 닫지는 않는다.
- 편성 저장은 자율참여 인원을 변경할 수 없다. 낡은 원로/행동대장 화면도 기존 가입 인원을 덮어쓰지 못한다. 가입 인원이 바뀌면 편성 화면의 기존 8초 조회를 사용해 갱신하며 편집 중에는 갱신하지 않는다.
- 기존 조직 거래/행 잠금/영수증을 재사용한다. 가입 대상 userId/organizationId를 요청으로 받지 않고 인증 계정의 현재 소속에서 결정한다. 마지막 한 자리 동시 가입, 재시도, 저장 실패 시 롤백을 검증했다. 새 스키마·DB 초기화·외부 메시지 발송은 없다.
- 점령 보호 20분, 부대 재출정 10분, 같은 지역 재공격 15분, 개인 재교전 1분을 유지하며 가입/탈퇴로 대기를 초기화하지 않는다. 가입 자체는 회차 참여 실적이 아니며 실제 출정/전투 입장과 기존 8곳 점령 보상 기준을 유지한다.

## UI와 이미지

조직에 사용자가 이미 승인한 command-20261021의 남색 은장 패널/초록 버튼을 9-slice로 사용한다. 새 타 콘텐츠 이미지를 도입하거나 승인 자산을 수정하지 않았다. 자율참여 2개를 편성 화면 맨 위에 분리하고 지도에서도 가입·탈퇴할 수 있다. 일반 조직원에게는 불필요한 전체 편성 편집 도구를 표시하지 않는다. 기능/시각 자체 검수는 사용자의 신규 시각 승인을 뜻하지 않는다.
