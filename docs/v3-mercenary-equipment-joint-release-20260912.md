# V3 개편·용병·장비 강화 공동 출시

2026-09-12 사용자 지시: **`v3개편하고 용병출시,이거 다 동시에 올릴거임 기록해놔`**. 여기서 장비 기능은 같은 대화에서 최종 승인된 장비 강화 V2·장비보호권·파괴 기록 복구를 뜻한다.

## 고정 출시 규칙

- 2026-09-12 후속 `용병관련 전체 항목 CMS 등록 라이브로 배포해`에 따라 **용병 CMS 등록/편집 기능은 먼저 운영 배포**한다. 실제 획득·편성·전투는 아래 공동 출시 기준을 유지한다. 구현 계약은 `docs/project-v-mercenary-cms-live-20260912.md`다.

- **V3 개편 + 용병 출시 + 장비 강화·보호·복구를 같은 운영 업데이트 회차에 함께 공개·활성화한다.** 하나만 먼저 출시하거나 신규 기능을 단독으로 ON으로 바꾸지 않는다.
- 이 지시는 공동 출시 일정·범위 기록이며 지금 즉시 배포하라는 지시가 아니다. 각 기능의 로컬 구현·검수·범위 커밋은 계속 진행한다.
- UI·연출 승인과 운영 정책·경제·실제 계정 연결 완료를 구분한다. 세 범위가 모두 준비되기 전에는 준비 중인 개편/신규 기능을 활성화하지 않는다.
- 무한의탑은 V3 개편의 공동 출시 준비 안에서 관리한다. 2026-09-09의 재기획 대기·제외 기록은 과거 상태이며 2026-09-11 구현 검수판이 추가됐다. 탑을 별도 먼저 출시하지 않는다. 이번 기록으로 탑 보상 수치나 시각 검수를 자동 승인하지 않는다.
- 용병은 기존 일반 덱 5장과 별도 최대 1슬롯을 유지한다. 등급·사용자 스킬 배정·개별 이펙트·획득·편성·전투 연결 조건을 이번 일정 지시로 확정하지 않는다.
- 장비 강화 V2 UI·연출 최종 승인은 유지한다. 성공률 10% 하한·성공/유지/파괴 3종·보호권 게임 내 극희귀 획득·상자 제외도 유지한다. 운영 확률·비용·전투력·보호/복구 세부 정책은 미정이다.
- 실제 출시 시 세 범위의 DB 마이그레이션·기능 플래그·캐시·공지·롤백 계획을 한 회차로 검수한다. 깨끗한 최신 main 기준에서 `npm run release:gate` 통과 후 `npm run deploy:production`만 사용한다. 다른 콘텐츠의 별도 출시 조건은 임의로 해제하지 않는다.

## 2026-09-12 후속 선공개 승인

- `용병관련 전체 항목 CMS 등록 라이브로 배포해`: 용병 CMS와 초안 DB를 운영에 등록했다. 획득·편성·전투는 OFF다. 기준은 `docs/project-v-mercenary-cms-live-20260912.md`다.
- `장비강화 라이브 배포,유저공개만 해놓고 강화는 ON되야 가능하게`, `방어구도 되야한다`: 승인 V2 기반 장비 강화 센터와 OWNER CMS를 선공개한다. 대상은 무기·상의·하의·신발·장신구이며 실제 보유 장비만 읽는다. 강화·파괴·보호·복구 실행은 OFF를 유지한다.
- 이 선공개는 공동 게임플레이 활성화를 승인한 것이 아니다. 운영 정책·실행 서버·전투력 연결 검수가 끝나기 전에는 CMS ON 저장과 직접 API 실행을 모두 거부한다. 장비 선공개 계약은 `docs/equipment-forge-public-v2084.md`다.
