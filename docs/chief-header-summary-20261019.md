# 장군 배너 상단 이동 · 2026-10-19

사용자 `장군 배너좀 다른곳에 둘 좋은방법 없냐? 줄이던가 다른곳에 두는거 어떤지 검토해봐`에 상단 계급 오른쪽의 작은 정보 버튼과 모바일 재화 아래 한 줄을 제안했고, 후속 `시작해`로 구현했다.

로비 일러스트 위의 큰 집권 배너를 공통 헤더로 옮겼다. PC에서는 개인 계급 오른쪽에 높이 54px, 980px 이하에서는 재화 아래 높이 44px로 배치한다. 기존 금색 휘장, `현 장군 · 닉네임`, 대수와 남은 임기를 표시한다. 좁은 화면에서는 대수와 반복되는 집권 접두사를 생략하고 전체 정보는 버튼의 접근성 이름과 상세 창에서 제공한다. 긴 닉네임은 한 줄 말줄임이며 툴팁과 접근성 이름에는 원문을 유지한다.

큰 테두리·광택·신규 집권 배지를 없애고 기존 상단 글꼴·색·간격을 따른다. 2026-10-18 기존 디자인 우선 지시에 따라 기존 휘장 이미지를 재사용하며 별도 장식 이미지를 만들지 않는다. 장군/여왕 상태, 직무정지·파면·공석·연결 대기 표시와 상세/집권식 연결, 개인 아바타 선택은 유지한다. 모바일 BGM 조작은 일러스트 오른쪽 위에 남겨 헤더와 분리했다. 서버 임기·권한·운영 설정·계정 데이터는 수정하지 않는다.

원본은 `preview/lobby-clarity-v1/index.html`, `style.css`, `ui/adventure-lobby/component.js`이며 공식 빌더로 `js/adventure-lobby-v2107.js`를 재생성했다. 메인/세계관 로더에 `chiefHeader=20261019-v1`을 추가했다. 기존 서비스워커의 로비 번들 network-first 정책을 유지한다. 공통 헤더 높이는 기존 ResizeObserver로 반영한다.
