# 엠퍼러 상위 장비 재제작과 시안 보관 — 2026-10-08

## 최종 채택 — V5 4종과 공통 프레임

사용자 **`채택`**에 따라 공개 프리뷰의 갑옷·바지·신발·듀얼디스크 4종과 각 PNG에 포함된 공통 사각 프레임을 최종 시각 승인본으로 고정했다. 단일 기준은 `preview/mythic-emperor-successor-v1/approval-20261008.json`이며 원본 4장의 SHA-256, 원본 제작 커밋, 승인 범위와 보존 정책을 기록한다. 별도 분리 프레임 파일은 이번 제작물에 포함되지 않았다.

백금·금세공·청록빛 보석·에메랄드 비단의 현재 형태와 색을 유지한다. 원본을 재생성·재압축·수정하지 않으며 이전 시안 10장도 보관한다. 아래의 검수 대기 표현은 제작 당시 이력이며, 최신 시각 승인 상태는 `VISUAL_APPROVED`다. 정식 세트명·능력치·제작식·CMS 등록·획득·보상 연결은 아직 확정하지 않았다.

이번 후속 작업은 승인 기록·매니페스트·고정 컨텍스트만 갱신한다. 내용/diff 확인과 범위 커밋·원격 반영으로 종료하며 이미지 재검수·게임 테스트·운영 재배포를 반복하지 않는다.

## 최신 요청

사용자 `엠퍼러 상위 장비 리소스 제작 다시, 화려하게 판타지느낌으로 하던가 현대 제복을 만들던가 해라.`를 적용했다. 선택한 방향은 **화려한 판타지 황제 장비**다. 이전 SF 우선 요구를 현재 디자인 기준으로 사용하지 않는다. 갑옷·바지·신발·듀얼디스크 네 부위, 엠퍼러 상위의 위상과 장식된 사각 프레임은 유지한다.

직전 `이 색감`으로 지정한 첨부의 짙은 청록·에메랄드 섬광을 보석과 배경 광원에 적용한다. 색상 선택을 완성된 장비의 시각 승인으로 확대하지 않는다.

## V5 새 디자인

- 입체적인 백금 장갑, 화려한 금세공, 커다란 청록 보석과 에메랄드색 비단을 사용한다.
- 갑옷은 날개형 견갑·중앙 보석·곡선 장식, 바지는 연결된 허리와 양쪽 다리, 신발은 좌우 한 쌍, 듀얼디스크는 전완 장착부에 연결된 두 원형 장식으로 구분한다.
- 네 변의 프레임에는 금색·백금 레일, 조각 모서리, 청록 보석, 상단 문장과 하단 결합부를 배치한다.
- 첫 갑옷을 나머지 세 부위의 프레임·재질·색 기준으로 입력한다. 기존 엠퍼러 이미지는 품질·위상 비교 기준이며 수정하지 않는다.
- 원본·프롬프트·해시는 `preview/mythic-emperor-successor-v1/`에 보존한다. 도구는 내장 `image_gen.imagegen`이며 출력 PNG를 재압축·재색칠하지 않는다.

## 범위와 검수

최초 제작 범위는 두 장비 프리뷰 폴더와 이 문서다. **게임 장비 등록·능력치·제작식·획득·보상 풀은 변경하지 않는다.** 블랙미라클 자동 편입도 수행하지 않는다. 후속 `채택`으로 완성 원본 4종과 공통 프레임의 시각 승인은 완료됐으며 정식 세트명은 아직 미정이다.

자산 원본 해시·규격·참조 경로와 갤러리 PC/모바일의 표시·확대·닫기·다운로드를 확인한다. 게임 코드와 API 변경이 없으므로 무관한 게임 테스트를 실행하지 않고 지정 `npm run deploy:production -- --assets-only` 경로를 사용한다.
