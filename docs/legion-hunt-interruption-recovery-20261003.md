# 군단토벌 중단 횟수 복구·종료 보상 정산

사용자 요청: 모바일 강제 종료로 횟수만 차감되는 문제를 보정한다. 정상 종료·패배에서는 획득한 아이템을 지급하고 결과가 확정되지 않은 중단에서는 횟수를 복구한다.

## 적용 동작

- 새 원정은 전투 시작 시 입장 1회를 예약 차감한다. 필드에서 누른 아이템은 서버의 해당 원정 가방에 저장하고, 클리어·전멸·시간 초과·사용자가 누른 **철수 정산**에서 보관함에 지급한다. 바닥에 남았거나 소멸한 아이템을 새로 지급하지 않는다.
- 종료 요청은 검증된 결과와 가방을 먼저 영구 저장한다. 그 다음 보상 지급·지급 증명·정산 완료 표시를 기존 원자 배치에서 함께 반영한다. 지급 실패 시 종료 기록과 가방은 남고 부분 지급은 롤백된다.
- 종료 요청의 응답 유실은 같은 원정으로 재시도한다. 입장 화면 복귀·재접속에서도 미완료 지급을 먼저 정산한다. 정산 대기 중에는 새 원정이 기록을 덮어쓰거나 횟수를 환급하지 않는다.
- 서버에 종료 결과가 없는 원정은 입장 화면 재진입·취소·다음 출전 때 종료하고 예약 차감 1회를 한 번만 되돌린다. 해당 미정산 가방은 지급하지 않는다. 미시작·OWNER 무제한 원정·확정 결과는 횟수를 환급하지 않는다.
- 한국시간 날짜별 사용 기록을 보존한다. 전날 원정의 복구로 오늘의 정상 사용 횟수를 줄이거나 일일 기본 2회를 늘리지 않는다.
- 배포 전 버전의 진행/취소/만료 원정도 남아 있는 최근 세션과 시작 시각으로 보정한다. 이미 즉시 지급된 기존 보상은 회수하지 않으며 정상 종료 시 중복 지급하지 않는다. 과거 세션이 덮어쓰여 근거가 없는 차감은 추정 복구하지 않는다.
- 신규 시작 계약은 version 4다. 구버전의 신규 입장만 새로고침으로 유도하고 기존 원정 종료·복구는 유지한다. CMS 확률·수량·운영 모드, 하루 2회·OWNER 무제한, 공용 전투 엔진은 변경하지 않는다.
- 입장 화면에 복구 완료/정산 안내, 획득 알림에 `종료 후 지급`, 결과에 지급 완료 안내를 표시한다. 운영 CMS 설명도 같은 정책으로 맞춘다.

## 검증 및 배포 범위

- 실제 PostgreSQL 호환 계층/PGlite 및 SQLite에서 신규 복구 회귀 10개 통과. 횟수 복구 응답 유실·중복 호출, 완결 결과 4종, 정산 실패·TTL 경과·취소·다음 입장, OFF 모드 복구, 날짜 경계, 구버전 기지급 보상을 확인했다.
- 보상/모드 기존 회귀를 새 정산 정책으로 갱신: 서버 9개 및 별도 탐색 회귀 1개 통과. 인벤토리·카드·장비·차량, 부분 지급/지급 증명/CAS 충돌 롤백, 설정 변경 경쟁, TEST→ON 보상 승격 차단, 오래된 드랍 설정 유지 검증.
- 입장 컨트롤러 관련 변경 회귀 4개 통과. 나머지 계정 편성·CMS·드랍 배치·종료 시계 회귀는 최종 scoped 배포에서 실행한다. 이미 통과한 무관한 게임 검사를 반복하지 않는다.
- 로컬 운영 핸들러와 격리 DB로 PC 1440×1000·모바일 390×844 각각 실제 로비 → 전투 → 아이템 클릭 → 지급 전 0개 → 정산 응답 강제 유실 → 재시도로 1개 지급 → 복귀 → 두 번째 전투 강제 새로고침 → 입장 1회 복구를 검증했다. 재복구에서 추가 환급 없음, 확정 보상 유지, 콘솔 오류/가로 넘침 없음. 스크린샷으로 복구·결과 화면 확인.
- 브라우저 증거: `C:/Users/User/.codex/tmp/legion-hunt-recovery-20261003/ui-qa.json` 및 `pc-*.png`, `mobile-*.png`. 운영 계정 재화는 검증에 사용하지 않았다.
- 직전 운영 커밋: `d04826b7bdd3da5e9d1ce68d4fe8a87e887b5da2`, Pages `23b9f296-c541-460c-b0e5-fe40ecb9df02`(Wrangler 운영 목록 확인).
- 군단토벌 단일 콘텐츠의 정산·복구 경로 변경이다. 기존 사용자 잠금·CAS·원자 배치를 재사용하며 공통 인증/DB 기반/마이그레이션/의존성/전투 규칙 변경이 없으므로 `npm run deploy:production -- --scoped`를 사용한다.

## 유저 안내 문안

군단토벌 중단 보정 및 보상 정산 방식이 개선되었습니다.

- 클리어·패배·시간 초과·철수 정산 시 직접 획득한 아이템을 지급합니다.
- 튕김·접속 종료로 결과가 확정되지 않았다면 군단토벌 입장 화면에 다시 들어올 때 사용한 입장 1회가 복구됩니다.
- 결과는 확정됐지만 지급 응답이 끊긴 경우에는 재접속 후 보상을 다시 확인해 정산합니다. 같은 보상이나 횟수가 중복 처리되지 않습니다.
- 업데이트 후 게임을 새로고침해 주세요.
