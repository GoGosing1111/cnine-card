# 듀오 참가 오류·콘텐츠 현황 표시 — 2026-09-25

사용자 요청: 콘텐츠 현황판에 듀오 모집중을 표시하고, 시즌 참가 신청에서 발생한 `DUO_PROFILE_SIZE` 오류를 수정한다.

- 재현: 동일 장비 70,000개와 추가 장비 1개를 보유한 계정에서 기존 65,537행 조회가 처리 한도를 넘겨 신청을 거부했다. 수량 제한 상향이나 임의 절삭 대신 읽는 자료를 바꿨다.
- 운영 PostgreSQL에서는 이미 준비된 `user_equipment_counts_v1`로 중복 보유를 확인한다. 강화 상태를 먼저 추려 실제 인스턴스를 PK로 연결하고, 착용 장비는 전용 편성에서 읽는다. 강화 단계별 요약으로 잠재 전력을 계산하되 모두 강화된 품목에 미보유 기본 장비 전력을 더하지 않는다. SQLite·집계 준비 전에는 DB에서 동일 전력을 묶는다.
- 기존 슬롯별 최고 전력·착용 전력·강화 배율과 변경 계정만 갱신하는 캐시·버전 검증을 유지한다. 보유량·편성·행동력·보상·시즌 일정과 DB 스키마를 변경하지 않는다.
- 현황판은 현재 시즌 포인터와 시즌의 공개 상태를 한 번 읽어 `랭크 듀오 / 모집중 / 모집 마감`을 표시한다. 현황판 첫 항목을 누르면 기존 듀오 화면으로 이동한다. 대전 중에는 대전중·종료 시각을 표시하고, 숨김·종료·기한이 지난 상태는 제외한다.
- 기존 서버 15초 캐시·화면 30초 갱신을 유지한다. 현황 조회에서 참가자·전체 인벤토리·전력 계산·시즌 진행을 실행하지 않는다. 듀오 조회 실패는 다른 콘텐츠 표시를 막지 않는다.
