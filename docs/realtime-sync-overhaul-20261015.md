# 계정·PVP·격전지 동기화 및 이미지 전달 개편

사용자 요청: 전체 동기화를 한 회차에 개편하고 압축 가능한 큰 이미지를 함께 경량화한다. 기존 운영 점검은 사용자가 관리한다. 경제·보상·승패·출시 설정과 1계정 1클라이언트 정책은 유지한다.

## 구현 기준

- 계정별 변경 버전은 실제 보유/재화/편성 변경과 같은 PostgreSQL 거래에 기록한다. 소켓은 변경 버전만 전달하고 상세 정보는 기존 인증 API로 읽는다. 롤백·영수증 재시도로 새 보상을 만들지 않는다.
- 접속 계정의 버전 행만 제한적으로 확인하며 전체 보유 목록 폴링·공유 전역 집계 행을 추가하지 않는다. 재접속·탭 복귀·오래된 응답·알림 누락에 대한 복구를 제공한다.
- PVP는 서버 확정 결과를 보존하고 중단된 요청/연출을 복구한다. 격전지는 기존 WebSocket에 왕복시간 측정, 단조 증가 시각, 오래된 패킷 차단, 밀린 동작 정리와 재연결을 보강한다.
- 원본 및 승인 해시는 보존한다. 서비스에서 읽는 큰 이미지의 경량 파생본을 만들며 원본 크기·투명도·아틀라스 좌표를 유지한다. 더 작아지지 않는 파일과 애니메이션/확정 원본은 보수적으로 분류한다.
- 공통 데이터 변경·통신·전투가 함께 바뀌는 큰 작업이다. 관련 회귀·PC/모바일 확인 후 전체 release gate가 포함된 지정 배포를 한 번 수행한다. 운영 점검을 자동 해제하지 않는다.

## 적용한 동작

- `account_sync_versions_v1`와 29개 테이블의 statement trigger 87개를 추가했다. 같은 문장의 다중 행 변경은 계정별 한 번으로 합치고, 시간 갱신만 있는 UPDATE와 무변경 UPDATE는 무시한다. 실제 자산 변경과 버전 기록은 같은 거래다. `app_meta`는 계정별 용병/PET 보유·편성 키만 추적한다.
- 새 AccountSync Durable Object는 인증 API가 발급한 15초·1회용 티켓으로 접속한다. 로그인 토큰이나 계정 상세 정보는 소켓 URL/메시지에 넣지 않는다. 계정당 최대 4개 연결, 60초 인증 갱신, 활성 접속 계정에 한한 5초 버전 행 확인을 사용한다. 일반 변경은 요청 완료 시 즉시 알리고, CMS/직접 운영 변경 및 누락된 알림은 주기 확인으로 보완한다.
- 클라이언트는 변경 영역만 갱신하고 오래된 응답과 이전 로그인 응답을 버린다. 숨긴 화면에서는 알림 연결을 쉬고 복귀 시 최신 상태를 확인한다. 전투 중에는 메인 화면 재구성을 미룬다. 재화·보유·인벤토리·편성·행동력·메시지 배지를 연결했다.
- PVP는 요청 ID와 매칭권을 계정별 sessionStorage에 보존한다. 응답 유실·로그인 만료·서버 잠금 뒤에는 같은 영수증으로 재확인한다. 새 매칭보다 ‘미확인 경기 결과 확인’을 우선한다. 서버가 미성립/만료를 확정한 경우만 해제한다. 기존 점수·차감·보상 원자성과 재시도 처리 코드는 유지한다.
- 격전지는 단조 시각과 낮은 RTT 표본으로 재생 시각을 보정한다. 중복/오래된 패킷을 무시하고, 12초 무응답 연결을 다시 맺으며 15초 전황 단절 시 재생을 일시 정지한다. 배우별 실행 1개+최신 대기 1개, 한 프레임 최대 6개 그룹으로 밀린 연출을 정리한다. ping 응답은 보낸 사람에게만 반환하며 실제 상태 전환은 전원에게 보낸다. 서버 승패·HP·기믹·보상 및 새로고침 이탈 판정은 유지한다.

## 이미지 전송

- 256KiB 이상 파일을 조사해 운영 이미지 1,482개를 변환 후보로 삼았다. 8% 이상 절감되고 크기·RGBA·애니메이션 프레임/지연/반복이 보존된 1,282개 URL을 1,245개 WebP 파생 파일에 연결했다.
- 해당 이미지 합계 **2,238,268,820 → 1,444,950,238바이트**, **793,318,582바이트(756.6MiB), 35.4% 절감**이다. 한 화면의 다운로드나 FPS 개선율을 뜻하지 않는다. 원본 파일과 승인 해시는 변경하지 않았다.
- DOM·전투 로더·서비스워커가 공통 색인을 사용한다. 내용 해시 파일은 재사용하고, 압축본 실패 시 원본으로 돌아간다. API·관리자 요청은 이미지 캐시에서 제외한다. `?original=1`은 원본 조회용이다.
- 전체 해시/픽셀 검수는 `docs/image-delivery-20261015/manifest.json`에 있다. 브라우저 검수에서 불투명 RGB와 알파는 일치했고, 반투명 경계는 PNG/WebP의 premultiply/unpremultiply 반올림 때문에 8bit 합성값 기준 최대 2 미만 차이가 있었다. 크기·프레임 좌표 변화는 없다.
- Cloudflare Pages의 실제 계정 한도는 20,000개 파일이다. 압축본과 다른 채팅의 신규 프리뷰를 함께 보존하기 위해 지정 배포 도구가 임시 배포 디렉터리를 만든다. `tests/**/*.test.[cm]js`, `tests/**/*.browser.mjs` 실행 파일만 배포에서 제외한다. 테스트는 Git/출시 검사에 남고, 프리뷰가 사용하는 fixture/helper 및 원본 자산은 유지한다. 원격 커밋은 실제 원본 HEAD로 지정한다.
