# 중단된 동일 런타임 배포 검사 재개 — 2026-09-29

- 클랜전 보상 배포 준비 중 origin/main의 선행 랭크전 수정 배포가 미완료인 것을 확인했다. 직전 운영은 8e24a55, 후보는 75116c03이다.
- 기존 전체 게이트는 앞선 실패 수정 뒤 지원된 재개 경로로 진행되다가 test:workshop 도중 프로세스가 중단됐다. 해당 채팅의 실행 결과는 1073807364이며 이후 실행 중인 배포 프로세스는 없다.
- 원본 로그/해시는 보존하고 이미 성공한 전체 단계 출력만 연결한다. 마지막 workshop은 완료로 간주하지 않고 처음부터 재실행하며 이후 모든 단계와 출시·Hyperdrive 보호를 유지한다.
- 기존 재개 도구는 실패 요약만 지원했다. 명시적 `RELEASE_GATE_RESUME_INTERRUPTED=1`과 20자 이상 사유가 있고 마지막 단계 요약이 없을 때만 중단 재개를 허용한다.
- 런타임/공통 헬퍼/의존성/게이트 명령 변경 차단, 원본 SHA·로그 해시 검증, clean tree와 origin/main 일치 요구는 유지한다. 성공 요약이 있는 마지막 단계에는 중단 플래그로 재개할 수 없다.
- 클랜전 보상 코드는 별도 브랜치에 보존했다. 선행 런타임과 재개 도구만 먼저 배포하고, 그 실제 운영 SHA를 기준으로 클랜전 기능을 scoped 배포한다.
