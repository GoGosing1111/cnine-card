# 간호사 용병 회복 너프 — 2026-10-05

사용자 요청: 간호사 회복으로 격전지 전체 클리어가 가능하다는 제보를 확인하고 너프한다.

## 확인 결과

- 운영 CMS revision 60에서 디임간호사·희야 간호사·조은 간호사·봉순 간호사는 MS-051 `백의의 맹세` 하나를 공유했다. 총 공격력 320% 회복, 재사용 4턴, 자원 25였다.
- 전체 생존 아군에게 총 회복량을 균등 분배하므로, 사망으로 생존자 수가 줄면 남은 대상의 회복량이 커진다. 격전지 3분대에 간호사 3명을 편성할 수 있어 각각의 회복이 누적된다.
- 운영 격전지 설정 revision 4와 서버 전투 엔진으로 비교했다. 조합·장비에 관계없이 모두 클리어된다는 주장은 재현되지 않았다. 최고 난이도도 장비가 높은 조합에서는 회복을 제거해도 이길 수 있었다.
- 과도한 생존자 집중 회복은 재현됐다. 고정 조건 576회 비교의 변경 전 대상별 최대 회복은 최대 체력의 73.41%였다. 실제 이용자 승률을 조사한 결과는 아니다.

## 변경

| 항목 | 이전 | 변경 |
|---|---:|---:|
| 총 회복 예산 | 공격력 320% | 공격력 160% |
| 재사용 | 용병 행동 4턴 | 용병 행동 6턴 |
| 대상별 1회 상한 | 남은 체력까지 | 대상 최대 체력의 15% |
| 자원 소모 | 25 | 25 |

15% 상한을 먼저 적용하고 회복 억제·저주·아이콘 효과를 적용한다. 초과 회복과 남은 분배량은 버리며 다른 대상에게 재분배하지 않는다. 생존 일반 카드와 용병만 회복하며 부활·보호막을 추가하지 않는다. 같은 스킬을 쓰는 PVE/PVP에 동일하게 적용한다.

새 전투 스냅샷에 `nurseHealing` 정책을 저장한다. 이미 시작된 격전지는 저장된 기존 규칙을 유지해 QTE·탈퇴로 재계산하더라도 과거 체력과 전투 기록이 바뀌지 않는다. 운영 CMS는 MS-051의 balance와 effect만 트랜잭션으로 변경한다. 획득 확률·가중치·원화·등급·보스 설정·보상·출시 플래그는 변경하지 않는다.

## 비교 조건과 결과

`tests/helpers/cooperative-fixture.mjs`의 BALANCED 일반 카드 조합, 3개 난이도, 분대별 장비 보너스 100만·500만·2천만, 간호사 1명(V-049/V-055/V-051) 또는 3명(V-051/V-052/V-053), 동일한 16개 시드 `7919*n`으로 전후 576회 비교했다. 저장한 운영 combat 설정과 전체 결과는 `nurse-heal-nerf-20261005-results.json`에 있다. QTE 추가 효과를 제외한 공통 서버 전투 비교이며 플레이어 집단 승률로 해석하지 않는다.

| 간호사 3명 조건 | 이전 평균 총 회복 | 변경 평균 총 회복 | 감소 |
|---|---:|---:|---:|
| HARD / 장비 500만 | 15,888,637 | 6,844,327 | 56.9% |
| EXTREME / 장비 500만 | 35,091,416 | 14,277,628 | 59.3% |
| EXTREME / 장비 2천만 | 85,549,707 | 24,600,361 | 71.2% |

변경 후 모든 회복 이벤트가 대상 최대 체력의 15% 이내였다. 전투 행동·대상 선택 순서도 달라지므로 모든 고정 시드에서 승률이 단조 감소하지는 않는다. 고장 난 클리어 판정을 보스 강화로 보정하지 않고 확인된 회복량을 제한한다.
