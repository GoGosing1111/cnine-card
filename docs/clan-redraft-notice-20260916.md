# [클랜 시즌 2 전체 재지명 안내]

클랜별 인원 불균형을 해소하기 위해 **9월 16일(수) 오후 7시부터 전체 재지명**을 진행합니다.

- **진행 시간:** 9월 16일 19:00~20:00
- **진행 방식:** 기존 클랜장이 PICK 1부터 블라인드 드래프트로 다시 지명합니다.
- **참가 대상:** 기존 신청자와 추가 반영된 참가자를 포함한 총 157명
- **별도 신청 불필요:** 기존 참가 신청은 자동 유지됩니다. 재참가 버튼을 누르거나 다시 신청하지 않으셔도 됩니다.
- **인원 균형:** 클랜별 최종 인원을 19~20명으로 맞춥니다.
- **지명 제한:** 각 차례는 30초이며, 미지명 시 다음 클랜으로 넘어갑니다. 20:00까지 남은 참가자는 미충원 정원에 자동 편성됩니다.

기존 일반 멤버 편성은 초기화되므로 재지명 완료 후 소속 클랜을 확인해 주세요. 클랜장 여러분은 오후 7시에 맞춰 접속해 주시기 바랍니다.

첫 정규 클랜전은 기존 일정대로 **9월 17일(목) 21:00**에 시작합니다.

이용에 혼선을 드려 죄송합니다. 균형 있는 클랜전이 진행되도록 하겠습니다.
