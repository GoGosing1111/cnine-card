# 군단토벌 보스 출현과 0초 종료 — 2026-09-28

사용자 보고: 보스가 나타나지 않은 상태로 전투가 계속되다가 시간 초과. 후속 확정: **보스전까지 포함하여 총 15분, 마지막 구간 보스 출현, 0초 종료**.

## 원인과 수정

- 운영 세션 읽기 전용 확인에서 시작 약 891초 후에도 화면의 확인 이벤트는 약 494초에 머문 사례가 있었다. 서버는 보스와 정상 결과를 생성했지만, 공용 GSAP 시계와 애니메이션 의존 대기열의 진행 차이가 누적돼 보스·종료 이벤트가 뒤에 묶였다.
- 총 제한을 900초로 고정하고 기존 보스 시간 150/150/135/120초를 그 안에 포함한다. 보스 출현은 보통·어려움 750초, 악몽 765초, 지옥 780초다. 화면은 15:00부터 한 번만 감소하며 0초 뒤 별도 보스 타이머를 시작하지 않는다.
- 서버는 보스 출현 직후, 첫 공격 전 아군·용병·보스 HP와 보호막 스냅샷을 복사한다. 군단토벌 전용 `HuntTimedPlayback.js`는 기존 PixiJS 8.20.0/GSAP 3.13.0 V3 재생기를 사용하면서 경계를 애니메이션 대기보다 먼저 처리한다.
- 경계에서 이전 연출을 취소하고 세대 번호를 갱신한 뒤 서버 상태를 적용한다. 이전 비동기 공격이 새 보스에게 도착하지 않는다. 확인되지 않은 과거 이벤트는 순서대로 한 번씩 기존 KO 드랍 처리에 전달한다. 자동 보상·추가 지급이나 HP 초기화는 없다. 보스 전환으로 기존 필드 드랍을 지우지 않는다.
- 900초에는 서버 최종 상태로 맞추고 전투·사격·효과·렌더 루프를 정지한다. 결과는 서버의 CLEAR/DEFEAT/TIME_LIMIT 판정을 보존하고 직접 획득한 아이템만 기존 정산 API에서 집계한다. 정산 재시도는 같은 영수증을 반환한다.
- 일시정지 시 전투 시계도 멈춘다. 1배속, 하루 입장 횟수, CMS 모드와 드랍 설정·거래 로직은 유지한다. 구버전 시작 요청(version 2)은 새로고침 안내로 차단하고 현행 클라이언트는 version 3을 사용한다. 이미 시작된 구버전 원정은 저장된 서버 계약을 보존한다.
