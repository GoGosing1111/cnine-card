# 엠퍼러·동방 장비 강화 마스터의 별 비용

- 대상 코드: `EMPEROR_TOP`, `EMPEROR_BOTTOM`, `EMPEROR_SHOES`, `EMPEROR_DUAL_DISK`, `EQ_1788486929132`(동방 금룡 돌격소총), `EQ_1788486888336`(동방 금룡 대물저격총).
- 모든 강화 단계에서 기존 단계별 마스터의 별 수량의 **2배**를 견적에 확정한다. 코인, 성공·유지·파괴 확률, 보호권 및 복구 비용은 변경하지 않는다.
- 서버 견적의 수량을 화면·잔액 검사·원자적 차감·영수증에 공통 사용한다. 배포 전 낮은 비용으로 발급된 견적은 강화 시작 전에 만료 처리하여 새 견적을 받게 한다. 이미 시작된 거래의 재시도는 최초 거래 계획을 유지한다.
