# 족각도시 이동 대기시간 표시 — 2026-10-12

## 요청과 변경

사용자 건의: 기존 `행동 확인 / 이동 대기시간을 확인하세요.` 안내에서 실제 남은 이동 대기시간을 알 수 있도록 표시한다.

- 선택한 장소의 이동 버튼과 바로 아래 안내에 서버 `nextMoveAt` 기준 남은 초를 표시한다. 대기 중에는 이동 요청을 막고, 시간이 끝나면 버튼을 자동 활성화한다.
- 서버에서 이동 대기로 거절한 경우 실제 남은 초와 종료 시각·서버 시각을 반환한다. 안내 팝업도 초 단위로 갱신하며, 완료되면 `대기 완료`를 표시한다.
- 기존 서버 시각 보정과 1초 UI 타이머를 재사용한다. 대기 표시 때문에 추가 API 폴링이나 전체 화면 재렌더링을 하지 않는다.
- 현재 장소·사망·휴식·구금·진료 필요·요청 처리 중의 이동 제한을 유지한다. CMS 이동 대기 설정, 회차·TEST/ON, 경제·거래 정책은 변경하지 않는다.
- 도시 스크립트·CSS 로더 및 앱/서비스워커 캐시 버전을 갱신한다.

## 관련 검수

- PC 1440×1000 및 모바일 390×844 실제 도시 화면 확인 완료. 남은 초, 이동 잠금/자동 해제, 팝업 카운트다운, 만료 후 이동, 가로 넘침 없음, 브라우저 오류 없음.
- 기기 시각이 서버보다 2분 빠른 상황에서도 서버 기준으로 표시됨을 확인했다. 다른 세션에서 서버의 이동 대기가 연장된 상황도 실제 API 거절 응답으로 확인했다.
- 브라우저 검수: `tests/jokgak-city-move-countdown-20261012.browser.mjs`. 결과·화면은 작업 트리 외부 `../city-qa/`에 보관한다. 운영 계정 대신 격리된 도시 DB fixture를 사용했다.
- 서버 관련 회귀: `tests/jokgak-city-move-countdown-20261012.test.mjs`. SQLite/Postgres 경로에서 실제 API 오류의 남은 초·시각, 거절 시 위치/영수증 불변, 종료 1ms 전 차단, 종료 시각 이동, 동일 영수증 재시도를 검사한다. 배포 경량 게이트에서 실행한다.
- `node --check js/jokgak-city-v1.js` 및 `git diff --check` 통과. 배포 게이트에 `check:worker`를 포함한다.
