# CMS 영토전 선택팀 강제종료 충돌 수정 — 2026-09-30

## 재현과 원인

- 운영 62회차의 `FINISH` 요청이 22:50:43~22:50:46 KST에 `territory_war_mutation_guards_ok_check` 오류로 실패했다. 같은 구간에 교전 3건(629888~629890)이 완료됐다.
- 강제종료는 개인 보상 준비 후 회차 종료·승리 클랜 승점·완료 영수증을 처리한다. 이 사이 공격이 회차 `version`을 올리면 종료 UPDATE가 0행이 되어 원자성 검증이 실패했다. 운영 조회에서 해당 회차는 미종료, 승점 영수증 없음, 준비된 개인 보상 수령 0건을 확인했다.
- PostgreSQL과 SQLite에서 종료 직전 전투 피해·버전을 갱신해 같은 검증 오류를 재현했다.

## 수정 범위

- 관리자 인증과 승리팀 검증을 마친 CMS 강제종료 경로에서만 `adminJudgment`를 서버 내부 인자로 전달한다. 선택한 승리팀은 공격 결과로 재계산하지 않으므로 전투 버전 변경만으로 종료를 거부하지 않는다.
- 종료 가능한 회차 상태, 미정산 여부, 시즌, 4개 승리 클랜과 시즌 승점 행, 완료 영수증 중복 검증을 유지한다. 회차 종료·4클랜 각 2점·영수증은 기존 단일 트랜잭션 그대로다.
- 자동 승패 판정의 버전 검증, 개인 보상 계산과 미수령 보상 UPSERT, 관리자 작업 키, 공통 DB·인증·스키마는 변경하지 않는다.
- 운영 데이터는 읽기 전용으로 조사했다. 복구 과정에서 별도 회차 종료나 승점 수동 지급을 실행하지 않는다.
