# 용병 합성 관리 CMS 연결 — 2026-09-25

## 요청과 운영 경로

- 사용자 후속 지시 `합성관리 어디서하노` → `연결해`에 따라 CMS의 누락된 합성 관리 탭을 연결한다.
- 경로: **CMS → 용병 관리 → 합성 관리**, 직접 주소 `https://cnine-card.pages.dev/admin/#mercenaries/fusion`.
- 기존 OWNER CMS 접근 권한과 서버 저장 API를 사용한다. 실제 합성 개방은 이 지시의 범위에 포함하지 않는다.

## 관리 기능

- 공개 feature API에서 실제 소모·지급 상태와 확정 정책을 조회한다. 현재 합성은 OFF다. 같은 등급 중복 8장, 기본 보유 보존, 승급 10%, 동일 등급 결과 90%, 추가 비용 0, 결과 1장, SSS 재료 제외를 표시한다.
- C→B부터 SS→SSS까지 결과 등급과 저장된 용병 후보 수를 보여 준다. 저장하지 않은 용병 등급 초안으로 운영 확률을 계산하지 않는다.
- 용병별 추첨 가중치는 기존 `admin/mercenaries/draw`의 공용 설정·리비전·감사 이력·요청 ID를 재사용한다. 합성 화면에서 가중치를 저장할 수 있으며 하이퍼팩에도 적용된다는 안내를 표시한다. 등급 내 선택 비율과 각 재료 등급의 합성 1회당 획득 확률을 구분한다.
- 개봉 확률 탭과 동일한 편집 상태를 공유해 서로 다른 가중치 초안을 덮어쓰지 않는다. 개봉 확률·수량·메모의 미저장 변경이 있으면 합성 화면의 저장을 막고 해당 탭에서 먼저 정리하도록 안내한다.
- 합성 시연 링크, 상태 재조회, 가중치 재조회, 저장 결과 재확인, 최근 공용 설정 이력을 제공한다. 성공 확률·재료 수·비용은 승인된 고정 정책이다. 합성 ON/OFF를 바꾸는 가짜 스위치는 추가하지 않는다.
- 초기 CMS 조회 실패에도 재시도 버튼이 보인다. feature 조회는 12초 이내 종료하며 실패를 OFF로 위장하지 않는다. 권한 변경 시 편집 상태와 늦게 도착한 응답을 초기화한다.

## 관련 검수와 배포 범위

- 실제 직전 운영 배포: Wrangler 목록의 `7186c6af-bec9-49c1-a12c-c0cc721e11e8`, 소스 `995138629634b08110e9c7f8a31f8d48c41e1dfd`.
- 변경은 기존 용병 CMS의 신규 탭, 공유 가중치 편집 화면, 해시 경로, 캐시 참조에 제한된다. 서버·거래 코어·DB·인증·의존성·게임 합성 동작 변경이 없다. `npm run deploy:production -- --scoped`로 배포한다.
- 구현 검수 `tests/mercenary-fusion-admin-20260925.browser.mjs` 통과: 실제 Chrome 1440×1000 / 390×844, 버전이 붙은 CMS 진입 모듈 및 운영 스타일, 격리 PostgreSQL과 실제 CMS 핸들러를 사용했다. 운영 설정에는 시험 저장하지 않았다.
- 직접 링크, OWNER 메뉴, 49개 용병 가중치, 5개 등급 전이, 저장·동일 요청 재확인(리비전 1회 증가), 기존 확률·수량·메모 보존, 탭 간 반영, 숨겨진 초안 저장 차단, 미저장 등급 제외, 해시 이동, 권한 초기화 통과.
- 초기 CMS 503, feature 응답 정체·잘못된 응답을 주입한 후 재시도 복구 확인. feature 오류 검사에서는 12초 기한만 0.5초로 줄였다. PC·모바일 가로 잘림과 페이지 오류 없음. 화면·보고서: 배포 루트 밖 `../qa-mercenary-fusion-cms/`.
- 위 최종 UI 검수는 배포 과정에서 중복 실행하지 않는다. 범위 게이트는 `tests/mercenary-draw-cms-v1.test.mjs`, `tests/mercenary-fusion-eight.test.mjs`로 기존 공용 저장의 권한·리비전·감사·원자성·재시도와 합성 OFF·확정 경제 정책을 확인한다. 서버 파일 변경이 없어 별도 Worker 컴파일 사전 검사는 추가하지 않는다.
- 기존 clean/main, 출시 플래그, 캐시, Hyperdrive 캐시 OFF·바인딩 검사는 지정 배포 명령으로 유지한다.
