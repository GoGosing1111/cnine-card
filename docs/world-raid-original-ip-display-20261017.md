## 원인과 수정

- API 표시 변환의 레이드 객체 목록에 `availableBosses`가 빠져 있었다. 현재 방이 없는 실제 `raid/status` 응답의 개방 선택지를 기존 승인 원화·SD·이름 대응표로 변환한다.
- 실제 앱 요일표 설명을 고정 문자열에서 표시 중인 보스 이름의 중복 제거 목록으로 변경했다. 현재 오르제·렌조·제노이며 이름 변경도 같은 응답을 따른다.
- 주간 레이드 CMS의 잘못된 로테이션 안내도 현재 세 이름으로 표시한다. 저장된 보스 코드·ID·과거 방·영수증은 수정하지 않는다.
- `index.html` 앱 쿼리와 `service-worker.js` shell 태그를 `20261017-world-raid-original-ip-v1`로 맞췄다.
- 기존 승인 보스 이미지와 실제 이미지 최적화 파생 파일을 연결한다. 새 원화 생성·UI 재설계·전투/보상/입장 비용·참여 횟수·운영 설정 변경은 없다.
