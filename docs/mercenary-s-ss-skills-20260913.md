## 자산·재생 원칙

신규 9종과 청아 재제작 1종은 각각 내장 ImageGen으로 별도 생성한 실제 16프레임 연속 시트다. 요청 해상도와 반환 해상도를 구분한다. 채택 원본은 네 열·네 행 1254×1254 RGBA이며, 원본 격자를 그대로 잘라 최대 1px의 투명 여백으로 314px 셀을 맞춘다. 업스케일·키잉·합성 중간 프레임을 만들지 않는다. 원본 PNG 바이트, 프롬프트, 개별 프레임과 무손실 WebP 아틀라스 해시는 `skill-assets-v2/generation-inputs.json` 및 `manifest.json`에 남긴다.

프레임 경계를 침범한 홍성 파쇄탄·청룡 탄착 첫 시안은 반려 후 재생성했다. 반려 원본은 작업 QA 폴더와 생성 원본 폴더에 보존한다. 기존 녹색 탄착의 원본·아틀라스·프레임은 변경하지 않으며 `archive-ms005-emerald-v2.json`으로 이전 해시를 보존한다.

PixiJS **8.20.0**, GSAP **3.13.0**. 별도 Application·Ticker·GSAP 사본은 없다. 기존 `MercenarySkillFX.js` → `RenderAuthoredSkill.js` → `RenderSSkill.js`와 `MercenarySpriteSequence.js`를 사용한다. 주 재질은 실제 프레임을 읽고, 궤적·파편·먼지·지면광은 같은 V3 시간축의 보조 계층이다. 서버의 피해·대상·승패를 연출이 다시 계산하지 않는다.

기본 접촉은 05프레임(인덱스 4)과 스킬 `visual.impacts`를 맞춘다. 엘로디는 05·09프레임을 0.85·1.80초에 맞추고 첫 서버 이벤트만으로 미래 봉인 파열을 미리 보여 주지 않는다. 발·총구·무기·몸통은 승인 SD 해시에 연결된 `mercenary-attachment-points-v1.json` 좌표를 사용한다. 원화와 SD를 교체하거나 같은 이미지 필드로 합치지 않는다.

사운드는 기존 라이선스 녹음 9종의 원본 MP3를 보존하고 예고·충돌·잔향의 구간·이득·시점을 스킬별로 설정한다. `skill-audio-v1.json`에 원음 ID·출처·라이선스·해시·측정 피크가 있다. 오실레이터나 절차적 노이즈를 생성하지 않는다. 충돌 피크는 공용 Web Audio 출력 시계로 정렬하고 배속·일시정지·취소에서 음원을 정리한다.

## 전투·CMS 계약

`functions/_mercenary_combat.js`가 아홉 고유 mechanic을 처리한다. 추가 타격으로 에너지·재귀 발동을 만들지 않는다. 보호막 전용 파쇄의 잔여 예산, 사망한 표적의 화살 몫, 이전 표적의 흡수 기록은 다른 HP·대상에게 이전하지 않는다. 공격 스킬 감쇠는 기본 공격에 소모하지 않는다.

신규 피해 배율·재사용 턴·비용은 기존 CMS와 같이 미정(`null`), 검수 상태는 `PENDING`이다. 기존 공통 전투 정책의 방호·집중·지속·약화 상한을 참조하며 오프라인 100 HP 예시를 운영값으로 저장하지 않는다. 이번 제작·배정으로 공동 출시 게이트나 개봉 상태를 켜지 않는다.

카탈로그 1 → 2 읽기 확장은 기존 17종의 완전한 문서만 허용한다. 이름·수치·메모·검수 상태·등급·기존 연결을 모두 보존하고 신규 9종만 추가한다. 카탈로그 읽기로 용병을 자동 배정하지 않는다. 별도 `prepareSSkillAssignments`를 사용한 명시적 운영 작업만 S·SS에 연결한다. 수정 번호 비교, 원본 해시, 트랜잭션, 요청 ID와 감사 기록으로 중복·경합을 막는다.
