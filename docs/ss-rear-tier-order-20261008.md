# SS 후열과 SSS의 PVE 등급 역전 축소 — 2026-10-08

이 문서는 **간호사 회복 상한만 조정한 미배포 중간안의 검증 이력**이다. 사용자 후속 “제대로 너프해라 아니면 후열 용병부터 공격받게 하던가”에 따라 SS 후열 원거리 11종과 간호사 4종의 우선 피격을 추가했다. 실제 최종 정책·검사·배포 기록은 ss-rear-priority-balance-20261008.md를 따른다. 아래 V2 표기는 개발 중간안이며 운영에 별도로 배포되지 않았다.

사용자 후속 기준은 “SS 후열이 SSS보다 유리한 역전을 줄이기”다. 직전 하향은 7c3233060f5d424a6b68998c8e62747132b04713에 운영 반영됐다. 그 이후에도 군단토벌 장기전에서 일반 SS 간호사의 회복이 누적되어 일반 SSS보다 높은 클리어율이 남았다.

## 최종 조정

- 새 전투 정책 V2에서 간호사 4종의 대상별 1회 PVE 회복 상한을 최대 체력 10%에서 **1%**로 낮춘다. 회복 예산은 공격력 120%, 재사용 6 용병 행동, 비용 25를 유지한다.
- SS 후열 원거리 11종과 간호사의 아군 일반 카드 2회당 추가 행동 1회는 직전 하향을 유지한다. 이번 후속 변경은 원거리 11종의 전투 결과를 추가로 바꾸지 않는다.
- PVP는 기존 행동 주기와 공격력 160% 예산·15% 상한을 유지한다. SS 전열·S/SSS·SS 리미티드·발테르와 출시 잠금은 그대로다.
- 정책 V1이 저장된 전투는 120% 예산·10% 상한을 유지한다. 정책이 없는 과거 전투도 기존 로직을 사용한다. 진행 중인 전투 재현에 새 수치를 소급하지 않는다.
- CMS 원본 배율을 수정하지 않고 서버 정책과 도감 설명을 같은 모듈에서 산출한다. 회복 억제는 상한 뒤에 적용하며, 사망자 부활·초과 회복 재분배는 하지 않는다.

회복 예산만 줄이고 상한을 5%로 둔 탐색안은 장기전 클리어율을 낮추지 못했다. 1% 상한에서는 40~120% 예산의 결과가 같아 상한이 결정적이라는 점을 확인했다. 따라서 예산은 직전 120%로 보존하고 상한만 조정했다. 회복을 제거한 비교는 원인 분리를 위한 오프라인 실험이며 실제 회복 기능은 유지한다.

## 독립 난수 비교

운영 CMS 61의 비식별 고정 자료와 실제 서버 전투 엔진을 사용했다. 아포칼립스 보스 4종, 탑 50·70·90·100층, 군단토벌 4난도 전체 15분을 비교했다. 각 콘텐츠별 장비 3구간, 동일 FUR/ZENITH 덱의 HP2·HP0 편성, 용병 레벨 1, 슈트·마법 없음으로 고정했다. 난수는 탐색 2001~2008과 분리한 **3001~3008**을 사용했다. 간호사 4종의 전투 성능이 동일하므로 V-051을 대표로 계산하고 일반 SSS 4종과 비교했다.

조정 전후 각각 2,880회, 총 **5,760회**다. 같은 편성·장비·난수에서 용병만 바꿨다. SSS 결과는 조정 전후 완전히 같았다.

| 콘텐츠 | SS 간호사 V1 | SS 간호사 V2 | SSS 4종 평균 |
| --- | ---: | ---: | ---: |
| 아포칼립스 | 113/192 (58.85%) | 107/192 (55.73%) | 516/768 (67.19%) |
| 무한의탑 | 144/192 (75.00%) | 144/192 (75.00%) | 755/768 (98.31%) |
| 군단토벌 | 170/192 (88.54%) | 141/192 (73.44%) | 542/768 (70.57%) |

군단토벌에서 **간호사는 클리어하고 같은 조건의 SSS는 실패한 비교**가 144/768 (18.75%)에서 **58/768 (7.55%)**로 줄었다. 역전 사례가 약 59.7% 줄었고 간호사와 SSS 평균의 클리어율 차이는 +17.97%p에서 +2.86%p로 축소됐다. 반대 사례인 SSS만 클리어는 6/768에서 36/768로 늘었다. 아포칼립스·탑의 동일 비교에서는 간호사만 클리어한 사례가 전후 모두 없었다.

군단토벌 SSS 개별 클리어는 오메가-X 121/192, 라그니엘 123/192, 크라이베른 122/192, 베르칸 176/192다. 조정 후에도 앞의 세 용병과 비교한 간호사 우위 사례는 각각 21·18·19건 남는다. 베르칸과의 비교에서는 0건이다. 평균만으로 모든 SSS가 간호사보다 강하다고 주장하지 않는다. 이 수치는 선택한 조건의 통제 시뮬레이션이며 실유저 승률, 모든 장비·슈트·편성의 결과, SS 클리어 불가능을 뜻하지 않는다.

원자료와 탐색 결과는 같은 이름 JSON에 보존한다. 재현 스크립트는 scripts/measure-ss-rear-tier-order-20261008.mjs이며, 아래 명령은 저장소 밖 캐시에 기준 결과를 저장한다.


## 검증과 배포 범위

도감 PC 1440×1000·모바일 390×844에서 120% 예산·1% 상한·PVP 160%·15% 안내와 가로 잘림 없음을 확인했다. 런타임 변경은 shared/mercenary-ss-rear-pve-v1.mjs 한 파일이며 전투 렌더러 변경은 없다.

최초 비교의 운영 기준은 **7c3233060f5d424a6b68998c8e62747132b04713**다. 배포 준비 중 먼저 합쳐진 군단토벌 지역 확장 변경을 통합한 e875f1ba에서도 전후 5,760회 결과가 모두 같음을 다시 확인했다. 실제 후속 배포의 직전 운영 기준은 배포 영수증에 기록한다.
