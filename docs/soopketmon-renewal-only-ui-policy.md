# 숲켓몬 리뉴얼 UI 단일 기준

- 운영·프리뷰·로그인·로딩·점검·오프라인·오류 화면은 V21 대규모 리뉴얼 UI만 사용한다.
- 구형 웹사이트형 셸과 폐기된 `preview/soopketmon-mobile-v1` UI는 fallback으로도 노출하지 않는다.
- 신규 셸이 준비되기 전에는 기존 앱 DOM을 숨기고 `V21 COMMAND INTERFACE` 연결 화면을 표시한다.
- 네트워크 단절 시에도 전용 차콜/시안 오프라인 화면을 사용한다.
- 기존 기능 DOM은 데이터·이벤트 계약을 위해 내부적으로 유지할 수 있지만, 사용자에게 보이는 표면은 리뉴얼 컴포넌트로 감싼다.
- 배포 전 `v21-ui-ready` 가드, 최신 오프라인 페이지, 갱신된 서비스워커 캐시 키를 함께 검증한다.
