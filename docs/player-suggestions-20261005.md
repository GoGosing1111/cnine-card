## 보스별 추가 보상

CMS 전투 관리의 아포칼립스 몬스터마다 `보스 처치 추가 보상`에 코인 추가율, 마스터의 별, 미스틱 에너지 입력칸을 제공한다. 저장 키는 `battle_apocalypse_settings_v1.monsterProfiles.<monsterId>.clearBonus`다.

- 기본값은 세 필드 모두 `null`(미설정)이다. 사용자 수량 지정 전에는 추가 지급하지 않는다. 0은 명시적인 지급 없음이다.
- 코인은 해당 전투의 기존 최종 코인 보상에 지정 비율을 추가하며, 두 아이템은 지정 개수를 추가한다. 승리 시 지급하며 회피 연습 성공 여부로 수량을 변경하지 않는다.
- 기존 CMS 탭이 새 필드를 누락하고 저장하더라도 저장된 보스별 보상은 유지한다.
- 새 추가 보상은 서버 전투 스냅샷의 승패·수량을 사용한다. `app_meta`의 전투별 영수증과 기존 원자성 가드를 사용하고, 수량·로그·완료 상태를 한 배치로 확정한다. 중복 확인, CAS 경합, 아이템 비활성화·로그 오류 시 중복·부분 지급을 막는다.
- 연결 중단 시 같은 전투의 추가 보상 확인을 24시간 내 재개한다. 재확인에는 새로운 전투 요청이나 행동력 차감이 없다. 기존 기본 전투 전체의 정산 구조를 변경하는 작업은 아니다.
