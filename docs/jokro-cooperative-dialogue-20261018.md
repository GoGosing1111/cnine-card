# 족로 격전지 광역기·초록 대사 프레임 — 2026-10-18

사용자 `족로 격전지에서 광역기 발동 안한다 그리고 멘트창 너무 촌스러워 초록색 프레임 고급스럽게 꾸며봐`에 따른 수정이다.

## 원인과 수정

- 실제 격전지 서버는 청룡단천의 WINDUP·전체 대상 피해·END를 정상 발행했다. 이전 화면은 첫 3대상 광역기를 약 1.7초에 웨이브 전환으로 취소해 원래 2.12초인 타격 연출에 도달하지 못했다. 같은 캐릭터의 최신 일반 공격 한 개만 보존하는 대기열도 광역기 이벤트를 덮어쓸 수 있었다.
- 격전지의 최신 청룡단천 이벤트는 자신의 일반 공격 대기열을 대체하고 즉시 V3 재생으로 넘긴다. 이전 대기열이 끝나더라도 낡은 일반 공격을 시작하지 않는다. 다른 분대는 계속 독립적으로 진행한다. 장시간 지연·이탈·웨이브 전환의 기존 서버 동기화 정책은 유지한다.
- 격전지에서만 발도 준비와 첫 파열 진입을 압축해 실제 타격 연출을 0.2초에 표시한다. 원본 후반 효과는 1배속으로 유지하며 일반 PVE는 기존 5.6초·2.12초 타격을 유지한다. 새 몬스터가 같은 슬롯에 배치되면 이전 대상 ID의 연출이 새 대상에게 HP나 피해 숫자를 적용하지 않도록 확인한다. 서버 피해량·공격 속도·에너지·재사용·계정 편성·운영 설정은 변경하지 않았다.
- 족로 전용 초록 대사 프레임을 built-in ImageGen으로 새로 생성했다. 녹옥·흑강·얇은 금속 테두리와 양끝 청룡 장식을 사용한다. 원본 PNG·투명 알파를 보존한 lossless WebP·최종 프롬프트·해시는 `assets/ui/project-v/mercenaries/jokro-dialogue-20261018/`에 있다. 이름·기술명·대사·등급은 DOM이다. 기존 승인 초상과 다른 용병의 프레임은 보존한다.
- 새 프레임은 가로 3-slice로 모서리를 보존하고 PC·모바일에 직접 연결했다. 혼합 분대의 대사 레일은 모든 화자의 높이를 먼저 확보해 대사와 화자가 바뀌어도 전장 크기가 변하지 않는다. 기술 검수는 사용자 시각 승인과 구분한다.
