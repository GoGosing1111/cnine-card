# 족각도시·군단토벌 화면 부하 개선 — 2026-10-12

숲켓몬을 열어 놓으면 다른 Chrome 창도 느려진다는 신고를 재현한 뒤, 족각도시의 반복 페인트와 숨겨진 화면 작업을 줄였다.

## 변경

- 폭동 지역의 붉은 경계와 채움·광원은 유지하고, 필터가 적용된 SVG의 stroke/fill opacity 애니메이션을 제거했다. 별도 레이어의 파동·불티는 유지한다.
- 도시 상태 조회 때 전체 `innerHTML`을 교체하던 방식을 도시 전용 DOM 패치로 바꿨다. 지도, 이미지, 변경 없는 체류자와 버튼을 유지하고 달라진 속성·문자·행만 반영한다. 선택·스크롤·키보드 초점과 저장 중인 체크박스를 유지하며 실패 후 체크 상태는 서버 값으로 돌아간다.
- 도시 화면을 숨기거나 freeze/pagehide하면 1초 화면 타이머와 상태 조회를 멈춘다. 숨기기 전에 시작한 조회의 늦은 응답도 화면에 반영하지 않는다. visibility/resume/pageshow에서는 서버 종료 시각 기준으로 갱신하고 즉시 상태를 다시 조회한다. 화면을 떠나면 이벤트 리스너와 타이머를 함께 해제한다.
- 군단토벌은 숨김·freeze 동안 250ms HUD 타이머와 시간·진행률·보스 HUD 갱신을 중단한다. 복귀하면 경과 시간을 즉시 표시하고 타이머는 하나만 재개한다. 명시적으로 일시정지한 사냥은 화면 복귀만으로 풀리지 않는다.
- 사냥 경과 시간, 서버 전투 기록, 드랍·자석 펫·보상 정산과 도시 전투·회차·CMS 경제 설정은 변경하지 않았다. 화면 숨김이 사냥 중단이나 결과 건너뛰기로 이어지지 않는다.

## 측정과 검수

현재 운영 소스와 같은 도시 화면을 로컬 Chrome 1440×1000에서 실행하고 폭동 2곳을 표시했다. 동일한 개선 코드에서 기존 경계 애니메이션만 복원한 경우와 제거한 경우를 각각 5초 측정했다.

| 5초 측정 | 기존 경계 효과 | 개선 후 |
|---|---:|---:|
| 페이지 TaskDuration 증가 | 1,511.38ms | 21.524ms |
| Paint 이벤트 | 3,596회 | 17회 |
| Paint 합계 | 586.855ms | 4.593ms |

이는 격리 재현의 페이지 작업량이며 PC 전체 CPU 사용량이나 모든 사용자 환경의 개선율을 뜻하지 않는다. 운영 계정으로 행동하거나 재화를 변경하지 않았다.

- Chrome 1440×1000 / 390×844: 지도·대상 선택, 같은 지도/체류자 노드 유지, 키보드 초점, 행 변경·삭제, 팝업 숨김 체크 저장을 확인했다. 처음 검수에서 저장 중 체크박스가 이전 값으로 순간 복원되는 문제를 발견해 수정했다.
- 문서 숨김을 주입한 11초 구간에서 도시 상태 조회 0회, 도시 DOM 변경 0회를 확인했다. 늦게 도착한 응답의 숨김 렌더링 차단과 복귀 조회, 화면 종료 후 타이머 해제도 확인했다. 실제 OS의 타이머 제한을 측정한 결과는 아니다.
- 군단토벌 HUD 회귀: 숨김 타이머 0개/화면 쓰기 0회, 전투 이벤트 진행 유지, 복귀 시간 반영, 반복 resume 후 타이머 1개, 명시적 일시정지 유지. 캐시 연결 검사까지 새 회귀 3개 통과.
- PC·모바일 캡처와 측정은 `docs/qa/recent-content-performance-20261012/`, 재현 코드는 `tests/recent-content-performance-20261012.browser.mjs`와 같은 이름 `.test.mjs`에 보존한다.
