# 용병 5+1 편성 · 스킬 수치 · 하이퍼팩 개방 (2026-09-13)

사용자 지시: PVE·PVP 용병 1장 편성 재확인, 하이퍼팩 개봉 ON. 후속 답변으로 “스킬별 수치 초안을 만들어 함께 적용”을 승인했다. 이번 범위의 이전 편성·개봉 OFF 보류를 해제한다. 다른 공동 출시 기능의 플래그와 용병 중복 강화는 별도 정책을 유지한다.

## 편성 계약

- 일반 덱은 정확히 5장 `cardIds`, 용병은 별도 `mercenaryCode` 최대 1개다.
- 기존 계정당 전용 슬롯 하나를 PVE·PVP 공격·방어가 함께 사용한다. 소유한 용병만 배치·교체·해제할 수 있다.
- 실제 덱 화면에 별도 슬롯을 표시하고 용병 격납고의 저장 API로 연결한다. 일반 덱 저장 배열과 용병 소유권 검증은 유지한다.
- PVE 출전 전투력과 PVP 편성·매칭 화면의 표시 합계에도 용병 고정 전투력을 정확히 한 번 더한다. 일반 카드 수와 일반 카드 전투력 소계는 분리한다.
- 운영 등급별 고정 전투력과 기존 스킬 배정을 보존한다. 이후 CMS에서 다시 검수 대기·수치 미설정으로 저장한 스킬만 전투에서 제외하며, 준비된 용병 기본 편성은 유지한다.

## 하이퍼팩

CMS 용병 개봉 확률 탭에 기존 하이퍼 개방 패널의 누락된 마운트 지점을 연결한다. 준비 상태 확인 뒤 기존 ON 버튼으로 개방하며 운영 확률·지급량·개별 카드 균등 확률·중복 집계·구매 단가는 유지한다. 1회 5억 코인, 최대 10회 일괄 개봉 정책이다.

## 검증과 롤백

SQLite·PostgreSQL 계정 경로에서 5+1 편성, 소유권·중복 요청·revision 충돌·교체·해제와 PVE/PVP 양쪽 스냅샷을 검증한다. 26개 서버 스킬 기믹의 에너지·재사용·피해 합계·표적 상실·지원 효과를 검증한다. 실제 덱·격납고·CMS 화면은 데스크톱과 모바일로 별도 확인한다.

하이퍼 개봉은 CMS OFF로 즉시 보류할 수 있다. 편성은 전용 공개 플래그를 되돌려 보류한다. CMS 값은 적용 전 revision 및 기록을 기준으로 복구하며 이미 지급된 유저 카드·중복 집계를 삭제하지 않는다. 배포는 범위 커밋 및 `npm run release:gate` 통과 뒤 `npm run deploy:production`을 사용한다.
