# 사현 행동 보장 · 스킬칩 연출 순서 · 레오넬 대사창 정렬 — 2026-10-19

사용자 후속 `그래도 사현 행동력이 느리거나 공격스킬을 안쓰는거처럼 보임`, 첨부 이미지와 `프레임 안에 초상화 들어가게 더 조정해라`, `글씨 텍스트 위치도 재정렬하고 멘트`에 따른 수정이다.

## 재현

- 운영 CMS를 읽기 전용으로 확인했다. 사현의 스킬은 ON, 강제 행동 간격 4, 2연속 행동, 속도 375%, 전투력 2억 2천만이다. 설정 누락은 없었다. `cms-reference.json`에 아즈마/사현 설정만 보존했다.
- 기존 서버는 일반 카드 행동과 아주 짧은 속도 게이지 시간이 모두 충족돼야 보스 강제 행동을 허용했다. 레오넬의 예약된 추가 행동은 게이지 시간을 진행시키지 않아, 카드당 400만·2천만·1억 조합에서는 실제 사현 스킬이 **0회**인 채 처치됐다. 레오넬 없는 경우에도 높은 카드 속도에서 사현의 첫 기술이 크게 늦어졌다. `cadence-before.json`은 기존 운영 소스의 전체 전투 결과다.
- 스킬칩이 있는 별도 재생 경로에서는 0ms 예산으로 기록된 레오넬 광역기와 사현 기술들이 겹쳐 실행됐다. 실제 메인 화면에서 사현의 3개 서버 기술 중 `seal, ultimate`만 완료 기록으로 남고 `curse`가 누락되는 것을 재현했다. 제어된 공통 시계 검사에서도 5개 긴 연출이 같은 순간에 모두 시작됐다. 앞선 2초 제한 수정과 별개의 원인이다.
- 첨부한 레오넬 대사창은 초상화와 상단 이름 줄이 기존 이미지의 안쪽 장식 영역을 침범했다. 원본 프레임은 유지한다.

## 변경

사현의 단일 정의에 `PARTY_ACTIONS` 응답 방식을 추가했다. 서버는 카드·용병의 실제 행동을 세고 CMS의 `forcedActionEvery`만큼 완료되면 살아 있는 사현에게 다음 차례를 보장한다. 현재는 4회다. 연속 타격 효과·슈트 독립 사격·아이콘 소환물은 이 카운터를 늘리지 않는다. 일반 카드 전멸 후에도 살아 있는 용병의 행동으로 이어진다. 자연 행동과 기존 2연속 행동, 최초 봉인 → 저주 → 궁극기 순서는 유지하며 이후에는 기본 공격을 계속한다. 기술을 무한 반복시키거나 죽은 보스를 되살리지 않는다.

이 변경은 실제 공격 기회를 늘리므로 승패가 바뀔 수 있다. 통제된 레오넬 조합에서 카드당 100만·400만은 기존 승리에서 패배로 바뀌었고, 2천만·1억은 사현의 3개 기술을 맞은 뒤 승리했다. 능력치·피해 공식·보상·사현 2배 능력치/보상은 변경하지 않는다. 아즈마·다른 아포칼립스·일반 PVE·PVP는 기존과 결과가 정확히 일치한다.

공통 스킬칩 재생기는 아포칼립스 기술과 레오넬·진무·헬리오스·시라누이·카이론·족로의 긴 광역기를 독립된 행동으로 취급한다. 저장된 예산이 0이어도 앞의 연출 완료를 기다린다. 슈트의 독립 사격/스킬칩 시계와 서버 피해 기록은 유지한다. 기존 저장 영수증에도 적용한다.

레오넬 대사창은 기존 전용 프레임·원화의 바이트를 보존하고 CSS 배치만 수정했다. 프레임 높이 132px와 안쪽 여백으로 초상화 46px(작은 화면/격전지 38px)를 내부에 넣었다. 이름과 스킬명은 같은 기준선의 윗줄, 멘트는 아래 줄의 왼쪽 정렬로 배치했다. 긴 스킬명은 말줄임하며 멘트는 줄바꿈한다. 모든 대사를 미리 측정하는 기존 로직을 유지해 멘트가 바뀌어도 전장 높이가 움직이지 않는다. 대사 내용과 승인 이미지를 바꾸지 않았으며 기술 검수를 사용자 시각 승인으로 기록하지 않는다.
