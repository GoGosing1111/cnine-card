# 영토전 업데이트 안내

영토전 시설·전장 개편이 운영에 반영됐습니다. 신규 시설과 지휘관 스킬은 현재 모집 중인 회차의 모집 마감·진영 편성부터 적용됩니다.

## 전장 진입과 복귀

기존 영토전 지도에서 현재 교전 거점을 선택하고 **전장 진입**을 누르세요. 전장에서는 방벽 상태, 중계탑, 시설과 교전 목표를 확인할 수 있습니다. **전선으로 돌아가기**를 누르면 기존 지도로 복귀합니다.

## 전력 중계탑

- 점령 즉시 진영 전력 **20** 충전
- 점령 유지 중 공성 피해 **15% 증가**, 교전마다 전력 **2 추가 충전**
- 점령 진영 지휘관의 **EMP 파동** 사용 권한 해금
- 상대 진영도 확보 교전으로 탈환 가능

중계탑 강화와 보급 강화가 동시에 유지되면 공성 피해가 **32.25% 증가**합니다.

## 보급 수송열차

- **15분 간격**, 열차당 **5분 동안** 호위 교전 진행
- 호위 **20점** 달성 시 진영 전력 **25** 충전
- **180초간 공성 피해 15% 증가**
- 호위 성공 진영의 해당 열차 참여자는 **행동력 3**을 열차별 1회 수령 가능
- 행동력 최대치 안에서 회복되며, 전선이 이동해도 같은 회차 종료 전까지 미수령 보급 수령 가능

## 신규 지휘관 스킬

- **EMP 파동:** 중계탑 확보 진영만 사용. 적 시설의 강화 효과·추가 충전과 새 공성포 발사 준비를 120초간 차단합니다.
- **성벽 파쇄탄:** 180초간 적 철벽의 피해 감소 효과를 절반으로 약화합니다.
- **공병 투입:** 정지된 아군 시설을 즉시 복구합니다.
- **거대 공성포:** 진영 전력 100을 사용해 30초 후 적 최대 방벽 HP의 10%를 타격하고 적 시설을 60초간 정지시킵니다. 대포병 반격으로 피해를 줄일 수 있습니다.

각 스킬은 진영별로 **45분의 독립 쿨타임**을 갖습니다. 전선 이동으로 쿨타임이 초기화되지 않습니다. 예약된 공성포는 EMP에 취소되지 않으며, 공성포만으로 거점을 점령할 수는 없습니다.

## 교전과 연출

**전선 공성 / 중계탑 확보 / 열차 호위** 중 이번 교전의 목표를 선택합니다. 시설 교전은 기존 개인 카드 전투와 행동력 비용을 사용하며, 방벽 피해 대신 시설 기여를 얻습니다. 개인 승리 보상과 참여 횟수는 기존 규칙대로 집계됩니다.

전용 시설 일러스트와 전장 배경, EMP·포격·복구·점령 연출이 추가됩니다. PC·모바일의 문구와 버튼, 전황 LIVE 배치를 조정했으며 연출을 끌 수 있습니다.

시설 점령과 보급 강화는 현재 전선에 적용됩니다. 시설이 정지되는 동안 해당 강화와 추가 충전은 중단됩니다. 운영 수치는 회차 편성 시 확정되며 진행 중인 회차에는 변경된 설정이 소급 적용되지 않습니다.
