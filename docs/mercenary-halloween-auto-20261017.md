# 할로윈팩 자동뽑기 · SS/SSS 획득 연출 · ON 표시

## 요청과 실제 동작

사용자 `자동뽑기 추가해`, `SS,SSS 습득하면 연출나오게 하고`를 반영한다. 할로윈 계약실 하단 **자동뽑기**에서 1회/10회씩, 반복 횟수 1~100회를 선택한다. 총 횟수와 최대 비용을 확인하고 시작하며 선결제하지 않는다. 매번 기존 서버 개봉 경로로 확정한 영수증·실제 사용 코인만 집계한다. 마지막 결과 묶음과 전체 진행/사용 금액을 함께 표시한다.

- 확정 결과를 먼저 표시하고 SS·SSS 획득 시 기존 등급별 원본 영상을 재생한다. 같은 묶음에 두 등급이 있으면 SS→SSS 각 1회, 해당 등급이 여러 장이면 같은 등급 영상을 반복하지 않는다. 영상이 끝나거나 사용자가 건너뛰면 다음 연출/개봉으로 이어진다. 무음 기본값과 소리 선택·일시정지·건너뛰기를 유지한다.
- 계정별 기존 브라우저 잠금을 전체 자동 실행 동안 유지한다. 개봉마다 고유 requestId와 미확인 요청 저장, 서버 확정 영수증을 사용하며 결과/연출 완료 전 다음 개봉을 하지 않는다. 각 묶음 사이 900ms 대기를 둔다.
- 직접 중지, 계약실 닫기, 화면 이탈은 다음 요청을 차단한다. 진행 중인 거래를 취소됐다고 표시하지 않고 결과를 확인한다. 판매 OFF/설정 버전 변경, 잔액 부족, 재고·통신 오류, 계정 변경 시 중지한다. 재진입·이전 결과 복구로 자동 실행을 재개하지 않는다.
- 자동 설정 1회당 최대 100회 반복, 최대 1,000회 개봉이다. 최대 비용은 BigInt로 계산하며 실제 차감은 기존 단일/10회 가격으로 서버가 처리한다. 가격·확률·재고·획득 경로와 전투 정책은 자동뽑기로 변경하지 않는다.

## OFF 표시 원인과 운영 설정

처음 운영 r6 조회 시 실제 저장 모드는 OFF였고, 2단계 합계가 95.755%라 ON 저장 조건을 충족하지 못했다. 사용자 `일반 SSS를 92.985%로 맞춰` 승인 후 기존 88.74%를 92.985%로만 변경해 합계를 100%로 보완했다. 운영 r7, 감사 로그 47380, 작업 키 `ops:halloween-remainder:20261017:v2`. SS 7종 각 1%, 헬리오스 0.01%, 진무 0.005%, 꽝 80%, 가격 1회 10억/10회 100억 코인, 한도·발행량은 그대로다.

후속 사용자 **`ON으로 바꿔라`**는 앞선 OFF 유지 지시를 대체한다. 요청에 따라 변경 준비 중 조회한 서버는 이미 **r8 / ON / 개봉 가능 / 개방 조건 충족**이었다. 저장 시각은 2026-10-17 10:54:55 KST. 중복 상태 변경 없이 최신 ON을 유지했다.

추가 사용자 `SSS확률 0.005로 변경`과 `꽝 80% 유지, 일반 C를 10.495%로` 확정에 따라 2026-10-17 11:03:23 KST **r9**로 1단계 SSS 0.5%→0.005%, C 10%→10.495%만 변경했다. 꽝 80%·나머지 1단계 확률·2단계 확률·가격·판매 ON을 유지했다. 감사 로그 47383, 작업 키 `ops:halloween-sss-entry:20261017:v1`. 운영 API에서 두 단계 조건 충족·ON·개봉 가능을 확인했다.

최종 후속 `SSS 0.0025로 변경`에 따라 2026-10-17 11:07:34 KST **r10**으로 SSS **0.0025%**, C **10.4975%**를 적용했다. 앞서 선택한 잔여 확률의 C 배분과 꽝 80%, 나머지 값, ON을 유지했다. 감사 로그 47385, 작업 키 `ops:halloween-sss-entry:20261017:v2`. 운영 조회로 개방 조건 충족·개봉 가능을 확인했다.

첨부한 팩 선택 카드에는 별도로 `판매 OFF · 출시 준비 중`이 고정돼 있었다. 이를 `drawEnabled`에 따른 ON/OFF와 실제 가격으로 변경하고, 계약실 입장 안내의 추후 가격 공개 문구도 현재 가격으로 바꿨다. CMS는 서버에 저장된 상태와 미저장 선택을 구분하고 판매 선택 바로 아래에 저장 실패/차단 사유를 표시한다. **일반 SSS를 잔여 확률로 맞춤**은 OWNER가 눌렀을 때만 계산하며 설정 저장 전 운영에 적용하지 않는다.
