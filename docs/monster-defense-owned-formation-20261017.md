# 몬스터 디펜스 · 보유 용병/카드 편성

사용자 `몬스터 디펜스 내 용병과 카드를 배치할수있게 해야지 방식은 격전지 처럼 선택하는 방식이 좋을듯`에 따라 고정 검수 캐릭터 드롭다운을 실제 보유 원화 선택창으로 교체했다.

## 동작

- 본인 보유·출전 가능한 용병 2명과 카드 1장. 용병은 중복 없이 선택 순서대로 전방/중앙에 배치한다. 원화 클릭·터치·키보드로 선택/해제하고 이름 검색·등급 필터·추가 목록 보기를 제공한다.
- 입장 전 선택과 대기방의 **내 분대 편성**에서 교체할 수 있다. 취소하면 기존 편성/준비를 유지하며, 적용하면 본인 준비만 해제한다. 저장된 일반 PVE/PVP 덱·용병 슬롯은 수정하지 않는다. 계정별 마지막 선택을 브라우저에 보관하고 소유권은 서버에서 다시 확인한다.
- 선택창은 기존 격전지처럼 보유 원화를 보여준다. 대기실/전투는 선택한 캐릭터의 실제 승인 SD를 사용한다. 전용 SD가 없는 일반 카드는 기존 공용 전투 외형을 사용하며 상세에 표시한다. 전투 로딩은 실제 출전 6~9기만 대상으로 하여 전체 인벤토리 SD를 미리 읽지 않는다.
- 기존 디펜스 역할 능력치·전용 전술과 30웨이브 확률 성장/부활을 유지한다. 선택창에 디펜스 체력·공격·전술을 표시하고 계정 고유 스킬/장비/성장 전투력이 그대로 적용되는 것으로 안내하지 않는다. TEST 및 계정 보상 OFF는 유지한다.

## 서버

`functions/_monster_defense_roster.js`가 격전지 `loadCoopOwnedCards`와 `mercenaryAccountState`의 실제 보유·출전 판정을 재사용한다. 선택/준비 검증은 선택 카드 한 장만 조회하며 목록 조회는 기존 묶음 방식으로 모든 보유 카드를 제공한다. 한정/전용 용병 접근 조건을 그대로 따른다.

생성·참가·선택·준비 시 서버가 만든 캐릭터 명세를 Durable Object에 전달한다. 클라이언트 능력치/원화/다른 계정 정보는 저장하지 않는다. 편성 revision과 요청 영수증으로 동시 변경·재시도·충돌을 구분하고, 대원별 방 소속·대기 상태를 검사한다. 전투 티켓의 READY 직접 호출은 계정 편성 방에서 차단하여 보유 검증을 우회할 수 없다. 이전 검수 방/이미 진행 중인 전투는 저장한 편성을 유지한다.

## 이미지

내장 ImageGen으로 흑철·은색·청록 수호석의 투명 선택 프레임을 제작했다. 원본 PNG와 프롬프트/참조/해시는 `preview/coop-defense-v1/assets/formation-v1/manifest.json`에 보존한다. SHA-256 `12e6af1bbe849e98e9a440e7946fff3f9398fbca15d0e9c80db7865bcba953eb`. 기존 디펜스 전용 패널·명패·버튼·문장을 함께 사용하고 새 CSS 일반 박스로 마감하지 않는다.

## 검수

- 디펜스 모델·성장·실제 Durable Object·보유 편성 관련 25개 검사 통과. 수량 0·미보유/중복 선택 차단, 능력치 주입 무시, READY 우회 차단, 소유권 재확인, 준비 해제, 다른 분대 보존, 중복 요청/다른 payload/낡은 revision, 재접속, 전투 시작 후 교체 차단을 포함한다.
