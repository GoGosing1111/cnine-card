# 족각도시 지역 탐색·전용 밸런스·병원 이동·경찰 승진

2026-10-12 사용자 요청 및 의료진 제외 확인에 따른 구현.

## 이용 방식

- 지도에서 선택한 지역의 탐색 목록을 확인하고 실제 그 지역으로 이동한 뒤 ‘이 지역 탐색하기’를 누른다.
- 병원·모텔을 제외한 9개 지역에 다른 장비 풀을 제공한다. 기본 무료, 재사용 60초, 발견 없음 30%, 세 장비 비중 35/25/10이다. 중복 장비는 추가되지 않는다.
- 기존 시장 무기 3종은 가격 2,000/8,000/20,000원을 유지한다. 신규 무기 7종과 방어구 6종은 탐색으로 획득하며 인벤토리에서 직접 장착한다.
- 무기와 방어구는 각각 1개 장착한다. TEST/ON 보관함을 분리하고 교대 시 초기화한다. 도입 시 현재 회차의 기존 구매 무기는 보존한다.
- 서버가 실제 위치·근무·사망·구금·모텔·대기를 검사한다. 추첨 결과, 보관함, 대기시간, 행동 영수증을 기존 플레이어/생활 상태 CAS 거래에 함께 기록한다. 동일 요청 재시도와 응답 유실은 저장된 결과를 반환한다.

## 도시 전투

기존 구현은 숫자만 정규화하면서 카드 타입과 용병 고유 전투 효과를 유지했다. 이제 PVP 카드 5장의 외형을 사용하되 양쪽 모두 방어·방어·공격·속도·회복의 같은 역할과 같은 기본 속도를 적용한다. 카드 성장·장비·고유 능력·타입 조합·펫·용병 고유 스킬/추가 행동을 가져오지 않는다. 계정 편성과 일반 PVP/PVE 엔진은 수정하지 않는다.

도시 전투력 = 무기 전투력 + 방어구 전투력 + 경찰 승진 보너스. 동일 장비·동일 시드에서 계정 전투력·카드 타입·용병을 바꿔도 전투 결과가 동일하며, 도시 장비 차이는 공격·방어 양쪽에 적용된다.

## 병원

- 기존 5분 설정도 유효 최대 180,000ms로 정규화한다. CMS의 조정 상한도 3분이다.
- 의사·간호사는 체류 제한을 적용하지 않으며 병원 근무도 유지한다.
- 일반 이용자는 입원 기준 3분에 병원·모텔을 제외한 지역으로 배치된다. 사망 대기 3분 종료 시에는 부활하면서 이동하므로 추가 3분을 기다리지 않는다.
- 입원 시각을 기반으로 고정된 목적지를 계산해 조회·재접속으로 다시 추첨하지 않는다. 온라인 조회 시 즉시 반영하고 오프라인 DB 반영은 기존 1분 주기 스케줄러가 수행한다.
- 현재 회차 이동 내역을 생활 상태에 보존해 다른 화면에서도 목적지를 안내한다. 계정별 확인 기록으로 닫기·새로고침 시 반복 표시하지 않는다. 기존 팝업 끄기 선택을 따른다.

## 경찰 승진

| 직급 | 기존 필요 실적 | 도시 전투력 | 자동 수입·근무 급여 |
| --- | ---: | ---: | ---: |
| 순경 | 0 | +0% | +0% |
| 경장 | 3 | +5% | +10% |
| 경사 | 8 | +10% | +20% |
| 경위 | 15 | +15% | +30% |

체포 성공 +2, 순찰 완료 +1의 기존 실적 기본값을 유지한다. 전투력은 무기+방어구에 직급 비율을 적용한 뒤 버림한다. 자동 수입은 다음 정산에 적용하며 이미 지급한 수입을 재계산하지 않는다. 근무 급여는 시작 시 확정하여 이후 승진이나 설정 변경으로 다시 계산하지 않는다. 승진 실적·급여 영수증도 중복 요청에 한 번만 반영한다.

CMS → 족각도시 → ‘탐색·장비’에서 발견 비중·대기·장비 수치를, ‘직업·수입’에서 직급별 전투력·수입 상승률을 설정한다. 새 승진 혜택은 다음 회차부터 적용한다. 이미 확정된 과거/현재 회차에 필드가 없으면 0%로 유지하여 소급 정산하지 않는다.
