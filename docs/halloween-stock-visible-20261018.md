# 할로윈팩 현재 잔여 수량 표시

사용자 후속 요청으로 앞선 수량 숨김 표시를 대체한다. 상점·계약실·시연에서 SS 7종과 SSS 3종의 기존 이미지 프레임 아래에 `남은 N장`을 표시한다. 값은 공개 팩 API의 발행 원장에서 계산한 `remaining`이다. 0장은 `남은 0장 · 소진`으로 표시하며 준비되지 않았거나 조회되지 않은 수량은 `수량 확인 중`으로 구분한다.

계약실의 초기 조회, 개봉·결과 복구 후 조회와 자동뽑기 중 재조회는 수량 문구를 갱신한다. 같은 페이지 상점의 카드 데이터와 현재 표시에도 갱신된 재고를 전달하므로 계약실을 닫아도 이전 수량으로 되돌아가지 않는다. 승인 원화·프레임·배경을 그대로 쓰고 숫자는 DOM으로 표시한다. 가격·확률·판매 상태·재고·지급·차감 서버 로직은 변경하지 않았다.

기존 `mercenary-halloween-pack-20261017.browser.mjs`의 수량 검사 범위를 갱신해 1440px·390px에서 상점과 계약실 10종, 실제 재고 값·소진·재조회 후 상점 갱신·페이지 재표시·가로 넘침 없음을 확인했다. 오류·누락 자산·구매 POST 모두 0건이다. 서버 재고 변화 검증은 격리 PostgreSQL 데이터에서만 수행했다. 현재 표시 정책과 충돌하는 기존 단위 검사 2곳의 기대 문구도 갱신했다.

앱·계약실·공용 표시 모듈과 서비스워커 캐시를 갱신한다. 원격 main의 최신 족로 격전지·대사창 변경을 보존한 상태에서 관련 수량 회귀만 수행하고 범위 배포한다. 운영 결과는 완료 후 기록한다.
