# 레오넬 백은 문장·네온 연속 모션 — 2026-10-19

사용자 `좋다 그대로 대기자세랑 스킬,공격 모션까지 안끊기게 만들어`로 V3 시안을 선택했다. 낮고 크게 배치한 사자 문장, 지면에 붙은 백은 문양, 흰색 캐릭터 테두리와 검 오라를 기존 레오넬의 대기·공격·삼연·궁극기에 연결했다. 앞선 `궁극기 컷신은 최초로 한번` 요청도 함께 적용한다.

## 변경과 보존

- 기존 승인 몸 작화 40장은 재생성하지 않고, 등록된 발 기준점으로 몸 전용 아틀라스에 패킹했다. 검은 원본 한 장을 별도 계층에서 연속 회전·이동한다. 길이·폭을 변형하거나 프레임별로 다른 검을 만들지 않는다.
- 몸 자세 사이를 혼합하고 공격 종료 전에 같은 대기 자세로 복귀한다. 행동 시작 시 실제 대기 상태를 이어받는다. 검 회전·손 위치도 같은 위상으로 연결하고 실제 타격 시각에는 기존 등록 자세를 정확히 사용한다.
- 문장/지면 이미지와 12장 검 오라는 내장 ImageGen 투명 원본이다. 검 오라 축은 프레임별 밝은 중심선을 등록해 기존 검날 구간에 붙인다. 네온은 몸·검의 실제 알파 윤곽에 적용하여 모든 자세에서 같은 흰색 테두리를 유지한다.
- 지속 효과의 위상은 행동 시작·복귀 때 초기화하지 않는다. 숨김·취소·제거는 기존 V3 타임라인 소유권을 따른다. 다른 액터의 피격 반동·공용 카메라는 덮어쓰지 않는다.
- 같은 전투의 최초 궁극기에만 컷인을 허용한다. 컷인이 실제 표시될 때 소비하며, 새 전투 payload에서는 초기화한다. 후속 궁극기도 원래 4.25초·1.79초 서버 접점을 유지한다.
- 기본 전투력 230만, 몸 공격 2배·기존 스킬 효과 1배, 획득 잠금과 보유권, 피해·대상·보상·CMS는 변경하지 않는다. 새 그림을 카드 원화나 기존 승인 전투 원본에 덮어쓰지 않았다.

## 제작 공정과 증거

기준 경로는 `preview/mercenary-leonel-sss-limited-20261018-v2/`다.

1. **원본 고정:** `approved-20261019/concept-v3.png`, `concept-prompt.txt`, `white-crest-approval-20261019.json`. 기존 원화/대기/검 해시를 함께 보존한다.
2. **동작 설계:** `motion.mjs`의 실제 접점·동작 2배/효과 1배를 유지하고 `source/LeonelWhiteRig.js`의 연속 자세·진입·복귀를 추가했다.
3. **몸 연속 작화:** 기존 승인 `assets/sources/body-*.png` 40장의 실제 몸 동작을 재사용한다. 각 프레임의 출처 해시를 `manifest.motionBody`에 기록했다.
4. **원본 무기:** `assets/locked/leonel-sword.png`를 단일 텍스처로 사용한다. 같은 검을 등록된 손 위치·각도에 연결하며 전 구간의 검날 길이가 동일하다.
5. **효과 작화:** `prompts/white-crest-20261019.json`, `assets/white-crest-20261019/*-source.png`. 사자 문장, 발밑 문양, 12개 서로 다른 흰 검 오라 프레임. 기존 공격·삼연·광역 효과는 보존했다.
6. **패킹·등록:** `build-white-crest-assets.mjs`. 몸은 640px 셀/305px 신체 기준으로 원본 610px를 정확히 절반 패킹하고 실전 높이 333을 유지한다. 발 피벗 320/540, 손·검날 좌표는 기존 원본 좌표에서 계산한다. 투명 WebP는 무손실이다.
7. **접점·지면:** `qa-white-crest.mjs`가 60Hz 전 구간의 검 길이 불변·지면 고정과 5개 실제 검격 접점을 확인한다. 진입/회복 시 손 위치와 효과 위상 차이 <1e-6.
8. **공용 실제 재생:** 기존 V3·PixiJS·GSAP. `source/LeonelFX.js`와 `preview/project-v-v3/source/battle/LeonelCombatPlayback.js`에 연결하고 기존 V3 소비 번들을 재빌드했다.
9. **화면/제어:** `qa/white-crest-20261019/`의 PC 1440×1000·모바일 390×844 캡처, 0.25/0.5/1/2배속·일시정지·취소·제거 검사. 최초 컷인/반복 생략을 확인했다. 실제 물리 휴대전화 검수와 구분한다.
10. **영상/재현:** 같은 폴더의 `desktop-continuous.webm`, `mobile-continuous.webm`는 실제 60fps 캔버스 녹화다. 두 영상의 약 9.52초 실제 재생·정상 종료·오류 없음은 `video-playback.json`, 장면 확인은 `video-contact.png`에 보존한다.
11. **사용자 승인 범위:** V3 구상은 위 사용자 문구로 승인됐다. 구현된 모션은 실제 재생 영상으로 제시한다. 기술 검사를 별도의 사용자 모션 시각 승인으로 기록하지 않는다.
