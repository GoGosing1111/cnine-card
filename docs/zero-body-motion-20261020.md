# 제로 공격 몸동작 2배 · 차분한 대기 — 2026-10-20

사용자 `공격모션 자체는 2배 빠르게하고 대기자세에서 좀 얌전히 서있게 변경해`, 후속 `스킬이펙트 속도는 그대로 공격모션만 빠르게`를 적용한다.

- `source/BodyMotion.mjs`에서 제로의 몸·쥔 검·이동·몸 잔상만 별도 시간으로 재생한다. 검격 직전의 준비와 검격 뒤 회수 동작을 2배로 진행하고 남는 시간은 준비/회수 자세로 유지한다. 각 검격이 닿는 기존 시각은 고정한다. 천검 포위는 소환검 타수와 시전자 명령 동작을 별도로 취급한다.
- 기존 `motion.mjs`, `array-motion-v4.mjs`, `SummonedSwordArray.js`의 효과·소환검 시간표와 이동 경로는 그대로다. 효과 프레임·용 궤적·검 투사체·폭발·타격 시각·전체 기술 길이·V3 타임라인 배속은 바꾸지 않는다. 접근성 동작 줄이기 설정도 유지한다.
- 대기는 승인 idle 0번 자세로 고정한다. 제로의 `calmIdle` 표시로 일반 전신 스프라이트의 상하 이동·비율 압축 트윈을 만들지 않는다. 망토·백금 검익·네온은 기존 시간으로 계속 재생한다. 다른 캐릭터의 대기는 변경하지 않는다.
- 일반 공격 3종, 광역 2종, 적 진영, 공통 V3/PVE/사냥/협동 디펜스와 기존 제로 프리뷰가 같은 몸동작을 사용한다. 몸 크기·원화·파지·이미지 바이트·도감 배치·공격 횟수·피해·쿨다운·획득·계정 보유는 변경하지 않는다. 자동 확대 OFF를 유지한다.
