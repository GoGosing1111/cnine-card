# S 청아 상위권 재조정 · 2026-09-18

사용자 지시: “청아 S급에서는 상위티어로 유지하게 밸런스조정 다시하고 A등급에는 절대 안지게 만들어라.” 이 문서가 앞선 청아 하향·상위 등급 보정의 최신 기준이다.

## 적용 규칙

- S 청아(V-005)의 PVP 탄착 교정(MS-005 / SAME_TARGET_CALIBRATION)을 **원래 피해량·타격별 피해 상한의 70% → 100%**로 회복한다. 직전 버전 대비 약 42.9% 증가다.
- 운영 CMS 배율 4.2에서 각 탄의 공격력 배율은 `0.98 / 0.98 / 1.372 → 1.4 / 1.4 / 1.96`이다. 최종 피해에는 기존 방어·회피·보호막과 상한이 적용된다.
- 전투 시작 편성에 살아 있는 SS·SSS 용병이 있을 때는 **기본 공격 50%, 탄착 교정 35%**를 그대로 적용한다. 상위 등급 상대의 스킬 계수를 별도 상수로 분리해 동급 이하 조정과 함께 늘어나지 않게 했다. 상대 사망·표적 변경 뒤에도 시작 시점의 제한은 유지된다.
- 청아의 기본 공격·S 고정 전투력·PVE, 다른 용병, 3행동 연사·즉시 초탄·마지막 탄 보너스·비용 25·재사용 5행동은 유지한다. 승자 강제 지정·난수 교체·등급에 따른 명중 조작은 추가하지 않는다.
- 운영 CMS revision 55를 읽기 전용으로 확인했다. 등급·스킬 배정·개봉 확률·계정 재화는 변경하지 않는다. 도감·보유 용병·CMS 설명은 공통 정책 함수를 사용한다.

## 검증 범위와 결과

운영 로스터와 전투 정책이 기존 CMS 55 스냅샷과 일치하는지 확인했다. 양측의 일반 카드 5장을 같은 전력·구성으로 두고 별도 용병 1장을 배치한다. 카드당 전력 10만·100만·2,000만, 혼합·공격·방어·속도 4종 덱, A/B 양쪽을 비교한다. 난수는 `n × 7919`, 조정 표본 n=1~128, 별도 검증 n=1001~1128이다. 아래는 실제 이용자 전적이 아닌 서버 엔진 시뮬레이션 결과다.

### A급 10종 전원

일반 카드의 전력 연계를 양측에 동일하게 적용하고 용병만 남긴 1대1에서 **61,440전 전승, 패배 0·무승부 0**을 확인했다. 리시아·카르시아·서윤·엘리시아·녹시아·솔레아·아우렐리온·케일·세이지·레니아 전원을 포함한다. 각 상대 6,144전으로, 전력·구성·공격/방어 위치·두 난수 표본을 모두 검사한다.

일반 카드 5장까지 싸우는 팀 전투에서도 A급 상대 86.5~90.4%의 승률을 확인했다. 팀 전투에는 다른 카드와 난수가 영향을 주므로, 위 1대1 전승은 임의의 전력 차이·부상·불리한 팀 편성까지 포함한 무조건 팀 승리 규칙이 아니다.

S/A 팀 전투 92,160전과 A 단독 대결 61,440전, 합계 153,600전의 세부 결과를 동명 JSON에 기록한다. 재현 명령:

```powershell
node scripts/audit-cheonga-upper-s.mjs ../qa/cheonga-calibration.json 128 1
node scripts/audit-cheonga-upper-s.mjs ../qa/cheonga-holdout.json 128 1001
```

### 영향 범위·출시 검사

- 직전 커밋 `cfde5a21d58d6592cc326c8818487447c8f00b4f`와 비교해 청아 외 용병 PVP 8,256개, 전체 44종 일반/아포칼립스 PVE 8,448개, 청아 대 SS·SSS PVP 1,920개의 **전체 전투 반환값이 일치**했다.
- 기존 SS별 우세·청아 대 SS 단독 패배 검사를 유지한다. 신규 검사에서 현행 S급 전원 상대 우세와 A급 10종 전원 단독 대결 승리를 확인한다. 피해 상한·후속탄·자원 1회 차감·재사용·범위 제외 검사를 포함해 해당 테스트 파일 23개가 통과했다.
- PC 1440×1000 / 모바일 390×844에서 실제 메인 앱의 PVE/PVP 입장 → 전투 → 결과 → 복귀와 도감·CMS의 100% 및 50%/35% 표시를 검수한다. 재입장·구버전 갱신·입장 오류 복귀도 격리 계정 API에서 확인한다.
- 정책 버전은 `20260918-cheonga-upper-s-v3`이며 CMS 모듈의 캐시 키를 함께 갱신한다. Pixi·GSAP 연출과 메인 전투 번들은 변경하지 않는다.
- 깨끗한 범위 커밋을 origin/main에 통합한 뒤 `npm run deploy:production`으로 전체 `release:gate`와 지정 배포를 실행한다. 이후 운영 도감·정적 정책 파일과 운영 자산을 사용하는 격리 계정의 입장·전투·복귀를 확인한다.
- 롤백은 이 범위 커밋을 되돌리고 동일한 출시 검사·배포 절차를 따른다. DB 복구는 필요하지 않다.

## 유저 공지 문안
