# 용병카드 개봉 확률 CMS — 2026-09-12

사용자 지시: “용병카드 확률 준비해놔 CMS에 / 아직 유저 개봉은 OFF / 용병카드 등급별 확률 부여, 마스터의별, 미스틱에너지, 꽝 4가지”.
후속 선택: “확률·수량 초안도 제안”.

운영 CMS의 **용병 관리 → 개봉 확률**에 편집 가능한 제안 초안을 등록한다. 이번 요청은 CMS 준비이며 V3·용병·장비 공동 출시나 유저 개봉 활성화가 아니다.

## 제안 초안

모든 확률은 **개봉 1회 기준의 절대 확률**이다. 용병 등급 안에서 다시 적용하는 조건부 확률이 아니다.

| 결과 종류 | 등급/항목 | 확률 | 당첨 시 수량 |
| --- | --- | ---: | ---: |
| 용병카드 | C | 16% | 1장 |
| 용병카드 | B | 9% | 1장 |
| 용병카드 | A | 4% | 1장 |
| 용병카드 | S | 0.8% | 1장 |
| 용병카드 | SS | 0.18% | 1장 |
| 용병카드 | SSS | 0.02% | 1장 |
| 마스터의 별 | MASTER_STAR | 10% | 1개 |
| 미스틱에너지 | MYSTIC_ENERGY | 20% | 1개 |
| 꽝 | NONE | 40% | 없음 |
| **전체** | **용병카드 소계 30%** | **100%** | |

카드 획득 30%와 재화 획득 30%, 꽝 40%를 출발점으로 비교하는 제안이다. 100회 기준 기대값은 카드 30장, 마스터의 별 10개, 미스틱에너지 20개다. SSS는 10,000회 기준 기대값 2장이며 확정 획득이나 천장이 아니다. 개봉 비용과 공급량이 미정이므로 운영 경제 검수를 마친 확률로 취급하지 않는다.

## 화면과 저장

- 진입: /admin/#mercenaries/draw
- 조회: GET /api/admin/mercenaries/draw
- 저장: PATCH /api/admin/mercenaries/draw
- 요청: policy, expectedRevision, requestId, reason. OWNER 및 기존 BATTLE_MANAGE 권한을 모두 확인한다.
- 용병 6등급, 재화 2종, 꽝 총 9개 결과를 정확히 한 번씩 설정한다. 결과의 큰 분류는 사용자 지정 4가지다.
- 확률은 0.0001% 단위의 정수로 저장하며 합계 1,000,000 = 100%만 허용한다. 빈값·음수·초과·중복·알 수 없는 결과·비정수 수량·ON 플래그를 거절한다.
- 재화 지급 수량은 각 항목에서 직접 변경한다. 카드는 1장, 꽝은 0개로 고정한다.
- “남은 확률을 꽝으로 채우기”는 사용자가 누를 때만 동작한다. 자동 정규화나 자동 확률 배분을 하지 않는다.
- 합계와 100회 기대 수량을 즉시 표시한다. 저장 사유, JSON 내보내기, 다시 불러오기, 충돌 시 편집 보존과 응답 유실 시 동일 요청 재확인을 지원한다.
- mercenary_draw_config_v1 및 mercenary_draw_audit_v1에 별도 저장한다. 기존 용병 이름·등급·스킬 배정·성장 설정을 덮어쓰지 않는다.
- 설정 변경과 변경 전후 JSON·관리자·사유·리비전·요청 해시는 하나의 DB 트랜잭션에 기록한다. 같은 요청 재실행은 중복 저장하지 않는다.
- 최초 등록은 ON CONFLICT DO NOTHING으로 동작한다. 저장된 운영 초안을 시드 재실행으로 초기화하지 않는다.

## 개봉 OFF 및 미확정 항목

- MERCENARY_CARD_OPENING_RELEASE_ENABLED=false를 서버 코드에 고정한다.
- mercenary-cards/feature는 userOpeningEnabled=false를 반환한다.
- mercenary-cards/open, mercenary-cards/open-batch는 설정을 읽거나 팩·재화를 차감하기 전에 MERCENARY_OPENING_DISABLED / HTTP 409를 반환한다.
- DB의 openingEnabled 위조나 PATCH 요청의 ON 값으로 이 차단을 해제할 수 없다. CMS에는 ON 버튼이 없다.
- 확률 추첨, 팩 소비, 카드/재화 지급, 유저 개봉 UI 및 편성·전투 연결을 추가하지 않는다.
- 사용자가 정하지 않은 개별 용병 등급과 스킬은 자동 배정하지 않는다. 화면의 “CMS 등급 설정 N종”은 설정 현황이며 획득 풀 승인 표시가 아니다.
- 개봉 비용·공급, 같은 등급 내 카드별 확률, 획득 대상, 중복 처리, 천장과 공동 출시 조건은 별도 확정 사항이다.
