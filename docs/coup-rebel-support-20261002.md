# 쿠데타 반란군 지원 · 전선 체력 — 2026-10-02

사용자가 제안안을 승인하고 전선 체력 1,000만을 지정했다. 반란군은 행동력 90초당 1, 포격 25분, 결집 45분으로 적용한다. 족장팀은 기존 120초·30분·60분을 유지한다. 최대 행동력 10, 결집은 50으로 충전, 포격 최대 HP 30%는 유지한다.

현재 모집 회차에 `rebelSupport`의 회차 ID와 승인 preset을 저장한다. 새 회차를 열면 `coupSettings` 정규화에서 이 보정은 제거된다. 최대/현재 양쪽 거점 체력과 회차 설정, 다음 회차 기본 체력은 10,000,000으로 저장한다. 지휘관·참가 명단·전선 위치·원폭 OFF·전투 시간·출격 대기·보상·수감 정책은 변경하지 않는다.

OWNER CMS의 **쿠데타·재판 → 이번 회차 반란군 지원**에서 적용한다. 현재 회차 ID, revision, 모집 상태, 미개전·무전투를 확인한다. 현재/다음 체력 설정과 회차 보정, 멱등 영수증을 단일 기존 배치 트랜잭션으로 저장한다. 중간 실패는 전체 롤백하고 같은 요청 재시도는 다시 적용하지 않는다. 이미 전투가 시작된 회차에 체력을 재충전하지 않는다.

서버 출격의 사전/확정 행동력 검사와 상태 응답, 개인 회복 타이머, 규정, 지휘 스킬 재사용 시간에 같은 회차 정책을 사용한다. 반란군 보정이 없는 과거·다음 회차는 기존 값으로 동작한다. 결집 초과 행동력은 자연 회복을 하지 않으며, 원폭 회복 차단 중 적립은 하지 않는다.

## 범위 검사·배포

국소 쿠데타 변경이며 공통 인증·DB 기반·마이그레이션·의존성·V3 엔진은 수정하지 않는다. 실제 직전 운영 기준은 Cloudflare canonical deployment `3bf173d3-5808-4615-9436-428e1f99d035`, 소스 `b311b2e3a75429ba2208aec3e5eb5643e2af529e`다. 이후 main 차이는 운영 기록과 운영 작업 스크립트·테스트뿐이며 게임 실행 파일은 변경되지 않았다.
