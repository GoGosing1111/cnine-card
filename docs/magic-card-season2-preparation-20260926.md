## 이번 요청과 결과

사용자 요청: 이전 시즌2 논의를 찾아 검토하고, 기존 마법카드보다 향상된 성능과 새로운 효과를 준비하며 리소스까지 제작한다. 후속 `이미지 다 마음에 드는데 마법카드 프레임도 넣어서 프리뷰 만들어 유저한태 안내먼저 하게 효과도 적고`에 따라 **원화는 승인본으로 보존하고 프레임·효과 설명을 합친 유저 안내용 프리뷰**를 만든다.

## 신규 성능 제안

S2는 조건을 충족하면 확정 발동하며 +9 주요 수치는 +0 대비 30% 성장한다. 조건·횟수 예산까지 강화로 늘리지는 않는다. 기본 성장 배율은 1/1.03/1.06/1.09/1.12/1.15/1.18/1.22/1.26/1.30이다.

| 카드 | +0 → +9 주요 수치 | 새 전투 상호작용 |
| --- | --- | --- |
| 월식의 예언서 | 표식 피해 +12% → +15.6% | 팀 집중 표식 총 6타, 처치 시 남은 타수 이전 |
| 인과 절단 | 방어 무시 50% → 65%, 보호막 관통 30% → 39% | 세 번째 직접 공격마다 발동, 최대 2회 |
| 운명의 대리 | 이전 피해 경감 20% → 26% | 아군 HP 1 보존과 장착자의 피해 대신 받기, 팀당 1회 |
| 생명 연성진 | 전환 60% → 78%, HP 상한 18% → 23.4% | 승인된 초과 회복을 보호막으로 전환, 팀당 3회 |
| 성좌 전환 | 게이지 +20 → +26, 후퇴 보호 20% → 26% | HP 35% 이하 전열과 건강한 후열 교대, 팀당 1회 |
| 붕괴 장부 | 기록 50% → 65%, 방어 약화 12% → 15.6% | 보호막 파괴 시 기록 60% 폭발, 최대 1회 |
| 별의 유언 | 공격력 +8% → +10.4%, 게이지 +12 → +15.6 | 첫 최종 사망 후 생존 일반 아군 전체 강화, 팀당 1회 |
| 만상 거울 | 복제 효율 70% → 91% | PVP 상대의 첫 복제 허용 마법 성공을 따라 하기, 최대 1회 |

9월 초안에서 추가한 강화 요소는 월식의 기본 수치를 10%에서 12%로 올린 것, 운명의 대리에 이전 피해 경감, 성좌 전환에 후퇴 직후 직접 피격 2회 보호를 붙인 것이다. 이 수치는 이번 요청에 따른 **제안**이며 운영 밸런스 확정/전투 활성화 승인이 아니다.

기존보다 나은 체감은 +0부터의 사용성, 예측 가능한 조건 발동, 팀 효과·관통·위치 교대·피해 이전에서 만든다. 모든 상황에서 모든 S1을 이기는 카드라고 주장하지 않는다. 거울은 PVP 전용이며, 연성진은 실제 회복원, 장부는 상대 보호막, 성좌 전환은 교대 가능한 후열을 요구한다.

## 후속 전투 연결 계약

- 일반 카드 5장과 용병 별도 슬롯을 유지하며 마법은 기존 일반 카드 슬롯과 연결한다. 유언/치유/교대의 1차 대상은 일반 카드로 한정하고 용병·슈트·소환체에는 자동 확장하지 않는다.
- 대리는 기본 보호막/피해 감소 이후, 전직 생존/불사조보다 먼저 판정한다. 하나의 피해는 하나의 생존 예산만 쓰며 이전 피해에서 대리/반격/흡혈/부활을 재귀 실행하지 않는다. 장착자는 죽을 수 있다.
- 연성진은 회복 풀에서 승인된 양과 실제 회복량의 차이만 사용한다. 상한 때문에 보호막을 하나도 만들지 못했으면 횟수를 소비하지 않는다.
- 인과 절단의 보호막 관통은 최종 피해를 HP/일반 경로로 나누는 것이지 추가 피해를 한 번 더 주는 것이 아니다. 무적·아포칼립스의 슈트 필수 조건은 유지한다.
- 장부는 실제 보호막 피해만 기록하며 기록 상한은 장착자 공격력 200%다. 표적을 바꾸면 초기화하고 추가 피해·복제는 기록하지 않는다.
- 성좌 교대는 현재 공격 정산 후 서버 위치/표적 선택과 V3 위치를 같은 이벤트로 갱신해야 한다. 새 독립 전투 렌더러를 만들지 않는다.
- 거울의 1차 허용 목록은 `CRISIS_HEAL`, `PUNISH_TRAP`, `ARCANE_COUNTER`, `FOLLOWUP_HASTE`, `SHIELD_SIPHON`, `TIME_DISTORTION`, `PURIFY_LIGHT`, `CHAIN_ECHO`다. 원본 이벤트 ID/소유자를 기록하며 재복제를 차단한다. 정수 봉인/낙인과 S2 효과는 초기 복제 목록에서 제외한다.
- 시즌별 풀/가중치/가격/강화 비용은 이번 작업에서 확정하지 않는다. S1 편성·강화·보유·풀을 바꾸는 운영 쓰기는 없다.
