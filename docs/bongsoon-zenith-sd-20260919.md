기본 image_gen 도구로 흰 고양이 귀, 둥근 볼, 앞머리와 긴 검은 머리, 흰 의상과 손짓을 반영했다. 생성된 실제 RGBA 알파를 보존하며 사방 48px 투명 여백만 더해 1350×1350으로 저장했다. 배경 제거·얼굴 재가공은 하지 않았다. 최종 프롬프트는 `docs/bongsoon-zenith-sd-20260919-prompt.md`에 기록한다.

기존 ZENITH 전투 전용 매니페스트에 카드 ID로 추가했다. PVE/PVP가 공유하는 아트 어댑터와 반응형 이미지 맵으로 전달하며 도감·덱·카드 상세에는 원본 사진을 유지한다. 기존 29종의 시각 승인 기록은 수정하지 않고 이번 제작·연결 지시를 별도로 기록한다.

배포 범위는 자산, 등록 데이터, SD 캐시 쿼리와 해당 로스터 검사 목록이다. 전투 엔진·버전·플레이백·스킬·게임 수치는 바꾸지 않는다. 자산 배포 경로는 SD 캐시 값만 변경된 스크립트 및 엄격한 경로의 이미지 맵 추가를 허용하며 그 외 런타임 변경은 계속 일반 출시 게이트로 보낸다. 사용자 지시에 따라 전체 게임 테스트를 실행하지 않는다.

자산 전용 기존 검사와 실제 아트 어댑터의 PVE/PVP/공성 조회가 통과했다. 기존 30종 매핑 불변, 도감·덱·상세·인벤토리 SD 차단, 31종 매니페스트, PNG·AVIF·WebP 경로를 확인했다. 배포 범위 판정은 이번 캐시·이미지 맵 추가를 허용하고 실행 코드 추가를 거절하는지 확인했다. 전투 전체 회귀 테스트는 이번 이미지 추가에서 실행하지 않았다.
