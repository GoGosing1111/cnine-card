# PVP 전투력 개편 구현·검증 보고

작성일: 2026-10-15 / 정책: `pvp-deck-growth-20261015-v1`

**상태: 검수안 구현 완료, 라이브 미반영.** 사용자 최종 지시 “그래 다하고 보고해 바로 라이브 반영하지 말고”에 따라 실행 스위치 `PVP_POWER_BALANCE_RELEASED=false`를 유지한다. 운영 DB·계정·획득 정책·재화는 수정하지 않았다. 아래 수치는 출시 후보이며 현재 서비스 수치가 아니다.

## 1. 기존 문제와 개편 방향

발테르의 기본 전투력 1,080,000, 헬리오스 1,123,200, 진무·카이론·시라누이 1,347,840은 일반 SSS의 기본값 180,000과 분리된 특별 정책이었다. 여기에 높은 카드 연계 배율, 추가 행동, 피해 경감·면역이 함께 적용됐다. 따라서 표시 전투력만 낮춰서는 실제 격차가 해결되지 않는다.

특히 기존 발테르 정책에는 베르칸을 공격 원인으로 식별한 피해를 0으로 만드는 규칙이 있었다. 아군 카드가 전멸한 용병은 상대 카드의 행동에서도 예약 행동 기회를 얻었다. 상대 카드가 성장해 더 자주 행동하는 이점이 적 용병의 행동으로 되돌아가는 구조였다. S~SSS 등급 차이 보정 역시 한 단계에 연계 체력·방벽 +500%, 연계 공격·상한 +100%로 컸다.

이번 검수안은 다음 세 가지를 함께 바꾼다.

1. 표시 전투력과 실제 전투 성능을 분리해 과도한 기본 전투력을 바로잡는다.
2. 성장한 카드·장비의 전투력이 실제 피해와 행동 기회에 도움이 되게 한다.
3. 카드 타입, 역할, 보호·제어·저격 및 용병 조합으로 전력 열세를 뒤집을 여지를 남긴다.

리미티드·신규 용병의 고유 스킬과 우수한 성능은 유지한다. 보유한 용병의 종류만으로 무조건 이기도록 판정을 덮어쓰는 규칙은 추가하지 않는다.

## 2. 전투력 → 실제 전투 보너스

### 산정 기준

전투 시작 시 서버가 만든 카드 5장과 선택 용병의 전투력을 합산한다. 일반 장비의 PVP 전투력은 기존 배분을 거친 카드에, 용병 장비는 해당 용병에 각각 한 번만 포함한다. 기존 서버 카드 조합 보정 이후의 전투 입력을 사용하며, 클라이언트가 보낸 총전투력이나 승률은 사용하지 않는다.

용병의 연계 공격력·체력·방벽을 다시 전투력으로 환산해 더하지 않는다. 전투 중 체력이 줄거나 한 명이 쓰러져도 시작 시 보너스를 다시 계산하지 않는다. 전투력 수치는 정수 안전 범위와 정상 편성을 확인한다.

```text
R = 내 편성 전투력 / 상대 편성 전투력
G = max(0, log2(R))
피해 배율 = 1 + min(0.35, G × 0.30)
행동 게이지 충전 배율 = 1 + min(0.18, G × 0.15)
```

| 전투력 우위 | 추가 피해 | 행동 게이지 충전 속도 |
| --- | ---: | ---: |
| 동일 | 0% | 0% |
| 10% 높음 | 약 4.13% | 약 2.06% |
| 25% 높음 | 약 9.66% | 약 4.83% |
| 50% 높음 | 약 17.55% | 약 8.77% |
| 2배 | 30% | 15% |
| 3배 | 상한 35% | 상한 18% |

상대보다 낮다고 내 기본 능력치를 추가 차감하지 않는다. 비율이 조금 증가할 때 갑자기 다른 등급의 보너스로 뛰지 않는 연속식이다. 실제 속도는 엔진의 정수 반올림을 따른다.

**행동 보너스는 전투 안의 게이지 충전 속도다.** 입장 행동력·티켓을 지급하거나 즉시 추가 턴을 강제하는 효과가 아니다. 빠르게 끝난 전투에서는 총 행동 횟수가 오히려 적을 수 있으므로, 총 턴 수가 모든 대전에서 증가한다고 보장하지 않는다.

피해 배율은 공격별 기존 상한을 계산한 뒤 한 번 적용한다. 방어·회피·보호막·피해 경감은 계속 작동한다. 공격자가 명시된 일반 공격·용병/아이콘 스킬·반격·지속 피해가 대상이며, 별도 고정/최대 체력 비례 효과 등 공격자 정보가 없는 기존 효과를 일괄 증폭하지 않는다. 원래 피해에 연동되는 추가 효과에도 같은 보너스를 다시 곱하지 않는다.

보호 분담은 증폭된 피해를 이중 증폭하지 않으며, 다단 공격은 전체 시전 예산 안에서 보너스를 분배한다. 보호막만 파쇄하는 경로는 추가 배율 때문에 HP까지 넘쳐 깎이지 않게 제한한다.

### 듀오와 영토전

- 듀오는 각 소유자의 카드 5장·용병·장비로 전투력을 산출하고 상대 두 편성의 평균과 비교한다. 강한 팀원의 보너스를 다른 소유자의 카드·용병에 복사하지 않는다.
- 용병 연계와 예약 행동도 자기 소유자의 카드만 기준으로 한다.
- 개편 활성화 시 영토전의 기존 전력 차이 축소 보정을 제거하고 같은 성장 규칙을 사용한다. OFF 상태에서는 기존 보정이 그대로다.
- 과거 영토전 재생 입력과 이미 저장된 듀오 대전은 저장 당시 버전을 사용한다. 버전 없는 기존 기록은 이전 규칙으로 재생하며, 개편 기록은 향후 스위치를 다시 꺼도 해당 버전을 유지한다.
- 듀오 평가 캐시 키에 정책 버전을 포함해 새 규칙 출시 시 기존 평가를 재사용하지 않는다. 기존 조회 한도·캐시·소유권·거래 처리는 유지한다.

## 3. 용병의 강점과 과도한 격차 조정

상위 SSS 리미티드 5종은 **PVP 기본 전투력 180,000**을 사용한다. 용병 개인 장비 전투력은 별도로 더하므로 장비 착용 후 표시되는 총전투력이 항상 18만이라는 뜻은 아니다. 일반 용병의 등급별 고정 기본 전투력과 SS 리미티드 7종의 기존 전투용 기본값 18만은 유지한다. 카드의 수집 등급을 바꾸지 않는다.

| 대상 | PVP 기본값 | 발테르 대비 고유 능력·연계 배율 | 자연 속도 계수 / 예약 누적 계수 |
| --- | ---: | ---: | ---: |
| 발테르 | 180,000 | 1.00 | 1.50 / 1.50 |
| 헬리오스 | 180,000 | 1.04 | 1.56 / 1.56 |
| 진무·카이론·시라누이 | 180,000 | 1.248 | 1.56 / 1.56 |

발테르는 평균 아군 카드 공격력 440%·체력 560%를 연계 기준으로 사용한다. 시작 방벽은 전열 보정 포함 평균 카드 체력 360%이며, 위 상위 배율을 적용한다. 실제 능력치는 기존처럼 고정 능력치와 연계 기준 중 큰 값을 사용하고 개인 장비 효과를 한 번 반영한다.

상위 5종은 PVP에서 받는 피해 20% 경감을 갖는다. 기존 특정 용병 피해 무효와 포괄 제어·독·반격 면역은 제외한다. 헬리오스의 발테르 대비 4%, 진무·카이론·시라누이의 헬리오스 대비 20% 능력 관계는 보존한다. 스킬별 역할·고유 연출·PVE 전용 광역기 제한은 그대로다.

SS 리미티드 7종은 기존 개별 능력·연계 계수를 보존하고 자연 속도/예약 누적 계수를 1.6으로 둔다. PVP에서 상대 용병 이름마다 달랐던 연계 배율은 사용하지 않는다. 수집 SS·전투상 SSS 취급 규칙은 유지한다. 이름별 승률을 목표치에 강제로 맞추는 방식은 사용하지 않는다.

일반 용병은 카드 행동마다 1, 베르칸·아잔트는 1.25, 리미티드는 위 계수를 예약 값으로 누적한다. **예약 값 3마다 용병 1행동 기회**를 얻는다. 전투 중 자연 행동과 예약 행동은 기존 엔진에서 처리하며, 명중 연출 횟수를 행동 수로 세지 않는다. 아군 카드가 모두 쓰러지면 적 카드 행동으로 예약 값을 얻지 않고 자기 자연 속도로 계속 싸운다. 자연 속도 하한은 시작 시 아군 평균 속도 × 0.6 × 용병 속도 계수다.

S~SSS 용병의 등급 차이 보정은 단계당 연계 체력·방벽 +15%, 연계 공격·피해 상한 +10%로 완화한다. 최종 고유 능력과 보호·제어·회복을 이용할 수 있어 높은 등급 하나로 상대 전략을 완전히 차단하지 않도록 했다.

## 4. 2번 검증 — 성장이 실제로 유리한가

확률을 넣어 승자를 고르는 검사가 아니라 **실제 서버 전투 엔진**을 반복 실행했다. 8개 용병 대진 × 4개 카드 타입 편성 × 6개 성장 비율을 양 진영에서 비교했고, 카드당 전투력 1만·2천만·20억 구간도 확인했다. 전체 비교는 36,416전이며 아래 표의 각 칸은 64전이다.

동일한 균형형 카드 구성, 기본 카드당 2천만에서 좌측 일반 SSS 편성의 카드 전투력만 높인 결과:

| 대진 | 동일 성장 | 카드 전력 +5% | +10% | +25% |
| --- | ---: | ---: | ---: | ---: |
| 크라이베른 → 발테르 | 0/64 | 1/64 | 37/64 | 64/64 |
| 베르칸 → 발테르 | 22/64 | 61/64 | 64/64 | 64/64 |
| 아잔트 → 진무 | 8/64 | 50/64 | 59/64 | 64/64 |

이는 카드 성장, 기존 능력치 환산, 새 보너스, 용병 정책을 모두 포함한 결과다. “피해 보너스 하나만으로 승률이 이렇게 오른다”는 뜻은 아니다. 표의 비율은 **카드 입력 전투력 비율**이며 용병 기본 전투력까지 합한 전체 편성 비율은 약간 다르다.

비교 대상으로 실행한 기존 규칙에서는 베르칸이 같은 균형형 구성으로 카드 전력을 10배까지 올려도 발테르 상대 0/32승이었다. 특정 피해 무효가 성장 가치를 막는 문제가 확인됐고, 개편안에서는 해당 제한 없이 실제 피해를 줄 수 있다.

공식은 150,000개 증가 구간에서 보너스 비감소·상한·연속성을 검사했다. 동일 능력치의 별도 격리 전투에서는 2배 전력 보너스만 적용했을 때 실제 피해 60,000 → 78,000, 같은 200행동 동안 행동 기회 100:100 → 105:95를 확인했다.

처음의 64전 비교에서 작은 승률 하락 2건이 나와 숨기지 않고 양쪽 조건을 각각 1,024전으로 확장했다.

- 베르칸 속도형 vs 이네스 속도형, 카드 전력 +5% → +10%: 32.42% → 40.14%.
- 카드당 1만 아잔트 vs 진무, +10% → +25%: 11.91% → 14.94%.

확장 표본에서는 모두 개선됐다. 단, 행동 순서·명중·대상 선택이 바뀌므로 **모든 개별 시드에서 성장 전 승리가 성장 후에도 유지된다는 보장은 하지 않는다.** 원본 비교와 후속 표본은 JSON에 모두 보존했다.

## 5. 3번 검증 — 조합으로 역전하고 리미티드의 강점도 남는가

균형형·공격형·방어형·속도형의 4×4 조합, 5개 용병 대진, 카드 전력 90%·100%·110%를 비교했다. 각 조건은 선공/후공을 바꿔 48전씩 실행했다.

- 장비 전투력·연계 능력의 중복 반영 없음. 피해·반격·보호 분담·아이콘 연타의 추가 배율을 한 번만 반영.
- 듀오 소유자별 보너스·연계·행동 격리, 영토전 저장 입력 재생과 재시도 보존.
- 일반 SSS·SS 리미티드·상위 SSS 리미티드 8개 PVE 사례의 **전체 결과/타임라인 SHA-256이 수정 전과 일치**.
- 족각도시 전용 정규화 전투, 배틀슈트, PVE에 새 보너스 미적용.
- PC 1440×1000 / 모바일 390×844에서 용병도감 PVP 18만·PVE 108만 전환, 설명 가독성, 가로 넘침 없음 확인.
- 실제 공용 V3 번들에 로컬 검수 서버 결과를 전달해 피해·타격 수·최종 체력 비율 일치 확인. 운영 전투나 계정은 사용하지 않음.
- API Worker `wrangler deploy --dry-run` 빌드 성공. 실제 배포 명령은 실행하지 않음.

### 전체 검사 상태 — 전부 통과로 보고하지 않음

공용 전투 개편이므로 전체 `release:gate`를 한 번 실행했다. 기존 실패로 중단된 뒤 남은 명령만 이어 검사했으며, 앞서 통과한 무관한 검사를 반복하지 않았다. 두 구간 합계는 **3,539개 중 3,524 통과 / 7 실패 / 8 건너뜀**이다. 별도 용병 검사 45개에서는 44 통과 / 기존 실패 1개였다. 이 합계는 서로 겹칠 수 있는 실행 건수이며 고유 검사 수를 뜻하지 않는다.
