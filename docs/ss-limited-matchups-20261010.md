# SS 리미티드 상대별 PVP 승률 조정

사용자 요청: `리미티드 SS 오메가,라그니엘은 55~~60% 승률 유지하고 크라이베른,베르칸은 50%~~55% 정도로 유지`.

대상은 나무늘봉순·조은·이네스·오리꿍·디임·아윤·하이희야 7종이다. 각 용병의 오메가-X/라그니엘 상대 승률 55~60%, 크라이베른/베르칸 상대 50~55%를 통제된 일반 PVP 검증 기준으로 삼는다. 과거의 네 상대 전체 종합 48~50% 기준을 대체한다.

## 전투 정책

- `shared/mercenary-ss-limited-v1.mjs` 버전 3의 `SS_LIMITED_PVP_LINK_SCALES`로 SS 리미티드의 PVP 연계 최소 공격력·최소 최대 체력·초기 방벽을 조정한다. 기본 능력치/스킬/타깃 규칙은 유지한다.
- 상대 용병 구성으로 전투 시작 시 한 번 결정한다. 일반 PVP는 해당 상대의 계수, 듀오는 상대 용병별 계수의 산술 평균을 사용한다. 네 일반 SSS 이외의 상대는 1을 기여한다. 상대가 쓰러진 후 보정이 바뀌거나 방벽을 추가로 얻지 않는다.
- 일반 카드·상대 일반 SSS의 자체 수치, PVE, 발테르/헬리오스 자체 정책, 표시/성장 SS 등급, 180,000 기본 전투력, 행동 주기 1.0625배(16회당 17회), 스킬 560%/비용 35/재사용 5행동은 유지한다.
- 계정/닉네임/승패 기록/난수값으로 계수를 고르거나 승자를 강제로 바꾸지 않는다. 서버의 원래 전투 엔진이 조정된 연계 수치로 실제 전투를 수행한다. 보정 정책은 도감 설명에 표시하고 공개 API에 `ssLimitedBalanceVersion=3`을 제공한다.

## 측정 방법

- 실제 운영 CMS revision 61의 일반 SSS 스킬과 런타임 전투 정책이 기준 fixture와 일치함을 읽기 전용으로 확인했다. 실제 유저 전투나 재화 지급은 실행하지 않았다.
- 일반 덱 12개(3개 전투력 구간)와 장비/고유특성/마법 편성 23개, 총 35개를 같은 비중으로 비교한다. 양 진영에서 같은 카드/장비/성장을 사용한다.
- 초기 기존 도구는 같은 난수를 여러 편성에 반복 사용했고, 별도 검증에서 9개 상대 조합이 목표를 벗어났다. 그 실패 결과를 `ss-limited-matchups-calibration-20261010.json`에 보존했다. 이번 기준은 상대·편성·진영·표본 번호를 SHA-256으로 섞어 편성 간 난수 재사용을 제거한다. 조정 후보끼리는 동일한 사례 난수로 비교한다.
- 최종 조정은 표본 번호 240001부터 48개, 최종 검증은 겹치지 않는 340001부터 128개를 사용한다. 상대 조합마다 35×2×128=8,960전, 용병마다 35,840전, 7종 총 **250,880전**이다. 조은과 디임은 같은 연계 후보를 사용하되 두 용병 모두 실제 엔진으로 별도 검증한다.
- 결과는 동일 조건 시뮬레이션의 승률이다. 다른 덱/성장/상성의 실유저 승률이나 듀오 전체 승률을 이 구간으로 보장하는 수치는 아니다. 원시 승/무/패, 상대·진영·편성별 분모 및 Wilson 구간은 최종 JSON에 보존한다.

## 검수와 배포 범위

- 신규 경로 검사: 양 진영의 동일 보정, 상대 일반 SSS와 일반 카드 불변, 전투 시작 후 고정/중복 적용 방지, PVE 및 잘못된 대상 제외, 듀오 소유자 구분/상대 구성 평균, 계정 변경 무관함을 확인했다.
- 직전 운영 엔진 `572e51c4`와 비교한 SS 리미티드 PVE 14개 및 일반 SSS끼리 PVP 12개 결과가 동일하다. 정책 버전과 보정 계수 메타데이터 두 필드만 비교에서 제외하며 피해·행동·HP·승패 전체는 그대로 비교한다.
- PC/모바일 도감 안내 및 실제 서버 생성 PVE/PVP 영수증을 배포 V3 번들에 연결한 화면을 확인했다. 네 전투 재생에서 HP/피해는 영수증과 일치했고 중복 적용·브라우저 오류가 없었다. 관련 검사는 범위별로 한 번만 실행한다.
- 국소 SS 리미티드 PVP 연계 정책과 도감 안내 변경이며 인증·DB/거래 기반·의존성·보상·출시 플래그 변경은 없다. 직전 운영 소스 `817f664d51a02a52428ecddf1b3fe0079b0ef57b`, Pages `761e56b8`를 기준으로 공식 `npm run deploy:production -- --scoped`를 사용한다.
- 배포 검사에는 SS 리미티드 성능/보고서 재현·행동 주기·편성 스냅샷·실제 번들/메인 로더 연결과 Worker 문법을 포함한다. 통과한 신규 경로/브라우저 검수를 다시 실행하지 않는다.
