# 쿠데타 족장 스킬 · 2026-09-15

족장 기본 정책: 원자폭탄은 운영자가 ON으로 전환하기 전까지 잠금. 결사대 결집은 행동력 50, 재사용 1시간. 각 스킬 쿨타임은 독립이다. 배포로 기존 운영 ON/OFF 값을 변경하지 않는다.

2026-09-15 후속 승인: 현재 반란군 참가자 **애장이(계정 83)**를 이번 회차 임시 지휘관으로 지정한다. 사용자가 운영 계정 후보를 확인하고 확정했다. 라운드 `07306811-48cf-43ef-8cc3-58a810fdd2e3`의 `settings_json.rebelCommand={roundId,userId:83}`에만 저장하며 새 회차로 승계하지 않는다.

| 반란군 지휘 스킬 | 효과 | 쿨타임 |
|---|---|---|
| 야포단 포격 | 현재 전선 족장팀 최대 HP의 30% 피해, 잔여 HP 한도 | 45분 |
| 결사대 결집 | 참가한 반란군 전원 행동력 50 충전 | 1시간 30분 |

반란군은 원자폭탄을 사용할 수 없다. 반란군 지휘관은 현재 회차에 지정된 ACTIVE 계정이며 REBEL 참가자여야 한다. 권한·등록 진영·라운드 설정을 저장 트랜잭션에서도 검증한다. 반란군 쿨타임 키는 `coup-rebel:<roundId>`로 족장 임기 키와 분리하며, 같은 회차의 지휘관 교체로 쿨타임이 초기화되지 않는다. 포격·결집 대상은 요청 본문이 아닌 서버가 결정한다.

반란군 참가자는 지휘관 이름과 두 스킬, 45분·1시간 30분의 대기시간을 확인한다. 발동 버튼은 임시 지휘관에게만 열린다. 발동 결과에는 명령한 진영·지휘관과 실제 대상 진영을 표시한다. 기존 전투 렌더러·버전·준비 검사는 수정하지 않는다.

| 스킬 | 효과 | 쿨타임 | 공개 상태 |
|---|---|---|---|
| 원자폭탄 | 무작위 반란군 최대 50명 행동력 0, 10분 회복 차단 | 30분 | 기본 OFF |
| 야포단 포격 | 현재 전선 반란군 최대 HP의 30% 피해, 잔여 HP 한도 | 30분 | 족장 사용 가능 |
| 결사대 결집 | 참가한 족장팀 전원 행동력 50 충전 | 1시간 | 족장 사용 가능 |

행동력은 기본 최대 10, 출격당 1 소모, 2분마다 1 회복. 결집으로 10을 초과한 동안 자연 회복은 멈춘다. 원폭 차단 10분 동안의 회복량은 적립하지 않으며 피격 12분 후 첫 1이 회복된다. 기존 출격 간격도 함께 적용한다.

## 권한과 저장

- 족장 스킬은 현재 회차의 재직 중인 족장만 발동한다. 직무정지·파면·임기 만료 및 비활성 계정은 차단한다. 반란군은 위 임시 지휘관 규칙으로 별도 검증한다.
- CMS `쿠데타 · 재판 → 족장 전용 스킬`에서 OWNER만 원자폭탄 ON/OFF를 저장할 수 있다. 설정 키 `coup_chief_skill_settings_v2118`가 없거나 JSON boolean true가 아니면 OFF다. 배포·스키마 초기화는 ON을 쓰지 않는다.
- 원폭 ON/OFF는 트랜잭션 안에서도 설정 행 잠금과 조건 검증을 거친다. 서버를 직접 호출해도 OFF 발동은 실패한다.
- 라운드 revision CAS, 임기 권한 잠금, 스킬별 임기 쿨타임, 행동력 변경, 전선 HP와 발동 영수증은 단일 배치로 저장한다. 실패하면 전체 롤백하고 동일 requestId 재시도는 기존 결과를 돌려준다.
- 신규 테이블 `coup_energy_v2118`, `coup_skill_cooldowns_v2118`, `coup_skills_v2118`은 런타임 스키마 초기화로 생성한다. 기존 참가자에게 저장 행이 없으면 행동력 10으로 해석한다.
- 발동 후 본인에게 결과 팝업을 열고, 쿠데타 관전자에게는 기존 5초 전황 폴링으로 새 스킬 팝업을 전달한다. 최초 진입 시 과거 발동을 재생하지 않는다.

## 검증

`npm run test:coup`: SQLite 및 PostgreSQL 호환 계층에서 권한, OWNER ON/OFF, 50명 표적, 10+2분 회복, 행동력 차감, 독립 쿨타임, 재시도, 동시 발동, 전선 돌파와 실패 롤백을 검증한다. 기존 쿠데타 정산·재판·투표·출격 회귀도 포함한다.

실제 클라이언트 JS/CSS와 생성 자산을 불러오는 로컬 API 모형을 사용해 CUA 브라우저에서 데스크톱 카드, 390px·320px 화면, OFF 잠금, 결집 상세/발동 결과/쿨타임을 직접 검수했다. 운영 유저에게 테스트 스킬을 발동하지 않는다.

배포는 깨끗한 범위 커밋에서 `npm run deploy:production`을 실행하며 포함된 `release:gate` 성공이 선행 조건이다.
