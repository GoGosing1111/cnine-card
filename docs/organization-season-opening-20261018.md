# 조직 추가 배분과 시즌 개막 — 2026-10-18

사용자는 추가 모집 마감 후 배분 버튼이 없는 문제를 제보하고, 나무늘봉순을 무쇠파로 지정한 뒤 나머지 인원 균등 배분과 시즌 개막을 요청했다. 승리 기준은 4거점에서 6거점으로, 코인 보상은 마지막 정정에 따라 3천억으로 확정한다. 앞선 5천억 지시는 적용하지 않는다.

## 동작

- 추가 모집 중에는 배정을 차단하고, 서버 마감 이후 OWNER의 평가·배정안·확정을 허용한다. CMS 모집 화면에 `추가 인원 배분하기`를 제공한다.
- 기존 명부는 그대로 둔다. 추가 신청자만 평가하며 지정 배정 → 조직별 인원 차이 최대 1명 → 기존 기준 전력 합계를 포함한 전력 균형 순으로 배분한다. 고정 대상과 기존 조직원은 교환하지 않는다.
- 확정은 기존 요청 영수증·회차 잠금·5분 평가 유효기간·계정 상태·평가 정책 검증을 사용한다. 새 회원만 INSERT하며 기존 가입 시각, 슬롯, 기준 전력과 최초 배정 시각, 아지트 점수·단계를 보존한다. 실패 시 명부와 영수증을 함께 되돌린다.
- 조직 세력전의 해당 회차 종료 시 6거점 이상 점령 조직 참여자에게 각각 300,000,000,000 코인을 메시지함 보상으로 지급한다. 마스터의 별 300,000개와 미스틱 에너지 300개는 유지한다. 참가 시 소속과 종료 시 소속이 일치해야 한다. 점령지 수만큼 보상을 중복하지 않는다.
- 신규 회차는 보상 규칙을 시작 시 보존한다. 기존 정산은 재발급하지 않는다. 기존 클랜 세력전의 4거점·300억 기준은 유지한다. 조직 공동 자금은 기존 지역당 수입과 별도로 정산한다.
- 기존 조직 콘텐츠 전용 ImageGen 패널·버튼·탭을 사용하고 문구와 실제 상태를 DOM으로 표시한다. 새 장식을 CSS 도형으로 만들지 않았다. 기능·화면 검수는 사용자 시각 승인과 다르다.
- 후속 요청에 따라 지도 마우스 드래그를 추가했다. 6px 이내의 손떨림은 클릭으로 허용하고 드래그 후 거점 선택은 차단한다. 포인터 캡처로 지도 밖에서 놓아도 종료하며 새로고침 중 카메라 위치를 보존한다. 드래그 중 들어온 서버 변경은 놓은 뒤 그린다. 전체 범위·서울·선택 지역 확대와 모바일 터치 선택을 유지한다.
