# 작업 지시서 — "앗, 이런!" 크래시 대응 (V1843)

담당: 코덱스 · 근거: `docs/앗이런-크래시-원인-v1843.md`

**결론부터: 할 일은 A 하나뿐입니다.** 코드 수정 없이 에셋 재생성 + 캐시 버스트입니다.

---

## 실측 근거

헤드리스 크롬(뷰포트 400×700, 모바일 폭)에 결과 모달을 띄우고 끝까지 스크롤하며
크롬 전체 프로세스 RSS 증가분을 잰 값입니다. **각 3회, 편차 거의 없음.**

| 방식 | RSS 증가분 |
|---|---:|
| **현재 — 카드 원본 100장** | **+417 MB** |
| **A — 384px 축소본 100장** | **+56 MB** |
| B — 원본 + 화면 밖 `src` 제거 | +379 MB |

모바일 크롬 렌더러는 300~500MB 에서 죽습니다. **+417MB 는 그대로 크래시 구간입니다.**

### 왜 "간헐적" 인가

같은 100연차인데 **어떤 카드가 걸렸느냐**로 갈립니다.

| 뽑은 카드 100장 | RSS 증가분 |
|---|---:|
| 무작위 100장 | +35 MB (안전) |
| 무거운 카드 100장 | **+417 MB (사망)** |

이미지 메모리는 파일 크기가 아니라 `가로 × 세로 × 4바이트` 입니다.
0.2MB 짜리 webp 도 2048×1536 이면 디코딩하면 12MB 입니다.
카드 원본 실측: 중앙값 0.9MB · 평균 1.6MB · 상위10% 3.5MB · **최대 22MB**.

---

## ⛔ B(화면 밖 `src` 제거)는 하지 마세요

처음에 제안했다가 **실측에서 기각했습니다.** +417 → +379MB, 9% 밖에 안 줄고
스크롤을 되돌리면 같은 이미지를 다시 디코딩해 오히려 더 쓰는 구간이 나왔습니다.

이유: 결과 카드에는 이미 `loading="lazy"` 가 걸려 있어 크롬이 알아서 지연 로드합니다.
화면에 들어오는 순간 **원본 해상도로 디코딩**되는 건 똑같습니다.
`src` 를 떼도 이미 디코딩된 뒤이고, 다시 붙이면 재디코딩됩니다.

**메모리를 줄이는 유일한 방법은 애초에 작은 이미지를 디코딩하게 하는 것** — 즉 A 입니다.

# A. 반응형 카드 이미지 재생성

## 왜

파이프라인(`scripts/generate-responsive-card-images.py`)은 이미 있는데
**커버리지가 337 / 2,243장** 입니다. 나머지 1,906장은 원본이 그대로 나갑니다.
결과 모달뿐 아니라 **도감·덱 편성도 85% 는 원본**을 씁니다.

## A-1. 입력 목록 만들기

Neon 에서:

```sql
SELECT json_agg(DISTINCT replace(image_url, '\', '/'))
FROM cards
WHERE is_active = 1
  AND image_url IS NOT NULL
  AND btrim(image_url) <> '';
```

결과를 `scripts/active-card-images.json` 으로 저장.

> ### ⛔ 여기가 제일 위험한 지점
> 스크립트는 매니페스트를 **덮어씁니다**(append 아님).
> 입력에 없는 경로는 매니페스트에서 **사라져 원본으로 되돌아갑니다.**
> 반드시 **기존 매니페스트와 합집합**을 만든 뒤 돌리세요.
>
> ```bash
> node -e "
> const fs=require('fs');
> global.window={};
> eval(fs.readFileSync('js/responsive-card-images-v1729.js','utf8'));
> const old=Object.keys(window.CNineResponsiveCardImages);
> const fresh=JSON.parse(fs.readFileSync('scripts/active-card-images.json','utf8'));
> const all=[...new Set([...old,...fresh].map(v=>String(v).replace(/\\\\/g,'/').replace(/^\/+/,'').split('?')[0]))].sort();
> fs.writeFileSync('scripts/active-card-images.json',JSON.stringify(all));
> console.log('기존',old.length,'+ 신규',fresh.length,'→ 합집합',all.length);
> "
> ```
>
> **합집합이 337 이상**인지 확인하고 넘어가세요. (이 스니펫은 실제로 돌려서 확인했습니다 —
> 역슬래시·앞 슬래시·쿼리스트링 정규화까지 원본 스크립트와 같은 규칙입니다.)

## A-2. 변환

```bash
python -m pip install pillow pillow-avif-plugin
python scripts/generate-responsive-card-images.py \
  --input scripts/active-card-images.json \
  --root . \
  --workers 8
```

끝나면 JSON 한 줄이 찍힙니다:

```json
{"sources": 2200, "generated": 2100, "files": 8400}
```

- `generated` 가 **337보다 커야** 합니다. 작으면 A-1 합집합을 건너뛴 것이니 중단하세요.
- `sources` > `generated` 는 정상 — 스크립트가 **가로 384px 미만은 건너뜁니다**
  (이미 작아서 축소 의미가 없음).

## A-3. 캐시 버스트 · 빼먹으면 A 전체가 무효

`index.html` 76번째 줄:

```html
<!-- 이전 -->
<script defer src="js/responsive-card-images-v1729.js?v=1729-responsive-card-images"></script>
<!-- 이후 -->
<script defer src="js/responsive-card-images-v1729.js?v=1843-full-coverage"></script>
```

`_headers` 가 `/js/*` 를 `max-age=31536000, immutable` 로 잠급니다.
**이 값을 안 바꾸면 유저는 옛 매니페스트(337장)에 1년 묶입니다.**

## A-4. 확인

```bash
node -e "
const fs=require('fs');global.window={};
eval(fs.readFileSync('js/responsive-card-images-v1729.js','utf8'));
console.log('매니페스트 등록:',Object.keys(window.CNineResponsiveCardImages).length,'(이전 337)');
"
ls assets/responsive/cards | wc -l    # 등록 수 x4 근처
```

배포 후 모바일 크롬에서 100연차 → `Shift+Esc`(데스크톱) 또는 원격 디버깅으로
탭 메모리 증가분이 **+60MB 내외**면 성공입니다 (현재 +417MB).

# 재발 방지 (선택)

카드를 추가할 때마다 커버리지가 다시 벌어집니다. CI 나 배포 전 체크로:

```bash
node -e "
const fs=require('fs');global.window={};
eval(fs.readFileSync('js/responsive-card-images-v1729.js','utf8'));
const have=new Set(Object.keys(window.CNineResponsiveCardImages));
const need=JSON.parse(fs.readFileSync('scripts/active-card-images.json','utf8'));
const miss=need.filter(p=>!have.has(p));
if(miss.length){console.error('반응형 축소본 없는 활성 카드',miss.length,'장:',miss.slice(0,5));process.exit(1)}
console.log('커버리지 OK');
"
```

# 하지 말 것

| | 왜 |
|---|---|
| 화면 밖 `src` 제거 / 결과 모달 가상화 | 실측 9% 효과. 재디코딩으로 더 쓰는 구간 발생 |
| CSS 로 작게 줄이기 | 표시 크기와 무관하게 **원본 해상도로 디코딩**됨 |
| 입력 목록을 활성 카드만으로 넣기 | 매니페스트를 덮어써 기존 337장 중 일부가 원본으로 되돌아감 |
| `?v=` 안 올리고 배포 | `_headers` 가 1년 immutable 로 잠가 유저에게 안 닿음 |
| `cardHtml` 의 `enabled:iconCard` 를 전부 true 로 | `special-reveal-card-ui`·`inventory-result-card` 는 크게 보여주는 화면이라 뭉개짐 |
