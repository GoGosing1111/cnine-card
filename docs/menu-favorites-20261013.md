# 계정별 메뉴 즐겨찾기 — 2026-10-13

사용자 요청: `자기가 자주 이용하는 메뉴 즐겨찾기 추가하고 이용가능하게 해 사이드 메뉴에 즐겨찾기 추가하고`.

## 이용 방법

- 메뉴 목록의 별표로 즐겨찾기를 추가·해제한다. 별표와 메뉴 이동 버튼은 분리해 잘못 이동하지 않게 한다.
- PC 사이드 메뉴의 로비 아래, 모바일 하단 메뉴, 메뉴 창 상단에 `즐겨찾기`를 제공한다. 등록한 메뉴는 추가한 순서로 표시하며 검색과 기존 바로가기를 지원한다.
- 같은 계정으로 로그인하면 다른 기기에서도 같은 목록을 불러온다. 즐겨찾기를 열 때 서버 목록을 다시 확인한다. 숨김·미출시·권한 제한 메뉴는 기존 메뉴 표시 및 접근 조건을 그대로 따른다.
- 빈 목록에는 추가 방법을 안내한다. 저장 중에는 해당 별표의 중복 요청을 막으며 저장 실패 시 완료 표시를 하지 않고 재시도를 안내한다.

## 저장과 연결

- `GET/POST /api/me/menu-favorites`는 기존 인증 및 상위 접근 보호를 사용한다. 사용자 ID는 인증 결과에서 가져오며 요청 본문의 계정 지정은 받지 않는다.
- 기존 `app_meta`에 `menu_favorite_v1:<userId>:<route>` 키로 메뉴별 저장한다. 추가는 충돌 시 유지, 해제는 해당 키만 삭제하므로 재시도가 중복을 만들지 않고 서로 다른 기기에서 추가한 다른 메뉴를 덮어쓰지 않는다. 별도 스키마·재화·획득 정책 변경은 없다.
- 클라이언트 캐시는 계정별로 구분하며 서버 응답으로 동기화한다. 이전 계정의 늦은 응답과 저장 전에 시작된 조회 응답이 현재 목록을 덮어쓰지 않게 한다.
- 원본은 `ui/adventure-lobby/favorites.js`, `ui/adventure-lobby/component.js`, `preview/lobby-clarity-v1/`이다. `npm run build:lobby`로 실제 공용 번들을 생성한다. 메인·독립 화면 로더와 서비스 워커 캐시 버전을 함께 갱신한다.
