# PWA 공통 화면 수명주기 성능 수정 — 2026-09-28

사용자 보고: 숲켓몬 PWA를 실행하면 화면 종류와 관계없이 같은 Chrome의 다른 창도 느려진다. 공통 UI에서 재현 가능한 불필요한 작업과 화면 교체 후 남는 관찰 대상을 수정했다.

## 변경

- `runtime-performance-v1727.js`: 제거된 화면의 IntersectionObserver 등록을 해제한다. 클래스가 바뀐 노드도 정리하며, 연결된 화면 안에서 이동한 노드는 유지한다. 중첩된 추가/삭제 기록은 가장 바깥 하위 트리에서 한 번만 처리한다.
- `lobby-bgm-v1803.js`: 음소거 상태가 같으면 버튼 HTML을 다시 만들지 않는다. 중복 감시 타이머를 하나로 줄이고 창 비활성/숨김 중 DOM 확인을 중지한다. 기존 BGM 재생 정책은 유지한다.
- `app.js`: 전투 스크롤 잠금은 모달의 클래스 또는 삽입/제거가 바뀔 때만 재확인한다. 파티클의 클래스 변경마다 앱 전체에서 모달을 찾지 않는다.
- 명함·챌린저 장식 PixiJS/GSAP: 다른 창으로 이동하면 재생을 멈추고 돌아오면 재개한다. 기존 공유 벤더, 활성 화면의 디자인, 게임 전투 시계와 결과 처리는 유지한다.
- 진입 HTML과 해당 장식 번들의 캐시 쿼리를 갱신한다. 서비스워커의 기존 app.js network-first 및 메인 로더 버전 계약은 유지한다.

서버·DB·권한·보상·게임 규칙·런타임 의존성은 변경하지 않았다.
