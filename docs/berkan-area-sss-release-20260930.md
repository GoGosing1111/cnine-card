# 베르칸 흑금 천우 PVE 연결 · SSS 0.1% 균등

2026-09-30 사용자 요청: 흑금 천우 운영 PVE 연결, PVP 광역기 제외 유지, 획득 ON. 후속 답변으로 확률 의미를 **SSS 등급 전체 0.1%, SSS 용병끼리 균등 추첨**으로 확정했다.

## 적용 범위

- 베르칸 V-055에 기존 MS-055 흑금 낙성과 추가 MS-056 흑금 천우를 함께 배정한다. 천우는 서버에서 PVE만 허용한다. 비용·재사용 조건에 따른 기존 순환 선택을 사용하며 0.1%는 스킬 발동률이 아니다.
- 천우는 살아 있는 적 전체를 각각 한 번 타격한다. 기존 낙성과 동일한 **총 배율 5.6 / 비용 35 / 재사용 5행동**을 사용하고 대상 수로 총 피해 예산을 나눈다. 회피·방어·보호막·제압·대상 제외 규칙과 서버 확정 피해를 유지한다.
- 기존 16프레임 화살비, 베르칸 모션, V3 PixiJS 8.20.0 / GSAP 3.13.0을 재사용한다. 원화·SD·이펙트 이미지 바이트는 변경하지 않았다. 1.62초에 서버 결과를 한 번씩 반영하고 등록된 V3 시계·취소·잔향 정리를 사용한다.
- 사용자 피드백으로 발견된 모션 크기 오류를 바로잡는다. 기존 모드별 `bodyPixels` 확대 때문에 512px 프레임이 대기 약 444px → 시전 약 623px로 뛰었다. 대기 프레임과 같은 픽셀 배율을 모든 모션·활 발사 기준점에 적용해 시전 중 프레임 크기를 고정한다.
- 실제 화면 검수에서 베르칸의 기본 전투 높이도 380으로 일반 캐릭터 260보다 크게 지정된 것을 발견했다. 베르칸만 260으로 맞춘다. 다른 SSS 캐릭터의 배치 높이는 변경하지 않는다.
- 운영 CMS의 이전 54종/34스킬 문서는 읽기 확장으로 보존하고, 명시적인 감사 저장에서 베르칸·천우를 포함한 55종/36스킬로 저장한다. 다른 용병 배정과 운영 편집값은 보존한다.
- SSS는 50ppm(0.005%) → **1000ppm(0.1%)**. 오메가-X V-021, 라그니엘 V-046, 크라이베른 V-049, 베르칸 V-055의 가중치를 각각 1로 설정한다. SSS 내 각각 25%, 전체 개봉 기준 각각 **0.025%**다. 베르칸의 기존 가중치 0(획득 OFF)을 해제한다.
- 증가분 950ppm은 꽝 408450 → 407500ppm에서 이동한다. 나머지 등급·재화 확률과 수량은 그대로다. 하이퍼팩 개봉은 기존 ON을 확인하며 별도 구형 개봉 플래그는 변경하지 않는다.
