# 리미티드 용병 편성 개방 — 2026-10-09

사용자 `리미티드 용병 편성 가능게해라`, 후속 `SD다 제작해놨는데 올려`를 반영한다. 발테르·나무늘봉순·조은·이네스·오리꿍·디임·아윤·하이희야 8종을 보유 계정의 PVE/PVP 공통 용병 슬롯에 편성할 수 있다.

## 적용

- 서버의 허용 코드·계정 상태·단일/다중 계정 전투 스냅샷을 리미티드 단일 편성 정책에 연결했다. 기존 소유권·요청 ID·편성 버전·사용자 잠금·원자적 저장/재시도를 그대로 사용한다. 계정 지급·재화 변경·스키마 변경은 없다.
- 도감의 리미티드 하드 잠금을 제거하고 실제 보유 용병에 편성/해제 버튼을 제공한다. 미보유 용병의 일반 하이퍼팩 유도 링크는 표시하지 않는다. 기존 한정 원화·프레임을 유지한다.
- 전투력은 발테르 1,080,000, SS 리미티드 180,000이다. 전투 엔진의 기존 발테르 전용 정책과 SS 리미티드 일반 SSS 동급 정책을 재사용하며 편성 화면·합산 전투력과 일치시켰다. 능력치·기술·상성 수치는 이번에 변경하지 않는다.
- 일반 CMS/획득/합성 풀에 한정 카드를 넣지 않는다. 리미티드팩 OFF·개봉 가격·확률·계정별 하루 3,000회 한도는 그대로다. 원화 카탈로그의 과거 공개/획득 메타데이터는 보존하고 공개 도감에 현재 편성 가능 여부를 별도 투영한다.

## 발견한 아윤·하이희야 제작본

기존 별도 작업 트리 `pve-reform-plan-20261007/cnine-card`, 커밋 `eec0cfb8`의 `preview/mercenary-limited-ayoon-heeya-v3-20261008/`를 통합했다. SD 2장·몸 동작 24자세·효과·원본·프롬프트·무기 등록·기술 검수 이력을 보존한다. 운영 코드에 통합되지 않았던 제작본이며 새 생성물을 만들지 않았다.

실제 V3의 용병 로더와 기본기/스킬 재생에 연결하고 공용 소비자 번들을 갱신했다. 이전 제작 당시의 120,000/420% 일반 SS 능력치·CMS 추가 구현은 가져오지 않았다. 이후 확정한 한정 성능을 사용하며, 연속 시각 타격은 마지막 접점에서 해당 서버 적중 결과를 한 번 표시한다. 아윤은 기존 낫 베기, 하이희야는 기존 후속 사격 판정을 유지한다.

기존 제작본에 기록된 아윤 낫 자루의 머리카락 가림 구간은 일부 자세에서 단절되어 보일 수 있다. 사용자 업로드 지시에 따라 제작본을 그대로 연결하며 무기를 임의 재작화하거나 이 문제를 수정 완료로 기록하지 않는다. 기존 원화·프레임·SD/아틀라스 해시를 확인한다.

## 검수·배포 범위

공통 인증·DB 기반·스키마·거래 구조를 변경하지 않는 콘텐츠 편성 연결이므로 scoped 배포한다. 관련 계정 편성(소유/미소유, 저장/재시도/충돌/실패 롤백/해제, SQLite/PostgreSQL), 8종 PVE/PVP 전투 정책, 도감/원본 해시, V3 실제 번들/메인 로더를 검사한다. 기존 대량 밸런스 시뮬레이션은 수치가 바뀌지 않아 재실행하지 않는다.

PC 1440×1000·모바일 390×844 검수는 실제 편성 함수에 연결한 로컬 테스트 계정과 V3/Pixi/GSAP 렌더러로 수행한다. 실제 운영 계정에 지급/편성하지 않는다. 증빙은 `preview/mercenary-limited-deployment-20261009/`다.

서버/도감 회귀 28개와 PC·모바일 확인 14개가 통과했다. 같은 코드에 대한 검사를 반복하지 않고 배포 단계에서 V3 번들/메인 로더 검사와 Worker 컴파일을 추가 수행한다. 운영 배포 결과는 `mercenary-limited-deployment-20261009-release.json`에 기록한다.
