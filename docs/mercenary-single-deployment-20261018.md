# 용병 편성 중복 영역 제거

사용자가 1번 첨부에서 지정한 상단 `전투별 용병 편성` 영역을 제거했다. 실제 HTML과 생성 원본에서 모두 제거하고 전용 CSS와 없어진 이름 요소의 갱신 코드를 정리했다. 상단 현재 편성 요약, 선택한 용병의 이미지 편성 패널, PVE/PVP 선택·저장·해제·성장 기능은 유지한다. 새 UI 이미지를 만들지 않고 기존 전용 패널을 그대로 사용한다.

HTML의 앱·스타일 캐시 주소에 `singleDeployment=20261018-v1`을 추가했다. PC 1440px·모바일 390px에서 중복 영역 없음, 남은 모드 버튼 2개, 선택·편성·해제·새로고침·모드 간 영수증 복구와 가로 넘침 없음을 확인했다. 기존 브라우저 검사의 제거된 요소 참조와 용병 장비 링크 추가로 모호해진 선택자를 실제 남은 조작으로 갱신했다. 브라우저 오류 0이며 모든 계정 변경 검사는 격리 데이터로 수행했다.

검수: `tests/mercenary-loadout-modes.browser.mjs`, 앱·원본 문법 검사와 두 HTML의 제거 확인. 화면·실행 기록은 `docs/qa/mercenary-single-deployment-20261018/`에 보존한다. 배포에서는 관련 편성 회귀만 실행하며 보유·전투 수치·획득 정책·운영 계정 편성은 변경하지 않는다.
