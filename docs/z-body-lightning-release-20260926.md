## 반영 내용

- 뇌검 집행은 적 1명마다 헬기폭격과 같은 계산식의 5배 피해를 5회로 분할한다. 살아 있는 전열·후열 전체를 대상으로 하며 적 수로 희석하지 않는다. 간격은 헬기폭격과 동일한 15초다.
- Z바디 고유 스킬이므로 소유 스킬칩이 없어도 발동한다. 기존 스킬칩과 일반 공격, 보호막·회피·치명타·종말 보스 관통 계산은 유지한다. 서버 확정 피해를 재생하고 PVP에는 추가하지 않는다.
