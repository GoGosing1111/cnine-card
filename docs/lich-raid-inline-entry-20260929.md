# 리치왕 정벌 레이드 화면 내부 연결 — 2026-09-29

사용자 요청: 리치왕 진입 화면도 붕괴 코어·월드레이드처럼 기존 레이드 화면 안에서 표시한다.

## 변경

- `리치왕 정벌` 탭의 별도 페이지 이동을 없애고 `pveRaidHubView` 내부의 `pveLichRaidView`로 연결했다. 같은 탭 컨트롤러에서 월드·붕괴 코어·리치왕 선택 및 재진입을 처리한다.
- 운영 마크업과 계정 클라이언트를 재사용한다. 임베딩된 화면의 ID와 CSS를 리치왕 영역에 한정하고, 별도 사이트 헤더와 게임으로 돌아가기 링크를 제거했다. 기존 직접 주소는 유지한다.
- 탭·PVE 화면 이탈 때 자동 조회, 진행 중 조회, 이벤트 리스너, 열린 안내창 및 전장을 정리한다. 이미 보낸 공대 변경 명령은 서버의 기존 멱등 처리와 상태 조회로 확인하며, 화면 이탈만으로 공대를 해산하지 않는다.
- 리치왕 전투 어댑터는 기존 `ProjectVBattleV3Live.ensureRuntime()`을 사용한다. V3 엔진을 중복 포함하던 코드를 제거하고 게임의 `cnineCardCatalog`를 덮어쓰지 않는다. 공통 전투 소스·카드 도크·서버 전투/보상 규칙은 변경하지 않았다.
- TEST 접근 조건, 입장권/공대 정책, 모든 모드 보상 잠금은 유지한다.
