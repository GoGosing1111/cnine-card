# 군단토벌 TEST 참여자·0.001 가중치 — 2026-09-28

사용자 후속 지시: TEST 참여 인원을 직접 지정하고, 드랍 선택 가중치는 0.01뿐 아니라 0.001까지 지원한다.

## 적용

- CMS 군단토벌의 TEST 참여자에서 정확한 닉네임 또는 계정번호로 검색한 뒤 추가·제외하고 운영·드랍 설정을 저장한다. 최대 100명, 안정적인 숫자 계정 ID를 저장한다. 닉네임 변경은 참여 권한에 영향을 주지 않는다.
- TEST는 OWNER와 지정 계정만 이용하고 실계정 보상은 지급하지 않는다. OWNER는 무제한, 지정 일반 계정은 기존 하루 2회다. 제외 저장 후 다음 요청부터 입장·진행·줍기를 차단한다. OFF는 지정 여부와 무관하게 차단한다.
- 명단은 OWNER CMS에만 노출한다. 일반 상태 API는 기존 설정 조회 1회로 현재 계정의 이용 가능 여부만 반환한다. 검색 버튼/Enter에서만 제한된 정확 일치 쿼리를 1회 실행하며 입력 중 조회·폴링은 없다. 저장 시 최대 100개 ID를 한 쿼리로 확인하고 기존 설정 CAS·감사 로그 트랜잭션을 사용한다.
- 기존 설정과 이전 CMS 클라이언트에서 빠진 명단은 호환 처리한다. 명단을 생략한 저장은 기존 명단을 보존하며 명시적 빈 배열만 비운다.
- 후보 가중치는 0.001 단위로 저장한다. 추첨은 가중치를 1,000배 정수로 변환하여 작은 후보도 보존한다. 선택 확률은 소수점 5자리까지 표시하고 더 작은 양수는 `0.00001% 미만`으로 표시한다.
- 실제 운영 모드·참여자·드랍 후보는 이 배포로 변경하지 않는다. 실지급의 원자성·재시도 영수증 등 이전 구현을 유지한다.
