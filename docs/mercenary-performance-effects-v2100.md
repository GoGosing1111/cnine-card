# 용병 PVP 성능과 7역할 기본 공격 · V2100

사용자 지시: 용병 편성 시 전투력이 오르는데 PVP에서 더 약해지는 현상 확인·수정, 별도 공격 이펙트와 특성별 타격 신규 제작. 후속 메시지로 수호·돌격·기습·사격·저격·제압·지원 7역할을 명확히 지정했다.

## 전투 계산 수정

운영 CMS revision 53의 43종과 기존 등급 고정 전투력으로 비교했다. V2099의 용병 예약 행동이 일반 카드 행동 한도에 포함되고, 방어형 보호막 풀을 5장 대신 용병까지 6등분하는 손해를 확인했다. 용병을 중간에 추가하면서 일반 카드 초기 게이지·명중 난수 소비도 달라졌다.

- 일반 카드 5회 행동 직후 같은 서버 시각에 용병 추가 행동을 처리한다. 일반 카드 게이지·행동 한도·몬스터 강제 행동 횟수에 포함하지 않는다. 용병의 자연 행동과 준비/재사용 대기 규칙은 유지한다.
- 일반 카드 5장에 속하는 보호막 풀은 기존 5장에 분배한다. 용병 스킬의 보호·회복 예산은 해당 스킬에서 별도로 계산한다.
- 용병 초기 게이지·기본 공격·스킬에 별도 결정적 난수 흐름을 사용한다. 용병이 없는 기존 전투는 동일한 결과를 유지한다.
- 추가 행동은 진영별 일반 행동 한도의 2배까지 허용한다. 추가 행동 한도를 소진해도 남은 일반 카드 행동은 끝까지 진행한다. 용병끼리만 남은 교착 상태도 유한하게 종료된다.
- 용병 추가 기본 공격에는 일반 카드 연장전의 최대 HP 비례 강제 피해를 주지 않는다. C~SSS 고정 전투력과 CMS의 스킬 배율·비용·재사용 대기를 사용한다.

변경 파일은 `functions/_battle_v2_preview.js`, `functions/_mercenary_combat.js`다. 일반 카드 5장과 별도 용병 1장의 저장/API 계약 및 운영 CMS 값은 변경하지 않는다. 새로 생성되는 서버 전투부터 적용되며 저장된 과거 결과는 다시 계산하지 않는다.

## 성능 검증

카드당 1만·10만·40만·100만·2천만, 43종, 512개 난수에서 용병을 공격/방어 양쪽에 각각 추가했다. 기본 덱은 공격·방어·속도·생명·공격이며 양쪽 결과를 합산한다.

| 결과 | V2099 | 수정본 |
| --- | ---: | ---: |
| 용병 미편성보다 합산 승률이 낮은 비교 항목 | 50 / 215 | 0 / 215 |
| 베스페라, 카드당 100만에서의 합산 승률 | 48.14% | 52.44% |

동일 조건 미편성 합산 승률은 50%다. 추가로 방어 3·생명 2 상대와 속도 2·공격 2·생명 1 상대(+4% 전투력)를 128개 난수·3구간·43종으로 확인했다. 두 추가 행렬의 합산 및 진영별 승률 악화 항목은 0개였다. 이는 지정된 비교군의 반복 검증이며, 전투력만으로 개별 승패를 보장하는 정책은 아니다.

용병 없는 PVE/PVP 256건을 이전 커밋과 비교해 전체 결과·타임라인 일치를 확인했다. 회귀 검사는 보호막 보존, 일반 카드 순서·시각·난수·행동 한도 보존, 죽은 용병 제외, 극단적 속도와 교착 종료, 고정 전투력, 43종 PVP 비교를 포함한다.

## 새 시각 자산

7역할 각각 별도 ImageGen 원본과 16개 연속 프레임, 총 112프레임을 제작했다. 색상만 바꾼 기존 일반 4계열 효과가 아니다. 총기·활·마법은 무기/시전 기준점에서 방출하고, 검·방패·창·건틀릿은 접근 후 충돌한다. 역할은 서버의 `actor.role`, 무기 접점은 기존 해시 검증된 43종 attachment 데이터에서 읽는다.

상세 자산·프롬프트·SHA-256·연속 프레임·소멸·PixiJS/GSAP·오디오·검수 기록은 `preview/mercenary-role-attacks-v2100/README.md`와 `assets/manifest.json`, `verification.json`에 보관한다. 캐릭터 SD와 기존 배정 스킬은 기존 리소스를 사용한다.

2026-09-13 사용자가 실제 검수 화면을 확인하고 “검수 완료, 라이브에 연결”을 승인했다. `assets/user-approval.json`에 7종 원본과 아틀라스 해시를 고정했다. 새 효과는 공용 `MercenaryCombatPlayback.normalAttack`에서 직접 재생하며, 일반 카드 기본 공격과 기존 CMS 배정 스킬은 기존 경로를 유지한다. 입장 시 역할 아틀라스를 SD와 함께 불러와 첫 공격 중 다운로드 대기를 방지한다.

`scripts/build-v3-grid-consumers.mjs`로 모든 공용 V3 소비 번들을 다시 빌드한다. 라이브 앱과 전투 번들 URL의 `mercenary=2100` 캐시 키를 갱신했다. UI 화면·그리드·경제 설정을 바꾸지 않고 기존 운영 화면 안의 전투 연출에 적용한다.
