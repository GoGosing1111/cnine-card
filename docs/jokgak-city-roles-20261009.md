# 족각도시 생활·역할 스킬 및 CMS 모드 수정 — 2026-10-09

사용자 확정: 포만감 100에서 2시간 소진, 교전 보호 30초, 구걸·동냥 수락 시 현금 100원, 갱단 처치 시 20%/4,000원, 현재 ON 유지. 후속 공격자 패배 체력 표시와 CMS OFF/TEST 선택 오류를 함께 반영한다.

## 구현

- 포만감 기본 50/시간. 이동에 새 보호는 없으며 교전 후/부활 보호 기본 30초. 운영 저장값의 12/시간·300초는 별도 감사 영수증을 남기는 `scripts/ops/jokgak-city-roles-20261009.mjs`로 변경한다. 이전 경과 생활은 구 설정으로 먼저 정산하고 지갑은 그대로 유지한다.
- 거지의 구걸/동냥은 같은 장소의 활동 가능한 사람에게 지도 우측 하단에 100원 수락/거절 알림을 보낸다. 공유 대기 60초, 알림 30초. 서버 저장 요청의 금액만 사용하며 요청 당시 초대받은 계정만 참여한다. 이동·활동 종료·역할/모드 변경·만료 시 요청을 재사용할 수 없다.
- 기부는 양쪽 생활/플레이어 CAS, 초대 1회 수락, 영수증 및 수신 알림을 기존 batch로 함께 저장한다. 거절/실패에는 현금 이동이 없고 응답 유실 재시도는 동일 영수증을 회수한다. TEST/ON 지갑과 다른 게임 재화는 유지한다.
- 갱단의 처치 승리는 기본 강탈에 +10%p, 최대 4,000원. 정상 승리는 10%/2,000원. 공격자/방어자 중 실제 승자의 역할과 패자 도시 체력 0을 기준으로 한다. 무승부/강탈 OFF/잔액·보유 상한도 기존 규칙을 따른다.
- 기존 서버 공격자 패배 HP 차감은 유지하고, 결과창에 감소량과 양측 잔여 체력을 추가했다. 성공 영수증을 받으면 프로필부터 즉시 갱신한다.
- CMS 거지/갱단 특수 설정을 추가했다. 운영 모드 라디오의 `name` 누락으로 OFF와 ON이 동시에 체크되고 마지막 ON이 수집되는 문제를 재현했다. 같은 라디오 그룹으로 고치고 저장된 모드와 현재 선택 안내를 구분했다.
- 배포 전 기존 공개 프리뷰에도 구걸·동냥·100원 기부·갱단 처치 계산과 HP 결과를 연결했다. 프리뷰는 예시 계정만 사용한다. 새 이미지/DB 스키마/공통 인증/거래 기반/전투 엔진 변경은 없다.
