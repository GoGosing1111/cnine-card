## 변경

- 크라이베른 PVP 평타 확정 피해: **1.00 → 1.165배(+16.5%)**.
- 극빙 왕관 PVP 스킬 피해 상한: **1.3 → 1.6**. 한 행동의 40%/60% 분배, 최초 전열 최대 2명 지정, 첫 타격 회피 시 후속 파열 취소를 유지한다.
- 평타 보강은 한 번만 적용하며 이후 수호·가로채기가 그 예산을 나눈다. 새 난수·회피 재추첨·추가 행동을 만들지 않는다. 단일/듀오 소유자에 동일하게 적용한다.
- PVE, CMS 원배율 5.88·비용 35·재사용 5행동, 기본 능력치·등급·획득 확률·베르칸/라그니엘 수치는 그대로다. 특정 상대 코드·계정·최근 승패·목표 승률에 따른 런타임 보정은 없다.

## 검증과 배포 범위

크라이베른 PVP 피해 경로의 국소 변경으로 scoped 배포한다. 공통 인증·DB·거래·경제·의존성은 변경하지 않는다. 게임 UI·원화·모션은 변경하지 않았다.

- 개발 중 직접 관련 검사 15건 통과, 출시 전용 API 차단 검사 1건은 이미 출시된 상태라 기존 조건대로 제외됐다. 최종 1.165 계수는 배포 검사에서 다시 확인한다.
- 비용/쿨타임·표식/회피·왕관 분배·0피해/억제·보호/가로채기·PVE 경계·동일 입력 재현·듀오 소유자·다른 용병 격리를 검증한다.
- `npm run build:v3-grid`로 공용 소비자 10개를 갱신했다. 라이브 연출 실행 번들은 동일하고, 독립 전장 프리뷰의 서버 모형 번들 및 빌드/공유 소스 해시가 변경된다.
- 최종 배포에서는 JSON의 직접 관련 검사 6개 파일과 Worker 구문, 실제 번들/메인 로더, 출시 플래그·캐시·Hyperdrive를 확인한다. 대규모 모의전은 재실행하지 않는다.
- 직전 확인 운영 소스는 리치왕 주간 보상 배포 `a8c026bf81066fb7c0ca6a839af4e2815e34d883`, Pages `bbf288cc-8781-4551-955e-4316b60ce1d4`다. 이후 문서 기록은 보존하고 함께 반영한다.
