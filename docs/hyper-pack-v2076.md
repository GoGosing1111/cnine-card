# 하이퍼팩 준비 연결

사용자 요청 및 현재 준비/출시 경계, 아트 원본 해시, CMS/API 계약과 개봉 연출 검수 기록은 [`preview/hyper-pack-v1/README.md`](../preview/hyper-pack-v1/README.md)를 기준으로 한다.

- 프리미엄 카드팩 판매 종료, 나머지 팩을 한 칸씩 이동하고 하이퍼팩을 마지막에 추가.
- 첨부 원본 이미지 그대로 사용. 1회 5억, 최대 10회 50억.
- 꽝·마스터의 별·미스틱 에너지·용병카드 결과 연출 준비.
- 확률/재료 수량은 CMS에서 사용자 직접 설정. 기본값 미설정.
- 용병 등급/획득 승인 전 실제 개봉·재화 차감·지급은 잠금. 실제 지급 트랜잭션은 후속 연결 과제다.
- 프리미엄 큐브·기존 보유 카드·기존 지급 영수증 복구는 유지.
