# S 청아 PVP 조정 · 2026-09-18

> 후속 체급 지시에 따라 SS·SSS 상대 보정을 추가했다. 현재 적용 기준은 [S 청아 상위 등급 보정](mercenary-cheonga-tier-20260918.md)이며, 아래 수치는 첫 조정의 기록이다.

사용자 요청: S 청아의 과도한 성능과 SS 상대 우세를 점검하고 하향한다.

## 확인한 원인과 변경

운영 CMS revision 55를 읽기 전용으로 조회했다. 청아(V-005)는 S / MARKSMAN / MIDDLE이며 MS-005 탄착 교정의 설정은 피해 배율 4.2, 비용 25, 재사용 5행동이다.

지난 원거리 개선에서 준비 행동을 없애고 빗나감·표적 처치 후에도 후속탄을 이어가게 했다. 세 번의 행동에 걸친 피해 예산과 마지막 탄 40% 보너스는 유지되어, 높은 연사 지속 피해와 행동별 피해 상한을 함께 확보했다. 공격이 멈추는 결함은 아니며, 개선 후 PVP 화력이 과도하게 남은 경우다.

- **S 청아의 PVP 탄착 교정에만 피해량·타격별 피해 상한 70%를 적용한다.** 기존 대비 30% 하향이다.
- 현재 CMS 기준 각 탄의 공격력 배율은 `1.4 / 1.4 / 1.96 → 0.98 / 0.98 / 1.372`다. 최종 피해에는 기존 방어·회피·보호막·상한 계산이 적용된다.
- 초탄 즉시 발사, 이후 두 행동에서 한 발씩 발사, 표적 재지정, 마지막 탄 보너스, 비용 25, 재사용 5행동은 유지한다.
- 기본 공격·능력치·행동 간격·PVE는 변경하지 않는다. 다른 용병에게 MS-005를 배정한 경우나 다른 등급·다른 스킬에도 이 개별 하향을 적용하지 않는다.
- 도감·보유 용병·CMS는 같은 정책 함수로 적용 규칙을 표시한다. CMS 원본·등급·배정·개봉 확률·계정 데이터에는 쓰기 작업을 하지 않았다.

## 검증과 반영

- 현재 구현과 시뮬레이션 후보의 전투 반환값 8,448개가 일치했다.
- 검수 중 반영된 아포칼립스 업데이트 `e4ab286a` 위에 통합한 후에도 아래 25,152개 전투 반환값 비교를 재실행해 모두 일치했다. 아포칼립스·용병 CMS의 두 캐시 키를 함께 보존했다.
- 청아 외 43종 PVP 8,256개와 청아 포함 44종 일반/아포칼립스 PVE 8,448개는 변경 전후 전체 반환값이 일치했다.
- 회귀 검사는 실제 3연사 피해·상한·초탄 빗나감·비용 1회 차감·재사용·PVE·타 소유자·등급·무기·스킬 범위와 SS 9종 상대 성능을 확인한다. `tests/mercenary-ranged-balance.test.mjs`는 기존 `test:v3-joint` 및 `release:gate`에 포함된다.
- PC·모바일에서 도감 설명 및 실제 메인 앱 PVE/PVP 입장 → 청아 스킬 → 결과 → 복귀를 격리 계정 API로 검수한다. 운영 계정 재화는 사용하지 않는다.
- 깨끗한 범위 커밋에서 `npm run deploy:production`의 전체 출시 검사를 통과한 뒤 배포한다. 배포 후 운영 정책 버전·정적 파일·도감 표시를 다시 확인한다.
- 롤백은 이 범위 커밋을 되돌리고 같은 출시 검사와 배포 명령을 사용한다. DB 복구나 재화 역변경은 없다.

## 유저 공지 문안

S등급 청아의 PVP 성능을 조정했습니다. 탄착 교정의 각 탄 피해량과 최대 피해 상한이 기존 대비 30% 감소합니다. 즉시 사격과 3연사 방식, 마지막 탄 교정 보너스는 유지됩니다. 기본 공격, 스킬 소모 자원·재사용 대기, PVE 성능은 동일합니다.
