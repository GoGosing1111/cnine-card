## 지휘 통신

기존 서버는 양 진영 지휘관 메시지를 공통 상태에 포함했다. 이제 요청자의 최신 회차 참가 행에서 `status=ACTIVE`와 `side=A/B`를 확인하고 같은 진영의 메시지만 응답한다. 공유 캐시는 내부에서 유지하되 응답 배열을 별도로 만들어 다른 요청자의 정보가 섞이지 않게 했다.

전체 상태·신규 지도 폴링·전송 직후 상태·CMS 상태 모두 같은 필터를 사용한다. 관전자와 비활성 참가자는 빈 목록을 받으며 관리자 상태 조회도 진영 제한을 우회하지 않는다. 클라이언트도 자기 팀 메시지만 그리며 아군 지휘관과 ‘아군 전용’ 표시, 같은 진영에게 전송됐다는 안내를 제공한다.

SQLite·PostgreSQL에서 양 진영 연속 조회, 캐시 재사용, 폴링, 지휘관 전송, 다른 팀 조회, 관전자/관리자 조회, 소속 변경, 비활성화 후 차단을 실제 상태 함수로 검증했다. 신규 검사는 `tests/territory-team-command-20261011.test.mjs`이며 기존 영토전 검사 스크립트에 연결한다.
