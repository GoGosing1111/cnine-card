# 용병 장비 슬롯 디자인 개선 · 2026-10-12

사용자가 빈 무기 슬롯 이미지를 지정해 시각 개선을 요청했다. 장비실 전체 구조와 조작은 유지하고 다섯 부위의 슬롯 컴포넌트를 새로 만들었다.

- 단순한 팔각 판과 작은 선 아이콘을 얇은 금속 테두리·안쪽 홈·모서리 장식이 있는 장비 받침으로 교체했다. 부위명은 프레임 안에 넣었다.
- 무기·상의·하의·신발·장신구의 빈 상태에는 각각 새 금속 문양 SVG를 사용한다. 작은 툴바용 아이콘과 구분하며 외부 이미지나 폰트 의존성을 추가하지 않았다.
- 미장착 표기와 + 표시, 선택·포커스·드롭 강조, 눌렀을 때의 반응을 추가했다. 장착하면 실제 승인 장비 이미지와 강화 수치를 표시하며 해제하면 빈 문양으로 돌아온다.
- 화면 높이에 따라 슬롯 크기를 조정하고 세로 간격을 확보한다. 기존 장비·용병 원본, 저장 API, 장비 수치와 경제 정책은 변경하지 않았다. 공통 캐시 버전은 유지하고 독립 페이지 버전을 `20261012-armory5`로 올렸다.
