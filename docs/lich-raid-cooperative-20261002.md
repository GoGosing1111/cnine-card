# 리치왕 협동 V2 — 2026-10-02

사용자 후기에서 같은 역할의 동시 입력이 봉인 오답으로 처리되고, 정벌대 한 명의 버튼이 공대 전체 편성을 공격시켜 다른 정벌대원의 참여가 불필요한 문제를 확인했다. 사용자가 개편안의 구현·배포를 승인했다.

## 확정 동작

- **각자의 PvE 덱으로 입장하는 기존 동작은 유지한다.** 일반 카드 5장·용병·배틀슈트는 각 계정의 준비 시점 편성이다. 변경 대상은 공격 실행 주체와 기믹이다.
- 새로 창설한 공대에 `rulesVersion: 2`를 저장한다. 배포 이전 공대·진행 중 전투는 V1로 끝난다. 구형 클라이언트가 V2 명령을 보내면 입력 단계 식별자가 없어 갱신 안내로 차단된다. 현재 운영 모드·입장권·참여 명단·보상 잠금·고정 보스 전투력 설정은 변경하지 않는다.
- 최소 3명·최대 6명, 각 역할 한 명 이상, 공대장 입장권 1장 규칙을 유지한다. 역할별 인원에 맞춰 개인 과제를 배정한다. 출정 집결 12초, 전투 제한 300초, 4단계 7작전, 작전 사이 3초다.
- **봉인대:** 작전마다 각자의 3문양 봉인을 입력한다. 실제 순열을 섞으며 후반에는 역순이 포함된다. 첫 완성 이후 7초 안에 전원 완성해야 결계를 고정한다. 연결 실패는 개인 진행을 새 단계로 초기화하고 12% 광역 피해·잔재 1을 부여한다. 차단 담당은 작전마다 교대하며 말살 대응 시간은 5.5초다.
- **정벌대:** 봉인 전원 완료 후 각자의 문양 사슬을 파쇄한다. 1단계에는 바로 가능하며, 2단계부터는 감옥이 8초 뒤 절대영도를 흡수할 때까지 보존한 다음 6초 안에 모든 사슬을 수동 파쇄한다. 조기 파쇄는 잔재와 62% 절대영도 피해, 파쇄 방치는 전멸이다.
- **구출대:** 사슬 전부 파쇄 후 역병·영혼이 열린다. 역병 담당 한 명과 나머지 영혼 담당을 나누고, 혼자라면 둘 다 맡는다. 역병은 2~4중첩(2초 간격)에 전이, 영혼은 2초 채널링이다. 별도의 죽음의 저주를 지정 담당이 해당 문양으로 정화한다. 미정화 시 24% 광역 피해·잔재 1이 발생한다. 후반의 저주·말살 예고 순서는 작전별로 달라진다.
- **생존:** 매 방벽 붕괴에 전체 최대 HP 20%, 마지막은 28% 충격을 받는다. 회복은 공대 4회·생존 편성 HP 34%, 부활은 공대 1회·영혼 1개다. 일반 문양 오답은 12% 피해·잔재 1, 잔재 3은 전멸이다.
- **공격:** 방벽이 무너지면 모든 역할이 자신의 편성으로 공격한다. 각 계정 1.4초 간격·개인 결전 2회. 공격자의 실제 카드·용병·슈트만 피해 계산하며 반격 4.5%(잔재 추가분 포함)는 해당 계정 편성에 적용한다. 일반 공격 기회 11초, 마지막 12초다. 마지막에는 해방된 영혼 3개 이상이 필요하다.
- 현재 작전의 담당을 역할 변경으로 없앨 수 없다. 배분 변경은 다음 작전에 적용된다. 퇴장자의 미완료 과제는 남은 같은 역할이 인계하며 기존 마감 시각을 연장하지 않는다.

## 입력·전장 구현

- 서버가 소유자·과제·진행 단계를 포함한 입력 제어 정보를 반환한다. API는 입력마다 역할별 담당과 현재 단계 토큰을 검증한다. 완료된 단계의 늦은 재전송은 다음 문양으로 해석하지 않는다. 잘못 선택한 현재 문양만 실수로 처리한다.
- 기존 공대 CAS·사용자 잠금·요청 영수증·원자 트랜잭션을 재사용한다. 새 DB 스키마·마이그레이션·인증·공통 전투 계산 변경은 없다.
- `CoopOverlay.js`를 기존 라이브 V3 효과 계층에 추가했다. 개인 문양, 정/역순, 담당자, 감옥 사슬, 개별 마감 시각·입력 가능 상태, 공대 체력을 전장에서 표시한다. 기존 V3 진형·5장 카드 도크·원화/SD·배틀슈트 렌더러를 재사용한다.
- PC·모바일 버튼은 최소 44px이고 입력 처리 중에는 중복 조작을 막는다. 서버 응답을 즉시 적용하며 확인용 GET을 추가하지 않는다. 작전 타이머 갱신만으로 입력 버튼을 교체하지 않는다.
- 게임 안 역할 안내와 5장 공략 지침을 새 규칙으로 갱신하고 진입·HTML·CSS·JS·전투 번들 캐시를 `20261002-coop-v2`로 연결했다.
