# 랭크전 매칭 범위 완화 — 2026-10-07

사용자 요청: ‘균형 조건에 맞는 상대를 찾지 못했습니다’가 반복되어 상대를 더 쉽게 찾도록 완화한다.

## 원인과 변경

- 기존 운영 기준은 점수 차 250점, 대칭 전투력 차 20%를 동시에 만족해야 한다. 점수순 앞 96명의 편성만 검사하고, 직전 두 번 연속 만난 상대는 무조건 제외했다.
- CMS 기준은 그대로 1순위로 사용한다. 후보가 없으면 점수 범위를 +100점 / +250점, 전투력 범위를 +10%p / +20%p로 순서대로 확대한다. 현재 운영 기준으로 **250점·20% → 350점·30% → 500점·40%**다. CMS 전투력 범위 상한 100%를 넘지 않는다.
- 대칭 전투력 차는 `(큰 전투력 / 작은 전투력 - 1) × 100`이다. 40% 상한이면 큰 쪽이 작은 쪽의 최대 1.4배다. 점수 또는 전투력 한쪽만 무제한으로 푸는 경로는 없다.
- 후보 메타데이터는 최대 768명, 실제 편성은 96명씩 최대 8묶음으로 조회한다. 기본 범위의 최근 상대가 아닌 후보를 찾으면 즉시 멈춘다. 한 계정씩 조회하지 않고 기존 묶음 조회를 유지한다.
- 범위 내 다른 후보가 있으면 세 번째 연속 대전을 피한다. 유일한 적합 상대이면 재대전을 허용한다. 그 외에는 기본 범위, 최근 만나지 않은 상대, 가까운 점수·전투력 순으로 선택한다.
- 완화된 범위로 발급한 90초 매칭 티켓도 같은 범위로 재사용한다. 실제 전투의 현재 점수·편성 재검증, 중복 티켓/영수증, 행동력·점수·보상 원자 처리는 유지한다.
- OWNER·정지·비활성·자기 자신·유효하지 않은 방어 덱은 기존과 같이 후보에서 제외한다. 듀오 랭크전, CMS 저장값, 시즌·전투 결과·보상은 변경하지 않는다.
