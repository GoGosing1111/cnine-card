# 요일별 레이드 보스 V2140

## 운영 규칙

- KST 요일 기준으로 일요일 하시라마, 월요일 나가토, 화요일 오비토, 수요일 요리이치, 목요일 길가메시, 금요일 이치고, 토요일 마이트 가이를 배치한다.
- 기존 CMS의 개방 요일, 시간대, 입장 횟수, 입장 비용은 그대로 사용한다. 개방 시간에 입장 가능한 보스만 당일 보스로 교체한다.
- 기준 전투력은 580만~700만, 체력은 1억 8천만~2억 1천600만으로 아포칼립스 하시라마급 이상이다.
- 보스마다 쫄몹 2종을 둔다. 첫 쫄몹은 전투 시작, 두 번째 쫄몹은 보스 체력 55%에서 등장한다. 생존 중 파티 피해의 65%를 쫄몹이 받아 보스에 적용되는 피해를 차단한다.
- 보스 궁극기 발동, 쫄몹 체력, 피해 분배와 보상 판정은 서버가 확정한다. 클라이언트는 결과를 재계산하지 않는다.
- 참여·클리어·쫄몹·누적 피해·순위·희귀 드롭 보상은 방 생성 시 보스별 스냅샷으로 고정한다. 모든 보상 풀은 붕괴 코어(`CORE_RAID_ENTRY_TICKET`)를 포함하며 코인 단일 보상 상한은 100억이다.

## 렌더링과 성능

- 전투 화면은 기존 PROJECT V V3 진형과 카드 도크를 그대로 사용한다.
- 신규 SD는 768px WebP를 전투에 사용하고 PNG 원본은 제작 원본으로 보존한다.
- 궁극기는 승인 고정된 공용 PixiJS 8.20.0 `Sprite`의 텍스처를 GSAP 3.13.0 타임라인으로 교체해 재생한다. 신규 5종은 각각 서로 다른 12프레임 아틀라스이며 충돌 프레임은 7번이다. 하시라마와 마이트 가이는 승인된 기존 12프레임 아틀라스를 재사용한다.
- 궁극기 런타임과 현재 보스의 아틀라스만 발동 시 지연 로드한다. WebGL은 `low-power`, 해상도는 최대 1.5 DPR로 제한한다.
- 전투 상태 갱신은 기존 DOM을 패치하고 4회마다만 전체 동기화한다. 요일 로스터 DB 조회는 30초 공유 캐시와 단일 `IN` 조회를 사용한다.
- 이번 범위에는 신규 사운드를 넣지 않았다. 승인되지 않은 합성음이나 테스트 음원도 연결하지 않았다.

## 생성 자산

- 생성 방식: Codex 내장 ImageGen, SD는 `stylized-concept`, 궁극기는 투명 배경 4열×3행 연속 프레임 시트.
- SD 프롬프트 핵심: 성인 캐릭터 정체성을 유지한 3.5등신 고급 RPG 전투 SD, 전신, 투명 배경, 텍스트·UI·워터마크 없음.
- 나가토 수정 프롬프트 핵심: 뻗은 손만 수정하며 엄지 1개와 손가락 4개, 총 5개 손가락을 명확하게 구성하고 나머지는 보존.
- 궁극기 프롬프트 핵심: 준비·방출·충돌·소멸 형태가 실제로 변하는 정확히 12개 연속 프레임. 나가토는 보랏빛 중력 붕괴, 오비토는 청흑색 차원 절단, 요리이치는 적금색 태양 검격, 길가메시는 황금 보구 포화, 이치고는 흑적색 월아로 구분한다.
