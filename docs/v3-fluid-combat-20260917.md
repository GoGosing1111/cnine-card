# V3 전투 컷신 제거와 공통 결과창 · 2026-09-17

사용자 지시: PVE와 PVP 모두 카드 사진 컷신을 없애고, 발동 멘트가 전투를 멈추지 않도록 한다. 결과창은 운영 로비·용병도감·장비강화의 네이비 패널, 라임 강조, 한글 정보 위계를 따른다.

## 구현

- `SkillTimeline.js`의 카드 사진 패널, 전장 암전, 컷신 카메라 확대, 컷신 타격 정지를 제거했다. 기존 PixiJS 효과와 GSAP 이동·충돌·취소·피해 반영 시점은 유지한다.
- `BattleEngine.js`에서 라이브 초기 배치는 즉시 완료한다. 스킬·마법·회복·호송·궁극기 안내는 최대 대기 2건인 비차단 큐로 표시한다. 표시 크기는 320×46 CSS px 이하로 유지하며 모바일 상단 상태 표시와 떨어뜨린다.
- `battle-v3-live.js`의 레거시 궁극기 사진/영상 사전 재생을 제거한다. 서버 스킬명·행동·피해 이벤트는 그대로 전달하고 실제 조작이 필요한 QTE는 유지한다. V3에서 의미가 없어진 PVE 궁극기 스킵 체크박스를 숨긴다.
- 같은 `resultHtml()`을 PVE와 PVP에서 사용한다. 승패, 코인, 시즌 점수, 마력 수정, 카드/조각 보상을 표시하고 전투력·생존·체력/보호막·슈트 기여는 전투 상세에서 확인한다. 값은 정산 응답에서 읽으며 지급 처리는 변경하지 않는다.
- 결과 내부 스크롤과 복귀 버튼을 분리했다. 320px에서는 기존 하단 카드의 180px 원본 프레임을 0.3배로 균일 축소한다. 원화·SD·등급 프레임·배치 순서·진형·서버 계산·확률·보상 정책은 바꾸지 않는다.

## 버전과 검증

- 공통 래퍼 `3.37.0-fluid-combat`, 실제 엔진 `2126-fluid-combat`. 메인 기능 로더는 공통 래퍼의 준비 판정/자동 갱신을 계속 사용한다. 새 캐시 키를 루트 HTML·앱·공용 CSS·전투 브리지에 연결했다.
- `npm run build:v3`로 공통 엔진 소비자 9개를 재생성했다. 기존 잠금 파일의 PixiJS/GSAP 버전을 그대로 사용한다.
- `test:live-connections` 76개 통과. 실제 번들/메인 로더 버전 판정, 구버전 갱신, 이벤트 HP 순서, 멘트 비차단 큐, 취소 정리, 두 모드의 미디어 호출 0회, 승패/0·음수·대형 보상/HTML 이스케이프 회귀 검사를 포함한다.
- 로컬 격리 계정 API와 실제 메인 `index.html`을 사용해 로비 메뉴 → 토벌 시작/PVP 매칭 → 전투 → 결과 상세 → 복귀를 확인했다. 실계정과 재화를 사용하지 않았다. FUR·PRESTIGE·ZENITH 원본 카드 및 별도 하이희야 SD를 사용했다.
- 1440×1000, 390×844, 320×640, 800×450에서 전장·결과·스크롤·복귀를 확인했다. PVE ↔ PVP 전환과 재입장, PVE/PVP API 503 안내 및 복귀, 구버전 엔진 자동 교체를 확인했다.
- 배포는 최신 main 위의 범위 커밋과 깨끗한 작업 트리에서 `npm run deploy:production`만 사용한다. 이 명령이 전체 `release:gate`를 먼저 실행한다. 배포 후에는 운영 정적 파일과 격리 계정 API를 조합하여 같은 진입 경로를 다시 확인한다.
