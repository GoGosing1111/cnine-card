- 메시지 제목: `첫 2차 인증 기프트 박스`. 메시지를 수령하면 인벤토리에서 기존 박스를 개봉한다. 코인·카드·장비가 인증만으로 즉시 지급되지는 않는다.

- 가입 14일은 발송 자격이다. 발송 완료된 박스의 수령·개봉 기한은 없으며, 당시 인증 계정을 유지해야 한다. 기존 박스와 보상 구성(100억 코인, 슈퍼스타 +11, FUR·제니스 +13, 미스틱 장비 4종·소버린 SKS, 마법 +5)은 유지한다.
