# SS 후열 우선 피격 조정 — 2026-10-08

사용자 최종 지시는 “SS 후열이 SSS보다 유리한 역전을 줄이기”, “제대로 너프해라 아니면 후열 용병부터 공격받게 하던가”다. 행동 빈도나 피해량만 줄이는 안으로는 일부 SS 원거리의 군단토벌 우위가 충분히 줄지 않아 후열 보호를 직접 변경했다.

## 최종 동작

- 일반 SS 후열 원거리 11종과 간호사 4종은 새 PVE 전투에서 **적 몬스터의 기본 공격 최우선 대상**이다. 앞줄 일반 카드가 살아 있어도 해당 용병을 먼저 공격한다. 용병 사망 후에는 기존 진형 타깃 선택으로 복귀한다. 여러 대상이 있으면 기존 체력 비율 기준으로 선택한다.
- 추가 행동은 기존 하향대로 일반 카드 2회당 1회다. 간호사 PVE 회복은 공격력 120% 총예산, 대상별 최대 체력 1% 상한, 재사용 6 용병 행동·자원 25다.
- 3회·5회 행동 간격이나 피해 60% 적용안은 탐색에만 사용했으며 최종 정책에 넣지 않았다. 승패를 덮어쓰거나 강제로 실패시키지 않는다.
- 보스의 고유 스킬·봉인·저주·광역 패턴은 기존 타깃 규칙을 유지한다. 이번 변경은 몬스터 기본 공격 경로다. PVP·SS 전열·다른 등급·SS 리미티드·발테르와 출시 잠금은 유지한다.
- 새 스냅샷은 정책 V2를 저장한다. 기존 V1 전투는 후열 우선 피격 없이 10% 회복 상한을 유지하며, 정책이 없는 과거 기록도 소급 변경하지 않는다.
- 단일 정책은 shared/mercenary-ss-rear-pve-v1.mjs, 전투 적용은 functions/_battle_v2_preview.js다. 용병도감도 같은 정책에 맞춰 “적의 기본 공격 우선 대상”과 간호사 1% 상한을 표시한다.

대상 원거리: V-004 베스페라, V-009 련화, V-036 네레이아, V-037 아델린, V-040 마리엘, V-042 경찰 조은, V-043 동탄 디임, V-044 하이희야, V-045 망이사, V-047 비키니 조은, V-050 저격 오리꿍. 대상 간호사는 V-051~V-054다. 전투에서 BACK으로 배치되는 MIDDLE도 포함한다.

## 독립 난수 검증

운영 CMS 61에서 캡처한 고정 자료와 실제 서버 엔진으로 아포칼립스 보스 4종, 무한의탑 50·70·90·100층, 군단토벌 4난도 전체 15분을 비교했다. 각 시나리오에서 장비 3구간, FUR/ZENITH 일반 카드의 HP2·HP0 편성, 용병 레벨 1, 슈트·펫·마법 없음으로 고정했다. 간호사 4종은 전투 성능이 같아 V-051 하나를 대표로 계산했다.
