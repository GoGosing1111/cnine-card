## 운영 기준

- 적용 경계: `pig_coin_clan_round_release_v1`, 시즌 ID 5 / 전투 ID 64부터. CMS의 클랜전 ON 및 피그코인 보상 ON을 유지한다.
- 방어, 진행 중, 오류로 실패한 요청은 공격 참여에서 제외한다. 정상 완료한 패배 전투는 포함한다. 진행 누적과 실제 완료 전투 수 중 큰 값을 쓰되 둘을 더하지 않는다.
- 회차 종료 전 가입한 해당 시즌 클랜원을 대상으로 승리와 참여 조건을 독립적으로 계산한다. 챔피언스리그는 별도 보상 체계이므로 이번 정규 회차 지급에 포함하지 않는다.
- `clan_war_pig_coin_v1:<warId>`에 명단·조건·금액을 고정한다. 원장 `CLAN / WAR:<warId>`와 지갑은 한 거래로 적립한다. 동일 정산 및 응답 유실 재시도는 재지급하지 않는다.
- 정산 오류는 회차 완료 상태를 보존하고 다음 클랜전 상태 갱신에서 다시 처리한다. 적용 시즌은 기존 시즌 종료 피그코인 지급을 차단하여 중복 지급하지 않는다.

## 메시지 수령 버튼

- 사용자 문의 증상은 ‘보상 받기’ 버튼 누락이다. 운영 피그코인 메시지 59건 중 02:29 KST 기준 33건 정상 수령, 26건 미수령·표시 가능 상태. 숨겨진 미수령 보상 및 수령 영수증/원장 불일치는 0건이다.
- 피그코인 지원 배포 전의 클라이언트는 로컬 보상 종류 목록에 `PIG_COIN`이 없어 버튼을 만들지 않는다. 문의한 기기의 실제 열린 코드 버전은 접근할 수 없어 확인하지 못했다. 이미 열린 구버전 화면은 새로고침이 필요하다.
- 서버 메시지 응답에 검증된 보상 종류·이름·아이콘·지원 여부를 함께 제공한다. 클라이언트 목록에 없는 새 보상도 서버가 지원하는 경우 개별/일괄 수령 버튼에 표시한다. 서버 표시 문자열은 HTML 이스케이프한다. 실제 수령의 소유권·원자적 지급 검증은 유지한다.
- 모바일 실제 검수에서 기존 CSS의 `top:12px`와 개편 CSS의 `bottom:14px`가 삭제 버튼에 동시에 적용돼 353px 높이로 늘어난 오류를 발견했다. 수령 버튼 오른쪽의 실제 클릭 대상이 삭제 버튼이었다. `top:auto`로 초기화해 하단 44px 버튼으로 제한한다.
- 앱과 관련 CMS/상점 모듈 캐시 키만 갱신한다. 전투 엔진·SD·V3 버전은 변경하지 않는다.

## 검증

- SQLite 및 실제 PostgreSQL 호환 어댑터 + PGlite: 30/30 합산, 경계·대상 조건, 중복/동시/응답 유실, 원장·지갑 실패/상한 롤백, 실제 회차 완료 후 정산 실패와 재처리.
- 실제 메시지 표시 함수에서 로컬 PIG_COIN 항목을 제거해도 서버 메타데이터로 버튼이 표시되는 회귀 검사. 잘못된 보상·수령 완료 제외 및 문자열 이스케이프 검증.
- PC 개별 수령, 390px 모바일 개별/일괄 수령 및 클릭 영역을 브라우저에서 검사한다. 검수 계정과 API 응답은 로컬 합성 데이터이며 운영 사용자의 보상을 대신 수령하지 않는다.
- 배포 전 `npm run release:gate`, 배포는 `npm run deploy:production`을 사용한다.
