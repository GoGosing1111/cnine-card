# 마법카드 시즌2 전투 구현·연결 준비 — 2026-09-30

사용자 요청에 따라 이전 승인 원화 8종을 보존하고, 용병 대응 마법 2종을 추가해 **10종의 실제 전투 효과**와 시즌2 팩 리소스를 준비했다. 공개 프리뷰는 갱신하지만 실계정 지급·상점·개봉·편성·운영 전투는 활성화하지 않는다. 상태는 `CONNECTION_REVIEW_PENDING`, `runtimeEnabled=false`, `drawEnabled=false`다.

## 신규 용병 대응 2종

두 효과 모두 정화 가능하고 대상 용병 자신의 행동이 끝날 때 남은 횟수를 줄인다. 일반 카드·몬스터·보스·배틀슈트와 제어 면역 대상에는 붙이지 않는다. 지휘 단절 중에는 스킬 자원·쿨타임을 소비하지 않으며 용병의 독립 추가 행동 기회는 유지한다. 적 용병이 없는 PVE에서는 발동하지 않는다. 수치는 이번 구현 제안으로 최종 운영 확정값이 아니다.

- `functions/_mercenary_combat.js`: 실제 평타·공격 스킬·정화·회복·스킬 자원/쿨타임 판정에 연결한다.

- `functions/_magic_season2_catalog.js`: 비활성 카드 10종과 별도 S2 팩의 등록 초안 및 SQL 행 → 검수 편성 변환 함수. 실운영 `_magic.js`/API는 이 모듈을 가져오지 않는다.
- `preview/magic-card-season2-v1/registration-draft.json`: 위 등록 초안 출력. 가격·가중치·강화 비용/성공률은 미정 `null`. 기존 S1 풀·보유·강화·CMS는 변경하지 않는다.
