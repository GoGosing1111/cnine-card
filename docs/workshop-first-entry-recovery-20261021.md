# 제작소 최초 진입 오류 복구 — 2026-10-21

## 요청과 원인

제작소 첫 진입에서 “제작소 정보를 제시간에 받지 못했습니다. 다시 시도해 주세요.”가 먼저 표시되는 제보를 수정했다.

기존 제작소 읽기의 총 제한은 12초였다. 이 시간에 브라우저 공통 GET 대기열에서 기다린 시간, 서버 처리, 응답 본문 수신이 모두 포함됐다. 공통 대기열은 동시 6건이며 개별 요청의 제한은 대기열을 나온 후 시작한다. 따라서 앞선 요청이 밀리면 제작소 요청을 서버로 보내기도 전에 제작소의 별도 제한이 끝날 수 있었다.

운영 DB는 읽기 전용 거래로 확인했다. 일반 표본의 제작소 조회는 995ms, 장비 보유량이 많은 표본의 첫 조회는 7,746ms였다. 후자의 합성 조회가 6,842ms를 차지했으며, 동일 쿼리의 후속 실행 계획에서는 기존 인덱스와 레시피별 2,001개 상한이 적용되고 실행 43ms를 확인했다. 이 측정은 최초 조회·대기 시간이 기존 제한을 소진할 수 있다는 근거이며, 모든 계정의 동일 실패를 단정하지 않는다.

## 변경

- 제작소 정보 조회의 전체 제한을 30초로 조정했다. 대기열과 응답 본문까지 제한하며 무기한 대기하지 않는다.
- 개별 서버 응답 대기는 기존 12초로 유지하고, 시간 초과·네트워크 단절·429/502/503/504의 일시 실패에 한해 새 GET을 한 번 자동 재시도한다.
- 로그인/권한 오류와 점검 응답은 자동 재시도하지 않는다. 계정 변경, 재화 변경, 다른 화면으로 이동해 폐기된 조회도 자동 재시도하지 않는다.
- 같은 진입의 자산 로딩·즉시 재렌더는 하나의 조회와 복구 결과를 공유한다. 계속 실패하면 기존 오류·수동 재시도 기능을 제공한다.
- 제작/합성 POST, 재화, 확률, 한도, DB 구조와 서버 조회 SQL은 변경하지 않는다. UI 구조·이미지 변경 없이 로딩 제어만 수정했다.
- 메인 앱과 서비스워커의 배포 캐시를 함께 갱신한다.
