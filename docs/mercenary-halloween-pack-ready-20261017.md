# 할로윈팩 출시 준비 · 전용 UI · 2026-10-17

사용자 요청: 상점 이미지 공개/OFF, SSS 당첨 안에서 리미티드 확률을 추가 판정, SS·SSS 하이퍼팩 영상, 이전 리미티드처럼 빠른 일괄 결과. 적용 범위 답변은 **새 할로윈팩만**이다. 후속 요청은 **할로윈에 맞게 UI 전체 재제작**이다.

## 출시 상태와 확률

- 할로윈 7종 V-980~V-986은 승인된 SS 원화와 이름을 보존한다. 캐릭터별 서버 전체 5장이다.
- 상점 카탈로그에 할로윈팩과 승인 원화 7종을 노출한다. 판매·개봉 OFF이며 OWNER도 개봉할 수 없다. 기존 리미티드팩은 종료/OFF, 하이퍼팩은 기존 ON을 유지한다.
- 가격 1/10회, 첫 단계 C/B/A/S/SS/SSS/꽝, 두 번째 단계 할로윈 7종/일반 SSS 확률은 운영 미정/null이다. 수치를 임의 저장하지 않는다.
- 첫 단계 SSS만 두 번째 추첨에 진입한다. 두 번째에서 리미티드가 아니면 일반 SSS를 지급한다. 할로윈 당첨 카드의 실제 등급은 SS이며 진입 등급 SSS를 카드 등급으로 표시하지 않는다.
- CMS의 두 단계 합계는 각각 100%가 필요하며 준비 중 부분 입력을 허용한다. 실제 카드 확률은 첫 SSS 확률 × 내부 카드 확률이다. 예를 들어 1%와 2%는 0.02%다. 이 예시는 운영 설정이 아니다.
- 종전 V1 절대 확률 문서는 덮어쓰지 않는다. 읽기에서 새 V2 조건부 필드를 null로 제공하며 OWNER의 향후 저장 시 기존 원문을 감사 이력에 보존한다.

## 거래와 복구

별도 HALLOWEEN 요청 종류와 계정별 브라우저 보류 키를 사용한다. 모든 결과는 서버에서 한 번 추첨해 영수증 계획에 고정한다. 기존 runJointOperation과 코인·카드 거래 함수를 사용하며 새 DB 테이블·DDL·공통 인증 변경은 없다.

가격·확률·일반 용병 풀 버전, 코인 잔액, 5장 재고를 거래 시 다시 검증한다. 재고 청구·일련번호·카드·코인·완료 상태를 같이 저장한다. 두 이용자의 마지막 1장 경합과 10회 묶음 재고 부족은 부분 지급·차감 없이 처리한다. 재고 소진 확률을 다른 카드로 이전하거나 이미 정한 결과를 다시 뽑지 않는다.

클라이언트는 POST 전에 같은 요청 번호를 저장한다. 응답 유실은 기존 영수증 조회와 같은 요청 복구로 처리한다. 계정 변경, 중복 탭, 닫기, 영상 건너뛰기는 추가 구매를 시작하지 않는다. 공개 HTTP 경로의 releaseEnabled는 false 상수이며 요청/OWNER/쿼리로 우회할 수 없다.

## 할로윈 UI

최초 갈색 박스 시안은 사용자의 품질 지적에 따라 교체했다. 현재 화면은 ImageGen으로 제작한 달빛 저택·호박/촛불 배경, 호박 동장 주요 버튼, 박쥐 은장 보조 버튼과 투명 카드 프레임을 사용한다. 글자는 생성 이미지에 넣지 않고 Noto Sans KR/Barlow Condensed와 운영 공통 메뉴·정보 위계를 유지한다.

- 상점: 실제 리버스콜 팩을 저택 제단 위에 표시하고 OFF 상태와 승인 원화 7종을 함께 보여준다. 가격을 0코인으로 표시하지 않는다. 모바일 컬렉션은 가로 스크롤이다.
- 계약실: 실제 팩·원화·잔여 수량과 추첨 안내를 제공한다. OFF에서는 구매 버튼이 활성화되지 않는다.
- 구매 확인: 같은 할로윈 배경/이미지 버튼, 실제 수량·비용. 취소에 먼저 초점을 주고 배경을 inert로 전환한다. ESC는 확인을 취소하며 결제하지 않는다.
- 결과: 확정된 10장 DOM을 한 번에 삽입한다. 데스크톱 5열/모바일 3열로 이름과 번호를 표시하고 마지막 카드까지 스크롤할 수 있다. 영구 도감 프레임은 수정하지 않는다.
- 영상: 실제 결과 중 최고 등급 SS 또는 SSS 하나만 재생한다. 하이퍼팩의 기존 1280×720 원본을 재사용하고 소리는 기본 OFF다. 건너뛰기/일시정지/닫기/탭 비활성화를 처리한다. 영상 로드 전에 모든 결과가 표시된다.
- OWNER: 두 단계 확률·실효 확률·재고·저장 버튼도 같은 계열로 꾸미되 수치 입력의 가독성을 유지한다.

원본/런타임 WebP/전체 프롬프트/해시: assets/ui/packs/halloween-interface-20261017/manifest.json 및 prompts.json. 도구는 **built-in image_gen**이다. 생성 원본을 그대로 보존했고 실행용은 비율 유지 WebP로 출력했다. 배경·버튼 2개·프레임 런타임 합계 약 541KiB다. 새 디자인을 사용자 최종 시각 승인으로 기록하지 않는다.

시연: /preview/halloween-pack-interface-20261017/. 실제 계약실의 공통 마크업/CSS를 쓰고 계정 저장소·API·추첨·결제·지급은 전혀 호출하지 않는다. 화면에 시연을 명시하며 확인 버튼은 비활성이다.
