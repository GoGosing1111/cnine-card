# 용병 장비 조작 구조 개편 · 2026-10-12

사용자는 앞선 `armory3` 결과를 색 변경 수준으로 반려하고 모든 버튼·클릭 흐름의 재설계를 요청했다. 후속 지시는 숲켓몬 마크를 정확하게 넣는 것이다. 이번 `armory4`가 앞선 시각 결과를 대체한다.

## 화면과 실제 조작 변경

- 헤더는 라이브 로비 `js/adventure-lobby-v2107.js`의 동일한 SVG 마크와 **숲켓몬 / SOOPKETMON** 한글·영문 표기를 사용한다. 임의의 V 방패 문장을 제거했다. 로고와 로비 버튼 모두 `/?screen=home`으로 연결한다.
- 큰 제목·설명·버튼 줄을 쌓던 화면을 PC 화면 높이에 맞춘 장비실로 재구성했다. 왼쪽은 용병 원화와 팔각 슬롯, 오른쪽은 독립 스크롤 보관함과 하단 비교창이다. PC 장비 선택에는 모달을 사용하지 않는다.
- 슬롯 클릭 → 해당 부위 보유 장비 → 현재/선택 장비의 PVE·PVP 차이 → 교체·해제로 이어진다. 원화·슬롯·장비 목록·비교 결과를 동시에 보며 선택할 수 있다.
- PC 끌어놓기는 포인터를 따라가는 장비 이미지와 올바른 슬롯 강조를 제공한다. 드롭은 비교 후보만 선택하며 명시적인 장착 버튼을 눌러야 서버에 저장한다. 다른 부위로 드롭하면 안내하고 저장하지 않는다. 모바일 스크롤에는 끌어놓기를 적용하지 않는다.
- 지역은 이미지가 있는 펼침 메뉴, 정렬은 별도 메뉴, 검색은 열고 닫는 입력 줄로 바꿨다. 격자/목록 전환, 필터 전체 초기화, 장비 화살표·Home·End 탐색, Enter 선택, Escape 닫기를 제공한다.
- 모바일에서는 장비 보관함 바로가기와 하단 비교창을 사용한다. 하단 교체·닫기 버튼은 상세 효과를 스크롤해도 표시된다. 도감은 기본 수치를 표시하고 직접 장착을 제공하지 않는다. 보유한 동일 장비가 있으면 보유 장비 선택으로 연결한다.
- 뒤로가기는 비교 닫기 → 선택 조건 해제 → 이전 같은 사이트 화면 또는 직접 진입 시 로비 순서로 처리한다. 새로고침, 연결 실패·재시도, 빈 보관함·도감 진입도 새 구조로 연결했다.
- 실제 계정 조회·장비 저장 API, revision·영수증 ID·재시도 정책을 유지한다. PVE/PVP 저장, 장비 수치·획득·확률·강화 정책, 서버·DB·출시 플래그 변경은 없다. 기존 승인 용병/아이템 원화와 제작실 배경을 재사용한다.
