# 격전지(협동) — 심층 제련소 3단계

사용자 지시: 리치왕 복제를 제거하고 새 협동 전장을 제작한다. 월드 레이드 하위 탭에서 분리해 **PVE → 격전지(협동)**로 직접 입장한다. 일반 몬스터와 준보스를 포함해 단계별로 격파한다.

| 단계 | 적 | 전투 방식 |
| --- | --- | --- |
| 1 · 제련소 외곽 | 용철 추적자 2기, 불씨 감시기 1기 | 근접 공격과 원거리 연사 |
| 2 · 노심 관문 | 준보스 노심 수문장 | 최대 체력 30% 방벽, 연속 공격 |
| 3 · 심층 노심 | 최종 보스 삼핵 거신 아르케 | 삼핵 차단, 표적 엄폐·동료 교란 |

앞 단계의 적을 모두 격파한 뒤 다음 단계가 등장한다. 제한 시간은 세 단계 합계 180초다. 아군 체력·방벽·생존·스킬 자원을 초기화하지 않는다. 일반 카드 6장과 용병 3명의 소유자별 편성·스킬 연동 및 공용 V3 로스터를 유지한다.

최종 보스 등장 10초 후부터 30초 간격으로 특수 공격이 교대한다. 일반/격전/극한 입력 시간은 9/8/7초다. 모든 생존 분대가 차단하면 거신 최대 체력 8% 피해, 미완료 시 아군 전체 최대 체력 12/18/24% 피해다. 집중 포화는 표적 분대가 엄폐하면 기본 피해의 75% 감소, 동료 교란 한 명마다 추가 25% 감소한다. 판정·피해·중복 입력 처리는 서버에서만 확정한다.

## 리소스와 재생

원본·프롬프트·SHA-256·실제 크기·알파·PixiJS/GSAP 잠금 버전은 `assets/ui/cooperative-arke-v1/manifest.json`, `prompts.json`, `motion-prompts.json`에 보존한다. 아르케 원화와 전투 스프라이트는 별도 파일이다. 보스 타격 8프레임, 노심 파열 8프레임, 집중 포화 8프레임을 기존 V3 Pixi 효과 계층과 GSAP 시간축에서 재생한다. 단계 전환 시 이전 적의 진행 중인 연출을 취소하고 서버 개체 ID로 슬롯을 다시 연결한다. 과거 전투의 리치왕 스냅샷은 배포 중 재접속/이탈 정산을 위해 보존한다.

신규 시각 자산의 기술 확인과 사용자 최종 시각 승인은 구분한다. 이 변경은 기존 TEST 운영 범위이며 공개 설정·테스트 계정 명단·입장 재화·보상 정책을 변경하지 않는다.

## 출시 범위

협동 전장과 해당 조건의 공용 전투 분기만 변경한다. 공통 인증·DB 기반·마이그레이션·의존성 변경은 없으므로 scoped 배포를 사용한다. 관련 협동 회귀, 실제 V3 번들/로더, 공통 진형 및 기존 연속 증원 전투를 검증한다. 운영 직전 Pages의 실제 커밋을 기준으로 원격 main을 합친 뒤 `npm run deploy:production -- --scoped`를 사용한다.

### 최종 화면 검수

모바일 기믹 안내를 전투 캐릭터 아래·공용 도크 위로 이동했다. 적 교체 때 공용 진형의 이름표 높이를 다시 계산한다. 수정 후 `%TEMP%/cooperative-qa-QKPzpO/screenshots/report.json`에서 3인 전투·3단계·모바일 입력·새로고침·일반 PVE/PVP 전체 재생 PASS, JS 오류 0. 불씨 감시기의 제자리 2연사 및 아르케 8프레임 타격 중 취소는 `tests/cooperative-enemy-playback.browser.mjs`로 별도 확인했고 증빙은 `%TEMP%/cooperative-qa-edqRiI/enemy-playback/`다.

배포 기준은 Cloudflare Pages의 `f737b6d7-bda0-49e0-8761-b50538527f7c`, 소스 `39bc87bb`를 직접 조회해 확정했다. 이후 main의 금도끼 운영 완료 문서는 실행 코드 변경 없이 합친다. 선정 검사는 협동 3개 파일, V3 번들/로더, 공통 진형, 폐차장 서버 증원, 연속 사냥, 기존 레이드 및 PVE 메뉴 연결과 Worker 컴파일이다.

### 배포 검사 후속

첫 scoped 실행은 업로드 전에 정지했다. 새 협동 원본 2개를 추가한 빌드 명세에 맞춰 공통 진형 검사의 원본 수를 68→70으로 갱신하고 두 파일의 참여를 명시 검증한다. `pve-auxiliary-navigation-v2023`은 이미 삭제된 방치형 원정 스크립트를 요구하는 과거 검사였다. 직전 운영 `39bc87bb`의 index에도 요구 문자열이 없음을 읽기 전용 확인했으며, 이번 작업과 무관한 폐기 콘텐츠 검사를 고치거나 복구하지 않는다. 독립 PVE 진입은 실제 3개 브라우저에서 이미 검증했다. 통과한 서버·로더·증원 검사는 반복하지 않고 실패한 공통 빌드 명세 검사와 아직 실행하지 않은 컴파일/출시 보호만 재개한다.
