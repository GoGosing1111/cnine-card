# 족각도시 무기·개인 객실·병원 체류

## 승인 범위

퇴장 후 재입장해도 같은 6시간 교대의 직업을 유지한다. 현재 PVP 편성의 카드·용병을 사용하고, 도시에서만 계정 스펙을 공통 기준으로 맞춘 뒤 장착 무기로 편성 전체 전투력을 정한다.

사용자 승인 가격: 쇠파이프 2,000원 / 권총 8,000원 / 소총 20,000원. 전부 도시 현금으로 구매한다. CMS에서 가격과 전체 전투력, 무기 사용 여부를 조정한다. 맨손 100,000 / 쇠파이프 200,000 / 권총 300,000 / 소총 450,000은 조정 가능한 구현 기본값이며 별도 사용자 수치 승인으로 기록하지 않는다.

모텔은 개인 객실 15분, 퇴실 후 재이용 1시간. 병원은 최대 5분 후 임의 장소로 이동하며 의사·간호사는 예외. 경찰 최대 체력은 150이다.

## 구현

- 역할 시드/교대별 배정 비중을 그대로 유지한다. 퇴장·재입장 및 현재 교대 중 CMS 비중 변경으로 재추첨되지 않는다.
- 도시 보유 무기와 장착 상태를 기존 life JSON 안에서 TEST/ON별로 분리한다. 시장 구매에는 소유권 중복 검사, 현금 차감, 플레이어/life/정책 CAS, 행동 영수증을 같은 거래로 사용한다. 구매는 자동 장착하지 않으며 미니 인벤토리에서 한 개를 장착한다. 부활/재입장/교대에 보유품을 지우지 않는다.
- 도시 전용 팀 생성에서 전체 예산을 카드 5개(+용병 1개)에 나눈다. 계정 원본 값과 저장 편성을 수정하지 않는다. 장비·돌파·용병 성장/연계 스탯·마법·펫 버프는 도시 편성에 넣지 않는다. 카드 타입과 용병 고유 기술/위치, 서버 전투 엔진과 V3 연출을 유지한다. 무기가 공격 빈도까지 중복 증폭하지 않도록 속도 기준은 맨손 예산을 쓴다. 용병/유형 상성까지 같은 승률을 보장하는 정책은 아니다.
- 경찰 검문은 도시 전투력과 장착 무기를 표시한다. 상대 현금/미니 인벤토리 전체는 목록·방어 영수증에 공개하지 않는다.
- 모텔 입실은 무료, 자연 회복/포만감 규칙은 기존 기준을 사용한다. 객실 이용자는 다른 사람의 목록에서 숨기며 들어오는/나가는 대상 행동 모두 서버에서 거부한다. 아이템 사용/무기 장착/조기 퇴실은 가능하다. 종료 시 집으로 이동한다. 이른 퇴실/도시 퇴장도 그 시점부터 재이용 대기를 남긴다.
- 병원 입원 시각을 한 번 저장한다. 의사/간호사를 제외한 역할은 5분 후 병원·모텔 외 9개 장소 중 이동하며 사용자 ID+입원 시각의 안정적인 의사난수로 정해 새로고침으로 다시 뽑지 않는다. 퇴원 직후 5분은 낮은 건강으로 즉시 재이송되는 반복을 막는다. 사망자는 실제 부활 마감부터 5분을 계산해 늦은 접속으로 병원 체류를 연장하지 못한다.
- 자동 만료는 서버 조회/행동 시 투영하고 저장한다. 알림 조회도 본인 자동 상태를 반영하며 UI는 만료 시 갱신한다. 추가 스케줄러는 없다.
- 기존 지도/네이비·라임 스타일에 시장 무기상, 장착 프로필, 인벤토리, 모텔 건물/개인 객실과 병원 카운트다운을 추가한다. 지도 버튼을 누를 때 일반 버튼 active transform이 위치를 움직이던 문제도 바로잡았다.

## 검수

- 신규 서버/운영 회귀: SQLite/Postgres에서 역할 고정, 구매·장착·모드 분리, 부족액·중복 거부, CAS 전체 롤백/유실 응답 복구, 모텔 전후 보호/대기, 병원 타이머/의료진 예외/오프라인 부활, 경찰 체력 저장을 확인한다. 계정 스펙 1 vs 1조의 같은 무기 팀 스탯 일치 및 일반 PVP 원래 스펙 사용을 검증했다.
- 동일 카드 조합 64개 고정 난수·양 진영 검수에서 낮은 계정 스펙+쇠파이프가 높은 계정 스펙+맨손을 60회 이상 이긴다. 실제 플레이 승률을 의미하지 않는다.
- DB 작업 회귀는 0~100 CHECK→0~1000, 범위 밖 거부, dry run 전체 롤백, 실패 롤백, 1회 적용/재시도, TEST 모드/기존 정책/지갑 보존, 사망 경찰 비부활을 통과했다.
- 실제 도시 handler+격리 DB 브라우저 PC1440/모바일390 총 14항목 통과, 예외 0. 구입 확인·소유·장착·잔액·전투력·모텔 만료·병원 퇴원·의료진 상주·CMS 저장 확인. CMS 시험 가격 변경은 격리 DB에서만 수행했다.
- 별도 실제 V3 브라우저 PC/모바일 6항목 통과. 무기 보정 전투 재생, 도시 배경, 비모달 피격 알림, 결과 현금 및 복귀까지 확인. 전투 예시 계정으로만 검수했다.
- 스크린샷으로 PC/모바일 시장·인벤토리·모텔·병원/CMS와 모바일 실제 전투를 직접 확인했다. 근거는 `docs/qa/jokgak-city-expansion-20261010/`에 보존한다.
