## 사용자 확정
- 가격 49,800원, 코인 100조, 엠퍼러 에너지 200개, SSS 리미티드 조각 5개. 이전 50조 구성은 이번 지시로 변경한다.
- 구매는 기존 시즌패스 활성 이용자에게만 표시·허용한다. 기존 구매 신청·핑크빛유두 팝업·입금 확인 후 원자 지급 절차는 유지한다.
- 시즌패스 구매자에게 서버 안내 페이지의 구매 경로, 구성, 서버 개발 및 새 엔진 도입 목적, 구매 조건, 승부예측 불가를 게임 메시지로 발송한다.
- 이번 안내만 눌러 읽음 처리하면 서버에서 삭제한다. 다른 메시지와 보상 메시지는 유지한다.

## 적용
- 기존 coin_logs 및 app_meta의 support_package_coin_v1:<userId>로 패키지 잔액을 추적한다. 공통 DB 스키마·인증·DB 어댑터 변경은 없다.
- 일반 콘텐츠 소비는 패키지 코인을 먼저 사용한다. 새로 획득한 일반 코인은 베팅 가능하다. 승부예측 차감은 제한 잔액을 줄이지 않는다.
- 경매 입찰에서 사용한 패키지 코인은 예약 원장을 유지하고 유찰·차순위·운영자 무효 환급 때 제한 잔액으로 복원한다.
- 패키지 지급 및 베팅은 사용자 잠금과 동일 거래의 행 잠금, 잔액·로그 커서·원장 버전 비교를 적용한다. 기록이 바뀌면 전체 롤백하고 같은 요청으로 재확인한다. OWNER도 패키지 코인 베팅은 불가하다.
- 승부예측 API와 최대 금액 버튼은 패키지 제외 잔액을 사용하고 PC·모바일에 제외 금액을 표시한다. 새로운 이용 규정 버전을 적용한다.
- 공지 캠페인 support_package_launch_notice_20261020_v1. 영구 운영 영수증 ops:support-package-notice:20261020:v1을 메시지와 함께 저장하여 읽고 삭제한 뒤 재실행해도 재발송하지 않는다. 실제 수신자와 발송 시각은 배포 후 운영 영수증에 기록한다.
- 이전 배포에서 지급한 50조 내역이 있으면 실제 지급 로그로 복원한다. 2026-10-20 11:41 KST 운영 사전 조회: 구매·지급 0건, 기존 구매자 96명. 배포 전에 다시 확인한다.
