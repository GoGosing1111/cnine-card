# 리치왕 정벌 초보 공략 지침 — 2026-10-01

사용자가 기존 공략은 첫 참가자가 이해하기 어렵다며 상세한 지침을 요청했다. 실제 게임 안의 공략 대화상자를 입장·역할·단계별 순서·공용 자원·패배 조건의 다섯 장으로 다시 작성했다.

## 내용과 화면

- `functions/_raid_lich_king.js`, `_raid_lich_live.js`와 `MechanicOverlay.js`의 현재 규칙·버튼 이름을 대조했다. 공대 창설/참가, 세 역할 배분, 개인별 PvE 편성 스냅샷, 준비/출정, 12초 집결과 210초 제한을 순서대로 설명한다.
- 정벌대는 감옥 유지 후 집중 공격, 봉인대는 영혼 말살 차단과 봉인 순서, 구출대는 같은 문양의 역병 전이·영혼 구출·회복을 수행한다. 버튼 이름, 활성화 조건과 누르면 안 되는 행동을 구체적으로 적었다. ‘감옥 처리’라는 대기실 문구도 ‘6초 유지’로 명확히 했다.
- 네 단계·일곱 작전의 HP 목표와 상대 시간(2초 전이 / 6초 감옥 흡수 / 7·10초 말살 시작)을 안내한다. 3단계 초반에 영혼을 두 번 구출하는 순서, 공격 기회가 열리기 전 완료 조건과 마지막 영혼 3개 확보를 설명한다.
- 역병과 영혼의 문양이 다를 수 있음을 왕관 구울 예시로 설명하며, 봉인 순서와 영혼 계산에도 예시를 넣었다. 차단·결전·회복·정화·방벽·부활은 개인 횟수가 아닌 공대 전체 공용 자원이라고 명시한다.
- 잘못된 문양·봉인 순서, 감옥 조기 파괴, 역병 5중첩, 말살 5초 초과, 잔재 3중첩, 기믹/공격/광폭화 제한과 전 카드 전투 불능을 안내한다. 새로고침을 즉시 패배라고 허위 안내하지 않고 현재 서버에서 시간이 계속 흐르는 사실과 실제 나가기 동작을 설명한다.
- PC는 고정 목차와 본문 스크롤, 모바일은 다섯 목차가 모두 보이는 상단 탐색을 사용한다. 닫기는 고정 44px 이상이고 Escape와 원래 버튼으로의 초점 복귀를 유지한다. 기존 한글/숫자 서체를 재사용한다.
- 전투 중 공략을 열면 현재 자신의 역할로 바로 이동한다. 공략을 열어도 시간이 흐르는 안내와 역할 표시가 현재 상태에 맞춰 갱신된다. 목차/본문 조작은 전투 명령을 보내지 않는다.
- 독립 화면은 `guide.css`, 게임 안 화면은 같은 소스를 `build-inline.mjs`로 생성한 `inline.css`를 사용한다. 관련 UI 캐시는 `20261001-guide-v2`로 갱신했다.
