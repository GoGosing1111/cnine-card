## 승인 원본과 연결

- 승인 보드: `assets/ui/project-v/battle-hud-b-v1/approved-concept.png`, SHA-256 `a66881f1f1cb5522a0ee4b881b8e745cc51b60e82a373ffd9583e64bc70d3295`.
- 내장 ImageGen으로 글자/체력색을 분리한 투명 프레임과 중립색 체력 질감을 제작했다. `originals/`에 생성 PNG를 바이트 그대로 보존하고 투명 여백 정리·비율 유지 축소 후 무손실 WebP로 연결했다. 프롬프트·원본/런타임 해시는 같은 폴더의 `manifest.json`에 있다.
- `BattleHud.js`가 공통 V3의 이미지 프레임·실시간 이름·HP·보호막·짧은 피해 잔량을 담당한다. 진영 표시는 생성된 프레임의 흰 표시등 영역만 청색/적색으로 착색한다. 실제 진행률 마스크 외 장식을 CSS/Graphics 도형으로 대체하지 않는다.
- PC 논리 크기는 240×52, 모바일은 300×70이다. 전장 축소를 적용한 PC 1440×960 화면에서 **108×23.4px**, 모바일 390×844 PVP에서 **60×14px**, PVE에서 **66×15.4px**로 확인했다. 이름 길이·체력·보호막 변화가 프레임 폭을 늘리지 않는다.
- 실제 폰트 폭으로 이름을 맞추며 긴 이름만 말줄임한다. 원래 전체 이름은 actor와 HUD 데이터에 보존한다. 상대 이름은 캐릭터 좌우 반전과 분리한다.
- 보호막은 HP 아래 청색 줄이며 0이면 숨긴다. HP 0/회복/부활의 기존 상태 전이를 유지한다. 피해 잔량은 짧게 감소하며 동작 줄이기에서는 즉시 반영하고 파괴 시 타임라인을 해제한다.
- 공통 V3 소비자 10종, 몬스터 디펜스 및 로그라이크 프리뷰를 재빌드한다. 디펜스 일반 몬스터는 기존 이름 생략 정책을 유지하고 프레임의 아래 체력 부분만 표시한다. 새 V3 용병 외형·아우라·스킬·보호막 스냅샷 변경을 보존했다.
- 룬 발판·ICON/SSS/SSS 리미티드 구분·펫 20% 축소·서버 판정·획득·경제·OFF/TEST 설정은 변경하지 않는다.
