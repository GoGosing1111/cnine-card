# 천룡검황 진무 · 지정 계정 전용 라이브 연결

사용자 지시: 천룡검황 진무, SSS 리미티드, 일반 이용자 습득 불가, 핑크빛유두에게만 지급,
리미티드 수량에서 제외, 라이브 연결. 성능은 모든 용병 중 최상위이며 공격속도는 동일,
기존 최상위보다 15% 이상 강하게 지정했다. 본 구현은 헬리오스의 최신 공격 상향까지 포함해 20% 우위를 적용한다.

## 구현

- 운영 코드 V-989, 이름 천룡검황 진무. 기존 프리뷰 V-993은 오리꿍과 충돌하므로 운영에 사용하지 않는다.
- 단일 정책: shared/mercenary-jinmu-v1.mjs. 기본 전투력 1,347,840, 최신 헬리오스 대비
  기본·연계 공격력, 체력, 전용 방벽 +20%. 장비가 강하거나 일반 카드가 약해도 이 차이를 유지한다.
  자연 속도, 일반 카드 25행동당 추가 78행동, 모션 계수 2.6은 헬리오스와 같다.
- PVE 천룡강림: 전체 적 대상 총 560%, 에너지 35, 재사용 5행동. 여러 용·검기·충격파는
  대상별 서버 피해 영수증을 한 번씩 표시한다. PVP는 기본 공격 정책을 따른다.
- 금룡일섬·용린보와 세 번째 기본 공격의 용령파 변주, PVE 천룡강림, 상시 용혼 아우라를
  기존 V3 PixiJS/GSAP 전장에 연결한다. 용령파 변주는 추가 피해/행동/에너지 판정이 없다.
  아우라 PNG는 alpha=1 직접 프레임 교체이며 화면 전체 안개·화이트 플래시·딤을 추가하지 않는다.
- 동일한 원화 V2와 124프레임 자산을 재생성·재압축하지 않는다. 머릿결 규칙과 원본 해시는 유지한다.
  일반 카드 5장과 별도 용병 슬롯, 서버 HP·방벽, 기존 공통 카메라/대상 피격 제어를 유지한다.
- 계정 ID 1만 보유/편성을 허용한다. 다른 계정은 비정상 보유 행이 있어도 조회·편성·단건/일괄 전투 연결에서 차단한다.
  핑크빛유두의 내 용병에만 전용 항목을 합치며 공개 용병·리미티드 팩·일반 합성 풀에 추가하지 않는다.
  공개 LIMITED 카탈로그는 9종 그대로, LIMITED 수량 표시에 포함하지 않는다.
- scripts/ops/jinmu-owner-grant-20261012.mjs는 ID·닉네임·역할·활성 상태를 검증해 정확히 1장 지급한다.
  카드·획득 영수증·관리 로그·중복 방지 키를 하나의 거래로 저장한다.
  리미티드 stock/issues·팩 설정·코인·기존 편성에는 쓰기하지 않는다.
