# 조직 후속 개발 · 내 조직 명부와 현재 아지트 — 2026-10-15

사용자 “라이브 반영하고 다음 조직 개발할거 작업시작해”에 따라 입단 UI를 먼저 공개하고, 다음 작업으로 배정 이후의 조직원 명부와 아지트 현황을 연결했다.

## 구현 범위

- 실제 소속 행에서 조직을 결정하고 같은 회차·같은 조직의 명부 최대 10명만 읽는다. 요청의 organizationId나 userId로 다른 조직의 명부를 고를 수 없다.
- 명부는 닉네임·슬롯·입단 시각·본인 표시만 사용한다. 동료의 설문·희망 조직·평가 전력은 반환하지 않는다. 미배정자는 빈 명부이며 TEST 접근 권한을 잃으면 조회도 차단된다.
- UI는 10칸의 명부, 본인 강조, 빈 자리, 실제 조직 점수와 현재 아지트를 표시한다. 긴 닉네임은 두 줄과 전체 제목 속성으로 보존하고 HTML을 이스케이프한다.
- 현재 아지트는 organization_progress_v1에 저장된 stage를 따른다. 설정이나 누적 점수만 읽고 자동 승급하지 않는다. 점수 소모형에서 잔액이 줄어도 이미 저장된 단계가 초기화되지 않는다.
- 누적 방식과 다음 기준이 설정돼 있을 때만 현재 점수·다음 기준·남은 점수와 진행 막대를 표시한다. 기준 미정은 미정, 기준 도달은 반영 대기, 5단계는 최종 단계로 표시한다.
- 현재 거점과 성장 미리보기의 표식을 구분하고 “현재 아지트로 돌아가기”를 제공한다. 단계 미리보기를 눌러도 실제 소속·점수·단계에 쓰기 요청이 발생하지 않는다.
- 기존 imagegen 황동·강철 자산을 명부와 버튼에 사용한다. 아지트 활성화 상태가 이미지 위치/크기를 초기화하던 CSS 우선순위를 수정했다. 기존 아지트 원본은 보존하고 화면 표시 영역에서 구상도 화살표를 제외했다.

## 공개 및 검수

이 단계는 **새 조직 기능의 준비 코드·격리 TEST**다. 공개 /organization/은 계속 미리보기이며 조직 운영 API를 호출하지 않는다. 실제 모집·가입·점수 지급·성장 실행·콘텐츠 해금은 OFF이고 새로운 운영 DB 설치를 하지 않았다. 공개 화면에는 가상 조직원이 나타나지 않는다.

실제 사용자 신청이나 운영 점수를 만든 검수가 아니다. tests/organization-headquarters-20261015.test.mjs는 PGlite의 가상 배정으로 명부 조회 범위·설정 변경과 단계 보존·PC 1440/모바일 390 표시·XSS 이스케이프·현재 단계 복귀·점수 무변경을 검사한다. 조직 기존 회귀와 공개 화면을 포함한 관련 검사 16개가 통과했다. 이후 버튼 보정은 관련 브라우저 경로를 다시 검사한다.

증빙: preview/organization-system-v1/qa/headquarters/. 같은 폴더의 기존 입단 검수 캡처와 혼동하지 않는다.

로컬에서 배정 이후 화면을 확인하려면 node scripts/serve-organization-preview.mjs --assigned로 실행한다. 기본 실행은 기존 입단 심사 검수다. 두 모드 모두 localhost와 가상 계정만 사용하며 실제 운영 데이터에 연결하지 않는다.

점령 지역 구현·정산 영수증·성장 실행은 이후 개발 대상이다. 지역당 점수, 정산 간격, 성장 기준과 보상을 임의 확정하지 않는다.
