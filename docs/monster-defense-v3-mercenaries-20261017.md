# 몬스터 디펜스 V3 용병 연결 — 2026-10-17

사용자는 디펜스에서 캐릭터 크기가 V3와 다르고, 특히 용병의 아우라·이펙트·고유 스킬이 없는 문제를 지적했다.

## 원인

디펜스가 V3 엔진을 상속했지만 별도 캐릭터 생성 함수에서 아군의 전체 PNG 높이를 일괄 245로 설정했다. 용병마다 다른 투명 여백·실제 몸 높이·발 기준점과 전용 대기 어댑터를 사용하지 않았다. 보유 편성 API도 이름·SD·디펜스 공통 역할만 전달하고 실제 용병 스킬 배정을 제외했다. 서버에는 공통 역할의 기본 행동과 수동 전술만 있었고 클라이언트도 공통 공격 상태만 재생했다.

## 변경

- 기존 V3의 승인 아트 어댑터·표시 높이·발 기준점·무기 방출점과 전용 대기 연출을 사용한다. 투명 PNG 전체 높이와 실제 몸 높이를 구분한다. 일반 카드의 기존 V3 외형 배율도 전달한다. 승인 이미지를 재생성하거나 변경하지 않는다.
- 용병마다 가벼운 독립 재생 상태와 이펙트 레이어를 두어 여러 용병의 시전이 서로 취소되지 않게 한다. PixiJS 8.20.0 렌더러는 하나이며 기존 GSAP 3.13.0과 승인된 V3 스킬 재생 코드를 사용한다. 연속 타격 사건은 제한된 큐로 보존하고, 늦은 평타가 무한히 쌓이지 않게 한다.
- 서버의 실제 소유권·출전 가능·스킬 배정 검증을 통과한 고유 기술을 방 생성/편성 시 저장한다. 기존 `mercenaryCombat` 판정기를 디펜스의 정규화된 HP·공격력에 연결하여 자동 시전, 피해·회복·보호막·연타·상태 효과를 처리한다. 같은 방어선의 아군과 기본 사거리+300 안의 적을 대상으로 한다. 계정 전투력·장비·PVP 성능을 가져오지 않는다.
- 기존 행동 간격에 따라 기술 행동을 진행하고 스킬별 에너지·행동 횟수 기준 쿨다운을 보존한다. 일반 회복 행동도 에너지 회복 경로에 연결한다. 이동 중 유닛은 대상에서 제외한다. 진입 억제는 기존 게이지 감소 비율을 적의 1.4초 행동 주기 기준 이동/공격 지연으로 환산하며 보스 면역을 유지한다.
- 일반 피해·스킬 피해·보스 광역 피해가 실제 보호막을 소모한다. 피해 영수증과 처치 집계는 한 번만 반영한다. 내부 Map/Set과 수호 대상 참조를 ID 기반 JSON으로 저장해 Durable Object 재시작 후 에너지·쿨다운·연속 기술·보호 상태가 초기화되지 않는다. 내부 상태표는 공개 응답에서 제외한다.
- HP/보호막 표시는 최신 서버 스냅샷만 따른다. 지연된 V3 재생 콜백이 HP를 과거 값으로 되돌리거나 피해를 추가 적용하지 않는다. 피해/회복 수치는 디펜스 좌표계에서 한 번 표시한다. 지원 전송·다른 전선 보기·숨김·사망·종료 시 시전과 대기열을 정리하고 다시 보일 때 아우라를 재개한다.
- 베스페라를 회복형으로 강제 지정하던 오래된 테스트 역할 덮어쓰기를 실제 저격 역할로 수정한다. 수동 전술은 별도로 유지하고 편성 상세에 배정된 자동 스킬을 안내한다. PC의 공세 안내 패널은 첫 전선의 용병 머리를 가리지 않는 오른쪽으로 옮긴다.
- 최신 main의 이미지 바닥 문양을 함께 유지한다. 보유 로스터의 실제 등급·리미티드 분류를 연출에 전달해 일반 SSS/SSS 리미티드 문양을 구분한다. 기본 리미티드 목록 밖에 있는 시라누이·진무 등도 계정 API의 실제 분류를 따른다.

## 호환과 운영 상태

새 보유 편성 방에만 `mercenarySkillRevision:1`을 기록한다. 필드가 없는 기존 진행 방은 이전 전투 판정을 유지한다. 적용 후 새 대기방에서 시작해야 자동 고유 스킬을 사용할 수 있다. 기존 진행/보상 영수증을 삭제하거나 강제 종료하지 않는다.

기존 정규 V3 전투 생성 함수는 변경하지 않고 디펜스가 호출할 승인 리소스 준비 함수만 공개했다. 일반 PVE/PVP의 스킬 판정과 기존 배포 번들을 교체하는 작업이 아니다. 운영 디펜스 OFF, 지정 계정, 계정 보상 OFF를 유지한다. 확률·가격·획득·팩·ADMIN·계정 지급 변경은 없다.

## 검수

- 실제 격리 서버 보유 로스터의 21종을 두 명씩 편성하여 각 용병의 실제 배정 스킬 시전, 유한한 HP/피해/회복, 매초 JSON 복원, 재접속 후 동일 결과를 검사했다. 같은 전선/사거리 밖 타격 차단, 이전 방 호환, 보호막의 평타·보스 광역 흡수와 저장 복원, 억제의 이동 지연·보스 면역도 검사한다.
- 실제 격리 서버 `/defense/`를 Chrome에서 실행했다. 발테르·시라누이, 베르칸·크라이베른, 진무·헬리오스, 베스페라·디임간호사의 PC 1440×1000/모바일 390×844 대기·평타·스킬·아우라를 확인했다. 단일 캔버스, 실패 자산/브라우저 오류 0, 지원 전송 시 시전 정리, 재접속, 종료 시 타임라인/대기열 정리를 확인했다.
- 진행 속도·전술·기존 성장 정산·원거리 정체·V3 진입 및 크라이베른 배율 회귀는 관련 검사로 한정한다. 이전 저장 방 검사에서 새 스킬로 적이 첫 폴링 안에 처치되는 차이를 확인하고 해당 검수 데이터에 이전 방의 버전 상태를 명시했다. 새 방의 스킬은 별도 실제 피해 검사로 유지했다.
- 화면과 검사 보고서는 `docs/qa/monster-defense-v3-mercenaries-20261017/`에 보존한다. 기술 검수를 사용자 시각 승인으로 기록하지 않는다.
- 최신 바닥 문양 통합 뒤 8종 화면 검수를 통과했고, 등급·리미티드 메타데이터 전달 수정 뒤 발테르·시라누이/베르칸·크라이베른 4종의 실제 문양 분류, PC·모바일 화면과 이동/재접속/종료를 추가 확인했다. 브라우저 오류·실패 자산은 0이다.
- 배포 전 읽기 전용 운영 확인: `mode:OFF`, 설정 revision 9, 지정 계정 5명, 계정 보상 false. 별도 설정 변경을 하지 않는다.
