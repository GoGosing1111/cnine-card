# 몬스터 디펜스 ON · 난이도별 클리어 보상

사용자 `몬스터 디펜스 ON으로 돌릴수있게 해놓고 난이도별로 클리어 보상 지급할수있게해`, 후속 `CMS에서 직접 설정`을 반영한다. 기존 TEST 전용·계정 보상 불가 제한을 이번 요청 범위에서 해제한다. 배포가 운영 설정을 저장하거나 자동 ON으로 전환하지 않는다.

## 운영 방법

OWNER CMS → **디펜스**에서 운영 상태를 OFF / TEST / ON으로 선택한다. 입문·보통·어려움·악몽·재앙에 각각 코인, 마스터의 별, 활성 인벤토리 아이템 종류와 수량을 입력하고 `실전 클리어 보상 지급`을 체크하여 저장한다. 신규 보상 기본값은 0·아이템 없음·지급 중지다. 사용 중인 난이도 중 적어도 하나에 실제 보상을 입력해야 지급을 켤 수 있다. 아이템은 난이도마다 중복 없이 최대 20종이다.

- ON은 로그인 계정에 공개한다. TEST는 기존 OWNER/지정 계정 정책을 유지한다. OFF는 입장을 중지한다.
- ON 실전의 마지막 웨이브 승리 때 참가자 전원에게 각자 해당 난이도 보상을 한 번 지급한다. 횟수 제한이나 입장 비용을 임의 추가하지 않는다.
- TEST, 혼자 연습, 패배는 계정 재화를 지급하지 않는다. 기존 TEST 방에 보상을 소급 적용하지 않는다.
- 보상 수량은 방 생성 시 확정한다. CMS 수량 수정은 새 방부터 반영한다. 운영 상태를 ON 이외로 변경하거나 보상 체크를 해제하면 미정산 지급도 중지한다. 이미 지급한 보상은 회수하지 않는다.
- TEST 방과 ON 방 목록은 별도 이름 공간을 사용하며 다른 모드의 방에 신규 참가할 수 없다. 기존 참가자의 진행/재접속은 기존 방 정책을 유지한다.
- 대기실에서 선택한 난이도의 보상을 확인할 수 있다. 결과창은 지급 완료·정산 대기·연습/TEST 제외·지급 비활성을 실제 서버 응답에 맞춰 표시한다.

## 지급 보호

`monster_defense_reward_receipt_v1:<roomId>`에 방 생성 요청, 생성/시작/종료 시각, 난이도, 설정 revision과 참가자별 결과를 저장한다. 서버 방의 실제 시작·최종 웨이브·생존 수호석·실제 참가자 목록을 검증하며 클라이언트가 보상이나 승패를 지정할 수 없다.

영수증, 전원 코인/인벤토리와 지급 로그를 기존 DB batch 한 거래로 저장한다. 설정 CAS, 유효 아이템, 대상 계정과 안전 정수 한도를 검사한다. 중간 지급 오류는 전체 롤백하며 DB 저장 후 DO 응답이 유실돼도 같은 영수증을 읽는다. 참조 유형은 `MONSTER_DEFENSE_CLEAR`다. 공통 인증, DB 스키마, 의존성, 기존 협동전 지급 로직은 변경하지 않는다.

서버 알람은 접속 종료 뒤에도 지급을 처리한다. 지급 실패 시 15초부터 최대 5분 간격으로 재시도하며 미정산 승리 방은 2시간 수명 종료 뒤에도 보존한다. 승리를 만료 패배로 덮어쓰지 않는다. 정상 지급한 만료 방은 기존 정리 경로를 사용한다.

## 화면과 검사

몬스터 디펜스의 기존 전용 ImageGen guardian-panel, squad-nameplate, ready-command-button을 사용한다. 다른 콘텐츠 원화를 바꾸거나 새 장식을 추가 생성하지 않는다. 원본·프롬프트·해시는 기존 ui-v5/lobby-v4 색인을 유지한다. 이번 화면 검사는 사용자 시각 최종 승인으로 기록하지 않는다.

- `tests/monster-defense-rewards-20261020.test.mjs`: SQLite/PostgreSQL(PGlite) 난이도 5종·3인 지급·동결 수량·OFF·TEST/연습/패배 제외·동시/중복 요청·계정/아이템/잔액 오류 전체 롤백, 6개.
- `tests/monster-defense-rewards-live-20261020.test.mjs`: 실제 DO/API의 일반 계정 ON, 모드별 목록, 서버 START/최종 웨이브, 오프라인 지급, 응답 유실 재시도, 만료 후 실패 보존/재시도, 2개.
- 직접 영향 회귀: 기존 `monster-defense-live.test.mjs` 2개, `monster-defense-rooms.test.mjs` 3개. 공유 DO 런타임 연결 확인으로 `cooperative-websocket.test.mjs` 1개를 지정 배포에 포함한다.
- `tests/monster-defense-rewards-20261020.browser.mjs`: 격리된 실제 API/DO와 PC 1440×1000·모바일 390×844에서 CMS 저장/재조회/아이템 삭제, 일반 계정 입장, 난이도 보상, 실제 클리어 결과와 새로고침, 연습 제외를 검사한다. 운영 계정 쓰기 0. 증빙은 `docs/qa/monster-defense-rewards-20261020/`다. 모바일 보상 수치가 프레임 장식에 닿지 않도록 좌우 여백을 확보했다.
- `check:worker`, 최종 전투 번들 빌드. 공통 전투 모션/이펙트/밸런스/용병도감 배치는 변경하지 않는다.
