# 재료 제작 마스터의 별 비용 상한 · 2026-10-24

사용자 “제작소 재료제작에 마스터의별 상한선 풀어” 요청과 “1억개” 확인에 따라 MATERIAL_CRAFT의 마스터의 별 비용 설정 상한을 1,000,000에서 100,000,000으로 올렸다. 현재 레시피 비용을 일괄 변경하는 작업이 아니다. 한 번의 제작 요청은 기존 최대 100회를 유지한다.

서버 저장과 OWNER CMS 입력 상한을 함께 수정했다. 카테고리 전환 시 새 상한을 적용하고, 장비 제작 20,000,000·다른 일반 분류 1,000,000·서버 고정 미스틱 에너지의 별 비용 0을 유지한다. CMS 스크립트 캐시 키를 갱신했다.

100회 제작은 별 비용 합계가 10,000,000,000이 된다. PostgreSQL이 결제 검증의 매개변수를 int4로 추론해 범위를 초과하는 오류를 격리 DB 검사에서 재현했고, 두 결제 검증 식에 BIGINT 캐스트를 적용했다. 공통 DB 어댑터·스키마·의존성을 바꾸지 않았다. 기존 거래·영수증·소지품 잠금·동일 재료와 비용의 합산 검증을 유지한다.

중단된 선행 사용자 요청 “디임 나무늘봉순 씨나인 마크 잠깐 제외해”도 처리했다. 라운지 마크는 조은(zalalz)·남수댕(mew030709)만 표시한다. 카드 정렬과 사진·링크·운영 CMS 데이터는 변경하지 않았다.
