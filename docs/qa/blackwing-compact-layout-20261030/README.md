# 흑익의 맹약 전장 비율 수정

사용자가 첨부 화면의 큰 하단 출전 카드와 상단 검은 제목 띠를 함께 줄이도록 요청했다. 흑익의 맹약에 한정해 중복 V3 제목 띠를 숨기고, 캔버스와 기믹 영역의 위쪽 여백을 0으로 바꿨다. 기존 레이드 상단 제목·시간·전투기록·나가기 버튼은 유지한다.

공유 카드 마크업·원화·프레임은 그대로 사용한다. 폭과 균일 배율을 함께 조정해 PC 카드 폭 112→56px, 모바일 66→44px로 줄였다. 흑익 외 PVE/PVP의 공용 CSS·렌더러·진형·전투 판정·재화·보상은 수정하지 않았다. 사용자 이번 지시는 과거 흑익의 도크 크기 유지 기록에 우선한다.

실제 메인 로더와 V3 번들, 격리 계정 API로 검수했다. 운영 계정 쓰기와 메시지 발송은 없다. 기존 체크아웃과 의존성을 재사용했고 저장공간 유지관리나 예약은 수행하지 않았다.

- 수정 전: 첨부와 같은 1159×848에서 큰 카드와 72px 중복 제목 띠 재현.
- 수정 후: 1159×848, 1440×1000, 390×844, 676×755, 844×390에서 용혈 축적과 흑익/대검 선택, 총 10경로 통과. 가로로 짧은 화면은 기존 세로 스크롤을 유지한다.
- 캔버스·기믹의 시작점이 전장 시작점과 일치하고, 프레임/슬롯 크기 및 1:1.41 비율 유지, 가로 넘침 없음, 기믹 터치 영역과 카드 도크 분리 확인.
- 실측 도크: 1159×848에서 약112px, 390×844에서 약92px. 카드 자체 높이는 각각 약79px/62px.
- PC·모바일 저울 배치 수정/6인 확정/성역/전투기록 추가 검수 통과. 해당 기존 검수의 재접속 확인도 함께 통과했다.
- 브라우저 스크린샷을 직접 확인했다. 테스트 fixture의 빠른 진입에서 발생하던 기존 자원 로더 경합은 검수 스크립트에서 실제 메인 로더 준비를 기다려 분리했다. 게임 로딩 코드는 변경하지 않았다.
