## 변경

SS 리미티드는 내부 전투 등급이 SSS여서 일반 등급 우위가 적용되지 않았다. 기존 v4에서는 블러드문 카르베나 50.84%, 네베라 51.92%, 강윤 59.01%였다. 기본 정책을 전반적으로 올리면 SSS 리미티드도 다시 압도하므로, 기존 서버 전투 시작 시 등급 우위 경로에 라자크의 지정 상대를 추가한다.

상대의 살아 있는 용병이 **모두 SS 리미티드 또는 신궁 강윤**인 PVP에서는 라자크에게 **연계 공격·피해 상한 4배, 연계 HP·방벽 16배**를 적용한다. 서버 정본 `ssLimitedProfile` 21종과 강윤 V-057의 정확한 코드로 판별한다. 일반 카드, 다른 아군 용병, 행동 횟수, 상대 능력치를 바꾸지 않는다. 용병 성장 전 각 소유자의 일반 카드 5장 평균을 사용하며, 부상 비율·장비 가산·성장·재진입 중복 방지를 보존한다. HP 증가가 상대 피해 상한을 같은 비율로 늘려 효과를 상쇄하지 않도록 기존 등급 우위의 상한 분모도 그대로 사용한다.

듀오에서 SSS 리미티드 등 다른 상대 용병이 섞이면 이 추가 우위는 적용하지 않는다. SS 동반자 때문에 상위 SSS 상대 성능까지 상승하는 경로를 차단한다. 전투 시작 후 상대가 사망해도 우위를 다시 계산하지 않는다. PVE, 기본 전투력 100만·일반 SSS 성장·블러드문팩 무제한, 기존 v4 기본 수치, 스킬 비용 25·공통 재사용 3행동, PVE 광역, 고정 대기·모션 2배·승인 원화를 유지한다. 새 면역이나 승자 결과 덮어쓰기는 없다.
