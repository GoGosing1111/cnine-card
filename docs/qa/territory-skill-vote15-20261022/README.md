# 영토전 스킬 투표 15표 — 2026-10-22

사용자 요청: 영토전 **스킬 투표** 자동 발동 기준을 25표에서 15표로 낮춘다.

- 서버 단일 상수 TERRITORY_SKILL_REQUIRED_VOTES를 15로 변경했다. 투표 저장, 발동 거래 보호, 자동 재처리, 상태 응답 및 발동 안내가 같은 값을 사용한다.
- 스킬 패널, 발동 토스트, 공성포 시설 버튼, 투표 알림과 CMS 안내를 맞췄다. 동적 UI는 서버가 내려준 기준을 표시한다.
- 진행 중인 투표와 완료된 발동 영수증을 보존하기 위해 기존 V25: 식별자를 그대로 사용한다. 현재 15표 이상 모인 유효한 투표는 정상 상태 갱신/투표 처리 시 자동 발동 대상이 된다. 별도 표 초기화나 직접 운영 투표는 없다.
- 참가자당 한 표, 스킬 변경 시 표 이동, 진영 공유 45분 쿨타임, 시설 조건과 스킬 피해는 유지한다.
- 기존 콘텐츠 이미지를 유지하는 수치/문구 수정이다. UI 이미지 신규 제작이나 시각 승인으로 기록하지 않는다.
