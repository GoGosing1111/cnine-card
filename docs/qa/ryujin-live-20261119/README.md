# 류진 운영 반영 검수

사용자 지시: 전투력 400만 최상위 용병으로 설정하고 반영. V-958, SSS LIMITED, 류진으로 독립 등록했다. 획득처는 지정되지 않아 LOCKED이며 계정 지급·상점 개방·메시지 발송은 없다.

일반 공격 220%, PvE 광역 총 피해 6,000/7,200/8,400%, 에너지 10·공통 재사용 2행동, 속도·추가 행동 5.5, 받는 피해 85% 경감. 서버가 대상 중복과 방벽·회피를 처리하고 각 대상에 한 번 적용한다. 동일 성장·장비의 상위 14종과 4조건·12시드·공수 양쪽 1,344전 모두 승리했다. 임의의 성장 격차를 무시한 무조건 승리를 뜻하지 않는다. 기존 헬리오스킹·진 족로 수치는 변경하지 않았다.

승인 원화와 전신 교체 작화를 그대로 사용한 Spine 4.3.26 / runtime 4.3.13. 각성 1·일반 공격 3·광역 연출 13, 총 17동작을 연결했다. 효과는 기존 V3 GSAP 시계를 사용하며 일러스트 컷인은 없고 전장 내 종결 연출은 유지한다. 06번 후면 원화 10% 확대·상향과 10번 채움, 승인 발판·검 오러를 연결했다. 두 후면 PNG는 정지 원화이며 별도 프레임 애니메이션으로 만들었다는 뜻은 아니다. 본체·검·원화 픽셀 해시는 manifest.json으로 대조한다.

PC와 모바일 크기 Chrome, iPhone WebKit 에뮬레이션에서 전체/대표 동작·피해 동기화·취소·재진입·퇴장을 확인했다. 실제 로비의 Windows 진입 URL 및 H5 iframe에서 클릭→전투→종료→재입장도 확인했다. 별도의 운영 계정 전투·쓰기 없이 실제 서버 함수로 만든 격리 응답을 사용했다. 실휴대기기·설치형 앱 검수는 아니다.

Windows 실제 로비 경로 첫/재진입 1,140/345ms, H5 1,089/454ms(로컬 단회). Chrome RAF p95 약 4.3ms는 호스트 240Hz 스케줄러 값이며 게임의 240FPS 달성을 뜻하지 않는다. 진입 중 긴 프레임이 남아 있다. WebKit의 전장 렌더링은 류진을 숨겨도 p50 212~228ms로 느리다. 필터 영역의 고정 130px 패딩을 화면상의 실제 기운 반경으로 제한했으며 측정 편차 때문에 전체 속도 개선을 단정하지 않는다. WebKit 성능 통과 및 실 iPhone FPS는 주장하지 않는다. 모든 검수에서 퇴장 후 류진 상태·타임라인·갱신 0을 확인했다.

운영 배포 상태와 공개 파일/두 Worker/Windows 매니페스트 검증은 최종 completion.json을 기준으로 한다.
