# 레이드 메인 로비 작은 창 배치

사용자가 첨부한 월드 레이드 메인 로비를 수정했다. PC에서는 6개 레이드를 왼쪽에서 고르고, 작은 화면은 3열/2열로 줄바꿈한다. 시간표와 개방·참가 조작을 앞에 두고 요일별 작전표는 펼쳐 본다. 보스 원화·입장 조건·전투 화면은 보존했다.

1024×600에서 6개 탭과 개방·참가 버튼이 최초 화면 안에 들어온다. 더 좁은 화면에서는 기존 세로 스크롤로 모든 조작에 도달한다. 17개 관련 회귀와 Impeccable 기계 검사, 네이티브 주간표 키보드·포커스 보존, Nox 진입, 퇴장 정리를 확인했다.

Windows headless 브라우저와 API fixture로 검수했으며 실기기 검수가 아니다. 운영 정적 파일을 렌더한 최종 확인도 모든 API를 격리했다. WebKit의 기존 ResizeObserver 경고와 긴 프레임은 수정 전후 모두 기록했다. 로딩은 단회·캐시 편차가 있어 속도 개선으로 해석하지 않는다. 자세한 수치와 범위는 [completion.json](completion.json)을 참고한다.
