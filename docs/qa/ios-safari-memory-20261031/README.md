# iPhone Safari 전투 메모리 최적화 — 2026-10-31

사용자 요청: iOS Safari에서 군단토벌·레이드 등 전반적인 튕김 제보에 따른 최적화. 후속으로 작업 완료 뒤 유저 공지문 작성 요청.

## 확인 및 변경

- 기존 엔진은 전투가 끝나도 공통 역할 스킬 아틀라스와 세 레이드 전용 아틀라스를 보존했다. Pixi 8.20 TextureSource.destroy는 ImageBitmap의 참조를 버리지만 close를 호출하지 않는다. 실제 소스와 이미지 캐시를 확인했다.
- 실제 이미지 디코딩 동시 실행을 모바일 3개, 데스크톱 8개로 제한한다. 상위 Assets.load가 아니라 내부 이미지 파서를 제한해 중첩 아틀라스 로딩 교착을 피한다.
- iPhone과 데스크톱 UA의 iPad를 판별해 렌더 해상도 상한 1.25, 렌더링 45FPS를 적용한다. 일반 모바일 1.5, PC 2/60FPS를 유지한다. 공통 시계와 서버 전투 시간·난수·피해는 그대로다.
- 모바일의 미사용 공통 스킬/용병 역할 이미지는 필요할 때 읽는다. 전투 종료 때 해당 프레임 캐시, 디코딩 이미지, 사용이 끝난 텍스트 캔버스/필터 풀을 반환한다. GPU 일시 퇴거에는 ImageBitmap.close를 호출하지 않는다.
- 흑익·바르센·이스겐 전용 프레임 뷰와 원본 아틀라스를 이탈 때 해제한다. 늦게 끝나는 로딩, 부분 실패, 중복 해제 및 다음 입장과의 경합을 처리한다.
- 공용 V3 10번들과 별도 디펜스 1번들을 생성했다. 기존 공통 빌더에 디펜스와 누락된 흑무 해시 기록을 포함해 후속 공통 재빌드에서도 누락되지 않도록 했다. 기존 원화·다른 모션·서버 전투/경제/계정/CMS 변경 없음.

## 측정

아래 수치는 캐시에 남은 고유 이미지의 가로×세로×4 바이트 추정치다. 전체 RAM·GPU 메모리·최대 메모리나 실제 iPhone 프로세스 측정값이 아니다. Chromium의 동일 iPhone UA, 390×844, DPR3, 레반 PVE/레반 대 카드구 PVP 시나리오를 전후 비교했다.

| 경로 | 수정 전 MiB | 수정 후 MiB |
|---|---:|---:|
| PVE 진행 시점 | 157.94 | 141.26 |
| PVP 진행 시점 | 301.06 | 273.71 |
| 두 전투 종료 후 | 55.69 | 7.02 |

종료 후 이미지 캐시 추정치 약87.4% 감소. 캔버스는 585×1176 → 488×980으로 픽셀 면적 약30.5% 감소. WebKit에서는 종료 후 5.77MiB가 남았다. 동일 WebKit 문서에서 흑익 72.91, 바르센 84.91, 이스겐 69.16MiB → 각각 종료 후5.77MiB, 두 번째 진입도 같은 수치. 해제 후 전용 아틀라스0, 캔버스0, 모바일 이미지 동시수 최대3을 확인했다.

## 검증 및 범위

- 새 수명주기 회귀9개 통과: iPad/아이폰 판별, 동시 디코딩/실패, ImageBitmap 1회 반환, 사용 중 캔버스 보존, 공통 역할 이미지 지연 로딩·재입장, 세 레이드 지연 완료/중복 요청/부분 실패 반환. 기존 메모리·실제 메인 로더·레이드 모바일 복구·연속 전투 검사를 scoped 배포에서 실행한다.
- 실제 메인 index의 PVE 시작과 PVP 매칭 → 전투 → 결과 → 복귀: Chromium 1440px/390px, WebKit 390px 통과. 기존 기능 로더와 실제 생성 번들, 격리 계정 API를 사용했다.
- WebKit 군단토벌3회 연속 시작·중단·결과·재도전·복귀, 흑익/바르센/이스겐 준비 화면 각2회 재입장·메인 라우트 이탈·이미지 반환, 디펜스 연습전 진입·결과·로비 복귀 통과. 레이드는 초기 기믹/집결 화면에서 자산 수명을 검수했으며 전체 공략 완주 검사는 아니다. 검수 DB의 기믹 마감만 늘려 저속 콜드 로딩을 허용했다.
- WebKit 메인 초기화의 ResizeObserver 경고1건은 직전 HEAD를 그대로 제공한 기준 실행에서도 동일하게 재현됐다. 전투 오류와 구분해 baseline-content-webkit/report.json에 보존했다. 기준 외 pageerror 없음.
- 기존 ONEstore 생성물이 원본의 과거 로비 변경과 일치하지 않아 전체 생성 검사에 선행 차이가 있다. 이를 이번 변경에 포함하지 않고 기존 variant의 엔진/엔트리 캐시 키와 앱 해시만 갱신했다. SDK/결제/광고 변경 없음.
- 실제 iPhone 하드웨어·제보 기종/OS 로그는 제공되지 않았다. Windows WebKit26.5와 모바일 에뮬레이션 검증이며 모든 튕김 해결을 보장하지 않는다.
