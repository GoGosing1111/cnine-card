# 봉인전 PvE 용병 연결

사용자 `용병 연결해야지` 지시에 따라 세 봉인과 용 보스 본체전에 저장된 PvE 용병을 연결한다. 기존 `raidDeckPower(..., 'PVE')`가 소유·편성·공개 여부를 확인한 서버 스냅샷을 사용한다. 요청 본문의 용병 선택이나 전투력을 신뢰하지 않는다.

- 준비 화면에 실제 PvE 용병 이름과 레벨을 표시한다. 전투력 계산은 카드의 상대별 고유 능력·시너지를 유지하고 장비, 용병 전투력, 기존 아바타 배율을 각각 한 번 적용한다.
- 공통 전투 생성기의 `buildAvatarMercenaryFighter`와 `publicFighter`를 사용한다. 카드 5장과 별도로 용병 슬롯 1개를 전달하고 기존 승인 원화·전투 SD·기본 공격 모션을 재사용한다. 새로운 원화나 엔진 번들을 만들지 않는다.
- 봉인전의 전투력 비교와 궁극기 비활성 규칙은 유지한다. 용병의 합류 공격은 서버가 확정한 공헌도를 분담하며, 새 피해량을 추가 생성하지 않는다. 본체 마지막 타격도 실제 차감량과 재생 합계가 일치한다.
- 현행 SEALS_BOSS 영수증 안에 출전 용병과 전투력을 함께 저장한다. 편성을 바꾼 뒤 같은 요청을 재시도해도 당시 용병이 유지되며 차감·보상이 중복되지 않는다. 기존 CLASSIC 전투의 신규 응답에도 용병을 전달하지만 과거 영수증을 소급 변경하지 않는다.
- 프리뷰는 헬리오스 Lv.1 예시를 사용한다. 실제 운영은 각 계정의 PvE 편성을 따르며 용병 미편성 시 카드 5장으로 출전한다.
