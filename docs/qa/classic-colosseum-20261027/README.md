# 클래식 멸망전 — 2026-10-27

사용자 요청에 따라 선공개 홍보 포스터를 먼저 제작하고, 게임 PVP 메뉴에 운영자 초대 1:1 대전을 구현했다. 최종 정정 **장비 대여 없음**을 적용했다.

- 기본 운영 OFF. OWNER는 게임 안의 **대전 → 클래식 멸망전 → 운영자 관리**에서 ON/OFF와 두 참가자 초대를 관리한다. OFF는 미확정 경기를 취소하고 이전 초대를 다시 살리지 않는다.
- 초대받은 두 계정이 각각 팝업으로 수락한다. 참가자마다 한 경기만 참여하며 초대·편성 마감은 30분이다. 시작된 경기의 연결 끊김 복구는 편성 마감 이후에도 가능하다.
- 공개·활성 일반 카드 5장, C~ZENITH. FUR·SUPERSTAR·ICON 제외. 마법카드는 최대 5장이다. 카드와 마법카드만 전용 +10 대여이며 보유 여부·재화와 무관하다. 장비·용병·펫·배틀슈트·개인 성장 보너스는 제외한다.
- 마법카드는 이 콘텐츠 안에서 +10으로 표시하며 현재 공통 최상위 +9 발동률 설정을 공평하게 적용한다. 일반 마법카드 강화 한도나 운영 확률을 변경하지 않는다. 이 기준을 대여 화면에도 표시한다.
- 카드 고유특성은 공통 정책을 한 번 읽어 양측에 적용한다. 서버가 고정한 편성과 시드로 기존 PVP 엔진에서 승부를 계산한다. 전용 콜로세움 배경 외에 공용 V3 진형·원화 프레임·로스터·효과·서버 판정은 그대로 사용한다.
- 두 참가자가 준비하면 결과·콜로세움 일보·승패 팝업 알림을 한 거래로 확정한다. 기사 문구는 게임의 패배를 놀리는 고정 문안이다. 닉네임은 HTML 이스케이프한다. 영수증 재요청으로 기사를 중복 발행하지 않는다.
- 행동력·재화 차감과 별도 보상 없음. 계정의 보유·성장·장비·일반 PVP 편성·랭킹을 변경하지 않는다. 기존 app_meta와 원자 가드를 사용하며 새 마이그레이션·런타임 DDL은 없다.
