# SX슈트 제작식 및 X 기반 조립 연출

제작소 → 배틀슈트 제작 → SX슈트. 코어 8 10개 + 코인 300조, 성공률 10%, 성공 시 SX슈트 1개. 실패 시 재료와 코인 소모. X 바로 다음 순서이며 별 결제·자동 장착·계정 직접 지급은 없다. 기존 X/Z/다른 제작식, SX 능력치 및 박스 보상은 유지한다.

승인 SX 원본을 한 번 로드해 Canvas 영역별 원본 조각으로 조립한다. 머리·목·흉부는 연결하고 대검은 제자리 체결로 원형을 유지한다. X와 같은 13.4초 Pixi/GSAP 흐름·기계 팔·점화·서버 결과 표시다. 임시 원화 조각은 종료 시 파기하며 승인 원본은 변경하지 않는다. 초안의 겹친 대검/부품은 시각 검수 후 원본 영역 중복 제거와 제자리 대검 체결로 수정했다.

성공/실패 경계, 300조/10개 정확한 원장, 10경+1 잔액, 부족·거래 실패·재시도·경합·결과 복구를 검증한다. 운영 등록은 레시피/재료/감사/영수증 단일 거래, 실패 및 정상 예행 롤백, 독립 READ ONLY와 SELECT 전용 재실행으로 확인한다. 계정 직접 쓰기·메시지 발송 0건.

performance.json은 다섯 환경 진입·재진입·프레임·퇴장 기록이다. 실휴대기기·설치형 Windows 검수가 아니며 공개 파일 검수도 계정 API는 격리했다. completion.json에 실제 배포와 등록 결과를 기록한다.
