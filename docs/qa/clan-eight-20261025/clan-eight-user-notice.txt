안녕하세요. 리버스콜 운영팀입니다.
클랜 간 인원 격차를 줄이기 위해 클랜을 6개에서 8개로 확대하고, 기존 클랜원 129명의 균등 재배정을 완료했습니다.

1. 클랜 8개 체제로 확대
기존 DK·삼성·T1·한화·LG·롯데에 FM·DC가 추가되었습니다.
클랜별 최대 정원은 기존과 같은 25명이며, 전체 수용 인원은 150명에서 200명으로 늘어났습니다.

2. 전체 129명 재배정 결과
DK 17명 / 삼성 16명 / T1 16명 / 한화 16명 / LG 16명 / 롯데 16명 / FM 16명 / DC 16명
17명인 클랜 1개, 16명인 클랜 7개로 편성했습니다. 클랜 간 인원 차이는 최대 1명입니다.
인원 균형을 먼저 맞추고, 서버에 저장된 평가 전력의 합계 차이를 줄인 뒤 희망 클랜을 반영했습니다. 희망 클랜 배정은 보장되지 않으며, 이 기준이 실제 전투 승률이 같다는 뜻은 아닙니다.
기존 소속에서 이동한 인원은 111명, 소속을 유지한 인원은 18명입니다. 전체 129명의 최종 명단과 이전 소속은 함께 제공하는 포스터에서 확인하실 수 있습니다.

3. 새 소속 기준 원로 지정 및 편성 안내
각 클랜의 새 명단에서 저장 평가 전력 상위 3명을 원로로 지정했습니다. 동률은 배정 슬롯과 계정 번호 순으로 결정했습니다.
기존 소속을 기준으로 구성되어 있던 공격대·방어대, 행동대장, 준비 상태와 지역 주둔 편성은 비웠습니다. 클랜원과 원로께서는 게임 내 최신 소속을 먼저 확인해 주세요. 편성 및 출전은 현재 운영 잠금 정책과 추후 재개 안내를 따릅니다.

4. 그대로 유지되는 내용
개인 코인·아이템·보유 카드와 기존 획득/보상 기록은 변경하지 않았습니다.
점령지 소유권·공동 자금·누적 적립액·아지트 단계는 각 클랜 기준으로 유지했습니다. 사람이 이동했다고 이전 클랜의 자금이나 점령지가 함께 이동하지 않습니다.
과거 정규 클랜전·챔피언스리그의 명단, 전적과 보상 기록은 그대로 보존됩니다. 기존 가입 심사 대기 신청도 삭제하지 않았습니다.

5. 대회 일정 및 가입 방식
정규 클랜전·챔피언스리그·세력전의 모든 일정은 계속 잠겨 있습니다. 이번 재편으로 대회가 자동 재개되지는 않으며, 재개 일정은 별도로 안내하겠습니다.
새 가입 방식은 검토 단계이며 시행을 보류했습니다. 현재의 원로 심사 방식이 유지됩니다. 확정된 변경이 있으면 별도로 안내하겠습니다.
