사용자 요청: “장비창에서 +10 효과 프레임 이펙트 더 보강할수있나”.

- 기존 장비 슬롯·보관함 레이아웃과 원화를 유지하며 +10의 금빛 외곽 광원, 두 방향의 밝은 테두리 흐름, 네 모서리 섬광과 작은 입자를 보강했다. 기존 코드 기반 광원에 SVG를 더했으며 새 이미지 프레임으로 교체하지 않았다.
- 무기·상의·하의·신발·장신구 중 정확히 +10인 장착/보유 장비만 새 연출을 표시한다. 기존 +8·+9 색상과 배틀슈트 제외 조건을 유지한다. 강화 수치·확률·능력치·보유량·API·DB 변경은 없다.

- 운영 로더·루트 HTML·공유 프리뷰의 캐시 버전은 `enhanceGlow=20261019-v2`다. 확인 경로: `/preview/live-character-loadout-v2-v1/?enhancementGlow=1` (샘플 데이터).
