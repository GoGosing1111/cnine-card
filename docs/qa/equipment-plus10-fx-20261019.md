## V4: 기존 금장에 황금빛 아우라 추가

사용자는 V3의 위치 어긋남과 일부 변에만 나타나는 불꽃을 지적했고, 네 변에 작은 불꽃을 반복 배치한 미배포 중간안도 반려했다. 최종 후속 요청은 “이전에 쓰던 금장에다가 아우라 빛을 더하던가 아이템 아이콘에 황금으로 효과를 주던가”다. 반복 불꽃 중간안은 운영에 배포하지 않는다.

- 장비 원화에 들어 있는 기존 금장 프레임을 그대로 사용한다. 원화 가장자리의 밝은 금속 픽셀을 읽어 가까운 빛 번짐과 넓은 황금빛 아우라를 합성하고, 아이템의 밝은 금속 부분에도 낮은 불투명도의 금빛을 더한다. 새 프레임·불꽃·회전 띠·별 모양 섬광을 붙이지 않는다.
- 전체 광도가 천천히 변하며 네 변의 금장은 제자리에 유지된다. 화면에 덧붙였던 별도 사각 테두리 광원과 V3 화염 아틀라스의 실행 코드/인라인 데이터는 제거한다. V3 생성 원본·프롬프트·해시는 반려된 제작 이력으로 위 QA 폴더에 보존한다.
- 이미지의 패딩·원본 종횡비·object-fit contain 결과를 기준으로 Canvas를 배치한다. 이미지 로딩과 슬롯 크기 변경에 다시 맞추며, 텍스트·강화 수치·수량은 광원 위에서 표시한다. screen 합성으로 원화를 어둡게 덮지 않는다.
- 광원 마스크는 이미지별로 한 번 계산하고 블러는 크기 변경 때 미리 렌더링한다. 화면 갱신에서는 준비된 두 레이어만 합성한다. 기존 단일 애니메이션 루프, 30Hz 제한, 최대 DPR/버퍼, 화면 밖·숨긴 탭·동작 줄이기·destroy 정리를 유지한다. 외부 이미지의 CORS 제한으로 픽셀을 읽을 수 없으면 기존 원화를 보존한다.
- 첨부와 같은 `weapon-03-512.png` M14 장비를 공유 프리뷰의 샘플에 넣어 1440px/390px에서 확인했다. 추가 1280px/430px 리사이즈에서도 정렬 오차 0.02px 미만이다. 네 변 각각 24개 구간을 3개 시점에서 확인해 모든 구간에 광원이 존재했다. 아이템 중앙은 강한 덮개 없이 부분 하이라이트만 남긴다.
