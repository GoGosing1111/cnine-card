## 동작

- 각 전황 상단 ‘아군 채팅’으로 진입한다. PC 1280px 이상은 전황 오른쪽 패널, 그보다 좁은 화면은 전황/채팅 전환이다. ‘전황 보기’ 또는 ‘채팅 숨기기’로 원래 전황·스크롤을 복구한다. 별도 팝업 없음.
- 실제 용병도감 `panel-v3.webp`, `action-user-approved.webp`와 `command-ui-v1.css`를 재사용한다. CMS도 같은 리소스를 사용하며 모바일 메뉴의 기존 100vh 공백을 이 메뉴에서만 보정한다.
- CMS 메뉴는 OWNER에게만 표시하며 조회·저장 API도 OWNER를 검사한다. 기존 CMS 권한 변경 이벤트와 관찰자를 연결한다. 설정 revision 충돌 검사와 감사 기록은 한 거래로 저장한다.
- 서버가 현재 시즌·회차와 소속을 판정한다. 클랜별, 영토전 A/B팀별, 현재 LIVE 세력별로 분리한다. 로그인 세션·정지·소속 변경·회차 종료를 재확인한다.
- 미설정 상태는 3종 모두 OFF다. 배포에서 설정을 생성하거나 ON으로 변경하지 않는다.
