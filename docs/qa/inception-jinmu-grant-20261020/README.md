## 구현과 검증

`scripts/ops/inception-jinmu-grant-20261020.mjs`는 라이브 USER_LOCK과 DB 보조 임대 잠금 아래 정확한 계정 신원을 재확인한다. 보유 1장·획득 기록·감사 로그·완료 영수증을 한 거래로 저장한다. 일회 키는 `ops:inception-jinmu-grant:20261020:v1`이며 완료 영수증이 있으면 검증만 하고 재지급하지 않는다.

2026-10-20 운영 DB 롤백 검증은 `dry-run.json`에 보존했다. 잘못된 계획 거부, 보유·획득·감사 저장 후 영수증 저장 실패의 전체 롤백, 정상 지급 후 쓰기 없는 재실행, 최종 원상복구를 확인했다. 검증 중 지급은 커밋하지 않았다.

관련 회귀는 `tests/inception-jinmu-grant-20261020.test.mjs`와 `tests/mercenary-halloween-sss-20261017.test.mjs`를 사용한다. 신규 계정 허용/타 계정 차단, 미보유 차단, 도감·PVE/PVP 편성 및 단건/일괄 스냅샷·랭크 선택·성장, 팩 재고와 발행 기록 보존을 확인한다. Worker 컴파일을 포함한 scoped 배포로 진행한다.
