## 반영 범위

`shared/pet-art-catalog-v1.mjs`에 기존 순서를 보존하며 2행을 추가한다. 기존 API가 승인 원화를 도감과 OWNER CMS 원화 후보에 표시한다. CMS에 아직 설정하지 않은 두 펫은 미설정 버프·미보유로 표시하고 실제 장착은 차단한다. CMS 문서·보유권·기존 펫·개봉 풀/가중치·잠재력·계정 지급·전투 수치에는 쓰지 않는다.

승인 기록은 원화 승인과 이름 확정이다. 새 애니메이션·버프·획득·실전 활성화의 승인으로 확대하지 않는다.
