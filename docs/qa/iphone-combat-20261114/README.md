# 아이폰 Safari 전투 메모리 최적화 · 2026-11-14

듀오랭크·랭크전·군단토벌·격전지의 실제 화면 진입과 퇴장 경로를 격리 API로 검증했다. 게임 결과와 재화 처리는 변경하지 않았다.

- 원본을 보존하고 151개 이미지의 아이폰용 WebP를 제공한다. 원본 합계 307.6MB → 13.2MB. 단일 전투 다운로드 수치가 아니다.
- 듀오 이미지 RGBA 추정 MiB: 398.8 / 398.8 → 160.5 / 160.5.
- 랭크전 이미지 RGBA 추정 MiB: 287.4 / 270.7 → 122.4 / 122.4.
- 전직 효과의 지연 로딩·해제와 격전지 보스 효과 캐시를 정리하고 다음 전투 진입과 충돌하지 않도록 기다린다.
- 관련 검사 93개 통과. 모든 화면에서 크래시·이미지 누락 0건. 기존 셸 ResizeObserver 경고만 관측했다.

측정은 Windows WebKit의 iPhone 13 에뮬레이션이며 실제 아이폰 측정이 아니다. 프레임 시간과 첫 진입·재진입 시간, 종료 후 작업 상태는 [performance.json](performance.json)에 조건과 함께 기록했다. 해당 환경의 프레임 변동이 커서 실기기 속도 개선이나 사용자 튕김 해소를 확정하지 않는다.
