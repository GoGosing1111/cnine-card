# 미라클 버닝 10분·코인 최대 300배 — 2026-10-21

사용자 요청: “미라클버닝 10분짜리 만들고 코인배율 300배까지 늘려”.

## 구현

- OWNER CMS의 미라클 버닝 진행 시간에 10분 추가. 선택값은 10·30·60·120분이다.
- CMS와 서버 입력 상한, 공통 전투 보상 설정 정규화의 미라클 상한을 300배로 함께 수정했다. 서버 재조회·공개 상태·실제 보상 경로에서도 300배를 유지한다.
- 기본값 60분·100배, 일반 버닝 10배/하이퍼 30배 상한과 기존 진행 시간, 전용 OWNER 권한은 유지했다.
- 이벤트 만료, 다른 버닝과의 중복 금지, 드랍 확률 +30%, 아이템 수량, 행동력·충전 규칙은 유지했다.
- 운영 설정을 직접 변경하거나 미라클 버닝을 발동하지 않는다. CMS에서 운영자가 선택·저장한다.
- 기존 하늘빛 배경을 유지하고 전용 ImageGen 프레임을 CMS 패널·입력·버튼·상태에 연결했다. 실시간 수치/문구는 DOM이다. 기능 검수는 사용자 시각 승인이 아니다.
