# 시청시간 동의 팝업 반복 수정 — 2026-10-28

사용자 제보: 동의했는데 계속 팝업이 뜬다. 첨부 화면은 정보 제공 확인 성공 문구와 다시 동의/재연결하라는 버튼이 동시에 표시된 상태다.

## 원인과 재현

`completePendingPlaydkVerification()`이 일반 PLAY DK 접속과 동의 확인용 재연결을 구분하지 않고, 새 토큰 교환에 성공할 때마다 `openSoopWatchConsent({verificationResult})`를 호출했다. 이 수동 열기 경로는 기존 계정별 `shown` 안내 기록을 무시했다. 기존 브라우저 검사는 같은 토큰의 재사용 차단만 확인해, 로그인마다 새 토큰이 오는 반복을 발견하지 못했다.

수정 전 실제 메인 런타임과 격리 API로 모바일에서 최초 안내를 닫은 뒤 서로 다른 두 토큰을 전달했다. 두 번 모두 정보 제공 확인 성공 팝업이 열려 제보와 같은 현상을 재현했다. 실제 제보 계정의 저장 상태나 외부 서비스 설정을 조회한 것은 아니다.

## 수정

- 일반 토큰 응답은 자동 안내 규칙을 적용한다. 서버가 정보 제공을 확인했으면 새 브라우저에서도 팝업을 띄우지 않고 기존 `shown` 안내 기록만 저장한다. 정보가 없더라도 이미 본 안내를 반복하지 않는다.
- 사용자가 팝업의 재연결 버튼을 눌렀을 때만 계정 번호·시각을 현재 탭의 sessionStorage에 기록한다. 10분 이내 같은 계정의 다음 확인 응답에 한 번만 결과를 보여준다. 잘못된 주소·다른 계정·만료·이전 세션의 지연 응답은 강제 안내로 이어지지 않는다.
- 확인 성공 화면은 ‘확인 완료 / 게임 계속하기’로 표시하고 재동의·재연결 요구를 숨긴다. 메시지함에서 동의 설정을 다시 열 수 있다.
- 안내 버전 `20261026-v1`을 유지해 이전 `shown` 기록을 보존한다. 파일 캐시만 갱신하고 원스토어 파생물은 공식 생성기로 갱신한다.
- 동의 상태·SOOP ID·시청기록을 영구 저장하지 않는다. 실제 동의/철회는 계속 PLAY DK에서 사용자가 관리한다. 서버 인증·기프트·계정/재화 정책 변경은 없다.
