# SX슈트 코어 8 · 씨나인 스트리머 박스 추가

SUIT_CORE_8을 SX슈트 제작용 재료로 등록하고, 씨나인 스트리머 박스의 새 개봉부터 1개씩 확정 지급한다. 기존 미개봉 보유분에도 적용된다. 원래 코인 25조·마스터의 별 2억·핑두 리페어 쿠폰 3개·슈트 코어 6 10개는 유지한다. 30개를 새로 개봉하면 코어 8은 30개다.

과거 완료/대기 영수증은 저장된 구성대로 재확인하며 소급 지급은 없다. SX 제작식·확률·필요 수량은 변경하지 않는다. 운영 계정 직접 지급·자동 개봉·메시지 발송은 없다.

ImageGen 기본 도구로 투명 원화를 생성해 PNG를 그대로 보존했다. SX의 코발트·은백·금색을 적용한 512px WebP를 인벤토리/개봉창에서 공유한다. 사용자 별도 시각 승인은 주장하지 않는다. 프롬프트·원본·해시는 art-prompt.json, art-manifest.json에 기록한다.

관련 검사와 배포 결과는 completion.json, 동일 조건의 5환경 진입/개봉/프레임/퇴장 비교와 한계는 performance.json이다. 실휴대기기·설치형 Windows 검수는 아니다.
