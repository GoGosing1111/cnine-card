# 검수 중 발견 및 보정

첫 scoped gate는 51개 중 45개 통과, 6개 실패로 운영 배포 전에 중단됐다. 지급 로직의 원복·동시 요청·구형 영수증·30개 수량 검사는 통과했다.

- 리베이스가 sparse checkout의 비공개 검수 자료를 다시 제외하여 기존 코어 7 감사 JSON, 스트리머 박스 manifest, ranked-shop HTML, 이번 원화 manifest를 읽지 못한 4건이다. 모두 추적 중인 원본을 정확한 경로로 복원했다. 파일 삭제나 런타임 변경은 없다.
- 기존 씨나인/리버스콜 박스 테스트 2건은 실제 API 구간을 분리 실행하면서 이미 운영에 추가된 발동권 폐기 상수 2개를 주입하지 않았다. 운영 모듈의 실제 상수를 해당 테스트 의존성에 연결했다. 운영 API·인증·폐기 정책 변경은 없다.

실패가 있었던 관련 테스트 파일과 배포 정책상 필수 로더 검사만 공식 scoped 배포에서 다시 실행한다. 통과한 브라우저 5환경·CMS·운영 카탈로그 롤백 검사는 실행 코드가 동일하여 반복하지 않는다. 최초 실패 원본 로그는 프로젝트 루트 operations/sx-core8-cnine-box-20261117/release-7df86250f.log에 보존한다.
