## 화면 수정

- 흑익 탭의 붉은 이미지/인라인 스타일을 제거하고 레이드 탭에 같은 공통 패널/선택 버튼을 적용한다.
- 용병 도감 `command-20261021`의 승인 패널/행동 버튼을 재사용한다. `css/command-ui-v1.css`를 공통 정본으로 추출해 도감과 흑익이 동일 변수/원본 URL을 사용한다. 생성·참가·준비·출정은 연두색 행동 버튼, 새로고침·나가기는 남색 보조 버튼이며 처리 중/역할 마감/준비 미완료 상태를 반영한다.
- 역할 선택·공대 준비/모집·공략 안내·공대 전황·전투 조작 패널에 같은 남색 9-slice 프레임을 실제 연결했다. 패널 48/16px, 버튼 38/9px 분할을 보존하고 텍스트는 DOM으로 유지한다. 도감 원화·원본 해시와 기존 도감 기능은 그대로다.
- 마지막 화면 재확인에서 레이드 기본 CSS가 비선택 탭 프레임과 선택 탭 글자색을 덮는 문제를 발견했다. 공통 탭 규칙의 우선순위를 명시하고 초록 버튼에는 짙은 글씨를 적용했다. PC·모바일에서 실제 표시 색과 모든 보이는 탭의 원본 프레임을 검사했다.
- 기존 보스 원화를 상단 기준으로 배치해 PC와 모바일에서 투구 얼굴·날개가 잘리지 않도록 한다. 새 원화·패널·버튼 이미지를 만들지 않았으며 승인 원본은 보존했다.
- 역할 선택은 설명이 함께 보이는 라디오 항목 3개, 공대는 역할별 고정 6자리로 표시한다. 실제 RAID 카드의 얼굴을 공대원·내 5장 편성·전투 중 공대 체력 현황에 표시한다.
- 초상화는 이미 저장된 공대 편성에서 최소 표시 필드만 반환한다. 다른 참가자의 전체 편성/계정 성장 정보는 추가 공개하지 않으며 참가자별 추가 DB 조회도 없다. 준비 시 최신 편성이 반영되면 초상화도 갱신한다.
- 가로로 늘어난 장식 패널과 긴 단일 설명 문단을 제거하고 모집 목록과 5단계 안내를 나눈다. 기존 OWNER CMS 스타일과 전투 렌더러·본체 방향·스킬·밸런스·입장/보상 정책은 그대로다.
