## 변경

- 현재 메인 로비의 `assets/ui/tactical-20261030/panel-flat.webp`, 남색/청록 색상, 방어·편성 아이콘을 재사용했다. 출전 로비·대기방·방 목록·편성창에 적용한다.
- 출전 분대와 대기방의 세 슬롯은 `sourceArt` 카드 이미지로 표시한다. 용병 SD 대신 승인된 카드 원화를 사용하고 카드 이름/역할/등급을 DOM으로 표시한다.
- PC는 카드 편성과 입장 조작을 좌우로 배치한다. 모바일은 세로 흐름과 분대 탭을 사용하며 고정 버튼이 카드 위를 덮지 않는다.
- 보유 목록 새로고침으로 원래 버튼이 교체된 경우에도 편성창을 닫으면 같은 ID의 버튼으로 초점을 돌린다.
- UI CSS는 마지막에 로딩되는 기존 `rooms.css`에 포함했다. HTML 2개와 번들에 새 캐시 버전을 연결했고 공개 파일 수를 늘리지 않았다.
- 첫 공개 WebKit 검수에서 개별 아이콘 경로 두 개의 404를 발견했다. 해당 파일은 제작 원본으로 공개 포장에서 제외되므로 메인 로비와 동일한 WebP 바이트를 HTML data URI로 포함하도록 수정했다. 공개 재검수 결과와 두 배포 이력을 구분해 보존한다.
- 서버·입장 횟수·비용/보상·난이도·전투 SD/모션/밸런스·기존 iOS 메모리 최적화는 수정하지 않았다. 운영 계정/DB 쓰기와 메시지 발송은 없다.
