# 산타걸 조은 승인 V10 리소스 교체

사용자 지정 최종 이미지로 A-39 / SANTA_JOEUN의 로비 1024·640px와 투명 장비창 640px 리소스를 교체한다. 얼굴·피부색·포즈·의상을 재생성하거나 보정하지 않는다. 승인 PNG SHA-256: `9559836f88d68bfb5f859871ae91eea22b1c06c3b4469bcffe6ce973c0ff9092`.

1024px 로비 WebP는 원본 RGB와 완전히 일치한다. 투명 PNG도 원본 RGB와 일치하며 배경 투명도만 추가했다. 모바일·장비창은 원본 비율로 축소 후 무손실 저장한다. `encoding-validation.json`과 `alpha-validation.json`에 대조 결과를 남겼다.

기존 카탈로그 옵션·공개/판매 OFF·보유·장착은 유지한다. 이미지 URL 3개의 캐시 버전과 카탈로그 버전만 올린다. 완료 영수증은 `completion.json`에 기록한다. 계정 지급·장착·메시지 발송은 없다.

검수: 관련 파일/배포 개수 검사 1개 통과. 운영 DB에서 부분 실패·전체 예행연습을 모두 롤백하고 재실행 추가 쓰기 0건을 검증했다. Windows의 Chrome·WebKit으로 PC·Android·iOS·Windows 진입·H5 진입과 CMS를 확인했다. 실제 휴대기기/설치형 Windows 앱 검수는 아니다.

승인 PNG를 무손실 WebP로 1,960,346→1,351,752바이트로 줄였다. 다만 얼굴 픽셀 보존을 위해 이전 손실 압축본보다 파일은 커졌다. 첫 진입·재진입·프레임과 제한된 네트워크 조건은 `browser-validation.json`에 수록했다. 기존 WebKit 경고 및 긴 프레임은 전후 모두 관찰됐고, 퇴장 후 장비 DOM·애니메이션·요청은 0건이다.
