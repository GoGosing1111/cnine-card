# 블러드팩 개봉 준비 — 2026-10-23

사용자 요청: 할로윈팩의 화면과 개봉 방식을 그대로 복제하고 스킨을 교체한다. 별도 CMS로 관리하고 개봉 준비 상태로 둔다. 후속 구성 지정: **블러드문 5종 + 레오넬·제너럴 족·프라임 레퀴엠**.

- SS: V-960~V-964, 기존 승인 원화·각 10장 등록 유지.
- SSS: 레오넬 V-978, 제너럴 족 V-974, 프라임 레퀴엠 V-975. 팩 발행 한도 미정, 카운터를 생성하지 않는다. 기존 직접 지급·보유·편성 설정은 변경하지 않는다.
- 할로윈팩의 SSS 헬리오스·진무·발테르·족로는 블러드팩에 포함하지 않는다.
- 판매 OFF, 서버 출시 플래그 OFF. 가격·확률·SSS 한도는 임의 결정하지 않는다. OWNER CMS는 별도 OFF 초안을 저장한다. 실제 개봉 경로는 DB·계정·요청 본문 조회 전에 423으로 차단한다.

## 구현

할로윈팩의 1/10회, 구매 확인, 10장 동시 결과 공개, SS→SSS 실제 등급 영상, 음소거·일시정지·건너뛰기, 자동뽑기 최대 100회, 화면 이탈 중지, 이전 영수증 복구, 저장 공간 부족 복구를 동일하게 복제했다. 소진 구간의 일반 SSS 대체·중복 요청·발행/소유/코인 원자 처리도 동일하다.

블러드팩의 설정 키 `mercenary_bloodmoon_ss_pack_v1`, 저장 영수증, 거래 종류 `MERCENARY_BLOODMOON_OPEN`, 1회 지정 지급 키, 브라우저 대기/이력/잠금 및 DOM/CSS 이름을 모두 별도로 사용한다. 일반 용병 풀과 획득 영상은 기존 공통 리소스를 이용한다. 기존 V1 등록 초안은 읽을 때만 V3로 정규화하고 DB에 자동 저장하지 않는다. 최초 도감 등록 운영 도구는 과거 V1 형식을 유지한다.

OWNER CMS → 용병 관리 → **블러드팩**. 상점에 별도 팩 항목·컬렉션을 제공한다. 비거래 화면 시연: `/preview/blood-pack-interface-20261023/`.

## 이미지

내장 ImageGen으로 팩·배경·카드 프레임·기본 버튼·강조 버튼·자동뽑기 패널 6종을 제작했다. 원본/전체 프롬프트/SHA-256/배포 파생본은 `assets/ui/packs/blood-pack-20261023/manifest.json`에 보존한다. 3종 SSS는 승인 원화에서 320/640px WebP 전달본만 생성했으며 원화는 수정하지 않았다. 중앙이 투명한 프레임과 버튼의 실제 alpha를 확인했다. 기능 및 배치 검수는 사용자 시각 승인을 의미하지 않는다.

- 자동뽑기 순서·중지·탭/계정 잠금, 모바일 복구·오프라인/백그라운드 복귀, 저장 공간 부족을 검사한다.
