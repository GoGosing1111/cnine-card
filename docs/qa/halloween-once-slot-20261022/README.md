# 할로윈팩 1회 확정 슬롯 지정 — 2026-10-22

운영에서 명시적으로 등록하는 특정 SSS 1회 확정 설정에 version 3과 0부터 시작하는 `slotIndex`를 지원한다. 예를 들어 `slotIndex: 2`는 다음 신규 10회 개봉 결과의 세 번째 칸이다. 해당 칸이 없는 단일 개봉은 일반 확률로 진행하며 확정 기회를 유지한다. 기존 version 1 SS와 version 2 특정 SSS는 첫 칸 동작을 유지한다.

확정 카드 재고를 먼저 계산한 뒤 지정한 위치에 넣고, 나머지 결과는 다시 추첨하지 않는다. 재고 경합 시에도 지정 칸을 우선 처리한다. 품절 대체, 지급 실패, 코인 부족, OFF는 확정을 소모하지 않는다. 확정 소모·발행·획득·차감·감사 기록은 기존 단일 거래에 포함하고, 획득 ID는 실제 결과 칸을 사용한다. 등록 전 확정된 개봉 계획과 완료 영수증은 소급 변경하지 않는다. 클라이언트 입력으로 코드나 슬롯을 지정할 수 없다.
