# 족각도시 갱단의 경찰 카운터

사용자 요청: 갱단에 승진 무효·피해 상향뿐 아니라 전투력 우위를 더해 경찰 전용 카운터로 적용. 다른 직업 상대는 제외. 적용 완료 후 유저 공지문 작성.

## 동작

- 실제 역할 GANG 대 POLICE일 때만 갱단 도시 전투력에 30%를 가산하고 경찰의 policePowerBonus를 제거한다. 무기와 방어구 전투력은 그대로다. 공격자와 방어자 방향에 무관하다.
- 승리한 실제 갱단이 패배한 경찰에 주는 도시 체력 피해는 40이다. 반대 방향과 다른 역할 조합의 피해는 기존 역할 설정을 따른다.
- 일반 공격·방어·체포 방어·보급 교전에 적용한다. 무승부는 피해가 없으며 위장 직업은 판정에 쓰지 않는다.
- 서버가 전투력과 피해를 결정하고 저장 영수증을 재사용한다. 계정/장비/직급/현금/회차 정책을 별도 운영 SQL로 변경하지 않는다. 기존 경찰 수입과 급여, 일반 PVP/PVE 전투는 유지한다.
- UI 역할 안내, 진행 방법, 공격 영역, 경찰 조직 안내 및 캐시 버전을 함께 갱신했다. 기존 전용 아트와 화면 구성을 사용한다.

## 검증

- 신규 서버 검사 7개 통과: 49개 역할 조합, 양방향·0/5/10/15/50% 직급, 실제 정규화 전투, SQLite/Postgres 일반 공격·방어·체포·보급, 영수증 재사용·실패 롤백·응답 유실·무승부·체포 사망 현상금 제외.
- 동일 장비 / 최고 직급 / 200개 seed / 양방향 총 400회 통제 실험: 갱단 400승. 운영 유저 승률 통계나 모든 장비 격차의 승리 보장이 아니다.
- PC 1440px / 모바일 390px 실제 도시 UI와 격리 DB로 안내·규칙·경찰 조직 표시 확인, 가로 넘침 0·브라우저 오류 0. 운영 계정 행동 0건.
- 기존 탐색/경찰 승진·현상수배·보급 회귀와 check:worker는 공식 scoped 배포에서 실행한다. 신규 검사 중 응답 객체 구조/JSON 직렬화 비교 두 곳의 테스트 기대를 정정했으며 제품 코드를 우회하지 않았다.
