# 블러드문 전투 리소스·밸런스 검수

2026-10-23 사용자 요청 `전투 리소스 만들고 밸런스는 할로윈 SS리미티드 상위로 밸런스 조정해`를 구현했다. [제작·수치·검수 기록](../../../preview/mercenary-bloodmoon-battle-20261023-v1/README.md), [검수 화면](../../../preview/mercenary-bloodmoon-battle-20261023-v1/index.html), [단일 매니페스트](../../../preview/mercenary-bloodmoon-battle-20261023-v1/manifest.json)를 따른다.

후속 `이거 써 캐릭터 줄이지말고`의 봉순 첫 시트를 정확한 해시로 보존했고, `왼쪽 상단2개 다리짤림`의 단검 두 동작을 부츠까지 복원했다. 다섯 캐릭터는 승인 원화와 분리된 전투 동작 80프레임·개별 효과 80프레임을 사용한다. [프롬프트·수정 이력](../../../preview/mercenary-bloodmoon-battle-20261023-v1/prompts-v3-current.json)을 보존했다.

후속 검사에서 시작·종료·취소 시 캐릭터가 정상 크기의 57~68%로 복귀하던 문제를 확인하고 수정했다. PC·모바일 모두 실제 화면상 배율을 100%로 유지한다. 투사체는 총구부터 표적까지 0.12초 등속 직선으로 비행하며 스킬은 0.07초 간격 세 발이다. `캐릭터 대기에 움직임 최소화해라`에 따라 대기는 첫 자세로 고정하고 몸체·발 위치를 유지한다. [수정 전 측정](../../../preview/mercenary-bloodmoon-battle-20261023-v1/qa/scale-before.json)과 [배율·대기·투사체 회귀 검사](../../../preview/mercenary-bloodmoon-battle-20261023-v1/qa/motion-regression.json)에 기록했다.

추가 지적의 봉순 두 대기 원본은 부츠 하단 자체가 누락되어 있었다. 내장 ImageGen으로 발끝·굽·밑창을 완성해 두 대기 텍스처만 연결했고 선택 원본과 다른 14동작은 보존했다. 1254/512 해상도 차이만 환산하여 몸체를 경계에 맞춰 줄이지 않는다. [복원 프롬프트·산출물](../../../preview/mercenary-bloodmoon-battle-20261023-v1/prompts-idle-feet-v2.json)에 기록했다.

근접 4종은 이동 자세로 접근하고 무기 접촉 후에만 타격 이펙트·피격 반응을 재생한다. 수정 전 조기 효과 48건을 재현했고 수정 후 0건, 명중 위치 오차 1px 미만을 확인했다. 기본 모션 속도는 사용자 지시대로 2배이며 이동 0.42초를 실제 약 0.211초에 재생한다. 위 투사체 기준 시간도 실제 기본 재생에서는 절반이다. [접촉·2배속 검사](../../../preview/mercenary-bloodmoon-battle-20261023-v1/qa/contact-speed.json)에 기록했다.

기본 전투력은 356,400(바토리 +20%, 할로윈 기본 7종 +50%)이다. PVP 11,520회, PVE 104회와 PC/모바일 10사례를 검증했다. 클로는 두 타격으로 나뉜 총 배율 2,640%를 사용하며 PVE 최소 피해 우회 보정은 켜지 않는다. 수치와 결과는 [서버 계산 보고서](../../../preview/mercenary-bloodmoon-battle-20261023-v1/qa/balance-report.json)에 있다.

현재 상태는 **기술 검사 통과 · 사용자 전투 원화/연출 검수 대기**다. 정식 등급·독자 캐릭터 A/B의 이름·운영 코드·획득/전투 연결을 확정하지 않았다. 기존 용병 보유량, 할로윈·SSS 팩의 발행 한도, 운영 가격·확률과 전투 코드 변경은 없다.
