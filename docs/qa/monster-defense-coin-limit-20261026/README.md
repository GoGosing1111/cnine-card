사용자는 코인 입력 상한으로 저장하지 못한 값을 사진 그대로 저장하도록 요청했고, 무기/방어구 강화주문서를 각각 입문 1%부터 난이도마다 1%씩 올리도록 지시했다. 추가 난이도 사진도 같은 설정 작업에 포함한다. 두 사진은 이 폴더의 reference-*.png에 보존한다.

## 수정

- HTML과 서버의 임의 1조 상한을 제거한다. 공통 DEFENSE_COIN_MAX = Number.MAX_SAFE_INTEGER로 정확한 정수 저장 및 기존 지급 시 합계 오버플로 방지를 유지한다.
- OWNER API가 인증된 editorId를 제공한다. 브라우저 임시 저장을 계정별로 분리하고 전체 난이도/보상/성장/테스터의 작성 중 값을 저장한다. 빈 입력과 미완성 아이템도 그대로 복구한다.
- 서버 재조회 시 로컬에서 수정한 필드만 병합한다. 다른 운영자가 변경한 별도 항목은 보존하고 같은 항목 충돌은 입력을 유지한 채 확인 문구를 표시한다. 임시 저장 자체는 서버 반영이 아니다.
- 검증 실패/네트워크 오류/전체 새로고침에 입력을 유지한다. 서버 저장 후 응답이 유실된 경우 새 조회로 완료를 확인하며 중복 저장하지 않는다. 임시 저장 불가 시 창을 닫지 말라는 안내 및 이탈 보호를 제공한다.
