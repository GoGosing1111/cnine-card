## 검수

- 실제 메인 페이지 로더·V3 전장·배경·진형·HUD·카드 도크를 사용했다. 별도 프리뷰 장식을 만들지 않았다.

- `dry-run.json`: 실제 운영 예행연습 전체 롤백. 현재 정의·설정의 보존 해시 확인.
