- 스타부: 남수댕 `mew030709`, 조은 `zalalz`, 디임 `qpqpro`.
- 로비 아바타 화면 오른쪽 위에 작은 C9 버튼을 추가했다. PC 166×48px, 모바일 148×44px로 기존 음향 컨트롤 아래의 전용 slot에 표시한다. 라운지 배너는 최종 화면에서 제거했다. 별도 네이티브 dialog로 현황판을 열며 Escape/‘로비로’ 버튼은 현황판만 닫고 로비 버튼으로 포커스를 돌려준다. 링크는 정확한 SOOP 방송국 주소를 새 탭으로 열고 `noopener noreferrer`를 사용한다.
- 6명의 공개 방송국 정보와 큰 원본 SOOP 프로필 이미지를 확인했다. 애니메이션을 유지하고 원본 픽셀을 확대하지 않는다. 사진 로딩 실패 시 작은 원본, 그다음 이름 첫 글자로 대체하며 링크는 계속 제공한다. 방송 중 여부나 시청자 수는 추정하지 않는다.
- 기존 라운지의 9명 목록·순서·로고·CMS 저장값·계정 데이터는 변경하지 않는다. 새 현황판은 이번에 지정된 6명 명부를 사용한다.
- built-in `image_gen` 사용. 사용자 참조와 생성 PNG를 `art/`에 무손실 보존하고 웹에는 359,556바이트 WebP를 연결했다. `image-prompt.json`, `art-manifest.json`에 프롬프트·해시·제작 경로를 보존한다. 기존 C9 로고를 재사용했다. 기술 검수를 별도 시각 승인으로 기록하지 않는다.
- 실제 메인 로비의 작은 버튼 → 현황판 → 로비를 PC 1440px, 모바일 390/360px에서 확인했다. 2개 부서·6명·새 탭·역방향 opener 차단·원본 픽셀·버튼 글자색·가로 넘침·키보드/복귀 버튼·포커스 복원·기존 라운지 9명 링크 보존을 확인했다. `browser.json`, `lobby-entry-*.png`, `lobby-board-*.png`가 최종 검수다. 이전 `entrance-*.png`/`board-*.png`는 라운지 진입 초안 이력이다. 검수는 음소거이며 API는 GET 전용 로컬 fixture다.
- 국소 UI 변경으로 기존 라운지·로비 메뉴 회귀를 공식 scoped 배포에서 실행한다. 로비 생성 번들의 원본 일치 검사도 통과했다. 배포 실행기와 결과는 같은 폴더에 기록한다. 배포 후 공개 컴포넌트 검수는 실제 메인 전체 진입 검수와 구분한다.
