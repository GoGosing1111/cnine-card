# 리버스랜드 일일 이용권·150명 쿠폰·보상 5배

사용자의 최종 5배 정정을 적용한다. 핑두의 감사 선물은 미개봉 5개이고 상자 내용은 변경하지 않는다. 현재 저장 확률은 아래와 같으며 가중치 설정을 덮어쓰지 않는다.

| 보상 | 신규 당첨 수량 | 수량 단위 | 확률 |
|---|---:|---:|---:|
| 코인 | 5억~2,500억 | 5억 | 42% |
| 엠퍼러 에너지 | 5~25개 | 5개 | 5% |
| 마스터의 별 | 5,000~5,000,000개 | 5,000개 | 42% |
| 미스틱 에너지 | 5~5,000개 | 5개 | 10% |
| 핑두의 감사 선물 | 5개 | 고정 | 1% |

## 발급·초기화

한국 시간 하루에 등록 스트리머마다 10장을 자동 발급한다. 기존 1분 스케줄러가 자정 이후 처리하며 state/spin에도 같은 영수증의 보완 경로가 있다. 매일 발급하는 수량이 10장이고 사용하지 않은 잔량은 보존한다. 중단 중 놓친 날짜의 소급 발급은 없다. 날짜·계정 고유 키와 사용자 잠금, 발급 묶음·인벤토리·로그·영수증 거래로 중복을 막는다. 자동 발급 이용권의 새 쿠폰 사용 인원은 150명이며 OWNER 수동 지급 폼도 기본 150명이다.

대상 계정은 4718 강구열, 4754 조은, 4773 진짜디임, 4913 오리꿍, 4977 하이희야♡, 5209 김아윤, 5393 주성, 5426 나무늘봉순, 5950 남수댕ㅗ다. 등록하지 않은 OWNER·이전 스트리머는 자동 발급하지 않는다.

일회 도구 `scripts/ops/reverse-land-daily-20261020.mjs`는 전체 SOOPKETLAND_TICKET 인벤토리와 미사용 발급 묶음을 0으로 초기화한 뒤 오늘분을 같은 거래로 발급한다. 기존 쿠폰·추첨·사용 이력·다른 아이템은 보존한다. 초기화 전 인벤토리·묶음·등록·카탈로그·설정은 `ops:reverse-land-daily:20261020:v1:before`에 보관한다. 완료 키 `ops:reverse-land-daily:20261020:v1` 재시도는 초기화를 반복하지 않는다.

## 확인

- 관련 회귀 48개 통과: 일일 동시 요청·소진 후 재요청·한국 시간 자정·접속 지연 보완·등록 및 차단 상태·미등록 OWNER 제외·150명 상한·기존 쿠폰 최소 수량 호환·새 최대 수량 지급.
- 실제 PostgreSQL 어댑터/PGlite로 초기화+오늘 지급의 원자성, 감사 실패 시 전체 롤백, 등록 변경 차단, 재실행 후 잔액 보존, 2,500억 코인 BIGINT 지급을 확인했다.
- 운영 DB 사전 롤백 검증: 기존 251장/미사용 묶음 10개 초기화, 등록 9명 각 10장, 다른 두 보유자의 잔량 0. 이 검증 단계는 실제 반영하지 않았다.
- 기존 UI 이미지를 유지하고 금액·자동 발급 안내·인원 기본값만 변경했다. PC 1440 및 모바일 390에서 보상/OWNER 폼/결과·넘침·실행 오류를 확인했다. 기술 검수이며 새 시각 승인이 아니다.
- 기존 수량 분포의 각 결과를 5배로 변환한다. 확률을 5배 하거나 과거 쿠폰을 재가격하지 않는다.
- 새 scheduler 소스는 Worker 번들로 배포하며 Pages 정적 파일에서만 제외한다. 운영 실행 코드·이미지는 보존한다.

## 배포 및 운영

배포·일회 초기화·오늘 지급은 검증된 소스의 scoped 배포 후 실행한다. 실제 완료 영수증은 후속 절에 기록한다.
