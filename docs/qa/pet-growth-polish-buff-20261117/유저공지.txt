[펫 주사위 · 장비 연마 효과 상향 안내]

펫 성장과 장비 연마의 투자 효과를 더 크게 느끼실 수 있도록 능력치 효과를 상향했습니다.

■ 펫 능력치 주사위
등급 순서: C / B / A / S / SS / SSS

공격력 · 방어력 · 최대 체력
기존: +0 / 1 / 2 / 3 / 4 / 5%
변경: +0 / 5 / 10 / 20 / 35 / 50%

속도
기존: +0 / 1 / 2 / 3 / 4 / 5%
변경: +0 / 3 / 6 / 10 / 16 / 25%

■ 펫 고유 특성 주사위
등급 순서: C / B / A / S / SS / SSS

맹공 · 수호 · 생명 · 사냥꾼
기존: +1 / 2 / 3 / 5 / 7 / 10%
변경: +2 / 5 / 10 / 20 / 30 / 50%

질주
기존: +1 / 2 / 3 / 5 / 7 / 10%
변경: +1 / 3 / 6 / 10 / 16 / 25%

행운
기존: +1 / 2 / 3 / 5 / 7 / 10%
변경: +2 / 4 / 7 / 12 / 18 / 25%

맹공은 공격력, 수호는 전투 시작 보호막, 생명은 최대 체력, 질주는 속도를 높입니다.
사냥꾼은 PvE 보스 피해, 행운은 PvE 코인 획득에 적용됩니다.
펫 종류별 기본 효과와 성장 가능한 최고 등급은 유지됩니다.

■ 장비 연마 효과 3배 상향
연마 성공 1회당 상승량이 다음과 같이 바뀝니다.

공격력: +2% → +6%
치명타 확률: +0.5%p → +1.5%p
치명타 피해: +3%p → +9%p
보스 피해: +2% → +6%
방어 관통: +0.5%p → +1.5%p

예를 들어 공격력 옵션 20단계는 +40%에서 +120%로 적용됩니다.
캐릭터 장비는 기존 PvE 적용 범위를 유지하며, 용병 개인 장비 연마는 해당 용병이 장착한 모드의 PvE·PvP에 적용됩니다.

■ 기존 성장도 자동 반영
이미 확정한 펫 등급과 기존 연마 단계에 새 효과가 적용됩니다. 다시 주사위를 굴리거나 연마할 필요가 없습니다.
선택 대기 중인 주사위 결과도 그대로 유지되며, 기존 유지·새 결과 적용을 추가 비용 없이 선택할 수 있습니다.

주사위 비용·등급 확률, 연마 성공률 10%, 장비당 성공 50회·옵션별 20단계 제한은 변경되지 않습니다.
연마 1회 비용도 기존과 동일한 코인 10조·마스터의 별 3천만 개·연마석 1개입니다. 꽝일 때도 동일하게 소모됩니다.

새 효과는 새로 시작하는 전투에 적용됩니다. 게임을 새로고침한 뒤 펫 도감과 장비 연마 화면에서 상향된 수치를 확인해 주세요.
