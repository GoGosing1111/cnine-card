# SSS 리미티드 첫 궁극기 컷신 · 전용 대사창

대상: 제로 V-976, 프라임 레퀴엠 V-975, 제너럴 족 V-974, 카드구 V-970, 레반 V-971.

사용자 최종 요구는 첨부 화면의 가로 얼굴 클로즈업만 사용하고, 궁극기에 한 번만 표시하며, 용병에 맞춘 새 대사 리소스를 제작하는 것이다. 각 전투의 각 용병이 처음 사용하는 PVE 광역 궁극기에 1.15초 컷신을 한 번 표시한다. 후속 궁극기는 컷신을 반복하지 않고 해당 기술의 대사와 기존 공격 모션을 재생한다. 숨김/복귀·취소·같은 전투의 배우 재생성으로 표시 횟수를 초기화하지 않는다. 새 전투만 초기화한다.

## 전용 원화와 대사

- 제로: 은청색 검날과 사파이어.
- 프라임 레퀴엠: 붉은 기계 장갑과 녹색 코어.
- 제너럴 족: 황금 함대·포신·지휘 문장.
- 카드구: 검은 포커 카드·스페이드·왕관.
- 레반: 흑적 대검·갈라진 검날.

내장 image_gen으로 다섯 프레임을 각각 새로 생성했다. 발테르·헬리오스·진무의 그림/테두리/장식을 가져오지 않는다. 기존 공용 대사 레일의 위치 계산과 수명 관리만 사용한다. dialogue-generation.json에 최종 프롬프트, 원본 절대 경로와 SHA-256, 프로젝트 WebP의 SHA-256·알파·크기를 보존한다. 원본 PNG를 변경하지 않고 알파를 유지한 WebP 파생물 5개를 런타임에 연결했다.

최종 프레임: assets/ui/project-v/mercenaries/sss-area-dialogue-20261028/.
16개 기술별 새 대사는 shared/mercenary-area-cutins-v1.mjs에 있다. 레반 멸참은 실제 서버 영수증 MS-929 + visualMode=myeol을 그대로 따른다.

## 구현 범위

공통 Pixi 8.20.0/GSAP 3.13.0의 기존 엔진 시계를 사용한다. 승인된 각 용병의 원화 텍스처를 사선 가로 마스크로 표시한다. 별도 전신 확대·스킬 제목 패널·캔버스 내 대사 상자는 없다. 첫 연출 완료 후 원래 서버 이벤트를 정확히 한 번 기존 광역기 재생기로 전달한다. 시간 기반 전투의 다음 일반 행동도 이 연출과 타격을 기다린다.

서버 전투 계산·능력치·피해량·타깃 수·에너지·재사용 대기·성장·획득·발행·계정 보유 및 출시 플래그를 바꾸지 않는다. 운영 계정/API 쓰기 0건이다. PVP·기본 공격은 추가 컷신과 대사 레일을 만들지 않는다. 초기 공용 프레임 시안과 전신 확대 시안은 이 최종안으로 대체했다.

공통 10개 V3 소비 번들을 재생성하고 메인/원스토어의 로더·캐시 버전을 함께 갱신했다. 이전 Cardgu/Revan 테스트의 11개 번들 고정 수와 이전 버전 접미사 기대값은 변경 전 main에서도 맞지 않는다. 그 무관한 테스트를 수정하거나 이번 배포 게이트로 사용하지 않았고, 현재 배포 보고서 전체 해시와 실제 메인 로더를 검사하는 새 테스트를 사용했다.

## 배포

직전 운영은 Cloudflare 읽기 전용 확인으로 Pages 1fcc7153 / 소스 48ec1eac0097c2863d9dbca297e192a0878a3649이다. 기존 희소 작업 폴더를 재사용한다. 배포는 release.mjs로 지정된 npm run deploy:production -- --scoped만 실행하며 결과와 공개 20파일 해시·두 Worker 상태를 기록한다. 최종 상태는 completion.json을 따른다. 저장공간 유지관리·예약·과거 지급 재실행은 하지 않는다.
