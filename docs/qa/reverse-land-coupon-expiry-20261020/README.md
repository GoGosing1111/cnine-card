# 리버스랜드 공유 쿠폰 8시간 자동 소멸

사용자: “리버스랜드 쿠폰은 8시간뒤에 자동소멸되게 변경해”.

## 적용

- `SLD-` 공유 쿠폰은 발급 시각 + 8시간부터 신규 사용 불가다. 기존 발급 코드도 동일하다.
- 사용자가 받은 리페어 쿠폰 등 인벤토리 아이템, 코인·카드, 미사용 랜드 이용권은 이 제한 대상이 아니다.
- 발급·수령 기록은 삭제하지 않는다. 성공한 요청의 영수증 재시도는 만료 후에도 같은 결과를 반환하며 재지급하지 않는다.
- 새 발급 응답·쿠폰·추첨 기록은 동일한 발급 시간을 저장한다. 재시도·히스토리 조회는 원래 쿠폰 시간을 읽고 재발급하거나 기한을 연장하지 않는다.
- 실제 수령 거래에서 계정·쿠폰 행을 잠근 다음 PostgreSQL `clock_timestamp()`로 기한을 다시 확인한다. SQLite는 `julianday('now')` 기준이다. 요청이 대기하는 중 만료되면 지급·사용 횟수·영수증을 함께 롤백하고 `LAND_COUPON_EXPIRED`를 반환한다.
- 기존 `created_at`을 사용하므로 스키마 변경·기존 쿠폰 일괄 수정·만료 스케줄러가 필요 없다. 시간이 지나면 수령 조건이 즉시 거짓이 된다.
- 당첨 결과·보관함·OWNER 목록에는 만료 시각과 남은 시간을 표시한다. 서버 시각 보정으로 PC 시간이 잘못되어도 표시를 맞추며, 화면을 계속 열어 두어도 만료된 코드와 공유 안내가 숨겨진다.
- 기존 UI의 정보 행·리페어 이미지·디자인을 유지한다. 새 배지·패널이나 장식 이미지는 추가하지 않는다.
- 코인/에너지/마별/미스틱/감사선물/리페어 60/5/14/10/1/10%와 일일 10장·쿠폰 150명 정책을 유지한다.
