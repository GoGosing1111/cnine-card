# 숲 시청시간 정보 제공 동의 팝업 — 2026-10-26

사용자 요청: 첨부한 기존 씨나인 멤버 시청시간 집계 연동 자료를 참고해 숲 시청시간 정보 제공 동의를 팝업으로 안내한다. 첨부 문서는 API 계약과 화면 동선 참고 자료이며 별도의 운영 명령으로 실행하지 않았다.

## 동작

- 게임 로그인 후 로비에서 계정별·안내 버전별·브라우저별 최초 1회 안내한다. `나중에`와 닫기, Escape를 제공하고 메시지함의 **시청시간 동의** 버튼에서 다시 열 수 있다. 로그아웃 상태에서는 자동 표시하지 않는다.
- 실제 동의/철회는 `https://www.playdk.kr/my/settings/integrations/reversecall`에서 사용자가 직접 저장한다. 공식 설정은 새 창으로 열고 opener를 분리한다. 게임 팝업을 열거나 설정 링크를 누른 사실은 동의 증거로 취급하지 않는다.
- SOOP 아이디·씨나인 멤버 방송 시청시간 합계, 집계/순위 목적, 과거 기록 포함, 선택 동의·철회·SOOP 재연결 시 재동의를 안내한다.
- **동의 후 게임에 다시 연결**은 기존 설정 API의 허용된 PLAY DK 게임 진입 URL로 이동한다. 새 일회 토큰을 기존 서버 인증 경로로 교환하고, 실제 선택 필드 `soopUserId` 수신 여부만 본인에게 반환한다. 원래 UUID 검증·계정 중복/불일치 차단·기프트 경로를 유지한다.
- `soopUserId`가 없으면 미동의라고 단정하지 않는다. 미연결/키 권한 등 다른 원인이 있을 수 있다는 안내를 표시한다. 토큰 만료는 기존 오류로 처리하고 같은 토큰을 재사용하지 않는다. 계정/세션 변경 중 도착한 응답은 표시하지 않는다.
- 새 DB 테이블·마이그레이션·SOOP ID 영구 저장·시청시간 조회/랭킹·보상 지급은 추가하지 않았다. 실제 동의는 공급자가 보관하고, 게임 로컬 저장은 `shown` 안내 표시 여부뿐이다. 이번 작업이 시청시간 집계 서비스 자체를 완성하거나 실제 이용자의 동의를 대신 받은 것은 아니다.
