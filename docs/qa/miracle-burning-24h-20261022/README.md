- 기존 10분·30분을 유지하고 1~24시간을 1시간 단위로 선택한다. 미라클 전용 API의 허용 목록을 확장했으며 CMS는 서버의 `allowedDurations`로 선택지를 구성한다.
- 선택/발동 확인/미리보기는 `24시간`처럼 시간 단위로 표시한다. 최대 24시간의 종료 시각, 재조회와 공개 상태, 정확한 만료 경계를 기존 실제 처리기 회귀에서 확인한다. 24시간 초과·임의 분·소수 등 잘못된 요청은 저장하지 않는다.
- 기본값 1시간·100배, 코인 최대 300배, 전용 OWNER 권한, 일반/하이퍼의 기존 시간 목록과 다른 정책은 유지한다. 현재 운영 이벤트를 발동하거나 재설정하지 않는다.
