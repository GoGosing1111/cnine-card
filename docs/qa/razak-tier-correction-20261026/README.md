# 라자크 리미티드 위계 정정 — 2026-10-26

사용자는 이전 결과 “SSS 리미티드 상대 승률 84.9%, 12종 모두 승리 확인”을 잘못된 방향으로 지적하고, 목표를 **“일부 하위 리미티드와만 대등하고, 상위 리미티드에는 열세”**로 확정했다. 이 정정이 이전 v3 상향 기준보다 우선한다. 이전 실험 결과를 오류로 지우지 않고, 잘못 해석한 목표와 과한 성능을 v4로 수정한다.

## 검증

`before/live-after.json`은 정정 전 운영을 새로 읽은 READ ONLY 스냅샷이다. CMS r61·성장 r1·팩/성장/전투 설정 해시와 라자크 외 56종이 이전 측정 입력과 같다. `candidate-loader.mjs`는 후보 정책만 메모리에서 치환하며 실제 서버 파일이나 운영 DB를 바꾸지 않는다. a~l 후보는 시드 120001~120004, 선택한 l 검증은 130001~130016을 사용했다.

정책 확정 뒤 **사용하지 않은 150001~150032 시드의 46,592전**을 실제 서버 엔진으로 측정했다. 같은 일반 카드 5장·장비·마법·용병 레벨/장비, 13조건 동일 가중치, 공격/방어를 교환하며 펫은 제외했다. 이는 **실제 이용자 승률이나 용병 단독 결투가 아닌 팀 전투 실험**이다. 조건별 결과는 `holdout.json`에 보존한다. 후보를 선택한 시드와 최종 검증 시드를 구분한다.

`acceptance.mjs`는 최종 시드 실행 전에 정한 하위 2종 40~65%, 중위 3종 60% 미만, 상위 7종 40% 미만, 일반 SS 최소 98%, SS 리미티드 평균 80% 이상·각 상대 50% 이상을 검증했다. 하위/중위/상위 구분은 이번 목표 검증용이며 게임 등급을 변경하지 않는다. 모든 상대의 시작 수치는 이전 v3 실험과 동일하며, 라자크가 없는 PVE/PVP **1,456건**의 전체 결과 해시도 이전과 같다.

전용 정책/스킬/획득 관련 검사 13개 통과. `browser/browser-report.json`의 실제 V3 PC·모바일 아군/적군 전투 및 도감 5개 확인 통과. 기존 검사에서 바뀐 수치·행동 수·설명 기대값만 갱신했다. 공식 배포에서는 관련 성장·행동·듀오·블러드문 회귀와 전장 진입 연결 검사를 함께 수행한다.
