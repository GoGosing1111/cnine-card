# 트로피 3종 · 2026-10-23

사용자 요청: 푸른제국(챌린저 20회), 리미티드 에디션(SSS 리미티드 80% 보유), 충신 무공훈장(주간 퀘스트 20회).

최신 사용자 정정: **“전체도감기준으로해 / 리미티드”**. 이전 “주간퀘스트 글작성만 인정 나머지 맞음”에서 주간 글 작성과 공식 시즌 기준은 유지하고, 리미티드 분모는 전체 도감으로 확정한다.

- 푸른제국: 공식 랭크 시즌 종료 시 챌린저 최종 정산 누적 20시즌. 연속 여부와 무관하다.
- 리미티드 에디션: 전체 도감에 등록된 SSS 리미티드 용병의 서로 다른 종류 80% 이상. 중복 보유는 1종이며, 필요한 종류 수는 올림한다. 획득 불가·운영 전용·재고 소진 종류도 포함하며 현재 보유 및 전체 도감으로 표시한다.
- 충신 무공훈장: 글 작성 주간 퀘스트 완료 및 보상 수령 누적 20회. 다른 주간 퀘스트와 같은 영수증의 재조회는 제외한다.

## 원화

내장 ImageGen으로 각각 별도 제작했다. 원본 PNG는 변경하지 않고 보존하고, 512×512 투명 WebP를 명함에 연결했다. 이름과 달성 수치는 이미지에 굽지 않는다.

- `assets/ui/player-card/milestones-20261023/manifest.json`: 원본·파생 자산 SHA-256, 해상도, 투명도 확인.
- 같은 폴더의 `prompts.json`: 실제 생성 프롬프트 및 사용자 집계 기준 확인 기록.
- 생성 결과를 기술 검수한 것이며 사용자 시각 승인으로 기록하지 않는다.

## 검수

명함의 기존 진열장과 상세 보기를 사용한다. PC 1440px 및 모바일 390px에서 세 원화 로드, 이름·진행도, 페이지 이동, 선택, 미획득 상태 및 닫기를 확인했다. 화면 예시는 디자인 검수 데이터이며 운영 지급 기록이 아니다.

신규 트로피의 효과 기본값은 모두 0%다. 기존 8종 또는 9종 CMS 설정은 기존 수치를 보존하고 새 항목을 0%로 보완해 읽는다. 조회 중 설정이나 운영 기록을 쓰지 않는다. 과거 8종 운영 일괄 지급은 신규 트로피로 확대하지 않는다.

리미티드 분모는 실제 도감의 SSS LIMITED 목록을 사용한다. 최신 은설을 포함한 11종 중 80%는 올림하여 9종이다. 팩 ON/OFF, 확률, 잔여 재고, 획득 잠금 또는 계정의 지갑·개인 이용 제한으로 분모를 축소하지 않는다. 정정 전 획득 가능 3종 기준 검증은 비공개 작업 이력으로만 보존하며 최종 기준이 아니다.

관련 검증은 명함, 신규 집계, 기존 설정 호환, collection, 기존 월드레이드, 트로피 헌터 칭호 및 배포 원본 보존을 대상으로 한다. 중복·미수령·다른 계정 영수증·미완료 시즌·전체 도감 비율·읽기 중 쓰기 방지를 확인한다. 신규 0% 효과 때문에 기존 보상 처리에서 추가 획득/퀘스트 조회를 하지 않는다.

운영 배포 및 최종 산출물 확인 결과는 완료 후 이 문서에 기록한다.
