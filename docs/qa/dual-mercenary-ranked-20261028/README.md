# 용병 2명 전투 엔진 · 랭크전 차전별 2명 준비

사용자 요청: 전투 엔진 용병 2명 편성 준비. 후속 답변으로 랭크전의 기존 출전 순서 지정도 매 차전 2명으로 늘리는 것으로 확정했다. 전투 중 선택 방식으로 바꾸지 않는다.

- 일반 카드 5장과 용병 2명은 별도 배열이다. 같은 코드의 동시 편성을 거부하며 SSS는 리미티드를 포함해 1명, SS도 1명만 배치한다. S 이하의 서로 다른 용병은 같은 등급도 가능하다. 사용자 최종 규칙이 기존 전 등급 중복 금지보다 우선한다. 기존 단일 `mercenary` 인수와 운영 저장은 유지한다.
- 랭크전은 1·2·3차전 각각 2명, 서로 다른 6종이 한 번씩 출전한다. 먼저 2승하면 종료하며 매 차전 체력·기력·상태를 새로 만든다. 두 용병을 한 차전 단위로 앞/뒤 이동한다.
- 6종 로스터/매칭권은 기존 3종과 다른 v2 키에 저장하도록 준비했다. 운영에서 자동 저장·계정 마이그레이션하지 않는다. 기존 시즌·행동력·점수·보상·펫 정책을 바꾸지 않는다.
- 보유권·현재 서버 등급·revision·매칭 중 변경·매칭권 고정·상대 순서 비공개·세트당 1회 정산은 서버에서 검증한다. 여섯 슬롯의 성장 조회는 사용자별 배열을 한 번에 전달해 두 사용자 12종도 성장 SQL 1회다.
- 현재 용병의 개별 행동 배율과 성장 보너스를 각각 누적한다. 한 용병의 행동이나 한도 소진이 다른 용병의 행동을 소모하지 않는다. PVE 피해 합계에 두 용병을 각각 한 번 포함하며 슈트는 별도 슬롯이다.
- V3의 기존 카드/첫 용병/슈트 위치는 유지하고 두 번째 용병을 빈 격자에 배치한다. PC·모바일, 양측 2명과 차전 교체를 지원한다.

## 최종 사용자 규칙 및 공지

SSS 일반·SSS 리미티드는 같은 SSS 한도를 공유한다. SSS+SS, SSS+S, SS+S, 서로 다른 S+S 등은 가능하며 SSS+SSS, SS+SS는 불가하다. 여섯 종 전체의 SSS 수를 1명으로 제한하는 것이 아니라 **동시에 출전하는 차전별 2명**에 적용한다. 실제 CMS의 정규 rank를 기준으로 한다.

공지 문안 `notice.txt`는 사전 안내이며 게시/발송하지 않았다. 실전 개방 날짜를 임의로 확정하지 않았다.
