## 변경

상위 등급이 레벨에서 뒤처질 때 추가 등급 보정의 유지율을 `max(0, 1 - 레벨 차이 / 10)`으로 계산한다. 등급에 따른 공격·피해 상한·체력·방벽 추가분과 상대 성장 배율 보완의 지수에 적용한다. 5레벨 차이는 절반, 10레벨 이상 차이는 추가분이 없다. 원래 용병의 고유 능력치는 유지한다.

고레벨의 경감 관통·행동 대응에 걸리던 등급 감쇠도 같은 유지율로 완화한다. 10레벨 이상 높으면 배운 숙련을 100% 적용한다. 같은 전투 등급, 같은 레벨의 기존 등급 우위, PVE, 구형 성장 및 기존 개별 상성 정책은 보존한다. 듀오는 상대 최고 등급과 가장 큰 레벨 차이를 사용해 저레벨 동료로 추가 보정을 되살릴 수 없도록 한다.
