# 종언 레이드 6인 리듬 판정

11월 26일 운영 서버에 저장된 노말 6인 전투 두 판의 입력을 채보와 대조했다. 174노트 곡과 239노트 곡에서 각각 35개의 유효 입력이 적중 기록에서 빠졌다. 여섯 명이 동시에 플레이할 때 입력이 기존 1.5초 수신 기한을 지나 도착하는 상황을 재현했다.

6인 리듬 입력은 최대 6초의 전송 지연을 허용한다. 서버는 각 입력의 원래 시각과 레인으로 PERFECT 80ms, GOOD 160ms를 판정한다. 곡 끝에 전송 중인 마지막 입력을 기다린 시간만큼 다음 발판과 광폭화 시각을 옮긴다. 화면은 리듬 입력을 묶어 전송하고 서버에서 마지막으로 처리한 순번을 받는다.

## 검증

- 운영 기록에 남은 입력 1,656개를 두 곡에 재생했다. 채보에 맞은 1,477개가 적중했고, 기존 기록에서 누락된 70개가 모두 포함됐다.
- 두 곡을 노말과 헬에서 6명 전원으로 재현했다. 중첩·재전송한 입력과 지연된 마지막 노트, 헬 롱노트를 한 번씩 집계하고 다음 발판 단계로 넘어갔다. 160ms를 벗어난 타격과 실제 미입력도 구분했다.
- 격리된 6인 방에서 Chromium 한 명은 변경한 키 배열로 플레이하고 나머지 다섯 명은 동시에 레이드 API로 입력했다. 최대 3.6초 지연에서 화면 174콤보, 서버 전원 174/174개 적중·MISS 0을 확인했다. 같은 환경에서 한 노트를 건너뛰자 화면 콤보가 한 번 끊겼고 해당 참가자만 173/174개 적중·MISS 1로 기록됐다.
