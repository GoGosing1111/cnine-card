# 코인 10경 보유 오류 수정 — 2026-11-06

요청: 코인 보유 100,000,000,000,000,000(10경)까지 PVE 및 다른 콘텐츠가 오류 없이 동작하도록 수정.

## 원인과 수정

PostgreSQL BIGINT 지갑을 Number로 읽은 뒤 예상 잔액을 비교하거나 MAX_SAFE_INTEGER로 제한하여, 실제 지급이 맞아도 보상 증명이 실패하거나 큰 지갑 자체를 거부했다. 특히 10경+1에서 보상 10코인을 더하면 Number 결과가 위로 반올림되어 PVE 거래가 거부된다.

- 새 공용 정수 도구로 CAST(coin AS TEXT) 읽기, BigInt 계산, 큰 JSON 잔액의 십진 문자열 직렬화를 적용. 실제 저장 한도 9,223,372,036,854,775,807은 유지한다.
- 통합 PVE 드랍·고철장·아포칼립스·월드레이드 정산과 영수증을 정확한 잔액으로 검증하고 원장은 실제 DB 잔액을 기록한다.
- 협동전·디펜스·클랜·듀오·선물박스·시즌패스·족각시티 메시지의 잘못된 지갑 제한 수정. 아이템 수량/거래 금액 제한은 유지한다.
- 슈퍼스타/얼티메이트 일괄 구매, 진화, 영치금의 차감과 영수증 검증 수정. 과거 숫자형 얼티메이트 완료 영수증은 재결제 없이 조회한다. 새 큰 잔액은 정확한 문자열을 사용한다.
- 화면 표시용 기존 Number 필드는 유지하되 높은 잔액의 정상 구매 응답을 거부하지 않는다. 권위 있는 보유/가감/원장은 정수로 처리한다. 웹/스토어 캐시와 공용 모듈 배송을 갱신한다.

## 검증

수정 전 재현은 operations/coin-100quadrillion-20261106/ 로그에 보존. 2^53 경계 및 10경-1/10경/10경+1, 작은 홀수 증감, 실제 저장 한도 초과, 실패 원복과 같은 요청 재시도를 검사했다. 격리 PostgreSQL/SQLite 경로와 실제 서버 함수 사용.

PC1440/모바일390/320에서 실제 앱의 일괄구매 함수와 실제 API 처리기를 연결해 1,000회/10,000회 완료, 응답 유실 후 동일 요청 복구, 계정 전환 보호를 확인했다. 운영 계정 변경 및 실기기/설치앱 직접 검수는 하지 않았다. 최종 배포 검사와 공개 검증은 완료 후 아래에 기록한다.
