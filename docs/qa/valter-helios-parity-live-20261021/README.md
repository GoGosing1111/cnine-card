# 발테르 헬리오스 동급 조정 — 2026-10-21

사용자는 전투력 상승 없이 발테르를 헬리오스 동급으로 높이는 방안을 요청한 뒤 `반영해`로 제안 적용을 지시했다. 발테르 V-996의 전투 정책만 상향하며 기존 전투력과 경제 정책을 보존한다.

## 적용 수치

| 항목 | 이전 | 적용 |
| --- | ---: | ---: |
| 기본 전투력 | 1,080,000 | 1,080,000 |
| 자연 속도 배율 | 3 | 3.12 |
| 일반 카드 행동당 추가 행동 적립 | 3 | 3.12 |
| 일반 카드 25회당 추가 행동 | 75 | 78 |
| 카드 평균 공격력 기준 연계 하한 | 1,760% | 1,830.4% |
| 카드 평균 최대 체력 기준 연계 하한 | 1,120% | 1,164.8% |

| 장비를 제외한 고유 방어력 보너스 | 0% | 12% |

고유 방어력 보너스는 기본 전투력 1,080,000에서 산출한 방어력의 12%를 반올림해 더한다. 장비 방어력에 보너스를 곱하지 않는다. 이후 기존 성장 배율을 한 번만 적용한다. 보너스는 표시 전투력·매칭 전투력에 가산하지 않는다.

피해 경감 75%, 개인 면역과 베르칸 카운터, 기본 공격 상한 2배, PVE 종결 집행 총 560%·에너지 35·재사용 5행동, PVP 기본 공격, 모션 배속 2.5는 유지한다. 헬리오스의 실제 전투 정책은 변경하지 않는다. 성장·장비·가격·확률·발행·지급·CMS 운영 설정도 변경하지 않는다. 서버에서 새로 생성하는 전투부터 적용하며 저장된 전투 결과를 다시 계산하지 않는다.

## 구현

- `shared/mercenary-valter-v1.mjs`: 전투 정책 V3와 도감 설명.
- `functions/_mercenary_combat.js`: 고유 방어력 보너스와 기존 장비/성장 경로 연결.
- `shared/mercenary-helios-v1.mjs`: 소수 추가 행동 적립을 발테르에도 명시적으로 적용하고, 과거의 헬리오스 4% 우위 설명 정정. 기존 공개 함수 이름과 헬리오스 수치는 유지.

## 검증

- 발테르/헬리오스 신규 정책·행동 주기·PVE 광역·듀오·기존 55종 비교·장비 경로 관련 **42개 테스트 통과**. 변경된 연계 수치를 이전 8배로 가정하던 검사를 실제 카드 평균 기준 18.304배로 갱신했다. 과거 헬리오스 검사에서 현재 PVP 편성 전투력 보정을 빠뜨린 기대값은 해당 기존 규칙에 맞췄다. 수정한 실패 2개만 다시 실행했다.
- `current-engine.json`: 현재 서버 구현의 PVP **18,432회**, 발테르 승리 **9,077회(49.2459%)**. 앞서 제안한 고유 방어 +12% 실험의 **72개 덱/레벨/장비/전투력 셀에서 승패 수가 전부 일치**한다.
- 실험은 고정 입력·동일 조건·양 진영 교차 모의전이다. 실제 이용자 승률이나 모든 콘텐츠에서의 완전 동일 성능을 뜻하지 않는다. 18개 레벨/장비/전투력 조건 중 17개는 48.6~51.4%였고, Lv.20·일반 카드 전투력 10만·장비 없음 조건은 38.1%였다. 이 한계는 제안 당시부터 유지한다.
- `browser-report.json`: 실제 서버 PVE/PVP 타임라인을 배포용 V3 번들·메인 래퍼로 PC 1440×1000, 모바일 390×844에서 재생한 **4개 흐름 통과**. 세 번 연속 공격, HP 동기화, 대기 복귀, 기존 2.5배속, 가로 넘침 없음, 페이지 오류 없음 확인. 저장한 4장 화면도 직접 확인했다. 이 검수는 신규 사용자 시각 승인 기록이 아니다.
- 과거 실험은 `../valter-helios-parity-20261021/`에 원문 보존한다. 재현 도구는 `scripts/measure-valter-helios-parity-20261021.mjs`이며 기본 대상은 과거의 고정 커밋이다. 이를 현재 운영 측정으로 혼동하지 않는다.
