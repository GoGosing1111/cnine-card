# 몬스터 디펜스 보상 확장 · 2026-10-26

사용자 요청: 보상 종류를 다양하게 설정하고 난이도별 코인 수급량을 구분한다. 후속 답변은 **아이템별 확정·확률 보상과 수량 범위**, 코인은 **나중에 직접 결정**이다.

## 구현

- OWNER CMS → 디펜스 → 난이도별 클리어 보상에서 입문/보통/어려움/악몽/재앙 코인을 각각 저장한다. 기존 마스터의 별도 유지한다.
- 난이도마다 최대 20종의 지급 가능 인벤토리 아이템, 확률 0~100% (소수점 둘째 자리), 최소~최대 각 1~100,000개. 100%는 확정, 최소=최대는 고정 수량, 0%는 지급하지 않는다. 각 참가자/아이템별 독립 추첨이다.
- 기존 `{code, quantity}` 고정 보상은 동일한 형태로 읽고 저장한다. 확장 규칙만 `{code, chancePercent, minQuantity, maxQuantity}`를 쓴다. 운영 설정 마이그레이션이나 임의 지급을 하지 않는다.
- 코인 0~1조/마스터의 별 0~1천만의 기존 상한, ON 실전/최종 웨이브/실제 참가자 검증, TEST·연습·패배 지급 차단, OFF 긴급 중지, OWNER 권한/CAS 저장을 유지한다.
- 방 생성 때 비공개 난수 시드를 저장한다. 보상 추첨은 플레이어/아이템/확률·수량별 SHA-256 도메인 및 편향 없는 정수 선택을 사용한다. 전투 시드와 분리하며 스냅샷/API 결과에 보상 시드를 노출하지 않는다. 저장된 확률·수량은 새 방부터 적용한다.
- 기존 영수증 키를 유지하며 코인/인벤토리/로그/전원 결과를 한 DB 트랜잭션으로 확정한다. 오류·재시도·재접속·동시 요청은 재추첨이나 이중 지급을 하지 않는다. 모두 미당첨이면 완료 영수증과 미당첨 안내만 남긴다.
- CMS는 승인된 공통 남색 패널/연두 행동 버튼을 재사용한다. 로비에는 난이도별 코인과 확률·수량 범위, 결과에는 실제 받은 수량과 미당첨을 표시한다.
