사용자 Safari 제보 → 수정·배포·유저 공지 요청에 따른 전투 리소스 수정이다.

## 변경

- 명시적인 전투창 닫기에서 렌더러와 해당 전투의 카드·용병 원화·모션 이미지·배경을 회수한다. 재입장은 이전 초기화·재생 취소·이미지 다운로드·해제가 끝난 뒤 시작한다. 공통 HUD·역할·탄도 효과의 프레임 캐시는 보존한다.
- 종료된 렌더러의 늦은 닫기가 새 전투를 중단하지 않도록 소유자를 확인한다.
- 군단토벌 iframe 진입 전에 비활성 부모 전투 정리를 기다린다. 대기 중 입장창을 닫으면 iframe을 만들지 않는다.
- 아트 어댑터가 고른 SD와 컷인에 기존 승인 768/384 WebP 매핑을 적용한다. 미등록 이미지는 기존 원본을 유지한다.
- 탭 숨김·앱 전환은 명시적 닫기와 구분한다. 행동력, 코인, 보상, 환급, 전투 피해, 원화 및 UI 배치는 변경하지 않았다.
