# 용병 성장 V2 전투 검수 보고서

2026-10-15 · 준비 전용 · 운영 미반영 · `MERCENARY_LEVEL_RELEASE_ENABLED=false`, `PVP_POWER_BALANCE_RELEASED=false`

## 검수 결론

고레벨 일반 SSS가 저레벨 리미티드에게 실제 승리할 수 있는 경로를 전투 엔진에 구현했다. 성장으로 모든 조합이 경쟁하거나 모든 일반 SSS가 리미티드와 동급이 되는 결과는 아니다. 기존 일반 SSS 4종 × 리미티드 5종의 20개 상대 조합 모두 Lv.20 대 Lv.1에서 승리 사례가 있었으나, 조합·전력대별 편차가 크고 평균 승률은 낮다. 동일 레벨에서는 기존 리미티드 우위가 그대로 매우 강하다. 수치는 검수 후보이고 출시 승인 값이 아니다.

## 왜 능력치 증가만으로 부족했는가

현행 발테르는 일반 SSS와 비교해 공격 연계 1,760% 대 220%, 체력 연계 1,120% 대 280%, 아군 카드 행동당 추가 행동 3 대 1이며 피해를 75% 경감한다. 베르칸 피해에는 별도 완전 면역이 있다. 무장 없는 예시 자연 속도도 84,450 대 4,750이다. 단순한 소폭 능력치 상승은 공격 기회와 유효 피해를 확보하지 못했다. 기존 기본 전투력·연계·고유 행동·면역을 전역 하향하지 않고 성장 전용 숙련으로 보완했다.

## 확정한 검수 후보와 적용 순서

- 매 레벨: 체력 +25%, 공격 +25%, 방어 +6%, 속도 +1%. 레벨 1은 증가 없음.
- 5·10·15·20 돌파마다: 체력 +100%, 공격 +125%, 방어 +15%, 속도 +2%, 배정 스킬 계수 +5%.
- 돌파 관통 숙련: 각 +12.5%, 누적 최대 50%. 상대보다 높은 레벨에서만 사용하며 10레벨 차이에서 학습량 전부, 5레벨 차이에서는 절반을 사용한다. 적 고유 경감으로 사라질 피해의 해당 비율만 복구한다. 관통 숙련 50%일 때 75% 경감은 최종 37.5% 경감으로 남고, 베르칸 완전 면역은 해당 공격의 50%만 유효해진다. 동일 레벨·PVE·일반 카드에는 적용하지 않는다.
- 행동 대응 숙련: 각 +10·15·20·25%, 누적 최대 70%. 같은 레벨 차이 계수로 상대의 **성장 적용 전** 자연 속도 일부를 최소 속도로 확보한다. 원래 속도가 더 높으면 변화가 없다. 상대 성장·대응 결과·전투력 보너스를 다시 참조하지 않는다. V1 성장 스냅샷의 속도는 참조 후보에서 제외한다.
- 추가 행동 숙련: 각 +10·15·20·30%, 누적 최대 +0.75회/해당 덱의 아군 카드 행동. PVP에서 고유 행동량에 가산한다. 일반 1→1.75, 발테르 3→3.75이며 곱하지 않는다. 듀오에서도 각 소유자의 카드가 해당 용병에게만 행동량을 제공한다. PVE 고유 행동 주기는 유지한다.
- 누적 성장량은 기존 카드 연계·개인 장비가 반영된 능력치에 **한 번만** 적용한다. 본체 공격과 연계 공격은 최댓값을 선택하는 기존 구조를 유지한다. 체력 비율을 보존하고 기존 시작 방벽을 증폭하지 않는다. 스킬 비용·재사용·대상 수는 바꾸지 않는다.
- 성장 파생 능력치를 표시 전투력에 다시 더하지 않는다. 별도 PVP 전투력 보너스는 기존 서버 편성 전력에 따라 피해 최대 +20%, 행동 게이지 최대 +8%만 적용한다.

## 운영 상태

기본 `growth:null`, 경험치·돌파 확률 미입력 null, 레벨/PVP 보너스 OFF를 유지한다. 검수 프로필을 CMS나 DB에 저장하지 않았으며 배포·지급·개방·공지 게시를 하지 않았다. 레벨과 전투력 보너스는 후속 출시 승인 시 함께 적용한다.
