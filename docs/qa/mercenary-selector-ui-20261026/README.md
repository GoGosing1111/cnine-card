# 용병제작 선택 버튼 공통 리소스 — 2026-10-26

사용자 요청: “용병제작 버튼 리소스 교체해라 죄다 족로스타일이라 안어올림”.

## 변경

모든 용병 선택 버튼이 족로 전용 `jokro-craft-20261021/panel.webp`를 사용하던 CSS 묶음을 분리했다. 기존 승인 공통 UI인 남색 `panel-v3.webp`와 선택 시 연두색 `action-user-approved.webp`를 연결한다. 공통 `cn-command-ui / cn-ui-button / primary`와 48/16·38/9 9-slice를 그대로 사용한다. 새 이미지 생성·복제는 없다.

각 용병 초상화, 일반/리미티드 조각 구분, 남은 수량·제작 OFF·한정 수량 소진 문구, 제작식 ID와 선택 동작은 보존한다. 제작 잠금·재료·비용·확률·재고·보유·지급·서버 정책은 변경하지 않는다. 족로 본문의 전용 테두리는 해당 용병 화면에만 유지한다.

선택 버튼은 짙은 글씨와 흰 키보드 포커스를 사용한다. 모바일 선택 버튼의 안쪽 여백과 한글 줄바꿈을 정리했다. 제작소 스크립트/CSS URL에 `selectorUI=20261026-v1`을 추가하고 메인 앱·서비스 워커 캐시 버전을 함께 갱신한다.

## 검수

`browser.mjs`는 실제 제작소 렌더러·스타일과 정본 제작식 변환 함수를 사용하며, API는 격리된 GET-only 데이터다. 예시 수량/재료를 운영 설정으로 저장하지 않는다. PC 1440px·모바일 390/320px에서 다음을 확인했다.

- 기존 버튼이 족로 리소스를 공통 사용하는 문제를 재현: `before-1440.png`.
- 7개 용병 선택 전환, 선택 1개 유지, 승인 남색/연두 이미지 적용, 선택 글자색 `rgb(24,36,10)`, 키보드 Enter 선택 및 포커스 복원.
- 프라임 제작 OFF·두 품절 사례의 실제 제작 버튼 잠금 유지, 잔여량 문구 보존, 이미지 로드·가로 넘침·스크립트 오류 없음.
- 선택 전환으로 추가 API 조회 0, API POST 0, 운영 DB 쓰기 0. `local-browser.json`, `local-*-selector.png`, `local-*-workshop.png`.

프리뷰를 새로 꾸미지 않고 실제 제작소 컴포넌트를 검수한다. 기술 검수를 사용자 시각 승인으로 기록하지 않는다.

## 배포
