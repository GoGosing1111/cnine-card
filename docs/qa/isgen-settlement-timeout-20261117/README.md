# 이스겐 마지막 타격 정산 지연·통신 취소 수정

추가 제보 https://www.playdk.kr/board/skm/1538947 (열람 당시 댓글 0개). ‘입력 응답이 늦어지고 있습니다’는 2.5초 클라이언트 대기 제한에서 나온다. 이전 ‘같은 계정’ 거절 수정 d72b4d1a0은 먼저 배포했고, 이번 제보로 마지막 타격의 정산과 요청 수명을 추가 확인했다. 성공 영수증만으로 실제 클릭 횟수나 미참여 여부를 판단하지 않는다.

## 원인과 처리

운영 READ ONLY 재현에서 3인 회차(현재 보상 가능 2명)의 막타 보상 준비가 첫/반복 12.45/11.47초였다. 코인과 계급 경험치가 같은 업적 전체 이력을 각각 읽고, 큰 블랙윙 전투 JSON도 여러 번 파싱했다. 기존 2.5초 입력 제한은 화면 대기와 실제 fetch를 함께 취소했다.

이스겐 정산에서는 계정별 현재 컬렉션 보너스를 한 번 읽어 코인과 경험치에 사용하고, 독립된 보상 조회를 기존 PostgreSQL 읽기 파이프라인으로 묶는다. 지급 SQL은 참가자 순서대로 기존 한 거래에 남긴다. 블랙윙 업적의 PostgreSQL 조회는 전투 JSON을 한 번 파싱하며 SQL NULL·시작일 경계·참가 증명·15번째 획득 시각을 유지한다. SQLite 경로는 유지한다. 이 조회는 다른 콘텐츠의 같은 업적 조회에도 적용된다.

클라이언트는 2.5초에 버튼 대기를 풀고 추가 충돌 재시도를 중단하되, 이미 보낸 단일 요청은 화면 수명 안에서 최대 15초까지 결과를 기다린다. 늦게 온 정상 응답도 같은 전장에만 적용하고, 화면 퇴장 시 통신을 취소한다. 이미 갱신된 행동/종료 화면에 오래된 시간초과 안내를 띄우지 않는다. 대기 중에는 공격 결과를 확인 중이라고 안내한다.

12초 공격 제한·피해량·보상 수량/확률·주간 한도·기존 기록은 그대로다. 운영 데이터 직접 변경, 시험 지급, 댓글/메시지 발송은 하지 않았다.

## 검증과 한계

같은 운영 DB repeatable-read snapshot과 완료 시각으로 전후 준비를 비교했다. 63→33회 조회, 11,617.7→4,230.1ms, 지급 SQL 59개 및 지급 내용 해시 동일이다. 이는 Windows CLI에서 운영 DB까지의 네트워크를 포함하며, Cloudflare 실제 요청 지연이라고 확대하지 않는다. 비교용 격리 번들에서만 선택 보상 난수를 고정했고, UUID만 정규화했다. 실제 정산 쓰기는 실행하지 않았다.

실제 로비 메뉴에서 3.6초 막타 정산 지연과 취소를 주입했다. PC/Android 기존 화면은 fetch 취소 1건·HP 57,139 잔여·FAILED, 수정 후 PC/Android/WebKit/Windows URL/H5는 취소 0건·CLEAR·보상 1회였다. 첫 진입·재진입·프레임·퇴장을 측정했고 퇴장 후 요청 0건을 확인했다. 실휴대기기/설치형 Windows 측정이 아니며 기존 WebKit ResizeObserver 경고와 긴 프레임은 performance.json에 남긴다. 느린 네트워크 전체의 지연이 사라졌다는 뜻은 아니다.

관련 회귀에는 늦은 응답·퇴장·충돌 재시도 중단, 동일 토큰 중복 공격, 원자적 정산 실패 원복·동시 클리어·주간 한도, 3~6인 막타, PostgreSQL/SQLite 업적 경계 및 JSON null, 컬렉션 보너스와 배포 캐시 일치를 포함한다. 배포 확정값은 completion.json에 기록한다.

첫 guarded 배포 시도는 72개 중 69개 통과·기존 컬렉션 검사 3개 실패로 배포 전에 멈췄다. 두 변경 서버 파일을 d72b4d1a0 원본으로 로드한 대조에서도 같은 컬렉션 파일은 19개 중 16개 통과·동일 3개 실패였다(기본 업적 투영 1개, 과거 리미티드 도감 구성의 80% 가정 2개). 해당 기존 오류를 이번 수정으로 고치지 않았다. 실제 영향 범위의 53개 통과는 보존하며, 같은 계정 보너스 조회를 재사용할 때 코인 +30%·경험치 +20%, 다른 참가자 기본 보상, 재시도 중복 0건을 검증하는 SQLite/PostgreSQL 전용 2개 검사를 추가했다. 실행 코드는 296a30f01에서 그대로이고, 재개 배포는 이 2개와 필요한 컴파일만 실행한다.
