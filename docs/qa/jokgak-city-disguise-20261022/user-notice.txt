[족각도시 신규 아이템 안내 — 위장신분증]

족각도시 시장에 '위장신분증'이 추가되었습니다!

• 가격: 도시 현금 3,000원
• 효과: 현재 족각도시에 있는 다른 참여자 한 명의 닉네임과 직업으로 30분간 위장합니다. 대상은 무작위로 정해집니다.
• 사용 방법: 구매 후 인벤토리에서 사용
• 사용 제한: 한 회차당 최대 2회 / 경찰 사용 불가

위장은 닉네임과 직업 표시에만 적용되며, 실제 직업의 능력과 수입은 그대로 유지됩니다.
위장할 다른 참여자가 없으면 신분증은 소모되지 않습니다. 위장 중 다시 사용하면 대상을 다시 추첨하고 지속 시간이 새로 30분 적용됩니다.
회차가 끝나면 위장이 해제되고 남은 신분증은 사라지며, 사용 횟수도 초기화됩니다.
