# 프라임 레퀴엠 PVE 이펙트·광역기 빈도

사용자 요청: “프라임 레퀴엠 기술 이펙트 크기를 더 키우고 화려하게 … 광역기 빈도를 높여야함 (PVE)”.

## 변경

- 광역기 4종 공통 재사용 5→3 자기 행동, 에너지 35→20. 서버 기본 공격 적중으로 에너지를 회복하는 기존 규칙을 그대로 사용한다.
- 같은 30 자기 행동·적중 조건에서 기존 6회, 변경 후 10회(약 67% 증가). 실제 피격/전투 종료/대상 유무에 따라 전투별 횟수는 달라진다.
- 혈호 강림 1.50배, 혈영섬·참형 1.55배, 혈천개벽 1.45배, 적월 무간참 1.30배, PVE 기본 검격 1.20배. 전장을 가로지르는 큰 효과는 화면 폭 92% 안에 맞춘다.
- ImageGen으로 새 적월 충격파 텍스처를 제작하고, 마지막 타격에 기존 다중 프레임 효과와 함께 겹쳐 표시한다. 최대 2개 풀 스프라이트를 V3 시계에서만 확대·회전·소멸하며 동작 줄이기에서는 회전 없는 낮은 밝기 1개만 사용한다.
- 2배속과 기술 길이, 타격 시점, 시전당 총 1,512% 분산 피해, 기본 전투력 2,300,000, 공격/방어/HP/속도/연계, PVP 수치·연출, 획득 잠금을 유지한다.
- 새 이미지 로드는 승인된 몸/기술 효과와 독립적이다. 새 이미지가 늦거나 실패해도 입장·기술 재생·서버 HP 처리를 기다리게 하지 않는다.

## 원본·공정·시각 검수

1–4. 원화·몸 8동작·무기·방출점은 기존 V7 승인 파일을 그대로 재사용한다. 기준은 preview/prime-requiem-blood-skills-20261021-v1/live-approval-20261021.json 및 source/MotionAtlas.mjs, SkillPlan.mjs다. 이번 요청은 효과 크기/강도와 PVE 빈도이며 몸·무기를 재생성하지 않았다.

5. 기존 호랑이·검격·기둥·적월의 서로 다른 효과 프레임을 모두 보존했다. 새 정지 텍스처는 보조 충격파 계층이며 기존 주 효과의 연속 작화를 대체하지 않는다. 원본 PNG·실제 프롬프트·SHA-256은 art-manifest.json, imagegen-prompt.json에 보존한다. built-in image_gen.imagegen, 투명 배경.

6–7. 투명 RGBA 원본을 1024px WebP로 패킹(595,582바이트)했다. 원본 중심 알파와 색을 유지하며 타격 중심은 실제 대상 진형에서 계산한다. 몸 위치·파지·발 지면·타격 시점은 기존 승인 동작을 그대로 사용하고 복귀와 동일 배율을 검사했다.

8–10. PrimeRequiemCombatPlayback.js, 공용 V3/PixiJS/GSAP 한 시계와 기존 48개 풀을 사용한다. PC/모바일 네 광역기 캡처와 실제 재생 영상 desktop-pve-review.webm, mobile-pve-review.webm을 보존한다. 일반 배속/2배속 정책·중단·재개·동작 줄이기 검증은 report.json을 따른다.

11. 새 효과는 사용자 시각 승인으로 기록하지 않았다. 기존 V7 원화/모션 승인을 보존하며 이번 변경의 기술 검증과 새 효과 시각 승인 상태를 구분한다.
