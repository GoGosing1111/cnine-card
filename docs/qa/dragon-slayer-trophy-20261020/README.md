# 드래곤 슬레이어 · 월드레이드 5,000회

사용자 요청: “드래곤 슬레이어 트로피 리소스 만들고 추가해 / 월드레이드 격파 5000번”.

## 획득과 표시

- 코드 `WORLD_RAID_CLEAR_5000`, 명함 진열장 아홉 번째 트로피. 누적 진행률·5,000회 목표·최초 달성일을 서버 기록으로 표시한다. 획득 후에도 실제 격파 횟수는 누적하며 트로피 자체는 한 종류다.
- 월드레이드 공개 모드의 정상 격파에 참여한 인원을 집계한다. 막타·피해량 순위·보상 수령 여부와 무관하다. TEST, 실패, 시간 초과, 모집 취소, 출발 전 퇴장, 전투력 0은 제외한다.
- 정기 상태 갱신과 참가자 상태 조회의 두 종료 경로 모두 전투 종료·방 영수증·참가자별 횟수를 하나의 기존 DB 배치에서 저장한다. 고유 방 영수증의 실행 토큰으로 중복 요청을 차단하고 계정별 원자 증가로 다른 방의 동시 완료를 보존한다.
- 트로피 조회는 읽기 전용이다. `trophy_world_raid_clear_v1:<userId>`의 영구 누적값을 쓰며 과거 레이드 상세 정리 후에도 유지한다.
- 기존 CMS 8종 설정은 읽을 때 신규 항목의 보너스를 모두 0으로 보완한다. 기존 수치·리비전·감사는 그대로다. CMS 저장은 9종 전체를 요구한다. 새 코인·경험치·드롭 보너스는 임의로 지급하지 않는다.
- 과거 OWNER의 8종 트로피 수동 지급 작업은 고정된 기존 8종만 유지하며 새 트로피를 자동 지급하지 않는다.

## 과거 실적

`scripts/ops/world-raid-trophy-baseline-20261020.mjs`가 종료·HP 0·유효 참가·저장된 공개 모드 설정으로 증명되는 기록만 집계한다. 이미 설정이 정리된 과거 방은 TEST 여부를 입증할 수 없어 제외한다. 운영 사전 조회에서는 전체 6,391방 중 설정이 남은 공개 격파 3,863방, 356계정의 71,393회 참여, 최다 780회였으며 즉시 달성자는 없었다.

런타임은 최초 집계 전에도 같은 과거 증명을 읽어 첫 증가에 포함한다. 일회 작업은 이미 만들어진 계정별 누적값을 덮어쓰지 않는다. 완료 키 `trophy_world_raid_baseline_v1`을 마지막에 같은 거래로 남기며 재실행은 쓰기 없이 기존 영수증을 반환한다. 외부 QA 디렉터리에 dry run·배포 후 실행·재실행 결과를 보존한다.

## 이미지

- 기본 제공 ImageGen으로 전용 투명 조형 트로피 제작: 흑철 드래곤·직선 대검·금속 받침대. 이미지에 글자나 달성 숫자를 굽지 않았다.
- `assets/ui/player-card/dragon-slayer-20261020/dragon-slayer-v1.png`: 생성 원본 1254×1254, 바이트 보존.
- `dragon-slayer-v1.webp`: 실제 화면에 연결한 512×512 투명 WebP. 비율 유지 축소와 투명 안전 여백만 적용.
- 같은 폴더의 `prompts.json`, `manifest.json`에 프롬프트·생성 방식·원본/파생 해시를 보존했다. 원본과 제작 기록은 Git, 런타임 WebP는 Pages에 포함한다.
- 제작·구현 검수와 사용자 시각 승인은 별개다. 사용자 시각 승인을 임의 기록하지 않았다.

## 검증

- 신규 SQLite/Postgres 10건: 4,999→5,000, 최초 달성일 유지, 중복·오래된 요청, 서로 다른 방 완료, 종료 배치 실패 시 전체 롤백, 과거 실적·TEST/실패/퇴장 제외, 기존 설정 호환, 실제 종료 함수 연결, baseline dry run/재실행/원본 정리 후 유지.
- 명함·수집 보너스·월드레이드 전투·보상 결과 관련 64건 통과. 공개 명함과 공통 보유 효과에 같은 실적이 표시되고 조회가 지급하지 않는지 확인했다.
- 실제 명함 UI 프리뷰를 Chrome 1440·390·340px에서 확인했다. 3페이지 탐색, 획득·미획득 이미지, 횟수·최초 달성일·상세, 키보드, 터치 크기, 가로 잘림, 이미지 로드, 콘솔 오류를 검증했다. PC는 애니메이션 기본, 모바일은 동작 줄이기다.
- QA 원본: `C:/Users/User/.codex/qa/dragon-slayer-trophy-20261020/`.

운영 반영 결과는 같은 폴더의 `release.json`에 기록한다.
