- 실제 드랍값과 평균 획득 범위는 로컬 운영 전용 설정으로 주입한다. 기존 정예 드랍 0 설정은 유지한다. 정예 처치 수가 달라도 보스 처치까지 완료한 원정의 장비 획득 확률이 지정 범위 안에 있는지 적용 전에 검사한다. 보스 미처치에는 보스 판정이 없으며 천장·확정 지급은 추가하지 않는다. 기존 운영·수집 버프는 별도 적용한다.
- 연마석, 별도 필드 풀, 몬스터 능력치, 실행 모드, 공급 설정, 계정 재산은 유지한다. 이미 시작한 원정의 서버 정책 스냅샷은 재작성하지 않는다.
- 로비와 입장 응답의 세트·고유 확률 필드를 제거한다. OWNER CMS의 원본 정책과 서버 저장 정책은 유지한다. 로비에는 드랍률 상향 사실만 표시한다.
