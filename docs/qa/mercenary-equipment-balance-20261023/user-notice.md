# 용병 장비 상향 안내

용병 장비의 전투력과 고유효과가 강화되었습니다.

- **전투력 2배 상향:** 모든 용병 장비의 전투력이 기존 대비 2배로 증가했습니다. 기존에 보유 중인 장비에도 적용됩니다.
- **흑조의 작살총:** 보호막을 상대하는 화력이 강화되고 방어 관통 효과가 추가되었습니다.
- **태양송곳:** 보스에게 가하는 피해가 크게 증가하고 방어 관통 효과가 추가되었습니다.
- **단장의 가면:** 추가 타격이 더 자주 발동하며, 추가 타격의 피해량도 증가했습니다.
- **여왕의 생체갑:** 체력 회복이 강화되고, 최대 체력 증가와 피해 감소 효과가 추가되었습니다.
- **낙뢰의 깃:** 치명타 확률과 치명타 피해가 증가하고, 치명타 적중 시 추가 화력이 강화되었습니다.
- **드랍률 상향:** 군단토벌에서 용병 장비를 획득할 확률이 상향되었습니다.

장비 전투력은 PVE·PVP에 적용되며, 고유효과는 기존과 동일하게 PVE에서 적용됩니다.
