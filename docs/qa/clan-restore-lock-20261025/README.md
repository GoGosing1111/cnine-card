# 정규 클랜전·챔피언스리그 복원과 전체 일정 잠금

2026-10-25 사용자 요청: 정규 클랜전과 챔피언스리그를 복원하고 세력전은 매일 2회 랜덤·승점 미포함으로 되돌린다. 후속 답변 **세력전까지 모두 잠금**을 적용한다. 새 모집 방식은 검토 단계다.

## 적용 범위

- 기존 정규전·챔피언스리그 화면과 마지막 시즌의 순위/명단/대진 기록을 다시 접근할 수 있다. 최신 클랜 본부는 현재 6개 클랜을 그대로 사용한다.
- 정규전·챔피언스리그·세력전의 모집, 자동 개최, 대진 생성과 전투 입장을 서버에서 차단한다. 구버전 요청, OWNER 직접 실행, 저장된 ON 정책, 스케줄러로 우회하지 못한다.
- 세력전 일정 생성기는 과거 랜덤 방식(매일 2회, 서로 겹치지 않는 각 3시간)으로 복구했다. 잠금 중 실제 일정 생성/개전/순연/정산은 하지 않는다. 주간·시즌 승점 생성/합산/다음 시즌 전환도 중지한다.
- 소속·명단·점령·편성·공동 자금·보상 설정과 과거 기록은 보존한다. 지난 정규전 8개 클랜을 현재 6개 클랜으로 재배정하지 않는다. 과거 보상 재시도는 읽기 전용 화면에서 실행하지 않는다.
- 새 데이터베이스 스키마, 지급, 계정 편성 변경, 새로운 모집 제도는 없다. 기존 공통 도감 패널/행동 버튼과 기존 대회 화면을 재사용한다.

잠금의 단일 기준은 `shared/clan-restoration-v1.mjs` (`20261025-restored-locked`)다. 현재 잠금을 해제하려면 후속 사용자 지시에 따른 별도 변경이 필요하며 CMS ON만으로 해제하지 않는다.

- 신규 회귀 6개: 실제 overview/CMS SELECT 전용 조회, PENDING 보상 불변, 17개 구버전/OWNER 쓰기 경로 차단, 스케줄러 DB 접근 없음, 매일 랜덤 2회 경계, PostgreSQL 주간/시즌 경계 무정산, CMS ON/수동 정산 우회 방지.
- 관련 기존 회귀: `clan-champions-v2071`, `clan-faction-sessions-policy`, `organization-schedule-20261023`, `organization-faction-20261015`. 과거 날짜의 고정 일정 이력은 계속 검증한다.
- 사전 58개 검사에서 55개 통과/3개 실패. 실패는 기존 `clan-retirement-20261012`의 15개 클랜 기대값(현재 6개), SQLite fixture의 `territory_war_v3_rounds.status` 누락이다. 변경 전 `8420c0f30b9a3c1bd331eeb64d96f79435059fc8` 소스로 동일한 3개 실패를 재현했다. 기존 폐지 과정의 테스트를 이번 복원 작업에서 개정하지 않고 신규 복원 회귀와 관련 4개 파일을 배포 검사로 사용한다.
- 실제 컴포넌트 PC 1440px/모바일 390px: 복원 메뉴, 정규전 잠금, 챔피언스리그 지난 대진, 본부 iframe, 세력전 잠금/랜덤 규칙, 승점 미포함, CMS 안내. 넘침·JS 오류·실패 요청 없음. 새 패널/선택 버튼 이미지와 짙은 글자색을 확인했다.
