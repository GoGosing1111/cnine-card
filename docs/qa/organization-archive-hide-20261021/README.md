# 조직 상단 이전 메뉴 제거

사용자 첨부의 조직 본부·마지막 대회 기록 버튼을 렌더링하지 않는다. 폐쇄된 클랜 화면은 현재 조직 본부로 직접 진입하며 오래된 대회 탭 선택도 조직으로 정규화한다. 기존 내부 메뉴·세력전 팝업·현황·과거 대회 데이터는 유지한다.

기존 PC·모바일 진입 검사를 갱신해 두 버튼 부재, 자동 갱신 시 iframe/선택/초점/스크롤 보존과 과거 탭 복귀를 확인했다. 검수 중 발견한 모바일 비로그인/모집 화면 제목 눌림은 해당 헤더만 한 열로 배치하고 hidden 속성을 보존해 수정했다. 새로운 원화는 만들지 않았으며 기존 승인 이미지 패널과 버튼을 유지했다.

관련 검사 2개 통과, 1440/390px 직접 캡처 확인. 메뉴 제거 배포 `1a080646a`(234e2073) 후 발견된 모바일 배치 보정 a39c2c4dc을 https://1ac56610.cnine-card.pages.dev에 반영했다. 최종 운영 파일 8개가 로컬 원본과 SHA-256 일치한다. 서버 데이터 변경은 없다.
