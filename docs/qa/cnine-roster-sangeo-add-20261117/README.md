# 씨나인 현황판 스타부 상어녀 추가

스타부 마지막에 상어녀(595935)를 추가해 9→10명, 전체 19→20명으로 갱신한다. 여캠부 10명과 기존 순서는 유지한다. 방송국: https://www.sooplive.com/station/595935

웹·H5·Windows URL의 로비 진입과 현황판 첫 진입/재진입, 프로필, 프레임 및 퇴장을 동일 조건으로 비교했다. 실제 휴대기기·설치형 Windows 검수는 아니다. 초기 부서 선택 사진 요청은 6개를 유지하며 추가 프로필은 스타부에서 지연 로딩한다. 기존 긴 프레임과 WebKit 경고를 기록했다.

관련 기존 검사 2개 파일과 Worker 컴파일을 운영 배포에서 한 번 실행한다. 결과는 completion.json, 측정 조건과 비교는 performance.json에 기록한다. 운영 계정 쓰기·메시지 발송은 없다.
