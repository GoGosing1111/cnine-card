- ON 실전은 계정당 **모든 난이도 통합 하루 3회**, 한국시간 00:00 초기화. OWNER도 동일하다. 방장과 참가자 모두 전투 시작이 확정될 때 1회 소모한다. 대기실 생성/참가/나가기 자체는 차감하지 않는다.

- 연결이 끊겨도 서버 전투는 계속된다. 계정별 서버 방 포인터로 브라우저 저장 정보 없이도 원래 방을 복구한다. 만료되거나 무효화된 연결권은 계정 인증으로 한 번 자동 재발급하고 같은 명령 ID를 재사용한다. 인증·멤버 검증은 유지한다.
- 정상 종료 결과와 자동 보상 정산 상태는 종료 후 **24시간** 복구 가능하도록 보존한다. 지급 실패 방은 정산 완료 전 삭제하지 않는다. 기존 TEST·연습/배포 전 방의 보존 규칙은 그대로다.
