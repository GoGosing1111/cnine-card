# 용병 경험치 50% 이전 물약 — 2026-10-25

## 사용자 확정

- 누적 성장 경험치의 50%를 물약으로 추출한다. 원래 용병은 Lv.1 / EXP 0 / 돌파 0단계로 초기화하며 보유 카드 수량은 유지한다.
- 받는 용병당 계정 내 1회만 사용한다. 용병 코드를 기준으로 영구 기록하며 추출·초기화·재획득으로 재사용할 수 없다.
- 같은 등급끼리만 이전하며, 일반 SSS와 SSS 리미티드는 별도다. 그 외 C/B/A/S/SS는 기존 등급 경계를 사용한다.

## 구현

- `shared/mercenary-experience-transfer-v1.mjs`: 완료한 레벨의 필요 XP + 현재 XP + 보관 XP를 합산해 50%를 내림한다. 돌파 실패·재료 초과 소멸 XP는 제외한다. 완료한 레벨은 해당 완료 영수증의 정책으로 계산하고, 과거 영수증이 없는 레벨만 현재 성장 기준표를 사용하며 추출 확인창에 명시한다.
- 성장 API에 추출 예상량 / 추출 / 사용을 연결했다. 서버가 소유권·등급·성장 버전·물약 버전·정책 버전·확인 XP를 검증한다. 같은 요청 번호 재시도는 기존 영수증을 반환한다.
- 기존 `app_meta`에 계정별 개별 물약·사용 기록·잔여 XP·마지막 초기화 버전을 저장한다. 공통 스키마·인증·트랜잭션 기반 변경과 마이그레이션은 없다. 기존 계정 잠금, joint operation, 거래 내 상태 비교로 초기화·물약 생성/소모·사용 기록·영수증을 원자 처리한다. 정상 보관 공간은 물약 200개이며 가득 차면 추출을 실행하기 전에 차단한다.
- 물약을 사용하면 기존 돌파 구간까지 적용하고 나머지는 해당 용병에게 보관한다. 이후 정상 돌파 성공·실패 뒤 보관 XP를 자동 적용한다. 성공 확률·실패 천장·MAX 21·실패 시 현재 XP 소모는 유지한다. MAX 이후 남은 XP도 보관하며 추출 시 합산한다.
- 돌파 영수증은 돌파 직후 상태와 보관 XP 적용 후 상태를 구분해 과거 실패 집계를 유지한다. 추출 이후의 실패 천장은 새 성장 주기로 계산하며 기존 불변 영수증은 수정하지 않는다.
- `mercenary-codex/leveling/transfer.html`: 추출량·초기화·1회 사용 확인 후 진행한다. 기존 성장 화면에 진입 버튼·사용 이력·보관 XP를 표시한다. 인벤토리에는 보관된 물약 수량을 표시하고 선택 화면으로 연결한다. 일반 `inventory/use`로 선택 없이 소모할 수 없다.
- 공통 도감 남색 패널 / 승인 연두 행동 버튼을 재사용했다. 새 물약만 built-in image_gen으로 제작했다. 원본과 런타임 이미지·최종 프롬프트·SHA-256은 `assets/items/mercenary-experience-transfer-20261025/manifest.json`에 보존한다. 기능 검수는 사용자 시각 승인으로 주장하지 않는다.
