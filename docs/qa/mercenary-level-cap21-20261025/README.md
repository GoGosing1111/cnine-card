# 용병 최대 21레벨 — 2026-10-25

사용자 최종 정정: **아니 21까지만이지**. 앞선 20레벨 요청을 대체한다.

## 적용

- 20레벨 최종 돌파에 성공하면 21레벨 MAX. 21레벨에서 전수 미리보기·전수·돌파 요청을 서버가 거부하며 재료·지갑·성장 기록을 추가 변경하지 않는다. 22 이상, 최종 돌파 누락, 만렙 잔여 경험치 상태도 거부한다.
- 기존 5/10/15/20 돌파 경험치·기본 확률·소모·천장과 성장 계수는 유지한다. 마지막 성공에도 기존 레벨당 성장 공식의 한 단계가 적용된다. 레벨 21에 다음 경험치나 새 돌파를 만들지 않는다.
- 영속 스키마는 기존의 checkpoint `level=20` + 최종 해금 `breakthrough_mask=15` + 경험치 0을 사용한다. 계정 조회와 새 전투 스냅샷에 한정해 이를 21로 해석하고 새 최종 성공도 같은 체크포인트 형식으로 저장한다. 계정·설정 일괄 수정이나 DB 스키마 마이그레이션은 없다.
- 과거 영수증·이미 저장된 전투 스냅샷의 20레벨은 그대로 검증/재생한다. 새 영수증은 결과 21로 고정되어 재시도해도 추가 돌파나 소모가 없다.
- 성장실의 현재/최대 레벨, 안내, 능력치 미리보기 1~21, 성공 결과와 CMS 누적표를 일치시켰다. V3 소비 번들 및 협동 방어전 코드를 재빌드했다. 원화·모션·디자인은 그대로다.

- 기존 레벨 전수·돌파·확률·실패 천장·정책·원자성/롤백·클라이언트 영수증·성장 공식 검사를 함께 실행한다. 신규 cap 사례와 관련 기대값 수정 후 실패 5건을 재확인하여 통과했다.
