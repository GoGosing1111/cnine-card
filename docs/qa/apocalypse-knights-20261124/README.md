# 아포칼립스 상위 토벌 2단계

모르가스(46번째) 다음에 라흐덴(47번째)과 벨시르(48번째)를 배치했다. 두 보스 모두 기존 아포칼립스 탭에서 보스 1명과 호위 6명을 처치하는 단독 토벌이다. 별도 보상 지정이 없어 기본 처치 보상은 모르가스와 같은 코인 40억과 마스터의 별 300만 개로 설정했다.

## 두 보스와 공략

| 단계 | 기본 전투력 | 서버 도전 전투력 | 보스 기술 |
| --- | ---: | ---: | --- |
| 라흐덴 · 흑철의 집행관 | 3조 | 13조 4,550억 | 흑철 낙인 → 홍련의 계율 → 단죄의 낙검 |
| 벨시르 · 침수 천문대의 파수자 | 3조 4,000억 | 14조 7,356억 | 침성의 조류 → 궤도 동결 → 낙성의 자오선 |

라흐덴은 공격력이 높은 두 명의 기술을 3행동 동안 봉인하고, 다음에는 공격력이 높은 세 명의 회복을 4행동 동안 막는다. 세 번째 행동에서는 **현재 보호막이 가장 많은 두 명**에게 공격력 142%의 낙검을 내린다. 피해의 60%가 보호막을 관통한다. 보호막이 같으면 공격력이 높은 대상, 그다음은 앞 좌석을 고른다.

벨시르는 첫 행동에 **전원의 회복을 4행동 동안 차단**하고, 다음에는 공격력이 높은 네 명을 3행동 동안 봉인한다. 세 번째 행동에서는 전원에게 공격력 55%의 피해를 주며 72%가 보호막을 관통한다. 이때 회복 차단이 남은 대상은 피해가 20% 늘어난다. 정화와 대상 본인의 행동으로 저주가 끝나면 추가 피해 조건도 사라진다.

토벌 선택 화면에는 라흐덴의 비교 장비로 **용병 8단 +10강**, 벨시르에는 **용병 10단 +15강**을 표시한다. 두 수치는 실전 편성을 비교한 조건이며 도전 버튼에 장착 제한을 걸지 않는다.

## 현재 편성으로 비교한 결과

2026년 11월 24일 01시 38분 KST에 운영 데이터를 읽기 전용 트랜잭션으로 조회했다. 최근 7일 조회 구간에 모르가스 승리 기록이 있는 일반 계정을 대상으로 카르겐·발카르·모르가스전의 기록 전투력 상위 5명을 골랐다. 같은 기간의 전체 몬스터 토벌 기록에서도 같은 다섯 계정이 같은 순서로 상위 5위를 차지했다. 기록 전투력 범위는 1억 654만~1억 1,432만이었다. 다섯 계정 모두 실제 저장한 카드 5장, 레벨 21 용병 2명, SX 슈트를 사용했다.

서버의 토벌 전투 엔진에 저장 덱, 펫 성장·특성, 계정과 용병의 연마, 무기·슈트, 시즌 장비, 마법, 계정 등급 및 카드 시너지를 반영했다. 실착 대조군에는 고유 장비 효과도 들어간다. 장비 비교에서는 용병 두 명의 다섯 부위를 함께 교체하고, 해당 용병의 같은 부위에 붙어 있던 연마를 옮겼다. 원래 빈 부위의 연마는 0이다.

## 원화와 화면 검증

적흑 기사는 날이 선 다층 투구와 흑철 갑주, 선명한 적흑 대비, 두 손을 긴 대검의 자루에 포갠 자세로 그렸다. 청염 기사는 청색 화염 투구와 천구의 고리를 닮은 검 가드, 앞으로 뻗는 검선으로 구분했다. 두 참고 그림을 바탕으로 신규 초상과 투명 전신을 각각 제작했다. 두 기사의 체형은 성인 비율이며, 전투 원본은 모두 투구와 시선이 왼쪽 아군을 향한다.
