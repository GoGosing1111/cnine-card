- 기존 X와 SX/Overlord의 상대 피해를 묶던 과거 검사만 최신 X 단독 상향에 맞췄다. 다른 슈트 10개 PVE 경우 및 PVP 1개의 전투 전체 JSON 해시가 직전 운영 소스와 동일하다.
- 클라이언트는 서버의 확정 피해를 재생한다. 새 전투부터 적용하며 저장된 이전 전투를 다시 계산하거나 수령 상태를 바꾸지 않는다.

## 수치 선정

더듬이구의 공개 저장 편성을 복원하고, 동일 보스/편성/32개 난수로 1/4/8/16/24/32배 후보를 비교했다. 384회는 특정 편성 비교이며 전체 유저 승률이나 최소 클리어 조건이 아니다. 공개 스냅샷에는 내부 상태 일부가 없으므로 과거 운영 전투의 정확한 재생이라고 주장하지 않는다.
