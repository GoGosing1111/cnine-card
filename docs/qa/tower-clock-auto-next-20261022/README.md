# 무한의탑 남은 시간 · 자동 다음 층 (2026-10-22)

사용자 요청: “무한의탑 남은시간 3분 안흐르는거같은데 그리고 자동 다음층 넘어가기 추가해”.

## 원인과 수정

- 공용 연속 전투 래퍼가 일반 전투에도 엔진의 beforeEvent/afterEvent 콜백을 기대했지만, 이 콜백은 스킬칩 시간축 경로에서만 호출됐다. 일반 편성은 남은 시간/소환 진행도가 초기값에 멈추고 일시정지 경계도 처리되지 않았다.
- 스킬칩 시간축은 기존 전체 타임라인/공유 시계를 유지한다. 일반 연속 전투만 래퍼가 서버 순서대로 전체 행동을 기다린 뒤 시간/진행도를 전달한다. 2초 제한이나 결과 건너뛰기를 추가하지 않았다. 같은 일반 연속 전투 경로를 사용하는 폐차장도 해당 콜백을 받는다.
- 서버의 공식 시간은 게이지 계산값이며 실제 재생 벽시계와 다르다. 이번은 표시/재생 연결 수정으로, 180초 한도·속도·피해·승패·난이도는 변경하지 않았다. 높은 성장의 편성은 공식 시간이 초 미만으로 변할 수 있어 소수 둘째 자리까지 표시한다. 메타데이터가 없는 연출은 시간을 3분이나 진행도를 0으로 되돌리지 않는다.
- 자동 다음 층은 기본 OFF, 같은 화면/계정 세션에서만 사용한다. 입구·전투·결과에서 켜거나 끌 수 있다. 전체 재생과 서버 finish 정산 성공 후 승리 결과를 3초 보여 주고 현재 진행도를 다시 읽어 정확히 다음 층에만 도전한다.
- 패배·최고층 완료·연결 오류·화면 숨김/이탈·계정 변경·편성 부족·진행도 불일치에 중단한다. 다음 층 조회/리소스 로딩 중 끄기에도 새 POST를 차단한다. 새로고침 시 자동 설정은 OFF이며 기존 전투 영수증 복구를 유지한다. 반복 파밍·새 스킵·추가 보상은 없다.
- 탑 전용 ImageGen 버튼/프레임을 재사용했다. PC 자동 버튼은 상단 제어 영역, 모바일은 HUD 바로 아래에 배치한다. 기술 검수를 사용자 시각 승인으로 기록하지 않는다.
