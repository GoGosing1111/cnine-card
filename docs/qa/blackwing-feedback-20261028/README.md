## 원인과 변경

- 기존 정상 진행은 약한 개인 반격 외에 필수 피해가 없어 공대 회복을 쓰지 않고 완주할 수 있었다. 새 방의 규칙 v2는 매 단계 시작 5초 뒤 전원 최대 HP 20% 폭발과 성공한 성역에도 6% 잔열 피해를 적용한다. 수호의 공대 30% 회복 4회는 유지하고 공유 4초 간격을 둔다. 체력과 다음 폭발을 화면에 표시하며 한 참가자의 편성이 전멸하면 수행 불가능한 역할을 기다리지 않고 이름과 함께 종료한다.
- 파쇄·봉인은 매 단계 및 4·5단계 용염마다 공동 문양을 새로 받는다. 같은 역할 두 사람이 서버가 고정한 닉네임 순서와 서로 다른 해·달·별 문양을 입력한다. 문양 미완료 상태의 역할 기믹 및 성역은 차단한다. 오답은 침식, 동료 차례의 입력은 거절, 지난 진행 토큰은 무시한다. 전원 동시 표시하며 재접속/폴링으로 재추첨하지 않는다.
- PC 1050px 이상에서 공통 V3 전장 오른쪽에 작전·조작 패널을 배치했다. 모바일은 하단 패널과 고정 조작부를 사용한다. 승인 도감의 남색 패널·연두색 버튼, V3 진형·카드 도크·원화는 유지한다.

## 4·5단계와 절단 분기

성역은 내구도 2씩 총 6회이며 직전과 같은 성역을 연속 사용하지 않는다. `1→2→3`은 필수 정답이 아니다. 4단계 3회를 거친 잔량을 최종전에서 사용한다.

흑익 절단은 최종 용염 2회에 수호 2의 **용혈 반전 시작 이후 2.5초 미만 검 반격**이 추가된다. 대검 절단은 검 반격 없이 최종 용염 3회다. 원래 코드에도 이 차이가 있었고 새 UI·기록에 명확히 표시했다. 제보 공대의 당시 입력 원본을 특정하지 못했으므로 실제 실패를 이 원인으로 단정하지 않는다.
