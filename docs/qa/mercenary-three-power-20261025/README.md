사용자 요청: 프라임 레퀴엠·제로는 300만, 제너럴 족은 270만으로 변경한다.

레오넬 V-978은 2,300,000으로 유지한다. 수정 전 운영 공개 API에서 네 용병의 230만과 획득 잠금을 확인했다.

## 구현

- 제로의 레오넬 기준 계수를 300만으로 비례 보정하고 프라임은 제로와 공유한다. 제너럴 족은 별도 270만 프로필로 분리한다. 전열 추가 방벽 60%를 포함한 전체 방벽이 전투력에 비례하도록 기존 방식대로 보정한다.
- 실제 PVE/PVP의 공격·체력·방어, 카드 연계 공격/체력/방벽, 기본 피해 상한과 장비를 적용한 능력치가 새 기준을 사용한다. 개인 속도·3.12 행동량·80% 피해 경감·면역, 스킬의 1,512% 총 피해 배율과 에너지/재사용, 성장/장비 적용 방식은 유지한다.
- 도감 설명·검증·캐시와 배포 스냅샷의 버전을 갱신했다. 실제 전투 화면에 내장된 용병 메타데이터도 기존 코드 빌드로 갱신했으며 원화와 모션은 수정하지 않았다.
- 계정 지급·재화·소유 카드·성장·편성·확률·재고·획득/판매 잠금을 변경하지 않는다. 저장된 보유 용병도 다음 조회·전투부터 공통 프로필을 사용한다.

## 확인

- `npm run test:mercenary-three-power`: **14개 통과**. 실제 서버 PVE/PVP 전투 생성, 기본/장비 능력치와 연계 비율, 제로=프라임 동급, 제너럴 족 90% 기준, 레오넬 불변, 행동량·스킬 총 피해/순환/재사용·획득 잠금·보유자 편성·도감 값을 확인했다.
- 전장 입장·실제 로더·프라임 렌더링 회귀 **13개 통과**. 원본 텍스처를 변경하지 않아 관련 3개 원화 해시 검사와 배포 파일 목록 검사는 이번 수치 수정의 검사 집합에서 제외했다. 초기 전체 실행의 원화 검사 3개는 sparse checkout에 원본 PNG가 없어 실패했으며 전투 검사들은 통과했다. 전체 검사 자체를 제거하거나 완화하지 않았다.
