# 바토리 PVE 하향 — 2026-10-21

사용자 “그럼 pve 너프해”는 직전 조사에서 제안한 **바토리 전용 PVE 최소 피해 보정 제거**의 승인이다. 보스 최대 HP가 높다는 이유로 바토리 기술 피해가 비례 증가하던 부분만 낮춘다.

`shared/mercenary-bathory-v1.mjs`의 `pveSkillMinimumDamage`를 false로 바꿨다. 일반 PVE와 아포칼립스의 바토리 스킬은 다른 근접 기술처럼 실제 공격력·스킬 배율·방어·치명타·기존 상한으로 계산한다. 기본 공격, 연계 수치, 성장, 1,008% 배율, 최대 50% 잃은 HP 추가 피해, 비용 20, 재사용 1행동, 행동 속도·횟수는 보존한다.

격전지는 기존부터 체력 비례 최소 피해가 0이어서 이번 변경 전후 결과가 같다. PVP·다른 용병의 최소 피해 규칙도 바뀌지 않는다. 이전 영수증과 진행 중 전투의 이미 확정된 결과를 재계산하지 않는다. 계정 성장·재화·팩 수량·CMS 값은 수정하지 않는다.

## 관련 검증

`tests/mercenary-bathory-pve-20261021.test.mjs`는 실제 용병 시전과 공용 피해 계산 및 전체 전투를 사용한다. 이전 바토리 하한만 메모리에서 복구한 대조군과 비교하며 운영 파일·데이터를 테스트 중 수정하지 않는다.

- 동일 공격력·남은 HP 비율에서 보스 최대 HP 20억→200억 변경 시 피해가 증가하지 않는다.
- Lv.1/10 아포칼립스 하한 제거, 잃은 HP 보너스, 성장, 시전당 서버 타격 1회·비용 20을 확인했다.
- 일반 PVE와 부하 6마리가 있는 아포칼립스의 전체 전투에서 하한이 피해를 결정하던 첫 보스 스킬 타격이 감소한다.
- 극한 격전지의 바토리/진무 × Lv.1/10 × V3 전 단계/단일 최종 보스 8조건 전체 반환값이 이전과 같다.
- PVP Lv.1/10 × 양 진영 4조건 전체 반환값이 이전과 같다.
- 진무·근접 리미티드 V-997·원거리 리미티드 V-990의 PVE 전체 결과가 이전과 같다.

전체 전투 하한 검증은 하한이 실제 피해를 결정하는 Lv.1 조건을 사용한다. 처음 사용한 Lv.10 조건 중에는 실제 공격력 피해가 기존 하한보다 커서 첫 타격이 줄지 않는 경우가 있었다. 이는 모든 PVE 피해에 동일 비율의 하향을 적용한 것이 아님을 보여준다. Lv.10의 하한 제거와 기존 공격력 피해 보존은 별도 고정 표적 시전으로 확인한다.

고정 표적 예시: 카드 각 200만, 바토리 Lv.10/첫 돌파, 개인 용병 장비 없음, 보스 방어 1천만·HP 100%, 비치명·난수 변동 1.

| 보스 최대 HP | 변경 전 일반 PVE | 변경 후 일반 PVE |
| --- | ---: | ---: |
| 20억 | 338,688,000 | 242,172,328 |
| 200억 | 3,386,880,000 | 242,172,328 |

위 수치는 동일 조건의 격리 계산이다. 제보 화면의 333,470,204를 복원한 기록이나 전체 이용자 피해 감소율이 아니다. 기존 조사와 읽기 전용 설정은 `../bathory-damage-audit-20261021/`에 보존돼 있으며, 당시 조사 스크립트는 조사 커밋 `a89a22ada` 기준으로 실행해야 한다.

## 운영 반영

관련 검사 6개와 Worker 구문 검사, 기존 scoped 배포의 소스·캐시·Hyperdrive 보호를 적용한다. UI/리소스 변경이 없어 이미지 제작이나 전투 연출 재생 검수는 이번 범위에 없다. 별도 계급 변경의 운영 배포와 겹치지 않게 순서를 확인한 뒤 `npm run deploy:production -- --scoped`로 배포한다. 배포 식별자와 읽기 전용 운영 확인은 완료 후 이 문서와 `production.json`에 기록한다.
