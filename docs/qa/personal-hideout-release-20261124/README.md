# 리버스콜 개인 은신처 배포 후보 · 2026-11-24

## 성장과 파밍

서버가 확정한 승리에 보상을 붙인다. 한국 시간의 전투 시작일 기준으로 군단토벌, 아포칼립스, 무한의탑의 첫 승리가 건축 설계도 1개씩을 지급한다. 군단토벌 솔로와 2인 파티는 계정별로 하나의 일일 보상 한도를 공유한다. 보상 자격이 있는 파티원 두 명은 각각 정산한다. 무한의탑은 기존에 서버에서 허용하는 재도전 승리를 포함하며, 같은 날의 소재 묶음은 한 번 지급한다.

| 콘텐츠 | 첫 승리 일반 재료 | 추가 재료와 코어 |
| --- | --- | --- |
| 군단토벌 | 철판 12, 배선 8, 회로 3, 냉각 3, 구동 2 | 설계도 1, 합금 외장 패널 1. 코어는 승리당 1회 추첨 |
| 아포칼립스 | 철판 16, 배선 8, 회로 3, 냉각 3, 구동 2 | 설계도 1, 가죽 마감 키트 1. 코어는 승리당 1회 추첨 |
| 무한의탑 | 철판 16, 배선 10, 회로 4, 냉각 3, 구동 2 | 설계도 1, 코어 1회 추첨 |

동력 코어는 10,000개 결과 중 175개가 당첨되는 독립 추첨으로 정산한다. 기존 보상 대상 레이드의 세 번 추첨도 회당 1.75%를 쓴다. 일반 아파트·고급 아파트·펜트하우스는 건축 설계도 21·48·87개를 각각 사용한다. 총 156개이며 작업대 할인이 적용되지 않는다. 기존 일반 부품 비용과 작업대 할인은 적용한다. 승급 코인이 충분하고 부품을 다른 곳에 쓰지 않는 모델에서 매일 세 곳, 두 곳, 한 곳을 성공하면 각각 52·78·156일차에 도달한다.

## 등급과 시설의 코인 비용

판자촌은 무료로 처음 개방한다. 일반 아파트는 1,000조, 고급 아파트는 5,000조, 펜트하우스는 1경을 기존 승급 재료와 함께 사용한다. 세 번 승급의 코인 합계는 1경 6,000조다.

작업대·냉장고·차고·무기고·휴식 소파·분석 조명 공통으로 설치(Lv.1)부터 Lv.5까지 각각 1,000조, 2,500조, 5,000조, 7,500조, 1경을 쓴다. 작업대 할인은 기존 일반 부품에 적용한다. 코인과 은신처 재료를 같은 거래에서 차감한다. 결제 결과를 다시 요청할 때는 기존 업그레이드 영수증을 사용한다.

은신처와 대액 코인 회귀 검사 50개를 통과했다. SQLite와 PGlite에서 1경보다 1코인 적은 잔액·결제 직전 잔액 변경·거래 실패·재시도를 확인했다. 로컬 PC와 원스토어 H5 에뮬레이션에서 세 승급 가격 표시와 냉장고 결제 응답 유실 복구를 확인했다. API Worker 드라이런도 통과했다.

## 가구 스킨

고급 아파트 이상과 해당 가구 보유가 필요하다. 코냑 가죽 소파에는 코인 1,000조, 마스터의 별 5,000만, 동력 코어 8개, 가죽 마감 키트 20개가 필요하다. 탐사형 작업대에는 코인 1,500조, 마스터의 별 8,000만, 동력 코어 12개, 합금 외장 패널 30개가 필요하다. 계정당 한 번 해금하며 기본 외형과의 교체는 무료다. 코인·마스터의 별·은신처 재료 차감과 해금 기록을 같은 거래에서 처리한다. 요청 영수증으로 재시도를 복구한다.

가구 확장은 shared/personal-hideout-v1.mjs의 additionalDecor 목록에 고유 코드, 이름, 폭, 필요하면 벽면 유형을 추가한다. 해당 코드의 decor-*.webp를 은신처 에셋 경로에 둔다. 장식 제작은 시설 효과를 중복 부여하지 않는다.

## 검수

- 관련 서버 검사 53개 통과. 격리 SQLite와 PGlite에서 파티 양쪽 계정 지급, 아포칼립스 보상 재청구, 탑 정산, 자정 경계, 코어 기준값, 세 가지 소모량의 롤백과 재시도를 검사했다.
- 격리 Chrome 1440px와 390px 터치 에뮬레이션에서 실제 은신처 화면과 API를 연결해 가구 제작, 액자 위치 지정, 좌우 반전, 저장, 스킨 구매와 적용을 확인했다.
- Pages 스테이징 파일 19,995개. 가구·스킨·부품 이미지와 Windows 매니페스트를 대조했다. Pages Functions 컴파일, API Worker 드라이런, 원스토어 생성물 체크를 통과했다.
- 원격 main과 운영 상태는 이 후보로 변경하지 않았다. 운영 검증기는 후보 브랜치와 origin/main의 커밋이 다르면 배포를 차단한다.

## 은신처 화면 확대

방을 먼저 배치하고 시설·가구·트로피·공간 확장 탭과 부품 보관함을 아래에 배치했다. PC는 64dvh까지 뷰를 키우고 모바일은 55dvh를 사용한다. 좁은 화면에서는 가구의 최대 표시 배율을 제한해 큰 작업대가 화면 안에 들어오게 했다. 방 이름 표지는 가로 이동 중에도 보인다.

실제 로비에서 PC, Android 터치, 원스토어 H5 에뮬레이션으로 진입해서 방 이동·드래그·진열장·4단계 성장·복귀를 확인했다. 격리 Chrome과 로컬 자료에서 첫/재진입은 PC 214/63ms, Android 281/76ms, H5 355/100ms였다. 드래그 p95는 세 경로에서 모두 약 4.3ms이고 퇴장 뒤 추가 은신처 조회 0회였다. 실기기·설치앱 계측이 아니다. 추가 화면 검사는 320px 세로와 844×390 가로에서도 가구 제작·배치와 스킨 적용을 통과했다.

## 전체 출시 검사 상태

전체 출시 명령의 테스트 단계는 기존 프라임 경로를 별도로 검증하도록 성능 검사를 정정한 뒤, 실패 지점부터 마지막 군단토벌 지역 검사까지 완료했다. 은신처와 로비의 변경에 해당하는 검사는 최종 화면 구성에서 다시 실행했다. 최종 운영 검증기는 로컬 배포 후보와 원격 main의 커밋이 다르므로 배포를 차단한다.
