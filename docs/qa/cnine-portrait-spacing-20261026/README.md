# 씨나인 부서 선택 사진 크기·간격 수정 — 2026-10-26

사용자 첨부처럼 부서 선택 화면 사진이 아래 입장 버튼과 붙는 문제를 수정한다. 원본 사진을 가공하지 않고 화면 표시 크기만 조정한다.

- 원인: 앞쪽의 `.c9-entry-portraits img`와 뒤쪽의 `.c9-member-portrait img`가 같은 선택자 우선순위여서 공통 120px 높이가 선택 화면에도 적용됐다. 64px 프레임 안의 실제 사진이 64×120px로 늘어나 인원 표시를 덮고 입장 버튼에 4px 겹치는 것을 실제 로컬 메인 PC에서 재현했다.
- 선택 화면의 이미지 선택자를 한정하고 프레임/사진이 같은 크기 변수를 사용하도록 수정했다. PC는 56×56px, 모바일은 화면에 따라 28~36px 정사각형이다. 프레임 밖으로 나오는 이미지를 제한하며 기존 원본 픽셀 확대 방지와 이미지 대체 처리를 유지한다.
- PC 사진 아래 인원 표시까지 16px·입장 버튼까지 52px, 모바일 390px에서 각각 14px·46.5px 간격을 확인했다. 여캠부/스타부 내부 멤버 사진은 기존 PC 120px·모바일 72px를 유지한다. 명부 6/3명·순서·링크·부서 전환·로비 복귀는 동일하다.
- 실제 로컬 메인 PC 1440px·모바일 390px에서 사진 비율, 프레임 범위, 버튼/인원 간격, 부서 내부 사진 크기, 가로 넘침 없음과 로비 초점 복원을 검수했다. `before.json`, `browser.json`과 화면 PNG에 재현/수정 증거를 보존한다. API는 GET 전용 fixture로 운영 계정/설정 쓰기 0건이다.
- 변경 런타임은 CSS와 index/서비스 워커 캐시 3파일이다. 공식 scoped 배포에서 기존 라운지 회귀 18개를 실행한다. 배포 전 원본 정책/인원과 공개 CSS·캐시 반영을 확인하며 테스트용 코드를 운영에 연결하지 않는다.
