# 랭크전 용병 등급 정렬·즐겨찾기

랭크전의 용병 6칸 선택 목록을 SSS → SS → S → A → B → C 순으로 묶고, 같은 등급 안에서는 한국어 이름순으로 정렬했다. 동명이인은 기존 블랙크라운·블러드문·할로윈·리미티드 표기를 유지한다. 선택 가능한 등급을 좁히는 필터와 즐겨찾기만 보기, 각 선택 용병의 ☆ 추가/★ 해제 버튼을 제공한다.

즐겨찾기는 `cnine_ranked_mercenary_preferences_v1:<serverUserId>`에 계정별로 저장된다. 같은 기기의 현재 브라우저 저장소를 사용하며 다른 기기와 동기화하지 않는다. 브라우저 저장이 제한되면 이번 접속 동안 기능을 유지하고 저장 제한 안내를 표시한다. 잘못된 저장값·중복 코드·계정 전환을 처리한다.

필터 밖의 현재 선택은 ‘현재 선택’ 그룹으로 남겨 두며 저장된 출전 순서나 편집 중인 초안을 자동 변경하지 않는다. 즐겨찾기 조작은 서버 편성 저장을 호출하지 않는다. 기존 명시적 저장, 차전 이동, 동일 용병 중복 금지, 차전당 SS/SSS 1명 제한, 매칭/저장 중 잠금과 상대 출전 순서 비공개를 유지한다. 서버·보상·밸런스·획득·보유 변경은 없다.

## 구현·검증 범위

- 실제 `js/ranked-series-ui-v1.js`와 `css/ranked-series-v1.css`에 적용. 승인 공통 남색 패널과 연두 버튼 이미지를 원본 URL로 재사용했다. 기존 용병 원화와 랭크전 프레임을 보존했다.
- 단위검사 7개: 정렬, 같은 이름의 종류 구분, 즐겨찾기 추가/해제, 필터 밖 선택 유지, 편성 제한, 재접속/계정 격리, 손상·제한 저장소, 매칭/저장 중 조작 금지.
- 실제 메인 게임 로더를 이용한 Chromium PC1440·WebKit390·터치320 검사. 모든 API는 로컬 fixture로 격리하며 실제 계정 편성 쓰기나 경기는 실행하지 않는다.
- WebKit의 기존 ResizeObserver 알림과 계정 전환 시 일반 메뉴 API 취소 진단은 직전 운영 소스 `e7791deca`에서도 동일 재현했다. 원본 비교 증거를 보존하고 새 오류와 구별한다.
- 배포 게이트는 새 관련 단위검사와 기존 동명이인/저장/상대 비공개 검사만 실행한다. 캐시 및 배포판 진입 문서를 동기화한다.

원본 증거와 화면: `operations/ranked-mercenary-favorites-20261106/`. 최종 운영 결과는 같은 QA 폴더의 `completion.json`에 기록한다. 실제 아이폰·설치 앱 직접 검수와 사용자의 시각 승인을 의미하지 않는다.
