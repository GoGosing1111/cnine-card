# 랭크전 용병 등급 정렬·즐겨찾기

필터 밖의 현재 선택은 ‘현재 선택’ 그룹으로 남겨 두며 저장된 출전 순서나 편집 중인 초안을 자동 변경하지 않는다. 즐겨찾기 조작은 서버 편성 저장을 호출하지 않는다. 기존 명시적 저장, 차전 이동, 동일 용병 중복 금지, 차전당 SS/SSS 1명 제한, 매칭/저장 중 잠금과 상대 출전 순서 비공개를 유지한다. 서버·보상·밸런스·획득·보유 변경은 없다.
