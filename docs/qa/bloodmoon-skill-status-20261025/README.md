## 원인과 수정

기존 소스 `1851613fa`에서 실제 서버가 만든 조은 V-961 / MS-961의 `MERCENARY_DEBUFF` (`OFFENDER_MARK`, `BASIC_WEAKENED`)를 재생하면 범용 `skillById` 조회로 내려가 같은 오류가 발생했다. 블러드문 전용 스킬은 범용 카탈로그에 등록되지 않으므로 후속 표식·약화 기록을 블러드문 전용 처리기로 연결했다.

후속 상태는 기존 배너에 표시하고 서버 HP·방벽 값만 동기화한다. 공격 연출·피해·에너지·재사용을 추가하지 않는다. 죽거나 사라진 대상은 무시하며 다른 미정의 스킬 검증은 유지한다. 디임 V-962의 별도 서버 이벤트에서는 같은 예외를 재현하지 못했으며, 요청된 디임의 실제 스킬 기록과 화면 경로를 함께 검수했다.

공유 V3 소비자 10개를 재빌드하고 엔진·래퍼·메인 로더 버전에 `bloodmoon-status-playback-20261025-v2`를 함께 반영했다. 메인 JS·서비스 워커 캐시도 갱신했다. 원화·전투 수치·획득 조건·발행 수량·계정 데이터는 변경하지 않았다.
