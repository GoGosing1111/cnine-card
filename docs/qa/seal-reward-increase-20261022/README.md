# 봉인전 공동 완료 보상·계급 EXP 증가

사용자 요청: `공동완료보상 5천억으로 증가`, `계급 EXP 100으로 증가`.

- 공동 완료 코인: 100,000,000,000 → **500,000,000,000 (5,000억)**. 마스터의 별 1,000,000개·최소 공격 20회·참여 보상·고난도 보스 설정은 유지한다.
- 기존 회차는 시작 시 확정된 보상을 유지한다. 확인 시 최신 64회차는 CLEARED였으며 진행 회차가 없다. 다음 새 회차부터 증가한 완료 보상을 사용한다.
- 신규 봉인·본체 정상 완료 전투의 기본 계급 EXP: **40 → 100**. 승패 공통이며, 도감·물약 배율과 정확히 한 번만 적립하는 기존 영수증 구조를 유지한다. 과거 EXP를 소급 변경하지 않는다.
