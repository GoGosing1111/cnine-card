## 동작

- 전체 도감/리미티드에서는 현재 편성과 관리 링크를 접는다. 편성하기는 기존 관리 영역을 펼친다. 390×844에서 첫 카드 시작 y=682.73→345.14, 첫 카드 이름 하단505.73px.
- 상세는 이름·원화·전투력·대표 스킬을 먼저 표시하고 편성 변경을 펼쳐 기존 PVE/PVP 슬롯을 조작한다. 새 용병의 모바일 상세는 맨 위에서 시작한다.
- PC 카드 Enter 선택 후 초점을 유지한다. 방향키/Home/End로 이동하고 Tab→상세 보기→Enter로 상세 제목, Esc로 원래 카드에 복귀한다.
- 필터 밖으로 나간 선택은 해제하고 명시적 선택 대기를 표시한다. 조회 새로고침도 이 대기 상태를 보존한다. 필터 초기화는 현재 탭을 유지하며 검색창에 초점을 둔다.

- 편성 요청/재시도/중복 방지/리비전 로직과 서버·성장·획득·전투·계정 데이터는 변경하지 않는다.
