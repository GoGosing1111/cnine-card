# 제작소 시각 개편 재작업 — 2026-11-06

사용자는 앞선 정보 정리 중심 결과를 거절하고 실제 UI와 아이콘 교체를 요청했다. 우선순위는 선택·재료·비용·성공률을 함께 이해하는 제작 편의다. 로컬 Impeccable 스킬의 재검토 결과 rebuild를 받아 화면 구조를 교체했다.

## 변경

- 승인 공통 UI 정본: 용병 도감의 남색 금속 프레임과 연두색 행동 버튼을 실제 9-slice 리소스로 적용. 기존 제작 챔버와 장비/슈트/재료/용병/재화 이미지를 재사용했다. 신규 래스터 및 승인 이미지 바이트 수정은 없다.
- 7분류에 실제 게임 이미지. PC에는 이미지 제작품 목록, 결과물과 제작 조건을 나눈 작업대. 모바일에는 현재 이미지가 보이는 목록 펼치기와 이미지 버튼 목록, 선택 후 작업대로 포커스·스크롤 이동.
- 이전 모바일 전용 드롭다운과 중복 요약 제거. 성공률과 보유/필요/부족 수량을 단일 요구량 표로 통합. 획득량·현재 보유량·전투력, 장비 소모와 누적 천장, 용병 남은 발행수량 유지.
- 제작 확률·비용·소모·서버 처리·영수증 재확인·조립/공개 연출은 기존 경로를 사용한다. 계정 직접쓰기나 보상/메시지 발송은 없다.

## 검증 및 근거

- 격리 실제 모듈: Chromium 1440, WebKit 390, Chromium 320에서 7분류 21화면 및 이미지 선택·X-BODY 부족 상태 6화면. 검색/필터/3회 비용/101회 거부/선택 포커스/10경 표시/깨진 이미지/가로 넘침 검사.
- 실제 게임 셸: PC 44항목, WebKit390/Chromium320 14화면. 정상 조작·통신 응답 유실 후 동일 요청번호 재확인·수동 재시도·CMS 미설정 보호 포함.
- 기존 제작소 108검사 중 105 즉시 통과. sparse에서 생략된 저작 JSON 2개를 Git 정본으로 복원하고, 기존 SVG만 허용하던 아이콘 검사를 이미지 기준으로 변경한 뒤 해당 31검사 전부 통과.
- S-BODY 코인+마스터의 별 동시 소모 표시/제출 및 동일 요청 재확인 브라우저 검사 통과. 검사 결제는 로컬 격리 API만 사용했다.
- Impeccable 검출기 결과 `[]`. 전체 독립 검수 및 최종 판정은 동봉 리뷰 기록에 남긴다.
- UI 스킬: `.agents/skills/impeccable/SKILL.md`. 기존 전역 디자인 정본을 유지하는 확장으로, 글로벌 디자인 파일을 교체하지 않았다. 표면 계약은 `.impeccable/surfaces/js-workshop-v1881-js.md`에 갱신했다.
- 캡처·실행·로그: 프로젝트 루트 `operations/workshop-visual-rebuild-20261106/`. 배송 폴더의 ignored 파일 차단과 불필요한 복사 방지를 위해 해당 기존 작업 영역에 보존한다.

## 보존 범위

기존 코인10경 대응과 후속 전체 콘텐츠 코인 정산, X-BODY PVE 수정이 포함된 최신 origin/main을 fast-forward로 통합했다. 다른 작업 파일과 주 작업 폴더의 체크아웃/인덱스를 변경하지 않았다. 실계정 제작, 실기기 및 설치 앱 직접 검수는 하지 않았다. 원화·과거 증거·완료 영수증·예약·유지관리 설정은 변경하지 않았다.

## 운영

최종 검수 및 지정 배포 게이트 통과 후 같은 소스로 공개 파일과 Windows 필수 파일, 이번에 사용한 기존 아트의 해시를 확인한다. 완료 값은 completion.json과 아래 운영 완료 기록이 정본이다.

전체 UI 리뷰는 기존 재설계 요구 5개 충족을 확인하고 WebKit 장비 선택창 가독성 1건을 지적했다. native select의 appearance·색상·화살표·비활성·포커스를 수정하고 같은 21+14 화면을 재촬영했다. 선택창의 실제 스크롤 위치와 비활성 상태, 모바일→PC 전환 후 포인터/Enter 선택을 별도 검증했다. 최종 단일 항목 판정은 review-verdict.md 범위에 한정한다.
