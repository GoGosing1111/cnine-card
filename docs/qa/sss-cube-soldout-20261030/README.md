수정은 유효한 큐브 전용 한도가 모두 소진된 용병만 제외한다. 미등록 한도, 획득 잠금, 잘못된 구성은 기존대로 차단한다. 추첨은 남은 정수 가중치 합계로 직접 수행하므로 반올림 오차나 재추첨 없이 기존 비율을 보존한다. 10개 개봉 도중 소진된 항목도 다음 추첨에서 제외한다. 가능한 보상이 부족하면 배치 전체를 차감하지 않는다.

화면은 현재 확률을 소수점 8자리 반올림으로 표시하고 소진 항목을 표시한다. CMS의 원래 확률과 한도는 유지한다. OFF, 전체 소진, 다른 설정 오류를 구분해서 보여준다. 완료 영수증 재시도는 기존 결과를 반환하며, 마지막 수량 경쟁과 실패 시 전체 원복 보호를 유지한다.
