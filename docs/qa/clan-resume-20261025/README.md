# 정규 클랜전·세력전 재개, 란x2 탈퇴, 순위표 UI

사용자 확정: 정규 클랜전 **화·수·목·토 21~22시**, 세력전 **하루 1회**, **4개 이상 점령 시 정규 시즌 승점 +1**. 이전 방식의 랜덤 3시간·영토전 일시정지/순연을 유지한다. 후속 **란x2 탈퇴**와 첨부한 순위표 **UI 변경**을 함께 반영한다. 챔피언스리그 개최와 새 가입 방식은 보류한다.

## 구현

- 8개 현재 클랜을 새 정규 시즌으로 연결한다. 기존 7라운드 단일 순환 대진 28경기, 첫 경기 10월 27일 21시, 마지막 경기 11월 5일 22시 종료(KST). 예전 시즌/챔피언스리그 이력은 수정하지 않는다. 기존 행동력·참여형 전투·승점/보상 설정을 보존한다.
- 하루 1개 랜덤 3시간 회차를 DB에 한 번만 생성한다. 재개 당일에는 실제 적용 시각보다 최소 5분 뒤의 온전한 3시간 구간을 뽑고 과거 일정으로 소급 개전하지 않는다. 영토전으로 중단되면 기존 규칙대로 남은 시간을 유지한다.
- 종료 시 4개 이상 점령한 클랜은 **정규 시즌 합계에 정확히 1점**. 3개는 0점, 8개도 1점이다. 기존 정산 영수증과 동일 원자 거래로 처리한다. 기존 주간 점령지 비례 정산은 중지 상태다. 정규 시즌 마감 전에 끝난 회차만 그 시즌에 포함한다.
- 기본 점령 보상 및 피그코인 점령 조건을 4개로 맞추고 기존 보상 금액/활성 상태를 유지한다. 변경 전 회차 보상이나 과거 기록을 재지급하지 않는다.
- 정확한 계정 **란x2 / ID 73 / DC**의 현재 클랜 소속·원로·부대/행동대장 참조만 제거한다. 계정은 ACTIVE로 보존하고 카드·재화·과거 전적은 유지한다. 129→128명, DK17/삼성16/T1 16/한화16/LG16/롯데16/FM16/DC15명. 원로 23명이며 DC의 남은 원로 2명을 유지한다.
- 기존 원로 심사 가입 승인 시 같은 클랜의 정규 명부에도 반영한다. 신규 자동가입 구상은 시행하지 않는다. 옛 모집·드래프트·과거 세력전 직접 요청·챔피언스리그 개최/보상 재실행은 차단한다.
- 순위표는 승인된 도감 남색 패널과 연두 버튼, 원본 문양을 재사용한다. 세력전 기여 점수를 총 승점 바로 아래로 합치고 안내/정산 기록을 접을 수 있게 했다. 모바일 메뉴는 2행으로 정리한다. 별도 원화 복제/생성은 없다.
