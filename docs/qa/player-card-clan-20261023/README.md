# 명함 현재 소속 클랜 — 2026-10-23

사용자 첨부 명함에서 ShowMaker가 자유 소속으로 표시됐다. 기존 명함 API가 퇴역한 clan_members 시즌 명부와 퇴역 표식을 조회해 현재 6개 클랜 가입을 반영하지 못한 것이 원인이다.

## 수정

- 명함의 현재 소속만 최신 LIVE 회차의 organization_members_v1로 조회한다. 최신 LIVE가 ASSIGNED이며 해당 사용자가 현재 명부에 있을 때 shared identity의 6개 클랜 이름·마크 키를 반환한다.
- 현재 원로 → 공격대 행동대장 → 클랜원 순으로 역할을 표시한다. 원로는 기존 canonical 판정과 최대 3명·활성 같은 클랜 기준을 그대로 쓴다.
- TEST·이전 회차·미배정·탈퇴·6개 외 소속을 현재 소속으로 대체하지 않는다. 옛 시즌 번호는 현재 명함의 season에 넣지 않는다(null).
- clanHistory와 트로피 기록은 기존 역사 조회를 유지한다. 조회는 SELECT만 사용하며 계정·소속·상태·재화 쓰기는 없다. 기존 명함 JS/CSS와 디자인은 변경하지 않는다.

## 검수 및 운영

- 관련 회귀 28건 및 Worker 문법/실제 번들 컴파일 통과. 현재 소속·역할 새 회귀 3건에는 타인/닉네임 조회, 퇴역 표식 유지, TEST/구회차 제외, canonical 원로, 행동대장 및 조회 중 쓰기 없음이 포함된다.
- 실제 운영 DB를 READ ONLY REPEATABLE READ로 조회하여 수정된 handlePlayerCard와 기존 PVP/계급/듀오 함수를 실행했다. 운영 HTTP 인증 토큰을 만들거나 게임 행동을 호출하지 않았다.
- ShowMaker 실제 LG 소속과 명함 LG / 클랜원 일치. 이 응답을 기존 명함 JS/CSS로 PC 1440px·모바일 390px에서 렌더링하고 닫기/다시 열기 및 소속 표시를 확인했다.
- 소스 `7aa15eda8e3563d0342eb2bd4fcf3f764bf1fee0`, Pages `81a52c21-1681-4037-8a6b-8428cbaaa4c6` success.
- API Worker `0fe8af8b-de0f-4ea4-9033-518eb213dd07`, 클랜 스케줄러 `4b423082-2968-46e4-8e27-ac7b8eb2139d`.
- 배포된 Worker에 새 현재 명부 쿼리·helper 존재 확인. required commit 및 읽기 검증 소스 일치 확인.
- 회원 129명(22/22/21/22/21/21), 기존 소속과 원로 그대로. 운영 DB 쓰기 0건.
