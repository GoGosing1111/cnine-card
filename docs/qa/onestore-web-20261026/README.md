# 리버스콜 원스토어 H5 웹게임

사용자 요청: 이미 웹게임으로 등록한 원스토어 연동 검증의 SDK 탑재/초기화 대기를 해결하고, 승부예측·포로수용소·후원 관련 화면을 보이지 않게 한다.

실행 주소는 `https://cnine-card.pages.dev/onestore/`다. 계정·심사 여부와 무관하게 이 배포판에는 항상 같은 제한이 적용된다. 원스토어 공식 도메인의 iframe이 기존 `/`을 요청하면 같은 출처의 전용 주소로 이동한다. `distribution=onestore-web` 명시 진입도 지원하며 기존 네이티브 APK의 `distribution=onestore`와 일반 웹은 유지한다.

공식 CDN v1.1.0 SDK를 첫 모듈로 연결한다. 이벤트/뒤로가기 등록 → initializeAsync → 실제 DOM/게임 화면 준비 진행률 → startGameAsync 순서다. pause/resume는 입력·음원·기존 캔버스 일시정지 이벤트에 연결하고 safeArea/ringerSilent를 반영한다. exit는 playerId별 작은 세션 UI 기록만 동기 저장한다. 계정 진행 상태·서버 전투·재화는 기존 서버 저장 경로를 사용한다. SDK 실패는 재시도 화면을 제공하며 일반 브라우저의 미지원 응답은 제한을 유지한 채 플레이한다. 새 광고·결제·상품·보상 지급을 추가하지 않는다.

기존 원스토어 APK의 검수된 클라이언트 패치를 공유 생성기로 분리해 재사용한다. 원스토어 전용 소스만 약 1.1MB 생성하며 이미지/프로젝트/의존성을 복사하지 않는다. 승부예측, 포로수용소/데스게임, 후원 신청/계좌/패키지/시즌패스 메뉴·알림·기록·미확인 숫자를 제외한다. 삭제·완료 쪽지 일괄 정리는 막고 원본 메시지를 보존한다. 기존 웹에서 저장한 펫 후원 신청 임시 기록도 읽거나 삭제하지 않는다. 일반 인벤토리·쪽지·펫 기능과 기존 보유 권리는 유지한다.

Pages는 허용된 게임 문서만 `/onestore/`에서 제공하고 각 문서에 동일 정책/SDK를 연결한다. 공유 내비게이션과 Chromium Navigation API를 통해 문서 이동 후에도 전용 경로를 유지한다. 관리자/제외 문서 진입은 막는다. iframe을 추가로 중첩하지 않으며 전체화면 실패 시 부모 화면을 바꾸던 코드를 전용 변형에서 제거한다. iframe CSP는 원스토어 공식 도메인을 허용한다. 루트 PWA의 새 서비스워커는 전용 경로를 캐시하지 않는다.
