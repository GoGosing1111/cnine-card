# PvE·PvP 펫 편성

덱의 펫 장착창은 해당 전투 모드로 열린다. 펫 도감과 독립 장착창에서는 두 편성의 펫 이름을 보고 각각 장착·교체·해제할 수 있다. 보유한 펫 한 마리를 두 모드에 함께 쓸 수 있다.

기존 계정의 공용 펫은 조회할 때 두 모드에 표시한다. 최초 모드 지정 저장은 기존 선택과 빈 슬롯을 한 거래로 확정한다. 모드마다 마지막 변경 버전을 비교하며 요청 영수증과 계정 동기화는 기존 키를 쓴다. 분리 전 구버전 저장과 과거 요청 재시도도 지원한다. 분리 후 모드가 빠진 신규 요청에는 게임 새로고침을 안내한다.

전투 시작 버프는 전투에 입장하는 각 계정의 해당 모드 펫을 읽는다. 코인·드랍 보너스도 PvP, PvP 드랍, 듀오 랭크전과 PvE 보상 경로를 구분한다. 경매장에서는 어느 한 모드에 장착된 마지막 한 마리를 보호한다.
