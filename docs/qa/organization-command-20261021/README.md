## 구현

- 서울 25개 구, 종료 시 8곳 이상 점령한 조직의 해당 회차 실제 참여자만 지급한다. 1인당 코인 3,000억·마스터의 별 30만·미스틱 에너지 300개는 유지한다. 미완료인 이전 9곳 규칙 회차만 기존 거래 안에서 8곳으로 전환한다. 정산 완료 이력·기지 자금·가입/편성/공격 조건은 보존한다. 이전 점령 리셋 작업은 재실행하지 않는다.
- 조직 본부의 전황·명단·아지트·입단, 세력전 지도·부대 편성·자금/보상·기록·운영 CMS를 Pretendard Variable과 승인된 남색 은장 패널/초록 버튼으로 통일한다. 패널 48px→16px, 버튼 38px→9px 9-slice를 사용한다. 실제 숫자와 문구는 DOM이다.
- 본부 첫 화면에 세력전 입장·부대 편성·내 조직 바로가기를 둔다. 편성은 전용 전체 화면의 편성 탭으로 직접 진입한다. 공격대 5개/방어대 5개를 그룹으로 구분하고 기존 편성/저장 권한을 유지한다. 지도는 원래의 서울 행정 경계를 사용하고 모바일 전체 지도에서 지역명에 겹치는 문장을 줄인다.
- 실제 LIVE/ON 회차 상태를 공개 콘텐츠 현황에 `ORGANIZATION_FACTION`으로 표시한다. 시작/종료 시각과 점령 조건만 보내며 부대·참여자·전투 원본은 공개하지 않는다. 대기/순연 예정/종료/TEST/OFF는 개전 상태로 표시하지 않는다. 영토전 중단 시 중단 안내를 표시하고 종료 카운트다운을 멈춘다.
- 로그인한 사용자가 로비에 있고 다른 팝업이 없을 때 회차별 개전 팝업을 1회 표시한다. 계정·조직 회차·세력전 회차 키를 **이 기기의 localStorage**에 최대 40개 보존하고 Web Locks로 같은 브라우저의 탭 중복을 막는다. 새로고침/재접속/중단 후 재개로 같은 회차를 반복 표시하지 않는다. 다른 기기 또는 저장소 초기화까지 계정 전체에서 동기화하는 기능은 아니다. 로비 밖이면 실제 진행 중일 때 복귀 후 표시한다. 종료·로그아웃·계정/화면 전환 시 열린 알림을 정리한다.
- 기존 콘텐츠 현황의 일반 조직 항목은 ‘조직 본부’로 구분하며 실제 세력전 항목은 로비 기본 현황과 전체 현황에 함께 표시한다. 일정은 기존 1분 스케줄러, 현황은 기존 30초 조회·15초 서버 캐시를 따른다.
