# 프라임·제로 최상위 PVP 상향 · 2026-11-02

사용자 요청은 레반·카드구 상대 10~15% 승률 우위이며, 후속으로 **높은 승률 유지·부족한 구간 보강**, **프라임·제로는 최강이어야 하므로 상향**을 확정했다. 최종 기준은 동일 성장·장비 조건에서 최상위 우위를 확보하는 것이다. 기존 높은 승률을 60~65%로 낮추지 않는다.

- 두 용병의 PVP 공격력·기본 공격 피해 상한을 **30% 상향**, 최대 체력·방벽을 **6배**로 강화했다. 연계·장비·성장 적용 후 최초 생성 시 한 번만 적용하며, 기존 체력 비율을 보존한다. 피해 상한의 기준 내구력을 같은 배수로 높여 방어 상향이 상쇄되는 문제를 방지했다.
- 새 정책은 기존 제너럴 족 전용 4배 공격·16배 내구·행동 대응과 중첩하지 않는다. 원래 전용 우위는 유지한다. 2용병과 듀오에서도 각 소유자의 프라임·제로에만 적용하며 다른 카드/용병을 강화하지 않는다.
- 기본 전투력 300만, 성장·장비 원장, 자연 속도/추가 행동, PVE 스킬과 능력치, 원화·연출, 획득/제작/팩/재고/보상은 유지한다. 이미 생성된 전투를 재계산하거나 재입장 때 회복·재증폭하지 않는다. 승자·난수·시드별 판정을 강제로 바꾸지 않는다.
