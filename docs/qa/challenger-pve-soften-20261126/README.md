# 격전지 종언과 군단토벌 일반 몬스터 조정

2026년 11월 26일 출시 직후 파멸의 계정별 최근 전투 기록을 확인했다. 19시 53분에 조회한 시작 기록 8건 중 3건에서 서버 전투 타임라인 끝까지 일반 몬스터 처치가 없었다. 격전지는 패배 보상 기록이 생기지 않아 운영 보상 수령 건수로 승률을 산출할 수 없다.

## 전투력과 보스 시간

| 난이도 | 일반 몬스터 | 정예 또는 보스 |
| --- | --- | --- |
| 격전지 종언 | 첫 웨이브 전투력 3,650억 → 912억 5,000만 (75% 감소) | 정예 2조 9,000억 → 2조 6,100억, 보스 5조 1,600억 → 4조 6,440억 (각 10% 감소) |
| 개인 군단토벌 파멸 | 5개 지역의 일반·정예 기준 전투력 1조 1,200억 → 1,680억 (85% 감소) | 지역 보스 680조 → 612조 (10% 감소). 보스 출현 6분 35초 → 6분 30초, 전체 전투 7분 |
| 2인 성채 멸화의 심장 | 일반·정예 전투력 20% 감소 | 성주 전투력 15% 감소. 성주 출현 5분, 전체 전투 7분 |

격전지는 방을 만들 때, 군단토벌은 전투를 시작할 때 설정을 확정한다. 기존 파멸 세션에서 6분 35초 출현과 25초 처치 시간을 복원하는 경우도 검증했다. 세 모드의 재화·소모품·재료는 직전 난이도 대비 2.5배다. 장비·용병·장착형 스킬칩은 기존 획득 규칙을 사용한다.

## 일반 몬스터 교전

시즌 30 챌린저 상위 20명의 실제 보유 카드·장비·용병으로 서버 전투를 재현했다. 시간대는 한국 표준시이며 편성은 19시 46분에 읽었다. 추가로 19시 55분에는 최근 파멸 도전자 8명의 편성을 읽어 각자 도전한 지역에서 같은 시드 6개로 전후를 비교했다.

| 검증 지표 | 조정 전 | 조정 후 |
| --- | ---: | ---: |
| 종언 2인, 15초 안에 가장 많이 피해를 입은 첫 웨이브 몬스터의 체력 감소율 중앙값 (40전) | 11.95% | 47.78% |
| 종언 3인, 같은 지표 (40전) | 16.80% | 67.18% |
| 파멸, 상위 20명 편성이 전투 중 일반 몬스터를 한 마리 이상 처치 (5개 지역 200전) | 160/200 | 200/200 |
| 파멸, 최근 도전자 편성이 처음 10초 안에 한 몬스터의 체력을 1% 이상 감소 (48전) | 42/48 | 48/48 |
| 파멸, 최근 도전자 편성이 전투 중 일반 몬스터를 한 마리 이상 처치 (48전) | 32/48 | 48/48 |
| 멸화의 심장, 상위 파티가 첫 30초 안에 일반 몬스터를 한 마리 이상 처치 (40전) | 40/40 | 40/40 |

격전지의 서버 전투 상태, 파멸의 클라이언트 재생 상태, 성채의 체력 프레임에서 방벽과 실제 체력을 각각 추적했다. 격전지에서 전투 시작 0.34초의 일반 몬스터 한 마리가 최대 체력의 51.735%를 남긴 표본을 사용해 Chromium 1440px·390px 양쪽에서 화면의 체력바가 100%에서 51.735%로 줄어드는 것을 확인했다.

## 최종 클리어

같은 상위 20명 편성과 같은 난수 시드로 운영 전투 엔진을 전후 각 1,800번 실행했다. 격전지는 수동 기믹 입력 없이 비교했다. 아래 수치는 모의전 결과다.

| 난이도 | 조정 전 | 조정 후 |
| --- | ---: | ---: |
| 격전지 종언 2인 | 55/400 (13.75%) | 103/400 (25.75%) |
| 격전지 종언 3인 | 40/400 (10.00%) | 115/400 (28.75%) |
| 개인 군단토벌 파멸 | 120/600 (20.00%) | 120/600 (20.00%) |
| 2인 성채 멸화의 심장 | 49/400 (12.25%) | 77/400 (19.25%) |

파티는 20명의 파트너를 라운드마다 교차 배정했다. 전투 시드는 `7919 × (1 + 편성 인덱스 + 20 × 라운드)`다. 최종 클리어 비교는 파티 210~229, 개인 210~215를, 첫 교전 비교는 180~181을 사용했다. 최근 도전자 표본에는 250~255를 사용했다.

관련 자동 검사 96개, PC·모바일 크기의 세 난이도 선택, 파멸 새 보스 출현 시각, 협동 2인 출전과 화면 재생을 점검했다. 운영 설정 적용은 두 정책과 감사 기록을 한 트랜잭션으로 처리하고, 중간 실패 시 원복과 재실행 시 중복 적용 방지를 검증했다.
