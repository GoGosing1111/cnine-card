# 종언의 주파수 리듬게임 키 설정

로비의 **키 설정** 또는 전투 중 **공략 → 키 설정**에서 종언의 악보 4개 레인을 각각 지정할 수 있다. 레인을 고르고 실제 키를 누르면 즉시 적용하고 현재 브라우저에 저장한다. 두 레인이 같은 키를 선택하면 기존 키와 맞바꾼다. 기본 배열은 왼쪽부터 D · F · J · K다.

## 입력 검증

- PC에서 Z · ↓ · Space · 숫자패드 1을 지정한 뒤 레이드 화면을 다시 불러왔다. 공략과 전투 버튼이 같은 키를 표시했다. 헬 1인 연습에서 첫 8노트를 입력하고, 474ms 롱노트 꼬리까지 유지해 9콤보와 서버 점수 9점을 확인했다.
- 원스토어 H5의 390px 모바일 환경에서 같은 배열을 저장하고 재진입했다. 노말 3인 공대에서 화면 버튼 터치로 첫 8노트와 8점을 확인했다.
- 중복 키 교환, 기본값 복원, Esc 취소, 손상된 저장값, 한글 입력 상태, 여러 레인 동시 누르기와 독립 해제, 반복 키다운, 포커스 이탈을 검사했다.
- 두 브라우저 검증은 격리된 테스트 계정과 데이터베이스를 사용했다. 각 검증에서 전투와 보상 화면을 거쳐 퇴장한 뒤 캔버스와 오디오 재생이 종료됐다.
