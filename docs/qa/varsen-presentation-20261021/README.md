# 바르센 레이드·인벤토리 이전 표기 정리

사용자 보고: 바르센 레이드 멘트 출력 영역과 인벤토리에 이전 마다라 리소스가 남아 있었다.

- 대사창 CSS가 이전 보스 이미지를 직접 참조하고 있었다. 기존 승인 바르센 SD로 연결하고 입장권 목록·상세·입장 화면·CMS에도 같은 승인 이미지를 사용한다. 승인 원본과 최적화 이미지의 바이트는 수정하지 않았다.
- 대사 제목·기믹 안내의 화둔/완전체 표현을 업화/거신으로 정리하고, 성공·실패·반격·입장 안내·보상 기록·영문 표기를 바르센으로 통일한다.
- 저장된 공대 및 재시도 영수증은 응답 표시 단계에서 변환한다. 사용자 닉네임이나 닉네임을 포함한 행동 기록을 일괄 치환하지 않는다.
- 인벤토리는 기존 `MADARA_RAID_ENTRY_TICKET` 코드의 이름·영문 부제·이미지·사용 안내만 바꾼다. 레이드 초기화 시 기존 카탈로그의 이름·부제·이미지도 갱신하며 보유 수량·미확인 수량·설명·등급·활성 상태를 유지한다.
- 전투 판정·피해·입장 비용·보상·운영 설정·저장 코드·영수증 ID는 유지한다. 새 그림이나 화면을 제작하는 작업이 아닌 기존 승인 이미지 연결 및 표시 문구 수정이다.
- 화면 재생성 스크립트에 기존 보상 공개 버튼·받은 보상 목록의 생명주기를 반영하여 재생성으로 현행 기능이 누락되지 않게 한다. 생성된 런타임의 실제 변경은 두 표시 문구뿐이다.

## 확인

- 운영 DB 읽기에서 기존 입장권의 이름 `마다라 레이드 입장권`, 부제 `MADARA RAID ENTRY`, 이미지 `cast-03.png`를 확인했다.
- 관련 회귀 10개 통과: 저장 응답 변환, 닉네임·전투·영수증 보존, 기존 입장권 7개/미확인 2개 보존, 카탈로그 표시 필드만 갱신, 생성물 재현 및 기존 보상 공개 연결, 기존 오리지널 몬스터 표시 회귀.
- 로컬 실제 게임 화면과 격리된 합성 계정/API로 PC 1440×1000, 모바일 390×844를 확인했다. 인벤토리 7개 표시·직접 사용 차단·현재 SD 연결, 대사 화자와 초상화, 가로 넘침 없음, 페이지 오류 0개.
- `docs/qa/varsen-presentation-20261021/`에 화면 및 확인 결과를 보존한다. 기능 확인을 새 리소스에 대한 사용자 시각 승인으로 취급하지 않는다.
