# 시즌패스 2개월차

게임의 보상 → 시즌패스에서 1개월차와 2개월차를 선택한다. 기존 후원 등록은 1개월차 구매로 읽는다. 두 달을 모두 산 계정은 각 달의 수령 기간에 해당 달력에서 보상을 받는다. 같은 달력은 최대 30일까지 열리며 후발 구매자도 이미 열린 날짜의 보상을 한 번씩 받을 수 있다.

2개월차는 사용자가 선택한 대로 빈 보상표와 판매 준비 상태에서 시작한다. OWNER CMS → 시즌패스 → 2개월차 보상표에서 30일을 채우고 ‘저장 시 2개월차 판매·보상 ON’을 선택해 저장한다. 처음 개방한 한국 날짜가 달력의 1일차다. 기존 후원 가격 29,800원과 입금 확인 절차를 사용한다. CMS 후원 관리에서는 최근 신청 월과 시각을 확인하고 실제 입금 내역에 맞는 월을 선택한다. 2개월차는 입금 확인 시점부터 30일간 수령할 수 있다.

기존 계정 데이터와 1개월차 설정·영수증은 원본 키로 읽으며 일괄 이관이 필요하지 않다. 개별·일괄 수령, CMS 저장, 구매 후원 등록은 기존 원자적 거래와 복구 경로를 사용한다. 2개월차 수령 기록은 달력 시작 시각이 1개월차와 같아도 별도로 처리한다. 과거 요청에 월이 없으면 1개월차로 처리하고, 구형 관리 화면에서 최근 2개월차 신청을 확정하려면 새 화면에서 월을 명시해야 한다.

범위 검수는 기존 후원 기능의 구매·수령·보상표와 로비 진입 경로에 해당한다. SQLite와 PostgreSQL에서 기존 구매자, 신규 구매자, 양쪽 구매자, 부분 등록, 개방·중지, 결제 실패 원복, 재시도, KST 경계 및 대형 지갑을 확인했다. PC Chromium 1440px와 모바일 WebKit 390px에서 CMS 등록 → 계좌 안내 → 결제 확인 → 수령과 응답 유실 복구를 격리 계정으로 점검했다. 작업 원본은 operations/season-pass-months-20261107에 있다.
