사용자 첨부의 STALE_ENEMY_INSTANCE 전투 중단 수정.

## 원인과 변경

승인받아 해당 계정의 미완료 전투 한 건을 읽기 전용으로 조회했다. 1층의 199개 이벤트 중 seq 110·111은 구수댕 ICON의 깊은 감칠맛 표식 EXPIRED 알림이며, 대상은 이미 HP 0으로 처치되고 같은 슬롯의 새 몬스터로 교체된 상태다. 연속 전투 엔진이 이 정상적인 종료 알림까지 오래된 공격 대상으로 취급해 중단했다.

연속 전투의 퇴장한 대상에 대한 ICON_STATUS 종료(EXPIRED/CLEANSED/WARD_END)만 화면 객체를 수정하지 않고 소비한다. 시간·진행도 콜백과 이벤트 순서는 유지한다. 일반 공격·전이 피해·신규 상태·퇴장한 공격자는 기존 검증으로 차단한다. 새 몬스터를 이전 몬스터 대신 참조하지 않는다. 현재 대상의 종료 알림은 기존 경로로 처리한다.

서버 판정·피해·전투 기록·보상·층 진행도와 자동 다음 층 조건은 변경하지 않았다. 운영 계정 쓰기 0건. 원본 비공개 기록은 저장소에 포함하지 않고 승인된 로컬 임시 파일에서만 재생한다. 화면의 계정 식별 문구는 격리 재생 계정으로 교체했다.
