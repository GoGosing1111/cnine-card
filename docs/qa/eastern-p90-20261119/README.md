# P90 제작 준비 및 착용 리소스

> 최신 상태: [일반 유저 공개·제작 ON 완료](../eastern-p90-public-20261119/README.md). 아래는 공개 전 준비 기록입니다.

운영 코드 반영 완료. 제작식 586은 OFF·비공개·OWNER-only로 유지합니다. 조건 저장 감사 64705, 최초 준비 감사 64700.

- 금룡 대물저격 또는 금룡 대물소총 **+15 1개 선택**. 장착 장비·다른 강화 단계·타인 장비는 제외합니다.
- 비밀무기 설계도 **1장·2장·3장 각 1개**, 코인 **500조**, 마스터의 별 **10억**.
- 성공률 **10%**. 두 무기를 교체해도 실패 누적 유지. **5번 실패 후 6번째 확정 성공**.
- 실패하면 선택한 무기가 파괴되며 기존 리페어로 같은 종류·+15를 복구할 수 있습니다. 기존 복구 정책: 리페어권 1개 + 코인 1,000억, 기간 제한 없음. 제작 비용은 반환되지 않습니다.
- 성공하면 투입 무기가 소모되고 **P90 +0 1개**를 지급합니다. 기존 연마 계승 경로를 유지합니다.
- E/F/G/H/S 슈트는 승인된 금룡 대물저격 착용 아틀라스와 투명 무기 리소스를 재사용합니다. 원화·공격 주기·전투력은 변경하지 않았습니다.

| 장비 | +0 총 전투력 | +15 총 전투력 |
|---|---:|---:|
| P90 | 910,000 | 5,005,000 |
| 금룡 대물저격 | 468,000 | 2,574,000 |
| 금룡 대물소총 | 468,000 | 2,574,000 |
| S-BODY | 12,500,000 | 해당 없음 |

P90 +0은 PvE 819,000 / PvP 91,000, +15는 PvE 4,504,500 / PvP 500,500입니다. S-BODY는 전부 PvE 전투력입니다. 연마·기타 계정 보너스 제외.

운영 변경은 조합식·재료·정책·감사·영수증의 단일 거래이며 오류 주입 5개 지점과 전체 예행 롤백을 확인했습니다. 독립 READ ONLY 대조 및 영수증 재실행은 SELECT 1회·쓰기 0건입니다. 운영 계정 재화·장비 변경과 메시지 발송은 없습니다.

SQLite/PostgreSQL 격리 검수에서 양쪽 무기 파괴·실제 종류 복구·공유 천장·정확한 고액 차감·부분 실패 롤백·응답 재시도를 확인했습니다. PC/Android/WebKit/Windows 진입 URL/H5의 실제 로비 경로에서 착용·사격, 제작소 첫/재진입, 프레임과 퇴장 정리를 확인했습니다. CMS는 실제 모듈/API를 격리 PostgreSQL에 연결해 조건 저장과 재조회를 확인했습니다.

성능은 단회 에뮬레이션이며 실휴대기기·설치형 Windows 앱 측정이 아닙니다. 운영 서비스 조회는 SQL 17/16회(유저)와 16/15회(CMS)를 유지했고 DB 왕복이 주 대기였습니다. 원본 아틀라스 재사용과 투입 장비 일괄 조회로 추가 자산·장비별 쿼리를 만들지 않았습니다. PC 제작 첫/재진입은 657/714→557/222ms, Android는 646/183→757/1466ms였습니다. 조건·캐시·다른 작업 부하 편차가 있어 속도 개선을 주장하지 않습니다. 기존 WebKit ResizeObserver 경고와 긴 프레임은 JSON에 기록했습니다.
