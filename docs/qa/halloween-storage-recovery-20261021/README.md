## 수정

- 서버 영수증·계정·요청 ID·횟수를 검증한 다음 완료된 pending을 해제한다. 선택적 브라우저 히스토리는 결과 전체 대신 재조회용 작은 참조를 저장하며, 저장 실패 시에도 확정 결과를 표시한다.
- 다음 개봉의 영속 요청 저장이 용량 초과로 실패하면 이 팩의 선택적 히스토리 키만 비우고 한 번 재시도한다. 다른 게임/로그인/사용자 저장 데이터는 삭제하지 않는다.
- pending 저장이 여전히 실패하면 개봉 API 호출 전에 한국어 오류로 중단한다. 서버 미확정·다른 계정·다른 요청·횟수 불일치는 기존 pending을 보존한다.
- 클라이언트 코인 캐시 저장 실패가 확정 영수증 이벤트와 결과 표시를 막지 않게 한다. 자동뽑기 재개, 새 요청 자동 구매, 서버 재화·발행 한도·확률 변경은 없다.
- 메인 로더와 할로윈 세션 import 버전, 셸 캐시를 함께 갱신한다. 기존 승인 전용 이미지를 그대로 사용하며 UI 조형·레이아웃 변경은 없다.
