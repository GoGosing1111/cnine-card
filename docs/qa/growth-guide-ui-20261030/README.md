# 초보자 가이드 리소스 교체 · 중복 제목/닫기 제거

사용자 요청: “초보자가이드 UI 오늘 작업한 리소스로 교체하고 중복으로 닫기나 초보유저 성장팁 안겹치게 해라”. 첨부 화면의 바깥 팝업 헤더와 iframe 내부 헤더가 동시에 보이던 문제를 수정했다.

## 변경 범위

- 초보자 가이드의 금색 가죽 스킨을 오늘 제작한 `assets/ui/tactical-20261030/panel-flat.webp`와 기존 은색 아이콘 6종으로 교체. 남색·청색 강조·기존 로비 폰트와 버튼 재질 사용.
- 삽입된 가이드의 내부 헤더만 첫 화면부터 숨겨 팝업 상단 제목/닫기 한 벌을 유지. 단독 URL에서는 제목과 닫기를 제공한다. 마지막 페이지 이동 버튼은 `가이드 마치기`로 구별한다.
- 팝업 헤더는 고정하고 iframe 본문만 스크롤. 모바일 목차는 2열, PC는 왼쪽 목차와 오른쪽 본문. 원본 `content.mjs`, 읽음 체크 저장 키, 메뉴 이동/메시지 origin·source 확인, 보상·재화·계정 로직 보존.
- 아이콘 원본 바이트는 기존 빌드에서 가이드 모듈에 삽입해 단독 URL도 동일하게 보인다. 신규 공개 파일을 추가하지 않으며 기존 20,000개 Pages 한도 안에 유지한다.
- 공유 로비 번들, 이를 읽는 기존 15개 웹 진입 경로의 캐시와 service worker만 갱신. 다른 콘텐츠 내부 UI·서버/Worker 소스·원스토어 전용 변형은 변경하지 않는다. 기존 원스토어 변형을 통째로 재생성하면 앞선 로비 변경까지 포함되는 것을 확인해 이 작업에서 생성한 변형 변경은 모두 되돌렸다.

## 검수

- 격리 API fixture를 이용한 실제 메인 화면 1440×1000, 768×1024, 390×844, 320×740에서 각 6항목: 총 24구간.
- 각 화면에서 제목 1개, 상단 닫기 1개, 제목/닫기 교차 0, 버튼 44px 이상, 가로 넘침 0, 아이콘/본문 이미지 누락 0.
- 6항목 체크, 이전/다음, 마지막 종료, 재열기 후 체크 유지, iframe 안에서 ESC, 상단 닫기, 인벤토리 바로가기 모두 정상. 브라우저 JavaScript 오류 0.
- 단독 URL 1440/390/320px에서도 제목/닫기 표시, 가로 넘침 0, 아이콘 정상.
- `content.mjs` 변경 없음. 아이콘 6개는 원본 WebP와 바이트 동일. 변경된 스타일/마크업은 가이드에만 한정한다.
- 관련 자동 검사는 공식 scoped 배포에서 기존 `tests/tactical-ui-delivery-20261030.test.mjs`, `test:lobby`로 한 번 실행한다. 기존 공개 수량, 아이콘 해시, 공유 로비 생성본 및 메뉴 계약 확인을 포함한다.

운영 기준은 Cloudflare 읽기 전용 조회로 확인한 Pages `30e986b0-e792-4acb-b7a6-f34143dce98e`, 소스 `6a6d55cdc38b33c9058b0742abdf5bfad9b08b30`. 배포는 `npm run deploy:production -- --scoped`를 사용한다.

검수 원본/스크린샷/배포 결과는 프로젝트 루트 `operations/growth-guide-ui-20261030/`에 보존한다. 기존 체크아웃·의존성 재사용, 운영 계정 직접 쓰기/메시지 전송/저장공간 유지관리/예약 없음.
