# 승부예측 큰 지갑 잔액 조회 복구

- 사용자 신고: 족단 ADMIN 계정에서 `Invalid coin wallet`과 함께 승부예측 목록이 표시되지 않음.
- 운영 읽기 조회에서 일반 계정 족단(ID 4582)은 정상이었으며, 관리자 계정 족다니(ID 5849, ACTIVE ADMIN)의 약 5경 잔액으로 동일 오류를 재현했다. 권한 차단이 아니라 패키지 코인 분리 로직이 전체 지갑에 JavaScript 안전 정수 한도를 적용한 문제다.
- 지갑과 코인 로그 금액을 SQL TEXT로 읽고 BigInt로 정확히 해석한다. 제한 코인 대조·잔액 동시 변경 검사에는 정확한 정수 문자열을 사용하고, 기존 화면용 숫자 필드와 UI는 유지한다.
- 패키지 제한 잔액의 기존 안전 정수 검증과 패키지 지급 한도, 일반 계정의 이벤트당 500억 제한, 기존 원자 거래·재시도·권한 조건은 유지한다. 공통 DB 어댑터와 스키마를 수정하지 않는다.
- 실제 계정 잔액·재화·권한·패키지 기록·경기·베팅을 운영에서 수정하거나 생성하지 않는다.

## 검증

- `tests/prediction-large-wallet-20261020.test.mjs`: PostgreSQL 실제 호환 계층에서 ADMIN/일반 목록 조회, 5경대 잔액의 정상 베팅·중복 방지·정확한 환불, Number로 구분되지 않는 1코인 동시 변경 차단/새 조회 복구, 큰 일반 원장 금액과 패키지 제외 금액 및 음수 차단 3개 통과.
- 기존 패키지 지급/원장 및 승부예측 목록·정산 검사는 scoped 배포에서 실행한다. UI 구조·이미지 변경 없음.
- 배포 및 운영 확인 결과는 같은 폴더 `release.json`에 기록한다. 비공개 QA 폴더이므로 정적 사이트에 포함하지 않는다.
