# 제작소 선택·재료·비용·확률 UI 개편

사용자 요청: 제작소 전체 UI 점검과 리소스 개선, UI 스킬 적용. 우선순위 답변: **“제작 편의: 선택·재료·비용·성공률을 한눈에”**.

## 구현 범위

- 차량 제작, 장비 합성, 재료 제작, 배틀슈트 제작, 슈트코어 합성, 장비 제작, 용병 제작 7개 분류.
- PC는 설계도 목록과 상세 작업대를 유지하고 선택 상태·제작 가능 상태·실제 결과물 이미지를 일관되게 표시한다. 슈트 목록은 코어 대신 슈트 자체를 사용한다.
- 모바일은 제작 분류/제작품 선택 상자를 사용한다. 제작품 변경 후 새 상세 영역으로 포커스와 스크롤을 이동한다. 상단 요약에서 결과물, 표시된 성공률, 현재 횟수/결제 방식의 필요량·보유량·부족분을 확인한다.
- 재료 행, 코인·마스터의 별·카드 조각 아이콘, 부족/충족 상태, 확률 표기를 통일한다. 경 단위를 지원하며 정수 문자열 표시는 BigInt로 처리한다. 서버 잔액이나 경제 정책은 바꾸지 않는다.
- 용병 검색 결과가 없는데 카이론 패널이 나오는 문제, 슈트 검색 결과가 없는데 공개 제작식이 없다고 안내하는 문제를 수정한다. 전체 레시피로 복귀하는 버튼을 제공한다.
- 장비 제작 확률을 전달받은 레시피 값으로 표시하고 기존 천장 상태를 반영한다. 로딩·빈 결과·부족 재료·한정 수량 소진·진행 중·결과 재확인 상태를 유지한다.

## 디자인 및 리소스

명시적으로 요청한 로컬 Impeccable 스킬을 사용했다. 기존 네이비/라임 게임 UI를 유지한 Operate 화면 개편이며 글로벌 디자인 시스템 교체가 아니다. 제품 맥락은 `PRODUCT.md`, 표면 계약은 `.impeccable/surfaces/js-workshop-v1881-js.md`에 기록했다. 두 개발 문서는 공개 배송에서 제외된다.

기존 승인 차량·장비·슈트·용병·재료 원본과 썸네일 매핑을 그대로 재사용한다. 원화 바이트·조립 부품·Spine·전투/제작 연출 수정은 없다. 새 래스터 파일 없이 작은 SVG 아이콘과 CSS/HTML 리소스 연결을 개선했다.

초기 점검에서 확인한 문제는 분류별 상이한 비용 표기, 작은 보조 글자, 모바일의 긴 선택 목록, 부족분 식별, 빈 검색 결과의 잘못된 패널이었다. 최종 기계 검출기 결과는 `[]`. 별도 새 컨텍스트의 finish reviewer가 21개 캡처를 검토했고, 지적한 모바일 선택 이동·조건 요약·슈트 겹침·확률 라벨·용병 비활성 버튼 5건 모두 수정 후 **ship** 판정을 받았다. 이 판정은 해당 5건의 해결 범위다.

## 검수 근거

- 변경 전 1440/390, 변경 후 Chromium 1440·WebKit 390·Chromium 320에서 7분류, 총 21화면. 렌더 오류·가로 넘침·보이는 이미지 손상 없음.
- 실제 메인 앱/라우터/지연 로더를 통한 PC 핵심 조작 44항목 통과. 조회 실패 후 복구, 전송 응답 유실 후 동일 requestId 재확인, 결제 방식과 재료 안내, 검색 포커스, 리스트 위치, 필터를 포함한다.
- 실제 메인 앱 모바일 WebKit 390·Chromium 320에서 7분류, 총 14화면 통과. 선택 후 포커스, 검색, 빈 결과, 10경 표시, X-BODY 25조/코어 부족, 제작 횟수 3회 비용 갱신, 101회 차단 검증.
- 기존 `test:workshop`: 첫 실행 83항목 통과. 변경된 내비게이션을 예전 번호 문자열로 검사하던 3검사는 실제 생성 HTML 검사로 갱신해 통과했다. sparse 작업 폴더의 누락 조립 소스·보고서·번들은 Git 정본에서 필요한 파일만 복원했다. 실패 검사 재실행에서 42항목 통과 후 남은 누락 2건도 각각 통과했다. 거래/서버 코드 수정은 없다.
- 조립 연출 GSAP seek/skip/restart/cancel, 실제 서버 영수증 후 연출 시작과 상태 동기화, X-BODY 계약 검사를 보존한다.
- `node --check` 두 UI 모듈, ONE store 14파일 생성/일치 검사 통과. 최종 결제/용병 재료/배송 회귀와 운영 파일 검증은 배포 기록에 추가한다.

계정과 API는 격리 fixture이며 운영 재화 소모·계정 직접 쓰기·메시지 발송 0. 실제 장치/설치 앱 검수나 운영 계정 제작을 했다는 의미가 아니다. 공지·예약·용량 유지관리·삭제를 실행하지 않았다.
