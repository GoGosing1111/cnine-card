발동 알림과 BGM 발동표에 0~100% 음량 슬라이더와 음소거/해제 버튼을 추가했다. 재생 중 즉시 반영하며 음원을 다시 불러오거나 재생 위치를 초기화하지 않는다. 음량과 음소거 전 수치는 기기 localStorage에 저장한다. 다음 곡·재입장·새로고침·음소거 상태 새로고침 후 해제에 유지된다. 미설정 사용자는 기존 곡별 `#av` 음량(미지정 25%)을 그대로 사용한다. 다른 이용자에게 음량 변경 요청을 보내지 않는다.
