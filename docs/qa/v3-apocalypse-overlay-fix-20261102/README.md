# 아포칼립스 전장 빨간 타원 제거 — 2026-11-02

사용자 긴급 요청에 따라 전장을 덮는 붉은 타원을 제거한다. V3 HUD의 전체 크기 `::after`와 기존 `.apocalypse-battle-field:after` 배지가 같은 가상 요소에 합쳐졌다. 배지의 붉은 배경·999px 둥근 모서리에 새 레이어의 오른쪽/아래 inset이 남아 큰 타원이 되었다. 앞선 일반 사냥 fixture에는 실제 아포칼립스 클래스와 전용 CSS가 빠져 이 충돌을 놓쳤다.

- 기존 아포칼립스 배지 가상 요소를 제거하고 새 HUD에서도 해당 요소를 명시적으로 비표시한다. 두 CSS 중 하나가 구버전으로 남아 있어도 덮개를 표시하지 않는다.
- 메인/원스토어의 두 스타일 URL과 앱·서비스워커 버전을 갱신한다. 피해·안전지대 선택·타이머·실패/성공·보상 코드는 변경하지 않는다.
- 기존 실제 V3 브라우저 검사에 `APOCALYPSE`를 추가해 전용 CSS와 실제 클래스 조합을 검사한다. 수정 전 PC에서 붉은 가상 요소 694×812px와 검사 실패를 재현했다. 수정 후 PC1440·모바일390·가로844에서 모두 `content:none / display:none`을 확인했다.
- 동일 실행에서 키보드 정답·클릭 오답·시간초과, 중복 응답 방지, 버튼 최소44px, 초상 고정 폭, 전체 배경, 최종 상태·종료를 검증했다. 운영 API는 격리했으며 실기기 검증은 아니다.

기록: 프로젝트 루트 `operations/v3-apocalypse-overlay-fix-20261102/`. `before/`와 `fixed/`에 원인 재현·수정 화면과 결과를 보존한다. 실제 배포와 공개 화면 검증 결과는 후속 기록한다. 기존 폴더/의존성 재사용, 원본 보존. 운영DB/계정쓰기·메시지·사용자 화면 조작·유지관리·예약 없음.
