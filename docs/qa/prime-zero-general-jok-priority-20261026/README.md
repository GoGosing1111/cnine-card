## 적용 정책

PVP에서 상대의 살아 있는 용병이 모두 제너럴 족 V-974이면 프라임 V-975·제로 V-976에게만 적용한다. 일반 1대1 PVP와 상대 용병 둘 다 제너럴 족인 듀오를 포함하며, 다른 용병이 섞인 상대 편성에는 적용하지 않는다. 서버 정본 코드·실제 편성으로 판정하고 전투 시작 시 한 번 고정한다.

- 기존 연계 공격 4배, 체력·방벽 16배의 전용 우위.
- 양쪽 소유자별 카드 연계·장비·성장을 모두 반영한 뒤, 제너럴 족 실제 공격력의 최소 4배와 최대 체력·방벽의 최소 16배를 추가로 보장한다. 현재 체력 비율을 보존하고 기존에 더 높은 값은 낮추지 않는다.
- 제너럴 족의 자연 속도와 소유자 카드 행동으로 얻는 추가 행동을 합산한 기준의 2배 이상으로 대응한다. 다른 소유자의 카드 속도를 섞지 않는다. 기본 전투력·성장 원장·추가 행동 숙련 수치를 바꾸지 않는다.
- 공격·방어·피해 경감·보호막·회피·행동 판정은 실제 서버 전투 엔진을 사용한다. 승자 결과를 덮어쓰지 않으며 사망 후 부활이나 재조회 회복·재증폭을 추가하지 않는다.

세 용병의 앞선 단일 스킬 1.5배·광역 총 3,024%와 상한 2배, 스킬 자원/재사용, 승인 원화·모션을 유지한다. 기본 전투력은 프라임·제로 300만, 제너럴 족 270만이다. 프라임 제작 r6·ON과 CMS/성장/팩/런타임 설정을 보존한다. 계정·재화·지급·설정 변경 없음.
