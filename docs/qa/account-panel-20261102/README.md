# 닉네임 계정 창 · 개인키 숨김과 로비 UI

사용자 요청: 닉네임을 누르면 나오는 창에서 개인키가 바로 노출되지 않도록 하고, 현재 로비를 참고해 UI를 바꾼다.

후속 확정: **카드 조각을 마스터의 별로 교체**, **코인·마스터의 별을 50억·100억처럼 간단 표시**한다. 최신 창은 보유 코인·수집 카드·마스터의 별을 표시한다.

## 변경

- 최초 열기·다시 열기는 빈 password 입력과 고정 마스킹 표시다. 실제 키를 초기 HTML·value 속성·보조 텍스트에 넣지 않는다. 직접 보기를 눌러야 표시하며, 숨기기·30초 경과·창 초점 이탈·탭 숨김·닫기·페이지 이탈 때 지운다.
- 키를 보여주지 않고 복사할 수 있다. 기존 클립보드 지원이 없는 환경은 화면 밖 임시 필드로 복사하고 즉시 지운다. 복사 실패를 성공으로 안내하지 않으며, 저장된 키가 없으면 보기/복사를 비활성화한다.
- 실제 로비의 `assets/ui/tactical-20261030/panel-flat.webp`, 남색·청록색·Pretendard를 사용한다. 제목은 내 계정, 정보는 로그인 상태·닉네임·보유 현황·복구 키·하단 조작으로 정리한다. PC 폭620px, 모바일은 코인 한 줄과 카드/마스터의 별 두 열, 보기/복사 버튼 한 줄을 유지한다. 짧은 화면은 패널 내부에서 스크롤한다.
- 코인과 마별은 로비와 같은 만/억/조 단위·최대 소수1자리로 줄인다. 예: 50억·100억·1.2조·58.9조. 숫자를 누르면 정확한 수치, 다시 누르면 간단표시로 돌아간다. title과 보조기기 이름에도 정확한 수치를 제공한다. 표시만 변경하며 재화 원장과 카드 조각 데이터는 유지한다.
- Escape·배경 클릭·닫기·계속 이용하기로 종료한다. Tab 초점을 창 안에 유지하고 닉네임 버튼으로 돌려준다. Safari의 클릭 초점 차이를 보완했다. 공유 모달 교체/셸 재렌더링 시 이벤트·타이머도 해제한다.
- 인증·개인키 발급/저장·세션 API·로그아웃 확인·계정 재화/보유·서버 코드는 유지한다. 운영 계정/DB 쓰기·키 재발급 없음.
- 메인 HTML/서비스워커 캐시를 함께 갱신한다. ONE store 파생 앱과 매니페스트는 기존 생성기로 갱신하고, 배포 파생 패치의 CSS 참조만 같은 버전으로 맞춘다. 메인/파생 계정 함수가 동일함을 확인했다.

## 검증

검사: `tests/account-panel-privacy-20261102.test.mjs`. 실제 index/app/로비를 headless 브라우저로 열고 닉네임 버튼을 누른다. 계정 API와 클립보드는 격리 fixture이며, 증거의 키와 닉네임은 가짜 검수용이다.

- Chromium 1440×1000·390×844·320×740·1440×560: 기본숨김·복사·명시적 보기/숨기기·타이머·화면이탈·닫기/재진입·키없음·복사거부/구형복사/실패·외부모달교체·Tab/Escape/초점복귀·긴닉네임·로그아웃 취소/확인. 초기133항목 통과, 최종 배포 게이트에서 화면숨김 회귀를 포함해 다시 검증한다.
- WebKit 390×844: 위 핵심 열기/복사/보기/숨기기/화면이탈/재진입과 Safari 초점 복귀32항목 통과. 실제 오류0. 기존 `docs/qa/ios-safari-memory-20261031/browser.json`에도 있는 ResizeObserver 알림1건은 경고로 별도 보존했다.
- 첫 브라우저 시도는 격리 계정의 시청 동의 안내가 클릭을 막았다. fixture의 기존 안내 확인 상태를 설정하고 재검사했다. 최초 파생본 생성은 엄격 패치의 옛 CSS 쿼리 때문에 중단했고 같은 캐시 참조를 반영해 재생성했다. 실패 기록은 보존한다.
- 공개 파일·Windows 매니페스트·실제 번들 로더·파생본·공개 포장은 표준 scoped 게이트와 배포 직후 확인한다. 무관한 전체 게임 검사는 반복하지 않는다.

## 범위와 기록

실기기·설치 앱 검수나 사용자 최종 시각 승인으로 기록하지 않는다. 키 저장 방식 자체를 바꾸는 인증 개편이 아닌 계정 화면의 노출 제어다. 사용자 화면 조작·실제 계정 로그인·메시지·용량 유지관리·새 예약 없음.

기존 `output/revan-live-20261027/release-checkout`과 의존성을 재사용했다. 원본 증거는 프로젝트 루트 `operations/account-panel-20261102/`에 보존한다. 직전 운영 Pages/Worker와 배포 계획, 실패/정상 화면, 공개 파일 해시, 복구용 이전 커밋을 함께 기록한다. 미출시 V3.5 원본은 기존 공개 포장 제외 규칙을 유지한다.
