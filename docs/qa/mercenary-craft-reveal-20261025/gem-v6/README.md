# 용병 제작 보석 손잡이 정정 V6 — 2026-10-25

사용자 지시: 기존 금색 바를 유지하고 겹친 손잡이의 ‘밀기’ 표시를 제거한다. 첨부한 V4 화면의 빨간 선처럼 파란 보석이 바 왼쪽 안쪽에서 시작한다. V5의 연두색 버튼 시안은 반려되었다.

- 중첩된 봉인 장치·화살표·‘밀기’ 글자를 없앴다. 기존 원화의 파란 보석과 얇은 금색 테두리만 SVG로 잘라 움직이는 손잡이로 사용한다. 보석 중심은 바 너비의 20%에서 시작해 80%까지 이동한다.
- 금색 바의 양쪽 고정 보석만 비운 `action-track-v6.webp`를 사용한다. 기존 금속 프레임·실루엣·종횡비·주변 장식과 제작실/결과 배치를 유지한다. ImageGen built-in으로 투명 PNG를 편집했고 원본·프롬프트·해시는 자산 폴더에 보존했다. 보석 자체는 기존 `action.webp`를 사용한다.
- 시각적 보석 크기와 별도로 손잡이의 넓은 입력 영역(PC 104×88px, 모바일 92×84px)을 유지한다. 바 전체에서도 최대 120px의 오른쪽 드래그로 개방한다. 탭·역방향·미완료 드래그는 개방하지 않는다.
- 실제 제작소와 격리 SQLite에서 1440×1000·754×892·390×844·320×640·844×390, 성공/실패·터치/마우스/키보드 **225개 확인 통과**. 보석 시작 위치·문구 간격·모바일 중앙/끝 터치·포인터 정리·결과 배치·영수증 중복 차감 방지를 확인했다. `browser.json`과 PNG에 기록했다.
- 실제 인앱 브라우저 754×892에서도 새 보석과 문구 사이 간격, 시작 위치를 직접 확인했다. 기술 검수를 사용자 시각 승인으로 기록하지 않는다.
- 제작 재료·가격·성공률·획득 정책·계정 데이터는 변경하지 않았다. 미리보기는 예시 영수증만 사용한다.

반려 시안은 `../handle-v5/`, 이전 손잡이/입력 수정은 `../drag-v4/`에 이력으로 보존한다. 최신 배포의 다른 콘텐츠 변경을 유지해 rebase한 뒤 지정 scoped 배포 절차를 사용한다.
