# 아르덴 방어구 설계도

사용자 요청에 따라 아르덴 승인 방어구와 에너지의 백금·금색·청록 팔레트를 참조한 전용 설계도 아이콘을 내장 ImageGen으로 제작했다. 기존 설계도는 보존하며 새 아이템 `ARDEN_ARMOR_BLUEPRINT` / 아르덴 방어구 설계도를 추가한다.

원본 PNG와 512px WebP, 실제 프롬프트와 SHA-256은 이 폴더의 manifest.json·prompts.json에 기록한다. 기술 검수를 사용자 시각 승인으로 기록하지 않는다. 기존 인벤토리 렌더러를 그대로 사용한 PC 1280px·모바일 iframe 390px 검수는 qa.json과 스크린샷을 따른다. 별도 프리뷰 UI는 제작하지 않았다.

기존 아르덴 에너지와 동일하게 MATERIAL / SPECIAL / 활성으로 등록하며 직접 사용은 불가하다. 기존 제작소 CMS의 재료 선택 목록에 노출된다. 제작식·비용·확률·드롭·상점·계정 지급은 추가하지 않는다.

등록 도구 scripts/ops/arden-armor-blueprint-20261024.mjs는 신규 한 행·감사 로그·완료 영수증을 같은 SERIALIZABLE 거래에 저장한다. 같은 코드·이름·이미지가 존재하면 덮어쓰지 않는다. 재시도는 후속 CMS 편집을 보존한다. 관련 5개 검사는 tests/arden-armor-blueprint-20261024.test.mjs에서 자산·기존 인벤토리 표시·신규 등록·기존 원장 보존·중복·충돌·실패 롤백을 검증한다.

신규 자산과 일회 등록 도구만 포함된 작은 변경으로 지정된 scoped 배포를 사용한다. 운영 이미지 해시 확인 후 등록하고 별도 읽기 연결로 카탈로그·CMS·영수증을 검증한다. 최종 운영 영수증은 production.json에 기록한다.
