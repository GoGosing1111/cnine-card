# 블러드문 프라임 재료 카드 · 제작 잠금 — 2026-10-25

사용자 요청: 블러드문팩의 프라임 레퀴엠 완제 지급을 `기운잃은 프라임 카드`로 바꾸고, 이 재료로 완제 용병을 제작하는 연결과 리소스를 준비한다. 후속 답변에 따라 **제작 조건은 추후 결정, 현재 제작 잠금**이다.

## 구현

- 재료 아이템 `MERCENARY_PRIME_DEPLETED_CARD`, 분류 MATERIAL, 등급 SSS. 직접 사용/편성할 수 없고 인벤토리에 수량으로 보관한다. 신규 이미지 원본·프롬프트·입출력 SHA-256은 `manifest.json`과 `originals/`에 있다. built-in ImageGen으로 기존 승인 프라임을 참조한 별도 재료 카드를 만들었으며, WebP는 크기/포맷 변환만 했다. 기술 검수를 사용자 원화 승인으로 기록하지 않는다.
- 기존 확률/재고 키 `V-975`는 동일하다. 1/10회와 최대 100,000회 추첨 모두 해당 구간을 재료 1장으로 지급하고 팩 발행 번호를 한 번 소비한다. 팩 한도·확률·가격은 추가 설정하지 않았다. 할로윈은 변경하지 않았다.
- 재료 지급은 `cnine_user_inventory`와 `inventory_logs`에 기록한다. 동일 원자 거래에서 팩 발행 번호·재료·코인·완료 영수증을 확정하며 `user_mercenary_cards_v1`/용병 획득 로그에는 새 프라임 완제를 만들지 않는다. 기존 발행 테이블의 V-975는 이 구간의 팩 발행 번호이며, 재료 지급의 근거는 재료 인벤토리 로그다.
- 미결제 PENDING 구버전 계획은 추첨 위치·금액을 보존하면서 재료로 전환한다. 이미 COMPLETED인 완제 영수증과 기존 보유 카드는 바꾸지 않는다. 재료 영수증은 실제 인벤토리 로그와 발행 번호를 확인해야 복구된다.
- 제작소 `WORKSHOP_PRIME_REQUIEM`은 재료→프라임 레퀴엠 V-975 완제 연결을 공개하지만 서버 출시 플래그 false다. 재료 수량/코인/마스터의 별/성공률/제작 한도는 모두 null이며, CMS ON·직접 API·지급 helper도 차단한다. 다른 제작 레시피와 기존 프라임 전투/원화는 유지한다.
- 팩은 기존 붉은 UI, 제작소는 승인 남색 패널/연두 버튼을 사용한다. ITEM 결과도 이미지/수량과 제작 재료 안내를 표시하며 획득 없음으로 합산하지 않는다.
