사용자 승인한 거상식 세로 초상, 큰 상단 패널 축소, 모바일 배경 전체 채움을 공통 V3 전투에 적용한다. 작은 초상은 표시 전용이며 선택·클릭 기능을 추가하지 않는다. 사용자 최종 지시는 전체 라이브 배포다.

## 구현

- 아군/상대 초상에 기존 얼굴 원본, 이름, HP/보호막, 행동 및 전투불능 상태를 표시한다. 런타임 ID와 진영을 함께 사용하여 같은 카드의 양쪽 상태가 섞이지 않는다. 실제 서버 최종 상태와 용병 상태를 반영한다.
- 모바일 세로 초상은 모두 50px이다. 초기 검사에서 기존 카드 CSS의 내용 폭 정렬이 남아 이름 길이에 따라 폭이 달라졌고, 리스트·항목 폭을 고정하여 수정했다. `browser-initial/HUNT-390.png`는 반려된 초기 검사이며 배포 기준이 아니다.
- 전장은 기존 Pixi 캔버스 하나로 화면 전체를 채운다. 초상 공간은 전투 배치에만 예약하며 배경에는 검은 여백을 만들지 않는다. 새로운 배경이나 용병 원화는 생성하지 않았다.
- 일반전/PVP·듀오·협동 2/3분대에서 실제 편성을 표시한다. PC의 다중 분대는 열로 나누고 모바일은 화면 높이에 맞춘다. 가로 화면의 밀집 초상은 얼굴을 이름 옆에 둔다.
- 얇은 전황 헤더, 전투 진행 표시와 작은 회피 기믹을 적용한다. 기믹의 입력·타이머·요청 소유권·서버 판정은 유지한다. 탑·격전지·흑익·군단·월드레이드의 전용 헤더/시계/조작 UI 및 진무 대사를 보존한다.
- 공통 엔진의 11개 소비 번들, 원스토어 파생본과 캐시 버전을 동기화한다. 직전 아이폰 메모리 수정 `ab6c5a2d6`을 기준으로 합쳐 그 소스와 검사도 보존한다.

후속 83개 검사는 모두 통과했다. 이어 공통 출시 검사에서 앱 URL의 주 버전과 서비스워커 버전 불일치를 확인해, 실제 반영 전에 두 버전을 `tactical-hud-20261102-v1` 접두어로 일치시키고 원스토어 파생본을 다시 생성했다. 실패 로그와 수정 내역을 모두 보존한다.

Impeccable의 로컬 고정 버전으로 구현·시각 검토를 수행했다. 최종 소스 탐지는 기존 CSS 9행의 청록 왼쪽 테두리 경고 1건을 보고했다. 이 규칙은 기존 복구/구형 UI에 남아 있는 스타일이며 새 초상 배치의 클릭 가능성을 뜻하지 않는다. 탐지 결과를 무시 설정으로 숨기지 않았다. 별도의 디자인/기술 검토에서 고정 폭·밀집 초상·전용 헤더·대사·보스 선택·배너 위치 문제를 확인하고 수정했다. 일부 기존 용병 이미지는 얼굴 전용 원본이 없어 전신/효과가 함께 보이며 이름으로 구분한다.

실제 휴대폰/설치 앱 검수나 모든 전투·모든 조합의 검증으로 확대하지 않는다. 피해·승패·보상·편성·운영 DB 및 원화/모션은 변경하지 않는다. 사용자 화면 조작, 메시지 발송, 저장소 유지관리·삭제·예약은 하지 않았다. 라이브 결과와 공개 파일/클라이언트 매니페스트 해시는 배포 후 기록한다.
