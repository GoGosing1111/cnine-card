# 무한의탑 200층 확장

2026년 11월 24일

150층 다음에 151~200층을 잇는다. 이번 주 150층을 완료한 계정은 151층에서 이어서 오를 수 있다. 일반 카드 5장과 출전 용병 최대 2명으로 도전하고, 한 층에서 일반 24마리와 정예 3마리, 마지막 수호자 1마리를 180초 안에 쓰러뜨리면 다음 층이 열린다. [기존 150층 운영 기준](../tower-coop-live-20261102/README.md)

관문 사이의 일반층에서는 해당 구간의 우두머리가 마지막에 등장한다. 도전 화면과 전투 화면은 같은 층의 수호자 원화를 사용한다. [몬스터 9종](monster-roster.webp) · [ImageGen 제작 프롬프트](art-prompts.json) · [원본과 배포 파일 해시](art-files.json)

## 진행과 정산

현행 탑과 같이 각 층을 그 주 처음 클리어할 때 층에 설정된 코인과 기존 부가 드롭을 정산한다. 151~200층 기본 코인은 121~150층 규칙을 연장해 10층 아래 같은 위치의 1.3배로 계산했다. 수집 보너스를 적용한 탑의 1회 정산 한도는 기존 100조다. 진행과 순위는 매주 월요일 0시(한국시간)에 초기화한다. [기존 층별 코인 계산식](../../../scripts/ops/tower-121-150-policy-20261102.mjs) · [주차 처리](../../../functions/_tower_weekly.js)

| 수호자 관문 | 기본 클리어 코인 | 직전 10층 관문 대비 |
|---:|---:|---:|
| 150층 | 8조 7,880억 | 기준 |
| 160층 | 11조 4,244억 | +30% |
| 170층 | 14조 8,517억 2,000만 | +30% |
| 180층 | 19조 3,072억 3,600만 | +30% |
| 190층 | 25조 994억 680만 | +30% |
| 200층 | 32조 6,292억 2,884만 | +30% |

일반층끼리도 같은 위치에서 10층마다 30%씩 오른다. 예를 들어 141층의 기본 코인은 1,318억 2,000만, 151층은 1,713억 6,600만, 161층은 2,227억 7,580만이다. 한 구간 안에서도 첫 일반층부터 아홉 번째 일반층까지 층마다 증가한다. [층별 기본 코인 원본](floor-plan.json)

## 편성별 모의 전투

11월 24일에 저장된 시즌 29 챌린저 토벌 편성 20개를 탑 엔진에 대입했다. 장비 비교에서는 같은 카드·용병·펫·슈트·부위별 연마 효과를 사용하고 두 용병의 5부위 장비와 강화도만 바꿨다. 입장 가능한 각 편성은 층마다 같은 난수 시드 16개로 전투했다.

| 관문 | 비교한 용병 장비 | 전 부위 +10 승리 | 전 부위 +15 승리 |
|---:|---|---:|---:|
| 160층 | 심연성좌 8단 | 208/320 (65.0%) | 303/320 (94.7%) |
| 170층 | 심연성좌 8단 | 156/320 (48.8%) | 199/320 (62.2%) |
| 180층 | 새벽별 · 유니크 1단계 | 142/320 (44.4%) | 249/320 (77.8%) |
| 190층 | 그믐달 · 유니크 2단계 | 121/320 (37.8%) | 240/320 (75.0%) |
| 200층 | 태양왕좌 · 유니크 3단계 | 98/320 (30.6%) | 160/320 (50.0%) |

기존 착용 장비로는 159층에서 320전 전승했고, 160층에서 168승(52.5%)을 거뒀다. 유니크 장비 없이 창세의 왕관 10단 +15를 착용한 편성은 170층에서 272승(85.0%), 179층에서 142승(44.4%)을 기록했다. 유니크 입장 조건에 미달한 편성은 승률 집계에서 제외했다.

별도 연속 등반에서는 같은 20개 편성이 159층 클리어 상태에서 출발해 층마다 최대 3번 도전했다. 창세의 왕관 +15로 시작해 180·190·200층에서 각 단계 유니크 +15로 교체한 경우 170층은 18개 편성, 180층과 190층, 200층은 각각 9개 편성이 통과했다. 층별 비교 12,400전과 연속 등반 1,452전을 합쳐 13,852전이다. [편성별 결과 집계](balance.json) · [재현 스크립트](../../../scripts/qa/measure-tower-200-20261124.mjs)

## 서버와 화면 검증

Chrome의 1,440px PC 화면과 390px 모바일 화면에서 160·180·200층에 각각 진입했다. 실제 전투 캔버스에서 구간별 몬스터 이미지를 불러오고, 도전 화면의 수호자와 서버가 전송한 마지막 적의 이미지가 일치하는지 확인했다. [화면 검증 6건](browser/verification.json) · [PC 180층](browser/1440-180-entry.webp) · [모바일 200층 전투](browser/390-200-battle.webp)

격리 PostgreSQL 호환 DB에서 150층을 완료한 계정으로 151~200층을 일반 시작·완료 경로로 통과했다. 179/180층, 189/190층, 199/200층 경계에서 입장 안내와 서버 판정이 일치했다. 조건을 채운 뒤에는 같은 요청으로 입장할 수 있었고, 입장 후 장비를 바꾼 경우에도 저장된 전투를 정산했다. 200층 완료 뒤에는 다음 월요일 1층으로 복귀했다. [서버 등반 검사](../../../tests/tower-151-200-20261124.test.mjs) · [도전 화면 검사](../../../tests/tower-abyss-ui-20261021.test.mjs)
