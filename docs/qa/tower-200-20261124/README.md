# 무한의탑 200층 확장과 주간 보상안

2026년 11월 24일 · 로컬 준비본

이번 주 150층을 깬 이용자는 151층부터 이어서 오른다. 200층에 처음 도달하면 나락의 군주를 상대하고, 그 주에 이미 깬 수호자를 다시 잡아 강화주문서를 얻을 수 있다. 층 배치와 전투는 로컬 서버 경로로 검증했다. 아래 주간 보상, 반복 보상, 기념 칭호는 지급 설계안이다.

## 151~200층

기준이 되는 기존 150층은 수호자 전투력 90억, 기본 코인 8조 7,880억이다. 일반 카드 5장과 용병 최대 2명 편성으로 한 층씩 오른다. 각 전투는 일반 24마리, 정예 3마리, 마지막 수호자 1마리 순서이며 공식 제한 시간은 180초다. [150층 출시 기록](../tower-coop-live-20261102/README.md)

| 신규 구간 | 일반층 코인 | 10층 관문 수호자 | 관문 전투력 | 관문 기본 코인 |
|---|---:|---|---:|---:|
| 151~160층 | 1,700억~1,900억 | 혈월 군주 | 150억 | 10조 |
| 161~170층 | 2,000억~2,200억 | 망각의 집행자 | 250억 | 12조 |
| 171~180층 | 2,300억~2,500억 | 가시왕 모르가 | 400억 | 15조 |
| 181~190층 | 2,600억~2,800억 | 식월의 예언자 | 650억 | 18조 |
| 191~200층 | 2,900억~3,100억 | 나락의 군주 | 1,000억 | 25조 |

전투력은 직전 관문부터 다음 관문까지 열 층에 같은 비율로 나눠 올리고 100단위로 반올림했다. 첫 신규 일반층은 약 94.7억이며 153층부터 기존 엔진 상한인 100억을 넘는다. 준비본에서 151~200층의 허용 전투력을 1,000억까지 열었다. 일반층 코인은 같은 구간에서 한 층마다 25억씩 오른다. [전투 엔진](../../../functions/_tower_v3.js) · [층별 수치 50개](floor-plan.json)

한 주에 151~200층을 모두 등반하면 기본 코인은 일반층 45곳에서 **10조 8,000억**, 수호자 관문 5곳에서 **80조**로 총 **90조 8,000억**이다. 기존 1~150층을 더한 1~200층 합계는 약 **131조 8,038억**이다. 모두 수집 보너스 적용 전 금액이다. 새 구간의 실제 한 전투 지급액은 수집 보너스를 합산해 기존 정산 한도인 100조까지 계산한다. [기존 120층 코인표](../tower-boss-rewards-20261022/floor-plan.json) · [121~150층 코인표](../tower-121-150-20261102/floor-plan.json)

## 주간 클리어 보상

등반과 순위는 매주 월요일 0시(한국시간)에 1층부터 새로 시작한다. 각 층의 그 주 첫 승리에는 기본 코인을 지급한다. 아래 재료는 정해진 관문을 그 주 처음 통과하는 순간 자동 지급한다. 숫자는 **해당 층까지 받은 누적량**이다. 예를 들어 190층에서 200층으로 올라가면 마스터의 별 7,000만 개와 아르덴 에너지 3개를 더 받는다. [기존 주차 처리](../../../functions/_tower_weekly.js)

| 이번 주 최고 클리어 층 | 마스터의 별 누적 | 아르덴 에너지 누적 |
|---:|---:|---:|
| 50층 | 1,000만 개 | 1개 |
| 100층 | 3,000만 개 | 2개 |
| 150층 | 6,000만 개 | 4개 |
| 160층 | 9,000만 개 | 6개 |
| 170층 | 1억 3,000만 개 | 8개 |
| 180층 | 1억 8,000만 개 | 10개 |
| 190층 | 2억 3,000만 개 | 12개 |
| **200층** | **3억 개** | **15개** |

계정의 첫 200층 돌파에는 능력치 없는 기념 칭호 **「나락의 정복자」**를 1회 제안한다. 다음 주에도 등반 코인과 주간 재료를 다시 획득한다.

## 같은 주 반복 클리어 보상

입구에서 **수호자 재도전**을 직접 선택한다. 이번 주에 돌파한 10층 단위 관문 중 원하는 곳에 입장하며, 같은 관문을 여러 번 골라도 된다. 보상은 계정 전체에서 주 5승까지다. 첫 등반은 별도로 집계하므로 낮은 층을 지나가며 5회를 소모할 일이 없다.

| 조건 | 보상 |
|---|---|
| 보상 대상 재도전 승리 1회 | 해당 관문 기본 코인의 5%, 소수점 버림. 1승 최대 1조 |
| 이번 주 재도전 3번째 승리 | 코인과 무기 강화주문서 1장 |
| 이번 주 재도전 5번째 승리 | 코인과 방어구 강화주문서 1장 |
| 패배·중단 | 남은 보상 횟수 보존 |
| 5승 이후 | 보상 소진 표시 후 연습 가능 |

반복 코인은 수집 보너스를 곱하기 전의 관문 기본값으로 계산한다. 재도전 정산에는 위 코인과 주문서만 편성한다. 층 진행·순위와 기존 장비, 블랙미라클, 보호권, 카우방 입장권 등 부가 추첨은 원래 등반 경로에 둔다. 시즌 과제의 1층 재도전은 기존 전용 경로를 쓴다.

| 이번 주 선택한 관문 | 승리당 코인 | 같은 관문 5승 합계 |
|---:|---:|---:|
| 150층 | 4,394억 | 2조 1,970억 |
| 160층 | 5,000억 | 2조 5,000억 |
| 170층 | 6,000억 | 3조 |
| 180층 | 7,500억 | 3조 7,500억 |
| 190층 | 9,000억 | 4조 5,000억 |
| 200층 | 1조 | 5조 |

**180층에서 멈춘 주**에는 주간 재료로 별 1억 8,000만 개와 에너지 10개를 확보한다. 180층을 다섯 번 더 깨면 여기에 코인 3조 7,500억과 무기·방어구 강화주문서 각 1장이 붙는다. 200층 다섯 번의 최대 반복 코인은 전체 등반 기본 코인의 약 3.8%다.

## 보상 적용 시 정산 기준

- 첫 보상 주차는 월요일 0시(한국시간)에 시작한다. 주중에 층을 먼저 개방할 경우 이번 주 150층을 마친 계정은 저장된 다음 도전층인 151층에서 이어간다.
- 주간 관문은 계정·주차·관문마다 한 번 기록한다. 재도전은 서버가 확정한 전투 결과와 계정·주차별 승수로 정산한다. 횟수 증가, 지갑·인벤토리 지급, 영수증을 한 거래에 묶어 재접속하면 같은 결과를 돌려준다. 5번째 승리에 두 요청이 동시에 도착해도 마지막 보상은 한 번이다.
- 월요일 0시를 넘긴 미확정 전투는 기존 주차 전환 규칙에 따라 종료한다. 전환 전에 정산이 끝난 전투는 원래 주차의 영수증으로 복구한다. 계정 최초 칭호 소유 기록은 주차와 독립적으로 관리한다.
- 입구에는 ‘이번 주 최고층’, ‘다음 관문 보상’, ‘재도전 보상 0/5’를 표시하고, 출전 전 승리 코인과 다음 주문서까지 남은 승수를 보여준다.

## 로컬 검증

격리 PostgreSQL 호환 DB에서 150층을 마친 계정으로 151~200층 전부를 서버의 시작·완료 경로로 연속 통과했다. 기본 코인 합계, 200층 결과 재요청 때의 단일 지급, 마지막 층 완료, 201층 입장 종료, 다음 월요일 1층 복귀를 확인했다. 별도 검사에서는 큰 수집 보너스가 있는 계정의 200층 지급액 100조를 확인했다. 신규 4개와 기존 전투·보스 보상·주차·정산 검사 34개를 합쳐 38개가 통과했다. 주간 재료와 반복 보상은 제안한 수량과 계정당 주간 지급 총량을 검산했다. [신규 검사](../../../tests/tower-151-200-20261124.test.mjs)

150층과 신규 관문 5곳에서 편성당 같은 시드 16개로 총 2,688번 모의 전투를 했다. 고정 편성 8개는 장비·펫을 뺀 카드 5장(장당 25만 또는 100만)과 21레벨 용병 2명으로 구성했다. 비교 편성 20개는 11월 24일에 저장된 시즌 29 챌린저의 **토벌** 장착 상태를 탑 엔진에 대입했다.

| 관문 | 고정 편성 8개 승리 / 128전 | 챌린저 토벌 편성 20개 승리 / 320전 |
|---:|---:|---:|
| 150층 | 84 / 128 | 320 / 320 |
| 160층 | 79 / 128 | 320 / 320 |
| 170층 | 64 / 128 | 320 / 320 |
| 180층 | 40 / 128 | 320 / 320 |
| 190층 | 38 / 128 | 320 / 320 |

고정 편성은 150층에서 6종, 200층에서 2종이 한 번 이상 승리했다. 이 곡선은 성장 중인 덱에는 편성을 다듬을 목표를 주고, 완성된 상위 덱에는 매주 돌아올 수 있는 난도를 주려는 제안이다. 실제 이용자층별 승률과 소요 시간은 공개 후 측정할 항목이다. [모의 전투 집계](balance.json) · [재현 스크립트](../../../scripts/qa/measure-tower-200-20261124.mjs)
