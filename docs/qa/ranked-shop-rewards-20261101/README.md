# 랭크전 상점 · 별도 코인 · 시즌 티어 보상

고급 전리품 상점의 현재 8개 상품 구성·가격·갱신 주기·한도를 복사한다. 랭크전 상점은 별도 `RANKED_COIN` 인벤토리 재화와 `ranked:` 구매/팩 식별자를 사용한다. 기존 상점의 코인·한도·팩은 별도로 유지한다. 기존 남색 패널과 청록색 스타일, 새 투명 랭크전 코인 이미지를 사용한다.

하위 티어마다 절반, 정수 재화인 랭크전 코인은 소수점 버림이다. 기존 PVP 일반 코인은 시즌 정산 메시지, 듀오 일반 코인은 자동 지급 경로를 유지한다. 랭크전 코인은 양쪽 모두 시즌 정산 시 자동 지급한다. 추가 순위 보상·카드 조각·티어 판정·챌린저 인원·전투/입장 규칙은 유지한다.

진행 중인 PVP 시즌 25와 듀오 시즌 6 및 이후 시즌에 적용하며 종료된 시즌은 소급 지급하지 않는다. 운영 설정은 `ops:ranked-shop-rewards:20261101:v1` 완료 키로 한 번만 적용한다. 기존 구매·인벤토리·정산 테이블과 거래 보호를 재사용하며 스키마 변경은 없다.

검수: SQLite/PostgreSQL 파이프라인 구매·잔액 부족·실패 원복·재시도·팩 경계·권한, PVP/듀오 정산의 원복 및 중복 방지 검사 10개 통과. PC 1440px 및 모바일 390/320px의 8개 상품/티어, 검색·수량·취소·구매·보관함·공통 메뉴 확인. CMS 저장·재조회·원복 확인. 운영 설정의 실패/정상 예행연습은 모두 원복 확인. 관련 회귀와 포장 검사를 포함한 고유 97개 검사를 통과했다. 공개 파일 19개와 모바일 WebKit 검수를 완료했으며 양쪽 Worker는 새 버전 100%다.

공개 파일 수 제한을 위해 브라우저에서 실행되지 않는 기존 Python/PowerShell 제작·변환 도구 8개만 공개 배포에서 제외한다. 저장소 원본은 그대로 보존한다. 원화나 플레이용 자산을 삭제하지 않는다.

증거: 프로젝트 `operations/ranked-shop-rewards-20261101/`. 코인 원화와 프롬프트: `output/imagegen/ranked-coin-20261101/`. 운영 반영 결과는 `completion.json`에 별도 기록한다. 실제 사용자 계정 보상 직접 지급 및 별도 메시지 발송은 수행하지 않는다.
