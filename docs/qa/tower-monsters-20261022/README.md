# 무한의탑 몬스터 14종 전체 교체

사용자 요청: `몬스터 리소스 전체 교체가 필요함`. 직전 무한의탑 120층 개편의 후속으로, 현재 탑에 연결된 몬스터 14종을 내장 ImageGen으로 새로 제작했다.

## 적용 범위

- 120개 운영 층의 수호자 안내와 일반 24마리 → 정예 3마리 → 수호자 1마리 전투에 연결한다. 정예는 해당 일반종의 전용 아트를 함께 사용한다.
- 탑 전용 표시 계층이며 토벌·레이드·일반 몬스터 관리 데이터는 변경하지 않는다. 안정적인 내부 몬스터 ID, 전투력, 스킬 수치, 보상, 진행도, 지급 영수증도 유지한다.
- 새 전투는 새 아트를 포함한다. 이전에 저장된 미완료 전투는 저장 내용을 수정하지 않고 API 응답의 이미지·표시 이름만 새 자산으로 보여준다. 이전 PNG 및 승인 이력도 보존한다.
- 기존 탑 UI 프레임·배경·버튼과 공용 V3 엔진은 유지한다. 독립적인 새 모션·스킬을 만들었다고 주장하지 않는다.

## 원본 및 제작 기록

- 도구: 내장 `image_gen`, 각 1종마다 별도 생성 호출, 총 14회. 모두 실제 RGBA 투명 이미지.
- 프롬프트: `prompts.json`; 원본: `sources/*-v1.png`; 생성 출력 경로: `generation-paths.json`.
- 실제 소비 자산과 SHA-256: `assets/ui/tower-monsters-20261022/manifest.json`.
- 원본 바이트를 보존하고 Sharp로 알파 여백 정리·비율 유지 축소·투명 캔버스 배치·WebP 인코딩만 수행한다. 재생성·색상 보정·형태 변형은 하지 않는다.
- 전투용 640×640 WebP 14종 합계 1,350,012바이트. 1종 72,736~114,968바이트. 한 전투에는 최대 두 종류의 텍스처가 필요하다.
- 제작된 리소스는 기술 검수 대상이다. 사용자 시각 승인은 별도이며 자동 승인으로 기록하지 않는다.

## 검증

- 교체 전 기준 `a25f0e955`의 탑 전투를 120층 × 두 전력 조건으로 저장했다. 240건 모두 교체 후 ID·공격·체력·행동·타임라인·승패·시간·진행 수치 해시가 일치했다. `combat-before.json`, `combat-contract.mjs` 참조.
- 14종 원본 및 WebP 해시, 실제 투명도, 가장자리 여백과 발 기준점, 기존 PNG 보존을 검증한다.
- 실제 API 라우트를 격리 SQLite/PostgreSQL에서 실행한다. 14종 상태 표시, 진행 중 전투 복구, 보상 원자 처리와 중복 정산 방지, 토벌/레이드 영향 없음 검사를 포함한다.
- PC 1440px 및 모바일 390px에서 7개 계열을 실제 탑 버튼으로 진입해 일반·정예·수호자·결과를 검수한다. 운영 계정은 사용하지 않으며 소리는 OFF다. QA 프레임 정지는 이벤트 경계에서만 수행하고 전투 데이터를 바꾸지 않는다.
- Pages 제한을 위해 브라우저에서 참조하지 않는 Node 회귀 검사 16개를 배포 대상에서 제외한다. 소스와 실행 경로는 Git에 보존하고 기존 전투 이미지도 모두 유지한다.
