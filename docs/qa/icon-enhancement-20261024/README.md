# 아이콘 +10 강화 준비 — 2026-10-24

사용자 요청: 아이콘을 +10까지 강화하고 전투력에 메리트를 부여한다. 마스터의 별과 코인을 함께 소모하며, 후속 답변 **“모든 단계 성공 확률 10%”**를 확정 정책으로 사용한다.

## 구현 상태

- 아이콘 카드 상세에 현재/다음 전투력, 마스터의 별·코인 보유량과 비용, 단계별 표, 강화 시도 및 결과 복구를 연결했다. 새 프리뷰 페이지는 만들지 않았다.
- OWNER CMS → 아이콘 카드 → 아이콘 강화 · 비용 설정에서 단계별 두 비용을 저장한다. 초기값은 **운영 OFF, 비용 전부 null**이다. +1 비용 두 개 없이 ON 저장은 차단하고, ON 상태에서도 미입력 단계는 서버에서 차단한다. 기존 계정·강화 단계·재화·합성 설정을 수정하지 않는다.
- 성공률은 +0→+1부터 +9→+10까지 모두 10%. 천장·확정권·중복 카드 소모가 없다. 실패 시 두 재료를 소모하고 단계·카드 수량을 유지하며, 하락·파괴는 없다.
- 전투력은 매 단계 기본 18만의 20%인 36,000씩 증가한다. 이는 사용자에게 설계가 위임된 성장 수치이며, 사용자가 지정한 성공률과 구분한다.

## 사용자 화면 교정 · V2

사용자가 첫 PC 시안의 텍스트 정렬과 구성을 반려했다. V2는 현재/다음 전투력을 동일 폭으로 중앙 정렬하고, 성공률을 헤더 우측에 분리했다. 마스터의 별과 코인은 동일 크기 전용 이미지 트레이를 사용하고 재료명·필요량·보유량의 기준선을 맞췄다. 실제 강화 단계 진행률과 결과, 하단 표/새로고침을 정리하고 모바일에서는 재료 트레이를 세로로 배치한다.

현재 `1440-card.png`, `390-card.png`, `320-card.png`는 V2 검수본이며, 첫 시안은 `history-v1/`에 보존한다. 화면에 보이는 100개/10억은 격리 검수 계정의 샘플 설정으로 운영 비용이 아니다. V2 기능/화면 검수는 새 사용자 시각 승인을 뜻하지 않는다.

## 실제 전투 반영

기존 ICON의 FUR +15 상위 보정이 강화 증가분을 덮지 않도록 공격·체력·방어의 카드 기초 보정에도 같은 배율을 적용한다. 장비 기여분은 중복 배율을 받지 않는다. PVP 장비 분배의 ICON 가중치는 +0 기준으로 유지하므로 강화로 다른 슬롯의 장비·속도를 빼앗지 않는다. 속도·고유 스킬 수치·횟수·쿨다운·덱 최대 2장 제한은 유지한다. 캡틴 전투는 기존 별도 모델에서 공격·체력만 성장하고 백분율 방어·속도를 유지한다.

+0 결과와 일반 등급 정책은 그대로다. 향후 FUR CMS 변경에 따른 기존 상위 보정은 계속 작동한다. 표시 기본 전투력은 FUR 비교 보정·장비를 포함한 최종 실전 능력치와 다르다.

## 거래와 복구

기존 계정 변경 잠금, joint_operations_v1 영수증, DB 원자 거래를 재사용한다. 마스터의 별·코인 차감, 각각의 로그, 강화 단계와 영수증 완료를 한 거래로 저장한다. 설정 revision·보유 수량·기존 단계·실패 횟수를 검증하며 변경되면 원복한다. 같은 요청 번호는 재추첨·재차감하지 않는다. 미결제 요청의 성공 여부와 난수는 응답하지 않는다. 재진입 시 서버의 미완료 요청을 복구하고 계정 간 영수증 접근을 차단한다.

기존 카드 조각/일괄 강화 경로는 ICON 전용 강화 메뉴를 안내한다. 자동 강화나 CMS 수동 강화 지급을 새로 열지는 않았다.

## 검증과 자산

- SQLite/PostgreSQL에서 전 단계 성공·실패 경계, 재료 부족, 비용 미입력/OFF, +10 상한, 재시도, 중복 요청, 오류 원복, 설정 충돌, 영수증 권한을 검증했다.
- 실제 서버 PVE/PVP/캡틴 계산으로 9종 역할의 단계별 공격·체력·방어 증가와 속도 유지, 클라이언트/서버 전투력 일치를 검사했다.
- 기존 아이콘 역할·행동·조은 회복·철구 스킬 및 FUR/SUPERSTAR 강화 관련 101개 회귀 검사를 통과했다.
- 실제 카드 상세와 실제 CMS 편집 컴포넌트를 격리 계정 DB에 연결해 1440/390/320px에서 실행·재진입·저장·가로 넘침·콘솔 오류를 검사했다. 브라우저 검수에서 발생한 차감은 모두 로컬 격리 계정이다.
- ImageGen built-in으로 전용 패널·버튼·재료 트레이를 제작했다. `preview/icon-enhancement-20261024/manifest.json`에 원본·해시·프롬프트를 보존하고 WebP 세 장을 실제 화면에 연결했다. 기능 검수를 사용자 시각 승인으로 기록하지 않는다.
- 준비 상태 배포이며 재료 가격은 확정하지 않았다. 실제 강화 ON은 비용을 입력하고 운영 스위치를 켜는 경우에만 가능하다.
