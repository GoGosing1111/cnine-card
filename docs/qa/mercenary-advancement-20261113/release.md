## 전투와 계정 검증

- **직업 전용 검사 40개 통과.** 16개 직업 각각의 경계 조건과 실제 서버 전투 발동을 확인했다. 연격자의 광역·다단 공격 횟수, 파괴자의 보호막 소진 경계, 불사자의 두 번째 치명타, 듀오 양쪽 소유자의 지휘 중첩과 해제를 검사했다. 세 회복 직업은 생명형 카드가 없는 편성에서도 작동한다. 시즌 2 마법을 함께 쓸 때의 회복과 연장전 회복 봉쇄도 확인했다.
- **운영 성장 설정을 적용한 모의전 384회.** SS·SSS 16·21레벨, 서로 맞춘 편성 전력 세 구간에서 직업당 PvE 12회와 PvP 12회를 수행했다. 이 표본에서 파괴자와 정화사의 발동은 0회였다. 별도 21레벨 PvP에서 보호막 편성을 상대로 파괴자가 12전 중 10전에서 발동했고, 정화사는 상대가 실제로 건 파멸의 낙인 1건을 해제했다. 직업별 수치는 아래 JSON에 있다. 운영 유저의 승률은 측정하지 않았다.
- **실제 도감 거래.** 격리 SQLite와 PostgreSQL에서 최초 전직, 변경, 재화 부족, 영구 소유·등급·레벨 제한, 다른 계정의 영수증 재사용 거부를 확인했다. 저장 중 실패하면 코인·별·전직 상태가 함께 원복됐다. 두 창의 동시 변경과 응답 유실 후 새로고침에서도 같은 요청은 한 번만 차감됐다. 듀오 편성 캐시는 전직 후 갱신된다.
- **실제 전투 연출.** 운영용 V3 렌더러가 기존 용병 스킬과 전직 발동을 구분한다. 서버가 생성한 결계사 개막 이벤트로 진입한 뒤, 같은 렌더러에서 전직 16종과 방패 잔여 횟수·복수 충전·지휘 오라의 생성과 해제를 확인했다.
- **기존 기능.** 도감 회귀 검사 239개, 전투 격자 25개, 마법·협동·장비·Windows 업데이트 49개가 통과했다. 최신 클랜 변경을 합친 뒤 전직·클랜·전장 진입 묶음 62개도 통과했다. 검사 묶음 간에는 중복이 있다.

## 오후 반영

1. 배포에 사용할 깨끗한 체크아웃에서 현재 `origin/main`과 후보 브랜치 `codex/mercenary-advancement-release-20261113`를 통합한다. 기능 커밋 이후 이 문서와 검수 자료만 추가됐다.
2. 프로젝트의 정식 배포 명령 `npm run deploy:production`을 실행한다. 배포 스크립트가 API Worker, Pages, 클랜 Worker를 순서대로 처리한다. 후보 상태에서 공식 배포 검사가 남긴 한 가지 조건은 배포할 HEAD와 `origin/main`의 일치다. 운영 DB 마이그레이션이나 사전 일괄 지급은 필요 없다.
3. 반영 후 공개 웹과 스토어 도감에서 버튼과 가격을 확인하고, Windows 배포 목록에 전직 리소스 27개가 포함됐는지 확인한다. 실제 계정 차감은 이용자가 전직을 확정할 때 일어난다.
