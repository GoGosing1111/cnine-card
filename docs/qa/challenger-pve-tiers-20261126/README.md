## 전투 설정

- **격전지 종언**의 기본 전투력은 일반 몬스터 3,650억, 정예 2조 9,000억, 최종 보스 5조 1,600억이다. 종별 특성을 적용한 세 웨이브를 3분 안에 돌파해야 한다.
- **솔로 파멸**의 일반 몬스터 기준 전투력은 1조 1,200억, 지역 보스는 680조다. 보스는 6분 35초에 등장하며 마지막 25초 안에 처치해야 한다. 다섯 지역 모두 클리어 사례가 있었고, 20개 편성 중 4개가 한 번 이상 클리어했다.

- 신규 단계는 직전 단계 대비 재화·소모품·재료 수량을 2.5배로 지급한다. 장비·용병·장착형 스킬칩은 직전 단계의 수량과 확률을 사용한다. 홀수 묶음에서 생기는 0.5개는 두 정수 수량을 같은 확률로 지급하며, 확정된 수량으로 수령·재접속한다.
- 종언 기본 보상은 1인당 코인 1조, 마스터의 별 1,000만, 엠퍼러 에너지 5개, 펫 봉인구 15개, 잠재력 물약 5개다. 선택 보상의 최소 코인은 750억이다. 파멸의 1인 코인 상한은 750억, 멸화의 심장은 7,500억이다. 양쪽 모두 보스 처치 시 확정 연마석 50개를 지급한다.

## 표본과 판정

- 솔로는 저장된 PvE 카드 5장과 용병 2명을 사용했다. 격전지는 저장한 덱에서 편성 제한을 만족하는 전투력 상위 카드 2장을, 성채는 저장한 덱의 아이콘 카드를 우선 선택했다. 성채의 빈자리는 보유 아이콘 중 돌파 단계와 기본 전투력이 높은 순서로 채웠다. 용병·장비·시즌 효과는 콘텐츠별 서버 편성 계산을 따랐다.
- 파티 전투는 순위별로 파티원을 교차 배정해 인원별 400판씩 비교했다. 솔로는 20개 편성 × 5개 지역 × 6개 시드로 600판을 비교했다. 검증 시드는 순위 인덱스 `i`(0~19), 라운드 `r`(파티 83~102, 솔로 83~88)에 대해 `7919 × (1 + i + 20 × r)`로 고정했다.
- 클리어 횟수는 각 콘텐츠의 실제 승리 판정을 따랐다. 비율은 이 시점의 편성으로 계산한 서버 모의전 결과이며 출시 후 이용자 통계와는 별도로 집계한다.
- Chromium 1440px·390px에서 신규 난이도 선택, 격전지·성채 방 생성, 솔로 전투 시작을 검증했다. 격전지·성채의 2인 준비, 방장 출전, 두 이용자의 로딩 완료와 전투 시작도 확인했다. 운영 설정 적용 과정은 직전 난이도 행 보존, 중간 실패 시 원복, 완료 후 중복 적용 방지를 검증했다.
- 추가로 실행한 10월 격전지 회귀 검사에서 5건이 기존 운영 소스 `024f70308`과 동일하게 실패했다. 4건은 용병 1명으로 새 방에 준비하는 시나리오, 1건은 과거 극한 난이도에서 두 덱의 승수 차이를 검사하는 시나리오다. 상위 20명 검증은 운영 편성 규칙인 2용병으로 진행했다.
