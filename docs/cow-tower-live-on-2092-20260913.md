# 카우방·기존 무한의탑·폐차장 유저 ON · 2092

2026-09-13 사용자 지시: “일단 재등반은 나중에 하고 카우방,무한의탑 연결해”, “무한의탑은 기존 정책대로 유지”, 후속 “아니 ON 시키라고”, 이어 “폐차장도 연결해라”. 세 콘텐츠는 이전 공동 대기보다 이 명시적인 유저 ON 지시를 우선한다.

- 카우방 공개 경로·PVE 포탈 발견을 활성화하고 운영 `expedition_v3_cow_room`을 ON/approved로 전환한다. 기존 25만 입장 코인, 클리어 5억, 하루 6회·30억, 일반 PVE 2%·아포칼립스 3%, 포탈 1개당 1회 규칙을 보존한다. CMS는 OWNER만 OFF/TEST/ON·운영 수량을 저장하며 CAS 충돌 검사를 유지한다.
- 무한의탑은 `/api/tower/status`와 `/api/tower/fight`의 기존 진행·최초 보상·부가 드롭을 그대로 쓴다. 실제 탑의 공통 V3 연출도 유지한다. `/pve-v3/?content=tower`는 `/?screen=battle&pve=tower`로 연결한다. 현재 70층·최초 합계 14억 4,500만은 운영 CMS 조회 기준이며 코드에 보상표를 복제하지 않는다.
- 최고층 완료 화면은 다음 층 미설정 안내보다 먼저 표시한다. 자동진행은 다음 미클리어 층 등반이며 1층 초기화/재등반과 다르다. 50% 감액·10회 재등반, 160층, 하루 10회·2% 반복 코인·타이어 초안은 적용하지 않는다.
- 폐차장은 기존 운영 CMS의 ON과 3구역·입장권·횟수·보상을 유지하고 실제 V3 입장·서버 전투·원자적 지급·결과 복구를 공개한다. 제작소·메인 폐차장 메뉴는 V3 화면으로 연결한다. 기존 요청 영수증과 이전 클라이언트의 복구 경로는 보존한다.
