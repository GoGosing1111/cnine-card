# SSS 광역 연출 후 보스 기술 재생 중단 수정 — 2026-10-19

사용자 `SSS 이상 용병들중 궁극기 사용하면서 범위가 크게 잡히거나 컷신느낌이 있으면 아포칼립스나 보스들이 스킬을 못쓰는 느낌`, 재현 용병 답변 `레오넬`에 따른 수정이다.

## 재현과 원인

실제 서버 시뮬레이터로 레오넬 + 사현 전투를 생성했다. 이 전투 기록에는 레오넬 광역기와 사현의 정지선·공백회랑·천경붕괴가 모두 있었다. 첫 레오넬 광역기와 뒤의 보스 기술 3개를 순서대로 추출해 운영 소비 번들 + 실제 웹 `createRenderer().play()`로 재생했다. 계정·CMS·보상 운영 쓰기는 없다.

레오넬 궁극기는 **4.25초**, 피해 접점은 **1.79초**인데 웹의 기본 제한은 **2초**였다. 기존 코드에서 2.006초에 `검극 · 전선 단절 연출이 지연되어…`가 발생했다. 첫 피해 이후 나오는 검압 연출에 도달하지 못했고 아포칼립스 재생 자체가 실패하여 보스 기술은 0개 재생됐다. 서버의 스킬 봉인이나 피해 누락으로 판정한 것은 아니다. `docs/qa/leonel-boss-playback-20261019/reproduction.json`에 보존한다.
