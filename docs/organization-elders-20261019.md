# 조직 원로 3명 · PVP 클랜전 메뉴 제거

사용자 요청: “조직에서 상위3명씩 지휘관 지정해 지휘관이라는 단어 말고 원로”, 후속 “사이드메뉴 PVP에서 클랜전 이제 빼라”.

## 적용

- 조직 배정에 사용한 `seed_power` 내림차순 상위 3명을 조직별 원로로 지정한다. 동률은 배정 슬롯, 계정 ID 순이다. 이번 현재 회차 15개 조직의 일회 지정이며 이후 전력 변동으로 자동 교체하지 않는다.
- 세 원로 모두 기존 부대 편성·행동대장 임명·주둔·출정·공동 자금 아지트 승급 권한을 갖는다. 실제 교전 입장/공격은 해당 부대원 조건, 개방 시간, 보호/대기, 비용 조건을 그대로 따른다.
- 명부·세력전·아지트·CMS에서 원로로 표기한다. CMS는 3개 선택란, 중복/타 조직/비활성 계정 검증, 기존 명단 비교 후 저장을 제공한다. 원로를 모두 해제한 빈 명단은 과거 단일 역할로 되살아나지 않는다.
- 기존 단일 `commanderId`/`isMaster` 응답 필드는 캐시 호환용으로 유지한다. 권한은 원로 목록으로 판정하며 오래된 단일 지정 요청은 다수 원로 명단을 덮어쓸 수 없다.
- 기존 조직 이미지 세트와 레이아웃을 사용한다. 새 장식 이미지를 추가하지 않았다. 공통 PVP 메뉴에서 `clanWar` 진입 항목을 제거하고 기존 조직·세력전·영토전 항목은 유지한다.
