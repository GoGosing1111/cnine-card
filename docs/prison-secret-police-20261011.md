# 감옥 비밀경찰 착용 표시 — 2026-10-11

사용자 요청: “비밀경찰 칭호 착용자는 감옥에서 비밀경찰 표시나오게 만들어”. 일반 행정부 감옥에 현재 장착한 `SECRET_POLICE` 칭호의 승인 PP 문장과 공개 칭호 배지를 표시한다.

- 표시 위치: 감옥 공개 채팅 닉네임 옆, 수감자 명단, 선택한 수감자 상세, 화면 상단 내 장착 칭호.
- 기존 공개 칭호 조회를 일괄 사용한다. 실제 소유권·현재 장착·만료·활성·공개 조건을 모두 만족해야 한다. 보유만 한 계정, 만료/회수된 칭호, 이름만 같은 다른 코드에는 표시하지 않는다.
- 채팅 POST 응답에도 같은 서버 판정을 넣어 전송 직후 표시한다. 조회는 현재 장착을 매번 확인하므로 해제하면 기존 채팅을 포함해 다음 상태 갱신에 표시가 사라진다. 기존 5초 감옥 갱신을 사용한다.
- 칭호·계정·채팅 스키마 변경이나 소유권 지급은 없다. 일반 방문객/수감자 표식, 채팅 제한, 수감·석방·영치금·사식 정책은 유지한다. 표시는 새 운영 권한을 부여하지 않는다.
