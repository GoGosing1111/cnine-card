# 서버 운영 후원 · 2026-10-10

## 적용 범위

- 전체 메뉴 하단 `서버 안내 → 서버 운영 후원`에 작은 텍스트 진입점을 둔다.
- 후원 페이지는 아래 조건을 충족한 모든 일반 유저에게 공개한다. 사용자 정정에 따라 핑크빛유두 전용 제한은 CMS 후원 관리에만 적용한다.
- 페이지의 기존 조건인 가입 시각부터 72시간 경과와 2차 인증 완료를 모두 유지한다. 조건 미충족이면 버튼을 만들지 않고 직접 API 접근도 차단한다.
- CMS에 별도 `후원 관리` 메뉴를 추가한다. 확인된 운영 계정 핑크빛유두(ID 1, OWNER)만 접근할 수 있으며, 정확한 닉네임/계정 ID로 조회한 계정에 30일 부여·연장·즉시 중지가 가능하다. 닉네임 일치만으로 권한을 주지 않는다.
- 운영자가 후원 내역을 확인한 뒤 CMS에서 처리한다. 자동 결제, 계좌 안내, 실제 계정에 대한 일괄 혜택 부여는 포함하지 않는다.

## 거래·접근 보호

- 기존 인증, 사용자 변경 잠금, `app_meta`, 원자성 가드/DB batch를 사용한다. 새 테이블·마이그레이션·공통 인증 변경은 없다.
- 계정별 revision과 원본 값 비교, 소유 펫/CMS 원본 확인, 요청 ID 영수증으로 중복 연장·중복 변경을 차단한다.

- 적용 대상·기간 판단은 서버에서 수행한다. 화면의 만료 갱신도 서버 시각 오프셋을 사용한다.
