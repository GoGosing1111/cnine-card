# 하이퍼팩 특정 SS·결과 칸 1회 지정

- 사용자 요청: 족게이다 계정의 다음 10회 개봉 세 번째 칸에 SS 베스페라(V-004)를 1회 지정한다.
- 운영 확인: 계정 ID 4111, 활성 계정, CMS revision 55의 V-004 이름 베스페라·등급 SS. 설정 직전에 계정·등급·대기 개봉 요청을 재검증한다.
- 기존 `mercenary_pack_ss_once_v2104:<userId>` 설정에 선택적인 `mercenaryCode`와 `slotIndex`를 함께 저장한다. 세 번째 칸은 0부터 세는 `slotIndex:2`다. 둘 중 하나만 있거나 0~9 범위를 벗어나면 거부한다.
- 두 필드가 없는 기존 설정은 열 번째 칸의 무작위 SS 보장을 그대로 유지한다. 일반 요청으로는 이 설정을 만들 수 없다.
- 지정 용병은 현재 개봉 CMS의 실제 SS여야 한다. 전체 카탈로그 검증과 기존 소유·중복·원화·영수증 처리를 사용하며, 결과 배열 순서를 바꾸지 않는다.
- 10회 개봉의 지정 칸만 보장한다. 나머지 칸과 이후 개봉의 확률은 기존 CMS를 사용한다. 1회 개봉·다른 계정은 설정을 소모하지 않는다.
- `ARMED → CONSUMED` 변경, 코인 차감, 용병 지급, 관리자 감사 기록은 같은 원자적 거래에 포함된다. 실패하면 전부 되돌리고, 같은 요청 재시도는 저장된 결과를 재사용한다. 오래된 경쟁 요청은 추가 지급·차감 없이 취소된다.
- 개봉 코인이나 팩을 미리 지급·차감하지 않는다. 실제 다음 10회 개봉이 완료될 때만 설정을 소모한다. 소비된 동일 운영 요청을 다시 등록하지 않는다.
- 검증: `tests/mercenary-ss-once-v2104.test.mjs`의 SQLite·PostgreSQL 17개 검사. 특정 카드·세 번째 칸·영수증 순서, 계정/개봉 수 제한, 실패 복구·재시도·경쟁 요청, 등급 변경 거부 및 기존 무작위 SS 기능을 검증한다.
