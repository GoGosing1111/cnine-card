# 월드 레이드 미수령 보상 화면 복구 — 2026-10-11

서버의 참가 기록은 `reward_claimed=0`, 보상 영수증과 지급 계획은 모두 `READY`인데 브라우저에는 "이미 보상 정산이 완료되었습니다"만 표시되는 사례를 확인했다. 운영 DB는 읽기 전용 트랜잭션으로 조회했다. 실제 제보 기기의 localStorage를 직접 읽지는 않았으며, 기존 `cnine_raid_claimed_<instanceId>=1`을 넣은 격리 재현에서 첨부와 같은 화면이 발생했다.

이 저장 키는 계정을 구분하지 않고 로그아웃 뒤에도 남았다. 화면과 결과 계속하기는 이 브라우저 표시를 서버의 미수령 기록보다 우선했다. 브라우저 수령 마커의 읽기·쓰기를 제거하고 현재 방에 해당하는 서버 참가 기록·영수증·마지막 정산 기록만 완료 판단에 사용한다. 결과 연출을 이미 봤다는 기록은 유지한다.

숫자와 문자열 형태의 0을 모두 미수령으로 처리한다. 서버가 완료를 확정한 결과는 재수령 버튼을 제공하지 않고 "방 목록으로"를 제공한다. 레이드 조회에는 `microcache:false`를 명시해 수령 직후나 방 목록 복귀 때 1초 공통 캐시가 직전 응답을 다시 표시하지 않도록 한다. 공통 API 캐시 구현, 서버 보상 계산·지급·중복 방지, 참여 횟수와 CMS 정책은 바꾸지 않는다.
