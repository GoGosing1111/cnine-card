## 운영 화면

- 관리자 CMS 왼쪽 독립 메뉴 **격전지(협동)**. OWNER만 표시하고 API도 OWNER만 허용한다.
- 운영 상태 OFF / TEST / ON, 정확한 닉네임·계정번호 검색, 테스트 참여자 추가·제외(최대 100명), 대기방 모집 시간 60~3,600초, 전투 제한 30~180초.
- 세 단계의 이름·공략 안내 및 난이도별 추천 편성. 일반 몬스터 3기 → 준보스 → 아르케의 순서·종류·승인 자산은 고정이다.
- 일반·격전·극한별 다섯 몬스터의 고정 전투력, HP·공격·방어 배율, 시작 방벽, 연속 공격 횟수와 강제 행동 주기를 개별 조정한다. 배율은 공용 엔진이 실제 적용하는 100~1,200% 범위로 검증한다. 종전 입력 70~90%는 엔진에서 이미 100%로 계산되었으므로 기본 CMS에는 실제 적용값 100%를 표시한다. 기본 전투 결과가 바뀌지 않음을 전체 payload 비교로 확인했다.
- 최종 보스 첫 기믹 시각·간격·최대 6회, 차단 성공 피해, 난이도별 입력 시간·차단 실패 피해·집중 포화 피해. 대응 창보다 기믹 간격이 길어야 한다. 엄폐/교란의 피해 경감 규칙은 고정이다.
- 입장 재료 코드·수량·부담 대상과 클리어 코인·마스터의 별·미스틱 에너지는 **초안만 저장**한다. 모든 모드에서 실제 차감·보상은 잠금 상태이며 CMS에도 명시한다. 신규 경제 지급·차감·마이그레이션을 추가하지 않았다.

## 적용 범위와 저장

- 기존 `app_meta.cooperative_battleground_settings_v1` 한 문서를 확장한다. 기존 간단 운영창이 공개 모드·테스터만 저장해도 CMS 전투·경제 초안을 보존한다.
- 저장 버전과 저장 직전 원문에 대한 조건부 UPDATE로 동시 편집 충돌을 차단한다. 갱신 계정·시각·리비전을 기록하며, 충돌 시 편집 내용을 유지한다.
- 전투·모집 설정은 방 생성 시 서버가 복사해서 Durable Object에 저장한다. CMS 변경·전투 이탈에 따른 시뮬레이션 재생성으로 기존 파티 설정이 바뀌지 않는다. 이전 버전 방은 기존 기본값/이전 보스 스냅샷 호환을 유지한다.
- 공개 로비·전장 시간·단계 이름·공략·기믹 피해 안내는 서버 설정 요약을 사용한다. 진행 중에는 그 방에 저장된 설정이 기준이다.
- 기존 운영 데이터와 공개 모드를 임의 변경하지 않았다. 배포로 TEST를 ON으로 전환하지 않는다.
