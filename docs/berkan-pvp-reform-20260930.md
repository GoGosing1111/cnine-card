# 베르칸 PVP 후속 개편 — 2026-09-30

족게이다 연패 조사 후 사용자가 `수정개편해 그럼`으로 승인했다. 기존 지시인 **속도·행동 주기를 유지하고 크라이베른·라그니엘 대비 약 60~63%**를 최신 속도형/중복 방어형 전투 규칙에서 다시 검증한다.

## 변경

- 베르칸 PVP 확정 평타 피해 계수: **0.99 → 0.50**. 기존처럼 한 번만 적용하고 보호·가로채기는 그 예산을 나눈다.
- 흑금 낙성 PVP 피해 상한 계수: **1.7 → 1.865**. 평타 비중을 줄이고 보호막을 가진 후열에 대한 스킬 피해를 보완한다. 원배율 5.6, 비용 35, 재사용 5행동, 후열 우선 2명 지정은 유지한다.
- 상한에 걸린 흑금 낙성도 **이미 뽑은 타격 피해 편차 95~105%**를 유지한다. 새로운 난수나 회피 재추첨은 없다. 고정 상한만 조절할 때 특정 보호막 구간에서 승률이 급변하는 현상을 완화한다.
- 베르칸의 PVP·MS-055 경로에만 적용한다. 속도·행동 가산·재생 속도는 1.25배 그대로다. PVE 상한 1.7·피해, 흑금 천우의 PVE 전용 규칙, 다른 용병과 일반 카드는 유지한다.
- 특정 상대 코드, 계정, 최근 승패, 목표 승률을 런타임 조건으로 사용하지 않는다. CMS·계정 데이터·이전 승패 및 보상은 변경하지 않는다.

## 측정과 재현

기존 무특성 고전투력 덱만으로는 강화·고유특성 진화·마법카드가 있는 실제 편성을 대표하지 못했다. 정확히 재현한 기존 전투 53건에서 양측의 **서로 다른 23개 편성 전부**를 추출했다. 계정 식별자·닉네임·이미지·실제 전투 시드는 제거했다. 양 팀의 일반 카드·장비 154,300·마법카드를 동일하게 맞추고 용병과 시작 진영을 교환한다. 모든 편성의 비중은 같다. 카드 +13, 마법 +9, 진화된 고유특성과 미진화 카드가 있던 편성을 그대로 보존한다.

## 변경 범위와 검증

베르칸 피해 경로의 국소 수정이다. 인증·DB·거래·경제·의존성·다른 콘텐츠 규칙을 변경하지 않으므로 scoped 배포한다.

- 수정 전 현재 엔진에서 기록한 **PVE 46건 + 베르칸 없는 PVP 46건의 전체 응답 SHA-256이 수정 후 모두 동일**하다.
- 새 평타/스킬 검사: 단일·듀오 소유자, PVP 전용 조건, 가로채기 예산, 스킬 억제와 0 피해, 고정된 대상 수·비용·쿨타임, 실제 엔진 상한 편차와 결정적 재현, 익명화한 시험 편성 보존.
- 새 검사 7건 통과(처음 6건 + 편성 가정 수정 후 해당 1건). 최초 검수의 시험 편성 검사 1건은 모든 카드가 진화됐다고 잘못 가정해 실패했다. 실제 미진화 카드도 그대로 보존하도록 검사 가정을 수정했다. 실행 코드·편성·측정 결과는 바꾸지 않았다.
- 배포 단계에서는 행동 주기, PVE 광역기·군단토벌, 공용 실제 번들/메인 로더 연결, 속도형/방어형 회귀와 Worker 구문·출시 플래그·캐시·Hyperdrive를 확인한다. 이미 통과한 새 평타 검사와 완성된 대규모 모의전은 중복 실행하지 않는다.
- 공용 소비자 10개를 기존 빌더로 갱신했다. 라이브 연출 번들의 실행 내용은 동일하며 shared 소스 해시와 독립 전장 프리뷰의 서버 모형 번들/빌드 기록만 달라졌다. UI·원화·스프라이트·사운드 변경은 없다.
- 과거 `mercenary-berkan-twin-starfall-20260927.test.mjs`의 이미 확인된 무관한 PVE 가정 실패 2건은 이번 작업에 끌어오지 않는다. PVP 상한 기대값 2곳만 갱신했다. 좁혀 실행한 회피·보호막·억제/무대상·0피해 검사는 통과했다. `one cast`는 갱신한 PVP 상한 검사를 통과한 뒤 기존 PVE 연속 행동 가정(`true !== false`, 30행)에서 다시 실패했다. 신규 PVE 광역기가 다음 행동에 나오는 것을 부정하는 과거 가정이며 1차 하향 때도 동일하게 확인된 실패다. 이 검사는 더 반복하거나 실행 코드를 과거 동작으로 되돌리지 않는다.
