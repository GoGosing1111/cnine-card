## 변경

- 기존 재료 일괄 제작의 화면·서버 허용 범위에 `SUIT_CORE_SYNTHESIS` 인벤토리 결과만 추가한다.
- 제작소 → 슈트코어 합성에서 1~100회 입력, 증감, 최대 버튼을 제공한다. 최대 횟수는 투입 코어·코인·마스터의 별 각각의 보유량과 100회 상한 중 가장 작은 값이다.
- 선택 횟수의 총 비용을 확인한 후 요청 1건으로 처리한다. 매회 기존 CMS 확률로 독립 판정하고 성공 횟수 × 기존 결과 수량을 지급한다. 실패한 횟수도 기존 비용을 소모한다.
- 기존 PostgreSQL 행 잠금·최종 잔액 검증·차감/지급/감사 거래·영수증 재조회 경로를 그대로 사용한다. 응답 유실 후 동일 요청을 복원하며 다시 차감하거나 추첨하지 않는다.
- 다른 제작 종류의 일괄 허용 범위, 장비 제작 연출, CMS 경제값·공개 상태·지급은 변경하지 않는다. 메인 앱과 제작소/폐차장 공용 스크립트의 캐시 키를 갱신한다.
