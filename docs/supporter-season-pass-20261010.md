# 후원자 30일 시즌패스 — 2026-10-10

사용자 확정: **후원 적용일부터 30일, 당일 보상만 수령**. 후속 디자인 지시: **이쁘고 화려하게**.

## 사용 경로와 표시

- 공용 로비 전체 메뉴의 **시즌패스**에서 바로 진입한다. 서버 안내·후원 안내의 30일 시즌패스 버튼으로도 연다.
- 네이비·샴페인 골드, 왕관 문장과 광원, 실제 보상 이미지·수량, 수령 진행률을 사용한다. 오늘은 라임, 7·14·21·28·30일은 특별 장식으로 구별한다. 장식만으로 별도 보상을 생성하지 않는다.
- PC 7열, 중간 화면 5열, 모바일 3열 달력. 날짜를 선택하면 해당 날짜의 모든 보상과 수량을 위쪽 상세 영역에서 확인한다. 수령 버튼은 적용 중인 후원자의 오늘 보상만 활성화한다.
- KST 적용 날짜가 1일차이고 자정에 다음 날짜로 바뀐다. 놓친 보상은 이월되지 않는다. 정확한 후원 720시간의 마지막 부분 날짜가 31번째 보상을 만들지 않는다.
- 이용 중 후원 연장은 기존 달력 다음 30일로 이어진다. 펫 변경·연장·CMS 수정으로 기존 수령 기록을 초기화하지 않는다. 중지 후 재등록해도 같은 KST 날짜에는 다시 지급하지 않는다.

## CMS

- 기존 후원 관리와 같은 **ID 1 / OWNER 전용** 시즌패스 메뉴. 일반 OWNER·ADMIN에게 관리 권한을 확대하지 않는다.
- 패스 이름, 운영 ON/OFF, 30일 각각 최대 12종, 아이템별 정수 수량, 이름·코드 검색과 종류 필터, 날짜 범위 복사를 제공한다.
- 활성 아이템·재료·팩·티켓, 코인·카드 조각·마법 결정, 공개 장비·이동수단, 기존 보상 카탈로그의 공개 카드(SUPERSTAR/ZENITH/FUR)를 선택한다. 새 항목은 카탈로그를 다시 불러오면 표시한다. 이름·이미지는 서버 카탈로그에서 확정한다.
- 종료된 PREMIUM_CUBE와 기존 게임 드롭 전용 장비보호권 제한은 유지한다. 이동수단은 1개이며 이미 보유했다면 기존 보유를 유지한다. 일반 보상 최대 100만, 코인 최대 1조, 장비 하루 총 50개를 적용한다.
- **초기 상태는 OFF / 30일 미등록**이다. 운영자가 보상·수량을 저장하고 ON으로 열면 지급을 시작한다. ON 저장은 30일 모두 한 종류 이상 보상이 있어야 한다. 사용자 미지정 운영 보상표·수량은 임의 생성하지 않았다. 브라우저 검수 보상은 메모리 DB에만 존재한다.

## 거래와 복구

기존 인증·사용자 변경 잠금·app_meta·원자적 DB batch·통합 보상 지급기를 재사용한다. 새 테이블, 마이그레이션, 공통 인증·DB 기반 변경은 없다.

- 계정/적용 기간/일차별 영수증과 계정/KST 날짜별 영수증을 보상·로그와 한 거래로 저장한다. 실패하면 전체 롤백하며 중복·동시 요청은 확정 영수증을 반환한다.
- 후원 상태·CMS 원본·아이템 활성 조건·지갑과 보유 수량을 거래 안에서 비교한다. PostgreSQL에서는 사용자와 후원/보상 설정 행을 잠근다. 정수 안전 범위를 검증한다.
- CMS는 예상 revision, 고유 저장 토큰, 감사 기록과 영수증으로 이전 창의 덮어쓰기와 중복 저장을 막는다.
- 수령·저장 요청은 전송 전에 계정별 브라우저 저장소에 보관한다. 응답 손실·새로고침 후 같은 요청으로 확인한다. 과거에 받은 보상은 이후 보상표 수정과 무관하게 당시 영수증 내용을 표시한다.
- API는 private/no-store, 인증 계정 기준 지급, 허용 필드 검사와 동일 출처 POST를 유지한다. 기존 가입 72시간·2차 인증과 운영자 읽기 전용 미리보기 조건도 유지한다.
