숲켓몬 v1336 카드팩 영수증 50,000건 자동 분할 정리

- 카드팩 영수증 한 번 클릭 최대 정리 수량을 5,000건에서 50,000건으로 확대
- 실제 D1 DELETE는 기존 안전 단위인 500건씩 최대 100회 자동 분할
- 5,000 / 10,000 / 25,000 / 50,000 선택 지원, 기본 50,000
- 각 배치 최대 4회 자동 재시도 및 10배치마다 짧은 휴식 적용
- PENDING 영수증은 기존대로 삭제 금지
- 지급 검증(draw_grant_assertions)을 영수증보다 먼저 삭제하는 순서 유지
- 내부 100회 처리 중 감사 로그를 매번 쓰지 않고 전체 실행 완료 후 1회만 기록
- 기존 카드, 코인, 조각, 보상 및 전투 데이터 변경 없음
