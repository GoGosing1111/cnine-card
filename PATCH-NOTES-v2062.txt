PATCH NOTES v2062 — 재정금고·뽑기·연금술 조회 최적화
검토일: 2026-09-08
범위: 서버 7개 파일 + 회귀 검사/문서. 로컬 커밋 전용, push·배포 없음.

[조회 최적화]
- 연금술 화면의 공통 강도 범위와 보상 풀을 120초 캐시한다.
  같은 스냅샷 안의 중복 강도 집계를 없앤다.
- 장비 재료 조회를 DB.batch로 묶고 지급 가드 확인/정리를 지급 batch에 포함한다.
- 재정금고의 클라이언트 미사용 ledger 조회/응답 필드를 제거한다.
  원장 기록은 그대로 유지한다.
- 재정금고 공통 표시 데이터(우승 클랜·이벤트·세금 출처 집계)를 60초 캐시하고
  세금 집계용 커버링 인덱스를 추가한다.
- SQLite/D1 foundation schema·seed의 별도 batch를 병합한다.
  PostgreSQL execSchema 경로는 유지한다.
- 마법 status 설정 30초, 프라임 공개 config 설정/풀 120초,
  블랙미라클 CMS 카탈로그 120초, 차량 공개 config 카탈로그 120초 캐시를 적용한다.
- 차량의 독립 읽기를 Promise.all로 묶는다.
  PostgreSQL에서는 실제 호환 계층의 SQL 직렬 실행이 그대로 유지된다.

[검토 중 보완한 안전성]
- 새 캐시가 실제 구매/개봉/연성의 가격·OFF 상태·보상 후보 판정에 적용되지 않게
  fresh 조회를 유지한다. 유저 재화/보유 자산도 매번 읽는다.
- 재정금고 우승 클랜 배당 예산안 상신은 최신 우승 클랜을 다시 읽는다.
- 슈퍼스타팩 릴리스 메모는 DB별 완료 데이터만 보존한다.
  진행 중인 요청의 Promise를 다른 요청과 공유하지 않는다.
- 슈퍼스타팩에서 다른 requestId의 만료 PENDING이 새 요청을 막으면
  만료 행 정리 후 한 번 재시도한다. 진행 중인 PENDING은 보호한다.
- CMS 쓰기 성공 후 해당 로컬 캐시를 무효화한다.
  다른 Workers 인스턴스의 화면 표시는 최대 TTL만큼 늦을 수 있다.
