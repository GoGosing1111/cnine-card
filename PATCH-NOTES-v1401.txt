[v1401 추가]
1. 세션 시간·인증 안정화
- ISO/SQLite 혼합 만료시간을 datetime()으로 정확히 판정
- 신규 세션 시간은 UTC SQL 형식으로 통일
- 과거 ISO 세션은 소량씩 안전 변환
- 만료 임박 세션만 30일 연장
- 계정별 최신 세션 최대 20개 유지(다른 기기 세션을 즉시 끊지 않음)
- 동일 서버 요청 안의 중복 인증 조회를 WeakMap으로 1회 병합
- 전역 인증 캐시는 사용하지 않아 밴·강제 로그아웃 반영 지연 없음

2. 클라이언트 세션 복구·재연결
- 게임 이용 중 401 발생 시 저장 개인키로 로그인 복구 1회
- 여러 API가 동시에 401이어도 로그인 요청은 하나만 실행
- 인증 복구 후 원래 요청 1회 재실행
- GET 네트워크/429/502/504는 1회만 제한 재시도
- POST는 네트워크·502 계열을 무조건 재전송하지 않아 중복 지급 방지
- 연결 실패 시 5초→10초→20초→30초 점진 재연결
- 브라우저 online/화면 복귀 시 즉시 재확인
- 잘못된 개인키(401/403)는 무한 재연결하지 않음

3. D1 장기 용량·정리 성능
- 5분 전역 잠금, 1/64 요청 샘플링, 작업당 최대 50행
- 한 실행에 정리 인덱스 1개와 정리 작업 1개만 처리
- 32개 정리 전용 인덱스 순차 설치
- 39개 영수증·로그·감사 이력 정리/축약 작업 순환
- PENDING/RUNNING/PROCESSING/READY/STOCK_RESERVED 등 진행 데이터 보호
- high_grade_reroll_usage_v2는 영구 사용 제한 행을 삭제하지 않고 오래된 대형 JSON만 축약
- 메시지 보상 수령 영수증 및 장비 드랍 영구 중복방지 행은 삭제하지 않음

4. 출석 상세 이력 용량 제한
- user_attendance_summary_v1401에 누적 출석일·최근 출석·연속 출석 보존
- 기존 계정은 최초 조회 시 1회 안전 백필
- 180일이 지난 상세 출석 행만 소량 정리
- 출석 지급·코인 로그·요약 갱신은 하나의 D1 batch로 처리
- 중복 출석 요청 실패 시 코인과 로그가 함께 롤백

5. 추가 장기 보관 정책
