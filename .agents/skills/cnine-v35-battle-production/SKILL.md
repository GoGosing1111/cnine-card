# V3.5 전투 제작

프로젝트의 [V3.5 제작 규정](../../../docs/project-v35-battle-production-standard.md)을 먼저 읽는다. 이 문서가 도구 역할·비용 확인 이력·작업 방식·던전앤파이터급 품질·산출물·검수 상태의 단일 기준이다. 세부 내용을 이 스킬에 중복 저장하지 않는다.

현재 요청과 캐릭터별 PROJECT.md, 최신 승인 원화·무기·정본 .spine을 확인한다. 2026-11-01 후속 지시는 [새 캐릭터 기준안부터 재시작](../../../preview/v35-character-baseline-20261101/PROJECT.md)이다. 진 족로 Spine 시안은 반려·보류이며 [과거 명세](../../../docs/v35-jin-jokro-pilot-20261101.md)를 근거로 자동 재개하지 않는다. 설치된 spine-animation 스킬의 리깅·동작 지침을 해당 범위에서 적용하되, 최신 사용자 지시와 프로젝트 규정이 우선한다.

- 기본 방식은 파일·명령줄 제작이다. 사용자의 편집기 화면이나 원격 마우스/키보드 조작을 요구하거나 자동 재개하지 않는다. 2026-11-01 화면 방해 중단 지시 이후에는 사용자가 다시 명시적으로 요청하기 전까지 GUI 검수도 재개하지 않는다. 숨김 CLI와 화면 없는 런타임 검수를 사용한다.
- 전신 기준안, 정지 재조립 비교, 대기, 기본 공격, 스킬·효과 순서로 진행한다. import 후 실제 부품 배율·관절·접점과 외형을 먼저 확인한다. 검수 전 조립 프리뷰를 자동으로 열지 않는다.
- 몸과 무기의 힘 전달·파지·접지·준비/접촉/회수를 먼저 완성한 뒤 교체 작화·스미어·기술별 연속 이펙트를 붙인다. Spine만 적용한 상태나 정지 그림 트윈을 목표 품질 달성으로 판정하지 않는다.
- 최신 네이티브 편집본과 승인 원본을 보존하고 기존 V3 렌더러·GSAP 시계를 재사용한다. 전체 작업 폴더나 의존성을 복제하지 않는다.
- 구조/파일 검사, 실제 시각 검수, 실기기 성능, 사용자 피드백, 운영 연결 여부를 각각 기록한다. 미달한 결과를 완료로 포장하지 않는다.
- 이미 검증한 환경과 검사 결과를 재사용한다. 문서·규칙만 변경하면 관련 내용·경로·diff 검증과 범위 커밋·원격 반영으로 마친다.
- 최신 V3 업그레이드 지시: 현재 운영 계열 소스·리소스의 실제 동작을 먼저 확인하고 기존 전장/배우/편성/HUD/공용 시계/서버 이벤트 안에 새 Spine을 연결한다. 횡스크롤은 검의 상하 회전 제한이 아니다. 기술별 몸통 방향·발 지지·실루엣을 다르게 설계하고 큰 시점 변화는 교체 작화로 만든다. [기존 V3 연결 기록](../../../preview/v35-v3-upgrade-20261101/PROJECT.md)을 현재 후속 작업에 사용한다.
