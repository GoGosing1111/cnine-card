■ 문제 1 — 전투 길이가 전투력 격차에 비례해 무한정 늘어났다
===============================================================================
  기존 피해는 전부 공격력 기반 고정값이다. 몬스터 전투력이 올라가면 몬스터 HP 는
  선형으로 커지는데 플레이어 1타는 그대로라, 전투 길이가 격차에 비례해 늘어난다.

    측정 (카드 12만×5, 장비 50만)
      몬스터 전투력 0.5배 : 12~32행동  (7~19초)
      몬스터 전투력 1.0배 : 23~63행동  (13~33초)
      몬스터 전투력 2.0배 : 43~125행동 (24~54초)   ← 여기가 길다

  HP 를 그냥 낮추면 짧은 전투까지 같이 짧아지고, 몬스터 HP 를 낮추면 보스가 같이
  약해진다. 둘 다 원하는 방향이 아니다.

  [수정] 피해 산출을 "고정 피해"에서 "고정 피해 + 최대체력 비례 하한" 으로 바꿨다.
      const MONSTER_MIN_DAMAGE_PERCENT = 0.016;
      damage = max(기존_고정피해, 대상_최대체력 × 1.6%)

    - 고정 피해가 이미 이 값보다 크면 아무 일도 일어나지 않는다.
      → 짧은 전투(공격형 덱 / 약한 몬스터)는 수치가 그대로다.
    - 1 / 0.016 = 62.5 → 플레이어 행동 약 63회가 전투 길이의 상한이 된다.
      → 격차가 아무리 벌어져도 전투가 그 이상 늘어나지 않는다.
    - 대상이 MONSTER 일 때만 적용한다. 카드가 맞을 때는 적용하지 않는다.
    - 반격(counter)과 호송작전에는 적용하지 않는다.
      호송은 차량 피해가 별도 공식이라 전투 길이가 바뀌면 난이도가 통째로 흔들린다.

    결과 (2배 몬스터)
      일반 방어5   93행동 44초 → 68행동 35초
      일반 생명5  103행동 47초 → 69행동 35초
      보스 방어5  112행동 50초 → 71행동 36초
      보스 생명5  125행동 54초 → 73행동 37초
      0.5배·1배 구간은 ±2행동 이내로 사실상 변화 없음.

■ 문제 2 — 보스 궁극기가 아무 일도 안 하고 있었다 (제보 확인 완료)
===============================================================================
  두 가지가 겹쳐 있었다.

  (a) 장비 경감이 궁극기를 지워버림
      supportMitigationPercent = (실효전투력 - 카드자체전투력) / 실효전투력, 상한 90%
      → 장비·탈것·칭호를 쌓을수록 궁극기가 선형으로 사라진다.
      설계 의도는 "지원 전투력이 궁극기 생존력을 준다" 였는데, 상한이 90% 라
      사실상 무효화까지 간다.

      측정 (설정 15%, 덱 전체 체력에서 깎인 비율)
        장비 없음        10.4%
        장비 60만         4.9%
        장비 300만        1.6%
        장비 600만        1.0%   ← 제보한 "체력이 안 닳는다"

  (b) 방어형은 실드가 궁극기를 100% 흡수
      방어형은 최대체력의 22~38% 짜리 실드를 들고 시작하는데 applyDamage 가
      실드부터 깎는다. 15% 궁극기는 실드에 전부 먹혀서
      **방어형 덱은 장비가 0이어도 궁극기 피해가 정확히 0.0% 였다.**

  [수정]
    - 경감 상한 90% → 40%. 지원 전투력이 생존력을 준다는 의도는 유지하되,
      아무리 껴도 설정값의 60% 는 반드시 들어간다.
    - 궁극기는 실드를 관통한다 (applyDamage 에 ignoreShield 옵션 추가).

    결과 (설정 15%, 덱 전체 체력 손실)
      장비 없음   균형 10.4% → 16.2%   방어5  0% → 15.0%
      장비 60만   균형  4.9% →  9.7%   방어5  0% →  9.0%
      장비 300만  균형  1.6% →  9.7%   방어5  0% →  9.0%
      장비 600만  균형  1.0% →  9.7%   방어5  0% →  9.0%

■ 문제 3 — 보스와 일반 몬스터의 차이가 거의 없었다
===============================================================================
  공격 계수 0.0513 vs 0.0438 (17% 차이), HP 2.53 vs 2.20.
  게다가 v1813 의 강제 행동 주기가 보스·일반 공통 15 라, 보스는 95행동짜리 전투에서
  6번만 움직였다. 샌드백이 될 수밖에 없다.

  [수정]
    - 보스 공격 계수 0.0513 → 0.065 (일반 몬스터 0.0438 은 그대로)
    - 강제 행동 주기 : 보스 8 / 일반 12 (기존 공통 15)
      → 보스가 한 판에서 움직이는 횟수가 약 두 배

    결과 (2배 보스, 생존 카드 수)
      공격5  4.8 → 3.0
      균형   4.9 → 3.2
      생명5  4.2 → 3.2
      속도5  4.2 → 3.0
      방어5  4.8 → 4.3

  ※ 승률은 전 구간 100% 를 유지한다. "적당히 올린다" 요청에 맞춰 카드는 죽지만
    판은 진다까지 가지 않는 지점으로 잡았다. 더 올리려면
    MONSTER_MIN_DAMAGE_PERCENT 는 그대로 두고 보스 공격 계수만 올리면 된다.

■ 문제 4 — PVP 도 길다 (106행동 / 48초)
===============================================================================
  v1813 에서 PVE 만 줄이고 PVP 를 그대로 둔 이유가 있다. PVP 는 100행동에
  연장전(회복 봉쇄·피해 증폭)이 걸리는 구조라, HP 만 낮추면 연장전에 도달하지
  못해 상성이 통째로 뒤집힌다.

  [수정] HP 배율과 연장전 임계값을 같이 옮긴다.
      HP 배율        4.25 → 2.6
      연장전 시작     100 → 64
      행동 상한       130 → 83

    이러면 "몇 번째 행동에서 연장전이 걸리나"의 상대적 위치가 보존된다.
    측정으로 확인했다 (아래 표는 승률 / 연장전 발생률).

      균형 vs 균형     57%/100%  →  51%/100%      (미러는 50% 가 정답)
      생명5 vs 방어5    0%/100%  →   0%/100%
      공격5 vs 방어5  100%/  0%  → 100%/  0%
      방어5 vs 속도5    0%/ 71%  →   3%/ 78%
      속도5 vs 생명5  100%/  0%  → 100%/  0%
      공격5 vs 생명5  100%/  0%  → 100%/  0%

      길이 106행동 48초 → 69행동 35초

  ⚠ 방어 감소 곡선(D/(D+600), 상한 65%)은 이번에 손대지 않았다.
    이 곡선은 전투력 1만 이상에서 전원 65% 로 포화돼 사실상 죽어 있지만,
    살리면 PVP 연장전 발생률이 100% → 0% 로 사라진다(측정 확인).
    별도 패치로 PVP 재밸런싱과 같이 가야 한다. 아래 "남은 것" 참고.

■ 적용 범위
===============================================================================
  적용됨
    - PVE 몬스터 토벌            (createPveBattleV2)
    - 영토전 공성                (_siege.js → createPveBattleV2)
    - PVP 랭크전 / 클랜전        (createPvpBattleV2)

  제외됨
    - 호송작전(ESCORT) : 하한을 끄고 원본과 완전히 동일하게 동작한다.
      무작위 100판 회귀로 행동수·승패 100% 일치 확인.
    - 무한의탑 / 레이드 / 봉인전 : 이 모드들은 V2 전투 엔진을 쓰지 않는다.
      무한의탑은 `playerPower >= monsterPower` 단순 비교이고 궁극기는
      playerPower 에서 %를 빼는 방식이며, 화면 타임라인은 클라이언트
      (battle-v3-live.js 의 towerPayload/sealPayload/raidPayload)가
      약 7개 이벤트로 합성한다. 이미 몇 초짜리라 줄일 것이 없고,
      피해 공식을 바꿔도 아무 영향이 없다.

■ 남은 것 / 다음 후보
===============================================================================
  1. 방어 감소 곡선이 죽어 있다.
       reduction = clamp(D_eff/(D_eff+600), 0, 0.65)
       상수 600 이 전투력 스케일에 안 맞아, 전투력 1만 이상은 전원 정확히 65%.
       → 방어 스탯·관통 수치가 실제로는 아무것도 안 하고 있다.
       고치려면 분모를 공격자 공격력 비례로 바꿔야 하는데, 그러면 PVP 연장전
       구조가 무너지므로 PVP 재밸런싱과 묶어서 별도 패치로.
  2. 승률은 여전히 전 구간 100%. "질 수도 있는" 난이도를 원하면
     보스 공격 계수 / pve_attack_percent 로 조절 (보상·진행도 영향 검토 필요).
  3. 이번 수치는 카드 12만×5 + 장비 50만 기준 시뮬레이션이다.
     실제 유저 전투력 분포와 다르면 MONSTER_MIN_DAMAGE_PERCENT 하나만
     조절하면 전투 길이 천장이 바로 움직인다 (1.6% = 약 63행동).
