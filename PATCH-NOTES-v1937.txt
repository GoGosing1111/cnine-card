PROJECT V v1937 - 고유효과 전직 출시

1. 고유효과 전직 4종 준비
- FUR/ZENITH 등급 +13 이상 카드만 대상입니다.
- 활성 고유효과에서 가장 높은 능력치 계열을 서버가 자동 판정합니다.
- 동률 우선순위는 공격 > 방어 > 속도 > 생명입니다.
- 성공 확률은 10%이며, 성공 여부와 관계없이 마스터의 별 1,000개를 소모합니다.
- 클라이언트는 카드 ID와 멱등 요청 ID만 전송하고 성공 판정은 서버가 수행합니다.
- 파쇄자, 반격자, 잔영자, 불멸자 4종의 서버 계산과 실제 전투 전달 경로를 준비했습니다.
- 기능은 ON으로 출시하며 로그인한 일반 유저도 조건을 충족한 카드에서 사용할 수 있습니다.

2. 서버 안전성
- 카드 보유/등급/강화/고유효과/재화/전직 이력을 서버에서 다시 검증합니다.
- 카드당 전직 1회와 요청 멱등성을 보장합니다.
- 마스터의 별 차감, 10% 성공/실패 결과, 전직 기록, 완료 영수증과 경제 감사 로그를 한 DB 트랜잭션으로 확정합니다.
- CHECK guard로 조건부 0행을 트랜잭션 오류로 승격해 부분 차감·부분 저장을 원천 롤백합니다.
- 성공·실패 결과를 요청 영수증에 고정해 같은 요청 재전송으로 결과가 바뀌거나 재료가 다시 빠지지 않습니다.
- 라이브 PVE, 랭크 PVP, 클랜전, 영토전, 호송, 몬스터공성, OWNER V2 프리뷰에서 DB 전직 상태만 전투 엔진에 전달합니다.

3. 전투 밸런스
- 파쇄자: 치명타 +6, 관통 +20, 피해 상한 +12
- 반격자: 반격 확률 +3, 반격 배율 +3, 비방어 반격 +1, 직접 피해 -20%
- 잔영자: 회피 +6, 회피 상한 +6, 관통 +8, 최대 HP -7%
- 불멸자: 최대 HP +12%, 최후 생존 25%, 회복 풀 +15%
- 1,200 시드/진영, 매치업당 2,400판에서 기본 대비 52.00~53.92%, 전직 상호전 48.83~51.17%를 확인했습니다.
- 전직 카드가 없는 기존 전투의 부활/방어/승패 결과는 유지합니다.

4. UI
- 카드 상세 안에 전직 준비 UI를 추가했습니다.
- PC 2x2, 모바일 1열 구조이며 별도 중첩 모달을 만들지 않습니다.
- 4종을 모두 비교하되 실제 추천/확정 계열은 서버 응답만 사용합니다.
- 로그인 시 서버의 ON/TEST/OFF 상태를 동기화하며 이번 출시는 ON입니다.
- 실행 버튼과 최종 확인창에 성공률 10%, 실패 시에도 재료 1,000개 소모를 명시합니다.

5. PROJECT V 전투 이펙트 제외
- 이번 커밋과 배포에는 신규 전투 이펙트를 포함하거나 런타임에 연결하지 않습니다.
- 최근 V3 후보는 원본 프레임 해상도가 부족해 전경이 뭉개지는 문제가 확인되어 품질 미달 시안으로 별도 보관했습니다.
- 보스 궁극기는 신규 타격 이펙트 대상이 아니며 기존 별도 화면 연출 체계를 유지합니다.
- 향후에는 실제 고해상도 프레임을 새로 제작하고, 라이브 V3의 PixiJS WebGL, GSAP 충돌 타임라인, 히트스톱, 카메라 셰이크, 50ms 화이트 플래시, 녹음 SFX 동기화 구조로 독립 프리뷰에서 다시 검수합니다.

영향 범위
- 전직 기능: ON 출시
- 신규 전투 이펙트: 이번 변경에서 제외, 런타임 미연결
- 기존 카드 원본/프레임/SD, 기존 V3 역할 이펙트, 전투 결과 로직: 유지
