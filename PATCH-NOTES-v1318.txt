숲켓몬 v1318 · PVE/PVP 전투엔진 V2 실제 화면 완전 통합

배포
- v1317 이하 누적 패치 대신 v1318 누적 패치 하나만 적용합니다.
- v1316 PVE 시작 버튼 핫픽스와 v1317 PVP V2 서버 판정을 포함한 전체 누적 패치입니다.

핵심 수정
- 일반 PVE와 일반 PVP의 V2 활성 경로가 /preview/battle-v2와 같은 렌더러 구조를 사용합니다.
- 기존 PVE/PVP 화면에 V2 숫자만 끼워 넣던 혼합 화면을 제거했습니다.
- V2 서버 응답을 기다리는 동안에도 기존 전투 화면이 잠깐 노출되지 않고 V2 전용 계산 화면이 표시됩니다.
- 카드 프레임, 등급 프레임, 돌파 표시, 고유효과 CSS, 행동 순서, 실제 HP, 보호막, 행동 게이지, 타격 궤적, 치명타, 방어, 회피, 회복, 반격, K.O., 전열 붕괴를 동일한 V2 화면에서 재생합니다.
- V2 연출 속도는 사용자 조절 없이 1.6배로 고정합니다.

반응형 표시
- PC: 양 진영 전체 카드 배치와 중앙 전투 메시지를 표시합니다.
- 와고 iframe: width 100%, height 1750 환경을 감지해 활성 카드 2장과 양 팀 미니 덱을 표시합니다.
- 모바일 세로: 상대 활성 카드 상단, 내 활성 카드 하단, 양 팀 미니 덱을 표시합니다.
- 모바일 가로: 활성 카드 좌우 대치와 양 팀 미니 덱을 표시합니다.
- 화면 크기 변경 시 전투 API를 다시 호출하거나 전투를 처음부터 재생하지 않습니다.
- 저사양 모드와 이펙트 축소 분기는 추가하지 않았습니다.

PVE 판정 수정
- 행동 제한에 도달했을 때 몬스터 HP가 1 이상 남아 있으면 잔여 HP 비율과 관계없이 무조건 패배합니다.
- 기존처럼 몬스터가 살아 있는데 유저 승리 또는 판정 승리가 표시되지 않습니다.
- PVE 최대 행동 수는 120회입니다.
- 몬스터를 실제로 처치한 경우에만 승리 보상과 드롭을 지급합니다.

PVE 몬스터 V2 난이도 보정
- 저장된 몬스터 전투력 값은 변경하지 않습니다.
- 일반 몬스터: V2 환산 HP +10%, 공격 +35%, 방어 +30%
- 보스 몬스터: V2 환산 HP +20%, 공격 +45%, 방어 +40%
- 공격과 방어를 별도 보정하므로 단순 HP 증가만 적용되는 구조가 아닙니다.

PVP
- 공격자와 수비자의 실제 저장 덱 5장, 돌파, 고유효과, 양쪽 장비 PVP 보너스 10%를 사용합니다.
- 기존 시즌 점수, 전투 횟수, 승패, 코인, 큐브, 마법 결정, 장비 드롭, 상대 연속 대전 제한을 유지합니다.
- PVP 행동 제한 시에는 기존 설계대로 남은 HP와 보호막 비율 판정을 유지합니다.

CMS
- 일반 PVE/PVP 엔진 설정의 표시 버전을 v1318로 갱신했습니다.
- 기존 엔진, V2 OWNER 테스트, V2 전체 공개 전환 기능을 유지합니다.
- V2 OWNER 테스트에서는 OWNER의 일반 PVE/PVP에만 적용됩니다.
- V2 전체 공개에서는 일반 유저에게도 동일한 V2 실전 화면과 판정이 적용됩니다.

DB 및 용량
- 신규 테이블, 컬럼, 인덱스, 영수증을 추가하지 않았습니다.
- 타격 타임라인, 카드별 HP, 보호막, 행동 게이지 변화는 HTTP 응답으로만 전달하고 D1에 저장하지 않습니다.
- 이번 버전은 functions/api/[[path]].js의 DB 쿼리를 변경하지 않았습니다.
- PVE는 기존 battle_logs 요약 1행만 유지합니다.
- PVP는 기존 pvp_match_history 요약 1행과 카드 ID 5개 저장 구조를 유지합니다.
- 화면 전환과 반응형 변경으로 추가 API 호출이나 DB 쓰기를 발생시키지 않습니다.
