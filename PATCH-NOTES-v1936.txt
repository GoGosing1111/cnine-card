PATCH NOTES v1936 - 계열 개편 (S1)

[한 줄]
총량 제한이 없던 계열 능력을 전부 유한 자원으로 바꾼다.
계열 간 격차 68%p -> 18%p. PVE 전투 결과는 보존.

[왜 이렇게 하나]
스탯을 계열마다 완전히 똑같이 맞춰놓고 재도 계열별 승률이 55/73/91/94 로 갈렸다.
(균형형 5장 상대, 계열 카드 1장만 섞기)
즉 격차는 스탯이 아니라 능력의 성격에서 나온다.

방어형 무료 부활, 생명형 무한 회복처럼 총량 제한이 없는 능력은
수치를 아무리 깎아도 다른 계열이 따라올 수 없었다. 레버 30개를 측정했고 전부 3%p 미만이었다.
  안 통한 것: 스탯 프로필 재배분 / 회피 / 치명타 / 반격 수치 / 방어곡선 분모 3종 /
             행동빈도 압축 / 처형 / 관통 / 부활봉인 / 처치추격 / 연쇄 처치 / 공격형 추가타
  ※ 조건부 능력은 공격형에게 무의미하다. "죽였을 때" 보상인데 공격형이 못 죽인다.

그래서 수치가 아니라 무한 자원을 유한 자원으로 바꾼다.

[변경]
1. 방어형 - 무료 부활(INDOMITABLE) 삭제
   대신 전투 시작 시 팀 전체에 방벽 (방어형 최대HP x40%, 장수 체감 1/0.6/0.35/0.2/0.12)
   반격은 방벽이 남아 있을 때만 발동. 확률 25%->20%, 배율 0.55->0.60
   아군 보호(GUARD_PROTECT)는 팀 방벽으로 대체
   -> 전반에 강하고 방벽이 깨지면 평범해진다. 명확한 약점이 생긴다.

2. 생명형 - 무료 부활(SURVIVE) 삭제
   전투당 회복 총량 도입 (생명형 최대HP x65%, 장수 체감). 모든 회복이 여기서 차감된다.
   지속 회복 4% -> 7%, 긴급 회복 18% -> 30%
   연장전 회복 완전 차단 -> 절반 유지 (기존에는 연장전 진입 = 생명형 자동 패배였다)
   중복 페널티 60/75/85/90 -> 35/55/68/78
   단일 힐러 오라: "정확히 1장일 때만" -> 장수 곡선 0.7/0.4/0.25/0.15/0.1
   -> 길게 끄는 싸움에 강하고 순간 폭딜에 약해진다. 생명형 2~3장 편성이 가능해진다.

3. 속도형 - 프로필 속도 0.27 -> 0.225, 공격 0.25 -> 0.195
   방벽에 추가 피해 100% (실드가 남아 있을 때만)
   처치 시 게이지 +70, 최대 3회
   -> 방벽을 벗기는 역할

4. 공격형 - 프로필 공격 0.38 -> 0.35, 방어 0.14 -> 0.11
   ※ 공격력↑ HP↓ 가 아니라 공격력↑ 방어↓ 다.
     이 엔진은 HP 가 공격력보다 값어치가 크다(딜은 감소율·상한에 막히고 HP 는 안 막힌다).
     HP 를 깎으면 공격형이 오히려 더 약해진다(측정 확인).
   PVP 관통 0.30 -> 0.42, PVP 마무리 배율 1.10 -> 1.30
   상대 팀 부활 예산 1회 봉인, 처치 시 게이지 +45 최대 2회

5. 편성 - 신규
   계열 종류 수 보너스: 2종 +4% / 3종 +9% / 4종 +15% (팀 전체 공격력·최대HP)
   같은 계열 중첩 시 프로필 편차 감쇠: 1 / 0.72 / 0.45 / 0.28 / 0.28

6. 피해 모델 - PVP 전용
   방어 감소 분모: 상수 600 -> 공격자 공격력 x0.9
     상수 600 은 전투력 스케일에 안 맞아 1만 이상은 전원 65% 고정이었다.
     = 방어 스탯도 관통 수치도 실제로는 아무 일을 안 했다.
   피해 상한: 최대HP 46% -> 60%
   행동 속도에 기저값(전투력 x0.012) 추가. 계열 간 행동 빈도 격차 1.6배 -> 1.2배
   ⚠ 6번은 PVP 에만 적용한다. PVE 에 넣으면 승률은 100% 로 같은데
     보스전 카드 생존이 3.0장 -> 1.2장으로 떨어진다(측정). PVE 는 이미 승률 100% 라 실익이 없다.

7. PVE 보정
   부활을 없앤 만큼 PVE 생존력이 떨어지므로 PVE 에서만 방벽 x2.6, 회복 총량 x2.4

[측정]
PVP - 계열 카드 2장 + 균형형 3장 덱끼리 (매치업당 110시드)
  공격 19% -> 42%   방어 87% -> 59%   속도 60% -> 53%   생명 33% -> 46%
  계열 간 격차 68%p -> 18%p

PVP - 5장 조합 56개 전수 리그 (조합당 22시드)
  1위        방방속속속 96% (2계열) -> 방방힐공공 92% (3계열)
  2·3위      -> 방힐공공속 90% (4계열), 방방힐공속 88% (4계열)
  상위10 평균 계열 수 2.9 -> 3.1
  평균 전투 길이 56행동 -> 34행동

PVE 회귀 - 승률 전 구간 100% 유지
  균형형 5장          4.8 / 3.0 / 2.8장 생존 -> 4.8 / 3.0 / 2.8장  (완전 동일)
  방1힐1공2속1        5.0 / 5.0 / 4.0장      -> 5.0 / 4.8 / 3.7장
  방2힐1공1속1        5.0 / 5.0 / 3.8장      -> 5.0 / 4.9 / 3.3장
  (120만 일반 / 120만 보스 / 240만 보스)
  전투 길이 55->54, 61->60 행동. 사실상 동일.

[유저 체감]
- 방어형·생명형의 자동 부활이 사라진다. 이번 개편에서 가장 크게 체감되는 부분이다.
- PVP 전투가 짧아진다 (평균 56 -> 34행동)
- 생명 1 + 방어 2 구성이 더 이상 유일한 정답이 아니다
- PVE 는 승패·생존·길이가 사실상 그대로다
