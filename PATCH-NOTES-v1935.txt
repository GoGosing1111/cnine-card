PATCH NOTES v1935 - 고유효과 이중 적용 제거 (S0)

밸런스 개편이 아니라 정합성 복구다. 승패는 바뀌지 않는다.

[문제 1] 고유효과가 PVE 계열에서 두 번 곱해졌다
_magic.js 의 buildCardUniqueDeckState 가 card.power 에 공격%를 이미 곱해 놓는데,
엔진의 buildFighter 가 uniqueAbility 로 같은 %를 한 번 더 곱했다.

게다가 buildFighter 는 HP·공격·방어·속도를 전부 power 에서 파생한다.
그래서 공격 특성 카드가 HP 와 방어와 속도까지 같이 얻었다.

  고유 공격 40%  -> 실제 공격 2.04배 (의도 1.40배), HP 1.40배, 방어 1.40배
  고유 공격 80%  -> 실제 공격 3.46배 (의도 1.80배)

경로마다 달랐다.
  이중: PVE 몬스터 토벌, 방치 자동, 영토전 공성, 호송작전
  단일: PVP 랭크, 영토전  <- 이쪽이 원래 의도한 동작

[문제 2] FUR/ZENITH +11~13 배율 뒤에 재클램프가 없었다
uniqueStat 이 ±500(속도 300) 으로 자른 값에 FUR+13(x2) 을 곱하면 1000% 가 되는데
패시브 층은 그대로 썼고 엔진의 uniquePercent 만 500 으로 잘랐다.
층마다 다른 값을 쓰는 상태였다.

[수정]
1. functions/api/[[path]].js       PVE 몬스터 토벌
   engineCards 를 battleDeck(부스트본) 이 아니라 원본 cards + uniqueAbility 로 구성.
   PVP(6279행) 와 동일한 방식으로 통일.
2. functions/_siege.js             영토전 공성
   engineDeck 신설. 화면에 나가는 cards 는 battleDeck 그대로라 표시 전투력은 그대로다.
3. functions/_escort_operation.js  호송작전
   cards 를 baseDeck 기준으로 구성. roles(계열 분포)는 poweredDeck 유지.
4. functions/_magic.js             scaleUniqueEffect
   배율 적용 뒤 uniqueStat 으로 다시 자른다. 속도는 300 상한.

[측정] 카드 12만x5 + 장비 50만, 4계열 x 고유 20/40/80% x 몬스터 60/120/200만 x 일반/보스
       = 72개 조합, 조합당 60시드

  승패가 달라진 조합: 0 / 72
  전투 길이: 최대 +49% (고유 80% 구간). v1902 의 63행동 상한 안이다.
  대부분 구간은 +9~19%.

  재클램프는 CMS 값 250% 초과에서만 걸린다. 40~120% 는 변화 없음.
    CMS 300% x2 -> 600% -> 500% (덱 전투력 2.65배 -> 2.45배)
    CMS 500% x2 -> 1000% -> 500% (3.32배 -> 2.45배)
