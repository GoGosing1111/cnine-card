# 대진 형식 수정 — 사용자 확정

사용자 정정: 첫 라운드부터 부전승을 두지 않고 6명 전원이 3경기를 치른 뒤 승자 3명이 진출한다.

- 1경기: 강구열 vs 오리꿍
- 2경기: 주성 vs 디임
- 3경기: 나무늘봉순 vs 하이희야

최초 추첨에서 나온 두 대진은 유지하고, 처음 부전승으로 잘못 배치한 두 참가자를 3경기로 묶는다. 새로운 참가자 재추첨 없이 기존 무작위 순서를 사용한다.

기존 v1 포스터는 이 형식에 맞지 않아 폐기 시안이다. 최종 포스터에는 첫 라운드의 부전승 표기를 사용하지 않는다.

사용자 답변으로 3강 진행 방식이 확정됐다: 3강 진출자 중 1명을 추첨해 결승으로 바로 올리고, 남은 2명의 대결 승자가 결승에 진출한다. 실제 부전승 추첨은 첫 라운드 승자 3명이 확정된 뒤 진행하며, 포스터에서 특정 참가자나 경기 승자에게 미리 배정하지 않는다.
