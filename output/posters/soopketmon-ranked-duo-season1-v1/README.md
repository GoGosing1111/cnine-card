## 제작 방향

기존 숲켓몬 랭크전 경기장의 어두운 건축과 청·적색 조명을 배경으로, 두 파트너가 함께 출전하는 구성을 제작한다. 금빛 문구와 듀오의 협력 장면을 중심에 둔다. 날짜, 보상, 참가비, 승리 조건 등 사용자에게 지정받지 않은 운영 정보는 넣지 않는다.

- 도구: 내장 `image_gen`.
- 최초 프롬프트와 참조 원본: [prompt.md](prompt.md).
- 여성 팔과 ‘숲’ 글자 수정 프롬프트: [prompt-v2.md](prompt-v2.md).
- 손잡는 자세 변경 프롬프트: [prompt-v3.md](prompt-v3.md).
- 최종 수정본의 파일 정보 및 해당 부위 확인: [qa-v3.json](qa-v3.json).
- 참고 원본은 변경하지 않고, 선택된 생성 결과를 픽셀 가공 없이 PNG로 보존한다.

독립 공유용 포스터 자산이다. 게임 코드·캐릭터 카탈로그·운영 데이터·기능 플래그를 변경하지 않는다. 관련 자산 확인과 작업 범위 커밋으로 보존하며 게임 전체 검사나 운영 재배포 대상에 포함하지 않는다.

## V2 수정 범위

사용자가 V1의 여성 팔 형태와 상단 ‘숲’의 중성 ㅜ에 위로 튀어나온 획을 지적했다. V2에서 해당 부위를 수정했으나 사용자는 주먹 맞대는 자세 자체를 부자연스럽다고 거절했다. V1·V2는 수정 입력으로 보존하고, 자체 검수 기록은 사용자 최종 품질 승인으로 취급하지 않는다.

## V3 자세 변경

사용자의 후속 요청에 따라 두 사람이 양팔을 아래로 내리고 가운데에서 안쪽 손을 잡는 자세로 변경한다. 주먹 맞대는 팔의 각도를 재사용하지 않고 양쪽 어깨부터 손까지 다시 구성한다. ‘숲’ 글자와 나머지 행사 문구는 유지하며 최종 링크는 V3다.
