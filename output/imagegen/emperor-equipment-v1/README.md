## 파일 / 재현

- `prompts-v1.json`: 최초 4종 생성 프롬프트. 기존 미스틱 원본을 각각 참고했습니다.
- `inventory-finish-prompts-v1.json`: 장비 디자인을 유지하면서 배경·여백만 교정한 최종 프롬프트.
- `mystic-live-baseline-v1.json`: 읽기 전용 운영 카탈로그 확인 결과.
- `manifest-v1.json`: 최종 PNG 경로, 치수, 해시와 슬롯.
- 최종 결과는 기존 미스틱 인벤토리 이미지와 같은 정사각형 **불투명 장비 아이콘**입니다. 최초 생성본의 체크무늬는 실제 알파가 아니어서 최종 파일로 사용하지 않았습니다.
- 최종 원본 PNG는 재압축·리사이즈하지 않고 복사 보존합니다. 기존 미스틱 4종도 변경하지 않습니다.
- 최종 4종은 모두 1254×1254 RGB PNG입니다. `node output/imagegen/emperor-equipment-v1/verify-assets.mjs`로 이미지 형식·최종 해시·미스틱 원본 보존을 검증할 수 있습니다.
- 개별 파일: `emperor-suit-v1.png`, `emperor-leggings-v1.png`, `emperor-shoes-v1.png`, `emperor-dual-disk-v1.png`.

이 리소스 요청은 개편 중인 V3 PVE 기능이나 운영 배포를 포함하지 않습니다.
