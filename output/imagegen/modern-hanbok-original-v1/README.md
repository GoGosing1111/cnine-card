# 현대 한복 의상 시안 — 현재 V6

현재 원본은 `modern-hanbok-original-source-art-v6.png`다. 내장 `image_gen`으로 제작했으며, 한복 구조와 체형을 고친 프롬프트는 `prompt-v4.md`, 짧은 치마를 완성한 최종 편집 프롬프트는 `prompt-v6.md`다.

사용자의 최신 기준은 한국 한복의 형태, 딤우스의 2D 작화, 과하게 넓거나 마르지 않은 자연스러운 성인 체형, 더 짧은 치마다. 별개 성인 가상 캐릭터 방향에 동의한 기존 범위를 유지한다.

- V1은 실사 질감 때문에 반려됐다.
- V2는 신체와 옷의 폭이 넓다는 지적으로 반려됐다.
- V3는 반대로 너무 마른 비율과 부족한 한복 형태로 반려됐다. 이 버전의 마른 체형을 다음 작업 기준으로 삼지 않는다.
- V4는 연결된 저고리 소매, 교차하는 깃과 흰 동정, 붉은 끝동·옷고름, 주름 치마를 다시 설계하고 팔다리와 몸통의 자연스러운 볼륨을 되돌렸다. 치마 길이 변화가 부족해 추가 편집 대상으로 남겼다.
- V5의 치마 단축 편집은 생성 도구의 출력 안전 검사에서 차단돼 이미지가 없다. 실제 프롬프트와 실패 상태를 보존한다.
- V6는 불투명한 안쪽 속바지가 붙은 짧은 치마로 변경했다. 치마 밑단을 분명하게 올리고 고름·노리개 길이를 맞췄다. V4의 체형과 저고리, 얼굴, 자세, 한옥 배경은 유지한다.

딤우스 원본은 `assets/ui/avatars-v1/lobby-source-drafts/avatar-f08-ember-esports-ace-lobby-v1.png`다. 작화·비율 참고로만 입력했고 인물의 얼굴 정체성은 복제하지 않았다. 해당 원본의 SHA-256은 `07155FC396F73741936E45F29A608209FFF2B79A135F89B14A7E6A2AA09C7EED`이며 수정하지 않았다.

한복의 깃·동정·소매 배래·고름 구조는 [국립민속박물관의 한복 설명](https://webzine.nfm.go.kr/2018/05/23/%ED%95%9C%EB%B3%B5%EA%B3%BC-%EC%A1%B0%EC%84%A0%EC%98%B7-%EC%82%AC%EC%9D%B4/)을 참고했다. 짧은 치마와 속바지는 사용자 요청에 맞춘 현대적 의상 해석이며 역사 복식 재현물이 아니다. 외부 사진은 생성 입력으로 사용하지 않았다.
