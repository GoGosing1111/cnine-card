# 현대 한복 의상 시안 — 현재 V3

사용자 요청은 짧은 치마의 현대 한복이다. 별개 성인 가상 캐릭터 방향에 동의한 뒤, 딤우스 아바타의 2D 작화와 길고 가는 비율을 명확히 지정했다.

현재 원본은 `modern-hanbok-original-source-art-v3.png`, 정확한 프롬프트는 `prompt-v3.md`다.

- V1은 실사 질감 때문에 반려됐다.
- V2는 딤우스 아바타의 그려진 선·명암·머리카락 표현으로 재작화했지만 신체와 옷의 폭이 넓다는 지적으로 반려됐다.
- V3는 상체·어깨·골반·허벅지를 가늘게 다시 설계하고, 소매와 치마의 퍼짐까지 줄였다. 기존 한복 요소와 2D 작화는 유지한다.
- 딤우스 원본은 `assets/ui/avatars-v1/lobby-source-drafts/avatar-f08-ember-esports-ace-lobby-v1.png`다. 작화·실루엣 참고로만 입력했고, 해당 인물의 얼굴 정체성을 복제하지 않았다.
- 모든 버전은 내장 `image_gen`으로 제작한 1024×1536 sRGB RGB PNG이며, 생성 원본의 바이트를 그대로 보존했다. 기존 디임 자산은 수정하지 않았다.
- V3 시각 확인: 이전 시안보다 좁은 몸통·골반·다리, 2D 명암, 얼굴·손·신발, 한복의 고름·노리개·학 자수와 의상 불투명성을 확인했다. 문자나 카드 프레임은 없다.

의상·원화 시안이며 사용자 시각 검수 전이다. 기존 아바타 교체, 신규 카탈로그 등록, 계정 지급과 운영 설정 변경은 포함하지 않는다.
