## 형상과 연출

승인된 전방 장갑·중앙 함교·안테나·측면 포대·후방 엔진 형상을 유지하면서 장갑 재질을 황금색으로 변경했다. 청백색 오라는 선체 앞뒤로 감기며 금빛 전류가 섞인다. 어두운 격납고와 바닥의 반사광으로 황금 선체·포구·엔진이 명확하게 보이도록 구성했다. 효과는 원화 안의 정지 표현이며 별도 애니메이션이나 전투 기능이 아니다.
