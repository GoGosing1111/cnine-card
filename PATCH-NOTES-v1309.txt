숲켓몬 v1309 장비 전투력 전 콘텐츠 표시 일치 패치

[핵심 규칙]
- 장비 총 전투력: PVE 90% / PVP 10%
- 장착 칭호: PVE에만 추가, PVP에는 미적용
- 서버 전투 판정과 콘텐츠 화면이 동일한 장착 보너스를 사용

[표시 수정]
- 일반 PVE/자동전투: 출전 덱 및 전투 진입 화면에 카드 + 장비 + 칭호 표시
- PVP: 덱 편성 및 전투 진입/결과에 카드 + 장비 PVP 보너스 표시
- 무한의탑: 저장 덱/전투 진입 화면에 장비·칭호 포함 전투력 표시
- 균열 원정: 출정 전/전투 화면에 장비·칭호 포함 전투력 표시
- 월드 레이드: 참가 시 카드/장비·칭호 분해 표시, 전장에는 포함 여부 명시
- 봉인전: 기존 서버 PVE 장비 반영과 '장비·시너지 포함' 표시 검증
- 대장전: 기존 서버 PVP 장비 반영 검증 및 UI에 '장비 포함' 명시

[동기화]
- 장비/칭호 장착·해제 API가 최신 보너스를 즉시 반환
- 장착 변경 직후 열려 있는 PVE/PVP/무한의탑/균열 표시를 새로고침 없이 갱신
- 레이드·봉인전·대장전의 이미 등록된 덱은 공정성을 위해 등록 당시 스냅샷 유지
  (새 참가/새 회차 등록 시 최신 장비 전투력 재계산)

[성능/DB]
- 장비와 칭호 보너스를 기존 2회 SELECT에서 CTE 1회 SELECT로 통합
- 신규 테이블/컬럼/로그/마이그레이션 없음
- 전투 상세 JSON 추가 저장 없음
- 기존 데이터 DROP/RENAME/초기화 없음
