V2034 — 슈퍼스타 전투력 / 덱 1장 제한

요청
- 같은 강화 단계의 일반 FUR·ZENITH 등급 전투력 중 높은 값에 10,000을 더한다.
- +0~+13 전체 적용. +11~+13도 가산분 10,000에 강화 배율을 다시 곱하지 않는다.
- SUPERSTAR는 덱당 최대 1장. PRESTIGE/FUR/ZENITH 각 2장과 일반 덱 총 5장은 유지한다.

반영
- 서버 공용 cardBattlePower와 라이브 battleCardPower에 같은 등급 비교 후 가산 계산.
- CMS 기본 전투력의 SUPERSTAR 값은 파생값으로 표시하고 직접 입력은 잠금.
- 카드 상세에 슈퍼스타 전투력 계산과 1장 편성 규칙 안내.
- PVE/PVP 저장, PVE 전투/소탕, 레이드 출전 검증 및 기존 덱 스냅샷에 1장 제한.
- 랭크전 일괄 상대 조회에서 제한 초과 방어 덱은 매칭 후보에서 제외.
- 클랜/영토전 등이 재사용하는 덱 스냅샷도 제한 초과 덱을 전투에 공급하지 않음.
- 기존 보유 카드나 저장 덱은 임의 삭제/대체하지 않음. 초과 덱은 재편성 필요.
- 모바일 등급 제한 배지는 4개를 2×2로 표시.
- 앱/CMS/PVE/서비스워커 캐시 갱신 및 변경된 태그를 검사하는 테스트 정합성 갱신.

유지
- 다른 등급 전투력, 개별 카드 고유 보너스, 강화 비용/성공률/천장, 전직/고유효과 변경 없음.
- V3 전투 엔진/렌더러/캐릭터/원화/SD/프레임/배틀슈트/신규 레이드 출시 상태 변경 없음.
- 보상, 행동력, 상점 판매, 팩 드랍풀 변경 없음. 운영 DB 직접 변경 없음.

- 작업 범위만 커밋/원격 main 푸시 후 npm run deploy:production 사용.
- 배포 명령 안의 release:gate를 우회하지 않는다.
