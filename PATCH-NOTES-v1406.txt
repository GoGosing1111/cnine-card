CNINE CARD v1406 — Territory War instant V2 / 50v50 concurrency

기준
- cnine-card(38).zip + v1400~v1405 누적
- 전체 프로젝트가 아닌 수정·신규 파일 누적 패치

핵심 변경
1. 영토전 공격의 전선 전체 잠금 제거
   - 기존: 한 전투가 매칭·덱 조회·V2 계산·DB 반영을 끝낼 때까지 같은 전선의 다음 공격 차단
   - 변경: 각 요청의 V2 매칭·전투 계산은 병렬 실행, 공성 HP·행동력 반영만 짧은 D1 원자 배치로 처리

2. 50 vs 50 동시 참가 부하 완화
   - 공성 HP는 MAX/MIN 기반 원자 감소 SQL 사용
   - HP가 0이 된 뒤 도착한 전투는 행동력·기여도·공성 피해를 적용하지 않음
   - 공격 응답에서 무거운 전체 랭킹·최근 기록 조회 제거, 경량 상태만 반환
   - 실시간 상태 조회를 전선+내 상태 JOIN 1회로 축소
   - CMS 설정 5초 isolate 캐시
   - 등록 PVP 덱 카드 조회 5초 isolate 캐시
   - 100명 폴링 주기 ±12% 분산으로 동시 요청 파도 방지

3. 즉시 전투 연결 및 PENDING 경고창 제거
   - 공격 버튼 클릭 즉시 V2 로딩 화면 표시
   - 동일 requestId가 처리 중이면 409 alert 대신 200 pending 응답
   - action-status 경량 조회로 0.3초 간격 자동 결과 확인
   - 완료되면 동일 seed의 V2 전투를 바로 재생
   - 응답 유실·중복 클릭에도 행동력/공성 피해 중복 반영 없음

4. 상대 매칭 분산
   - 동일 전력 ±30% 후보를 우선
   - 후보 내 requestId seed 기반 분산
   - 유사 전력 후보가 없을 때도 전체 상대 진영에서 분산 매칭

5. 전선 종료 안전성
   - 마지막 피해를 실제 남은 HP만큼만 기여도에 기록
   - 공성 HP 0 미만 방지
   - 전선 해석 잠금은 HP가 0이 된 마지막 공격에만 사용
   - 일반 공격은 전선 잠금 테이블을 사용하지 않음

변경하지 않은 항목
- Battle Engine V2 판정·타임라인·연출
- PVP 덱 5장 규칙
- 카드 고유효과·시너지·장비 PVP 보너스
- 공성 피해 계산식과 CMS 설정값
- 영토전 보상 및 전선 이동 규칙
- 기존 D1 테이블/운영 데이터
