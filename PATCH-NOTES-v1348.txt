변경 내용
1. 사용자가 확정한 장비 화면 PNG를 실제 장비 화면 배경으로 연결
- PVE/PVP 고정 숫자가 없는 완성 PNG 사용

2. 사용자가 확정한 차고 클린 PNG를 실제 차고 화면 배경으로 연결

- 실제 차량 보유/장착 데이터가 있을 때만 차량 이미지와 수치 표시
- 장착/해제, 등급 필터, 보유 이동수단 목록 기능 유지

3. 임시 CSS 버튼/그림 제거
- 보이는 탭은 PNG 자체 디자인만 사용
- HTML 버튼은 투명 클릭 영역으로만 동작
