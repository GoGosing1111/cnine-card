[SOOPKETMON v1290] 봉인전 CMS 설정 저장 롤백/지연 반영 수정

기준
- cnine-card(39).zip
- v1279~v1289 누적 포함

원인
- 봉인전 CMS 진입/새로고침 때 시작된 이전 overview 요청이 저장 완료 후 뒤늦게 도착하면,
  과거 설정값으로 입력 폼을 다시 채우는 비동기 응답 경합이 가능했다.
- 저장 성공 후 다시 GET 조회에 의존하여 화면을 갱신하므로 느린 요청 순서에 따라 2~3회 저장해야
  반영된 것처럼 보일 수 있었다.

수정
- 조회 요청 순번을 부여하고 오래된 응답은 화면 반영하지 않음
- 사용자가 입력 중인 폼은 일반 현황 조회가 덮어쓰지 않음
- PATCH 저장 응답의 실제 저장값을 즉시 폼 기준값으로 확정
- 저장 API가 저장 직후 DB를 재조회하여 일치 여부를 검증
- 저장 응답에 최신 overview를 함께 반환하여 불필요한 재조회 제거
- 새 봉인전 시작/종료 후에도 서버 반환 overview를 직접 반영
- 스크립트 캐시 버전 갱신
