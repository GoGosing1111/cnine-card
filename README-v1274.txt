숲켓몬 v1274 보급상자 확률 합계·콘텐츠별 지급 개수

1. CMS 보급상자 장비 풀
- 체크된 장비 확률 합계를 실시간 표시
- 장비별 입력값을 %로 명확히 표시
- 합계가 100%가 아니면 빨간 경고 및 저장 차단
- 서버도 활성·공개 장비와 합계 100%를 재검증

2. 콘텐츠별 보급상자
- PVE/PVE_AUTO/TOWER/RAID/RIFT/PVP/CAPTAIN별 지급 개수 1~100 설정
- 성공 판정 1회 후 설정 개수를 한 번에 지급
- 중복 요청은 최초 지급 개수를 영수증에 보존해 재지급 방지
- 보유 수량과 미확인 수량을 실제 지급 개수만큼 증가

3. 유저 표시
- 획득 연출에 xN 표시
- 자동전투 결과의 보급상자 개수를 실제 합계로 표시

DB 변경
- 기존 equipment_supply_drop_grants에 quantity INTEGER DEFAULT 1 컬럼만 안전 추가
- 신규 테이블 및 실패 로그 없음
