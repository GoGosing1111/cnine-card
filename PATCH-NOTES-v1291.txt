[SOOPKETMON v1291] FUR 최초 획득 보정 누적 패치

기준
- 최신 전체 기준본: cnine-card(39).zip
- v1279 ~ v1290 누적 변경 포함

핵심 규칙
- 프리미엄팩(premium), 리미티드팩(pickup)에서만 적용
- FUR 카드를 한 번도 보유하지 않은 유저만 대상
- 두 팩의 카드 개봉 수를 하나의 공용 카운터로 합산
- 기본 50번째 카드부터 FUR 보정 확률 시작
- 기본 50회 2% → 99회 20%까지 점진 상승
- 기본 100번째 카드에서 FUR 100% 확정
- 원래 설정된 FUR 확률보다 보정 확률이 낮으면 원래 확률 유지
- FUR를 자연 획득하거나 다른 경로에서 먼저 획득해도 대상 즉시 종료
- 과거 FUR 보유 이력이 있는 계정은 카드 퇴사 후에도 재보정하지 않음
- 10회/20회 개봉도 슬롯별로 순서대로 카운트 적용
- FUR 획득 후 같은 묶음의 남은 슬롯은 정상 확률로 진행
- SSR 천장과 병행되며 FUR 획득 시 SSR 이상 획득 규칙대로 SSR 천장 초기화

CMS
- 카드팩 세부 설정의 프리미엄팩/리미티드팩에 FUR 최초 획득 보정 영역 추가
- 사용 여부, 보정 시작 회차, 확정 회차, 시작 확률, 확정 직전 최대 확률 설정
- 현재 선택한 팩에서 획득 가능한 FUR 후보 카드 수 표시
- 설정은 두 팩에 공용으로 적용

DB/성능
- 신규 user_fur_first_pity 테이블은 유저당 최대 1행
- 전투/뽑기 상세 JSON 또는 별도 누적 로그를 추가하지 않음
- 묶음 개봉 1회당 카운터 쓰기 최대 1회
- 기존 테이블 DROP/RENAME/초기화 없음
- 런타임 안전 생성 및 별도 마이그레이션 SQL 포함
