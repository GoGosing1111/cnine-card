숲켓몬 v1278 보급상자 장비 풀 0.001% 정밀도 수정

원인
- CMS 합계 표시는 소수 둘째 자리까지만 반올림했지만 저장 검증은 더 정밀하게 수행했습니다.
- 실제 합계가 100.001%여도 화면에는 100.00%, 초과량은 0.00%로 보여 원인을 알 수 없었습니다.
- 장비별 입력 step도 0.01이라 0.001%를 정식 지원하지 않았습니다.

수정
- 장비별 확률 입력 단위를 0.001%로 변경했습니다.
- CMS 합계와 차이를 소수 셋째 자리까지 표시합니다.
- 브라우저와 서버 모두 확률을 1/1000% 정수 단위로 합산합니다.
- 99.999% + 0.001%는 정확히 100.000%로 저장됩니다.
- 100.001%는 0.001% 초과로 정확히 표시하고 저장을 막습니다.
- 균등 분배도 24개 등 나누어떨어지지 않는 수량에서 합계가 정확히 100.000%가 되도록 나머지를 분배합니다.
- DB 구조 변경 없음.
