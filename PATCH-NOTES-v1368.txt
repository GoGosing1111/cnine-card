[v1368] 영토전 OFF 동작 수정 및 모집 화면 재디자인

기준
- v1367 누적 패치

서버 수정
- 운영 모드 OFF에서는 신규 회차를 자동 생성하지 않음.
- OFF 상태에서는 모집 종료, 자동 편성, 준비 종료, 전쟁 종료 전환을 실행하지 않음.
- OFF 저장 시 현재 RECRUITING/PREPARING/ACTIVE 회차를 DISABLED로 전환.
- 진행 중 무방비 점령 작전과 점령 타이머 제거.
- OFF 상태에서 참가 신청, 신청 취소, 이동, 공격, 작전 취소 차단.
- TEST 또는 ON 전환 시 새 모집 회차를 생성.
- OFF 상태에서 회차 종료 버튼으로 신규 모집을 생성하지 않음.

사용자 UI 수정
- 큰 설명용 문구 중심 화면 제거.
- 회차, 현재 신청자, 모집 종료 시간, 편성 준비도, 규칙, 내 신청 상태 중심의 게임형 모집 화면으로 교체.
- OFF 상태 전용 운영 중지 화면 추가.
- OFF에서는 모집 카운트다운과 신청 버튼을 표시하지 않음.

CMS 수정
- OFF 상태에서 운영 중지 상태를 명확히 표시.
- OFF 상태에서는 강제 편성 및 회차 종료 버튼 비활성화.
