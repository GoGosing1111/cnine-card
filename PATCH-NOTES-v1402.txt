CNINE CARD v1402 - 영토전 V3 단일 전선 공성전 누적 패치

기준
- cnine-card(38).zip + v1400 + v1401 적용 상태
- 기존 D1 테이블/운영 데이터 삭제·초기화 없음
- 기존 영토전 V2 테이블은 보존하고 진행 중 회차만 DISABLED 전환

영토전 V3 구조
- 9개 고정 거점: A 본진 - 전초 - 중간 - 관문 - 중앙 - 관문 - 중간 - 전초 - B 본진
- 동시에 진행되는 교전지는 항상 1곳
- 중앙에서 시작하며 A 승리 시 B 방향, B 승리 시 A 방향으로 전선 1칸 이동
- 상대 본진 교전에서 승리하면 즉시 회차 종료
- 제한 시간 종료 시 전선 위치 > 현재 공성 HP 비율 > 누적 피해 순서로 승자 판정

전투
- 소대 편성·소대 공격·개별 이동·다중 영토 동시전투 제거
- 참가자는 개인 행동력을 소모해 상대 진영 공성 HP 공격
- PVP 등록 덱 전투력의 제곱근 기반 피해 계산으로 고전투력 독점 완화
- 최소/최대 피해, 피해 변동폭, 행동력, 공성 HP를 CMS에서 설정
- 전초·중간·관문·본진별 HP 배수 설정

안정성
- 공격 requestId UNIQUE 및 PENDING/APPLIED/COMPLETED 단계 저장
- 응답 유실 후 같은 requestId 재시도 시 피해와 행동력 재차 적용 금지
- APPLIED 상태 재시도는 누락된 전선 이동·본진 정산만 복구
- 교전지별 서버 잠금으로 동시 마지막 타격의 중복 전선 이동 차단
- 관리자 편성·강제 종료 작업키 영수증 적용
- 보상 수령 서버 잠금과 조건부 claimed_at 처리 유지

D1 용량
- 공격 영수증에는 피해·행동력·소형 결과만 저장
- 완료 공격 7일, 실패 공격 2일 후 50행 단위 자동 정리
- 완료 관리자 작업 30일, 실패 작업 7일 후 자동 정리
- 수령 완료 보상은 365일 후 자동 정리
- PENDING/APPLIED 공격, 미수령 보상은 정리 대상에서 제외
- 신규 정리 인덱스 및 계정 삭제 연관 테이블 추가

UI/CMS
- 사용자 화면을 가로형 9거점 미니맵과 양 팀 공성 HP 화면으로 전면 교체
- 현재 교전지·내 행동력·누적 피해·기여도·최근 공격 표시
- 전장 표시 중 3초 기본 경량 갱신, 백그라운드 20초
- CMS를 V3 공성 HP·피해 모델·보상 설정으로 전면 교체
- 기존 API 라우터에 누락되어 있던 handleTerritoryWar 연결 추가
