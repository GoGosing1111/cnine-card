v1379 영토전 실시간 지도·소대 조우전
- 지도 상태 경량 폴링(기본 3초, CMS 2~15초)
- 소대 이동은 소대장/현재 지휘권자만 가능
- 인접 지점 이동 시 반대 진영 소대 또는 점령 소대와 만나면 자동 3대3 V2 조우전
- 승자 지점 잔류, 패자 직전 위치 후퇴
- 지도에 A/B 소대 수, 점령 중, CONTESTED 표시
- 조우전 참가자는 폴링으로 결과를 감지해 V2 화면 재생
- 폴링 응답에는 V2 전체 JSON 미포함; 참가자만 encounter 상세 API로 1회 조회
- 동일 지점 이동/교전 잠금으로 중복 처리 방지
