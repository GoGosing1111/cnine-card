PATCH NOTES v1934 - V3 전장 로딩 무한 대기 수정

[증상]
"V3 WebGL 전장 구성 중" 에서 진행이 안 된다.
상태줄이 "WebGL 전장을 즉시 다시 구성하고 있습니다." 로 바뀐 뒤에도 그대로 멈춘다.

[원인]  ※ 실제 브라우저에서 재현 확인
BattleEngine.setBattlefield() 의 배경 교차 페이드가 GSAP 트윈이고,
GSAP 은 requestAnimationFrame 으로 돈다.

  await new Promise(resolve => {
    gsap.to(backgroundLayer, {alpha:0, ... onComplete: () => {
      apply();
      gsap.to(backgroundLayer, {alpha:1, ... onComplete: resolve});
    }});
  });

화면이 가려지면(탭 전환 / 화면 잠금 / 백그라운드 PWA) rAF 가 멈춘다.
그러면 onComplete 가 영원히 안 불리고 이 await 가 풀리지 않는다.

battle-v3-live.js 의 initialize() 는 이 순서다.

  await setBattlefield(mode);   <-- 여기서 영구 대기
  await setVisible(true);       <-- 화면을 켜는 건 그 다음

즉 "안 보여서 멈추는데, 보이게 만드는 코드가 그 뒤에 있는" 순환 대기다.
14초 타임아웃이 걸려 재시도해도 같은 자리에서 다시 막힌다.

추가로 backgroundLayer.activeMode 는 apply() 안에서만 설정된다.
마운트 직후에는 비어 있으므로 setBattlefield 의 조기 반환 조건이 성립하지 않고,
전투에 들어갈 때마다 항상 이 트윈을 탄다.
