2026-10-16 · 정지형 전신 SD 리소스 제작

커맨더 크리그와 오메가-09를 작화·기계 재질 참고로 사용해 새 디펜스 전용 몬스터 7종을 제작했다. 흑철·은색·아이보리 공통 재질, 큰 실루엣, 역할별 센서 색으로 구분한다.

## 파일
- 확인 페이지: `index.html`. HTTP 서버에서 열거나 배포된 동일 경로를 사용한다.
- 전체 비교 이미지: `overview.png` — 실제 갤러리의 브라우저 캡처.
- 선택 리소스 및 파일 해시: `manifest.json`.
- 최초 생성 프롬프트 7개: `prompts.json`.
- 지원병 여백 보정: `prompt-pulse-weaver-v2.json`.
- 생성 원본 위치: `generation-sources.json`.
- 개별 원본: `assets/`. 모두 실제 RGBA PNG, 1254×1254.
- 펄스 위버는 지팡이 상단 여백을 확보한 V2가 현재 선택본이다. V1도 이력으로 보존한다.

## 제작과 검수
내장 `image_gen.imagegen` 모드로 7종 각각 생성하고 지원병 여백만 1회 보정했다. CLI/API 대체 도구를 사용하지 않았다. 생성 PNG를 바이트 그대로 복사했으며 픽셀 수정·누끼 후처리·크롭·재압축하지 않았다. 참고한 기존 두 SD도 변경하지 않았다.

전신·무기 끝·사족 연결·총기 축을 직접 확인했다. 선택 7종 모두 실제 알파를 갖고, 알파 32 초과 내용 기준 최소 여백은 32px다. 파일 해시와 원본 일치를 확인했다. 갤러리는 데스크톱 1440×1080, 모바일 390×844, 일반 160px/보스 200px 축소, 밝은/어두운/체크 배경, 확대·좌우 이동·닫기·다운로드 경로를 확인했다. 기술 검수 기록은 `../../docs/qa/monster-defense-exclusive-20261016.json`이다.

이번 묶음은 이미지 제작 시안이다. 이름·역할·일반/정예 구분은 제안이며, 사용자의 시각 승인을 받은 것으로 기록하지 않는다. 움직임·스킬·전투 능력치·웨이브 배정은 이 리소스 제작의 완료 범위에 포함하지 않는다. 기존 디펜스 TEST의 13종 로스터와 설정은 이 묶음을 자동으로 읽지 않는다.
