# 엠퍼러 +10 · 황제의 위광
상태: **로컬 전투 프리뷰 / 사용자 시각 검수 대기**. 라이브 장비 효과 등록·계정 변경·전투력 변경 없음.

## 실행
저장소 루트에서 `node preview/emperor-set-v3-20261019/serve.mjs`를 실행하고
http://127.0.0.1:3555/preview/emperor-set-v3-20261019/ 를 연다.
현재 이 PC의 3555 포트에서 실행 중이다. 기존 3553 프리뷰는 유지한다.

전투는 자동 반복한다. 상단에서 효과 켜기/끄기, 일시정지, 1 → 0.5 → 2배속, 다시 재생을 조작할 수 있다.
무음으로 시작한다. `cnine_battle_sound=OFF`는 이 로컬 프리뷰 origin에만 저장된다.

## 적용 기준과 표현
- 장비 소유 계정의 상의·하의·신발·장신구가 모두 엠퍼러이고 각각 +10 이상이어야 한다. 보유만 한 장비·혼합 세트·한 부위 +9는 제외한다. 무기는 조건에 포함하지 않는다.
- 시연은 왼쪽 A 계정의 네 부위 +10 스냅샷을 사용한다. 사용자 캐릭터·아바타를 V3에 추가하지 않는다.
- PC: 아군 진형을 감싸는 황금 바닥 문양, 진형 중앙 뒤의 왕관·태양·월계수 문장, 상승하는 작은 금빛 입자.
- 모바일 세로 화면: 원래 V3 카드 진형을 유지하며 각 아군 진형 위치의 바닥 문양으로 분산한다. 적 진영에는 표시하지 않는다.
- 실제 아군 공격의 `normalAttack.onImpact` 순간에 대상 몸통의 금빛 파열을 재생한다. 12개 서로 다른 연속 이미지가 점화 → 파열 → 파편 분리 → 잔불 소멸을 표현한다. 기존 피해 이벤트·기술·대상·승패는 그대로다.
- 전용 UI 패널·버튼·카드 프레임은 생성하지 않았다. 기본 V3 HUD·카드 도크와 기존 아트 어댑터를 사용한다.

## 구현·원본
- `EmperorSetFX.mjs`: 기존 `ProjectVPixiBattle.fxRuntime`의 Pixi Container/Sprite/Texture를 사용한다. 새 렌더러·중복 라이브러리·번들은 없다.
- 시간 소유자는 기존 `BattleEngine.timeline`의 GSAP이다. 초 단위로 바닥·문장·입자·0.7초 타격 아틀라스를 샘플링하며 자동 재생 AnimatedSprite/Ticker 시계는 추가하지 않는다.
- `app.mjs`: 기존 V3 전투 셸·서버 시뮬레이션 결과를 재생한다. 재시작은 공용 `resetSession`으로 사망/투명도/체력 상태까지 초기화한다. 중단은 타임라인·효과와 렌더러를 정리한다.
- `build-fixture.mjs`: 실제 등록 카드 ID 5종과 원래 아트를 사용해 공용 `createPvpBattleV2`를 seed 20261019로 실행한다. 동일한 시연 덱 5 대 5이며 새 카드나 별도 사용자 모델을 발명하지 않는다.
- `set-policy.mjs`: 프리뷰 전용 장비 조건. 운영 장비 조회·서버 API 연결은 아직 하지 않는다.
- `assets/`: ImageGen 생성 원본 네 장을 바이트 그대로 보존한다. `impact.png`는 보조 입자, `impact-sequence.png`는 4×3/12프레임 주 타격 연속 작화다.
- `prompts.json`: 실제 전체 생성 프롬프트. `manifest.json`: 원본 해시·알파·크기·참조 장비 해시·현재 공용 번들 해시·PixiJS 8.20.0 / GSAP 3.13.0·아틀라스 좌표와 피벗.
- 이번 범위는 **계정 장비의 전장 장식과 보조 적중 효과**다. 신규 슈트/용병의 몸·무기 동작을 제작하거나 기존 승인 작화를 변경하지 않는다. 몸 작화·무기 합성은 기존 V3 승인 리소스로 유지한다.

## 검수
`node preview/emperor-set-v3-20261019/verify.mjs`로 장비 조건 16개, 4개 원본의 알파, 아틀라스 셀, 실제 카드 식별자, 아바타 미사용을 확인했다. 새 JS 문법 검사 통과.

실제 브라우저 1440×900 및 터치 390×844에서 아군 문장/바닥, 카드·체력바, 효과 ON/OFF, 일시정지, 0.5/1/2배속, 재시작, 반복 재생, 정리, 동작 줄이기를 확인했다.
- 전장 canvas 1개, A/B 각각 5명, 계정 아바타 OFF.
- 일시정지 동안 FX 시계 고정. 0.5배속은 GSAP timeScale 0.5. 효과 OFF 시 세 신규 효과 레이어 모두 숨김.
- 재시작 때 사망 상태를 강제로 만들었던 카드도 IDLE/HP 100으로 복구하고 이전 FX는 파괴됨. 바닥/문장 레이어 2개, 타격 레이어 1개만 유지.
- 동작 줄이기: 회전 0, 상승 입자 0, 추가 타격 플래시 생략.
- 페이지 정리 경로 실행 후 남은 타임라인 0, canvas 0.
- 모바일 가로 넘침 0, 조작 버튼 높이 44px. 새 자산 HTTP 오류 0, 콘솔 error 0, /api/ 요청 0.
- 기존 공용 엔진에서 사용하지 않는 Apocalypse atlas cache 경고가 발생한다. 신규 이미지 누락은 없으며 이 프리뷰에서 공용 엔진을 수정하지 않았다.
- 탭 비활성화 중 보존 로직은 프리뷰에 구현했다. DevTools 격리 탭 전환이 `document.hidden`을 true로 바꾸지 않아 실제 백그라운드 전환의 시각 확인은 제한된다.

증빙: `qa/desktop-start.png`, `qa/desktop-impact.png`, `qa/mobile-start.png`, `qa/mobile-on.png`, `qa/mobile-off.png`, `qa/desktop-review.mp4`, `qa/mobile-review.mp4`, `qa/report.json`.
기술 확인과 사용자 시각 승인은 별도이며, 라이브 출시는 이번 요청 범위에 포함하지 않는다.
