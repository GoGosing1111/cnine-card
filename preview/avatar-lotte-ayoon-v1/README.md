# 롯데 아윤 · A-26

사용자 요청: 첨부 이미지를 롯데 아바타 **롯데 아윤**으로 등록하고 장비창 리소스를 제작한다. 김아윤을 롯데 클랜에 편입한 후, 롯데 전원에게 T1 조은과 같은 옵션으로 현재 시즌 종료까지 기간제로 지급한다.

## 리소스

- 로비 원본은 첨부 PNG를 무가공 보존했다. SHA-256 `0e6f04d91511f570a87d1f121326aa460c916056af725930c88d16e7eb2a2df9`.
- 장비창 전신은 내장 `image_gen`으로 생성했다. 실제 프롬프트는 [prompts.md](prompts.md). 생성 원본 SHA-256 `31f995a5f5b6652efadebd072c1c0e2c151516e2ba53f21dc56bdde52eefd5fd`.
- 생성된 실제 알파를 그대로 보존한다. 투명 여백 정리, 균일 배율, 패딩, WebP 압축만 적용한다.
- 런타임: 로비 1024×1536 / 640×960 WebP, 장비창 640×1664 알파 WebP (110,106바이트).
- `node preview/avatar-lotte-ayoon-v1/build-assets.mjs`는 원본 해시와 알파·외곽 잘림을 검증하고 파생 파일·매니페스트를 만든다.
- 실제 운영 `SoopketmonCharacterLoadoutV2`를 재사용하는 프리뷰에서 PC 1440×1000, 모바일 390×844를 확인했다. 전신·구두 표시, 밝은 배경 알파 경계, 이미지 로딩, 가로 넘침과 콘솔 오류를 확인했다.

## 등록·지급

`LOTTE_AYOON` / A-26, 활성·공개 ON, 판매 OFF, 획득 EVENT. 코인 습득량 +75%, 레이드 추가 입장 +10회는 운영 T1 조은의 옵션을 대조해 복사한다.

시즌 5(시즌 번호 2) `ends_at=2026-09-27T13:00:00.000Z`, 즉 **2026-09-27 22:00 KST**까지 지급한다. 현재 롯데 19명과 김아윤(ID 5209)을 합한 20명이 대상이다. 클랜 정원은 기존 20명을 사용한다.

클랜 편입은 기존 OWNER 편입 기능의 확인·적용 경로를 사용한다. 아바타 등록·옵션·20명 소유권·감사 로그·완료 영수증은 별도 단일 트랜잭션으로 처리한다. 명단이나 시즌 종료·옵션이 바뀌면 중단하고, 완료 영수증 재실행은 중복 지급하지 않는다. 자동 장착은 하지 않는다.
