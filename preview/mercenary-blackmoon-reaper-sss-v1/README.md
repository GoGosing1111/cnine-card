## V2 후속 수정

사용자: `용병 의상 디자인 자체는 마음에 드는데 칼을 좀 더 내가 보낸 사진하고 비슷하게 디자인할것 그리고 공중에 부양하는 장면으로 비슷하게 구상할것`.

후드·어깨·상의·허리·코트의 디자인은 유지하고, 대검을 참고 이미지처럼 넓고 단순한 일체형 칼날·짧은 가드로 수정했다. 전경 바위와 지면을 없애고 두 발을 자연스럽게 늘어뜨렸으며, 발끝 아래에 회색 구름과 공백이 보이는 공중 부유 구도로 바꿨다. 검은 달과 붉은 주황 광원은 유지한다.

## 디자인 및 참고

사용자 첨부 `3bd20b10ad1e6a48ba69ef1bade765bb.jpg`의 검은 초승달·회색 폭풍 구름·어두운 인물·대검·붉은 주황 광원을 유지했다. 후드 아래 얼굴을 완전한 암부로 처리하고 눈빛만 남겼으며, 무거운 검은 코트와 굵직한 대검으로 재설계했다. 이번 사용자 요청에 따라 일반 원화 규정의 노출된 얼굴·표정 가독성보다 검은 실루엣을 우선한다.

채색 기준은 베스페라(`female-office-sniper-red-v1.png`), SSS 완성도 참고는 승인 라그니엘(`approved-20260919/mercenary-v046-ragniel-source-art-v1.png`)과 크라이베른(`cryvern-source-art-v1.png`)이다. 이들의 인물·색상·무기·배경 디자인은 복제하지 않았다.

- 검은 초승달과 회색 배경, 검은 실루엣, 대검, 몸 앞뒤로 흐르는 붉은 주황 광원을 확인했다.
- 두 팔·손목·대검 손잡이 연결, 자연스럽게 내려간 반대 손을 확인했다.

- 생성 원본은 1024×1536 RGB sRGB이며 확대·재압축·수정하지 않았다.
- 게임 등록·기존 흑월 원화 교체·CMS·획득·전투 연결은 이 원화 제작에 포함하지 않는다.
