아래 표의 동작들은 독립 프리뷰 모드다. 실제 전투에서 극빙 왕관은 하나의 전용 스킬, 연격/십자참/빙선풍은 1회 기본 공격의 시각 변주다. 수정 반격벽은 서버 보호막 손실의 반응 연출일 뿐 추가 반격 피해가 없다. 피해 권한은 서버에만 있다.

**54개 동작 + 80개 효과 = 134개 개별 프레임**. 스킬별 준비·방출·충돌·소멸을 내장 ImageGen으로 각각 생성했다. 정지 이미지 색 변경/확대·회전을 개별 연속 프레임으로 세지 않는다. CLI/API 대체 생성은 없다.

ImageGen 스킬에 따라 실제 생성 알파와 원본을 보존했다. 정확한 프롬프트는 `prompts/`, 시트 원본은 `assets/source/`, 경로·해시는 `manifest.json`이다. 발바닥·머리 높이·검끝 등록은 `registration.mjs`.

모션은 알파 연결 성분으로 분리해서 옆 셀로 걸친 검끝을 격자 선으로 자르지 않는다. 동일 시트에 동일 신체 배율을 사용하여 웅크린 동작을 확대하지 않는다. 768px 모션/512px FX 셀에 투명 여백만 더하고 무손실 WebP로 묶는다. 효과는 `fx-` 경로로 분리해 모션 파일명과 충돌하지 않는다. FX 인접 프레임의 알파 교차는 새 생성 프레임으로 세지 않는다.

## 더 진한 고강화 광원 V2

후속 요청: `괜찮긴한데 몸에 두르는 이펙트 광원이 더 진했으면 좋겠는데`.

`source/IceDualSwordFX.js`의 현재 포즈 텍스처·알파·앵커·배율을 매 프레임 따라간다. 18개 실루엣 복사본은 넓은 코발트 블룸 1개, 가까운 청색 블룸 1개, 진한 코발트 외곽 8방향, 청백색 테두리 8방향이다. 원본 캐릭터가 앞에 있어 갑옷·얼굴·손·무기 재질을 유지한다.

`BlurFilter` 2개와 `ColorMatrixFilter` 4개를 재사용한다. RGB만 바꾸고 원본 알파는 유지한다. 별도 오라 12프레임과 상승 입자는 보조 계층이며 원형 후광만으로 몸 광원을 대체하지 않는다. 원본 PNG에 빛을 구워 넣거나 갑옷을 재생성하지 않는다.

GSAP의 동일 시간으로 맥동·스킬 강화·입자를 제어한다. 정지/취소하면 이동·타격·입자·예약 음향은 정리하고 승인 SD와 고정된 기본 광원으로 복귀한다. 광원 체크로 전체 ON/OFF 비교 가능. 종료 때 복사본·필터를 정리하며 공유 텍스처는 보존한다.

## 실제 런타임

- 잠금 버전: **PixiJS 8.20.0 / GSAP 3.13.0** (`package-lock.json`).
- 구현: `source/IceDualSwordFX.js`, `skill.mjs`, `source/preview.js`, `source/CueAudio.js`.
- 공용 `preview/project-v-v3/source/battle/BattleEngine.js`, 아트 어댑터, 기존 진형, `battle-v3-live.js`와 카드 프레임 도크 재사용. 새 Pixi Application이나 별도 진형을 만들지 않았다.
- 일반 카드 5장 + 별도 용병 1개. 용병은 `engine.allies`의 여섯 번째 카드가 아니다. 연출이 서버 피해·승패·재화를 다시 계산하지 않는다. 실제 판정은 신규 `_mercenary_cryvern.js`가 기존 서버 전투 엔진의 RNG·피해·KO 경로로 처리한다.
- `engine.simpleTimelines`에 등록된 단일 GSAP 타임라인. 0.25/0.5/1/2배속·정지·앞뒤 시킹·취소·대상 소멸·화면 이탈 정리. 자동 재생용 별도 Ticker 없음.
- 발바닥·검끝 등록으로 상대 몸통에 실제 검끝을 맞춘다. 타격 시각에 접촉 포즈와 해당 FX의 피크를 선택한다.
