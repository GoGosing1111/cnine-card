`npm run prepare:cryvern` / `npm run test:cryvern`. 기존 연출 화면 외에 [실제 전투 판정 재생](./combat.html)을 추가했다. 동일 덱 8,192판 로컬 PVP 비교에서 라그니엘 상대 승률 53.34%. 운영 승률 보장은 아니다.

- 사용자 선택 원본은 `redesign/user-selected-standing-source-art.png`에 무변형 보존했다. 내장 ImageGen 편집 결과는 1024×1536 sRGB RGB PNG이며 SHA-256은 `321600E04E4CDB3ABD9D35CCEEFCF4AFBD9F34AED73ABD5A8AD038123A999535`다.
- 선택 및 국소 수정 기록: `redesign/review-v3.json`. 정확한 편집 프롬프트: `redesign/prompt-standing-crest-v3.txt`.

## 재개된 전투 리소스 · 팔 수정 검수

- 승인 원화 V3에서 오른쪽을 향한 성인형 전투 SD를 새로 제작했다. 새 SD V3은 `팔 이상해 다시`, V4는 `왼쪽 팔 이상함`으로 반려되어 `assets/rejected/`에 보존했다.
- 최신 수정본: `assets/ice-dual-sword-sd-v5-left-arm-corrected.png`. 화면 왼쪽 팔의 어깨 아래부터 팔꿈치·손목·손잡이 연결을 다시 그리고 손을 허벅지 앞쪽으로 옮겼다. 해당 검은 파지에 맞게 이동했다.
- 내장 ImageGen 사용. 프롬프트는 `prompts/sd-v3-side.txt`, `sd-v4-arms.txt`, `sd-v5-left-arm.txt`다. V4를 V5 국소 수정 대상으로만 사용했으며 반려본으로 연속 모션을 만들지 않았다.
- V5는 1254×1254 실제 RGBA, 투명 비율 73.70%, 외곽 4px 가시 픽셀 0개다. PNG 생성 원본을 그대로 저장했다. 해시와 현재 상태는 `sd-review.json`.
- V5도 후속 반려됐다. 원화 자세 추출 V6은 외곽 여백 기술검수에 실패했으며 선택하지 않았다. 생성 프롬프트와 폐기 이유는 보존한다.
- **현재 검수본은 `assets/ice-dual-sword-sd-v7-forward-blade.png`**다. 사용자가 지정한 대로 왼손 검날을 왼쪽 아래가 아닌 몸 앞 오른쪽 아래로 향하게 바꾸고 손목·파지를 수정했다. `prompts/sd-v7-forward-blade.txt`, 1254×1254 RGBA, 투명 비율 72.76%, 외곽 가시 픽셀 0개다.
- 이후 사용자의 `그래 맨 마지막꺼 승인하고 다음꺼 만들으라고 스킬하고 모션들 라그니엘 리소스 퀄리티랑 똑같이`로 **V7이 승인됐다**. 현재 모션 54프레임·효과 80프레임의 독립 검수판을 준비했다. 승인 원화와 SD는 분리·보존한다.

## 미정 / 연결 보류

이름·칭호·용병 코드·능력치·스킬 배정·획득 정책은 미정이며 자동 지정하지 않는다. 전투 SD V7은 후속 승인됐고 신규 모션·효과는 독립 검수판으로만 연결한다.

이번 승인은 **원화 선택과 SSS 등급 확정**이다. 라이브 도감 공개·전투 연결·배포 승인이 아니므로 기존 로스터, 운영 코드, 기능 플래그와 DB를 변경하지 않는다. 160px 축소 및 실제 카드 프레임 합성 검수는 향후 카드 연결 전 수행하며, 사용자 원화 승인과 기술 출시 검수를 분리한다.

기계 판독용 기록은 `approval.json`. 생성 당시 프롬프트와 미선택 원본은 `output/imagegen/ice-crystal-dual-sword-20260922/`에 보존되어 있다.

## 신규 원화 재설계 후보

- 사용자가 정면 SD의 전투 방향을 지적한 뒤, `일러스트를 새로 만들어 서있는 자세로 디자인만 참고해서 너만의 그림을 만들어`로 새 원화를 요청했다.
- `redesign/standing-original-source-art-v1.png`: 서 있는 성인 전신, 오른쪽을 향한 투구, 새 갑옷 구조·쌍검 배치·빙하 성벽 배경을 설계한 신규 원화. SD가 아니다.
- ImageGen 스킬 / 내장 ImageGen 사용. 작화 참고는 라그니엘 원화, 디자인 모티프 참고는 최초 첨부 JPG. 이전 SD나 생성 원화의 자세 수정 방식은 사용하지 않았다.
- 프롬프트: `redesign/prompt-standing-original-v1.txt`. 메타데이터·해시·검수 상태: `redesign/review.json`.
- 1024×1536 sRGB RGB PNG 생성 원본을 무변형 보존. 사용자 승인 대기이며 기존 승인 원화와 등급 기록을 덮어쓰지 않았다.
- 이 새 원화의 SD·모션은 아직 제작하지 않았으며 기존 반려/검수 대기 SD의 동작 제작도 진행하지 않았다. 라이브 변경 없음.
