# 몬스터·레이드 V3 기본 SD 36종

승인 원화 36종을 기준으로 제작한 정지형 전신 SD 검수판이다. 토벌 29종(38개 데이터 항목)과 레이드 7종을 포함한다. 노말 18개 항목과 빅물개는 제외한다.

- `index.html`: 승인 원화·SD 비교, 분류/검색, 이전/다음, 확대, 투명/전장/밝은 배경, 크기 조절과 좌우 보기.
- `manifest.json`: 선택된 SD 36종의 원본 경로·SHA-256·대응 ID·실제 프롬프트·알파 검수·원화 승인 연결.
- `assets/`: 내장 `image_gen`이 생성한 1254×1254 투명 PNG 원본. 재압축·수동 배경 제거·가로세로 비율 변형 없이 보존한다.
- `prompts/`: 생성 요청 38회 기록. 키르안은 전신/검 끝 여백을 보정한 V2, 네리크는 원화에 없던 검을 제거한 V2를 선택한다. 최초 시안은 제작 이력으로 남긴다.
- `generation-plan.json`: 최종 선택 36종에 실제 사용한 프롬프트와 참조 목록.
- `qa/`: 원본 해시·알파 검사, 시각 검수 기록, PC·모바일 화면 및 조작 확인.

원화의 얼굴·피부색·연령·머리·의상·무기 특징을 유지하면서 작은 전투 크기에서 구분되는 비율과 실루엣으로 제작했다. 승인 원화 자체는 수정하지 않았다. 이름은 사용자 후속 요청에 따라 칭호를 뺀 2~3글자 새 가칭으로 교체했다. `names-v2-20261013.json`에 새 이름 34개와 36종 대응표·기존 이름 중복 검색 범위를 기록한다. 원화·SD의 현재 이름은 각 manifest를 따르며 생성 당시 프롬프트와 파일명은 유지한다.

현재 결과는 기본 전신 1장씩이다. SD는 사용자 검수 대기이며 대기/공격/피격/사망 모션·스킬 효과·런타임 바인딩은 완료 상태가 아니다. 실제 게임 연결 때 동작 아틀라스와 프레임별 발 기준점을 확정한다. 현행 ID·스킬 성능·보상·DB·출시 플래그는 변경하지 않았다.

자산 검증 및 색인 재생성: 저장소 루트에서 `node preview/monster-original-ip-sd-20261013-v1/build-manifest.mjs`.
