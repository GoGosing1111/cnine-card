# 헬리오스-R · 솔라 오버드라이브

헬리오스-R을 차고에 장착하면 내 출전 용병의 공격력과 방어력이 전투 시작부터 각각 **10%** 오른다. 두 명을 편성하면 각 용병에게 한 번씩 적용한다. [차량별 수치와 적용 전장](../aether-zero-support-v1/README.md)

황금색 게이트가 열리면 헤드라이트 두 줄이 바닥을 훑고 차체가 미끄러져 들어온다. 차가 가속하며 남긴 연무가 흩어지면 용병의 발밑에 주황빛 터빈이 켜진다. 기본 공격을 주고받는 순간 해당 용병의 터빈이 밝아진다. [헬리오스-R 원화](../../assets/effects/helios-r-v1/manifest.json) · [공통 등장·퇴장 원화](../../assets/effects/vehicle-transit-v1/manifest.json)

저장소 루트에서 `node preview/equipment-sets-v3-20261019/serve.mjs`를 실행하면 헬리오스-R의 등장·퇴장과 족로·흑월의 적중 장면을 다시 볼 수 있다. [헬리오스-R 전용 시연](http://127.0.0.1:3556/preview/helios-r-support-v1/) · [무한의 탑에서 보기](http://127.0.0.1:3556/preview/aether-zero-support-v1/?mode=tower&vehicle=helios)
