## 스킬 동작과 수치 시안

**금란 연사**: 현재 행동 안에서 주 대상에게 빠르게 6연사하고, 마지막 탄이 붉은 에너지 꽃잎과 금빛 파편으로 퍼져 주변 적 2명까지 타격한다.

| 항목 | 검수용 시안 |
| --- | --- |
| 주 대상 | 첫 5탄 각각 44%, 마지막 탄 100%, 합계 320% |
| 주변 적 | 마지막 탄에 최대 2명, 각각 40% |
| 전체 상한 | 공격력 기준 합계 400%; 단일 대상은 320% |
| PVP | 피해 예산 82%: 전체 최대 328%, 단일 262.4% |
| 비용 / 재사용 | 25 / 5턴, 시전당 한 번 |
| 조건 | 별도 준비 턴·체력 조건·전탄 명중 조건 없음 |
| 중단 | 사망·기절·침묵·주 대상 소멸 시 남은 공격 취소 |

주변 적이 없을 때 미사용 피해를 주 대상에게 몰아주지 않는다. 방어 무시, 최대 HP 비례 피해, 기절, 추가 행동, 타격별 자원 회복과 스킬 재발동을 추가하지 않았다. 회피·보호막·피해 경감은 운영 전투의 기존 규칙을 사용한다.

참고 비교: 2026-09-19 최신 작업 트리의 `shared/mercenary-hi-heeya-v2118.mjs`는 SS 하이희야 단일 피해 계수 4.2, 비용 25, 재사용 5턴이다. 본 시안의 PVE 전체 합계는 4.0, 단일 3.2로 두고, SS 원거리 재조정 취지를 반영해 PVP 계수 .82를 별도로 둔다. 이 예산은 후속 등록 승인에 포함됐다. 실전 승률을 보장하는 수치는 아니며 방어·명중·피해 상한·획득 및 CMS 연결은 별도 회귀 테스트와 실제 V3 전투로 검증했다.

## 연속 이펙트와 공용 런타임

- 개화탄은 준비→압축→접촉→꽃잎 파열→분해→소멸의 서로 다른 16프레임이다. 단일 그림 확대·회전이나 기존 효과 색상 변경으로 대체하지 않았다.
- 생성 원본은 1254×1254 RGBA로 보존했다. 4×4의 실제 경계를 반올림해 추출하고 384px 셀로 투명 패딩한 무손실 WebP 아틀라스를 사용한다.
- 실제 렌더링: `source/MangisaSkillFX.js`, 부팅·조작: `source/preview.js`.
- 공유 엔진: `preview/project-v-v3/source/project-v-pixi-battle.src.js`, `BattleEngine.js`, `BattleCharacter.js`, 기존 V3 아트 어댑터·카드 도크·진형을 그대로 사용한다.
- 잠금 버전: **PixiJS 8.20.0 / GSAP 3.13.0**. 별도 CDN 또는 추가 Pixi Application을 만들지 않았다.
- 한 GSAP 타임라인을 `engine.simpleTimelines`에 등록한다. 프레임·총구·탄도·충돌·소멸은 이 시계만 샘플링하며 Pixi AnimatedSprite 자동 재생을 쓰지 않는다.
- 발사: 0.42 / 0.56 / 0.70 / 0.84 / 0.98 / 1.23초. 탄도 75ms, 마지막 접촉 **1.305초 / 이펙트 프레임 4**. 총 길이 2.85초.
- 총구는 프레임별 정규화 좌표를 스프라이트 로컬→월드→기존 효과 레이어로 변환한다. 충돌은 대상 몸통 기준점이다.
- 타격 피해는 순수 모의 계획에서 미리 계산해 시킹에도 중복 누적하지 않는다. 운영 서버 피해·승패를 클라이언트에서 계산하지 않는다.
- 사운드는 **무음 시각 검수본**이다. 합성 테스트음을 넣지 않았다.

- 0.25배속 재생, 일시정지 시각 고정, 2배속 재개, 마지막 타격 시킹과 재시작을 확인했다.
- 완료 후 표시 효과 0개·등록 타임라인 0개를 확인했다. 완료 타임라인 1개는 재생용으로 보관하고, 중지 시 소유 타임라인까지 제거한다. 화면 이탈 정리 코드는 구현했으며 실제 페이지 종료 후 메모리 검수는 별도로 수행하지 않았다.
- 초기 검수에서 잡은 프리뷰 뷰포트 모듈의 DOM 준비 오류와 사격 중 SD 축소를 수정했다. 공용 엔진의 미사용 보스 아틀라스 캐시 경고는 별도 기존 경고로 남는다.
