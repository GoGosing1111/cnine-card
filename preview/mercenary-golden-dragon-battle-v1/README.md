# 천룡검황 진무 · SSS LIMITED 전투 리소스

2026-10-12 제작. 자연스러운 머릿결 V2 원화를 기준으로 흑백 도포, 용 견갑, 긴 직선 검, 황금 동양 용을 전투 리소스로 제작했다. 이름과 스킬명은 연출 구분용 가칭이다.

사용자 후속 지시를 반영해 **전체 화면을 덮는 플래시·안개·암전 오버레이를 제거**했다. **캐릭터의 용과 금린 아우라는 불투명도 100%**다. 아우라는 원화 프레임을 직접 교체하며 반투명 크로스페이드를 사용하지 않는다. 부드러운 외곽 광원의 원본 알파는 유지한다.

## 구성

| 분류 | 시퀀스 | 재생 프레임 |
|---|---|---:|
| 캐릭터 | 대기, 대시, 검격, 스킬 시전, 광역기, 피격, 쓰러짐 | 40 |
| 이펙트 | 금린 아우라, 대시 잔광, 용형 검기, 황금 용, 충전 문양, 광역 용강림, 충돌 | 84 |

- `assets/sources/`: 무가공 생성 원본. 투명 전신 마스터와 전체 모션·이펙트 시트를 보존한다.
- `assets/frames/`: 개별 투명 PNG 124장. 모션 768×768, 이펙트 512×512.
- `assets/atlases/`: 모션 7종(2304×1536), 이펙트 7종(2048×1536).
- `references/`: 기준 원화 V2 원본 사본. 원본 SHA-256을 보존했다.
- `manifest.json`: 파일·해시·프레임 수·발 접점·배율·이펙트 경계 색인.
- `landmarks.json`: 원본 프레임별 신체 높이와 발 좌표.
- `prompts/`: 내장 이미지 생성 도구에 전달한 프롬프트와 입력 경로.
- `source/`, `skill.mjs`: 기존 V3 엔진용 연출 코드와 타임라인.
- `qa/`: PC·모바일 캡처, 실제 V3 재생 영상, 검사 기록.

모션 원본 42프레임과 이펙트 원본 84프레임을 생성했다. 원본 경계에 검끝이 닿은 대시 1장과 발끝이 닿은 피격 1장은 재생에서 제외하고 원본에는 남겼다. 검격의 최초 여백 부족 시트도 별도로 보존했다. 개별 신체 부위를 휘거나 늘리지 않고, 온전한 캐릭터를 공통 발 접점에 배치했다.

## 연출

| 가칭 | 동작 |
|---|---|
| 용혼 | 불투명한 황금 용과 금린 고리가 몸의 뒤·앞을 감싼다. |
| 용린보 | 몸을 숙여 가속하고 금린 잔광과 함께 착지·복귀한다. |
| 금룡일섬 | 접근 → 검 준비 → 직선 검의 접촉과 용형 검기 → 복귀. |
| 용령파 | 손짓과 충전 문양 → 황금 용의 관통 → 적진의 연속 충돌. |
| 천룡강림 | 검을 들어 봉인 해제 → 내려치기 → 용강림·금린 폭쇄·3단 충격파. |
| 피격·쓰러짐 | 충격을 받아 회복하거나 검에 의지해 무릎을 꿇는다. |

원화 컷인과 카메라 흔들기는 ‘동작 줄이기’에서 꺼진다. 광역기의 용 머리·뿔·폭발은 실제 알파 경계를 기준으로 PC·모바일 전장 안에 배치한다. 효과음은 기존 V3 자산을 재사용하며 기본 OFF다.

## 프리뷰

프로젝트 루트에서 실행한다. 기존 PixiJS 8.20.0·GSAP 3.13.0과 V3 전장·카드·용병 아트 어댑터를 재사용하므로 원 프로젝트 안에서 실행한다.

```powershell
node preview/mercenary-golden-dragon-battle-v1/serve.mjs
```

브라우저: `http://127.0.0.1:8876/preview/mercenary-golden-dragon-battle-v1/`

전체 시연, 동작별 선택, 재생·일시정지, 구간 이동, 0.25~2배속, 타격 순간, 아우라·효과음, 동작만 보기, 중단·대상 소멸을 확인할 수 있다. 기존 양측 카드 5장을 유지하고 용병은 별도 슬롯에 표시한다. 21.55초짜리 전체 시연의 실제 V3 녹화는 `qa/full-showcase.webp`다.

## 검수 및 재현

```powershell
node preview/mercenary-golden-dragon-battle-v1/build.mjs
node --test preview/mercenary-golden-dragon-battle-v1/qa.test.mjs
node preview/mercenary-golden-dragon-battle-v1/qa-runtime.mjs
node preview/mercenary-golden-dragon-battle-v1/record-demo.mjs all
```

범위 검사 3개와 PC 1440×1080·모바일 390×844의 브라우저 검사 22개를 통과했다. 프레임·접촉 시점, 배속·정지, 중단·대상 소멸, 효과음 동기화, 동작 줄이기, 전체 시연 완료, 반복·해제 시 자원 회수를 확인했다. 페이지·자산 오류와 가로 넘침, 검사한 프레임의 핵심 이펙트 잘림은 없었다.

원본에서 재패킹하려면 `build-assets.mjs`를 실행한다. 색 제거·배경 키잉·신체 변형 없이 원래 RGBA를 사용하고, 인접 셀의 다른 그림을 제외한다. 재패킹하면 기술 검수 상태가 대기로 돌아간다.

사용자 후속 지시로 **천룡검황 진무(V-989)** 라이브 연결을 확정했다. 지정 계정 1번에만 1장을 지급하고 일반 획득·리미티드 발행 수량에서 제외한다. 현재 정책·검수는 `docs/jinmu-live-20261012.md`를 따른다. 기존 V-993 프리뷰 식별자는 폐기하며 오리꿍 운영 코드를 변경하지 않는다.
