# 생뷰왕 아바타 — A-16 / SAENGBYUWANG

사용자의 아바타 추가 및 장비창 이미지 제작 요청과 후속 오피스룩·짧은 치마·블라우스 상단 단추 열림·양쪽 얼굴 수정 요청을 반영했다. 용병 로스터와 별도다.

- 로비: 도시 야경의 오피스 일러스트. 첨부된 최초 이미지의 얼굴 분위기를 참고해 수정한 1024×1536 RGB 원본이다.
- 장비창: 로비와 같은 얼굴, 아이보리 블라우스·블랙 미니스커트·힐의 전신. 체크무늬 원본과 실제 투명 PNG를 구분해 보존한다.
- 사용자가 **배경만 스크립트로 제거**를 승인했다. 해당 원본에서 측정한 중성색 배경을 연결 영역으로 제거하고 2px 경계를 매팅했다. 완전 불투명 인물 픽셀의 RGB 변경은 0이다.
- 기존 아바타 API의 로비 1024/640px WebP 및 장비 640px WebP 필드에 연결한다.

기존 신규 아바타 방식대로 CMS에서 설정할 수 있게 등록한다. 데이터 사용·유저 공개·판매는 OFF, 획득 방식·가격·효과는 미설정이다. 등록을 반복해도 운영자 설정과 기존 아바타를 덮어쓰지 않는다.

검수 화면의 장비창 탭은 실제 운영 character-loadout-v2 렌더러와 CSS를 사용하고 별도 검수 데이터만 제공한다. 계정 장착·보유 장비는 변경하지 않는다. 원본과 파생본 해시는 manifest.json, 최종 생성 프롬프트는 final-prompts.md에 기록한다.

장비 원본 PNG는 1024×1536을 유지한다. 운영 WebP는 인물을 변형하지 않고 좌우 투명 여백을 잘라 640px 폭으로 만들며, 하단 128px 투명 여백을 추가해 총 640×1664다. 기존 장비창의 인물 영역에 크게 들어가고 하단 정보판 위로 신발이 보이도록 맞췄다. 1280px 데스크톱과 390px 모바일에서 이미지 로딩, 가로 넘침, 배경 전환, 장비창 탭과 전신 배치를 확인했다.

검증: node --test tests/avatar-saengbyuwang-cms.test.mjs preview/avatar-saengbyuwang-v1/qa-assets.test.mjs, npm run test:avatar, npm run release:gate.
