- 기준 원화: `assets/rank-chart-square-source-v3.png`. 21개 정사각형 계급표 V3 생성 원본을 바이트 그대로 보존했다.
- 원본 SHA-256: `0a8acfb26f3ea2c9865133952ff73d451087185c73a88670fa78fa87eafe7b15`.
- 대령, 준장, 소장, 중장, 대장, 원수 6종에만 별도 Canvas 광원 계층을 그린다. 사각 칸 바깥과 다른 15개 계급의 픽셀은 바뀌지 않는다.
- 상위 계급으로 갈수록 순환 광원 1/2/2/3/4/5개, 입자 3/5/9/14/20/30개, 문양 광택과 별 반짝임이 강화된다. 중장부터 모서리 전류, 대장부터 내부 광선, 원수에 오성 연쇄 반짝임과 백금 섬광을 더한다.
- 반복 주기 6초. GIF/애니메이션 WebP는 100프레임, 프레임당 60ms, 무한 반복. 계급장 개별 파일은 256×256이다.
- UI 미리보기: `index.html`. 일시정지, 이펙트 ON/OFF, 동작 줄이기 설정, 비활성 탭/화면 밖 렌더링 절약을 제공한다. 오디오 없음.
- 비교 GIF: `exports/rank-effects-six.gif`. 개별 리소스: `exports/*-loop.webp`.
- 검수: `qa/report.json`, `qa/desktop.png`, `qa/mobile.png`. 반복 경계 일치, 효과 영역 밖 픽셀 불변, 단계별 효과량 증가, 모바일 가로 넘침 없음, 브라우저 오류 없음 확인.
- 계급 경험치·효과 수치 개편과 실제 게임 계급장 교체는 이 그래픽 시안에 포함하지 않는다.

로컬 확인: `node review.mjs --serve` → `http://127.0.0.1:8873/`.
다시 내보내기: `node --max-old-space-size=4096 review.mjs`.
빌드 도구는 번들된 Playwright/Sharp와 설치된 Chrome을 사용한다. 다른 환경에서는 `RANK_FX_NODE_MODULES`로 패키지 경로를 지정한다.
