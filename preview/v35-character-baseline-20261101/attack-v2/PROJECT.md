## 수정 내용

앞무릎의 기존 축은 원화 y1004에 있어 실제 무릎보다 아래에서 꺾였다. 새 축은 (758,935)다. 뒷다리 IK는 큰 굽힘에서 무릎이 반대 방향으로 돌았으므로 앞을 향해 굽히도록 수정하고 축을 (301,1055)로 다시 잡았다. 양 무릎에 보조 뼈를 추가해 허벅지와 종아리 사이의 면적을 유지한다. 단순히 이동량만 줄여 오류를 숨긴 수정이 아니다. [리깅 코드](prepare-leg-rig.mjs).

몸통은 기존 ImageGen 보완 원화 `../attack-v1/sources/body-no-coat-registered.png`를 재사용했다. 기술적 사각 자르기만 수행한 완전한 몸통·다리 부품으로 교체해 이전 선택 경계의 코트 잔여 조각을 제거했다. 따라서 현재 몸통/머리가 기준 PNG의 픽셀 그대로라는 주장은 하지 않는다. 기준 PNG와 이전 네이티브 파일, 수정한 칼 원본은 변경하지 않았다. 새 래스터 생성·Krita·Effekseer 작업은 이번 수정에 사용하지 않았다.

29뼈·11부품이며 `setup` 0.1초, `idle` 4.2초, `attack_basic` 1.12초다. 앞발은 0.12~0.31초에 전진하고, 0.31초 착지 후 0.34초 베기 접촉으로 이어진다. 0.34~0.38초 접촉 자세를 유지하고 후속 동작 뒤 0.70~0.96초 회수 디딤으로 복귀한다. 어깨→팔꿈치→손목의 시간 차, 몸통 선행과 머리 반작용, 늦게 따라오는 코트가 포함된다. 코트는 허리 뼈에서 전체 방향을 움직이고 끝단의 변형은 작게 나눠 면이 접히는 현상을 수정했다.

## 작업 방식과 확인 범위

사용자 **“내 화면 계속 방해받는데 따로 작업 못함?”** 이후 편집기·마우스·키보드·사용자 브라우저 조작을 중단했다. 이 정본은 파일 작성 → 숨김 Spine CLI import/save/reopen/export → 화면 없는 Chrome에서 공식 Spine 런타임 검수로 제작했다. 그 전에는 이전 `06c1f1563f47`을 GUI에서 열어 자세를 확인했으나 새 정본을 GUI로 편집하거나 검수했다고 기록하지 않는다.

Spine에는 편집기 내부 뼈/메시/키 편집을 호출하는 지원되는 외부 자동화 API가 없다. 공식적으로 지원하는 데이터 수정 후 import와 CLI 배치 작업을 사용한다. [공식 답변](https://esotericsoftware.com/forum/d/29562-spine-cli--mcp-automation-and-json-round-trip), [CLI 문서](https://esotericsoftware.com/spine-command-line-interface).

- 네이티브 저장/재열기/내보내기 및 스켈레톤 하나·세 애니메이션 확인.
- 225시점에서 보이는 삼각형 뒤집힘 0, 비정상 좌표 0, 접지 구간의 발 이동 0.000001px 미만, 손목/발목 체인 끝 오차 0.000009px 미만. [수치 검사](qa/geometry.json). 이 결과만으로 동작 품질을 합격 처리하지 않는다.
- 정상 속도 세 번 공격→대기, 착지/타격/회수 이벤트 각 세 번, 정지/탐색/배속/비활성 복귀/중단 확인. [실행 검사](qa/playback.json).
- 전신 준비·착지·접촉·후속·회수와 30fps 간격의 무릎 34장, 밝고 어두운 배경을 이미지로 검토했다. 정상 속도 영상은 실제 실행을 녹화한 것이며 사람이 연속 감상한 검수로 기록하지 않는다.
- 390px 브라우저 화면·오류 없음 확인. 실기기 성능 검사는 수행하지 않았다.

사용자 시각 승인은 미수신이다. 이번 범위는 몸과 검의 기본 공격 수정이며, 대표 스킬·연속 이펙트·피격 반응·사운드·실전 액터 연결을 완료하거나 던전앤파이터급 전투 완성으로 판정하지 않는다.

## 재현

기존 프로젝트의 의존성과 설치된 Spine을 사용한다. `prepare-leg-rig.mjs` → `author-motion.mjs` → `native.mjs` → `build.mjs` 순서로 실행한다. `serve.mjs` 실행 후 `qa/inspect.mjs`, `qa/playback.mjs`, `qa/delivery.mjs`를 실행한다. 네이티브 파일이 사용자가 편집한 해시로 변경됐으면 생성 스크립트는 중단한다. 부모 정본과 이미지 디렉터리는 상대 경로 의존성이므로 함께 보존한다.
