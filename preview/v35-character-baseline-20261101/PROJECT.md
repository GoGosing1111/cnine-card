# V3.5 새 캐릭터 전신 기준안

2026-11-01. 사용자 지시: **“새 캐릭터로 처음부터 기준점부터 다시 잡아가라.”**

현재 기준 후보는 [baseline-v3.png](baseline-v3.png)다. 새로 디자인한 흑발·붉은 코트·강철 보호구·직선 한손검의 성인 남성 검사다. 오른쪽을 향하는 전투 대기 자세로 체형·시점·손과 무기·다리 지지를 검토한다. 이름·등급·능력치는 정하지 않았다.

**상태: 전신 원화 후보 / 사용자 시각 승인 전.** 부품 분리·Spine 리깅·대기/공격 모션·이펙트·실제 전투 연동·운영 등록은 아직 없다. 던전앤파이터급 전투 품질을 입증한 결과가 아니다. 기존 진 족로의 승인 V7과 반려된 조립/모션 이력은 보존하고 작업을 자동 재개하지 않는다.

## 이번에 확인한 것

- 세 후보를 직접 열어 전신·얼굴·손·검·다리를 확인했다. V1/V2의 카드 일러스트에 가까운 선 자세에서 V3의 무릎을 굽힌 전투 자세로 바꿨다.
- V3는 머리·몸통·양팔·양다리와 검 전체가 한 그림에 연결돼 있다. 이전 부품 조립을 재사용하지 않았다.
- 1024×1536 RGBA PNG와 파일 해시를 확인했다. 생성 원본을 픽셀 변경 없이 복사했다. 실제 제작 도구는 built-in ImageGen이며, Krita·Effekseer·Aseprite·Spine으로 이 그림을 만들었다고 기록하지 않는다.
- 알파 0인 투명 픽셀은 존재하지만 캐릭터 최대 알파는 254다. 완전 불투명 픽셀 255가 없는 생성 결과이므로 최종 게임 컷아웃의 알파 검수 통과로 간주하지 않는다. 생성 알파를 임의 수정하지 않았다.

## 아직 확정하지 않은 기준

- 이 외형과 전투 시점의 사용자 채택 여부.
- 양발 접지 피벗·바닥 좌표·손 파지점·검 중심선의 정확한 좌표와 실제 V3 표시 크기. 화면상 부츠 바닥에 높이 차이가 남아 있어, 기준 자세 확정 때 원근과 접지 조건을 함께 정리해야 한다.
- 밝고 어두운 전장 배경에서의 알파 가장자리·몸 내부 불투명도, 분리 후 가려진 관절의 보완 범위.
- 대기·공격의 힘 전달, 관절 극한 자세, 정상 속도 재생과 전장 가독성. 정지 원화로 이를 통과했다고 판단하지 않는다.

## 다음 제작 순서

1. 전신 후보의 체형·얼굴·시점·의상·무기·기본 자세부터 맞춘다. 후보를 승인 원본으로 자동 승격하지 않는다.
2. 기준이 정해지면 필요한 부품을 분리·보완하고 동일한 자세로 다시 조립한다. 원화와 같은 크기로 나란히/겹쳐 비교해 실루엣·부품 크기·관절 연결을 먼저 검수한다.
3. 네이티브 import/save/export 후 실제 표시 배율까지 확인한다. 검수 전 조립 프리뷰를 자동으로 열지 않는다.
4. 대기 한 동작, 기본 공격, 대표 스킬 순으로 진행한다. 몸과 무기를 확인한 뒤 효과를 더한다.

V1은 기존 진 족로 이미지를 입력으로 쓰지 않은 신규 생성이다. 프로젝트 원화 규정의 스타일 참고를 눈으로 확인했으며, ImageGen 입력은 V1 없음 → V2에 V1 → V3에 V2다. V3는 V2의 픽셀 보존 편집이 아니라 같은 디자인을 참고한 자세 재작화다. 전체 프롬프트와 생성 원본은 보존한다.
