# V3.5 새 캐릭터 전신 기준안

2026-11-01. 사용자 지시: **“새 캐릭터로 처음부터 기준점부터 다시 잡아가라.”**

현재 작업 기준은 [baseline-v4.png](baseline-v4.png)다. 새로 디자인한 흑발·붉은 코트·강철 보호구·직선 한손검의 성인 남성 검사다. 사용자 후속 **“어 해봐”**에 따라 이 그림으로 부품 분리·정지 조립·호흡 대기를 진행했다. 이름·등급·능력치는 정하지 않았다.

**현재 상태: 칼 추출 수정 및 기본 베기 팔 동작 수정안.** 후속 “해봐 그럼”에 따라 공격을 만들었으나, 사용자가 칼 추출 오류와 “팔이 각목” 같은 움직임을 지적했다. 이전 칼과 첫 베기는 반려 이력으로 보존한다. [현재 편집 파일·영상·검수](attack-v1/PROJECT.md)는 갑옷/소매 분리, 어깨→팔꿈치→손목 순서와 타이밍을 다시 만든 1.2초 베기 수정안이다. 기술 검사와 선택 자세 확인은 수행했으며 사용자 시각 승인·던전앤파이터급 달성·운영 연결은 아직 없다.

## 기준 원화 제작 당시 확인한 것

- 네 후보를 직접 보고 전신·얼굴·손·검·다리를 확인했다. V1/V2의 카드 일러스트에 가까운 선 자세에서 V3의 무릎을 굽힌 전투 자세로 바꿨다.
- 작업 도중 갱신된 [최신 작화 규정](../../docs/project-v-mercenary-card-art-standard.md)의 두 스타일 참고와 승인 백색 외투 V2를 직접 열었다. V4는 승인 V2를 마감 참고로 사용해 바지·코트의 잔주름 음영과 금속 잔선을 정리한 후속 후보다. 다른 인물의 승인 범위를 새 검사에 적용하지 않는다.
- V4는 머리·몸통·양팔·양다리와 검 전체가 한 그림에 연결돼 있다. 이전 부품 조립을 재사용하지 않았다.
- 1024×1536 RGBA PNG와 파일 해시를 확인했다. 생성 원본을 픽셀 변경 없이 복사했다. 실제 제작 도구는 built-in ImageGen이며, Krita·Effekseer·Aseprite·Spine으로 이 그림을 만들었다고 기록하지 않는다.
- 알파 0인 투명 픽셀은 존재하지만 캐릭터 최대 알파는 254다. 완전 불투명 픽셀 255가 없는 생성 결과이므로 최종 게임 컷아웃의 알파 검수 통과로 간주하지 않는다. 생성 알파를 임의 수정하지 않았다.

## 기준 원화와 과거 대기 단계의 검증 이력

- 이번 제작 진행 지시와 결과물의 최종 시각 승인을 구분한다.
- 원화상의 발·파지·칼끝 좌표는 [rig-map.json](rig-v1/sources/rig-map.json)에 기록했다. 두 발의 원근에 따른 y 차이를 그대로 유지하며 실제 V3 전장 바닥·좌우 반전·표시 크기는 후속 연동에서 확인한다.
- 밝고 어두운 정지 조립과 대기 주요 시점을 확인했다. 원본 최대 알파 254는 보존했다. 모든 전장 배경에서의 최종 알파 품질 승인과는 구분한다.
- 숨겨진 관절의 보완 작화, 큰 체중 이동, 공격의 준비·접촉·회수와 실제 전장 가독성은 남아 있다. 현재 대기는 하체·검을 고정한 작은 상체 호흡이다.

## 최초 제작 순서 · 후속 작업은 현재 PROJECT.md 참조

1. 정지 조립·호흡 대기 전달본에서 체형과 연결을 유지한다. 후보를 최종 승인 원본으로 자동 승격하지 않는다.
2. 기본 공격의 주요 자세를 설계하고 움직일 때 드러나는 몸·관절·손의 보완 작화를 만든다. 원본 픽셀만 분리한 현재 부품을 과도하게 늘리지 않는다.
3. 준비 → 베기 → 접촉 → 회수 → 대기 복귀를 몸과 무기만으로 확인한다.
4. 대표 스킬과 연속 효과를 붙이고 실제 전투 연동·가독성을 별도로 검수한다.
