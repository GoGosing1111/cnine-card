- 화면: `skills.html` (배포 URL은 `/preview/project-v-mercenary-system-v1/skills`)
- 설계 기준: `docs/project-v-mercenary-skills-v1.md`
- 16개 고유 동작, 16개 개별 ImageGen 투명 소재, 48개 상황, 브라우저 CMS 의견 초안.
- 상태: 검수 전용, 실제 계정·운영 전투·등급·획득 미연결. 무음.

## 실제 사용 기록

PixiJS 8.20.0 / GSAP 3.13.0 (`package-lock.json`). `source/skills-lab.src.js`가 기존 V3 엔진·카드 도크를 마운트한다. `source/MercenarySkillFX.js`가 기존 `effectLayer`에 Pixi Sprite를 붙이고, V3 취소 목록에 등록한 GSAP 시계 1개로 재생한다. 신규 렌더러 또는 CDN 사본은 없다.

소재는 `skill-assets/manifest.json`에 원본·변환 해시, 알파, 프롬프트와 생성 방식을 기록한다. 캐릭터 원화·SD는 기존 승인 로스터에서 읽는다. 용병은 일반 5인 배열 밖의 별도 객체다.

시각은 초 단위이며 단계·충돌 시점은 `shared/mercenary-skills-v1.mjs`의 기술별 `visual`이다. 몸통 충돌점은 발 원점에서 `fullBodyHeight × root.scale.y × 0.54` 위다. 발은 승인 `footAnchor`를 사용한다. 이동·회전·투명도·배속·일시정지·탐색은 한 GSAP 시계에서 샘플링한다. 첫 충돌 버튼은 충돌 직후 80ms의 효과를 보여준다. 취소 시 시각 0·원래 위치·효과 0으로 돌아간다. 공유 텍스처는 유지한다.

정량 동작은 `skill-rehearsal.mjs`가 먼저 확정한다. UI/FX는 확정 로그만 재생한다. 예시 숫자는 운영 계수가 아니다. 생성 스프라이트를 합성한 동작 검수이며, 신규 아틀라스 제작·사운드 제작을 포함하지 않는다.

## 검증 기록

기술별 3상황의 결정성·피해 경계·표적 예외·보스 면역, CMS 입력 계약과 Pixi/GSAP 취소·탐색·공유 텍스처 수명을 `tests/mercenary-skills-v1.test.mjs`에서 확인한다. 브라우저·배포 검증 결과는 최종 작업 시 아래에 기록한다.

2026-09-10 실행 결과:

- `npm run build:mercenary-skills`: 독립 번들 빌드 성공. 공유 V3 원본·라이브 번들 변경 없음.
- `npm run test:mercenary-codex`: **132 / 132 통과**. 이 중 신규 스킬 검증 63개이며 정상·약점·보스 48개 시나리오를 포함한다.
- CUA 실제 브라우저: 기본 데스크톱 및 390×844 화면에서 16종씩 선택 → 충돌 확인 → 취소를 수행했다. 전용 Sprite 표시, Canvas 1개, 효과 레이어 1개, 일반 유닛 5개, 독립 용병 1개, 취소 뒤 효과 0·등록 타임라인 0·위치 오차 0을 확인했다.
- 추가 UI 검수: 보스 중단 면역과 준비 기술 없는 대상의 중단 불발, 2배속 재생, 일시정지 시각 유지, 실제 새로고침 뒤 CMS 의견 복원, 빈 이름 저장 차단, 이름 검색과 지원 역할 3종 필터. 테스트 의견은 빈 값으로 되돌려 저장했다. 임시 뷰포트 변경을 해제했다.
- 16개 런타임 WebP 합계 **2,542,762 bytes**, 전부 실제 알파, 512×512, 가장자리 알파 최대 2/255. 황금 방벽의 초기 여백 문제와 재편집본의 불투명 배경을 발견해 새 투명본으로 교체했다. 채택본만 원본 폴더에 보존했다.

브라우저 재생은 스프라이트 동작 검수다. 연속 프레임 아틀라스·신규 사운드·실제 서버 전투 통합의 완료를 뜻하지 않는다.

출시 URL 후속 검수에서 Pages가 `.html`을 제거하면 Pixi의 상대 전장 경로가 `/preview/assets/`로 잘못 해석되는 문제를 발견했다. `skill-asset-base.mjs`에서 기존 V3 디렉터리를 자산 기준으로 고정하고 Pixi 초기화에 전달했다. 확장자 없는 주소와 로컬 `.html` 주소의 동일 해석을 회귀 검증에 추가했다. 기존 V3 엔진·라이브 라우트는 변경하지 않았다.

후속 수정 검증: `npm run test:mercenary-codex` **133 / 133 통과**. Pages와 같은 `.html` 리다이렉트를 사용하는 로컬 서버의 확장자 없는 주소에서 솔바인·베스페라·경찰 조은·동탄 디임의 실제 효과 표시와 취소를 재확인했다. 독립 번들 캐시 버전은 `20260910-2`다.
