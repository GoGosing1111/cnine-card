# 카우방 — 붉은 목초지 V3

2026-09-09 · 전투 구현 완료 · 로컬 체험 편성 · 계정/보상 미연결

2026-09-11: [공통 점유 그리드](../../docs/project-v-common-grid-v1.md)를 기본 적용한다. 증원·KO에 맞춰 실제 자리만 표시하며 모바일은 콘텐츠 높이로 맞춘다. 사용자 지시로 라이브 배포 보류.

## 플레이

`/preview/cow-room-v3-v1/`에서 목초지 진입을 누른다. 일반 젖소 도끼병 18마리(최대 3마리 동시 교전) → 정예 도끼병 3마리(순차 교전) → 카우 킹 1마리. 22마리 모두 격파하면 승리다. 구간 전환 시 아군 체력·방벽·게이지·마법/부활 예산을 초기화하지 않는다. 전멸하거나 서버 행동/시뮬레이션 한도를 넘으면 실패한다.

일시정지/이어하기, 1×/2×, 재시작, 세 가지 체험 전투력을 제공한다. 적은 플레이어와 무관하게 고정이다. 최초 입장의 시드 7123 기준:

| 편성 | 일반 카드 + 슈트 | 결과 | 격파 | 행동 |
| --- | --- | --- | --- | --- |
| 저전력 | 32.5만 | 패배 | 13/22 | 142 |
| 기본 | 130만 | 승리 | 22/22 | 153 |
| 강화 | 260만 | 승리 | 22/22 | 131 |

수치와 적 구성은 전투 검수용이며 운영 경제 정책이 아니다. 실제 도감의 카드 ID·원화·승인 SD·슈트를 사용하는 체험 편성으로, 로그인 계정의 저장 덱이나 재화를 조회하지 않는다. `COW_ROOM_RELEASE_ENABLED=false`이고 운영 메뉴/API에는 연결하지 않았다. 기존 PVE 전체 통합 출시 규칙을 유지한다.

## 한 번 구현해 공통 경로 사용

- `functions/_cow_room_v3.js`는 서버 소유 스냅샷을 받아 정식 `createPveBattleV2`의 `encounter`를 생성하는 순수 함수다. 체험 모델도 이 함수를 그대로 호출한다. 화면에 맞춰 임의 승패·피해·보상을 만드는 로직이 없다.
- 이 페이지의 호출은 **브라우저 로컬 계산**이다. 운영 서버의 인증 입장·스냅샷 저장·정산이 완료됐다는 의미가 아니다. 라이브 연결 시에는 서버가 저장 덱/장비를 조회해 이 함수에 전달하고, 클라이언트는 확정 타임라인만 받아야 한다.
- `scripts/build-cow-room-v3-v1.mjs`는 기존 V3 진입점을 그대로 사용한다. `CowBattleEngine`은 공통 연속 교전 엔진을 상속하고 전장 이미지만 지정한다. 별도 캐릭터 진형·카드 도크·피해 계산기·시간 제어기를 만들지 않았다.
- 공통 엔진의 선택형 `continuousEncounter`와 전장 getter/표시명 설정을 추가했다. 기존 폐차장 기본값은 유지된다. 적 식별자는 `B:{slot}:ENCOUNTER:COW:{instance}`이며 퇴장한 개체 ID를 새 개체로 매칭하지 않는다.
- 같은 적 슬롯의 재사용 전 지원 사격의 실제 탄착을 비운다. 최대 16개 시각 큐에서 역압을 적용하고, 서버 피해·발수는 바꾸지 않는다. 카우 킹은 일반/정예 21마리가 모두 KO된 뒤에만 나온다.

## V3·효과·카드 자산

PixiJS **8.20.0**, GSAP **3.13.0** (`package-lock.json`). 실제 사용 파일은 `source/CowBattleEngine.js` → `../scrapyard-v3-v1/source/ScrapyardBattleEngine.js` → `../project-v-v3/source/battle/BattleEngine.js`다.

- Pixi `effectLayer`와 기존 `BattleEngine.timeline()` GSAP을 사용한다. 증원 진입 0초, 파편 0.08초, 착지 원 0.12초, 진입 완료 0.48초, 약 0.68초 정리. 공유 폐차장 연출을 재사용하며 새 전투 스킬/사운드는 추가하지 않았다.
- 공격/피격/사격/KO는 기존 V3 타임라인의 발사·충돌 기준점과 승인 슈트 아틀라스를 사용한다. 지원 피해는 `SERVER_BATTLE_V2_TIMELINE` 한 경로다. 신규 피해 타이머 없음.
- `battle.html`은 라이브 `battle-v3-live.js`, 공용 `card.css`, 등급별 프레임과 동일한 아트 어댑터 체인을 로드한다. 일반 카드 5장과 별도 배틀슈트. 카드 원화는 도감 원본이며 전투 SD와 분리했다.
- 신규 투명 SD는 도끼병/카우 킹 2종, 배경 1종. SD를 새 카드 원화로 등록하지 않았다. 실제 RGBA 1254×1254, 전체 실루엣이 캔버스 안에 있으며 원본을 재압축하지 않았다. 생성 입력은 `PROMPTS.md`, 원본 경로·해시·크기는 `manifest.json`.
- 일시정지는 현재 공격과 탄착을 마친 경계에서 멈춘다. 재시작/이탈은 실행 세대 번호로 이전 실행을 취소하고 효과와 지원 사격을 정리한다. 무음이며 계정의 라이브 사운드 설정을 바꾸지 않는다.
