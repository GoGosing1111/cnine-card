# 카우방 V3 검증 기록

2026-09-09. 로컬 HTTP 정적 서버, Chromium. 운영 API/계정/재화 검수는 수행하지 않았으며 출시 연결을 뜻하지 않는다.

## 자동 검사

- `npm run build:cow-room-v3`: 성공.
- `npm run test:cow-room-v3`: 6/6 통과. 실제 카드 5장과 별도 슈트, 20시드의 최대 동시 3마리·일반→정예→왕 순서, 고정 적 스펙과 저전력 패배, 잘못된 편성/큰 수치 거부, 실제 투명 알파, 운영 경로 미연결.
- `npm run test:scrapyard-v3`: 60/60 통과. 기존 전투 결과·세대 교체·지원 사격·원정 예약/정산/응답 유실·취소/복구 회귀.
- `npm run test:v3-wide-grid`: 11/11 통과. 공통 진형 크기·슬롯·스케일·타임라인 회귀.
- 새 모듈과 공유 bridge `node --check`, 작업 범위 `git diff --check` 통과.
- 운영 배포는 이번 범위에서 수행하지 않았다. `release:gate` 전체 통과나 라이브 출시 완료로 주장하지 않는다.

브라우저는 일반 URL의 기본 rAF로 검사했고 `backgroundQa=1`을 사용하지 않았다. 모바일은 Chromium 뷰포트 에뮬레이션이며 실기기 FPS/발열 측정 결과가 아니다.

관찰된 비치명 경고: 재준비 시 공통 V3 자산 정리에서 `boss-ultimate-impact-atlas-v2.json?v=2-low-afterimage`가 Cache에 없다는 Pixi 경고 1종. 전투 진행/결과/큐 정리는 정상이며 JavaScript error는 없었다. 이 작업에서 공통 이펙트 자산의 수명 정책을 변경하지 않았다.

## 경계

카우방은 공통 전투 함수와 V3 렌더러를 사용하는 로컬 체험이다. 실제 저장 덱 입장, 운영 CMS, 희귀 드롭, 보상 지급, 모바일 장시간 실행은 통합 출시 전 별도 검수가 필요하다. 무한의탑은 이번에 재기획만 했으며 서버 개편을 완료하지 않았다.
