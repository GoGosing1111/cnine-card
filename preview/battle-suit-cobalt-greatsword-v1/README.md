# 청색·은백색 대검 배틀슈트 — 서 있는 리소스

요청: `바디슈트 리소스 서있는거만 만들어봐 칼 대검으로 착용하고`. 후속 `칼디자인 이거 참고`의 백금색 날·중앙 금색 문양·금빛 가드 대검을 사용한다. 이번 범위는 한 장의 정지 전신 이미지다.

## 2026-10-07 부분 승인과 머리 수정

사용자: `머리 아래로는 다 합격임 근데 머리 뒤에 뿔 없애야하고 내가 보낸 사진하고 너가 만든 리소스랑 얼굴 디자인 디테일 차이가 많이나네`.

- **몸체·대검·파지·자세는 최초 V1에서 승인**됐다. 승인 출처 PNG를 `assets/cobalt-greatsword-standing-v1-body-approved.png`에 무가공 보존한다. 최초 머리는 승인 대상이 아니다.
- 최신 후보 `assets/cobalt-greatsword-standing-v2-head-revised.png`: 뒤통수 위로 길게 솟은 청색 뿔을 제거하고, 최초 갑옷 참고 이미지의 작은 청색 이마 장식·은색 이마/볼/턱 판금 구성을 반영했다.
- 두 결과 모두 내장 `image_gen` 생성 원본을 바이트 그대로 복사한 1024×1536 RGBA PNG다. 실제 알파가 있으며 PNG를 재압축하거나 기존 승인 자산을 덮어쓰지 않았다.
- 몸체와 대검의 외형·배색·서 있는 자세·파지를 나란히 시각 비교했다. V2는 생성 도구의 전신 수정 출력이며 V1 하단 픽셀을 직접 합성한 파일은 아니다. 향후 기존 부위를 수정할 때도 승인 기준은 보존된 V1이다.
- **수정한 머리는 사용자 검토 대기**다. 완성된 모션·아틀라스·스킬 리소스나 V3 연결로 보고하지 않는다. 이름·등급·전투력·CMS·제작식·획득·운영 활성화는 이번 작업 범위에 없다.

원본과 최신 후보의 파일 크기·해시·검수 범위는 `manifest.json`, 실제 사용 프롬프트와 입력 역할은 `prompts.json`에 기록한다. 참고용 사용자 첨부는 원래 로컬 경로와 해시만 기록하며 배포용 자산에 복제하지 않는다. 미승인 머리 후보는 이 프리뷰에서 보존하고 운영 카탈로그에 연결하지 않는다.

## V3 — 머리 크기 비교본

후속 `머리크기 한 10~15% 키우면 어때?`에 따라 V2의 얼굴 디자인과 뒤쪽 뿔 제거 상태를 유지하면서, 목 연결점을 기준으로 머리 가로·세로 약 **12.5% 확대**를 요청한 V3를 제작했다. 최신 표시 파일은 `assets/cobalt-greatsword-standing-v3-head-scale.png`다. 실제 생성 편집의 목표 배율이며 수학적 리샘플링으로 1.125배를 적용한 파일은 아니다. 몸체·대검 디자인과 전신 구도를 시각 비교했고, V1 승인 출처와 V2도 계속 보존한다. V3 전체 최종 승인은 아직 대기 중이다.
