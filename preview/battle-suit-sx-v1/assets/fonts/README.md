# 푸른 사신 전용 서체

- Noto Serif KR 900, Google Fonts 원본 배포: https://github.com/google/fonts/tree/main/ofl/notoserifkr
- SIL Open Font License 1.1. `OFL.txt`를 동봉한다.
- 2026-10-07 Google Fonts CSS API의 `text=푸른 사신` 서브셋을 자체 호스팅한다. 실행 중 외부 폰트 요청은 없다.
- 실제 URL, 취득 날짜, 용량, SHA-256은 `source.json`에 기록한다.
- 정확한 한글은 Pixi Text로 표시한다. 투명한 검 장식 PNG에는 글자나 사각형 이름판이 없다.
