# 핑두의 소원램프 · V2077

기간제 이벤트. 이동수단 / 장비 / 배틀슈트 중 종류를 먼저 선택한 뒤, 코인과 소원권으로 해당 목록의 아이템 1개 또는 꽝을 확정한다.

## 운영

- CMS → 설정 → 핑두의 소원램프.
- 기간(KST), 1회 코인·소원권 비용, 종류별 개별 보상·꽝 확률을 직접 입력한다. 각 종류 합계는 정확히 100%. 확률은 상대 가중치가 아닌 실제 %다.
- 기본 비공개 / 운영 OFF. 기간·비용·확률은 모두 null이며, 검수 예시를 운영 기본값으로 사용하지 않는다.
- 메뉴: 전체 메뉴 → 보상 → 핑두의 소원램프. 서버 공개 설정이 켜져 있고 종료 전일 때만 표시된다. 실제 개봉은 서버의 기간·활성 설정으로 재검증한다.
- 사용자 화면: /events/wish-lamp/. 미리보기: /preview/wish-lamp-v1/. 미리보기는 API 결제를 호출하지 않고 결과 선택·보상 순환으로 연출만 검수한다.
- 소원권 PINGDU_WISH_TICKET은 CMS 유저관리 → 인벤토리 아이템 지급에서 지급한다. 설정/지급 목록 최초 조회가 소원권 카탈로그를 등록할 뿐 계정에 자동 지급하지 않는다.
- 사용자 인벤토리에서는 소원권을 직접 사용할 수 없다. 소원램프 화면에서만 코인과 함께 소비한다. 미보유 계정의 인벤토리에 0개짜리 소원권을 광고하지 않는다.
- 보유 차량은 추첨 제외. 남은 차량의 원래 확률 비율대로 전체 당첨확률을 재배분하며 꽝 확률은 유지한다. 두 차량을 모두 보유하면 이동수단 소원을 막는다.
- 당첨 장비·배틀슈트는 강화 없는 새 인스턴스 1개다. 기존 아이템 수치·이미지, 장착·덱은 변경하지 않는다.

## 서버·안전성

- functions/_wish_lamp.js → PostgreSQL, app_meta.pingdu_wish_lamp_v2077.
- 설정 GET/PATCH는 USER_MANAGE 권한. revision으로 동시 관리자 덮어쓰기 방지.
- users 행 잠금 + 요청별 advisory lock. crypto.getRandomValues 서버 추첨. 클라이언트의 임의 보상·비용·roll 필드는 무시.
- 계정의 보유 차량 및 정확한 카탈로그·확률·설정 revision을 포함한 quote를 확인 후 소비한다. 설정 변경 시 새 동의가 필요하다.
- 실제 지급 INSERT ... SELECT의 RETURNING 행수가 정확히 1인지 확인한다. 0행, 차감 검증 실패, 감사 로그/완료 기록 오류, 처리 중 기간 종료는 모두 ROLLBACK한다.
- 소원권 차감·코인 차감·아이템 지급·감사 로그·wish_lamp_receipts_v2077 완료 기록을 하나의 PostgreSQL 거래로 처리한다.
- 완료된 requestId를 재전송하면 기존 결과와 현재 잔액만 반환한다. 종료 이후에도 복구 가능하며 재추첨·추가 차감하지 않는다.
- 브라우저는 계정별 미완료 requestId를 결제 전에 저장한다. 통신 실패·인증 만료는 이를 보존한다. 연출 초기화 실패 시에도 이전 결과 복구는 가능하다.
- 감사 기록은 계정별 최근 12건을 화면에 표시하지만, 재결제 방지용 영수증을 임의 삭제하지 않는다.
- 운영 API의 기존 인증·점검·수감자 제한을 통과해야 진입한다. 외부 Origin의 수정 요청은 차단한다.

## 연출·원화

- 공유 PixiJS 8.20.0 + GSAP 3.13.0 번들 재사용. 이벤트 페이지에서만 지연 로드. 단일 Pixi Application, GSAP 시간선으로 입자·잔광·램프·보상 공개를 제어.
- 원화 로드 → 램프 부유 / 분홍·금빛 소원 연기(0.35–2.9초) → 당첨 시 2.65초부터 동심원·110개 파편 발광 → 3.0초 보상 등장 → 3.5초 이름 / 5초 완료.
- 꽝은 당첨 폭발과 보상 스프라이트를 사용하지 않는 별도 결과. 음원·절차적 합성음은 추가하지 않았다.
- 일시정지/계속재생/건너뛰기, 백그라운드 일시정지, 페이지 이탈 시 타임라인·관찰자·Pixi 자원 정리.
- build: npm run build:wish-lamp. feature bundle 약 6.2KB; Pixi/GSAP 중복 번들 없음.
- assets/ui/events/wish-lamp-v2077/manifest.json에 built-in image_gen 프롬프트, 원본 SHA-256, 규격 기록. 최종 PNG는 무가공 복사했고 원본 generated_images도 보존.
- announcement-poster.png는 유저 공지용 1024×1536. 미정 기간·비용·확률을 기재하지 않으며 꽝 비용 소모를 안내한다. CMS에서 내려받기 가능.
