# 백금 대검 기사 · 서 있는 전신 리소스 시안

사용자 요청: “용병 V3 리소스 하나만 만들어봐 서있는 모션”. 첨부 기사를 바탕으로 서 있는 전신 대기 자세 **PNG 1장**을 제작했다. 현재는 기본 자세 시안이며 연속 애니메이션이나 V3 운영 전투 연결 완료로 기록하지 않는다.

- 리소스: [투명 PNG](assets/ivory-knight-standing-v1.png), 1131×1391 RGBA, 2,210,503바이트.
- 제작: **built-in image_gen**, 첨부 이미지는 캐릭터 디자인 참조로 사용했다. [실제 프롬프트](prompts/standing-v1.txt).
- 첨부 [참조 원본](assets/source/user-reference.png)과 생성 결과를 바이트 그대로 보존했다. 재압축·색상·알파 후처리 없음.
- [manifest.json](manifest.json)에 출처·SHA-256·규격·투명 경계·검수 항목을 기록했다.
- 백금 투구와 금장 갑옷, 자연스러운 백발, 검은색·아이보리 망토, 장식 대검을 유지했다. 첨부에서 잘린 하체·장화·검 끝을 전신 구성으로 새로 그렸다.
- 성인 전신 비율, 손과 손잡이의 접점, 직선 검신, 검 끝·발끝 및 실루엣 잘림 여부를 직접 확인했다. 알파 0~255, 알파 임계값 8 기준 모든 가장자리에 투명 여백이 있다.

사용자 시각 승인은 아직 받지 않았다. 이 파일은 향후 모션 제작의 기본 자세 검수용이며, 여러 프레임의 대기·이동·공격·이펙트는 이번 단일 자세 시안에 포함하지 않았다. 실제 연속 모션 제작 시 [공통 11단계 공정](../../docs/project-v-motion-effects-production-standard-20260927.md)을 이어 적용한다. 이름·등급·CMS·지급·전투 수치 및 운영 카탈로그를 변경하지 않았다.

검증 범위는 이미지·해시·투명 경계·JSON과 변경 diff다. 게임 실행 코드 변경이 없으므로 게임 테스트를 추가로 수행하지 않는다.
