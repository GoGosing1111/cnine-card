# 차고 이동수단 전투 지원

전투에 입장할 때 장착한 이동수단이 자신의 출전 용병 모두에게 공격력과 방어력을 올려 준다. 무한의 탑, 몬스터 토벌, 군단 토벌 개인·파티, 개인 및 듀오 랭크전에 같은 수치를 사용한다.

| 이동수단 | 공격력 | 방어력 | 용병 발밑 연출 |
| --- | ---: | ---: | --- |
| 헬리오스-R | +10% | +10% | 헤드라이트가 비춘 자리에 주황빛 터빈이 돈다. |
| 에테르 제로 | +20% | +20% | 은폐를 풀고 지나간 기체의 양 날개가 펼쳐져 청록빛으로 굴절된다. |
| 롤스로이스 하이퍼카 | +35% | +35% | 청록빛 리본과 은색 문장이 겹쳐 피어오른다. |
| BMW M9 | +55% | +55% | 금빛 터빈 세 날개가 맞물리고 적중 순간 한 번 더 회전한다. |
| 벡터-GT | +80% | +80% | 라임색 이중 주로와 체커 문양이 전방으로 번진다. |

용병의 장비·카드 연동·펫·랭크전 보정을 먼저 계산한 뒤 전투 시작 능력치를 한 번 올린다. 기본 공격과 스킬은 각각 기존에 사용하던 공격력 값을 읽는다. 개인 랭크전은 매 라운드 새로 출전한 용병, 듀오는 네 장착자가 각각 데려온 용병에게 적용한다. 일반 차고 이동수단도 소유자 진영에서 등장하고 퇴장한다.

## 전투 시연

저장소 루트에서 `node preview/equipment-sets-v3-20261019/serve.mjs`를 실행하고 이동수단과 전장을 선택한다. 시연은 각 전투 엔진이 만든 입장 상태와 첫 공격·방어 기록을 발췌해 재생한다. [듀오 랭크전에서 벡터-GT 보기](http://127.0.0.1:3556/preview/aether-zero-support-v1/?mode=duo&vehicle=vector) · [개인 랭크전에서 롤스로이스 보기](http://127.0.0.1:3556/preview/aether-zero-support-v1/?mode=pvp&vehicle=rolls)

전투 기록을 다시 만들려면 `node preview/aether-zero-support-v1/build-fixtures.mjs`를 실행한다. 차량, 발밑 문양, 게이트, 연무, 가속 잔상과 충격파는 투명 배경의 개별 리소스다. 움직임 줄이기 설정에서는 문양의 밝기로 적중을 표시한다. [상위 차량 원화와 런타임 리소스](../../assets/effects/garage-support-v1/manifest.json) · [공통 등장·퇴장 원화](../../assets/effects/vehicle-transit-v1/manifest.json)

게임 API와 비공개 매칭 작업은 이동수단 버프와 등장·퇴장을 기본 적용한다. 런타임의 `MERCENARY_VEHICLE_BUFFS`와 `VEHICLE_TRANSIT_FX` 설정값이 있으면 그 값을 우선한다. 전투 입력에 장착자와 규칙 버전을 저장해 기존 경기 기록은 해당 당시 수치로 재생한다.
