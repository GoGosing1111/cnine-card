## 얼굴 참조와 작화 참조

사용자가 명시적으로 이예준 카드의 얼굴을 요청했다. 다음 멤버 카드 사진은 얼굴 정체성에만 사용했으며 PROJECT V 작화 기준으로 취급하지 않았다.

1. `assets/cards/철구/006.webp` — 도핑구. 눈매, 눈썹, 코, 볼·턱선, 짧은 검은 머리의 주 참조.
2. `assets/cards/special/chulgu-fur.webp` — 운영 카드명 철구, 멤버명 이예준, 카드 ID `CN-346F8DB0DEB84D41`. 정면 눈·코·입의 보조 참조.
3. `assets/cards/철구/003.webp` — 전역구. 얼굴과 자연스러운 성인 비율의 보조 참조.

운영 카드명과 멤버 연결은 인증된 읽기 전용 조회로 확인했다. 치타구 카드도 확인했으나 동물 몸이나 합성 구도는 생성 입력에 사용하지 않았다.

화풍은 `docs/project-v-mercenary-card-art-standard.md`를 따른다. 최종 편집에는 `assets/ui/project-v/mercenaries/female-office-sniper-red-v1.png`를 회화적 채색 참고로 사용했다. 해당 캐릭터의 얼굴·의상·무기·배경은 차용하지 않도록 지시했다. 원본 카드와 공식 앵커는 변경하지 않았다.

## 제작 검수와 범위

- 얼굴의 눈매·눈썹·코·입·볼과 턱 윤곽을 참조와 비교했다. 최종 인물 유사성은 사용자 검수 대상이다.
- 얼굴을 가리지 않는 구도, 흰 런닝구, 간장통 손잡이와 손의 접점, 반대 손, 간장 물결, 이름·등급·워터마크 부재를 생성 결과에서 확인했다.
- V1의 사진 같은 피부 표현을 V2에서 붓질과 면 채색으로 수정했다. 얼굴 구조는 유지하도록 지시했다.
- 간장통의 왼쪽 가장자리는 화면 밖으로 일부 잘린 상태다. 실제 카드 프레임과 160px 적용 검수는 아직 진행하지 않았다.
- 이번 결과는 독립 원화 후보이며 새 용병 코드·등급·스킬·획득 정책·전투 SD·운영 연결을 지정하지 않았다.
