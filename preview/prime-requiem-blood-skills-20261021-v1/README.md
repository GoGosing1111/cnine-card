# 프라임 레퀴엠 · SSS 리미티드

사용자가 이름과 등급을 확정하고 일반기 3개·광역기 2개 제작을 요청한 전투 프리뷰다. 후속 “대부분 마음에 든다, 화려한 스킬 2개 필요”에 따라 기존 5종을 유지하고 특수 광역기 2종을 추가했다. 정자세·진한 붉은 네온·선명한 전신 혈갑 요청도 함께 반영한다.

최신 V7는 “뿔 말고 다르게, 느낌은 괜찮지만 오른쪽으로 치우친다”는 교정을 반영한다. 뒤쪽 적월의 길게 솟은 끝을 **뭉툭하게 깨진 원형 달 조각**으로 교체했다. 기존 오른쪽 추가 이동과 기울기를 없애고 투구·가슴 중심축의 중간에 정렬했다. 원형 적월 8프레임·흑염 16프레임·느린 붉은 네온 맥동을 유지하며, 정자세의 혈류 나선은 숨겨 얼굴·갑옷·녹색 코어를 드러낸다. 본체 원본과 7종 공격 스킬은 보존한다.

| 분류 | 기술 | 연출 |
| --- | --- | --- |
| 일반 | 혈섬 돌진 | 검끝 관통 → 이어 베기, 2타 |

기술 이름은 제안명이며 캐릭터 이름·SSS 리미티드 등급은 사용자 확정이다. 위력 수치·쿨다운·소모량·획득 경로는 미지정이다. 프리뷰의 다섯 표적은 범위 연출을 보여주기 위한 것으로 운영 대상 수를 확정하지 않는다.

## 실행

```powershell
node preview/prime-requiem-blood-skills-20261021-v1/build-resources.mjs
node preview/prime-requiem-blood-skills-20261021-v1/build.mjs
node preview/prime-requiem-blood-skills-20261021-v1/serve.mjs
```

`http://127.0.0.1:8864/preview/prime-requiem-blood-skills-20261021-v1/`

개별 선택, 기존 5종 연속 재생, 새 특수기 2종 연속 재생, 일시정지, 0.25/0.4/0.5/1/2배, 탐색, 충돌 순간, 정지를 제공한다. 기본값은 2배속이며 사운드는 무음이다. 첫 화면과 취소 시 사용자 원본 0번의 양발을 딛고 선 자세를 표시한다.

`대기 감상`은 현재 기술을 유지한 채 정자세의 상시 오라로 돌아온다. 공격/연속 재생을 마치면 자동으로 대기 오라를 재개한다. 정지 버튼은 모션과 오라를 함께 멈춘다. 대기 오라는 공격 배속과 분리한 6.4초 주기로 기존 GSAP 시계 하나를 사용한다. 동작 줄이기에서는 첫 프레임과 고정된 광원을 표시한다.

`prime-requiem-idle-v7.webm`은 실제 V3 캔버스에서 녹화한 약 8.4초 대기 장면이다. `node record-idle.mjs v7`으로 녹화하고 같은 렌더러의 캐릭터 뷰를 `qa/idle-closeup-v7.png`로 추출한다. 신규 스프라이트를 합성한 콘셉트 이미지가 아니라 실제 전투 렌더 결과다. V6 영상은 제작 이력으로 보존한다.

`prime-requiem-showcase-v3.webm`은 정자세·혈갑 대기 장면과 새 특수기 2종을 실제 V3에서 기본 2배속으로 녹화한다. `prime-requiem-five-skills.webm`은 직전 V2의 5종 영상 이력이다. 백호 질주 시트는 로딩하지 않는다. 폭발 시트의 원본 프레임 4(포효하는 머리)를 런타임 프레임 0으로 사용해 12프레임만 재생한다.

사용자가 반려한 혈핵 폭주·종언의 레퀴엠과 이전 16프레임 몸체·대기 자세는 재생 목록에서 제외했다. 기존 파일은 제작 이력으로 보존한다.

## 기존 전투 연결

기존 `preview/project-v-v3/source/battle/BattleEngine.js`를 `mountForBattle`로 사용한다. Pixi Application을 별도로 만들지 않는다. `PrimeRequiemFX`는 동시에 하나의 GSAP 타임라인만 소유한다. 선택 직후는 정자세에서 적월·흑염·네온이 순환하고, 공격을 재생하면 같은 시계로 교체한다. 공격 중 몸체·이동·혈류·잔상·검끝 충돌·타격 멈춤은 같은 시각을 샘플링한다. 정지·시킹 시 오라도 함께 정지하며 취소 후 잔여 공격은 없다.

참고 영상 [던파TV의 진(眞) 버서커](https://youtu.be/vfBuylrhTFc)는 실제 YouTube 플레이어를 0.4배속으로 설정해 관찰했다. 기존 기술에는 10.5~13.5초의 교대 검격을, 혈천개벽에는 15.3~22.5초의 혈기 흡수·검격 뒤 거대한 지면 분출을, 적월 무간참에는 24.5~28.5초의 돌파·혈흔·큰 마무리를 적용했다. 뒤의 30.9~32.7초 각성 장면도 비교했다. 거대 혈검·혈월 형상은 이 캐릭터용으로 새로 제작했으며 영상 원본은 게임 자산에 복사하지 않았다.

기존 일반 카드 다섯 장과 V3 카드 도크를 사용하고, 프라임 레퀴엠은 별도의 용병 표시 슬롯 하나에 둔다. `V-999`는 로컬 전투 아트 어댑터의 형식에 맞춘 임시 키일 뿐 운영 코드나 도감 등록이 아니다. 서버 요청·피해 적용·DB 쓰기·보상은 없다.

UI 패널·버튼·배지·HUD는 이번에 생성한 `ui-blood-forged-frame.png`를 9-slice로 사용한다. 전장은 전용 `blood-sanctum.png`다. 이름, 수치, 시간, 선택 상태는 코드로 표시한다.

## 검수 상태

`qa/browser-report.json`은 PC 1440×1000, 모바일 390×844의 전용 범위 검사다. 7종 기술, 새 2종의 0.08초 간격 샘플·주 효과 12개 이상 프레임 소비, 정자세·혈갑·네온, 단일 캔버스, 5+1 분리, 배속·정지·역방향 탐색·페이지 종료 정리를 확인한다. 직접 검격은 검끝 접점을 검사하고 후속 혈류 분출은 독립 효과로 구분한다. `qa/`의 스크린샷은 실제 V3 결과다. 기능 검사 통과는 새 원화·스프라이트·기술 연출의 사용자 승인과 별개다.

후속 검사 `qa/neon-rim-v5.json`은 같은 PC·모바일 크기에서 8개 자세의 본체·외곽 정렬, 실제 필터 출력의 붉은 발광 픽셀·투명 내부, 공격 재생·정지·복귀·필터 해제를 확인한다. `qa/desktop-neon-rim-v5.png`와 `qa/mobile-neon-rim-v5.png`에서 투구·검·어깨·다리 윤곽이 혈갑 앞에 선명하게 나타나는 것을 직접 확인했다. V3 영상과 전체 검사 기록은 당시 이력으로 보존하며 V5 전체 재검사로 바꾸어 기록하지 않는다.

`qa/idle-aura-v6.json`은 V6 변경만 검사한다. PC·모바일에서 적월 8/흑염 16프레임 소비, 루프 시작/끝 렌더 픽셀 일치, 일시정지, 정자세 혈류 숨김, 공격으로 전환, 개별 기술과 연속 재생 완료 후 대기 복귀, 대기 감상 버튼, 단일 캔버스, 종료 시 필터 해제를 확인했다. 별도로 동작 줄이기의 고정 프레임을 확인했다. 두 화면의 정자세와 버튼을 직접 시각 검수했으며 사용자 시각 승인은 대기 상태다.

`qa/idle-aura-v7.json`은 달 원본 교체와 위치 조정에 한정한 PC·모바일 확인 기록이다. 새 8프레임 소비, 몸 중심축 정렬, 루프 양 끝 렌더 일치, 대기 재생, 공격 전환·대기 감상 복귀, 가로 넘침·리소스 오류 없음을 확인했다. `qa/*-idle-*-v7.png`와 실제 캐릭터 확대 렌더에서 뿔 같은 끝 제거·좌우 여백을 직접 확인했다. `qa/idle-video-v7.json`은 새 영상의 실제 재생과 서로 다른 프레임을 확인한 기록이다. 변경하지 않은 7종 공격 전체 검사는 반복하지 않았다.

라이브 공개, 획득, 편성, 게임 수치, 영구 스킬 배정은 모두 비활성 상태다.
