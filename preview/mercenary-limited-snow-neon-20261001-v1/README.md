# 나무늘봉순·조은 리미티드 용병 원화

[검수 프리뷰](index.html)는 승인된 리미티드 프레임을 기본 적용한다. 원화·160px 카드·프레임 단독 보기와 현재 표시 방식 그대로의 확대를 지원한다. **예상 등급은 SS이며 등급 확정·운영 등록은 별도다.**

- **나무늘봉순 전체 원화 승인:** [사용자가 최종 선택한 원본](assets/bongsoon-snow-source-art-approved-20261001.png). 재첨부 파일을 바이트 단위로 그대로 복사했다. 얼굴·의상·쌍기관단총·파지에 추가 수정을 적용하지 않는다. [승인 및 SHA-256 기록](bongsoon-approval-20261001.json).
- **조은 수정본 검수 대기:** [각형 레이저포·키 비율 수정 V7](assets/joeun-neon-source-art-v7-angular-laser.png). 최신 재첨부본의 승인된 얼굴·의상을 기준으로 키/다리 비율을 약간 늘리고, 원형 통을 배제한 사각 발사구·다층 장갑·하부 동력 장치로 레이저 중화기를 새로 설계했다. 사용자 자유 재설계 지시가 과거 DNF 무기 형태 복제 요청을 대체한다.
- **리미티드 전용 프레임 V1 승인:** [1024×1536 투명 RGBA PNG](assets/mercenary-limited-frame-v1.png). 백금·흑연 테두리와 청록/보라 프리즘. [승인 및 SHA-256 기록](frame-approval-20261001.json). 원화·프레임·이름 표시는 별도 계층이며 원화에 합쳐 저장하지 않는다.

조은은 **내장 image_gen**으로 수정했다. [실제로 사용한 최종 프롬프트와 입력](prompt-joeun-v7-retry1.json), [최초 V7 명세](prompt-joeun-v7.json)를 보존한다. 최초 V7 생성은 서비스의 출력 검토에서 차단되어 결과가 전달되지 않았으며, 승인 복장과 수정 범위를 명시한 다음 호출의 결과를 V7로 저장했다. [프레임 제작 프롬프트](prompt-frame-v1.json)도 별도로 보존한다.

[매니페스트](manifest.json)는 현재 선택된 원본·참조·과거 버전의 크기, 형식과 SHA-256을 기록한다. 봉순 승인 원본 해시는 `B15D0CCBB2429C539BC337198B1BABBD3D277E1FF84FC2DAD88B209431AC4FF3`, 프레임 해시는 `A8931DBD4C8C069B2D38731F58AF708C373C8765412702ED040908FA750A506C`로 고정한다. 재압축·업스케일·색 보정 없이 원본을 보존한다.

검수는 이 프리뷰에 한정한다. [PC·모바일 표시 및 조작 확인](qa-preview-v7.json)은 원본 로드, 프레임 적용, 원화 보기, 확대, 160px, 프레임 단독 보기, 가로 넘침을 다룬다. 시각 결과는 원화와 실제 프레임 합성 화면을 직접 확인하며 사용자 최종 승인과 구분한다. 게임 실행 파일을 바꾸지 않았으므로 게임 전체 검사나 운영 재배포는 하지 않는다.

이전 V1~V5 파일과 프롬프트는 이력으로 보존하며 최신 승인본으로 혼동하지 않는다. 중단된 V6 요청의 입력·프롬프트는 당시 기록이며 최신 선택에 다시 적용하지 않는다. SD·스킬·전투 연결은 요청 범위가 아니다. 공식 기준은 [용병 작화 규정](../../docs/project-v-mercenary-card-art-standard.md)이다.
