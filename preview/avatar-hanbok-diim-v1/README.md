## 자산과 재현

- 런타임 장비창은 640×1664 실제 알파 WebP. 비균일 변형 없이 동일 배율과 패딩으로 머리·꽃신을 모두 보존한다. 로비는 1024/640px WebP.
- 개별 원본·파생 파일 해시, 규격, 알파와 배치는 `manifest.json`.

## 등록과 옵션

`HANBOK_DIIM`을 CMS에 한 번만 추가한다. 신규 획득 방법·가격·효과·공개·판매는 미설정 상태이며 운영자가 CMS에서 설정한다. 기존 아바타 설정·소유권·재화는 등록 과정에서 변경하지 않는다.

코인 습득률 상한은 +100%로 확대했다. `DROP_RATE_PERCENT`는 1~100 정수이며 **기본 확률 × (1 + 옵션/100)**, 최종 확률은 최대 100%다. CMS는 중복 없는 5종 효과를 지원한다. 기존 옵션 수치는 유지한다.

드랍 적용: 통합 드랍풀, 장비 보급상자 드랍, 블랙미라클 팩 드랍, 고급 재뽑기권 드랍, 확률형 마력결정 보상, PVE 카드 드랍, 주간 프리미엄 큐브 드랍. 가중치 풀은 무보상 확률만 줄이며 보상 간 상대 비율은 유지한다. 확정 수량, 주간/일일 한도, 큐브의 기본 누적 확률과 초기화 규칙, 뽑기·팩 개봉·제작 확률은 유지한다. 여러 번 판정하는 통합 보상은 같은 정산 내 잔여 일일 한도도 공유한다.

효과 조회는 요청 안에서만 캐시한다. 장착·소유·기간·활성·공개를 모두 만족해야 하며 OFF에서는 적용하지 않고 TEST에서는 OWNER만 적용한다.

## 검증

`npm run test:avatar`에 원본 해시/알파, PostgreSQL CMS 등록·5종 효과 저장·롤백·재시도, 만료·장착·공개 게이트, 코인/확률 경계, 가중치 보상 분포, 일일 한도와 실제 결정 지급 영수증 재사용 검사를 포함했다.

Chrome 실제 렌더러로 1440×1000 데스크톱, 390×844 모바일의 갤러리와 장비창을 검수했다. 전신 잘림·가로 넘침·이미지 로드 실패 없음. 밝고 어두운 배경에서 머리카락 사이 체크 배경 제거를 확인했다. 프리뷰의 장비창은 라이브 `SoopketmonCharacterLoadoutV2`를 사용하고 계정 상태를 저장하지 않는다.
