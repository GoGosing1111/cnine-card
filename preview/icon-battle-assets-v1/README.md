V1 사진도 보존한다. 사진만 바꿀 때는 `node preview/icon-battle-assets-v1/build-assets.mjs --sync-portraits`와 프리뷰 `build.mjs`를 실행해 메타데이터·소비자만 재생성한다.

## 제작 범위

- 디임: 청록 쌍검 / 청류 교차검 / 월광 해일
- 하이희야: 중기관총 / 탄착 섬광 / 오렌지 오버드라이브
- 나무늘봉순: 비취 장궁 / 비취 화살 / 백화 유성우
- 오조은: 마이크 음파 지팡이 / 공명 펄스 / 프리즘 앙코르
- 신규 고유효과 시안: 치명 확률·치명 피해·관통·흡혈. 4종 구성 제안과 시각 자산이며 운영 종류·수치는 별도 확정 대상이다.

내장 imagegen 모드로 각각 생성했다. 프롬프트는 `generation-inputs.json`, 무가공 생성 원본은 `assets/source/`에 보존한다. 출력 경로·해시·알파·프레임 검수는 `manifest.json`에 기록한다. CLI/API 우회 생성은 사용하지 않았다.

각 이펙트는 별개의 16프레임 원본 시트다. 생성 시트의 실제 프레임만 추출하며 정지 이미지를 복제·회전·확대해 중간 프레임을 만들지 않는다. PNG 원본 보존, 투명 여백 정렬과 WebP 무손실 인코딩만 사용한다.

## 재생 원칙

기존 V3 엔진과 아트 어댑터, 진형 및 하단 카드 도크를 재사용한다. 신규 ICON의 미출시 프레임 계층만 프리뷰 안에서 추가한다. 기존 등급의 프레임·도크 비율·진형은 바꾸지 않는다. 일반 카드 5슬롯 중 4종을 시연하며 용병 슬롯으로 넣지 않는다.

PixiJS는 공용 `effectLayer`에서 실제 프레임을 표시하고 GSAP 한 타임라인이 재생·정지·배속·시킹을 제어한다. 피해와 승패를 계산하지 않는 시각 검수 전용이다. 이번 범위는 무음이며 새 합성음은 추가하지 않는다.

기술 검증과 사용자 시각 승인은 구분한다. SD·스킬의 시각 승인은 아직 대기 중이다. 운영 카드·CMS·획득·전투 활성화 및 배포는 하지 않는다.

## 실제 파일·재생 규격

- SD 4종: 원본 1254×1254 RGBA PNG → 균일 리사이즈·투명 여백 → 768×768 무손실 WebP. 원본 사진과 SD 경로는 분리하고 원본 해시는 보존했다.
- 효과 12종: 각각 독립 생성된 4×4 시트. 총 192개 실제 프레임을 384×384 셀에 원래 크기로 배치한다. 1536×1536 무손실 WebP 아틀라스이며, 색만 바꾼 재사용이나 생성 중간 프레임은 없다.
- 시트 가장자리의 미세한 자연 광량은 알파 12/255 이하만 허용한다. 불투명 배경막과 가시적인 셀 경계 침범은 거부한다. 장궁 평타와 음파 스킬은 각각 V2로 재생성해 통과했으며, 반려 원본·프롬프트·사유도 보관했다.
- 아틀라스는 알파 합성이 아닌 원시 픽셀 복사로 패킹한다. 완전 투명 픽셀의 RGB를 제외하면 개별 프레임과 아틀라스의 알파·색상은 정확히 같다. 모든 비교는 허용 오차 없이 해시로 검사한다.
- 실제 사용 파일: `source/IconEffectPlayback.js` → 공용 `preview/project-v-v3/source/battle/BattleEngine.js`의 `effectLayer`. 잠금 버전은 PixiJS **8.20.0**, GSAP **3.13.0**이다.
- GSAP 시간이 유일한 재생 시계다. 인접한 실제 두 프레임 사이의 표시 보간만 사용하며, Pixi 자동 프레임 타이머는 없다. 충돌은 0-based 4번(화면의 5번)이며 `duration × 4 / 15`초다.
- 타격·스킬은 실제 표적 몸통 기준점, 치명 확률·흡혈은 실제 시전자 몸통 기준점에 붙는다. SD 발바닥 좌표는 `manifest.json`의 캐릭터별 `footAnchor`에 기록했다.
- 효과 교체마다 이전 타임라인·표시 객체·전용 텍스처를 해제하고 선택한 아틀라스 하나만 로드한다. 192개 프레임 전체를 전투 진입 시 한꺼번에 로드하지 않는다.
- SD는 전신 정지 전투 자산이며 이번 작업에 캐릭터 신체의 공격 모션 아틀라스나 사운드는 포함하지 않는다. 효과의 준비·접촉·확산·소멸은 개별 연속 프레임으로 구현했다.
