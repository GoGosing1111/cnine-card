# 비키니 조은 · SS / V-047

2026-09-21 사용자 요청: 승인한 일러스트를 비키니 조은 SS 용병으로 추가하고 SD·전용 스킬을 연결한다. 망이사 수준의 실제 사격 모션을 사용한다.

- 카드 원화는 승인 PNG를 그대로 보존했다. 1024×1536, 원본 해시는 `manifest.json`에 기록했다.
- 전투 SD는 6장 사격 시트의 첫 포즈를 그대로 사용한다. 조준, 첫 반동, 복귀, 강한 사격 준비, 마무리 반동, 정렬로 이어진다. 상의는 노출을 줄인 스포츠형이며 불투명 랩 스커트를 유지한다. 카드 원화는 변경하지 않았다.
- 실제 생성된 프레임만 추출해 640px 투명 셀에 배치했다. 움직이지 않는 그림의 이동·회전으로 포즈를 만들거나 중간 프레임을 복제하지 않았다. 포즈별 총구와 공통 발바닥 기준점은 매니페스트에 있다. 유휴 SD와 사격 첫 포즈가 같아 복장·비율이 갑자기 바뀌지 않는다.
- 전용 스킬 **라벤더 리코셰(MS-047)**: 전열 단일 표적, 6연사 연출, 420% 피해 배율, 비용 25, 재사용 5턴. 마지막 탄착 1.305초에 서버가 이미 확정한 피해·보호막·회피 결과만 반영한다. 탄환 연출은 추가 피해나 추가 행동을 만들지 않는다. 기존 SS 하이희야와 같은 기본 피해·비용·대기 기준이다. CMS 설정 가능.
- 등급 전투력 120,000, 중열 MARKSMAN, 기존 일반 덱 5장과 분리된 용병 1슬롯. 하이퍼팩 SS 등급 내 균등 추첨 목록에 포함된다. 기존 등급 확률은 변경하지 않는다.

## 렌더링·재생

PixiJS **8.20.0**, GSAP **3.13.0**. 공용 V3 엔진과 전장·진형·카드 도크를 그대로 사용한다.

- `source/BikiniJoeunSkillFX.js`: 실제 6포즈와 16탄착 프레임, 프레임별 총구, 반동/복귀, 정리.
- `../project-v-v3/source/battle/BikiniJoeunCombatPlayback.js`: 평타와 전용 스킬을 V3의 GSAP 시계에 연결. 평타도 실제 사격 모션을 사용한다. 타 용병에 CMS로 스킬을 배정해도 조은의 몸으로 바꾸지 않는다.
- `../../shared/mercenary-bikini-joeun-v1.mjs`: 스킬 정의·초기 수치와 6발 시점. 총구 발사 .42/.56/.70/.84/.98/1.23초, 이동 .075초.
- 전용 VFX는 준비→접촉→라벤더 결정/연무 확장→파편→소멸의 서로 다른 16프레임이다. 마지막 충돌은 프레임 4에 맞춘다.
- 소리는 기존 승인 MARKSMAN MS-009 프로필과 공유 AudioContext를 사용한다. 원음/라이선스/해시는 `../project-v-mercenary-system-v1/skill-audio-v1.json` 및 해당 소리 출처 문서를 그대로 따른다. 새 합성음은 없다. 사격 시점에 피크를 맞추고 배속·중단을 공용 시계와 동기화한다.

## 생성·검수

내장 imagegen 도구로 생성. 프롬프트는 `prompt-*.txt`, 무가공 생성 시트는 `assets/source/`에 보존했다. 원래 사격 시도는 도구 노출 검수에서 거절되어 커버를 늘렸으며, 잘린 총구를 수정한 최종 시트를 사용한다. `build-assets.mjs`는 원본 픽셀의 추출·투명 패딩·아틀라스화만 수행한다.

검수: 1440/390px에서 여섯 포즈, 평타, 16프레임 탄착, 중단 후 원상 복귀와 가로 잘림 없음. 실제 메인 앱의 토벌 시작/랭크전 매칭 버튼으로 PVE·PVP 진입→결과→복귀 4경로 통과. SQLite/PostgreSQL 획득 중복 방지·별도 편성·단일 피해/비용·CMS 기존 값 유지 검사 통과. 기존 용병과 승인 원본은 유지한다.

빌드: `node preview/mercenary-bikini-joeun-v1/build.mjs`, `npm run build:v3-grid`. 운영용 엔진과 래퍼는 동일한 `20260921-bikini-joeun-ss-v1` 버전을 사용하며 메인 기능 로더에서 직접 진입을 검수한다.
