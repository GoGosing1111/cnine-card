# 몬스터·레이드 오리지널 원화 비교

2026-10-13 제작. **원화 36종 사용자 승인 완료. 승인 원화 기반 기본 SD 36종 검수판 준비. 게임 미적용.**

토벌 NORMAL 18개와 빅물개(ID 8)를 제외한 38개 데이터 항목에 대응하는 원화 29종, 활성 일반 레이드 4종과 특별 레이드 3종을 비교한다. 같은 캐릭터의 난이도별 중복 행은 함께 관리하되 샹크스의 두 원화는 각각의 구도를 보존했다. 비활성 레이드 5종은 재활성화하지 않는다.

## 기준과 사용

- `index.html`: 기존 그림·새 원화를 나란히 확인. 분류, 이전/다음, 방향키, 확대 지원. `#hunt-006-nervan`처럼 특정 원화로 바로 진입할 수 있다.
- `manifest.json`: 현재 적용 후보 원본, SHA-256, 크기, 참조 원화, 대응 ID, 제작 프롬프트와 상태의 단일 색인.
- `prompts/`: 내장 `image_gen`으로 실제 사용한 요청과 참조/출력 경로. 별도 외부 생성기나 API 키를 사용하지 않았다.
- `assets/`: 생성 PNG 원본을 재압축 없이 보존. 이미지마다 원본 구도를 참고해 제작했으며 일괄 세로/가로 늘이기를 하지 않았다.
- `baseline-gameplay.json`: 2026-10-13 읽기 전용 조회의 전투 설정 기준. 개인정보·계정 데이터는 포함하지 않는다. 이번 작업은 DB에 쓰지 않았다.

## 최신 보정

동양인·백인 외형을 포함하도록 캐릭터마다 얼굴, 머리, 연령을 분리했다. 초기 시안에서 편중됐던 네르반·카르도·바레온은 V2로 교정했고, 태온은 칼날을 잡던 손을 손잡이 뒤로 교정한 V2를 선택한다. 구버전은 이력으로 보존한다. 바레온의 두 일러스트는 V2 얼굴·복식 정체성을 공유한다.

사용자 후속 지시로 빅물개는 교체에서 제외했다. `unused/hunt-008-moru-source-v1.png`는 제외 지시 전에 만든 보관본이며 목록과 게임에 사용하지 않는다. `briefs-v1.json`은 최초 이력이다. 최신 선택 파일은 반드시 `manifest.json`을 따른다.

## 다음 단계 상태
