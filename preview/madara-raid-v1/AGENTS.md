# 마다라 레이드 개발 준비

- 사용자 2026-10-11 지시: `준비해서 구현 시작해 라이브 올리지말고 준비까지만 해놔`.
- 운영 배포, main 통합, 라이브 메뉴/API/CMS 연결, 실계정 공대·입장권·보상 지급은 금지한다. 이 개발 브랜치에서 로컬 프리뷰와 관련 검증·범위 커밋까지만 한다.
- 포스터의 3역할·4기믹·최종 10%를 기준으로 한다. 전장은 기존 PROJECT V V3 렌더러·진형·로스터·아트 어댑터를 사용한다.
- 실제 경제·보스 전투력·입장 정책·보상 수량·출시 일정은 미정이다. 로컬 검수 수치를 운영 확정값으로 취급하지 않는다.
- 신규 정지 원화는 검수 자산이다. 연속 모션·개별 스킬 프레임·사운드의 완성이나 사용자 시각 승인을 주장하지 않는다.
- 후속 요청으로 로컬 공대장·입장권·방 생성·목록 갱신·강퇴와 보스 대사·전투 연출을 추가한다. 이는 운영 연결 승인이 아니다. 검수 입장권 3장, 생성자 1장 차감·참가 무료·미환급은 로컬 동작 확인값이며 운영 경제 확정값으로 승계하지 않는다.
- V2는 `assets/presentation-manifest.json`의 본체 시전 4포즈·5종 60효과 프레임, 자막 대사와 감상 모드를 사용한다. 이전 정지 자산만 있던 상태는 이력이다. 거신 원본·검은 그대로 보존하며 거신의 추가 본체 동작·성우 음성·신규 녹음 사운드와 사용자 시각 승인은 별개다.
