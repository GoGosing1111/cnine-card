# 체온 아바타 — A-14 / CHEON

사용자 제공 사진의 긴 갈색 머리, 얼굴 인상, 검은 상의와 밝은 어깨끈·실버 목걸이를 참고한 **숲켓몬 아바타**다. 하의와 신발은 차콜 테일러드 팬츠·검은 앵클부츠로 구성했다. 용병 카드가 아니며, 원본 인물 사진은 이 공개 폴더에 복사하지 않았다.

- `index.html`: 로비용/장비창용 비교, 장비창 밝은·어두운 배경 검수, 원본 링크.
- `assets/avatar-cheon-lobby-source-art-v1.png`: 내장 이미지 생성 도구의 1024×1536 RGB 원본을 무가공 보존.
- `assets/avatar-cheon-equipment-source-art-v1.png`: 1024×1536 실제 RGBA 전신. 손가락 안쪽과 팔·다리 사이 배경도 제거.
- 로비 1024/640px와 장비 640px WebP: 모바일용 별도 파생본.

이미지 생성의 배경 추출 결과는 체크무늬 RGB였다. 사용자가 **“배경만 스크립트로 제거”**를 승인한 뒤 기존 연결 배경 제거·경계 매팅 방식을 이 이미지 색상에 맞춰 적용했다. 얼굴·의상·포즈를 다시 그리거나 변형하지 않았으며, 최종 불투명 픽셀의 RGB 변경은 0이다. 가장자리 알파만 매팅·정리했다.

`equipment-draft-v1.png`는 재현을 위한 실패 원본이며 장비창에 연결하지 않는다. [manifest.json](manifest.json)에 원본·파생본 해시, 알파 통계, 사용자 승인과 공개 상태를 기록했고 [prompt.md](prompt.md)에 전체 프롬프트를 보존했다.

사용자의 후속 **“라이브적용하고 CMS바로 적용해”** 지시에 따라 A-14 / CHEON / 체온을 운영 CMS에 등록한다. 로비 1024/640px와 장비창 640px WebP를 기존 아바타 API에 연결하며, `ensureCheonAvatar`의 원자적 카탈로그·마커 등록은 재실행해도 CMS 편집값을 덮어쓰지 않는다.

기존 신규 아바타 등록 정책에 따라 데이터 사용·유저 공개·상점 판매는 OFF, 획득 방식·가격·효과는 미설정으로 둔다. CMS → 아바타 관리 → A-14 체온에서 운영자가 설정할 수 있다. 계정 지급·전체 시스템 설정 변경·용병 등록은 포함하지 않는다.

## 검증 및 재현

```sh
node preview/avatar-cheon-v1/remove-equipment-background.cjs
node --test preview/avatar-cheon-v1/qa-assets.test.cjs
npm run test:avatar
```

배경 제거 스크립트는 입력 해시를 검증한다. 다른 아바타에 같은 색상 임계값이나 손가락 좌표를 그대로 적용하지 않는다.

브라우저 검수: 기본 PC 화면과 390×844 모바일 화면에서 로비·장비 전신, 신발 잘림 없음, 밝은/어두운 배경 전환을 확인했다. 검수 버튼은 이미지 밖에 배치해 발을 가리지 않으며 임시 뷰포트 설정은 검수 후 해제했다.
