# 은백·금색 대검 기사 — V5 전투 리소스

2026-10-01. 승인된 시작 이미지(V14), 한손 파지, 원본 대검을 기준으로 기존 제작 방식인 **내장 ImageGen의 연속 포즈 제작 + 원본 대검 합성**을 유지했다. 골격 리깅·부위 변형 방식으로 전환하지 않았다. 사용자가 폐기한 두 궁극기 시트와 체형이 무너진 V3 작업 시트는 사용하지 않는다. 폐기 기록은 `rejections.json`이다.

현재 상태는 **독립 V3 프리뷰 반영 완료, 사용자 시각 검수 대기**다. V8 원화와 V12 손·팔 파지 승인을 새 모션 전체의 승인으로 확대하지 않았다. 이름·등급·성능·스킬 배정·운영 연결은 확정하지 않는다.


`모션만`으로 아우라·광역 효과·카메라 진동을 끄고, 0.25×/0.5× 재생과 프레임 탐색으로 파지를 확인할 수 있다.

- `qa/v5-grip-details.png`: 손잡이를 감싼 장갑의 확대 비교.
- `assets/motion-v5/`: 새 원본 시트, 개별 PNG, PNG/WebP 아틀라스.

## 보존한 기준과 제작

기본 자세는 `assets/knight-sd-v14-original-blade-approved-grip.png`이며 정지 대기에 그대로 사용한다. V12의 승인 손 불투명 픽셀 7,352개는 V14와 차이가 없다(`qa/blade-v14-report.json`). V8 원화·사용자 첨부 승인 디자인·기존 승인 대기 시트·V12 파지 원본을 덮어쓰지 않았다.

대검은 `assets/weapon/sword-original.png`, SHA-256 `A31B35AAD0800C06516BC7EF1BE9F0243ACCA5782D8C70F53C4041A8304661E7`이다. 승인 원본과 같은 RGB 158,452픽셀을 유지한다. 검신·칼끝·손잡이는 다시 그리지 않는다. 몸 대비 배율을 고정하고 검 전체에 균일 확대·회전·이동만 적용한다. 휘기·부분 늘리기·새 칼끝 추가는 없다.

각 원본 포즈의 실제 손잡이 축과 닫힌 주먹의 가림 구간을 검출한 뒤 원본 대검을 합성하고 같은 포즈의 장갑 픽셀을 전경에 복원한다. 제작용 녹색·청록·자홍 표식은 출력에서 제거한다. 새 원본은 항상 승인 시작 이미지를 참고하며, 작은 머리·자연 성인 체형·긴 다리·낮은 신발 굽·눈을 가리는 투구·노출 하관을 기준으로 삼는다. 프롬프트는 `prompts/motion-v5-*.txt`, 배율과 출처는 `asset-specs-v5.json` 및 `manifest.json`에 있다.

시트는 4개의 큰 포즈를 그려 해상도를 확보했다. 알파 연결 요소로 분리하되 `utility-source.png` 아래 두 망토가 닿은 부분만 x=518에서 분리한다. 몸·손·표식은 이 경계와 겹치지 않는다. 원본 RGBA 파일은 보존한다.

## V3 연결과 검수

기존 공용 V3 렌더러와 PixiJS **8.20.0**, GSAP **3.13.0**을 사용한다. 실제 파일은 `source/KnightFX.js`, `source/preview.js`, `skill.mjs`다. GSAP 하나가 모션·효과·이동·카메라를 제어하고 기존 `engine.simpleTimelines`에 등록된다. 서버 피해나 승패를 계산하지 않는다. 일반 카드 5장과 별도 용병 슬롯, 기존 도감 원화·카드 프레임을 유지한다.

- 표시 몸 높이: 기사 **312.39**, 크라이베른 **312.12**. 투명 여백을 제외한 기준이며 머리만 키우지 않는다.
- 참격 중 발은 적과 같은 지면 높이에 고정한다. 검끝을 억지로 맞추기 위해 캐릭터의 세로 위치를 바꾸던 보정을 제거했다. 이동은 실제 대시 프레임을 사용한다.
- 타격 시각: 공격 **1.77초**, 집행 **1.77·3.65초**, 심판 **2.61초**, 궁극기 **2.56·4.44초**. 참격 6번 프레임과 효과 충돌 피크, 기존 녹음 효과음을 같은 시계에 맞췄다.
- 주변 광원은 현재 캐릭터·검 실루엣을 따라가는 진한 붉은 외곽, 붉은 내부 광원, 얇은 금빛 테두리다. 갑옷이나 눈을 붉게 칠하지 않는다. 기존 전용 아우라 12프레임을 함께 사용한다.
- 기존 라이선스 녹음 효과음을 재사용하며 출처·해시·동기점은 `manifest.audio`에 있다. 새 합성음을 만들지 않았다.
