# V3 콘텐츠별 공통 그리드 검수

로컬 주소: `http://127.0.0.1:8791/preview/v3-common-grid-v1/`

토벌·탑·월드 레이드·봉인전·호송·아포칼립스·랭크·공성·영토·클랜전 10종의 기존 V3 진입을 비교한다. 승인 카드 원화·전투 SD·장비와 기존 서버 전투 생성 함수를 읽으며 전투력은 검수 예시다. 계정 API·운영 저장·입장권·보상은 호출하지 않는다.

용병 포함 배치는 아래 비교 링크, 실제 연속 전투는 원정·폐차장·카우방 링크에서 확인한다. 독립 전장을 복제하지 않고 공용 V3 번들을 사용한다. 편성 정보가 없는 용병을 임의로 추가하지 않는다.
