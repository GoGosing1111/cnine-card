# 장비 강화소 · The Celestial Forge

상태: **TECH_QA_COMPLETE_USER_REVIEW_PENDING / PREVIEW_ONLY** · 2026-09-11.

사용자 요청: 장비보호권은 인게임 극희귀 획득, 상자 획득 제외. 파괴 장비는 쿠폰으로 복구. 성공률 최소 10%, 성공·유지·파괴 세 확률. 후속 답변에 따라 확률표와 경제는 시연 수치로 제작했다.

## 실행

```powershell
node preview/equipment-forge-v1/serve.mjs
# http://127.0.0.1:8899/preview/equipment-forge-v1/
node --test preview/equipment-forge-v1/qa.test.mjs
```

서버는 localhost/127.0.0.1에만 바인딩한다. 이 프리뷰와 필요한 장비 이미지·음원·공유 UI 라이브러리만 제공한다. API 요청과 POST는 받지 않는다. 장비·보호권·쿠폰·코인·결정·기록은 메모리의 체험 데이터이며 새로고침 시 초기화된다.

## 화면과 조작

- 장비 6종 선택, 종류 필터, 시연 전투력 비교, 비용과 확률 표시.
- 기본 확률: 성공 / 유지(무반응) / 파괴. 하한·합계·소수 둘째 자리 검사 후 표 전체를 한 번에 적용한다.
- 보호권 체크 시 기본 파괴 판정은 유지로 전환되며, 기본 판정과 보호 후 확률을 모두 표시한다. 시연 기준은 파괴 방지 때만 1장 소모다.
- 파괴 기록 선택 → 복구 쿠폰 확인 → 장비 복구 → 동일 인스턴스로 재강화. 기록별 중복 복구와 연속 확인 클릭의 중복 차감을 막는다.
- 상단 `시연 설정`: 임시 확률표, 0.5×/1×/2× 속도, 동작 줄이기, 체험 초기화.
- 하단 `연출 미리보기`: 성공·유지·파괴·보호·복구를 재료 소비 없이 개별 재생.
- 진행 중 일시정지/계속 재생/건너뛰기. 다른 탭으로 이동하면 정지하고 돌아온 뒤 직접 재개한다. 화면 이탈 시 타임라인·렌더러·오디오를 해제한다.
- 모바일은 장비 목록 가로 스크롤과 세로 배치다. 강화 시작 시 연출 무대로 이동한다. 대화상자는 네이티브 dialog의 키보드 포커스 제한·Escape 닫기를 사용한다.

## 실제 연출 구현

- 사용 파일: `source/fx.mjs`, `source/app.mjs`.
- 기존 `js/ui-fx-vendor-v2045.bundle.js`와 `CNineUiFxVendor`를 사용한다. **PixiJS 8.20.0 / GSAP 3.13.0**(package-lock 및 설치 버전). 별도 CDN이나 라이브러리 사본을 추가하지 않았다.
- 이 화면은 장비 강화 UI다. 기존 전투 V3 렌더러·진형·원화·SD·전투 계산은 수정하지 않는다.
- 한 GSAP 시연 시간으로 충전, 나선 궤적, 파티클, 충돌과 파편 좌표를 결정한다. Pixi ticker는 계산된 시각을 렌더링하며 최대 60fps다. 배경의 대기 시계는 시연 중 정지한다.
- 0–1.50초: 입자 수렴 / 1.50–2.25초: 압축 / **2.25초 충돌** / 3.15초 결과 문구 / 4.80초 종료.
- 기준점: 무대 `(50%, 46.5%)`가 장비·충돌 중심, 플랫폼 광원은 장비 중심 아래 `무대 높이 × 25.3%`. 화면 크기 변경 시 같은 비율로 다시 계산한다.
- 성공: 수렴광, 상승 광주, 방사형 입자, 플랫폼 파동.
- 유지: 폭발 없이 에너지가 흩어지고 원본 장비가 남는다.
- 파괴: 원본 장비 텍스처를 40개 개별 마스크 조각으로 분리하여 서로 다른 궤도·각도·중력으로 붕괴. 균열·먼지·불티 별도 계층.
- 보호: 파괴 균열을 막는 보호 장벽과 보존된 원본 장비.
- 복구: 파괴 조각 역류·재결합 후 원본 장비가 완전히 복원되고 복구광이 소멸.
- 아틀라스 없음. 정지 이펙트 한 장을 확대하는 방식이 아니라 프레임마다 궤적·균열·파편·입자 형태를 계산한다. 장비 원본 PNG는 읽기 전용 텍스처로 재사용한다.
- 재생 시작 전 체험 모델이 영수증을 1회 확정한다. 건너뛰기·정지·배속·연출 시연에서 결과를 다시 추첨하거나 재료를 다시 차감하지 않는다.
- WebGL 실패 시 HTML 장비 이미지와 즉시 결과를 제공하는 간소화 화면으로 동작한다. 동작 줄이기에서는 흔들림·점멸·대기 입자를 생략한다.
