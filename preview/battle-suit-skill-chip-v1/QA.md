## 모바일·성능

390×844, DPR 2, CPU 4배 감속의 **데스크톱 Chrome 모바일 에뮬레이션**이다. 실제 저사양 휴대폰/GPU 벤치마크로 해석하면 안 된다.

- 실제 V3 child viewport 560px, canvas 500px, 카드 도크 bottom 560px. 하단 5장 카드 모두 프리뷰 안에 표시되며 가로 넘침 없음.
- 폭격+일반 사격 한 번, 3.9초 표본: rAF 545개, 간격 중앙값 8.3ms / p95 12.5ms / p99 16.6ms, 50ms 초과 간격 0. 일반 사격 7회, 종료 후 잔류 스킬 스프라이트 0, 실제 피해 0. 모니터 고주사율 및 에뮬레이션 결과이며 모바일 120fps 보증이 아니다.
- 로컬 네트워크 무감속 + CPU 4배 감속 trace: 부모 검수 UI LCP 416ms, CLS 0.00. **LCP는 WebGL 전장 준비 완료 시간이 아니다.** 외부 사용자/운영 트래픽의 성능 수치는 측정하지 않았다.
- render-blocking CSS의 추정 절감 0ms: 원본 V3 CSS를 변경하지 않음. 기존 카드 원본 축소 권고는 본 작업의 원본 보존 규칙에 따라 변경하지 않음.
- 생성 자산은 원본 PNG 보존 + 무손실 WebP 전송. 폭발 아틀라스 2,227,668→1,201,578 bytes, 약 46% 감소. 전체 신규 런타임 텍스처는 원본 해상도/알파 유지.
- 모바일 전용 입자 수 87개, 데스크톱 119개로 고정 풀을 사용하며 반복마다 생성하지 않는다. 화면 흔들림은 reduced-motion에서 기본 OFF다.

## 효과음 동기

실제 녹음된 CC0 헬기·폭발 원음, 기존 승인 총성 녹음의 발사 프록시를 사용한다. 첫 재생은 사용자 조작으로 오디오 컨텍스트를 해제한 뒤 시작한다.

Web Audio가 보고한 출력 지연 40ms 환경에서 출력 timestamp 매핑으로 보정했다. 일반 재생 예약 오차는 폭격 4개/로켓런처 1개 모두 부동소수점 반올림 수준(약 0ms)이었다. 0.25/0.5/1/2배속 예약 수식과 중단 시 모든 노드 해제를 테스트했다. **스피커 실제 출력과 디스플레이 발광의 물리적 ±20ms 동기는 루프백 장비로 측정하지 않았다.** 블루투스·사용자 장치 청음 검수가 남아 있다.

## 자산 검수

폭발 24프레임 전체가 실제 RGBA다. 각 셀의 2px 테두리 최대 alpha는 1~2/255로 통과. 최초 시안의 프레임 경계 침범과 두 번째 시안의 RGB 체크무늬 배경은 폐기하고 최종 투명 시안으로 교체했다. 빌드가 같은 검사를 재수행한다. 프레임마다 지면 접촉점을 측정하여 피벗 메타데이터로 사용한다.

최종 화면: 데스크톱 접근 그림자·폭발·로켓런처 충돌, 모바일 폭발·하단 원본 카드 도크를 직접 확인했다. 시각 연출은 사용자 승인 후 아래 사항만 조정했으며 사용자 장치 사운드 검수는 남아 있다.
