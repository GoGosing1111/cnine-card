상태: **V2 모션·이펙트 사용자 시각 승인 / 슈트·용병 공통 제작 기준 확정 / 운영 연결 OFF**.

2026-09-27 사용자 `좋아 아주 훌륭해 ... 현 제작과정을 100% 이행해야함`으로 현재 V2의 모션·이펙트와 제작 과정이 승인됐다. 승인 구현은 `da74b060`, 승인 범위·원본·산출물·공정 파일 해시는 [승인 기록](approval-20260927.json)에 보존한다. 이후 제작은 [슈트·용병 모션 및 이펙트 공통 제작 규정](../../docs/project-v-motion-effects-production-standard-20260927.md)의 11단계 전체를 이행한다.

V1의 검끝 고정과 단발 스킬은 사용자 반려다. 후속 ‘던전앤파이터 귀검사나 웨펀마스터처럼 화려하게’ 지시에 따라 V2는 빠른 교차 돌진, 연속 베기, 올려베기, 도약 내려베기로 다시 구성했다. 기존 게임의 스프라이트를 가져오지 않고 X 외형과 원본 검을 사용한다.

## 구성

- 몸 동작: 대시 8 + 공격 8 + 스킬 8 + 새 검술 동작 8 = **32프레임**
- 현재 이펙트: 대시 12 + 횡베기 12 + 교차 검격 12 + 마무리 검압 12 + 지면 파열 12 = **60프레임**. V1 공격/스킬 효과는 현재 매니페스트에서 제외했다.
- 투명 768×768 동작 셀, 각 동작 묶음 4×2 아틀라스, 프레임별 발바닥 피벗·파지점·칼끝 기록
- 몸·검의 물리적 비율은 모든 동작에서 동일하다. 웅크린 몸의 보이는 높이를 기준으로 확대하지 않는다.
- 검날/가드 픽셀은 고정 자산, 쥔 손과 짧은 손잡이는 몸 동작 계층에 속한다.
- 원화·대시/공격/스킬 아틀라스·개별 프레임·썸네일·원본 생성 시트·프롬프트를 별도로 보존한다.
- 무음 검수. 전투 수치·스킬 피해·장비/CMS 등록·획득/제작 비용·라이브 기능 플래그를 설정하지 않는다.
- 기능 검증은 시각 품질 승인이나 Z-BODY보다 낫다는 사용자 승인을 대신하지 않는다.

## 재생

`source/XBodyFX.js`는 공용 V3 `BattleEngine`의 기존 지원 액터·효과 레이어·카메라를 사용한다. 번들 안의 PixiJS는 **8.20.0 한 벌**, GSAP은 **3.13.0 한 벌**이며, 시간은 V3에 등록한 GSAP 타임라인 하나로 샘플링한다. `build-report.json`에 실제 의존성과 공용 런타임 파일을 기록한다.

| 동작 | 전체 길이 | 단계 | 타격 기준 |
| --- | --- | --- | --- |
| 대시 | 1.15초 | 준비 → 발진 → 공중 가속 → 착지 → 회복 | 이동 전용 |
| 공격 | 1.10초 | 발도·접근 → 횡베기 → 검기 잔향 → 회복 | 0.37초 |
| 스킬 | 3.40초 | 교차 돌진 4연격 → 올려베기 → 도약 내려베기 → 검압 파열·파편 → 잔향 | 0.37 / 0.64 / 0.91 / 1.18 / 1.43 / 2.18초 |

지상 동작은 적의 발바닥과 같은 지면 높이를 유지한다. 좌우 간격은 검날 중간 구간의 도달 거리로 정하며, 검끝을 적의 중심에 맞춰 높이를 옮기지 않는다. 칼날 구간과 적 몸통의 교차 여부를 검증하고 검끝은 몸통 너머로 지나간다. 도약은 1.49~2.18초의 명시적인 높이 곡선으로만 움직인다. 6회 적중은 연출 기준이며 서버의 실제 타수·피해를 의미하지 않는다.

잔상은 과거의 실제 동작 프레임 4개를 샘플링한다. 검격·교차 검기·지면의 돌과 먼지는 별도 연속 그림을 재생한다. 최종 자세는 충돌 구간에 유지되고, 마지막 충격에 더 강한 카메라 반동을 준다. 배경 패럴랙스가 갈라지지 않도록 카메라의 기본 위치를 유지하고 초점 피벗으로 화면을 잡는다.

프리뷰에서 피해를 만들거나 계정 API를 호출하지 않는다. 카드 도크·프레임·원화/SD·진형은 기존 V3 및 기존 읽기 전용 fixture를 그대로 사용한다. 확대 버튼은 공용 카메라만 조절한다. Z-BODY 비교 링크는 현재 Z 뇌검 검수 화면을 연다.

재생, 처음부터, 중단, 0.25/0.5/1/2배속, 시간 탐색, 다음 적중 구간, 이펙트 표시, 시간순 동작 프레임 선택을 지원한다. 중단·페이지 이탈·탭 숨김 시 타임라인과 효과를 정리한다.

## 반영 범위

V2 모션·이펙트 시각 승인은 완료됐다. 승인된 원본과 연출을 고정하고 후속 수정은 새 후보로 검수한다. 빌더의 새 산출물은 `USER_REVIEW_PENDING`으로 시작하며 이 승인 기록을 자동 승계하지 않는다. 승인 기록의 파일 해시와 다른 결과를 승인본으로 취급하지 않는다.

이번 규정·승인 기록 반영은 문서와 메타데이터 변경이다. 운영 JS/API/CMS/출시 플래그를 연결하지 않았으므로 문서·경로·해시 확인과 범위 커밋·원격 반영으로 끝낸다. 운영 활성화는 기존 출시·연결 승인 범위를 따른다.
