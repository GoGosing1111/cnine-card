## 구성

- 몸 동작: 대시 8 + 공격 8 + 스킬 8 = **24프레임**
- 이펙트: 대시 12 + 공격 12 + 스킬 16 = **40프레임**
- 투명 768×768 동작 셀, 각 동작 4×2 아틀라스, 프레임별 발바닥 피벗·파지점·칼끝 기록
- 몸·검의 물리적 비율은 모든 동작에서 동일하다. 웅크린 몸의 보이는 높이를 기준으로 확대하지 않는다.
- 검날/가드 픽셀은 고정 자산, 쥔 손과 짧은 손잡이는 몸 동작 계층에 속한다.
- 원화·대시/공격/스킬 아틀라스·개별 프레임·썸네일·원본 생성 시트·프롬프트를 별도로 보존한다.
- 무음 검수. 전투 수치·스킬 피해·장비/CMS 등록·획득/제작 비용·라이브 기능 플래그를 설정하지 않는다.
- 기능 검증은 시각 품질 승인이나 Z-BODY보다 낫다는 사용자 승인을 대신하지 않는다.

## 재생

`source/XBodyFX.js`는 공용 V3 `BattleEngine`의 기존 지원 액터·효과 레이어·카메라를 사용한다. 번들 안의 PixiJS는 **8.20.0 한 벌**, GSAP은 **3.13.0 한 벌**이며, 시간은 V3에 등록한 GSAP 타임라인 하나로 샘플링한다. `build-report.json`에 실제 의존성과 공용 런타임 파일을 기록한다.

| 동작 | 전체 길이 | 단계 | 타격 기준 |
| --- | --- | --- | --- |
| 대시 | 1.15초 | 준비 → 발진 → 공중 가속 → 착지 → 회복 | 이동 전용 |
| 공격 | 1.05초 | 준비 → 내려베기 → 타격 정지 → 회복 | 0.34초, 4번 몸 프레임 |
| 스킬 | 2.60초 | 응축 → 들어올리기 → 내려베기 → 충돌 → 소멸 | 1.00초, 6번 몸 프레임 |

접점은 선택한 실제 V3 몬스터의 중심과 칼끝을 맞춘다. 프리뷰에서 피해를 만들거나 계정 API를 호출하지 않는다. 카드 도크·프레임·원화/SD·진형은 기존 V3 및 기존 읽기 전용 fixture를 그대로 사용한다. 확대 버튼은 공용 카메라만 조절한다. Z-BODY 비교 링크는 현재 Z 뇌검 검수 화면을 연다.

재생, 처음부터, 중단, 0.25/0.5/1/2배속, 시간 탐색, 타격 프레임, 이펙트 표시, 8개 동작 프레임 선택을 지원한다. 중단·페이지 이탈·탭 숨김 시 타임라인과 효과를 정리한다.
