# 베르칸 추가 광역기 · 흑금 천우

2026-09-27 사용자 요청: 베르칸 공격속도·행동력 상향 및 추가 광역기 제작.

2026-09-30 사용자 연결·ON 지시에 따라 `MS-056`, `USER_APPROVED_LIVE_PVE`, `runtimeEnabled:true`로 운영 PVE에 연결했다. PVP는 서버에서 제외한다. 기존 MS-055 흑금 낙성의 두 대상 사격은 유지한다. 새 스킬의 역할은 적 진영 전체를 덮는 흑금 화살비다.

## 연출

- 기존 V3 `mountForBattle`, 전투 진형, 카드 원화/등급 프레임/하단 도크, `BerkanFX`의 공용 효과 레이어와 40개 스프라이트 풀을 재사용한다.
- PixiJS **8.20.0**, GSAP **3.13.0**. 독립 렌더러·자체 전투 시계·피해 계산은 없다.
- `source/BerkanAreaFX.js`가 새 화살비 아틀라스와 기존 베르칸 시전/광원·보조 접촉 프레임을 결합한다. 메인 화살비는 강하 → 개별 착탄 → 연쇄 폭발 → 넓은 충격파 → 소멸로 형태가 바뀌는 **16개 개별 연속 프레임**이다.
- 로컬 연출 시계 기준 준비 0~1.05초, 첫 접촉 **1.62초**, 파열 정점 1.92초, 충격파 2.25초, 소멸 3.22초, 대기 복귀 3.40초. 기본 시연 속도 1.25배이며 모든 자세·타격·잔향이 같은 GSAP 시계를 사용한다.
- 대상 다섯 명의 실제 V3 좌표로 진영 중심/넓이를 계산한다. 회피에는 개별 피격·반동을 표시하지 않는다. 취소/대상 소멸은 즉시 대기로 돌아오고 소유한 효과만 정리한다.
- 신규 사운드는 추가하지 않았다.

## 원본과 가공

`image_gen`으로 새 RGBA 스프라이트 시트를 생성했다. 원본 1254×1254 PNG는 `assets/source/arrow-rain-v1.png`에 그대로 보존하며 SHA-256은 `e12fab349208d9c0610b604f96b9239f978933f89d353fe1965490565453e2e5`다. 요청 전문은 `generation-prompt.txt`다.

`pack.mjs`는 원본을 균일하게 1280×1280으로 정규화하고 4×4 셀을 나눈 뒤 각 셀에 투명 여백 32px을 추가한다. 캐릭터/효과를 다시 그리거나 특정 프레임만 변형하지 않는다. 각 프레임·아틀라스 해시, 알파와 피벗은 `manifest.json`에 기록했다. 기존 베르칸 카드 원화·SD·승인 모션 원본은 수정하지 않았다.

## 재현

`node preview/mercenary-berkan-area-v1/pack.mjs`

`node preview/mercenary-berkan-area-v1/build.mjs`

`node --test preview/mercenary-berkan-area-v1/qa.test.mjs`

검사는 원본/프레임 해시, 16개 고유 이미지, 실제 알파·투명 경계, 접촉 프레임, 실제 Pixi/GSAP의 다섯 대상 재생·일시정지·배속·탐색·취소·대상 소멸·완료 후 레이어/타임라인 정리, 운영 PVE 연결 상태를 확인한다. 서버가 확정한 전체 적 대상 결과를 `BerkanCombatPlayback.js`에서 1.62초 접촉 시 한 번만 반영하며 V3 등록 GSAP 시계·취소 처리를 재사용한다. 기존 낙성처럼 총 피해 배율 5.6·비용 35·재사용 5행동을 사용한다.
