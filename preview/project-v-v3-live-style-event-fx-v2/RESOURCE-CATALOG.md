# 전투 이펙트 리소스 카탈로그

아래 명칭은 재생·비교를 위한 임시 라벨이다. `BOSS ULT.`는 사용자 승인으로 아포칼립스 보스 궁극기에 연결됐고, 나머지 5종은 `UNASSIGNED` 상태다.

| 번호 | 임시 라벨 | 시각 식별 특징 | 사운드 식별 특징 | 활용처 |
|---:|---|---|---|---|
| 01 | CRITICAL | 진홍색 이중 절단과 짧은 충격 섬광 | 검풍, 둔중 충격, 저역 감쇠 | 미지정 |
| 02 | COUNTER | 청색 방어 충돌 뒤 적색·청색 역방향 검풍 | 방어 충돌, 역검풍, 금속타 | 미지정 |
| 03 | ULTIMATE | 보라·금색 대형 사선 절단과 지면 파열 | 흡입, 마검 절단, 에너지 방출 | 미지정 |
| 04 | BOSS ULT. | 철흑·암적색 낙하 충격과 대형 붕괴 | 압력 강하, 금속 붕괴, 충격파 잔향 | 아포칼립스 보스 궁극기 |
| 05 | DODGE | 빙청색 횡방향 공기 절단과 잔상 | 고속 검풍, 공기 절단, 이탈음 | 미지정 |
| 06 | REVIVE | 에메랄드·금색 상승광과 역행 파편 | 역재생 질감, 회복 파동, 깊은 잔향 | 미지정 |

각 묶음은 `원출력 → 투명 시트 → 런타임용 아틀라스 → 녹음 사운드` 순서로 분리되어 있다. 상세 경로와 SHA-256은 `manifest.json`에서 관리한다.
