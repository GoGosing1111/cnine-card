## 원본 보존과 확인

- 내장 `image_gen`의 참조 이미지 기반 생성·편집으로 제작했다. 각 프롬프트는 작업 이력과 함께 보존했다.
- 승인 원본은 생성 결과의 바이트를 그대로 복사한 1024×1536, 정확한 2:3, 8-bit RGB PNG다. 리사이즈·재압축·사진 합성은 하지 않았다.
- 사용자가 재첨부한 PNG는 파일 인코딩이 달라 파일 SHA-256은 다르지만, 읽기 전용 디코딩으로 비교한 **네 장의 전체 픽셀은 생성 원본과 모두 동일**했다. 첨부 파일·원본 SHA-256과 디코딩 픽셀 SHA-256은 승인 기록에 있다.
- 정본은 `assets/ui/project-v/mercenaries/approved-20260926/`에 있으며, 프리뷰는 그 정본만 참조한다.
- PC 1440px·모바일 390px의 원본 로드와 가로 넘침, 160px 축소와 기존 용병 프레임 조합을 확인했다. 프레임은 HTML 계층이며 원화에 합치지 않는다.

## 교체 이력

V1에서 의상·배경 방향을 잡았다. V2의 헤어·자세 반복과 희야의 추가 팔 오류, V3의 얼굴 이질감, 디임 V4의 얼굴·머리 비율·피부 톤은 후속 지적으로 교체했다. **희야 V2는 반려본이며 다음 제작 입력으로 쓰지 않는다.**

망순·조은·희야 V4 이후 사용자가 각각 확정 이미지를 다시 첨부했다. 봉순은 가방 든 V1을 최종 선택했으므로 V4를 다시 대표본으로 올리지 않는다. 디임 V5는 얼굴 방향만 이어받았고 최종 선택은 V6다.

일부 디임 생성 요청은 도구 출력 필터로 이미지가 반환되지 않았다. `prompt-diim-v3.txt`, `prompt-diim-v5.txt`, `prompt-diim-v6.txt`는 미출력 요청 이력이며 최종 생성 프롬프트와 구분한다. 최종 디임 V6는 `prompt-diim-v6-standing.txt`에서 생성됐다.

이번 승인은 원화 확정이다. 신규 카드 코드·등급·스킬·SD·획득·CMS·라이브 도감 등록은 별도 연결 지시 전까지 추가하지 않는다.
