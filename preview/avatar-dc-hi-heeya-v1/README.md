# DC 하이희야 — 테니스 유니폼 아바타

사용자가 승인한 테니스 일러스트와 새 투명 장비창 전신이다. 이름은 **DC 하이희야**, 코드 `DC_HI_HEEYA`, 시리얼 **A-22**다.

## 승인 및 자산

- 2026-09-17: 테니스복 최종안 승인, 적용·장비창 자산 제작·T1조은 동급 옵션·DC 전원 11일 지급 지시.
- 로비 원본은 승인 이미지 그대로 보존한다.
- 장비창 전신은 내장 image_gen으로 투명 RGBA를 생성했다. 배경을 코드로 추출하거나 얼굴/체형을 변형하지 않았다.
- 런타임 파생본은 기존 장비창 규격에 맞춘 균일 크기 조정·투명 여백·WebP 압축만 수행한다.
- 원본과 파생본 해시·규격·알파 검사는 `runtime-manifest.json`, 제작 프롬프트는 `lobby-prompt.md`와 `equipment-prompt.md`에 기록했다.

## 연결 및 검수

공용 `SoopketmonCharacterLoadoutV2`를 재사용했다. PC 1440px·모바일 390px에서 이미지 로딩, 전신·발끝 표시, 가로 넘침, 일러스트/장비창 탭 전환을 확인했다. 어두운 배경과 밝은 배경에서 실제 투명 가장자리를 확인했다.

옵션은 운영 `T1_JOEUN`의 코인 획득량 +75%, 레이드 입장 +10회와 동일하다. 지급 시점부터 11일 보유권을 부여하며 장착 상태를 강제로 변경하지 않는다. 판매는 OFF, 이벤트 지급으로 등록한다.
