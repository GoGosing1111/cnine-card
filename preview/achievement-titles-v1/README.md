# 폐인 · 우승청부사

사용자 확정 조건(2026-09-27):
- 폐인: 카드 도감 전체 100% **그리고** 차량 도감 90% 이상.
- 우승청부사: 서로 다른 트로피 4종. 같은 종류의 반복 획득은 한 종류로 집계.

전용 투명 문장과 이름 색상을 장비의 칭호 화면, 닉네임 옆 공용 배지, 공개 명함, CMS에 연결한다. 폐인은 자수정·백금의 도감 문장, 우승청부사는 금빛 트로피·루비 문장이다. 사용자 후속 지정으로 장착한 폐인은 전체 전투력 +50,000, 우승청부사는 +75,000을 적용한다. 기존 칭호와 같이 PVE·PVP에 동일하게 적용하고 기간 제한 없이 소유한다.

## 자산

내장 ImageGen으로 두 문장을 각각 생성했다. 정확한 요청은 `prompts.json`, 무가공 원본은 `source/`, 파생 자산·해시는 `manifest.json`에 보존한다. 배포용 이미지는 알파를 유지한 384×384 WebP다. 원본은 변경하지 않았다.

## 획득과 표시

- 기존 장비 화면의 비동기 `POST character/title/sync`가 자동 판정한다. 장비 목록 로딩과 전투 요청에는 업적 스캔을 추가하지 않는다.
- 카드: 활성·PUBLIC 도감 항목 중 수량이 1 이상인 서로 다른 카드. 비공개·비활성·은퇴 카드를 제외하며 추가 보유분으로 누락 카드를 채울 수 없다.
- 차량: 활성·공개 차량 카탈로그의 보유 종류 수. `보유×10 >= 전체×9`로 계산하며 반올림으로 문턱을 넘기지 않는다. 두 카탈로그 모두 비어 있으면 해금하지 않는다.
- 트로피: 명함과 같은 공식 정산·지급 기록. 듀오 챌린저, 클랜 정규시즌 우승, 3연속 챌린저, 랭크 시즌 우승, 클랜 챔피언스 우승 중 4종 이상. 미완료·테스트 정산과 다른 계정 기록은 제외한다.
- 기존 칭호 테이블과 유니크 키를 사용한다. 두 등록 행과 신규 foundation marker는 한 번에 저장한다. 운영자가 수정한 등록값은 재배포로 덮어쓰지 않는다.
- 기존에 전투력 0으로 등록된 두 칭호도 별도 일회성 power marker로 50,000/75,000을 반영한다. 두 수치와 marker는 같은 배치에서 저장하고, 이후 CMS 수정값과 기존 소유·장착 기록을 보존한다.
- 지급은 한 배치로 처리하고 중복 요청·동시 요청·응답 유실 재시도에도 소유 행은 1개만 남는다. 획득 후 카탈로그가 늘거나 보유 카드가 줄어도 회수하지 않는다.
- 이번 두 코드의 자동 조건은 사용자 확정값으로 고정한다. CMS에서 비활성·비공개 또는 MANUAL로 전환하면 자동 해금을 중단한다.
- 신규 업적 판정의 조회는 최대 8개(대상 1, 도감 집계 2, 공식 트로피 5)이며 기존 계정의 두 칭호가 모두 지급되었으면 조회 1개로 끝낸다. 전체 계정 순회나 보유 항목별 왕복을 하지 않는다.
