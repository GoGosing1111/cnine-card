2026-09-16 사용자 승인: **“좋아 장비창도 만들어서 추가해”**.

승인된 로비 원본의 얼굴·긴 검은 머리·키 큰 슬렌더 체형·긴 다리·T1 클랜 유니폼·밀착 미니스커트를 유지했다. 장비창은 같은 인물과 의상의 별도 선 자세로 제작했다.

## 자산

- 로비: `assets/avatar-t1-joeun-lobby-source-art-v1.png` — 승인 원본 1024×1536 RGB PNG를 무가공 보존.
- 장비창: `assets/avatar-t1-joeun-equipment-source-art-v1.png` — 내장 image_gen이 생성한 실제 알파 포함 1024×1536 PNG를 무가공 보존.
- 런타임: 로비 1024/640px WebP, 장비창 640×1664 알파 WebP. 장비창은 투명 여백 정리·균일 배율·패딩·압축만 적용한다. 얼굴·의상 재생성이나 코드 배경 제거를 하지 않는다.
- 생성 방식과 실제 프롬프트: `prompts.md`. 원본·파생 파일 해시와 알파 검증: `manifest.json`.
- 이전에 반려된 실사형·플리츠 치마 시안은 사용하지 않는다.

## 등록

`T1_JOEUN` / **A-18 T1 조은**을 기존 아바타 CMS·장비창·로비 계약으로 등록한다. 신규 등록 기본값은 활성·공개·판매 OFF, 획득 UNSET, 가격 NULL, 효과 미설정이다. 운영자가 CMS에서 설정하며 이번 등록으로 소유권을 지급하지 않는다. 등록 재실행 시 운영자 편집과 기존 아바타 설정을 보존한다.

## 재현·검수

`node preview/avatar-t1-joeun-v1/build-assets.mjs`로 원본 해시 검증 후 런타임 파일과 매니페스트를 만든다.

프리뷰 `index.html`은 기존 `SoopketmonCharacterLoadoutV2` 장비창을 재사용한다. 검수 데이터는 계정에 저장하지 않는다. PC·모바일의 전체 실루엣, 밝고 어두운 배경의 알파 경계, 이미지 로딩·잘림·가로 넘침을 확인한다.

Chrome 1440×1000·390×844에서 로비/장비창 전환과 실제 장비창 컴포넌트를 검수했다. 머리·손·부츠 잘림, 가로 넘침, 이미지 로딩 오류와 페이지 오류가 없고 밝은 배경에서도 투명 경계를 확인했다. 장비창 런타임 WebP는 132,076바이트다.

`tests/avatar-t1-joeun-cms.test.mjs`에서 실제 PostgreSQL 호환 CMS 등록·설정 보존·원자적 롤백·장착 이미지 계약을 확인한다. 운영 배포는 전체 `npm run release:gate` 통과 후 `npm run deploy:production`만 사용한다.
