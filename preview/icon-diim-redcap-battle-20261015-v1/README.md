# 디임 ICON · 자율 병기 준비

새 사용자 사진과 선택 기술 AUTONOMOUS_WEAPON(자율 병기)의 격리 리소스 검수판이다. 기존 디임 ICON(CN-1C000001)과 원화·스킬·획득을 교체하지 않는다. 정지 SD, 정지 병기 본체, 16프레임 스킬 FX만 제작하며 신체 동작 시트는 없다.

원본 사진 `sources/diim-photo-original.png` SHA-256: `59E79BBB4BB5D40D368DACB63E19D917FB9883ED4E586972211A8C39606687F1`. 바이트 그대로 보존하고 기존 ICON 프레임을 재사용한다. 실제 신규 카드 ID는 null, 운영 수치는 null, 등록·획득·전투 활성화는 OFF다.

## 빌드와 실제 판정

`node preview/icon-diim-redcap-battle-20261015-v1/build.mjs`

이 폴더만 출력한다. SD·병기 원본 true-alpha PNG를 비율 유지 672px+48px 여백의 768px 무손실 WebP로, FX 원본 4×4 16셀을 384px 셀/1536px 아틀라스로 패킹한다. 경계 alpha≤12와 고유16프레임을 검사하며 알파 재도색/컬러 키/가짜 중간 프레임을 만들지 않는다. 원본·확대/축소·본체와 FX를 분리 보존한다.

`build-fixtures.mjs`는 기존 신규 ICON 준비 엔진의 진짜 Symbol 입력을 이용한다. 초기 스냅샷을 저장한 뒤 실제 시뮬레이션을 실행하며 사건을 합성하지 않는다. 아군2·적2, 병기 별도 slot10이다. `independent.json`은 소환 후 독립 공격9회·실제 피격3회, `owner-death.json`은 주인 KO 직후 병기 소멸을 검수한다. 모든 숫자는 검수 fixture 전용이며 운영 기본값이 아니다.

## V3 연결

기존 V3의 BattleCharacter·playEvents·HP동기화·소환 수명주기를 재사용한다. 준비 인스턴스에서 실제 ICON_SUMMON 사건이 올 때 같은 서버 actor ID의 병기에 새 이미지를 넣는다. 본대/용병 슬롯에 끼워 넣거나 실제 슬롯을 재배정하지 않는다. HP·피해·공격 횟수·주인 사망은 서버 사건만 소비한다.

시각 콘셉트는 캔디 자동포탑(가칭)이다. 병기 본체는 고정 래스터1장이고 포구/발 좌표는 input.json의 원본 픽셀 기준으로 고정한다. FX0–7은 전개,8–10은 포구에서 표적으로 향하는 볼트,11–15는 표적의 충돌/소멸이다. 볼트는 전체 스프라이트의 좌우반전만 하며 포신이나 이미지 부분을 변형하지 않는다. 사건 재생/일시정지/0.25×·1×/이전·다음 사건/FX OFF 및 원본16프레임 보기로 검수한다.

공통 엔진·카드 로스터·API·운영 데이터는 변경하지 않는다. 이미지 생성 프롬프트와 입력 출처는 별도 generation 기록에 연결한다. 기술 검사와 사용자 시각 승인은 별개다.

## 기술·화면 검수

- `qa.test.mjs`: 원본 해시, SD/병기 비율·기준점, 16개 FX 원본/아틀라스 픽셀, 독립 공격·피격 및 주인 사망 소멸 5개 검사 통과.
- `qa.browser.mjs`: PC 1440·모바일 390에서 실제 서버 시나리오 전체 재생, 0.25×/1×, 일시정지, FX OFF, 사건 탐색, 독립 HP·공격·피격·주인 사망을 통과. `qa/report.json`에 기록.
- `qa.lifecycle.mjs`: 초기 서버 HP, 원래 0/2 슬롯을 반복 탐색·resize 후에도 유지, FX OFF 후 원본 프레임 숨김, 재생 복귀 시 원본 프레임 제거, 로딩 중 dispose, 실제 뒤로가기 후 단일 canvas 복구 통과. `qa/lifecycle.json`에 기록.
- `qa.capture.mjs`: 최종 병기 크기·HP바·일반 공격 문구를 적용한 화면과 짧은 재생 영상. 전체 판정 검사를 반복하지 않고 실제 첫 병기 공격까지 느린 재생 후 기록된 사건을 탐색한다.

최종 화면은 `qa/1440-overview.png`, `qa/390-overview.png`, `qa/*-final-summon.png`, `qa/*-fx-off.png`, `qa/*-independent-result.png`, `qa/*-owner-death.png`이며 영상은 `qa/1440-review.webm`, `qa/390-review.webm`이다. 원본 사진·3개 생성 PNG는 `sources/`, 실제 생성 프롬프트·출처·생성 이력은 `generation-prompts.json`, 파생 해시·알파 검사와 셀 기준은 `manifest.json`에 있다.

SD·병기의 발 좌표는 원본 픽셀 측정값을 768px 결과로 동일 비율 변환했다. 병기 본체는 별도 슬롯 안에서만 2배 등비 확대했고 HP바는 실제 본체 상단에 배치했다. 원본 FX의 접촉 peak는 zero-based 11이다. 실제 병기 공격은 8–15 프레임 부분 재생을 사용하며 HP 적용은 변경하지 않은 공통 V3의 서버 사건 타이밍을 따른다.

기술 검수 완료는 사용자 시각 승인을 의미하지 않는다. 신규 실제 카드 ID·운영 수치는 null, 등록·획득·전투 활성화는 OFF 상태다.
