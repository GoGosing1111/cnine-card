## 검과 원본 보존

사용자 최종 지시인 화면 반대 방향 전환은 V3 전체 이미지를 정확히 좌우 반전해 적용했다. RGBA 채널 비교 불일치는 0이다. 현재 마스터는 화면 오른쪽을 바라보며 손잡이는 오른쪽, 칼집은 왼쪽으로 이어진다. 입의 검 없이 일본도 1자루와 칼집 1개를 사용한다.

`master-v4-facing-right.png`의 SHA-256은 `0C7B37275767E6FC428F3AE484C76B1D1BE7958CDF1E91E3F725A4C2A11DF48C`다. 대기에는 이 원본 한 컷을 사용한다. 새로운 호흡 시트의 칼집 변형은 반려 기록으로 남기고 재생에서 제외했다. 슬래시의 마지막 납도 준비 컷도 칼집 방향과 파지가 어긋나 제외했다. 완전한 납도 연속 동작은 구현했다고 표시하지 않는다.

캐릭터 프레임은 완전한 인물 연결 영역을 분리해 전체를 동일 비율로 축소·배치한다. 칼·손·몸을 따로 휘거나 늘리는 처리는 없으며, 무릎을 꿇는 컷도 서 있을 때의 신체 기준 크기를 유지한다. 부드러운 일본도 곡선을 직선으로 펴는 처리도 하지 않는다. 프레임 사이에는 생성된 원화 간의 차이가 있으므로 시각 승인과 기술 검증을 구분한다.

승인 일러스트는 `assets/sources/jokro-source-art-approved-20261017.png`에 그대로 보존했다. SHA-256은 `82297D41E879DAB7DF179345875EBF329A3E825BB20BD76C68BFBE91667DFBDB`다. 전투 마스터와 별개다.

내장 ImageGen으로 제작했다. 새 일러스트와 효과의 원본 PNG, 네이티브 알파, 프롬프트, 파생 프레임·아틀라스와 해시는 이 폴더에 저장했다. 과거 시안은 이력으로 남기며 `manifest.json`의 현재 참조만 재생한다. 같은 족로 콘텐츠에서 제작한 용 이펙트와 UI 프레임을 이어 사용하고, 전용 버튼 원본을 추가 제작해 실제 컨트롤에 연결했다.

기존 V3 전투 엔진, PixiJS 8.20.0, GSAP 3.13.0과 카드 도크를 사용한다. 아군·적군 각 5장에 족로를 별도 용병 슬롯으로 표시한다. `V-992`는 독립 프리뷰 어댑터의 임시 식별자이며 운영 명부에는 쓰지 않는다. 원화는 하단 참고 화면에만 표시하며 전투 일러스트 컷인 로딩과 렌더링을 제거했다.

청룡단천은 2.12초에 발도와 화면 절단, 2.72초에 용린 파열이 이어진다. V3 전장을 캡처한 두 조각을 강체로 이동하고, 신규 12프레임 참격과 12프레임 파열을 재생한다. HUD·카드 도크는 유지한다. 동작 줄이기에서는 전장 분할과 카메라 흔들림을 생략하고 검기는 유지한다. 중단·대상 소멸·이전 시점 탐색·크기 변경·정리 시 캡처 텍스처를 해제한다.

캐릭터 모션은 첫 타격을 기준으로 시간을 2배 압축했다. 스킬 이펙트·효과음·타격 시각·전체 이펙트 길이는 기존 값을 유지한다. 사용자가 조작하는 프리뷰 배속은 별도다. SSS 리미티드 대사는 같은 콘텐츠의 전용 이미지 프레임 안에 DOM으로 표시하며, 얼굴 초상 없이 5개 문구를 공격·스킬 시전마다 순환한다. 종료·중단 후에도 마지막 대사를 남기고, 문구 길이로 레이아웃이 움직이지 않도록 높이를 확보했다.

## 진무 상위 성능 구성

`balance.mjs`와 `references/jinmu-operating-baseline-20261018.json`을 따른다. 기준은 `origin/main`의 실제 진무 정책이며 원본 파일·커밋·해시를 함께 보존했다. 기본 전투력 1,347,840 → 1,617,408, 신체 능력·공격력/체력/방벽 연계·기본 공격 상한은 20% 상승, 행동 배율 3.12와 면역은 유지, 피해 감소는 75% → 80%다.

청룡참은 총 672% / 4턴 / 에너지 30, 청룡단천은 총 840% / 5턴 / 에너지 35다. 진무의 총 560% / 5턴 / 35보다 높다. 광역 피해는 생존 대상 전체에 나눠 한 번씩 배정하며, 연출의 두 충격이 두 번의 추가 피해를 발생시키지 않는다. 재시도 영수증도 중복 생성하지 않는다. 이 계산은 검수용 로컬 시뮬레이션이며 실서버 HP·피해·쿨다운을 변경하지 않는다.

재생·일시정지·탐색·배속·중단, 시전 중단/대상 소멸, 동작만 보기, 아우라, 동작 줄이기를 지원한다. 효과음은 기존 실제 녹음 큐를 연결하며 기본 OFF다. 같은 V3 GSAP 시각으로 동작·타격·효과음을 제어하고, 서버 피해나 재화는 변경하지 않는다.
