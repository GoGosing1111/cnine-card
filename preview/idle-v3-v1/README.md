# 심연 원정 · V3 방치형 검수 V1

상태: **INDEPENDENT_PREVIEW_ONLY / 사용자 검수 대기 / 무음 고정**

프리뷰 주소: `/preview/idle-v3-v1/`

## 구현 범위

- 3지역 × 4구간, 각 지역 마지막은 관문 보스.
- ‘자동 원정 시작’ → 승리한 구간 다음으로 자동 진행.
- 적 능력치는 구간별 고정. 플레이어 스펙에 비례해 적을 키우지 않는다.
- 36행동 안에 적 HP를 0으로 만들지 못하면 실패. 남은 HP 비율이 유리해도 클리어가 아니다.
- 실패 시 열린 일반 구간에서 자동 사냥. 패배로 재료·돌파 기록을 차감하지 않는다.
- 일반 구간을 직접 골라 반복 가능. 미돌파 구간과 보스는 안전 사냥 대상으로 선택할 수 없다.
- 연구 데이터로 원정대 훈련. 레벨당 기본 전투력 +20%p, 최대 20레벨. 현재 진행 중인 전투의 스펙은 바뀌지 않고 다음 전투부터 적용된다.
- 배틀슈트 03 아메시스트 + 황금용 AR를 별도 지원 유닛으로 포함한다. 5장 덱 슬롯을 차지하지 않으며, 기존 독립 사격 시계와 실제 피해 계산을 적용한다. 직전 전투의 슈트 피해량을 별도로 표시한다.
- 첫 돌파는 기본 보상 + 추가 보상 2배. 이후 해당 구간 반복은 기본 보상만 지급.
- 중지는 현재 전투 정산 후 적용. 화면을 떠나면 즉시 취소하고 미완료 전투는 정산하지 않는다.
- 이 브라우저의 `cnine_preview_idle_v3_v1`에만 진행 저장. 재방문 시 자동 시작하지 않는다.
- 운영 음량 설정은 변경하지 않는다. 프리뷰에서 V3 오디오 믹서만 비활성화하여 완전 무음으로 동작한다.

## 전투·아트 단일 기준

`functions/_battle_v2_preview.js`의 `buildFighter`, `buildMonsterFighter`, `buildBattleSuitFighter`, `simulateBattleV2Preview`, `publicFighter`, `teamSummary`를 직접 import한다. 서버 파일 자체는 수정하지 않았다. 검수 모드 전용 제한 행동·구간 수치를 적용하며, 라이브 계정의 전체 장비·전직·고유특성 계산을 그대로 복제한 스펙은 아니다.

일반 HUNT 피해 하한은 약한 슈트도 적의 최대 HP 비례 피해를 보장해 ‘스펙에 따라 막힘’을 지워버릴 수 있다. 따라서 이 독립 검수의 몬스터 계산에는 기존 `pve_difficulty: APOCALYPSE`의 스펙 연동 하한과 슈트 관통 공식을 재사용한다. 적의 원래 능력치 자체는 플레이어와 무관하게 고정이다. 운영 아포칼립스·V3·배틀슈트 수치는 변경하지 않는다.

연출은 **운영 중인 V3 번들 한 개**와 `js/battle-v3-live.js`의 `prepareLoading` / `createRenderer`를 호출한다. PixiJS·GSAP를 중복 번들링하지 않는다. iframe은 라이브 V3의 실제 viewport와 모바일 카드 프레임을 보존하기 위한 경계다.

일반 전투 진형, SD 캐릭터, 하단 `rosterCardHtml`, `css/card.css`, `css/battle-v3-live.css`, ZENITH / SUPERSTAR / Faker 프레임 계층은 재구현하거나 덮어쓰지 않는다. 지역별 배경도 V3에 이미 존재하는 배경 선택 API만 이용한다. 몬스터 SD 식별 모드는 HUNT를 유지한다.

검수 덱은 실제 승인 로스터의 **FUR 3장 + SUPERSTAR 1장 + ZENITH 1장**이다. 각 카드 200,000 + 배틀슈트 300,000 = 총 1,300,000에서 시작한다. 계열 배정과 훈련 보정은 프리뷰용 수치이며 특정 계정의 스펙이 아니다. 용병·실계정 덱은 연결하지 않았다. 배틀슈트 추가에 맞춰 저장 스키마를 2로 올렸으며 이전 검수 상태는 새 스펙으로 초기화된다.

- 카드 원화: `assets/ui/project-v/characters/{fur,zenith,superstar}/manifest-*.json`의 `sourceArt`.
- 전투 SD: 같은 매니페스트의 `battleSprite`와 운영 아트 어댑터 4종.
- 몬스터 원화/SD: `assets/ui/project-v/monsters/hunt-tower/manifest-v1.json`.
- 배틀슈트·황금용 AR 사격 아틀라스: `assets/ui/project-v/account-battle-suits/manifest-v2.json`의 승인된 조합. 스킬칩은 이번 프리뷰에 장착하지 않았다.
- 경량화: 운영 반응형 카드/SD 맵의 기존 WebP 사용, 맵이 없으면 원본 유지.
- 연속 사격 메모리: Pixi 8.20의 uid/tick 기반 stroked BitmapText 캐시가 매 피해 숫자마다 새 글꼴 아틀라스를 만드는 것을 방지한다. 이 프리뷰의 피해 숫자 스타일에만 내용 기반 캐시 키를 적용한다. 글꼴·크기·외곽선·색은 변경하지 않고, 운영 V3 파일도 변경하지 않는다.
- 신규 이미지·스프라이트·합성음 생성 없음. 기존 아트 앵커 및 라이브 리소스 수정 없음.

## 미연결 범위

운영 메뉴, 기존 방치형, 계정 API, DB, 실제 코인/아이템/우편/보상은 전혀 연결하지 않았다. 네트워크는 정적 리소스 GET만 수행한다. 프리뷰 저장 데이터는 개발자 도구로 조작 가능한 검수 상태로, 운영 보상 권한으로 사용할 수 없다.

오프라인 정산도 아직 연결하지 않았다. 실제 출시 시에는 서버의 검증된 최고 클리어·덱 스냅샷, 유저 뮤테이션 락, 원자적 보상/멱등성 영수증, 시각 조작/중복 탭 방어, 오프라인 보상 상한·CMS 설정을 별도로 설계·검수해야 한다.

## 빌드 및 검사

```text
npm run build:idle-v3-preview
npm run test:idle-dungeon
npm run release:gate
```

새 프리뷰 회귀 검사는 `tests/idle-v3-preview-v1.test.mjs`이며 기존 방치형 검사와 함께 릴리스 게이트에 포함된다.

시드 1~30 검증 결과: 기본 전투력은 1-1~1-3 승리, 1-4는 0/30승. 훈련 Lv.3은 1-4 30/30승. 훈련 Lv.20은 전체 12구간 각각 30/30승. 이는 **검수 밸런스**이지 운영 보상·난이도 확정값이 아니다.

재생 세대와 전투 객체를 검사해 중복/취소/이전 판의 결과가 중복 정산되지 않게 했다. 새 창이나 탭을 만들지 않고 기존 QA 탭을 재사용한다.

기존 테스트 창이 다른 창에 가려지면 Chromium이 iframe의 rAF를 1FPS로 제한하는 환경이 있다. 백그라운드 연속 전투 자동검사는 `?backgroundQa=1`에서만 타이머 기반 프레임 스케줄러를 사용한다. V3·GSAP·피해 계산은 그대로 실행하며, 기본 주소에서는 이 스케줄러를 적용하지 않는다. 부드러움/FPS 실측의 근거로 이 검수 모드를 사용하지 않는다.
