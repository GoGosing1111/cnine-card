# 라그니엘 · SSS 전투 SD와 종언의 백금성역

사용자 지정 이름 **라그니엘**, 등급 **SSS**. 백색·금색 갑옷, 붉은 머리, 날카로운 금속 면갑, 면갑에서 목 아래까지 연결된 백색 고르제, 광익과 대검을 유지한 전투 리소스다. 칭호 `종말의 대천사`와 궁극기 이름 `종언의 백금성역`은 이번 시연의 제작 명칭이다.

**상태: 기술 검수 완료 · 사용자 시각 검수 대기.** 독립 프리뷰이며 운영 도감·획득·편성·API·스킬 배정에는 연결하지 않았다. `V-046`은 프리뷰 어댑터에 필요한 로컬 식별자다. 공격력·계수·확률·비용·쿨다운은 지정하지 않았다.

## 보기와 재현

현재 검수 서버: <http://127.0.0.1:8817/preview/mercenary-ragniel-v1/>

프로젝트 루트에서:

```powershell
node preview/mercenary-ragniel-v1/build-assets.mjs
node preview/mercenary-ragniel-v1/build.mjs
node --test preview/mercenary-ragniel-v1/qa.test.mjs
$env:RAGNIEL_PREVIEW_PORT = '8817'
node preview/mercenary-ragniel-v1/serve.mjs
```

서버는 로컬 주소에서 정적 파일의 GET/HEAD만 제공한다. 계정·API·운영 DB를 호출하지 않는다. 자산을 다시 빌드하면 기술 검수 상태가 대기로 초기화되므로 재검수 후 기록한다.

총 동작 26프레임 + 이펙트 28프레임. 각 단계의 팔·다리·날개·검 또는 이펙트 형태가 달라지는 생성 원본이다. 보조 잔상·입자·지면광은 이 연속 프레임 위에 더했다.

- 원화: 1024×1536 RGB PNG, 사용자 선택 V5를 바이트 그대로 보존했다.
- 기본 SD: 1254×1254 RGBA PNG, 실제 투명 픽셀 55.16%, 외곽 4px의 가시 픽셀 0개.
- 동작 셀: 768×768 RGBA, 발 기준점 `(0.5, 0.9)`.
- 이펙트 셀: 512×512 RGBA. 궁극기 각 셀의 지면광 높이를 개별 등록했다.
- 런타임 아틀라스: lossless WebP. 개별 PNG는 `assets/frames/`에 있다.
- 원본 시트는 `assets/source/`에 보존했다. 첫 궁극기 시트는 외곽 여백이 부족해 ImageGen V2로 수정했으며, V1은 생성 이력으로만 남겼다.
- 추출은 native alpha의 연결된 캐릭터를 구분하고 투명 캔버스에 배치하는 방식이다. 정사각형 격자로 단순 절단해 검끝이나 이웃 날개를 잘라내지 않는다. 원본 그림을 재채색하거나 알파를 임의로 교체하지 않았다.

## 타이밍과 정렬

| 시점 | 궁극기 동작 |
|---:|---|
| 0.00초 | 날개 개방, 성검 집중 |
| 0.72초 | 대시 시작 |
| 1.16초 | 대검 들어 올리기 |
| 1.58초 | 검날 접촉, 검격 시트 6번 / 궤적 시트 4번 |
| 1.78초 | 거대 성검 형성 |
| 2.32초 | 성검 낙하 |
| 2.42초 | 최종 지면 충돌, 시전 시트 5번 / 궁극기 시트 5번 |
| 2.62초 | 광익 파열 |
| 3.55초 | 금빛 파편과 잔광 소멸 |

대시 단독은 1.45초, 검격 단독은 1.85초이며 검날 접촉은 0.66초다. 프레임 번호는 0부터 센다.

검격 6번의 원본 칼날 접촉점 `(1054, 690)`과 발 기준점 `(887, 711)`을 등록했다. 발에서 칼날까지의 실제 오프셋·체격 배율·진형 배율을 사용해 접근 지점을 계산하므로 칼날과 대상 몸통의 타격 광원이 맞는다. 실제 Pixi 좌표 변환 회귀 검사에서 오차는 0.01 전장 단위 미만이다.

궁극기는 광역 착탄이다. 대상의 지면 깊이를 유지하고, 광익 전체가 보이도록 착탄 중심의 가로 위치를 화면 안으로 보정한다. 모바일에서 가장자리 적 때문에 이펙트 전체가 지나치게 작아지지 않는다. 전장 진형·일반 카드·하단 카드 도크는 이동하거나 재작성하지 않았다.

## 실제 렌더러와 재생 제어

- **PixiJS 8.20.0**: `source/RagnielSkillFX.js`가 공유 V3 엔진의 `effectLayer`와 기존 캐릭터를 사용한다.
- **GSAP 3.13.0**: V3 `simpleTimelines`에 등록된 타임라인 하나가 `clock.time`을 진행시킨다. 동작 프레임, 이동, 궤적, 광익, 충돌과 소멸을 이 시간에서 결정한다.
- 공유 엔진: `preview/project-v-v3/source/battle/BattleEngine.js`.
- 연결: `source/preview.js`에서 기존 V3 준비·렌더링·아트 어댑터를 사용한다. 새 Application이나 별도 전장 렌더러를 만들지 않는다.
- 일반 카드 5장은 그대로 유지하며 라그니엘은 `setFormationMercenaries`의 별도 용병 슬롯에 배치한다.
- 원화는 상세·컷인용, 투명 SD와 동작 아틀라스는 전장용이다. 카드 도크에 SD를 넣지 않는다.
- 64개 재사용 Sprite 풀이 있고, 스킬별 Graphics와 타임라인을 매 프레임 새로 만들지 않는다.
- 시점 재계산은 순수 함수 `skill.mjs`를 사용한다. 되감기와 재생 반복이 피해·HP·승패를 누적 변경하지 않는다.
- 재생/일시정지, 0.25·0.5·1·2배속, 시점 탐색, 시전 중단, 대상 소멸, 중지, 페이지 이탈 시 정리를 제공한다. 공유 텍스처 소스는 파괴하지 않는다.

## 선택 효과음

기존 검수된 실녹음 합성 클립을 재사용한다. 기본값은 OFF다. 새 절차적 합성음·오실레이터·단일 알림음을 만들지 않았다.

원본 출처와 라이선스는 `preview/project-v-v3-event-fx-v1/assets/audio/manifest.json` 및 해당 프리뷰 README가 기준이다. 라이선스는 **Mixkit Free License**이며 CC0로 재분류하지 않는다: <https://mixkit.co/license/#sfxFree>.
