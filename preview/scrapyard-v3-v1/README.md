# 폐차장 회수 작전 — V3 연속 교전 검수

2026-09-09 / **독립 프리뷰·사용자 검수 대기 / 운영 연결 안 함**

## 이번 범위

- 기존 일반 카드 5장 + 별도 배틀슈트로 OUTER 한 구역을 전투한다.
- 일반 몬스터 3마리로 시작, 빈 기존 적 슬롯에만 증원, 일반 9마리 전멸 후 보스 1마리 출현.
- 한 번의 시뮬레이션·한 V3 렌더러·한 전투 상태를 사용한다. 증원 경계에서 HP/방벽/게이지/시작 효과/마법 예산/슈트 독립 사격 시계를 초기화하지 않는다.
- 전투력 부족으로 전멸하거나 행동·시간 한도를 넘으면 실패한다. 적 스펙은 플레이어 전투력에 맞춰 자동 보정하지 않는다.
- 무한의탑, 운영 폐차장 화면·API, 입장권, 보상, 제작, CMS 값, 계정 저장 상태는 변경하지 않는다.
- 신규 투명 몬스터 SD 2종은 검수용이다. 운영 몬스터 원화·SD 또는 승인된 슈트·무기 원본을 덮어쓰지 않았다.

## 계산과 운영 권한의 경계

`source/encounter-model.mjs`는 실제 `functions/_battle_v2_preview.js`의 전투 함수를 가져와 **브라우저 로컬에서** 샘플 편성을 계산한다. 운영 서버가 계정 덱을 조회하거나 전투/보상을 저장하는 구현이 아니다.

공유 함수에는 선택 인자 `reinforcements`만 추가했다. 기본값 `[]`인 기존 호출은 이전 시드 결과와 바이트 단위로 동일하다. 현재 운영 라우트는 이 인자를 전달하지 않는다. 최대 40개 대기 인스턴스, 적 몬스터만, 고유 ID·슬롯·기초 수치 검증을 적용한다. 정식 연결 전에는 별도 서버 세션, 최신 실제 덱 조회, 차감·지급 원자성, 재접속·동시 요청 방지, CMS와 보상 정책 승인이 필요하다.

샘플 값은 출시 밸런스가 아니다. 일반 카드 합계 100만 + 슈트 30만, 적 일반 85만/보스 250만이다. 기존 APOCALYPSE 스탯 게이트 수식을 재사용한다. 검수 선택은 0.25×/1×/2×. `maxActions=100`, `maxDuration=2`는 엔진 내부 시계 한도이며 화면상의 2초 제한이 아니다.

시드 7123: 기본 편성 94행동·10/10 격파·승리, 저전력 편성 51행동·2/10 격파·패배, 강화 편성 92행동·10/10 격파·승리. 기본 편성 피해 합계 24,629,000 = 일반 카드 5,884,269 + 슈트 18,744,731.

## V3 통합과 애니메이션

- `scripts/build-scrapyard-v3-preview-v1.mjs`는 정식 V3 소스 진입점을 그대로 번들링하되 이 프리뷰에서만 엔진 생성자를 `source/ScrapyardBattleEngine.js` 하위 클래스로 바꾼다. 운영 V3 번들은 변경하지 않는다.
- PixiJS **8.20.0**, GSAP **3.13.0** (`package-lock.json`). 중복 CDN/라이브러리/렌더러 없음.
- `battle.html`은 라이브 `battle-v3-live.js`, 원본 카드 도크, `card.css`, 등급별 ZENITH/SUPERSTAR/Faker 프레임, 기존 아트 어댑터 체인을 그대로 로드한다. 카드 원화와 전투 SD는 분리한다.
- 새 증원 이펙트는 기존 Pixi `effectLayer`의 `Container`/`Graphics`로 먼지·금속 파편·착지 원을 그리고, 기존 `BattleEngine.timeline()`의 GSAP이 제어한다. 0초 진입 → 0.08초 파편 → 0.12초 착지 원 확산 → 0.48초 진입 완료 → 약 0.68초 정리. 신규 이펙트는 비공격 연출이며 피해를 계산하지 않는다.
- 사격·이동·피격·KO는 기존 V3 `playEvents`, `SkillTimeline`, `AccountBattleUnit`의 실제 프레임/총구/목표 기준점을 사용한다. 신규 사격 아틀라스나 임의 피해 타이머는 만들지 않았다.
- 이미지는 왼쪽을 보는 투명 전신 SD. 기존 적 view의 반전을 내부 스프라이트에서 상쇄한다. 일반 높이 280, 보스 395 기준이며 기존 적 5개 슬롯 중 0~2만 재사용한다. 아군/슈트 진형·원화 프레임 CSS는 수정하지 않는다.
- 적 ID는 `B:{slot}:SCRAP:{instance}`. 이전 탄착 큐를 비운 뒤 같은 슬롯을 재사용하고, 퇴장한 ID에 대한 이벤트는 차단한다. 이전 인스턴스의 최종 HP가 새 인스턴스에 적용되지 않도록 최종 동기화 대상을 현존 ID로 제한한다.
- 저전력 전투의 수백 발 적체를 막기 위해 프리뷰 이벤트 공급에 **16개 시각 큐 한도**를 둔다. 큐가 차면 실제 탄착 완료를 기다릴 뿐 서버 계산 피해·발수·원래 8발 병합 기준은 바꾸지 않는다.
- 1×/2×, 공격 경계 일시정지/재개, 재시작 제공. 정지 전에 현재 공격과 탄착을 마무리한다. 초기화·화면 이탈 시 epoch로 이전 실행을 무효화하고 공유 GSAP·파편·지원 사격을 정리한다. 사운드는 무음이며 라이브 사운드 설정은 건드리지 않는다.
