## 브라우저

Chrome / 데스크톱 1440×1200, 모바일 에뮬레이션 390×844.

- 일반 카드 5장(원화·등급 프레임), 별도 지원 슈트, 실제 알파 몬스터 3마리, Pixi canvas 1개 확인.
- 기본 편성: 360개 이벤트, 10개 인스턴스/10처치/최종 승리, 피해 표시 5,884,269 + 18,744,731. 종료 큐 0.
- 저전력 모바일: 994개 이벤트, 5개 인스턴스까지 등장/2처치/최종 패배. 큐 최대 16, 종료 큐 0. 오류 화면 없이 실패 결과 도달.
- 수백 발이 한꺼번에 쌓이던 초기 시안의 탄착 6초 초과 문제를 발견하여 생산자 역압(16개)을 추가했다. 기존 피해량·사격 발수·8발 병합 기준은 유지한다.
- 일시정지 후 두 번 측정한 처치/등장/이벤트 번호/HP/큐 상태가 완전히 동일. 재개 성공. 보스 등장 직후에도 정지 시 9/10 처치, 보스 단독, 큐 0 확인.
- 전투 도중(보스 출현 후) 초기화: 다시 3개 최초 인스턴스, 이벤트 0/처치 0, 카드 5장, canvas 1개, 큐 0. 이전 판 완료 콜백이 새 판에 결과를 표시하지 않음.
- 사망한 몬스터 슬롯을 재사용할 때 시체의 반투명 회전 자세를 기준 자세로 저장하는 문제를 발견했다. 스프라이트 교체 전에 애니메이션을 정리하고 view·전신 이미지의 원점/회전/alpha를 초기화하도록 수정했다. 사망 개체는 기존 쓰러짐 후 0.16초 페이드로 퇴장한다. 해당 재발 방지 자동 검사 포함.
- 모바일 가로 넘침 0px. 카드 5개는 너비 66px, x=8/79/150/221/292로 모두 프레임 내에 표시.
- 운영 `/api/` 호출 0, 계정/쿠폰/아이템/입장권/보상 저장 없음. 오디오 믹서 파기·무음 확인.
- 공용 V3의 미로드 아포칼립스 FX 캐시 해제 경고 1종을 관찰했다. 캐시 누락 경고이며 새 프리뷰의 전투 오류는 아님. 운영 FX를 수정하지 않았다.

백그라운드 자동화 탭에서는 기존 `?backgroundQa=1` rAF 보조를 사용했다. 이 결과는 실제 모바일 기기 FPS/메모리 보증이 아니다. 일반 URL은 네이티브 rAF를 유지한다. 실제 모바일 저사양 기기의 장시간 성능, 네트워크 재접속, 운영 계정 저장/보상 API는 이번 독립 검수 범위에 포함하지 않는다.
