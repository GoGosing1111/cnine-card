# 펫 도감 개편 · 제품 사실

리버스콜의 기존 펫 도감에 보유 개체의 능력치와 고유 특성 변경을 통합한다. 사용자는 펫을 고른 뒤 같은 상세 화면에서 능력치, 특성, 각 주사위, 전투 시작 이펙트와 PvE·PvP 편성을 관리한다.

- 사용자 요청: 펫 도감 UI 개편, 한 펫 화면에서 능력치·특성 모두 관리, 실제 주사위 굴림 연출, 이미지로 만든 아이콘과 UI 리소스 교체.
- 펫 등급은 C부터 SSS까지의 성장 상한이다. 공격·방어·체력·속도는 독립 추첨하며 상한을 넘지 않는다.
- 예시 이름은 정확히 **흑구**다. 이 검수의 SSS 흑구, 비용, 확률, 보유량은 가정이다.
- 능력치 주사위는 네 항목을 한 번에 추첨하고, 특성 주사위는 특성과 등급을 변경한다. 이전 또는 새 결과 중 한 묶음을 선택한다.
- 실제 펫 원화와 리버스콜의 어두운 RPG UI 맥락을 유지한다. 새 리소스는 ImageGen으로 제작하고, 기존 승인 버프 아이콘을 재사용한다.
- 운영 연결 전 로컬 기능 검수다. 실제 계정, DB, 비용 정책과 배포는 아직 연결하지 않았다.
