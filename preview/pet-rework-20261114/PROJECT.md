# 펫 개편 1차 구현 · 2026-11-14

## 최신 검수 화면 · 도감 통합

펫을 선택하면 원화·보유 개체·능력치·고유 특성이 같은 페이지에 나타난다. '관리' 추가 진입과 능력치/특성 탭을 없앴다. 새 ImageGen 패널·버튼·도감 아이콘을 연결했고 두 주사위는 12개 원화 프레임으로 약 1.12초간 굴러간 뒤 결과 비교를 표시한다.

최신 UI 검수 명령은 `node scripts/qa-pet-codex-v3-browser.mjs`, 성능 측정은 `node scripts/qa-pet-codex-v3-performance.mjs`다. 아래 구버전 검수 명령과 스크린샷은 최초 구현 기록이다. 현재 증거는 `docs/qa/pet-rework-20261114/unified/`에 있다.

1440·768·390·320px에서 능력치와 특성의 동시 접근, 양쪽 주사위의 서로 다른 프레임, 결과 유지/적용, 개체 편성, 미보유·검색·필터, 응답 재확인, 6종 이펙트와 종료 정리를 검사했다. 이미지 경량화 전후 같은 신규 UI의 최초 표시 중앙값은 12,301→2,054ms다. Windows Chrome headless의 모바일 뷰포트·CPU 4배·80ms 지연·1.5MB/s 조건이며 실제 기기나 운영 서버 측정은 아니다. 주사위 프레임 측정은 별도의 무제한 Windows 호스트 조건에서 p95 4.6ms, 최장 24.9ms, 50ms 초과 0회였다.

실사용 이미지·원화·출처는 `assets/ui/pets/rework-20261114/codex-v3/`, 정확한 제작 프롬프트는 `preview/pet-rework-20261114/ui-v3-prompts.json`에 있다. 신규 기능은 `growth.layout: 'unified'` 어댑터가 연결된 로컬 검수에서만 활성화된다.

상태: 로컬 구현·검수 완료. 운영 API, 데이터베이스, 실제 계정, 배포에는 연결하지 않았다.

## 개편 규칙

- 펫 종별 성장 상한을 C / B / A / S / SS / SSS로 구분한다. 공격·방어·체력·속도는 각각 독립 추첨하며 종별 상한을 넘지 않는다.
- **예시 펫: 흑구. SSS 등급이라고 가정한 설명**이다. 실제 흑구의 운영 등급을 확정하거나 변경한 것이 아니다. 공격 B·방어 A·체력 S·속도 SSS처럼 서로 다른 결과가 가능하고 네 능력치 모두 SSS인 결과도 가능하다.
- 능력치 주사위와 특성 주사위를 분리한다. 능력치는 네 항목을 한 번에 재추첨하고 이전 결과 또는 새 결과 중 한 묶음을 선택한다. 개별 항목을 서로 섞지는 않는다. 특성 변경은 능력치를 보존한다.
- 확인 중인 결과를 보관하고 선택이 끝날 때까지 추가 추첨과 편성을 막는다. 같은 요청의 재시도는 같은 영수증을 돌려줘 주사위가 중복 차감되지 않는다.
- 보유한 개체별 성장과 PvE·PvP 편성을 구분한다. 펫 도감에서 해당 펫을 선택한 뒤 '능력치 · 특성 관리'로 진입한다.
- 화면에서 적용 확률과 비용을 읽을 수 있다. 검수 화면의 확률·비용·보유량은 예시이며 운영 기본값을 추가하지 않았다. 예시의 SSS 3%가 네 번 독립 적용될 경우 전체 SSS 확률은 0.000081%다.

## 특성과 시작 연출

| 특성 | 연결 방향 | 이미지 |
| --- | --- | --- |
| 맹공 | 전투 시작 공격 지원 | 기존 승인 공격 버프 리소스 |
| 수호 | 전투 시작 보호막 | 기존 승인 보호막 리소스 |
| 생명 | 최대 체력 지원 | 기존 승인 생명 리소스 |
| 질주 | 속도 지원 | 기존 승인 속도 리소스 |
| 사냥꾼 | PvE 보스 대상 사냥 표식 | 새 ImageGen 12프레임 아틀라스 |
| 행운 | 지정 콘텐츠 보상 지원 | 새 ImageGen 12프레임 아틀라스 |

공격·방어·체력·속도의 실제 수치 환산과 특성 수치는 운영 정책이 명시되어야 한다. 현재 연출은 전투 결과를 계산하지 않는다. 사냥꾼은 PvP와 보스 없는 전투에서 비활성화되며, 전투 시작 이벤트의 중복·복원 재생을 방지한다.

전투 연동 모듈은 기존 PixiJS 8.20.0, GSAP 3.13.0 및 엔진 타임라인을 사용한다. 별도 렌더러가 있는 작은 검수용 뷰어는 로컬 미리보기 전용이며 운영 전투에 추가하지 않는다. 화면을 닫으면 뷰어와 갱신 작업을 정리한다.
