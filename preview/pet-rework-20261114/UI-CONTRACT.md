# 펫 도감 단일 상세 화면

THESIS: 목록에서 펫 하나를 선택하면 능력치와 특성 관리가 동시에 나타난다. 별도 진입 버튼과 성장 종류 탭을 제거한다.

OWN-WORLD: 기존 리버스콜의 어두운 남색 RPG 도감, 승인된 펫 원화, 기존 버프 이미지. 사용자 요청에 따라 패널·버튼·도감 아이콘을 새 ImageGen 남색 판과 금속 테두리, 청록 버튼으로 교체한다. 전체 게임의 브랜드나 다른 메뉴는 변경하지 않는다.

STORY: 펫 찾기 → 보유 개체 선택 → 능력치 또는 특성 주사위 → 이미지 프레임 굴림 → 기존/새 결과 선택. 편성과 시작 이펙트 확인도 같은 상세 화면에 둔다.

FIRST VIEWPORT: 도감 제목과 수집 현황, 검색·필터, 이미지 펫 목록, 선택한 흑구의 이름·성장 상한. 데스크톱에서는 원화, 능력치, 특성을 나란히 배치하고 좁은 화면에서는 같은 페이지에 세로로 이어진다.

FORM: 사용자가 지정한 좁고 구체적인 도감 기능 통합. established-surface extension, code-led. new-work의 'precisely specified narrow request'에 따라 concept-seed와 별도 시안 선택 없이 구현했다. 승인된 화면 전체 시안은 없으며 새 이미지들은 실사용 리소스다.

QUALITY: 읽을 수 있는 한글, 44px 이상 조작부, 원화 전체 윤곽 보존, 실제 교체되는 12프레임 주사위, 결과 선택 전 중복 차감·편성·개체 변경 차단, 축소 모션 대응, 종료 후 남는 연출 갱신 없음.
