# 영토전 리뉴얼 · 포스터와 신규 전술

사용자 요청: 새 영토전 리소스를 활용해 “영토전 리뉴얼 / 다시 전장으로 !” 포스터를 만들고, 공격·기타 효과 2~3종을 이미지 생성 스킬로 추가한다.

## 결과물

- 포스터 원본: `assets/territory-renewal-poster-v1.png` — 1024×1536 PNG. 실제 `network-v2` 지도와 수호·정화 성채를 참조했다. 문구는 9개 거점·세 갈래 전선, 개인 균형 편성·아군 전용 지휘, 신규 전술 3종이다.
- 생성 방식: built-in `image_gen`, 별도 API/CLI 사용 없음. 포스터 `poster-prompt.json`, 효과 `fx-prompts.json`에 실제 프롬프트를 보존한다.
- 신규 효과: `../../assets/ui/territory-war/renewal-skills-v1/manifest.json`. 원본 PNG 3장, 각 16개의 서로 다른 그림으로 구성한 WebP 아틀라스 3장, 아이콘 3장을 보존한다.
- 기술 검수를 사용자 시각 승인으로 기록하지 않는다. 원본·파생물 해시는 각 매니페스트에 기록한다.

## 스킬 기본값

| 스킬 | 선택 거점 효과 | 제한 |
|---|---|---|
| 천뢰 관통포 | 아군 전력 40 소비, 적 최대 방벽 HP 6% 즉시 피해 | 아군 시설 정상 가동, 적 HP 최소 1 유지 |
| 동력 교란파 | 적 전력 최대 35 감소 | 아군 시설 정상 가동, 이미 예약된 포격 유지 |
| 성채 재건 | 아군 최대 방벽 HP 8% 복구, 전력 +20 | 최대치 안에서 실제 부족량만 보충, EMP 해제 없음 |

기존 25명 투표와 스킬별 45분 공통 쿨타임을 사용한다. 기본값은 구현값이며 사용자 개별 수치 승인으로 기록하지 않는다. OWNER CMS에서 조정할 수 있고 편성 시 회차 정책에 고정한다. V6 다중 거점만 제공하며 영토전 운영 모드는 변경하지 않는다.

## 실제 렌더링과 검수

- 실제 사용 파일: `js/territory-artillery-fx-20261003.js`, `js/territory-battlefield-v5.js` 및 기존 V3 `mountEffectScene`.
- 기존 PixiJS 8.20.0과 GSAP 3.13.0을 재사용한다. 추가 렌더러, 별도 ticker, 정지 이미지의 확대·축소 트윈을 주요 효과로 사용하지 않는다.
- 타임라인: 관통포/교란파 2.8초(충돌 1.2초), 재건 3.6초(충돌 1.5초). 전반 7프레임과 후반 9프레임을 등록된 V3 GSAP 시계에 맞춰 재생한다.
- 관통포는 적 지면, 교란파는 적 시설 중심, 재건은 아군 지면에 고정한다. 각 프레임의 피벗을 사용하고 화면 좌우 안에 전체 효과가 들어오도록 균일 축소한다. 전체 화면 흐림·백색 덮개·새 사운드는 없다.
- 1440×1000 PC와 390×844 모바일에서 효과 3종, 실제 스킬창, CMS 입력을 확인했다. 양 진영 방향, 일시정지/이어 재생/0.5배속/시점 이동/정지, 지도 복귀 중단, 동작 줄이기, 렌더러 정리를 확인했다.
- 연속 프레임의 개별 해시·실제 투명도·불투명 경계 없음, 지연 로딩 중 취소, SQLite/PostgreSQL 투표·재시도·동시 상태 충돌·원자적 롤백을 검증했다.
- 브라우저 검수 원본: `C:/Users/User/.codex/tmp/territory-renewal-20261013/qa/`, 요약 `visual-qa.json`. 테스트/배포 결과는 `../../docs/territory-renewal-skills-20261013.md`.
