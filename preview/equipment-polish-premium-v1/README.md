# 장비 연마 · 고급 제작 리소스 V1

2026-10-05 사용자 요청으로 제작한 청금색 연마석과 전용 제작 연출 검수판이다. 2026-10-04에 승인된 고급 제작라인 흐름을 연마 콘셉트에 적용했다.

## 열기

저장소 루트에서 `node preview/equipment-polish-premium-v1/serve.mjs` 실행 후 `http://127.0.0.1:8937/preview/equipment-polish-premium-v1/`를 연다. 서버는 이 프리뷰와 필요한 공통 자산만 로컬에 제공한다. 파일을 직접 여는 방식은 ES 모듈과 공통 자산 경로 때문에 지원하지 않는다.

다섯 원본은 내장 `image_gen`으로 각각 생성했다. 정확한 생성 프롬프트는 `prompts.json`, 실제 규격·SHA-256·참조 자산·타임라인은 `manifest.json`에 있다. 프롬프트의 요청 해상도와 실제 출력 규격을 구분한다. 생성 PNG를 재압축하거나 다시 그리지 않았다. 아틀라스는 행 우선 16프레임이며 313.5×313.5의 분수 UV 영역으로 읽는다.

기존 아발론 M4A1 원본과 공통 PixiJS 8.20.0 / GSAP 3.13.0 번들을 참조한다. 무기는 전체를 동일 비율로 확대·축소하고 회전하며 총몸과 총열을 따로 변형하지 않는다. 재사용 사운드 세 종은 저장소에 출처가 기록된 Mixkit 기반 편집 음원이며 신규 녹음이 아니다. 원본·라이선스 기록은 manifest의 audio 항목에 연결했다.

## 연출

전용 연마실 → 연마석 충전 → 봉인 대기 → 밀어서 개방 → 파편과 충격파 → 선택된 옵션 상승 순서다. 연출 논리 시간은 하나의 GSAP 시계로 구동하며 대기 화면의 미세 움직임만 별도로 재생한다. 충전 1.4초 후 밀기를 기다리고, 논리 시간 2.50초 충격, 4.35초 옵션 확정 강조, 4.55초 결과 노출, 6.1초 완료로 구성한다. 사용자 대기 시간은 재생 시간에 포함하지 않는다.

2026-10-05 후속 지시 **“이펙트 터지는게 무기보다 아래로 뜨는게 아쉬운듯”**을 반영했다. 개방 아틀라스·충격파·발산 파편의 발생점을 실제 총몸·총열 축 높이(아발론 원본의 정규화 좌표 0.5, 0.30)에 함께 고정했다. 장비의 크기와 전체 회전도 발생점에 반영한다. 탄창까지 포함한 이미지 사각형의 중앙이나 받침대 높이를 폭발 기준으로 사용하지 않는다.

PC 포인터·모바일 포인터·키보드 Enter/방향키, 미완료 밀기 복귀, 바로 결과 보기, 다시보기, 일시정지, 속도 선택, 동작 줄이기, 선택형 사운드를 제공한다. 사운드는 처음에는 꺼져 있다.

## 시연 데이터와 운영 상태

실제 계정·장비·재화를 호출하지 않는 메모리 시연이다. 5개 중 아직 최대치가 아닌 옵션 하나가 같은 확률로 1단계 올라간다. 옵션별 10단계, 전체 20회, 수치·비용은 검수용 예시다. 운영 밸런스 승인을 뜻하지 않는다.

연출 시작 전에 결과 영수증과 시연 차감이 한 번 확정된다. 밀기·건너뛰기·다시보기는 동일 영수증을 표시한다. 새로고침·시연 초기화는 시연 상태를 초기화한다. 실제 서버의 저장·재입장·거래 구현은 포함하지 않는다.

상태는 `RESOURCE_PREVIEW_READY_USER_REVIEW_PENDING`이다. 원본 리소스와 작동 프리뷰를 제공하며 운영 기능 활성화나 최종 시각 승인은 별도로 기록한다.
