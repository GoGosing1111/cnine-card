## 실행

```text
npm run build:v3-wide-grid-preview
npm run test:v3-wide-grid

```

정적 서버에서 `/preview/v3-wide-grid-v1/`을 연다. 작업 중 기존 로컬 서버 `http://127.0.0.1:8793`을 재사용했다. `?grid=original`은 기존안, `?grid=wide`는 확장안이다. 계정 로그인·API 변경·입장권 소모·보상 지급은 없다.

- 기존 / 확장안 버튼: 같은 프레임 안에서 즉시 비교. 전투 중에는 배치 변경 금지.
- 전투 재생: 기존 폐차장 검수 덱으로 일반 적 9마리와 최종 보스 1마리, 2배속.
- 일시정지: 현재 공격과 탄착을 정리한 경계에서 정지. 초기화는 기존 세션을 취소하고 새 렌더러를 준비한다.
- 390px 휴대폰은 5장 도크 전체 표시. 320px 등 좁은 화면은 기존 카드 크기를 줄이지 않고 전장 프레임을 좌우로 스크롤한다. 운영 카드 CSS는 수정하지 않았다.

## 확장 수치

단위는 실제 화면 픽셀이 아니라 공통 V3 디자인 좌표다. PC 1,600×820 / 모바일 1,050×1,500의 원래 씬과 루트 배율을 유지한다.

- PC 확장: 원점 `(705, 90)`, 타일 `190×80`, 외곽 `(40, 50)–(1560, 690)`. 앞줄 발이 하단 카드에 가리지 않도록 상단 여유를 활용한다.
- 모바일 확장: 원점 `(462, 510)`, 타일 `126×76`, 외곽 `(21, 472)–(1029, 1080)`.
- 아군은 원래 슬롯에 행 +1, 적군은 열 +2·행 +1. 카드 순서·인원·개체 ID는 바꾸지 않는다. 중앙 교전 간격만 추가한다.
- 각 캐릭터/슈트는 기존 좌표에서 산출한 `restScale`을 보존한다. 기존 Y에 대응하는 개별 perspective resolver로 이동 중에도 갑자기 축소되지 않게 한다.
- 기존안을 더 작게 만들어 비교하지 않는다. 기존안은 실제 공통 V3의 `configureIsometricScene`, `drawIsometricFloor`, `layoutCharacterGrid`를 그대로 호출한다.

## 공유 엔진 / PixiJS·GSAP

`package-lock.json`: **PixiJS 8.20.0 / GSAP 3.13.0**. 의존성 변경 없음.

- `source/WideGridBattleEngine.js`: 공통 V3 → 기존 `ScrapyardBattleEngine`을 상속한 프리뷰 전용 투영·바닥·배치 어댑터. 기존 `CombatBillboardLayer/IsometricFloor`에 PixiJS `Container/Graphics`로 확장 바닥만 그린다. 두 번째 Application/렌더러는 없다.
- `preview/project-v-v3/source/battle/BattleEngine.js`, `SkillTimeline.js`, `AccountBattleUnit.js`: 기존 GSAP 공격 이동·히트·복귀·슈트 사격 재생을 그대로 사용한다. 게임 판정과 사격 주기는 변경하지 않는다.
- `preview/scrapyard-v3-v1/source/ScrapyardBattleEngine.js`: 승인 방향 확인용 연속 개체 교체와 GSAP 등장 연출을 재사용한다. 죽은 개체의 사격 큐를 비운 뒤 같은 적 슬롯을 재사용한다.
- `preview/scrapyard-v3-v1/battle-bridge.js`: 실제 라이브 V3 카드 도크·프레임·아트 어댑터와 전투 재생/취소/정리를 재사용한다. 이번 작업용 도크 복제나 CSS 덮어쓰기는 없다.
- 충돌은 기존 원본 아틀라스 총구와 현재 대상 좌표로 결정한다. 새로운 사격 프레임·총구 보정·사운드는 추가하지 않았다. 검수 브리지는 음소거이며 운영 사운드 설정은 건드리지 않는다.
- 자산은 기존 폐차장 프리뷰 README의 승인 배경/기어죠/브레이커 SD와 실제 카드·슈트 리소스를 그대로 참조한다. PNG·아틀라스 재생성 없음.

- 1600px/390px 기존↔확장 비교: 모든 아군·적군 `restScale`, 슈트 크기, 루트 배율 동일. 카드 5장의 DOM 위치·폭·높이 동일. 동일 전투 스냅샷 SHA-256 확인.
- PC/390px: 일반 적 9 + 보스까지 **10/10 격파**, 정상 종료, `sustainedFire.queuedDamageEvents=0`, 캔버스 1개.
- 공격 경계 일시정지: `paused=true`, 큐 0. 전투 중 그리드 변경 차단 확인. 정지 상태 초기화 후 이벤트 0·큐 0·캔버스 1·카드 5 확인.
- 320px: 페이지 가로 넘침 없음. 원래 도크의 최소 폭을 보호하는 프리뷰 가로 스크롤로 5번째 카드까지 접근 가능.
- 보조 시계로 전체 재생한 세션에서는 콘솔 오류/경고가 없었다. 일반 시계의 가려진 자동화 창에서는 rAF 제한으로 탄착의 벽시계 6초 제한에 걸리는 경우를 추가 발견했다. 프리뷰 어댑터의 대기 한도만 같은 GSAP 재생 시계로 보완했다. 큐를 버리거나 피해를 생략하지 않으며, 활성 재생 6초 제한·취소 해제·정지 중 대기는 별도 테스트로 확인했다. 초기화 과정의 공통 아포칼립스 자산 캐시 회수 경고도 관측했으며 운영 코드에는 손대지 않았다.
- 자동화 중 가려진 창 전체 재생 검수는 기존 `?backgroundQa=1` 보조 시계로 진행했다. 이 결과를 실기기 FPS 측정으로 취급하지 않는다. 일반 프리뷰 URL에는 보조 시계가 없다. 최종 일반 시계의 가려진 창 전체 재생은 별도 재검수 대상이다.
- 운영 `preview/project-v-v3/`, `js/`, `css/`, `functions/`, `assets/`는 이번 작업 전 HEAD와 동일. 운영 V3 번들 SHA-256: `9932088B85C6BF2AF136C351539E7C56A1A86AD7FBEA086295A5AB6D59CC4727`.
