# 핑두의 금도끼 은도끼

`/preview/golden-axe-v1/`는 선택한 결과를 재생하는 연출 검수 화면이다. 운영 API로 참가·차감·지급하지 않는다. 라이브 화면은 `/events/golden-axe/`이며 같은 UI·PixiJS 연출을 사용한다.

사용자 최종 캐릭터 지시: 핑크색 쫄쫄이를 입은 귀여운 가면 라이더. 큰 둥근 헬멧, 짧은 팔다리, 웃는 녹색 눈의 SD로 제작했다. 노인 신령과 성인 체형 시안은 사용하지 않는다.

## 자산과 재생

- 원본 그대로 복사한 생성 PNG: `assets/ui/events/golden-axe-v1/`의 연못·핑크 라이더·도끼 3종 아틀라스. 생성 프롬프트와 SHA-256은 같은 폴더의 `prompts.json`, `manifest.json`.
- 실제 렌더러: `js/golden-axe-fx-v1.src.js` → `golden-axe-fx-v1.bundle.js`. 기존 `ui-fx-vendor-v2045.bundle.js`를 변경 없이 재사용한다. PixiJS 8.20.0, GSAP 3.13.0.
- 1024×760 논리 좌표: 연못 충돌 (512,607), 라이더 발 (550,650), 당첨 금도끼 중심 (445,320). 아틀라스는 512×1024 세 영역을 나눈다.
- 투척 0–0.95초, 물보라 0.94초, 등장 1.7–2.65초, 도끼 공개 2.5–3.4초, 금도끼/꽝 분기 4.42초, 종료 6.3초. 물방울·파문·반사광·광선은 GSAP 시간에 따라 형태와 위치가 바뀐다.
- 기존 라이선스 확인된 `assets/sfx/v3-role-impact-v2/heal.mp3`를 무가공 재사용하며 기본 소리는 OFF. 출처는 해당 폴더 `PROVENANCE.md`; 충돌/결과 음향은 0.92/4.42초에 연결한다.
- 건너뛰기, 모션 줄이기, 화면 비활성화, 페이지 이탈 정리 지원. 초기 연출 준비는 12초 제한 후 간소화 결과로 전환하고 재생은 10초 안전 제한을 둔다. 서버 결과를 먼저 확정하며 연출이 추첨하거나 재지급하지 않는다.

## 검수

실제 브라우저에서 PC 1440×1000, 모바일 390×844를 확인했다. 당첨·꽝·건너뛰기, 가로 잘림, 결과 표시, 새로고침 후 같은 영수증 복구를 확인했다. 격리 PGlite 계정에서 낡은도끼 1회 차감, H-BODY 지급, 보유 슈퍼스타 +7→+13, 엔진 부품 150개 선택, CMS 잘못된 확률 합계 차단과 OFF 저장을 확인했다. 운영 계정으로 추첨하지 않았다.

`node tests/serve-golden-axe-v1.mjs`는 127.0.0.1:4237에서만 동작하는 격리 검수 서버다. `/qa/golden-axe-admin/`에서 실제 CMS 모듈을 테스트한다. 이 테스트 DB의 100% H-BODY 설정은 운영 기본값이 아니다.

빌드: `npm run build:golden-axe`. 단일 이벤트 빌드는 공용 벤더 번들을 다시 생성하지 않는다. 기능 검증: `npm run test:golden-axe`; 출시는 `npm run release:gate` 및 `npm run deploy:production`.
