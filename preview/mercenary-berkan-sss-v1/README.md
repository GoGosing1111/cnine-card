## 전투 재생과 성능

- 실제 구현: [source/BerkanFX.js](source/BerkanFX.js), [skill.mjs](skill.mjs), [source/preview.js](source/preview.js).
- 잠금 버전: **PixiJS 8.20.0 / GSAP 3.13.0**.
- 기존 `preview/project-v-v3/source/battle/BattleEngine.js`, V3 진형·아트 어댑터·공용 카드 도크를 재사용한다. 별도 전투 렌더러/라이브러리를 추가하지 않았다.
- GSAP 타임라인을 V3의 `simpleTimelines`에 등록한다. 별도 ticker/setInterval/애니메이션 RAF를 만들지 않는다.
- 캐릭터 위치는 이동하지 않는다. 화살은 활끝에서 표적 몸 위치로 이동하며 서버 피해는 계산하지 않는다.
- 기본 사격 방출 **0.82초**, 명중 **1.12초**. 흑금 낙성 방출 **1.70초**, 파열 최고 프레임 **2.08초**, 종료 **4.60초**.
- 오라는 동작별 실제 텍스처·크기·앵커를 추종한다. 쓰러짐에서는 꺼지고, 정지·복귀 시 대기 포즈로 돌아온다.
- 스킬 종료 후 사각 잔상 제보를 재현하고, 베르칸의 두 BlurFilter에 중간 버퍼를 지우는 경로를 적용했다. 기존 광원을 유지하며 큰 시전 포즈에서 대기 자세로 돌아올 때 이전 버퍼 경계가 남지 않는다.
- 스킬 Sprite 풀 40개를 재사용한다. 윤곽 18개와 오라 2개는 한 번 생성한다. 11개 아틀라스의 RGBA 크기 합계 116 MiB이며 프리뷰에서는 전 동작을 미리 읽는다. 같은 원본 텍스처 소스는 Pixi Assets 캐시를 사용한다.
- DB 조회, 서버 polling, 재화 변경, 계정 변경 없음. 추가 타격이나 사망 판정 없음. 신규 사운드는 제작/연결하지 않았다.

## 승인된 SSS 등록/확률

[release/candidate.json](release/candidate.json)과 [release/roster.json](release/roster.json)에 **V-055 베르칸 / SSS**를 준비했다. 기존 54종, CMS 설정과 배정은 보존한다. 2026-09-27 “현재 모션·오라로 확정” 승인으로 운영 카탈로그·기본 스킬 배정과 전투 연결을 추가했다. 기존 운영 CMS 행은 변경하지 않고 신규 행만 읽기 확장한다. V-051~V-054는 별도 승인된 간호사 용병이 사용하므로 베르칸은 V-055다.

`berkanSelectionWeights`는 반영 당시 CMS의 **크라이베른 가중치**를 읽은 정책에 베르칸을 같은 값으로 추가하도록 설계했다. SSS 등급 전체 확률, 기존 카드 간 상대 가중치, 다른 등급·재화 확률은 바꾸지 않는다. 베르칸 가중치를 운영자가 나중에 직접 저장하면 그 값을 우선한다.

현재 운영 CMS의 최신 수치 자체는 이 제작 턴에서 읽지 못했다. 숫자를 추측해 고정하지 않았다. 예를 들어 기존 SSS 가중치가 8991:999:10이면 베르칸 10을 추가하여 크라이베른과 베르칸 모두 SSS 내 10/10010이 된다.

스킬 **흑금 낙성(MS-055)**은 후속 사용자 지시에 따라 `GILDED_STARFALL`의 **후열 우선 최대 2명 동시 타격**으로 변경했다. 후열이 부족하면 전열을 채우고 전투 시작 공격력이 높은 순서로 지정한다. 전체 배율 **5.6**을 대상 수로 나누며, 대상이 하나면 5.6으로 한 번 타격한다. 비용 **35**, 재사용 **5턴**을 한 번 적용한다. 기존 단일 저격 CMS 정의는 읽을 때 이 정의로 확장하며, 다른 용병·배정·확률과 이후 운영자 수정은 보존한다.

**시각 검수 상태:** 2026-09-27 사용자 모션·광원 확정. `runtimeEnabled=true`. 실제 재생은 `preview/project-v-v3/source/battle/BerkanCombatPlayback.js`가 공용 V3의 GSAP 타임라인으로 제어한다. 일반 사격·스킬 모두 서버 결과를 각 한 번만 적용한다.

2명 타격에서도 같은 승인 아틀라스와 40개 Sprite 풀을 사용한다. 두 화살은 1.70초에 함께 발사하고 2.08초에 각 표적 위치에서 파열한다. 회피한 표적의 파열은 표시하지 않고 다른 표적 피해는 그대로 재생한다. 서버 `MERCENARY_STARFALL` 이벤트 하나에 두 피해 결과를 담으며 추가 조회·스킬 비용·독립 시계를 만들지 않는다. 이전 전투의 단일 `MERCENARY_HIT` 기록도 계속 재생한다. 종료 4.60초, PixiJS 8.20.0 / GSAP 3.13.0, 금빛 오라와 사각 잔상 방지 경로는 유지한다.

같은 일반 덱, 양 진영 교대, 네 전투력 구간과 네 덱 유형으로 8,192전 비교한 베르칸의 크라이베른 상대 승률은 **49.98%**다. 두 시드 구간은 50.27% / 49.68%, 단일 보스 평균 스킬 피해는 크라이베른의 **96.06%**다. 운영 승률을 의미하지 않는 로컬 정식 전투 엔진 비교다. [balance-report.json](balance-report.json)에 표본과 결과를 보존한다.
