기존 주작 아우라, 주작 투사체, 강림을 포함한 이전 효과 전체를 현재 자산에서 제거했다. 폐기한 원본·프레임·아틀라스·영상·빌더 180개와 SHA-256은 `retired-phoenix-20261018.json`에 기록한다. 과거 파일은 Git 이력에서만 확인하며 현재 프리뷰에 다시 사용하지 않는다.

사용자 후속 지적에 따라 기존 UI 배치와 CSS는 그대로다. 불필요하게 생성했던 프레임·버튼은 프로젝트에서 제거했고, 전투에 필요한 연출 명칭과 문구만 바꿨다.

## 베르칸·아잔트 상위 밸런스

사용자 후속 “성능은 베르칸 ,아잔트 상위로 밸런스 반영해라”에 따라 `balance.mjs`에 실제 실행 가능한 준비 정책을 반영했다. 비교 대상은 2026-10-15 동일 성능 정책인 V-055/V-056이다.

방어·회피·보호막·억제·기절·침묵·단일 공격 가로막기를 기존 전투 계산에 적용한다. 관통은 연출 콘셉트이며 방어를 무조건 무시하지 않는다. 화살비는 PVE 전용이고 대상 수로 총 예산을 나눈다. 6회 시각 접점이나 마지막 거대 화살은 추가 피해·행동·자원 회복을 만들지 않는다. 특정 상대 코드에 대한 피해 면역·강제 승리·전용 상성 보정은 없다.

검증은 `balance-engine.mjs`가 현재 공용 전투 엔진의 메모리 모듈에만 준비 정책을 연결한다. 별도 전투 계산식을 복제하지 않으며 삽입 지점이 달라지면 실패한다. V-000은 프리뷰 별칭이다. 운영 코드·이름·팩·CMS·계정 보유분을 등록하지 않는다. 재현 명령은 `node preview/mercenary-imperial-archer-sss-v1/measure-balance.mjs`, 결과는 `qa/arrow-v2/balance-report.json`이다.

동일 덱·장비·마법·난수와 양 진영으로 **1,056전** 비교했다. PVP는 베르칸 상대 384전 중 377승, 아잔트 상대도 384전 중 377승(각 98.18%)이다. 이는 해당 동일 조건 모의 대전 결과이며 운영 승률을 의미하지 않는다. 12개 보스/장비 조건 × 8개 난수 × 3용병의 PVE 288전에서 모두 클리어했고, 새 궁사는 평균 클리어 행동이 15.36~35.66% 감소했다. 용병이 담당한 누적 피해는 7.34~13.68% 증가했다. 짧아진 전투의 누적 피해이므로 이를 DPS 상승률로 표시하지 않는다.

`balance.test.mjs`는 실제 상위 능력치, 1회 자원/재사용·피해 예산, 억제·회피·보호막·대상 부재, PVP 광역 제외, 1/5/12대상 광역, 추가 행동·듀오 소유자 격리, 현재 보고서 해시와 미선택 운영 전투 6개의 전체 결과 동일성을 검사한다. 운영 전투 모듈 원본과 공통 번들은 변경하지 않았다.
