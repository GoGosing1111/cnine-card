# X-BODY 추가 광역기 — 천룡 강림

상태: **기술·PC/모바일 검수 통과 / 신규 광역기 사용자 시각 승인 / 운영 연결 OFF**.

2026-09-27 사용자가 승인된 X-BODY와 같은 품질로 크고 화려한 광역기 한 개를 추가하도록 요청했다. 검을 치켜들어 천룡을 소환하고, 거대한 용이 적 진형으로 급강하하며 다섯 접점에서 지면 파열을 일으키는 동작으로 제작했다. 기존 대시·공격·6연격 승인본은 덮어쓰지 않고 비교 버튼에서 그대로 재생한다.

## 01 — 승인 원본 고정

기준은 [X-BODY V2 승인 기록](../battle-suit-x-v1/approval-20260927.json)이다. 승인 원화 SHA-256은 `91cdd399bb2e042b32b6fa7573c8491a913a97d456dcbb8a13dffbb5d49b8ddc`, 고정 칼날·가드는 `f000bc9e0b029beeb6cc8443858a3095ae6a1dcf89601a45a453ef7844d32150`이다. 원본 107개 파일의 해시를 검사해 비대상 승인본의 보존을 확인했다. 이번 범위는 새 광역기 몸 동작과 용·지면 효과이며 원화·칼날·기존 모션은 변경하지 않았다.

## 02 — 동작·적중 설계

전체 길이는 4.60초다. 준비 → 짧은 전진 → 검을 올려 응축 → 천룡 형상화 → 명령 베기와 거대 용 돌진 → 급강하·지면 파열 → 광역 파동 → 회복·소멸로 연결한다. 실제 포즈와 효과 단계는 [motion.mjs](motion.mjs)에 등록했다.

| 단계 | 구간 | 내용 |
| --- | --- | --- |
| 이동·응축 | 0.00–0.80초 | 기존 승인 대시 2프레임과 새 준비·검올림 포즈 |
| 천룡 소환 | 0.46–1.42초 | 코일·머리·뿔·몸통이 점차 드러나는 12프레임 |
| 돌진·급강하 | 1.39–2.68초 | 수평 돌진에서 몸을 꺾어 내려찍는 12프레임 |
| 진형 적중 | 2.18 / 2.24 / 2.30 / 2.36 / 2.42초 | 실제 다중 전장 몬스터 다섯 위치의 지면 접점 |
| 파열·잔향 | 2.12–4.24초 | 돌과 수정 파편, 양쪽 파도형 충격, 지면 파동 |
| 회복 | 2.64–4.60초 | 검 회수와 망토 안정, 모든 효과 정리 |

이는 시각 연출 시간표다. 프리뷰에서 실제 피해·승패·보상·스킬 수치나 계정 상태를 만들지 않는다.

## 03 — 몸 전용 연속 작화

built-in `image_gen`으로 2×2 시트 두 장, 서로 다른 몸 동작 8개를 제작했다. 입력별 역할과 실제 사용 프롬프트는 [prompts.json](prompts.json)에 보존했다. 승인 캐릭터 원화와 몸 전용 기준 시트를 참조해 외형·비율·채색을 유지하고, 무기는 짧은 손잡이만 생성했다. 어깨·팔꿈치·몸통·무릎·망토가 자세마다 달라지는지, 팔·다리 수와 전신 잘림을 원본과 합성본에서 확인했다.

원본: `assets/sources/body-dragon-a.png`, `body-dragon-b.png`.

## 04 — 동일 무기 원본 합성

[기존 칼날 출처](../battle-suit-x-v1/assets/locked/blade-provenance.json)의 단일 RGBA를 사용한다. 원화에서 선택한 25,248개 픽셀은 기존 승인본과 동일하다. [pack-assets.mjs](pack-assets.mjs)는 칼날 전체에 균일 배율·회전·이동만 적용하고, 몸/손 생성 시트를 합성한다. 최종 배율은 모든 동작에서 `600 / 1317 × 0.6`으로 같다. 프레임별 무기 출처·회전·배율과 파지점/칼끝을 [manifest.json](manifest.json)에 남겼다. 새로 그린 칼날은 0개다.

## 05 — 단계별 효과 연속 작화

별도 생성한 4×3 RGBA 시트 네 장, 총 48프레임이다. 소환·돌진은 같은 천룡의 뿔·머리·비늘·금색/청록 팔레트를 유지한다. 머리 방향, 몸통 굽힘, 앞발과 꼬리, 파편·파도·잔향의 형태가 실제로 바뀐다. 프레임별 독립 그림과 투명도를 확인했다.

| 파일 | 역할 |
| --- | --- |
| `assets/sources/fx-dragon-coil.png` | 형상화·소환 |
| `assets/sources/fx-dragon-rush.png` | 돌진·뱅크·급강하·용 형상 소멸 |
| `assets/sources/fx-dragon-impact.png` | 돌·수정 파편·무거운 지면 충격 |
| `assets/sources/fx-dragon-ring.png` | 시전자 검압과 광역 지면 파동 |

지면 파편은 일반 합성을 사용해 돌의 명암을 유지한다. 정지 그림 한 장의 확대/이동만으로 소환·돌진을 대체하지 않았다. 무음 검수이며 합성 테스트음을 추가하지 않았다.

## 06 — 알파·피벗·패킹

[pose-registration.json](pose-registration.json)에 원본 손·발 좌표와 무기 방향을 등록했다. 웅크린 프레임을 보이는 높이로 확대하지 않고 같은 신체 기준을 적용한다. 개별 RGBA 768×768 셀 8개, 3072×1536의 4×2 아틀라스 한 장, 별도 썸네일을 생성했다. 모든 프레임의 바깥 알파는 0이며 전신·무기가 캔버스 안에 들어온다. 소스·프레임·아틀라스·효과 해시는 매니페스트에 기록했다.

## 07 — 접점·지면

천룡의 머리 위치는 프레임별 피벗에서 추적하고, 시전자는 지상 기준으로 서서 소환한다. 칼끝을 몬스터 몸통에 억지로 붙이지 않는다. 광역 효과는 V3의 실제 몬스터 다섯 액터가 가진 서로 다른 지면 좌표에 배치했다. 초기 단일 전장 마운트로 다섯 메타데이터가 겹치던 문제는 공용 native continuous 전장으로 수정했다. PC·모바일의 다섯 좌표가 서로 다르고, 시전자 지면 오차는 0임을 확인했다. 이펙트 OFF 화면에서 실제 몸·무기 동작도 확인했다.

## 08 — 공용 V3·PixiJS·GSAP

[source/preview.js](source/preview.js)는 공용 V3의 실제 native continuous 전장과 기존 `z-body-thunder-v3/fixtures.json` 다중 전투 자료를 사용한다. 일반 카드 5장·카드 도크·등급 프레임·아트 어댑터를 재사용한다. 새 렌더러나 가짜 도크를 만들지 않았다.

[source/DragonFX.js](source/DragonFX.js)는 기존 지원 액터·효과 레이어·카메라에 연출을 올린다. V3에 등록한 GSAP 타임라인 하나가 몸·용·지면·접점·반동을 샘플링한다. PixiJS **8.20.0 한 벌**, GSAP **3.13.0 한 벌**이며 [build-report.json](build-report.json)에 실제 공유 파일과 번들 해시를 남겼다. 모바일에서 큰 용이 잘리지 않도록 전체 진형과 꼬리를 포함해 카메라를 잡고, 넓어진 시야에서도 공용 배경이 끊기지 않도록 같은 카메라 변환을 보정했다.

## 11 — 사용자 시각 승인

기존 X-BODY V2는 사용자 시각 승인과 후속 라이브 배포 지시를 받았다. **이 추가 광역기는 2026-09-27 사용자 “이 연출로 승인”으로 시각 승인됐다**. 기술 검사 성공으로 승인 상태를 자동 승계하지 않는다. [공통 제작 규정](../../docs/project-v-motion-effects-production-standard-20260927.md)의 11단계에 따라 실제 영상과 프리뷰를 제시한 뒤 사용자 확인을 받아 [승인 기록](approval-20260927.json)에 해시를 고정했다.

원본 검수 매니페스트의 `runtimeEnabled`는 `false`로 보존한다. 후속 운영 연결은 별도 운영 매니페스트를 사용한다. 스킬 수치·획득 비용·계정 지급은 이 검수판에 포함하지 않는다.
