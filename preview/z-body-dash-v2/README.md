## 모션

| 구간 | 기존 | 개선 |
| --- | ---: | ---: |
| 돌진 시작 | 340 ms | 55 ms |
| 적 앞 도착 | 640 ms | 190 ms |
| 첫 검격 접촉 | 810 ms | **245 ms** |
| 접촉 자세 유지 | 90 ms | 50 ms |
| 귀환 시작 | 1,160 ms | 390 ms |
| 원위치 도착 | 1,435 ms | 540 ms |
| 동작 종료 | 1,695 ms | **640 ms** |

승인된 16개 대시·검격 프레임의 시간 배치를 바꿨다. 짧게 힘을 모으고 급가속한 뒤 검이 닿는 자세에서 50 ms 멈춰 충돌을 읽을 수 있게 했다.

bodyScale **0.563696948902027**을 유지한다. 헬멧~발바닥 592 px는 월드 기준 333.70859375로 H/S바디와 동일하다. 전장 배치의 공통 rootScale을 그대로 사용하며 검의 여백으로 기체를 축소하거나 체형을 변형하지 않는다.

서버 공격 주기·피해·스킬칩 자격·승패는 변경하지 않는다. 이미 전달된 대시 영수증의 표시 시점을 245 ms로 옮긴다. 승인된 광역기 V3 및 시전 모션 V5의 프레임·충돌 1,080/1,210/1,340/1,430/1,540 ms는 그대로 사용한다.

## 이펙트와 원본

내장 **image_gen**으로 제작했다. 프롬프트와 내장 도구 원본 위치는 [prompts.json](prompts.json), 파일별 SHA-256·크기·알파·프레임 정합 정보는 [assets.json](assets.json)에 있다.

| 용도 | 저장 경로 | 규격 |
| --- | --- | --- |
| 돌진 잔광 | assets/wake-atlas.png | 2,048×1,536, RGBA, 12프레임 |
| 검격 접촉 | assets/cut-atlas.png | 2,048×1,024, RGBA, 8프레임 |
| 잔광 생성 원본 | assets/wake-source.png | 1,448×1,086, 무가공 보존 |
| 접촉 생성 원본 | assets/cut-source.png | 1,774×887, 무가공 보존 |

- 잔광: 코발트·시안의 흐름에 백색 절단광과 금색 필라멘트를 겹친다. 압축→분출→분열→소멸 형태가 프레임마다 변한다.
- 접촉: 가는 검광→응축된 사선 절단→금색 파편→잔향의 8프레임이다. 191 ms에 시작해 네 번째 접촉 프레임이 정확히 245 ms에 나온다.
- 원래 대시 자세를 22/44/66 ms 뒤에서 샘플링하는 3단 잔상과 출발 지면 고리·얇은 속도선·접촉 파편은 보조 계층이다.
- 생성된 RGBA의 알파를 유지했다. Sharp **0.35.2**로 셀 분리·균일 리사이즈·투명 여백·선두점 정렬만 처리했다. 몸체 원본 5개 파일은 수정하지 않았다.
- 사운드는 추가하지 않았다.

## 실제 구현과 재현

PixiJS **8.20.0**, GSAP **3.13.0**. 기존 V3 엔진·카드 도크·아트 어댑터·배치·카메라를 그대로 로드한다.

- 공용 엔진: preview/project-v-v3/source/battle/BattleEngine.js
- 공용 Z 컨트롤러: preview/project-v-v3/source/battle/ZBodySwordAnimation.js
- 모션 시간: source/DashProfile.mjs
- Pixi 프레임·잔상·잔광: source/ZBodyDashFX.mjs
- 상속 연결 및 공용 GSAP onUpdate: source/withDashV2.mjs
- preview-extension.mjs: 프리뷰 빌드 시 컨트롤러의 대시 시퀀스 선택 한 곳과 클래스 내보내기만 확장한다. 운영 소스와 번들을 덮어쓰지 않는다.
- build-report.json: Pixi 1개·GSAP 1개, 실제 입력 파일·운영 기반 해시·번들 해시 기록.

캐릭터 모션과 효과는 같은 engine.timeline의 시간에 맞춰 샘플링한다. 별도 FX 타이머나 두 번째 렌더러는 없다. 취소 시 이펙트·틱 핸들러를 정리하고 원위치·대기 자세로 돌아간다.

프로젝트 루트에서:

```powershell
node preview/z-body-dash-v2/pack-assets.mjs
node preview/z-body-dash-v2/build.mjs
node --test preview/z-body-dash-v2/runtime.test.mjs tests/z-body-sword-live.test.mjs
```

리소스 패킹은 저장된 원본을 우선 사용하므로 내장 도구의 외부 캐시가 없어도 재현할 수 있다.
