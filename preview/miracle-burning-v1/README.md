# 미라클 버닝 검수

- `index.html`: 운영과 같은 `js/miracle-burning-v1.js`와 CSS를 사용하는 발동 팝업. 하늘색 결정 왕관·날개·천상 도시 이미지, 광선·입자·등장 연출. 텍스트는 실제 DOM이다.
- `admin.html`: 실제 관리자 컴포넌트를 가짜 API에 연결한 UI 검수 화면. 전용 OWNER/다른 OWNER 전환, ON/OFF·배율 저장, 팝업 미리보기 가능. 운영 서버에 요청하거나 이벤트를 발동하지 않는다.
- 두 검수 화면 모두 사운드 OFF. 운영 팝업도 별도 합성 사운드를 추가하지 않는다.
- 이미지 원본·운영 변환본의 프롬프트와 SHA-256은 `PROMPT.md`에 기록했다.
