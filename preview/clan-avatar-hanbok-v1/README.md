## 제작 기준과 출처

- 내장 `image_gen` 도구로 인물별 1회씩 총 8개 이미지를 생성했다. CLI·API 우회 생성은 사용하지 않았다.
- 인물별 기존 장비창 원본을 얼굴·헤어·체형·자세 기준으로, 한복 디임을 동정·옷고름·짧은 치마·꽃 자수·노리개 기준으로 사용했다.
- 기존 의상의 클랜 문장·글자·로고를 제거했다. 새 장식은 일반 꽃 자수이며 클랜 표식을 넣지 않았다.
- 한복 디임 참조 원본 SHA-256: `2F8CA42C38EA3865BE2628E2455455EEE5B0EA828EF62EAAE7F534EEC0569BE0`.
- 입력 원본은 변경하지 않았다. 인물별 입력/출력 해시는 [asset-qa.json](asset-qa.json), 실제 사용한 전체 프롬프트와 참조 경로는 [prompts.md](prompts.md), 인물 매핑은 [manifest.json](manifest.json)에 기록했다.

## 비교 화면과 확인 결과

[index.html](index.html)은 정적 갤러리다. 전체·치마·바지/마스코트 필터, 밝은/어두운 배경, 큰 이미지, 이전/다음, 원본과 비교, PNG 저장을 제공한다.

- 자산 검사: 8/8 통과. 정확한 크기, 실제 투명 알파, 충분한 불투명 인물 픽셀, 프레임 경계 잘림 없음, 입력/출력 해시 기록.
- 브라우저: Chrome 1440×1080 PC와 390×844 모바일에서 8종 로딩, 필터, 테마 전환, 비교, 다음 이미지 이동 확인. 가로 넘침과 페이지 오류 없음.
- 시각 확인: PC·모바일 밝은/어두운 갤러리와 비교 화면을 확인했다. 마크 제거, 인물 실루엣, 손·발·치맛단, 밝고 어두운 배경의 투명 경계가 검수 가능하다.
- 결과: [브라우저 검사](gallery-qa.json), [PC 화면](qa/gallery-desktop.png), [모바일 화면](qa/gallery-mobile.png).
- 자산 검사 재실행: 저장소 루트에서 `node preview/clan-avatar-hanbok-v1/inspect-assets.mjs`.

## 반영 범위

현재 상태는 `COSTUME_DESIGN_REVIEW`다. 사용자 요청의 의상 준비 범위로 전신 마스터와 독립 비교 화면을 저장한다. 게임 메뉴·카탈로그·소유권·기간·옵션·DB는 수정하지 않았다. 장비창 전신과 로비 장면은 별도 자산이라는 기존 아바타 계약을 따른다. 로비용 장면과 운영 해상도 파생물은 이 전신 파일로 대체하지 않는다.

작은 자산 준비 작업으로 분류하여 자산 검사와 해당 비교 화면의 PC·모바일 확인만 수행했다. 게임 실행 파일 변경과 운영 매핑이 없어 게임 전체 검사 및 게임 운영 재배포는 수행하지 않는다. 작업 범위 파일만 커밋하고 원격에 보존한다.
