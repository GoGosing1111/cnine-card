## 최신 제작 우선순위 — 사용자 정정

핵심은 **일러스트에 있는 용병을 전투 리소스로 활용하고, 여러 동작과 던전앤파이터 같은 액션, 화려한 기술별 이펙트를 만드는 것**이다. 승인 일러스트의 얼굴·체형·복장·무기·색상/분위기를 유지한다. 기술마다 자세·몸통 방향·동선·무기 궤적·리듬과 주 효과를 다르게 설계한다. 모든 용병에 동일 베기/돌진/폭발을 반복 적용하지 않는다.

**세세한 망토·장식 움직임은 필요하지 않다.** 미세 흔들림과 장식 물리 연출은 기본 작업·완료 조건에서 제외한다. 큰 액션의 의상 실루엣과 기본 관절/손/발의 연결만 필요한 만큼 유지한다. 부드러운 보간만 개선한 결과를 V3.5의 핵심 성과로 취급하지 않는다.

다음 제작은 원화 대조 → 서로 다른 핵심 액션과 고유 효과 설계 → 필요한 공격·회전 교체 작화 → Spine 연결 → 기술별 효과 제작 → 같은 V3 전장에서 정상 속도 비교 순서다. 첫 용병에서 확인한 제작 방식을 확장하되 용병별 액션과 주 효과를 공용 템플릿으로 고정하지 않는다. 세부 흔들림 때문에 대표 액션/스킬 제작을 뒤로 미루지 않는다. 이번 문서 정정은 새 모션/효과 제작 완료를 뜻하지 않는다.

## 현재 V3에서 확인한 것

- 엔진이 다른 별도 모형이 아닌 `project-v-pixi-battle.src.js`의 `mountForBattle`과 `battle-v3-live.js`의 `prepareLoading/createRenderer`를 사용했다. 326개 빌드 소스가 원격 기준과 줄바꿈 정규화 후 일치한다. 정확한 기준 커밋과 해시는 [소스·리소스 기록](qa/current-v3-audit.json)에 있다.
- 공통 로스터 파일에는 57개 항목이 있고, `MercenaryCombatPlayback`에는 전용 `CombatPlayback` 모듈 30개가 연결돼 있다. 로스터 개수는 별도 전용 카탈로그까지 합친 전체 운영 용병 수가 아니다. 전체 용병·모든 스킬을 눈으로 검수했다고 주장하지 않는다.
- 발테르 V-996, 족로 V-979, 카드구 V-970, 아우렌 V-001을 실제 V3 전장에서 각각 두 번 기본 공격시켰다. 준비·접촉·후속 연출·복귀를 녹화하고 추출 프레임을 확인했다.
- 발테르 원본 명세에는 준비, 돌진, 공격, 회전, 회수와 양손 파지/들기/내리치기/복귀 작화가 분리돼 있다. 카드구는 deal/rip/storm/crown 각각 6프레임, utility 4프레임을 갖고 있다. 이것은 자산 명세 확인이며 이번에 모든 모드의 최종 시각 품질을 승인한 것은 아니다.
- 기존 캐릭터마다 신체 픽셀 높이, 이미지 여백, 발 기준점, 기본 방향, 전용 속도가 다르다. 발테르 표시 신체 높이 약 312.39, 족로·카드구 285를 확인했다. 새 Spine은 신체 높이 285를 기준으로 편성 배율을 따르며 전체 PNG 높이로 비교하지 않는다.

## Spine 연결 방식과 검사

`SpineBattleAdapter.mjs`는 기존 BattleCharacter의 view에 공식 Spine 인스턴스를 붙인다. root·팀 반전·HUD·ID·HP는 기존 V3가 소유한다. 원래 `normalAttack`은 Spine 배우에만 분기하고 다른 용병은 기존 구현으로 전달한다. 정식 카드 코드 대신 검수 전용 `QA-V35-SPINE`을 썼다.

- Pixi 인스턴스/캔버스 1개, Spine `autoUpdate=false`, V3 등록 GSAP 타임라인 사용. 별도 실시간 시계나 피해 계산 없음.
- 발테르와 Spine의 같은 전장 혼합 재생, 적 방향 반전, 390px 모바일 브라우저 배치 및 카드 도크 표시 확인.
- 기본 공격 1회당 타격 전달 1회, 편성 위치 복귀, 정지 시 시간·위치 변화 0, 접촉 전 취소 시 추가 타격 0, 사망 표시 제거·부활 표시 복귀 확인.
- 실제 `playEvents`에 TURN/회피/연속 공격 fixture를 넣어 HP 스냅샷 순서대로 반영, 서버 HP 동기화 각 1회 확인. 0.25배 약 3450ms·2배 약 433ms, 공격 중 숨김 시 취소·복귀, resetSession 시 이전 Spine 제거·기존 용병 재진입 확인.
- 계정 API, 실제 서버 피해/재화, 운영 데이터는 사용하지 않았다. 적 방향 검사는 HUNT fixture의 적 용병 배치이며 전체 PVP·협동전 검사와 구분한다. 물리 모바일 성능은 미검수다.

## 다음 작화·모션에 적용할 고정 기준

1. **준비 → 낮은 횡베기 → 몸을 돌린 후속 동작**이 서로 다른 실루엣이어야 한다. 역방향 사선 베기·찌르기·회전 마무리도 기술마다 자세와 발 지지를 다르게 설계한다. 같은 팔 회전에 검광 색만 바꾸는 것으로 대체하지 않는다.
2. 강한 몸통 방향 변화는 새 몸통·팔·손/파지·가려진 부분의 교체 작화를 만든다. 기존 평면 그림을 억지로 늘려서 옆·뒤 시점을 만들지 않는다. 검의 강체 형태와 손 접점은 유지한다.
3. 접근 이동과 제자리 디딤을 분리한다. 현재 연결용 공격에는 root 접근/복귀 이동이 있으나 접근·후퇴 전용 발걸음 작화는 없다. 이것을 최종 돌진 모션으로 승인하지 않는다.
4. V3의 실제 크기, 배경, 앞뒤 배우, HP바/카드 도크를 놓고 검수한다. 확대 프리뷰가 좋아 보여도 모바일에서 포즈가 구분되지 않으면 수정한다.
5. 연출상 여러 검격과 서버 피해 횟수는 별개다. 기존 배속·타격 스냅샷·회피·죽음·복귀 규칙을 그대로 따른다. 새 기술의 수치·발동 조건을 시각 연출 작업에서 임의 변경하지 않는다.

남은 제작: 방향이 바뀌는 교체 작화, 접근/후퇴 및 피격·사망 동작, 복수 기본 공격·대표 스킬과 각각의 고유 효과, 정식 로더/로스터 연결과 전체 대상 모드 검수. 사용자 “좀 낫네 그래도 갈길이 되게 먼데”는 부분 개선 피드백이며 최종 시각 승인으로 확대하지 않는다.
