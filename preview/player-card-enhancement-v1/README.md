# 명함 강화 프레임 프리뷰

2026-09-27 · 독립 검수판 · 운영 연결/활성화 없음

현재 디자인은 프레임 재질의 반사광과 보석 장식, 아우라를 단계적으로 강화한다. 사용자 후속 지시에 따라 기존 최고급 세공 프레임은 +15로 내리고, +20에는 독립 제작한 **천상의 성물** 원화와 전용 후광/빛의 파편을 적용했다. 초기의 전류·테두리를 도는 점·와이어 날개 컨셉은 사용하지 않는다. 사용자가 +20 외형을 승인한 뒤 약간 얇게 요청하여 장식 조각의 균일 배율을 **0.85배**로 줄였다. 원화의 비율/픽셀은 보존한다.

## 실행

```powershell
node preview/player-card-enhancement-v1/serve.mjs
```

`http://127.0.0.1:8975/preview/player-card-enhancement-v1/`

127.0.0.1 바인딩, 필요한 프리뷰/자산만 허용, GET/HEAD만 지원. API·환경 파일·임의 문서는 제공하지 않는다. 포트 변경은 `CARD_FX_PREVIEW_PORT`로 지정한다.

## 비교 단계

| 단계 | 외형 | 연출 |
| --- | --- | --- |
| +0 | 기본 윤곽 | 낮은 반사광 |
| +5 | 연마한 금속 | 넓은 표면 반사 |
| +10 | 입체 면 가공 | 다중 반사와 가장자리 아우라 |
| +15 | 프레스티지 | 기존 최상위 보석 세공, 장식선, 광채 |
| +20 | 천상의 성물 | 전용 금속 장식 원화, 큰 보석, 후광, 반짝임, 빛의 파편 |

+0~+15는 샴페인 골드/크리스털/블랙 크롬의 재질을 비교할 수 있다. +20은 전용 외형으로 고정된다. 수치는 연출 비교용이며 운영 강화 최대 단계·비용·확률·등급을 확정하지 않는다.

## 구현과 자산

- 기존 `js/ui-fx-vendor-v2045.bundle.js`: PixiJS **8.20.0**, GSAP **3.13.0**. 중복 라이브러리/렌더러 없음.
- 기존 `PlayerCallingCard.render`, 명함 CSS 및 아바타/트로피/티어 원본을 사용한다. 계정 API 호출 없이 예시 기록만 표시한다.
- `fx.mjs`: 일곱 개 입체 단면의 법선과 두 개의 넓은 광원으로 금속/크리스털 표면 반사색을 매 프레임 계산한다. 정적인 sprite 기하를 한 texture에 배칭하고 tint만 갱신한다. 모서리 보석과 세공 장식은 Pixi Graphics로 작성했다.
- `legendary.mjs`: 최상위 원화를 5×5 영역으로 구성해 중앙 문장, 모서리, 측면 보석의 비율을 보존한다. 연결 부분만 늘린다. 원본 파일의 픽셀/알파는 수정하지 않는다. 후광, 보석 광원, 십자 반사광, 입자는 공용 GSAP 시간에 맞춰 실제로 재생한다.
- `assets/celestial-relic-frame-v1.png`: 내장 imagegen 도구로 신규 생성한 전용 원화, **1536×1024 RGBA**, 중앙 알파 0. 원본 SHA-256 `89F1849C325DE728D8D886DCEEB2039771008F7656A832F1EAF463A843A8CFC2`.
- 생성 프롬프트/출처는 `assets/PROVENANCE.md`에 기록한다. 다른 카드 프레임 원화를 덮어쓰지 않았다.
- CSS는 배치/버튼을 담당하며 효과를 CSS keyframes로 구현하지 않았다.
- Pixi 자동 ticker OFF. GSAP 시간으로 상시 연출, 강화 연출, 전체 단계 비교, 배속을 통일한다. 강화 연출은 3.60초, **1.02초 광량 최대**, 1.52초부터 감쇠하며 3.60초에 완료한다.
- 효과 OFF/정지/숨겨진 문서는 render callback을 제거한다. 모션 감소 환경은 정지 상태에서 시작한다. 종료 시 tween, observer, 이벤트, Pixi 및 생성 texture를 해제한다. 새 사운드는 사용하지 않는다.

## 관련 검수

- PC/모바일 명함, 원화 모서리/문장 비율, 본문 가독성 및 테두리 정렬 확인. 최상위 프레임에 맞춰 본문 하단 여백을 확보했다.
- 모바일 canvas를 화면 너비 안에 배치하여 아우라로 인한 가로 넘침을 수정했다.
- 5개 단계, 3개 재질 선택, 효과 OFF/ON, 정지/재생, 1.03초 위치 이동, 2배속 전체 단계 비교 및 +20 종료 확인.
- 시즌 기록/트로피 탭, canvas 1개, 명함 이미지 로딩, 콘솔 오류 없음 확인.
- Node에서 프레임 경로의 유한 좌표·경계·법선·이음새, 강화 종료 감쇠, 모듈 구문 확인.
- 로컬 제공 경로 200, API/환경/임의 파일 404, POST 405 확인.
- 모션 감소는 코드에 반영했으며 OS 설정 변경 검수는 하지 않았다.

이 디렉터리만 변경한다. 사용자 시각 승인과 별도 연결 요청 전에는 운영 게임/강화/보상에 연결하지 않는다.
