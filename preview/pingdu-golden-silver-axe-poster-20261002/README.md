- 요청: 게임 내 리소스를 참고한 이벤트 포스터, 10월 2일부터 7일간.
- 표기: **2026년 10월 2일 ~ 10월 8일 · 단 7일간**. 시작일을 포함해 7일이며, 지정되지 않은 시각은 표기하지 않았다.
- 최종본: `assets/posters/pingdu-golden-silver-axe-20261002-v1.png` 및 같은 이름의 JPG, **2048×3072**.
- 편집 가능한 조판 원본: 이 폴더 `index.html`. 생성 그림과 모든 한글 텍스트를 별도 계층으로 유지한다.
- `prompt.json`에 실제 최종 이미지 생성 프롬프트와 정확한 문구를 기록했다.

## 사용 리소스

`assets/ui/events/golden-axe-v1/`의 `pink-rider.png`, `moonlit-pond.png`, `axes.png`를 직접 열어 확인한 뒤 내장 image_gen의 참조 입력으로 사용했다. 핑두의 핑크 헬멧·초록 눈·흰 목도리, 연못·정자·가을 단풍, 금·은도끼의 장식과 보석 색을 계승했다. 기존 게임 원본은 수정하지 않았다.

생성된 글자 없는 `artwork-v1.png`는 원본 그대로 보존했다. Black Han Sans와 Noto Sans KR의 실제 글리프로 제목·브랜드·일정을 조판했으며, 기존 폰트와 SIL OFL 라이선스를 재사용한다. WAGO 표기와 확정되지 않은 보상·확률은 넣지 않았다.
