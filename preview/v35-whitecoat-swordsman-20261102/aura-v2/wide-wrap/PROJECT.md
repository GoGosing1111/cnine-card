# 확대 배치 중간 이력

사용자 “검기가 몸을 폭넓게 감싸야 할 것 같다, 이펙트 자체는 나쁘지 않음”에 따른 확대 후보와 검사·녹화다. `qa/candidate-d.png`의 오른쪽 쏠림을 사용자가 지적해 후속 수정했다. 이 폴더는 최종 중앙 배치로 사용하지 않는다. **현재 검토본은 [balanced-wrap](../balanced-wrap/PROJECT.md)**이다.

기존 작화/텍스처는 유지하며 후보A/B는 단순 확대, 후보C/D는 발밑의 흐름이 내려가지 않도록 위쪽으로 위치를 보정했다. 뒤쪽 폭1.52/높이1.30, 앞쪽 폭1.40/높이1.20 배율을 후속 균형 배치에서도 유지한다. 수치 검사121건 통과가 사용자의 좌우 외형 지적을 대체하지 않는다. 모든 후보 이미지와 중간 녹화를 보존한다.
