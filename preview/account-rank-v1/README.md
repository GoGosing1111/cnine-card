# 계정 레벨·계급 검수판

기획 및 디자인 검토용. 실계정 레벨, 경험치, 재화, 전투와 연결하지 않은 프리뷰다.

## 실행

저장소 루트에서 `node preview/account-rank-v1/serve.mjs` 실행 후
`http://127.0.0.1:8936/preview/account-rank-v1/`를 연다.
다른 포트는 `RANK_PREVIEW_PORT` 환경 변수로 지정한다. 서버는 127.0.0.1에만 바인딩한다.

- 첫 탭: 21계급 선택, 레벨 1~250 변경, 계급 혜택 및 다음 목표.
- 두 번째 탭: 이병·소령·원수 원화 비교, 원래 명함 렌더러에 계급 표식 적용, 로비/클랜/채팅/결과 크기 검수.
- 세 번째 탭: 모든 유저 Lv.1 시작, 전체 PVE별 플레이량과 약 50일 성장 기간. XP 일일/콘텐츠별 획득 상한 없음.
- `mobile-review.html`: 390px/320px iframe에서 모바일 레이아웃을 반복 확인하는 로컬 검수 페이지.

## 범위

확정 방향: 최고 250레벨, 전용 군인 마스코트, 편의/PVE 중심, PVP 전투력 영향 없음, 기존 계정도 Lv.1 시작, 전체 PVE 경험치 획득 제한 없음, 기준 플레이 약 50일 만렙.
제안: 백호 마스코트, 21계급 경계, 모든 XP·버프·프리셋 수치. 상세 근거는 `docs/account-level-rank-proposal-20260916.md`.

원화는 **대표 3종**만 준비했다. 다른 계급은 최종 원화가 아니라 계급 표기 초안임을 명시한다. 생성은 built-in `image_gen`을 사용했으며 요청은 1024px, 반환된 실제 원본은 모두 1254px 정사각 RGBA였다. 원본 PNG를 그대로 보존했다. 프롬프트: `assets/prompts.json`.

## 재사용

- `js/soopketmon-v21-exact-shell-adapter.js`: 부팅 비활성화 후 공통 메뉴 계약만 사용.
- `js/player-card-v2052.js`, `css/player-card-v2052.css`: 명함 렌더러 재사용. 프리뷰 계급 표식만 지역 DOM에 삽입.
- 장비 강화 UI의 네이비·라임 팔레트 및 선택/상세 구성을 계승.
- 어떤 운영 JS/CSS/API 파일도 수정하지 않았다.

## 검증

- `node --test tests/account-rank-preview-v1.test.mjs`: 6개 테스트 통과.
- 기존 명함 테스트까지 함께 실행한 결과: 23개 통과 / 실패 0.
- 1~250 무누락/무중복, 249개 레벨 상승 XP 경계, Lv.250 상한.
- 모든 레벨에서 PVP/클랜/영토/공유 레이드/미정 모드 버프 0.
- PNG 3종 실제 알파 최솟값 0 / 최댓값 255.
- 실제 브라우저 데스크톱, 390px 및 320px 모바일 프리뷰 시각 검수. 페이지 가로 넘침 없음.
- 계급 선택, 표시 탭 전환, 기존 명함 열기·닫기, 원화 교체, PVE별 플레이량 변경 및 50일/25일 계산 확인.

운영 구현 및 배포 완료로 취급하지 않는다. 아직 제작하지 않은 18계급 원화, 서버 경험치 정산, 혜택 연결, 프리셋 저장, 실계정 전파는 별도 후속 구현 항목이다.
