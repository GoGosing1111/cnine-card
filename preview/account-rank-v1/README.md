# 계정 레벨·계급 검수판

기획 및 디자인 검토용. 실계정 레벨, 경험치, 재화, 전투와 연결하지 않은 프리뷰다.

## 실행

저장소 루트에서 `node preview/account-rank-v1/serve.mjs` 실행 후
`http://127.0.0.1:8936/preview/account-rank-v1/`를 연다.
다른 포트는 `RANK_PREVIEW_PORT` 환경 변수로 지정한다. 서버는 127.0.0.1에만 바인딩한다.

- 첫 탭: 전용 썸네일을 갖춘 21계급 선택, 레벨 1~250 변경, 계급 혜택 및 다음 목표.
- 두 번째 탭: 전체 21계급 선택, 기존 명함 렌더러에 계급 표식 적용, 로비/클랜/채팅/결과 크기 검수.
- 성장 방식 탭, 지급량 안내, 필요 EXP, 예상 기간 계산기 제거.
- `mobile-review.html`: 390px/320px iframe에서 모바일 레이아웃 검수.

## 공개 화면과 내부 정책

공개 데이터 `model.mjs`에는 계급·레벨 경계·아이콘·혜택만 남겼다.
경험치 지급 정책과 계산식은 `scripts/internal/account-rank-growth-v1.mjs`에 보관한다. 공개 JS에서 이 파일을 import하지 않는다.
프리뷰 서버는 UI 파일·PNG·공유 명함 리소스만 허용하며 내부 정책, 기획 문서, README, 생성 프롬프트 등의 HTTP 접근은 404다.
이 분리는 로컬 검수 서버 기준이다. 향후 운영 연결에도 동일한 비노출 계약을 적용해야 한다.

## 전체 21계급 원화

훈련병부터 원수까지 **전용 아이콘 21종**을 완성했다. 기존 이병·소령·원수 원본 3종의 해시는 보존했다.
나머지 18종은 built-in `image_gen`으로 각각 제작했다. 원사는 세 갈매기가 위를 향하도록 개별 수정한 `sergeant-major-v2.png`를 사용한다.
모든 원본은 1,254×1,254 RGBA PNG이며 원 밖 실제 투명 알파를 확인했다. 색 계열, 모자·제복, 자세와 막대·갈매기·봉오리·꽃·별 개수로 구분한다.

- 원본 및 해시: `assets/manifest.json`
- 초기 3종 프롬프트: `assets/prompts.json`
- 추가 18종 및 원사 수정 프롬프트: `assets/prompts-expansion.json`
- 최종 파일은 모두 저장소에 복사했다. 생성 원본은 Codex generated_images에도 보존한다.
- 상태는 `CONCEPT_REVIEW`. 기술 검수 완료가 사용자 디자인 승인이나 운영 활성화를 의미하지 않는다.

## 재사용

- `js/soopketmon-v21-exact-shell-adapter.js`: 부팅 비활성화 후 공통 메뉴 계약 사용.
- `js/player-card-v2052.js`, `css/player-card-v2052.css`: 기존 명함 렌더러 재사용. 프리뷰 계급 표식만 지역 DOM에 삽입.
- 기존 게임 네이비·라임 팔레트 및 선택/상세 구성을 계승.

## 검증 · 2026-09-16

- `node --test tests/account-rank-preview-v1.test.mjs tests/player-card-v2052.test.mjs`: **26개 통과**.
- 레벨 1~250 무누락/무중복, 내부 XP 경계, PVP 및 미정 모드 버프 0 검증.
- 21종 파일 경로·SHA-256·실제 알파 최솟값 0 / 최댓값 255 검증.
- 공개 클라이언트의 성장 정보 비포함 및 내부 파일 HTTP 접근 차단 검사 통과.
- 실제 데스크톱과 390px/320px 모바일에서 계급 선택, 두 탭, 명함 열기·닫기 및 계급 연동 확인.
- 브라우저 21종 전체 로딩 확인. 390px/320px 화면의 실 콘텐츠 폭 375px/305px에서 가로 넘침 없음.
- 320px 기존 명함 내부도 가로 넘침 없이 계급·이름·레벨 표시.

운영 구현 및 배포 완료로 취급하지 않는다. 서버 경험치 정산, 혜택 연결, 프리셋 저장, 실계정 전파는 후속 운영 구현 범위다.
