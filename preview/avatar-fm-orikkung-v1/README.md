# FM 오리꿍 (A-20 / FM_ORIKKUNG)

사용자가 승인한 덕코프 오리 형태의 FM 유니폼 아바타. 로비 원본은 무가공 보존하고 장비창은 승인본을 참조해 별도 자세의 네이티브 알파 PNG로 제작했다.

- 제작 도구와 전체 프롬프트: `prompts.md` (내장 image_gen)
- 원본·런타임 파일 해시, 알파 검증과 크기: `manifest.json`
- 파생물 재생성: `node preview/avatar-fm-orikkung-v1/build-assets.mjs`
- 미리보기는 기존 `SoopketmonCharacterLoadoutV2`를 그대로 사용한다.
- 원본 배경 제거·재채색·체형 변형 없이 비율을 유지한 크기 조정, 투명 여백, WebP 압축만 수행한다.

## 승인된 등록·지급

2026-09-17 사용자가 장비창 제작·추가, T1 조은과 동일 옵션, FM 클랜 11일 기간제 지급을 지시했다.

- 운영 T1_JOEUN 기준: 코인 획득량 +75%, 레이드 입장 +10회.
- 사용·공개 ON, 판매 OFF, 이벤트 획득. 기존 T1 조은 설정을 변경하지 않는다.
- 지급 대상은 실행 시 재검증한 현재 FM 시즌 명단이다. 지급 시점부터 정확히 11일 뒤 만료한다.
- 신규 등록·효과 복사·보유권·감사 기록은 `scripts/ops/avatar-fm-orikkung-release.mjs`의 단일 트랜잭션으로 처리한다.
- 같은 지급 기록의 재실행은 기존 결과를 반환하며 추가 지급 또는 만료 연장을 하지 않는다.
- 지급은 장착 상태와 계정 재화를 변경하지 않는다. 기존 아바타 API가 만료 보유권의 장착·효과를 차단한다.
- 운영 지급 명단·시각·만료 시각은 공개 자산에 넣지 않고 DB 작업 영수증 및 비공개 로컬 영수증에 기록한다.
