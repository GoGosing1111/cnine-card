## 생성 리소스

| 리소스 | 연속 프레임 | 실행 파일 |
| --- | ---: | --- |

## 실제 재생과 전투 연결

`js/territory-artillery-fx-20261003.js` → 기존 `ProjectVPixiBattle.mountEffectScene()` → V3 `BaseBattleEngine`의 동일 PixiJS 8.20.0 렌더러 생명주기와 GSAP 3.13.0 등록 타임라인을 사용한다. 추가 CDN·Pixi/GSAP 사본·Canvas2D 포격은 없다. 일반 전투 생성자는 기존 경로를 유지하고, 시각 전용 장면만 `effectScene` 옵션을 쓴다.

`js/territory-battlefield-v5.js`의 기존 서버 이벤트 중복 제거·전선 이력 초기화가 재생을 제어한다. `SIEGE_CANNON`은 발사 준비만 표시하며 실제 발사는 `CANNON_FIRED`를 따른다. 탄체·프레임·반동·접촉을 한 GSAP 시간으로 계산하고, 피해나 승패를 다시 계산하지 않는다.

| 연출 | 발사 | 정확한 접촉 | 종료 |
| --- | ---: | ---: | ---: |
| 공성포 | 0.14초 | 1.05초 | 3.25초 |
| 일반 포격 | 0.06초 | 0.62초 | 1.72초 |

착탄 지점과 비행 종료 좌표는 같다. PC·모바일의 포대 지면을 목표 선택 버튼 위에 두고, 모바일 방벽·중계탑 표시는 위로 모아 포구·착탄이 버튼이나 HUD에 가려지지 않게 했다. 탭 비활성화·전선 지도에서는 타임라인을 일시정지하고, 연출 OFF·닫기에서는 등록 타임라인과 스프라이트를 정리한다. 개인 전투 진입 시 시각 장면을 해제하고 동일 전역 V3 소유권을 넘기며, 복귀 시 포격 장면을 다시 연결한다.
