[v1367] 영토전 자유 점령·소대 지휘·DB bounded-state 누적 패치

기준
- v1366 모집 전용 화면 및 확대 지도 UI
- v1365 모집·균형 편성·보상 구조

핵심 변경
1. 진행 단계
- 모집 RECRUITING: 기본 5시간
- 준비 PREPARING: 기본 10분
- 전쟁 ACTIVE: 기본 120분
- 종료 FINISHED: 신규 공격 차단 후 최종 영토 점수 1회 정산

2. 주기적 영토 유지 점수 완전 제거
- 시간마다 점수를 쓰는 settleHold 로직 제거
- 종료 시 일반/중앙/적 본진 인접 영토를 한 번만 계산

3. 소대 현재 상태 테이블
- territory_war_squads: 회차+진영+소대당 1행
- 소대장/현재 지휘자/현재 영토/상태/행동력/최종 계산 시각/승패/공헌도만 저장
- 개인 행동력 테이블을 신규 로직에서 사용하지 않음

4. 지휘권
- 편성 1번을 소대장으로 지정
- 소대장 명령 미실행 시간이 설정값을 넘으면 2번, 이후 3번 순으로 임시 지휘권 승계 가능
- CMS에서 지휘 유저를 강제 지정 가능

5. 이동·공격
- 아군 인접 영토 이동 무료
- 현재 소대 위치에서 인접한 중립/적 영토만 공격 가능
- 본진과 연결이 끊긴 고립 영토는 공격 출발점으로 사용 불가
- 방어는 행동력 미소모
- 일반/중앙 영토별 주둔 소대 상한 적용

6. 무방비 점령
- 방어 소대가 없으면 기본 30초 점령 작전
- 시간 경과 자체로 쓰지 않고 종료 시각만 저장
- 다음 상태 조회/작전 요청에서 만료를 계산해 1회 반영

7. 점수
- 소대전 승리 기본 1점
- 일반 영토 최종 점령 3점
- 중앙 영토 최종 점령 5점
- 종료 시 일반 5점 / 중앙 15점 / 적 본진 인접 10점 기본값

8. DB 상한
- V2 턴 타임라인은 DB에 저장하지 않음
- 최근 전투는 회차당 설정 건수(기본 100건)만 유지
- 새 회차 생성 시 오래된 작전/전투/소대/영토/참가 운영 데이터 자동 정리
- 미수령 보상은 보존, 수령 완료 보상과 오래된 회차 요약은 제한 보관

주의
- 동일 영토 동시 전투는 영토 단위 짧은 락으로 중복 판정을 차단한다.
- 자동 전투 대기열 순차 실행은 이번 패치에 포함하지 않았으며, 충돌 요청은 잠시 후 재시도 안내로 처리한다.
