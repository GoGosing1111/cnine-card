CNINE CARD v1305 - 공식 자동 뽑기

기준
- v1304 누적본 기준
- v1303 자동 클릭 차단 롤백 상태 유지

추가 기능
- 카드팩 화면에 '자동 뽑기 설정' 버튼 추가
- 1/10/20장 묶음 선택
- 1~500회 반복 횟수 설정
- 4/6/10초 순차 요청 간격 (최소 4초)
- 연출 간소화 선택
- SSR/MA/LIMITED/FUR 획득 시 자동 정지 선택
- 진행 횟수, 획득 장수, 사용 코인, 진행 시간 실시간 표시
- 현재 개봉 완료 후 안전 중지
- 완료 후 등급별 요약과 SSR 이상 획득 기록 표시

안전 및 부하
- 서버 요청은 항상 1개씩 순차 처리
- 병렬 카드뽑기 요청 없음
- 기존 requestId/영수증/결과 무결성 검증 유지
- 코인 부족, 서버 오류, 지급 확인 지연 시 즉시 자동 종료
- 자동 뽑기 전용 DB 테이블/로그/마이그레이션 없음
- 일반 뽑기 API 외 추가 서버 호출 없음
