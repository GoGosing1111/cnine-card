# 반응형 카드 이미지 재생성 (앗-이런 크래시 대응)

현재 매니페스트(`js/responsive-card-images-v1729.js`)에 **337장**만 등록돼 있습니다.
나머지 카드는 화면에 **원본 그대로** 뜹니다. 원본은 평균 1.6MB, 상위 10% 는 3.5MB,
최대 22MB 를 브라우저 메모리에 올립니다(파일 크기가 아니라 `가로×세로×4바이트`).

아래 3단계를 그대로 실행하면 됩니다.

---

## ① 현재 활성 카드 이미지 목록 뽑기 (Neon 에서 실행)

```sql
SELECT json_agg(DISTINCT replace(image_url, '\', '/'))
FROM cards
WHERE is_active = 1
  AND image_url IS NOT NULL
  AND btrim(image_url) <> '';
```

결과(JSON 배열)를 `scripts/active-card-images.json` 으로 저장합니다.

> 몬스터·장비 등 카드 외 이미지도 목록에 넣고 싶으면 UNION 으로 붙이면 됩니다.
> 스크립트는 가로 384px 미만 이미지는 알아서 건너뜁니다.

## ② 변환 실행

```bash
python -m pip install pillow pillow-avif-plugin
python scripts/generate-responsive-card-images.py \
  --input scripts/active-card-images.json \
  --root . \
  --workers 8
```

`assets/responsive/cards/` 에 `<해시>-192.avif/webp`, `<해시>-384.avif/webp` 가 생기고
매니페스트가 갱신됩니다.

## ③ 매니페스트 캐시 버스트

`index.html` 에서 `responsive-card-images-v1729.js?v=…` 값을 올려주세요.
`_headers` 가 `/js/*` 를 1년 immutable 로 잠그기 때문에 이 값을 안 바꾸면
유저는 옛 매니페스트(337장)에 그대로 묶입니다.

---

## 확인

```bash
node -e "
const m=require('fs').readFileSync('js/responsive-card-images-v1729.js','utf8');
console.log('등록 이미지:', (m.match(/\.(png|webp|jpg|jpeg)\"\s*:/g)||[]).length);
"
```

활성 카드 수와 비슷하게 나오면 성공입니다 (현재 337).
