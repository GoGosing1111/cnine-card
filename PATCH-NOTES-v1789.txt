PATCH-NOTES-v1789 : PVE 전투덱 편성 화면의 빛기둥 제거 + 재발 방지 구조 개선

[증상]
PVE 전투덱 편성 화면에서 화면 전체를 가로지르는 대각선 빛기둥이 보인다.
"카드 화면에 CSS 빛기둥 쓰지 말라"는 지시가 반복됐는데도 계속 되살아났다.


[원인 — DevTools 로 확정]
범인은 카드 홀로그램 광택 .card-holo 다. (해당 화면에 24개 존재)

  css/card.css
    .card-holo{
      position:absolute; z-index:4;
      inset:-60%;                                  <- 카드보다 220% 크게 퍼진다
      background:linear-gradient(115deg,
        transparent 38%, rgba(255,255,255,.36) 48%, transparent 58%);
      transform:translateX(-45%) rotate(8deg);
      mix-blend-mode:screen;
    }

  inset:-60% 탓에 254px 카드에서도 실제 렌더 크기가 559x723 이 된다.
  카드가 여러 장 깔리면 이 대각 흰 띠들이 서로 겹쳐서
  화면을 가로지르는 빛기둥처럼 보인다.


[왜 계속 되살아났나 — 두 가지 구조 문제]

1. 화면별로만 껐다
   이미 카드도감에서는 꺼져 있었다:
     css/soopketmon-v21-exact-luxury.css:565
       .dex-card-display .card-holo { display:none !important }
   하지만 .dex-card-display 를 쓰지 않는 화면(PVE 전투덱 편성 등)에는 그대로 남았다.
   화면이 하나 늘어날 때마다 다시 새어 나오는 구조였다.

2. 차단 규칙이 동적 주입 CSS 안에 있었다
   위 soopketmon-v21-exact-luxury.css 는 index.html 이 로드하지 않는다.
   js/soopketmon-v21-exact-shell-adapter.js 의 ensureStyles() 가 런타임에 주입한다.
   따라서 어댑터 실행 전이거나 어댑터가 관여하지 않는 라우트에서는 차단이 안 걸린다.
   (같은 어댑터 246줄이 .light-beams 등 노드를 removeChild 하지만,
    이후 라우트가 재렌더되면 소용없다)


[수정]
새 파일: css/no-light-beams-v1789.css
  index.html 이 "모든 스타일시트 뒤에" 정적으로 로드한다.
  어댑터 동작 여부·타이밍·라우트와 무관하게 항상 적용된다.

  차단 대상:
    .card-holo                                   <- 이번 범인. 전역으로 끈다.
    .light-beams / .light-pillars / .light-beam / .light-pillar
    .ambient-lines / .ambient-beams / .beam-layer / .hero-beams
    .dex-renewal-shell::before / ::after

index.html
  idle-dungeon-v1603-polish.css 다음 줄에 추가 — 반드시 마지막이어야 한다.


[영향 범위 — 확인 필요]
.card-holo 를 전역으로 껐으므로 카드 프레임이 나오는 모든 화면에서 광택이 사라진다.
(도감·PVE 덱·PVP 덱·전투 화면 등. 도감은 원래부터 꺼져 있었다)

  - 전투 화면에서는 남기고 싶다면:
      .battle-v2-live-shell .card-holo { display:block !important; opacity:1 !important; }
    를 no-light-beams-v1789.css 맨 아래에 추가한다.

  - 빛기둥이 아니라 "카드 안에 갇힌 은은한 광택" 을 원한다면:
      .card-holo{ inset:0 !important; opacity:.12 !important; display:block !important; }
    단, 이는 "빛기둥 금지" 지시와 어긋날 수 있으니 확인 후 적용할 것.

  - 되돌리려면 no-light-beams-v1789.css 의 해당 블록만 지우면 된다.


[검증]
Chromium(Playwright)으로 index.html 의 실제 스타일시트 전체를 물린 상태에서
실제 카드 마크업(article.card-frame > div.card-holo)을 6장 렌더링
  → .card-holo 6개 전부 display:none, opacity:0, 크기 0x0
  → .light-beams 도 display:none
