# 여왕 / 즉위 전용 한글 서체

- 글꼴: Google Fonts의 Noto Serif KR, 900.
- 원본 배포: https://github.com/google/fonts/tree/main/ofl/notoserifkr
- 라이선스: SIL Open Font License 1.1, 동봉 `OFL.txt`.
- 취득일: 2026-09-28.
- Google Fonts CSS API의 `text=여왕즉위` 옵션으로 제공받은 네 글자 서브셋을 `NotoSerifKR-royal-900.ttf`로 자체 호스팅한다. 실행 중 외부 폰트 요청을 추가하지 않는다.
- CSS 별칭 `SoopRoyal`. 동적 닉네임과 안내 문구는 기존 한글 UI 서체를 사용한다.
