# Weekly Raid Ultimate FX V1

- Generator: Codex built-in ImageGen
- Output: five transparent 4×3 sheets, exactly 12 chronological frames per skill
- Runtime: approved shared PixiJS 8.20.0 `Sprite` texture sequence, GSAP 3.13.0
- Collision: frame 7, visual peak aligned at approximately 430–480 ms
- Audio: none added; no procedural or placeholder SFX used
- Build: `node scripts/build-weekly-raid-fx-v1.mjs`

Themes are intentionally separate: violet gravity collapse (Nagato), blue-black dimensional severance (Obito), red-gold sun-breathing slash (Yoriichi), golden treasury barrage (Gilgamesh), and black-red crescent annihilation (Ichigo). Each sheet changes silhouette through anticipation, release, impact and dissipation rather than moving one still image.
