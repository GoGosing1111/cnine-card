숲켓몬 v1315 · 일반 PVE 전투엔진 V2 OWNER 실전 적용

배포
- v1314 이하 누적 패치 대신 이 v1315 누적 패치 하나만 적용합니다.
- 기존 일반 유저는 기존 PVE 엔진을 유지합니다.
- 기존 battle_settings_v1에 엔진 설정이 없는 경우 기본값은 V2_OWNER입니다.
- OWNER 계정의 일반 PVE 전투부터 V2가 즉시 적용됩니다.

CMS
- 일반 PVE 전투엔진 모드 추가
  1. LEGACY: 기존 엔진
  2. V2_OWNER: OWNER만 V2, 일반 유저는 기존 엔진
  3. V2_PUBLIC: 전체 공개
- V2 재생 속도는 사용자 조절 없이 1.6배 고정입니다.
- 설정 캐시는 최대 1초이며 게임의 battle/config는 브라우저 캐시 없이 다시 조회합니다.
- 저장 직후 DB 재조회 값이 요청값과 다르면 저장 성공으로 처리하지 않습니다.

일반 PVE V2
- 실제 PVE 덱 5장, 돌파, 카드 고유효과, 덱 시너지, 장비·칭호 PVE 전투력을 사용합니다.
- 카드 전투력을 최대 HP, 공격력, 방어력, 속도로 분배합니다.
- 전열 2장 / 후열 3장, 속도 행동 게이지, 보호막, 회피, 회복, 생존, 반격을 사용합니다.
- 기존 궁극기와 보스 궁극기를 V2 타임라인에 연결했습니다.
- 기존 카드 프레임, 고유효과 CSS, 타격·치명타·궁극기 효과를 유지합니다.
- PC, 와고 iframe, 모바일의 기존 PVE 전투 모달에서 재생됩니다.
- 전투 인트로, 행동 간격, 궁극기 영상 재생률을 1.6배로 고정했습니다.
- 행동 제한으로 끝난 전투는 판정 승리·판정 패배로 명시합니다.

기존 기능 유지
- 전투 횟수 차감, 코인 보상, 카드 드롭, 큐브, 마법 결정, 장비 드롭은 기존 지급 경로를 유지합니다.
- 현재 화면의 반복 자동전투도 한 전투씩 V2 battle/fight를 순차 호출합니다.
- 별도 일괄 처리 API battle/auto와 PVP·무한의탑·레이드·봉인전·대장전은 이번 단계에서 기존 엔진을 유지합니다.
- V2가 비활성인 계정은 기존 판정·연출 코드를 그대로 사용합니다.

DB 및 용량
- 신규 테이블, 컬럼, 인덱스, 마이그레이션이 없습니다.
- V2 전체 타임라인은 API 응답에만 포함되고 D1에 저장되지 않습니다.
- battle_logs는 기존 소형 요약 1행만 기록합니다.
- 기존 저장 정리 기능의 PVE 전투 로그 기본 보존 기간 7일을 그대로 사용합니다.
- 엔진 설정은 기존 app_meta의 battle_settings_v1 JSON 안에만 추가됩니다.
