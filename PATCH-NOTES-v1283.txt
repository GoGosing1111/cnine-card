숲켓몬 v1283 봉인전 1차 플레이어블 누적 패치

기준
- 최신 전체 기준본: cnine-card(39).zip
- 누적 포함: v1279 대장전 DB 수동 정리 + v1280~v1282 대장전 대용량 재발 차단

신규 콘텐츠: 봉인전
- 월드 레이드의 개인 피해량 경쟁과 다른 서버 공동 목표형 보스 콘텐츠
- 파괴 봉인 / 수호 봉인 / 정화 봉인 3개 역할
- 유저는 저장된 PvE 덱 5장으로 하루 정해진 횟수만 참여
- 장비, 카드 고유 능력, 덱 시너지가 반영된 PvE 전투력을 공헌도로 환산
- 서버 전체가 세 역할 목표를 모두 달성하면 봉인 완료
- 현재 가장 진행률이 낮은 역할에는 CMS 설정값만큼 지원 보너스 적용
- 공헌도 순위는 현황 확인용이며 완료 보상은 참여자 모두 동일

유저 화면
- PVE 상단 콘텐츠 탭에 `봉인전` 추가
- 보스명, 보스 이미지, 설명, 운영 상태, 종료 시각 표시
- 서버 참여 인원 / 총 의식 횟수 / 세 역할 실시간 진행도 표시
- 내 PvE 덱 전투력, 오늘 남은 참여 횟수, 개인 누적 공헌도 표시
- 역할 선택 후 봉인 의식 연출과 공헌도/참여 보상 결과 표시
- 봉인 완료 참여자 보상 직접 수령
- 새 이벤트가 시작되어도 이전 봉인전의 미수령 완료 보상 별도 노출
- 전체/파괴/수호/정화 공헌도 현황 조회
- 자동 초단위 폴링 없음: 진입, 참여, 수동 새로고침 때만 D1 조회

CMS
- OWNER 전용 `봉인전 관리` 메뉴 추가
- OFF / TEST / ON 운영 모드
- 콘텐츠명, 보스명, 이미지, 설명, 시작/종료 시각 설정
- 일일 참여 횟수 설정
- 역할별 서버 목표와 전투력 배율 설정
- 가장 부족한 역할 지원 보너스 설정
- 참여 1회 코인/카드 조각 보상 설정
- 봉인 완료 참여자 코인/카드 조각 보상 설정
- 설정 저장 후 새 봉인전 시작
- 현재 활성 이벤트 종료
- 참여 인원, 참여 횟수, 누적 공헌도, 보상 수령 인원과 최근 이벤트 확인

DB 저장 원칙
- 기존 테이블/컬럼/데이터 DROP, RENAME, 초기화 없음
- 신규 테이블만 안전 생성
  * seal_battle_events: 이벤트 1행과 역할별 서버 누적값
  * seal_battle_user_progress: 이벤트당 유저 1행의 누적 공헌 집계
  * seal_battle_action_receipts: 중복 요청 차단용 소형 영수증
  * seal_battle_clear_claims: 완료 보상 중복 수령 차단
- 전투 라운드, 카드 상태, 연출 JSON을 DB에 저장하지 않음
- 참여 영수증에 response_json, battle_log_json 컬럼 자체가 없음
- 요청 영수증은 기본 14일 보존
- 종료·완료 이벤트의 개인 집계와 완료 보상 수령 기록은 기본 90일 보존 후 소량 정리
- 신규 참여 영수증 ID 기준 정확히 20회마다 소량 자동 정리
- 경기/참여 1회당 대용량 중복 JSON이 생성될 경로 없음

원자성/중복 방지
- request_id 고유 영수증으로 동일 참여 중복 반영 방지
- 일일 참여 횟수는 조건부 UPDATE로 선점
- 서버 공헌도, 개인 집계, 참여 보상, 영수증 완료를 D1 batch로 처리
- 마지막 역할 달성 시 이벤트 CLEARED 상태를 공헌도 UPDATE와 동시에 반영
- 완료 보상은 PENDING -> CLAIMING -> COMPLETED 예약 상태로 중복 지급 차단
- 핵심 batch 성공 후 잔액/화면 갱신 조회가 실패해도 이미 반영된 참여·보상을 되돌리거나 중복 지급하지 않음
