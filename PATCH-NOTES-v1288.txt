[SOOPKETMON v1288] 봉인전 공헌도 순위 차등 보상 누적 패치

기준
- 전체 프로젝트: cnine-card(39).zip
- v1279~v1287 누적 포함

신규 기능
- 봉인전 종료 후 전체 공헌도 최종 순위에 따라 차등 보상 수령
- CMS에서 순위 시작/종료 구간을 자유롭게 추가·삭제
- 구간마다 다음 보상을 개별 선택 및 조합 가능
  · 일반 큐브
  · 고급 큐브
  · 프리미엄 큐브
  · 장비 보급상자
  · 코인
- 봉인 실패 시 순위 보상 지급 여부 설정
- 새 봉인전 시작 시 순위 보상 설정을 이벤트에 스냅샷 저장
- 유저 공헌도 현황에서 현재 순위와 구간별 보상 확인
- 종료된 현재/이전 봉인전의 미수령 순위 보상 수령 UI

순위 확정 기준
1. 총 공헌도 내림차순
2. 총 참여 횟수 내림차순
3. 마지막 공헌 시각 오름차순
4. 사용자 ID 오름차순

안전성
- 순위 보상은 유저당 이벤트별 1회만 지급
- 코인·큐브·장비 보급상자 지급과 영수증 완료를 D1 batch로 원자 처리
- 보상 설정은 진행 중 이벤트에서 변경되지 않도록 시작 시 고정
- 전투 상세 JSON 추가 저장 없음
- 기존 DB DROP/RENAME/초기화 없음
- 신규 컬럼/테이블/인덱스만 추가
