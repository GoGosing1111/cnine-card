검토 기준
Android 껍데기에 별도 분석 SDK가 없더라도, 앱 안에서 실행되는 웹 게임이 서버로 보내는 데이터도 포함한다.
아래는 소스 기반 준비표다. Play Console에 자동 제출하지 않았으며 공유 여부·보존 기간·선택 여부를 일괄 '없음'으로 답하지 않는다.

1. 개인 정보 / 사용자 ID
예상 답변: 수집함. 닉네임, 내부 계정 ID. 계정 관리·게임 기능·부정 이용 방지 목적.
근거: functions/api/[[path]].js의 auth/register 및 auth/login.
로그인은 이메일/일반 비밀번호 가입이 아니라 발급된 비밀키의 해시와 세션으로 처리된다. 공개 문서에 비밀키 원문을 수집·공개한다고 쓰지 않는다.
공유/선택 여부: 다른 이용자에게 닉네임이 보이는 기능과 운영 인프라 처리를 구분해 최종 확인.

2. 기기 또는 기타 ID
예상 답변: 수집함. 클라이언트 식별값, 세션 식별/해시, IP 해시 등 계정·보안 정보.
목적: 로그인 유지, 세션 관리, 가입 제한/부정 이용 방지.
정확한 위치/광고 ID/전화번호를 수집한다고 추정하지 않는다. IP 기반 지역 산출·외부 로그 처리 여부는 별도 확인.

3. 앱 활동 / 기타 사용자 제작 콘텐츠 / 앱 내 상호작용
예상 답변: 수집함. 카드·용병·장비·펫·재화·전투·거래·보상·클랜 활동 및 서비스 이용 기록.
목적: 게임 상태 저장, 보상 정산, 오류 및 중복 지급 방지, 커뮤니티 기능.
공개 랭킹·클랜 등 사용자에게 공개되는 범위는 기능별로 구분.

4. 메시지 / 기타 앱 내 메시지
채팅·클랜 대화·메시지 기능의 실제 저장/공개 범위 확인 후 선택.
서비스 기능과 신고 대응 목적. 앱 사용 자체의 필수 데이터와 선택적 대화를 구분.

5. 이메일 주소 / 고객지원 내용
고객지원 이메일로 이용자가 문의할 때 발신 이메일과 문의 내용 처리.
앱 가입 필수 이메일로 오인하지 않는다. 계정 복구/2차 인증의 실제 수집 항목도 추가 확인.
문의 목적 외 이용/보관 여부는 운영 절차로 확정.

6. 앱 정보 및 성능 / 진단
Cloudflare 및 데이터베이스 운영 로그, 장애 추적 서비스/브라우저 보고 여부를 확인.
Android 패키지에는 신규 광고·결제·분석 SDK를 추가하지 않았다. 웹과 인프라의 기존 로그가 '없음'이라는 뜻은 아니다.

7. 금융 정보 / 구매 내역
시즌패스 중단은 사용자 확정. 후원·외부 결제와 게임 혜택 연계, 거래 기록의 현재 운영 상태는 별도 확인.
Play Billing을 구현하지 않은 빌드다. 실제 유료 디지털 혜택이 노출된다면 결제 정책을 충족하도록 구현/운영 정리 후 제출.

8. 위치 / 연락처 / 사진 / 오디오 / 파일
패키지는 위치·연락처·카메라·마이크·외부 저장소 권한을 추가하지 않았다.
웹 입력·업로드·문의 첨부 등 실제 기능이 있는지 확인한 후 각 항목을 확정한다. 권한 부재만으로 수집 부재를 확정하지 않는다.

9. 암호화 / 삭제
사이트는 HTTPS로 연결되며 패키지는 평문 HTTP를 허용하지 않는다.
삭제 요청 경로·처리 대상·보존 예외를 확정하고 실제 처리를 검증하기 전 '삭제 요청 가능' 항목을 완료 처리하지 않는다.
계정 삭제 시 연계 게임 데이터·로그·백업 처리도 포함해 결정한다.

확인 필요 운영 정보
- 인프라/위탁 제공자와 처리 국가, 실제 전송 항목, 보존 기간.
- 인증/복구 수단과 입력 데이터, 2차 인증 자료의 처리.
- 공개 채팅/프로필/순위와 비공개 메시지의 범위.
- 지원 문의와 삭제 요청을 본인 확인하고 처리하는 담당/절차/기간.
- 외부 결제·랜덤 보상의 현재 운영 및 정책 적합성.
