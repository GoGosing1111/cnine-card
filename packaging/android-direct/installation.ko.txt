처음 설치 / 기존 1.0.1에서 전환
1. 안드로이드에서 APK를 내려받고 다운로드 목록에서 파일을 엽니다.
2. 안내가 나오면 다운로드에 사용한 브라우저/파일 앱에 설치를 허용합니다.
3. 기존 앱이 있다면 삭제하지 말고 업데이트 설치합니다.
4. 리버스콜 실행 → 게임 파일 준비 완료 → 게임 시작.
5. 전용 앱 저장소로 전환되므로 기존 게임 개인키로 한 번 다시 로그인해야 할 수 있습니다. 서버의 보유 카드·진행 정보는 같은 계정을 사용합니다.

게임 파일
최초에 필수 파일을 준비하고, 다음 실행부터 저장 파일의 해시를 검사하여 변경·누락·손상된 파일만 받습니다. 이미지·음원은 사용할 때 저장해 재사용합니다. 약 768 MiB 기준으로 오래된 선택 리소스를 정리하며 필수 파일은 유지합니다. 파일 정리는 다음 런처 준비 때 진행합니다.
Android System WebView를 사용하지만 게임 파일 저장은 브라우저/PWA 캐시와 분리된 앱 전용 저장소가 담당합니다. 계정/API/실시간 통신은 저장하지 않으며 플레이에는 인터넷 연결이 필요합니다.

APK 업데이트
1. 앱 실행 또는 게임에서 런처 복귀 시 새 앱 버전을 자동 확인합니다.
2. 새 APK를 자동 다운로드하고 파일 해시·패키지·버전·기존 앱 서명을 확인합니다.
3. '업데이트 설치'를 누릅니다. 첫 이용 시 리버스콜의 '이 출처 허용' 설정이 필요할 수 있습니다.
4. 안드로이드 설치 화면에서 최종 확인합니다. 설치가 끝나면 앱을 실행합니다.
게임 중 설치하지 않으며, 다운로드/검증 실패나 설치 취소 시 현재 앱을 유지합니다.
1.0.1에는 업데이트 기능이 없으므로 이번 버전을 한 번 직접 설치해야 합니다.

인게임 뒤로가기 (1.1.1부터)
열린 메뉴/상세창을 먼저 닫고, 인벤토리/PVP 화면에서는 게임 로비로 돌아갑니다.
로비에서는 2초 안에 뒤로가기를 두 번 누르면 게임 준비 화면으로 돌아갑니다.

Android 7.0 이상 설치 대상. Android System WebView의 최신 지원 버전을 권장합니다. 기기별 실행/설치는 별도 확인이 필요합니다. iPhone/iPad에는 설치되지 않습니다.
