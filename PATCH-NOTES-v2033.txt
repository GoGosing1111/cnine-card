v2033 · 승부예측 MATCHDAY 개편

- 유저 승부예측을 네이비·화이트·코발트 블루의 매치데이 화면으로 전면 교체.
- 축구 / 야구 / 농구 / LOL / 세트카 / 기타 종목 필터, 진행·종료 탭, 내 배팅 필터, 경기 목록 페이지 지원.
- 내 선택과 배팅 금액, 적중 시 예상 수령액(원금 포함), 예상 순이익을 구분. 추가 입력 시 전체 풀과 선택지 풀에 추가 금액을 반영해 재계산.
- 수수료 10%와 행정부 지원금을 실제 정산식과 같은 순서로 적용. 완료·환불 내역은 예상액이 아닌 서버의 실제 payout 표시.
- 선택지별 배당·참여 비율·참여자 명단, 마감 시간, 오늘의 적중왕, 이용 규정·확정 팝업, 빈 화면·오류·OFF 상태까지 개편.
- CMS > 코인 승부예측 > 신규 승부예측 등록에서 카테고리를 선택. 기존 경기는 경기별 카테고리 > 분류 저장으로 변경.
- CMS에도 종목별 목록 필터와 건수 표시. 기존 미분류 경기는 기타로 표시하며 제목으로 자동 추정·변경하지 않음.
- 분류는 기존 app_meta의 독립 키로 저장. 운영 이벤트 테이블 ALTER 없이 기존 경기·배팅·선택·코인 원장 유지, 관리 권한·감사 로그 적용.
- 배팅 최소 10만 / 일반 유저 경기당 최대 5억 / OWNER 보유 코인 기준, 같은 선택 추가, 취소 불가, 자동 마감·정산·무효 환불·기록 24시간 유지.
- 응답 유실 시 동일 요청 번호로 재확인. 경기 마감으로 진행 목록에서 사라져도 복구 버튼 유지. 화면 이탈·계정 변경 시 무단 재시도 방지.
- 모바일 반응형·키보드 포커스·동작 줄이기 지원. V21 경로 식별자와 종료 시 타이머 정리 유지.
- V3 전투, 카드 프레임·캐릭터, 밸런스·보상 정책 변경 없음.
